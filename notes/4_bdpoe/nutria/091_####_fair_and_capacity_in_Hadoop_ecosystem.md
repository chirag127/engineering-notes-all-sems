

#### Fair and Capacity in Hadoop Ecosystem

* Fair scheduling in Hadoop is a method of allocating resources to various applications in a fair manner. This ensures that all applications get their fair share of resources and no single application takes up more than its share. 
* Capacity Scheduler is used to manage resources in Hadoop clusters. It is responsible for allocating resources to applications in a fair and efficient manner.
* Capacity Scheduler works by creating queues and assigning resources to them. It also allows users to configure the minimum and maximum capacity of each queue.
* Capacity Scheduler also supports hierarchical queues, which can be used to create a hierarchy of queues. This allows resources to be allocated in a hierarchical manner.
* Capacity Scheduler also supports preemption, which allows resources to be taken away from one application and given to another application that needs them more.
* Capacity Scheduler also supports multiple levels of scheduling, which allows resources to be allocated in a more granular manner.
* Capacity Scheduler also supports dynamic resource allocation, which allows resources to be allocated to applications on an as-needed basis.
* Capacity Scheduler also supports resource isolation, which allows resources to be allocated in a way that prevents one application from taking up more than its share.
* Capacity Scheduler also supports job prioritization, which allows jobs to be given priority based on their importance.
* Capacity Scheduler also supports job scheduling, which allows jobs to be scheduled in advance so that they can be executed at the right time.
* Capacity Scheduler also supports resource reservations, which allows resources to be reserved for specific applications or users.
* Capacity Scheduler also supports fair sharing, which allows resources to be allocated in a way that ensures that all applications get their fair share of resources.
