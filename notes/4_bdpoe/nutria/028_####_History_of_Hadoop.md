
#### History of Hadoop
1. Hadoop was developed in 2006 by Doug Cutting and Mike Cafarella.
2. Hadoop is an open-source software framework for distributed storage and distributed processing of large datasets on computer clusters built from commodity hardware.
3. Hadoop is designed to scale up from single servers to thousands of machines, each offering local computation and storage.
4. Hadoop was originally inspired by Google's MapReduce and Google File System (GFS) papers.
5. The Hadoop framework consists of two core components: the Hadoop Distributed File System (HDFS) and the MapReduce programming model.
6. HDFS is a distributed file system that provides high-throughput access to application data.
7. MapReduce is a programming model for processing large datasets with a parallel, distributed algorithm on a cluster.
8. Hadoop is used by companies such as Yahoo!, Facebook, and Amazon.com for large-scale data processing.
9. Hadoop is also used for data analysis, machine learning, and other applications.
10. Hadoop is popular for its scalability, reliability, and cost-effectiveness.
