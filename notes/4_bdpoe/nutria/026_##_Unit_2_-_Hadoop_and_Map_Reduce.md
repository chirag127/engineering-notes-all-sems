
## Unit 2 - Hadoop and Map Reduce

Hadoop and Map Reduce are two of the most popular tools used for distributed computing. Hadoop is an open-source software framework for distributed storage and processing of large datasets on commodity hardware. It is based on the MapReduce programming model. Map Reduce is a software library used to process and analyze large data sets in a distributed computing environment.

**Mnemonics and Learning Tricks:**

- **H**adoop is **A**n **D**istributed **O**pen-source **P**rogramming **F**ramework
- **M**ap **R**educe is a **D**ata **P**rocessing **L**ibrary

**Advantages:**

- Hadoop and Map Reduce are both open-source, meaning that they are free to use and can be easily modified to suit the needs of the user.
- Hadoop and Map Reduce are both highly scalable, meaning that they can be used to process large datasets quickly and efficiently.
- Hadoop and Map Reduce are both fault-tolerant, meaning that they can continue to run even if one of the nodes fails.

**Disadvantages:**

- Hadoop and Map Reduce require a lot of maintenance and tuning to ensure optimal performance.
- Hadoop and Map Reduce are not suitable for real-time applications, as they are batch-oriented.
- Hadoop and Map Reduce are not suitable for small datasets, as they are designed to process large datasets.

**Examples and Applications:**

- Hadoop and Map Reduce are used for data mining, machine learning, data analytics, and natural language processing.
- Hadoop and Map Reduce are used for data storage, data warehousing, and data analysis.
- Hadoop and Map Reduce are used for web indexing, log processing, and recommendation systems.
