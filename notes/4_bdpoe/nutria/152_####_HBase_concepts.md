

#### HBase Concepts

- HBase is an open source, non-relational, distributed database modeled after Google's BigTable and is written in Java.
- It is developed as part of Apache Software Foundation's Apache Hadoop project and runs on top of HDFS (Hadoop Distributed File System).
- HBase provides low-latency random read/write access to the data stored in HDFS.
- It is designed to scale up from single servers to thousands of machines, each offering local computation and storage.
- HBase is highly fault-tolerant and can handle large amounts of data and heavy load.
- HBase supports a wide range of data types including numbers, strings, and binary data.
- HBase is a column-oriented database, which means that data is stored in columns rather than rows.
- HBase provides a powerful API for creating, reading, updating, and deleting data stored in HBase tables.
- HBase also provides a rich set of features such as replication, versioning, and security.
- HBase is used for real-time read/write access to large datasets, such as Big Data and Internet of Things (IoT) applications.
- Mnemonics to remember HBase:
  - H: Hadoop Distributed File System
  - B: Big Table
  - A: API
  - S: Scalable
  - E: Enterprise-ready
