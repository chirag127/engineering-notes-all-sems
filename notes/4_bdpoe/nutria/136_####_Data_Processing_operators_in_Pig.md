
#### Data Processing Operators in Pig

1. **FILTER**: This operator is used to filter out the records from the data set that does not match the given condition. 
2. **FOREACH**: This operator is used to apply an expression to each record in the dataset. 
3. **GROUP**: This operator is used to group the data set by one or more fields. 
4. **JOIN**: This operator is used to join two or more datasets together based on the common fields. 
5. **LIMIT**: This operator is used to restrict the number of records in the output. 
6. **ORDER BY**: This operator is used to sort the data set based on the fields. 
7. **SAMPLE**: This operator is used to randomly select a subset of the records from the data set. 
8. **SPLIT**: This operator is used to divide the data set into two or more parts. 
9. **UNION**: This operator is used to combine two or more data sets together.

Mnemonics and Learning Tricks: 
- **FILTER**: Think of a filter that is used to filter out records that don't match a given condition. 
- **FOREACH**: Think of each record in the data set as a person, and apply an expression to each of them. 
- **GROUP**: Think of grouping the data set like gathering a group of people together. 
- **JOIN**: Think of joining two or more datasets together like joining two or more pieces of a puzzle together. 
- **LIMIT**: Think of limiting the number of records in the output like limiting the number of people in a room. 
- **ORDER BY**: Think of ordering the data set like ordering a list of items. 
- **SAMPLE**: Think of sampling the data set like sampling food from a buffet. 
- **SPLIT**: Think of splitting the data set like splitting a cake into two pieces. 
- **UNION**: Think of combining two or more datasets together like combining two or more pieces of paper.
