
#### Spark on YARN
- Apache Spark is an open-source distributed computing platform that enables high-speed and large-scale data processing.
- YARN (Yet Another Resource Negotiator) is a resource management platform that allows multiple applications to run on the same cluster.
- Spark on YARN is a combination of the two, allowing Spark to run on YARN's resource management framework.
- Spark on YARN provides a number of advantages, such as:
  - Improved scalability and resource utilization
  - Improved performance due to better scheduling and resource allocation
  - Improved fault tolerance due to YARN's ability to restart failed applications
- In order to use Spark on YARN, users must configure the Spark environment to use YARN. This includes setting up the YARN cluster, configuring the Spark application, and submitting the application to the YARN cluster.
- Spark on YARN can be used for a variety of applications, such as machine learning, stream processing, and graph processing.
- Mnemonics and learning tricks for Spark on YARN:
  - Spark + YARN = SYnergy (Spark and YARN Working Together)
  - YARN = Yet Another Resource Negotiator
