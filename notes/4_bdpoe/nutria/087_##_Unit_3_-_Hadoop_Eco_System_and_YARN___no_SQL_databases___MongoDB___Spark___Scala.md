
## Unit 3 - Hadoop Eco System and YARN, no SQL databases, MongoDB, Spark, Scala

* Hadoop Eco System: Hadoop is an open-source software framework for distributed storage and distributed processing of large datasets on computer clusters built from commodity hardware. It provides a software platform for distributed storage and processing of big data using the MapReduce programming model. Hadoop Eco System comprises of various components such as HDFS, YARN, MapReduce, Pig, Hive, HBase, Zookeeper, Oozie, Flume, Sqoop and Mahout.

* YARN: YARN (Yet Another Resource Negotiator) is a resource-management platform responsible for managing compute resources in clusters and using them for scheduling of users' applications. It is a large-scale, distributed operating system for big data applications. It provides a central platform to manage resources in a Hadoop cluster, allowing multiple data processing engines such as interactive SQL, real-time streaming, data science and batch processing to handle data stored in HDFS.

* NoSQL Databases: NoSQL databases provide an alternative to traditional relational databases and are used to store and process large volumes of data. These databases are designed to handle structured, semi-structured, and unstructured data. Examples of NoSQL databases include MongoDB, Apache Cassandra, and Redis.

* MongoDB: MongoDB is a document-oriented NoSQL database used for high volume data storage. It is an open-source database system written in C++ that uses a document-oriented data model. It is designed for scalability and high performance and is highly reliable.

* Apache Spark: Apache Spark is an open-source distributed general-purpose cluster-computing framework. It is a fast and general-purpose cluster computing system. It provides in-memory computing capabilities to speed up data processing. It is used for data streaming, machine learning, graph processing, and ad-hoc query processing.

* Scala: Scala is a general-purpose programming language designed to express common programming patterns in a concise, elegant, and type-safe way. It is a multi-paradigm language that supports both object-oriented programming and functional programming. It is designed to be concise and is used for large-scale data processing.

* Mnemonics and Learning Tricks: Mnemonics are memory aids that can be used to help remember facts, figures, and concepts. They are often used in the classroom to help students remember material. Common mnemonic strategies include rhymes, acronyms, visual imagery, and chunking.
