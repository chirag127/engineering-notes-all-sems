

#### Hadoop I/O

* Hadoop I/O is a set of components that are used to read and write data from and to the Hadoop Distributed File System (HDFS). 
* It is responsible for managing the data flow between the client and the HDFS. 
* Hadoop I/O includes the InputFormat and OutputFormat classes, which define the format of the data that is read from and written to HDFS. 
* Hadoop I/O also includes the RecordReader and RecordWriter classes, which are responsible for reading and writing the data from and to the HDFS. 
* The Hadoop I/O also includes the FileInputFormat and FileOutputFormat classes, which are responsible for managing the files that are read from and written to HDFS. 
* Additionally, the Hadoop I/O includes the CompressionCodec classes, which are responsible for compressing and decompressing the data that is written to and read from HDFS. 
* Finally, the Hadoop I/O includes the SequenceFileInputFormat and SequenceFileOutputFormat classes, which are responsible for reading and writing sequence files from and to HDFS. 

Mnemonics and Learning Tricks: 
* InputFormat: I for Input 
* OutputFormat: O for Output 
* RecordReader: R for Read 
* RecordWriter: W for Write 
* FileInputFormat: F for File 
* FileOutputFormat: F for File 
* CompressionCodec: C for Compress 
* SequenceFileInputFormat: S for Sequence 
* SequenceFileOutputFormat: S for Sequence
