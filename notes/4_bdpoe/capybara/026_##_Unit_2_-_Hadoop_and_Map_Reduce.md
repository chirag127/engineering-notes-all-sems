## Unit 2 - Hadoop and Map Reduce

Hadoop is an open-source framework used for distributed storage and processing of large datasets. MapReduce is a programming model used for processing large, distributed datasets. In this unit, we will learn about Hadoop and MapReduce and their applications.

### Hadoop

Hadoop is a distributed system that allows for the storage and processing of large datasets across multiple computers. It is designed to handle big data and is used by many companies to process vast amounts of data quickly and efficiently. Hadoop consists of two main components:

- Hadoop Distributed File System (HDFS): HDFS is a distributed file system that allows for the storage of large datasets across multiple computers. It is designed to handle large files and can be accessed using the Hadoop API.

- Yet Another Resource Negotiator (YARN): YARN is a resource management system that allows for the scheduling of tasks across multiple computers in a Hadoop cluster. It manages the resources required for processing tasks and ensures that tasks are executed efficiently.

### MapReduce

MapReduce is a programming model used for processing large, distributed datasets. It consists of two main functions:

- Map: The map function takes a set of input data and converts it into a set of key-value pairs. Each key-value pair represents a specific attribute of the input data.

- Reduce: The reduce function takes the output of the map function and combines it into a smaller set of key-value pairs. The reduce function is used to aggregate the data and perform calculations on it.

### Advantages of Hadoop and MapReduce

- Scalability: Hadoop and MapReduce are designed to handle large datasets and can scale to accommodate more data as needed.

- Speed: Hadoop and MapReduce can process large datasets quickly and efficiently, making them ideal for processing big data.

- Fault-tolerance: Hadoop and MapReduce are designed to be fault-tolerant, meaning that they can continue processing data even if there are failures in the system.

### Applications of Hadoop and MapReduce

- Big data processing: Hadoop and MapReduce are commonly used for processing large datasets in industries such as finance, healthcare, and retail.

- Data warehousing: Hadoop and MapReduce can be used to store and process data in a data warehouse, making it easier to access and analyze data.

- Log processing: Hadoop and MapReduce can be used to process log files, making it easier to identify patterns and anomalies in data.
