## Unit 3 - Hadoop Eco System and YARN , NoSQL Databases, MongoDB, Spark, Scala

In this unit, we will explore the Hadoop ecosystem and YARN, NoSQL databases, MongoDB, Spark, and Scala. These are essential tools for big data processing and analysis. 

### Hadoop Ecosystem and YARN

- Hadoop is an open-source framework for distributed storage and processing of large datasets on clusters of commodity hardware.
- The Hadoop ecosystem includes tools for data ingestion, data processing, and data storage.
- YARN (Yet Another Resource Negotiator) is a cluster management technology that manages resources in a Hadoop cluster and schedules jobs.
- YARN is responsible for managing resources and scheduling computations on the cluster.
- The Hadoop ecosystem is built using HDFS (Hadoop Distributed File System) for distributed storage and MapReduce for distributed processing.
- Hadoop provides fault-tolerance and scalability for big data processing.

### NoSQL Databases

- NoSQL (Not Only SQL) databases are non-relational databases that provide flexible data models and scalability.
- NoSQL databases are used in big data applications where data is unstructured and requires flexible schema design.
- NoSQL databases allow for easy scaling and high availability.
- Some popular NoSQL databases are MongoDB, Cassandra, Couchbase, and Redis.

### MongoDB

- MongoDB is a document-oriented NoSQL database that provides high scalability and flexible schema design.
- MongoDB stores data in JSON-like documents and provides indexes for fast querying.
- MongoDB supports sharding for horizontal scaling and replication for high availability.
- MongoDB is used in big data applications for its flexibility and scalability.

### Spark

- Spark is a distributed computing framework that provides fast processing of large datasets.
- Spark supports various programming languages such as Java, Python, and Scala.
- Spark provides a high-level API for data processing and supports SQL, streaming, and machine learning.
- Spark provides fault-tolerance and caching for fast processing of datasets.

### Scala

- Scala is a programming language that runs on the Java Virtual Machine (JVM).
- Scala is a hybrid of object-oriented and functional programming paradigms.
- Scala is a popular language for big data applications and is used in tools such as Spark and Akka.
- Scala provides type inference, pattern matching, and higher-order functions for concise and expressive code.

In conclusion, the Hadoop ecosystem and YARN, NoSQL databases, MongoDB, Spark, and Scala are essential tools for big data processing and analysis. Understanding these tools and their applications is crucial for anyone working with big data.
