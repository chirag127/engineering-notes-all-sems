#### History of Hadoop

Hadoop is an open-source software framework that is used for storage and processing of large-scale data sets. It was created by Doug Cutting and Mike Cafarella in 2005. The name "Hadoop" was inspired by the name of a toy elephant that belonged to Doug Cutting's son.

Here's a brief history of Hadoop:

1. In 2003, Google published a paper on the Google File System (GFS), which was a distributed file system that allowed for the storage and processing of large-scale data sets.

2. In 2004, Google published another paper on MapReduce, which was a programming model that allowed for the processing of large-scale data sets.

3. In 2005, Doug Cutting and Mike Cafarella started working on an open-source implementation of the GFS and MapReduce papers. This open-source implementation was named "Hadoop".

4. In 2006, Yahoo! became the first major user of Hadoop. They used it to process and analyze their web search data.

5. In 2008, Hadoop became a top-level Apache project.

6. In 2009, Hadoop 0.20 was released, which included improvements to the Hadoop Distributed File System (HDFS) and MapReduce.

7. In 2011, Hadoop 0.23 was released, which included improvements to HDFS, MapReduce, and the introduction of Hadoop Common.

8. In 2012, Hadoop 1.0 was released, which included improvements to HDFS, MapReduce, and Hadoop Common.

9. In 2013, Hadoop 2.0 was released, which included improvements to HDFS, MapReduce, and the introduction of YARN (Yet Another Resource Negotiator).

10. Since then, Hadoop has continued to evolve and improve. Today, it is used by many companies and organizations around the world for storage and processing of large-scale data sets.

Mnemonic: "Google MapReduce -> Hadoop -> Yahoo! -> Apache -> Hadoop 0.20 -> Hadoop 0.23 -> Hadoop 1.0 -> Hadoop 2.0 -> YARN"
