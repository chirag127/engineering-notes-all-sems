### Drivers for Big Data

The major drivers for Big Data are:

1. Increased data volume: The amount of data in the world is exploding. More data is being generated than ever before from sources like social media, e-commerce, and IoT devices. This huge volume of data is a key driver for Big Data.

2. Increased data velocity: The speed at which data is being generated and processed is increasing rapidly. For example, data from internet activity or sensors is streaming in at a high velocity. This velocity of data is another driver for Big Data.

3. Variety of data: Data today comes in all types of formats (structured, unstructured, semi-structured). The variety of data including text, audio, video, etc. needs to be processed and analyzed, driving the need for Big Data.

4. Low cost of data storage: The cost of storing data has decreased significantly with the advent of cloud storage and technologies like Hadoop. This low cost of storage has enabled storing huge amounts of data and is an important driver for Big Data.

5. New data sources: There are many new sources of data today like social media, IoT devices, and more that are generating data. The emergence of these new data sources results in an increase in data volume, velocity, and variety which are drivers for Big Data.
