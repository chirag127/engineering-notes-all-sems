## Unit 3 - Hadoop Eco System and YARN , NoSQL databases , MongoDB , Spark , Scala

### Hadoop Eco System and YARN

- Hadoop Eco System refers to the suite of tools and libraries developed around Hadoop for storage and processing of large data sets. It includes tools like Pig, Hive, HBase, Zookeeper, Oozie, Flume, Sqoop, etc.
- Yet Another Resource Negotiator (YARN) is the resource management layer of Hadoop. It separates the resource management and job scheduling/monitoring function from the programming model. This enables running multiple data processing engines on Hadoop cluster, dynamically share cluster resources and scale.
- Advantages of YARN: Scalability, Multi-tenancy, Compatibility with MapReduce, Ability to run multiple data processing engines.
- Key components of YARN are ResourceManager, NodeManager and ApplicationMaster.
- YARN powers many of the tools in Hadoop Eco System.

### NoSQL databases

- NoSQL databases are non-relational databases that store data in formats other than tables/records. They are distributed, scalable and open-source.
- The need for NoSQL databases arose due to limitations of RDBMS like rigidity, scalability issues with increase in data volume/variety/velocity.
- Types of NoSQL DBs: Key-Value stores (DynamoDB), Document DBs (MongoDB, CouchDB), Wide-column stores (Cassandra, HBase), Graph DBs (Neo4j, JanusGraph).
- Advantages: Scalability, Schemaless, Distributed, Open source. Disadvantages: Eventual consistency, Limited query capabilities.
- Use cases: Content management, Real-time analytics, IoT data.
