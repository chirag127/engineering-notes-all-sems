### Big Data technology components

The core components of a big data ecosystem are:

1. Data sources - The input data which feeds the big data system. It can be data from sensors, social media, transaction logs, etc.
2. Ingestion - The process of capturing and bringing data into the big data system from various sources. Tools like Flume, Kafka, Spark Streaming are used for data ingestion.

Mnemonic: First we INGEST data like food into our system.

3. Storage - The data is stored in a storage system. Distributed file systems like HDFS and NoSQL databases like HBase are commonly used.

Mnemonic: We STORE the ingested data for later use.

4. Processing - The stored data is processed and analyzed using various tools. Processing can be done in batches using MapReduce or in real-time using Spark Streaming or Storm.

Mnemonic: We PROCESS the stored data to extract insights.

5. Analysis - The processed data is analyzed to find patterns and insights. Tools like Hive, Pig, Spark MLlib are used to analyze the data.

Mnemonic: We ANALYZE the processed data to gain knowledge.

6. Visualization - The insights are represented visually using tools like Tableau or Power BI. This makes it easier to understand the insights by humans.

Mnemonic: We VISUALIZE the analyzed data for easy understanding.

The advantages of big data technologies are:

- Ability to handle large volumes of data
- Enables fast processing of data
- Integrates various data sources and data types
- Provides various options for data processing, analytics and visualization
- Scalable and cost effective

The disadvantages are:

- Require skilled personnel to implement and use
- Complex ecosystems with many interconnected components
- Require high performance computers and networking
- Privacy and security concerns with huge data sets

Applications of big data:

- Recommendation systems
- Fraud detection
- Sentiment analysis
- Predictive analytics
- Precision medicine
- Automated driving
