## Hadoop Eco System Frameworks , Pig , Hive and HBase

### Hadoop Eco System

- Hadoop Eco System refers to the suite of Apache open source software libraries and tools that are designed to solve the big data problems.
- The core Hadoop framework consists of Hadoop Common, Hadoop Distributed File System(HDFS) and Hadoop YARN.
- Hadoop Common - contains the common utilities and libraries that support other Hadoop modules
- HDFS - distributed file system that stores data on commodity machines, providing high throughput access to large datasets
- YARN - resource management platform responsible for scheduling applications, allocation of cluster resources and job monitoring
- Other frameworks in Hadoop Eco System - Hive, Pig, HBase, Spark, Kafka, etc. which are built on top of core Hadoop components to solve specific problems.

**Mnemonics:**
Think of Hadoop Eco System as a shopping mall. Core Hadoop frameworks are the basic infrastructure like parking, electricity, etc. Other frameworks are like the variety of stores built over the infrastructure to serve different needs.

### Pig

- Pig is a high-level data flow language and execution framework for parallel computation.
- It removes the complexity of MapReduce programming by providing an easy to use language called Pig Latin to analyze large datasets.
- Pig Latin statements are converted into MapReduce jobs which are executed on the Hadoop cluster.
- Some advantages of Pig are - Easy to learn, handles complex data processing tasks, ability to handle nested data and combination of data types, optimizes execution of jobs, etc.
- Used for - filtering, grouping, joining, ordering, etc. data processing tasks on large datasets.

**Mnemonics:**
Pig makes Hadoop oink by making Hadoop programming easy as child's play.
