#### Input Formats in Map Reduce

The input data to a MapReduce job is divided into input splits which are processed by the map tasks. The *InputFormat* is responsible for dividing the input into splits and providing the map tasks a RecordReader to read records from the splits.

Some commonly used InputFormats in MapReduce are:

- TextInputFormat: Used for plain text input. Splits input on newline characters.
- KeyValueTextInputFormat: Used for input in the form of <key> <value> pairs. Splits input on newline characters.
- NLineInputFormat: Splits input into splits of N lines. N is configurable.
- SequenceFileInputFormat: Used for reading sequence files generated by SequenceFileOutputFormat.
- DBInputFormat: Used to read data from databases. Queries database and converts results to key-value pairs for maps.

**Mnemonics**: For exams, remember the common InputFormats by associating their names with their usage. For e.g.
* TextInputFormat - Used for plain text
* KeyValueTextInputFormat - Key-value pair input
* NLineInputFormat - Configurable number of lines per split
* SequenceFileInputFormat - Reads sequence files
* DBInputFormat - Reads from databases

**Advantages**: Appropriate selection of InputFormat can optimize performance based on data characteristics and job requirements.
**Disadvantages**: Incorrect selection of InputFormat can lead to suboptimal performance or job failures.
**Examples**: TextInputFormat is used for word count. DBInputFormat is used to read data from a MySQL database and filter/process records in MapReduce.
