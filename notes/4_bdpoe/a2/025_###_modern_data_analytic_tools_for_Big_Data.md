### Modern Data Analytic Tools for Big Data

The following are some of the popular modern data analytic tools used for Big Data -

1. Hadoop EcoSystem - Hadoop is a framework for distributed storage and processing of very large data sets on computer clusters. It includes tools like HDFS, MapReduce, Pig, Hive, HBase, Zookeeper, Oozie, Flume, Sqoop, etc. which can be used for data processing, storage, analysis and modeling at massive scales.

- **HDFS** - Hadoop Distributed File System is the primary storage system used by Hadoop for storing huge data on commodity hardware.
- **MapReduce** - A programming model for processing large data sets with parallel, distributed algorithms on a cluster.
- **Pig** - A high-level dataflow language and execution framework for parallel computation. It allows users to write complex MapReduce transformations using a simple scripting language.
- **Hive** - A data warehouse infrastructure built on top of Hadoop for providing data summarization, query, and analysis.

2. Apache Spark - A fast and general-purpose cluster computing system. It provides APIs in Python, Java, Scala, and R and supports a wide variety of workloads such as batch processing, streaming, machine learning, and graph processing. Some of the main components of Spark are Spark Core, Spark SQL, Spark Streaming, MLlib, and GraphX.

3. TensorFlow - An open source software library for numerical computation using data flow graphs. It is primarily used for machine learning applications such as neural networks. It has APIs in Python, C++, Java, Go, and R.
