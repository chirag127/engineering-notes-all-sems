### SCALA

Scala is a general-purpose programming language that combines object-oriented and functional programming concepts.

- Scala is statically typed, supports functional and object-oriented programming.
- It runs on Java Virtual Machine (JVM) and can interoperate with Java code.
- Scala's syntax is designed to be clean, concise and less prone to errors.
- It emphasizes immutability and pure functional programming style.

Some key points to remember:

- Everything in Scala is an object, including primitives.
- Uses == for equality check and === for reference equality.
- Uses var for mutable variables and val for immutable variables.
- Supports named and default arguments, variable length arguments, closures, etc.
- Has rich standard library and can leverage Java's vast library ecosystem.
- Offers concise and readable syntax using symbols like => for functions, :: for cons operator, etc.
- Supports both imperative and functional styles along with strong support for concurrent and distributed programming.

Few advantages of Scala:

- Increased productivity due to concise and expressive syntax.
- Combination of OOP and FP paradigms gives flexibility to choose appropriate style for the problem.
- Static typing avoids runtime errors and increases code reliability.
- Can leverage existing Java frameworks and libraries.
- JVM integration enables Scala code to be efficient and scalable.

Few applications of Scala:

- Used by Twitter for performance critical components.
- Used by Foursquare, LinkedIn, Netflix, Tumblr, etc.
- Useful for scientific computing and data science applications due to ML libraries like MLlib.
- Great choice for concurrent and distributed systems due to actor model and ScalaSTM.
- Suitable for developing Android apps when used along with Scaloid or ScalaDroid frameworks.
