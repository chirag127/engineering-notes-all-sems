#### IBM Big Data strategy

IBM's big data strategy revolves around its IBM Cloud and IBM Watson platforms. The key components of IBM's big data strategy are:

1. IBM Cloud: IBM Cloud provides the infrastructure to store and manage big data. It offers storage, computing resources, and services to build big data applications. IBM's cloud-based big data services include IBM Db2 on Cloud, IBM dashDB, and IBM Analytics Engine.

2. IBM Watson: IBM Watson is IBM's AI platform. It enables businesses to gain insights from their data using machine learning and NLP. Key Watson services for big data include Watson Explorer, Watson Studio, and Watson Machine Learning.

3. Data science and analytics tools: IBM offers various tools for data scientists and analysts to explore, clean, and analyze data as well as build analytics models. Some key tools are IBM SPSS Statistics, IBM SPSS Modeler, and IBM Data Science Experience.

4. Data integration: IBM has capabilities to integrate data from various sources. It offers IBM InfoSphere Information Server which helps to integrate, cleanse, transform, and deliver data.

5. Hadoop and Spark: IBM works with Hadoop and Apache Spark, which are open-source frameworks for storing and processing big data in a distributed fashion. IBM offers its distribution of Hadoop called IBM BigInsights and IBM Spectrum Conductor which manages workloads on Hadoop and Spark clusters.

Advantages of IBM's big data strategy:
- It provides a comprehensive set of capabilities for the entire big data lifecycle from storing to analyzing data.
- The cloud-based and AI-powered services can enable faster insights from data.
- The open-source integrations make it flexible and compatible with other tools in the big data ecosystem.

Disadvantages:
- The multitude of tools and services can be confusing and overwhelming to navigate.
- IBM's services can be expensive compared to some other cloud and analytics providers.
- IBM has to keep up with the fast pace of changes in big data technologies like Hadoop and Spark.
