#### Spark Applications

1. Spark Streaming: Spark Streaming utilizes Spark Core's fast scheduling capability to perform streaming analytics. It ingests data in mini-batches and performs RDD transformations on those mini-batches of data. Some key benefits of Spark Streaming are:

- It can recover from failures and process data reliably.
- It can process data at a very high throughput.
- It supports stateful and stateless processing.
- It has a high-level API that speeds up development.

Mnemonics to remember key points:
- Mini-batches of data (not micro-batches)
- Fault-tolerant and high throughput
- Stateful and stateless processing supported
- High-level API for fast development

2. Spark SQL: Spark SQL utilizes the Spark Core's computational power to perform relational processing on data. It exposes a SQL-like interface called DataFrames API and can also act as a distributed SQL query engine. Some key benefits of Spark SQL are:

- It is easy to learn for SQL professionals and SQL users.
- It supports a wide variety of data sources like JSON, Parquet, Hive, etc.
- It can be tuned and optimized easily as per the use case.
- It can handle petabytes of data and trillions of rows with ease.

Mnemonics to remember key points:
- Easy to learn for SQL users (Uses SQL-like interface)
- Supports diverse data sources (json, parquet, hive, etc.)
- Easily tunable and optimizable
- Scales to huge data volumes with ease
