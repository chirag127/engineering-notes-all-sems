#### Applications on Big Data using Hive

Hive is a data warehouse system built on top of Hadoop for providing data summarization, query, and analysis. Following are some of the major applications of Hive on Big Data:

1. Data Warehousing - Hive enables the distributed storage and processing of huge datasets on Hadoop and provides tools to query and analyze the data similar to traditional databases. It allows users to write queries using a SQL-like language called HiveQL making it easy for developers and analysts comfortable with SQL to work with Hadoop datasets.

2. Business Intelligence - Hive facilitates BI analysis on Big Data as it allows traditional SQL queries and also provides mechanisms to project and join queries from multiple tables. This enables easy data aggregation, filtering, and complex analysis on huge data which can then be visualized for various business insights.

3. Data Visualization - The analyzed and aggregated data from Hive can be plugged into data visualization tools for effective data representation. Tools like Tableau and Power BI can be integrated with Hive to plot beautiful charts, graphs, and infographics from the mined data.

4. Machine Learning - The preprocessed and structured data from Hive can be fed into machine learning models for training and analysis. Hive's SQL-like interface provides an easy mechanism to extract required features and labels from Big Data which can then be used for machine learning tasks like classification, clustering, regression, etc.

Some Mnemonics and tips for learning:

- Think of Hive as a SQL-on-Hadoop tool.
- Remember HiveQL is like SQL and makes it easy for SQL users.
- Hive warehouses and analyses data but does not modify or update data.
- Hive is suitable for analytic queries over large datasets.
- Hive provides mechanisms for joining tables and running aggregation queries.
