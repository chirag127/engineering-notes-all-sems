#### Grunt in Pig

Pig Latin has a few simple rules for converting English words into Pig Latin words -

1. If a word begins with a consonant, move all consonants before the first vowel to the end of the word and append "ay".
For example:
- Grunt -> Unt-gray
- Phone -> One-phay

Mnemonics/Learning tricks:
- Consonants before first vowel go "ay"

2. If a word begins with a vowel, just append "way" to the end of the word.
For example:
- Apple -> Appleway
- Eat -> Eatway

Mnemonics/Learning tricks:
- Words starting with vowels, just add "way"

Advantages of Pig Latin:
- It is an easy to learn encoding/language game.
- It can add an element of fun to communication.
- It can be used as a secret code to conceal the meaning of a conversation from others.

Disadvantages:
- It is very easy to decode/decipher Pig Latin and hence not a strong encryption method.
- It has limited usage and applicability.

Applications:
- Used as a game to create coded sentences and decode them.
- Sometimes used as a rudimentary encryption technique to conceal meaning.
