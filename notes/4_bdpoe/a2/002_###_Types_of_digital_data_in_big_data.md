### Types of digital data in big data

The major types of digital data in big data are:

1. Structured data - Data that is organized in a predefined format. For example, data in relational databases with tables, rows, and columns. Examples include customer records, sales transactions, etc.
Mnemonic: Think of structured data as data kept in well-STRUCTURED tables.

2. Semi-structured data - Data that does not have a strict data model or is not organized in the standard tabular form. For example, XML, JSON, etc. Examples include server logs, XML/HTML files, etc.
Mnemonic: Think of semi-structured data as data that is half-STRUCTURED or inconsistently structured.

3. Unstructured data - Data that has no identifiable structure or format. Examples include text documents, multimedia content, etc. Examples include tweets, blog posts, images, videos, etc.
Mnemonic: Think of unstructured data as raw data with no set STRUCTURE.

Advantages of structured and semi-structured data:
- Easy to store and query
- Can be directly used for analysis

Advantages of unstructured data:
- Contains hidden insights and patterns
- Valuable for machine learning and deep learning

To analyze and extract insights from unstructured data, techniques like natural language processing, computer vision, etc. are required.

The type of data and the analysis requirements determine the big data tools and technologies to use. For structured and semi-structured data, databases and SQL queries are suitable whereas for unstructured data, machine learning and deep learning techniques are more appropriate.
