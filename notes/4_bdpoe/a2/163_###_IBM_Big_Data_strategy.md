### IBM Big Data strategy

IBM's big data strategy revolves around its IBM Cloud and AI platforms. The key components of IBM's big data strategy are:

1. IBM Cloud: IBM Cloud provides the infrastructure to store and process huge volumes of data. IBM offers a range of cloud services for big data including IBM Cloud Object Storage, IBM Cloud Data Services, and Watson Studio.
2. IBM Watson: IBM Watson is IBM's AI platform. It offers various AI services that can be applied to big data to gain insights and make predictions. Some key Watson services for big data include Watson Natural Language Understanding, Watson Machine Learning, and Watson OpenScale.
3. Data management and governance: IBM offers various data management and governance tools like IBM InfoSphere and IBM Cloud Pak for Data. These help in data integration, data quality management, data cataloging, data governance, and data privacy.
4. Hybrid and multicloud: IBM's big data solutions work across hybrid cloud and multicloud environments. This enables customers to keep their data in private data centers or other public clouds and use IBM's big data and AI services to gain insights.
5. Open source tools: IBM works with various open source big data communities and contributes code to open source projects. This allows IBM to incorporate the latest innovations from open source projects into its commercial offerings. Some examples are Apache Hadoop, Apache Spark, and Apache Kafka.

Some key advantages of IBM's big data strategy are its capabilities in AI and hybrid cloud. The wide range of services and open source partnerships allow customers to solve a variety of big data use cases. However, IBM has intense competition in the cloud computing and big data market from companies like Amazon Web Services, Microsoft Azure, and Google Cloud Platform. IBM would need to continue innovating rapidly to keep up with the competition.
