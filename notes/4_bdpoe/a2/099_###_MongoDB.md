### MongoDB

MongoDB is a document-oriented NoSQL database. Some key points about MongoDB are:

1. It stores data in JSON-like documents. Fields in a document can vary from document to document and data structure can be changed over time.
2. It is scalable and distributed, allowing it to handle large amounts of data.
3. It is open-source and has a large community behind it.
4. It is great for unstructured data like documents, social media data, logs, etc.

Some mnemonics to remember MongoDB:

- MongoDB stores data in JSON-like documents (Remember: MongoDB -> JSON)
- Scalable and distributed (Remember: Mongodb -> Scale)

Advantages of MongoDB:

- Schema-less dynamic schemas: No need to define schema for documents. Fields can be added on the go.
- Scalability: It is horizontally scalable i.e. more machines can be added easily to handle load.
- Performance: It gives high performance due to in-memory storage and indexing.
- Flexibility: It is very flexible in terms of data storage and ease of use.

Disadvantages of MongoDB:

- Limited query capabilities: It has limited query capabilities as compared to SQL databases.
- Less standardized: It is relatively new so it is less standardized and has less community support.
- Limited joins: Performing joins on data is difficult and resource intensive.

Applications of MongoDB:

- Storing unstructured data like user profiles, log data, sensor data, etc.
- Real-time analytics
- Content management systems
- Mobile and web applications
