#### History of Hadoop

- Hadoop was created by Doug Cutting in 2005. He named it after his son's toy elephant.
- It was initially released as a patch for the Nutch open source crawler project.
- The initial goal was to develop a distributed system for processing huge amounts of web content and storing it reliably.
- The initial versions of Hadoop were based on papers published by Google on MapReduce and Google File System (GFS).
- In 2006, Hadoop was accepted as an Apache Software Foundation project and the first stable release (version 0.1) came out in January 2008.
- In 2009, Hadoop 0.20 was released with a new MapReduce API and significant performance improvements. This led to wider adoption of Hadoop.
- In October 2011, Hadoop became a top-level Apache project.
- In February 2012, Hadoop 1.0 was released with a new architecture and new features. The same year, Hortonworks was formed to provide enterprise support for Hadoop.
- In October 2013, Hadoop 2.0 (YARN) was released. It introduced significant changes to the resource management layer, separating out application scheduling and cluster resource management.
- Today, Hadoop has become the de facto standard for big data processing and is used by many organizations for storing and processing huge amounts of data on commodity hardware in a distributed manner.

Some key points to remember:

- Hadoop was created by Doug Cutting in 2005 based on Google's MapReduce and GFS papers.
- It was initially a patch for Nutch and aimed at processing web content.
- In 2006, it became an Apache project and version 0.1 was released in 2008.
- Significant improvements in versions 0.20 (2009) and 1.0 (2012) led to wider adoption.
- Hadoop 2.0 (YARN) released in 2013 separated resource mgmt and app scheduling.
