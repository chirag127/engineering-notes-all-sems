### Introduction to Big Data platform

- Big Data platform refers to the infrastructure and tools used to store and analyse large volumes of data. Some of the key components of a Big Data platform are:

1. Data Storage - Data is stored in a distributed file system like HDFS (Hadoop Distributed File System) or cloud-based object storage like Amazon S3. This allows massive amounts of data to be stored across multiple machines.

2. Processing - Data processing is done using a distributed computing framework like MapReduce or Spark. This allows processing and analysis of data to be distributed across multiple nodes in a cluster for faster processing of large data.

3. Querying - Data can be queried using tools like Hive (for structured data) or Pig (for complex data processing tasks). This allows you to run SQL-like queries on the data for analysis and processing.

4. Analytics - Tools like Mahout, MLlib can be used for machine learning and analytics on the data. This allows you to build machine learning models to gain insights from the data.

5. Visualization - Tools like Tableau or Zeppelin can be used to visualize the data and analysis for easier understanding and communicating insights.

Some Mnemonics and learning tricks for remembering the components:

- Think of storing data as 'saving' it - so 'S' for Storage
- Processing is doing work on data - so 'P' for Processing
- Querying is 'asking questions' on data - so 'Q' for Querying
- Analytics is 'analysing' data - so 'A' for Analytics
- Visualization is 'seeing' the data - so 'V' for Visualization

The advantages of a Big Data platform are scaling to large data volumes, distributed processing for faster analysis, choice of tools for different use cases, and cost-effectiveness.
The disadvantages are complexity in setup and management, requirement of specialized skills, and risk of single point of failure.
