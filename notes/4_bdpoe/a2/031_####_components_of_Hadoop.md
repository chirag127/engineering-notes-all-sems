#### Components of Hadoop

1. HDFS (Hadoop Distributed File System): Stores data on commodity machines, provides high throughput access to application data and is highly fault-tolerant.
- Mnemonic: Hadoop Distributed File System => Highly Distributed Fault-tolerant Storage
- Advantage: Scalable, Fault-tolerant, Low cost
- Application: Big data storage for Hadoop ecosystem tools

2. MapReduce: A programming model for large scale data processing. It divides the work into two phases - Map (data processing) and Reduce (aggregated results).
- Mnemonic: Map => Divide the work, Reduce => Combine the work
- Advantage: Scalable, Fault-tolerant, Distributed processing
- Application: Data processing, filtering, sorting etc.

3. YARN (Yet Another Resource Negotiator): A cluster management technology. It manages computing resources in clusters and uses them for scheduling users' applications.
- Mnemonic: Yet Another Resource Negotiator => Resource management and job scheduling
- Advantage: Scalable, Multi-tenant (can host multiple data processing frameworks), High utilization of resources
- Application: Enables running multiple data processing frameworks on Hadoop
