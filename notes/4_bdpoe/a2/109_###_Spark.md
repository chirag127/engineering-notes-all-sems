### Spark

**What is Spark?**

- Spark is a fast and general-purpose cluster computing system.
- It provides high-level APIs in Scala, Java, Python, and R, and an optimized engine that supports general computation graphs for data analysis.
- It has built-in modules for streaming, SQL, machine learning, and graph processing.

**Key Features:**

- Speed - Spark can run programs up to 100x faster than Hadoop MapReduce in memory, or 10x faster on disk.
- Generality - You can use Spark to build efficient pipelines that integrate streaming, batch processing, machine learning, and graph processing.
- Scalability - Spark has been used on clusters with thousands of nodes.
- Fault Tolerance - Spark continues to run even if some nodes fail.
- Compatibility - Spark runs on Hadoop, Apache Mesos, Kubernetes, standalone, or in the cloud. It can access diverse data sources including HDFS, Cassandra, HBase, and S3.

**Components:**

- Spark Core - The underlying general execution engine for distributed processing.
- Spark SQL - APIs for structured data processing and relational queries.
- Spark Streaming - APIs and underlying engine for processing live streams of data.
- MLlib - Common machine learning algorithms and utilities.
- GraphX - APIs and underlying engine for graph processing and graph-parallel computations.

**Advantages:**

- Speed - Spark is 100x faster than Hadoop for large-scale data processing as it stores data in-memory.
- Generality - Spark provides unified APIs for diverse workloads like batch processing, streaming, machine learning, and graph processing.
- Easy to use - Spark has simple and expressive APIs in diverse languages like Scala, Java, Python, and R.
- Polyglot - You can write applications in multiple languages and seamlessly interface between them.
- Integrations - Spark integrates with diverse data sources and file formats. It runs on Hadoop, Apache Mesos, Kubernetes, standalone, or in the cloud.
