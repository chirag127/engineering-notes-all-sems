#### Introduction to NoSQL databases

NoSQL databases are non-relational databases that do not require a fixed schema and follow a basic key-value pair, wide-column, graph or document data model. They are scalable, distributed and flexible databases well suited for large volumes of structured, semi-structured and unstructured data.

Some key points about NoSQL databases:

- They have dynamic schemas for unstructured data. Data is stored in many ways like key-value pairs, JSON documents, graph structures or wide-column stores.
- They are distributed and scalable. Data is partitioned across multiple machines. This allows them to handle large volumes of data and high traffic.
- They are open-source and horizontally scalable. New servers can be added to handle growth.
- They sacrifice some ACID (Atomicity, Consistency, Isolation, Durability) properties to achieve fast performance and high scalability.
- Popular NoSQL databases are MongoDB, CouchDB, Cassandra, HBase, Redis, etc.

Advantages of NoSQL databases:

- Scales easily by adding more servers in the pool.
- Schemaless architectures.
- Distributed for scalability and fault-tolerance.
- Open-source and distributed.

Disadvantages of NoSQL databases:

- Eventual consistency leading to anomalies.
- Lack of standardization.
- Limited query capabilities.
- Not ACID compliant.

Applications of NoSQL databases:

- Content management systems.
- Real-time analytics.
- Mobile and web applications with unpredictable data or traffic.
- Storing logs or time-series data.
- Recommendation engines.

**Mnemonics:**

- **CAP theorem**: Consistency, Availability, Partition tolerance. Pick 2.
- **BASE**: Basically Available, Soft state, Eventual consistency.

**Tips to learn:**

- Learn different data models - key-value, document, wide-column, graph.
- Understand scaling and sharding concepts.
- Get hands-on with a popular NoSQL database like MongoDB.
- Know when to use a NoSQL vs SQL database.
