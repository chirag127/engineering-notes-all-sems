#### Compliance of Big Data

Compliance of Big Data refers to following the regulations and laws regarding collection, storage, processing, and usage of data. Some key points to keep in mind regarding compliance of Big Data are:

1. Data Privacy: Personal data of individuals should be kept private and not shared publicly without consent. Data should be anonymized when shared publicly for analysis. Laws like GDPR regulate data privacy.
2. Data Security: Data should be securely stored and transmitted with strong encryption and access controls. Data breaches should be reported as per regulations.
3. Data Governance: There should be documentation of data lifecycle including how data is collected, stored, used, and destroyed. This helps in auditing data compliance.
4. Data Quality: Data should be accurate, complete, and updated. Outdated or incorrect data can lead to faulty analysis and decisions. Data quality monitoring is important.
5. Bias Mitigation: AI and ML models built on data should be bias-free and fair. Diversity in data and audit of algorithms for biases is required.

Some mnemonics to remember compliance requirements:

- PRIVACY: Protect Records and Information of Individuals and Consumers
- SECURE: Store Data Electronically with Controls, Encryption and Regulation
- GOVERN: Document Data Governance including Collection, Storage, Usage, Destruction
- QUALITY: Ensure Accurate, Complete and Updated Data
- UNBIASED: Avoid Bias in AI/ML models, Diversity in Data and Audit Algorithms
