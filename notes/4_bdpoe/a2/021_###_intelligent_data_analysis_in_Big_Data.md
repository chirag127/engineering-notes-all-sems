### Intelligent Data Analysis in Big Data

Intelligent Data Analysis in Big Data involves applying machine learning and artificial intelligence techniques to extract insightful patterns and information from large data sets. Some key points about Intelligent Data Analysis in Big Data are:

1. Machine Learning - Machine Learning algorithms like classification, regression, clustering, association rule learning, deep learning, etc. are used to train models on large data sets and detect patterns to make predictions or decisions without being explicitly programmed. For e.g. Predictive models can be built to predict customer churn, forecast sales, detect spam, etc.

2. Feature Engineering - The raw data is processed and transformed into meaningful features that can be fed into machine learning models. This is an important step that requires domain knowledge to extract useful features from the data.

3. Hyperparameter Tuning - The performance of machine learning models depends on hyperparameters. Hyperparameter tuning is used to select the optimal hyperparameters for a model to achieve the best performance. This can be done manually or using randomized search methods.

4. Ensemble Methods - Ensemble methods like bagging, boosting, stacking, etc. are used to combine multiple machine learning models to obtain better performance than a single model. This helps to reduce overfitting and variance.

5. Automated Machine Learning - Automated machine learning tools are used to automate the machine learning workflow including data preprocessing, feature engineering, model selection, hyperparameter tuning, and ensemble modeling to speed up the machine learning process.

Some Mnemonics and learning tricks for Intelligent Data Analysis in Big Data:

- Think of machine learning as learning machines that can learn from data without being explicitly programmed
- Remember that feature engineering is key to extract useful information from raw data to feed into ML models
- Think of hyperparameters as knobs to tune ML models
- Remember that ensemble methods combine multiple ML models to obtain better performance
