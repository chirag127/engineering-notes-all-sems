## Unit 2 - Functional Testing
Functional Testing is a type of software testing that verifies if a system or application works as intended. It focuses on verifying the functionality of the system, including inputs, outputs, and processes. The objective of functional testing is to ensure that the system meets the requirements and specifications defined by the stakeholders. It involves testing the system's functionality by comparing the actual results with the expected results. The process of functional testing can be divided into several stages, including requirements analysis, test planning, test case design, test environment setup, test execution, and test result analysis. The tools used for functional testing include manual testing, automated testing, and hybrid testing. The success of functional testing depends on the thoroughness of the testing process and the accuracy of the test cases.
