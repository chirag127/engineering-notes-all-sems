### Web Testing for the notes of the Unit 7 - Testing Web Applications in the subject of Software Testing
Web Testing:
- Tests the functionality, performance, and security of a web application.
- Tests include:
  - UI testing: checks the look and feel of the application.
  - Functional testing: verifies the correct functioning of the application.
  - Performance testing: measures the response time and scalability of the application.
  - Security testing: verifies the protection of sensitive data and the application against attacks.
- Tools used:
  - Selenium, JUnit, TestNG, etc. for functional testing.
  - Apache JMeter, LoadRunner, etc. for performance testing.
  - OWASP ZAP, Nessus, etc. for security testing.
- Best practices:
  - Automate repetitive tests.
  - Test on multiple browsers and devices.
  - Continuously monitor performance.
