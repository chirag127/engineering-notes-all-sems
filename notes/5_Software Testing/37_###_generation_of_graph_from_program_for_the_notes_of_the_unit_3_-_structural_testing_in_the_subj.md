### Generation of Graph from Program for the notes of the Unit 3 - Structural Testing in the subject of Software Testing
1. Generation of Graph from Program: 
A graph can be generated from a program by using visualization tools such as Graphviz, Gephi, and Cytoscape.
2. Steps to generate a graph:
- Select a visualization tool
- Load the program code into the tool
- Configure the settings to display the graph as desired
- Run the tool to generate the graph
3. Uses of Graphs in Software Testing: 
- To represent the structure of a program
- To visualize the control flow of a program
- To identify potential areas for testing based on the graph structure.
