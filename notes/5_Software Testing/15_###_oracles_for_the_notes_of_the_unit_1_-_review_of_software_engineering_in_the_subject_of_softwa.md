### Oracles for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing
Oracles in software testing are mechanisms used to determine if a software system is producing the correct output. They are used to verify the correctness of the system under test. There are several types of oracles, including:

1. Code-based oracles: These are oracles that are built into the code of the system under test. They can be used to verify the output of the system against a set of expected results.

2. Expert oracles: These are oracles that rely on the knowledge and expertise of a human tester. The tester uses their knowledge and experience to determine if the output of the system is correct.

3. Statistical oracles: These are oracles that use statistical methods to determine if the output of a system is correct. They can be used to verify the output of the system against a set of expected results.

4. Model-based oracles: These are oracles that use a model of the system under test to verify the output. The model can be used to simulate the behavior of the system and compare the output against expected results.

In software testing, oracles are an important tool for verifying the correct behavior of a system. They help to ensure that the system is functioning as expected and that any defects are identified and addressed.
