### Levels of Testing for the notes of the Unit 5 - Software Testing Activities in the subject of Software Testing
Levels of Testing:
1. Unit Testing: Tests individual components or modules of the software.
2. Integration Testing: Tests the integration of multiple modules.
3. System Testing: Tests the software as a whole system.
4. Acceptance Testing: Tests the software to determine if it meets customer requirements.
5. Performance Testing: Tests the software's response time, load capacity and stability.
6. Security Testing: Tests the software's security features and vulnerabilities.
7. Regression Testing: Tests the software after changes have been made to ensure no unintended consequences.
