### Object Oriented Integration and System Testing for the notes of the Unit 6 - Object Oriented Testing in the subject of Software Testing
Object Oriented Integration and System Testing:
1. Object Oriented Integration Testing is a software testing process that involves testing the interactions between objects in a software application.
2. It focuses on verifying the integration of objects and their behavior in response to external stimuli.
3. System Testing, on the other hand, is a type of software testing that verifies the overall functionality of a software system.
4. It checks if the system meets the specified requirements and if it integrates well with other systems.
5. Object Oriented Integration Testing and System Testing complement each other in ensuring the overall quality of a software application.
