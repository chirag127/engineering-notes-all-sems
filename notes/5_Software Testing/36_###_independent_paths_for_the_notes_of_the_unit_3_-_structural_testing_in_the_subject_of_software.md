### Independent Paths for the notes of the Unit 3 - Structural Testing in the subject of Software Testing
Independent Paths: 
1. Definition: A set of unique sequences of instructions in a program that can be executed without intersecting. 
2. Importance: Helps to ensure that all parts of a program function correctly and uncover any unnoticed interactions. 
3. Techniques: Control Flow Graph, Cyclomatic Complexity, Path Testing. 
4. Limitations: Does not guarantee complete coverage, can be time-consuming and complex to implement.
