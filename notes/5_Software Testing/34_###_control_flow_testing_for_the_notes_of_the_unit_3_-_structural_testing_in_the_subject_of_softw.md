### Control Flow Testing for the notes of the Unit 3 - Structural Testing in the subject of Software Testing
Control Flow Testing is a testing technique used to verify the order in which statements, conditions, and decisions are executed in a software program. It focuses on the flow of execution of the program and ensures that the correct sequence of events is being followed. This type of testing is performed to validate the control structures in the program such as loops, conditionals, and branches. The objective is to verify that the program logic is correct and that the program execution follows the intended flow.

White box testing involves testing the internal workings of a software program, including the source code, logic, and algorithms. It focuses on the program's structure and design, and tests are designed to validate the program's functionality and data flow. 

Black box testing, on the other hand, focuses on the external behavior of the software program. It does not take into account the internal workings of the program and tests are designed based on the program's requirements and specifications. The tester does not need to have any knowledge of the program's source code or internal workings. 

In summary, white box testing is concerned with the internal structure of the program, while black box testing focuses on the program's external behavior.
