## Unit 3 - Structural Testing
Structural testing is a type of software testing that focuses on the internal structure of a software application. It verifies the integrity of the code and the relationships between different components. The goal of structural testing is to ensure that the software is well-designed, maintainable, and scalable. It is usually performed after functional testing, and before performance testing. Structural testing techniques include code coverage analysis, control flow analysis, data flow analysis, and boundary value analysis. The results of structural testing are used to improve the quality of the code and to identify potential problems that may arise in the future.
