### Scheme for the notes of the Unit 4 - Regression Testing in the subject of Software Testing
- Definition: Regression testing is a type of software testing that verifies that changes made to a system or application do not negatively impact existing functionality.

- Purpose: To ensure that changes made to the software do not cause unintended consequences or break existing functionality.

- Techniques: 
  1. Re-running previously passed tests 
  2. Selective testing of modified areas 
  3. Automation 
  4. Test case prioritization 

- Benefits: 
  1. Improved software quality 
  2. Reduced risk of introducing bugs 
  3. Increased confidence in changes 
  4. Improved maintenance efficiency 

- Challenges: 
  1. Selecting appropriate test cases 
  2. Maintaining an up-to-date regression test suite 
  3. Balancing thoroughness with efficiency 
  4. Keeping regression tests up-to-date with changing requirements.
