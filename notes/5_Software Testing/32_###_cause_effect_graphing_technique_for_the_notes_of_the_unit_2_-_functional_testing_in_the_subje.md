### Cause Effect Graphing Technique for the notes of the Unit 2 - Functional Testing in the subject of Software Testing
Cause-Effect Graphing Technique (CEGT) is a functional testing technique used to identify and prioritize test cases. It involves creating a visual representation of the relationship between inputs (causes) and expected outputs (effects). The goal is to identify all possible combinations of inputs and outputs and to prioritize test cases based on risk or importance.

Steps to use CEGT:
1. Identify input variables (causes)
2. Identify output variables (effects)
3. Draw a graph showing the relationship between causes and effects
4. Prioritize test cases based on risk or importance

Benefits of using CEGT:
1. Helps to identify all possible combinations of inputs and outputs
2. Prioritizes test cases based on risk or importance
3. Provides a visual representation of the system under test
4. Facilitates collaboration and communication between team members

CEGT is commonly used in software testing, but can also be applied to other areas such as hardware testing and process improvement.
