## Unit 4 - Regression Testing
Regression testing is a type of software testing that verifies that changes made to a system or application do not negatively impact existing functionality. It is performed to ensure that newly added features or bug fixes do not break existing functionality. Regression tests are typically automated and run after each code change. The goal is to identify and fix any issues before they reach production, ensuring the continued stability and quality of the system.
