
## Unit 5 - Application Layer in Computer Networks

* The application layer is the highest layer of the seven-layer Open Systems Interconnection (OSI) model. It is responsible for providing services to the user, such as creating, displaying, and manipulating data, as well as providing an interface between the user and the network. 
* The application layer is responsible for the following tasks:
    * Establishing, maintaining, and terminating connections between applications
    * Performing authentication and encryption
    * Encoding and decoding data
    * Supporting multimedia applications
    * Supporting file transfer, access, and management
    * Supporting email, instant messaging, and other communication protocols
    * Supporting network management
* Common protocols used in the application layer include:
    * Hypertext Transfer Protocol (HTTP)
    * File Transfer Protocol (FTP)
    * Simple Mail Transfer Protocol (SMTP)
    * Domain Name System (DNS)
    * Dynamic Host Configuration Protocol (DHCP)
    * Telnet
    * Secure Shell (SSH)
    * Network File System (NFS)
