
### Routing Algorithms and Protocols in CN

* Distance Vector Routing Algorithm: This algorithm uses the concept of vectors to determine the shortest path to the destination. Each router maintains a table that stores the distance from itself to all other nodes in the network. Each router periodically sends its table to its neighbors, who then update their tables accordingly. The algorithm is quite simple, but it can suffer from count-to-infinity problems if not properly configured.

* Link State Routing Algorithm: This algorithm uses the concept of a "link state" to determine the best route to the destination. Each router maintains a map of the entire network, which it uses to determine the best path to the destination. The router periodically sends its map to its neighbors, who then update their maps accordingly. The algorithm is more complex than distance vector routing, but it is more reliable and can handle more complex networks.

* Path Vector Routing Algorithm: This algorithm is a combination of the distance vector and link state algorithms. It uses the concept of a "path vector" to determine the best route to the destination. Each router maintains a table that stores the distance from itself to all other nodes in the network, as well as the route that it took to get there. The router periodically sends its table to its neighbors, who then update their tables accordingly. The algorithm is more reliable than the distance vector algorithm and can handle more complex networks.

* Hierarchical Routing Algorithm: This algorithm uses the concept of a hierarchical network to determine the best route to the destination. The network is divided into multiple levels, with each level representing a different region or area within the network. Each router maintains a table that stores the distance from itself to all other nodes in the network, as well as the route that it took to get there. The router periodically sends its table to its neighbors, who then update their tables accordingly. The algorithm is more reliable than the distance vector and link state algorithms and can handle more complex networks.

* Multicast Routing Algorithm: This algorithm is used to efficiently send data to multiple destinations at the same time. Each router maintains a table that stores the distance from itself to all other nodes in the network, as well as the route that it took to get there. The router periodically sends its table to its neighbors, who then update their tables accordingly. The algorithm is more reliable than the distance vector and link state algorithms and can handle more complex networks.
