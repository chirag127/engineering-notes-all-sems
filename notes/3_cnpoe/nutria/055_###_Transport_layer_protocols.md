
### Transport layer protocols

* **Transmission Control Protocol (TCP)**: TCP is a connection-oriented protocol that provides reliable, in-order delivery of data packets over a network. It is a full-duplex protocol, meaning that it can send and receive data simultaneously. TCP is responsible for establishing and maintaining connections between two endpoints and ensuring that all data is received correctly. 

* **User Datagram Protocol (UDP)**: UDP is a connectionless protocol that provides unreliable delivery of data packets over a network. It is a half-duplex protocol, meaning that it can either send or receive data at any given time. UDP is a lightweight protocol that does not require acknowledgement of data packets, making it faster than TCP. 

* **Internet Control Message Protocol (ICMP)**: ICMP is a connectionless protocol used for diagnostics and error reporting. It is used to diagnose network problems, such as packet loss or excessive delay, and to detect malicious activities, such as port scanning. ICMP messages are sent between two hosts in response to errors in the network.

* **Stream Control Transmission Protocol (SCTP)**: SCTP is a connection-oriented protocol that provides reliable, in-order delivery of data packets over a network. It is a full-duplex protocol, meaning that it can send and receive data simultaneously. SCTP is often used in applications that require high reliability, such as VoIP and video streaming.

* **Real-time Transport Protocol (RTP)**: RTP is a connectionless protocol used for real-time multimedia applications, such as audio and video streaming. It is a half-duplex protocol, meaning that it can either send or receive data at any given time. RTP is responsible for sequencing and timestamping data packets, ensuring that data is received in the correct order and at the correct time.
