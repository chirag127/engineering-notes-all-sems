

### Hyper Text Transfer Protocol

* Hyper Text Transfer Protocol (HTTP) is an application-level protocol for distributed, collaborative, hypermedia information systems.
* It is a communication protocol used for transferring data from a web server to a web browser.
* HTTP is a request/response protocol between clients and servers.
* Clients typically generate HTTP requests and servers respond with HTTP responses.
* The most common methods used in HTTP are GET, POST, PUT, and DELETE.
* HTTP is stateless, meaning that each request is independent of any other request made by the same client.
* HTTP is an extensible protocol, meaning that new methods and headers can be defined.
* HTTP is a reliable protocol, meaning that it guarantees that the data sent from the server to the client is received in the same order it was sent.
* HTTP is a secure protocol, meaning that data sent between the client and the server is encrypted and cannot be intercepted by third parties.
* HTTP is an efficient protocol, meaning that it minimizes the amount of data sent over the network.
* HTTP is an open protocol, meaning that anyone can implement it without having to pay any licensing fees.

Mnemonics:

* GET: Get information from the server.
* POST: Post information to the server.
* PUT: Put information on the server.
* DELETE: Delete information from the server.
