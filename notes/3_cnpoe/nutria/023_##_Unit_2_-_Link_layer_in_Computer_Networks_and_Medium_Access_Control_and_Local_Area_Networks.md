
## Unit 2 - Link Layer in Computer Networks and Medium Access Control and Local Area Networks

1. The link layer is the data link layer of the OSI model and is responsible for the transmission of data between two nodes connected by a physical link.

2. It is responsible for the physical addressing of nodes and error detection and correction.

3. Medium Access Control (MAC) is the sublayer of the link layer that is responsible for controlling access to the shared physical medium.

4. Local Area Networks (LANs) are networks that span a small geographic area such as a single building or campus.

5. The most common type of LAN is Ethernet, which uses a bus or star topology and CSMA/CD as its MAC protocol.

6. Other common LAN technologies include Token Ring, FDDI, and Wi-Fi.

7. Mnemonics and learning tricks to remember the link layer:
    * L - Link Layer
    * M - Medium Access Control
    * LA - Local Area Network
    * O - OSI Model
    * E - Ethernet
    * T - Token Ring
    * F - FDDI
    * W - Wi-Fi
