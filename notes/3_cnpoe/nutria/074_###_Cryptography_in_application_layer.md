
### Cryptography in application layer

* Cryptography in application layer is the practice of using encryption techniques to secure data and communications.
* It is used to protect data from unauthorized access, modification, and disclosure.
* Cryptography can be used to protect data at rest, data in transit, and data in use.
* Cryptography can also be used to authenticate users and devices, as well as to verify the integrity of data.
* Cryptography can be implemented in a variety of ways, including symmetric key algorithms, public-key algorithms, hash functions, and digital signatures.
* Symmetric key algorithms use the same key for both encryption and decryption. Examples include AES, DES, and 3DES.
* Public-key algorithms use two different keys for encryption and decryption. Examples include RSA, DSA, and ECC.
* Hash functions are used to generate a fixed-length message digest from a variable-length message. Examples include MD5, SHA-1, and SHA-2.
* Digital signatures are used to authenticate the identity of the sender and verify the integrity of the message. Examples include RSA, DSA, and ECC.
