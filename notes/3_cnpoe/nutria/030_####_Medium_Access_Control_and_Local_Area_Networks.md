
#### Medium Access Control and Local Area Networks

* Medium Access Control (MAC) is a sub-layer of the Data Link layer of the OSI model. It is responsible for providing reliable and secure communication between two or more devices on the same network.
* MAC is used to control the access of the medium by multiple devices. It is used to determine which device can access the network at a given time.
* Local Area Networks (LANs) are computer networks that are limited to a small physical area, such as a single building or campus.
* LANs are used to connect computers and other devices, such as printers, to each other.
* A MAC address is a unique identifier assigned to each device on a LAN. It is used to identify the device on the network and is used for communication between devices.
* MAC addresses are usually assigned by the manufacturer of the device and are stored in the device's firmware.
* MAC addresses are divided into two parts: the first part is the Organizationally Unique Identifier (OUI) and the second part is the device's serial number.
* MAC addresses are used in the Media Access Control protocol to control access to the network. The protocol uses the MAC address to determine which device can access the network at a given time.
* A common mnemonic for remembering the MAC address is: "OUI Over Under Serial Number".
* The main advantage of using MAC addresses is that they are unique and can be used to identify devices on the network.
* The main disadvantage of using MAC addresses is that they can be easily spoofed, which can lead to security issues.
* Examples of applications that use MAC addresses include file sharing, streaming media, and printing.
