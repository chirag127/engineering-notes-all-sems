
### Multiplexing in transport layer

* Multiplexing is a technique used in computer networks to allow multiple sources to share the same physical communication link. It is used to increase the capacity of a single link, by allowing multiple logical connections to be multiplexed over the same physical link. 
* Multiplexing is used in the transport layer of the OSI model. It enables multiple applications to send and receive data simultaneously over a single link. 
* Multiplexing is used to reduce the amount of physical links required to connect two nodes. It also helps to reduce the amount of overhead associated with establishing multiple connections.
* Multiplexing is based on the concept of dividing a physical link into multiple logical links. Each logical link is assigned to a specific application or process. 
* Multiplexing is achieved through the use of multiplexing protocols, such as the Transmission Control Protocol (TCP) and the User Datagram Protocol (UDP). 
* Multiplexing protocols use a combination of sequence numbers and acknowledgements to ensure that data is sent and received in the correct order. 
* Multiplexing can be used to reduce the amount of bandwidth required for a given application. This is achieved by allowing multiple applications to share the same physical link.

    * Multiplexing Makes Many More Links (MMML) 
    * Multiplexing Makes Maximum Links (MMM-L)
