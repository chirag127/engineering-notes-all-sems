
### Basic Internetworking in Network Layer

* Internetworking is the process of connecting two or more computer networks, allowing them to communicate and share resources. 
* The network layer is responsible for routing data packets between different networks. It is the third layer of the OSI Model, and is responsible for IP addressing and routing of data packets.
* The main protocols used in this layer are IP, ICMP, and ARP. 
* IP (Internet Protocol) is responsible for addressing and routing of data packets. It uses a 32-bit address known as an IP address. This address is used to identify a device on a network.
* ICMP (Internet Control Message Protocol) is used for diagnostics and error reporting. It is used to report errors, such as a packet being dropped, or to report the status of a connection.
* ARP (Address Resolution Protocol) is used to map an IP address to a physical hardware address, such as a MAC address.
* The network layer is responsible for routing data packets from one network to another. This is done using a routing protocol, such as RIP, OSPF, or BGP.
* The network layer also provides Quality of Service (QoS) to ensure that data packets are delivered with the desired level of service.
* The network layer also provides security, by encrypting data packets and authenticating users.
