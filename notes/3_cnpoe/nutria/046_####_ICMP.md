
#### ICMP

* Internet Control Message Protocol (ICMP) is a network protocol used by IP networks for error reporting, diagnostics, and other control functions. 
* It is an integral part of the Internet Protocol (IP) suite and provides a way for hosts to communicate information about network problems to other hosts in the network. 
* ICMP messages are typically sent in response to errors such as an unreachable network, an unreachable host, or a packet that could not be delivered. 
* ICMP messages can also be used to query the status of a connection or to request a response from a remote host. 
* ICMP messages are sent in the form of packets, which contain a header and a payload. 
* The header contains information about the type of message, the code, and the checksum. 
* The payload contains additional information about the message, such as the IP address of the sender and the destination. 
* ICMP is an important part of the IP protocol suite and is used by network administrators and engineers to troubleshoot and diagnose network problems.
