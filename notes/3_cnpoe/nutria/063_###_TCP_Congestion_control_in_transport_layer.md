
### TCP Congestion Control in Transport Layer

* TCP congestion control is a mechanism used in transmission control protocol (TCP) to avoid network congestion, which can lead to packet loss, delays, and other network performance issues.
* It works by regulating the amount of data that can be sent over a network by adjusting the window size.
* The window size is the amount of data that can be sent without receiving an acknowledgment from the receiver.
* TCP congestion control works by monitoring the amount of data that is sent and received.
* If the amount of data sent exceeds the amount of data received, then the window size is decreased to reduce the amount of data sent.
* If the amount of data sent is less than the amount of data received, then the window size is increased to allow more data to be sent.
* TCP congestion control also uses a variety of algorithms to detect and respond to network congestion.
* These algorithms include slow start, congestion avoidance, fast retransmit, fast recovery, and others.
* Slow start is an algorithm used to gradually increase the window size until a certain threshold is reached.
* Congestion avoidance is an algorithm used to maintain a certain window size in order to avoid overloading the network.
* Fast retransmit is an algorithm used to quickly retransmit lost packets in order to reduce the amount of time it takes to recover from packet loss.
* Fast recovery is an algorithm used to quickly increase the window size after a packet loss in order to reduce the amount of time it takes to recover from packet loss.

* It is used to regulate the amount of data that can be sent over a network in order to avoid network congestion, which can lead to packet loss, delays, and other network performance issues.
