
## Unit 3 - Network Layer in Computer Networks

1. The Network Layer is responsible for the delivery of packets from the source host to the destination host across multiple networks.
2. It is responsible for routing the packets through the best path, and for providing Quality of Service (QoS) guarantees.
3. It provides services such as logical addressing, segmentation, and flow control.
4. Logical addressing is used to identify the source and destination hosts, which are identified by their IP address.
5. Segmentation is used to break down large packets into smaller units, which are easier to transmit over the network.
6. Flow control is used to ensure that the source does not send more data than the destination can handle.
7. The Network Layer uses two protocols to achieve its objectives: the Internet Protocol (IP) and the Transmission Control Protocol (TCP).
8. The Internet Protocol is responsible for routing packets through the network, and for providing Quality of Service guarantees.
9. The Transmission Control Protocol is responsible for reliable data transfer between two hosts.
10. Mnemonics and learning tricks for the Network Layer:
    - Logical Addressing: "IP Address: Identifying People" 
    - Segmentation: "Segmenting Data for Transmission" 
    - Flow Control: "Controlling the Flow of Data"
