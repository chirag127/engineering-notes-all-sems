
### Domain Name System

* The Domain Name System (DNS) is a distributed, hierarchical database that stores information about domain names and the associated IP addresses. It is used to translate domain names into IP addresses, allowing computers to communicate with each other over the internet.
* DNS is an essential component of the internet, as it allows users to access websites without having to remember the IP address of the server hosting the website. 
* DNS is a distributed system, meaning that it is spread across many different servers around the world. Each server stores information about a specific portion of the DNS database. 
* DNS is hierarchical, meaning that each level of the hierarchy is responsible for a specific portion of the DNS database. For example, the top level of the hierarchy is responsible for the “.com” domain, while the second level is responsible for “example.com”. 
* DNS is also an important security component of the internet, as it helps protect against malicious attacks such as DNS spoofing, which can redirect users to malicious websites.
* Mnemonics and learning tricks for the Domain Name System can include remembering that DNS stands for "Domain Name System", and that it is responsible for translating domain names into IP addresses. Additionally, remembering that DNS is a distributed, hierarchical database can help to better understand how it works.
