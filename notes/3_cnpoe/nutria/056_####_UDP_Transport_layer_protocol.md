
#### UDP Transport Layer Protocol

* UDP (User Datagram Protocol) is a transport layer protocol that is used to send data over the internet. It is an unreliable, connectionless protocol that does not guarantee delivery of data packets or provide any mechanism for flow control.
* UDP is a simple protocol that uses a minimum of protocol mechanisms. It does not establish a connection between the sender and the receiver, and does not provide any mechanism for flow control or error checking.
* UDP is used for applications where speed and low overhead are more important than reliability, such as streaming media and real-time gaming.
* UDP is also used for DNS queries, DHCP requests, and other network services that require a quick response.
* UDP packets are typically smaller than TCP packets, as they do not include the additional headers and acknowledgements that TCP packets include.
* UDP is a connectionless protocol, meaning that each packet is sent independently and the receiver does not need to send an acknowledgement that the packet was received.
* UDP is often used in applications where data needs to be sent quickly and reliably, such as in video and audio streaming applications.
* UDP is also used in Voice over IP (VoIP) applications, as it allows for faster transmission of data.
* UDP is also used in Domain Name System (DNS) queries, as it allows for faster resolution of domain names.

Mnemonics and Learning Tricks: 
* UDP stands for User Datagram Protocol 
* UDP is Unreliable, so it does not guarantee delivery
* UDP is Connectionless, so there is no need for handshaking
* UDP is Fast, as it does not include any additional headers or acknowledgements 
* UDP is Used for Streaming, VoIP, and DNS queries
