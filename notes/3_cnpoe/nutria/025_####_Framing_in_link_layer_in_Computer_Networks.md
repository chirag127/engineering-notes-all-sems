

#### Framing in Link Layer in Computer Networks

* Framing is the process of segmenting data into frames and adding a header to each frame. It is used in the link layer of the OSI model.
* The header contains information such as the source and destination address, error-checking information, and other control bits.
* The main purpose of framing is to ensure that data is transmitted correctly and efficiently over a network.
* There are several types of frames used in the link layer, including Ethernet frames, Token Ring frames, and HDLC frames.
* Ethernet frames use the IEEE 802.3 standard and have a minimum size of 64 bytes and a maximum size of 1518 bytes.
* Token Ring frames use the IEEE 802.5 standard and have a minimum size of 18 bytes and a maximum size of 4500 bytes.
* HDLC frames use the ISO/IEC 3309 standard and have a minimum size of 5 bytes and a maximum size of 4096 bytes.
* Framing is important for ensuring that data is transmitted correctly and efficiently over a network. It helps to ensure that data is not lost or corrupted during transmission, and it helps to improve the speed of data transfer.
* A good mnemonic to remember the types of frames used in the link layer is "Ethernet Token HDLC".
