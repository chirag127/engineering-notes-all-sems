

#### Network Architecture with Reference to Computer Networks

- Network architecture is the design of a computer network. It includes the physical and logical components of the network, as well as the protocols used to communicate between those components. 
- A network architecture is typically divided into layers, each of which provides a specific type of functionality. The most common layers are the physical layer, the data link layer, the network layer, the transport layer, the session layer, the presentation layer, and the application layer. 
- Network architectures can be either centralized or distributed. In a centralized architecture, all of the components are connected to a single central server, while in a distributed architecture, the components are connected to multiple servers. 
- Network architectures can also be classified as either client-server or peer-to-peer. In a client-server architecture, the client requests information from the server, while in a peer-to-peer architecture, the nodes communicate directly with each other. 
- Network architectures can also be classified as either point-to-point or broadcast. In a point-to-point architecture, data is sent directly from one node to another, while in a broadcast architecture, data is sent to all nodes simultaneously. 
- Network architectures can also be classified as either static or dynamic. In a static architecture, the nodes are pre-configured and the network topology does not change, while in a dynamic architecture, the nodes can be added or removed and the network topology can change. 
- Network architectures can also be classified as either circuit-switched or packet-switched. In a circuit-switched architecture, the data is sent over dedicated circuits, while in a packet-switched architecture, the data is sent in packets over a shared medium. 
- Network architectures can also be classified as either connection-oriented or connectionless. In a connection-oriented architecture, the nodes establish a connection before data is transmitted, while in a connectionless architecture, the data is sent without establishing a connection. 
- Network architectures can also be classified as either synchronous or asynchronous. In a synchronous architecture, the nodes communicate in real-time, while in an asynchronous architecture, the nodes communicate at different times. 
- Network architectures can also be classified as either mesh, star, or hybrid. In a mesh architecture, all of the nodes are connected to each other, while in a star architecture, the nodes are connected to a central node. In a hybrid architecture, a combination of the two is used. 
- Network architectures can also be classified as either wired or wireless. In a wired architecture, the nodes are connected by cables, while in a wireless architecture, the nodes are connected by radio signals. 
- Network architectures can also be classified as either local area networks (LANs) or wide area networks (WANs). A LAN is a network that is limited to a small geographic area, while a WAN is a network that spans a large geographic area. 
- Network architectures can also be classified as either centralised or decentralised. In a centralised architecture, all of the components are connected to a single server, while in a decentralised architecture, the components are connected to multiple servers.

Mnemonic: 

- Physical Layer (PL): Packets Linked to the LAN
- Data Link Layer (DLL): Data Links Logically Organized
- Network Layer (NL): Networks Linked to the OSI
- Transport Layer (TL): Transports Layers Over Networks
- Session Layer (SL): Sessions Linked Over Time
- Presentation Layer (PL): Packets Linked to the Protocol
- Application Layer (AL): Applications Linked to the End User
