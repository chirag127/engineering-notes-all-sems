
#### Network structure with reference to Computer Networks

* Network structure is a broad term that refers to the physical and logical organization of a network.
* It includes the physical components of the network, such as cables, routers, and switches, as well as the logical components, such as IP addresses, subnets, and routing protocols.
* In computer networks, the network structure is important for efficient communication between computers.
* The network structure is composed of several layers, each with their own specific purpose.
* The physical layer is the lowest layer and is responsible for the transmission of data over the physical medium.
* The data link layer is responsible for the transfer of data between two nodes on the same network.
* The network layer is responsible for routing packets from source to destination.
* The transport layer is responsible for end-to-end communication between two applications.
* The application layer is responsible for providing services to the user.

Mnemonics and Learning Tricks:
* The easiest way to remember the layers of the network structure is to use the acronym “P-D-N-T-A”, which stands for Physical, Data link, Network, Transport, and Application.
* Another helpful trick is to think of the layers as a series of steps, with each layer building on the one before it. 
* For example, the physical layer is the foundation of the network, and the application layer is the top layer.
* Additionally, you can think of the layers as a set of building blocks, with each layer adding something to the network.
* Finally, you can remember the layers by thinking of them as a series of concentric circles, with the physical layer at the center and the application layer at the outer edge.
