
### Electronic mail in application layer

- Electronic mail (email) is a system used for exchanging digital messages from an author to one or more recipients. Email is an important application layer protocol that is used in almost all modern networks.
- Email is composed of two main components: the message header, which contains information about the sender, recipient and other routing information, and the message body, which contains the actual content of the message. 
- Email is sent over the Internet using the Simple Mail Transfer Protocol (SMTP). SMTP is a text-based protocol that is used to send and receive email messages.
- Email messages are stored on the server using the Post Office Protocol (POP) or the Internet Message Access Protocol (IMAP). POP and IMAP are used to access the messages stored on the server.
- Email messages can be encrypted using the Secure/Multipurpose Internet Mail Extensions (S/MIME). S/MIME is a standard for encrypting and signing email messages.
- Email can also be used for authentication and authorization. Email authentication is used to verify that a message is from the sender it claims to be from. Email authorization is used to grant access to certain resources or services.
- Mnemonic for remembering the components of email:
  - **S**imple Mail Transfer Protocol (SMTP) 
  - **P**ost Office Protocol (POP)
  - **I**nternet Message Access Protocol (IMAP) 
  - **S**ecure/Multipurpose Internet Mail Extensions (S/MIME).
