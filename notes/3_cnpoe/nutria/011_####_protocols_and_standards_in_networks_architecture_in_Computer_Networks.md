
#### Protocols and Standards in Networks Architecture in Computer Networks

* **TCP/IP** - Transmission Control Protocol/Internet Protocol is a suite of communication protocols used to interconnect network devices on the internet. It is the most widely used network protocol and is the basis for communication over the internet. It is a connection-oriented protocol that provides reliable data transfer between two nodes.

* **OSPF** - Open Shortest Path First is a link-state routing protocol used to calculate the shortest path between two nodes in a network. It is a classless protocol that supports VLSM and CIDR. It is widely used in large networks as it is more efficient than distance vector routing protocols.

* **BGP** - Border Gateway Protocol is an inter-autonomous system routing protocol used to exchange routing information between different autonomous systems on the internet. It is a path-vector protocol that uses the concept of autonomous systems to calculate the best path between two nodes.

* **RIP** - Routing Information Protocol is a distance vector routing protocol used to find the shortest path between two nodes in a network. It is a classful protocol that supports variable length subnet masks but does not support VLSM or CIDR.

* **EIGRP** - Enhanced Interior Gateway Routing Protocol is a hybrid routing protocol used to calculate the shortest path between two nodes in a network. It is a classless protocol that supports VLSM and CIDR. It is a very efficient protocol and is used in large networks.

* **IGMP** - Internet Group Management Protocol is a network layer protocol used to manage the membership of IP multicast groups. It is used to enable hosts to join and leave multicast groups and is used by routers to learn the multicast group memberships of the hosts on the network.

* **802.11** - IEEE 802.11 is a set of standards for wireless local area networks (WLANs). It defines the physical and MAC layers of the network and is used for communication between wireless devices. It supports both infrastructure and ad-hoc networks.
