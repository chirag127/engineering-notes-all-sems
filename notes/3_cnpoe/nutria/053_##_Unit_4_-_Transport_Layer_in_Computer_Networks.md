
## Unit 4 - Transport Layer in Computer Networks

* The Transport Layer is the fourth layer of the Open Systems Interconnection (OSI) model. It is responsible for providing reliable end-to-end communication between two hosts. 
* The Transport Layer is responsible for providing a reliable end-to-end communication service to the upper layers of the OSI model. It is responsible for providing the necessary services to ensure reliable data transfer between two hosts. 
* The Transport Layer is responsible for providing the necessary services to ensure reliable data transfer between two hosts. It provides services such as segmentation, flow control, error control, and congestion control. 
* The Transport Layer uses two different protocols for reliable data transfer: the Transmission Control Protocol (TCP) and the User Datagram Protocol (UDP). TCP is a connection-oriented protocol that provides reliable data transfer. UDP is a connectionless protocol that provides unreliable data transfer. 
* The Transport Layer is responsible for providing error control, which ensures that data is correctly received by the receiving host. Error control is achieved by using the Cyclic Redundancy Check (CRC) algorithm. 
* The Transport Layer is responsible for providing flow control, which ensures that data is sent at an appropriate rate. Flow control is achieved by using the sliding window protocol. 
* The Transport Layer is responsible for providing congestion control, which ensures that data is sent at an appropriate rate. Congestion control is achieved by using the congestion avoidance algorithm. 
* The Transport Layer is responsible for providing segmentation, which ensures that data is correctly transmitted across the network. Segmentation is achieved by using the segmentation and reassembly algorithm. 
* Mnemonics to remember the Transport Layer: 
    * T - Transmission Control Protocol (TCP) 
    * U - User Datagram Protocol (UDP) 
    * E - Error Control (CRC Algorithm) 
    * F - Flow Control (Sliding Window Protocol) 
    * C - Congestion Control (Congestion Avoidance Algorithm) 
    * S - Segmentation (Segmentation and Reassembly Algorithm)
