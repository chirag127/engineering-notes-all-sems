
#### Services in Networks Architecture in Computer Networks

* Network services are applications that run on the network and provide users with access to resources. 
* Common services include file sharing, printing, messaging, web hosting, and streaming media. 
* Network services are typically provided by a server and accessed by a client. 
* Network services can be divided into two categories: connection-oriented and connectionless. 
* Connection-oriented services require a client to establish a connection with a server before any data can be exchanged. Examples of connection-oriented services include FTP and Telnet. 
* Connectionless services allow clients to send data without establishing a connection with the server. Examples of connectionless services include UDP and ICMP. 
* Network services are usually provided by a dedicated server, but they can also be provided by a computer that is running multiple services. 
* Network services can be secured using authentication and encryption. 
* Network services are typically administered using a web-based interface or a command-line interface. 
* Network services can be monitored using network management software. 
* Mnemonic: CONNECT = Connection-oriented services, UDP = Unreliable Datagram Protocol, ICMP = Internet Control Message Protocol.
