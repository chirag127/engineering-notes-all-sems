
#### Network performance and transmission impairments in Computer Networks

* Network performance and transmission impairments refer to the various factors that can potentially reduce the performance of a network. These include:
  * Bandwidth Limitations: Bandwidth is the maximum rate at which data can be transmitted over a network. If the amount of data being sent exceeds the available bandwidth, then the network performance will suffer.
  * Latency: Latency is the amount of time it takes for a data packet to travel from one node to another. If the latency is too high, then the performance of the network will suffer.
  * Packet Loss: Packet loss occurs when data packets are lost in transit due to network congestion, faulty hardware, or other issues. Packet loss can lead to degraded network performance.
  * Interference: Interference is the disruption of a signal due to external sources such as radio frequency interference (RFI), electrical noise, or other sources. Interference can lead to degraded network performance.
  * Security: Security is a critical factor in maintaining the performance of a network. If security measures are not in place, then malicious actors may be able to gain access to the network and cause disruption.

* Mnemonics and Learning Tricks:
  * BAND: Bandwidth Limitations, Availability, Network Design, Delay
  * LAP: Latency, Availability, Packet Loss 
  * PIE: Packet Loss, Interference, Encryption
