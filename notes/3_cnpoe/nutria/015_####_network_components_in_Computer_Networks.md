
#### Network Components in Computer Networks

1. **Routers**: Routers are network devices that route data packets between two or more networks. Routers use routing protocols to determine the best path for the data packets to travel. Routers also use access control lists to filter traffic and provide security.

2. **Switches**: Switches are network devices that connect multiple devices on a network. Switches use packet switching to forward data packets to the correct destination. Switches also use access control lists to filter traffic and provide security.

3. **Firewalls**: Firewalls are network devices that protect networks from malicious traffic. Firewalls use packet filtering to identify and block malicious traffic. Firewalls also use access control lists to filter traffic and provide security.

4. **Network Interface Cards (NICs)**: NICs are network devices that connect computers to a network. NICs use network protocols to communicate with other computers on the network. NICs also use access control lists to filter traffic and provide security.

5. **Modems**: Modems are network devices that connect computers to the Internet. Modems use modulation and demodulation to convert digital signals into analog signals and vice versa.

6. **Wireless Access Points (WAPs)**: WAPs are network devices that provide wireless access to a network. WAPs use radio waves to transmit and receive data. WAPs also use access control lists to filter traffic and provide security.
