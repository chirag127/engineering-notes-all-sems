
#### LAN Standards in Local Area Network

* Ethernet: The most widely used LAN standard, Ethernet is a set of rules that govern how computers communicate with each other. It is used to connect computers, printers, and other network devices in a local area network. Ethernet supports data transfer rates of 10 Mbps, 100 Mbps, 1 Gbps, and 10 Gbps.

* Token Ring: Token Ring is a LAN standard that uses a token-passing scheme for data transmission. It is a point-to-point topology, where all the nodes are connected to each other in the form of a ring. Token Ring supports data transfer rates of 4 Mbps, 16 Mbps, and 100 Mbps.

* Wi-Fi (IEEE 802.11): Wi-Fi is a wireless LAN standard that uses radio waves to connect computers. It supports data transfer rates of 11 Mbps, 54 Mbps, and 600 Mbps.

* FDDI (Fiber Distributed Data Interface): FDDI is a LAN standard that uses fiber optic cables for data transmission. It supports data transfer rates of 100 Mbps and 1 Gbps.

* ATM (Asynchronous Transfer Mode): ATM is a LAN standard that uses a cell-switching technique for data transmission. It supports data transfer rates of 25 Mbps, 155 Mbps, and 622 Mbps.
