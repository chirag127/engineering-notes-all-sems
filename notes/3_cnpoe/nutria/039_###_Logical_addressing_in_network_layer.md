
### Logical addressing in network layer

- Logical addressing is a method of assigning a unique address to a device or a node in a computer network. It is used to identify the device or node in the network so that it can communicate with other nodes or devices.
- The logical address is also known as the IP address or the Network address. It is a 32-bit number which is divided into four 8-bit octets. 
- The IP address consists of two parts. The first part is the network address and the second part is the host address. 
- The network address is used to identify the network to which the device or node belongs. The host address is used to identify the device or node within the network. 
- The IP address is used to route the packets from one node or device to another. It is also used for the purpose of authentication and authorization.
- Mnemonics and learning tricks for logical addressing in network layer include: 
    - IP address = Internet Protocol address 
    - IP = Internet Protocol 
    - IPV4 = Internet Protocol version 4 
    - IPV6 = Internet Protocol version 6 
    - Each octet of an IP address is represented in decimal format (0-255)
    - Each octet of an IP address is separated by a period (.) 
    - The IP address is used to route the packets from one node or device to another. 
    - The IP address is also used for the purpose of authentication and authorization.
