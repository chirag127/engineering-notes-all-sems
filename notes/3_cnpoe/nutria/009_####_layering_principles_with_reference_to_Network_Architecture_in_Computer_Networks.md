

#### Layering Principles with Reference to Network Architecture in Computer Networks

1. Layering is a technique used in computer networks to divide the entire network architecture into different layers. Each layer has a specific role to play in the functioning of the network.

2. The layers are typically divided into seven layers: the physical layer, the data link layer, the network layer, the transport layer, the session layer, the presentation layer, and the application layer.

3. The physical layer is the lowest layer in the network architecture. It is responsible for the physical connection of the network and the transmission of bits between the nodes.

4. The data link layer is responsible for the reliable transmission of data frames between two nodes. It also provides error control and flow control mechanisms.

5. The network layer is responsible for the logical addressing of nodes and routing of packets.

6. The transport layer is responsible for the reliable delivery of packets between two nodes. It also provides congestion control mechanisms.

7. The session layer is responsible for the establishment and maintenance of sessions between two nodes.

8. The presentation layer is responsible for the formatting of data for transmission between two nodes.

9. The application layer is the highest layer in the network architecture. It is responsible for providing services to the user applications.

10. Mnemonics: 
- Physical Layer: Please Link Data
- Data Link Layer: Data Link Layer Does Error Control
- Network Layer: Network Layer Decides Routing
- Transport Layer: Transport Layer Ensures Reliable Delivery
- Session Layer: Session Layer Establishes Connections
- Presentation Layer: Presentation Layer Formats Data
- Application Layer: Application Layer Provides Services
