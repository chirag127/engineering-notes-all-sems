

#### Error Detection and Correction in link layer in Computer Networks

* Error Detection and Correction is a method of ensuring that data is sent correctly over a communication channel. It is used in the link layer of the OSI model, and is responsible for ensuring that data is transferred accurately between two points.
* Error Detection is the process of detecting errors in a data stream. This is usually done by adding a checksum to the data, which is used to compare the data that is sent to the data that is received. If the checksum does not match, then an error has occurred and the data needs to be resent.
* Error Correction is the process of correcting errors that have been detected. This is usually done by adding a redundancy to the data, which can be used to reconstruct the data if an error has occurred.
* One of the most common methods of Error Detection and Correction is the use of Cyclic Redundancy Checks (CRCs). CRCs are used to detect errors in a data stream, and can also be used to correct errors.
* Another method of Error Detection and Correction is the use of Hamming Codes. Hamming Codes are used to detect and correct single-bit errors in a data stream.
* Error Detection and Correction is an important part of ensuring that data is sent correctly over a communication channel. It is important to make sure that data is sent correctly, as errors can lead to data loss or corruption. Mnemonics such as "CRC for Check, Hamming for Correct" can be used to help remember the different methods of Error Detection and Correction.
