
### Forwarding and Delivery in Network Layer

* The network layer is responsible for forwarding and delivering data packets from source to destination. 
* The network layer uses routing protocols to determine the best path for the data packet to travel from source to destination.
* It also adds the source and destination addresses to the data packet, so that it can be identified and routed correctly.
* The network layer also provides error control, flow control, congestion control and other services.
* The most popular protocols used in the network layer are Internet Protocol (IP), Address Resolution Protocol (ARP), Internet Control Message Protocol (ICMP) and Open Shortest Path First (OSPF).
* IP is responsible for addressing, routing and fragmentation of data packets.
* ARP is responsible for resolving IP addresses to MAC addresses.
* ICMP is responsible for error control and flow control.
* OSPF is responsible for routing in large networks.
* The network layer also provides Quality of Service (QoS) to ensure that data packets are delivered in a timely manner.
* It also provides security features such as encryption and authentication. 
* The network layer is also responsible for multicasting, which is the process of sending data to multiple destinations simultaneously.
