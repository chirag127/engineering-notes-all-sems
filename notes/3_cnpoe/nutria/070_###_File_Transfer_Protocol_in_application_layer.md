
### File Transfer Protocol in Application Layer
- File Transfer Protocol (FTP) is an application layer protocol that allows users to transfer files between two computers over a network.
- FTP is a client-server protocol, meaning that a user must connect to an FTP server in order to access files.
- FTP is a connection-oriented protocol, meaning that it establishes a connection with the server before any data is transferred.
- FTP uses TCP as its transport protocol and can be used to transfer files of any size.
- FTP is used to transfer files over the Internet and is the most commonly used protocol for transferring files.
- FTP allows users to upload and download files, as well as to create, delete, and modify directories and files on the server.
- FTP also allows users to set permissions on files and directories, so that only certain users can access them.
- FTP is a secure protocol and supports both implicit and explicit encryption.
- FTP is used in a wide variety of applications, such as web hosting, file sharing, and software distribution.
