
#### DHCP

* Dynamic Host Configuration Protocol (DHCP) is a protocol used for assigning IP addresses and other network configuration parameters to devices on a network.
* DHCP works by sending out a broadcast message to all devices on the network, asking them to identify themselves.
* The device that identifies itself first is assigned the IP address.
* DHCP is used to assign IP addresses automatically, eliminating the need for manual configuration.
* DHCP also provides other network configuration parameters, such as DNS servers, default gateway, and subnet mask.
* DHCP is a client-server protocol, where the DHCP server provides the configuration information to the DHCP clients.
* DHCP can be used in both wired and wireless networks.
* DHCP also supports dynamic IP address allocation, where IP addresses can be allocated to clients on demand.
* DHCP also supports IP address leasing, where IP addresses are allocated to clients for a specific period of time.
* DHCP is an Internet Engineering Task Force (IETF) standard protocol, defined in RFC 2131.

Mnemonics:

* Dynamic Host Configuration Protocol: 
  * D - Dynamic
  * H - Host
  * C - Configuration
  * P - Protocol
