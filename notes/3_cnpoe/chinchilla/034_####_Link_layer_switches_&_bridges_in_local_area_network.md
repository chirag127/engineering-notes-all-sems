#### Link layer switches & bridges in local area network

Link layer switches and bridges are network devices used to connect multiple devices in a local area network (LAN). They operate at the data link layer (Layer 2) of the OSI model, which is responsible for providing reliable communication between adjacent devices on a network.

Some important points to understand about link layer switches and bridges are:

- Switches and bridges are used to connect multiple devices in a LAN and improve network performance by reducing the amount of network traffic.
- They operate by analyzing the MAC addresses of incoming frames and forwarding them to the appropriate port based on the destination MAC address.
- Switches and bridges work by creating a table of MAC addresses and their associated ports, which is called the forwarding table or MAC address table.
- When a switch or bridge receives a frame, it checks the destination MAC address against the forwarding table. If the MAC address is not in the table, the switch or bridge floods the frame to all ports except the incoming port. This is called flooding.
- Switches are faster and more efficient than bridges because they have more ports and can support higher network speeds.
- Bridges are used to connect multiple LANs together and are often used in conjunction with routers to create larger networks.

Some useful mnemonics for understanding link layer switches and bridges are:

- MAC address table: "My Aunt Carol has a table of MAC addresses."
- Flooding: "The switch or bridge floods the network like a flood of water."

Overall, understanding the role of link layer switches and bridges in a LAN is essential for anyone working with computer networks. By efficiently forwarding network traffic based on MAC addresses, these devices help to improve network performance and reduce network congestion.
