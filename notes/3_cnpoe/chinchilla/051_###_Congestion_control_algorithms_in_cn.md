### Congestion control algorithms in CN

Congestion control algorithms are an essential component of computer networks. They help prevent congestion and ensure that the network operates efficiently. In this section, we will discuss the most commonly used congestion control algorithms in computer networks.

1. **TCP Reno**: 
TCP Reno is a widely used congestion control algorithm that is used in the Transmission Control Protocol (TCP). It works by reducing the sending rate when congestion is detected. It uses a combination of packet loss and delay to detect congestion. 

2. **TCP Vegas**: 
TCP Vegas is another congestion control algorithm used in the TCP protocol. It uses Round Trip Time (RTT) measurements to detect congestion. It adjusts the sending rate based on the estimated bandwidth and delay of the network.

3. **TCP New Reno**: 
TCP New Reno is an improved version of TCP Reno that uses a more efficient algorithm for handling retransmissions. It uses a fast recovery mechanism that allows it to quickly recover from packet losses without waiting for a timeout.

4. **TCP Cubic**: 
TCP Cubic is a congestion control algorithm that is used in the TCP protocol. It uses a cubic function to adjust the sending rate based on the congestion window size and the network congestion level. It is designed to be more responsive to congestion than other algorithms.

5. **TCP BBR**: 
TCP BBR is a congestion control algorithm that is designed to optimize network performance for high-speed networks. It uses a combination of packet loss and RTT measurements to detect congestion. It adjusts the sending rate based on the estimated available bandwidth of the network.
