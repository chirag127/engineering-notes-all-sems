### Logical addressing in network layer

The network layer uses logical addresses to identify the source and destination devices. The logical addresses are mapped to physical addresses using address resolution protocol (ARP).

- The logical addresses are assigned to devices independently of their physical locations in the network. This makes it easy to connect devices to different physical networks without changing their addresses.
- The logical addresses are hierarchical and facilitate efficient routing of packets through the network. The IP addresses used in the Internet are logical addresses belonging to the network layer.
- The logical addresses are allocated to devices by the network administrator. This makes it easy to track the devices on the network.
- Examples of logical addresses are IP addresses and IPX addresses.

Mnemonics to remember logical addresses:

- Logic before physics: Logical addresses are assigned first before mapping to physical addresses.
- Location independence: Logical addresses are independent of device locations.
- Easy administration: Logical addresses are allocated by network admin making device tracking easy.

Advantages:

- Device location independence
- Easy device tracking and management
- Hierarchical addressing facilitating efficient routing

Disadvantages:

- Extra overhead to map logical addresses to physical addresses
- Chance of address conflicts if not planned properly
