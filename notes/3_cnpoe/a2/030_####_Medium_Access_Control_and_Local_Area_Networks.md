#### Medium Access Control and Local Area Networks

- Medium Access Control (MAC) is a mechanism that controls how multiple devices share the same physical medium to transmit data. It prevents data packet collisions and ensures efficient use of the medium.
- Some common MAC techniques are:
- CSMA/CD (Carrier Sense Multiple Access with Collision Detection): Devices first sense the medium idle time and then transmit. If collision is detected, they wait for a random time and retry. Used in Ethernet.
- Token Passing: A special packet called token is passed between devices. Only the device holding the token can transmit. Token Ring uses this technique.
- Scheduling: Time slots are pre-allocated to devices to transmit data. Used in wireless standards like GSM and CDMA.

**Mnemonics:**
- *CSMA/CD - First listen, then talk. If crash, then wait and walk (retry).*
- *Token passing - Pass the token, then you can talk.*
- *Scheduling - Wait for your turn, then you can burn (transmit).*

**Local Area Networks (LANs):**
- Connect devices in a local area like office, home, etc.
- Use physical medium like twisted pair, coaxial cable or wireless.
- Usually high speed (Gbps) with low latency and cost.
- Examples: Ethernet, Token Ring, Wireless LAN (Wi-Fi), etc.

**Advantages:**
- High speed
- Low cost
- Easy to set up and maintain

**Disadvantages:**
- Limited range (local only)
- Vulnerable to security threats and interference
