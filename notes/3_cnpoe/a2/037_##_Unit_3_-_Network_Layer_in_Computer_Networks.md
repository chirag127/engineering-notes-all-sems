## Unit 3 - Network Layer in Computer Networks

The Network Layer is responsible for routing of packets from source to destination. It uses IP addresses to identify source and destination machines.

Some key points about Network Layer:

1. It provides logical addressing and routing functions. IP addresses are assigned at this layer to identify each device.
2. It determines the best path for data packets to travel from source to destination. This is done using routing protocols like OSPF, BGP, etc.
3. It handles packet fragmentation and reassembly. If a packet is too large for the MTU, it gets fragmented into smaller packets at this layer. The destination reassembles the packets.
4. It provides flow and congestion control to prevent packet loss. This ensures efficient use of available bandwidth.
5. It supports Internetworking by establishing and maintaining internetwork connections.

IPv4 and IPv6 are the primary protocols used at the Network Layer.
Some Mnemonics for learning:

- IP addresses are like postal addresses directing packets
- Routing is like finding the fastest route for a delivery truck
- Fragmentation is like splitting a large parcel into smaller ones
- Congestion control is like traffic regulation to prevent jams

Applications: The Network Layer enables communication across networks and makes global Internet connectivity possible. All Internet services and applications rely on the functions provided by the Network Layer.
