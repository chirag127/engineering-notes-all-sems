#### Network devices in Computer Networks

The major network devices in Computer Networks are:

1. Repeater: A repeater is a device that receives a signal and re-transmits it at a higher level or higher power, so that the signal can cover longer distances. Repeaters are used to extend the length of a network segment.
 Mnemonic: A repeater REPEATS the signal to go longer distances.

2. Hub: A hub is a device that connects multiple Ethernet devices together, making them act as a single segment. It receives signals from any connected device and transmits it to all other devices. Hubs operate at the physical layer and do not understand network addresses.
 Mnemonic: A hub HUBS all the devices together into a single network segment.

3. Bridge: A bridge is a device that connects two network segments and forwards traffic between them based on MAC addresses. It operates at the data link layer and helps reduce unnecessary traffic on each segment.
 Mnemonic: A bridge BRIDGES two network segments together.

4. Switch: A switch is a multi-port bridge that forwards traffic between network segments based on MAC addresses. It divides a network into smaller segments and reduces collisions. Switches are more efficient than hubs.
 Mnemonic: A switch SWITCHES data between network segments intelligently.

5. Router: A router is a device that forwards traffic depending on network layer addresses like IP addresses. It can connect multiple networks and route traffic between them efficiently. Routers allow isolation and security between networks and enable communication between networks with different protocols.
 Mnemonic: A router ROUTES data between networks based on network addresses.
