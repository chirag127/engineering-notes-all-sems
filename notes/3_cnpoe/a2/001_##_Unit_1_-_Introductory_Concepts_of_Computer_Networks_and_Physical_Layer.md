## Unit 1 - Introductory Concepts of Computer Networks and Physical Layer

- Computer Network: A computer network is a group of computers that are interconnected and able to communicate with each other to share resources and information.
- Nodes: The devices that are connected in a computer network are called nodes. Examples of nodes are computers, printers, servers, etc.
- Links: The communication pathways that connect the nodes in a computer network are called links. Examples of links are twisted pair cables, fiber optic cables, Wi-Fi, etc.
- Packet: The data in a computer network is transmitted in the form of packets. A packet contains the data to be transmitted along with the address of the sender and recipient.
- Protocols: Protocols are the rules and formats that govern the communication between devices in a computer network. Examples of protocols are IP, TCP, UDP, SMTP, etc.

### Physical Layer

- The lowest layer of the OSI model that deals with the physical connections between devices.
- Specifications of the physical medium, pin assignments, cable types, signal types, etc. are defined at the physical layer.
- Examples of physical layer components are network adapters, cables, connectors, etc.
- Key characteristics and functions:

- Data transmission: Converting data into signals and transmitting over the network medium.
- Data reception: Receiving signals from the network medium and converting back into data.
- Electrical specifications: Specifications for voltage, pin assignments, cable types, etc.
- Mechanical specifications: Specifications for connectors, plugs, etc.

Mnemonics:
- Please Do Not Throw Sausage Pizza Away - for remembering the layers of OSI model from Physical layer to Application layer.

Advantages:
- Provides an interface between the network medium and the devices.
- Establishes and terminates physical connections between devices.

Disadvantages:
- Vulnerable to network issues like cable breakage, signal interference, etc. which can disrupt the flow of data.

Applications: Ethernet, DSL, etc.
