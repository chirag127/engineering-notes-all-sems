### Point-to-point networks in network layer

Point-to-point networks consist of direct dedicated links between two nodes. Some key points about point-to-point networks:

- There are only two nodes in the network which are directly connected.
- Full bandwidth of the link is dedicated to these two nodes.
- Higher cost but provides highest security and reliability.
- Examples: Leased lines, Cable modems, DSL.

**Mnemonics:**

- Remember 'P2P' for Point-to-Point. Only two parties involved, no middleman.
- Imagine two people directly shouting at each other from two mountains. No third person in between.

**Advantages:**

- Simple to implement. Only two nodes are involved.
- High transmission speed. Entire bandwidth is dedicated to the two nodes.
- High level of privacy and security as there is no third node to interfere.

**Disadvantages:**

- Expensive to establish and maintain.
- Not scalable as number of links grows exponentially with number of nodes.
- If one node fails, the link fails. No alternative path exists.

_Applications:_ Leased lines, Cable modems, DSL, Satellite communication.
