#### DHCP

DHCP stands for Dynamic Host Configuration Protocol. It is a network management protocol used on IP networks whereby a DHCP server dynamically assigns an IP address and other network configuration parameters to each device on a network so they can communicate with other IP networks.

Some key points about DHCP are:

- It eliminates the need for network administrators to manually assign IP addresses to every device on the network. This saves time and effort and reduces errors.
- The IP addresses leased to devices can be reused when devices are disconnected from the network, allowing a limited pool of IP addresses to be shared among a larger number of network devices.
- Additional configuration information provided by DHCP may include subnet mask, default gateway, DNS server addresses, etc. This ensures devices have all the information they need to participate fully in the network.
- The DHCP process uses a client-server model. The DHCP client sends a broadcast query requesting necessary network information. The DHCP server responds with an IP address and other network details.
- DHCP allows centralized management of the IP address space and ensures IP address conflicts are avoided.
- DHCP supports static IP address assignments as well if needed. Some devices like servers may require fixed IP addresses, so DHCP reservations can be set up to allocate the same IP address to a specific device based on its MAC address.

Some mnemonics to remember DHCP are:

- Dynamic Host Configuration Protocol
- DHCP doles out network configs
- DHCP - no more manual IP drama!
