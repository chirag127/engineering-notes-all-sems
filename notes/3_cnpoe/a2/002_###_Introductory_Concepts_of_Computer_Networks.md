### Introductory Concepts of Computer Networks

Some key introductory concepts of computer networks are:

1. Network Devices - Devices that facilitate communication and data transfer in a computer network like routers, switches, modems, etc. Routers connect multiple networks and forward packets between them. Switches connect devices in a local network and forward packets between the ports. Modems modulate and demodulate signals for transmission over communication channels.
2. Protocols - Rules and standards that govern communication in a network. Examples are TCP/IP, Ethernet, Wi-Fi, etc. TCP/IP is the dominant protocol suite for the Internet. Ethernet is used in local area networks. Wi-Fi is used for wireless networks. Protocols facilitate orderly transmission of data.
3. Bandwidth and Latency - Bandwidth refers to the maximum data transfer rate of a network. Higher bandwidth means faster data transfer. Latency refers to the time taken for data to be transferred from one point to another. Lower latency means faster response and delivery times. Bandwidth and latency affect network performance.
4. Transmission Medium - The physical pathway that carries the data in a network. Can be wired (optical fiber, twisted pair cable, coaxial cable) or wireless (radio waves). The capabilities and characteristics of the transmission medium influence the network speed, range, and other factors.

Mnemonics -

- **Never** Eat **Cake** In a **Router** - for remembering the order of network devices - Never (modem) -> Eat (router) -> Cake (switch) -> In a Router
- Please **Do** Not **Throw** Sausage **Pizza** Away - for remembering layers of TCP/IP model - Physical -> Data link -> Network -> Transport -> Session -> Presentation -> Application

Advantages of computer networks - Resource sharing, faster communication, connectivity, cost efficiency.
Disadvantages - Complexity, security issues, dependence on network.
