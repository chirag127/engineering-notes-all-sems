# Computer Networks

## Introduction
- A computer network is a group of computers that use a set of communication protocols over electrical, optical or wireless signalling mediums to communicate and share resources.
- The computers connected in a network can range from just two computers to millions of computers.
- The key characteristics of a computer network are:
    - Shared resources: The resources like data, storage, printers, etc are shared among the networked computers.
    - Communication medium: A communication path like wires, cables, wireless signals, etc are used to transmit data between the computers.
    - Network devices: Specialized devices like routers, switches, gateways, etc are used to interconnect the computers and facilitate communication.
    - Protocols: Standard set of rules and convention are used for communication between the network devices and computers. Some popular protocols are TCP/IP, HTTP, FTP, etc.

## Types of Networks
The major types of computer networks are:
1. Local Area Network (LAN): Covered a small physical area like home, office, etc. Uses Ethernet technology.
2. Wide Area Network (WAN): Covers a large geographical area. Uses telephone lines, optical fibres, satellites, etc. Examples: Internet.
3. Metropolitan Area Network (MAN): Covers a city or a large campus. Uses high-speed communication channels.
4. Wireless Local Area Network (WLAN): Uses radio waves to connect devices within a local area. Examples: Wi-Fi.

## Network Topologies
The way the computers and network devices are physically connected in a network is known as network topology. The common network topologies are:
1. Bus topology: All devices are connected to a central cable.
2. Star topology: All devices are connected to a central switch.
3. Ring topology: All devices are connected to each other in a closed loop.
4. Mesh topology: Each device is connected to every other device.
