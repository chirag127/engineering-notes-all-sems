#### Protocols and Standards in Networks Architecture in Computer Networks

The protocols and standards that enable communication between devices in a computer network are:

1. Ethernet: Ethernet is a link layer protocol standard that defines a family of network interfaces and protocols for communicating over wired and wireless local area networks (LANs). It uses Carrier Sense Multiple Access with Collision Detection (CSMA/CD) for mediating access to the network among multiple devices. Ethernet is the most popular network technology in local area networks with speeds ranging from 10 Mbps to 100 Gbps.

- Mnemonic: Think of "ETHER" as the medium that "CARRIES" data packets in a LAN.

2. IP (Internet Protocol): IP is a network layer protocol that provides packet addressing and routing functionality for transferring data across networks. It underlies the communication across the Internet and most private networks. The current version of IP is IPv4 with a newer version IPv6 also deployed in networks. IP packets encapsulate the data from higher layer protocols like TCP and UDP to enable end-to-end delivery across networks.

- Mnemonic: IP is the "INTERNET" Protocol that uses "ADDRESSING" to "ROUTE" packets.

3. TCP (Transmission Control Protocol): TCP is a transport layer protocol that provides reliable, ordered, and error-checked delivery of byte streams over IP networks. It is typically used for applications that require high reliability such as email, web browsing, and file transfer. TCP uses a three-way handshake to establish a connection and flow control to regulate the rate of data transfer.

- Mnemonic: TCP provides "RELIABLE" and "ORDERLY" "TRANSMISSION" of data with "CONTROL" and "CONNECTION" to applications.
