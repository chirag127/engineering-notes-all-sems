### Data compression in application layer

Data compression is a technique to reduce the size of data to save storage space and bandwidth during transmission. Some of the data compression techniques used in the application layer are:

1. ** lossless compression**: The original data can be reconstructed from the compressed data exactly. Examples are Huffman coding, Lempel-Ziv coding (like Gzip). These are useful for compressing text files, program files, etc. where losing even a single bit of data is not acceptable.

Mnemonics: Lossless compression means **no loss** of data.

2. **lossy compression**: The original data cannot be reconstructed exactly from the compressed data. Some amount of data is lost in compression. Examples are JPEG, MP3, MP4, etc. These are useful for compressing multimedia like images, audio, and video where some amount of loss of data is tolerable.

Mnemonics: Lossy compression leads to **loss** of data.

Advantages of data compression:
- Reduces storage space and bandwidth requirements.
- Faster data transfer and access.
Disadvantages of data compression:
- Required additional processing to compress and decompress data which can introduce latency.
- Lossy compression leads to loss of data.

Applications of data compression:
- Image, audio and video formats (JPEG, MP3, MP4, etc.)
- File compression utilities (ZIP, RAR, etc.)
- Databases
- Network protocols (HTTP, SSH, etc.)
