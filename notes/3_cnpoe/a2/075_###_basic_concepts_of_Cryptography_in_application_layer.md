### Basic concepts of Cryptography in application layer

1. Encryption - Convert plain text into cipher text which cannot be understood by anyone except the intended recipient who has the key to decrypt it.
Mnemonics - Caesar cipher, substitution cipher, transposition cipher, etc. are some basic encryption techniques to remember.

2. Decryption - Convert cipher text back into plain text using a key. The receiver requires the same key used for encryption to decrypt the message.

3. Keys - Keys are used to encrypt and decrypt data. Without the correct key, cipher text cannot be decrypted into plain text.
There are two types of keys:

- Symmetric key - Same key is used for both encryption and decryption. Private key is shared between the sender and receiver.
- Asymmetric key - Uses a public key and a private key. The public key is shared with everyone while the private key is kept secret.

4. Digital Signature - A method to verify the authenticity and integrity of a message. The sender uses their private key to sign a message and the receiver uses the sender's public key to verify the signature.
If the signature matches, it confirms that the message was indeed sent by the owner of the private key and was not altered.

5. Hash Functions - Produce a fixed size hash value from a variable size input. The hash is unique to the input data and any change in input will result in a different hash.
Used to verify data integrity as a change in input will result in a different hash. The original and new hash can be compared to check for changes.
