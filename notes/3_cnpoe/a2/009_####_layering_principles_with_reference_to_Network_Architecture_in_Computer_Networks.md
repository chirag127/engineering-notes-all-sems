#### Layering principles with reference to Network Architecture in Computer Networks

The layering principles followed in Network Architecture are:

1. Hierarchy: The network is divided into multiple layers forming a hierarchy. Each layer focuses on a specific functionality and provides services to the upper layer.
2. Abstraction: Each layer acts as an abstraction to the layer above it. A layer need not know the working details of the lower layer and just uses the services provided by the lower layer. This leads to modularity.
3. Service provision: A layer in the hierarchy provides services to the layer above it. For example, the Data Link layer provides reliable data transmission services to the Network layer above it.
4. Standard interface: Between each adjacent layers, standard interfaces are defined. These interfaces essentially comprise of the services provided by the lower layer to the upper layer. This enables interaction between layers.

The layering principles allow for modular design, simplification, flexibility and interoperability in the complex network systems. The OSI and TCP/IP models follow the layering principles and divide the network into 7 and 4 layers respectively. Each layer has certain defined functionalities and services.

- All People Seem To Need Data Processing - indicative of the OSI layers

Advantages: Modularity, simplicity, interoperability, flexibility, technology independence
Disadvantages: Added overhead, encapsulation

Examples: OSI model, TCP/IP model
Applications: Basis for network architecture and protocol design
