#### ARP
ARP stands for Address Resolution Protocol. It is a protocol used to map IP addresses to MAC addresses.

**Mnemonics:**
- ARP: Address Resolution Protocol
- IP to MAC mapping

**Learning Tricks:**
- Think of ARP as a phone book that converts IP addresses (phone numbers) to MAC addresses (person's name).
- ARP request is like looking up a phone number (IP address) to get the person's name (MAC address).
- ARP reply is the response that provides the MAC address for the requested IP address.

**Points to remember:**
1. ARP is used when a device needs to determine the MAC address of another device on the same network.
2. The device sending an ARP request (who-has) includes the IP address of the target device. The target device replies with its MAC address (is-at).
3. ARP requests are broadcasts and the target device unicasts the reply.
4. ARP entries are typically cached (saved) for a short period of time to speed up subsequent ARP lookups.
5. ARP has vulnerabilities like ARP poisoning/spoofing where an attacker sends malicious ARP replies to associate the wrong MAC address with an IP address.

**Advantages:**
- ARP enables IP-address-based communication by mapping IP addresses to MAC addresses.
- ARP caching reduces latency for subsequent ARP lookups.

**Disadvantages:**
- Vulnerable to attacks like ARP poisoning and spoofing.
- Entries can become stale if not flushed from cache.

**Applications:**
- Essential for communication in IP-based networks.
- ARP is used whenever an IP device needs to determine the MAC address of another device on the local network.
