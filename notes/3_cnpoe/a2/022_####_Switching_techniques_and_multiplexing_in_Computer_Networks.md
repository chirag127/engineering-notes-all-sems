#### Switching techniques and multiplexing in Computer Networks

- Switching techniques: Switching techniques are used to connect multiple devices in a network and facilitate communication between them. The main types of switching techniques are:
- Circuit switching: A dedicated end-to-end path is established between the source and destination devices before the actual data transmission takes place. The resources are dedicated to the connection for the duration of the connection. Examples: Traditional telephone network.
- Message switching: Messages are first stored and then forwarded. The network determines the path to forward the messages, and the messages may be received out of order. Examples: Email.
- Packet switching: Data is broken into packets that include destination address. The packets are then individually routed between nodes over multiple paths before arriving at the destination. Examples: Ethernet, IP networks.

Advantages of packet switching over circuit switching:
- Efficient use of resources: Resources are used only when there is data to transmit.
- Robust: There are multiple paths to the destination, so even if one path fails, packets can be rerouted dynamically.

Multiplexing: Multiplexing is a technique where multiple data streams are combined into one signal over a shared medium. This allows efficient use of the bandwidth of the shared medium. The main types of multiplexing are:
- Frequency division multiplexing (FDM): Different data streams are allocated different frequency ranges.
- Time division multiplexing (TDM): Different data streams are allocated different time slots.
- Statistical time division multiplexing (STDM): Time slots are allocated on demand to the data streams that have data to transmit.

Multiplexing is used in networking technologies like Ethernet, FDDI, etc. to share the medium among multiple communicating devices.
