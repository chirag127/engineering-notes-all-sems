#### LAN standards in local area network

Here are the key LAN standards used in local area networks:

1. Ethernet: Ethernet is the most popular LAN standard. It uses CSMA/CD access method and supports data transfer rates of 10 Mbps, 100 Mbps, 1 Gbps, 10 Gbps, 40 Gbps, and 100 Gbps. Ethernet uses MAC addresses to uniquely identify devices on the network. Ethernet cables include twisted pair, coaxial, and fiber optic cables.

Mnemonics:

- Fast Ethernet: 100 Mbps, Uses twisted pair or fiber optic cable
- Gigabit Ethernet: 1 Gbps, Uses twisted pair or fiber optic cable
- 10 Gigabit Ethernet: 10 Gbps, Uses fiber optic cable

2. Token Ring: Token Ring uses a token passing access method and supports data transfer rates of 4 Mbps and 16 Mbps. It uses a special 3-byte frame called a token that is passed around the ring. Only the device holding the token can transmit data. Token Ring uses MAC addresses and can use twisted pair or fiber optic cables.

3. FDDI: FDDI stands for Fiber Distributed Data Interface. It uses a token passing access method and supports data transfer rates of 100 Mbps. FDDI uses fiber optic cables and MAC addresses. It is typically used as a high-speed backbone network.

Advantages:

- High speed - Ethernet, FDDI
- deterministic access - Token Ring

Disadvantages:

- Expensive hardware - FDDI
- Complex access method - Token Ring

Applications:

- Ethernet: LANs, MANs, Backbones
- Token Ring: LANs
- FDDI: Backbones
