## Unit 5 - Application Layer in Computer Networks

The Application layer is the topmost layer of the OSI model. It provides interfaces for application software to access the network.

Some key points about the Application layer:

- It interacts with software applications that implement a communicating component.
- It provides protocols that allow application processes to interact and exchange data. For example, HTTP, FTP, SMTP, DNS, etc.
- It determines how data should be changed to suit the needs of the application. For example, formatting, code conversion, etc.
- It facilitates identifying and establishing communication partners, determining resource availability, and synchronizing communication.
- It determines how to translate application-specific data into network format and vice versa.

**HTTP:** Hypertext Transfer Protocol is used for accessing web pages on the Internet. It defines how messages should be formatted and transmitted, and what actions web servers and browsers should take in response to various commands.

**FTP:** File Transfer Protocol is used to transfer files between computers over the Internet. It defines separate commands for logging in, transferring files, and logging out.

**SMTP:** Simple Mail Transfer Protocol is used for e-mail transmission across the Internet. It defines how e-mail messages should be formatted and transmitted between mail servers.

**DNS:** Domain Name System is used to map domain names to IP addresses. It's a distributed database implemented using a hierarchy of DNS servers.

Some mnemonics/learning tricks:

- Think of the Application layer as the interface between users and the network. It's what lets you access apps and their functions.
- HTTP, FTP, SMTP are some common app layer protocols - the first letter of each spells out **HFT** which could help remember them.
- DNS is what translates domains to IPs, so it helps with **D**omain **N**ame resolution to **I**P addresses.
