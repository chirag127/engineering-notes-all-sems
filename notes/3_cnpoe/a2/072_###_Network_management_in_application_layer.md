### Network management in application layer

The application layer of OSI model is responsible for network management activities. Some of the important network management functions in application layer are:

1. **Monitoring:** It monitors the performance of network devices, network traffic, error rates, etc. Using monitoring tools and software, network administrators can check the health of the network and identify any issues. Some monitoring parameters are bandwidth usage, CPU/memory usage, device up/down status, etc.
2. **Diagnosing:** It is used to diagnose the root cause of any network issues or degrade in performance. Based on the monitoring data, network devices and connections are tested to identify and localize the fault. Appropriate troubleshooting steps are taken to resolve the issues.
3. **Reporting:** The monitoring and diagnosing data is aggregated and represented in the form of reports. These reports help network administrators to make informed decisions on network optimization, resource allocation, security, etc. The reports may contain graphs, charts or tables based on the network performance.
4. **Configuration management:** It is responsible for the configuration of network devices. The configuration of multiple devices across the network can be managed centrally. Any changes to the configuration can be easily tracked. It helps to maintain consistency in device configurations.
5. **Accounting management:** It tracks the usage of network resources by users and devices. Based on usage, appropriate billing can be done. It can also be used for network traffic analysis to identify heavy usage of resources.

Some mnemonics to remember the network management functions are:
- "MON"itor, "DIAG"nose, "REPO"rt, "CONF"igure, "ACCT"ount
- "Watch, Check, Tell, Set, Bill"

The network management makes the network robust, reliable and secure. It enhances the performance of the network and optimizes the utilization of available resources.
