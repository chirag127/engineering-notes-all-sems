#### Services in networks architecture in Computer Networks

The services provided in a computer network can be broadly classified into the following categories:

1.  **File sharing service:** This service allows sharing of files, documents, programs, etc. among the devices connected in the network. This is very commonly used in networks to access shared storage and resources.
2.  **Print sharing service:** This service allows sharing of printers connected to the network among the devices. The print jobs can be sent over the network to the shared printers, thereby eliminating the need to have a dedicated printer for each device.
3.  **Application sharing service:** This service allows sharing of applications installed on one device with other devices in the network. This is useful when an application is resource intensive and cannot be installed on all devices or when license of an application permits only limited installations. Remote desktop connections and thin-client systems make use of this service.
4.  **Email service:** This service allows exchange of emails among the devices in the network. The emails are stored in a centralized email server and can be accessed by the devices using email client applications.
5.  **Web service:** This service enables hosting of websites and web-based applications over the network which can be accessed by the devices connected to the network or external networks (like the Internet).

**Mnemonics:**

-   **FILERS:** File sharing, Print sharing, Application sharing, Email service, Web service
-   ** fortuneCookies:** File fortune, Print fortune, App fortune, Email fortune, Web fortune (to remember the services and their fortune or benefit of using in a network)

**Advantages:** Centralized management, resource optimization, easy access, cost efficiency.
**Disadvantages:** Reliance on network connectivity, security threats, single point of failure.
