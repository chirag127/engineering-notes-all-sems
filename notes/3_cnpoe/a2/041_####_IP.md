#### IP (Internet Protocol)

- IP is the primary networking protocol used on the Internet and most computer networks. It is a connectionless protocol that provides packet switching and routing functionality between networks.
- IP assigns a unique address to each device on a network and uses these addresses to route data between devices and networks. The current version of IP is IPv4 which uses 32-bit addresses, allowing for 4,294,967,296 (4.3 billion) unique addresses.
- IPv4 addresses are written in dotted-decimal notation like 192.168.1.1. They consist of 4 octets where each octet is represented by a decimal number between 0 and 255.
- The key features of IP are:

-- Connectionless: IP is a connectionless protocol as it does not establish a dedicated end-to-end connection between two hosts. It encapsulates messages into packets that may travel independently over different paths before reaching the destination.
-- Best effort delivery: IP packets are delivered on a best effort basis and there are no guarantees that packets will be delivered or delivered in the right order. Higher-level protocols like TCP provide mechanisms to ensure packet delivery.
-- Packet switching: IP uses packet switching which means data is split into packets that include destination addresses. The packets are routed independently based on the destination address. This is more efficient than circuit switching.
-- Addressing and routing: The core functions of IP are addressing and routing. The addresses are used to route packets to the destination host. IP relies on routing tables that contain paths to destination networks.

- Key Mnemonics:

-- IP is the "Postman" of the Internet - delivers packets
-- 4 octets in IPv4 address like 4 quarters in an orange
-- Connectionless like sending letters without calling first
-- Best effort delivery - no guarantee the packets will arrive
-- Packet switching - packets take different routes and reassemble at destination
