### Domain Name System

The Domain Name System (DNS) is a hierarchical and decentralized naming system for computers, services, or other resources connected to the Internet or a private network. It associates various information with domain names assigned to each of the participating entities. Most prominently, it translates domain names meaningful to humans into the numerical (machine-readable) IP addresses needed for locating and identifying networked devices worldwide.

* DNS is an internet service that translates domain names (like google.com) into IP addresses (like 172.217.168.196) that computers use to identify each other.
* DNS resolves hostnames to IP addresses. It matches the domain name from a URL to the IP address of the server hosting that website. This allows you to access websites and other online resources using easy to remember domain names instead of difficult to remember IP addresses.
* The DNS is a distributed database implemented in a hierarchy of DNS servers. There are DNS root name servers at the top that direct queries to top-level domain name servers. These then direct queries to lower-level domain name servers until the query is resolved. This hierarchy helps distribute the task of translating domain names to IP addresses and ensures resilience.
* The most common types of DNS records are:
    * A record - Maps a domain name to an IPv4 address
    * AAAA record - Maps a domain name to an IPv6 address
    * CNAME record - Specifies an alias for a canonical domain name
    * MX record - Specifies the mail servers for a domain
* Some advantages of DNS are: scalability, decentralization, fault tolerance, and domain name management. Some disadvantages are: vulnerability to attacks like DNS spoofing and hijacking, and single points of failure in the root name servers.
* DNS has many applications like: enabling browsing websites using domain names, sending and receiving emails, running internet services, etc. It is a crucial service for the functioning of the internet.
