### Hyper Text Transfer Protocol (HTTP)

HTTP is the set of rules for transferring web pages on the Internet. It defines how messages should be formatted and transmitted, and what actions web servers and browsers should take in response to various commands.

Key points to remember:

- HTTP uses TCP/IP connections to transfer web pages.
- Data is transmitted using a request-response model. The client (browser) sends a request to the server, which returns a response.
- HTTP is a stateless protocol, meaning that each command is executed independently, without reference to previous commands.
- HTTP supports caching of web pages to improve performance.
- URLs identify resources and specify the protocol (HTTP) and the domain name.
- HTTP status codes indicate success or failure of a request. Common codes are 200 (success), 404 (not found), and 500 (server error).

Some mnemonics to remember:

- Every Good Boy Does Fine - corresponding to the notes on the lines of the treble clef (E, G, B, D, F)
- Roy G. Biv - colors of the rainbow (Red, Orange, Yellow, Green, Blue, Indigo, Violet)

Advantages of HTTP:

- Simple and easy to understand
- Scalable - can handle a wide range of network conditions and speeds
- Flexible - allows for new features to be added
- Widely supported - implemented in all major browsers and web servers

Disadvantages:

- No built-in security - data is transmitted in plaintext and can be read by others
- Stateless nature can affect website performance for applications that require tracking state
- Some additional protocols needed to address deficiencies (e.g. HTTPS for security, cookies for state management)
