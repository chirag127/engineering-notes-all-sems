### World Wide Web

The World Wide Web (WWW or Web) refers to the collection of interlinked hypertext documents accessed via the Internet. With a web browser, one can view web pages that may contain text, images, videos, and other multimedia and navigate between them via hyperlinks.

Some key points to learn about the World Wide Web:

1. The web was created by Tim Berners-Lee in 1989. He wrote the first web browser computer program in 1990 while employed at CERN in Switzerland.

2. The web is one of the applications of the Internet, the others being email, peer-to-peer file sharing, online chat, etc. The web makes it possible to access linked documents or web pages over the Internet through the use of web browsers.

3. Data on the web is encoded in HTML (Hypertext Markup Language) which creates web pages when accessed through a URL or web address. These web pages can contain text, images, videos and other web resources.

4. The web operates on top of the Internet protocol and uses URIs (Uniform Resource Identifiers) to identify web pages and other web resources. HTTP (Hypertext Transfer Protocol) is the underlying method used to retrieve web pages/resources over the Internet.

5. The web has become a very large repository of information and services. Everything from news, music, videos, gadgets, data, and more are available on the web. The web has transformed numerous aspects of society and enabled new ways of business and work practices.

**Mnemonics:**

- Tim BL created the WEB (for Tim Berners-Lee created the World Wide Web)
- HTTP sends HTML (for Hypertext Transfer Protocol sends Hypertext Markup Language)

**Advantages:**

- Easy access to vast amount of information
- E-commerce and business opportunities
- Online communications via email, social media, etc.
- Entertainment and multimedia content

**Disadvantages:**

- Information overload can lead to confusion or distraction
- Reliance on the Internet can lead to feelings of being disconnected without web access
- The web has enabled new forms of scams, fraud and illegal activities
- Privacy and security concerns with personal data being tracked or hacked
