### Congestion control algorithms in CN

Congestion control algorithms are used in computer networks to manage and prevent congestion, which occurs when there is more traffic on a network than it can handle. In this section, we will discuss some of the most commonly used congestion control algorithms in computer networks.

1. TCP Reno: TCP Reno is a popular congestion control algorithm that is used in many computer networks. It is based on the principle of detecting congestion by observing packet losses and adjusting the sending rate accordingly. This algorithm is able to achieve high throughput and low latency in a wide range of network conditions.

2. TCP Vegas: TCP Vegas is another popular congestion control algorithm that is used in computer networks. It is based on the principle of detecting congestion by monitoring the round-trip time of packets and adjusting the sending rate accordingly. This algorithm is able to achieve low latency and high throughput in high-speed networks.

3. TCP New Reno: TCP New Reno is an improved version of TCP Reno that is used in many modern computer networks. It is able to detect congestion more accurately and adjust the sending rate more quickly than TCP Reno. This algorithm is able to achieve high throughput and low latency in a wide range of network conditions.

4. TCP Cubic: TCP Cubic is a newer congestion control algorithm that is used in many modern computer networks. It is based on the principle of detecting congestion by monitoring the available bandwidth and adjusting the sending rate accordingly. This algorithm is able to achieve high throughput and low latency in a wide range of network conditions, including high-speed networks.
