## Unit 3 - Network Layer in Computer Networks

The network layer is the third layer of the OSI reference model and is responsible for providing logical addressing and routing of data between different networks. It is a crucial component of computer networks as it enables communication between devices that are not directly connected to each other.

### Addressing

- The network layer uses a unique logical address, known as an IP address, to identify devices on a network.
- IP addresses are 32-bit numbers and are represented in dotted decimal notation.
- The first part of the IP address identifies the network and the second part identifies the host.

### Routing

- The network layer is responsible for determining the best path for data to travel between two devices on different networks.
- Routing protocols, such as OSPF and BGP, are used to exchange information about network topology and to determine the best path for data to travel.
- Routers are the devices that operate at the network layer and are responsible for forwarding data packets between networks.

### IP Protocol

- The Internet Protocol (IP) is the primary protocol used at the network layer.
- IP provides a connectionless, best-effort delivery service, which means that it does not guarantee delivery of packets and does not establish a connection before transmitting data.
- IP packets consist of a header and a payload. The header contains information such as the source and destination IP addresses, while the payload contains the actual data being transmitted.

### Mnemonics and Learning Tricks

- To remember the function of the network layer, you can use the mnemonic "ANNA" which stands for Addressing and Routing in Networks.
- To remember the structure of an IP address, you can use the phrase "Net ID, Host ID, and Dots Between" which corresponds to the format of the IP address.

Overall, the network layer is a critical component of computer networks, enabling communication between devices on different networks through logical addressing and routing of data. Understanding the concepts and protocols involved in the network layer is essential for anyone involved in computer networking.
