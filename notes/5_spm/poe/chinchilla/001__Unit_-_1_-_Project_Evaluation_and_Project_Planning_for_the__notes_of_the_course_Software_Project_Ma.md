## Unit - 1 - Project Evaluation and Project Planning for the notes of the course Software Project Management

In this unit, we will discuss the importance of Project Evaluation and Project Planning in Software Project Management. The following points will be covered:

- **Project Evaluation**
  - Definition and explanation of Project Evaluation
  - Importance of Project Evaluation in Software Project Management
  - Types of Project Evaluation
    - Technical Evaluation
    - Economic Evaluation
    - Operational Evaluation
    - Social Evaluation
  - Steps involved in Project Evaluation
    - Identifying the need for evaluation
    - Setting evaluation goals and objectives
    - Collecting data and information
    - Analyzing and interpreting data
    - Reporting and using evaluation findings
- **Project Planning**
  - Definition and explanation of Project Planning
  - Importance of Project Planning in Software Project Management
  - Steps involved in Project Planning
    - Defining project scope and objectives
    - Identifying project stakeholders
    - Creating a work breakdown structure (WBS)
    - Estimating project duration and cost
    - Creating a project schedule
    - Identifying project risks and developing a risk management plan
    - Creating a project team and assigning tasks
    - Monitoring and controlling project progress
    - Closing the project

It is important to note that Project Evaluation and Project Planning are two critical components of Software Project Management. They help ensure project success by providing a framework for evaluating the feasibility of a project and planning its execution. By following the steps outlined in this unit, project managers can effectively evaluate and plan their projects, thereby increasing the probability of project success.
