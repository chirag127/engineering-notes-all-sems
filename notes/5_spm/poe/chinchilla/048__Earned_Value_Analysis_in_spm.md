### Earned Value Analysis in SPM

Earned Value Analysis (EVA) is a technique used in project management to measure project performance against the project plan. It is a powerful tool that helps project managers to assess the progress of their projects, make informed decisions, and take corrective actions when necessary. In this article, we will discuss the basics of Earned Value Analysis in SPM.

#### What is Earned Value Analysis?

Earned Value Analysis is a project management technique that helps to measure the actual progress of a project against the planned progress. It is a method of tracking the performance of a project by comparing the actual work completed to the planned work and measuring the value of the work completed in monetary terms.

#### Why is Earned Value Analysis Important?

Earned Value Analysis is important because it provides project managers with a clear picture of the project's performance in terms of cost, schedule, and scope. It helps project managers to identify potential problems early on and take corrective actions to keep the project on track. It also helps to identify areas where the project is performing well, and project managers can use this information to replicate the success in other areas of the project.

#### How is Earned Value Analysis Calculated?

Earned Value Analysis is calculated using three key metrics: Planned Value (PV), Actual Cost (AC), and Earned Value (EV).

- Planned Value (PV): Planned Value is the budgeted cost of the work scheduled to be completed up to a specific point in time. It is calculated by multiplying the planned percentage of the work completed by the total budgeted cost of the project.

- Actual Cost (AC): Actual Cost is the total cost of the work completed up to a specific point in time. It includes all direct and indirect costs associated with the project.

- Earned Value (EV): Earned Value is the value of the work completed up to a specific point in time. It is calculated by multiplying the actual percentage of the work completed by the total budgeted cost of the project.

#### How is Earned Value Analysis Interpreted?

Earned Value Analysis is interpreted using a set of key performance indicators (KPIs), which include:

- Schedule Variance (SV): SV measures the difference between the planned value and the earned value. A positive SV indicates that the project is ahead of schedule, while a negative SV indicates that the project is behind schedule.

- Cost Variance (CV): CV measures the difference between the earned value and the actual cost. A positive CV indicates that the project is under budget, while a negative CV indicates that the project is over budget.

- Schedule Performance Index (SPI): SPI measures the efficiency of the project in terms of schedule. It is calculated by dividing the earned value by the planned value. An SPI value greater than 1 indicates that the project is ahead of schedule, while an SPI value less than 1 indicates that the project is behind schedule.

- Cost Performance Index (CPI): CPI measures the efficiency of the project in terms of cost. It is calculated by dividing the earned value by the actual cost. A CPI value greater than 1 indicates that the project is under budget, while a CPI value less than 1 indicates that the project is over budget.

#### Conclusion

In conclusion, Earned Value Analysis is an essential tool for project managers to measure the actual progress of a project against the planned progress. It helps project managers to identify potential problems early on and take corrective actions to keep the project on track. By calculating and interpreting key performance indicators, project managers can gain valuable insights into the project's performance and make informed decisions to ensure project success.
