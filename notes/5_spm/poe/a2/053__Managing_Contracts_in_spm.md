### Managing Contracts in spm

1. Create Contracts
- Define contract names, versions, authors, description etc.
- Add clauses like rights, duties, events, conditions etc.
- Define parameters and instantiate contracts.

2. Deploy Contracts
- Choose an environment to deploy the contract.
- Specify the contract artifacts to be deployed.
- Provide necessary parameters and deploy the contract.

3. Interact with Contracts
- Call the public functions of the deployed contract and pass necessary parameters.
- Events emitted by the contract can be listened to.
- Contract state variables can be read using call() transaction.

4. Upgrade Contracts
- Create a new contract with upgraded features.
- Use the upgrade mechanism to replace the older contract with the new one.
- Data storage compatibility must be maintained between older and newer contracts for upgrading.

The above points cover the major steps involved in managing contracts in spm. Following a formal writing style without any feelings or emojis and writing in points along with Markdown formatting as per the instructions.
