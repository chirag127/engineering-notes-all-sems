### Earned Value Analysis in spm

1. Earned Value Analysis (EVA) is a project management technique that measures the progress of a project against planned progress.
2. It integrates scope, cost and schedule measures to help the project team assess progress towards completion.
3. The three key metrics used in EVA are:
- Planned Value (PV): The budgeted cost of work scheduled to be completed by a specific point in time.
- Earned Value (EV): The budgeted cost of work actually completed by a specific point in time.
- Actual Cost (AC): The actual cost incurred for the work completed by a specific point in time.
4. Using these metrics, we can calculate additional metrics to analyze performance:
- Cost Variance (CV) = Earned Value (EV) - Actual Cost (AC)
- Schedule Variance (SV) = Earned Value (EV) - Planned Value (PV)
- Cost Performance Index (CPI) = Earned Value (EV) / Actual Cost (AC)
- Schedule Performance Index (SPI) = Earned Value (EV) / Planned Value (PV)
5. The CPI and SPI indicate how the project is performing compared to the plan. A value over 1 is good, under 1 is bad. Corrective action may be needed if these fall outside an acceptable range.
6. EVA is a useful way to identify and address performance issues early before they lead to missing objectives or exceeding budgets. Regular EVA reviews help keep the project on track towards successful completion.
