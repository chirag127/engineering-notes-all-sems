### Activities in Software Project Management

1. Planning
- Estimating costs and schedule
- Risk analysis
- Task allocation

2. Requirements Analysis
- Understanding client requirements
- Documenting requirements
- Validating and reviewing requirements

3. Design
- High-level design
- Detailed design
- Reviewing and finalizing design

4. Coding
- Implementing the design in a programming language
- Unit testing code modules
- Fixing bugs or defects

5. Testing
- Integration testing
- System testing
- Acceptance testing

6. Deployment
- Releasing software for client use
- Training users
- Maintenance and support
