### Software Process and Process Models

1. Software Process: A software process is a set of activities, methods, practices, and transformations that people use to develop and maintain software and the associated products (e.g., project plans, design documents).
2. Process activities: The generic software process includes specification, design, implementation, test, release, and maintenance activities.
3. Process models: Process models capture the essential aspects of a software process in an abstract way. They help standardize and organize the process of software development.
4. Waterfall model: The waterfall model consists of the following phases: requirements analysis, design, implementation, testing, deployment, and maintenance. The outputs of each phase serve as inputs to the next phase. The waterfall model emphasizes a systematic, sequential approach.
5. Incremental/iterative model: The incremental model focuses on incrementally building portions of the software. Each phase of the waterfall model is revisited as new increments are planned and developed. This process is iterative. The incremental model is useful for large, expensive projects.
