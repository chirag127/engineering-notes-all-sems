
### Activities in Software Project Management
1. Project Planning: This involves creating a timeline for the project and determining the resources and budget needed to complete it.
2. Project Scheduling: This involves creating a timeline for the project and determining the tasks that need to be completed in order to finish it.
3. Project Monitoring: This involves tracking the progress of the project and ensuring that it is on track to completion.
4. Project Risk Management: This involves identifying and managing potential risks that may arise during the project.
5. Project Quality Management: This involves ensuring that the project meets the desired quality standards.
6. Project Documentation: This involves creating and maintaining project documentation such as design documents, user manuals, and other related documents.
7. Project Change Management: This involves managing changes to the project scope, schedule, and budget.
8. Project Communication Management: This involves managing communication between stakeholders and team members throughout the project.
9. Project Closure: This involves closing out the project and ensuring that all deliverables are met.
