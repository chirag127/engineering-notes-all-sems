## Unit - 2 - Project Life Cycle and Effort Estimation

The project life cycle is a series of phases that a project passes through from its initiation to its closure. The phases are generally sequential and are determined by the needs of the project. The project life cycle provides a framework for managing a project and is essential for effective project management.

Effort estimation is the process of predicting the amount of effort required to complete a project. It is an important part of project planning and is used to determine the project schedule and budget. Effort estimation is based on the size and complexity of the project, the skills and experience of the project team, and the project management methodology used.

1. **Initiation Phase:** The initiation phase is the first phase of the project life cycle. During this phase, the project is defined and the feasibility of the project is assessed. The project charter is developed, which outlines the project objectives, scope, and stakeholders.

2. **Planning Phase:** The planning phase is the second phase of the project life cycle. During this phase, the project team develops a detailed project plan, which includes the project schedule, budget, and risk management plan. The project plan is used to guide the project team during the execution phase.

3. **Execution Phase:** The execution phase is the third phase of the project life cycle. During this phase, the project team executes the project plan and works to meet the project objectives. The project manager monitors the project progress and makes adjustments to the project plan as needed.

4. **Monitoring and Control Phase:** The monitoring and control phase is the fourth phase of the project life cycle. During this phase, the project manager monitors the project progress and compares it to the project plan. If the project is not progressing as planned, the project manager takes corrective action to bring the project back on track.

5. **Closure Phase:** The closure phase is the final phase of the project life cycle. During this phase, the project is completed and the project team delivers the project deliverables to the customer. The project team also conducts a lessons learned review to identify areas for improvement for future projects.

Effort estimation techniques include expert judgment, analogy, parametric estimation, and bottom-up estimation. The choice of technique depends on the project and the information available. It is important to regularly review and update the effort estimate throughout the project to ensure that it remains accurate.
