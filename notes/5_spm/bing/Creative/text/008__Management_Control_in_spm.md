### Management Control in SPM

Management control is the process of setting objectives for a software project and then monitoring the project to see what its true performance is. It involves the following steps:

- Data collection: The project manager needs to gather relevant data from various sources, such as progress reports, quality metrics, customer feedback, etc. to measure the actual performance of the project.
- Data processing: The project manager needs to transform the raw data into useful information, such as percentage of completion, deviation from schedule, cost variance, defect density, customer satisfaction, etc. to evaluate the project performance.
- Comparison: The project manager needs to compare the actual performance with the planned performance, such as the project objectives, scope, schedule, budget, quality standards, etc. to identify any gaps or discrepancies.
- Decision making: The project manager needs to analyze the causes of the gaps or discrepancies and decide on the appropriate actions to take, such as corrective actions, preventive actions, change requests, etc. to bring the project back on track or improve its performance.
- Modelling: The project manager needs to simulate the consequences of the potential actions and choose the best option that aligns with the project goals and stakeholder expectations.
- Implementation: The project manager needs to execute the chosen actions and communicate them to the project team and other stakeholders.
- Review: The project manager needs to monitor the effects of the actions and evaluate their impact on the project performance. The project manager also needs to update the project plan and documents accordingly.

Management control is a continuous and iterative process that helps the project manager to ensure that the project delivers the expected value and meets the stakeholder needs. Management control also helps the project manager to manage the project risks and uncertainties and cope with the changes and challenges that may arise during the project lifecycle.
