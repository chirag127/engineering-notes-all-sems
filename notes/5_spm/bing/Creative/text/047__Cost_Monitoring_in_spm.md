### Cost Monitoring in SPM

Cost monitoring in Software Project Management (SPM) is a process or function that monitors the expenses related to a software project, including hardware, development, maintenance and operations. Cost monitoring helps project managers to track progress and make sure they stay within budget. Some of the steps involved in cost monitoring are:

- Establishing a baseline budget or budgeted cost of work scheduled (BCWS) for each task or work package based on the original expenditure forecasts.
- Recording the actual cost of work performed (ACWP) for each task or work package based on the actual expenses incurred.
- Calculating the earned value or budgeted cost of work performed (BCWP) for each task or work package based on the percentage of completion or some other consistent method of assigning value.
- Comparing the BCWP, BCWS and ACWP to measure the cost variance (CV), the schedule variance (SV), the cost performance index (CPI) and the schedule performance index (SPI) for each task or work package and for the whole project.
- Projecting the estimate at completion (EAC), the estimate to complete (ETC) and the variance at completion (VAC) based on the current data and trends.
- Assessing the project status and taking corrective actions if necessary to bring the project back on track.

Cost monitoring can be performed on a regular basis or on a need basis, depending on the project size and complexity. Cost monitoring can be supported by tools such as charts, graphs, tables, dashboards and reports that display the relevant data and indicators. Cost monitoring can also be integrated with other aspects of project monitoring and control, such as scope, time, quality and risk.
