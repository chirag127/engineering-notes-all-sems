### Earned Value Analysis in SPM

Earned Value Analysis (EVA) is a project management technique that allows the project manager to measure the amount of work actually performed on a project beyond the basic review of cost and schedule reports. EVA provides a method that permits the project to be measured by progress achieved. The project manager is then able, using the progress measured, to forecast a project's total cost and date of completion, based on trend analysis or application of the project's "burn rate".

Some of the features of EVA are:

- It is an objective method to measure project performance in terms of scope, time and cost.
- It provides different measures of progress for different types of tasks.
- It provides an 'early warning' signal for prompt corrective action.
- It allows 'rolling up' the progress of many tasks into an overall project status.
- It provides a common value scale for every project task.

Some of the key elements of EVA are:

- Planned Value (PV) - The approved cost baseline for the work package.
- Earned Value (EV) - The budgeted value of the completed work packages.
- Actual Cost (AC) - The actual cost incurred during the execution of work packages up to a specified point in time.
- Schedule Variance (SV) - The difference between EV and PV. It indicates whether the project is ahead or behind schedule.
- Cost Variance (CV) - The difference between EV and AC. It indicates whether the project is under or over budget.
- Schedule Performance Index (SPI) - The ratio of EV to PV. It measures how efficiently the project is using time.
- Cost Performance Index (CPI) - The ratio of EV to AC. It measures how efficiently the project is using resources.
- Estimate at Completion (EAC) - The projected total cost of the project at completion, based on the current performance.
- Estimate to Complete (ETC) - The projected cost to complete the remaining work, based on the current performance.
- Variance at Completion (VAC) - The difference between the original budget and the EAC. It indicates the expected overrun or underrun at completion.

To perform EVA, the project manager needs to follow these steps:

- Define the work breakdown structure (WBS) and assign a budget to each work package.
- Establish the project baseline by aggregating the PV of all work packages.
- Monitor the project progress and record the AC and EV of each work package at regular intervals.
- Calculate the SV, CV, SPI, CPI, EAC, ETC and VAC using the formulas given below:

```
SV = EV - PV
CV = EV - AC
SPI = EV / PV
CPI = EV / AC
EAC = BAC / CPI
ETC = EAC - AC
VAC = BAC - EAC
```

- Analyze the results and take corrective actions if needed.
