### COSMIC Full Function Points in spm

- COSMIC stands for Common Software Measurement International Consortium, which is a group of experts who developed a functional size measurement method based on basic principles.
- COSMIC function points are a unit of measure of software functional size, which is the amount of functionality that a software system provides to its users.
- The functional size is consistent regardless of the technology used to build the software, and it can be estimated or measured based on the functional user requirements (FUR) of the software.
- The functional user requirements are the statements of what the software must do to satisfy the needs of its users, such as sending, receiving, or manipulating data.
- The process of measuring or estimating the functional size is called functional size measurement (FSM), and it involves identifying the functional processes, data movements, and data groups of the software.
- A functional process is a set of logically related and order-dependent data movements that the software executes in response to a triggering event from a functional user.
- A data movement is the movement of a single data group from or to a functional user or within the software boundary.
- A data group is a set of data attributes that are logically related from the perspective of a functional user.
- The size of a functional process is the sum of the sizes of its data movements, and the size of a data movement is one COSMIC function point (CFP).
- The size of the software is the sum of the sizes of all its functional processes, and it is expressed in CFPs.
- The functional size can be used for various purposes, such as estimating development effort, project duration, quality, test effort, scope, cost, maintenance, and replacement .
- COSMIC is an international standard for measuring software size, and it is applicable to business software, real-time software, and infrastructure software at any level of decomposition .
- COSMIC is an improvement over its predecessors, such as IFPUG and Mark II function points, as it is more consistent, accurate, and adaptable to different types of software .
