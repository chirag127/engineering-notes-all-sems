### Creation of Critical Paths in SPM

- SPM stands for Software Project Management, which is the discipline of planning, organizing, executing and controlling software projects.
- A critical path in SPM is the longest sequence of activities that must be completed on time for the project to finish by the deadline .
- The critical path method (CPM) is a technique that helps to identify the critical and non-critical activities, estimate their durations, and find the optimal schedule for the project .
- The steps to create a critical path in SPM are:

  1. Activity specification: List all the activities required to complete the project and define their dependencies, such as which activities must precede or follow others.
  2. Activity sequence establishment: Draw a network diagram that shows the logical order of the activities and their dependencies using nodes and arrows. The nodes represent the activities and the arrows represent the dependencies.
  3. Network diagram: Calculate the earliest start time (EST), earliest finish time (EFT), latest start time (LST), and latest finish time (LFT) for each activity using the forward and backward pass methods. The EST and EFT are calculated by adding the activity duration to the EST of the preceding activity or zero if there is no predecessor. The LST and LFT are calculated by subtracting the activity duration from the LFT of the succeeding activity or the project deadline if there is no successor.
  4. Estimates for each activity: Estimate the duration, cost, and resources for each activity using historical data, expert judgment, or other methods.
  5. Identification of the critical path: Identify the activities that have zero slack or float, which is the difference between the LST and EST or the LFT and EFT. These activities form the critical path, which determines the minimum time required to complete the project. Any delay in the critical path activities will delay the project completion.
  6. Critical path diagram to show project progress: Update the network diagram with the actual start and finish times of the activities and compare them with the planned times. Highlight the critical path activities and monitor their progress closely. Identify any potential risks or issues that may affect the critical path and take corrective actions if needed.
