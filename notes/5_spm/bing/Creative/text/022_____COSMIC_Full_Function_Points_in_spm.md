### COSMIC Full Function Points in SPM

- COSMIC function points are a unit of measure of software functional size  .
- Software functional size is the amount of functionality that a software provides to its users, based on the user's requirements .
- The functional size is consistent regardless of the technology used to build the software  .
- The functional size can be estimated or measured, depending on the availability of the requirements  .
- The functional size measurement (FSM) process is useful for planning and managing software projects or products, such as estimating effort, cost, duration, quality, etc  .
- The COSMIC method is a standard for FSM that is applicable to a wide range of application domains and software types .
- The COSMIC method defines four types of data movements that represent the functionality of the software: Entry, Exit, Read, and Write.
- An Entry is a data movement from the user to the software, such as inputting data or requesting a service.
- An Exit is a data movement from the software to the user, such as outputting data or providing a service.
- A Read is a data movement from persistent storage to the software, such as retrieving data from a database.
- A Write is a data movement from the software to persistent storage, such as storing data in a database.
- A COSMIC function point (CFP) is a unit that represents one data movement of any type.
- The functional size of a software is the sum of the CFPs of all the data movements that the software performs.
- The COSMIC method provides guidelines and rules for identifying, classifying, and counting the data movements of a software.
- The COSMIC method also provides a measurement model that defines the concepts and terms used in the FSM process.
