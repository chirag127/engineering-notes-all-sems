### Project Schedules in SPM

- Project schedules are the graphical or textual representation of the project activities, deliverables, and milestones along with their planned start and finish dates, durations, and resources .
- Project schedules are essential for managing the time constraint of a project and ensuring that the project objectives are met within the expected deadlines.
- Project schedules are created, managed, and monitored using a schedule management plan (SMP), which is a document that details how the scheduling methodology, tools, and processes will be applied to the project.
- The steps involved in creating a project schedule are:
  - Understand the project objectives and scope
  - Identify the project activities and dependencies
  - Estimate the activity durations and resources
  - Develop the schedule model using a scheduling method and tool
  - Analyze the schedule for feasibility, risks, and optimization
  - Communicate and update the schedule as the project progresses
- The scheduling method is the technique used to calculate the start and finish dates of the project activities based on their dependencies, durations, and resources. Some common scheduling methods are:
  - Critical path method (CPM): This method identifies the longest sequence of activities that determines the project duration and the activities that have no or little flexibility in their start and finish dates.
  - Program evaluation and review technique (PERT): This method uses three estimates (optimistic, pessimistic, and most likely) for each activity duration and calculates the expected duration and variance using a weighted average formula.
  - Critical chain method (CCM): This method accounts for the resource constraints and uncertainties in the activity durations and uses buffers to protect the project completion date from delays.
- The scheduling tool is the software or application used to create, manage, and monitor the project schedule. Some examples of scheduling tools are MS Project, OmniPlan, Merlin Project, GanttPRO, etc.
- The project schedule can be presented in different formats, such as:
  - Gantt chart: This is a graphical representation of the project activities as bars along a horizontal timeline, showing their start and finish dates, durations, dependencies, and resources.
  - Milestone chart: This is a simplified version of the Gantt chart that only shows the major deliverables and events of the project as diamonds or symbols along a timeline.
  - Network diagram: This is a graphical representation of the project activities as nodes or boxes connected by arrows, showing their dependencies, sequence, and logic.
  - Textual outline: This is a hierarchical list of the project activities and their sub-activities, showing their names, durations, and resources.
