### Cost Monitoring in spm

- Cost monitoring in software project management (spm) is the process of tracking the costs associated with a software project, like the cost of development, the cost of maintenance, and any associated expenses. This process helps project managers to track progress and make sure they stay within budget.
- Cost monitoring in spm is part of the project execution, monitoring, and control phase, which aims to assess the project status, analyze deviations, and take corrective actions if necessary.
- Cost monitoring in spm can be done using various techniques, such as:
  - Cumulative expenditure chart: This is a simple method of comparing actual and planned expenditure over time. It can also show revised estimates of cost and completion date based on the current status of the project.
  - Earned value analysis: This is a technique that allows the project manager to monitor a project in an integrated way, by assigning a value to each task or work package based on the original budget. The earned value is the value credited to the project when a task is completed. By comparing the earned value with the planned value and the actual cost, the project manager can measure the schedule performance, the cost performance, and the estimate at completion of the project .
  - Supplier performance management: This is a practice that is used to measure, analyze, and manage the performance of a supplier, such as a software vendor or a contractor. Supplier management professionals seek to cut costs, alleviate risks, and drive continuous improvement. Companies use systems to monitor supplier performance levels, such as quality, delivery, compliance, and innovation.

- Cost monitoring in spm is important because it helps to:
  - Control the project budget and avoid overspending or underspending
  - Identify and resolve any issues or risks related to the project costs
  - Evaluate the return on investment and the value delivered by the project
  - Improve the accuracy and reliability of future cost estimates
  - Enhance the communication and collaboration among the project stakeholders
  - Support the decision-making and the reporting processes

- Some mnemonics and learning tricks for cost monitoring in spm are:
  - AC: Actual Cost, the amount of money spent on the project so far
  - PV: Planned Value, the amount of money that should have been spent on the project by a certain date
  - EV: Earned Value, the amount of money that the project has earned by completing some tasks
  - SPI: Schedule Performance Index, the ratio of EV to PV, which indicates how well the project is meeting its schedule
  - CPI: Cost Performance Index, the ratio of EV to AC, which indicates how well the project is meeting its budget
  - EAC: Estimate at Completion, the projected total cost of the project at the end
  - A mnemonic to remember these acronyms is: **A**lways **P**lan **E**verything, **S**chedule **C**osts **E**fficiently
  - A formula to calculate EAC is: EAC = AC + (BAC - EV) / CPI, where BAC is the Budget at Completion, the original total budget of the project
  - A mnemonic to remember this formula is: **E**stimate **A**fter **C**osts = **A**ctual **C**ost + (**B**udget - **E**arned) / **C**ost **P**erformance
