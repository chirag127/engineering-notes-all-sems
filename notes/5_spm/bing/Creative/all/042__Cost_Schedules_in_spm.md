### Cost Schedules in spm

- Cost schedules are the tools and techniques used to estimate, budget, and control the costs of a project.
- Cost schedules are based on the work breakdown structure (WBS), which defines the scope and deliverables of the project, and the activity list, which describes the tasks and dependencies of the project.
- Cost schedules can be created using various methods, such as:
  - Analogous estimating: using historical data from similar projects to estimate the cost of the current project.
  - Parametric estimating: using statistical models or formulas to calculate the cost based on one or more variables, such as unit cost, duration, or complexity.
  - Bottom-up estimating: aggregating the cost estimates of the individual work packages or activities to get the total project cost.
  - Three-point estimating: using optimistic, pessimistic, and most likely estimates to account for the uncertainty and risk of the project cost.
  - Expert judgment: relying on the experience and knowledge of experts or stakeholders to provide the cost estimates.
- Cost schedules can be presented in various formats, such as:
  - Cost baseline: a time-phased budget that shows the planned expenditure of the project over time.
  - Cost performance baseline: a combination of the cost baseline and the scope baseline that shows the planned value (PV) of the project over time.
  - S-curve: a graphical representation of the cumulative cost of the project over time, which can be used to compare the actual cost (AC) and the earned value (EV) of the project.
  - Cost variance (CV): the difference between the EV and the AC of the project, which indicates whether the project is under budget (CV > 0) or over budget (CV < 0).
  - Cost performance index (CPI): the ratio of the EV to the AC of the project, which measures the cost efficiency of the project. A CPI of 1 means the project is on budget, a CPI greater than 1 means the project is under budget, and a CPI less than 1 means the project is over budget.
- Cost schedules can be updated and controlled using various techniques, such as:
  - Forecasting: predicting the future cost of the project based on the current performance and trends.
  - To-complete performance index (TCPI): the ratio of the remaining work to the remaining budget, which indicates the required cost performance to complete the project within the budget.
  - Variance analysis: analyzing the causes and impacts of the cost deviations from the baseline and taking corrective or preventive actions to address them.
  - Change control: managing the changes to the project scope, schedule, or cost that may affect the cost baseline or the cost performance baseline.
  - Earned value management (EVM): a methodology that integrates the scope, schedule, and cost of the project and provides a comprehensive view of the project performance and progress. EVM uses the following metrics to measure and control the project cost:
    - Planned value (PV): the authorized budget for the work scheduled to be completed by a given date.
    - Earned value (EV): the authorized budget for the work actually completed by a given date.
    - Actual cost (AC): the actual expenditure for the work completed by a given date.
    - Cost variance (CV): the difference between the EV and the AC of the project, which indicates whether the project is under budget (CV > 0) or over budget (CV < 0).
    - Cost performance index (CPI): the ratio of the EV to the AC of the project, which measures the cost efficiency of the project. A CPI of 1 means the project is on budget, a CPI greater than 1 means the project is under budget, and a CPI less than 1 means the project is over budget.
    - Schedule variance (SV): the difference between the EV and the PV of the project, which indicates whether the project is ahead of schedule (SV > 0) or behind schedule (SV < 0).
    - Schedule performance index (SPI): the ratio of the EV to the PV of the project, which measures the schedule efficiency of the project. An SPI of 1 means the project is on schedule, an SPI greater than 1 means the project is ahead of schedule, and an SPI less than 1 means the project is behind schedule.
