### Management Control in SPM

Management control in software project management (SPM) is the process of setting objectives for a software project and then monitoring the project to see what its true performance is. It involves the following steps:

- Data collection: The project manager and the team need to collect relevant data about the project progress, such as the status of tasks, deliverables, resources, costs, quality, risks, and issues. This data can be obtained from various sources, such as project management tools, reports, meetings, surveys, and feedback.
- Data processing: The collected data needs to be processed and transformed into useful information that can help the project manager and the team to understand the current situation of the project and identify any deviations from the planned objectives. This can be done by using various techniques, such as analysis, calculation, visualization, and summarization.
- Performance measurement: The processed information needs to be compared with the predefined criteria or standards that represent the desired performance of the project. These criteria can be based on the project scope, schedule, budget, quality, and stakeholder expectations. The comparison can reveal the gaps or variances between the actual and the expected performance, and indicate the level of achievement or satisfaction of the project objectives.
- Decision making: Based on the performance measurement, the project manager and the team need to decide what actions to take to improve the project performance, correct any problems, or prevent any risks. This can involve choosing among different alternatives, evaluating the consequences, and selecting the best option. The decision making can also include adjusting the project plan, scope, schedule, budget, or quality, if necessary, to align with the changing requirements or conditions.
- Implementation: The chosen actions need to be implemented and executed by the project manager and the team, following the established procedures and guidelines. The implementation can also involve communicating the changes, assigning the responsibilities, and allocating the resources.
- Review: The implemented actions need to be reviewed and evaluated by the project manager and the team, to see if they have achieved the desired results, solved the problems, or mitigated the risks. The review can also involve collecting feedback, measuring the outcomes, and documenting the lessons learned.

The management control process is iterative and continuous, as the project manager and the team need to repeat the steps regularly throughout the project lifecycle, to ensure that the project is on track and meets the expectations of the stakeholders. The management control process can also be supported by various tools and techniques, such as performance indicators, dashboards, reports, charts, graphs, and tables, that can help to visualize and communicate the project performance and status.
