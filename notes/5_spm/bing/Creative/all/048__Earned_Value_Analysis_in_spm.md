### Earned Value Analysis in spm

- Earned Value Analysis (EVA) is a project management technique that allows the project manager to measure the amount of work actually performed on a project beyond the basic review of cost and schedule reports.
- EVA provides a method that permits the project to be measured by progress achieved. The project manager is then able, using the progress measured, to forecast a project's total cost and date of completion, based on trend analysis or application of the project's "burn rate".
- EVA is based on assigning a 'value' to each task or work package (as identified in the WBS) based on the original expenditure forecasts. This value is called the Planned Value (PV) or the Budgeted Cost of Work Scheduled (BCWS).
- EVA also tracks the Actual Cost (AC) or the Actual Cost of Work Performed (ACWP), which is the actual cost incurred during the execution of work packages up to a specified point in time.
- The most important element of EVA is the Earned Value (EV) or the Budgeted Cost of Work Performed (BCWP), which is the budgeted value of the completed work packages. It is a measure of 'Progress' to assess 'Percentage of Completeness'.
- EVA uses these three elements (PV, AC, and EV) to calculate various metrics that indicate the project's health and performance. Some of the most common metrics are:
  - Cost Variance (CV) = EV - AC. It shows whether the project is under or over budget. A positive CV means the project is under budget, while a negative CV means the project is over budget.
  - Schedule Variance (SV) = EV - PV. It shows whether the project is ahead or behind schedule. A positive SV means the project is ahead of schedule, while a negative SV means the project is behind schedule.
  - Cost Performance Index (CPI) = EV / AC. It shows the efficiency of the project's cost performance. A CPI greater than 1 means the project is under budget, while a CPI less than 1 means the project is over budget.
  - Schedule Performance Index (SPI) = EV / PV. It shows the efficiency of the project's schedule performance. A SPI greater than 1 means the project is ahead of schedule, while a SPI less than 1 means the project is behind schedule.
  - Estimate at Completion (EAC) = BAC / CPI. It shows the projected total cost of the project at completion, based on the current cost performance. BAC is the Budget at Completion, which is the total planned value of the project.
  - Estimate to Complete (ETC) = EAC - AC. It shows the projected remaining cost of the project to complete, based on the current cost performance.
  - Variance at Completion (VAC) = BAC - EAC. It shows the projected difference between the planned and the actual total cost of the project at completion, based on the current cost performance.
  - To Complete Performance Index (TCPI) = (BAC - EV) / (BAC - AC). It shows the required cost performance for the remaining work to meet the original budget, based on the current cost performance.

- EVA provides an objective and integrated view of the project by measuring planned effort (costs), actual progress (earned value), and effort (actual costs) in terms of monetary values. Measuring plan, work, and progress with the same unit makes them comparable.
- EVA provides different measures of progress for different types of tasks. It is the single way for measuring everything in a project. It provides an 'Early Warning' signal for prompt corrective action. It allows 'rolling up' the progress of many tasks into an overall project status. It provides with a uniform unit of measure (dollars or work-hours) for the progress.
- EVA is a quantitative technique for assessing progress as the software project team moves through the work tasks, allocated to the Project Schedule. EVA provides a common value scale for every project task. Total hours to complete the project are estimated and every task is given an Earned Value, based on its estimated (%) of the total.
- EVA is one of the most appreciated and well-known project management tools. It is a project management technique that allows to measure performance and progress. It combines the measures of the project management triangle: scope, time and costs.
