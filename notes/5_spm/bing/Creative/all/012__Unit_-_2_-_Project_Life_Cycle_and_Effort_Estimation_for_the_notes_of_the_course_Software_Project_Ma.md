## Unit - 2 - Project Life Cycle and Effort Estimation for the notes of the course Software Project Management

- Project life cycle is a step-by-step framework of best practices used to shepherd a project from its beginning to its end.
- It provides project managers a structured way to create, execute, and finish a project.
- It generally includes four phases: initiating, planning, executing, and closing. Some may also include a fifth “monitoring and controlling” phase between the executing and closing stages.
- By following each step, a project team increases the chance of achieving its goals.
- The project life cycle provides projects with structure and tools to ensure they have the best chance of being successful.

### Initiating Phase

- In the initiation phase, the project is defined and its goals, scope, and resources are determined.
- The purpose and desired outcomes of the project are communicated with the stakeholders.
- The roles and responsibilities of the project team are clarified and the project charter is created.
- Some steps in the initiation phase include:
  - Communicating with stakeholders to understand the purpose and desired outcomes of the project
  - Identifying project scope
  - Determining SMART goals (specific, measurable, achievable, relevant, and time-bound)
  - Clarifying resources like budget and time constraints
  - Confirming team size and roles required
  - Determining how often and which stakeholders will be involved throughout the project
  - Compiling a project proposal and project charter
- Tools and documents used in the initiation phase can include:
  - Project proposal: The project proposal defines a project and outlines key dates, requirements, and goals.
  - Project charter: This is a definitive document that describes the project and main details necessary to reach its goals. This can include potential risks, benefits, constraints, and key stakeholders.
  - RACI chart: A RACI chart plots the roles and responsibilities of members on a project team.

### Planning Phase

- In the planning phase, the project plan is developed and the details of how the project will be executed are determined.
- The project plan is a comprehensive document that guides the project team and stakeholders throughout the project.
- It includes the scope, schedule, budget, quality, risk, communication, and procurement plans.
- Some steps in the planning phase include:
  - Breaking down the project scope into smaller and manageable tasks
  - Sequencing the tasks and creating a work breakdown structure (WBS)
  - Estimating the duration, cost, and resources for each task
  - Developing a project schedule and a Gantt chart
  - Setting the project baseline and milestones
  - Identifying and analyzing the project risks and creating a risk management plan
  - Defining the quality standards and criteria for the project deliverables and creating a quality management plan
  - Establishing the communication methods and frequency and creating a communication management plan
  - Determining the procurement needs and creating a procurement management plan
- Tools and documents used in the planning phase can include:
  - Work breakdown structure (WBS): A WBS is a hierarchical decomposition of the project scope into smaller and manageable deliverables.
  - Gantt chart: A Gantt chart is a graphical representation of the project schedule that shows the start and end dates of each task and their dependencies.
  - Project baseline: A project baseline is a snapshot of the project plan at a given point in time that serves as a reference for measuring the project performance and progress.
  - Risk register: A risk register is a document that records the identified risks, their probability and impact, and their response strategies.
  - Quality checklist: A quality checklist is a tool that lists the quality criteria and standards for each deliverable and helps to ensure that they are met.

### Executing Phase

- In the executing phase, the project plan is put into action and the project deliverables are produced.
- The project team performs the tasks according to the schedule, budget, and quality plans.
- The project manager leads and directs the team, communicates with the stakeholders, and monitors and controls the project performance.
- Some steps in the executing phase include:
  - Allocating and managing the project resources
  - Performing the project tasks and producing the deliverables
  - Tracking and reporting the project progress and performance
  - Managing the project changes and issues
  - Implementing the quality assurance and control processes
