The Dynamic System Development Method (DSDM) is an agile project delivery framework that was initially used for software development but can be applied to any project. It is based on eight principles that guide the project team throughout the project lifecycle. The principles are:

- Focus on the business need
- Deliver on time
- Collaborate
- Never compromise quality
- Build incrementally from firm foundations
- Develop iteratively
- Communicate continuously and clearly
- Demonstrate control

The DSDM framework consists of five phases: Feasibility, Foundations, Evolutionary Development, Deployment, and Post-Project. Each phase has specific objectives, activities, and deliverables. The following diagram illustrates the basic architecture of the DSDM framework:

```
|                 |   |                 |   |                 |   |                 |   |                 |
|   Feasibility   +--->   Foundations   +--->Evolutionary Dev.+--->   Deployment   +--->  Post-Project  |
|                 |   |                 |   |                 |   |                 |   |                 |
+-----------------+   +-----------------+   +-----------------+   +-----------------+   +-----------------+
```

The Feasibility phase is where the project team assesses the viability and suitability of the project idea and decides whether to proceed or not. The main deliverables of this phase are a feasibility report and an outline plan.

The Foundations phase is where the project team establishes the scope, objectives, and requirements of the project and agrees on the solution architecture and the project approach. The main deliverables of this phase are a prioritized requirements list, a solution architecture definition, a development approach definition, and a delivery plan.

The Evolutionary Development phase is where the project team builds and tests the solution incrementally and iteratively, based on the prioritized requirements and the feedback from the users and stakeholders. The main deliverables of this phase are a tested solution increment and a timebox review record.

The Deployment phase is where the project team delivers the solution to the users and stakeholders and ensures that it meets their expectations and needs. The main deliverables of this phase are a deployed solution, a benefits assessment, and a project review report.

The Post-Project phase is where the project team evaluates the project outcomes and lessons learned and identifies any follow-up actions or maintenance activities. The main deliverables of this phase are a benefits realization plan, a project closure report, and a maintenance plan.
