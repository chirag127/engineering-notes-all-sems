The diagram shows the main steps involved in the project management and control cycle, which are:

- Start Project Control Cycle: This is the initial stage where the project is defined and planned.
- Publish Initial Plan: This is where the project plan is communicated to the stakeholders and the team members.
- Gather Project Information: This is where the project progress is monitored and measured by collecting data from various sources.
- Compare Progress vs Targets: This is where the project performance is evaluated by comparing the actual results with the planned objectives and milestones.
- Take Remedial Action: This is where the project deviations are corrected by implementing corrective and preventive actions.
- Publish Revised Plan: This is where the project plan is updated and revised based on the changes and feedback.
- Review Project: This is where the project is reviewed and assessed by the project manager and the stakeholders.
- Document Conclusions: This is where the project outcomes and lessons learned are documented and reported.
- Satisfactory?: This is where the project quality and satisfaction are checked and verified.
- Project Completed?: This is where the project completion and closure are confirmed and celebrated.
- End Project Control Cycle: This is where the project control cycle is terminated and the project is handed over to the customer or the maintenance team.
