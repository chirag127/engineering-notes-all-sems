Effort and cost estimation techniques in software project management (SPM) are methods and tools that help to estimate the size, effort, and cost of a software project. They are important for planning, budgeting, and controlling a software project. There are different types of estimation techniques, such as algorithmic, non-algorithmic, and hybrid methods.

The following diagram illustrates the basic steps of estimation techniques in SPM :

```
+---------------------+      +---------------------+      +---------------------+
|                     |      |                     |      |                     |
|  Scope definition   |----->|  Size estimation    |----->|  Effort estimation  |
|                     |      |                     |      |                     |
+---------------------+      +---------------------+      +---------------------+
                                                                    |
                                                                    |
                                                                    V
                                                          +---------------------+
                                                          |                     |
                                                          |  Cost estimation    |
                                                          |                     |
                                                          +---------------------+
```

Scope definition is the process of identifying the software requirements, objectives, and boundaries of the project. Size estimation is the process of measuring the amount of work or functionality of the software. Effort estimation is the process of predicting the amount of human resources and time needed to complete the project. Cost estimation is the process of calculating the total expenses of the project, including labor, materials, equipment, and overheads.

Different estimation techniques may use different units, methods, and models to perform these steps. For example, some size estimation techniques may use lines of code, function points, or use cases as units of measurement. Some effort estimation techniques may use expert judgment, analogy, or parametric models as methods of prediction. Some cost estimation techniques may use bottom-up, top-down, or phase-wise approaches as models of calculation.
