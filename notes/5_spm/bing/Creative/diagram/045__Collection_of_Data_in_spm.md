Collection of Data in SPM is the process of gathering information about the progress, quality, and performance of a software project. There are different methods of collecting data in SPM, such as interviews, surveys, focus groups, secondary data analysis, and reviews. Each method has its own advantages and disadvantages, depending on the type of data needed, the availability of resources, and the project context.

The above diagram illustrates the basic architecture of data collection in SPM. The data collection methods are grouped into primary and secondary sources. Primary data are collected directly from the project stakeholders, such as customers, developers, testers, and managers. Secondary data are obtained from existing sources, such as databases, documents, or logs. The data collected are then processed and analysed to generate project data, metrics, and reports. These outputs can help the project manager to monitor, control, and improve the project.
