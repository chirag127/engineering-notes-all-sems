Motivation in SPM is the process of influencing the behavior of people involved in software projects to achieve the desired outcomes. Motivation can be affected by various factors, such as the rewards, the expectations, the values, and the needs of the individuals and the teams.

One possible way to draw a detailed ASCII diagram for motivation in SPM is:

```
+-----------------+     +-----------------+     +-----------------+
|                 |     |                 |     |                 |
|  Expectancy     |---->|  Instrumentality|---->|  Perceived value|
|                 |     |                 |     |                 |
+-----------------+     +-----------------+     +-----------------+
       |                       |                       |
       |                       |                       |
       V                       V                       V
+-----------------+     +-----------------+     +-----------------+
|                 |     |                 |     |                 |
|  Effort         |---->|  Performance    |---->|  Reward         |
|                 |     |                 |     |                 |
+-----------------+     +-----------------+     +-----------------+
       |                       |                       |
       |                       |                       |
       V                       V                       V
+-----------------+     +-----------------+     +-----------------+
|                 |     |                 |     |                 |
|  Basic needs    |---->|  Higher needs   |---->|  Self-actualization
|                 |     |                 |     |                 |
+-----------------+     +-----------------+     +-----------------+
```

The diagram illustrates the basic architecture of a model of motivation developed by Vroom and his colleagues. It identifies three influences on motivation:

- Expectancy, the belief that working harder will lead to a better performance;
- Instrumentality, the belief that better performance will be rewarded;
- Perceived value, of the resulting reward.

These influences affect the effort, performance, and reward of the individuals and teams involved in software projects. The reward can also satisfy different levels of needs, according to Maslow's hierarchy of needs. The lowest level is the basic needs, such as food and shelter. The highest level is the self-actualization, the feeling that one is completely fulfilling one's potential.
