Project Tracking in spm is the process of monitoring and controlling the progress, quality, and costs of software projects. It involves planning, executing, and reporting on the activities and deliverables of the project, as well as managing risks, issues, and changes. Project Tracking in spm can be done using various tools and techniques, such as dashboards, reports, metrics, KPIs, roadmaps, and workbenches.

The Project Manager creates and updates the Project Plan, which defines the scope, schedule, budget, quality, and resources of the project. The Project Tracker collects and analyzes the Project Data, which includes the status, progress, issues, risks, and changes of the project. The Project Tracker generates and communicates the Project Report, which summarizes the performance, outcomes, and recommendations of the project. The Project Stakeholder reviews and approves the Project Report, and provides feedback and guidance to the Project Manager.
