### COSMIC Full Function Points in spm

- COSMIC stands for Common Software Measurement International Consortium  .
- COSMIC function points are a unit of measure of software functional size   .
- The functional size is consistent regardless of the technology used to build the software .
- The functional size can be estimated or measured based on the software requirements .
- The functional size measurement (FSM) process is very useful for planning and managing software projects or products  .
- The COSMIC method defines four types of data movements: Entry, Exit, Read, and Write.
- Each data movement represents a movement of data from or to a functional process, which is a part of the software that responds to an event.
- A COSMIC function point (CFP) is a measure of one data movement of one data group.
- A data group is a set of data attributes that are logically related and that are manipulated together by the software.
- The COSMIC method provides a set of rules and guidelines for identifying and counting the data movements and data groups of a software.
- The COSMIC method can be applied to any type of software, from the smallest to the largest, and from any application domain.
- The COSMIC method has been empirically validated and shown to correlate well with effort and other software metrics.
