## Unit - 1 - Project Evaluation and Project Planning

This unit covers the following topics:

- Project evaluation: The process of assessing the feasibility, benefits, risks, and costs of a proposed software project.
- Project planning: The process of defining the scope, objectives, deliverables, schedule, resources, and quality standards of a software project.
- Project evaluation methods: The techniques used to evaluate the feasibility and benefits of a software project, such as payback period, net present value, internal rate of return, benefit-cost ratio, and risk analysis.
- Project planning methods: The techniques used to plan the scope, objectives, deliverables, schedule, resources, and quality standards of a software project, such as work breakdown structure, Gantt chart, network diagram, critical path method, resource allocation, and quality management.

Some key points to remember are:

- Project evaluation and planning are essential steps in software project management, as they help to ensure that the project is aligned with the organizational goals, meets the stakeholder expectations, and can be completed within the budget and time constraints.
- Project evaluation and planning are iterative and dynamic processes, as they need to be updated and revised throughout the project life cycle, based on the feedback, changes, and uncertainties that may arise.
- Project evaluation and planning require the involvement and communication of all the project stakeholders, such as the project sponsor, the project manager, the project team, the customers, the users, and the suppliers.
- Project evaluation and planning are based on the application of various methods and tools, which can help to analyze, estimate, and document the project requirements, assumptions, constraints, risks, and dependencies.
