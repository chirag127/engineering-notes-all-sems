
### Effect of Resource Contention and Resource Access Control (RAC) for the notes of the Unit 3 - Resources Sharing in the subject of Real Time System

Resource contention is a problem that can occur in real-time systems when multiple tasks attempt to access the same resource or set of resources at the same time. This can lead to conflicts that can cause the system to fail to meet its deadlines or to not perform as expected. Resource Access Control (RAC) is a mechanism used to manage access to resources in real-time systems. It is used to ensure that the resources are used in an orderly and efficient manner and that conflicts are avoided.

RAC can be used to manage both static and dynamic resources. Static resources are resources that are allocated to tasks at the beginning of the system's execution and remain allocated until the system terminates. Dynamic resources are resources that are allocated and deallocated during the system's execution.

RAC can be implemented in a variety of ways depending on the type of resource being managed. For example, for static resources, RAC can be implemented using priority-based scheduling algorithms. In this case, tasks are assigned a priority and the higher priority tasks are allowed to access the resources first. For dynamic resources, RAC can be implemented using a variety of algorithms such as the Earliest Deadline First (EDF) algorithm and the Rate Monotonic (RM) algorithm.

The main advantage of using RAC is that it can help to ensure that the system meets its deadlines by avoiding resource contention. It can also help to ensure that resources are used efficiently and that tasks are scheduled in an orderly manner. The main disadvantage of using RAC is that it can be difficult to implement and can be computationally expensive.

In conclusion, RAC is an important mechanism for managing access to resources in real-time systems. It can help to ensure that the system meets its deadlines by avoiding resource contention and can help to ensure that resources are used efficiently. However, it can be difficult to implement and can be computationally expensive.
