
### Timing Constraints for the notes of the Unit 1 - Introduction of Real Time System in the subject of Real Time System 

* **Real-Time Systems** are computer systems that must respond to events within a specified period of time. The timing constraints of such systems are critical for successful operation. 
* **Timing constraints** refer to the restrictions placed on the time it takes for a system to respond to an event or process. These constraints can be divided into two categories: **hard** and **soft** constraints. 
* **Hard constraints** are those that must be met in order for the system to function correctly. These constraints are typically set by the system designer and are not adjustable. 
* **Soft constraints** are those that can be adjusted or changed depending on the system requirements. These constraints are typically set by the user or system administrator. 
* **Deadlines** are the time limits placed on the completion of a task. If a deadline is not met, the system may suffer from serious consequences. 
* **Response time** is the time it takes for the system to respond to an event or process. This is typically measured in milliseconds or microseconds. 
* **Priority** is the order in which tasks are completed. Higher priority tasks are completed first, while lower priority tasks are completed last. 
* **Scheduling** is the process of assigning tasks to system resources in order to meet the timing constraints of the system. Scheduling algorithms are used to determine the order of tasks and the resources that should be used to complete them. 
* **Preemption** is the process of interrupting a task in order to start a higher priority task. This is typically used to ensure that timing constraints are met. 
* **Time slicing** is the process of dividing a task into smaller sections in order to meet timing constraints. This is typically used when a task is too complex to complete in one go. 
* **Time jitter** is the variation in the response time of a system. This is typically caused by external factors such as network latency or processor load. 
* **Real-Time Operating Systems (RTOS)** are operating systems designed to meet the timing constraints of a real-time system. These operating systems typically use scheduling algorithms and time slicing techniques to ensure that tasks are completed on time.
