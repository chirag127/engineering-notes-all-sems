
### Reference Models for Real Time Systems 

Real Time Systems (RTS) are computer systems that have a set of constraints that must be met in order for the system to function correctly. These constraints include timing, performance, reliability, and safety. Reference models are used to describe the architecture of a RTS, and provide a basis for the development of a real-time system. 

The most commonly used reference model for real-time systems is the four-layer model. This model consists of four layers: Application, Platform, Hardware and Operating System. 

**Application Layer**: The application layer is the topmost layer of the reference model. It is responsible for the implementation of the user’s requirements and consists of the user interface, the business logic and the data structures. 

**Platform Layer**: The platform layer is the middle layer of the reference model. It is responsible for providing the necessary services and components for the application layer to function. This includes services such as communication, synchronization, scheduling, and memory management. 

**Hardware Layer**: The hardware layer is the bottom layer of the reference model. It is responsible for providing the necessary hardware components for the platform layer to function. This includes components such as processors, memory, and peripherals. 

**Operating System Layer**: The operating system layer is the layer that provides the necessary services for the hardware layer to function. This includes services such as device drivers, memory management, and process scheduling. 

Reference models for real-time systems provide a basis for the development of a real-time system. They provide a structured approach to the development of a system, and help to ensure that the system meets its requirements. In addition, reference models can be used to evaluate the performance of a system, and can be used to compare different systems.
