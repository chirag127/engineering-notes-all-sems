
### Definition for the notes of the Unit 1 - Introduction of Real Time System in the subject of Real Time System
A real-time system is a system that responds to external events or stimuli within a specified time period. It is designed to process data as it is received and respond to it in a timely manner. Real-time systems are used in a variety of applications, such as industrial automation, robotics, medical systems, and avionics.

Real-time systems are characterized by the following characteristics:

* Timeliness: The system must respond to external events within a specified time period.
* Predictability: The system must be able to predict the time it will take to process data and respond to it.
* Reliability: The system must be able to maintain its performance in spite of external events or stimuli.
* Flexibility: The system must be able to adapt to changing external events or stimuli.
* Scalability: The system must be able to handle increasing amounts of data and respond to it in a timely manner.

Real-time systems can be divided into two categories: hard real-time systems and soft real-time systems. Hard real-time systems are those that must meet their deadlines with 100% accuracy. Examples of hard real-time systems include industrial automation systems, robotics, and avionics. Soft real-time systems are those that can tolerate some degree of latency. Examples of soft real-time systems include multimedia applications and computer games.
