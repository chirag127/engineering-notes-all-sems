
### Statements That Alter the Flow of Control for the Notes of the Unit 3 - Syntax-directed Translation in the Subject of Compiler Design

- Syntax-directed translation is a process used by compilers to convert a source language into a target language. It involves the use of a set of rules that define the structure of the source language and the operations that must be performed on it to produce the target language. 
- The rules are written in a syntax-directed language, which is a formal language that can be used to describe the syntax of a source language. 
- These rules are then used by the compiler to generate the target language. 
- Statements that alter the flow of control are an important part of the syntax-directed translation process. They allow the compiler to control the flow of the translation process and determine which parts of the source language should be translated into the target language. 
- For example, a compiler may use a 'if-then-else' statement to determine which parts of the source language should be translated into the target language. 
- Another example is the 'switch' statement which is used to select a particular branch of code that should be executed depending on the value of a given variable. 
- Finally, the 'goto' statement is used to jump to a specific line of code in the source language. 
- These statements are essential for the compiler to properly translate the source language into the target language. 
- They are also useful for debugging and optimizing the code since they allow the programmer to easily control the flow of the translation process.
