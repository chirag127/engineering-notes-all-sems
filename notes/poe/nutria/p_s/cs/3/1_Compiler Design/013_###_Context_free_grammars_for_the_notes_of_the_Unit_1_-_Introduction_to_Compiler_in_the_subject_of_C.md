
## Unit 2 - Basic Parsing Techniques

Parsing is the process of analyzing a string of symbols, either in natural language or in computer languages, according to the rules of a formal grammar. It involves resolving a string into its component parts and describing their syntactic roles. Basic parsing techniques are used to build compilers, interpreters, and other language processing tools.

### Syntax

Syntax is the set of rules that govern the structure of a language. It defines the way words and phrases are combined to form sentences, and the order in which they must appear. Syntax is the basis of all language processing, and is essential for understanding how a language works.

### Lexical Analysis

Lexical analysis is the process of breaking down a string of symbols into its component parts, or tokens. It involves recognizing words, numbers, and other symbols that make up a language. Lexical analysis is the first step in parsing a string of symbols.

### Context-Free Grammars

Context-free grammars (CFGs) are a type of formal grammar used to describe the structure of a language. A CFG consists of a set of rules that define how symbols can be combined to form valid sentences. CFGs are used to generate parsers for languages, and are the basis for most language processing tools.

### Top-Down Parsing

Top-down parsing is a type of parsing algorithm that starts at the root node of a parse tree and works its way down to the leaves. It is a recursive process, in which each node is expanded into its component parts until a complete parse tree is constructed. Top-down parsing algorithms are used to build parsers for languages.

### Bottom-Up Parsing

Bottom-up parsing is a type of parsing algorithm that starts at the leaves of a parse tree and works its way up to the root node. It is a recursive process, in which each node is reduced to its component parts until a complete parse tree is constructed. Bottom-up parsing algorithms are used to build parsers for languages.

### Ambiguity

Ambiguity is a common problem in language processing. It occurs when a string of symbols can be interpreted in multiple ways. Ambiguity can be resolved by using context-free grammars or other techniques to determine the correct interpretation.
