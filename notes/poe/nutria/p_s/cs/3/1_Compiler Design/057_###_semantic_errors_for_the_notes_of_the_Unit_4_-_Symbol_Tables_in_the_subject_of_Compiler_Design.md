

### Semantic Errors for the Notes of the Unit 4 - Symbol Tables in the Subject of Compiler Design

* Semantic errors are errors that occur when the meaning of the code is not what the programmer intended. 
* These errors are difficult to detect because the code is syntactically correct.
* They often occur when the programmer has misunderstood the language syntax or when the logic of the code is incorrect.
* Symbol tables are used to store information about the symbols used in a program. 
* A symbol table is a data structure that stores information about identifiers used in a program. 
* Symbol tables are used by compilers to keep track of the names and types of identifiers used in the program.
* Semantic errors can occur when incorrect information is stored in the symbol table. 
* For example, if a variable is declared with the wrong type, the compiler may store the wrong type in the symbol table. 
* This can lead to incorrect type checking or incorrect code generation.
* Another type of semantic error can occur when an identifier is used in the wrong context. 
* For example, if a variable is used in a context where it is not defined, the compiler may generate incorrect code. 
* This type of error can also be difficult to detect because the code may appear to be syntactically correct.
* Finally, semantic errors can occur when an identifier is used in the wrong scope. 
* If an identifier is used in a scope where it is not defined, the compiler may generate incorrect code. 
* This type of error can also be difficult to detect because the code may appear to be syntactically correct.
