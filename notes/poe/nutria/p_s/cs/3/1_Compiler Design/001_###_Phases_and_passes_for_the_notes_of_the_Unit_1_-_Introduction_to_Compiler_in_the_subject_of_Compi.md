
### Phases and Passes for the Notes of the Unit 1 - Introduction to Compiler in the Subject of Compiler Design

* A compiler is a computer program that translates a source code written in a high-level language into a low-level language, such as assembly or machine code. Compilers are divided into several phases, which are broken down into passes.

* The first phase of a compiler is the lexical analysis phase, also known as the scanning phase. In this phase, the source code is broken down into tokens. A token is a sequence of characters that has a meaning.

* The next phase is the syntax analysis phase, also known as the parsing phase. In this phase, the tokens from the lexical analysis phase are used to construct a parse tree. The parse tree is a representation of the source code in a hierarchical structure.

* The third phase is the semantic analysis phase. In this phase, the parse tree is used to check for semantic errors, such as type errors.

* The fourth phase is the code generation phase. In this phase, the parse tree is used to generate the target code.

* The last phase is the optimization phase. In this phase, the target code is optimized to make it more efficient.

* The passes of a compiler are the steps that are taken in each phase. For example, in the lexical analysis phase, the first pass is the tokenization pass. In this pass, the source code is broken down into tokens. The second pass is the lexical analysis pass. In this pass, the tokens are used to construct a symbol table. The symbol table is a data structure that stores information about the tokens.

* After the passes of each phase are completed, the compiler is ready to generate the target code.
