
### The Target Language for the Notes of the Unit 5 - Code Generation in the Subject of Compiler Design

* Code generation is the process of translating a program written in a high-level language into a machine language that can be read and executed by a computer.
* A compiler uses code generation to translate the source code of a program into a machine language that can be executed by the computer.
* The target language of a compiler is the machine language that the compiler will generate.
* Code generation is an important part of compiler design, as it is responsible for the actual execution of the program.
* Code generation involves several steps, including lexical analysis, syntax analysis, semantic analysis, and code optimization.
* Code optimization is the process of transforming the generated code into an efficient form that can be executed quickly and efficiently.
* Code optimization techniques include common subexpression elimination, loop unrolling, and loop invariant code motion.
* Code generation also involves the generation of data structures, such as symbol tables, which are used by the compiler to store information about the program being compiled.
* Code generation also involves the generation of assembly language code, which is the machine language that the computer processor can execute directly.
* The generated code must be in the correct format and must adhere to the target machine's instruction set.
* Finally, the generated code must be linked and loaded into the target machine's memory so that it can be executed.
