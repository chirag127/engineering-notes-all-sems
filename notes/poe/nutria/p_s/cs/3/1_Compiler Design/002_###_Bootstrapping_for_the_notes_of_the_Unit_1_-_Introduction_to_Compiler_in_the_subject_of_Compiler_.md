
### Bootstrapping for the Notes of Unit 1 - Introduction to Compiler in Compiler Design

Bootstrapping is the process of creating a self-hosting compiler. It is a process that involves writing a compiler in the language that it will compile. This process is used to create the first compiler for a language, or to create a new version of the compiler.

**Advantages of Bootstrapping**

- It is a cost-effective approach to creating a compiler as it does not require any external tools or libraries. 
- It allows for the compiler to be tested and debugged on its own code. 
- It ensures that the compiler is well-suited to the language it is intended to compile. 

**Disadvantages of Bootstrapping**

- It is a time-consuming process, as the compiler needs to be written and debugged before it can be used. 
- It is difficult to debug, as any errors in the compiler will cause the compiler to fail. 
- It is difficult to maintain, as any changes to the language will require changes to the compiler. 

**Examples of Bootstrapping**

- The C language was bootstrapped by its creator, Dennis Ritchie. 
- The Swift language was bootstrapped by its creators, Chris Lattner and Apple. 
- The Rust language was bootstrapped by its creator, Graydon Hoare. 

**Applications of Bootstrapping**

- Bootstrapping is used to create compilers for new programming languages. 
- It is also used to create new versions of existing compilers. 
- It is also used to create interpreters and other language-processing tools.
