

### Error Detection & Recovery for the notes of the Unit 4 - Symbol Tables in the subject of Compiler Design

Error detection and recovery is an important part of the compilation process. Compilers must detect and recover from errors in the source code in order to generate an executable program. Error detection and recovery is divided into two phases:

1. **Error Detection:** This phase involves the compiler scanning the source code and detecting any syntax or semantic errors. The compiler will then report these errors to the user, along with information about where the error occurred and what caused it.

2. **Error Recovery:** This phase involves the compiler attempting to recover from the errors detected in the previous phase. The compiler will attempt to repair the errors by making assumptions about what the programmer intended.

Error detection and recovery is a complex process and can be divided into several sub-tasks. These include:

- **Lexical Analysis:** This involves the compiler scanning the source code and breaking it into tokens. The tokens are then checked against the language's grammar rules to ensure that the source code is valid.

- **Syntax Analysis:** This involves the compiler constructing a parse tree from the tokens generated by the lexical analysis. The parse tree is then checked against the language's grammar rules to ensure that the source code is valid.

- **Semantic Analysis:** This involves the compiler checking the parse tree to ensure that the source code is semantically valid. This includes checking for type errors, undeclared variables, and other semantic issues.

- **Error Reporting:** This involves the compiler reporting any errors that it finds to the user. The compiler will provide information about where the error occurred, what caused it, and possible solutions.

- **Error Recovery:** This involves the compiler attempting to recover from the errors that it has found. The compiler will attempt to repair the errors by making assumptions about what the programmer intended.

Error detection and recovery is an important part of the compilation process. By detecting and recovering from errors, the compiler can generate an executable program from source code that may have errors.
