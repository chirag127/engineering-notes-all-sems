
### Run-Time Administration for the notes of the Unit 4 - Symbol Tables in the subject of Compiler Design

- Run-time administration is a process in which the compiler manages the memory and other resources during the execution of a program.
- Symbol tables are data structures used to store information about the symbols used in a program. They are used by the compiler to keep track of the names, types, and values of variables, constants, and other symbols used in the program.
- The run-time administration of symbol tables involves allocating memory for the symbol table and managing the entries in the symbol table. 
- The entries in the symbol table are organized in a hierarchical structure, which is used to store the information about the symbols used in the program. 
- The entries in the symbol table are divided into two types: global entries and local entries. Global entries are those that are visible to the entire program, while local entries are those that are visible only to the current scope. 
- The run-time administration of symbol tables also includes managing the scope of the symbols. The scope of a symbol is the region of the program in which the symbol is visible. 
- The symbol tables are also used to store information about the types of the variables used in the program. This information is used by the compiler to check the types of the variables used in the program. 
- The run-time administration of symbol tables also includes managing the memory allocated for the symbol table. This includes allocating and deallocating memory for the symbol table entries. 
- Finally, the run-time administration of symbol tables also includes managing the data stored in the symbol table. This includes updating the values of the symbols and managing the references to the symbols.
