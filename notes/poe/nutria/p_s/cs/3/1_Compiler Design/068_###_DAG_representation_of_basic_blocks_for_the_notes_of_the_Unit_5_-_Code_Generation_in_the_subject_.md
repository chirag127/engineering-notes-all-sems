
### DAG Representation of Basic Blocks for the Notes of Unit 5 - Code Generation in Compiler Design

* DAG stands for Directed Acyclic Graph, which is a data structure used to represent the flow of instructions in a program. 
* DAGs are used to represent basic blocks in a program, which are sequences of instructions that are executed in order without any branches or jumps. 
* A DAG is composed of nodes and edges, where a node represents an instruction and an edge represents the flow of control from one instruction to the next. 
* DAGs can be used to represent the control flow of a program, as well as its data flow. 
* DAGs are used to improve the efficiency of code generation by reducing the number of instructions that need to be generated. 
* DAGs can also be used to detect and remove redundant instructions, which can further improve the efficiency of code generation. 
* DAGs can also be used to detect and eliminate common subexpressions, which can also improve the efficiency of code generation. 
* DAGs can also be used to detect and eliminate dead code, which can also improve the efficiency of code generation. 
* DAGs can also be used to detect and eliminate unreachable code, which can also improve the efficiency of code generation. 
* DAGs can also be used to detect and eliminate redundant branches, which can also improve the efficiency of code generation. 
* DAGs can also be used to detect and eliminate redundant jumps, which can also improve the efficiency of code generation.
