
### Storage Allocation in Block Structured Language for the Notes of Unit 4 - Symbol Tables in the Subject of Compiler Design

Storage allocation is an important concept to understand when studying the subject of compiler design. Symbol tables are used to store information about the symbols that are used in the source code of a program. This information can include the type of the symbol, its scope, and other related information.

In block structured languages, such as C and Java, symbol tables are used to store information about each block, including the variables that are declared within the block. This information is used by the compiler to determine the type and scope of each variable, as well as to generate code for the block.

When a program is compiled, the compiler will allocate memory for each block in the program. This memory is used to store the symbol table information. The size of the memory allocated for each block is determined by the number of symbols that are declared within the block.

The memory allocated for symbol tables is divided into two parts: static and dynamic. Static memory is allocated when the program is compiled, and it is not modified during the execution of the program. Dynamic memory is allocated at runtime, and it can be modified during the execution of the program.

The symbol table information is stored in the static memory. The dynamic memory is used to store the values of the variables that are declared in the block. This allows the compiler to access the values of the variables during the execution of the program.

In addition to storing the symbol table information, the static memory can also be used to store code for the block. This code is generated by the compiler and is used to execute the instructions within the block.

To summarize, storage allocation in block structured languages is used to store the symbol table information and generated code for each block in the program. This information is used by the compiler to generate the code for the program, and it is also used by the runtime system to store the values of the variables.
