
### Deep Learning for the Notes of the Unit 4 - Artificial Neural Networks in the Subject of Machine Learning Techniques

Deep Learning (DL) is a type of machine learning that uses artificial neural networks to learn from data. DL is used to solve complex problems in areas such as computer vision, natural language processing, and robotics.

DL algorithms use layers of interconnected nodes to process data. Each layer of nodes is called a “layer” and is made up of neurons. A neuron is a mathematical function that takes input data and produces output data. Neurons are connected to each other in a network and the connections between them are called “weights”. The weights determine how the neurons interact with each other and how they transmit information.

DL algorithms use a combination of supervised and unsupervised learning. Supervised learning involves using labeled data to train the network, while unsupervised learning involves using unlabeled data to train the network.

The most commonly used DL algorithms are Convolutional Neural Networks (CNNs) and Recurrent Neural Networks (RNNs). CNNs are used for image recognition tasks, while RNNs are used for natural language processing tasks.

Advantages of DL include:

- Ability to learn from large datasets
- Ability to recognize patterns in data
- Ability to classify data
- Ability to identify anomalies and outliers

Disadvantages of DL include:

- Computationally expensive
- Difficult to interpret
- Prone to overfitting
- Prone to bias

Applications of DL include:

- Autonomous vehicles
- Image recognition
- Natural language processing
- Computer vision
- Speech recognition
- Robotics
- Recommender systems
