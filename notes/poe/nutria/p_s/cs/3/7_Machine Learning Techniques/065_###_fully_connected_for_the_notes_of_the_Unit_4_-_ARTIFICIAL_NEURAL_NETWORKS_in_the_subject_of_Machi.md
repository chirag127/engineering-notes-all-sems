
### Fully Connected for the Notes of the Unit 4 - Artificial Neural Networks in the Subject of Machine Learning Techniques

* Fully connected neural networks (FCNNs) are a type of artificial neural network in which all the nodes in a layer are connected to all the nodes in the previous and next layer. 
* FCNNs are composed of an input layer, one or more hidden layers, and an output layer. 
* The input layer receives input data, which is then passed to the hidden layers. Each hidden layer processes the data and passes it to the next layer until the output layer is reached. 
* The output layer produces the output of the neural network, which can be used for predictions, classification, and other tasks.
* FCNNs can be used for a variety of tasks, including image recognition, natural language processing, and time series forecasting. 
* FCNNs are trained using backpropagation, which is a supervised learning algorithm that adjusts the weights of the network based on the error in the output. 
* FCNNs are powerful and can be used to solve complex problems. However, they can be computationally expensive and require a large amount of data to train. 
* FCNNs are widely used in many applications such as computer vision, natural language processing, and robotics.
