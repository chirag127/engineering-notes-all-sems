
### Issues in SVM for the notes of the Unit 2 - REGRESSION in the subject of Machine Learning Techniques

* SVM is a supervised learning algorithm used for both regression and classification tasks.
* The main issue with SVM is that it can be computationally expensive because of the large number of parameters and the large number of training samples required.
* SVM also has difficulty dealing with data that is not linearly separable, which can lead to overfitting.
* Another issue is that SVM can be sensitive to outliers, which can lead to poor generalization performance.
* Additionally, SVM requires a good choice of hyperparameters, such as the kernel type, C and gamma, in order to get good performance.
* Finally, SVM is not suitable for large datasets, as it can be slow to train.

In conclusion, SVM is a powerful supervised learning algorithm that can be used for both regression and classification problems, but it does have some issues that should be taken into consideration before using it.
