
## Unit 2 - REGRESSION

Regression is a type of supervised learning algorithm used to predict a continuous target variable from a set of independent features. It is used to identify the relationship between the features and the target variable, and to make predictions about future values of the target variable based on the features.

Regression algorithms can be used for a variety of applications, such as predicting stock prices, predicting customer churn, and forecasting sales.

### Advantages of Regression

1. Regression algorithms are relatively easy to understand and interpret.
2. Regression can be used to predict future values of the target variable based on the features.
3. Regression algorithms are capable of capturing complex relationships between the features and the target variable.
4. Regression algorithms are relatively robust to outliers and noise in the data.

### Disadvantages of Regression

1. Regression algorithms can be sensitive to outliers and noise in the data.
2. Regression algorithms can be computationally expensive to train.
3. Regression algorithms can suffer from overfitting if the model is too complex.
4. Regression algorithms can suffer from underfitting if the model is too simple.

### Examples of Regression

1. Linear regression is a type of regression algorithm that models the relationship between the target variable and the features as a linear equation.
2. Logistic regression is a type of regression algorithm that models the relationship between the target variable and the features as a logistic curve.
3. Polynomial regression is a type of regression algorithm that models the relationship between the target variable and the features as a polynomial equation.
4. Support vector regression is a type of regression algorithm that models the relationship between the target variable and the features using support vector machines.

### Applications of Regression

1. Regression algorithms are used in a variety of applications, such as predicting stock prices, predicting customer churn, and forecasting sales.
2. Regression algorithms can be used to identify the relationship between the features and the target variable, and to make predictions about future values of the target variable based on the features.
3. Regression algorithms can be used to evaluate the impact of changes in the features on the target variable.
4. Regression algorithms can be used to optimize the parameters of a model to maximize the accuracy of predictions.
