
### Locally Weighted Regression for the notes of the Unit 3 - DECISION TREE LEARNING in the subject of Machine Learning Techniques

Locally Weighted Regression (LWR) is a supervised learning technique used to build predictive models from data. It is a type of linear regression, where the weights associated with each feature are adjusted according to the local characteristics of the data. The goal of LWR is to create a model that can accurately predict the target variable using the data from the training set.

LWR is used in situations where the data is too complex to be modeled with a standard linear regression model. In particular, it is used when the data is non-linear, or when the relationships between the features and the target variable are not well understood.

LWR works by fitting a linear regression model to a subset of the data. This subset is chosen based on the local characteristics of the data, such as the local variance or the local correlation between the features and the target variable. The weights associated with each feature are then adjusted according to the local characteristics of the data.

The main advantage of LWR is that it can provide more accurate predictions than a standard linear regression model. This is because it takes into account the local characteristics of the data, which may not be captured by a standard linear regression model.

The main disadvantage of LWR is that it can be computationally expensive. This is because it requires fitting multiple linear regression models to different subsets of the data.

Advantages:

* More accurate predictions than standard linear regression
* Can handle complex, non-linear data

Disadvantages:

* Computationally expensive
* May not be able to capture global characteristics of the data
