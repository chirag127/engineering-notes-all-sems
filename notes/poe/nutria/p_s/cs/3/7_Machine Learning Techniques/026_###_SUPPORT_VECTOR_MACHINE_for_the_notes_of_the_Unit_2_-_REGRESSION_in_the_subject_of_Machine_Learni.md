
### Support Vector Machine 
Support Vector Machine (SVM) is a supervised machine learning algorithm used for classification and regression problems. It is one of the most popular algorithms used in Machine Learning due to its accuracy and ability to handle complex data. 

SVM works by finding a hyperplane in the dataset that best separates the data points into their respective classes. It then uses this hyperplane to make predictions on new data points.

Advantages of SVM: 
- SVM is highly accurate and can handle complex data
- It can be used for both classification and regression problems
- It is robust to outliers
- It is able to handle high dimensional data

Disadvantages of SVM: 
- It can be computationally expensive
- It is not suitable for large datasets
- It requires careful preprocessing of data

Applications of SVM: 
- Text classification
- Image classification
- Handwriting recognition
- Bioinformatics
- Stock market prediction
- Face detection
