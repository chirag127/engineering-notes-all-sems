
### Support Vector Machine 
Support Vector Machines (SVMs) are a type of supervised machine learning algorithm used for classification and regression tasks. SVMs are based on the concept of finding a hyperplane that best divides a dataset into two classes.

**Advantages:** 
- SVMs are effective in high dimensional spaces.
- SVMs are relatively memory efficient.
- SVMs are effective in cases where the number of dimensions is greater than the number of samples.
- SVMs are versatile, as different Kernel functions can be specified for the decision function.

**Disadvantages:**
- SVMs can be sensitive to overfitting.
- SVMs are not suitable for large datasets.
- SVMs are not suitable for data with a lot of noise.

**Applications:**
- SVMs are used in text and hypertext categorization.
- SVMs are used for image classification.
- SVMs are used for medical diagnosis.
- SVMs are used for protein classification.
- SVMs are used for face recognition.
- SVMs are used for handwriting recognition.
