
### Types of Learning for the notes of the Unit 1 - INTRODUCTION in the subject of Machine Learning Techniques

Learning is a process of acquiring knowledge or skills through experience, practice, or study. In the context of Machine Learning, it refers to the process of training a model to learn from data. There are three main types of learning: supervised learning, unsupervised learning, and reinforcement learning.

**Supervised Learning**

Supervised learning is a type of machine learning in which a model is trained on labeled data to predict outcomes. The model is given a set of input data and corresponding labels, which it uses to learn how to map the inputs to the outputs. This type of learning is useful for tasks such as classification and regression.

**Unsupervised Learning**

Unsupervised learning is a type of machine learning in which a model is trained on unlabeled data to discover patterns or groupings in the data. The model is given a set of input data and is expected to learn how to group or cluster the data points based on their similarities. This type of learning is useful for tasks such as clustering and dimensionality reduction.

**Reinforcement Learning**

Reinforcement learning is a type of machine learning in which a model is trained on a set of actions and rewards in order to learn how to maximize its rewards. The model is given a set of actions and corresponding rewards, and is expected to learn how to choose the actions that will lead to the highest rewards. This type of learning is useful for tasks such as game playing and robotics.
