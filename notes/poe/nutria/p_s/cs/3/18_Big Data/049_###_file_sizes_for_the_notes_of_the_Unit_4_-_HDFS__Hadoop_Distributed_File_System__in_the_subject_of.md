
### File Sizes for the Notes of the Unit 4 - HDFS (Hadoop Distributed File System) in the Subject of Big Data

- HDFS is a distributed file system that runs on commodity hardware and stores data across multiple nodes in a cluster.
- HDFS stores large files in a distributed manner, meaning that a single file can be split into multiple blocks and stored on different nodes in the cluster.
- The maximum size of an HDFS file is limited by the number of blocks it can be split into, as each block is limited to 128 megabytes by default.
- HDFS is designed to store large files efficiently, so it is optimized for streaming data access.
- It also supports various file formats such as text, sequence files, binary files, and images.
- HDFS is highly fault tolerant and provides high availability, as it replicates blocks across multiple nodes in the cluster.
- HDFS also provides support for data replication, which helps to ensure data availability in the event of node failure.
- HDFS also supports data compression, which helps to reduce storage costs and improve performance.
- HDFS also provides support for data security, as it can be configured to use secure authentication and encryption.
- HDFS is suitable for applications that require large data sets, such as data warehouses, web search engines, and scientific computing.
