
### Data Format for the Notes of Unit 2 - Hadoop in the Subject of Big Data

* Hadoop is an open-source software framework written in Java that is used for storing and processing large datasets. It is based on the MapReduce programming model and is used for distributed computing across clusters of computers.
* Hadoop uses the HDFS (Hadoop Distributed File System) for storing data. HDFS is a distributed file system that stores data across multiple nodes in a cluster.
* Hadoop also uses the MapReduce programming model for processing data. MapReduce is a programming model that is used for distributed computing across clusters of computers.
* Hadoop also supports the YARN (Yet Another Resource Negotiator) resource management platform. YARN is used for managing and scheduling resources across the cluster.
* Hadoop also supports the HBase database for storing and managing data. HBase is a distributed, column-oriented database that is used for storing and managing large datasets.
* Hadoop also supports the Hive data warehouse for querying and analyzing data. Hive is a data warehouse system that is used for querying and analyzing large datasets.
* Hadoop also supports the Pig data processing language for analyzing data. Pig is a data processing language that is used for analyzing large datasets.
* Hadoop also supports the Spark data processing framework for analyzing data. Spark is a data processing framework that is used for analyzing large datasets.
