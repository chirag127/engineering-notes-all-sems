

## Unit 4 - HDFS (Hadoop Distributed File System)

HDFS is a distributed file system designed to store large amounts of data reliably and efficiently. It is an integral part of Hadoop, a distributed computing platform developed by the Apache Software Foundation. HDFS is designed to be fault-tolerant and highly available, making it suitable for large-scale, mission-critical applications.

**Features of HDFS**

1. Scalability: HDFS is designed to scale to hundreds of nodes in a cluster, allowing it to store petabytes of data.
2. Fault tolerance: HDFS is designed to be fault-tolerant, meaning that it can continue to operate even if a node fails.
3. High availability: HDFS is designed to be highly available, meaning that it can continue to serve data even if a node fails.
4. Data replication: HDFS replicates data across multiple nodes in a cluster, ensuring that data is not lost if a node fails.
5. Data integrity: HDFS ensures that data is not corrupted by checksumming data blocks before they are written to disk.

**Advantages of HDFS**

1. Cost-effective: HDFS is a cost-effective storage solution, as it allows users to store large amounts of data without the need for expensive hardware.
2. Reliability: HDFS is designed to be reliable and fault-tolerant, making it suitable for mission-critical applications.
3. Scalability: HDFS is designed to scale to hundreds of nodes in a cluster, allowing it to store petabytes of data.
4. High availability: HDFS is designed to be highly available, meaning that it can continue to serve data even if a node fails.
5. Data replication: HDFS replicates data across multiple nodes in a cluster, ensuring that data is not lost if a node fails.

**Disadvantages of HDFS**

1. Low throughput: HDFS has a low throughput, meaning that it is not suitable for applications that require high performance.
2. Limited scalability: HDFS is limited in its scalability, as it is not designed to scale beyond a few hundred nodes.
3. Lack of security: HDFS does not provide any security features, making it vulnerable to malicious attacks.
4. Lack of metadata support: HDFS does not support metadata, meaning that users must manually manage and track data.
5. Lack of flexibility: HDFS is not designed to be flexible, as it is designed to store large amounts of data in a single file system.
