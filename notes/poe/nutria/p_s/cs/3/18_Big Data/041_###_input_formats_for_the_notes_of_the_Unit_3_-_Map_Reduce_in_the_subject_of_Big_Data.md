
### Input Formats for Map Reduce
Map Reduce is a programming model used to process and analyze large datasets. It is used in Big Data applications to process data across a cluster of computers. In order to use Map Reduce, data must be provided in the correct format.

#### Text Input Format
Text Input Format is the simplest and most common input format used in Map Reduce. It reads data line-by-line from a text file and divides it into key-value pairs. Each line is divided into a key and a value separated by a tab or a space.

#### Sequence File Input Format
Sequence File Input Format is used to read files stored in Hadoop Sequence Files. It is used when the data is already stored in Hadoop Sequence Files or when the data needs to be processed in a specific order.

#### Key Value Input Format
Key Value Input Format is used to read data that is stored in the form of key-value pairs. It is used when the data needs to be processed in a specific order or when the data is already stored in the form of key-value pairs.

#### XML Input Format
XML Input Format is used to read data stored in XML files. It is used when the data needs to be processed in a specific order or when the data is already stored in XML files.

#### JSON Input Format
JSON Input Format is used to read data stored in JSON files. It is used when the data needs to be processed in a specific order or when the data is already stored in JSON files.

#### DB Input Format
DB Input Format is used to read data stored in a database. It is used when the data needs to be processed in a specific order or when the data is already stored in a database.
