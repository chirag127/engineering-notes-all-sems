
### Read for the Notes of the Unit 4 - HDFS (Hadoop Distributed File System) in the Subject of Big Data

HDFS, or Hadoop Distributed File System, is the primary storage system used by Hadoop applications. It is a distributed, scalable, and fault-tolerant filesystem designed to run on commodity hardware. HDFS provides high-throughput access to application data and is suitable for applications that have large data sets.

**Features of HDFS**
1. Scalability: HDFS can scale up to hundreds of nodes and petabytes of data.
2. Reliability: HDFS is designed to be highly fault-tolerant and provides automatic recovery from node failures.
3. High Throughput: HDFS provides high throughput access to application data.
4. Data Locality: HDFS stores data on the local node where it is being processed, which reduces network traffic and improves performance.

**Advantages of HDFS**
1. Scalability: HDFS can scale up to hundreds of nodes and petabytes of data.
2. Reliability: HDFS is designed to be highly fault-tolerant and provides automatic recovery from node failures.
3. Low Cost: HDFS is designed to run on commodity hardware, which makes it a cost-effective storage solution.
4. High Throughput: HDFS provides high throughput access to application data.
5. Data Locality: HDFS stores data on the local node where it is being processed, which reduces network traffic and improves performance.

**Disadvantages of HDFS**
1. High Latency: HDFS has high latency for small files, which can cause performance issues for applications that require low latency.
2. No Random Access: HDFS does not support random access to files, which can be an issue for applications that require random access.
3. Limited Security: HDFS does not provide built-in security features, such as authentication and authorization.

**Applications of HDFS**
1. Big Data Analytics: HDFS is used to store and process large amounts of data for analytics applications.
2. Data Warehousing: HDFS is used to store and process large amounts of data for data warehousing applications.
3. Machine Learning: HDFS is used to store and process large amounts of data for machine learning applications.
4. Image Processing: HDFS is used to store and process large amounts of data for image processing applications.
5. Video Processing: HDFS is used to store and process large amounts of data for video processing applications.
