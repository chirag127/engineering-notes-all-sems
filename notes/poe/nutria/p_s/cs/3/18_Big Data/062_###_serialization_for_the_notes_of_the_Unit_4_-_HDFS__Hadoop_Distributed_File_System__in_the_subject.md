
### Serialization for the Notes of the Unit 4 - HDFS (Hadoop Distributed File System) in the Subject of Big Data

* Hadoop Distributed File System (HDFS) is a distributed file system designed to run on commodity hardware. It is highly fault-tolerant and is designed to be deployed on low-cost hardware.
* HDFS is designed to store very large files (typically in the range of gigabytes to terabytes) across multiple machines. It stores each file as a sequence of blocks, all of which are of the same size except for the last block.
* HDFS is designed to be used by applications that need to store large data sets. It is especially well-suited for applications that have large streaming data sets, such as video on demand, web logs, and scientific simulations.
* HDFS provides high throughput access to application data and is suitable for applications that have large data sets. It is also highly fault-tolerant and is designed to be deployed on low-cost hardware.
* HDFS provides a mechanism for data serialization, which is the process of converting an object into a stream of bytes so that it can be stored on disk. This process is known as serialization.
* HDFS supports two types of serialization: Writable and SequenceFile. Writable is the simpler of the two and is more suitable for simple data types, such as integers and strings. SequenceFile is more complex and is more suitable for complex data types, such as images, audio, and video.
* HDFS also provides support for compression, which is the process of reducing the size of a file by removing redundant information. Compression can be used to reduce the size of a file and can also improve the performance of applications that access the file.
* HDFS provides support for access control, which is the process of restricting access to files based on user identity. Access control is important for applications that need to ensure that only authorized users can access sensitive data.
* HDFS is designed to be highly available and reliable and is used by many organizations to store and process large data sets. It is an important component of the Hadoop ecosystem and is used in many large-scale data processing applications.
