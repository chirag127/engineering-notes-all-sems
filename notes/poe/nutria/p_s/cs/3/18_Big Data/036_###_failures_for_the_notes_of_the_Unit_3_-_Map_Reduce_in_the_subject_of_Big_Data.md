
### Failures for Unit 3 - Map Reduce in Big Data

* **Data Skew:** Data skew occurs when the data is not evenly distributed across the nodes. This can lead to one node being overloaded with data, while other nodes have very little data. This can cause the entire system to run inefficiently and can even cause it to crash.

* **Network Bandwidth:** Network bandwidth can be a major issue when dealing with Big Data. If the data is too large, it can take a long time to transfer it across the network. This can lead to slow processing times and can cause the system to crash.

* **Data Locality:** Data locality is the idea that the data should be stored close to the nodes that are processing it. If the data is not stored close enough, it can take longer to process and can even cause the system to crash.

* **Data Duplication:** Data duplication can occur when the same data is stored in multiple places. This can lead to inefficient processing times as the system has to search through multiple copies of the same data.

* **Data Formatting:** Data formatting can be a major issue when dealing with Big Data. If the data is stored in the wrong format, it can take longer to process and can even cause the system to crash.
