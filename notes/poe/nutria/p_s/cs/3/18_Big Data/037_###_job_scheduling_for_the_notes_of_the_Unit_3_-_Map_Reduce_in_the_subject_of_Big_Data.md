
### Job Scheduling for the Notes of the Unit 3 - Map Reduce in Big Data

MapReduce is a programming model for processing large data sets with a parallel, distributed algorithm on a cluster. It is a framework for writing applications which process vast amounts of data (multi-terabyte datasets) in-parallel on large clusters of commodity hardware in a reliable, fault-tolerant manner.

Job scheduling is an important part of the MapReduce framework. It is responsible for scheduling tasks within the cluster, ensuring that tasks are assigned to the appropriate nodes and that they are completed in the most efficient way.

Job scheduling involves assigning tasks to the nodes in the cluster, ensuring that the tasks are executed in the most efficient way. This is done by assigning tasks to the nodes that have the most resources available, and by making sure that tasks that require the same resources are executed together.

Job scheduling also involves monitoring the progress of the tasks and taking corrective action if necessary. This can include re-assigning tasks to different nodes if the current node becomes unavailable, or increasing the priority of tasks that are taking longer than expected to complete.

Advantages of Job Scheduling in MapReduce:

- Allows for efficient use of resources in the cluster.
- Allows for tasks to be executed in parallel, leading to faster completion times.
- Allows for tasks to be re-assigned if the current node becomes unavailable.
- Allows for tasks to be given higher priority if they are taking longer than expected to complete.

Disadvantages of Job Scheduling in MapReduce:

- Can be difficult to configure correctly.
- Can be difficult to debug if something goes wrong.
- Can lead to inefficient use of resources if not configured correctly.
