
## Unit 2 - Hadoop

Hadoop is a distributed computing platform that enables organizations to store and process large amounts of data. It is open source and provides an efficient, reliable, and cost-effective way to manage data. Hadoop is composed of two components: the Hadoop Distributed File System (HDFS) and the MapReduce programming model.

**Hadoop Distributed File System (HDFS)**

HDFS is a distributed file system that allows the user to store data across multiple nodes. It is designed to be fault-tolerant and provides high throughput access to data. It is composed of two components: the NameNode, which is the master node that stores metadata about the data stored in the cluster, and the DataNode, which stores the actual data.

**MapReduce**

MapReduce is a programming model that allows users to process large amounts of data in parallel. It consists of two phases: the Map phase, which takes an input and produces a set of intermediate key-value pairs, and the Reduce phase, which takes the intermediate key-value pairs and produces an output.

**Advantages of Hadoop**

- Scalability: Hadoop can easily scale up or down depending on the amount of data to be processed.
- Fault tolerance: Hadoop is designed to be fault tolerant, meaning that if a node fails, the data will still be available on other nodes.
- Cost-effectiveness: Hadoop is an open source platform, so there are no licensing costs associated with it.
- High throughput: Hadoop can process large amounts of data quickly and efficiently.

**Disadvantages of Hadoop**

- Security: Hadoop does not have built-in security features, so it is important to implement security measures in order to protect data.
- Complexity: Hadoop is a complex system and requires a certain level of expertise to set up and maintain.
- Lack of support: Hadoop is an open source platform, so there is no official support available.

**Applications of Hadoop**

- Data warehousing: Hadoop is used to store large amounts of data and to analyze it for business intelligence.
- Big data analytics: Hadoop can be used to process large amounts of data and to generate insights from it.
- Machine learning: Hadoop can be used to process large amounts of data and to train machine learning models.
- Internet of things: Hadoop can be used to store and process data from connected devices.
