

### Command Line Interface for the Notes of the Unit 4 - HDFS (Hadoop Distributed File System) in the Subject of Big Data

* HDFS (Hadoop Distributed File System) is a distributed file system that is designed to run on large clusters of commodity hardware. It is the primary file system used in Hadoop applications. 
* HDFS provides high throughput access to application data and is suitable for applications that have large data sets. 
* The HDFS architecture includes a single NameNode, which manages the file system namespace and regulates access to files by clients. 
* The NameNode also maintains the file system tree and the metadata for all the files and directories in the tree. 
* The DataNodes are the slave nodes in the cluster that are responsible for serving read and write requests from the file system’s clients. 
* The DataNodes also perform block creation, deletion, and replication upon instruction from the NameNode. 
* HDFS provides a command line interface (CLI) for users to interact with the file system. The CLI is used to perform various operations such as creating, deleting, and listing files and directories. 
* The CLI also allows users to set permissions and access control lists (ACLs) on files and directories. 
* Additionally, the CLI provides tools for managing HDFS quotas, snapshots, and replication.
