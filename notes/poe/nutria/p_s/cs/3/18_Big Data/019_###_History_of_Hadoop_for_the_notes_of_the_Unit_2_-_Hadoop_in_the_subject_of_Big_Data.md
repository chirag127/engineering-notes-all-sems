
### History of Hadoop for the notes of the Unit 2 - Hadoop in the subject of Big Data

Hadoop is an open-source software framework used for distributed storage and processing of large datasets on clusters of commodity hardware. It was created by Doug Cutting and Mike Cafarella in 2006 and is now maintained by the Apache Software Foundation. Hadoop is written in Java and is designed to scale up from single servers to thousands of machines, each offering local computation and storage.

Hadoop's core components are the Hadoop Distributed File System (HDFS) and the MapReduce programming model. HDFS is a distributed file system that stores data across multiple machines and provides access to them through an API. MapReduce is a programming model for processing and analyzing large datasets in parallel.

Hadoop has become popular in the big data space due to its ability to store and process large amounts of data quickly and efficiently. It is used by many organizations for data storage, analysis, and machine learning applications. Hadoop is also used in many industries such as finance, healthcare, retail, and government.

Hadoop is an important tool in the field of big data and has been used to solve many complex problems. It has also been used to build large-scale distributed systems such as Apache Hadoop YARN and Apache Spark. Hadoop is also used to build data warehouses and real-time analytics systems.
