
### Hadoop Echo System for the notes of the Unit 2 - Hadoop in the subject of Big Data

Hadoop is an open-source software framework for distributed storage and processing of large data sets. It is designed to scale up from single servers to thousands of machines, each offering local computation and storage. It is an integral part of the Big Data ecosystem, providing an efficient and reliable way to store and process large amounts of data.

The Hadoop Ecosystem is a suite of open source components that provide the necessary tools and services to build and manage a Hadoop cluster. It includes components such as HDFS (Hadoop Distributed File System), MapReduce, YARN, Hive, HBase, Pig, Oozie, Flume, and Sqoop.

HDFS is the primary storage system used by Hadoop applications. It is a distributed file system that provides high-throughput access to application data. HDFS stores data across multiple nodes in a cluster and is designed to be fault-tolerant and highly available.

MapReduce is a programming model for processing large data sets in a distributed manner. It is the main component of the Hadoop Ecosystem and is used to process large data sets in parallel. It enables applications to quickly process large amounts of data by splitting the work across multiple nodes in the cluster.

YARN is the resource management layer of the Hadoop Ecosystem. It is responsible for scheduling jobs, allocating resources, and managing workloads across the cluster.

Hive is a data warehouse system for Hadoop. It provides a SQL-like language for querying and managing data stored in HDFS.

HBase is a distributed, column-oriented database built on top of HDFS. It is used for real-time access to data stored in HDFS.

Pig is a high-level dataflow language and execution framework for processing large data sets. It is used to write data processing programs in a language called Pig Latin.

Oozie is a workflow scheduler for Hadoop jobs. It is used to manage and execute complex multi-step jobs that involve multiple tasks and dependencies.

Flume is a distributed, reliable, and available service for collecting, aggregating, and moving large amounts of streaming data into HDFS.

Sqoop is a tool for transferring data between Hadoop and relational databases. It is used to import and export data between HDFS and relational databases such as Oracle, MySQL, and PostgreSQL.
