

### Output Formats for the Notes of the Unit 3 - Map Reduce in the Subject of Big Data

- MapReduce is a programming model that is used to process and generate large datasets. It enables users to process and analyze large datasets across clusters of computers.
- The output of the MapReduce job is stored in the output directory. The output of the MapReduce job can be stored in various formats.
- The output formats supported by MapReduce are:
    - Text Output Format: This is the default output format for MapReduce jobs. It writes the output as plain text files.
    - SequenceFile Output Format: This output format is used to write the output as a sequence of binary key/value pairs.
    - Avro Output Format: This output format is used to write the output as Avro data files.
    - ORC Output Format: This output format is used to write the output as Apache ORC files.
    - Parquet Output Format: This output format is used to write the output as Apache Parquet files.
- Each of the output formats has its own advantages and disadvantages. It is important to choose the right output format for the MapReduce job. For example, if the output needs to be stored in a database, then the Text Output Format is the best option.
