
### Design of HDFS for the Notes of the Unit 4 - HDFS (Hadoop Distributed File System) in the Subject of Big Data

* HDFS is a distributed file system that is designed to store large amounts of data reliably and efficiently.
* It is based on the Google File System and provides a platform for data storage and processing in a distributed environment.
* HDFS is designed to be fault-tolerant and highly available, and it is optimized for streaming data access.
* HDFS is designed to scale to petabytes of data and thousands of nodes in a cluster.
* HDFS is composed of a NameNode and multiple DataNodes. The NameNode is responsible for managing the file system namespace and access control.
* The DataNodes are responsible for storing the actual data and providing access to it.
* HDFS provides a number of features such as redundancy, scalability, reliability, and high availability.
* HDFS also provides data replication to ensure that data is not lost in the event of a node failure.
* HDFS also provides support for data compression and data encryption to improve performance and security.
* HDFS is used in a variety of applications such as web search, data mining, machine learning, and distributed analytics.
