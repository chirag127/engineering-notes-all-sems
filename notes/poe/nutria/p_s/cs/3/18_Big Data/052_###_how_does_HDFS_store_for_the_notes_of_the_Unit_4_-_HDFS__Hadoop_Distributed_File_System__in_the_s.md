
### How Does HDFS Store for the Notes of the Unit 4 - HDFS (Hadoop Distributed File System) in the Subject of Big Data

- HDFS is a distributed file system designed to store large files across multiple nodes in a Hadoop cluster. 
- It is designed to store and manage large amounts of data in a fault-tolerant manner, with a high degree of scalability. 
- HDFS is designed to be highly reliable and fault tolerant, meaning that it can continue to function even when a node or disk fails. 
- Data is stored in HDFS in the form of blocks, which are usually 64MB in size. 
- Each block is replicated across multiple nodes in the cluster, which helps to ensure that the data is not lost if a node fails. 
- Data is stored in HDFS in the form of files, which are divided into blocks and stored across multiple nodes in the cluster. 
- The HDFS NameNode is responsible for maintaining the metadata of the files stored in the cluster, including the locations of the blocks. 
- HDFS is optimized for streaming access to large files, which makes it an ideal choice for applications such as analytics and data processing. 
- It also provides a range of features such as high availability, scalability, and fault tolerance, which makes it suitable for storing large amounts of data.
