
## Program for Merge Sort for the Notes of the Design and Analysis of Algorithm Lab in the Subject of Real Time System

Merge sort is an efficient sorting algorithm that is used to sort large datasets. It is a divide and conquer algorithm that divides the input array into two halves, sorts each half, and then merges them to produce a sorted output.

### Algorithm

1. Divide the unsorted list into two halves.
2. Recursively sort each half.
3. Merge the two sorted halves to produce a single sorted list.

### Advantages

1. It is a stable sorting algorithm, meaning that equal elements remain in the same order.
2. It is not an in-place sorting algorithm, meaning that it does not require extra space.
3. It is a recursive algorithm, meaning that it can be used to solve more complex problems.

### Disadvantages

1. It is a time-consuming algorithm, meaning that it takes longer to sort large datasets.
2. It requires additional memory for the temporary arrays used in the sorting process.

### Example

Consider the following unsorted array:

`[3, 5, 1, 4, 2]`

The array is divided into two halves:

`[3, 5, 1]` and `[4, 2]`

Each half is sorted individually:

`[1, 3, 5]` and `[2, 4]`

The two halves are merged to produce a single sorted array:

`[1, 2, 3, 4, 5]`

Merge sort is used in a variety of applications, including:
