
## Sort a given set of n integer elements using Merge Sort method and compute its time complexity

Merge Sort is a type of sorting algorithm that uses the divide and conquer approach to sort a given set of n integer elements. It works by dividing the array into two halves and then sorting each half recursively. The sorted halves are then merged to form a single sorted array.

The time complexity of Merge Sort depends on the size of the array. In the worst case scenario, the time complexity is O(n log n). In the average case scenario, the time complexity is O(n log n). In the best case scenario, the time complexity is O(n log n).
