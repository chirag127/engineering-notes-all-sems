
## Implement N Queen Problem using Backtracking 

The N Queen Problem is a classic problem of computer science that involves finding a way to place N queens on an NxN chessboard such that no two queens are attacking each other. This problem can be solved using backtracking, which is a general algorithmic technique that considers searching every possible combination of solutions until a solution is found.

Backtracking is an important algorithm used in the Design and Analysis of Algorithms Lab in the subject of Real Time Systems. It is a recursive technique that is used to solve problems by searching through all possible solutions and finding the best one. In the case of the N Queen Problem, backtracking is used to search through all possible configurations of the board and find a solution that does not have any queens attacking each other.

The basic idea behind backtracking is to start with an empty board and then place a queen in each column one at a time. For each column, all possible positions of the queen are tried and if a solution is not found, the queen is removed and the next column is tried. This process is repeated until a solution is found or all possible combinations have been tried.

Advantages of backtracking include its simplicity and efficiency. It is also a general technique that can be used to solve a variety of problems.

Disadvantages of backtracking include its time complexity, which can be high for large problems. Additionally, backtracking can sometimes return incorrect solutions if not implemented correctly.

Examples of applications of backtracking include solving the N Queen Problem, solving Sudoku puzzles, finding Hamiltonian cycles, and solving the knapsack problem.
