
## Program for Selection Sort for the Design and Analysis of Algorithm Lab in the subject of Real Time System

* Selection Sort is an algorithm used to sort a list of elements in ascending or descending order. 
* It works by selecting the smallest or largest element from the list and placing it at the beginning or end of the list, respectively. 
* The algorithm then moves onto the next element, repeating the process until the list is sorted. 
* Selection Sort has a time complexity of O(n<sup>2</sup>) which makes it less efficient than other sorting algorithms such as Quick Sort and Merge Sort. 
* The algorithm is simple to implement and is often used in introductory courses to teach the concept of sorting.

* **Algorithm:**
  1. Start with the first element in the list.
  2. Compare it to each subsequent element in the list.
  3. If the element is smaller than the current element, swap the two elements.
  4. Repeat steps 2 and 3 until the end of the list is reached.
  5. Move to the next element in the list and repeat steps 2-4 until the list is sorted.

* **Advantages:**
  * Simple to implement.
  * Can be used to sort both ascending and descending order.
  * Does not require additional memory.

* **Disadvantages:**
  * Has a time complexity of O(n<sup>2</sup>) which makes it less efficient than other sorting algorithms.
  * Not suitable for large lists.

* **Examples:**
  * Sorting a list of numbers in ascending order.
  * Sorting a list of names in alphabetical order.
  * Sorting a list of employees by salary.

* **Applications:**
  * Used in databases to sort records.
  * Used in operating systems to sort files.
  * Used in scheduling algorithms to sort tasks.
