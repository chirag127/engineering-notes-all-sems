
## Data Definition Language (DDL) Statements

Data Definition Language (DDL) is a language used to define the structure and organization of data stored in a database. It is used to create, modify, and delete database objects such as tables, views, and stored procedures. DDL statements are commonly used in database management systems (DBMS) such as Oracle, MySQL, and SQL Server.

The DDL statements used in DBMS mapping with virtual lab labs are CREATE, ALTER, DROP, RENAME, and TRUNCATE.

### CREATE

The CREATE statement is used to create a new database object such as a table, view, or stored procedure. It is used to define the structure and organization of the data stored in the database.

### ALTER

The ALTER statement is used to modify an existing database object such as a table, view, or stored procedure. It is used to add, delete, or modify columns, constraints, and other database objects.

### DROP

The DROP statement is used to delete an existing database object such as a table, view, or stored procedure. It is used to remove an object from the database.

### RENAME

The RENAME statement is used to rename an existing database object such as a table, view, or stored procedure. It is used to change the name of an object in the database.

### TRUNCATE

The TRUNCATE statement is used to delete all the data stored in a database table. It is used to quickly delete all the data from a table without deleting the table itself.
