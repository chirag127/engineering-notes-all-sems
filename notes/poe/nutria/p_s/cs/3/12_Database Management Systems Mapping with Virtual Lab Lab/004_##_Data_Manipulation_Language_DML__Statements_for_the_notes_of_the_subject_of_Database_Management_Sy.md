
## Data Manipulation Language (DML) Statements 
Data Manipulation Language (DML) is a set of commands used to manipulate data in a database. It is used to perform operations such as inserting, updating, deleting, and retrieving data. It is used to manipulate data in a relational database management system (RDBMS). 

The most common DML statements are SELECT, INSERT, UPDATE, and DELETE. 

### SELECT 
The SELECT statement is used to retrieve data from a database. It can be used to select specific columns, specific rows, or specific values from a table. It is also used to join two or more tables together.

### INSERT 
The INSERT statement is used to add new records to a table. It is used to insert data into a table.

### UPDATE 
The UPDATE statement is used to modify existing records in a table. It is used to update existing data in a table.

### DELETE 
The DELETE statement is used to delete existing records from a table. It is used to delete data from a table.
