
## Unit 2 - PROBLEM SOLVING METHODS

Problem solving methods are techniques used to solve problems in a systematic and efficient manner. Problem solving methods typically involve understanding the problem, breaking it down into smaller parts, and finding a solution to each part. The following are some of the most common problem solving methods:

1. Algorithmic Problem Solving: Algorithmic problem solving involves using a set of instructions to solve a problem. This method is often used in computer programming, where a step-by-step procedure is necessary to solve a problem.

2. Heuristic Problem Solving: Heuristic problem solving involves using trial and error to find a solution to a problem. This method relies on the experience and intuition of the problem solver to come up with a solution.

3. Analytical Problem Solving: Analytical problem solving involves breaking down a problem into its component parts and then analyzing each part to determine a solution. This method is often used in engineering and scientific problem solving.

4. Systematic Problem Solving: Systematic problem solving involves using a systematic approach to solve a problem. This method is often used in business and management problem solving.

5. Creative Problem Solving: Creative problem solving involves using creative thinking to come up with a solution to a problem. This method is often used in design and art problem solving.

Each problem solving method has its own advantages and disadvantages. It is important to choose the right problem solving method for the problem at hand. By using the right problem solving method, it is possible to solve problems in an efficient and effective manner.
