
### Alpha for the notes of the Unit 2 - PROBLEM SOLVING METHODS in the subject of ARTIFICIAL INTELLIGENCE KCS

1. Problem Solving Methods: Problem solving methods are techniques used to solve problems in Artificial Intelligence. They are used to find solutions to complex problems that may not have a single, straightforward solution.

2. Search Algorithms: Search algorithms are methods used to find solutions to problems. They are used to search through a set of possible solutions and select the best one. Common search algorithms include depth-first search, breadth-first search, and A* search.

3. Heuristics: Heuristics are rules of thumb used to guide problem solving. They are used to make decisions about how to proceed with a problem and are often used to reduce the search space of a problem. Common heuristics include hill climbing, simulated annealing, and genetic algorithms.

4. Adversarial Search: Adversarial search is a type of search algorithm used to find solutions to two-player games. It is used to determine the best move in a game by looking at all possible moves and evaluating them based on their potential impact on the outcome of the game.

5. Constraint Satisfaction Problems: Constraint satisfaction problems are problems in which a set of constraints must be satisfied in order to find a solution. They are used to solve problems in which a set of variables must be assigned values in order to satisfy a set of constraints.

6. Knowledge Representation: Knowledge representation is the process of representing knowledge in a form that can be used by a computer. It is used to represent facts, rules, and relationships in a way that can be used by a computer to solve problems. Common knowledge representation techniques include semantic networks, frames, and rules.
