
### Authenticate the User when Submitting Login Form
Authentication is the process of verifying the identity of a user when they submit a login form. This is typically done by comparing the username and password provided by the user to the username and password stored in the database.

When using Java Database Connectivity (JDBC), Object Database Connectivity (ODBC) and section tracking Application Programming Interface (API) to design server site applications, authentication is an important part of the process. Authentication ensures that only authorized users can access the application.

To authenticate the user when submitting a login form, the following steps should be taken:

1. Retrieve the username and password from the form.
2. Compare the username and password to the username and password stored in the database.
3. If the username and password match, the user is authenticated.
4. If the username and password do not match, the user is not authenticated.

Authentication is an important part of designing server site applications and should not be overlooked. It is important to ensure that only authorized users can access the application.
