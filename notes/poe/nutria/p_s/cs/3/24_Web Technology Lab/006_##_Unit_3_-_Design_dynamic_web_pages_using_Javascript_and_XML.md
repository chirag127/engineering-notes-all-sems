
## Unit 3 - Design dynamic web pages using Javascript and XML

* Javascript is a programming language used to create dynamic web pages. It is used to add interactive elements to web pages, such as forms, animations, and other user interface elements.
* XML (Extensible Markup Language) is a markup language used to structure and store data. XML is used to create dynamic web pages, as it allows for the creation of dynamic elements on the page.
* Dynamic web pages are web pages that can be changed and updated without having to reload the entire page. This makes them more responsive to user input and allows for more interactive elements on the page.
* Javascript and XML can be used together to create dynamic web pages. Javascript is used to create the interactive elements on the page, while XML is used to store and structure the data.
* Advantages of using Javascript and XML to create dynamic web pages include:
  * Increased interactivity - Dynamic web pages can respond to user input in real time, making them more engaging and user-friendly.
  * Improved performance - Dynamic web pages can be loaded faster, as they don’t require the entire page to be reloaded.
  * Reduced development time - Dynamic web pages can be created more quickly, as the code is simpler and easier to understand.
* Disadvantages of using Javascript and XML to create dynamic web pages include:
  * Increased complexity - Dynamic web pages require more complex code, which can be difficult to debug and maintain.
  * Increased risk of security issues - Dynamic web pages can be vulnerable to security issues, such as cross-site scripting attacks.
  * Increased resource usage - Dynamic web pages can require more resources, such as memory and processing power.

Examples of applications that use Javascript and XML to create dynamic web pages include:
* Social media websites
* Online shopping websites
* Online gaming websites
* Online news websites
* Online mapping websites
