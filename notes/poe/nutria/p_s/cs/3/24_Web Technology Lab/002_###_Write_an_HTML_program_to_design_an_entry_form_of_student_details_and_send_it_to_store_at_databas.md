
### Write an HTML program to design an Entry Form of Student Details and send it to Store at Database Server like SQL, Oracle or MS Access for the Notes of the Unit 1 - Develop Static Web Pages using HTML in the Subject of Web Technology Lab

This topic covers the basics of creating an HTML program to design an entry form of student details and send it to a database server like SQL, Oracle or MS Access for the notes of the Unit 1 - Develop static web pages using HTML in the subject of Web Technology Lab.

##### What is an HTML Program?
An HTML program is a set of instructions written in Hypertext Markup Language (HTML) code to create a web page. HTML code is written in plain text and is used to structure and format the content of a web page.

##### What is an Entry Form?
An entry form is an interface that allows users to enter data into a database. It is usually a web page, with fields for users to enter data. The data is then stored in the database.

##### What is a Database Server?
A database server is a computer system that stores data in a database. It is the central repository of data and is responsible for managing the data and providing access to it. Common database servers include SQL, Oracle and MS Access.

##### How to Write an HTML Program to Design an Entry Form of Student Details and Send it to a Database Server?
1. Create a web page using HTML.
2. Add fields for users to enter data.
3. Connect to a database server.
4. Write a script to send the data from the entry form to the database server.
5. Test the program to make sure it works correctly.
