
## Unit 4 - Design dynamic web page using server site programming Ex. ASP/JSP/PHP

Dynamic web pages are web pages that are generated on the fly, usually in response to user input. They are created using server-side programming languages such as ASP, JSP, and PHP.

**Advantages:**

- Dynamic web pages are more interactive and can provide a better user experience.
- They can be used to create complex web applications that can store and process data.
- They can be used to create powerful web applications with a wide range of features.

**Disadvantages:**

- Dynamic web pages require a lot of development time and effort.
- They require a server-side programming language, which can be difficult to learn and maintain.
- They can be vulnerable to security risks if not properly secured.

**Examples:**

- Online shopping websites, such as Amazon, are examples of dynamic web pages. 
- Social media websites, such as Facebook, are also examples of dynamic web pages. 
- Web applications, such as Google Docs, are also examples of dynamic web pages. 

**Applications:**

- Dynamic web pages can be used to create complex web applications, such as online shopping websites, social media websites, and web applications. 
- They can also be used to create interactive websites, such as games and quizzes.
- They can also be used to create data-driven websites, such as databases and search engines.
