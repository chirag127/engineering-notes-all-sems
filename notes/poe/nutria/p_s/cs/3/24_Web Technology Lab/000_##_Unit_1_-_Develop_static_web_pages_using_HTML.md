
## Unit 1 - Develop Static Web Pages Using HTML

HTML stands for HyperText Markup Language and is the most basic building block of the web. It is used to structure and present content on the web, and can be used to create static web pages.

### What is HTML?

HTML is a markup language used to create web pages. It is used to structure and present content on the web. HTML consists of a set of tags that are used to define the structure and content of a web page. The tags are surrounded by angle brackets, and the content of the tags is placed in between the opening and closing tags.

### What is a Static Web Page?

A static web page is a page that does not change, even when a user interacts with it. It is a page that is served up exactly the same every time it is requested. Static web pages are created using HTML and CSS, and they are typically used for content that does not need to be updated frequently, such as information pages or product descriptions.

### How to Create a Static Web Page

Creating a static web page is relatively straightforward. The first step is to create an HTML document. This document should include the necessary HTML tags to structure the page, such as `<html>`, `<head>`, `<title>`, `<body>`, and `<h1>` tags. Once the HTML document is created, it can be styled using CSS. Finally, the page can be uploaded to a web server so that it can be accessed by users.

### Advantages of Using HTML

There are several advantages to using HTML for creating static web pages. First, it is relatively easy to learn and use. HTML is also supported by all major browsers, so it is accessible to a wide range of users. Additionally, HTML is a lightweight language, so it can be used to create pages that load quickly. Finally, HTML is an open standard, so it can be used to create pages that are compatible with any platform.

### Disadvantages of Using HTML

While HTML is a great language for creating static web pages, it does have some drawbacks. HTML is not a programming language, so it is not suitable for creating dynamic web pages that require user input and interaction. Additionally, HTML is limited in terms of styling options, and it can be difficult to create complex layouts with HTML alone. Finally, HTML is not as secure as other languages, so it is not suitable for creating applications that require a high level of security.
