
## Unit 5 - Design server site applications using JDDC, ODBC and Section Tracking API

This unit covers the design of server-side applications using the Java Database Connectivity (JDBC), Open Database Connectivity (ODBC) and Section Tracking Application Programming Interface (API).

* **Java Database Connectivity (JDBC)** is an application programming interface (API) that allows Java applications to access and manipulate data stored in a database. JDBC allows developers to write applications that interact with databases in a standard way, without having to know the details of the underlying database.

* **Open Database Connectivity (ODBC)** is a standard application programming interface (API) for accessing databases. It provides a common language for applications to access data stored in different types of databases, such as Oracle, Microsoft SQL Server, and Sybase.

* **Section Tracking Application Programming Interface (API)** is an application programming interface (API) that allows applications to access and manipulate data stored in a Section Tracking database. Section Tracking API provides a standard way for applications to access and manipulate data stored in a Section Tracking database.

Advantages of using JDBC, ODBC and Section Tracking API:

* All three APIs provide a standard way of accessing and manipulating data stored in a database, making it easier for developers to write applications that interact with databases.

* JDBC and ODBC are widely supported, meaning that applications written using these APIs can be used with a variety of databases.

* Section Tracking API is specifically designed for Section Tracking databases, making it easier for developers to write applications that interact with Section Tracking databases.

Disadvantages of using JDBC, ODBC and Section Tracking API:

* JDBC and ODBC are not as efficient as native database APIs, meaning that applications written using these APIs may not perform as well as those written using native database APIs.

* Section Tracking API is not as widely supported as JDBC and ODBC, meaning that applications written using this API may not be compatible with all Section Tracking databases.

Examples of applications that use JDBC, ODBC and Section Tracking API:

* Customer relationship management (CRM) applications often use JDBC and ODBC to access and manipulate data stored in a database.

* Business intelligence (BI) applications often use Section Tracking API to access and manipulate data stored in a Section Tracking database.

* Financial applications often use JDBC and ODBC to access and manipulate data stored in a database.
