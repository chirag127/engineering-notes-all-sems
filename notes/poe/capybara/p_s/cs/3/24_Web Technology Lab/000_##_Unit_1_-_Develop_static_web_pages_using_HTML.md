## Unit 1 - Develop static web pages using HTML

In this unit, you will learn about the basics of developing static web pages using HTML. HTML stands for Hypertext Markup Language, which is the standard markup language used to create web pages. This unit is designed to provide you with a foundational understanding of HTML, including its syntax, structure, and basic elements.

### Learning Objectives

By the end of this unit, you should be able to:

- Understand the basics of HTML syntax and structure.
- Create and edit simple HTML documents.
- Use HTML tags to format text and add images.
- Understand the importance of semantic markup.
- Create links between web pages using HTML.

### HTML Syntax and Structure

HTML documents are structured using a set of tags that define the content of a web page. These tags are enclosed in angled brackets (< >) and come in pairs (opening and closing tags) or as standalone tags. The basic structure of an HTML document includes the following:

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Page Title</title>
  </head>
  <body>
    <h1>Heading 1</h1>
    <p>Paragraph text goes here.</p>
  </body>
</html>
```

The `<!DOCTYPE html>` declaration tells the browser that this is an HTML5 document. The `<html>` tag defines the root of the HTML document. The `<head>` tag contains metadata about the document, such as the title displayed in the browser tab. The `<body>` tag contains the content of the web page.

### HTML Tags

HTML tags are used to define the structure and content of a web page. Some common HTML tags include:

- `<h1>` to `<h6>`: Used to define headings of different sizes.
- `<p>`: Used for paragraphs of text.
- `<a>`: Used to create links to other web pages or resources.
- `<img>`: Used to embed images in a web page.
- `<ul>` and `<ol>`: Used to create unordered and ordered lists, respectively.
- `<li>`: Used to define list items.

### Semantic Markup

Semantic markup is the practice of using HTML tags to convey the meaning of the content on a web page. This makes it easier for search engines and other tools to understand and categorize the content. Some common semantic HTML tags include:

- `<header>`: Used to define the header section of a web page.
- `<nav>`: Used to define the navigation section of a web page.
- `<main>`: Used to define the main content section of a web page.
- `<article>`: Used to define a self-contained article or blog post.
- `<footer>`: Used to define the footer section of a web page.

### Links

Links are an important part of web development, as they allow users to navigate between pages and resources. The `<a>` tag is used to create links, and the `href` attribute is used to specify the destination URL. Here's an example of a link:

```html
<a href="https://www.example.com">Visit Example.com</a>
```
