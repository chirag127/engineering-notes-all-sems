### Write an HTML program to design an entry form of student details and send it to store at database server like SQL, Oracle or MS Access for the notes of the Unit 1 - Develop static web pages using HTML in the subject of Web Technology Lab.

HTML or HyperText Markup Language is the standard markup language used for creating web pages. It is a fundamental skill for any web developer to learn and understand HTML. In this unit, we will learn how to develop static web pages using HTML. 

One of the essential tasks of a web developer is to create forms for user input. In this topic, we will learn how to design an entry form for student details using HTML and how to send it to store in a database server like SQL, Oracle, or MS Access.

#### Creating an Entry Form for Student Details

To create an entry form for student details, we can use HTML form elements. The following are the steps to create an entry form for student details:

1. First, we need to create an HTML file and define the form element. We can use the `<form>` tag to define the form element.

2. Inside the `<form>` tag, we can add input fields for student details like name, age, gender, etc.

3. We can use the `<label>` tag to label the input fields.

4. We can use the `<input>` tag to create input fields for student details. We can specify the type of input field using the `type` attribute.

5. We can use the `<button>` tag to create a submit button for the form. When the user clicks on the submit button, the form data will be sent to the server.

#### Storing the Form Data in a Database Server

To store the form data in a database server like SQL, Oracle, or MS Access, we need to use server-side programming languages like PHP or ASP.NET. The following are the steps to store the form data in a database server:

1. We need to create a server-side script that will receive the form data from the HTML form.

2. We can use the server-side scripting language to connect to the database server and insert the form data into the database.

3. We can use SQL queries to insert the form data into the database.

4. Once the form data is stored in the database, we can retrieve it using SQL queries and display it on a web page.

#### Advantages of using HTML for creating Entry Forms

1. HTML is a simple and easy-to-learn markup language.

2. HTML forms are supported by all web browsers.

3. HTML forms can be styled using CSS to make them visually appealing.

4. HTML forms are accessible to users with disabilities.

#### Disadvantages of using HTML for creating Entry Forms

1. HTML forms can be vulnerable to security attacks like cross-site scripting (XSS) and SQL injection.

2. HTML forms only provide basic validation for user input.

3. HTML forms cannot handle complex business logic.
