# Write HTML/Java scripts to display your CV in navigator, your Institute website, Department Website and Tutorial website for specific subject for the notes of the Unit 1 - Develop static web pages using HTML in the subject of Web Technology Lab

In the Web Technology Lab, students learn how to develop static web pages using HTML. As a part of the lab, students are required to write HTML/Java scripts to display their CV on various websites. In this section, we will discuss how to write these scripts and display a CV on Navigator, Institute website, Department website, and Tutorial website.

### Displaying CV on Navigator

To display your CV on the navigator, you need to create an HTML file that contains your CV information. Follow the below steps to create an HTML file:

1. Open a text editor like Notepad or Sublime Text.
2. Write the HTML code to create a basic structure of the web page.
3. Add your CV information in the body section of the HTML file.
4. Save the file with the .html extension.

Once you have created the HTML file, you can upload it to the web server and access it using the Navigator.

### Displaying CV on Institute Website

To display your CV on the Institute website, you need to follow the below steps:

1. Open the Institute website in a web browser.
2. Navigate to the section where you want to display your CV.
3. Click on the edit button to open the editor.
4. Write the HTML code to display your CV information.
5. Save the changes and publish the website.

Make sure to test your CV display on the Institute website by opening the website in different web browsers.
