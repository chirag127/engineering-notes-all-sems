### Prolog Programming for the notes of the Unit 3 - KNOWLEDGE REPRESENTATION in the subject of ARTIFICIAL INTELLIGENCE KCS

Prolog is a programming language that is widely used in the field of artificial intelligence. It is a declarative programming language that is based on logic programming. It is an ideal language for knowledge representation and reasoning.

Some of the key features of Prolog programming language are:

- Prolog is a declarative programming language. It means that we specify what we want to do and not how to do it.
- Prolog is based on logic programming. It uses a logical approach to solve problems.
- Prolog is an ideal language for knowledge representation and reasoning. It is used to represent knowledge in a logical way and to perform reasoning on that knowledge.
- Prolog has a built-in inference engine that can be used to perform reasoning on the knowledge represented in the program.
- Prolog is used in applications such as expert systems, natural language processing, and robotics.

#### Syntax of Prolog

The syntax of Prolog is based on the concept of clauses. A clause is a statement that consists of a head and a body. The head represents a predicate and the body represents a set of conditions.

Here is an example of a Prolog clause:

```
likes(john, pizza).
```

In this example, `likes` is the predicate, and `john` and `pizza` are the arguments.

#### Example of Prolog Program

Here is an example of a Prolog program that defines a family tree:

```
parent(john, mary).
parent(john, tom).
parent(sue, mary).
parent(sue, tom).
male(john).
male(tom).
female(mary).
female(sue).
```

In this program, `parent`, `male`, and `female` are predicates, and `john`, `mary`, `tom`, and `sue` are the arguments.
