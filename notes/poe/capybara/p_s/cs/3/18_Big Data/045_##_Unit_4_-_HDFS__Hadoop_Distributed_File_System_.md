## Unit 4 - HDFS (Hadoop Distributed File System)

Hadoop Distributed File System (HDFS) is a distributed file system designed to store and manage large amounts of data across clusters of commodity hardware. It is a critical component of the Hadoop ecosystem and is used widely in big data applications.

### Architecture of HDFS

HDFS follows a master-slave architecture where there is a single NameNode that acts as the master and several DataNodes that act as slaves. The NameNode manages the file system namespace, regulates client access to files, and manages the replication of data blocks. The DataNodes store the actual data blocks and serve read and write requests from clients.

### Advantages of HDFS

- Scalability: HDFS can store and manage data on clusters of commodity hardware, making it highly scalable and cost-effective.
- High availability: HDFS provides high availability by replicating data blocks across multiple DataNodes. If a DataNode fails, the data can be retrieved from other nodes in the cluster.
- Fault tolerance: HDFS is designed to handle failures gracefully. If a DataNode or NameNode fails, the system can continue to function without any data loss.
- Data locality: HDFS is designed to take advantage of data locality, which means that data is stored on the same node where it is processed. This reduces network traffic and improves performance.

### Disadvantages of HDFS

- Limited support for small files: HDFS is optimized for handling large files and is not well-suited for storing small files.
- Complexity: HDFS can be complex to set up and manage, especially for organizations that are not familiar with the Hadoop ecosystem.

### Applications of HDFS

HDFS is used widely in big data applications, including:

- Data warehousing: HDFS is used to store and manage large amounts of structured and unstructured data for analytics purposes.
- Log processing: HDFS is used to store and analyze log data generated by web servers and other applications.
- Image and video processing: HDFS is used to store and process large image and video files in applications such as surveillance and medical imaging.
- Machine learning: HDFS is used to store and manage large datasets for machine learning algorithms.

### Example of HDFS

Here is an example of how HDFS can be used to store and manage large amounts of data:

Suppose a company wants to store and analyze its customer data, which includes information such as customer demographics, purchase history, and product preferences. The company can use HDFS to store this data across a cluster of commodity hardware. The data can then be processed using Hadoop MapReduce or other big data processing tools to gain insights into customer behavior and preferences.
