### Unit 4: HDFS (Hadoop Distributed File System)

Hadoop Distributed File System (HDFS) is a distributed file system that is designed to store and manage large data sets across clusters of commodity hardware. It is a key component of the Hadoop ecosystem and is widely used in big data applications.

#### Architecture of HDFS

The HDFS architecture consists of the following components:

1. NameNode: It is the master node that manages the file system namespace and regulates access to files by clients. It stores the metadata information of files such as file name, size, location, permissions, etc. It does not store the actual data of the file.

2. DataNodes: They are the slave nodes that store the actual data of the file. They communicate with the NameNode to perform operations on the file system, such as storing, retrieving, and replicating data.

#### Advantages of HDFS

1. Scalability: HDFS is designed to scale horizontally, which means that it can handle large data sets by adding more commodity hardware to the cluster.

2. Fault-tolerance: HDFS is fault-tolerant, which means that it can recover from hardware failures by replicating data across multiple DataNodes.

3. Cost-effective: HDFS uses commodity hardware, which is less expensive than specialized hardware.

#### Disadvantages of HDFS

1. Not suitable for small files: HDFS is not suitable for storing small files because it stores the data in blocks, and each block has a fixed size of 128 MB (by default). Therefore, if a file is smaller than 128 MB, it will still occupy the entire block, which is inefficient.

2. Not suitable for real-time data: HDFS is designed for batch processing, and it is not suitable for real-time data processing.

#### Examples of HDFS Applications

1. Social media analytics: HDFS is used to store and process large amounts of social media data, such as tweets, posts, comments, etc.

2. Log processing: HDFS is used to store and analyze log data generated by applications, servers, and network devices.

#### Conclusion

HDFS is a distributed file system that is designed to store and manage large data sets across clusters of commodity hardware. It provides scalability, fault-tolerance, and cost-effectiveness, making it an ideal choice for big data applications. However, it is not suitable for storing small files and real-time data processing.
