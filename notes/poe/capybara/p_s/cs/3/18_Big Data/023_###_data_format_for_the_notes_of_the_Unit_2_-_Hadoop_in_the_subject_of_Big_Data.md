### Data Format for the Notes of Unit 2 - Hadoop in the Subject of Big Data

In the world of Big Data and Hadoop, it is essential to understand the different data formats that are used to store and process large volumes of data. In this section, we will discuss the different data formats that are used in Hadoop.

#### 1. Text File Format
- The text file format is the most basic and widely used data format in Hadoop.
- It is a simple file format that stores data in a plain text format and is readable by humans and machines.
- Text files are easy to create, easy to read, and can be processed using standard Unix tools.

#### 2. Sequence File Format
- The sequence file format is a binary file format that is used to store key-value pairs in Hadoop.
- It is a compressed file format that is optimized for storing large volumes of data.
- Sequence files are commonly used in MapReduce jobs to store intermediate data.

#### 3. Avro File Format
- The Avro file format is a data serialization system that is used to store data in a compact binary format.
- It supports schema evolution, which means that the schema of the data can be changed over time.
- Avro files are commonly used in Hadoop for data serialization and deserialization.

#### 4. Parquet File Format
- The Parquet file format is a columnar storage format that is used to store structured data in Hadoop.
- It is optimized for query performance and storage efficiency.
- Parquet files are commonly used in Hadoop for storing large volumes of structured data.

#### 5. ORC File Format
- The ORC file format is a columnar storage format that is optimized for Hadoop workloads.
- It is designed to be highly efficient and supports advanced compression techniques.
- ORC files are commonly used in Hadoop for storing large volumes of data.

In conclusion, understanding the different data formats that are used in Hadoop is essential for processing large volumes of data efficiently. Each data format has its advantages and disadvantages, and choosing the right data format depends on the use case and the type of data that needs to be processed.
