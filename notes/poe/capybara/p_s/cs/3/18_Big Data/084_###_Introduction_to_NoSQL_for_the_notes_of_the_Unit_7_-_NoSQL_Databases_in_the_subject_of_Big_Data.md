### Introduction to NoSQL for the notes of the Unit 7 - NoSQL Databases in the subject of Big Data

NoSQL is a type of database that stands for "not only SQL." It is a type of database that is used to store and manage large volumes of unstructured and semi-structured data. Unlike traditional relational databases, NoSQL databases do not use a fixed schema, which makes them more flexible and scalable.

#### Characteristics of NoSQL Databases

Some common characteristics of NoSQL databases include:

- Flexible schema: NoSQL databases do not use a fixed schema, which means that they can easily adapt to changes in data structure and format.

- Scalability: NoSQL databases are designed to scale horizontally, which means that they can handle large volumes of data by adding more nodes to the database cluster.

- High availability: NoSQL databases are designed to be highly available, which means that they can continue to function even if one or more nodes in the database cluster fail.

- Distributed architecture: NoSQL databases are designed to be distributed across multiple nodes, which means that they can handle large volumes of data by partitioning the data across multiple nodes.

#### Types of NoSQL Databases

There are four main types of NoSQL databases:

- Document databases: These databases store data as JSON or XML documents, which can be nested and hierarchical.

- Key-value databases: These databases store data as key-value pairs, where each key is unique and maps to a value.

- Column-family databases: These databases store data as columns rather than rows, which makes them ideal for storing large volumes of data that require high write throughput.

- Graph databases: These databases store data as nodes and edges, which makes them ideal for storing data that has complex relationships.

#### Advantages of NoSQL Databases

Some advantages of NoSQL databases include:

- Scalability: NoSQL databases are designed to scale horizontally, which means that they can handle large volumes of data by adding more nodes to the database cluster.

- Flexibility: NoSQL databases do not use a fixed schema, which means that they can easily adapt to changes in data structure and format.

- High availability: NoSQL databases are designed to be highly available, which means that they can continue to function even if one or more nodes in the database cluster fail.

#### Disadvantages of NoSQL Databases

Some disadvantages of NoSQL databases include:

- Lack of ACID compliance: NoSQL databases do not support ACID (Atomicity, Consistency, Isolation, Durability) transactions, which can make it difficult to maintain data consistency.

- Limited querying capabilities: NoSQL databases do not support complex queries, which can make it difficult to extract information from the database.

#### Examples of NoSQL Databases

Some examples of NoSQL databases include:

- MongoDB (document database)

- Cassandra (column-family database)

- Redis (key-value database)

- Neo4j (graph database)

#### Applications of NoSQL Databases

NoSQL databases are commonly used in the following applications:

- Big data: NoSQL databases are designed to handle large volumes of unstructured and semi-structured data, which makes them ideal for big data applications.

- Web applications: NoSQL databases are often used in web applications that require high scalability and availability.

- Real-time analytics: NoSQL databases are often used in real-time analytics applications that require fast data processing and analysis.
