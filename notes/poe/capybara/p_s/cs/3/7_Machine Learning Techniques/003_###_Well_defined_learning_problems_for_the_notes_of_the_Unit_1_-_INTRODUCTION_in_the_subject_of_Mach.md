### Well defined learning problems for the notes of the Unit 1 - INTRODUCTION in the subject of Machine Learning Techniques.

Machine Learning is a subfield of Artificial Intelligence that enables machines to learn from data without being explicitly programmed. Machine Learning involves the use of algorithms that can learn patterns from data and make predictions or decisions based on that learning.

In this unit, we will focus on the basics of Machine Learning and the various types of learning problems. Here are some well-defined learning problems that we will cover in this unit:

1. **Supervised Learning:** In supervised learning, the machine is trained on a labeled dataset, where the correct outputs are given for each input. The goal is to learn a model that can predict the output for new inputs that it has not seen before. Some of the common supervised learning problems include:

- Classification: Predicting a categorical output variable, such as the species of a flower based on its features.
- Regression: Predicting a continuous output variable, such as the price of a house based on its features.

2. **Unsupervised Learning:** In unsupervised learning, the machine is trained on an unlabeled dataset, where there are no correct outputs given. The goal is to learn patterns or structure from the data. Some of the common unsupervised learning problems include:

- Clustering: Grouping similar data points together based on their features.
- Dimensionality Reduction: Reducing the number of features in the dataset while retaining as much information as possible.

3. **Reinforcement Learning:** In reinforcement learning, the machine learns through trial and error by interacting with an environment. The goal is to learn a policy that maximizes a reward signal. Some of the common reinforcement learning problems include:

- Game Playing: Learning to play games such as chess or Go by interacting with the game board.
- Robotics: Learning to control a robot to perform tasks such as walking or grasping objects.

In conclusion, understanding the various types of learning problems is crucial for developing effective Machine Learning models. In the subsequent units, we will dive deeper into each of these learning problems and discuss various algorithms and techniques used to solve them.
