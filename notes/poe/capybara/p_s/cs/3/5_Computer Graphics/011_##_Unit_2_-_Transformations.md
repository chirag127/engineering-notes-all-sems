## Unit 2 - Transformations

In this unit, we will study about the transformations of functions. A transformation is the process of changing the shape or position of a function. We use transformations to make changes to a function without having to change the function itself. This unit will help you learn how to identify the different types of transformations and how to apply them to a variety of functions.

### Types of Transformations

There are four types of transformations that we will study in this unit:

1. Translation
2. Reflection
3. Stretching
4. Compression

#### Translation

Translation is also known as shifting. It is the process of moving a function horizontally or vertically. A horizontal translation is done by adding or subtracting a constant from the x-coordinate of each point on the graph. A vertical translation is done by adding or subtracting a constant from the y-coordinate of each point on the graph.

#### Reflection

Reflection is the process of flipping the function across an axis. A reflection across the x-axis is done by multiplying the y-coordinate of each point on the graph by -1. A reflection across the y-axis is done by multiplying the x-coordinate of each point on the graph by -1.

#### Stretching

Stretching is the process of making a function taller or wider. A vertical stretch is done by multiplying the y-coordinate of each point on the graph by a constant greater than 1. A horizontal stretch is done by multiplying the x-coordinate of each point on the graph by a constant greater than 1.

#### Compression

Compression is the process of making a function shorter or narrower. A vertical compression is done by multiplying the y-coordinate of each point on the graph by a constant between 0 and 1. A horizontal compression is done by multiplying the x-coordinate of each point on the graph by a constant between 0 and 1.

### Advantages and Disadvantages

Advantages of using transformations include:

- They allow us to make changes to a function without having to change the function itself.
- They are easy to apply once you understand the different types of transformations.

Disadvantages of using transformations include:

- They can be confusing at first, especially if you are not familiar with the different types of transformations.
- They can lead to errors if you apply them incorrectly.

### Examples

Here are some examples of how to apply transformations to functions:

#### Example 1: Translation

Given the function f(x) = x^2, translate the function 2 units to the left.

Solution:

To translate the function 2 units to the left, we need to subtract 2 from the x-coordinate of each point on the graph. Therefore, the new function is f(x+2) = (x+2)^2.

#### Example 2: Reflection

Given the function f(x) = x^3, reflect the function across the x-axis.

Solution:

To reflect the function across the x-axis, we need to multiply the y-coordinate of each point on the graph by -1. Therefore, the new function is f(x) = -x^3.
