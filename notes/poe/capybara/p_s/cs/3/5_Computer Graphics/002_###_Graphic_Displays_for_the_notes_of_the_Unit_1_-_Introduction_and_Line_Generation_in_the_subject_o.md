### Graphic Displays for the notes of the Unit 1 - Introduction and Line Generation in the subject of Computer Graphics

Graphic displays are an essential component of computer graphics. They are used to display images and visual information on a computer screen. In this section, we will discuss the basics of graphic displays, including their types, components, and working principles.

#### Types of Graphic Displays

There are two types of graphic displays:

1. Vector Displays: Vector displays are used to display vector graphics. These graphics are generated by drawing lines and curves between specified points. Vector displays are commonly used in CAD systems and other technical applications.

2. Raster Displays: Raster displays are used to display raster graphics. These graphics are generated by dividing the screen into a grid of pixels and then assigning colors to each pixel. Raster displays are commonly used in gaming, video playback, and image editing applications.

#### Components of Graphic Displays

The main components of graphic displays include:

1. The Screen: The screen is the physical surface on which the image is displayed. It is made up of a grid of pixels for raster displays and phosphor dots for vector displays.

2. The Graphics Card: The graphics card is responsible for generating the image that is displayed on the screen. It contains a graphics processing unit (GPU) that performs calculations to create the image.

3. The Video Memory: The video memory is a dedicated memory space that stores the image data that is being displayed on the screen. It is used by the GPU to quickly access the image data and update the screen.

#### Working Principles of Graphic Displays

The working principles of graphic displays are different for vector and raster displays:

1. Vector Displays: Vector displays work by generating lines and curves between specified points. The coordinates of these points are stored in the computer's memory and are used to create the image. As the image is drawn, the phosphor dots on the screen are excited, creating a bright spot at each point.

2. Raster Displays: Raster displays work by dividing the screen into a grid of pixels. The GPU assigns colors to each pixel based on the image data stored in the video memory. The colors are then sent to the screen, where they are displayed as a series of dots.

#### Advantages of Graphic Displays

Some of the advantages of graphic displays include:

1. High-quality images: Graphic displays can produce high-quality images with excellent color accuracy and resolution.

2. Real-time rendering: Graphic displays can render images in real-time, making them ideal for gaming and other applications that require fast image processing.

3. Versatility: Graphic displays can be used in a wide range of applications, from gaming to CAD systems to medical imaging.

#### Disadvantages of Graphic Displays

Some of the disadvantages of graphic displays include:

1. Cost: High-quality graphic displays can be expensive, making them out of reach for some users.

2. Power consumption: Graphic displays consume a significant amount of power, which can be a concern for mobile devices.

3. Limited viewing angles: Some types of graphic displays have limited viewing angles, which can make it difficult for multiple users to view the screen at the same time.

#### Examples and Applications of Graphic Displays

Some examples and applications of graphic displays include:

1. Gaming: Graphic displays are used extensively in gaming, where they are used to render realistic 3D environments and characters.

2. CAD systems: Graphic displays are used in CAD systems to create and edit technical drawings.

3. Medical imaging: Graphic displays are used in medical imaging to display X-ray and MRI images.

In conclusion, graphic displays are an essential component of computer graphics. They are used to display images and visual information on a computer screen, and they can be either vector or raster-based. Graphic displays have many advantages, including high-quality images and real-time rendering, but they also have some disadvantages, such as cost and power consumption. They are used in a wide range of applications, from gaming to medical imaging.
