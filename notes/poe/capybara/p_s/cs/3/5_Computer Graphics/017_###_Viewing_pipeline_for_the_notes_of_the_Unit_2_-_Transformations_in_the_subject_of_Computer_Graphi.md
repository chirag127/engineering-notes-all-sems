### Viewing pipeline for the notes of the Unit 2 - Transformations in the subject of Computer Graphics

In the world of Computer Graphics, a Viewing Pipeline is a sequence of transformations that are applied to an object in order to transform it from its original state into a form that is suitable for display on a screen. This pipeline consists of several stages, each of which performs a specific task. In this article, we will discuss the Viewing Pipeline for the notes of the Unit 2 - Transformations in the subject of Computer Graphics.

The Viewing Pipeline consists of the following stages:

#### 1. Model Space
The first stage of the pipeline is the Model Space. This is the coordinate system in which the object is originally defined. The object is represented by a set of vertices that are defined in this space.

#### 2. World Space
The second stage of the pipeline is the World Space. In this stage, the object is transformed from the Model Space into the World Space. This transformation involves translating, scaling, and rotating the object. The resulting object is then defined in a new coordinate system that is relative to the world.

#### 3. View Space
The third stage of the pipeline is the View Space. In this stage, the object is transformed from the World Space into the View Space. This transformation involves moving the camera to a specific location and orienting it in a particular direction.

#### 4. Projection Space
The fourth stage of the pipeline is the Projection Space. In this stage, the object is transformed from the View Space into the Projection Space. This transformation involves applying a perspective projection or an orthographic projection to the object.

#### 5. Screen Space
The fifth and final stage of the pipeline is the Screen Space. In this stage, the object is transformed from the Projection Space into the Screen Space. This transformation involves mapping the 3D coordinates of the object onto a 2D plane, which corresponds to the screen.

Advantages of Viewing Pipeline:
- Provides a standardized way to transform and render 3D objects.
- Allows for efficient rendering of complex scenes.
- Enables the use of different types of projections, such as perspective and orthographic.

Disadvantages of Viewing Pipeline:
- Can be computationally expensive, especially for large scenes.
- Requires a significant amount of memory to store the transformed objects.

Applications of Viewing Pipeline:
- Video games
- Virtual reality and augmented reality
- Computer-aided design (CAD)
- Medical imaging

In conclusion, the Viewing Pipeline is an essential part of Computer Graphics. It enables the transformation and rendering of 3D objects, allowing for the creation of complex and realistic scenes. Understanding the different stages of the pipeline is crucial for anyone interested in the field of Computer Graphics.
