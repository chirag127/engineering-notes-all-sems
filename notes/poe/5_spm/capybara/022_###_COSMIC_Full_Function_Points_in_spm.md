### COSMIC Full Function Points in SPM

COSMIC Full Function Points is a method used in Software Project Management (SPM) to measure the functionality provided by a software system. It is a functional size measurement method that is used to measure the size of a software system by quantifying the functionality provided by that software system. The COSMIC Full Function Points method is based on the concept of a functional process.

The COSMIC Full Function Points method is used to measure the size of software systems that are data processing intensive, such as transaction processing systems, and not suitable for systems that are event-driven or real-time.

Here are some key points to remember about COSMIC Full Function Points in SPM:

1. Definition of a Functional Process: A functional process is defined as a sequence of processing steps that produces a result, typically an output. Each functional process has a specific input, processing, and output.

2. Counting the Function Points: The COSMIC Full Function Points method counts the function points by identifying the functional processes in the software system and then assigning a complexity value to each functional process based on the input, processing, and output characteristics.

3. Complexity Values: There are four complexity values that can be assigned to a functional process, namely, Simple, Average, Complex, and Very Complex. The complexity values are based on the number of input and output data items, the number of processing steps, and the degree of complexity of the processing logic.

4. Calculation of Function Points: The COSMIC Full Function Points method uses a formula to calculate the function points based on the complexity values assigned to the functional processes. The formula is as follows: Function Points = Sum of (Complexity Value x Weighting Factor).

Advantages of COSMIC Full Function Points: The advantages of using the COSMIC Full Function Points method are that it provides a standardized way of measuring the size of a software system, it is independent of the technology used to implement the software system, and it is based on the functionality provided by the software system.

6. Disadvantages of COSMIC Full Function Points: The disadvantages of using the COSMIC Full Function Points method are that it requires a detailed understanding of the functional processes in the software system, it can be time-consuming to count the function points, and it does not take into account the quality attributes of the software system.

The COSMIC Full Function Points method is used in software development projects to estimate the size of the software system, to plan and manage the software development process, and to measure the productivity and quality of the software development process.
