## Unit - 2 - Project Life Cycle and Effort Estimation for the notes of the course Software Project Management

Project life cycle refers to the stages that a project goes through from initiation to completion. Software projects, like any other projects, follow a life cycle. The life cycle of a software project consists of the following stages:

1. Planning: This is the first stage of the software project life cycle. During this stage, the project objectives, scope, strategies, and deliverables are identified. The project manager creates a project plan that outlines the tasks, timelines, resources, and budget required for the project.

2. Analysis: In this stage, the requirements of the software project are identified. The project team works with the stakeholders to understand their needs and expectations. The requirements are documented and a functional specification is created.

3. Design: During this stage, the software architecture is designed. The software components and their interactions are identified. The design is documented and reviewed to ensure that it meets the requirements.

4. Implementation: In this stage, the software is developed according to the design. The code is written, tested, and integrated. The software is also documented and reviewed.

5. Testing: During this stage, the software is tested to ensure that it meets the requirements. Different types of testing, such as unit testing, integration testing, and acceptance testing, are conducted.

6. Deployment: In this stage, the software is released to the users. The software is installed and configured on the user's system. Training and support are provided to the users.

7. Maintenance: Once the software is deployed, it enters the maintenance stage. During this stage, bugs and issues are fixed, updates and upgrades are released, and the software is improved based on user feedback.

Effort estimation is an important part of software project management. It refers to the process of estimating the amount of effort required to complete a software project. Effort estimation is important because it helps in planning, scheduling, and budgeting the project. There are different techniques for effort estimation, such as:

1. Expert judgment: In this technique, experts in the field of software development provide their estimates based on their experience and knowledge.

2. Analogous estimation: In this technique, the effort required for a new project is estimated based on the effort required for a similar project that was completed in the past.

3. Bottom-up estimation: In this technique, the effort required for each task in the project is estimated and then aggregated to arrive at the total effort required for the project.

4. Parametric estimation: In this technique, a mathematical model is used to estimate the effort required for the project based on the size, complexity, and other factors.

Mnemonics and learning tricks:

1. To remember the stages of the software project life cycle, you can use the acronym PADIM:
- Planning
- Analysis
- Design
- Implementation
- Testing
- Deployment
- Maintenance

2. To remember the different techniques for effort estimation, you can use the acronym EABP:
- Expert judgment
- Analogous estimation
- Bottom-up estimation
- Parametric estimation

By understanding the project life cycle and effort estimation techniques, software project managers can effectively plan, execute, and control software projects to ensure their successful completion.
