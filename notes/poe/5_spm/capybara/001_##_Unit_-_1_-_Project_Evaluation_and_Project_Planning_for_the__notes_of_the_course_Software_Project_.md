## Unit - 1 - Project Evaluation and Project Planning for the  notes of the course Software Project Management

In software project management, project evaluation and planning are crucial steps in ensuring the success of a project. In this unit, we will discuss the importance of project evaluation and planning and the different techniques used in these processes. 

### Project Evaluation

Project evaluation is the process of assessing the feasibility of a project before it is started. The following are some of the techniques used in project evaluation:

- Feasibility Study: A feasibility study is conducted to determine whether the project is technically, economically, and socially feasible.

- Cost-Benefit Analysis: A cost-benefit analysis is used to determine whether the benefits of the project outweigh its costs.

- Risk Analysis: A risk analysis is conducted to identify potential risks that may affect the project and to develop strategies to mitigate them.

### Project Planning

Project planning is the process of developing a plan for the project. The following are some of the techniques used in project planning:

- Work Breakdown Structure: A work breakdown structure is a hierarchical decomposition of the project into smaller, more manageable tasks.

- Gantt Chart: A Gantt chart is a bar chart used to represent the project schedule.

- Critical Path Method: The critical path method is a technique used to determine the critical path of the project, which is the sequence of tasks that must be completed on time in order for the project to be completed on schedule.

- PERT: Program Evaluation and Review Technique (PERT) is a technique used to estimate the time required to complete each task and the overall project duration.

- Resource Allocation: Resource allocation is the process of assigning resources to tasks in the project.

Overall, project evaluation and planning are critical steps in software project management. By using the appropriate techniques, project managers can ensure that their projects are feasible, well-planned, and completed on time and within budget.
