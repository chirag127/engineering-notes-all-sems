### Earned Value Analysis in spm

Earned Value Analysis (EVA) is a project management technique that measures the progress of a project against planned targets. It integrates the scope, schedule and cost performance to provide a comprehensive assessment of the project.

The key metrics used in EVA are:

- Planned Value (PV): The budgeted cost of work scheduled to be completed by a specific date.
- Earned Value (EV): The budgeted cost of work actually completed by a specific date.
- Actual Cost (AC): The actual cost incurred for the work completed by a specific date.

Using these metrics, the following variances can be calculated:

- Schedule Variance (SV) = EV - PV
- Cost Variance (CV) = EV - AC

SV indicates if the project is ahead or behind schedule while CV indicates if the project is under or over budget.

Based on SV and CV, the following indices can be determined:

- Schedule Performance Index (SPI) = EV/PV
- Cost Performance Index (CPI) = EV/AC

SPI < 1 indicates the project is behind schedule while SPI > 1 indicates the project is ahead of schedule.
CPI < 1 indicates the project is over budget while CPI > 1 indicates the project is under budget.

Tracking the EVA metrics and indices over time provides an indication of the health of the project and helps in taking corrective actions.

Some tips for learning EVA:

- Understand the meanings of PV, EV and AC which form the basis of EVA
- Memorize the formulae for SV, CV, SPI and CPI
- Practice calculating the metrics and indices for sample projects to understand their implications
- Note how SPI and CPI values less than 1 or greater than 1 impact the project
- Recognize that EVA provides an integrated view of scope, schedule and cost to assess project performance
