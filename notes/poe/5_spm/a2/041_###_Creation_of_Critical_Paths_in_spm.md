### Creation of Critical Paths in spm

The following points can be followed to create critical paths in spm:

1. Identify all the activities and tasks required to complete the project. Include their durations and dependencies. This forms the project network diagram.
2. Draw the network diagram. The activities can be represented by arrows and the dependencies by connecting the arrows.
3. Identify the critical path. The critical path is the longest path through the network diagram and has the least amount of slack or float. The activities on the critical path cannot be delayed without delaying the project completion time.
4. Note down the activities and durations on the critical path. These are the critical activities that need to be focused on and completed on time. Any delays will delay the project completion time.
5. Identify near-critical paths. These are paths very close to the critical path duration. Even small delays in activities on near-critical paths can delay the project. Although not as critical as the critical path, near-critical paths also need monitoring and completion on time.

To easily remember the steps, the following mnemonics can be used -

CP creation - Connecting Paths, Calculating Durations
NCP monitoring - Nearing Critical Paths, Must-Complete-On-Time

The advantages of determining the critical path are -
- It identifies the key activities that need to be focused on to complete the project on time.
- It provides a schedule for the project by determining the minimum project completion time. The critical path activities have to be completed on time for the project to finish by the determined schedule.
- It helps in resource allocation by determining the key activities that are critical. Resources can be allocated to the critical activities to avoid delays.

The above points and mnemonics can help in learning and understanding the creation of critical paths for exams. Detailed diagrams and examples can also be included if required for a particular topic.
