### COCOMO II in spm

COCOMO II is a model for estimating effort, cost, and schedule for software projects. It stands for Constructive Cost Model. It is an improved version of the original COCOMO model from 1981.

The key points about COCOMO II in spm are:

1. It categorizes software projects into three levels based on project complexity - Organic, Semi-Detached, and Embedded.
2. It estimates effort using Size metric ( thousand source instructions (KSI)) and a set of cost drivers that capture product, personnel, and project attributes.
3. It provides three estimation models - Application Composition Model (ACM) for rapid cost estimates, Early Design Model (EDM) for early lifecycle estimates, and Post-Architecture Model (PAM) for detailed estimates.
4. It considers cost drivers like reliability, database size, complexity, use of software tools, etc. that impact effort and cost.
5. It gives a more comprehensive and detailed estimation than the original COCOMO model.
6. It results in more accurate effort and cost estimates compared to the original COCOMO model if the cost drivers are estimated properly.

Some mnemonics to remember COCOMO II in spm:

- COCOMO II has 3 levels - Organic, Semi-Detached, Embedded
- 3 models - ACM, EDM, PAM
- Considers size metric and cost drivers
- More accurate than COCOMO I
