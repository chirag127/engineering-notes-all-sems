### COSMIC Full Function Points in spm

COSMIC stands for:

- **C**ommunication
- **O**utput
- **S**ubfiles
- **M**aster files
- **I**nput
- **C**nterfaces

These are the 6 full function points that are considered while estimating functional size using COSMIC Function Point Analysis method in Software Project Management (spm).

**Communication (C):** This includes data inputs and outputs for communication between systems or subsystems. For e.g. message queues, database access, etc.
**Output (O):** This includes outputs to users which can be reports, messages or screens.
**Subfiles (S):** These are subordinate files referenced by transactional functions like lookup tables or control files.
**Master files (M):** These are main files that contain core data like customer records, product catalogs, etc.
**Input (I):** This includes all inputs from users like screens, messages or data entry interfaces.
**Interfaces (C):** This includes inputs and outputs that cross system boundaries. For e.g. XML or web services interfaces.

Some mnemonics or learning tricks to remember COSMIC full function points:

- Think of Communication as inputs/outputs between systems.
- Output is what the user sees - reports or screens.
- Subfiles are lookup tables to support transactions.
- Master files store core/master data.
- Inputs are what the user sends to the system like data or screens.
- Interfaces connect systems/subsystems.

COSMIC function points are estimated based on number and complexity of these full function points which helps in estimating functional size and effort for software projects. It considers both internal and external interfaces which makes it a comprehensive function point analysis method.
