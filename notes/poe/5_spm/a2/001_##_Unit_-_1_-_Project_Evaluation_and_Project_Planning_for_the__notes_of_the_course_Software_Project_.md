## Unit - 1 - Project Evaluation and Project Planning for the  notes of the course Software Project Management

- Project evaluation is the process of examining a project to determine its viability, feasibility and profitability. It is done at the initial stages of a project to determine whether it should be undertaken or not. The key aspects evaluated are -
- Technical feasibility - Can the project be implemented with the available technology and resources?
- Economic feasibility - Will the project be profitable and generate adequate revenue to cover costs?
- Operational feasibility - Can the project be integrated with existing systems and processes?
- Schedule feasibility - Can the project be completed within a reasonable time frame?
- Project planning involves defining clear objectives and tasks, estimating resource requirements and timelines, and risk management to execute the project successfully. The key steps are -
- Define objectives and scope - Clearly define the goals and deliverables of the project.
- Breakdown structure - Decompose the project into smaller manageable components and tasks.
- Resource allocation - Estimate resource requirements for each task and procure resources.
- Create schedule - Estimate time required for each task and milestone and create project schedule.
- Risk analysis - Identify potential risks and impacts on schedule and budget and plan risk mitigation strategies.
- Mnemonics - PETER (Project Evaluation Techniques - Political, Economic, Technical, Environmental, Resource feasibility)

Planning pointers - SMART (Specific, Measurable, Achievable, Relevant, Time-bound) objectives, WBS (Work Breakdown Structure), Cs (Cost, Schedule, Control, Communication)

Advantages of project evaluation and planning -
- Increased chances of success by assessing viability and managing risks
- More efficient use of resources through proper planning and scheduling
- Better communication and coordination between stakeholders
- Flexibility to accommodate changes through iterative planning process

Disadvantages of project evaluation and planning -
- Requires time and effort, adds to project cost
- Difficult to estimate costs and timelines accurately
- Plans may not survive contact with reality, requires progressive elaboration
- Strict adherence to plans can reduce flexibility to changes
