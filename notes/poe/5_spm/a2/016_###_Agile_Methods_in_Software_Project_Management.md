### Agile Methods in Software Project Management

Agile methods in software project management focus on iterative and incremental development of software. Some of the popular agile methods are:

- **Scrum:** Scrum is one of the most popular agile frameworks. It divides the project into small iterations called sprints, typically lasting 2-4 weeks. Each sprint has a defined goal and includes tasks like planning, designing, developing and testing. Daily stand-up meetings are held to track progress. At the end of each sprint, the progress is evaluated and next steps are determined.
- **Extreme Programming (XP):** XP is an agile software development methodology which emphasizes on programming best practices like continuous testing, planning, designing and coding. Some key features of XP are:
    - Pair programming: Developers work in pairs which leads to continuous peer review and knowledge sharing.
    - Test-driven development: Writing tests before coding helps in fulfilling requirements and continuous feedback.
    - Small releases: Features are released in short development cycles.
- **Lean Software Development:** It focuses on delivering value to the customer by eliminating wastage. Some principles of lean software development are:
    - Eliminating waste - Only building features that add value.
    - Amplifying learning - Learning from mistakes and incorporating feedback.
    - Deciding as late as possible - Delaying decisions until the last responsible moment when the most information is available.
    - Delivering as fast as possible - Quick delivery of features to gain customer feedback.

Advantages of agile methods:
- Customer satisfaction - Continuous delivery of features and consideration of changing requirements.
- Quality software - Focus on testing and quick feedback loops.
- Adaptability to change - Flexibility to incorporate changes.

Disadvantages:
- Can be difficult to estimate costs and timelines.
- Requirement of skilled team and customer involvement.
- Process overhead due to additional meetings and planning.
