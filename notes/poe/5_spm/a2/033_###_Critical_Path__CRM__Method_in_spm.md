### Critical Path (CRM) Method in spm

The Critical Path Method (CPM) or Critical Path Analysis (CPA) is a project modeling technique to schedule activities and tasks. It is used to effectively manage time and resources in a project.

Key points to learn:

1. Identify all tasks and activities: List down all the tasks and activities required to complete the project. Breakdown complex tasks into smaller subtasks. Clearly define the dependencies between tasks.
2. Determine duration: Estimate the duration required to complete each task. Consider optimistic, most likely and pessimistic time estimates and use an expected duration.
3. Draw network diagram: Draw a network diagram or activity-on-node diagram to show the sequence of tasks and their dependencies. The arrows show dependencies and the circles represent tasks.
4. Identify critical path: The critical path is the longest sequence of dependent tasks which determines the shortest possible duration to complete the project. Any delay in the critical path tasks will delay the project completion. Mark the critical path tasks in the network diagram.
5. Calculate float: The float or slack time is the amount of time a task can be delayed without delaying the project completion. It is calculated as the difference between the early start and late start or early finish and late finish of a task. Non-critical path tasks will have float.
6. Update schedule: If there are any delays or changes, update the schedule by recalculating the early and late start and finish times and the float. This helps to keep the project on track and take corrective actions if required.

Advantages: Helps schedule projects and utilize resources efficiently. Identifies critical tasks and manages risks.
Disadvantages: Requires accurate duration estimates which can be difficult. Does not consider resource constraints. Static and does not accommodate changes well.
Applications: Used in project management for scheduling and monitoring projects with interdependent tasks.
