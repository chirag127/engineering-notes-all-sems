
### Creation of Critical Paths in spm

1. Critical Path Method (CPM) is a project management technique used to identify the order in which activities must be performed in order to complete a project on time.
2. It involves identifying all the tasks that must be completed, estimating the duration of each task, and determining the sequence of tasks.
3. CPM is used to identify the shortest possible duration of a project, and the activities that could cause the project to be delayed.
4. To create a critical path, all the activities must be identified and their duration estimated.
5. The sequence of activities is then determined, and the longest path of activities is identified as the critical path.
6. The critical path consists of the activities that have the longest duration and must be completed in order for the project to be completed on time.
7. The critical path can be represented graphically using a Gantt chart.
8. A Gantt chart shows the sequence of activities, their duration, and the start and end dates of each activity.
9. The critical path is represented by the longest path on the Gantt chart.
10. To ensure that the project is completed on time, it is important to monitor the progress of the activities on the critical path and take corrective action if any of the activities are delayed.
11. Mnemonic: CPM (Critical Path Method) is used to identify the order in which activities must be performed in order to complete a project on time.
