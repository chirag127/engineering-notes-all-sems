### Static Dictionary for the notes of the Unit 3 - Coding a sequence in the subject of Data Compression

- A static dictionary is a predefined list of symbols/words along with their corresponding codes.
- The encoder uses this static dictionary to encode the input sequence by searching for each symbol/word in the input sequence in the dictionary and encoding them with their corresponding codes.
- For example, a static dictionary can contain -

Symbol/Word | Code
