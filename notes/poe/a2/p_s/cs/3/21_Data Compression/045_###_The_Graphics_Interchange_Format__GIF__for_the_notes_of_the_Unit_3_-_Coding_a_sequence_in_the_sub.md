### The Graphics Interchange Format (GIF)

- GIF is a bitmap image format that was introduced by CompuServe in 1987.
- It uses lossless data compression technique to support color images.
- GIF supports up to 8 bits per pixel, allowing 256 colors to be displayed simultaneously from a palette of 24-bit (16.8 million) colors.
- The color limitation makes the GIF format unsuitable for reproducing color photographs and other images with color continuity, but it is well-suited for simpler images, such as graphics, line drawings or low-color clip art.
- The GIF format supports animation and is still widely used to provide image animation effects.
- A GIF image can be interlaced, which means that the image is first rendered at a lower resolution, and progressively higher resolutions are sent as the file is loaded, allowing the user to see a lower resolution version of the image sooner.
- The key advantage of the GIF format is that it offers good compression for certain kinds of images, in particular those with few colors, without loss of information. However, for photographs, PNG or JPEG are more suitable, as they support a wider range of colors.

-- Animated icons and logos on websites
-- Simple graphs and diagrams
-- Low color emoticons and avatars
