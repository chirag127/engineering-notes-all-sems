Non uniform Quantization:
- In non uniform quantization, the quantization intervals are not equally spaced. The quantization intervals are spaced in a way that provides finer quantization to the input values which are more probable and coarser quantization to the input values which are less probable. This leads to more efficient coding as the probability density function of the source is exploited.
- The quantization intervals and the representative levels are designed based on the Probability Density Function (PDF) of the input data. The intervals with higher probability density are allocated more number of levels, thereby achieving fine quantization and the intervals with lower probability density are allocated lesser number of levels, achieving coarse quantization.
- This leads to reduced quantization error for the input values which are more probable and higher quantization error for the input values which are less probable. From an average perspective, this may reduce the overall quantization error. However, the complexity of implementation increases as proper study of the input PDF is required to design the non uniform quantizer.
- Example: If the input is having a Laplacian PDF, the quantization intervals can be designed to be wider for the outer intervals and narrower for the inner intervals. This provides fine quantization for the input values near the peak of the PDF and coarse quantization for the values in the tails.
- Applications: Non uniform quantization is employed in applications where the input data follows a known PDF and reduction of average quantization error is desired even at the cost of increased complexity such as in speech coding. The speech signals are known to follow certain PDFs and non uniform quantizers can be designed specifically for speech data to achieve lower quantization errors.
