## Unit 3 - Coding a sequence

1. Sequence - A sequence is an ordered collection of elements. In Python, sequences are indexed using integers. The main types of sequences are:
- Lists - Lists are mutable sequences, typically used to store collections of homogeneous items.
- Tuples - Tuples are immutable sequences, typically used to store collections of heterogeneous items.
- Ranges - Ranges are immutable sequences of numbers. They are commonly used for looping a specific number of times.

2. Indexing and Slicing - We can access elements in sequences using indexing and slicing:
- Indexing - We index a sequence by placing the index of the desired element in squared brackets after the sequence. For example: my_list[0] accesses the first element.
- Slicing - We can extract subsequences from a sequence using slicing. For example: my_list[1:3] extracts elements at index 1 and 2 (the 3 is exclusive).

3. Traversing Sequences - We can traverse sequences in Python using loops:
- for loop - We can loop over each element in a sequence using a for loop. For example: for element in my_list.
- while loop - We can also use a counter variable with a while loop. For example: counter = 0; while counter < len(my_list): counter += 1.

4. Built-in Sequence Functions - Python provides a number of built-in functions to work with sequences:
- len() - Returns the length of a sequence.
- min() - Returns the minimum element of a sequence.
- max() - Returns the maximum element of a sequence.
- sum() - Sums all elements in a sequence.
