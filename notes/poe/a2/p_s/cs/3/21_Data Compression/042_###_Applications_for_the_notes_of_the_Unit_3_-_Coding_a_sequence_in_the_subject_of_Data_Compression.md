### Applications for the notes of the Unit 3 - Coding a sequence in the subject of Data Compression

1. Lossless compression:
- Used when no loss of information is acceptable. Ex: PNG image format, ZIP files, etc.
- Algorithms like Huffman coding, Run-length encoding, LZW coding, etc are used.
- The compression ratio is lower than lossy compression but the original data can be recovered exactly.

2. Lossy compression:
- Used when some loss of information is acceptable to achieve higher compression. Ex: JPEG image format, MP3 audio format, etc.
- Algorithms remove some data in a way that the remaining data is a close approximation of the original.
- Higher compression ratio than lossless compression but original cannot be recovered exactly.

3. Sequence coding:
- Used for compressing data that exhibits some sort of order or pattern like text, audio, video, etc.
- Algorithms find and eliminate redundancies to compress the data.
- Statistical methods and dictionary methods are commonly used like Huffman coding, Arithmetic coding, Lempel-Ziv coding, etc.
- Often used in combinations for better compression like JPEG image format uses Discrete Cosine Transform followed by Huffman coding.
