### Mathematical Preliminaries for Lossless compression

1. Entropy - Entropy is a measure of uncertainty associated with a random variable. It denotes the minimum number of bits needed to encode the outcomes of a random variable. The entropy of a data source gives the theoretical lower bound on the number of bits per symbol needed to encode the source.
2. Shannon's Source Coding Theorem - According to Shannon's source coding theorem, the entropy of a data source defines the minimum number of bits needed per symbol to encode the source losslessly. In other words, it is impossible to compress the data to fewer than H bits per symbol on average, where H is the entropy of the source. This provides a theoretical limit on the maximum compression that can be achieved.
3. Redundancy - Redundancy refers to any unnecessary repetition or wasted space in the data. Data compression works by removing redundancy from the data. The more the degree of redundancy in the data, the more the compression that can be achieved.
4. Parse Codes - A parse code is used to uniquely decode the compressed data by defining parsing or decoding rules. Each parsing rule identifies a specific sequence of bits in the compressed data and specifies how the bits should be translated into the original data. Huffman coding and Arithmetic coding use parse codes for lossless data compression.
