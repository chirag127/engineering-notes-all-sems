#### Image Compression

- Image compression is a type of data compression applied to digital images to reduce image file size. The amount of compression can be varied, allowing a tradeoff between storage size and image quality. Lossy compression methods provide the most compression but may lose some data. Lossless methods may compress less but retain all original data.
- Some advantages of image compression are:
- Reduced storage space required for images.
- Faster transmission of images over network.
- Some disadvantages of image compression are:
- Loss of image quality with lossy compression methods.
- Increased computational requirements to compress and decompress images.
- Common image compression techniques:
- JPEG - Joint Photographic Experts Group, lossy compression, removes spatial redundancy.
- PNG - Portable Network Graphics, lossless compression, removes spatial redundancy.
- GIF - Graphics Interchange Format, lossless compression, uses palette and run-length encoding.
- Image compression is used in applications like:
- Digital cameras to reduce image file size.
- Websites to reduce time to load images.
- Image and video streaming to enable transmission.
- Storage of medical and satellite images.
