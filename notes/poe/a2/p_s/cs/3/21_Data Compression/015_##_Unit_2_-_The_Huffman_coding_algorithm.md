## Unit 2 - The Huffman coding algorithm

- The Huffman coding algorithm is a lossless data compression algorithm. It encodes the input data/characters into variable-length bit sequences based on the frequencies of the characters.
- It works by constructing a binary tree of nodes where each node represents a character and has a frequency value. The least frequent characters are at the bottom of the tree and the most frequent characters are at the top.
- The binary codes are then generated by traversing the tree from the root to the leaves, assigning 0 for left child and 1 for right child. The most frequent characters get the shortest codes and the least frequent characters get the longest codes.
- This results in an efficient compression as the most commonly occurring characters are represented using fewer bits leading to a reduction in the total number of bits needed to represent the data.
- Example: For input characters A, B, C, D with frequencies 5, 9, 12, 13, the Huffman tree would be:

        *
        |
    (13) D
      /  \
    (12) C
      |
    (9) B
      \
       (5) A

- The Huffman codes for the characters would be:
A: 0
B: 10
C: 110
D: 111

- Hence, the string 'ABACA' would be encoded as '0110101'. This requires only 7 bits instead of the original 20 bits (4 characters x 5 bits per character) leading to compression.
- Advantages: Simple and efficient algorithm resulting in optimal compression.
- Disadvantages: The Huffman tree needs to be built and transmitted as overhead before the data can be decoded, which can be significant for small files.
- Applications: Used in lossless data compression techniques like PNG image format and DEC Special Graphics format.
