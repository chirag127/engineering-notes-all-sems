### Encoding procedure for the notes of the Unit 2 - The Huffman coding algorithm in the subject of Data Compression:

1. Gather the frequency of occurrence of each character in the input data. This can be done by scanning the input data and maintaining a count of each character.
2. Construct a leaf node for each character and assign the frequency of occurrence to it.
3. While there are more than one nodes in the tree, select the two nodes with the least frequency and create a new internal node with these two nodes as children and with a frequency equal to the sum of the two nodes' frequencies.
4. Repeat step#3 until only one node remains. This node is the root node and has the frequency of the entire message. This completes the construction of the Huffman tree.
5. Now, traverse the Huffman tree and assign a code to each input character. This is done by assigning '0' to a left child and '1' to a right child. This completes the encoding.
6. The encoded message is generated by replacing each character in the input message with its code.

Advantages:
- Optimal prefix codes: Huffman coding generates the most efficient prefix codes.
- Adaptive: It adapts to the changing frequency of characters. If the frequency changes, we can construct a new Huffman tree to generate the codes accordingly.

Applications:
- Data compression applications like file compression.
- Used in fax machines, modems, etc.
