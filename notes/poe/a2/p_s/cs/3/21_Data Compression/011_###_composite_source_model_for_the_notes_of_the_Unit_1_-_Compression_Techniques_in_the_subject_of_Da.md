### Composite Source Model
- A composite source model considers the input data as produced by multiple information sources.
- Each source produces data with certain characteristics like alphabet size, probabilities of symbols, correlation, etc.
- The encoders designed for composite sources aim to remove redundancy between multiple sources and achieve greater compression than encoding each source separately.
- For example, in text compression, the input can be considered as generated by two sources - one producing letters and other producing words. Jointly encoding letters and words can give better compression than separately encoding letters and words.
- The advantage is increased compression ratio. The disadvantage is increased complexity of the encoder and decoder.
- Applications include JPEG image compression, MP3 audio compression, etc. which take into account the characteristics of multiple sources like RGB components of image, spectral components of audio, etc. and achieve high compression by jointly encoding them.
