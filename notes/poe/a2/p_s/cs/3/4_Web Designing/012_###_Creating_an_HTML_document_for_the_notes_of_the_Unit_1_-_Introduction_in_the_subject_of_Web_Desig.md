### Creating an HTML document for the notes of the Unit 1 - Introduction in the subject of Web Designing

1. HTML stands for Hypertext Markup Language. It is the main markup language used to create web pages.
2. An HTML document contains HTML tags enclosed within angle brackets (< >). HTML tags are used to structure the web page and define its content.
3. The basic structure of an HTML document contains the following components:

- <!DOCTYPE> Declaration: It tells the browser what version of HTML the page is using.
- <html> Element: It is the root element that contains the entire HTML document. It includes the <head> and <body> elements.
- <head> Element: It contains title, metadata, and other information about the document. It includes the <title> element.
- <title> Element: It specifies the title of the HTML document. The title is displayed on the tab, window, or in the page's heading.
- <body> Element: It contains the visible page content that is displayed on the screen. It includes headings, paragraphs, images, links, etc.

4. A simple HTML document structure would look like:

<!DOCTYPE html>
<html>
<head>
<title>HTML Document</title>
</head>
<body>
</body>
</html>

5. The .html or .htm extension is used to save an HTML file. The file can be opened in a web browser to view the web page.
