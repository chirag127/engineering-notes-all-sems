### Attribute sector for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. CSS stands for Cascading Style Sheets.
2. CSS is used to style the HTML elements in a web page and control the look and feel of a web page.
3. Some advantages of using CSS are:

- It separates the presentation from the content. This makes it easier to maintain and update the web page.
- It reduces the amount of code in HTML files which makes the web pages load faster.
- It enables us to control the style of multiple HTML elements from one single rule.

4. Some key concepts of CSS are:

- Selector: Selects the HTML element which needs to be styled.
- Declaration: Includes properties and their values separated by a colon (:).
- Properties: Specifies the attribute of an element that needs to be styled like color, background, width, height, etc.
- Values: Specifies the value of a CSS property.

5. The three main ways of incorporating CSS into an HTML document are:

- Inline styles: Using the style attribute in HTML elements.
- Embedded or internal style sheet: Using a <style> element in the HTML document.
- External style sheet: Using a .css file and linking it with the HTML document.

6. CSS works based on cascading order which means that the importance of rules is calculated based on below factors:

- Type of rule: Inline style > Internal style sheet > External style sheet
- Specificity of selector
- Order of rules
