### Markup Tags

1. HTML uses markup tags to structure web pages and web applications. Markup tags are keywords (enclosed in angle brackets) that tell the browser what type of content they surround.
2. The basic structure of an HTML document consists of tags in pairs - an opening tag and a closing tag. The closing tag has a forward slash "/". For example:
<html> Opening tag
< /html> Closing tag
3. Some tags enclose other tags or text. For example:
<body> Opening tag
<h1>Heading</h1> Enclosed tag
<p>Paragraph text</p> Enclosed tag
</body> Closing tag
4. Empty elements are denoted using a single tag and include a forward slash inside the tag. For example:
<img /> - image tag
<br /> - line break tag
5. Attributes provide additional information about the content. They are placed inside the opening tag and include a name and value separated by an equals sign. For example:
<img src="image.jpg" alt="Image description" />
