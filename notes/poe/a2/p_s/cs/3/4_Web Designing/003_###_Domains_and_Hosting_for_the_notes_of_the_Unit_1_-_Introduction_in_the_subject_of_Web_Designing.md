#### Domains

- A domain is the unique web address (URL) to identify a website or web page on the internet. For example, "google.com" and "wikipedia.org" are domains.
- Domain names are selected by the website owners and are registered with a domain name registrar. The domain name must be unique and not already registered by someone else.
- Domain names make it easy to remember and access websites instead of using the website's IP address. They can be the name of the company or website, or related to the theme or purpose of the website.
- The extension in a domain name is called Top Level Domain (TLD) like .com, .net, .org, .in, etc. The domain name comes before the TLD.

#### Hosting

- Hosting refers to the service of storing the website files on a server and making it accessible on the internet.
- Websites are hosted on either shared hosting, VPS hosting, dedicated hosting or cloud hosting servers. The type of hosting depends on the website's requirements and budget.
- The main components of hosting are:

1. Server: The computer system that stores the website files and serves the website on the internet.
2. Storage: The disk space required to store the website files and database. More storage is needed for media-heavy and ecommerce websites.
3. Bandwidth: The amount of data that can be transferred between the server and the users. More bandwidth is needed for websites with large traffic.
4. Control panel: The interface to manage the website files, databases, emails, and other components. Popular control panels are cPanel, Plesk, DirectAdmin, etc.
5. Database: The database is used to store and manage data for websites like blogs, ecommerce stores, etc. Popular databases are MySQL, SQL Server, etc.

- The hosting provider ensures high availability of the server, security, and technical support to keep the website running efficiently. The choice of a reliable and suitable hosting provider is important for a website.
