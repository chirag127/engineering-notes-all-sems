### CSS Properties for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. Color Property - Used to set the color of the text and other properties like border, background, etc. It can be set by name (like red, blue), RGB value (like rgb(0,0,255)), Hex code (like #0000ff).
2. Font-family Property - Used to set the font face (like Arial, Verdana, Times New Roman). If the font is not available on the system, the browser sets a default font. Multiple fonts can be specified in a list and the browser picks the first available font.
3. Font-size Property - Used to set the size of the font in pixels (px), points (pt), em, percentage (%), etc. Default size is 16px.
4. Background Property - Used to set the background color of an element. The color can be set in various ways similar to the color property. Images can also be set as background using the background-image property.
5. Text-align Property - Used to set the horizontal alignment of the text like left, right, center, justify, initial, inherit.
6. Border Property - Used to set the border around an element. The width, style (solid, dotted, dashed, double, groove, ridge, inset, outset), and color of all the four sides can be set together or each side can be set separately.
