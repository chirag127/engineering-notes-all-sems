1. Forms: Forms are used to collect user input. They consist of form controls/elements wrapped in <form> tags.
- The <form> tag defines a form, and the form controls are placed inside the <form> element.
- The <form> element has an attribute called action which defines the URL where the input from the form will be sent for processing.
- The <form> element uses the method attribute to specify the HTTP method for sending the data to the server. The two most common values are GET and POST.

2. Form Controls: Form controls include input fields, textarea, buttons, checkboxes, radio buttons, etc. which allows users to enter data. Some important form controls are:
- <input>: The <input> element is the most used form control. It can be displayed in many ways, e.g. text field, checkbox, radio button, submit button, etc. The type attribute determines what type of input field to display.
- <textarea>: The <textarea> element defines a multi-line text input field. This is displayed as a rectangular box where the user can enter text.
- <button>: The <button> element defines a clickable button. The button can contain text or an image that carries out an action.
- <select>: The <select> element allows the user to select one or more options from a drop-down list. Options are defined using the <option> element.
- <optgroup>: The <optgroup> element is used to group related options in a drop-down list.

3. Form Attributes: Forms and form elements can have additional attributes to specify validation, styling, etc. Some important attributes are:
- required: Specifies that input is mandatory.
- pattern: Specifies a regular expression to validate the input.
- placeholder: Provides a hint/example to the user about what to enter.
- autofocus: Specifies that the input field should automatically get focus when the page loads.
- autocomplete: Specifies if the browser should autocomplete the field based on values entered by the user in the past.
