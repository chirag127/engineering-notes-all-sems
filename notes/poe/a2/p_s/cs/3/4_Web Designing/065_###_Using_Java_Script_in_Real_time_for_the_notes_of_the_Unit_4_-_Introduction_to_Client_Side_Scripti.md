### Using JavaScript in Real time for the notes of the Unit 4 - Introduction to Client Side Scripting in the subject of Web Designing

1. JavaScript is a lightweight, interpreted programming or scripting language that is typically embedded into web pages.
2. It allows web pages to be interactive and more dynamic.
3. JavaScript is used to create things like pop-up windows, interactive effects within web pages, form validation, and much more.
4. Some examples of using JavaScript in real time for client side scripting are:
    - Updating parts of a web page immediately without reloading the whole page. For example, updating the number of items in a shopping cart, updating the time on a web page, etc.
    - Validating web form data immediately as the user types without submitting the form. For example, checking if a username is available or if an email is in the proper format.
    - Creating dynamic and interactive effects within a web page such as image rollovers, drop-down menus, sliders, and much more.
5. The advantages of using JavaScript for client side scripting are:
    - Increased interactivity and dynamic behavior of web pages.
    - Immediate feedback to the user without reloading the page.
    - Forms can be validated instantly without submitting.
    - Basic tasks can be handled on the client side without contacting the server, thus speeding up web applications.
6. The disadvantages of using JavaScript for client side scripting are:
    - The code can be viewed and modified by users which poses a security risk.
    - The implementation and behavior may differ across browsers and platforms which can lead to compatibility issues.
    - JavaScript relies on the client machine and can be disabled, limiting functionality.
    - Complex applications may require significant coding and debugging effort.
