### Introduction for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. CSS stands for Cascading Style Sheets. It is a style sheet language used to describe the presentation of a document written in a markup language like HTML.
2. With CSS, you can control the layout of multiple web pages all at once by changing just one external CSS file. This will save a lot of time as you will not have to edit each page individually to change the look and feel.
3. CSS allows you to separate the content of HTML documents from the presentation. This means that the HTML file will contain the content and structure of the web page and the CSS file will contain the presentation styles like color, font, layout, etc. This separation of concerns makes it easier to maintain the web pages.
4. There are three ways of introducing CSS to an HTML document:
    1. External CSS - Using a separate CSS file with a .css extension and linking it to the HTML document using <link> tag.
    2. Internal CSS - Using a <style> tag in the head section of HTML document and writing CSS rules inside it.
    3. Inline CSS - Using the style attribute inside the HTML elements and writing CSS rules.
5. The precedence of CSS will be as per the above order, i.e. Inline > Internal > External. This means that the styles written inline will have the highest precedence, and the external CSS file will have the lowest precedence. If there are conflicts, the style with higher precedence will be applied.
6. CSS has a simple syntax of selector {property: value} where the selector can be a HTML element, class, id, etc. and property is the style attribute you want to change and value is the style value you want to assign to it.
