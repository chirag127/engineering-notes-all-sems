### Display for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. CSS stands for Cascading Style Sheets. It is used to style the web pages and provide a presentation to the web content.
2. CSS separates the presentation from the content of a web page. It is placed in the `<head>` section of an HTML document or in a separate CSS file with a `.css` extension.
3. The CSS rule-set consists of two main parts - the selector and the declaration block. The selector points to the HTML element you want to style. The declaration block contains one or more declarations separated by semicolons. Each declaration includes a CSS property and a value.
4. There are three ways to implement CSS - external CSS, internal CSS and inline CSS. External CSS is preferred as it keeps the HTML and CSS code separate.
5. There are many CSS properties like `color`, `background`, `font-size`, `font-family`, `width`, `height`, `border`, `margin`, `padding`, etc. to style various aspects of an HTML element.
6. The `display` property specifies what type of rendering box the element generates. It can have values like `block`, `inline`, `inline-block`, `none`, etc. `Block` elements occupy the full width of the screen and stack on top of each other. `Inline` elements only take up as much space as required to fit its content.
7. CSS applies styles in the following order -Inline style > External and internal style sheets > Browser default
8. The advantages of CSS are - simpler maintenance, bandwidth savings, device independence, accessibility, etc. The disadvantages are - cross browser compatibility issues and extra time required to learn.
