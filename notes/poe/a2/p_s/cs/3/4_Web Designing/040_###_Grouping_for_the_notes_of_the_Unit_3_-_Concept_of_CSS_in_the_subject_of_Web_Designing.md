### Grouping for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. CSS stands for Cascading Style Sheets. It is used to style the web pages and control the look and feel/appearance of web pages.
2. There are 3 ways to add CSS to HTML:

- Inline Styling: Using the "style" attribute in HTML elements. eg: <h1 style="color:blue;">Heading</h1>
- Internal Styling: Using <style> element in the HTML document. eg: <style> h1 {color: blue;} </style>
- External Styling: Using a separate .css file. eg: <link rel="stylesheet" href="styles.css">

3. CSS has a syntax of selector {property: value;}. The selector points to the HTML element to be styled and the property: value pair contains the style to be applied.
4. There are many CSS properties like color, background-color, font-size, text-align, etc to style various aspects of elements.
5. CSS rules can be specified:

- For all elements of a type: h1 { property: value; }
- For elements with a specific attribute: a[href] { property: value; }
- For elements nested within another element: div p { property: value; }
- Using classes: .className { property: value; }
- Using IDs: #idName { property: value; }

6. The cascading order of CSS is: Inline style > Internal style sheet > External style sheet > Browser default
7. Advantages of CSS:

- Faster loading web pages as styles are stored in one CSS file rather than in each HTML file.
- Easy maintenance as any change in styling can be done by editing one CSS file.
- Presentation separated from content (look separate from data)
- Multiple web pages can share one CSS file to have a common style.
