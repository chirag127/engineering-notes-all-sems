### Using FTP Client for the notes of the Unit 5 - Web Hosting in the subject of Web Designing

1. FTP or File Transfer Protocol is a client-server protocol used for transferring files between a local and a remote computer.
2. An FTP client is a software which is used to transfer files to and from a remote FTP server. Some popular FTP clients are FileZilla, WinSCP, Cyberduck, etc.
3. To transfer website files to a web server, we need to use an FTP client by entering the FTP server hostname, username and password. This allows us to access the file system on the web server and upload or download files.
4. The main advantages of using an FTP client are:
- It is easy and convenient to use. We just need to drag and drop files to upload and download.
- It provides a GUI to transfer files which is more intuitive than using FTP commands.
- We can resume interrupted file transfers.
- We have more control over file transfers like maintaining directories, deleting files, etc.

5. The disadvantages of using an FTP client are:
- The FTP protocol is not secure as the data and credentials are transmitted in plain text which can be sniffed by hackers.
- FTP clients are not suitable for transferring large files or multiple files at once.

6. To conclude, FTP clients are easy to use software to upload and download website files to and from a web server. However, due to security concerns, it is not recommended to use FTP and instead use secure protocols like SFTP or SCP for file transfers. FTP can still be used for small websites where security is not a major concern.
