HTML Documents
- HTML stands for Hypertext Markup Language.
- HTML is the main markup language used to create web pages.
- HTML uses tags like <html>, <head>, <title>, <body>, <h1>, <p>, etc. to structure a web page semantically.
- An HTML document must have an .html extension and contain basic structure including <!DOCTYPE html> declaration, <html> element, <head> element, and <body> element.
- The <!DOCTYPE html> declaration defines the document to be an HTML5 document.
- The <html> element is the root element that contains the <head> and <body> elements.
- The <head> element contains metadata about the HTML document including <title> element which specifies the title of the web page.
- The <body> element contains the visible page content including text, images, videos, etc.
- HTML documents are processed by web browsers to display web pages.
- Key features of HTML:
    - Platform independent
    - Supports multimedia
    - Easy to learn
    - SEO friendly
    - Free and open standard
