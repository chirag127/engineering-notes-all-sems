### Working with block elements and objects for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. Block elements:
- Block elements occupy the full width available to them and cause a line break before and after them.
- Examples: <div>, <p>, <h1> to <h6>, <form>, <table>, etc.
- Used for headings, paragraphs, divisions/sections, forms, tables, etc.
- Can be nested inside each other.

2. Inline elements:
- Inline elements occupy only the width they require and do not cause a line break.
- Examples: <span>, <a>, <img>, <input>, <label>, etc.
- Used for links, images, etc and to apply styles to portions of text.
- Cannot be nested inside block elements.

3. Block vs Inline:
- Block elements start on a new line and take up the full width available.
- Inline elements do not start on a new line and only take up the width they need.
- Correct nesting must be maintained.
- Display properties can be used to override the default display behaviour.
