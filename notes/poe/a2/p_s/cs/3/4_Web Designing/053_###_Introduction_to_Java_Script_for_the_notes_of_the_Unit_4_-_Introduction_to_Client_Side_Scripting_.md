### Introduction to Java Script

Java Script is a lightweight, interpreted programming or scripting language that is typically embedded into web pages. It allows web pages to be interactive and more dynamic. Java Script code is interpreted by a browser and executed by a JavaScript engine.

* Java Script is case sensitive.
* Java Script statements are executed in sequence.
* Java Script can be used to -
  * Validate forms
  * Detect browsers and their versions
  * Create cookies
  * Create popup windows
  * Redirect the browser to a new page
  * And much more.
* Java script can interact with -
  * HTML elements
  * CSS styles
  * The browser
  * The server
  * And more

Some important concepts in Java Script are -

* Variables - Used to store data values.
* Data types - String, Number, Boolean, Object, Null, Undefined, Symbol
* Operators - Arithmetic, Comparison, Logical, String, Conditional, etc.
* Control flows - if...else, switch, for, while, do...while loops
* Functions - To organize the code, reuse the code and abstract actions
* Objects - Everything in Java Script is an object. Used to model real world things.
* Arrays - Used to store multiple values in a single variable.
* Events - Occur when an action is performed (like click, mouseover, keypress, etc.)
* And more concepts...
