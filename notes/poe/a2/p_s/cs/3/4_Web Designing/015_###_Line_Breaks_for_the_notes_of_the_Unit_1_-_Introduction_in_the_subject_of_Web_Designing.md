### Line Breaks

- Line breaks are inserted using the <br> tag in HTML.
- It is used to move the next line of text to a new line.
- It does not require a closing tag.
- It is helpful in:

- Formatting poetry or addresses:

        This is a poem<br>
        written in two lines

- Aligning elements:

        Name:<br>
        ________________

- Improving readability:

        Step 1: Take the ingredients<br>
        Step 2: Mix them together<br>
        Step 3: Bake for 30 minutes

- Note: Though `<br>` tag inserts a line break, it does not add any spacing between the lines. Additional CSS styling can be used to add space between the lines if required.

antages:
- Easy to use
- Improves formatting and readability

Disadvantages:
- Does not allow to specify how the line break affects the layout (spacing between lines)
- Overuse can lead to messy formatting

Examples and applications:
- Used in addresses, poetry, lists, etc. to format the content neatly.
- Used to align form elements or other components.
