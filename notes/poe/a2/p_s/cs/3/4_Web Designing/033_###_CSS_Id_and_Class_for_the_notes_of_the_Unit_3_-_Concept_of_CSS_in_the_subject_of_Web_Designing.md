### CSS Id and Class

- Id and Class are ways to identify and select HTML elements for styling using CSS.
- An id can be used to uniquely identify an element. Only one id can be given to an element and ids should be unique within a page. Example: `<h1 id="heading">`
- A class can be used to identify a group of elements. A class can be reused multiple times in a page. Multiple classes can be given to an element separated by spaces. Example: `<h1 class="primary bold">`
- To select elements with id or class and apply styling, use the syntax:

```css
#id {
    /* styling */
}

.class {
    /* styling */
}
```

- Advantages: ids and classes allow separation of content and presentation. Styling can be done externally using CSS keeping the HTML file clean and presentational changes can be made easily by editing the CSS file.
- Disadvantages: Overuse of ids and classes can make the CSS file lengthy, complex and hard to maintain.
- Applications: ids and classes are fundamental concepts in CSS and are widely used to style web pages. They enable modular CSS and reusability of styles.
