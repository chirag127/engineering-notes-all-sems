Lists and Tables are two important concepts in CSS which are used to arrange and organize content in a structured way on a web page.

### Lists:

Lists are used to present a series of items in a linear fashion. There are three types of lists in CSS:

1. Ordered Lists: Used for lists where the order of items is important. Each item is marked with a number.

Example:
1. Item 1
2. Item 2
3. Item 3

Code:
<ol>
  <li>Item 1</li>
  <li>Item 2</li>
  <li>Item 3</li>
</ol>

2. Unordered Lists: Used for lists where the order of items is unimportant. Each item is marked with a bullet point.

Example:
• Item 1
• Item 2
• Item 3

Code:
<ul>
  <li>Item 1</li>
  <li>Item 2</li>
  <li>Item 3</li>
</ul>

3. Definition Lists: Used to present a list of terms and their definitions.

Example:
Term 1
Definition of Term 1

Term 2
Definition of Term 2

Code:
<dl>
  <dt>Term 1</dt>
  <dd>Definition of Term 1</dd>
  <dt>Term 2</dt>
  <dd>Definition of Term 2</dd>
</dl>

### Tables:

Tables are used to present data in a tabular format with rows and columns.

Example:

Name    Age
John     35
Jane     29
Jack     42

Code:
<table>
  <tr>
    <th>Name</th>
    <th>Age</th>
  </tr>
  <tr>
    <td>John</td>
    <td>35</td>
  </tr>
  <tr>
    <td>Jane</td>
    <td>29</td>
  </tr>
  <tr>
    <td>Jack</td>
    <td>42</td>
  </tr>
</table>
