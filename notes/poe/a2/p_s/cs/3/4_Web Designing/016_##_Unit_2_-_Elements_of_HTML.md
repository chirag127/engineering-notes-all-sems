## Unit 2 - Elements of HTML

1. HTML elements - HTML elements are the main building blocks of an HTML document. They consist of a starting tag and an ending tag with content in between. For example, <html> to </html>, <head> to </head>, <title> to </title>, etc. The tags enclose the element content. Some important elements are:

- <html> - defines an HTML document
- <head> - contains metadata about the HTML document
- <title> - specifies the title of the HTML document
- <body> - contains the visible page content
- <h1> to <h6> - specifies HTML headings of different sizes
- <p> - specifies a paragraph of text
- <br> - inserts a single line break
- <hr> - inserts a horizontal rule (thematic break)

2. HTML attributes - HTML elements can have attributes which provide additional information about the element. They are always specified in the starting tag. For example, <a href="https://www.example.com"> link </a> has an href attribute which specifies the URL. Some common attributes are:

- id - assigns a unique ID to an element
- class - assigns a class name to an element to apply CSS styling
- style - specifies inline CSS styles for an element
- src - specifies the source URL for images, videos, audio, etc.
- alt - provides alternate text for images
- width, height - specifies the width and height of elements

3. HTML structure - An HTML document has a typical structure which includes the <html>, <head> and <body> elements and some mandatory elements within <head> like <title>. A basic HTML skeleton is shown below:

```html
<!DOCTYPE html>
<html>
    <head>
        <meta charset="utf-8">
        <title>Page Title</title>
    </head>
    <body>
        <!-- page content here -->
    </body>
</html>
```
