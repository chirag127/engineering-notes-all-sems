### Dimension for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. CSS stands for Cascading Style Sheets.
2. CSS is a stylesheet language used to describe the presentation of a document written in HTML (or XML).
3. With CSS, you can control the styling of multiple web pages all at once by changing just one single CSS file.
4. Some advantages of CSS are:

- It separates the presentation from the content.
- It makes webpages load faster.
- It provides more accessibility.
- It offers more stylistic control.

5. There are three ways of implementing CSS:

- Inline styling - Using the "style" attribute in HTML elements.
- Internal stylesheet - Using a "style" element in the head section.
- External stylesheet - Using a .css file.
