1. Alert Box - Pops up a dialogue box with a message when a button is clicked or an event occurs.
Example:
<button onclick="alert('Hello')">Click Me</button>

Output: A dialogue box pops up with the message "Hello" when the button is clicked.

2. Confirm Box - Pops up a dialogue box with a message and two options (OK and Cancel). Returns true if OK is selected else returns false.
Example:
<button onclick="confirm('Confirm?')">Confirm</button>

Output: A dialogue box pops up with the message "Confirm?" having options OK and Cancel when the button is clicked.

3. Prompt Box - Pops up a dialogue box with a message and a text input field. Returns the input text entered or null if cancel is selected.
Example:
<button onclick="prompt('Enter text:')">Prompt</button>

Output: A dialogue box pops up with the message "Enter text:" and a text input field when the button is clicked. The input text is returned if OK is selected else null is returned if Cancel is selected.
