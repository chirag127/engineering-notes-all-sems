### Conditions Statements

Conditions statements are used to perform different actions based on different conditions. They are used to control the flow of execution of a script. The following are the types of conditions statements:

1. If statement: It is used to execute a block of code if a specified condition is true.

Syntax:
if (condition) {
  // block of code to be executed if the condition is true
}

Example:
if (x == 10) {
  console.log("x is equal to 10");
}

2. If... else statement: It is used to execute a block of code if the condition is true and another block of code if the condition is false.

Syntax:
if (condition) {
  // block of code to be executed if the condition is true
} else {
  // block of code to be executed if the condition is false
}

Example:
if (x == 10) {
  console.log("x is equal to 10");
} else {
  console.log("x is not equal to 10");
}

3. If... else if... else statement: It is used to execute different blocks of code for different possible conditions.

Syntax:
if (condition1) {
  // block of code to be executed if condition1 is true
} else if (condition2) {
  // block of code to be executed if condition2 is true
} else {
  // block of code to be executed if all conditions are false
}

Example:
if (x == 10) {
  console.log("x is equal to 10");
} else if (x == 20) {
  console.log("x is equal to 20");
} else {
  console.log("x is not equal to 10 or 20");
}
