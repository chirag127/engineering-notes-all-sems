### Navigation Bar for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. Introduction to CSS
- CSS stands for Cascading Style Sheets.
- CSS is used to style the web pages and specify the look and formatting of the content using style rules.
- It separates the presentation of the document from the structure/content of the document.
- The styles are typically stored in CSS files with .css extension or in external style sheets.
- The CSS rules or styles consist of selectors and declarations block.

2. Advantages of CSS
- It makes web pages attractive and stylish.
- It reduces the amount of HTML code required which makes web pages load faster.
- It provides a wide range of formatting options like colors, backgrounds, margins, fonts, positioning, transitions, etc. to customize the appearance and layout of web pages.
- The look and feel of an entire website can be changed just by editing the CSS file/style sheet.
- It allows for consistency of layout and appearance across multiple web pages.

3. How to add CSS to HTML
- Inline styles - Using the style attribute in HTML elements
- Internal style sheet - Using <style> element in the head section
- External style sheet - Using .css file and linking using <link> element
