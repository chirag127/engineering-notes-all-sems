### Working with Lists

Lists are used to present a sequence of items in an organized manner. There are three types of lists used in HTML:

1. Ordered Lists: They are lists where each item has a number. They are created using `<ol>` tag. Each list item starts with the `<li>` tag. Example:
<ol>
    <li>Item 1</li>
    <li>Item 2</li>
    <li>Item 3</li>
</ol>

Advantages: Use ordered lists when order is important (steps in a process, chronological order, etc.).

2. Unordered Lists: They are lists that use bullet points. They are created using `<ul>` tag. Each list item starts with the `<li>` tag. Example:
<ul>
    <li>Item 1</li>
    <li>Item 2</li>
    <li>Item 3</li>
</ul>

Advantages: Use unordered lists when order is not important (listing items, options, etc.).

3. Definition Lists: They are lists of terms and their definitions. They are created using `<dl>` tag. Each term uses `<dt>` tag and each definition uses `<dd>` tag. Example:
<dl>
    <dt>Term 1</dt>
    <dd>Definition 1</dd>
    <dt>Term 2</dt>
    <dd>Definition 2</dd>
</dl>

Advantages: Use definition lists to present a glossary or list of terms and definitions.

Lists can be nested to create complex structures. They provide an easy way to present related pieces of information in a clear and structured manner.
