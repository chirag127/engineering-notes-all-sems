### Javascript Types

The following are the basic data types in Javascript:

1. String - Used to represent text data. Written in double or single quotes like "Hello" or 'Hello'. Strings can be concatenated using + operator. Examples: 'Hello', "Hi", etc.
Advantages: Used to display text on web page, store names, etc.
Disadvantages: Cannot perform mathematical calculations on strings directly.

2. Number - Used to represent numeric data. Can be integers or floating point values. Examples: 10, 3.14, -99, etc.
Advantages: Used for mathematical calculations.
Disadvantages: Different machines may have different precision for floating point numbers which can lead to rounding errors.

3. Boolean - Used to represent logical entities and can have only two values - true or false. Examples: true, false
Advantages: Used in control flows and logical operations.
Disadvantages: Can only have two values which may be limiting in some cases.

4. Object - Used to represent more complex data structures. Examples: Array, Date, RegExp, etc.
Advantages: Provides flexibility and modularity.
Disadvantages: Objects can be more complex to understand and work with.

5. Array - A special type of object used to represent ordered lists of data. Stores multiple values in a single variable. Written with square brackets []. Examples: [1, 2, 3], ['Hello', 'Hi']
Advantages: Used when working with multiple values, provides easy indexing.
Disadvantages: Size is fixed, less efficient than objects if frequent additions/removals are required.

6. Null - Represents unknown or non-existent value. There is only one null value. Example: null
Advantages: Used to represent absence of value.
Disadvantages: Can be confused with undefined value.

7. Undefined - Represents unassigned value. There is only one undefined value. Example: undefined
Advantages: Used to represent unavailability of value.
Disadvantages: Can be confused with null value.
