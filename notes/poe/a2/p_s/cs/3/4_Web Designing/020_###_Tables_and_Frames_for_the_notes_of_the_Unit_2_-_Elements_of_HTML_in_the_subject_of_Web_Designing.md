### Tables

- Tables are used to display data in a structured format with rows and columns.
- The `<table>` element is used to create a table. The `<tr>` element is used to create each row (`tr` stands for `table row`).
- The `<th>` element is used to create the headings and the `<td>` element is used to create the data cells.
- Attributes like `border`, `cellpadding`, `cellspacing`, `width`, `height`, `bgcolor`, etc. can be used to control the appearance of tables.
- Example:

```html
<table border="1">
  <tr>
    <th>Name</th>
    <th>Roll No.</th>
  </tr>
  <tr>
    <td>John</td>
    <td>12</td>
  </tr>
  <tr>
    <td>Jack</td>
    <td>18</td>
  </tr>
</table>
```

- Output:

| Name | Roll No. |
|
