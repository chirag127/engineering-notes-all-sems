### Border properties for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. Border-style: It defines the style of the border of an element. It can have values like solid, dotted, dashed, double, groove, ridge, inset, outset, none, hidden, etc.

- Solid: Uniform line.
- Dotted: Series of dots.
- Dashed: Series of short lines.
- Double: Two solid lines.
- Groove: 3D grooved effect.
- Ridge: 3D ridged effect.
- Inset: Element looks embedded.
- Outset: Element looks coming out.
- None: No border.
- Hidden: Same as none but disturbs layout.

2. Border-width: It defines the width of the border of an element. It can be in px, em, %, etc. Default value is 'medium'.

3. Border-color: It defines the color of the border. The value can be a color name or RGB value or Hex value, etc. Default value is the color of the text.

4. Border-radius: It is used to create rounded corners for border-box. The value can be in px, %, em, etc.

5. Syntax:

border: border-width border-style border-color;

border: 1px solid black;

Example:
```
div {
  border-style: dotted;
  border-width: 2px;
  border-color: white;
  border-radius: 10px;
}
```
