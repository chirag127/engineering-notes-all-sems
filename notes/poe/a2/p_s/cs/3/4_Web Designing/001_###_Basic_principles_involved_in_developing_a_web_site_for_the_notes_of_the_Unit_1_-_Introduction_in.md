### Basic principles involved in developing a web site for the notes of the Unit 1 - Introduction in the subject of Web Designing:

1. Planning and Designing:
- Deciding the purpose and goal of the website. What content is to be included? Who is the target audience?
- Creating sitemaps, flowcharts and mockups of the website structure and layout. Choosing suitable design elements, color schemes, fonts, images, etc.
- Planning for responsiveness and compatibility for multiple devices and screen sizes.

2. Choosing Suitable Technology:
- Selecting a suitable programming language like HTML, CSS, JavaScript, PHP, etc. based on the website requirements and complexity.
- Choosing a suitable web hosting service and domain name.
- Selecting appropriate frameworks, libraries, software and tools to ease the development process.

3. Implementation:
- Writing clean and structured code for the website using the chosen technology and languages.
- Implementing the planned design and including the content.
- Testing the website for responsiveness, functionality, performance, security issues, cross-browser compatibility, etc. and fixing any bugs or issues.

4. Deployment:
- Deploying the final website to the web server.
- Setting up security features and regular maintenance procedures.
- Continuously testing, updating and optimizing the website.

The above points cover the basic principles involved in developing a simple informational website. More complex websites would include additional principles like database integration, ecommerce features, user accounts, etc.
