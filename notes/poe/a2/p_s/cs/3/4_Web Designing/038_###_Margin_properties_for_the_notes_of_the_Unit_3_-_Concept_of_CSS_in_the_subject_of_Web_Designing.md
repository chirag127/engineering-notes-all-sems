### Margin properties for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. Margin: It refers to the transparent area that surrounds an element. It is outside the border.
- Margin clears an area around an element. It does not have a background color.
- It is used for spacing between elements to properly organize layout.
- Margin can be set using margin property which has values for top, right, bottom and left sides.
- Negative values can be used to overlap elements.

Syntax:
margin: [top] [right] [bottom] [left];

Example:
margin: 10px 20px 30px 40px;  /* top 10px, right 20px, bottom 30px, left 40px */

Advantages:
- Ensures proper spacing between elements.
- Used for alignment using auto value and centering blocks.
- Overlapping elements using negative values.

Disadvantages:
- Too much margin can lead to extra spacing and messy layout.
- Differing margin values on sides can make elements look unaligned.

Applications:
- Reusable layout components.
- Photo galleries.
- Forms.
- Navigation bars, etc.
