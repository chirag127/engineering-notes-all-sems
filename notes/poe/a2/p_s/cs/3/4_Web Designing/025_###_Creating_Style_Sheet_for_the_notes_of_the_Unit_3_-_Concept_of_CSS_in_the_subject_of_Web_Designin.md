### Creating Style Sheet for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. Creating a CSS file:
- Create a file with .css extension, for example, myStyles.css
- You can name the CSS file anything you like, as long as it has the .css extension
- The CSS file should contain only CSS rules and no HTML tags

2. CSS syntax:
- A CSS rule consists of a selector and a declaration block
- The declaration block consists of declarations separated by semicolons
- Each declaration includes a property and a value separated by a colon
- For example: selector {property1:value1; property2:value2}

3. Linking CSS to HTML:
- There are three ways to link a CSS file to an HTML file:
- External CSS: using <link> element in the HTML head
- Internal CSS: using <style> element in the HTML head
- Inline CSS: using style attribute inside the HTML elements

Advantages of using CSS:
- It separates style from content making it more manageable
- It enables you to control the layout and style of multiple web pages from one file
- bandwidth is reduced as CSS files are cached, and
- It makes web pages more accessible to people with disabilities

Disadvantages of using CSS:
- There is a steep learning curve to learn CSS
- Troubleshooting errors can be difficult
- Rendering issues can occur across different browsers
- Additional time is required to create CSS and ensure cross-browser compatibility
