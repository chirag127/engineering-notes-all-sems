### Creating page Layout and Site Designs

- Page layout refers to the structural design of a web page. It includes arrangement of major sections of a page like header, footer, navigation bar, content, sidebar, etc.
- Site design refers to the visual appearance of a website which includes choice of colors, fonts, images, interface elements, etc.
- For creating page layouts and site designs, CSS is used. Some key concepts of CSS for this are:

1. CSS selectors: Selectors are used to select the HTML elements to be styled. Different types of selectors like element selectors, id selectors, class selectors, universal selector, etc. are used.
2. CSS properties: There are hundreds of CSS properties available to style the elements like color, background, font-size, margin, padding, display, visibility, etc. These properties can have different values to create the desired style.
3. CSS positioning: Positioning refers to the arrangement of elements. Elements can be positioned using different positioning techniques like static, relative, absolute, fixed, sticky positioning. This is used to create layouts and align elements.
4. CSS floats and clears: Floats are used to take an element to the left or right of its container, allowing text and other elements to wrap around it. Clears are used to prevent an element from wrapping around a floated element. These are helpful in creating multi-column layouts.
5. CSS frameworks and libraries: There are many CSS frameworks and libraries available like Bootstrap, Materialize, Foundation, etc. which provide ready-to-use styles and components to easily create responsive layouts and site designs.

The above concepts can be used in different ways with a combination of HTML to create unique page layouts and attractive site designs for a web page. Examples and coding practice can help understand the implementation details.
