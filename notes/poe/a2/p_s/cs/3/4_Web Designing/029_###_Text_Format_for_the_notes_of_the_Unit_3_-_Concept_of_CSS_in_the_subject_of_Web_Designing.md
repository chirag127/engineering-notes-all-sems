### Text Format for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. CSS stands for Cascading Style Sheets. It is a language used to style an HTML document.
2. CSS separates the presentation of a document from the structure. This means that the HTML file contains the structure of the page and the CSS file contains the style information.
3. The advantages of using CSS are:

- It makes web pages more accessible.
- It saves time as you only need to specify the style once in a CSS file, rather than on every HTML element.
- It allows for faster download speeds as the CSS file is cached, and the browser does not need to re-download the CSS file if it has already been downloaded.
- It keeps the content and presentation separate, making web pages more maintainable.

4. There are three ways to insert CSS into an HTML document:

- External CSS: The CSS is stored in a separate .css file and linked to the HTML document using a <link> tag in the head section.
- Internal CSS: The CSS is included within a <style> element, inside the head section of the HTML document.
- Inline CSS: The CSS is included directly on the HTML element using the style attribute.

5. A CSS rule contains two main parts: a selector and a declaration block.

- The selector points to the HTML element you want to style.
- The declaration block contains one or more declarations separated by semicolons.
- Each declaration includes a property and a value, separated by a colon.

For example:
h1 {
  color: blue;
  font-size: 30px;
}

Here, h1 is the selector, and the part inside the curly braces is the declaration block containing two declarations for the properties color and font-size.
