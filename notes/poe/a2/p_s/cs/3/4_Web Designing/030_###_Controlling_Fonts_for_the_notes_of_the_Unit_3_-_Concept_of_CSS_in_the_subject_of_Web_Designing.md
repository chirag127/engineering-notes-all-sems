### Controlling Fonts for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. Font-family: This property is used to specify the font face to be used for the text. The value can be a font family name like "Times New Roman", "Arial", etc. or a generic family like serif, sans-serif, monospace, cursive, etc. Multiple font names can be specified as a list to set priority if a particular font is not available.

```
p {
  font-family: "Times New Roman", serif;
}
```

2. Font-size: This property sets the size of the font. It can be set in absolute units like px, pt, cm, etc. or in relative units like em, rem, etc. Larger the size, larger will be the text displayed.

```
h1 {
  font-size: 2em;
}
```

3. Font-style: This property is used to make the text italic or normal. The values can be normal, italic or oblique.

```
h2 {
  font-style: italic;
}
```

4. Font-weight: This property sets the boldness/thickness of the text. The values can be normal, bold, bolder, lighter, 100, 200, 300, 400, 500, 600, 700, 800, 900. Higher the value, bolder will be the text.

```
h3 {
  font-weight: bold;
}
```

5. Text-transform: This property is used to specify capitalization effects on text. The values can be none, capitalize, uppercase, lowercase. Capitalize converts the first letter of each word to capital, uppercase converts all letters to capitals and lowercase converts all letters to small letters.

```
p {
  text-transform: uppercase;
}
```
