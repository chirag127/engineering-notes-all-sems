### Pseudo class

Pseudo classes are used to define a special state of an element. They are denoted by a colon (:) followed by the pseudo class name.

Some commonly used pseudo classes are:

1. :hover - Used to define a style for an element when the user mouses over it.

For example:
a:hover {
  color: red;
}

This will change the color of the link to red when the user hovers the mouse over it.

2. :focus - Used to define a style for an element when it gains focus.

For example:
input:focus {
  background-color: yellow;
}

This will highlight the input field in yellow when it gains focus (when the user clicks or tabs into the input).

3. :visited - Used to define a style for a link that has already been visited by the user.

For example:
a:visited {
  color: purple;
}

This will change the color of visited links to purple.

4. :first-child - Used to define a style for the first child element of its parent.

For example:
div p:first-child {
  color: blue;
}

This will change the color of the first paragraph inside a div to blue.

5. :last-child - Used to define a style for the last child element of its parent.

For example:
div p:last-child {
  color: blue;
}

This will change the color of the last paragraph inside a div to blue.
