### Validation of Forms

- Form validation is the process of checking whether the input values entered by the user in a form are correct or not before submitting the form.
- This is done to ensure that the input data is in the correct format and fit for processing.
- Some common things checked during form validation are -

- Checking if all the mandatory fields are filled
- Confirming if the entered email address is in the correct format
- Verifying if the entered number is indeed a number and in the valid range
- Matching the confirmed password with the original password
- And more based on the requirements

- Form validation can be done on both the client-side (browser) and the server-side.
- Client-side validation is done using JavaScript. It verifies the input data instantly without the need to send it to the server. This provides a better user experience with instant feedback.
- However, the values can be manipulated on the client-side, so the final validation is always done on the server-side using server-side scripts for security.
- Some advantages of form validation are -

- It provides a good user experience with instant feedback
- It prevents invalid data from getting submitted and wasting resources
- It increases the security of the application by filtering out malicious input
- It can give useful tips to the user to correct the errors

- Some common validation techniques are -

- Required field validation - Checking for empty fields
- Data type validation - Checking if the data is of the correct type like email, number, etc.
- Length validation - Checking if the data is of the correct length
- Range validation - Checking if the number is in the correct range
- Match validation - Checking if two fields match, like in the case of passwords
- Custom validation - Validating based on custom rules
