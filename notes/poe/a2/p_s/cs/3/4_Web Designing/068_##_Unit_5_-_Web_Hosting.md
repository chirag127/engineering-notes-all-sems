## Unit 5 - Web Hosting

Web hosting refers to the service of allowing individuals and organizations to make their website accessible via the World Wide Web. Here are the key points about web hosting:

1. Web hosts provide space on their servers for websites and also provide connectivity to the Internet for serving the webpages to users.
2. The main types of web hosting are:
    - Shared hosting: Multiple websites are hosted on the same server sharing the resources. Cheap but performance can be affected by other websites on the same server.
    - Dedicated hosting: Entire server is rented for hosting a single website. More expensive but provides more resources and better performance.
    - VPS hosting: A virtual private server is allocated for hosting. Provides more control and resources than shared hosting but at a lower cost than dedicated hosting.
    - Cloud hosting: Website is hosted on virtual servers that pull resources from a large pool of physical servers. Scalable and reliable.
3. Important factors to consider when choosing a web hosting service:
    - Reliability and uptime: Choose a host with minimum downtime and good reliability.
    - Speed and performance: Hosting plan should provide good speed and load times for your website.
    - Storage and bandwidth: Sufficient storage space and data transfer for your website needs.
    - Security: Robust security to protect against vulnerabilities and attacks.
    - Support: Good customer support in case of any issues.
    - Cost: Choose a plan that fits your budget.
4. Popular web hosting companies include Bluehost, HostGator, DreamHost, Hostwinds, etc.
