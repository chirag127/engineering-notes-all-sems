 Here are the notes in markdown format for the topic ### Heading-Paragraphs for the Unit 1 - Introduction in the subject of Web Designing:

1. Headings: Headings are used to highlight important topics and sections in a document. They make the content easy to skim and navigate. There are 6 heading levels in HTML - <h1> to <h6>. <h1> is the highest (most important) level and <h6> is the lowest (least important) level.

**Example:**
<h1>Heading Level 1</h1>
<h2>Heading Level 2</h2>
<h3>Heading Level 3</h3>

**Advantages:**
- Proper use of headings improves accessibility and SEO of a web page.
- They make the content easy to organize, navigate and skim through.

2. Paragraphs: Paragraphs are groups of sentences that discuss a main idea. In HTML, paragraphs are denoted using the <p> tag. Some key points to keep in mind while writing paragraphs:

- Each paragraph should focus on one main idea.
- Use transition words/phrases to connect paragraphs and make the flow smooth.
- Keep paragraphs short and focused. Long paragraphs can make text difficult to read.
- Leave a blank line between paragraphs to separate them.

**Example:**
<p>This is a paragraph about web designing. Web designing refers to the process of creating websites. It includes aspects such as page layout, user interface design, and graphics.</p>
<p>The next paragraph discusses the key skills required for web designing. Creativity, technical skills, and communication skills are essential to be a good web designer.</p>

**Advantages:**
- Paragraphs make long-form content easy to read and comprehend.
- They bring structure and flow to web content.
- Paragraphs are crucial for accessibility as screen readers interpret paragraphs as separate chunks of information.
