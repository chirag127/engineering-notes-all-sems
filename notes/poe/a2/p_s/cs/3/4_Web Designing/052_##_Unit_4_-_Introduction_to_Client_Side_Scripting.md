## Unit 4 - Introduction to Client Side Scripting

Client side scripting refers to the scripts that are executed on the client side (web browser) rather than on the server. Some of the key points about client side scripting are:

1. Scripts are embedded in the HTML pages - The scripts are included within the HTML pages, inside the <script> tags. When the web page is loaded, the script is executed automatically.
2. Scripts are interpreted by the browser - The client side scripts are interpreted and executed by the web browser rather than the server. So the scripts are lightweight and execute faster.
3. Used for dynamic interactions - Client side scripts are commonly used to create dynamic interactions on web pages without performing a postback to the server. Some examples are:

- Validating web form data
- Generating dynamic content
-reacting to user events like mouse clicks, button clicks etc.
- Using AJAX to send and receive data from the server

4. Types of client side scripts - The popular types of client side scripts are:

- JavaScript - JavaScript is the most popular client side scripting language. It can be used to create dynamic effects, validate forms, detect browsers etc.
- VBScript - VBScript is a lightweight version of Visual Basic used to create web page interactivity. It is supported only on IE.
- JScript - JScript is Microsoft's implementation of JavaScript. It is similar to JavaScript but some features may differ in JScript.

The key advantages of client side scripting are speed and interactivity. The disadvantages are that the scripts can be viewed and modified by users and they may face compatibility issues across different browsers and platforms.
