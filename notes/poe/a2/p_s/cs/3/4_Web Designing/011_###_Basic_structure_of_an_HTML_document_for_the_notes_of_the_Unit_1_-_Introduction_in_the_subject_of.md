### Basic structure of an HTML document

An HTML document consists of a tree of elements with root element <html>. Each element has opening tag, content and closing tag.

- <html> - root element
    - <head> - contains metadata about the document
        - <title> - title of the web page
    - <body> - contains the visible page content
        - <h1> - main heading
        - <p> - paragraph
        - <img> - image
    - </body>
- </html>

Key points:

1. An HTML document starts with <!DOCTYPE> declaration which tells the browser what version of HTML the page is using.
2. The <html> element contains two sub-elements - <head> and <body>.
3. The <head> element contains the title of the page, meta information, scripts, etc. It is not visible on the page.
4. The <body> element contains the visible content of the web page like text, images, videos, etc.
5. Tags are enclosed in angle brackets (<>). Some elements have opening and closing tags (<p></p>). Some have only an opening tag (<img>).
6. Attributes provide additional information about elements and are specified in the opening tag (eg. <img src="image.jpg">).
7. Elements can be nested within each other in a hierarchical structure.

Advantages:

- Easy to learn and read.
- Platform independent and works on all browsers.
- Separates presentation from content.

Disadvantages:

- Limited styling and layout options.
- Difficult to maintain complex websites.
- Vulnerable to attacks if not written properly.

Applications:

- Creating web pages.
- Structuring web content.
- Displaying multimedia on web.
- Connecting web pages through hyperlinks.
