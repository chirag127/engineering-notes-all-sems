JS Popup Boxes

- JavaScript popups are message boxes/dialog boxes that pop up on a web page and can be used to display messages, get user input, etc.
- They are created using the JavaScript alert(), confirm() and prompt() functions.
- Alert Box - Displays a message and an "OK" button. Used to display a message to the user.
- Confirm Box - Displays a message and "OK" and "Cancel" buttons. Used to get confirmation from the user. Returns true for "OK" and false for "Cancel".
- Prompt Box - Displays a message and a text input field. Used to get input from the user. Returns the input text or null if "Cancel" is clicked.

Advantages:
- Easy to implement and display.
- Do not require much code.
- Common and familiar to users.

Disadvantages:
- Limited styling and customization options.
- Prone to pop-up blockers.
- Not suitable for complex user interactions.

Applications:
- Display error/status messages.
- Get user confirmation for actions.
- Get simple user input.

Example codes:

Alert box:
alert("Hello! I am an alert box.");

Confirm box:
confirm("Are you sure?");

Prompt box:
prompt("Enter your name: ");
