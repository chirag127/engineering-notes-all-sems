## Unit 1 - Introduction

1. Introduction to Computing - Computing is the process of using and developing components and systems to solve problems. It includes both software and hardware components. Software is the set of instructions that tell the hardware what to do to solve a problem or achieve some goal. Computing has transformed society with applications such as automation, artificial intelligence, mobile computing, and more.

2. Binary Number System - Computers can only understand 0s and 1s, which is known as binary. The binary number system is a base-2 number system that uses only two digits, 0 and 1. Each binary digit represents a power of 2 (20, 21, 22, etc.). For example, the binary number 01100101 equals 101 in the decimal number system. Binary is important to understand as it is the fundamental language that computers are built upon.

3. Data and Information - Data refers to raw facts and figures while information refers to organized or meaningful data. Computing systems take in data, process it, and produce information. For example, a list of numbers is data but those numbers organized into a spreadsheet is information. Data and information are essential to computing and all applications. Storage, databases, networks, and more are designed to handle data and information.

4. Algorithms - Algorithms are the step-by-step procedures for solving problems or completing tasks. They are essential to computing as computers execute algorithms. Algorithms must be written in a precise and unambiguous manner for a computer to execute them correctly. Examples of algorithms include sorting numbers, searching lists, and recommender systems algorithms. Efficiency and effectiveness are important characteristics of algorithms.
