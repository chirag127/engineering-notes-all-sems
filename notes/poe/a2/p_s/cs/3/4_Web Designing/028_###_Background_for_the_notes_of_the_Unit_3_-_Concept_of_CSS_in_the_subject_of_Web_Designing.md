### Background for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. CSS stands for Cascading Style Sheets. It is a style sheet language used to describe the presentation of a document written in a markup language like HTML.
2. With CSS, you can control the layout of multiple web pages all at once by just editing one single CSS document. This would save a lot of time as compared to styling each HTML element on each web page individually.
3. Some of the advantages of using CSS are:

- It separates the presentation from the content. This means that the HTML file contains the content and the CSS file contains the presentation, thus making it easier to manage websites.
- It makes web pages load faster as the browser downloads the CSS file only once and reuses it for all the web pages using that CSS file.
- It provides more control over web page layout and design as compared to using HTML attributes alone.
- It provides accessibility to web pages as the design and layout can be changed globally by editing just the CSS file.

4. There are three ways to add CSS to an HTML document:

- Inline styling: Using the `style` attribute in HTML elements.
- Internal stylesheet: Using a `<style>` element in the HTML document.
- External stylesheet: Using a separate .css file and linking it to the HTML document using `<link>` element.

5. Some of the CSS properties that can be used to style elements are:

- `color`: To set the text color.
- `background-color`: To set the background color.
- `font-family`: To set the font face.
- `font-size`: To set the font size.
- `text-align`: To set the text alignment.
- `padding`: To set the padding around the element's content.
- `margin`: To set the margin around the element.
- `border`: To set the border around the element.
