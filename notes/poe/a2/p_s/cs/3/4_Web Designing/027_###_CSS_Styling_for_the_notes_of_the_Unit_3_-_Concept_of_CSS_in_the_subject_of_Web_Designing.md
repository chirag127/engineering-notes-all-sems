### CSS Styling for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. CSS stands for Cascading Style Sheets. It is a style sheet language used to describe the presentation of a document written in HTML (Hypertext Markup Language) or XML (Extensible Markup Language).
2. CSS is used to separate the presentation of a web page from the structure and content. This separation leads to more maintainable and flexible web pages.
3. The CSS code is written in a .css file and the HTML file contains links to the CSS file to connect both the files. The CSS file contains rules that control the styling of elements in the HTML document.
4. A CSS rule-set consists of a selector and a declaration block. The selector points to the HTML element you want to style. The declaration block contains one or more declarations separated by semicolons. Each declaration includes a property and a value, separated by a colon.
5. Examples of CSS properties are color, font-family, background-color, width, height, border, etc. The value defines the style of the element for a particular property. For example, color: red; font-family: Arial; background-color: yellow; width: 50%; height: 200px; border: 2px solid black; etc.
6. There are three ways to add CSS to an HTML document - Inline styling (using the style attribute in HTML elements), Internal styling (using a <style> element in the HTML head), and External styling (using a separate .css file).
7. The advantages of using CSS are - Makes web pages attractive and customizable, Reduces repetition of code, Improves accessibility of web pages, Faster loading of web pages, Improved SEO due to less code, Easy maintenance as changes need to be made at a single place.
8. The disadvantages of using CSS are - Has a learning curve, Browser compatibility issues may arise due to different interpretations of CSS rules by different browsers, Debugging issues due to cascading nature of CSS may occur.
