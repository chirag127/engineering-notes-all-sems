## Unit 3 - Concept of CSS

CSS stands for Cascading Style Sheets. It is used to style the web pages and control the layout of the web page.

Some key points about CSS are:

1. CSS separates the presentation of a document from the structure. This means that the HTML file contains the structure of the web page and the CSS file contains the presentation aspects like colors, fonts, layout, etc. This makes the web page more manageable and easier to maintain.

2. CSS uses selectors to select the HTML elements and apply styles to them. Some commonly used selectors are tag selectors, class selectors, ID selectors, universal selector, etc.

3. CSS rules consist of selectors and declarations. Declarations are made up of properties and values. For example, color: blue; is a declaration where color is the property and blue is the value.

4. There are three ways to add CSS to HTML - Inline styles (using style attribute in HTML elements), Internal CSS (using <style> element in HTML head), and External CSS (using CSS files). External CSS is the preferred way as it separates presentation from content and allows reuse of CSS code.

5. CSS has different syntaxes - CSS1, CSS2, and CSS3. CSS3 is the latest version with additional features like rounded corners, shadows, animations, flexbox, etc. CSS3 is backwards compatible, which means that browsers recognize CSS3 properties that they support.

Advantages of using CSS:

- Separates presentation from content
- Makes web pages more accessible
- Provides flexibility to change styles across multiple HTML pages by changing one CSS file
- Results in smaller HTML file sizes due to removal of presentation attributes
- Supports different devices and screen sizes through media queries and responsive design

Disadvantages of using CSS:

- Has a steep learning curve
- Can be tricky to debug
- Lack of control over styling in older browsers
- Cumbersome to make minor changes to styles

Applications of CSS:

- Used to style web pages and control layout
- Enables responsive web design to support multiple devices and screen sizes
- Used for animations and transitions
- Used to create print styles for printing web pages
- Used in web design frameworks like Bootstrap to provide ready-to-use styles
