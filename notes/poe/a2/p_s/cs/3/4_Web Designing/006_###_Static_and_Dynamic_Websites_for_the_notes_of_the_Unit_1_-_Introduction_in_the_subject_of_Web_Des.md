 Here are the notes for the topic ### Static and Dynamic Websites for the Unit 1 - Introduction in the subject of Web Designing:

1. Static Websites:
- Static websites contain fixed web pages with content that remains the same and does not change with time.
- The web pages are created using HTML and CSS and the content is directly added to the pages.
- The pages are served as they are to the users without any processing.
- Examples: Personal portfolios, business brochure sites, etc.
- Advantages: Easy and quick to create, inexpensive to host, fast performance.
- Disadvantages: Content cannot be updated easily, functionality is limited.

2. Dynamic Websites:
- Dynamic websites have web pages that can display different and changing content.
- The pages are created using server-side languages like PHP, ASP.NET, etc. along with HTML and CSS.
- The content is fetched from a database and processed by the server using the server-side language before sending to the users.
- Examples: Ecommerce sites, blogs, forums, etc.
- Advantages: Content can be easily updated, more functionality can be added, customized content for users.
- Disadvantages: Requires more technical knowledge, additional costs for hosting and databases, can be slower than static sites.
