## Experiment 8 - Applications using TCP Sockets

- TCP Sockets are used to establish reliable end-to-end connections between two network devices/hosts. Some of the applications that use TCP Sockets are:

1. Web Browsing: HTTP uses TCP Sockets to establish a connection between the web browser and the web server. The web browser sends HTTP requests to the web server and receives HTTP responses over the TCP connection.
2. Email: The SMTP, POP3 and IMAP protocols used for email also use TCP Sockets to establish reliable connections between the email client and the email server.
3. FTP: The File Transfer Protocol uses TCP Sockets to transfer files between the FTP client and the FTP server.
4. SSH: The Secure Shell (SSH) protocol uses TCP Sockets to establish encrypted connections between the SSH client and the SSH server for remote login and remote command execution.

Advantages of using TCP Sockets:
- Reliable data transmission with ordered and error-checked delivery of packets
- Congestion controlled throughput
- In-order delivery of packets

Disadvantages of using TCP Sockets:
- Slower connection establishment process due to the 3-way handshake
- Higher overhead due to the additional flags and sequence numbers in TCP headers
- Head-of-line blocking can affect performance
