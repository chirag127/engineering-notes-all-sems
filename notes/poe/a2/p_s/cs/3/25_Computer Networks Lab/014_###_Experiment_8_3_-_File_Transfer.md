### Experiment 8.3 - File Transfer

- File Transfer refers to the process of copying or moving a file from one computer to another over a network. It allows sharing and accessing of files between systems.
- The basic requirements for File Transfer are:
    - A network connection between the sender and receiver systems.
    - A file transfer protocol which is a set of rules that govern the file transfer process. Some popular protocols are FTP, HTTP, SFTP, SCP, etc.
- The steps involved in File Transfer are:
    1. Select the file/files required to be transferred.
    2. Choose a File Transfer Protocol. For example, FTP for insecure file transfers over the internet and SFTP/SCP for secure file transfers.
    3. Provide the IP address or domain name of the receiver system.
    4. Provide the login credentials if required for authentication.
    5. Choose to either transfer the file or move (copy and delete from source) the file.
    6. The transfer speed depends on factors like network bandwidth, file size, protocol efficiency, etc.
    - Advantages: Convenient sharing of files, remote access of files.
    - Disadvantages: Vulnerable to security attacks if insecure protocols are used.
    - Applications: File sharing, website hosting, software/OS distribution, etc.

- Examples of File Transfer:
    - FTP: Used to upload/download files to/from a FTP server.
    - SFTP: Secure FTP, similar to FTP but encrypts the data.
    - SCP: Secure Copy, copies files over SSH for security.
    - HTTP: Web browsers use HTTP to download web page files from servers.
