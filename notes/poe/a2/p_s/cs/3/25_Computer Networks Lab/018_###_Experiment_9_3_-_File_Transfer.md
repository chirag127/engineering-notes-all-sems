### Experiment 9.3 - File Transfer

- File transfer refers to the process of copying or moving a file from one computer to another over a network. It allows sharing of files between computers.
- The two main types of file transfer are:
    - Pull-based transfer: The receiver initiates the transfer and pulls the file from the sender. e.g. FTP.
    - Push-based transfer: The sender initiates the transfer and pushes the file to the receiver. e.g. HTTP, FTP.
- File transfer can be done in two modes:
    - Binary mode: Transfers the exact contents of the file without any modification. Used for executable and multimedia files.
    - ASCII mode: Transfers the file by converting the characters to ASCII characters. Used for text files.
- Some advantages of file transfer are:
    - Allows access to files from anywhere.
    - Backup and storage of files at different locations.
    - Sharing of files among multiple users.
- Some disadvantages are:
    - Files may get corrupted or lost during transfer.
    - Slow transfer speed due to network congestion.
    - Security risks as files are accessible over the network.
- Examples of file transfer applications are FTP, SFTP, SCP, HTTP, etc.
- File transfer finds applications in cloud storage, email, and networking.
