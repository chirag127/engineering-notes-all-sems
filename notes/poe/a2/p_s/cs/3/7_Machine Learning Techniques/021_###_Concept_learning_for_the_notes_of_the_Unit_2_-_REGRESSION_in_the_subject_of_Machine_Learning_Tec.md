### Concept learning for the notes of the Unit 2 - REGRESSION in the subject of Machine Learning Techniques

1. Regression is a supervised learning technique which is used to predict the continuous valued output. It is used for forecasting and finding the relationship between variables.
2. The goal is to minimize the error between the predicted output and the actual output. The error is measured using loss functions like Mean Absolute Error(MAE), Mean Squared Error(MSE), etc.
3. The scatter plot is plotted between the input and output variables to analyze the relationship. If the points in the scatter plot lie in a linear pattern, linear regression is used. For non-linear patterns, non-linear regression is used.
4. Linear Regression: It assumes a linear relationship between the input and output variables. The best fit line is found using the least squares method. The equation of the line is:

y = a + bx

Where a is the intercept and b is the slope of the line.
5. Non-Linear Regression: It is used when the relationship between the input and output is non-linear. The non-linear functions like exponential, polynomial, etc are used to fit the data and find the best fit curve. More complex functions like neural networks and decision trees can also be used for non-linear regression.
6. Uses: Regression is used in fields like finance, healthcare, meteorology, etc for forecasting and trend analysis. Some applications are:
- Stock price prediction
- Estimating housing prices
- Predicting weight based on height
- Estimating the salary based on experience, skills, etc
