### Learning Task for the notes of the Unit 5 - REINFORCEMENT LEARNING in the subject of Machine Learning Techniques

1. Reinforcement Learning - Reinforcement Learning is a type of Machine Learning where the agent learns the behavior by interacting with the environment and receiving rewards and punishments. The goal is to maximize the cumulative reward. The agent determines the optimal way of achieving the highest reward through trial-and-error using feedback from the environment.

2. Components of Reinforcement Learning - The major components of Reinforcement Learning are:

- Agent - The learner or decision maker
- Environment - The system which the agent interacts with, observes and takes actions on
- State - Represents the current situation or status of the environment
- Action - The agent performs actions which cause a change in the state of the environment
- Reward - The agent receives reward or penalty corresponding to the state and action. The goal is to maximize cumulative reward.
- Policy - The set of rules which the agent follows to determine the action for a given state. The optimal policy leads to maximum reward.
- Value Function - Represents the expected cumulative reward or return of taking an action in a given state. The optimal value function leads to maximum reward.

3. Types of Reinforcement Learning

- Monte Carlo Methods - The agent interacts with the environment by performing actions and recording cumulative rewards to determine the optimal policy. No model of the environment is made. Examples are Monte Carlo and Temporal Difference.
- Temporal Difference Learning - Estimates the value function from consecutive time steps to speed up learning. Examples are SARSA, Q-Learning.
- Planning Methods - The agent makes a model of the environment and simulates it to determine the optimal policy. Examples are Value Iteration, Policy Iteration.
