### Introduction to MongoDB

- MongoDB is a document-oriented NoSQL database.
- Instead of storing data in tables and rows as in a relational database, MongoDB stores data in documents (data records) that are gathered together in collections.
- A document is a record in a MongoDB collection and is the equivalent of a row in a table.
- A collection is the equivalent of a table in a relational database.
- MongoDB document structure is JSON-like which means it supports nested documents, arrays, etc.
- Some key features of MongoDB are:
-- Scalability: MongoDB scales horizontally using sharding.
-- Schema less: In MongoDB, schemas are dynamic andDocuments in a collection can have different formats.
-- Fast: MongoDB provides high performance with large volumes of data and high throughput.
-- Rich queries: MongoDB supports rich queries, indexing, and aggregation.
-- Easy to use: MongoDB provides a very simple and easy to use interface.

### DEEP LEARNING for the notes of the Unit 4 - ARTIFICIAL NEURAL NETWORKS in the subject of Machine Learning Techniques

- Deep Learning is a subset of Machine Learning that uses neural networks with many layers of processing units for feature extraction and pattern analysis.
- The 'deep' in Deep Learning refers to the number of layers in the neural network.
- Some key types of Deep Neural Networks are:
-- Convolutional Neural Networks (CNNs): Use convolutional layers to extract spatial features from input data like images. Often used for computer vision tasks.
-- Recurrent Neural Networks (RNNs): Use recurrent layers to analyze sequential data like text or speech. Often used for NLP and speech recognition tasks.
-- Long Short Term Memory Networks (LSTMs): A type of RNN that is capable of learning long-term dependencies.
-- Autoencoders: Used for dimensionality reduction and data denoising.
