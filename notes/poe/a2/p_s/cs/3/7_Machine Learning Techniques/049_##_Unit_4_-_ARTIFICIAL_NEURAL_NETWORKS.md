## Unit 4 - ARTIFICIAL NEURAL NETWORKS

- Artificial Neural Networks (ANNs) are inspired by biological neural networks in the human brain. They are made up of interconnected nodes that operate like neurons firing and connections that operate like synapses.
- ANNs are fed large amounts of data and learn by detecting patterns in the data to make predictions or decisions without being explicitly programmed.
- The key components of an ANN are:
    - Input Layer: The input data is fed into the network through the input layer.
    - Hidden Layers: The hidden layers process the input and pass the data to the next layer. The number of hidden layers and number of nodes in each layer vary based on the problem. More hidden layers allow the network to learn more complex patterns but also increase training time.
    - Output Layer: The output layer produces the final output. The number of nodes in the output layer depends on the type of output - for example, one node for binary classification or number of classes for multi-class classification.
- Training an ANN involves iteratively adjusting the weights and biases of the connections between layers using an optimization algorithm like Gradient Descent until the network achieves the desired performance. This is done by feeding the network input data and expected outputs and measuring the error between the actual output and expected output to determine how to adjust the weights and biases.
- The advantages of ANNs are that they can learn complex nonlinear relationships between inputs and outputs and don't require explicit programming. The disadvantages are that they require large amounts of data to train the network, can be prone to overfitting, and are black-box models that are difficult to interpret.
- ANNs have applications in tasks like image recognition, speech recognition, machine translation, forecasting, and more.
