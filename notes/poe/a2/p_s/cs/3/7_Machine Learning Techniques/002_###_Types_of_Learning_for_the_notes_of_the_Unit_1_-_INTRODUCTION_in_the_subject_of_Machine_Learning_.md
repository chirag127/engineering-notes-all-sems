### Types of Learning

The major types of learning in Machine Learning are:

1. Supervised Learning: In supervised learning, the algorithm is trained on labeled data to learn a function that maps inputs to outputs. The training process uses labeled examples to learn a target function. It is classified into two types:
- Regression: Used for predicting continuous valued outputs. Examples: Linear regression, Logistic regression.
- Classification: Used for predicting discrete valued outputs. Examples: Decision trees, Naive Bayes, Neural networks.

2. Unsupervised Learning: In unsupervised learning, the algorithm is trained on unlabeled data to find hidden patterns or clustering in the data. The agent is expected to find a pattern and use it to classify new data points. Examples: Clustering, Association rule learning, Anomaly detection.

3. Reinforcement Learning: In reinforcement learning, the algorithm interacts with a dynamic environment by selecting actions in order to maximize the reward or minimize the loss. The agent learns the behavior optimal for its environment by trial-and-error using feedback from the environment. Examples: Monte Carlo methods, Temporal difference learning.
