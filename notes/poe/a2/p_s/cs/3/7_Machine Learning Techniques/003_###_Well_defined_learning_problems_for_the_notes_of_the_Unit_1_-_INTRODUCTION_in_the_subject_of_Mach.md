### Well defined learning problems for the notes of the Unit 1 - INTRODUCTION in the subject of Machine Learning Techniques

1. Supervised Learning - In supervised learning, we have labeled data consisting of input data and desired output values. The goal is to learn a model that maps the input to the output. Examples of supervised learning problems are:

- Classification - Predicting the class or category of a given input. Ex: Predicting if an email is spam or not.
- Regression - Predicting a continuous valued output. Ex: Predicting the price of a house based on various features.

2. Unsupervised Learning - In unsupervised learning, we have unlabeled data and the goal is to find hidden patterns or clusters in the data. Examples of unsupervised learning problems are:

- Clustering - Grouping similar data points together. Ex: Clustering customers by their shopping patterns.
- Association Rule Learning - Finding relationships between variables in large data sets. Ex: Finding products that are frequently bought together in a store.

3. Reinforcement Learning - In reinforcement learning, the learner interacts with a dynamic environment and the goal is to learn optimal actions that maximize reward over time through trial-and-error using feedback from the environment. Examples are:

- Learning to balance a pole.
- Learning to play games.
- Optimizing resources in a network.

The key aspects here are defining a reward function and exploring/exploiting to find the best strategies. Reinforcement learning is useful in scenarios where supervised/unsupervised learning cannot be applied as there is no labeled data.
