 Here are the notes for the topic ### Fully Connected Layers for Unit 4 - Artificial Neural Networks in the subject of Machine Learning Techniques:

1. A Fully Connected Layer is a layer in a neural network where each neuron in one layer is connected to every neuron in the adjacent layer.
2. In a Fully Connected Layer, every input is connected to every output, with each connection having its own weight and activation.
3. The output of a fully connected layer is calculated by summing up all the input signals multiplied by their respective weights and then passing the summed value through an activation function.
4. Fully Connected Layers allow the neural network to automatically learn complex patterns in the data by adjusting the weights associated with each connection.
5. Fully Connected Layers are often arranged in stacks, with the output of one layer becoming the input to the next layer. This allows them to recognize patterns at multiple levels of abstraction, similar to hierarchical thinking in humans.
6. Fully Connected Layers are widely used in neural networks for tasks such as image classification, speech recognition, machine translation, etc.

Advantages:
- Can learn complex patterns in data.
- Hierarchical feature learning.

Disadvantages:
- Large number of parameters which can lead to overfitting.
- Computational intensive due to large number of weights and connections.
