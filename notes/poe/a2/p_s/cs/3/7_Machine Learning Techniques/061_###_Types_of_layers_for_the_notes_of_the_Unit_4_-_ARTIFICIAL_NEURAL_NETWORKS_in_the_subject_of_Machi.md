### Types of layers for the notes of the Unit 4 - ARTIFICIAL NEURAL NETWORKS

1. Input Layer: This is the first layer of an ANN. It receives the input data and passes it to the next layer. The number of nodes in the input layer depends upon the number of features in the input data.
2. Hidden Layer(s): The hidden layers are the intermediate layers between the input and output layers. They transform the input into something that the output layer can use. The hidden layers apply a nonlinear transformation to their input. The number of hidden layers and the number of nodes in each hidden layer are hyperparameters that are determined by trial-and-error.
3. Output Layer: This is the final layer of an ANN. It produces the output for a given input. The number of nodes in the output layer depends upon the nature of the output. For example, if we are solving a binary classification problem, then the output layer will have only one node. But for a multi-class classification problem, the output layer will have as many nodes as the number of classes.

Advantages:
- ANNs can learn complex nonlinear relationships between input and output data.
- They are fault tolerant and can handle noisy data or missing data.
- They are flexible and can solve a wide variety of problems like regression, classification, decision making, etc.

Disadvantages:
- Training an ANN requires a large amount of data for good performance.
- The optimal architecture and parameters may not be obvious and require trial-and-error.
- The training process can be time-consuming.
- The trained networks may not be interpretable and it's difficult to understand why they make certain predictions.
