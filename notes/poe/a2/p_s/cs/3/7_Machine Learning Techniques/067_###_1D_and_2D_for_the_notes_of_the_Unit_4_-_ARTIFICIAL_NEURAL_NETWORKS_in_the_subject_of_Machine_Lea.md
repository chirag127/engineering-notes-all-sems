### 1D Neural Networks

1. A 1D Neural Network is a type of feedforward neural network that has 1 input feature and 1 output.
2. It has input nodes, hidden layers with activation functions and output layers.
3. The input is a single value which is fed into the input layer.
4. The hidden layers apply weights and activation functions to the input and pass it to the next layer.
5. The output layer provides the final output.
6. 1D Neural Networks are used for time-series prediction as they can learn the patterns in data that changes with time.

Examples:
- Predicting stock prices
- Speech recognition
- Predicting customer churn

Advantages:
- Simple architecture
- Fast training

Disadvantages:
- Limited to problems with 1 input feature
- May not be able to capture complex patterns

### 2D Neural Networks

1. A 2D Neural Network is a type of feedforward neural network that has 2 input features and 1 output.
2. It has input nodes, hidden layers with activation functions and output layers.
3. The input is a vector of size 2 which is fed into the input layer.
4. The hidden layers apply weights and activation functions to the input and pass it to the next layer.
5. The output layer provides the final output.
6. 2D Neural Networks can capture patterns in 2D data and are used for image classification, object recognition, etc.

Examples:
- Image classification
- Object recognition
- Facial expression recognition

Advantages:
- Can capture patterns in 2D data
- Used for computer vision problems

Disadvantages:
- Complex architecture
- Slow training due to large number of parameters
