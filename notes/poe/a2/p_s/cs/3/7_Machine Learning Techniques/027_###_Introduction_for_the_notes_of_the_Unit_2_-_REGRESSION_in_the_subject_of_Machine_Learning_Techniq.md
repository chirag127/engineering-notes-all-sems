### Introduction for the notes of the Unit 2 - REGRESSION in the subject of Machine Learning Techniques

1. Regression is a supervised learning technique which is used to predict a quantitative value based on the given input variables. It finds out a mathematical relationship between the input variables and the target variable.

2. The goal of regression is to determine the "best fit" line or curve that minimizes the error between the predicted and the actual values. This line or curve is called the regression line or regression curve.

3. Some of the common types of regression are:
- Linear Regression: Fits a straight line to the data
- Polynomial Regression: Fits a curved line to the data
- Stepwise Regression: Automated process of selecting variables for a regression model
- Ridge Regression: Handles the problem of multi-collinearity
- Lasso Regression: Performs L1 regularization to shrink the coefficients

4. The regression line or curve can be used to predict new values by using the relationship between the input variables and the target variable determined from the training data.

5. The accuracy of the regression model depends on various factors like:
- The type of relationship between the variables
- The amount and quality of data
- The chosen regression technique
- Handling overfitting and underfitting
- Feature engineering

6. Some applications of regression are:
- Stock price prediction
- Housing price prediction
- Predicting revenues and sales
- Predictive analytics
- And many more!
