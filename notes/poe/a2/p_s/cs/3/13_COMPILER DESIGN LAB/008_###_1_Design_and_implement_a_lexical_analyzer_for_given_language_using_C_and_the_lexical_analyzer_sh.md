### 1.Design and implement a lexical analyzer for given language using C and the lexical analyzer should ignore redundant

A lexical analyzer (also known as a scanner or tokenizer) is a software component that breaks up a stream of source code into basic linguistic units called tokens. Following are the steps to design and implement a lexical analyzer for a given language using C that ignores redundant tokens:

1. Define the language vocabulary - Identify all the basic building blocks of the language like keywords, identifiers, operators, literals, separators, etc. These tokens form the vocabulary of the language.

2. Define token patterns - For each token in the vocabulary, specify a regular expression that can be used to recognize its occurrences in the input. These patterns are used by the analyzer to identify the tokens.

3. Implement the analyzer - The actual implementation can be done using a finite state machine or switch-case statements. The analyzer takes the input source code and matches it against the token patterns. On successful match, it returns the corresponding token. This is done till the end of the input.

4. Ignore redundant tokens - To ignore redundant tokens, check if a token matches more than one pattern and ignore it if it does. This avoids repetition of tokens in the output. The parser can then use the stream of tokens generated by the analyzer to build the syntax tree.

Some advantages of using a lexical analyzer are:
- It divides the input into meaningful units which simplifies the task of the parser
- It can detect simple syntax errors like invalid tokens early
- It can handle complicated patterns using regular expressions

It has applications in compilers, interpreters, syntax highlighters, etc. The concepts can be understood with the help of examples and practice implementing a lexical analyzer for a small language.
