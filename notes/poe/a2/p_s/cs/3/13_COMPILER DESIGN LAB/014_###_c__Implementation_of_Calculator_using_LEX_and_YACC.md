### c) Implementation of Calculator using LEX and YACC

LEX and YACC are tools used to generate lexical analyzers and parsers respectively. They can be used together to implement a calculator -

1. First, the input arithmetic expression is scanned by the lexical analyzer (generated using LEX) to identify lexemes or tokens like numbers, operators, parentheses, etc. These tokens are then passed on to the parser.
2. The parser (generated using YACC) then checks for the syntax of the expression and builds a parse tree. The syntax rules are defined using a context-free grammar.
3. The parse tree is then traversed to evaluate the expression and print the result.

Advantages -
- LEX and YACC provide a simple way to implement the lexical analysis and parsing phase.
- They can handle complex expressions and are efficient.
- The grammar can be modified easily to accommodate changes.

Disadvantages -
- The code generated by LEX and YACC can be difficult to understand and debug.
- They require you to be proficient in writing grammars.

Examples of arithmetic expressions that can be evaluated -
- `3 + 5 * (2 - 1)`
- `sin(x) + cos(x)`
- `log(10) + exp(3)`

Applications -
- Used to implement simple calculators, programming language interpreters, etc.
- LEX and YACC form the basis for many compiler design tools.
