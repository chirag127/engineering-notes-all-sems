### At the end of course , the student will be able to:

1. Understand basic concepts of Data structures like array, linked list, stack, queue, binary tree, heap etc.
2. Implement basic operations on various data structures like insertion, deletion, traversal, searching etc.
3. Analyze the time and space complexity of various data structure operations.
4. Understand and implement basic and advanced algorithms on data structures like sorting, searching etc.
5. Apply data structures and algorithms to solve real world problems.

The course will cover the fundamentals of data structures and algorithms and their implementations in a programming language like C/C++ or Java. Detailed concepts and procedures to work with built-in as well as user-defined data structures will be discussed. Time and space analysis of algorithms and their efficiency will be an important part of this course. Students will get hands-on experience implementing data structures and algorithms and analyzing their performance. This course will help students gain expertise in data structures and algorithms which are essential for any programmer or software engineer.

The following data structures will be covered in detail:

- Arrays: Single and multi-dimensional arrays, array implementation of ADT list.
- Linked lists: Singly and doubly linked lists, circular linked lists.
- Stacks: Array and linked list implementations.
- Queues: Array and linked list implementations, priority queues.
- Binary trees: Representation, traversal techniques, binary search trees.
- Heaps: Max and min heaps.

Algorithms on the following will be implemented and analyzed:

- Sorting: Bubble sort, insertion sort, selection sort, merge sort, quick sort.
- Searching: Linear and binary search.
- Graph algorithms: Breadth first search, depth first search, topological sort, shortest path algorithms.
