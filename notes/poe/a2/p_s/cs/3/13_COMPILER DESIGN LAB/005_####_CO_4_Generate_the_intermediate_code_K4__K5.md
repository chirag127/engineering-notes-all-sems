#### CO 4 Generate the intermediate code K4, K5

- K4 and K5 are intermediate codes generated by the compiler after lexical and syntax analysis.
- K4 is a quadruplet code consisting of 4 fields - op code, operand1, operand2 and result. It represents the individual instructions of the source program.
- K5 is a triplets code consisting of op code, operand and address. It represents address computations required during code generation.
- The code optimizer uses K4 and K5 to perform peephole optimization and data flow analysis to produce an efficient target code.
- Examples of K4 quadruplet: (ADD, R1, R2, R3) which means R1 + R2 → R3. Example of K5 triplet: (LOAD, R4, 100) which means load the value at address 100 into R4.
- The intermediate codes provide a common representation for the source code which can be easily understood by the code optimizer and code generator to produce the final efficient machine code.
- Advantages: intermediate code is language independent, optimization is easy, debugging is facile.
- Disadvantages: extra processing required to generate and optimize the intermediate code leading to increase in compilation time.
