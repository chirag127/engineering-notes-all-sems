### 2. Implementation of Lexical Analyzer using Lex Tool

1. Lex is a generator tool for creating lexical analyzers. It takes input in the form of definitions of tokens using regular expressions and outputs a C program that can recognize those tokens in the input.
2. The lex program consists of three sections:
 - Definitions section: This section contains regular expressions that define the tokens.
 - Rules section: This section contains C code fragments that specify what action should be taken when a token is recognized.
 - User subroutines section: This section contains C functions and subroutines that are called from the rules section.
3. A simple example of lex program:
%%
[a-z]+  { printf("Alphabetic string\n"); }
[0-9]+  { printf("Numeric string\n"); }
 .      { printf("Special character\n"); }
%%
main()
{
    yylex();
}
4. In the above example:
 - The first section contains regular expressions [a-z]+, [0-9]+ and . that define 3 tokens - alphabetic strings, numeric strings and special characters respectively.
 - The rules section contains C code fragments that print a message when the corresponding regular expression is matched.
 - The user subroutines section is empty here. The main() function calls the yylex() function that is automatically generated by lex to perform the lexical analysis.
5. Advantages of using Lex:
 - It is a convenient and powerful tool for defining and recognizing tokens.
 - It generates efficient C code for the lexical analyzer.
 - It provides extensive features for error handling and recovery.
