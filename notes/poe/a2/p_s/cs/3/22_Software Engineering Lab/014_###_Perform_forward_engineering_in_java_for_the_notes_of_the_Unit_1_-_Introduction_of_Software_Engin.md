### Perform forward engineering in java for the notes of the Unit 1 - Introduction of Software Engineering Lab in the subject of Software Engineering Lab

1. Forward Engineering: The process of analyzing an existing system and designing a new system that will replace it is known as forward engineering. In forward engineering, the software life cycle moves forward from analysis to design to implementation.
2. Steps involved:
    1. Requirements Analysis: The requirements of the new system are gathered by analyzing the existing system. The requirements are noted down.
    2. Design: The design of the new system is created based on the requirements gathered. The design specifies the modules and components of the system and how they interact.
    3. Coding: The system is coded in a programming language based on the design. Here, java is used for coding.
    4. Testing: The developed system is tested for any bugs or errors. Necessary corrections are made.
3. Advantages:
    - The requirements are clear as an existing system is analyzed.
    - The design and development is systematic.
    - The end product is a brand new system which overcomes the drawbacks of the existing system.
4. Application: Forward engineering is used when an existing system needs to be replaced with a new system that is more efficient and robust. It is a useful technique for developing systems where the requirements are well understood.
5. In this lab, we perform forward engineering of a simple system in java to understand the steps involved and gain hands-on experience in the process. Detailed code and diagrams will be included in the lab manual.
