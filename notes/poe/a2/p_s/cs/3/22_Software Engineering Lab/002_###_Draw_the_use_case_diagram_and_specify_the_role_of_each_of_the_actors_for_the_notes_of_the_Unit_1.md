### Draw the use case diagram and specify the role of each of the actors for the notes of the Unit 1 - Introduction of Software Engineering Lab in the subject of Software Engineering Lab:

1. A use case diagram is a graphical representation of the interactions between the system and its environment (actors). It portrays the relationship between the system and the actors.
2. The actors are entities that interact with the system. They can be humans or other systems. The role of each actor is defined based on what task they perform with the system. For example:
- Customer: Places order, provides feedback
- Administrator: Manages product catalog, approves orders
- Supplier: Provides products
3. The use cases represent the functionalities or services provided by the system. They depict the tasks that the system performs in collaboration with the actors. For example:
- Place Order: Customer uses this use case to place an order
- Update Catalog: Administrator uses this use case to update product catalog
4. The relationships between actors and use cases are:
- Communicates with: Actor interacts with the system to complete a use case
- Extends: A use case extending another use case to provide additional functionalities
- Includes: A use case including the steps of another use case
