### Perform reverse engineering in java for the notes of the Unit 1 - Introduction of Software Engineering Lab in the subject of Software Engineering Lab

- Reverse engineering is the process of analyzing a system or device to determine how it works and how it was designed or built. In software engineering, reverse engineering is the process of analyzing a software system to identify the systems components and their interrelationships and to create representations of the system in other forms or at a higher level of abstraction.
- In this lab, we will be performing reverse engineering on a given java program to understand its working, control flow, variables used, classes and methods present, etc. This will help in understanding how the program works and debugging or modifying it if required.
- Steps involved:
    1. Analyze the package structure and imports used. Understand the purpose of imported packages and classes.
    2. Identify the main class and entry point of the program. Analyze the main method and its workings.
    3. Identify the variables used, their data types and scope. Understand how the variables are used in the program.
    4. Identify the methods defined. Analyze the methods - its parameters, return type, local variables and the tasks performed by the method. Understand the control flow between the methods.
    5. Identify the classes defined. Analyze the attributes and methods inside the classes. Understand the object creation and usage.
    6. Draw conclusions on the working and functionality of the program. Extract the core logic and steps performed by the program.
- Advantages: Helps in understanding existing code easily, debugging and maintaining legacy code, reusing components, etc.
- Disadvantages: Can be time consuming for large complex software, does not give a full picture of the design and architecture.
- Applications: Software maintenance, code auditing, security analysis, etc.
