## Unit 1 - Introduction of Software Engineering Lab

1. Software Engineering Lab: Software Engineering Lab focuses on hands-on practice of Software Engineering concepts and principles. The lab experiments and activities are designed to demonstrate major stages of Software Development Life Cycle (SDLC) with a project. The lab enables students to apply theoretical knowledge of Software Engineering to practical software development using programming languages and software tools.

2. Aim of the lab: The aim of Software Engineering lab is to impart practical knowledge of Software Engineering tools and techniques and to develop skills required for analyzing problems and implementing solutions. The lab reinforces theoretical concepts taught in the corresponding course.

3. List of Experiments: The list of experiments and activities to be performed in the lab are as follows:

- Requirements Analysis: Eliciting requirements, analyzing and documenting user requirements, drawing use case diagrams and activity diagrams.
- Design: Applying design concepts like abstract data types, software architecture styles and drawing UML diagrams like class diagrams, object diagrams, sequence diagrams.
- Implementation: Coding software in a programming language, using software tools and testing individual modules.
- Testing: Performing testing like unit testing, integration testing and system testing.
- Deployment: Deploying the developed software and studying performance analysis and software metrics.

4. Programming languages and tools: The lab experiments use programming languages like C/C++, Java and Python and software tools like SQL, Git, AWS, Android studio, etc. based on the project requirements.

5. Outcome: On completion of the lab experiments and activities, the students will be able to:

- Understand and apply software engineering principles and life cycle models to software projects.
- Use software engineering tools and techniques for different phases of software development.
- Apply programming skills to solve real-world problems.
- Work as a team to analyze problems and build software solutions.
