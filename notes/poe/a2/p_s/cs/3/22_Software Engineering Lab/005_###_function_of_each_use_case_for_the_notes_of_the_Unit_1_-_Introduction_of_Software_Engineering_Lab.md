### Function of each use case for the notes of the Unit 1 - Introduction of Software Engineering Lab in the subject of Software Engineering Lab:

1. Use Case 1: Requirement Analysis
- Analyze the requirements given by the client or instructor for the software to be developed.
- List down all the functional and non-functional requirements.
- Classify the requirements into various types like user requirements, system requirements, interface requirements, etc.
- Represent the requirements in diagrams or charts if required like use case diagrams, activity diagrams, etc.
- Note down the purpose and goal of the software to be developed based on the requirements.

2. Use Case 2: Feasibility Study
- Check for the feasibility of the proposed system in terms of technical, economical and operational feasibility.
- Estimate the cost, time and efforts required for the development of the software.
- Assess if the required technology, tools and resources are available for the development of the software.
- Determine if the development of the software is justified and worthwhile for the client or organization.

3. Use Case 3: Software Design
- Choose an appropriate design approach or methodology like object-oriented approach, structured approach, etc based on the requirements.
- Draw the software architecture diagram to depict the high-level design of the software.
- Detail out the various components and modules of the software through diagrams like flowcharts, entity-relationship diagrams, etc.
- Design the user interface for the interaction between the user and the software.
- Choose appropriate data structures and algorithms for the various modules and components.
