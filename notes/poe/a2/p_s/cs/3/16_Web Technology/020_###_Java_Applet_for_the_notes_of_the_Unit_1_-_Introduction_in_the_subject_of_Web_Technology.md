### Java Applet

- Java Applet is a program written in the Java programming language that can be embedded into HTML pages.
- It is designed to be executed by a Java-enabled browser.
- Java applets are used to create interactive effects within a web page. They can capture mouse input, display graphics and animation, play sounds and music, etc.
- The key advantages of Java applets are:
    - They are platform independent i.e. they can run on any system irrespective of the underlying operating system.
    - They are secure as they have restricted access to local system resources.
    - They enable rich user experience and dynamic content on web pages.
- The key disadvantages of Java applets are:
    - They require a Java-enabled browser to run the applet.
    - There can be compatibility issues with outdated Java plugins.
    - There can be performance issues as the applets have to be loaded over the network and then initialized in the browser.
- The basic steps to create and use a Java applet are:
    1. Write the Java applet program extending the Applet class.
    2. Compile the Java applet program into a .class file.
    3. Use the <applet> tag in HTML to embed the applet into a web page. Specify attributes like code, width, height, etc.
    4. Load the HTML page in a browser to execute the Java applet and see the output.
- Java applets can be used to create:
    - Interactive calculators, calendars, etc.
    - Animations and graphical effects.
    - Educational software.
    - Online surveys and forms.
    - Dynamic graphs and charts.
