### Forms

Forms are a way to collect user inputted data. They are a essential part of any web application as they are the primary means of interaction between the user and the web application.

The `<form>` element is used to create an HTML form. It contains various form elements or controls which are used to collect user input. Form elements include:

- Input elements like text fields, password fields, radio buttons, checkboxes, submit and reset buttons, etc.
- Select and option elements for selection input
- Button elements for submitting form or resetting form
- Textarea elements for multi-line text input
- Label elements to denote user input fields
- Fieldset and legend elements to group related form controls and provide captions

The basic structure of a form is:

```
<form>
  <!-- form elements like input, select, textarea, etc. -->
</form>
```

When the form is submitted, the data is sent to a server-side script which processes it and returns a response. The response is then displayed on the web page.
Forms have many applications such as:

- Registration and login forms on websites
- Feedback and contact forms
- Search forms
- Shopping carts
- Database entry systems

Advantages:

- Easy to use and implement
- Flexible (can contain various elements)
- Wide browser support

Disadvantages:

- Form data can be tampered if not sent using secure means (HTTPS)
- Limited styling options
- Dependency on server-side scripts to process form data
