### AWT Controls

The Abstract Window Toolkit (AWT) contains a rich set of GUI components called controls. The main AWT controls are:

- Labels: Used to display text or images. They do not accept user input.
- Buttons: Trigger an action when pressed. Can contain text or an image.
- Checkboxes: Used to select or deselect an option.
- Radio Buttons: Used to select one option from a group. Only one can be selected at a time.
- Lists: Show a list of options where one or more can be selected.
- Text Fields: Allow the user to input a single line of text.
- Text Areas: Allow the user to input multiple lines of text.
- Scrollbars: Used to provide a way to scroll through information.
- Menus: Provide a way to select commands, options or tasks.
- Dialogs: Used to prompt the user for information or to display warnings or error messages.

Advantages:
- Cross-platform: Works on Windows, Linux, Mac, etc.
- Easy to use: Simple API and GUI components.
- Customizable: Controls can be customized in appearance and functionality.

Disadvantages:
- Limited features: Less features than Swing.
- Heavyweight: Creates native peer components which can be resource intensive.
- Outdated: The AWT API is outdated and Swing is the modern alternative.

Examples: Simple GUI apps with buttons, text fields, labels, etc.
Applications: Basic desktop applications where a simple user interface is sufficient.
