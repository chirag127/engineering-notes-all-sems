### Images

- Images are important elements in web pages to make the content more attractive and visually appealing. They provide a graphical representation of the content which is more effective than plain text.
- To include images in a web page, the `<img>` tag is used. The syntax is:
`<img src="image_url" alt="image_description">`
- The `src` attribute specifies the URL or path to the image file. The `alt` attribute provides an alternate text description of the image which is useful for accessibility and in case the image does not load.
- The image file formats supported in web pages are JPEG, PNG, and GIF. JPEG is ideal for photographs, PNG is lossless and good for logos, and GIF supports animations.
- The size of the image can be specified using the `width` and `height` attributes in the `<img>` tag or using CSS properties. This helps to ensure that the page layout is not disrupted if the images load slowly or do not load.
- Images can be aligned to the left, right, and center of the page using the `float` and `text-align` CSS properties. Borders and spacing can also be added to images using CSS to enhance the appearance.
- Some advantages of using images in web pages are: they enhance visual appeal, convey information quickly, add interest, and can be used for branding and recognition. However, some disadvantages are: images increase page load time, can be bandwidth intensive, and may not be accessible to all users.
