### Networking

- A network is a group of two or more computer systems linked together. Networking allows computers and devices to share resources like internet access, data storage, applications, etc.
- The components required to build a computer network are:
  - Network interface cards (NICs): Enable computers to connect to a network and communicate with other devices.
  - Network cables: Connect network devices with each other. The most common types are Ethernet, fiber optic and wireless connections.
  - Routers: Transfer data between networks and ensure data is sent to the correct destination.
  - Switches: Connect network devices and direct data to the correct destination.
  - Servers: Provide shared resources, services and applications to other network devices.
- The types of computer networks are:
  - Local Area Network (LAN): Connects computers and devices in a limited geographical area like office, home, etc. Uses network cables or Wi-Fi.
  - Wide Area Network (WAN): Connects computers and devices across a large geographical area. Uses telephone lines, fiber optic cables, satellites, etc.
  - Wireless LAN (WLAN): Uses radio frequency waves to connect nearby devices without the need for network cables.
- The benefits of networking are:
  - Resource sharing: Files, data, applications, storage, etc. can be shared among network devices.
  - Centralized management: Networks can be centrally managed and monitored.
  - Communication: Allows users to communicate and collaborate.
  - Cost efficiency: Sharing of resources leads to cost savings.
  - Scalability: Networks can be easily scaled to accommodate more devices and meet growing needs.
