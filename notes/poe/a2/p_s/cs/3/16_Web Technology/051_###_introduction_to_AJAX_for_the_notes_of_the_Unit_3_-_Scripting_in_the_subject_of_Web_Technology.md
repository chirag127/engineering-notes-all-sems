### Introduction to AJAX

AJAX stands for Asynchronous JavaScript and XML. It is the use of the HTML5 `XMLHttpRequest` object to communicate with server-side scripts and dynamically update parts of a web page without reloading the entire page.

- AJAX allows web pages to be updated immediately without reloading the page. This provides a more responsive user experience.
- AJAX uses a group of technologies including HTML, CSS, JavaScript, DOM, and the XMLHttpRequest object.
- The `XMLHttpRequest` object is used to exchange data with a web server behind the scenes. This means parts of a web page can be updated without a full page refresh.
- AJAX allows web pages to send and retrieve data from a web server asynchronously (in the background) without interfering with the display and behavior of the existing page.
- Data is typically sent to the server in XML or JSON format and retrieved from the server in XML or JSON format. The XML or JSON data is then dynamically added to the web page using JavaScript.
- Some advantages of AJAX are:
    - Faster response and interactions due to no full page refreshes
    - Reduced bandwidth usage since only parts of a page are exchanged instead of full pages
    - Ability to perform transactions and updates in the background without interrupting the user
- Some disadvantages of AJAX are:
    - Can introduce complexity and compatibility issues
    - May not work with older browsers
    - SEO challenges since pages are not fully reloaded
    - Vulnerable to XSS (Cross-Site Scripting) and CSRF (Cross-Site Request Forgery) attacks if not designed properly
- Common uses of AJAX are:
    - Retrieving updated data without reloading a page (e.g. stock tickers, updated blog posts)
    - Sending data to the server for processing (e.g. registering a user, adding items to a shopping cart)
    - Ensuring web page elements are always up-to-date (e.g. chat apps, map markers)
