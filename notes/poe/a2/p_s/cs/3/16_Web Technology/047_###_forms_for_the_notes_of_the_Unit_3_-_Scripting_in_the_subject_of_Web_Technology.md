### Forms

Forms are a set of elements that allows user to enter data. The data entered by the user is sent to the web server for processing.

Some common elements of a form are:

- Form element: `<form>` is the root element that contains all form elements. It denotes the start and end of a form.
- Input elements: `<input>` elements are used to take input from the user like text, password, radio buttons, checkboxes, submit buttons, etc. For example, `<input type="text">`, `<input type="password">`, etc.
- Label elements: `<label>` elements are used to provide descriptions for input elements. They bind an input element with the label element.
- Select and option elements: `<select>` and `<option>` elements are used to create a dropdown list. `<select>` defines the dropdown and `<option>` defines the options in the dropdown.
- Button elements: `<button>` elements are used to create buttons to submit the form data or to reset the form.
- Textarea element: The `<textarea>` element is used to create a multiline text input.

The form data is sent to the server using one of the following methods:

- GET method: Appends the form-data into the URL. Has length restrictions.
- POST method: Sends the form-data in the request body. No length restrictions.

Forms have many applications like:

- Search forms
- Contact/Feedback forms
- Registration/Signup forms
- Login forms
- Payment forms
