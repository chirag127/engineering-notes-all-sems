### Protocols Governing Web

The World Wide Web works on the client-server model where the servers provide resources/services and clients access them. For the communication between the clients and servers, certain protocols are followed:

1. HTTP (Hypertext Transfer Protocol): It is the protocol for accessing web pages/resources. The clients (web browsers) send HTTP requests to servers hosting the resources and the servers send back HTTP responses with the required resources. HTTP uses commands like GET, PUT, POST, DELETE, etc. to specify the action required.
2. URL (Uniform Resource Locator): It is the address of a resource on the web. The structure of a URL specifies the protocol, hostname, path, etc. to locate a resource. For example, the URL `https://www.example.com/page.html` specifies the protocol (`https`), hostname (`www.example.com`), and path to the resource (`/page.html`).
3. HTML (Hypertext Markup Language): It is the main web markup language used to structure and present web pages. Web browsers render HTML documents/web pages from the servers and display them to the users. HTML uses tags like `<html>, <head>, <title>, <body>, <h1>, <p>, etc.` to structure the content.
4. CSS (Cascading Style Sheets): It is used to style the HTML web pages and control the layout and appearance of the content. Web designers use CSS to create attractive and visually appealing web pages.

The above protocols and languages work together in coordination to deliver web resources/pages to the users. There are other web languages and technologies as well like JavaScript, XML, etc. which are used to create interactive and dynamic web pages.
