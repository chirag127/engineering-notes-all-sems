### Data type for the notes of the Unit 1 - Introduction in the subject of Web Technology

* Text - Text data type includes characters and strings. Examples are paragraphs, headings, etc.
* Number - Numeric data type includes integers and floating-point numbers. Examples are 1, 2, 3.5, etc.
* Boolean - Includes logical values true and false. Used for conditions and evaluations.
* Array - Used to store multiple values in a single variable. For example, [1, 2, 3] is an array storing three values.
* Object - Used to store key-value pairs. For example, {name: "John", age: 30} is an object with name and age as keys and their respective values.
* undefined - Value taken by a variable that has been declared but has not yet been assigned a value.
* null - Indicates unknown value. It represents a null value.

Advantages of Data Types:
- It helps to identify the type of data and apply appropriate operations.
- It helps in efficient memory management.
- It avoids errors and increases reliability of programs.

Disadvantages of Data Types:
- It limits the type of data that can be stored in a variable.
- Additional effort is required to convert data from one type to another if required.
