### Arrays

- An array is a data structure that stores a collection of elements of the same type.
- It is a ordered list of elements and each element can be accessed using its index.
- The index starts from 0 and goes up to n-1, where n is the size of the array.

 advantages:
- Efficient access: Accessing an element in an array is very fast as it involves simple indexing.
- Uses less memory: Arrays require less memory as the elements are stored in a contiguous memory location.
- Ordered collection: The elements in an array are stored in a particular order which can be leveraged in many algorithms.

disadvantages:
- Fixed size: The size of an array is fixed. Once defined, it cannot be changed. To add more elements, a new array has to be created and elements have to be copied to the new array.
- Wastage of space: There may be wasted space in an array if elements are not completely filled. For example, if you create an array of size 10 but only store 5 elements, the remaining 5 spaces are wasted.

Examples:
- Array to store integer elements: int arr[] = {1, 2, 3};
- Array to store string elements: String fruits[] = {"Apple", "Banana", "Orange"};

Applications:
- Storing related data: Arrays are used to store related data of the same type together. For example, storing scores of students in a class.
- Matrix representation: A 2D array is used to represent a matrix. It makes operations on matrices very easy to implement.
- Cache memory: Arrays are used to implement cache memory which stores values for faster access.
