### HTML (Hypertext Markup Language)

- HTML is the main markup language used to create web pages. It uses a series of elements consisting of tags enclosed in angle brackets.
- HTML tags are classified into structural tags like `<html>, <head>, <title>, <body>`, semantic tags like `<header>, <footer>, <article>, <section>`, and presentational tags like `<b>, <i>, <u>, <s>, <strike>`.
- The HTML document structure consists of `<html>` as the root element, `<head>` for metadata like title and `<body>` for the visible page content.
- HTML attributes provide additional information about HTML elements and are specified inside the start tag. For example, `<a href="https://example.com">Link</a>` has `href` as the attribute.
- HTML has evolved through versions from HTML 4.01 to the current HTML5 with new features like video, audio, canvas, etc. and deprecated features like presentational tags.
- Advantages: Easy to learn, platform independent, forms the structure of web pages.
- Disadvantages: Lacks presentation, needs CSS for styling, prone to security issues like XSS if not encoded.
- Applications: Creation of web pages, web applications, etc.
