### Dynamic HTML for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

1. Dynamic HTML or DHTML refers to the combination of HTML, CSS, and JavaScript to create interactive and dynamic web pages.
2. It allows the web page to respond to user actions like clicks, hover, etc without reloading the page. This leads to a faster and more responsive user experience.
3. Some features of DHTML are:
- Changing style properties of elements using JavaScript. For example, changing color, size, visibility, etc.
- Moving elements around the page. For example, animating elements or creating drag and drop interfaces.
- Loading external data and displaying it on the page without reloading. For example, displaying updated news feeds or stock prices.
4. Advantages:
- Increased interactivity and responsiveness leading to a better user experience.
- Reduced server load as pages do not need to be reloaded for every user action.
- Complex effects and transitions can be created using JavaScript.
5. Disadvantages:
- Heavier web pages due to inclusion of multiple languages leading to slower load times.
- Compatibility issues as older browsers may not support all features. Extra effort is required to provide fallbacks.
- Increased complexity of code leading to harder maintenance.
