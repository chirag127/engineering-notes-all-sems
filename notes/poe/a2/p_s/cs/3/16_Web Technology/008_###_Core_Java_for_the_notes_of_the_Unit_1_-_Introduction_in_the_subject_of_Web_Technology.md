### Core Java

- Core Java is the basic level Java programming language which is the foundation for learning advanced Java concepts and frameworks.
- It consists of basic syntaxes, data types, operators, control flows, objects, exceptions, threads, collections and input/output concepts, etc. which are essential to get started with Java programming.
- Some key points to learn Core Java are:

1. Learn basic syntax like how to define a class, methods, objects, etc.
2. Understand primitive and reference data types and how to use variables and constants.
3. Get familiar with arithmetic, relational, logical and other operators and how to use them.
4. Learn control flows like if-else, switch, for loop, while loop, do-while loop, break, continue, etc. to control the flow of the program.
5. Understand object-oriented concepts like encapsulation, inheritance, polymorphism, abstraction, etc. and how to use classes and objects.
6. Learn to handle exceptions and errors to avoid abrupt program termination.
7. Understand multithreading and synchronization to make programs more responsive.
8. Learn collections framework to store and manipulate data.
9. Learn I/O concepts to read and write data from the console or files.

- Programming concepts are best learned by practicing coding. So practice writing simple Java programs to get a good grasp of the Core Java concepts and build a solid foundation to learn advanced Java.
