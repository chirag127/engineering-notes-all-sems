### Datagram for the notes of the Unit 3 - Scripting in the subject of Web Technology

1. Scripting languages - Scripting languages are lightweight programming or scripting languages that are embedded into web pages and are interpreted by a browser to perform certain tasks. They are easy to learn and fast to code in. Some popular scripting languages for web development are:

- JavaScript - Used to create interactive effects within web pages, validate forms, detect browsers, create cookies, etc. It is the most popular scripting language for web development.
- VBScript - Created by Microsoft and embedded into Active Server Pages. It is used to perform tasks on the web server.
- PHP - Server side scripting language used to create dynamic web pages. It is embedded into HTML pages and is processed by the web server to generate web pages.

2. Uses of scripting languages in web development - Scripting languages are used to:

- Validate web forms - To check if the user has entered information in required fields or entered information in the correct format like email, phone number, etc.
- Create dynamic web pages - To display different information on web pages based on user interactions or inputs. The web server processes the scripts to generate web pages dynamically.
- Add interactivity to web pages - To create menus, popups, calcuators, games, etc within web pages to enhance the user experience.
- Detect browser properties - To detect browser name, version, browser capabilities, etc and display web pages accordingly.
- Create cookies - To store information on the client system and access the same during subsequent visits.
- And more...

3. Advantages and disadvantages - Some key advantages of using scripting languages are:

- Easy to learn and fast to code in.
- Provide powerful functionality with few lines of code.
- Widely supported by browsers and web servers.

Some disadvantages are:

- The source code is exposed and can be manipulated.
- Prone to errors and security threats if not coded properly.
- Lack of error handling mechanisms.
- Performance can be affected if the script is complex.
