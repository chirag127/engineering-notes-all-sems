## Unit 4 - Enterprise Java Bean

- Enterprise JavaBeans (EJB) is a server-side software component architecture for modular construction of enterprise applications.
- EJBs support transactions, security, scalability, and other services.
- EJBs are scalable, multithreaded, and secure.
- There are three types of EJBs:
  - Session Beans - Manage business processes and interactions with clients. Stateless session beans do not retain client state, while stateful session beans retain state for a client.
  - Message-driven beans - Listen for and process JMS messages asynchronously.
  - Entity Beans - Represent data in a database and encapsulate persistent data in objects.
- Benefits:
  - Modularity - Application is divided into separate components.
  - Reusability - Components can be used across applications.
  - Security - EJBs have declarative security checks.
  - Remote Access - Clients can access EJBs over a network.
  - Scalability - EJBs can handle many clients and heavy loads.
  - Transactions - EJBs support ACID transactions to maintain data integrity.
  - Deployment - EJBs are deployed on application servers, separate from clients.
- Disadvantages:
  - Complexity - EJB architecture is quite complex with many services and APIs.
  - Performance Overhead - There is some additional overhead from the services EJBs provide.
  - Vendor Lock-In - Application is dependent on application server and EJB vendor.
- Applications: E-commerce, banking, inventory, and other enterprise applications. EJBs are a key part of Java EE and application servers.
