### Stored Procedures

- Stored Procedures are pre-compiled queries that are stored in the database.
- They are similar to functions or methods in programming languages.
- They take input parameters and return output parameters or results.
- They are used to encapsulate frequently executed queries and reduce network traffic.
- The database executes the stored procedure and sends only the results to the application.
- Stored Procedures can be written in languages supported by the database like SQL, PL/SQL, etc.
- Advantages:
    - Reduced network traffic.
    - Increased performance as procedures are pre-compiled.
    - Encapsulation of logic.
    - Re-usability.
    - Security as access can be controlled on procedures.
- Disadvantages:
    - Vendor dependent. Code cannot be ported across databases easily.
    - Debugging can be difficult in case of errors.
- Applications:
    - Data validation, access control and security features.
    - Implementing business logic at the database tier.
    - Simplifying application code.
