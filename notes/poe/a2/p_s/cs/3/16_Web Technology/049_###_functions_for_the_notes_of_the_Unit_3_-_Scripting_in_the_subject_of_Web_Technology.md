### Functions

- A function is a block of code that is executed only when it is called.
- Functions are used to organize the code into logical blocks, make the code reusable and increase the readability.
- Functions allow you to break up large chunks of code into separate tasks that can be handled independently. This makes the code more modular and efficient.
- The two types of functions are:
    - Built-in functions: Functions that are provided by the programming language itself like alert(), console.log(), etc. in JavaScript.
    - User-defined functions: Functions that are defined by the user/programmer to perform a specific task.

**Defining a function**

- To define a function, use the function keyword followed by:
    - The name of the function
    - parentheses ()
    - The code block enclosed within curly braces {}

**Syntax**

function functionName() {
    // function body
}

**Calling a function**

- To execute the code inside a function, you call or invoke that function by using its name followed by parentheses ().

**Arguments**

- Values that are passed to a function from the calling code are known as arguments.
- The parameters are the variables used in the function signature to refer to the values passed to the function.

**Returning values**

- A function can return a value to the calling code using the return statement.
- The return statement exits the function and returns the value immediately. Any code after the return statement will not be executed.

**Advantages**

- Code reusability: Functions allow you to reuse the code without repeating it.
- Modularity: Functions break up complex programs into small modules that are easier to understand and debug.
- Easy maintenance: When the logic of a program is broken into functions, it is easier to locate bugs and make changes by modifying specific functions only.
- Readability: Functions give names to the tasks they perform, thereby making the code more readable and understandable.
