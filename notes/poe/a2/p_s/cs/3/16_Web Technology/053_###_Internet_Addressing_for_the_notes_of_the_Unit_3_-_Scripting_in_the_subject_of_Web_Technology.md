### Internet Addressing

- IP addresses: Internet Protocol (IP) addresses are numerical labels assigned to each device connected to a network that uses the IP for communication. They consist of 32 binary bits, which are commonly written in decimal point notation having 4 decimal numbers ranging from 0 to 255 separated by periods. e.g. 192.168.1.1
- IPv4 addresses: The current version of IP addresses being used is IPv4 which has 32 bits allowing for 4,294,967,296 unique addresses. Due to the growth of the Internet, IPv4 addresses are getting exhausted and hence a new version IPv6 is introduced.
- IPv6 addresses: IPv6 uses 128 bits for addressing allowing for 340 trillion trillion trillion unique addresses. The addresses are written in hexadecimal colon notation. e.g. 2001:db8:85a3:0:0:8a2e:370:7334
- Subnet masks: Subnet masks are used to identify the network and host portions of an IP address. They consist of consecutive ones followed by consecutive zeros. The number of ones indicates the number of bits used for the network address. e.g. 255.255.255.0
- CIDR notation: Classless Inter-Domain Routing (CIDR) notation is a compact way to write IP addresses and subnet masks. The subnet mask is appended after the IP address separated by a slash (/). e.g. 192.168.1.0/24
- MAC addresses: MAC (Media Access Control) addresses are unique identifiers assigned to network interfaces for communications at the data link layer. They are 6 groups of hexadecimal digits separated by hyphens. e.g. 01-23-45-67-89-AB
