### 1. HTML Basics
- HTML stands for Hypertext Markup Language
- It is the main markup language used to create web pages
- HTML uses tags like <html>, <head>, <title>, <body>, <h1>, <p>, etc. to structure the content
- The HTML document structure includes the `<html>` tag at the start and `</html>` tag at the end with `<head>` and `<body>` in between
- The `<head>` section contains the page title and metadata while the `<body>` section contains the actual page content
- Heading tags like `<h1>` to `<h6>` are used to denote section headings and `<p>` tag is used to denote paragraphs
- Attributes like `id`, `class`, `style`, etc. are used to provide additional information about HTML elements

### 2. CSS Basics
- CSS stands for Cascading Style Sheets
- It is used to style the HTML elements and define their look and feel
- CSS is separated from the HTML content and is typically placed in external .css files
- Common ways to include CSS in HTML: inline styles, `<style>` tag, external .css file
- CSS style rules contain selectors and declarations where selectors specify the elements to style and declarations specify the properties and values to set
- Some common CSS properties are: `color`, `background-color`, `font-size`, `text-align`, `border`, `margin`, `padding`, etc.
- CSS can be used to position elements, create animations and transitions, use flexbox and grids, and more
