### XML

- XML stands for Extensible Markup Language.
- It is a markup language which is used to store and transport data.
- It is designed to store and carry data, not to display data.
- XML tags are not predefined. We can define our own tags.
- XML documents are surrounded by XML tags `<?xml version="1.0"?>` and `</>`.
- XML tags are case-sensitive. `<Note>` is different from `<note>`.
- XML tags have opening and closing tags. `<Note>` and `</Note>`
- XML elements can be nested. `<Note><To>Tina</To><From>John</From></Note>`
- XML elements can have attributes. `<Note date="12-04-2019">Hello</Note>`
- XML uses indentation to define structure. Proper indentation improves readability.

Advantages:
- Platform independent
- Language independent
- Extensible
- Simplicity
- Flexibility

Disadvantages:
- Difficult to read and understand for humans
- Require more bandwidth to transmit data
- Slow processing speed

Applications:
- RSS feeds
- SOAP
- Configuration files
- Office documents
