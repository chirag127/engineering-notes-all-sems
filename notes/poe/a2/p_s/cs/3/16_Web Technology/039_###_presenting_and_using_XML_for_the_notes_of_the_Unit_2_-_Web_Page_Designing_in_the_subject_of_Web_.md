### Presenting and using XML for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

1. XML stands for eXtensible Markup Language. It is a markup language designed to store and transport data. It focuses on what data is.
2. XML tags are not predefined like HTML tags. We can define our own tags and structure for the data. It makes XML versatile and flexible.
3. The basic structure of an XML document contains a root element which contains other elements. Each element has a start and end tag with content in between.
4. An XML document starts with an XML declaration which specifies the XML version and encoding. It is followed by the root element.
5. Elements can contain attributes which provide additional information about the elements. Attributes are always specified in the start tag.
6. XML documents can be validated against a document type definition (DTD) or an XML Schema to ensure correctness and validity. It helps in data integrity.
7. Some advantages of XML are:
    - Platform independent and programming language independent
    - Extensible and flexible
    - Self describing
    - Supports validation
8. Some applications of XML are:
    - RSS feeds
    - SOAP for web services
    - XHTML
    - SVG
    - XSLT for transforming XML documents
