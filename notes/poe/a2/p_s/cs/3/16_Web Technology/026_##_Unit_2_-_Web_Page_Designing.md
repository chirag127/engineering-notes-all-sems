## Unit 2 - Web Page Designing

1. HTML Basics
- HTML stands for Hypertext Markup Language
- It is the main markup language used to create web pages
- HTML uses tags like <html>, <head>, <title>, <body>, <h1>, <p>, etc. to structure a web page
- Attributes provide additional information about HTML elements
- HTML documents are plain text documents with .html extension
- Example of a basic HTML document:
<html>
  <head>
    <title>HTML Example</title>
  </head>
  <body>
    <h1>Hello World</h1>
    <p>This is a paragraph</p>
  </body>
</html>

2. HTML Elements
- HTML elements are defined by tags
- Each element has an opening tag <p> and a closing tag </p>
- Elements can have attributes within the opening tag <a href="https://example.com">link</a>
- There are empty elements with just one tag <img />
- Core elements include <html>, <head>, <title>, <body>, headings, paragraphs, lists, tables, forms, etc.
- Semantic elements include <header>, <footer>, <article>, <section>, <main>, etc. They add meaning to the content

3. HTML Layouts
- HTML layouts can be done using CSS which stands for Cascading Style Sheets
- Some ways to layout elements:
-- Using div and class/id attributes
-- Flexbox - for alignment, direction, ordering, and sizing
-- Grid - for 2D layouts dividing a container into rows and columns
-- Frameworks like Bootstrap have pre-built components and layouts
- Examples of layouts: Navigation bar, sidebar, forms, tables, etc.
