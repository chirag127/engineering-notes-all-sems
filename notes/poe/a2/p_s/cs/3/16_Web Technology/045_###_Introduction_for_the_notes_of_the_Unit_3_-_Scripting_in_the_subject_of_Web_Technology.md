### Introduction

- Scripting refers to a series of instructions written in a scripting language that is interpreted and executed by a runtime environment.
- Scripts are used to automate tasks, enhance web pages, and provide interactive effects within web pages.
- Some of the popular scripting languages for web development are:
    - JavaScript - Runs in the browser and is used to create interactive effects within web pages.
    - PHP - Runs on the server and is embedded into HTML pages to create dynamic web pages.
    - Python - Can be used on the server to create web applications and dynamic web pages.
- Advantages of using scripting for web development:
    - It separates the presentation from the logic/program. The HTML contains the presentation and the script contains the logic.
    - It makes web pages more dynamic, interactive, and responsive to user actions.
    - It can access and manipulate both the HTML document object model and other APIs provided by the runtime environment.
    - The scripts are interpreted at runtime, so changes do not require recompilation and can be tested quickly.
- Examples of using scripts:
    - Displaying popups, tooltips, etc. in response to user actions like clicking buttons, hovering over elements, etc. using JavaScript.
    - Retrieving data from databases/APIs and dynamically generating web pages using server-side scripts like PHP.
    - Image galleries, interactive forms, etc. using scripting languages.
- Applications of scripting: E-commerce websites, single-page applications, gaming websites, etc.
