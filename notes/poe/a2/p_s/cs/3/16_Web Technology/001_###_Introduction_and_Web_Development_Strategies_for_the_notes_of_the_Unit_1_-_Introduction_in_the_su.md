### Introduction
- The World Wide Web (WWW or Web) is a system of interlinked hypertext documents that are accessed via the Internet.
- Web pages are accessed using a software application called a web browser.
- Web development refers to the tasks associated with developing web sites for hosting via intranet or Internet.
- Web development can range from developing a simple single static page of plain text to complex web-based internet applications, social network services and electronic businesses.

### Web Development Strategies
1. Static Web Pages - Contains static content that remains the same for each web page visitor. Built using HTML and CSS. Easy and fast to develop but not suitable for dynamic data and frequent updates.
2. Server-Side Scripting - Uses scripts executed on the server to generate web pages dynamically based on the visitor's request and data. E.g. PHP, ASP.NET, Ruby on Rails. Useful for e-commerce sites and data-driven pages. Slower than static pages.
3. Client-Side Scripting - Uses scripts executed within the web browser to display dynamic content and interactions. E.g. JavaScript. Enhances user experience but can be disabled by browsers.
4. Database-Driven Websites - Uses databases to store and retrieve data and integrates with server-side scripts to generate dynamic web pages. E.g. online shopping carts use MySQL/SQL databases and PHP/ASP.NET scripts. Most complex to develop but highly scalable.
