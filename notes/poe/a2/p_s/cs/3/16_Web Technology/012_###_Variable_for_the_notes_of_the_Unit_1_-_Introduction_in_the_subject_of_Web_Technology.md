### Variables

- Variables are containers for storing data values.
- They are given a symbolic name which can be used to refer to the value they hold.
- The purpose of variables is to store data values in memory so that they can be used/accessed/manipulated during the execution of a program.
- Some key points about variables:
    - They have a name
    - They have a data type (like string, number, boolean, etc.) which determines the type of value that can be stored in them.
    - The value contained in a variable can change (be reassigned) during the execution of a program.
    - The name of a variable cannot have spaces or special characters other than _, $, and alphanumeric characters. It must begin with a letter.
    - Variable names are case-sensitive (age and Age would be two different variables).
- Examples of variables:
    - let name = 'John';        // stores a string value
    - let age = 30;             // stores a number value
    - let eligible = true;     // stores a boolean value
- Advantages:
    - Variables provide meaningful names to values which makes the code easier to understand and debug.
    - The values contained in variables can be changed easily without affecting the rest of the code. This increases the flexibility and reusability of code.
    - Variables use memory efficiently by storing values in one location and referring to them by their symbolic name whenever required.
- Applications:
    - Variables are fundamental to programming and are used extensively in all types of programs to store and manipulate data.
    - Almost all web technologies like JavaScript, PHP, etc. make heavy use of variables to store values, display them on web pages, pass them between pages, perform calculations on them, etc.
