### Layout managers

Layout managers are used to arrange and organize elements/components on a web page. They provide structure to the web page and handle the overall look and feel or appearance of the web page. Some of the commonly used layout managers are:

1. Tables: Tables arrange elements in rows and columns. They were extensively used for layouts in the past but have fallen out of favor due to accessibility and maintenance issues.
2. Frames: Frames split the browser window into multiple sections where each section can load a separate HTML document. They are not supported in some older browsers and create usability issues. Hence, they are not used nowadays.
3. CSS: Cascading Style Sheets or CSS is the preferred method for layout creation nowadays. It separates the presentation from the content and provides more control and flexibility over layout and appearance. Some CSS layout techniques are:

- Flexbox: Flexbox is a one-dimensional layout mode which arranges items in a row or column. It can be used to create entire web page layouts or small user interface components.
- Grid: CSS Grid is a two-dimensional layout system which divides the page into columns and rows. It enables placement of elements in flexible, space-efficient layouts.
- Floats: The float property allows elements to float to the left or right of its container, allowing text and other elements to wrap around it. It can be used to create entire web page layouts.
- Positioning: The position property can be used to precisely position elements and create layouts. The types of positioning are static, relative, absolute and fixed.

The choice of a layout manager depends on the requirements, level of control needed and browser compatibility. CSS-based layouts are more versatile, standard-compliant and preferred nowadays for creating web page layouts.
