# Java Server Pages (JSP)

- JSP is a dynamic web page technology that enables the creation of interactive web pages that are driven by Java code.
- JSP pages are compiled into servlets and execute on the server.
- JSP uses a combination of HTML, JavaBeans, and custom tag libraries to generate web pages.
- The Java code is inserted into JSP pages within <% %> and is executed on the server. The output can be HTML, XML, or other text-based formats.
- The Java code in the JSP page can access JavaBeans to perform processing and make the web page more dynamic.
- JSP pages have a .jsp extension and are stored in the web application's root directory or Java package structure.
- Advantages:
    - Clean separation of presentation and business logic.
    - Runtime efficiency - JSP pages are compiled into servlets once and reused.
    - Easy to make web pages dynamic.
    - Easy to integrate with enterprise beans and servlets.
- Disadvantages:
    - Additional complexity of having Java code in web pages.
    - Difficult to find errors since the compilation is done on the server.
    - Mixing Java code and HTML can be messy and hard to maintain.
- Applications: Content management systems, e-commerce sites, enterprise applications, etc.
