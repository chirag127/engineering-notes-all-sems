### Operator

An operator is a symbol that tells the compiler to perform specific mathematical or logical manipulations.

- Arithmetic operators: +, -, *, /, % - Used to perform arithmetic operations like addition, subtraction, multiplication, division and modulus.
- Assignment operators: =, +=, -=, etc. - Used to assign values to variables.
- Comparison operators: ==, !=, >, <, >=, <= - Used to compare values and return boolean values.
- Logical operators: &&, ||, ! - Used to combine conditional statements.

Examples:
x + y; //Adds x and y
x = y + 5; //Assigns y + 5 to x
x == y; //Checks if x is equal to y
x <= y; //Checks if x is less than or equal to y
x && y; //Checks if both x and y are true

Advantages:
- Operators provide convenience and readability to code.
- Complex logic can be implemented using operators.

Disadvantages:
- Overuse of operators can make the code complex and hard to read.
- Improper use of operators can lead to bugs and incorrect results.

Applications: Operators are fundamental building blocks used in almost all programs to perform operations, control flow and combine logic.
