### URL for the notes of the Unit 3 - Scripting in the subject of Web Technology

1. URL stands for Uniform Resource Locator. It is a string of characters that identifies the location of a resource on the Internet.
2. The basic structure of a URL contains four parts:
    - Scheme - Defines the protocol to be used for accessing the resource, e.g. http, https, ftp, etc.
    - Host - The domain name of the server that hosts the resource, e.g. www.example.com.
    - Port - The port number used to access the resource. It is optional and defaults to 80 for http and 443 for https if not specified.
    - Path - The path to the resource on the server. It can be a file name or a directory.
3. Some examples of URLs are:
    - http://www.example.com - Accesses the homepage of example.com.
    - http://www.example.com/notes.html - Accesses the notes.html page on example.com.
    - https://en.wikipedia.org/wiki/URL - Accesses the Wikipedia page for the topic URL.
4. The advantages of using URLs are:
    - They are human-readable and easy to share.
    - They are not prone to change if the resource location changes.
    - They allow accessing resources over the Internet using the appropriate protocols.
5. Scripting languages like JavaScript allow dynamically creating and modifying URLs to access resources or navigate to other pages. This is useful in single-page applications and AJAX calls.
