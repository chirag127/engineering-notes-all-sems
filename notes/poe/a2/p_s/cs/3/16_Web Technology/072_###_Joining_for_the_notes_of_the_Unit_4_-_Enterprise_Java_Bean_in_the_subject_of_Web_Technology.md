### Enterprise JavaBeans (EJB)

- EJB is a server-side software component architecture for modular construction of enterprise applications.
- EJB supports transactions, security, scalability, concurrency, and other services for enterprise-level applications.
- EJB provides a component-based view of building applications. An EJB application is made up of components that are deployed in an EJB container.
- The EJB container provides services such as persistence, transaction management, security, threading, lifecycle management, remoting, and other system-level services to the components.
- There are three types of EJB components:

1. Session Beans - Manage client sessions and business logic
2. Message-Driven Beans - Handle asynchronous messages
3. Persistent Entities - Represent data in a database

- Benefits of EJB:
    - Modularity - Applications are built from components.
    - Reusability - Components can be reused across applications.
    - Portability - Components are portable across application servers and systems.
    - Scalability - Application servers provide services to scale EJB applications.
    - Manageability - Application servers provide monitoring and management of EJB applications.

- Applications of EJB: EJB is used to develop large-scale, distributed, transactional, and secure enterprise applications in Java. It is a key technology for the Java EE architecture and is suitable for applications that are highly concurrent, use remote access, and require scalability, security, and transaction management.
