### CSS for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

1. CSS stands for Cascading Style Sheets. It is used to style the web pages and control the look and feel of the web pages.
2. CSS separates the presentation of the document from the structure/content. This makes the web page more accessible and easy to maintain as the styling is done in a single CSS file rather than embedding it in the HTML document.
3. The CSS rules are defined in a CSS file with .css extension. The CSS file contains style rules made up of selectors and declarations. The selectors specify the HTML elements to be styled and the declarations specify the properties and values to be applied to the elements.
4. There are three ways to implement CSS in HTML document - 
    1. Inline styling - Using the style attribute in HTML elements
    2. Internal styling - Using <style> element in the HTML head
    3. External styling - Using a separate CSS file
5. The cascading order of CSS is - Inline style > Internal style sheet > External style sheet. This means if there are multiple CSS rules applicable to an HTML element, the inline style's rule will be applied and if there is no inline style then internal style sheet's rule will be applied and so on.
6. There are many CSS properties to control backgrounds, colors, fonts, positioning, spacing, animations, transforms etc. Some commonly used properties are -
    1. Color - To set text color
    2. Background-color - To set background color of an element
    3. Font-family - To set font face
    4. Font-size - To set font size
    5. Text-align - To set horizontal text alignment
    6. Width and Height - To set width and height of an element
    7. Margin and Padding - To control spacing around and within elements
