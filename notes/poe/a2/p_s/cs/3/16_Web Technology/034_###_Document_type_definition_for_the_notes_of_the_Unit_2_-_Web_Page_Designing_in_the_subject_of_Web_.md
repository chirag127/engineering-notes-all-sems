### Document type definition for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

1. Document Type Definition (DTD) is a set of markup declarations that defines a document type for an SGML-family markup language (SGML, XML, HTML).
2. A DTD defines the legal building blocks of an XML document. It defines the document structure with a list of valid elements and attributes.
3. A DTD can be declared inline inside an XML document, or as an external reference.
4. The benefits of using a DTD are:
- It defines the structure of an XML document.
- It acts as a validator for the document.
- It serves as documentation, describing the purpose of each element and attribute.
5. The components of a DTD are:
- Elements: The basic structures of an XML document. Defines name, content, and attributes.
- Attributes: Additional pieces of information for elements. Defines name and value.
- Entities: Symbols or constructs that are replaced with other symbols or text. Includes general, parameter, and external entities.
- Notations: Used to associate attributes with external files, such as images. Defines name and system identifier.
