### Documents

- Documents are the basic units of information in a web page which can be in various formats like HTML, XML, JSON, etc.
- They contain data, content, and metadata about the web page.
- The web browsers parse the documents and render them on the screen as web pages.
- The documents are fetched from the servers using URLs and protocols like HTTP.

**HTML Documents**
- HTML documents contain HTML markup which describes the structure of a web page.
- They have .html or .htm extension.
- The basic structure of an HTML document contains <html> tags at the start and end with <head> and <body> tags in between enclosing the content.
- The head contains metadata like title, scripts, stylesheets, etc. while the body contains the visible page content.

**XML Documents**
- XML stands for Extensible Markup Language which is a markup language like HTML but more flexible.
- XML documents contain user-defined markup elements to structure, store and transport data.
- They have .xml extension and contain elements enclosed within angle brackets.
- XML documents require a root element and proper nesting of elements.
- They are used to share data over the internet and parse by various applications.
