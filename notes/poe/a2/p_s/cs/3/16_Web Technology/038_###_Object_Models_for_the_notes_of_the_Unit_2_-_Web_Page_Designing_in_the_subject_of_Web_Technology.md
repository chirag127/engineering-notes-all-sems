### Object Models for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

1. Document Object Model (DOM):
- The DOM is a programming interface for HTML and XML documents.
- It represents the page as a hierarchical tree of objects and allows programmers to navigate this tree and update various parts of the page.
- Objects in the DOM tree include elements, attributes, and text nodes.
- Changes made by the programmer are reflected immediately in the page and vice versa.
- The DOM is language and platform independent.
- Examples: Changing styles via JS, Creating/Removing elements, Adding event handlers.

Advantages:
- Separates presentation from content
- Simplifies accessing/modifying document content
- Makes pages more dynamic

Disadvantages:
- Requires time for the browser to create the DOM
- Increases memory usage
- Difficult to learn

2. Browser Object Model (BOM):
- Represents the browser window/frame and provides access to the browser's state and controls.
- Core objects include: window, frames, navigator, history, location, screen, etc.
- Lets you interact with the browser, e.g. get dimensions, detect plugins, open new windows, etc.
- Is browser dependent unlike the DOM.
