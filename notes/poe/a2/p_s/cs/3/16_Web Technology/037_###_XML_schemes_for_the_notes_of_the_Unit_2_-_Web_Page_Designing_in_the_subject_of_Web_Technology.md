### XML schemes for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

1. XML stands for Extensible Markup Language. It is a markup language much like HTML. It was designed to carry data, not to display data.
2. XML tags are not predefined like in HTML. You can define your own tags and attributes. This makes XML extensible.
3. XML uses a tree structure, where every element has a parent, except for the root element. This makes the data hierarchial and easy to parse for machines.
4. Some key features of XML are:

- It is extensible: You can define your own elements and attributes.
- It is platform independent: XML can be processed on any system or operating environment.
- It is simple to understand: The syntax of XML is very simple to read and understand.
- It can be transformed and manipulated easily: XML can easily be transformed and presented in different formats like HTML, PDF etc. using style sheets.
- It can be searched and indexed efficiently. The hierarchical and tag-based structure of XML data makes it easy to search and index.

5. Some advantages of XML are:

- Simplicity: XML is easy to read and create.
- Extensibility: XML is extensible and allows you to define your own tags and elements.
- Self describing: XML includes metadata that describes the structure of the data.
- Platform independence: XML can be processed on any system or operating environment.
- Widely supported: XML is a W3C recommendation and supported by many software tools and languages.
