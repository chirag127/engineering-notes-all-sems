### Beyond Text and Number entry for the notes of the Unit 5 - 3D INTERACTION TECHNIQUES in the subject of Augmented & Virtual Reality

1. Direct 3D Interaction Techniques

- Ray casting: Using a ray (line) from the user's pointer (mouse) to select/manipulate objects in the 3D space. The first object intersected by the ray is selected.
- Cone casting: Similar to ray casting but uses a cone instead of a line for selection. More than one object can be selected if they lie within the cone.
- Proximity selection: Objects within a specified radius/distance of the pointer can be selected.

2. Indirect 3D Interaction Techniques

- Walking: User navigates through the virtual environment using a key or joystick to control the movement of their viewpoint.
- Flying: Similar to walking but with more freedom of movement. The user can move in any direction and isn't bound to the ground plane.
- Pointing gestures: The user points or gestures in the direction they want to navigate. Motion is interpreted from the gesture.
- Viewpoint redirection: The user interacts with on-screen controls/widgets to specify a new viewpoint configuration (position, orientation, field-of-view).
