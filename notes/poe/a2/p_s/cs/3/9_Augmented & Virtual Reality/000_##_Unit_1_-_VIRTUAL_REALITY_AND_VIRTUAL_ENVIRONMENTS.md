## Unit 1 - VIRTUAL REALITY AND VIRTUAL ENVIRONMENTS

1. Virtual Reality (VR) - Virtual Reality is an artificial environment that is created with software and presented to the user in a very immersive way through headsets or multi-projected environments. It gives the user an experience of being physically present in a simulated, but not physically existing, 3D computer-generated environment. The main goal of VR is to completely imitate the physical world and create a sense of presence for the user. Some key components of a VR system are:

- VR Hardware: Head-mounted displays, motion trackers, haptic devices, etc.
- VR Software: Application software to create and display the 3D virtual environment.
- Interfaces: Input devices to navigate and interact with the virtual environment.

2. Virtual Environments (VE) - A virtual environment is a simulated environment that is created using software and presented to the user in a multi-sensory but non-immersive way. It is a 3D computer-generated representation of a physical environment which a person can explore. The main components include:

- A 3D graphical rendering engine to display the graphical environment.
- Sensors and tracking systems to monitor the user's actions and reactions.
- Interfaces to allow the user to interact with the virtual environment.

* Advantages: Used for training and education, entertainment, social connection, rehabilitation, etc.
* Disadvantages: Can cause cybersickness, isolated/unsocial, ethical concerns with violent/adult content.
* Examples: Video games, remote surgeries, virtual museums, social VR platforms, etc.
