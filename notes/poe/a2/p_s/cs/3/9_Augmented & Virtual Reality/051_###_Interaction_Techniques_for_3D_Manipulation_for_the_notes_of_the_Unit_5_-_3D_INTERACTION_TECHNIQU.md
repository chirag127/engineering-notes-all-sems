### Interaction Techniques for 3D Manipulation

The following are the common 3D interaction techniques used for manipulating 3D objects in virtual environments:

1. Direct manipulation: In direct manipulation, the user directly manipulates the 3D object using input devices like data gloves, haptic devices, etc. The movements and actions of the user directly control the object's position, orientation, scale, etc. This provides an intuitive way of interaction but requires expensive input devices.

2. Virtual hand: The user controls a virtual hand using input devices. The movements and gestures of the virtual hand are mapped to manipulating the 3D object. This is similar to direct manipulation but does not require expensive devices. However, it can be unintuitive if the mapping is not designed properly.

3. Ray casting: The user specifies a direction using input devices like mouse, trackball, etc. The software casts a ray in the specified direction and detects intersections with objects. The intersected object is then selected and can be manipulated using additional inputs. This is easy to implement but can be difficult to use for precise selections and manipulations.

4. Widgets: Standard 2D GUI widgets like buttons, sliders, etc. are used to manipulate properties of 3D objects like position, orientation, scale, color, etc. This is easy to implement and use but the 2D-3D mapping can be unintuitive. The large number of widgets required for multiple properties can also clutter the interface.

The choice of technique depends on the task, type of application, and available input devices. Different techniques can also be combined to achieve 3D manipulation. For example, ray casting can be used for selection and direct manipulation can be used for manipulation.
