1. Hardware:
- Head-mounted display (HMD): An HMD is a head-worn device that presents stereoscopic images to the user. It tracks the user's movements and adjusts the view accordingly.
- Sensors: Sensors are required to track the user's movements and gestures. This includes gyroscopes, accelerometers and optical tracking sensors.
- Computing system: A powerful computing system is required to quickly render the 3D graphics and process the tracking data from the sensors.

2. Software:
- Application software: Application software provides an interface to the user and translates their interactions into changes in the virtual environment.
- Middleware: Middleware coordinates inputs from the hardware, provides an interface to application software and handles things like calibration and device synchronization.
- Graphics software: Graphics software renders 3D graphics in real-time based on the scene descriptions and user interactions. It makes use of the graphics processing unit (GPU) for fast performance.

3. Content:
- 3D models: 3D models of objects, scenes and avatars are required to populate the virtual environment. These can be either computer-generated or scanned from the real world.
- Sound: Sound and audio cues add realism to the virtual experience and provide spatial context. Special spatial audio techniques are used to make sounds change as the user moves.

The key advantages of VR are immersion, interaction and imagination. The key disadvantages are cost, limited content and potential negative psychological effects. VR has a wide range of applications including entertainment, education, social connection, business, design, healthcare, engineering and scientific visualization.
