### Classification for the notes of the Unit 5 - 3D INTERACTION TECHNIQUES in the subject of Augmented & Virtual Reality

1. Direct Manipulation Techniques
- Physical Gestures: Using hands and physical movements to interact with objects in virtual environment. e.g. Picking, moving, rotating objects.
- Touch-based: Using touchscreen or touchpad to interact. e.g. Tap to select, swipe to navigate, pinch to zoom.
- Motion Tracking: Tracking position and orientation of objects or body using sensors. e.g. Tracking hands, head, stylus.

2. Virtual User Interface Techniques
- Ray casting: Simulating mouse pointer as a ray to select and manipulate objects.
- 3D Widgets: 3D equivalents of 2D GUI widgets like buttons, sliders, etc.
- Graphical User Interface (GUI): 2D or 3D interface using graphics and text to interact.

3. Voice and Sound-based Techniques
- Speech Recognition: Understanding and interpreting user speech to perform actions.
- Sound Localization: Determining location of sound source and using it as input.

Advantages:
- Natural and intuitive to use.
- Hands-free interaction.

Disadvantages:
- Require additional hardware like microphone.
- Challenging to implement and can be error prone.
