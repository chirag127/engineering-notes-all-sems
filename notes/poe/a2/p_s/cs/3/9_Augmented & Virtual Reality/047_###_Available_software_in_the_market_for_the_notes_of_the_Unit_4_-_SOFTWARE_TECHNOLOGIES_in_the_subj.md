### Available software in the market for the notes of the Unit 4 - SOFTWARE TECHNOLOGIES in the subject of Augmented & Virtual Reality

1. Unity: Unity is a cross-platform game engine developed by Unity Technologies. It is primarily used to develop video games and simulations for PC, consoles, mobile devices, and websites. Unity allows you to create 2D and 3D games/simulations. It provides features like a physics engine, graphics rendering, sound, scripting, etc. It supports languages like C#, JavaScript, Boo, etc. Many AR/VR apps and experiences are built using Unity.

2. Unreal Engine: Unreal Engine is a game engine developed by Epic Games. It is used to develop video games, architectural visualizations, TV shows, etc. It provides support for virtual reality (VR) and augmented reality (AR). It enables you to create high-quality 2D and 3D experiences. It provides features like a physics engine, graphics rendering, artificial intelligence, audio system, animation blending, etc. It supports languages like C++ and Blueprints. Many popular AR/VR apps/games like Pokemon Go, Beat Saber, etc are built using Unreal Engine.

3. Vuforia: Vuforia is an AR software development kit (SDK) developed by PTC. It enables you to create augmented reality experiences by recognizing and tracking planar images (images, objects, and scenes) and simple 3D objects (boxes, cylinders, etc.). It can be integrated with platforms like Unity and Unreal Engine. Many popular AR apps are built using Vuforia like ARUi, AR Timer, etc.
