### Input device characteristics for 3D User Interface Input Hardware

1. Tracking: The input devices should allow for 6 degrees-of-freedom (6DoF) tracking i.e. 3D positional tracking (x, y, z) and 3D orientational tracking (pitch, roll, yaw). This allows the user to freely move and manipulate objects in the 3D space. Some examples are optical trackers, magnetic trackers, inertial measurement units, etc.
2. Registration: The input device should be registered accurately in the 3D space so that the user interactions map correctly to the virtual environment. Any latency or inaccuracy can break the sense of immersion and presence.
3. Ergonomics: The input devices should be ergonomically designed for comfortable and long-duration use. They should not cause undue fatigue or stress on the user.
4. handedness accommodation: The input devices should accommodate both left-handed and right-handed users.
5. Adaptability: The input devices should be able to adapt to the needs of various applications and tasks. They should provide the necessary degrees-of-freedom and controls required to accomplish the user goals.
6. Affordability: The input devices should be reasonably affordable and accessible to a wide range of users to enable widespread adoption of 3D user interfaces. Lower-cost options may trade-off some capabilities but should retain the core functionalities.

Some examples of 3D user interface input hardware with the above characteristics are:
- Motion controllers with 6DoF tracking for natural in-air gesturing
- Data gloves for tracking hand movements and finger poses
- Exoskeleton gloves for force/haptic feedback
- Head-mounted displays with 6DoF tracking for gaze and head direction input
- Treadmills and omnidirectional treadmills for natural walking in virtual environments
