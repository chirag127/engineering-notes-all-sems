## Environment Centered Wayfinding Support

- Environment Centered Wayfinding provides contextual cues to the user about their location and orientation within an augmented/virtual environment.
- It uses the environment features like landmarks, paths, districts, nodes, etc. to provide the user with spatial awareness and navigation assistance.
- Some techniques for Environment Centered Wayfinding are:

**1. Landmark Highlighting**: Important landmarks in the environment like buildings, mountains, etc. are highlighted to make the user aware of their location relative to the landmark.
**2. Path Highlighting**: The path the user needs to take is highlighted to guide the user to the destination. The path can be highlighted by beams or arrows.
**3. District Highlighting**: The environment is divided into districts or neighborhoods and the current district the user is in is highlighted to provide coarse location awareness.
**4. Node Anchoring**: Specific locations or nodes in the environment are anchored with icons or labels to provide the user reference points and assistance in navigation.

- The advantages of Environment Centered Wayfinding are that it utilizes the natural landmarks and structures in the environment and does not require additional graphics. It provides an intuitive sense of location and direction to the user.
- The disadvantages are that it requires the virtual environment to have well-defined landmarks and paths which may not always be possible. It can also be cumbersome to highlight paths in large-scale environments.
- Environment Centered Wayfinding is useful in applications like navigation assistance in smart cities, navigation in virtual heritage sites or historical places, etc.
