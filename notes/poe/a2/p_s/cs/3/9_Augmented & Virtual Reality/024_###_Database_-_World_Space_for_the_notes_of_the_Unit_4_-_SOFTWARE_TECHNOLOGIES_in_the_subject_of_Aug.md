### Database - World Space

- A database is an organized collection of data stored and accessed electronically from a computer system.
- In Augmented and Virtual Reality applications, a database is required to store the data of the virtual world components like 3D models, textures, animations, scripts, physics simulations, user profiles, etc.
- This database of the VR/AR application is known as the World Space database.
- The world space database stores all the elements of the virtual world in a structured manner.
- It facilitates efficient storage, management, and retrieval of the virtual world data.
- The data in the world space database can be accessed and manipulated using programming interfaces.
- The world space database is designed based on the requirements and complexity of the virtual world.
- The most commonly used database models for world space database are:
	- Relational database model - Uses relations and tables to store and link data. Provides structured query language (SQL) to retrieve data. Examples: MySQL, SQLite, etc.
	- Object-oriented database model - Stores data in the form of objects and classes. Examples: MongoDB, CouchDB, etc.
	- Graph database model - Stores data in the form of nodes, properties, and lines. Useful for storing relationships between data. Examples: Neo4j, JanusGraph, etc.
- The choice of a suitable database model depends on the data storage and retrieval requirements of the virtual world application.
- Advantages of using a database for world space:
	- Efficient storage and management of large amounts of data.
	- Facilitates concurrent access of data by multiple users.
	- Provides data security and integrity.
	- Enables quick retrieval of data using queries.
- Disadvantages of using a database for world space:
	- Additional overhead of setting up and maintaining the database.
	- Limited scalability for extremely large datasets.
	- Complexity in database design and queries for complex relationships between data.
