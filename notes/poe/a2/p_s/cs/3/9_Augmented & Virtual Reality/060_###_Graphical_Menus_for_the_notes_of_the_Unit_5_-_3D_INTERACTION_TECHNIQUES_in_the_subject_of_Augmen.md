### Graphical Menus

- Graphical Menus refer to the menus displayed in the user interface of a 3D application which contain options to perform various interactions and tasks.
- They are graphical representations of the options in the form of icons, buttons, etc. instead of just text options.
- Some examples of graphical menus are:

1. Tool palette: Contains icons for various tools like selection tool, navigation tool, etc. User can select a tool to perform interactions.
2. Colour palette: Contains options to select colours for objects. Colour blocks or colour chips are used as options.
3. Object manipulation menu: Contains icons for transformations like move, rotate, scale, etc. User can select an icon to perform the respective transformation on objects.

Advantages:
- Easy to use as they contain graphical representations instead of just text.
- Take less cognitive efforts and are more intuitive.
- Aid in learning and remembering the purpose of different options.

Disadvantages:
- May require more screen space to display the graphical options.
- The icons need to be designed carefully to be self-explanatory. If not, they may create confusion.

Applications: Graphical menus are widely used in 3D modelling and animation applications as well as in various 3D interfaces and environments to provide an easy to use interaction experience.
