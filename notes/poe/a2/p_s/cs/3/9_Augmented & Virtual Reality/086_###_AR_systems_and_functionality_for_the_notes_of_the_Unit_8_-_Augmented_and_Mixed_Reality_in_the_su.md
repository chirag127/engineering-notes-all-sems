**AR systems and functionality:**

1. Tracking system: The tracking system keeps track of the user's location and orientation in the real world. It uses sensors like cameras, inertial measurement units, GPS, etc. to track the user's movements and adjust the augmented content accordingly.

2. Display system: The display system overlays the augmented content onto the real world. It can be a head-mounted display or smart glasses. The display must be transparent to allow the user to see the real world.

3.Rendering system: The rendering system generates the augmented content and aligns it with the real world based on the tracking data. It renders 2D or 3D graphics, videos, images, etc. and overlays them onto the real world in the correct positions, orientations, and scales.

4. Input system: The input system allows the user to interact with the augmented content. It can use controllers, hand gestures, voice, etc. as input which is then processed by the rendering system to provide appropriate output.

**Advantages:** Increased situational awareness, enhanced learning, entertainment, assistance in tasks, etc.

**Disadvantages:** Technical challenges, security and privacy concerns, social acceptance, etc.
