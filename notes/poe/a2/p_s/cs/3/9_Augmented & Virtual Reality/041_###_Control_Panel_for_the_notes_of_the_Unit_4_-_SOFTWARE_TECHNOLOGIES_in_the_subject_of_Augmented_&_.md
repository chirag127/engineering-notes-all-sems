### Control Panel for the notes of the Unit 4 - SOFTWARE TECHNOLOGIES in the subject of Augmented & Virtual Reality

1. Control Panel - The control panel is the interface which allows the user to control the various aspects of a software application. In case of Augmented and Virtual Reality applications, the control panel allows the user to control and adjust the following:

- Field of View - The field of view refers to the extent of the user's surrounding that is captured and displayed by the AR/VR application. The control panel allows the user to adjust the field of view as per their requirements. A wider field of view allows the user to see more of the surrounding but can reduce clarity. A narrow field of view provides higher clarity but limits the surrounding visibility.
- Focus - The control panel allows the user to adjust the focus of the AR/VR application. The focus can be adjusted based on the depth of field and allows the user to focus on a particular object or distance. This is useful in scenarios where multiple objects at different distances need to be viewed.
- Visual Effects - The control panel provides options to control various visual effects of the AR/VR application like brightness, contrast, colour, shadows, etc. These effects can be adjusted based on individual preferences and the surrounding conditions.
- Audio Effects - The control panel provides options to control various audio effects of the AR/VR application like volume, bass, treble, surround sound, etc. These effects can be adjusted based on individual preferences and the surrounding conditions.
- Application Settings - The control panel provides access to other application settings like gesture controls, haptic feedback, language, etc. The user can configure these settings as required for their interaction with the AR/VR application.
