## Unit 4 - SOFTWARE TECHNOLOGIES

1. Object Oriented Programming (OOP)
- OOP is a programming paradigm based on the concept of "objects", which can contain data and code.
- Objects are instances of classes, which are blueprints for objects.
- OOP uses abstraction to separate interfaces from implementations and encourages modularity.
- Key OOP concepts: encapsulation, inheritance, polymorphism, classes, objects, methods, etc.
- Advantages: modularity, reuse, simulation real world problems. Disadvantages: can be complex, inefficient.
- Examples: Java, C++, Python, etc. use OOP.

2. Service Oriented Architecture (SOA)
- SOA is a style of software design where applications are built as a set of interoperable services.
- Services are loosely coupled, reusable software components that have open interfaces.
- SOA focuses on application architecture and aims to allow integrating heterogeneous applications/systems.
- Key concepts: services, service description, service registry, service composition.
- Advantages: flexibility, interoperability, location transparency. Disadvantages: complexity, security.
- Examples: REST, SOAP are web service standards to implement SOA.
