### 2D Controls

- 2D controls refer to the input mechanisms used to interact with and control a 2D application or game. Some common 2D controls are:

- Mouse - The mouse is a pointing device that tracks the 2D motion and clicking actions of the user. It is used to control a cursor on the screen and perform actions like selecting, dragging, clicking, etc. Examples of use: Navigating menus, aiming and shooting in 2D games, drawing applications, etc.
- Touch - Touchscreens allow the user to directly interact with the 2D application through touch and gesture actions like tapping, swiping, pinching, etc. Examples of use: Mobile apps, casual 2D games, signature pads, etc.
- Keyboard - The keyboard can be used to control 2D applications through key presses. The keys can be mapped to different actions and controls. Examples of use: Typing text, navigating menus using arrow keys, controlling a 2D game character using WASD keys, etc.
- Gamepad - A gamepad is a specialized input device used to control 2D and 3D games. It provides buttons and analog sticks/direction pads to map different controls and actions. Examples of use: Controlling a 2D game character, switching weapons, accessing inventory, etc.

Advantages:
- Intuitive and easy to use for common actions like clicking, tapping, dragging, etc.
- Do not require specialized hardware and can use standard input devices.
- Simple to implement and program.

Disadvantages:
- Limited input which may not be suitable for complex interactions or controls.
- Touchscreens require the user to be very precise with their touches which can be difficult for some actions.
- Keyboard and mouse are not suited for all types of applications like motion-based games.

Applications:
- 2D applications like drawing tools, photo editors, casual games, etc.
- Menu navigation and control in software.
- Web-based applications and browser games.
