 Here are the notes for the topic ### Scripts for the notes of the Unit 4 - SOFTWARE TECHNOLOGIES in the subject of Augmented & Virtual Reality:

1. Scripting Languages: Scripting languages are programming languages that are interpreted at runtime instead of being compiled in advance. Some of the popular scripting languages used in AR/VR are:
- JavaScript: Used to develop interactive experiences and interfaces in web-based AR/VR. It is easy to learn and flexible.
- C#: Used to develop AR/VR applications for Microsoft platforms like HoloLens. It is an object-oriented language with solid frameworks for AR/VR development.
- Python: A popular, easy to learn scripting language used to quickly prototype and build AR/VR experiences. It has many libraries for AR/VR like PyVR and bpy.

2. Development Environments: Development environments provide an interface to write, test and debug scripts and code for AR/VR. Some options are:
- Unity: A popular development environment to create AR/VR experiences. It uses C#, JavaScript etc. and has many plugins and assets for AR/VR development.
- Unreal Engine: A widely used game engine and development environment which can be used to build advanced AR/VR experiences. It uses C++ and Blueprint visual scripting.
- Xcode: The development environment for Apple platforms like iOS and macOS. It can be used to develop ARKit based AR experiences using Swift and Objective-C.

3. Frameworks: Frameworks provide the functionalities and APIs to access hardware capabilities and develop AR/VR applications. Some examples are:
- ARKit: A framework by Apple to develop augmented reality experiences for iOS devices. It uses SLAM to track motion and place objects.
- ARCore: A framework by Google to develop AR experiences for Android devices. It uses motion tracking, environmental understanding and light estimation.
- Mixed Reality Toolkit: An open source framework and toolkit by Microsoft to build HoloLens and immersive headset apps. It contains many useful scripts and prefabs.
