### Design Guidelines - System Control

- Provide explicit controls for all degrees of freedom in the virtual environment. Do not remove controls or make them implicit without strong reasons and testing.
- Choose controls that map intuitively to the task and virtual object manipulations required. For example, use grab points or handles on virtual objects that correspond to natural grasping points.
- Choose input devices and mappings that provide an appropriate degree of control fidelity or precision for the task. In general, provide 1:1 mappings between input and output where possible.
- Provide multiple interaction techniques or allow the user to switch between techniques easily. Different techniques may be more appropriate for different tasks or preferences.
- Ensure that the user can easily understand the current state of input devices and how they map to outputs. Provide feedback on restrictions, limits, and conflicts.
- Allow the user to adjust and customize the input devices and control mappings. Provide defaults settings that work for most users and tasks.
- Ensure that the system responds to user inputs promptly and that the response is consistent and predictable. Minimize latencies and variability in system response.
- Prevent unwanted inputs from disrupting the system. Use thresholds, deadbands, and filtering as appropriate to ignore extraneous inputs.
- Provide mechanisms to allow the user to safely exit and re-enter immersive VR experiences. For example, provide a pause button or safe word to freeze the system state.

Advantages: Provides an intuitive and immersive experience. Allows customization for user preferences and tasks. Responsive and predictable system behavior.

Disadvantages: Requires extensive testing to get right. Needs to support multiple interaction techniques and input devices. Challenging to provide appropriate control fidelity and multiple controls.

Examples: VR headsets with hand controllers; motion tracking and gesture recognition; joystick, button box, and keyboard controls.

Applications: VR experiences; virtual simulations; 3D modeling and design; scientific visualization.
