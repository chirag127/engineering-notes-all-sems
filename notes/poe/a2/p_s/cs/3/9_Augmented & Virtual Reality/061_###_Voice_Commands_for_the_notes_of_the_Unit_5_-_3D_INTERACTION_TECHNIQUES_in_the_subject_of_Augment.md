### Voice Commands for the notes of the Unit 5 - 3D INTERACTION TECHNIQUES in the subject of Augmented & Virtual Reality

- Voice commands are a natural and intuitive way to interact with augmented and virtual reality systems. The user can speak commands to perform various actions like navigation, selection, manipulation, etc. without using hands.
- The speech is first recognized and converted into text by speech recognition systems. The text is then processed and matched with the relevant commands to perform the required action.
- Some advantages of using voice commands are:
    - Hands-free interaction. The user can interact without using hands, which can be useful for users with disabilities or when the hands are occupied.
    - Natural and easy to use. Speaking commands is a natural way of communication and is easy to use.
    - Can be used along with other input mechanisms. Voice commands can be used in conjunction with other inputs like hand gestures or controllers to provide a multimodal interaction technique.
- However, some disadvantages are:
    - Background noise can affect accuracy. The speech recognition accuracy can get affected by ambient noise.
    - Limited vocabulary. The system can only understand commands from a limited set of predefined commands. New or complex commands cannot be easily handled.
    - Exclusivity constraint. The speech-based interaction benefits users who can speak but not those who cannot speak. Additional input mechanisms are required to include such users.
- Some applications of voice commands in AR/VR include:
    - Navigating through menus or options. The user can say commands like 'Select', 'Next', 'Go back', etc. to navigate.
    - Manipulating objects. Commands like 'Rotate', 'Scale', 'Move up', etc. can be used to manipulate 3D objects.
    - Getting information. The user can say 'Tell me about this' or 'What is this' to get information about objects in the augmented/virtual environment.
