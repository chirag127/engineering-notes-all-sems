### Graphical User Interface for the notes of the Unit 4 - SOFTWARE TECHNOLOGIES in the subject of Augmented & Virtual Reality

1. A Graphical User Interface or GUI is a type of user interface that allows users to interact with electronic devices through graphical icons and visual indicators such as secondary notation, instead of text-based user interfaces, typed command labels or text navigation.
2. The GUI represents the information and actions available to a user through graphical icons and visual indicators such as secondary notation, as opposed to text-based interfaces, typed command labels or text navigation.
3. Some of the common elements of a GUI are:
    - Icons: Small graphical representations of actions or objects.
    - Windows: Rectangular regions of the screen that contain related GUI elements.
    - Menus: Lists of commands, options and actions presented in a linear list.
    - Toolbars: Collections of icons or buttons usually below the menu bar that provide faster access to commonly used commands.
    - Pointers: Arrow-shaped markers or cursors that highlight and select objects on the screen.
4. The main advantages of a GUI are:
    - Easy to learn and use as the interface is intuitive and visually based. Users don't need to learn commands and syntax.
    - Increases productivity as actions can be performed quickly using the mouse and keyboard.
    - Aids discoverability as available actions are visible.
5. Some disadvantages are:
    - Require more system resources to render and display the graphical elements.
    - Can be less efficient for users who are well familiar with typed commands or shortcut keys.
    - The abundance of icons and options can sometimes lead to confusion or make finding specific tools cumbersome.
6. GUI is widely used in software applications, operating systems and VR/AR systems to allow interaction in an easy to understand, visually representative manner. The elements can be designed as 2D or 3D to provide an immersive experience. Examples include the interfaces of Windows, macOS, and many smartphone apps.
