## Unit 6 - DESIGNING AND DEVELOPING 3D USER INTERFACES

1. Introduction to 3D User Interfaces
- 3D User Interfaces (3D UIs) provide an immersive environment for user interaction with software applications.
- They utilize 3D computer graphics to provide a simulated 3D environment. The user can interact with the 3D environment using input devices like keyboards, mice, touchscreens, motion trackers, etc.
- Key components of a 3D UI include:
-- 3D scene: Collection of 3D objects in a 3D space.
-- Avatar: A 3D representation of the user in the 3D space. The user can navigate the 3D space through the avatar.
-- Objects: 3D objects that the user can interact with in the 3D space like menus, buttons, controls, etc.
-- Viewport: The window through which the 3D space is rendered and displayed to the user.

2. Types of 3D User Interfaces
- Desktop metaphor interfaces: 3D space is made to resemble a physical desktop with documents, folders, etc.
- Immersive virtual environments: Highly immersive 3D spaces giving an experience of being physically present. Used for training, entertainment, etc.
- Augmented reality interfaces: Combines virtual 3D objects in the real world via devices like head-mounted displays. Used in healthcare, engineering, etc.

3. Interaction techniques
- Direct manipulation: Interacting directly with 3D objects like selecting, moving, rotating, scaling, etc.
- Menus: 3D menus for navigating commands and options.
- Tool palettes: 3D tools for interacting with the scene.
- Walk-in metaphors: Navigating 3D space by walking, flying, etc.
