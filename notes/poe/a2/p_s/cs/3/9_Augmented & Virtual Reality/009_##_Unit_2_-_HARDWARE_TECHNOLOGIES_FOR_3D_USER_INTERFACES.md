## Unit 2 - HARDWARE TECHNOLOGIES FOR 3D USER INTERFACES

1. Stereo Display Technologies
- Stereoscopy: Presenting different images to the left and right eyes to create an illusion of depth. Techniques: Active shutter glasses, polarized glasses, autostereoscopic displays.
- Advantages: Enable depth perception and 3D experiences. Disadvantages: Require specialized displays and glasses, reduce brightness and resolution, cause eye strain.
- Applications: 3D movies, games, scientific visualization, medical imaging, etc.

2. Tracking Technologies
- Mechanical: Exoskeletons, data gloves.
- Magnetic: Electromagnetic trackers.
- Optical: Computer vision-based tracking.
- Ultrasonic: Emit ultrasonic pulses and use time-of-flight to calculate positions.
- Advantages and disadvantages of different technologies and their applications in 3D interfaces.

3. Input Devices
- 3D mice: Include extra degrees of freedom for 3D navigation and control.
- Gesture recognition: Vision-based, glove-based and touchless gestural interfaces.
- Direct manipulation: Using hands or tools to interact with 3D virtual objects.
- Examples of 3D input devices and their applications including in medical simulation, design, etc.
