## Manipulation Techniques

- Direct Manipulation: Objects can be directly manipulated using hands or devices like data gloves. For example, directly translating, rotating or scaling an object in 3D space.
- Indirect Manipulation: Interaction is mediated via some intermediary device. For example, manipulating a 3D cursor using a mouse or stylus to select and modify objects.
- Widgets: Standard 2D or 3D GUI widgets can be used to vary parameters of objects. For example, using sliders to control the size or color of an object.
- Menus: Hierarchical menus are used to issue commands to perform operations on objects.
- Voxels: 3D volumetric display elements can be directly 'sculpted' or modified.

## Input Devices

- Mouse & Keyboard: Standard 2D input devices can be used to control 3D views and interactions.
- Trackers: Separate 6DOF trackers can be used to track head, hand or stylus positions to enable 3D interactions.
- Data Gloves: Flexible fiber optic or conductive fabric gloves can sense finger positions to enable 'hands on' 3D interactions.
- Stereo Glasses: Shutter glasses or polarized glasses can be used with stereo displays to provide perception of depth via stereo vision.
- Motion Trackers: Devices using accelerometers or gyroscopes worn on the body can track body motions to enable interaction via gestures, poses or balance.
- Haptic Devices: Force feedback devices can be used to feel object shape and texture, provide resistance to motion and enable precise 3D interactions.
