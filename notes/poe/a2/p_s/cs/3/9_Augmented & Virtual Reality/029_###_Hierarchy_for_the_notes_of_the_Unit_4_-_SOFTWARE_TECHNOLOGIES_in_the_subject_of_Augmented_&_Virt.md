### Hierarchy for the notes of the Unit 4 - SOFTWARE TECHNOLOGIES in the subject of Augmented & Virtual Reality

1. Augmented Reality Software
- Software frameworks for AR app development: ARKit, ARCore, Vuforia, etc.
- Tracking methods: marker-based, markerless, SLAM
- Rendering engines: Unity, Unreal Engine, etc.
- Programming languages: C/C++, C#, Java, etc.

Advantages: Immersive and interactive experience, overlay of digital information on real world.
Disadvantages: Require additional hardware components, limited FOV and tracking accuracy.
Applications: Education, retail, navigation, etc.

2. Virtual Reality Software
- Software frameworks for VR app development: OpenVR, Oculus SDK, Vive SDK, etc.
- Rendering engines: Unity, Unreal Engine, etc.
- Programming languages: C/C++, C#, Java, etc.

Advantages: Fully immersive digital experience.
Disadvantages: Isolated experience, requires additional hardware components.
Applications: Gaming, entertainment, social connectivity, etc.

3. Mixed Reality Software
- Software frameworks for MR app development: Windows Mixed Reality, etc.
- Rendering engines: Unity, Unreal Engine, etc.
- Programming languages: C#, C++, etc.

Advantages: Combination of AR and VR for an immersive experience.
Disadvantages: Require specialized hardware and components.
Applications: Industrial training, creative applications, etc.
