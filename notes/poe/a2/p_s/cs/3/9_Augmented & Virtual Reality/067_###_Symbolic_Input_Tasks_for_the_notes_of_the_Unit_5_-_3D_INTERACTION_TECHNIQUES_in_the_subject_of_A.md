### Symbolic Input Tasks for the notes of the Unit 5 - 3D INTERACTION TECHNIQUES in the subject of Augmented & Virtual Reality

- Symbolic input techniques involve the use of symbolic gestures or postures to interact with and control the VR system.
- Some of the popular symbolic input techniques are:
	- Hand Gestures: Recognizing hand gestures to trigger actions or input commands. For example, making an 'OK' sign with thumb and index finger to select an object or swiping left/right with five fingers to navigate.
	- Body Postures: Recognizing body postures or poses to input commands. For example, crossing arms to exit or standing straight with arms stretched out to zoom in.
	- Tangible User Interfaces: Physical objects are used as input devices to manipulate virtual objects. For example, a physical wand to control a virtual paintbrush or a physical sculpting tool to shape virtual clay.
- The key advantages of symbolic input techniques are:
	- Intuitive and easy to learn as they are based on familiar gestures and actions.
	- Do not require manipulation or handling of physical input devices. The user's own body acts as the input device.
	- Allow 'hands-free' interaction which can be desirable for certain applications.
- The disadvantages are:
	- Limited vocabulary of gestures and postures. Can't have too many commands mapped to symbols.
	- Require sophisticated computer vision and machine learning techniques to recognize gestures and poses accurately which can be computationally expensive.
	- Prone to errors due to variations in user characteristics and environments.
- Symbolic input techniques are suitable for application scenarios where 'hands-free' interaction is preferred and the command set is limited. Examples include virtual reality gaming, multimedia systems, etc.
