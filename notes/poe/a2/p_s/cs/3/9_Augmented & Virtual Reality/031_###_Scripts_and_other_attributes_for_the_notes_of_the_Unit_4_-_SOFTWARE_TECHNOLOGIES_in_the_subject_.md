### Scripts

- Scripts are the programming codes written to define the logic and functions of a VR/AR application.
- They are used to specify the behavior and interactions of different objects in the virtual environment.
- Popular scripting languages for VR/AR include:
-- Unity uses C#, JavaScript
-- Unreal Engine uses C++, Blueprint visual scripting
-- A-Frame uses JavaScript
-- JavaScript-based frameworks like ReactVR and Babylon.js also use JavaScript

Advantages of scripting:
- Easy to make changes and modifications
- Less complex than traditional programming languages
- Allows designers and artists to create VR/AR experiences without strong programming skills

Disadvantages of scripting:
- May not be efficient for complex applications which require high performance
- Difficult to debug and identify errors
- Programmers still required for more complex scripts and logic

### Other attributes

- Assets: Media files like 3D models, textures, audio, videos, etc. that are used in a VR/AR experience
- GUI: The graphical user interface components like menus, buttons, sliders, etc. that interact with the user
- Physics: The simulation of physical interactions and behaviors like motion, collision, gravity, etc.
- Lighting: The illumination of the virtual environment and objects for realistic effects
- Animations: The animated motions and transitions of objects to simulate real-world dynamics
