#### Position Tracking
- Position tracking is required to track the location of the user in the real world and update the virtual world accordingly.
- It is done using sensors like GPS for outdoor tracking and inertial measurement units (IMUs) comprising accelerometers and gyroscopes for indoor tracking.
- GPS provides absolute position but has limitations like inaccuracy indoors or in urban canyons. IMUs provide relative position and orientation changes but suffer from drift.
- Sensor fusion of GPS and IMUs is done to get accurate position tracking.

#### Orientation Tracking
- Orientation tracking is required to track the rotation and tilt of the user's head or device.
- It is done using inertial sensors like gyroscopes and accelerometers.
- Gyroscopes measure angular velocity and accelerometers measure linear acceleration to calculate orientation.
- However, the orientation tracking also suffers from drift and hence needs to be recalibrated periodically using other sensors or techniques like magnetic tracking.
- Orientation tracking is important for applications like viewing 3D models from different angles or for navigation assistance.
