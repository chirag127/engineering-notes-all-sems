Auditory Displays
- Auditory displays provide users with non-visual sensory feedback through sound.
- They are useful when visual displays are not feasible or appropriate, such as for users with visual impairments.
- Auditory displays can convey various types of information such as:
    - Spatial location or movement using directional audio cues (e.g. stereo panning)
    - Status changes or event notifications using earcons (auditory icons) or speech synthesis
    - Continuous data values using sonification (mapping data to sound properties)
- Advantages:
    - Accessible for those with visual impairments
    - Additional sensory channel can reduce cognitive load by distributing information across senses
    - Useful in situations where visual attention needs to be focused elsewhere (e.g. monitoring critical tasks)
- Disadvantages:
    - Auditory displays may be ignored or missed if there are other dominant sounds in the environment
    - The mapping of information to sound can be difficult to learn and interpret
    - The auditory system has limited bandwidth, so large amounts of data may be difficult to present effectively
- Examples:
    - Spatialized audio cues to indicate object locations or player positions in virtual environments
    - Earcons to indicate system status changes or alert users to events
    - Sonification of biometric data such as heart rate or EEG signals
- Applications:
    - Accessibility for those with visual impairments
    - Monitoring systems where visual attention is focused elsewhere
    - Spatial awareness and navigation aids
    - Presenting data that is naturally temporal in nature
