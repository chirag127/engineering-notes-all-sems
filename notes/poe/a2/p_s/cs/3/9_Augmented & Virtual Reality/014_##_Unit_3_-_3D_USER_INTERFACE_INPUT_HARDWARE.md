## Unit 3 - 3D USER INTERFACE INPUT HARDWARE

3D User Interface Input Hardware refers to the input devices used to interact with 3D applications and virtual environments. Some of the commonly used 3D user interface input hardware are:

1. Data Gloves: Data gloves are fabrics gloves with sensors that track the bending of fingers. They are used to input hand gestures and manipulate objects in 3D virtual environments. Examples include Cyberglove and 5DT Data Glove.
Advantages: intuitive and natural way to interact.
Disadvantages: bulky, expensive and require calibration.

2. Tracking Systems: They are used to track the position and orientation of the user or input devices. The commonly used tracking systems are magnetic, optical and mechanical tracking systems.
Magnetic Tracking System: Uses magnetic fields to track position and orientation. Example: Polhemus magnetic tracker.
Optical Tracking System: Uses cameras to detect markers or special patterns to track motion. Example: OptiTrack system.
Mechanical Tracking System: Uses joints and linkages to track motion. Example: Exoskeleton suits.

Advantages: Provide 6DOF tracking required for 3D interaction.
Disadvantages: Require line of sight, expensive and suffer from latency and noise.
