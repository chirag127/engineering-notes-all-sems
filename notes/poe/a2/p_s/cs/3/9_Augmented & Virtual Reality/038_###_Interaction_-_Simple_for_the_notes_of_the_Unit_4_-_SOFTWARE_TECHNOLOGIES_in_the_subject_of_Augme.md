 Here are the notes for the topic ### Interaction - Simple for the Unit 4 - SOFTWARE TECHNOLOGIES in the subject of Augmented & Virtual Reality:

1. Simple interaction techniques involve direct manipulation of objects in the virtual environment using input devices that map naturally to the task.
2. Examples of simple interaction techniques:
- Selection: Selecting an object by pointing and clicking on it. Can be achieved using mouse, touchscreen, gesture, etc.
- Navigation: Moving around the virtual environment. Can be achieved using keyboard, joystick, trackball, etc.
- Object manipulation: Rotating, scaling, and translating objects. Can be achieved using 3D mouse, data glove, etc.

Advantages:
- Easy and intuitive to learn and use.
- Minimal mode switches required.
- Direct and efficient.

Disadvantages:
- Limited to simple tasks. Complex manipulations and selections are difficult.
- Input devices may not always map naturally to the task.

Applications:
- Virtual environments for education and training.
- Computer-aided design systems.
- Virtual reality games and entertainment applications.
