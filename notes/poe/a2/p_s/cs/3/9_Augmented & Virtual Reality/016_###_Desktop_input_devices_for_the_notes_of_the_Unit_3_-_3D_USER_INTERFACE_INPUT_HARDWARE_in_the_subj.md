### Desktop input devices

The following are the commonly used input devices for desktop-based 3D user interfaces:

1. Mouse - The mouse is a 2D input device which can be used for 3D interactions using multiple buttons and scroll wheels. The buttons can be used for selection and manipulation of objects. The scroll wheel can be used for zooming in and out of the 3D scene. However, the mouse lacks the ability to sense depth and orientation which limits its use for 3D interactions.

2. Trackball - A trackball is a stationary controller with a ball on its surface which can be spun using the fingers or palm. It serves as an alternative to the mouse and can be more suitable for 3D interactions as it does not require sweeping motions. However, similar to the mouse, the trackball is also limited by its 2D input and lack of depth sensing.

3. Spaceball - A spaceball is a grip-based input device which can sense 6 degrees of freedom movements, making it suitable for 3D interactions. It allows users to navigate and manipulate 3D objects in an intuitive way. However, spaceballs are typically more expensive than mice and trackballs. They may also be less precise and take time to get accustomed to.

4. Data glove - A data glove is a wearable input device which senses the movements and bends of the fingers using sensors. It can allow users to naturally interact with 3D environments using hand gestures. However, data gloves are typically cumbersome to wear and need to be calibrated for each user. They are also prone to sensing errors. Due to these limitations, data gloves are not commonly used for desktop-based 3D interactions.

The choice of input device for 3D desktop interactions depends on the needs of the application, user preferences, and cost requirements. An ideal input device should allow intuitive and immersive interactions with 3D data through sensing 6 degrees of freedom as well as finger motions. However, there is no one device that meets all these requirements currently, so practitioners often use combinations of the above devices or other modalities like touchscreens for 3D interactions.
