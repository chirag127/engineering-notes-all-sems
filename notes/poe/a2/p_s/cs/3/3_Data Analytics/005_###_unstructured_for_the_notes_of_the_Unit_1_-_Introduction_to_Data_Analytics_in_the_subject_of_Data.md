### Unstructured Data

- Unstructured data refers to data that does not have a defined data model or is not organized in a pre-defined manner.
- It does not have a fixed field length or number of fields.
- The data is not organized in tabular form with rows and columns.
- Examples of unstructured data include text documents, PDF files, images, audio, video, emails, presentations, etc.
- Unstructured data lacks metadata to explicitly define data types, formats or structures. Hence, it is difficult to analyze unstructured data using traditional methods and tools.
- New techniques like Natural Language Processing, sentiment analysis, etc. are required to analyze unstructured data and derive insights from it.
- Around 80% of data in enterprises today is in unstructured format. This data holds a lot of valuable information but is difficult to process.
- Hadoop and NoSQL databases are designed to handle large volumes of unstructured data by storing and processing data in a distributed fashion.

Advantages:
- Contains a wealth of information in the form of comments, reviews, feedback, etc. which can provide key business insights if analyzed.
- Does not require a predefined schema hence is flexible. The schema can be applied later based on the analysis requirements.

Disadvantages:
- Difficult and time-consuming to analyze due to lack of structure.
- Prone to variability and inconsistency which makes it harder to understand.
- Requires specialized skills and techniques to extract information.
- Does not fit well into traditional relational databases which are designed for structured data.
