### Classification of Data

The different types of data can be classified into the following major categories:

1. Numerical data: This type of data represents values that are measurable and are expressed using numbers. For example, height, weight, salary, age,etc. Numerical data can be further classified into:
- Discrete data: Represents countable values that can only take on certain numerical values. For example, number of siblings, number of goals scored, etc.
- Continuous data: Can take on any fractional numerical value in a given range. For example, temperature, speed, pressure, etc.

2. Categorical data: This type of data represents attributes or characteristics that can be placed into categories. For example, gender, department, marital status, etc. Categorical data can be further classified into:
- Nominal data: Simply places individuals into distinct categories with no implied ordering. For example, gender (male/female), blood type (A/B/AB/O), etc.
- Ordinal data: Places individuals into distinct categories with an implied ordering. For example, satisfaction level (low/medium/high), education level (undergraduate/postgraduate), etc.

3. Time-series data: This type of data is collected over a period of time or has temporal properties. For example, stock prices, weather data, sale volumes, etc. The pattern and trends in time-series data can be analyzed to gain meaningful insights.
