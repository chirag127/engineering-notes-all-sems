### Drivers for Big Data

The major drivers for Big Data are:

1. Increase in data volume: The data volume is increasing exponentially due to increased digitalization. More and more activities are generating digital data like online transactions, social media activity, sensors, devices, etc. This huge volume of data is a major driver for Big Data.

2. Increase in data variety: The types of data are increasing rapidly. There is a variety of structured, semi-structured and unstructured data present. This diversity in data types and formats poses challenges in storing and processing the data which necessitates Big Data technologies.

3. Increase in data velocity: The speed at which data is generated and processed is very high. Real-time data needs to be processed instantly to enable applications like fraud detection or personalized recommendations. This speed and need for real-time insights drive the use of Big Data platforms and technologies.

4. Low cost of storage: The cost of storing huge volumes of data has decreased substantially with the evolution of technologies like HDFS and cloud storage. This has made it more feasible for organizations to store large data volumes, thus enabling Big Data processing.

5. New processing requirements: There are many new requirements for processing data like complex analytics, real-time processing, iterative processing of data at huge scales etc. Traditional data processing technologies cannot handle these requirements efficiently, necessitating the use of Big Data platforms and frameworks.
