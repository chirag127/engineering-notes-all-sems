### Graphic Displays

The following are the common types of graphic displays used for displaying computer graphics:

1. Raster Displays:
- They display images as a grid of pixels. Each pixel has a specific location and color value.
- The resolution of a raster display is measured by the number of pixels in each dimension. Higher resolution leads to sharper and clearer images.
- Examples: Computer monitors, TV screens, etc.
- Advantages: Can display complex and detailed images. Suitable for displaying photographs and videos.
- Disadvantages: Requires large amount of memory to store the color values of each pixel.

2. Vector Displays:
- They display images based on drawing lines and curves specified by mathematical equations.
- The quality of the display depends on the resolution of the display device.
- Examples: Old oscilloscopes, pen plotters, etc.
- Advantages: Requires less memory as only the equations need to be stored. Can produce high quality graphics.
- Disadvantages: Not suitable for displaying images with complex textures, photos, and videos.
