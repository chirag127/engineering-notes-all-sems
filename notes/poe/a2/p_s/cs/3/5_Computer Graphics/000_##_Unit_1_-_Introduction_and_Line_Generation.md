## Unit 1 - Introduction and Line Generation

1. Introduction to Computer Networks
- A computer network is a group of computers that are interconnected and able to communicate with each other to share resources.
- The interconnected computers are able to share files, data, resources like printers, etc. and can communicate with each other.
- The communication between computers is established using a combination of hardware and software.
- The hardware components include network cables, routers, switches, etc. and the software components include network operating systems and network protocols.

2. Line Configuration
- The physical connection between two network devices is called a line.
- The line can be a twisted pair cable, coaxial cable, fiber optic cable, etc. depending on the network technology used.
- The correct line configuration like straight-through, crossover, rolled, etc. needs to be used to establish a proper connection between two network devices.
- The line configuration depends on the pins on the network connector being used and proper configuration ensures the transmit and receive pins are connected correctly.
- Incorrect line configuration can lead to connection problems and data loss.

## Unit 1 - Introductory Concepts of Computer Networks and Physical Layer

1. Introduction
- A computer network is a group of interconnected computers that are able to communicate and share resources.
- Networks are classified based on scale (LAN, MAN, WAN), topology (bus, star, ring), and architecture (client-server, peer-to-peer).
- The benefits of networking include resource sharing, file sharing, communication, and remote access.

2. The OSI Model
- The OSI model is a conceptual framework for describing communications in a computer network.
- It consists of seven layers - Physical, Data Link, Network, Transport, Session, Presentation, and Application.
- Each layer performs a specific task and uses the services of the layer below it. Data is passed from top layers to bottom layers during transmission and in the reverse order during reception.
- The OSI model helps understand the overall networking process and troubleshoot issues.

3. The Physical Layer
- The Physical layer is the lowest layer in the OSI model.
- It is responsible for transmitting raw binary data over a physical medium.
- It defines specifications for the electrical/optical, mechanical, and procedural interfaces required for communication between devices.
- Examples of specifications include voltage levels, cable types, connectors, etc.
- The type of physical medium used determines the network technology like Ethernet, Token Ring, FDDI, etc.
