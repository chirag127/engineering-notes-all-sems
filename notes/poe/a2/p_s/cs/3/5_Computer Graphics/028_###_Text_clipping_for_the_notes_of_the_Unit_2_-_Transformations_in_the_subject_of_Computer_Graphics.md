### Services in networks architecture in Computer Networks

1. Client-Server Architecture: In this architecture, there are dedicated servers that provide services to client processes. The clients connect to the servers and request for services. The servers then process the requests and send back responses to the clients. For example, a web browser acts as a client and connects to a web server to fetch web pages.
2. Peer-to-Peer Architecture: In this architecture, there are no dedicated servers. Each host acts as both a client and a server. The peers are connected to each other and share resources and services. For example, BitTorrent is a peer-to-peer file sharing system.
3. Distributed Architecture: In this architecture, there is no central authority and the processes/services are distributed among multiple computers. The computers communicate with each other to share resources and services. For example, distributed control systems, Bitcoin, etc.

### Text clipping for the notes of the Unit 2 - Transformations in the subject of Computer Graphics

1. Translation: Shifting an object's location. It is represented by a displacement vector.
2. Rotation: Spinning an object about a point. It is represented by an angle of rotation and axis of rotation.
3. Scaling: Resizing an object. It is represented by a scale factor.
4. Composite transformations: Applying multiple transformations in a specific sequence to achieve the final desired transformation. The order of transformations matters due to non-commutativity.
