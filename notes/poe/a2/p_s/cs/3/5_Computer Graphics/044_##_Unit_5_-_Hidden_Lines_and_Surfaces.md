#### Network topology design in Computer Networks

- Network topology refers to the physical and logical arrangement of the network devices, cables, and other components that make up a computer network. The design of the topology determines how devices will communicate with each other, which devices are directly connected to each other, and how data flows between devices. There are primarily three main types of network topologies:

1. Bus topology: All devices are connected to a central cable, called a bus. Data is transmitted along the bus in both directions and received by all devices. Only one device can transmit at a time while others wait for their turn. Eg: 10BASE2, 10BROAD36 networks.
Advantages: Inexpensive, easy to install and extend.
Disadvantages: Difficult to troubleshoot, entire network is affected if there is a break in the central cable.

2. Star topology: All devices are directly connected to a central switch. Data is transmitted between devices through the switch. Eg: Ethernet networks.
Advantages: Easy to troubleshoot, isolate faults and expand the network.
Disadvantages: Heavily reliant on the central switch, entire network is affected if the switch fails.

3. Ring topology: All devices are connected to each other in a closed loop. Data is transmitted in only one direction around the ring. Eg: Token ring networks.
Advantages: Fault tolerance as the network can reroute in case of device/link failure.
Disadvantages: Data transmission is delayed as it has to pass through each device, difficult to troubleshoot and expand.
