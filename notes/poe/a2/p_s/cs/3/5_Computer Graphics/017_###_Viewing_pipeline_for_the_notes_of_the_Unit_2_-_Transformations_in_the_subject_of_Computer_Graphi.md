### ISP

ISP stands for Internet Service Provider. An ISP is a company that provides access to the internet and other related services such as web hosting, email, etc.

- Some of the major ISPs are companies like Comcast, AT&T, Verizon, etc.
- ISPs operate networks which are a combination of infrastructure like routers, cables, telephone lines, satellites, etc to provide internet connectivity to customers.
- Customers can choose from various plans provided by ISPs based on speed, data usage, costs, etc.
- ISPs are an important part of the internet as they enable access to the web and other online services for end users.
- However, some ISPs have also been criticized for issues like throttling speeds, privacy violations, unfair practices, etc.

### Viewing pipeline for the notes of the Unit 2 - Transformations in the subject of Computer Graphics

The viewing pipeline for transformations in computer graphics consists of the following steps:

1. Modeling transformation: The object is defined in model coordinates which are converted to world coordinates. This conversion is done through modeling transformation which involves translation, rotation, and scaling.
2. Viewing transformation: The world coordinates are converted to eye coordinates or camera coordinates. This is done through viewing transformation which includes translation and rotation.
3. Projection transformation: The 3D scene is projected onto the 2D viewport. This is done through projection transformation which involves perspective projection or orthographic projection.
4. Viewport transformation: The 2D viewport is converted to pixel coordinates on the screen. This final transformation is viewport transformation where the 2D viewport coordinates are scaled to fit the dimensions of the screen.

Through these transformation steps, 3D scenes are rendered and displayed on the 2D screen. Transformation matrices are used to denote the affine transformations in each step.
