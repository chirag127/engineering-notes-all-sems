### Entity Relationship Model
- The Entity Relationship (ER) model is a conceptual data model that views the real world as entities and relationships between entities.
- An entity is a person, place, thing, or event that is of interest to the organization.
- A relationship is an association between two or more entities.
- Attributes are descriptive properties possessed by each entity type.
- Cardinality refers to the number of entity occurrences to which another entity can relate.
- Keys are attributes that uniquely identify each entity occurrence.
- Diagrams are pictorial representations of entity types, attributes, and relationships.

### Entities and Entity Types
- An entity is a person, place, thing, transaction, or event about which data is stored.
- An entity type is a collection of entities that share common properties.
- An entity type is usually denoted by a noun.
- An entity occurrence (or instance) is a single entity that is a member of an entity type.

### Attributes
- Attributes are descriptive properties that characterize entities.
- Each entity type has a set of attributes.
- Attributes are usually denoted by adjectives or noun phrases.
- The set of attributes for an entity is called its schema.
- A key attribute (or candidate key) uniquely identifies each entity occurrence.
