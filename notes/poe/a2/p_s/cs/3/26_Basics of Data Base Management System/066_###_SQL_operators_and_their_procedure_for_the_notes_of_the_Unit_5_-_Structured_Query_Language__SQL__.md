#### SQL Operators
The following are the commonly used SQL operators:

- Arithmetic operators: +, -, *, /, %
Used to perform arithmetic operations like addition, subtraction, multiplication, division and modulus on numeric data.

- Comparison operators: =, !=, >, <, >=, <=
Used to compare values for equality, inequality, greater than, less than, greater than or equal to, less than or equal to, etc. and return a boolean result.

- Logical operators: AND, OR, NOT
Used to combine conditional statements and return boolean results.

- IS NULL, IS NOT NULL
Used to check if a value is NULL or not NULL.

- LIKE, NOT LIKE
Used for pattern matching to search for a specified pattern in a column.

- IN, NOT IN
Used to specify multiple possible values in a WHERE clause.

#### SQL Procedures
The common procedures in SQL are:

- SELECT - retrieves data from the database
- UPDATE - updates data in the database
- DELETE - deletes data from the database
- INSERT INTO - inserts new data into the database
- CREATE DATABASE - creates a new database
- ALTER DATABASE - modifies a database
- CREATE TABLE - creates a new table
- ALTER TABLE - modifies a table
- DROP TABLE - deletes a table

The procedures are used along with the operators and other clauses to query and manipulate the data in the database. The order of execution of procedures is important to get the desired results.
