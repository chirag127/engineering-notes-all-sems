### Overall Database Structure for Unit 1 - Introduction

1. What is a Database?
- A database is a collection of information that is organized so that it can be easily accessed, managed and updated.
- The most common type of database is the relational database, which uses a table-based structure.

2. Why do we need Databases?
- To organize data in a systematic manner.
- To reduce data redundancy and inconsistency.
- To share data among multiple users and applications.
- To provide security and protection of data.
- To facilitate decision making by providing relevant information quickly and efficiently.

3. Advantages of Database Management Systems (DBMS)
- Data integration: A DBMS integrates the data for an organization into a single system. This makes it easier to manage the data.
- Backup and Recovery: DBMS provides features for taking backups of data and recovering from failures. This increases the reliability of the data.
- Data Security: Only authorized users can access the data in a database. DBMS provides security features like access control and encryption to prevent unauthorized access.
- Data Abstraction: DBMS creates an abstract view of the data for the users. Users do not need to know the physical details of how the data is stored.
-Data Control: DBMS controls the redundancy in the data, integrity constraints, and authorization of access to the data. This ensures accuracy and consistency of the data in the database.
