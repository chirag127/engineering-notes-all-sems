### Data Models

The following are the major data models used in database systems:

1. Hierarchical Model:
- Data is organized into a tree-like structure with a parent-child relationship.
- Each record can have only one parent record.
- Examples: organizational chart, bill of materials.
- Advantages: simplicity, efficiency.
- Disadvantages: inflexibility, lack of connectivity among records at the same level.

2. Network Model:
- Data is organized into a graph structure with connections between records.
- A record can have multiple parent and child records.
- Examples: network database model.
- Advantages: flexibility, connectivity among records.
- Disadvantages: complexity, inefficiency.

3. Relational Model:
- Data is organized into tables (relations) with rows and columns.
- Relations can be linked together.
- Examples: relational database management system (RDBMS).
- Advantages: simplicity, flexibility, wide usage.
- Disadvantages: joins can lead to inefficiencies.

4. Object-Oriented Model:
- Data is represented as objects with attributes and behaviors.
- Objects are linked in class hierarchies.
- Examples: object database management system (ODBMS).
- Advantages: maps well to the real world, support for complex data.
- Disadvantages: performance overhead, lack of standardization.
