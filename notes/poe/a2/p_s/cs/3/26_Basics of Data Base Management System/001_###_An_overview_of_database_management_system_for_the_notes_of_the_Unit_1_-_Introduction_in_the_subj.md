### An overview of database management system for the notes of the Unit 1 - Introduction in the subject of Basics of Data Base Management System

A database management system (DBMS) is a software application that interacts with end users, applications, and the database itself to capture and analyze data. A DBMS allows a user to manipulate data, store data securely, retrieve data, and perform other functions.

-   **Data definition language:** Allows administrators to define data structures. For example, CREATE, ALTER, and DROP statements are used to define, modify, and remove database objects respectively.
-   **Data manipulation language:** Allows users to manipulate data. For example, INSERT, UPDATE, and DELETE statements are used to insert, update, and delete data respectively.
-   **Query language:** Allows users to retrieve data. For example, a SELECT statement is used to fetch data from a database that matches specified criteria.
-   **Transaction management:** Ensures that all transactions are processed reliably. Transactions must be atomic, consistent, isolated, and durable (ACID).
-   **Security management:** Prevents unauthorized access to data. The DBMS controls user access and privileges to maintain data security and integrity.
-   **Storage management:** Manages data storage and data access. The DBMS stores data on memory or hard disks and manages data access efficiently.
-   **Concurrency control:** Prevents multiple transactions from interfering with each other to maintain data consistency. For example, concurrency control ensures that two transactions do not try to update the same data at the same time.
-   **Backup and recovery:** Backs up data regularly and recovers data if a failure occurs. The DBMS backs up data periodically and recovers data and database objects if a system failure occurs.

Advantages:
-   Data redundancy is reduced as data is stored in a single place.
-   Data integrity is better maintained through constraints and validation checks.
-   Security is enhanced as access can be controlled through authentication and privileges.
-   Data independence is increased as programs are isolated from physical storage details.
-   Concurrent access is enabled which increases performance.
