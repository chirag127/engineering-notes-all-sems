## Unit 4 - Data Base Design & Normalization

1. Database Design - The process of producing a detailed data model of a database. It includes identifying entities, their attributes, and relationships. The goal of database design is to create a database that is:
- Accurate: Reflects the real world scenario.
- Consistent: Follows the same standards and formats.
- Integrated: Data is stored in a consistent, compatible format.
- Accessible: Data is available, secure, and usable.

2. Principles of Database Design - There are three main principles:
- Simplicity - Keep the design as simple as possible to avoid redundancy and ensure understandability.
- Maintainability - The database must be easily maintained and edited as requirements change.
- Expandability - The database design must allow for growth and changes to the database structure as the system evolves.

3. Normalization - The process of organizing data in a database to reduce redundancy and improve data integrity. The main types of normalization are:
- First Normal Form (1NF) - There are no duplicate rows in the table.
- Second Normal Form (2NF) - The table is in 1NF and all non-key columns depend on the primary key.
- Third Normal Form (3NF) - The table is in 2NF and all non-key columns must depend only on the primary key.
