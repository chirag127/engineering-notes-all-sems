### Structured Query Language (SQL)

- SQL is a standard language for accessing and manipulating databases.
- It is an ANSI (American National Standards Institute) standard.
- SQL commands are used to perform tasks such as updating data on a database, retrieving data, and creating databases and tables.
- Some common SQL commands are:

SELECT - retrieves data from the database
UPDATE - updates data in the database
DELETE - deletes data from the database
INSERT INTO - inserts new data into the database
CREATE DATABASE - creates a new database
ALTER DATABASE - modifies a database
CREATE TABLE - creates a new table
ALTER TABLE - modifies a table
DROP TABLE - deletes a table

- Advantages of SQL:

- It is easy to learn.
- It is simple and flexible.
- It is suitable for both simple and complex queries.
- It supports multiple tables and relationships between tables.
- It is supported by all major database systems.

- Examples of SQL queries:

SELECT * FROM customers; // Retrieves all columns from customers table
SELECT name, age FROM customers; // Retrieves specific columns from customers table
UPDATE customers SET age = 30 WHERE name = 'John'; // Updates age to 30 for customer named John
INSERT INTO customers (name, age) VALUES ('Jack', 25); // Inserts a new customer named Jack, aged 25

- Applications of SQL:

- SQL is used to query, manipulate and transform data from a relational database.
- It is widely used for websites and web applications to store and retrieve data.
- It is used in data science and business intelligence to analyze data and gain business insights.
- Almost all major database systems like MySQL, Oracle, Microsoft SQL Server, PostgreSQL, etc. use SQL to access and manage data.
