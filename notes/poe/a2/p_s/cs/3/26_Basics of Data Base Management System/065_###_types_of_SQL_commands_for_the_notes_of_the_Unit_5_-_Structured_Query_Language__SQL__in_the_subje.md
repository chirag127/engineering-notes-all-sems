### Types of SQL commands:

1. Data Definition Language (DDL): These commands are used to define the database structure. Some common DDL commands are:

- CREATE: Creates a new database, table, index, etc.
- ALTER: Alters an existing database object.
- DROP: Deletes an existing database object.

2. Data Manipulation Language (DML): These commands are used for manipulating the data in the database. Some common DML commands are:

- INSERT: Inserts new data into a table.
- UPDATE: Updates existing data in a table.
- DELETE: Deletes existing data from a table.

3. Data Query Language (DQL): These commands are used for retrieving data from the database. The most commonly used DQL command is:

- SELECT: Retrieves data from a database table that matches a specified criteria.

4. Transactional Control Language (TCL): These commands are used to manage the changes made by DML statements. Some common TCL commands are:

- COMMIT: Saves the changes made by DML statements permanently to the database.
- ROLLBACK: Reverts the changes made by DML statements and restores the database to its previous state.

5. Data Control Language (DCL): These commands are used to control access to the database. Some common DCL commands are:

- GRANT: Gives permissions or privileges to users.
- REVOKE: Removes permissions or privileges given to users.

The above points cover the major types of SQL commands along with common examples of commands under each type. These commands can be used in combinations to perform various database operations. Understanding these commands is essential to work with databases using SQL.
