### Database Languages and Interfaces

- **Data Definition Language (DDL)**: Used to define the database structure. Examples: CREATE, ALTER, DROP.
- **Data Manipulation Language (DML)**: Used to manipulate data within the database. Examples: INSERT, UPDATE, DELETE.
- **Data Query Language (DQL)**: Used to query the database and retrieve data. Example: SELECT.
- **Data Control Language (DCL)**: Used to control access to the database. Examples: GRANT, REVOKE.
- **Procedural Language**: Used to define procedures to be used for accessing and manipulating data. Examples: PL/SQL, SQL/PSM.
- **Interfaces**: Languages and tools used to interact with the database. Examples: ODBC, JDBC, SQL, PHP, Python, etc.

Advantages of using standard interfaces:
- Avoid vendor lock-in. Code can be ported to databases from different vendors.
- Increased interoperability. Different applications can access the same database.
- Reduced learning curve. Need to learn only one standard language instead of proprietary ones.

Disadvantages:
- May not be able to utilize vendor-specific advanced features.
- Standard languages may not be as efficient as proprietary ones.
- Additional abstraction layer can affect performance.

Examples of databases and interfaces:
- MySQL database can be accessed using MySQL SQL, PHP, Python, etc.
- SQL Server can be accessed using T-SQL, ODBC, JDBC, .NET, etc.
- Oracle database can be accessed using SQL, PL/SQL, ODBC, JDBC, etc.

Applications: Used by database administrators to maintain the database and by developers to build database applications. Standard interfaces enable interoperability between different applications and databases.
