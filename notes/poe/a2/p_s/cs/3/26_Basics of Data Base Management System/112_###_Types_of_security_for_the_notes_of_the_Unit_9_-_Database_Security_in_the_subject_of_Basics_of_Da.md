### Types of security for the notes of the Unit 9 - Database Security in the subject of Basics of Data Base Management System

1. Authorization - It controls what a user can do. It ensures that the users can only access the data and resources that they are authorized to access. It is managed through granting and revoking of privileges.
2. Authentication - It controls who can log into the database. It is used to verify the identity of users trying to access the database. It is done through passwords, biometrics, OTP, etc.
3. Access control - It controls how users can access the data. It can be discretionary, mandatory or role-based. Discretionary access control allows owners to control access. Mandatory access control is based on security labels. Role-based access control assigns permissions to roles and users are assigned roles.
4. Auditing - It tracks and logs the database activities including successful and failed logins, data access, etc. The audit trails are used to monitor violations and identify potential threats.
5. Data encryption - It converts the data into unreadable code that cannot be understood by unauthorized users. It ensures data confidentiality and is used to protect sensitive data. The encryption keys are used to encrypt and decrypt the data.
6. Backup - It creates copies of the database which can be used in case of loss of data or disasters. Backup needs to be kept secure and separate from the original database.
7. Application security - The database applications and interfaces need to be secured to prevent SQL injection, cross-site scripting attacks, etc. The user input needs to be sanitized and permissions need to be enforced at the application level too.

The above points cover the major types of security aspects that can be implemented in a database to ensure data security, integrity, and availability. Appropriate security measures need to be chosen based on the data sensitivity and system requirements. A combination of multiple security types may be required for highly critical data and systems.
