### Structured Query Language (SQL)

- SQL is a standardized language for storing, manipulating and retrieving data in relational databases.
- It is pronounced as "sequel".
- It allows users to access data in relational database management systems.
- It is a declarative language, which means that it specifies what needs to be done rather than how it is done.
- Some of the basic SQL commands are:

SELECT - retrieves data from the database
UPDATE - updates data in the database
DELETE - deletes data from the database
INSERT INTO - inserts new data into the database
CREATE DATABASE - creates a new database
ALTER DATABASE - modifies a database
CREATE TABLE - creates a new table
ALTER TABLE - modifies a table
DROP TABLE - deletes a table

- Examples of SQL queries:

SELECT * FROM customers; - selects all columns from customers table
SELECT name, age FROM customers; - selects name and age columns from customers table
UPDATE customers SET age = 30 WHERE name = 'John'; - updates age to 30 for all customers named John
DELETE FROM customers WHERE name = 'John'; - deletes all customers named John

- Advantages of SQL:

It is easy to learn.
It is simple and elegant.
It is platform independent.
It is standardized.
It is safe and secure.
It provides a clear interface between the database and the application programs.

- Disadvantages of SQL:

It may involve complex queries.
It lacks support for complex data types and structures.
It lacks support for database design features like triggers.
It has limitations with very large databases.

- Applications of SQL:

It is widely used to query, manipulate and transform data from a relational database.
It is the standard database language used in software applications, websites and machine learning.
Almost all major database software supports SQL.
It is a key skill required for many jobs like data scientists, data analysts, software engineers, etc.
