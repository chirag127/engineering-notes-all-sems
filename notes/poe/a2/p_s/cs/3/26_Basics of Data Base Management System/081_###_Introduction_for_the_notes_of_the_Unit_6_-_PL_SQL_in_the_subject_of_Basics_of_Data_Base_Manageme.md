### Introduction for the notes of the Unit 6 - PL/SQL in the subject of Basics of Data Base Management System

PL/SQL (Procedural Language/Structured Query Language) is a procedural extension of SQL that is used to access and manipulate data in an Oracle database. It provides a complete solution to develop database applications in the server-side.

The key points about PL/SQL are:

- It is a block-structured language that supports variables, loops, conditional logic, exceptions, procedures, functions, packages, etc.
- It integrates tightly with SQL and extends the capabilities of SQL.
- It improves performance, security, and integrity of database applications.
- It executes on the database server instead of the client. This eliminates network traffic and provides better performance and security.
- It supports object-oriented features like encapsulation, information hiding, etc.
- It follows the standard  SQL expressions syntax.

The advantages of PL/SQL are:

- Improved performance due to execution on the server-side.
- Tight integration with SQL.
- Increased productivity due to the procedural approach.
- Reusability of code using procedures, functions, and packages.
- Easy debugging and error handling.
- Scalability due to features like exceptions, collections, etc.

The typical applications of PL/SQL are:

- Stored procedures and triggers.
- Complex data manipulation and queries.
- Efficient processing of bulk data.
- Pre-validation and data security enforcement through triggers.
- Automated tasks like automatic archiving, data audit trails, etc.
