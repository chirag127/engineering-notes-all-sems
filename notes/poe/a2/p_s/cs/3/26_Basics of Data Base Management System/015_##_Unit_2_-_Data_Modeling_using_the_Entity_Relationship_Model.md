## Unit 2 - Data Modeling using the Entity Relationship Model

1. Entity Relationship Model: The Entity Relationship (ER) model is a conceptual data model that views the real world as entities and relationships between entities. An entity is an object that exists independently, like a person, place, thing, event, etc. Relationships show how entities interact. The key components of the ER model are:

- Entities: Represented by rectangles with named attributes
- Attributes: Descriptive properties of entities
- Relationships: Represented by diamonds, show interactions between entities
- Cardinality: The number of occurrences of one entity related to another

2. Entity Types: Entity types are categories of entities that share common characteristics. For example, customer, product, order, etc. An entity type can have multiple entities. Entity types are represented by rectangles containing the entity name.

3. Attributes: Attributes are descriptive properties possessed by each entity type. For example, name, address, age, price, quantity, etc. Attributes are displayed inside the rectangle representing the entity type.

4. Relationships: Relationships show how entity types interact. A relationship type is a category of relationships. For example, places an order, purchases a product, etc. Relationship types are represented by diamonds containing the relationship name. Cardinality specifies the number of occurrences of one entity related to another.
