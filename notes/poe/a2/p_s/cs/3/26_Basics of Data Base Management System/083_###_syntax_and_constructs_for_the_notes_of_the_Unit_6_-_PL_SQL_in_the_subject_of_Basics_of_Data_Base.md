### 1. Introduction to PL/SQL

- PL/SQL is Oracle's procedural extension to SQL. It enables you to mix SQL statements with the procedural features of programming languages.
- PL/SQL adds variables, conditions, loops, error handling, procedures, functions, packages, and other programming language elements to SQL.
- PL/SQL code is processed by the Oracle Database server. PL/SQL enhances SQL functionality and is tightly integrated with the database.

### 2. Block structure

- A PL/SQL block is defined by the keywords DECLARE, BEGIN, EXCEPTION, and END.
- The DECLARE section is optional and is used to declare variables and cursors.
- The BEGIN section contains the executable statements.
- The EXCEPTION section handles errors and exceptions.
- The END closes the block.

### 3. Data types

- PL/SQL supports a number of built-in data types including:
    - Numeric types: NUMBER, INTEGER, FLOAT, etc.
    - Character types: CHAR, VARCHAR2, LONG, STRING, etc.
    - Boolean type: BOOLEAN
    - Date and time types: DATE
- You can also define your own subtypes based on the built-in types and user-defined types like object types, VARRAYs, nested tables, etc.
