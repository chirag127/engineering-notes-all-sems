## Unit 3 - Relational Database Concepts

1. Relational Model - A relational database organizes data into one or more tables (or relations) of columns and rows, with a unique key identifying each row. Each table or relation represents one entity type. This model provides data independence, scalability, and structural simplicity.

2. Relational Algebra - Relational algebra is a mathematical query language for relational databases. It uses operators to perform queries. The five basic operators are:

- SELECT - Retrieves tuples/rows
- PROJECT - Retrieves columns/attributes
- JOIN - Combines two relations
- UNION - Concatenates two relations
- DIFFERENCE - Removes tuples from one relation that exist in another

3. Relational Calculus - A non-procedural query language. It specifies what to retrieve but not how to retrieve it. There are two forms: tuple relational calculus and domain relational calculus. The former specifies a pattern to search for in tuples, whereas the latter specifies a condition that must hold on an entire relation.

4. Structured Query Language (SQL) - A standardized query language for relational databases. It incorporates the relational algebra and relational calculus into a more user-friendly package. SQL queries can be used to perform the basic relational operations: select, project, join, union, difference.
