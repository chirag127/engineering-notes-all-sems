## What is SQL?

- SQL stands for Structured Query Language.
- It is a language used to query, manipulate and transform data from a relational database.
- It is a standard language for relational database management systems.
- SQL statements are used to perform tasks such as update data on a database, or retrieve data from a database.

## Uses of SQL

- Retrieve data from a database - Using the SELECT statement, we can retrieve data from a database in the form of tables.
- Insert new data into a database - The INSERT statement is used to insert new data into a database.
- Update existing data in a database - The UPDATE statement is used to update existing data in a database.
- Delete data from a database - The DELETE statement is used to delete data from a database.
- Create a new database or table - The CREATE DATABASE and CREATE TABLE statements are used to create a new database or table respectively.
- Perform administrative tasks - SQL is used to grant and revoke permissions to users, backup data, analyze data, etc.

## Advantages of SQL

- It is easy to learn.
- It is compatible with all major DBMS systems like MySQL, Oracle, MS Access, etc.
- It is efficient and powerful.
- It reduces the amount of code required as compared to other programming languages.
- It improves data security as SQL queries can be restricted to certain users and permissions.
