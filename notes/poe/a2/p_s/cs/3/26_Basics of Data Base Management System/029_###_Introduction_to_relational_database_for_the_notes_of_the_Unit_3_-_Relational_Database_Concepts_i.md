### Introduction to relational database

A relational database organizes data into one or more tables (or relations) of columns and rows, with a unique key identifying each row. Relational databases are powerful because they require few assumptions about how the data is structured or how it will be used.

Some key points about relational databases:

- Data is organized into tables (relations) with rows (tuples) and columns (attributes).
- Each column has a unique name and contains values of a particular type (such as integer, float, date, etc.).
- Each row contains a unique value for its primary key, a combination of columns whose values uniquely identify the row.
- Related tables can be linked together using foreign keys.
- Queries are used to retrieve and manipulate data.
- ACID properties guarantee reliable transactions.

Advantages:

- Structured query language (SQL) is simple and powerful.
- Scalable and able to handle large amounts of data.
- ACID transactions provide data integrity.
- Widely used with lots of support.

Disadvantages:

- Data relationships can become complex.
- Joins can degrade performance on large tables.
- Fixed schema can be limiting.
- Normalization can result in several tables.

Applications:

- Storing customer records, order data, etc. for e-commerce and businesses.
- Storing personal contacts and calendar information.
- Storing and managing data for apps.
