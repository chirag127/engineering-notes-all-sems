## Unit 7 - Transaction Processing Concepts

1. Transaction - A transaction is a single logical operation on the data, which may consist of several steps. A transaction processing system manages the transactions. Transactions must satisfy ACID properties:

- Atomicity - Either all steps are completed successfully or none.
- Consistency - Data is consistent before and after the transaction.
- Isolation - Transactions are isolated from each other.
- Durability - Once completed, the transaction is permanent.

2. Transaction Processing Modes:

- Batch processing - Transactions are accumulated and processed at once periodically. Slow, high volume.
- Real-time processing - Transactions are processed immediately as they occur. Fast, low volume.

3. Transaction management:

- Concurrency control - Ensure correct execution of multiple transactions accessing same data simultaneously. Methods: locking, timestamps, optimistic concurrency control.
- Recovery management - Ensure database is consistent even after system failures. Methods: rollback, checkpointing, logging.
