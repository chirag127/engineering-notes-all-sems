### Database System Concepts and Architecture

1. Database: A database is a collection of related data stored in a computer system. The data is organized and stored in such a way that it can be easily accessed, managed and updated.

2. Database Management System (DBMS): A DBMS is a software system that interacts with end users, applications, and the database itself to capture and analyze data. A DBMS manages the data and serves as an interface to interact with the database. It makes it possible for end users to create, read, update and delete data in the database. Examples of DBMS are MySQL, Oracle, MS Access, etc.

3. Data Model: A data model defines the logical design of the database. It determines how the data will be organized and what relationships will exist between the various data elements. The most common data models are:
    - Hierarchical model: Data is organized in a tree-like structure with a root, branches and leaf nodes.
    - Network model: Data is represented by a network of relationships. It is more flexible than the hierarchical model.
    - Relational model: Data is organized in one or more tables of columns and rows. This is the most popular data model for databases.
    - Object-oriented model: Data is represented in the form of objects which may reflect real-world objects.

4. Schema: The schema refers to the overall design of the database. It specifies the data elements, data types of each element, relationships between elements and constraints on the data. The schema is specified during the database design process and is implemented through the data definition language supported by the DBMS.

5. Data Independence: The concept of data independence implies that the application programs should be isolated from changes made to the physical structure of the database. The DBMS achieves this through the use of a data definition language and data manipulation language. This makes the database portable and flexible.
