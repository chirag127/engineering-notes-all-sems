## Unit 6 - PL/SQL

PL/SQL (Procedural Language/Structured Query Language) is Oracle Corporation's procedural extension for SQL and the Oracle relational database.

- PL/SQL is a combination of SQL along with the procedural features of programming languages. It allows you to mix SQL with the procedural capabilities of languages like C/C++, etc.
- PL/SQL supports variables, conditions, loops, exceptions, functions, stored procedures, triggers, etc. which provide more flexibility and control to handle data and business logic.
- PL/SQL code is stored in the database and executed by the database server. This makes it faster than executing similar code in a general purpose programming language.
- Key components of PL/SQL:
    - Block structure: PL/SQL code is grouped into blocks which have a declarative part, executable part and exception handling part.
    - Variables: Used to store data temporarily, similar to variables in other languages.
    - Cursors: Used to process individual rows returned by a multiple-row query.
    - Conditions: Support IF-THEN-ELSIF statements to execute code based on conditions.
    - Loops: Support looping through code using FOR, WHILE, etc.
    - Exceptions: Allow handling of errors/exceptions in a controlled manner.
    - Functions/Procedures: Allow creation of reusable modules to encapsulate logic.
    - Triggers: Allow execution of code automatically when a database event occurs (insert, update, delete).
- Advantages: Increased performance, reduced network traffic, close integration with database, security, modular programming, etc.
- Disadvantages: Vendor dependence (not portable), steep learning curve, debugging difficulties, etc.
