## History of Hadoop

- In 2002, Doug Cutting and Mike Cafarella created Hadoop to support distribution for the Nutch web search engine project.
- In 2003, Hadoop was introduced as an open-source project under the Apache Software Foundation.
- In 2006, Hadoop 0.1 was released with the first version of HDFS and MapReduce.
- In 2008, Hadoop won the top prize at the International DBT2 Big Data Challenge. This increased Hadoop's popularity significantly.
- In 2009, Hadoop 1.0 with a more robust HDFS and MapReduce was released.
- In 2011, Hadoop 2.0 (YARN) was released with a redesigned architecture. YARN separated the resource management and job scheduling/monitoring functions.
- Today, Hadoop 3.x is the current release with continued enhancements for scalability and performance.
- Hadoop has become the foundation of the fast-growing big data industry with its scalable and efficient distributed processing capabilities. It enabled processing huge amounts of data that was not feasible before.
- Advantages: Scalable, Fault-tolerant, Cost-effective, Flexible.
- Disadvantages: Complex to set up and manage, Lacks real-time processing, Requires expertise.
- Applications: Web indexing, data mining, machine learning, financial data processing, etc.

## Data Definition Language(DDL) Statements for the notes of the subject of Database Management Systems Mapping with Virtual Lab Lab

- CREATE: Used to create a new database, table, index, etc. For example, CREATE DATABASE db_name;, CREATE TABLE table_name();
- ALTER: Used to alter an existing database object. For example, ALTER TABLE table_name ADD column_name;, ALTER DATABASE db_name MODIFY NAME = new_db_name;
- DROP: Used to delete an existing database object. For example, DROP TABLE table_name;, DROP DATABASE db_name;
- TRUNCATE: Used to remove all rows from a table quickly. For example, TRUNCATE TABLE table_name;
- COMMENT: Used to add comments to the data dictionary. For example, COMMENT ON TABLE table_name IS 'table description';
- RENAME: Used to rename a database object. For example, RENAME TABLE table_name TO new_table_name;
