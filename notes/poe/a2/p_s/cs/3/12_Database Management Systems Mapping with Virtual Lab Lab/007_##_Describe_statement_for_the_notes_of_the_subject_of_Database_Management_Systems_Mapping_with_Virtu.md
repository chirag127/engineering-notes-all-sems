1. Database Management Systems (DBMS) is a software application that interacts with end users, applications, and the database itself to capture and analyze data. A DBMS makes it possible for end users to create, read, update and delete data in a database.

2. A Virtual Lab is a simulation of a physical laboratory, developed using software. It provides an environment similar to a physical laboratory, allowing the user to perform experiments, learn concepts and acquire skills.

3. The Virtual Lab for DBMS provides simulated environments to learn and practice database concepts and SQL skills. It contains various modules with different scenarios and laboratory experiments for creating, modifying and querying databases.

    - Understand integrity constraints and normalization concepts through simulations
    - Perform transactions and handle concurrency issues
