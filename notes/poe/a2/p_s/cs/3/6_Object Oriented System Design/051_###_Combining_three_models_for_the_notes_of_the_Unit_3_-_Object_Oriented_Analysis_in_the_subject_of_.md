### Combining three models for the notes of the Unit 3 - Object Oriented Analysis in the subject of Object Oriented System Design

- Object Oriented Analysis involves three models to capture the requirements of a system:
- Use Case Model: It captures the functionality of the system from the user's perspective. Use cases are identified and described in terms of actors, preconditions, postconditions, main success scenarios and extensions.
- Domain Model: It represents the vocabulary of the problem domain in terms of objects, attributes and relationships between objects. Class diagrams are created to show a static view of the model.
- Dynamic Model: It shows the dynamic behavior of the system in terms of state changes and flow of control. Sequence diagrams and activity diagrams are used to capture the dynamic aspects.

- These three models are interlinked and combined to get a complete understanding of the system to be designed:
- Use case realizations are mapped to interactions in the dynamic model.
- Classes in the domain model represent actors and concepts in the use case model.
- The dynamic model shows the collaboration between objects and the flow of messages which encapsulate the behaviors defined in the domain model.

- Advantages: Provides a holistic view of the system. Eliminates ambiguity and incompleteness. Useful for understanding, communication and documentation.
- Disadvantages: Can be complex for large systems. Requires highly skilled analysts. Difficult to maintain consistency across models.
- Applications: Used in the analysis phase of software development lifecycle to gather and understand requirements before design and implementation. Useful for object oriented system design.
