 Here are the key Object Oriented language features to cover in the notes for Unit 3 - Object Oriented Analysis:

### Encapsulation
- Hiding the internal details and only exposing the necessary interfaces to the outside
- Achieved through declaring variables/methods as private and only using public getter and setter methods
- Prevents misuse of data and provides more control over the code
- Example: A Student class can have private variables for name, age, etc. and public getter/setter methods to access them

### Inheritance
- Ability to derive a new class from an existing class and inherit its properties/methods
- The existing class is called the base/parent class and the new class is called the derived/child class
- Allows reusability of code and sharing common structure
- Example: A ' vehicle' class can have methods like start() and stop(). 'Car' and 'Bike' classes can inherit from 'Vehicle' and add more specific methods.

### Polymorphism
- Having multiple forms/classes that share a common interface
- Achieved through method overloading (compile time) and method overriding (runtime)
- Allows performing a single action in different ways
- Example: The 'start()' method can be implemented differently in 'Car' and 'Bike' classes inherited from 'Vehicle' as per their requirements. The interface remains the same.
