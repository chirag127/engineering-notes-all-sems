### Information Hiding

- Information Hiding is a technique where the internal details of a system are hidden from the external world and only the required interfaces are exposed.
- This is achieved by defining clearly separated interfaces which hide the implementation details.
- The advantages of information hiding are:
    - The complexity of the system is reduced. The users of the system do not need to know about the internal complexities and can focus on the functionality provided by the interfaces.
    - The internal implementations can be changed without affecting the external interfaces. This makes the systems flexible to changes.
    - The security of the system is increased as only the required interfaces are exposed to the external world.
- In Object Oriented Programming, information hiding is achieved through encapsulation. The data is hidden within the class through private access modifiers and only the required functionalities are exposed through public methods.
- For example, a simple calculator class can hide the complex arithmetic operations inside and only expose methods to get input and display output. This reduces the complexity for the users of the calculator class.
- In summary, information hiding increases the modularity of the system and reduces complexity by separating the interface and implementation. It is an important concept in Object Oriented Design to build flexible and secure systems.
