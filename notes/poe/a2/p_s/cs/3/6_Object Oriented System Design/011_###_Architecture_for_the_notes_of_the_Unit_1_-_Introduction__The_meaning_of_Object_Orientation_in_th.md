### Architecture for the notes of the Unit 1 - Introduction: The meaning of Object Orientation in the subject of Object Oriented System Design

1. Object Oriented Programming (OOP): OOP is a programming paradigm based on the concept of "objects", which can contain data in fields (attributes), and code in procedures (methods).
- Objects: An object is an instance of a class. It has its own state, and a set of behaviors.
- Class: A class is a blueprint from which individual objects are created. It defines properties and methods for its objects.
- Encapsulation: Hiding the internal details of how an object works. Only the essential information is provided to the outside.
- Inheritance: The ability for a class to inherit the properties and methods of another class. This allows code reuse and promotes hierarchy.
- Polymorphism: The ability of an object to take on different forms based on the context. This allows the same interface to have different underlying implementations.

2. Benefits of OOP:
- Modularity: The source code is divided into modules (objects) that have specific functions. This makes the code more organized, reusable and maintainable.
- Extensibility: New functionality can be easily added to an application by creating new objects. This makes OOP suitable for complex and evolving systems.
- Abstraction: OOP allows handling complexity by hiding unnecessary details and only showing the essentials. This makes the code easier to understand and less prone to errors.
- Productivity: OOP leads to faster and more efficient development of software as it reuses code and is based on prototypes from which new objects can be created.

3. Examples and Applications:
- Real-world modeling: OOP mimics real-world entities, so it is intuitive and easy to understand. For example, a banking system can have objects for accounts, customers, transactions, etc.
- GUI applications: The graphical user interfaces of applications are built using objects, for example windows, buttons, menus, etc.
- Operating systems: Modern operating systems are designed using OOP concepts. Processes, files, memory, etc. can be represented as objects.
- Database systems: Object-relational mapping is used to represent data from relational databases as objects in OOP.
- And many more...OOP is a very broad concept used in virtually all areas of software engineering.
