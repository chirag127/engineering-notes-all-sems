### Introduction to UML for the notes of the Unit 1 - Introduction: The meaning of Object Orientation in the subject of Object Oriented System Design

- UML stands for Unified Modeling Language. It is a standardized general-purpose modeling language in the field of software engineering.
- UML uses graphical notations to visually express the design of software projects. It facilitates communication between stakeholders, reduces the gap between problem space and solution space, and maintains consistency in artefacts.
- The key components of UML are:
    - Things - which represent objects, components of a system
    - Relationships - which represent connections between things
    - Diagrams - which are graphical representations of things and relationships
- The key diagrams used in UML are:
    - Class Diagram - represents classes, interfaces, and collaborations and their relationships
    - Object Diagram - represents instances of things and their relationships at a specific point in time
    - Use Case Diagram - represents interactions between external actors and a system
    - Sequence Diagram - represents interactions between objects or components in terms of sequence of messages
    - Activity Diagram - represents the workflow or business process and the flow of control from activity to activity
    - State Machine Diagram - represents the states of a system and transitions between states
    - Component Diagram - represents components, connectors, and relationships in a system
    - Deployment Diagram - represents hardware used to deploy and run a system
- The key benefits of using UML are:
    - It provides a common language for stakeholders to communicate design decisions and ideas.
    - It provides a big-picture overview of a system, makes complex software easier to understand.
    - It enables early detection of flaws in the design and allows making required changes easily.
    - It facilitates automatic code generation to boost productivity.
    - It enhances reusability and portability.
