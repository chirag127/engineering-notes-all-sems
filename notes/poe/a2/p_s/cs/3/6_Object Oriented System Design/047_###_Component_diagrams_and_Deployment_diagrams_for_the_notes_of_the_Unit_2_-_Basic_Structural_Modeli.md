### Component diagrams and Deployment diagrams for the notes of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design

Component diagrams:

- Component diagrams show the components that make up a system, and the dependencies between them.
- They are used to describe the high-level structure of software systems.
- The components represent code modules, executable software, or services.
- The dependencies between components are shown using directed arrows.
- Components can be interior (internal to a system) or exterior (external to a system).
- They help visualize the gross structure of a system/software and identify candidates for reuse.

Advantages:
- Aid in understanding a complex system.
- Identify reusable components.
- Effective for visualizing, documenting, and communicating architectural structures.

Deployment diagrams:

- Deployment diagrams show the configuration of run-time processing elements and the software components that live on them.
- They are used to describe the hardware used in system implementations and the execution environments and artifacts deployed on the hardware.
- They show the mapping of software components onto processing nodes.
- Nodes represent either hardware devices or software execution environments.
- Components represent the software applications deployed on the nodes.
- They are useful for visualizing, specifying, constructing, and documenting the physical deployment view of a system.

Advantages:
- Aid in visualizing and communicating the physical configurations of a distributed system.
- Facilitate checking that a system's software is deployable.
- Useful for system deployment, migration, and configuration management tasks.

Examples and applications of both the diagrams can be given. Detailed ASCII diagrams can be included to represent the components and dependencies or nodes and components and their relationships respectively. Overall, these diagrams are useful in getting a high-level overview of the structure of a software system and its deployment on processing hardware.
