Structured analysis and structured design (SA/SD) is a system development approach that emphasizes planning and organizing the system development effort. It uses data flow diagrams and structure charts to model the system and its components in a hierarchical manner.

The main steps in SA/SD are:

1. Problem definition - Identify and document the problem to be solved.
2. Requirements analysis - Determine system requirements.
3. Logical design - Develop data flow diagrams and data dictionary.
4. Physical design - Develop structure charts and convert to code.

Advantages:

- Focus on planning and organization.
- Uses graphical models which are easy to understand.
- Decomposition produces manageable components.
- Documentation provides a good record of the system.

Disadvantages:

- Can be time-consuming.
- The approach is not iterative and does not accommodate changes well.
- The graphical models can become complex for large systems.

Examples: The approach has been used to develop many business information systems. It was popular in the 1970s and 1980s but is less used today due to the limitations. However, the techniques are still useful for visual modeling and planning of systems.

Applications: SA/SD can be applied to the analysis and design of business information systems and other types of systems where a structured approach is appropriate. The data flow diagrams and structure charts can be useful tools for visual modeling even when a different overall approach is taken.
