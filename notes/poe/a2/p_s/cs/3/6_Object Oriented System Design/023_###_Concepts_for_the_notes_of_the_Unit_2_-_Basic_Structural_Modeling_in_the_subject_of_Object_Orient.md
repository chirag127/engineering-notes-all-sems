### Concepts for the notes of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design

1. Class Diagrams - Class diagrams are the most common diagrams used in object-oriented analysis and design. They show the classes in a system, their relationships, and the operations and attributes of the classes.

- Class - A class is a blueprint that defines the structure and behavior of a particular type of object. It includes attributes that describe the state of an object, and methods that describe the behavior of an object.
- Attribute - An attribute is a property of a class that describes a range of values that instances of the class can hold.
- Method - A method is an operation that can be performed on objects of a given class. Methods are used to model the behavior of a class.
- Relationships - Relationships between classes can include association, aggregation, composition, dependency, generalization, and realization. These relationships aid in modeling interactions and connections between classes.

2. Use Case Diagrams - Use case diagrams model the functionality of a system using actors and use cases. They are often used to provide an overview of all the use cases that a system must support.

- Actor - An actor is a person, organization, or external system that interacts with the system. Actors represent roles that users of a system can take.
- Use Case - A use case describes a set of sequences of actions that a system performs to achieve a goal. Use cases represent high-level system functions.
