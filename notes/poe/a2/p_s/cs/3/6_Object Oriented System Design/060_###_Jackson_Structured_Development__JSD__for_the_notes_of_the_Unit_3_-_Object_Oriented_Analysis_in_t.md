### Jackson Structured Development (JSD)

- JSD is a method for system development created by Michael A. Jackson. It focuses on structured programming and program design.
- In JSD, a system is developed in steps called *JSD Phases*. Each phase consists of activities called *JSD Tasks*.
- The phases of JSD are:
    1. Problem Definition
    2. Requirements Analysis
    3. Structural Modeling
    4. Top-Down Structural Programming
    5. Unit Testing
- Some key tasks in JSD are:
    - Task 1 - Understand the problem thoroughly
    - Task 2 - Identify major processes & data structures
    - Task 3 - Create data flow diagrams
    - Task 4 - Create Structure Chart diagrams
    - Task 5 - Create Top-Down Structured Program Design Language (TDS-PDL)
- The major advantage of JSD is it separates the tasks so as to avoid overload & keeps the development systematic. It also focuses on proper documentation & testing at each step.
- However, JSD can be rigid & time-consuming for large projects. It may not be suitable for projects with vague or rapidly changing requirements. It also relies heavily on structured programming which can be limiting.
- JSD is best suited for medium-sized software projects with fixed requirements where structured development & proper documentation is important. It can be a good methodology to learn fundamentals of system design & structured programming.
