### Object oriented design for the notes of the Unit 3 - Object Oriented Analysis in the subject of Object Oriented System Design

1. Class Diagram: A class diagram is a type of static structure diagram that describes the structure of a system by showing the system's classes, their attributes, operations (or methods), and the relationships among objects.
- Classes are represented by rectangles with three sections: the top section contains the class name; the middle section contains the attributes (data structures); and the bottom section contains the methods (functions).
- Relationships between classes are represented using arrows. The arrow points to the class that "owns" or "contains" the other class.
- Advantages:
    - Model the static view of an application.
    - Describe the vocabulary of a problem domain.
- Disadvantages:
    - Does not model the dynamic behavior of a system.
    - Does not show concurrency.

2. Object Diagram: An object diagram is an instance of a class diagram. It shows a collection of objects and their relationships. Object diagrams are useful to model the interactions between objects.
- Objects are represented as rectangles with object names inside.
- Relationships between objects use the same notations as in class diagrams.
- Advantages:
    - Shows examples of objects and their relationships.
    - Useful for explaining and demonstrating how a system works.
- Disadvantages:
    - Does not scale well for large systems with many objects.
    - Does not capture the dynamic aspects of a system.
