### Class Diagram
- A class diagram is a type of static structure diagram that describes the structure of a system by showing the system's classes, their attributes, operations (or methods), and the relationships among objects.
- It is the main diagram to visually represent the static view of an application.
- Classes are represented by rectangles, attributes are represented by ovals, and methods are represented by ovals with the operation name inside.
- Relationships between classes include association, aggregation, and composition.
- Class diagrams are useful to both analysts and designers, and for both analysis and design purposes.

### Association
- An association represents a relationship between two classes that indicates one class knows about, and in some way depends on, the other in order to function.
- It is a structural connection or channel between classes.
- It is denoted by a solid line. It can be unidirectional or bidirectional.
- The adornments used are name, role names, multiplicity, visibility.
- Multiplicity can be one (1), many (*) or a specific number (2-4).
- Visibility can be represented by + (public), - (private) or # (protected).
