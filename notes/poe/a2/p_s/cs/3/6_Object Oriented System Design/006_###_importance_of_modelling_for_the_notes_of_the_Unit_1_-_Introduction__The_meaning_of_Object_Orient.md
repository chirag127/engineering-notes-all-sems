### Importance of Modelling for Object Oriented System Design

1. Models the real world: Object oriented modelling techniques model the real world scenario into objects, attributes and relationships which makes it easy to understand and relate to. The objects and its attributes represent entities and its properties in the real world. The relationships between objects map the dependencies between entities. This makes the system design easy to comprehend and evaluate.
2. Abstraction: By representing complex real world scenarios in the form of objects, attributes and relationships, object oriented modelling achieves abstraction. This hides the underlying complexity and gives the designer a simplified view to work upon.
3. Extensibility: The object oriented models are extensible. New objects and relationships can be easily added to the model to incorporate additional aspects or features. The existing objects and relationships can also be modified as required. This makes the object oriented models flexible and scalable.
4. Communication: The object oriented models act as a means of communication between the clients, developers and other stakeholders. The visual representation through diagrams is easy to understand and discuss upon. This avoids miscommunication and ensures that the final product meets the requirements.
5. Reusability: The object oriented models can be reused in other scenarios as well by making relevant changes to objects and relationships. This reusability saves effort and time in designing systems for problems with similar nature.

The above points highlight the key importance of modelling in object oriented system design. The models form the blueprints based on which the system is built. A well designed model leads to an efficient and effective system.
