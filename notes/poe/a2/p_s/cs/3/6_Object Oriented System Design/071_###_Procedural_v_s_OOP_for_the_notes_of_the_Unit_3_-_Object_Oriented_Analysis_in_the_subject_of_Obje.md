### Procedural v/s OOP for the notes of the Unit 3 - Object Oriented Analysis in the subject of Object Oriented System Design

Procedural Programming:
- In procedural programming, the program is divided into small procedures/functions that operate on data.
- Data is exposed globally and can be accessed/modified by any procedure.
- There is no concept of objects and methods in procedural programming.
- Examples: C, Pascal, FORTRAN, BASIC, etc.

Object Oriented Programming (OOP):
- In OOP, programs are designed using objects and classes.
- Objects have data (attributes/fields) and code (methods) associated with them.
- Data is encapsulated or hidden within objects and can only be accessed via methods.
- OOP supports features like inheritance, polymorphism, abstraction, etc.
- Examples: C++, Java, Python, C#, etc.

Differences:
- OOP focuses on objects and their interactions while procedural programming focuses on procedures and functions.
- Data hiding and encapsulation is possible in OOP using objects, classes and access modifiers while data is globally accessible in procedural programming.
- Code reusability is higher in OOP due to concepts like inheritance. Procedural programming reuse code using functions and procedure calls.
- OOP models real world problems well using objects and their relationships. Procedural programming may not be able to model complex problems easily.

Advantages of OOP:
- Increased code reusability.
- Better maintainability as objects can be reused.
- Easier to model real world problems.
- Data hiding and encapsulation increases security of data.
- Polymorphism and inheritance lead to more robust designs.

Disadvantages of OOP:
- Increases complexity due to new concepts like inheritance and polymorphism.
- Programs may run slower due to runtime polymorphism.
- Difficult for programmers without OOP experience to understand/modify code.
