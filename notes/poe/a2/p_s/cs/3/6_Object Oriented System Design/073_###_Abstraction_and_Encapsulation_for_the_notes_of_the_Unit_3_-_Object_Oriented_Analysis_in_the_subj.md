### Abstraction and Encapsulation

Abstraction is hiding the implementation details and showing only functionality to the user.

- It focuses on what the object does instead of how it does.
- The low level details are hidden and only essential features are exposed to the user.
- Example: When you switch on a TV, it shows you the channels and volume options but hides the internal circuitry details from the user.

Encapsulation is wrapping up of data and functions into a single unit.

- The variables and methods are bundled into a single unit.
- The users cannot access the code or data directly.
- They have to use the interface provided to access the data.
- Example: In a capsule, the medicine is encapsulated or wrapped in a capsule shell and the user can only access it through the capsule and not directly.

Advantages:

- The user is isolated from the internal complexities of the system.
- The internal implementation can be changed without affecting the user.
- The users cannot access the data directly leading to data security and protection.
- The software is made more maintainable, flexible and reusable.

Applications:

- Object Oriented Programming uses abstraction and encapsulation to model real world problems.
- Used in API and software development to provide only the required interface to the user.
- Widely used in programming languages like Java, C++, Python, etc.
