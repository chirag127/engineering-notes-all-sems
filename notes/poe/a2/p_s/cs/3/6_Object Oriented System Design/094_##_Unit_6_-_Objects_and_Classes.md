## Unit 6 - Objects and Classes

- Objects are instances of classes. A class is like a blueprint that defines the structure and behaviors of its objects.
- Creating a class:
```python
class MyClass:
    x = 5
```
- Creating an object of a class:
```python
p1 = MyClass()
```
- Attributes are the variables that belong to a class. They are defined inside the class.
- Methods are the functions that belong to a class. They are also defined inside the class and are used to define the behaviors of the objects of that class.
- Encapsulation means hiding the internal details of a class from the outside. The attributes and methods can be made private (name prefixed with __) to prevent external access and change.
- Inheritance allows a new class to inherit the attributes and methods of an existing class. The existing class is the parent/base class and the new class is the child/derived class. This promotes code reusability.
- Overriding is when a method in a child class has the same name as a method in the parent class. In this case, the child class method overrides the parent class method.
- Polymorphism means having multiple forms. In OOP, the same method can do different things depending on the object that invokes it. This allows us to perform a single action in different ways.
- Examples and applications:

- Vehicle class and its sub-classes like Car, Bike
- Employee class and its sub-classes like Manager, Programmer
- Bank Account class
- Complex number class

Advantages:
- Code reusability
- Easy maintenance
- Security through encapsulation
- Models real-world things

Disadvantages:
- Increases complexity
- Require good design skills
