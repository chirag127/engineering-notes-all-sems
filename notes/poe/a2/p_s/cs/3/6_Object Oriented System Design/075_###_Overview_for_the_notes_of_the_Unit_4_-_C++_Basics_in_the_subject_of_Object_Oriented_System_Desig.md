### Overview for the notes of the Unit 4 - C++ Basics in the subject of Object Oriented System Design

1. Introduction to C++
- C++ is a middle-level programming language developed by Bjarne Stroustrup in 1979.
- It is an extension of C language and provides additional features to develop complex applications.
- It supports procedural, functional, generic and object-oriented programming styles.
- It is efficient, flexible and useful for developing system software and application software.

2. C++ Tokens
- The smallest individual elements in a C++ program are known as tokens.
- Tokens are identifiers, keywords, operators, separators, literals, etc.
- Keywords are reserved words with a pre-defined meaning in C++. Eg: int, void, if, else, etc.
- Identifiers are names given to variables, functions, arrays, etc. They follow certain rules.
- Operators are symbols that perform operations on variables and values. Eg: +, -, *, /, etc.
- Separators are symbols that are used to separate tokens. Eg: (, ), {, }, [, ], ;, etc.

3. Variables and Datatypes
- Variables are names of memory locations that store values.
