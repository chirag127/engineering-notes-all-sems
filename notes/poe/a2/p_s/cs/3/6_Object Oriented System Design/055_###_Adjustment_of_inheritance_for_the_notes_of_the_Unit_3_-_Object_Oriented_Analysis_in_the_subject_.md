### Adjustment of inheritance for the notes of the Unit 3 - Object Oriented Analysis in the subject of Object Oriented System Design

- Inheritance is a key feature of Object Oriented Programming which represents the 'is-a' relationship between two classes. It allows the child class to inherit the properties and methods of the parent class.
- For the notes of Unit 3 - Object Oriented Analysis, inheritance can be adjusted in the following ways:

1. Single inheritance: When a child class inherits from only one parent class, it is called single inheritance. This is the simplest form of inheritance. For example, a 'Square' class can inherit from a 'Rectangle' class as a square is a rectangle.

2. Multiple inheritance: When a child class inherits from multiple parent classes, it is called multiple inheritance. This can make the code complex and lead to ambiguity. Most OOP languages like Java and C# do not support multiple inheritances.

3. Multilevel inheritance: When a child class acts as a parent class for another child class, it results in multilevel inheritance. For example, 'Rectangle' can be a parent class for 'Square' which in turn can be a parent class for 'Cube'. This can be extended to multiple levels.

4. Hierarchical inheritance: When multiple child classes inherit from a single parent class, it is known as hierarchical inheritance. For example, 'Shape' can be a parent class for multiple child classes like 'Circle', 'Rectangle', 'Square', etc.

5. Hybrid inheritance: It is a mix of multiple inheritance types. For example, a child class can inherit from multiple parent classes and also act as a parent class for another child class.

The type of inheritance to use depends on the requirements and problem statement. Inheritance makes the code reusable and easy to maintain but can also make the code complex if not implemented properly. Appropriate use of inheritance results in efficient software architecture.
