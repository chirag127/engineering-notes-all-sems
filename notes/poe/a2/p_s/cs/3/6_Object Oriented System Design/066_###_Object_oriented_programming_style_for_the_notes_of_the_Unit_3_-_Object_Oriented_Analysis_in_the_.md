### Object oriented programming style

Object oriented programming style focuses on representing problems using objects and data rather than logic. Some key points about object oriented programming style are:

1. Objects - Objects are instances of classes that contain data in fields (attributes) and code in procedures (methods). Objects are used to model real world things.
2. Encapsulation - The internal workings of an object are hidden from the outside. Only the object's interface is exposed to the outside in the form of public methods. This helps to reduce complexity and increase reusability.
3. Inheritance - Objects can inherit attributes and behaviors from other objects. This helps in modeling hierarchical relationships and reusing code.
4. Polymorphism - Objects can take on more than one form based on the context. The same method can exhibit different behaviors in different instances. This makes the interface more flexible and generic.
5. Abstraction - Complex implementations are hidden behind simple interfaces. This reduces complexity and helps the user focus on what the object does rather than how it does it.

Advantages of object oriented programming style:
- Models real world problems well
- Increases reusability of code
- Reduces complexity through encapsulation and abstraction
- Supports modeling hierarchies through inheritance

Disadvantages:
- Can be complex to implement
- Polymorphism and inheritance can impact performance if not implemented properly
- Difficult to debug at times

Applications: Software development, Simulation modeling, Computer graphics, etc.
