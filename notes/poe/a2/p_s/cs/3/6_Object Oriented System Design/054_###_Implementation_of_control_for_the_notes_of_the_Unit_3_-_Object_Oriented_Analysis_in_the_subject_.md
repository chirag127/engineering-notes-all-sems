### Implementation of control for the notes of the Unit 3 - Object Oriented Analysis in the subject of Object Oriented System Design

1. Control refers to managing how the components of a system interact. It is implemented to manage the flow of data and execution in a system.
2. Some of the control mechanisms used in object oriented analysis are:
- Sequence: Specifies the order in which operations must be performed. It is implemented using control flows and iterators.
- Selection: Specifies conditions to determine which operations to perform. It is implemented using conditional statements like if-else.
- Iteration: Specifies repeating a set of operations until a condition is met. It is implemented using loops like for and while loops.
- Concurrency: Specifies multiple operations executing simultaneously. It is implemented using threads and synchronization mechanisms.

Advantages:
- Controls the flow of the system and ensures correct execution of operations.
- Provides flexibility to execute operations based on conditions and repetitions.
- Enables parallel execution of multiple operations to improve performance.

Disadvantages:
- Increases complexity of the system.
- May lead to issues like deadlocks and race conditions in case of improper implementation of concurrency.

Examples:
- Sequence: Performing login, then accessing data and then logging out.
- Selection: Displaying different screens based on user input.
- Iteration: Repeating a set of operations for each element in a list.
- Concurrency: Performing multiple requests simultaneously in a server.

Applications: Control mechanisms are fundamental parts of all software and systems. They are implemented in various software and technologies we use everyday like operating systems, databases, servers, etc. to manage their functioning.
