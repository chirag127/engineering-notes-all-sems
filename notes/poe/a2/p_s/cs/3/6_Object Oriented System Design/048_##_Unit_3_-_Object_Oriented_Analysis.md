## Unit 3 - Object Oriented Analysis

1. Object Oriented Analysis (OOA) is a software engineering approach that models a system as a group of interacting objects.
2. The core concepts of OOA are:
- Objects: Entities that encapsulate data and behavior. Examples: Customer, Order, Employee, etc.
- Classes: A classification of objects that share common structure and behavior. Examples: Vehicle can have classes like Car, Bike, Bus, etc.
- Attributes: Data that describes an object. Examples: Name, Age, Address, etc. of a Customer object.
- Methods: Behavior that an object can perform. Examples: CalculateBill(), PlaceOrder(), etc. of an Order object.
- Inheritance: Ability of a class to inherit properties from another class. Allows establishing is-a relationships. Example: Bus inherits from Vehicle class as a Bus is a type of Vehicle.
- Encapsulation: Hiding internal details of an object and only exposing necessary interfaces to interact with it. Provides data hiding and security.
- Polymorphism: Ability of an object to take on different forms based on the context. Allows establishing a has-a relationship. Example: Vehicle can have references of different types like Car, Bus, etc.

Advantages:
- Models real world objects and relationships.
- Increases reusability, maintainability and extensibility of a system.
- Provides data hiding and security through encapsulation.

Disadvantages:
- Complex systems can lead to excessive classes and relationships that are hard to understand.
- Requires skilled analysts and designers to apply OOA appropriately.

Applications: OOA is commonly used in designing complex software systems like banking systems, ERP systems, etc. It forms the basis for object oriented design and programming.
