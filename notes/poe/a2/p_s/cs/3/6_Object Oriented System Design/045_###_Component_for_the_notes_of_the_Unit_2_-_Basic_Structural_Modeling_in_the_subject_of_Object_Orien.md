### Component for the notes of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design

1. What is a Component?
- A component is a modular, deployable, and replaceable part of a system that encapsulates its implementation and exporting interfaces to enable communication with other components.
- In object-oriented programming, a component is a reusable software program building block.
- Components are self-contained and independent, with interfaces that allow for seamless integration with other components.

2. Advantages of Components
- Increased reusability - Components can be reused in different contexts and applications.
- Separation of concerns - Components implement a specific task/responsibility and hide internal complexity.
- Ease of maintenance - Problems can be isolated and fixed easily as components are independent.
- Scalability and flexibility - New components can be added or existing ones modified or replaced to scale systems and enable flexibility.

3. Characteristics of a good Component
- Has a published/defined interface.
- Has explicit context dependencies.
- Is replaceable.
- Is one of several alternatives.
- Has a specified Lifecycle.
- Is extensible.
