### Principles of Modelling

The key principles of modelling in Object Oriented System Design are:

1. Abstraction: Abstraction is the process of identifying common properties among different objects and grouping them into a common class. It focuses on the essential features of an object and ignores the irrelevant details. Abstraction makes the models easier to understand and work with.

2. Encapsulation: Encapsulation refers to hiding the internal details and complexities of a class from the outside world. Only the essential interfaces are provided to interact with the object. This makes the code robust, easy to maintain and flexible to changes.

3. Modularity: The system is divided into multiple modules where each module addresses a specific functionality. The modules are interconnected but independent. This makes the system easier to understand, test and debug.

4. Hierarchy: Objects are categorised into a hierarchical structure where child classes inherit the properties and behaviours from the parent class. This avoids repetition of code and increases reusability. The hierarchical order also makes it easier to understand the associations between classes.

5. Polymorphism: Polymorphism refers to the ability of an object to take on different forms based on the context. It allows the same interface to have different underlying forms. This makes the code generic, reusable and easily extensible.

The above principles form the foundation for creating an efficient, robust and scalable Object Oriented model. The models are an abstraction of the real world problem and lay down the blueprint for the software design and development.
