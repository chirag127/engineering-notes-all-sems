### Classes for the notes of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design

1. Class - A class is a blueprint or prototype from which objects are created. It defines the structure and behavior of a set of objects. Class defines properties and methods for its objects.

For example: A class `Car` can have properties like `color`, ` numberOfDoors`, `engineCapacity` and methods like `drive()`, `brake()`, `honk()`.

2. Object - An object is an instance of a class. It has its own state, stored in fields (variables), and exhibits its own behavior, which is shown via its methods (functions).

For example: `objCar1` and `objCar2` are two objects of class `Car`. They will have their own color, number of doors and engine capacity.

3. Inheritance - Inheritance is the mechanism in which a class can inherit the structure and behavior of another class. The class that inherits the properties of another class is called a child or derived class and the class whose properties are inherited is called a parent or base class.

For example: Class `Sedan` can inherit from class `Car`. `Sedan` will inherit the properties and methods of `Car` and also define its own additional properties and methods. This allows code reuse and promotes abstraction.
