### Notes for Unit 2 - Basic Structural Modeling

1. Classes and Objects
- Class - A blueprint that defines the structure and behavior of a type of objects. It comprises of properties and methods.
- Object - An instance of a class. It has its own state, stored in properties, and exhibits the behavior defined in its class.
- Inheritance - The process by which one class takes on the attributes and behaviors of another class. Allows code reuse and models relationships between entities.
- Encapsulation - The concept of packing data and code together into a single unit. The internal details of an object are hidden from the outside. Only the required interfaces are exposed.
- Abstraction - Hiding the complexity of the lower level details and showing only essential features.

2. Relationships between Classes
- Association - A relationship between two classes that expresses that objects of one class may use or be associated with objects of the other class. Indicates dependency.
- Aggregation - A special type of association that represents a part-whole relationship between two classes. The composed class cannot exist independently.
- Composition - A strong form of aggregation where a class wholly contains another class. The composed class cannot exist independently.

3. UML Diagrams
- Class Diagram - Shows classes, attributes, operations, and the relationships between classes.
- Object Diagram - Shows a snapshot of the detailed state of a system at a specific point in time. Shows objects and their relationships.
- Use Case Diagram - Shows the interaction between a system and external entities. Describes the functionality provided by a system in terms of actions and services.
