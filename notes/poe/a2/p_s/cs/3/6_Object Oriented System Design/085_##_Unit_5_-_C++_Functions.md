## Unit 5 - C++ Functions

Functions in C++ are blocks of code that perform a specific task and can be reused throughout the program. They allow us to organize our code into modules, make it more readable and easier to debug.

- Defining a Function: A function definition consists of a function header and a function body. The function header specifies the name and parameters of the function. The function body contains the actual code that is executed.
- Function Prototype: A function prototype is a declaration of a function that specifies the return type and parameters of the function without defining the function code. It is required before the function is called to let the compiler know the data types of arguments that will be passed to the function.
- Calling a Function: To execute the code inside a function, we call or invoke the function. We specify the function name followed by parentheses containing arguments (if required) and a semicolon. The arguments are the inputs to the function.
- Function Parameters and Arguments: Parameters are the variables listed inside the parentheses in the function definition. They acquire the values of the arguments passed to the function. Arguments are the real values passed to (and received by) the parameters.
- Return Statements: A return statement is used to exit a function and return control to the calling function. It can optionally return a value to the calling function. The return type of the function specifies the type of value that can be returned.

Advantages:
- Avoid repetition of code.
- Increased organization and modularization of code.
- Code is more readable and easier to debug.
- Information hiding - hide the implementation details.
