## Unit 1 - Introduction: The meaning of Object Orientation

- Object Oriented Programming (OOP) is a programming paradigm that uses objects and their interactions to design applications and computer programs.
- It focuses on objects, rather than actions and data, as the primary elements of computation.
- The key features of OOP are:

1. Encapsulation: Hiding the internal details of how an object does its work and restricting access to its variables and methods.
2. Inheritance: Allowing a new object to inherit the properties and behaviors of a parent object. This allows code reuse and promotes efficiency.
3. Polymorphism: Having objects of different types share the same method names and behaviors. The specific behavior depends on the object type. This allows common interfaces to be used.
4. Abstraction: Simplifying complex problems by identifying common aspects and generalizing them into a concept or class. This makes the system easier to understand and less prone to errors.

- The main advantages of OOP are:

- Modularity: The source code is divided into self-contained modules known as classes that can be reused. This increases organization and efficiency.
- Maintainability: It is easy to make changes to a specific aspect of the application without affecting other parts. This is because of encapsulation and modularity.
- Extensibility: New classes can be easily added to the system to expand its capabilities. This is enabled through inheritance.
- Flexibility: OOP languages are built to handle evolving requirements and changes. Polymorphism and abstraction make the code robust to changes.
