### Process and thread for the notes of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design

1. Introduction to Structural Modeling
- Structural modeling involves representing the static structure of a software system.
- It focuses on the components that make up a system and the relationships between them.
- The key aspects are:
    - Classes - entities with attributes and behaviors
    - Relationships - associations between classes
    - Interfaces - contracts that classes implement
    - Constraints - restrictions on classes and relationships
- Structural models are typically represented using UML class diagrams.

2. Class Diagrams
- Class diagrams are the main diagrams used for structural modeling.
- They show the classes in a system, their attributes, and the relationships between the classes.
- The key elements are:
    - Class - a blueprint for objects that defines attributes and behaviors
    - Attribute - a property of a class that holds data
    - Method - a behavior of a class that defines functionality
    - Relationship - an association between classes that can be unidirectional or bidirectional
        - Association - a basic relationship between classes
        - Aggregation - a whole-part relationship
        - Composition - a strong form of aggregation
        - Dependency - a weaker relationship where one class uses another
