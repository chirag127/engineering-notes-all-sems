### Terms for the notes of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design

1. Class Diagram: A class diagram is a type of static structure diagram that describes the structure of a system by showing the system's classes, their attributes, operations (or methods), and the relationships among objects.
- Classes: Classes represent entities with common characteristics. They are depicted as rectangles divided into compartments.
- Attributes: Attributes are properties of a class that provide a description of its characteristics. They are shown as rectangles within the class compartment.
- Operations: Operations are functions or methods that define the behavior of a class. They are shown as rounded rectangles within the class compartment.
- Relationships: Relationships show how classes interact with each other. The different types of relationships are association, aggregation, composition, generalization, dependency, and realization.

2. Object Diagram: An object diagram is an instance of a class diagram. It shows a snapshot of the detailed state of a system at a point in time. It reflects the actual existence of objects and their relationships. Object diagrams are expressed using object notation modeling elements.
- Objects: Objects are instances of classes. They are shown as rectangles with underlined names.
- Links: Links show the relationships between objects. They have the same notation as the links on class diagrams, such as an association link or an aggregation link.
