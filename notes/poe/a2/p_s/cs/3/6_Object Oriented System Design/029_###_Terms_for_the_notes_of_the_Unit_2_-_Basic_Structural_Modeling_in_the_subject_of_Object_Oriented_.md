### Class Diagram
- Class diagram represents the static structure of a system. It shows classes, interfaces, objects, attributes, operations, and their relationships.
- Class: A class is a blueprint that defines the structure and behaviors of a group of objects. It includes attributes and methods.
- Interface: An interface is a contract that a class must implement. It specifies what a class must do and not how it does it. It contains only method signatures.
- Inheritance: Inheritance represents an is-a relationship and is depicted with an arrow pointing from child class to parent class. It allows a class to inherit attributes and behaviors from another class.
- Association: Association represents a relationship between two classes. It's depicted as a line between classes. It specifies that classes are aware of and can access each other, but the degree of coupling is looser than with aggregation and composition.
- Aggregation: Aggregation is a weak form of association and represents a whole-part relationship. It's depicted as an unfilled diamond on the whole class side. The part could potentially belong to multiple wholes or exist independently.
- Composition: Composition is a strong form of aggregation and represents a part-whole relationship. It's depicted as a filled diamond on the whole class side. The lifetime of the part is dependent on the whole.
