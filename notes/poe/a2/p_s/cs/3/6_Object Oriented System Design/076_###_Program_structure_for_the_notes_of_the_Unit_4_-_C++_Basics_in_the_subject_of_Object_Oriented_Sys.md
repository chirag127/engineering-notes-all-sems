### Program structure for the notes of the Unit 4 - C++ Basics in the subject of Object Oriented System Design

1. Introduction to C++
- C++ is a powerful general-purpose programming language that can be used to create complex applications.
- It is an enhanced version of C language and provides additional features to support Object Oriented Programming approach.
- C++ combines the low-level functionality of C with the high-level functionality of C++.
- Some key features of C++ are - Object Oriented, Generic Programming, Exception Handling, Namespace, etc.

2. Structure of a C++ Program
- A C++ program consists of functions that are defined within files.
- A typical C++ program contains one or more header files and implementation files.
- The header file contains declarations of functions, variables, etc. and implementation file contains definitions of functions.
- A C++ program starts with a main() function which is the entry point of the program. The program ends when main() exits.
- The basic structure of a C++ program is -

```cpp
#include <iostream>

using namespace std;

int main() {
   // Program code here
   return 0;
}
```
