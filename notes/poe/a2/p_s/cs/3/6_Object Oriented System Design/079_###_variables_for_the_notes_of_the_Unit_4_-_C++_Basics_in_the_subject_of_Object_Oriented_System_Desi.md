## Variables

- Variables are containers for storing data values.
- They are named locations used to store data in the memory.
- Variables in C++ need to be declared before they can be used. The declaration specifies the type and name of the variable.
- The general form of a variable declaration is:

`type variable_name;`

For example,

`int age; // declares an integer variable called age`
`float salary; // declares a float variable called salary`
`char grade; // declares a character variable called grade`

- Variables must be initialized before use. This can be done in a single step when declaring the variable by specifying an initial value:

`int age = 21;`
`float salary = 4000.50;`
`char grade = 'A';`

- The type specifies what kind of data the variable can hold (integer, float, character, etc.). The name is used to refer to the variable in the program.
- Variables are useful to store data temporarily and to refer to changing quantities in a program.
- Examples of integers: age, count, number
- Examples of floats: temperature, height, total_cost
- Examples of characters: grade, status
