### Deployment

- Deployment refers to the process of making a software system available for use. It involves deploying the executable code and any additional components needed for the system to function in the production environment.
- Some key steps in deployment are:
- Installing and configuring hardware and the operating system
- Installing system software and runtime support libraries
- Installing and configuring the application software
- Data migration from previous systems (if any)
- User training and acceptance testing
- Going live and monitoring operations

Advantages of proper deployment:
- Reduces downtime and failures as system requirements are met and tested
- Ensures scalability as infrastructure can handle load
- Enables faster bug fixing and updates through good monitoring
- Results in high user satisfaction due to availability and performance

Examples of deployment:
- Deploying a website on a web server
- Releasing a mobile app on app stores
- Pushing code changes to servers in a cloud system
- Shipping and installing new machines/systems at client locations
