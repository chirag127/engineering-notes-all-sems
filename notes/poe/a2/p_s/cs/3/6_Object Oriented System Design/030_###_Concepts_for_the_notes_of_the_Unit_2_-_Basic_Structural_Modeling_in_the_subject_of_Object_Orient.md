### Concepts for the notes of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design

1. Class Diagrams -

- Class diagrams are the most common diagrams used in object-oriented modeling. They show a collection of classes, interfaces, and their relationships.
- Classes are represented by rectangles divided into compartments. The top compartment contains the class name. The middle compartment contains the attributes of the class. The bottom compartment contains the operations the class can perform.
- Relationships between classes are represented by arrows. The cardinality of the relationship is written next to the arrow.
- Aggregation is a special type of association that represents a whole/part relationship between classes. The whole class has control over the life cycle of the part, but the whole and the part can exist independently.

2. Object Diagrams -

- Object diagrams show instances of the classes at a particular moment in time. They are like snapshots of the system.
- Objects are represented by rectangles with the object name inside. Relationships between objects are shown with arrows labeled with the relationship name.
- Object diagrams are useful for visualizing and communicating how the classes might be instantiated and interact dynamically at run time. They are sometimes called instance diagrams or snapshot diagrams.
