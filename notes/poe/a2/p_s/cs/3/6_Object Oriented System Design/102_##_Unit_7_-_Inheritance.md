## Unit 7 - Inheritance

Inheritance is an important concept in Object Oriented Programming(OOP). It is a mechanism in which one class acquires the properties and behaviors of another class.

- The class which inherits the features of another class is called **Subclass**(also known as Child Class) and the class whose features are inherited is called **Superclass**(also known as Base Class or Parent Class).
- The key benefits of inheritance are:
- **Code Reusability**- It eliminates the need of writing the same code again and again.
- **Promotes DRY- Don't Repeat Yourself** principle which says "Every piece of knowledge must have a single, unambiguous, authoritative representation within a system."
- **Is-A Relationship**- Inheritance implements an "Is-A" relationship between two classes where one class inherits from another. For example, "A dog is an animal" so we can implement it in Java using inheritance as Dog extends Animal.
- The class which inherits the features is said to be **deriving** its characteristics from the base/parent class.

**Types of Inheritance**- There are five types of inheritance:
1. Single Inheritance - Only one subclass extends one base class.
2. Multilevel Inheritance - A subclass extends a subclass.
3. Hierarchical Inheritance - More than one subclass extends a single base class.
4. Hybrid Inheritance - A combination of more than one type of inheritance.
5. Multiple Inheritance - A subclass extends more than one base class.
