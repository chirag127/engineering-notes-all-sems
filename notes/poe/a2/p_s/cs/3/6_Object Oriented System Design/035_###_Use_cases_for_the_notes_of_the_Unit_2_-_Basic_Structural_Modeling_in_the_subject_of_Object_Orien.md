### Use cases for the notes of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design:

1. Learn about the basic building blocks of object oriented system design like:
- Objects
- Classes
- Inheritance
- Abstraction
- Encapsulation
- Polymorphism

2. Understand the advantages of object oriented system design like:
- Modularity - Objects of the same class can be grouped together.
- Reusability - Classes can be reused multiple times.
- Extensibility - New features can be easily added.
- Maintainability - Changes can be made easily by modifying the classes.

3. Study the core concepts of object oriented system design with examples like:
- Objects - Examples of real world objects and their attributes and behaviors.
- Classes - Define a blueprint for objects and provide initial values for the attributes and behaviors.
- Inheritance - Reuse an existing class to derive a new class and extend/modify its features.
- Abstraction - Hide the complexities of how a class works and only show the essential features.
- Encapsulation - Bind together the data and functions that work on the data within a class.
- Polymorphism - Provide a common interface for related classes and subclasses can override methods.

4. Learn to analyze and apply the basic structural modeling concepts to solve real world problems by designing systems/software applications based on objects and classes.

5. Prepare to answer questions based on the concepts and practice exercises or programming problems as part of exams or assessments.
