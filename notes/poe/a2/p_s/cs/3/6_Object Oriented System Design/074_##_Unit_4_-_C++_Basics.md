## Unit 4 - C++ Basics

1. Introduction to C++
- C++ is a general purpose, statically typed, compiled programming language that supports procedural, object-oriented, and generic programming.
- It was created by Bjarne Stroustrup in 1979 as an extension of C language.
- C++ combines the low-level functionality of C with the high-level functionality of languages like Java and C#.
- It is considered an intermediate-level language, as it encapsulates the low-level aspects of the machine, but also provides high-level programming features.

2. Structure of a C++ Program
- Preprocessor Directives: Lines start with # to handle macros, include files, etc.
- Main Function: Every C++ program has a main function which is the entry point of the program. It is written as int main().
- Statements and Expressions: Like other languages, C++ has statements to control flow and logical/mathematical expressions.
- Comments: // for single line and /* */ for multi-line comments.

3. Data Types
- C++ has a variety of data types which can be divided into core types (for integers, floats, doubles, booleans, characters) and user-defined types (structures, classes, enumerations, pointers, references, etc.).
- The size of data types depends on the compiler and platform but the ranges are fixed as per the C++ standard.
- Variables are named storage locations that hold values of a particular data type.
