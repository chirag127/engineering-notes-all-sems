### Control Structures

- Control structures are blocks of code that control the flow of execution of a program.
- The three main types of control structures are:
    - Sequence - Statements are executed in the order they appear in the program.
    - Selection - Condition is evaluated and based on the result, a block of code is executed.
    - Iteration - A block of code is executed repeatedly based on a loop condition.

#### Selection Control Structures

- Selection control structures are used to execute code based on a condition. The two types are:
    - If-else - If the condition is true, a block of code is executed. Else, another block of code is executed.
        - Syntax:
        if (condition) {
            // execute code if condition is true
        }
        else {
            // execute code if condition is false
        }
    - Switch - A variable is evaluated and matched against several cases. Code in the matched case is executed.
        - Syntax:
        switch (expression) {
            case x:
                // code block
                break;
            case y:
                // code block
                break;
            default:
                // code block
        }

#### Iteration Control Structures

- Iteration control structures are used to repeatedly execute a block of code. The three types are:
    - For loop - Loop is executed a fixed number of times.
        - Syntax:
        for (init counter; condition; increment) {
            // code block
        }
    - While loop - Loop is executed as long as the condition is true.
        - Syntax:
        while (condition) {
            // code block
        }
    - Do-while loop - Loop is executed at least once, then repeatedly as long as the condition is true.
        - Syntax:
        do {
            // code block
        } while (condition);
