### Multilayer Perception Model

- A multilayer perception (MLP) is a class of feedforward artificial neural network.
- It is composed of multiple layers of nodes:

1. An input layer
2. One or more hidden layers
3. An output layer

- Each layer consists of a set of neurons which transform the input data and pass it to the next layer.
- Except for the input layer, each layer's neurons receive input from all the neurons of the previous layer.
- The multilayer perception uses backpropagation for training the network.
- Backpropagation is a supervised learning technique used to train MLPs by adjusting the weights of the connections between neurons.
- It calculates the gradient of the loss function with respect to the weights and uses gradient descent to update the weights to minimize the loss.
- This process of forward propagation of inputs and backpropagation of errors is repeated iteratively until the network learns the training patterns.

**Advantages**:
- Can learn complex nonlinear relationships between input and output.
- Universal function approximators - can approximate any continuous function.

**Disadvantages**:
- Prone to overfitting.
- Training can be slow.
- Optimum number of hidden layers and neurons per layer is difficult to determine.

**Applications**:
- Classification (eg. Handwritten digit recognition)
- Regression
- Pattern recognition
- Time series forecasting
