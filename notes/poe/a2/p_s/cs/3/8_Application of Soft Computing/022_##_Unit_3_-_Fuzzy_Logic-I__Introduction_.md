## Unit 3 - Fuzzy Logic-I (Introduction)

- Fuzzy Logic is a multi-valued logic or probabilistic logic that deals with reasoning that is approximate rather than precise.
- In crisp logic, variables may have true or false values, but in fuzzy logic variables may have truth values that range between 0 and 1.
- Fuzzy logic has been applied to artificial intelligence, expert systems, natural language processing, and various other areas.

Some key points about Fuzzy Logic:

- It was introduced by Lotfi A Zadeh in 1965 as an extension of multi-valued logic.
- It allows the variables to have degrees of truthiness. The variables can hold values between 0 and 1, unlike crisp logic variables which hold true or false values.
- It resembles human decision making more closely than traditional logical reasoning which uses binary sets.
- The core of fuzzy logic is fuzzy set theory, which is a way of representing vagueness in concepts.
- Fuzzy logic uses linguistic variables to make decisions based on imprecise or uncertain information. Examples of linguistic variables are: high temperature, low height, medium speed, etc.
- Fuzzy rules are used to map inputs to outputs. The rules resemble conditional statements in if-then forms.
- Defuzzification is the process of producing a quantifiable result in fuzzy logic. The fuzzy outputs are converted into crisp values.
