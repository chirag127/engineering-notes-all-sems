## Unit 2 - Neural Networks-II (Back propagation networks)

- Backpropagation is a method used in training artificial neural networks for supervised learning.
- It involves propagating the error backwards from the output layers to the inner layers and updating the weights to minimize the loss function.
- The steps involved in backpropagation are:

1. Feedforward: Provide input to the neural network and calculate the outputs.
2. Calculate the errors: Compute the difference between the actual outputs and the expected outputs.
3. Backpropagate the errors: Propagate the errors from the output layer back to the hidden layers. During backpropagation, the learning rate is also applied to update the weights.
4. Update the weights: Adjust the weights of the connections between the nodes to reduce the error.

- The weights are updated in the direction of the negative gradient of the loss function w.r.t the weights. This is done using the gradient descent algorithm.
- The process of forward propagation and backpropagation is repeated multiple times using new training data until the network learns the underlying pattern.
- Advantages: It is simple and efficient. It can be used with multilayer networks to learn complex patterns.
- Disadvantages: It can be slow, and it may get stuck in local minima. The learning rate needs to be carefully tuned.
