### Neuron

A neuron is the fundamental unit of a neural network which mimics the functionalities of a biological neuron. It receives input, processes it and then generates an output.

#### Components of a Neuron

- **Inputs:** Inputs are the signals or data fed into the neuron. They are received from the output of other neurons or external sources.
- **Weights:** Each input has an associated weight which can amplify or attenuate the input signal. The weights are adjusted during training to produce the desired output.
- **Summing Junction:** The weighted inputs are summed together in the summing junction. This generates the net input to the neuron.
- **Activation Function:** The net input is then passed through an activation function which determines the output of the neuron. It converts the net input signal into an output signal. The output can be a binary value (0 or 1) or a continuous value between 0 and 1 or -1 and 1 depending on the type of activation function used.
- **Output:** The output of a neuron is then fed to other neurons or taken as the final output depending on whether it is a hidden neuron or output neuron.

#### Types of Neurons

- **Perceptron:** A single-layer neuron with a step activation function generating binary output (0 or 1). It can only be used to linearly separable problems.
- **Sigmoid Neuron:** A multi-layer neuron with a sigmoid activation function generating continuous output between 0 and 1. It can be used to solve non-linearly separable problems.
- **Tanh Neuron:** A multi-layer neuron with a hyperbolic tangent activation function generating continuous output between -1 and 1. It is similar to sigmoid neuron but outputs are centered around 0.
