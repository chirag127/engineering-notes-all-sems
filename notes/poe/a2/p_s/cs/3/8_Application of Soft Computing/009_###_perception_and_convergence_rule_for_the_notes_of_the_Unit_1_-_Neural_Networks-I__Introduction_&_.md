### Perception and Convergence Rule

- Perceptron is a single-layer neural network that uses a linear activation function to classify input data.
- It makes predictions based on a linear separating hyperplane.
- The training process of a perceptron involves finding the right weights that can separate the given input data into target classes using a linear separation.
- The convergence rule states that if a perceptron has weights that can separate the given input data linearly, then the perceptron training algorithm will eventually find a set of weights that achieves this separation.
- However, if no such linear separation exists, the perceptron training algorithm will continue endlessly trying different weights without converging. This is a limitation of single-layer perceptrons.
- To overcome this, we use multi-layer neural networks that can capture non-linear relationships to classify input data that is not linearly separable.

Advantages:
- Simple to understand and implement.
- Computational efficient.

Disadvantages:
- Limited to problems with linear separable data.
- Prone to overfitting.

Applications:
- Binary classification problems with linearly separable data.
- As a preprocessing step for non-linear classification.
