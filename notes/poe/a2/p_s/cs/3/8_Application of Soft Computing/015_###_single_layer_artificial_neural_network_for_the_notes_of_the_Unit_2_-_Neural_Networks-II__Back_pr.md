### Single Layer Artificial Neural Network

A single layer artificial neural network consists of an input layer and an output layer. It does not contain any hidden layers. The input is directly mapped to the output.

- The input layer contains input neurons which receive the input data.
- The output layer contains output neurons which produce the output.
- Each input neuron is connected to each output neuron.
- Each connection between the neurons has an associated weight which can be adjusted.

The working of a single layer neural network can be summarized as:

1. The input data is fed into the input neurons
2. The input is multiplied by the weights of the connections between the input and output neurons
3. The weighted sum is processed by the activation function of the output neurons to produce the output
4. The weights are adjusted using a learning algorithm to produce the desired output for given inputs

Advantages:
- Simple architecture and easy to implement
- Requires less training data and time

Disadvantages:
- Limited modeling power as it can only model linear relationships
- Prone to underfitting due to less parameters

Applications:
- Linear regression
- Logistic regression
- Perceptron
