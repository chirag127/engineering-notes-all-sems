### Fuzzy Sets and Crisp Sets

- A **crisp set** is a set where an element either belongs or does not belong to the set. There are no degrees of membership. For example, the set of tall men is a crisp set - a man is either tall or not tall.
- A **fuzzy set** is a set where elements can have degrees of membership between 0 and 1. For example, the set of tall men is a fuzzy set - a man can be very tall, tall, slightly tall, etc. depending on his height.
- Fuzzy sets are useful to handle imprecise concepts and graded classifications in the real world. Classical sets are too rigid to model such uncertain/imprecise data.
- The membership function of a fuzzy set assigns a membership grade between 0 and 1 to each element of the universe of discourse. It quantifies the degree to which an element belongs to the fuzzy set.
- For a crisp set, the membership function only takes values 0 or 1. For example, the membership function of the crisp set of tall men would map a man of height 6 ft to 1 (tall), and a man of height 5 ft to 0 (not tall).
- Key terms: Universe of discourse, membership function, fuzzy set, crisp set.
