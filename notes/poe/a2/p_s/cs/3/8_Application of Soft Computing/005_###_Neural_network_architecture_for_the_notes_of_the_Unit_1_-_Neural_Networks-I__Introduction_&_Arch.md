### Neural network architecture

For the notes of Unit 1 - Neural Networks-I (Introduction & Architecture)

1. A neural network is a series of algorithms that attempts to identify relationships between inputs and outputs and uses those relationships to make predictions or decisions on new data.
2. The architecture of a neural network generally consists of the following components:

- Input layer: The input data is fed into the network through the input layer. It consists of input nodes which are equal to the number of input features in the data.
- Hidden layer(s): The hidden layer(s) consists of hidden nodes which transform the input and detect complex patterns in the data. The number of hidden layers and nodes in each layer depend on the problem. Too few hidden layers may not model the data well while too many may lead to overfitting.
- Output layer: The output layer produces the final output. The number of output nodes depends on the number of classes or values to be predicted.

3. The layers are connected to each other through weighted connections that transform the input and determine the output. The weights are adjusted iteratively using a training algorithm to produce the desired output for the given input.
4. As the training progresses, the network learns the strengths of connections (weights) between nodes that lead to the desired outputs. These connections can then be used on new data to generate predictions.
5. Some advantages of neural networks are:
- They can capture complex relationships between inputs and outputs.
- They do not require feature engineering and can work with raw data.
- They are flexible and can approximate any function.

Some disadvantages are:
- They are black box models and the reasoning behind their predictions is difficult to understand.
- They require large amounts of data to train the network and avoid overfitting.
- They can be computationally intensive to train.
