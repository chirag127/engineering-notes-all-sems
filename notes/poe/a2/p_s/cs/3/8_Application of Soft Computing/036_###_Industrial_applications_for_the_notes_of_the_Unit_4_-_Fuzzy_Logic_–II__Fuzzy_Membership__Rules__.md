### Industrial applications for the notes of the Unit 4 - Fuzzy Logic –II (Fuzzy Membership, Rules) in the subject of Application of Soft Computing

- Fuzzy logic is widely used in industrial control systems:
- Speed control of motors: The speed of a motor can be controlled using fuzzy logic by providing inputs like error and change in error. The fuzzy sets for input variables can be defined using membership functions and appropriate rules can be framed to get the desired speed control.
- Washing machine: Fuzzy logic is used in fully automatic washing machines to control the washing process. Inputs like load size, soil level etc. are fuzzified and appropriate rules are used to control the washing time, washing speed, amount of detergent etc.
- Subway train control: Fuzzy logic is used in automatic train control systems to control the speed of trains depending on factors like possibility of collision, distance of adjacent trains etc. The input variables are fuzzified and appropriate rules are framed to control the speed of the trains.
- Camera focus and exposure control: Fuzzy logic can be used to automatically control the focus and exposure in cameras based on the lighting conditions and distance of objects. The inputs are fuzzified and appropriate rules are used to control the focus and exposure for sharp and bright images.

Detailed diagrams, codes and examples can be included for the above applications to help in understanding how fuzzy logic is applied in these applications. The advantages of using fuzzy logic in such applications is that it can work with imprecise inputs and can mimic human decision making to handle such real world problems which are difficult to solve using conventional control methods. The main disadvantage is that it requires expert knowledge to define appropriate membership functions and rules which can be challenging in some applications.
