Fuzzy If-Then Rules
- Fuzzy if-then rules are statements that control fuzzy inferences. They take on the form:
IF x is A THEN y is B
where A and B are linguistic variables.
- The antecedent (IF part) of a fuzzy if-then rule contains fuzzy conditions on inputs (x is A), and the consequent (THEN part) contains fuzzy conditions on outputs (y is B).
- Fuzzy if-then rules are used to formulate the qualitative aspects of human knowledge and reasoning processes. They provide a method of mapping inputs to outputs using fuzzy linguistic concepts.
- For example:
IF temperature is hot THEN fan_speed is high
IF error is large THEN change is big
- The antecedent of a fuzzy rule may have multiple parts combined using logical connectives (AND, OR, NOT). For example:
IF temperature is high AND humidity is high THEN air_conditioning is on
- The consequent of a fuzzy rule can also be compound, with multiple parts. For example:
IF error is large THEN change is big AND alarm is on
- The set of fuzzy if-then rules forms a fuzzy rule base which is analogous to a set of conditional statements in conventional programming.
