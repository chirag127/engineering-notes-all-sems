### Algorithms for the notes of the Unit 1 - Introduction: Algorithms, Analyzing Algorithms, Complexity of Algorithms, Growth of Functions, Performance Measurements, Sorting and Order Statistics - Shell Sort, Quick Sort, Merge Sort, Heap Sort, Comparison of Sorting Algorithms, Sorting in Linear Time.

**Algorithms:**
- A step-by-step procedure for solving a problem or completing a task.
- Inputs: Zero or more inputs.
- Outputs: One or more outputs.
- Definite instructions for solving a problem or performing a task.
- Termination condition: Specifies when to stop.

**Analyzing Algorithms:**
- Determine resource usage (time, space) as input size grows.
- Asymptotic analysis: focus on growth rate of resource usage, discard constants and lower order terms.
- Big-O, big-Omega, big-Theta notations to express growth rate.

**Complexity of Algorithms:**
- Time complexity: Number of steps required by an algorithm to solve a problem of size n.
- Space complexity: Additional storage space required by an algorithm to solve a problem of size n.

**Growth of Functions:**
- Constant: O(1), e.g. array access.
- Logarithmic: O(log n), e.g. binary search.
- Linear: O(n), e.g. linear search.
- Linearithmic: O(n log n), e.g. efficient sorting algorithms.
- Quadratic: O(n^2), e.g. selection sort.
- Exponential: O(2^n), e.g. brute-force approach for subset sum problem.
- Factorial: O(n!), e.g. travelling salesman problem.
