## Unit 1 - Introduction: Algorithms, Analyzing Algorithms, Complexity of Algorithms, Growth of Functions, Performance Measurements, Sorting and Order Statistics

### Algorithms
- An algorithm is a set of steps that are followed to solve a problem or complete a task.
- Algorithms are imperative and deterministic. They specify each step and the order in which the steps are to be performed.
- Examples: Recipes, Game strategies, Computer programs, etc.

### Analyzing Algorithms
- Analyzing algorithms involves determining the efficiency of algorithms.
- The time and space requirements of an algorithm must be estimated as a function of the size of the input.
- Commonly used measures are running time, number of steps, memory space, etc.

### Complexity of Algorithms
- The complexity of an algorithm refers to how much time and space it needs to run as a function of the input size.
- Usually measured in terms of the rate of growth of a function.
- Important complexity classes are:
** Polynomial time - P
** Exponential time - EXPTIME
** Non-deterministic polynomial time - NP
** Non-deterministic exponential time - NEXPTIME

### Growth of Functions
- The efficiency of an algorithm is determined by the rate of growth of the function that describes the algorithm's resource usage.
- Some common functions and their rates of growth (from smallest to largest) are:
** Constant - O(1)
** Logarithmic - O(log n)
** Linear - O(n)
** Polynomial - O(n^k), k > 1
** Exponential - O(2^n)
** Factorial - O(n!)

### Performance Measurements
- The efficiency of algorithms is measured experimentally by running them on a computer for input of various sizes and measuring resources usage like time and space.
- The results are then extrapolated to estimate performance on very large input sizes.
- Need to consider:
** Hardware Platform
** Programming Language
** Optimizations applied
** Nature of input data

When comparing algorithms, the experiment should be performed under identical conditions.
