### NP-Completeness
- NP-Completeness is a class of computational problems whose solutions can be verified in polynomial time but may take an exponential amount of time to solve.
- NP stands for Non-Deterministic Polynomial time.
- A problem is said to be NP-Complete if it is in NP and every other problem in NP can be reduced to it in polynomial time.
- The most important open question in computer science is whether P = NP. If P = NP, then NP-Complete problems can be solved in polynomial time.
- Some examples of NP-Complete problems are Boolean Satisfiability (SAT), Hamiltonian Path, Travelling Salesman Problem (TSP), etc.

### Approximation Algorithms
- Approximation algorithms are used to solve NP-Hard problems efficiently by trading off optimality for efficiency.
- They provide suboptimal but good enough solutions in polynomial time.
- The approximation ratio is a measure of how close the solution is to the optimal solution. It is the worst-case ratio of the solution cost to the optimal cost.
- Some examples of problems that use approximation algorithms are Vertex Cover, Set Cover, Knapsack Problem, etc.

### Travelling Salesman Problem (TSP)
- The Travelling Salesman Problem (TSP) is a classic NP-Hard problem.
- It involves finding the shortest route that visits each city exactly once and returns to the starting city.
- The problem becomes exponentially hard as the number of cities increases.
- Some approximation algorithms for TSP are Nearest Neighbour, Christofides' Algorithm, etc.
- The optimal solution can be found using Dynamic Programming and Branch and Bound but the time complexity is very high.
