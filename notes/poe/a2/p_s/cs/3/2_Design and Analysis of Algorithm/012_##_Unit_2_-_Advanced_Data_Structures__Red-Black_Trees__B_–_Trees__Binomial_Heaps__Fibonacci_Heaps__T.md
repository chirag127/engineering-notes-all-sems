## Unit 2 - Advanced Data Structures: Red-Black Trees, B – Trees, Binomial Heaps, Fibonacci Heaps, Tries, Skip List

Red-Black Trees:
- Balanced binary search trees (height is O(log n))
- Each node is either red or black
- No two adjacent nodes can have the same color
- Every path from the root to a leaf contains the same number of black nodes
- Used to implement sets and maps efficiently (logarithmic time for insertion, deletion, search)

Advantages:
- Balanced trees so access, insertion and deletion take logarithmic time
- Robust performance since heights are kept low

Applications:
- Implementations of sets and maps

B-Trees:
- Generalization of binary search trees
- Each node can have between d and 2d child nodes (typically a fixed d)
- All leaves are at the same depth
- Used for storing large amounts of data on disk ( database indexes)
- Allow efficient searching, sequential access, insertion, and deletion

Advantages:
- disk access is optimized by having high branching factor and all leaves at same depth
- height is kept low so logarithmic time access, insertion, deletion
- support efficient range queries

Applications:
- Database indexes
