### Performance Measurements

- Performance of an algorithm is measured in terms of resource usage like time taken, space used, etc.
- The two primary resources we consider for measuring performance are:
    - Time: Number of steps required.
    - Space: Additional storage space required.
- While analyzing the performance of an algorithm, we make certain assumptions:
    - The machine executes one instruction in one unit of time.
    - The size of the input is denoted by n.
- The performance of an algorithm may depend on the input size n and is expressed mathematically as a function T(n). For example, T(n) can represent the time required or S(n) can represent the space required.
- By analyzing the rate of increase of the function T(n), we can determine how the performance of the algorithm changes with an increase in the input size. This helps in determining the efficiency of the algorithm.
- Some of the common measures to analyze the performance are:
    - Computational complexity: Determining how much time and space are required for the algorithm to execute as a function of the input size. It is expressed using Big O notation.
    - Rate of growth: Determining how fast the time or space requirement grows as the input size grows. A faster rate of growth implies worse performance.
    - Scalability: The ability of an algorithm to handle larger input sizes efficiently. An algorithm is said to scale well if the increase in resources required is proportional to the increase in input size.
