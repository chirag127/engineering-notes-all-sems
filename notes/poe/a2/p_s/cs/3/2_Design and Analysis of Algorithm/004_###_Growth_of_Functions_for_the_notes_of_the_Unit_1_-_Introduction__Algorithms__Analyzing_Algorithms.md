### Growth of Functions
- The growth of a function refers to how its output increases as the input size increases.
- We analyze the growth of functions to understand the efficiency of algorithms.
- The efficiency of an algorithm depends on how fast its running time grows as the input size grows.
- We commonly use Big O notation to analyze the growth of functions.
- Some common types of growth are:
    - Constant - O(1) - Running time is same regardless of input size. Example - Accessing an element in an array.
    - Logarithmic - O(log n) - Running time increases logarithmically with input size. Example - Binary search.
    - Linear - O(n) - Running time increases linearly with input size. Example - Traversing an array.
    - Quadratic - O(n^2) - Running time increases quadratically with input size. Example - Bubble sort.
    - Exponential - O(2^n) - Running time increases exponentially with input size. Example - Recursive algorithms that solve a problem by dividing it into half repeatedly.
- We analyze growth of functions to get an idea of how algorithms scale with increasing input sizes and to determine efficiency. Lower order terms and constants are ignored while analyzing growth.
- The algorithm with the least growth of function is considered the most efficient. For example, binary search with O(log n) is more efficient than bubble sort with O(n^2) growth.
