#### Applications on Big Data using Hive

- Hive is a data warehouse infrastructure built on top of Hadoop for providing data summarization, query, and analysis. Some of the key applications of Hive are:

1. Data Warehousing - Hive provides an SQL-like interface to query and manipulate large data sets residing in distributed storage. This makes it easy to use for data warehousing tasks like extracting, transforming and loading (ETL) data.
2. Business Intelligence - The warehouse capabilities and query language of Hive enable easy reporting and business intelligence on large data. It allows analysts to run complex queries on Big Data for deriving insights and making business decisions.
3. Machine Learning - The output of Hive queries can be fed into machine learning algorithms to build models on large data sets. Hive's ability to summarize Big Data makes it suitable for feature engineering in machine learning.
4. Stream Processing - Hive can be used to run queries on real-time data streams and perform aggregations or transformations on the data. This enables real-time monitoring and analytics on streaming Big Data.

Some key advantages of using Hive are:

- SQL-like query language easy to learn for users familiar with SQL
- Hides complexity of MapReduce and distributed processing from users
- Scalable and fast due to compile-time optimizations and MapReduce
- Integrates with Hadoop ecosystem and works with multiple file formats

However, some disadvantages are:

- Can be slow for low-latency queries due to overhead of MapReduce
- Limited functionality compared to full SQL language and databases
- Requires tuning for optimal performance based on data and queries
