### Map Reduce features for the notes of the Unit 3 - Map Reduce in the subject of Big Data

- Map Reduce is a programming model for processing large data sets with a parallel, distributed algorithm on a cluster.
- It consists of two major tasks - Map and Reduce.
- The Map task divides the input into smaller sub-problems, which are then solved in parallel by multiple machines.
- The Reduce task then merges the solutions to these sub-problems to compute the final output.
- Some key features of Map Reduce are:
- Scalability - It can scale to massive data sets and clusters of machines.
- Fault Tolerance - It handles machine failures gracefully and continues processing without losing data.
- Low Latency - It can process data quickly as it's processed in parallel.
- Locality - It moves computations to the data instead of moving large data sets to the computations.
- Runs on inexpensive commodity hardware.
- Is easy to program with the Map and Reduce abstractions.

#### Pig - Introduction to PIG

- Pig is a high-level platform for creating Map Reduce programs used with Hadoop.
- It provides an easy to use scripting language called Pig Latin.
- Pig Latin abstracts away the complexity of Map Reduce and allows users to focus on the data processing logic.
- Some key points about Pig are:
- It compiles Pig Latin scripts into Map Reduce programs which are then executed on Hadoop.
- It optimizes and parallels multiple operations.
- It provides a wide variety of built-in data types and operators for data manipulation.
- It can work with unstructured and semi-structured data.
- It can be integrated with other Hadoop components like Hive.
- It reduces the development time required to create complex data processing pipelines.
