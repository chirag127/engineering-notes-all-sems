### Introduction

- MongoDB is a cross-platform, document-oriented database that provides high performance, high availability, and easy scalability.
- Instead of storing data in tables and rows as in a relational database, MongoDB stores data in JSON-like documents with dynamic schemas.
- MongoDB is classified as a NoSQL database program. Instead of using SQL to query the database, MongoDB uses its own JavaScript-based query language.
- Some key points about MongoDB:

- It is a document database that stores data in flexible, JSON-like documents.
- It is horizontally scalable and provides high performance.
- It has a dynamic schema and uses documents to represent the structure. The fields in a document do not have to be of the same type.
- It has good performance with high volume data sets and complex queries.
- The MongoDB server is available across multiple platforms.
- The drivers for MongoDB are available in all major languages.

- Advantages of MongoDB:

- Scalability: MongoDB scales horizontally by sharding and distributing data across multiple machines. This provides very high performance and throughput.
- Structure: The dynamic schema supports easy modifications to documents and scalable storage needs.
- Performance: MongoDB provides high performance with large data sets and high throughput.
- Easy replication: Setting up replication is straightforward and provides high availability and data redundancy.

- Disadvantages of MongoDB:

- Less suitable for complex transactions: MongoDB does not support ACID transactions and rollbacks.
- Learning curve: Although the Mongo database has a simple design, understanding the concepts of a document-oriented database can take time if coming from a relational database background.
- Limited query capabilities: Although MongoDB queries are flexible, the query language is limited in capabilities compared to SQL-based queries.
