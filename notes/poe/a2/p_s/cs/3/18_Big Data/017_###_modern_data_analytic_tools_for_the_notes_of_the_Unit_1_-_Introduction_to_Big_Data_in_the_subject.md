#### Modern Data Analytic Tools

The following are some of the popular modern data analytic tools:

1. Apache Hadoop:
- Open source software framework for distributed storage and processing of big data using the MapReduce programming model.
- Scalable and fault tolerant.
- Used for processing and storage of large data sets in a distributed computing environment.
- Components: Hadoop Distributed File System (HDFS), MapReduce.

2. Apache Spark:
- Open source cluster computing framework for real-time processing of large datasets.
- Supports in-memory data storage and processing for faster application performance.
- Supports Java, Python, Scala and R programming languages.
- Components: Spark Core, Spark SQL, Spark Streaming, MLlib, GraphX.
- Used for machine learning, stream processing, graph processing, etc.

3. Tableau:
- A data visualization tool for data analysis and Business Intelligence.
- Allows you to create interactive data visualizations, dashboards and BI apps with a drag and drop interface.
- Supports connections to Hadoop, Spark, AWS, Azure, etc.
- Used to gain business insights through data visualization.
