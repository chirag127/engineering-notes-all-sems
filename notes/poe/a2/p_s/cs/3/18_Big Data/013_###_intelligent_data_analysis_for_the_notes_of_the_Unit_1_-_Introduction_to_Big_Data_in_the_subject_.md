### Intelligent Data Analysis

- Data analysis is the process of inspecting, cleaning, transforming, and modeling data with the goal of discovering useful information, informing conclusions, and supporting decision-making.
- Intelligent data analysis uses machine learning and artificial intelligence techniques to automatically analyze data and reveal patterns and insights, without being explicitly programmed where to look.
- Some of the steps involved in intelligent data analysis are:

1. Data Collection - Gathering raw data from various sources.
2. Data Preparation - Cleaning, filtering and preprocessing the raw data.
3. Feature Engineering - Creating additional features/variables to make the data more suitable for modeling.
4. Choosing an AI/ML model - Deciding which machine learning or deep learning model is appropriate for the problem.
5. Training and Evaluation - Training the chosen model on the prepared data and evaluating its performance using metrics like accuracy, precision, recall, F1 score, etc.
6. Hyperparameter Tuning - Adjusting hyperparameters to optimize the performance of the model.
7. Deployment - Deploying the tuned model to production for making predictions on new data.

- The benefits of intelligent data analysis are:
- Automated discovery of patterns and insights.
- Processing and analyzing huge amounts of data.
- Adaptive learning without being explicitly programmed.
- Continuous improvement from experience.

- The limitations are:
- Requirement of large amounts of data to learn effectively.
- Prone to biases in data or algorithms which can lead to skewed insights or decisions.
- Lack of explainability - It is difficult to understand why the models make the predictions or decisions they do.
- Additional effort required to prepare data and select/tune models.

- Examples of applications include:
- Recommendation systems
- Image classification
- Speech recognition
- Predictive analytics
- Robotics
- Diagnosing diseases
