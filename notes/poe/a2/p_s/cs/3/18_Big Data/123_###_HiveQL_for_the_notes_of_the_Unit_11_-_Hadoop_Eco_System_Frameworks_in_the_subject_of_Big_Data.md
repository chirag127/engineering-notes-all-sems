# Computer Networks

Computer Networks is the study of how computers and network devices communicate and exchange data with each other. Following are some key points about Computer Networks:

1. Network Devices: Some key network devices are routers, switches, modems, network interfaces, gateways, etc. These devices facilitate communication and data transfer between computers and networks.

2. Protocols: Protocols are the rules that govern data communication. Some important protocols are IP, TCP, UDP, DNS, DHCP, HTTP, FTP, SMTP, etc. These protocols ensure that data is transmitted and received correctly between computers.

3. Bandwidth and Latency: Bandwidth refers to the maximum data transfer rate of a network. It is measured in bits per second (bps). Latency refers to the time taken for data to be transferred from one point to another. It is measured in milliseconds (ms). Bandwidth and latency are important metrics to determine network speed and performance.

4. Wired vs Wireless Networks: Wired networks use physical cables to connect devices while wireless networks use radio waves to connect devices. Wired networks are more secure and faster but less mobile while wireless networks are more mobile but slower and have more security vulnerabilities.

5. Network Architecture: The two main types of network architecture are client-server and peer-to-peer. In client-server, there is a centralized server that handles requests from client computers. In peer-to-peer, all computers have equivalent responsibilities and share resources.
