### Scaling Out

- Scaling out refers to handling large data and workload by increasing the number of nodes in a cluster.
- Instead of increasing the resources of a single machine, multiple machines are used with each having its own resources.
- The work is distributed across the nodes in a cluster, thereby improving performance and the ability to handle large data and workloads.
- Advantages:
    - Cost effective as commodity hardware can be used.
    - Highly scalable as more nodes can be easily added.
    - Fault tolerant as work can be handled by other nodes in case of node failures.
- Disadvantages:
    - Complexity in distribution and management of work across nodes.
    - Rising network traffics and overheads with increase in number of nodes.
- Examples: Hadoop, Spark, Flink, etc. use scaling out. Data and work is distributed across nodes in a cluster.
- Applications: Scaling out is suitable for large data and workloads as in big data analytics, machine learning on huge data sets, high traffic websites, etc.
