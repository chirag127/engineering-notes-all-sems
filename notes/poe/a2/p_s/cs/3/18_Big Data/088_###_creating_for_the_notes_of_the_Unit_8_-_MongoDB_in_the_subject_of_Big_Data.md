### MongoDB

MongoDB is a document-oriented NoSQL database used for high volume data storage. It stores data in JSON-like documents.

Some key points about MongoDB are:

1. MongoDB stores data in documents which are gathered in collections. A document is a record in a collection and a collection is a group of documents.
2. MongoDB is a schema-less database i.e. documents in a collection can have different fields. This makes it flexible and scalable.
3. MongoDB supports ad-hoc queries, indexing, and real time aggregation.
4. MongoDB is horizontally scalable i.e. it scales by increasing the number of servers in the cluster. This makes it suitable for large volumes of data.
5. MongoDB supports replication and high availability which makes it fault tolerant. The data is replicated across multiple servers for consistency and availability.
6. MongoDB supports multiple data centers and cloud providers which makes it highly robust and reliable.
7. Some applications of MongoDB are:
    - Content Management Systems
    - Real-time analytics
    - Mobile and web applications
    - Product catalogues
    - Sensor data
