## Unit 8 - MongoDB

MongoDB is a document-oriented NoSQL database used for storing data in a JSON-like document format. Some key points about MongoDB are:

1. It is a schemaless database i.e. documents in a collection do not need to have the same set of fields or structure. This makes it flexible to store and manage data.
2. Data is stored in documents which are grouped together in collections. A database stores one or more collections.
3. Documents are BSON documents (Binary JSON) which supports embedding of documents and arrays within documents.
4. MongoDB replication provides high availability and data redundancy. It supports replication across multiple servers/data centers. It can handle server failures by automatically shifting to a secondary replica.
5. MongoDB supports horizontal scaling i.e. you can scale MongoDB by increasing the number of servers in your replica set. This improves read/write performance and increases data storage capacity.
6. MongoDB supports indexes on any field, including nested fields. Indexes support efficient execution of queries on the database.
7. MongoDB supports geospatial indexes which allows for geo-spatial queries on locations. This is useful for location-based applications.
8. MongoDB Atlas is a fully managed cloud database service for MongoDB deployment. It handles administrative tasks, backup, scaling, upgrades, etc.

Some key advantages of MongoDB are:

- Schema less and flexible data model.
- Rich query language.
- Scalability and high performance.
- Replication and high availability.
- Handle big data.

Some disadvantages of MongoDB are:

- Less support for joins.
- Limited transactions.
- Not ACID compliant.
- Steeper learning curve.

MongoDB finds application in content management systems, big data, IoT applications, mobile and social infrastructure, etc.
