### Avro

- Avro is a data serialization system developed by Apache.
- It provides a rich data modelling environment for defining data structures/schemas.
- The schemas are defined using JSON format which makes it language independent.
- The defined schemas are compiled into code for the supported programming languages.
- The key features of Avro are:
-- Schema evolution: Allows backward compatibility. New fields can be added without breaking existing data.
-- Dynamic typing: Supports dynamic types like strings, integers, floats, booleans, enumerations, arrays, maps, unions, and records.
-- Efficient serialization: Binary data format with support for compression and performance.
-- Language independence: Supports many languages like Java, C++, C#, Python, PHP, Ruby, etc.
-- Remote procedure call (RPC): Supports RPC using the same binary serialization format.

The advantages of Avro are:
- Dynamic Schemas
- Efficient Serialization
- Rich Data Modelling
- Language Independence

The applications of Avro are:
- As an interchange format
- As a persistent data storage format
- For RPC
- As a columnar storage format in Hadoop
