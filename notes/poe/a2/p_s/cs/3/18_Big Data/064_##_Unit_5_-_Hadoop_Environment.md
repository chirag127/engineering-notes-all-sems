## Unit 5 - Hadoop Environment

1. Hadoop ecosystem consists of multiple components that work together to solve big data problems. The key components are:

- HDFS - Hadoop Distributed File System: Provides distributed, scalable and portable file system to store huge data across multiple machines.
- YARN - Yet Another Resource Negotiator: Manages and allocates system resources to various applications running on the Hadoop cluster.
- MapReduce: A programming model to process huge data in parallel and distributed manner.

2. Hadoop cluster consists of multiple nodes to store and process data:

- Master node: Consists of Jobtracker, Tasktracker and Namenode. Manages the slave nodes and resource allocations.
- Slave/Worker nodes: Consists of Datanodes and Tasktrackers. Provides computational power and storage to the cluster.
- Edge node: Consists of client machines to submit jobs and access the cluster.

3. Hadoop works on the principle of distributed and decentralized computing with storage and processing of data at the same place (data locality). This makes it highly scalable, fault tolerant and cost effective. Some key points:

- Hadoop handles large data sets on commodity hardware.
- Hadoop is highly fault tolerant using data replication and disk failure handling.
- Hadoop's scaling out approach makes it cost effective for huge data.
- Complex algorithms can be easily implemented in MapReduce paradigm.
