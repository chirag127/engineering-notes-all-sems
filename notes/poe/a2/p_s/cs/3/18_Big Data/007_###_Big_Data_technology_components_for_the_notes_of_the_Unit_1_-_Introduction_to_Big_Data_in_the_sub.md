### Big Data technology components:

1. Hadoop:
- Open source software framework for distributed storage and processing of big data sets.
- Uses Hadoop Distributed File System (HDFS) for storage and MapReduce for processing.
- Scalable, reliable, distributed computing.
- Runs on commodity hardware.
- Advantages: Scalability, Cost effectiveness. Disadvantages: Complexity.
- Used by companies like Facebook, Twitter, eBay, etc. for big data analytics.

2. NoSQL databases:
- Non-relational databases for scalable and distributed data storage for big data.
- Do not use SQL for querying and have simple models like key-value pairs, document, graph, etc.
- Distributed, open source, schema-less.
- Examples: MongoDB, Cassandra, HBase, Neo4j, etc.
- Used when data is unstructured/semi-structured or distributed.

3. Apache Spark:
- Open source framework for fast and general data processing.
- In-memory cluster computing that is up to 100x faster than Hadoop MapReduce.
- Supports multiple languages like Python, Scala, Java, etc.
- Used for streaming, machine learning, graph processing in addition to MapReduce-like tasks.
- Used by companies like IBM, Yahoo, Facebook, etc. for real-time data processing.
