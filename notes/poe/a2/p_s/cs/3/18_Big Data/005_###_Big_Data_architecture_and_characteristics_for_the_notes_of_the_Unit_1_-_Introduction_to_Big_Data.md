### Big Data architecture
The architecture of a Big Data system consists of three layers:

1. Data sources layer - This is the lowest layer which consists of the data sources from where the data is generated and collected. The data can be from file systems, databases, networking devices, sensors, social media, etc.
2. Processing layer - This layer is responsible for processing the raw data and extracting meaningful insights from it. The processing can be done using tools like Hadoop, Spark, Kafka, etc. which provide distributed and parallel processing capabilities.
3. Analytics/Application layer - This is the top layer which performs analytics on the processed data and generates reports and visualizations. This can be done using tools like Pig, Hive, SQL, machine learning libraries, etc. The insights can then be served to applications for various use cases.

### Characteristics of Big Data
The characteristics of Big Data are commonly referred to as the 4 V's:

1. Volume - Refers to the huge amount of data generated. Big Data systems can handle data at petabyte and exabyte scale.
2. Velocity - Refers to the speed at which the data is generated and processed. Big Data systems are designed for streaming and real-time data.
3. Variety - Refers to the different types and formats of data like structured, unstructured, text, images, videos, etc. Big Data platforms can integrate various types of data sources and formats.
4. Veracity - Refers to the uncertainty of the data and the fact that the data may be incomplete, noisy, or inconsistent. Big Data systems are designed to handle such uncertainties and inconsistencies in the data.
