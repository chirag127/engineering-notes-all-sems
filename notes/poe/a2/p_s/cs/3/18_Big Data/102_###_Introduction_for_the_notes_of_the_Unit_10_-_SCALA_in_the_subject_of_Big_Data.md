### Introduction for the notes of the Unit 10 - SCALA in the subject of Big Data

1. Scala is a general-purpose programming language providing support for functional programming and a strong static type system. It runs on the Java Virtual Machine (JVM) and can use existing Java code.
2. Scala's design goals attempt to combine object-oriented and functional programming techniques in a concise and coherent manner. Scala adds a number of features to support functional programming, including immutable data structures, pattern matching, and type inference.
3. Scala source code is intended to be compiled to Java bytecode, so that the resulting executable code runs on a Java virtual machine. Scala provides language interoperability with Java, so that libraries written in either language may be referenced directly in Scala or Java code.
4. The name Scala is a combination of the first letters of "scalable" and "language", signifying that it is designed to grow with the demands of its users.
5. The key aspects of Scala are:

- Combines Object Oriented and Functional Programming concepts.
- Has a concise and lightweight syntax.
- Is statically typed.
- Runs on JVM and is fully interoperable with Java.
- Supports both imperative and declarative styles.
- Facilitates concurrency through Actors.
- Has extensive standard libraries and third party libraries.

6. Some of the applications of Scala are:

- Used by Twitter for certain components of its backend.
- Used by Coursera for its course management system.
- Used by Netflix for its data pipeline framework.
- Used by Netflix, Yammer and Foursquare for building web services.
- Used to develop standalone applications as well as applications running on top of application servers like Apache Tomcat.
