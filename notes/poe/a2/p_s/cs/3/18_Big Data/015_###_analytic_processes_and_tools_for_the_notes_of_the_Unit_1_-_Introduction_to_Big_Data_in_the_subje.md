### Hadoop Eco System Frameworks

The Hadoop ecosystem refers to the framework and components built on top of Hadoop that extend Hadoop's capabilities. The main components of the Hadoop ecosystem are:

1. HDFS - Hadoop Distributed File System: The primary storage system used by Hadoop applications. It splits files into large blocks and distributes them across nodes in a cluster.
2. MapReduce: A programming model for large scale data processing. Users specify map and reduce functions, and the underlying runtime system handles parallelization, distribution, and fault tolerance.
3. YARN: A cluster management technology. It splits up functionalities of job scheduling and resource management, allowing for other processing models like graph processing and stream processing to be supported in Hadoop in addition to MapReduce.
4. Hive: A data warehouse infrastructure built on top of Hadoop for providing data summarization, query, and analysis. It provides a SQL-like interface to query and manage large datasets residing in Hadoop's HDFS.
5. Pig: A high-level data flow language and execution framework for parallel computation. It provides an alternative to Java for creating MapReduce programs, allowing users to focus on the analysis rather than programming details.
6. HBase: A distributed, scalable, big data store. It supports structured data storage for large tables, and provides features like Strong Consistency, Ordered Keys, Optimistic Concurrency Control, etc.
7. Zookeeper: A centralized service for maintaining configuration information, naming, providing distributed synchronization, and providing group services. Many Hadoop components utilize Zookeeper for coordination and configuration management.
8. Oozie: A workflow scheduler system to manage Hadoop jobs. It allows users to define and schedule complex data pipelines referred to as workflows.
