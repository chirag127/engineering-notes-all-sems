### Hadoop Eco System Frameworks

The Hadoop ecosystem consists of multiple frameworks that are built on top of the Hadoop Distributed File System (HDFS) and help in solving various types of Big Data problems. Some of the major frameworks in the Hadoop ecosystem are:

1. MapReduce: MapReduce is the core framework of Hadoop that performs distributed processing of large data sets. It divides the processing into two phases - Map and Reduce. The Map phase splits the input data into key-value pairs and the Reduce phase aggregates the key-value pairs to produce the final output.

- Advantages: Scalable, Fault tolerant, Distributed processing
- Disadvantages: Too low level, requires extensive coding
- Applications: Data mining, web indexing, log processing, etc.

2. Hive: Hive is a data warehouse system built on top of Hadoop for providing data summarization, query, and analysis. It allows analysts to run SQL-like queries (called HiveQL) on distributed data using MapReduce.

- Advantages: Familiar SQL-like interface, Scalable and Fault tolerant
- Disadvantages: Performance impacts due to extra abstraction layer
- Applications: Data warehousing, Analytics, Reporting, etc.
