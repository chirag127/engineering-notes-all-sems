### Introduction to Big Data platform

The following points describe a Big Data platform:

1. Storage - The primary requirement for a Big Data platform is storage to store the huge volumes of data. The options for storage include:
- Hadoop Distributed File System (HDFS) - Distributed and scalable storage system
- NoSQL databases - For unstructured data
- RDBMS - For structured data

2. Processing - The platform requires processing mechanisms to analyze the huge data and gain insights. The popular options are:
- MapReduce - For distributed processing of large data sets
- Apache Spark - For fast processing of large data sets
- Stream processing - For processing real-time data streams

3. Management - The platform requires components to manage the workflow, resources, and systems. Some options are:
- YARN - For resource management and job scheduling
- Oozie - For workflow management
- Zookeeper - For coordination between distributed systems

4. Analytics - The platform requires options to analyze the data and get business insights. Some choices are:
- Pig - For analyzing large data sets
- Hive - For querying and analyzing large data sets
- Mahout - For machine learning on large data sets
- Spark MLlib - For machine learning on large data sets

5. Visualization - The platform requires ways to visualize the data insights in a understandable format. Some options are:
- Tableau
- Power BI
- Apache Zeppelin

The overall Big Data platform brings together the storage, processing, management, analytics, and visualization components to provide a solution for storing and analyzing huge volumes of data to gain business insights. The specific components chosen depend on the use cases and requirements.
