**Structured Data:**
- Data that can be stored, accessed and processed in a fixed format or schema.
- Examples: Data in tables/spreadsheets, databases, data with defined data models.
- Advantages: Easy to store and query, can be accessed and processed efficiently using SQL.
- Disadvantages: Schema needs to be defined in advance, lacks flexibility to accommodate changes or new types of data.

**Semi-Structured Data:**
- Data that does not conform to a fixed data model but has some structure.
- Examples: XML, JSON, CSV files, log files, sensor data.
- Advantages: Retains some structure which makes it easier to process than unstructured data. Flexible schema.
- Disadvantages: More complex to process than structured data. Querying can be challenging.

**Unstructured Data:**
- Data that has no defined data model or schema.
- Examples: Emails, documents, multimedia, social media data.
- Advantages: Flexible, diverse data that can be mined for new insights.
- Disadvantages: Most difficult to store, process and query. Requires extensive preprocessing to extract value.

In detail, the three types of digital data for Big Data are:
1. Structured data: Data with a defined model stored in tables/databases. Easy to access but lacks flexibility.
2. Semi-structured data: Data with some structure like XML/JSON files. Easier to process than unstructured data but more complex than structured data.
3. Unstructured data: Data with no defined structure like emails/documents. Valuable for insights but most difficult to store, process and query.
