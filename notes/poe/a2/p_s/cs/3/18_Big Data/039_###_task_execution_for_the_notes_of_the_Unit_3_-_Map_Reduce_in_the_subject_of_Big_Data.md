### Task Execution for the notes of the Unit 3 - Map Reduce in the subject of Big Data

1. MapReduce is a programming model for processing large data sets with a parallel, distributed algorithm on a cluster.
2. It consists of two major tasks - Map and Reduce.
3. The Map task partitions the input data into chunks which are processed in parallel by the cluster nodes.
4. The Reduce task aggregates the output of the maps and produces the final output.
5. The input and output of MapReduce are key-value pairs.
6. MapReduce is fault tolerant and can handle node failures automatically by re-replicating the data and re-executing the failed tasks on other nodes.
7. Some advantages of MapReduce are its scalability, flexibility and efficient use of clusters.
8. Some disadvantages are its complexity in programming and inefficient for algorithms requiring multiple MapReduce phases.

### Pig

1. Pig is a high-level scripting language developed by Yahoo! to analyze large data sets.
2. It converts the Pig Latin scripts into MapReduce jobs which are executed on Hadoop.
3. Pig Latin includes operators like LOAD, FILTER, GROUP, FOREACH, etc. to perform operations on the data.
4. Some advantages of Pig are its simplicity, efficiency and ability to handle nested and complex data types.
5. However, Pig Latin scripts are hard to debug and optimize. Also, Pig is not suitable for real-time processing.
6. Pig is commonly used for data preprocessing, filtering, transformations, grouping, joining and aggregations on Hadoop clusters.
