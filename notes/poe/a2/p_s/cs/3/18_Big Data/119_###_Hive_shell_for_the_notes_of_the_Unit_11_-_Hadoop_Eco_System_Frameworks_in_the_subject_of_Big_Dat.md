### Introduction to Big SQL

- Big SQL is a SQL-on-Hadoop system developed by IBM. It allows you to use ANSI standard SQL to query data on Hadoop.
- It enables you to query data without the complexity of learning MapReduce or HiveQL. If you know SQL, you can easily query Hadoop data with Big SQL.
- With Big SQL, you can query data in:
    - JSON data
    - Parquet files
    - RCFile
    - Sequence files
    - Text files
- Some key benefits of Big SQL are:
    - ANSI standard SQL support - Easy to learn for SQL users and widely used skill
    - Performance - It provides optimal performance using Apache Drill's distributed query engine and implements advanced SQL optimizations and caching techniques.
    - Scalability - It can scale to handle terabytes and petabytes of data on Hadoop.
    - Flexibility - Query Hadoop data in various formats and integrate with Hive.
- To use Big SQL, you need a Hadoop cluster and Big SQL licensed software. You can connect to Big SQL using JDBC or ODBC to query data from applications.
- Some limitations of Big SQL are:
    - Not open source
    - Limited to IBM Hadoop distributions (no other Hadoop vendors)
    - Steeper learning curve than SQL-on-Hadoop systems without full SQL support
