## Unit 10 - SCALA

Scala is a general-purpose programming language that runs on the Java virtual machine (JVM) and also can be compiled to JavaScript source code.

Key points to learn:

1. Scala is a statically typed language with type inference, supporting both object-oriented and functional programming styles.
2. Scala source code is intended to be compiled to Java bytecode, allowing the resulting executable code to run on a Java virtual machine.
3. Scala provides language interoperability (each Scala application is also a Java application) and allows Java code to be referenced from Scala and vice versa.
4. Scala's functional capabilities build on the core Java collections library, providing persistent data structures and other functional constructs.
5. The Scala type system is strong and static, but supports explicit type annotations and type inference.
6. Scala has full support for Unicode, with syntactic flexibility akin to Python.
7. The Scala compiler can perform many static code analysis checks at compile-time.
8. Scala runs on the Java platform (Java virtual machine) and is interoperable with Java.

Advantages:

- Increased productivity due to less boilerplate code compared to Java.
- Concise and elegant syntax which is appealing to programmers.
- Supports both object-oriented and functional programming styles.
- Strongly statically typed to avoid bugs at compile-time.
- Interoperable with Java and runs on the JVM.
- Growing community and usage in industry.

Disadvantages:

- Steeper learning curve for programmers new to functional programming concepts.
- Runtime performance can suffer due to extra abstraction.
- Binary compatibility not guaranteed between Scala releases.
- Limited choice of libraries compared to more established languages like Java or Python.
