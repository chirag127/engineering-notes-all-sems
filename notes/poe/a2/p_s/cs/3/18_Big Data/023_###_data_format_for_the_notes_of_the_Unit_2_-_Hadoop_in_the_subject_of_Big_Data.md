### Data formats for the notes of Unit 2 - Hadoop

1. Input data formats
- Text input format: Default input format. Reads lines of text files.
- Key value input format: Reads binary input data.
- Sequence file input format: Reads sequence files.
- XML input format: Reads XML files.

2. Output data formats
- Text output format: Writes records into text files.
- Key value output format: Writes records into binary files.
- Sequence file output format: Writes records into sequence files.
- Multiple outputs: Writes to multiple output files.

#### Applications on Big Data using Pig

1. Pig Latin: Pig's data flow language. Similar to SQL.
- Load and store functions to import and export data.
- Filter, group, join, sort, etc.
- User defined functions.

2. Execution modes
- Local mode: Runs on a single machine.
- MapReduce mode: Runs on a Hadoop cluster.

3. Advantages
- Easy to learn.
- Handles nested and complex data types.
- Provides optimization opportunities.
- Integrates with Hadoop and MapReduce.
