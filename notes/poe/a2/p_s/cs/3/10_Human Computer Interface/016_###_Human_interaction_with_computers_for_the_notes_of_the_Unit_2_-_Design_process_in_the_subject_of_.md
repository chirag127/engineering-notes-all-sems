### Software Characteristics

- Reliability: The ability of a software product to perform its required functions under stated conditions for a specified period of time. The software should be fault-tolerant and robust.
- Efficiency: The capability of the software product to provide appropriate performance, relative to the amount of resources used, under stated conditions. The software should not utilize excessive amount of system resources like memory, CPU, etc.
- Usability: The capability of the software product to be understood, learned, used and attractive to the user, when used under specified conditions. The software should have a intuitive and user-friendly interface.
- Maintainability: The capability of the software product to be modified
- Portability: The capability of the software product to be transferred from one environment to another. The software should be independent of specific hardware and operating system.
- Testability: The capability of the software product to allow for and facilitate the establishment of test criteria and the performance of tests to determine whether those criteria have been met. Proper logging and debugging capabilities should be included in the software.

### Human interaction with computers for the notes of the Unit 2 - Design process in the subject of Human Computer Interface

- Input devices: Keyboard, mouse, touchscreen, microphone, etc. are used to enter data and commands into the computer.
- Output devices: Monitor, speaker, etc. are used to display the results from the computer.
- Graphical user interfaces (GUI): Use graphics, icons and menus to interact with the user. Examples are Windows, MacOS, etc.
- Command-line interfaces (CLI): Use text-based commands to interact with the user. Examples are Command Prompt and Linux terminals.
- pointing devices: Mouse, touchpad, trackball, touchscreen, etc. are used to point to and select objects on the screen.
- Voice interfaces: Allow users to interact with the computer using voice commands. Examples are Siri and Alexa.
- Gesture interfaces: Allow users to interact with the computer using hand gestures and body movements. Examples are Kinect and Leap Motion.
