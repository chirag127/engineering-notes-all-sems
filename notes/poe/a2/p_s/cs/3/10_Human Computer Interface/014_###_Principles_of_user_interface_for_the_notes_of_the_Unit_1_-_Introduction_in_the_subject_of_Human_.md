### Principles of user interface for the notes of the Unit 1 - Introduction in the subject of Human Computer Interface:

1. Simple and intuitive: The interface should be simple, intuitive and easy to use. The users should be able to understand how the interface works and be able to operate it without much training. This makes the interface user friendly. Examples: Simple buttons, icons, menus, etc.

2. Consistency: The interface should be consistent in its layout, design, and operations. Similar functions or items should be displayed in a similar manner throughout the interface. This makes it easy for the user to learn and remember how the interface works. Examples: Same icons or buttons used for same types of functions, same menu layout, etc.

3. Provide feedback: The interface should provide proper feedback to the user about the actions performed. This could be in the form of sounds, visual highlights, error messages, etc. This helps the user understand the effect of the actions and whether the actions were successful or not. Examples:Highlighting button when clicked, error messages when incorrect input, etc.

4. Error prevention: The interface should be designed to prevent errors as much as possible. This could be by providing defaults, constraining inputs, confirmation messages, etc. This makes the interface robust and easy to use. Examples: Providing default options, giving input constraints, asking for confirmation on important actions, etc.

5. Flexibility: The interface should be flexible enough to accommodate the needs of various types of users. It should provide options to change settings, modify layouts or views, provide shortcuts, etc. This allows power users to customize the interface as per their needs and skills. Examples: Providing customization options, multiple views or layouts to select from, keyboard shortcuts, etc.
