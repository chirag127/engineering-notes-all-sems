### Ordering of screen data and content for the notes of the Unit 3 - Screen Designing in the subject of Human Computer Interface

1. Grouping related items - Group related information, commands, and controls together. This makes the screen layout more logical, understandable, and easier to learn. For example, group all input fields together, align related buttons or controls together, etc.

2. Consistency - Maintain consistency in the positioning of screen elements, use of colors, terminology, etc. This helps the user predict the location of information or controls and understand the screen faster. For example, keep the logout button in the same position in all screens, use same color code for highlighting errors, use same terms for referring to the same things, etc.

3. Simplicity - Keep the screen layout simple and avoid clutter. Only include essential information and controls. Too much data or too many options on the screen can confuse the user and make it difficult to understand.

4. Flow - Arrange the screen elements in a flow or sequence. For example, in a multi-step process like signing up for a service, arrange the steps in a logical flow (enter personal details -> enter account details -> set security questions, etc.). This makes the process easy to follow and complete for the user.

5. Grouping - Group related content chunks or blocks together. For example, you can group account information under one section, order details under another section and contact information under a third section. This makes it easy for the user to find the relevant information fast.

6. Labelling - Use clear and appropriate labels for different sections, fields, controls, etc. This helps the user understand the purpose of each screen element easily. Keep the labels concise but descriptive.

7. Navigation - Provide obvious navigation controls to move between screens or sections. For example, use buttons, links or menus to allow the user to navigate to the next step in a process or move to a different section of the screen. Clear navigation helps the user understand how to access all the available options or information.
