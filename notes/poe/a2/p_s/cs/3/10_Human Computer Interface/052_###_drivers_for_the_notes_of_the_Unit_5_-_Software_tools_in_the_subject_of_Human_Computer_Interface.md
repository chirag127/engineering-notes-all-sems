### Drivers for Software tools in HCI

1. Programming Languages: Programming languages are essential tools for software development in HCI. Some popular languages used are:
- Python: Easy to learn, has multiple libraries for GUI, graphics, etc. Used to prototype and build apps.
- JavaScript: Used to develop interactive web pages and web apps. Works with HTML and CSS.
- C/C++: Compiled languages, efficient but complex. Used to develop system software and games.

2. IDEs: Integrated Development Environments provide a single application with all the tools needed for software development making the process efficient. Some popular IDEs are:
- Visual Studio: Used for development in multiple languages like C++, C#, Python, etc. Provides debugging and coding assistance tools.
- Eclipse: Open source IDE supporting languages like Java, PHP, C/C++, Python, etc. Provides debugging and coding assistance tools.
- Atom: Open source and extensible IDE with support for multiple languages. Can be customized with packages and themes.

3. Version Control Systems: VCS are essential for team collaboration and maintaining history of code changes. Some popular VCS are:
- Git: Distributed VCS, best suited for collaboration. Github is a popular hosting service for Git repositories.
- Mercurial: Distributed VCS with easy learning curve. Can be hosted locally or on services like Bitbucket.
- SVN: Centralized VCS suited for a linear development model. Can maintain history of all file versions in a central repository.
