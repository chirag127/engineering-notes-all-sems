### Interaction Devices

1. Keyboard:
- It is the most common input device used to enter data and control the computer.
- It allows the user to input alphanumeric data and control the computer.
- It consists of an arrangement of buttons or keys that can be pressed to input characters.
- It is suitable for entering textual data and commands.

2. Mouse:
- It is a pointing device that detects two-dimensional motion relative to a surface.
- It allows the user to interact with the graphical user interface of the operating system and application software.
- It translates the movement of the device across a surface into signals that the computer can understand.
- The two most common types of mice are mechanical mice and optical mice.
- It is suitable for selecting, dragging and moving objects on the screen.

3. Trackball:
- It is a pointing device consisting of a ball housed in a socket which can be rotated with fingers to control the cursor on the screen.
- It serves the same purpose as a mouse but does not require any flat surface to operate.
- It consists of sensors to detect the rotation of the ball and convert it into electrical signals which are sent to the computer.
- It is suitable for applications where there is less space to operate a mouse.
