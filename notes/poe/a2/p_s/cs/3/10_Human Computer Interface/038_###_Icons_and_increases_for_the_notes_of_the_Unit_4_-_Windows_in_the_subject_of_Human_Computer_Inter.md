## Icons

- Icons are small images that represent files, folders, applications, etc. to make them easily identifiable.
- They make it easy to locate and access the resources without reading the text.
- Icons use intuitive graphics and colours to convey the purpose. For example, a document icon may have an image of a page, a folder icon may have an image of a folder, etc.
- Icons save space and make the interface visually appealing and easy to use.
- However, too many icons can make the interface complex and confusing. They should be designed simply and meaningfully.

## Windows

- Windows are rectangular regions on the screen that display output or accept input.
- They are used to simultaneously display multiple resources or tasks.
- The operating system uses a windowing system that manages the windows, enables user interactions with them, and refreshes the contents of the windows.
- Common types of windows are application windows to interact with the software, dialog boxes to get input from the user, and notification windows to provide output to the user.
- The windows can be resized, moved, minimised, maximised, cascaded, tiled, closed, etc. based on the user requirements and convenience.
- However, too many overlapping windows can make the interface disorganised and difficult to use. Appropriate window management features should be provided.
