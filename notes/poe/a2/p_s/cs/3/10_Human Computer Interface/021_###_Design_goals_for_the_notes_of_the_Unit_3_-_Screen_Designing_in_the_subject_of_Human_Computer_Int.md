### Design goals for the notes of the Unit 3 - Screen Designing in the subject of Human Computer Interface:

1. Simplicity: The screens should be designed in a simple and easy to understand manner. Complex layouts and designs should be avoided. Only the required fields and elements should be present in the screen.
2. Clarity: The purpose and function of each element on the screen should be very clear to the user. Appropriate labels and instructions should be provided. The overall display should not be cluttered or confusing.
3. Consistency: The styles, layouts and elements used should be consistent across the screens. This helps the user in familiarizing with the system and navigating easily. Consistent and conventional styles should be followed as per the platform style guide.
4. Feedback: Appropriate feedback should be provided to the user about the inputs given, errors occurred, processing status, etc. This could be in the form of suitable messages, loading indicators, validation messages, etc. This keeps the user engaged and aware of the system status.
5. Responsiveness: The screen should respond to the user inputs and actions promptly. Avoiding delays and lagging helps in providing a good user experience. The response could be in the form of changed screen, message, error, etc. depending on the user action.
6. Device independence: The screens should be designed in a way that they can adapt to different devices and screen sizes. This could be achieved using responsive and adaptive design techniques. This increases the accessibility and usability of the system or application.
