### A brief history of Screen design

1. Command Line Interface (CLI) - In the initial days of computers, the only way to interact with the system was through commands. The user had to remember and type commands to perform tasks. There was no graphical user interface. Examples - DOS, Unix terminal.

Advantages - Minimal system resources required. Fast.
Disadvantages - Steep learning curve. Tedious to use.

2. Graphical User Interface (GUI) - Introduction of the mouse and on-screen elements like windows, icons, menus, pointers led to the GUI era. The Xerox Alto was the first computer with a GUI in 1973. Apple Lisa was the first commercial computer with GUI in 1983. Microsoft Windows was introduced in 1985.

Advantages - Easy to use. Visually appealing.
Disadvantages - Required more system resources. Slower than CLI.

3. WIMP - The most common elements of a GUI are the windows, icons, menus, and pointers. This combination is known as the WIMP interface. Most of the modern operating systems and softwares use the WIMP style of interface design with additional features.

4. Touch interfaces - The introduction of touchscreen technology enabled new ways of interaction using direct touch gestures. The on-screen elements are larger and spaced out. Examples - iOS, Android.

Advantages - Intuitive. Natural.
Disadvantages - Fatigue and Gorilla arm effect with prolonged use. Limitations with precise input.
