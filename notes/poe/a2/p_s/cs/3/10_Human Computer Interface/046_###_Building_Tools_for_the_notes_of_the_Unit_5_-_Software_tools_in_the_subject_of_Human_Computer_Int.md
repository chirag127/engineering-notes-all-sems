### Feasibility Study in Software Requirement Specification (SRS)

- A feasibility study is conducted to determine if a project is viable and worth pursuing. It evaluates if the system can be built with available resources and if it can be used by intended users.
- It is done in the early stages of software development life cycle. It is a part of SRS (Software Requirement Specification) which comes after the project initiation phase.
- The main objectives of feasibility study are:
- Technical feasibility - To check if the technology needed to implement the system is available or not. For example, whether required hardware, software, database etc. are available or can be developed with available resources.
- Economic feasibility - To check if the system can be developed and maintained within the budget constraints. It evaluates cost benefit analysis to see if benefits of the proposed system outweigh its costs.
- Operational feasibility - To check if the system can be integrated with existing systems and if the organization can operate and maintain it. It evaluates if users will adopt the new system and if it fits with the organizational culture and structure.
- Following are the steps involved in feasibility study:
- Gather system requirements and specifications
- Identify alternative solutions
- Evaluate alternatives (technically, economically and operationally)
- Prepare feasibility study report
- Make go/no-go decision

The feasibility study helps to determine if the project should be undertaken or not. It avoids wastage of resources on projects that are not practical or useful. It leads to the development of systems that are efficient, economical and useful to the organization.
