### Keyboard and function keys

The following are the commonly used keyboard keys and their functions:

- Regular keys: Used to enter letters, numbers, and symbols.
- Esc (Escape) key: Used to exit or stop the currently running process or to go back to the previous screen.
- F1 to F12 keys: Called function keys. Have specific functions assigned to them in various applications. Their functions can vary based on the application in use. Some common functions of F keys are:
- F1: Help. Provides help or documentation related to the currently active window or application.
- F2: Rename. Used to rename a selected file or folder.
- F5: Refresh. Refreshes or reloads the current page or window.
- F10: Menu. Used to activate the menu bar options.
- Tab key: Used to move the cursor to the next field or option. Shifts focus to the next control or option.
- Caps lock key: Used to switch between upper case and lower case letters. When caps lock is on, all letters are typed in upper case.
- Shift key: Used to type capital letters, symbols, and characters not directly available on the keyboard. Holding shift and pressing a letter key types the corresponding capital letter.
- Ctrl key: Used in combination with other keys to perform certain actions. Ctrl+C is used to copy, Ctrl+V to paste, etc. The functions vary based on the operating system and application.
- Alt key: Similar to Ctrl, used in combination with other keys to perform certain functions. Alt+F4 is used to close the current window, Alt+Tab is used to switch between open windows, etc. The functions vary based on the operating system and application.
