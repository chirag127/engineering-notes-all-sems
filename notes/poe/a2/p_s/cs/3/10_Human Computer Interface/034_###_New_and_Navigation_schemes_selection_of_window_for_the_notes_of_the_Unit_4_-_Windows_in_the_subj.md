### New and Navigation schemes selection of window for the notes of the Unit 4 - Windows in the subject of Human Computer Interface

1.  New Window: Opening a new separate window for a task is one of the ways to handle multiple tasks. This allows viewing and working on multiple tasks simultaneously. However, it can lead to cluttered desktop and taskbar if many windows are opened. It is suitable for unrelated and independent tasks. Examples: Opening multiple browser windows, multiple notepad windows, etc.
2.  Tabs: Tabs allow displaying multiple content panes within the same window. Only one tab is active at a time and switching between tabs is easy. It leads to less clutter and is suitable for related tasks or tasks performed sequentially. However, tabs take up taskbar space and switching between many tabs can be difficult. Examples: Browser tabs, text editor tabs, etc.
3.  Split Panes: Windows can be split into panes to display and work on multiple sections of a task simultaneously. Panes can be adjusted to suitable sizes. They are suitable for tasks where viewing different sections together is required. However, resizing panes and handling many panes can be difficult. Examples: Text editor panes, IDE panes, file browser panes, etc.

Advantages and disadvantages of different schemes can be compared and suitable scheme can be selected based on the nature of the tasks, user preferences and other factors. Designing intuitive navigation between panels and options to easily switch, remove, reorder tabs/panes improves user experience. Including additional features like previews, separators, labels, etc. can aid in use of windows and panes.
