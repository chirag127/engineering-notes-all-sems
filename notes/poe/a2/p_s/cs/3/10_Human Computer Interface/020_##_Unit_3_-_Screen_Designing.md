### Software Engineering Processes

1. Requirements Analysis: Gathering and analyzing system requirements to understand the problem and propose solutions. Includes eliciting, analyzing, validating and managing requirements.
2. Design: Producing a design that satisfies the requirements. Includes both high-level and detailed design.
3. Implementation: Implementing the design in a programming language. Includes Coding, Testing and Debugging.
4. Integration: Combining separate components and testing the overall system.
5. Deployment: Releasing the software and making it available to end-users.
6. Maintenance: Fixing bugs, enhancing functionality, improving performance and adapting to changing environments and requirements.

Advantages: Provides a systematic approach, Reduces risks and costs, Increases quality, Facilitates management.
Disadvantages: Can be bureaucratic, Difficult to plan fully, conflicts can arise between stages.

## Unit 3 - Screen Designing

1. Gather requirements: Determine requirements like target audience, platform, content, navigation, etc.
2. Plan layout: Decide on conceptual layout, arrangement of sections/content and navigation flow. Consider conventions and usability.
3. Choose visual elements: Select color scheme, fonts, images, icons, etc. that enhance accessibility, usability and aesthetics.
4. Prototype and test: Create prototypes to test layout, visual elements and interactions. Get user feedback and modify as needed.
5. Develop final screens: Build final screens with selected frameworks/libraries and implement transitions, animations and interactions.
6. Evaluate and optimize: Evaluate against requirements and usability guidelines and optimize performance, accessibility and user experience.
