## Unit 1 - Introduction

1. Data compression - Data compression is the process of encoding information using fewer bits than the original representation. It reduces the size of data to save storage space and transmission time.
2. Lossless vs lossy compression - There are two types of data compression techniques:
 - Lossless compression - It allows the original data to be perfectly reconstructed from the compressed data. Examples include ZIP, GZIP, PNG.
 - Lossy compression - It reduces the size of data through approximating and discarding some details. The original data cannot be reconstructed exactly. Examples include JPEG, MP3, MPEG.
3. Entropy - Entropy is a measure of randomness or uncertainty of a system. The more random the data is, the higher its entropy and the less it can be compressed. Regular and repetitive data has low entropy and can be compressed more.
4. Dictionary coding - It is a lossless compression technique that replaces frequently occurring strings with shorter codes. It works well for text data containing repeating words and patterns.
