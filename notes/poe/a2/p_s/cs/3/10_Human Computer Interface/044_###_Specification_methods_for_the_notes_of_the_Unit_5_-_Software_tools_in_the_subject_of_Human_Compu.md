### Specification methods for the notes of the Unit 5 - Software tools in the subject of Human Computer Interface

1. Low fidelity prototypes:
- Quick and inexpensive to create.
- Used early in the design process to gather user feedback.
- Include hand-drawn sketches, paper prototypes, etc.
- Help in understanding user requirements and iterating on design solutions.

2. High fidelity prototypes:
- Provide a more realistic experience through features like interactivity and higher visual fidelity.
- Include prototypes created using prototyping tools, coded sketches, etc.
- Allow detailed usability testing but take more time and effort to create.
- Useful in the later stages of the design process.

3. Storyboards:
- A series of sketches that show the interface behaviour over time.
- Help in envisioning the dynamics of the interface and user's interactions with it.
- Useful for communicating design ideas to stakeholders and team members.
- Limited fidelity - do not provide actual user experience.

4. Scenarios:
- Written descriptions of interactions between the user and the system.
- Help in understanding the context of use and key tasks.
- Useful in providing a shared understanding of the requirements to the team.
- Limited fidelity - do not provide actual user experience.
