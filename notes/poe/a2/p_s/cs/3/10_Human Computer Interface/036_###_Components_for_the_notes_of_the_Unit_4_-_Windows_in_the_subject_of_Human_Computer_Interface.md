### Components for the notes of the Unit 4 - Windows in the subject of Human Computer Interface

1. Title Bar: The title bar displays the title of the window and contains control buttons for minimizing, maximizing, and closing the window.

2. Menu Bar: The menu bar contains drop-down menus for performing actions on the window such as saving, printing, editing, etc. The menu bar is present below the title bar.

3. Toolbar: The toolbar contains buttons for commonly used commands. It provides an alternative way to issue commands instead of using menus. The toolbar is present below the menu bar.

4. Status Bar: The status bar is present at the bottom of the window. It displays information such as page number, page count, connectivity status, etc. related to the application.

5. Scroll Bars: Scroll bars are used to scroll through the content of windows that contain more information than can be displayed in the visible area of the window. Vertical scroll bar is used to scroll up and down and horizontal scroll bar is used to scroll left and right.

6. Border: A border surrounds the entire window. It can be resized by dragging the border. The style, color, and size of the border can be customized.

7. Taskbar: The taskbar is present at the bottom of the desktop. It displays the icons of running applications and is used to switch between applications and windows.

The above points cover the major components that are part of a typical window.
