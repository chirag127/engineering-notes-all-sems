## Unit 1 - Introduction to Software Engineering

1. What is Software Engineering?
- Software Engineering is the systematic application of engineering approaches to software development.
- It involves a series of steps like analysis, design, implementation, testing, deployment, and maintenance to develop software solutions.
- The key goals of Software Engineering are to develop software that is reliable, efficient, maintainable, and affordable.

2. Why is Software Engineering important?
- Software is embedded in almost every aspect of our lives today. Right from mobile phones to automobiles, a significant part of the functionality is provided by software.
- Software Engineering helps to build high quality, robust, and reliable software solutions that can be maintained and evolved easily as requirements change. This is critical for software that is part of safety-critical systems like aircraft control systems or medical devices.
- The systematic process also helps to bring down the cost and time required to build software solutions while achieving higher quality. This improves ROI for businesses and increases customer satisfaction.

3. Software Engineering Processes
- The key software engineering processes are:
-- Analysis: Determine requirements and feasibility
-- Design: Develop architecture/high-level design
-- Implementation: Code implementation
-- Testing: Test individual components and integrated system
-- Deployment: Release software for user use
-- Maintenance: Fix bugs and improve software

4. Software Engineering Tools
- There are many tools to aid the software engineering process:
-- Requirements management tools: To capture requirements
-- Diagramming tools: To create diagrams for analysis and design
-- IDEs: For coding and implementation
-- Version control: To manage changes to code
-- Bug tracking tools: To log and track bugs/issues
-- Testing tools: To automate testing
