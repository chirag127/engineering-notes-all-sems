## Unit 5 - Code Generation

- Code generation is the process of generating executable code from an intermediate representation or declarative description. The input is a model of the software, and the output is code in some programming language like C/C++, Java, Python, etc.
- The key benefits of code generation are:
    - Increased productivity - less time spent writing boilerplate code.
    - Increased quality - reduced defects as code is generated from a model rather than hand-written.
    - Maintainability - changes made to the model propagate to generated code, ensuring consistency.
- Types of code generators:
    - Template-based code generators - use text templates with placeholders that are filled with model data to produce output code. Easy to implement but less flexible.
    - Model-driven code generators - transform a model into output code using model queries and transformations. More flexible but complex to implement.
- Applications of code generation:
    - Database access layer generation - generates boilerplate code to access a database based on its schema.
    - GUI generation - generates interface code from screen layout descriptions.
    - Test case generation - generates test cases from a system model to increase test coverage.
    - Rapid prototyping - quickly generate prototype code from high-level specifications to demonstrate concepts.
- Advantages:
    - Productivity gain from less manual coding.
    - Higher quality code from generating from models rather than manual coding.
    - Consistency between model and code through automatic synchronization.
- Disadvantages:
    - Initial effort required to develop code generators.
    - Complex to implement for flexible, optimized code generation.
    - Generated code can be difficult to read and debug.
    - Model changes may have unexpected impact on generated code and require manual tweaking.
