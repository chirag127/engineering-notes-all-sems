### Parsers for Basic Parsing Techniques

1. Introduction
- A parser is a component of a compiler that analyses the input code and groups its constituents into syntactic units called phrases.
- The output of the parser is a parse tree that represents the syntactic structure of the input.
- Parsers can be handwritten or generated using parser generators.

2. Types of Parsers
- Recursive Descent Parsers: Uses recursive functions to parse input. Easy to write but errors are hard to recover from.
- LL Parsers: Constructs a parse table to determine if an input can be parsed. Left to right scanning of input.
- LR Parsers: Uses states and ACTION/GOTO tables to determine valid inputs. Right to left scanning of input. More powerful but harder to implement.
- Generalized LR Parsers: Extends LR parsing to handle broader class of grammars. Uses parse forest instead of single parse tree.

3. Applications
- Parsers are essential components of compilers and interpreters.
- They are used to analyse the syntax of programming languages and process the input code.
- The output parse trees are used to generate intermediate representations or executable code.
- Parsers play a key role in software that involves processing of formal languages.
