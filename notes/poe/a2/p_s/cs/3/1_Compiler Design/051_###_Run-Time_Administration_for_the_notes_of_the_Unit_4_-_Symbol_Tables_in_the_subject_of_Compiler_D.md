### Challenges of conventional systems compared to Big Data

1. Volume - The volume of data in Big Data is enormous. Conventional systems are not designed to store and process such huge volumes of data. This poses a challenge in storing and processing the data efficiently and effectively.
2. Velocity - The speed at which data is generated and processed in Big Data systems is extremely fast. Conventional systems cannot match up to the velocity of Big Data and this poses a challenge in analyzing streaming data in real-time.
3. Variety - Big Data consists of data in varying formats like structured, semi-structured and unstructured data. Conventional systems are designed to handle primarily structured data. This poses a challenge in integrating and analyzing the diverse data formats in Big Data.
4. Complexity - The complexity of Big Data analytics processes is high due to the volume, velocity and variety of data. Conventional systems are not equipped to handle such complexity which poses a challenge in deriving insights and value from Big Data.
5. Cost - The cost of storing and processing huge volumes of data is very high. Though the cost of storage has reduced over time, it still poses a challenge for organizations to afford the infrastructure and resources required for Big Data systems compared to conventional systems.

### Run-Time Administration for the notes of the Unit 4 - Symbol Tables in the subject of Compiler Design

1. A symbol table is a data structure that stores information about identifiers in a program. It aids in compiling, interpreting and debugging the program.
2. At compile-time, when the compiler encounters an identifier, it creates an entry for it in the symbol table. The entry stores information such as the identifier's name, type and scope.
3. At run-time, when interpreting or executing the code, the interpreter/compiler refers to the symbol table to resolve references to identifiers. This is critical for variables since the interpreter must know the type and memory allocation for a variable when its value is accessed or changed.
4. The symbol table is organized as a data structure to enable fast retrieval of information. The specific data structure used can vary but it is typically a hash table, a tree or a list.
5. Efficient implementation of a symbol table is important for the performance of a compiler or interpreter. The main operations on a symbol table are inserting a new identifier, looking up an identifier and removing an identifier. These operations must be fast even for symbol tables containing thousands of identifiers.
