### Code Generator

- The Code Generator is a part of the Code Generation phase of a Compiler.
- The Code Generator takes the Intermediate Representation (IR) of the source program as input and generates the target program code as output.
- The IR can be in the form of:
	- Syntax Trees
	- Abstract Syntax Trees (ASTs)
	- Control Flow Graphs (CFGs)
	- Three Address Code (TAC)
- The target program code can be in machine understandable binary code or assembly code.
- The Code Generator utilizes a variety of techniques for efficient and optimized code generation such as:
	- Basic Block Procedures
	- Peephole Optimization
	- Instruction Scheduling
	- Allocation of Registers
- The performance of a Compiler majorly depends on the efficiency and optimization techniques used by the Code Generator to generate high quality target code.
- Some key points to keep in mind while writing a Code Generator are:
	- Simplicity and Understandability of the generated code
	- Minimum Memory Usage
	- Efficient Execution
	- Optimized code with least execution cycles

The above points cover the key aspects regarding the Code Generator of a Compiler and how to write an efficient Code Generator. The points can act as a good reference to learn and understand the concept of Code Generation for Compiler Design exams and interviews.
