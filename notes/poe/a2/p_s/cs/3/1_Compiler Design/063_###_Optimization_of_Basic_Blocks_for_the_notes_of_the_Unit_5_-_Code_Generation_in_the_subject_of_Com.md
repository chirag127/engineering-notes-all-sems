### modern data analytic tools for Big Data

The following are some of the popular modern data analytics tools used for Big Data:

1. Hadoop Ecosystem - Hadoop ecosystem is a framework for distributed storage and processing of very large data sets. It includes tools like HDFS, MapReduce, Hive, Pig, HBase, Spark, etc. which are used for data storage, data processing, data querying and data analysis of Big Data.

2. Spark - Apache Spark is a fast and general-purpose cluster computing system. It provides APIs in Java, Python, R, and Scala, and supports various workloads such as batch processing, streaming, machine learning, and graph processing. It has in-memory data processing capabilities and is much faster than Hadoop for iterative and interactive apps.

3. Flink - Apache Flink is a framework and distributed processing engine for stateful computations over unbounded and bounded data streams. It has stream and batch processing capabilities with APIs in Java and Scala. It handles both high throughput and low latency in processing data streams.

4. Dremel - Dremel is a scalable, interactive ad-hoc query system for analysis of read-only nested data. It is capable of querying petabytes of data in seconds. It was designed by Google for highly scalable and fast interactive analytics.

5. Presto - Presto is an open source distributed SQL query engine for running interactive analytic queries against data sources of all sizes ranging from gigabytes to petabytes. It was created by Facebook to perform fast SQL-like queries on huge datasets. It can query various data sources like Hive, Cassandra, etc.
