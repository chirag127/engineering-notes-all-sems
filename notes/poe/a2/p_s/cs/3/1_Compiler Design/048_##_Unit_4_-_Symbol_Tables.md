## Unit 4 - Symbol Tables

- A symbol table is a data structure that stores symbols (such as variables and functions) and associates values with them.
- It is used to keep track of the names of variables, functions, and labels used in a program and their locations in memory.
- This allows the compiler or interpreter to quickly find the memory location associated with a variable or function when it is referenced in the program.
- Types of symbol tables:
    - Unordered symbol table - Symbols are inserted in arbitrary order. Searching is slow.
    - Ordered symbol table - Symbols are inserted in a specific order (alphabetical etc.) allowing faster searching.
- Operations on a symbol table:
    - Insert - Adds a new symbol and its associated value to the symbol table.
    - Lookup - Retrieves the value associated with a symbol.
    - Delete - Removes a symbol from the symbol table.
- Applications:
    - Compilers use symbol tables to keep track of variables, functions, and labels.
    - Debuggers use them to display the values of variables.
    - Interpreters use them to retrieve the value of a variable or the code for a function.
- Advantages:
    - Allow efficient lookup of symbols by name.
    - Enable detection of invalid references to variables and functions.
    - Aid in debugging and code generation.
