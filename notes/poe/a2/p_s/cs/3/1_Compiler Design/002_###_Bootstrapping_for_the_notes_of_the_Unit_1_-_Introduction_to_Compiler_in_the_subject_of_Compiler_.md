### Bootstrapping for the notes of the Unit 1 - Introduction to Compiler in the subject of Compiler Design

1. Bootstrapping is the technique used to develop a compiler for a programming language in that same language.
2. The initial compiler is first written in another programming language, often a low-level language.
3. The initial compiler is then used to compile a more sophisticated version of the compiler. This process is repeated resulting in increasingly more powerful compilers.
4. This technique helps to upgrade the compiler over time as the language evolves, and the limitations of the initial compiler are overcome with each iteration.
5. The major advantage of bootstrapping is that it allows the compiler to be self-hosted, i.e. compiled using itself. It helps to ensure that the compiler conforms to the language standards.
6. However, bootstrapping is a time-consuming and difficult process. Care must be taken to minimize errors as any error made in an iteration will get propagated to subsequent versions. Meticulous testing is required at each stage.
7. Examples of compilers developed using bootstrapping include compilers for languages such as C, C++, Go, Rust, etc. The bootstrap process is an important step in the development of modern programming languages.
