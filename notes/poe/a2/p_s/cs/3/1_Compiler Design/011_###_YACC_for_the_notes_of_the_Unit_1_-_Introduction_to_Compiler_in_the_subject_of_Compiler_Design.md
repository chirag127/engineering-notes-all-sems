### YACC

- YACC stands for Yet Another Compiler Compiler.
- It is a tool which generates a parser from a grammar specification.
- The grammar specification is written in a syntax called BNF(Backus-Naur Form).
- YACC converts the BNF grammar into C code which can be used as a parser in the compiler.
- The parser analyzes the input source program and breaks it into a sequence of tokens to check for grammatical errors.
- YACC provides interfaces to associate C code with components of the grammar. This code is executed when the components are recognized. This provides a way to create a syntax tree for the input.
- The advantages of using YACC are:

1. It reduces the time required to write a parser manually.
2. It ensures that the generated parser is free from syntax errors and ambiguities in the grammar.
3. It provides interfaces to write semantic actions associated with the grammar components allowing us to construct a syntax tree.

- The disadvantages of using YACC are:

1. The error messages generated by YACC may be difficult to understand sometimes.
2. The size of the generated parser code may be large and difficult to understand.
3. It uses lookahead which may result in inefficiencies.
4. The grammar needs to be written in a specific format (BNF) which has a small learning curve.

- Overall, YACC is a useful tool for compiler construction as it reduces the time required to generate a parser and ensures that it is free from syntax errors. With some effort, the disadvantages can be overcome and YACC can be effectively used to develop parsers in compilers.
