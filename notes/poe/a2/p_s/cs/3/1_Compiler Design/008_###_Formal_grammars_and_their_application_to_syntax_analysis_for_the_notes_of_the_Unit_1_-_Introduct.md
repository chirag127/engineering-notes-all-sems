### Formal grammars and their application to syntax analysis

A formal grammar is a set of rules that describe a language. It consists of the following components:

1. A finite set of symbols called an alphabet. The symbols can be terminals or nonterminals.
2. A set of productions or rules. Each production is of the form:

<nonterminal> → <string of terminals and/or nonterminals>

3. One of the nonterminals is designated as the start symbol.

The language generated by the grammar is the set of strings that can be derived by starting with the start symbol and applying productions until only terminals remain.

Formal grammars are classified into the following types:

1. Chomsky hierarchy: Type-0, Type-1, Type-2, and Type-3 grammars.
- Type-3 grammars generate regular languages.
- Type-2 grammars generate context-free languages.
- Type-1 grammars generate context-sensitive languages.
- Type-0 grammars generate recursively enumerable languages.

2. Phrase structure grammars: Constituency grammars that are context-free grammars. They are used to analyze the syntax of sentences in linguistics.

Formal grammars are used in syntax analysis, the first phase of a compiler. The input program is scanned and matched against the grammar rules to check for syntactic errors. If the input string is valid as per the grammar, the syntax analysis is successful. The output is a syntax tree that represents the structure of the input. This tree is used in subsequent compiler phases.

The advantages of using formal grammars for syntax analysis are:

1. They provide an unambiguous specification of the syntactic structure of the language.
2. They facilitate automatic analysis of the input.
3. They enable detecting and reporting syntax errors.

However, they have certain disadvantages too:

1. It is difficult to construct grammars for complex language features.
2. The number of rules can become very large for practical languages.
3. Ambiguities can occur in grammars.
