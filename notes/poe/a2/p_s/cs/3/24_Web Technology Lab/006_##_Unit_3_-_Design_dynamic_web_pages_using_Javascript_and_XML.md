## Unit 3 - Design dynamic web pages using Javascript and XML

1. Javascript - Javascript is a lightweight, interpreted programming or scripting language that is typically embedded into web pages. It allows web pages to be interactive and more dynamic. Using Javascript, web pages can respond to user events such as clicks, form input, etc. and perform various tasks like data validation, display alert messages, redirect pages, animate elements, etc. Some key features of Javascript are:
- It is lightweight and interpreted
- It is embedded into HTML pages
- It is client-side and executes in the browser
- It is cross-platform and cross-browser compatible
- It can access and manipulate DOM and CSS
- It has a simple and easy to learn syntax

2. XML - XML stands for Extensible Markup Language. It is a markup language much like HTML used to store and transport data. However, while HTML focuses on displaying data, XML focuses on storing and transporting data. It stores data in a hierarchical tree structure and uses custom tags to define data and its attributes. Some key features of XML are:
- It is a markup language like HTML
- It focuses on storing and transporting data, not displaying it
- It has a hierarchical tree structure
- It uses custom tags to define data and its attributes
- It is extensible, platform independent and language independent
- It separates content from presentation

3. Combining Javascript and XML - Javascript can be used to access and manipulate XML data. XML data can be loaded into the browser and Javascript can traverse the XML structure and extract necessary data from it. This allows web pages to dynamically display changing data from XML files. For example, an XML file containing product details can be loaded and Javascript can extract details of a specific product from it to display on a web page. This makes web pages more dynamic and data-driven. Some advantages of combining Javascript and XML are:
- XML separates data from presentation while Javascript can be used to present the data
- XML is platform and language independent while Javascript can easily access XML data
- The hierarchical structure of XML maps well to DOM accessed by Javascript
- It enables web pages to be dynamic and data-driven by loading external data
