### Write HTML/Java scripts to display your CV in navigator, your Institute website, Department Website and Tutorial website for specific subject for the notes of the Unit 1 - Develop static web pages using HTML in the subject of Web Technology Lab

1. HTML - Hypertext Markup Language is the primary web markup language to create web pages and display structured documents with headings, paragraphs, lists, links, quotes, etc. on the web.
2. To display your CV in the navigator:
    - Create an HTML file with .html extension
    - Add HTML boilerplate with <!DOCTYPE html>, <html>, <head> and <title> elements
    - In the <body> element, add heading <h1> for your name and contact information
    - Add sections for education, skills, experience, projects, achievements, etc. using <section> elements
    - Within each section, use headings, paragraphs, lists, emphasis elements to structure your CV content
    - Test the HTML file in the browser to view your CV
3. To display your CV in Institute/Department website and Tutorial website:
    - Create a separate HTML file for your CV following the above steps
    - Upload the HTML file to the website server
    - Link the HTML file within the website using anchor <a> element with href attribute pointing to the CV HTML file path
    - The linked CV will be displayed within the website when clicked
4. To display dynamic content and use JavaScript:
    - Learn JavaScript and integrate with HTML using <script> elements
    - Use JavaScript to fetch data from databases/APIs and dynamically update the HTML content using DOM methods
    - This enables to display updated CV and other content on the website without changing the HTML code always
