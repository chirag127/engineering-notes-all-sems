### Design server side applications using JDDC,ODBC and section tracking API

- JDBC (Java Database Connectivity) is an API that allows Java programs to interact with a relational database. It provides methods to query and update data in the database.
- ODBC (Open Database Connectivity) is a standard API for accessing database management systems. It allows Java programs to interact with a wide range of databases using a single standard interface.
- Section tracking API is used to track the sections or parts of a web page that need to be updated on the server side without reloading the entire page. It reduces bandwidth usage and increases performance.
