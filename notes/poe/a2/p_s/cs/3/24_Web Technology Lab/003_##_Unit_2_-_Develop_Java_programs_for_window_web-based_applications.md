## Unit 2 - Develop Java programs for window/web-based applications

- Learn to develop GUI applications using Swing and JavaFX.
- Understand the component architecture of Swing and JavaFX.
- Learn to handle events and user interactions.
- Develop web applications using servlets and JSP.
- Learn to access databases from web applications using JDBC.
- Understand the MVC architecture and its usage in web applications.
- Learn to develop web services and RESTful APIs.
- Deploy web applications to application servers like Tomcat.

#### Advantages:
- Java Swing and JavaFX provide platform-independent GUI development.
- Servlets and JSP enable efficient web development.
- Database access is convenient using JDBC.
- The MVC architecture separates concerns and improves maintainability.
- Web services and REST APIs can be accessed from any platform/language.

#### Disadvantages:
- Swing has a steep learning curve and can be complex to develop GUI's.
- JavaFX has limited browser support and requires plugins.
- JDBC requires manual resource management.
- deploying to application servers can be cumbersome to configure.

#### Examples:
- Calculator application with Swing/JavaFX
- Employee management web application using servlets/JSP and JDBC
- Weather API using REST principles
