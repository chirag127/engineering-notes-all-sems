### Install TOMCAT web server and APACHE for the notes of the Unit 5 - Design server site applications using JDDC,ODBC and section tracking API in the subject of Web Technology Lab

1. TOMCAT web server:
- TOMCAT is an open source Java EE web server used to host Java servlet and JSP applications.
- To install TOMCAT:
- Download the latest version of TOMCAT server from https://tomcat.apache.org/download-90.cgi
- Extract the zip file and go to the bin directory.
- Run the startup.bat (for Windows) or startup.sh (for Linux/Mac) file to start the TOMCAT server.
- Once started, you can access the TOMCAT homepage at http://localhost:8080 to ensure it is running properly.
- To deploy web applications, place the WAR or JAR file in the webapps directory of TOMCAT.
- Advantages: Open source, Java EE compatible, easy to use, supports JSP and servlets, widely used, large community support.

2. APACHE web server:
- APACHE is a free and open source web server software/HTTP server that serves data and files over the World Wide Web.
- To install APACHE:
- Download the APACHE server software from https://httpd.apache.org/download.cgi
- Extract the zip file and go to the bin directory.
- Run the httpd.exe (for Windows) file to start the APACHE server.
- Once started, you can access the APACHE homepage at http://localhost/ to ensure it is running properly.
- To deploy web applications or content, place them in the htdocs directory of APACHE.
- Advantages: Open source, highly configurable, runs on multiple platforms, supports numerous modules, large ecosystem of additional modules.
