## Unit 4 - Design dynamic web page using server site programming Ex. ASP/JSP/PHP

1. Server-side scripts - Scripts that are processed by the server are known as server-side scripts. Examples are ASP, JSP, and PHP.
2. ASP (Active Server Pages) - ASP is Microsoft's server-side scripting language that allows you to create dynamic web pages. It uses VBScript/JavaScript and interacts with databases.
3. JSP (JavaServer Pages) - JSP is Java's server-side scripting language. It allows you to create web pages that contain HTML, XML, and Java code. The Java code is executed on the server to generate dynamic content.
4. PHP (Hypertext Preprocessor) - PHP is an open-source server-side scripting language designed for web development. It can be embedded into HTML and is processed by the server.

Advantages:
- Dynamic content - The web pages can be changed or customized for each user or each visit.
- Interactivity - The pages can display data that changes, such as the number of visitors to the site or the user's location and preferences.
- Connect to databases - The scripts can interact with databases to display data on the web pages.

Disadvantages:
- Additional processing - The server has additional work to do in processing the scripts, which can slow down the performance.
- Security issues - There is a risk of security issues if the scripts are not properly secured.
- Vendor dependence - You are dependent on the software vendors to provide updates and patches.

Applications: E-commerce sites, personalized web pages, database access via web pages, etc.
