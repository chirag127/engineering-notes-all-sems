### Read the user id and passwords entered in the Login form and authenticate with the values available in the cookies for the notes of the Unit 5 - Design server site applications using JDDC,ODBC and section tracking API in the subject of Web Technology Lab

1. The user enters the username and password in the login form and submits it.
2. The username and password entered are sent to the server for authentication.
3. The server checks if the username and password matches with the values stored in the database.
4. If the username and password matches, then the authentication is successful and a session is created for the user. A session cookie is sent to the browser which stores the session id.
5. The session cookie is sent with every subsequent request from the browser to identify the user and maintain the session.
6. The values in the cookies can be accessed on the server side using appropriate APIs to get the user id and authenticate the requests.
7. Cookies provide a way to store and retrieve data about a user across multiple requests. They help to maintain a session and identify users.
8. Appropriate security measures should be taken while using cookies like setting expiry time, using SSL, etc. to prevent misuse.
