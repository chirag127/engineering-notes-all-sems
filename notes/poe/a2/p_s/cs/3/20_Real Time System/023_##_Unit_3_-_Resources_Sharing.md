## Unit 3 - Resources Sharing

- Resources sharing refers to the distribution of a computing resource (such as files, storage, applications, computing power, etc.) across multiple computers, networks or users.
- The key advantages of resource sharing are:
- Increased utilization: Resources are used more efficiently as they can be shared across multiple users. This leads to lower costs and less wastage.
- Increased access: Resources can be accessed by a larger number of users leading to better availability.
- Specialization: Resources can be shared according to users' needs leading to specialization. For example, high-performance computers can be used for complex computations while simple computers can be used for basic tasks.
- Scalability: It is easy to add or remove resources from a shared pool allowing the system to scale up or down as per requirements.
- The main types of resource sharing are:
- File sharing: Sharing of files, storage, printers, etc. across a network.
- Computing sharing: Sharing of computing resources like CPU and memory across a network to balance workload.
- Application sharing: Sharing of software applications so that multiple users can access the application simultaneously.
- Some key challenges in resource sharing are:
- Security: Resources need to be protected from unauthorized access. Strong authentication and access control mechanisms are required.
- Performance: Resource sharing can impact performance due to increased contention for resources. Effective resource scheduling algorithms are needed to optimize performance.
- Reliability: The failure of a shared resource can affect multiple users. Fault tolerance and high availability mechanisms need to be in place.
