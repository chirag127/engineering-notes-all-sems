### Definition for the notes of the Unit 1 - Introduction of Real Time System

1. Real Time System - A real time system is a computer system where the correctness of the system depends not only on the logical result of the computation, but also on the time at which the results are produced. They have well-defined, fixed, and rigid time constraints.

2. Hard Real Time System - In hard real time systems, missing a deadline results in system failure. Examples include aircraft control systems, nuclear plant monitoring systems, etc. Missed deadlines are not tolerated.

3. Soft Real Time System - In soft real time systems, although missing a deadline is undesirable, it is not catastrophic. The usefulness of the system degrades if deadlines are missed repeatedly. Examples include video conferencing systems, multimedia systems, etc. Occasional missed deadlines are tolerated.

4. Deadline - The time limit before which a task should be completed is known as the deadline. The deadline is one of the important characteristics used to classify a system as a hard or soft real time system.

Advantages - Ability to control devices and systems precisely. Critical task completion on time.
Disadvantages - Complex to design and implement. Resource constraints can lead to missed deadlines.
Applications - Aircraft control, Nuclear plant monitoring, Robotics control, Automotive systems, etc.
