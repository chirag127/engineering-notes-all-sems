## Unit 5 - Real Time Operating Systems and Databases

Real time operating systems are operating systems that are designed to serve the needs of real time applications. They are optimized for deterministic performance and predictability. Some key features of real time operating systems are:

- Strict timing constraints: Real time OS ensures that critical tasks are completed within strict deadline. It avoids unpredictable delays that can occur in general purpose operating systems.
- Priority based scheduling: Real time OS uses priority based scheduling algorithms to schedule tasks and meets deadlines. Higher priority tasks preempt lower priority tasks.
- Minimal latency: Real time OS minimizes latency between tasks and provides fast and predictable response times. General OS may introduce unpredictable delays due to cache misses, page faults, etc which are avoided in real time OS.
- Resource locking: Real time OS uses resource locking mechanisms to avoid resource conflicts that can lead to unpredictable delays.

Applications of real time operating systems include:

- Industrial control systems
- Robotics
- Medical systems
- Telecommunications systems
- Avionics systems

Databases designed for real time systems have features such as:

- Disk resident data: Real time databases keep most of their data in disk storage to maximize memory availability for time critical tasks.
- Locking: Real time databases use strict locking mechanisms and transaction scheduling to ensure predictable performance.
- Limited concurrency: Real time databases may use pessimistic concurrency control to avoid unpredictable delays due to transaction conflicts.
- Limited expressiveness: Real time databases typically use a restricted subset of SQL and avoid complex queries/transactions to ensure predictable performance.
