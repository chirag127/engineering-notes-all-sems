1. Client-Server Model
- In this model, clients send requests to the server and the server processes the requests and sends back responses to the clients.
- The server has dedicated resources to handle multiple client requests concurrently.
- Eg: Web servers, file servers, etc.

2. Peer-to-Peer Model
- In this model, there is no dedicated server and all entities (peers) have equal responsibilities and share their resources with each other.
- Peers can act as both clients and servers.
- Eg: File sharing applications, VOIP applications, etc.

3. Publish-Subscribe Model
- In this model, messages are classified into topics (channels) and subscribers can express interest in one or more topics and receive messages from those topics.
- Publishers publish messages to topics without knowledge of what subscribers, if any, may receive the messages.
- Eg: Social media updates, news feeds, etc.

Advantages:
- Decoupling of publishers and subscribers.
- Support for one-to-many and many-to-many communication.

Disadvantages:
- Difficulty in tracking the recipients of a message.
- Increased network traffic if multiple subscribers are receiving duplicate messages.

Applications:
- Tracking real-time events and updates.
- Real-time data streaming and broadcasting.
