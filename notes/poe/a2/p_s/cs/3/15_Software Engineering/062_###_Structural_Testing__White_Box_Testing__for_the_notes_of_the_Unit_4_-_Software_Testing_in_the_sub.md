### Structural Testing (White Box Testing)

- Structural Testing, also known as White Box Testing, evaluates the internal structure of the software to test the logic of the program.
- It is based on the program's internal logic and structure.
- The tester has knowledge of the internal logic and structure of the software.
- It uses coverage techniques to ensure that "all" independent paths are executed.
- Types of Structural Testing:
    - Statement Coverage - executing all statements
    - Branch Coverage - executing all branches
    - Path Coverage - executing all possible paths
    - Condition Coverage - evaluating all logical conditions
- Advantages:
    - Provides good test coverage
    - Can locate coding errors and logic flaws
    - Helps identify complex paths and exceptions
- Disadvantages:
    - Difficult to implement for large software
    - Requires detailed programming knowledge
    - May miss integration and interfaces issues
    - Testing every path can take significant time and effort
- Applications: Best used for unit testing and integration testing. Useful for critical software where thorough testing is required.

#### DHCP

- DHCP stands for Dynamic Host Configuration Protocol.
- It is a network protocol that enables a server to automatically assign an IP address and other network configuration parameters to a client on a network.
- The client (a computer or other network device) sends a broadcast request for network configuration information, and one or more DHCP servers respond with an offer of IP address and other configuration options.
- The client requests and accepts an IP address and configuration from one of the DHCP offers.
- This automation of network-interface configuration reduces the need for manual administration and prevents clients from having to manually configure their network devices.
- The DHCP process uses UDP messages on port 67 and 68 to carry out the IP address assignment process.
- Advantages:
    - Simplicity and ease of administration for network operators.
    - Auto-configuration for hosts.
    - Centralized management of IP addresses.
- Disadvantages:
    - Security issues if DHCP servers are compromised.
    - Reliance on DHCP servers for network connectivity.
- Common applications: Used in home networks, office networks, and large enterprise networks to automatically assign IP addresses and reduce manual configuration. Widely implemented in operating systems and network devices.
