### Regression Testing

- Regression Testing is a type of software testing to confirm that a recent program or code change has not adversely affected existing features.
- It is done to ensure that the software product is still working as intended after a change.
- The key goals of regression testing are:
    - To detect regression bugs.
    - To increase confidence in the correctness of software.
    - To determine whether a change has introduced any new defects.
- Types of Regression Testing:
    - Retest All - Running all tests again.
    - Selective Testing - Running a subset of tests.
    - Progressive Testing - Running tests in a specific order.
- When to perform Regression Testing?
    - After bug fixes or enhancements.
    - After software upgrade or modification.
    - Periodically throughout the lifecycle of a product.
- Advantages:
    - Helps identify defects early and reduces cost of bug fixes.
    - Increases reliability and stability of the software.
- Disadvantages:
    - Can be time-consuming and expensive for large software.
    - Difficult to determine which tests to rerun.
    - May provide a false sense of security if not performed properly.
- Examples: Automated Regression Testing tools like Selenium, TestComplete, etc.
