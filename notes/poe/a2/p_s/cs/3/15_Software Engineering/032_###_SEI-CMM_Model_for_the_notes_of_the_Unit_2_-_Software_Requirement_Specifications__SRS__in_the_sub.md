#### LAN standards in local area network

1. Ethernet: Ethernet is the most popular LAN technology. It uses CSMA/CD protocol to access the shared medium. Ethernet uses MAC addresses to identify devices. The popular Ethernet standards are:
- 10BASE-T: 10 Mbps over twisted-pair copper cable, maximum segment length 100 meters.
- 100BASE-TX: 100 Mbps over twisted-pair copper cable, maximum segment length 100 meters.
- 1000BASE-T: 1 Gbps over twisted-pair copper cable, maximum segment length 100 meters.
- 10GBASE-T: 10 Gbps over twisted-pair copper cable, maximum segment length 100 meters.

Advantages: Inexpensive, flexible, and easy to install.
Disadvantages: Shared medium, so throughput degrades as number of devices increase.
Applications: Ethernet is used in most LANs to interconnect computers and other devices.

2. Token Ring: In Token Ring, a special packet called token is passed around the network. Only the device possessing the token can transmit. It uses a ring topology and MAU (multistation access unit). The popular Token Ring standards are:
- 4 Mbps Token Ring
- 16 Mbps Token Ring

Advantages: Prevents collisions, provides greater determinism.
Disadvantages: Requires more expensive interfaces and MAUs, if the ring is broken the network goes down.
Applications: Token Ring was popular for IBM networks but not commonly used now due to competition from Ethernet.
