### Design Strategies for the notes of the Unit 3 - Software Design in the subject of Software Engineering

1. Decomposition: Breaking down a complex software problem into multiple modules/components that are interconnected. This makes the software easier to understand, develop and maintain.
- Hierarchical decomposition: Breaking down into parent-child relationships.
- Functional decomposition: Breaking down based on major functions.

2. Abstraction: Hiding the complex details and only showing the essential features. This reduces complexity and improves understandability.
- Data abstraction: Hiding the details of data structures.
- Control abstraction: Hiding the details of control flows.

3. Modularity: Dividing the software into separate, independent and interchangeable modules that have well-defined interfaces. This enhances reusability, flexibility, understandability and ease of development.
- Loose coupling: Reducing interdependencies between modules.
- High cohesion: Increasing the focus and relatedness of elements within a module.

4. Layering: Arranging system into hierarchical layers where each layer provides services to the layer above it and serves as a client to the layer below it. This localizes the impact of changes and provides abstraction.
- Examples: Application layer, system layer, hardware layer.
