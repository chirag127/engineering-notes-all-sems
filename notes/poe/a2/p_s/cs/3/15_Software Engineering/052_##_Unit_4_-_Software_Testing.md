## Unit 4 - Software Testing

Software Testing is a process of evaluating a software product to find whether the current software product meets the required conditions or not. It helps to identify and fix bugs or defects in the software.

-   Testing is done to provide quality software which is bug free, reliable and user friendly.
-   It is a very important process which ensures customer satisfaction and helps to improve the quality of the product.
-   There are mainly three types of software testing:
    -   Black Box Testing: It is a functional testing which is done without knowing the internal structure of the software. Testers verify the output based on the provided input. Eg: User Acceptance Testing.
    -   White Box Testing: It is a structural testing done by knowing the internal structure of the software. Testers verify the path of the program. Eg: Code Coverage, Path Testing.
    -   Grey Box Testing: It is a combination of Black Box and White Box Testing. The internal structure is partially known here.
-   The different phases of testing are:
    -   Unit Testing: Testing an individual module.
    -   Integration Testing: Testing the interface between modules.
    -   System Testing: Testing the entire system as a whole.
    -   Acceptance Testing: Testing by the customer to verify if the software meets requirements.
-   Advantages: Finds bugs early, increases reliability and quality, reduces cost of defect fixing.
-   Disadvantages: Time consuming, difficult to automate, needs highly skilled testers.

#### IP

IP stands for Internet Protocol. It is a set of rules for transferring data over a network. It handles the addressing and routing of data.

-   The current version is IPv4 which uses 32 bit addresses. The next generation is IPv6 which uses 128 bit addresses and provides a much larger address space.
-   IP works on the network layer of the OSI model and provides connectionless and best effort delivery of data packets.
-   An IP address is a unique address that devices use to identify and communicate with each other on a network. It consists of 32 bits for IPv4 and 128 bits for IPv6, divided into a network prefix and host identifier.
-   Routers operate at the network layer and use IP addresses to route data packets between networks based on routing tables which map IP addresses to network interfaces.
-   Examples: Email, web browsing, online streaming all use IP at the underlying network layer to transmit data over the internet.
