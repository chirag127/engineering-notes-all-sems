### SRS Document for the notes of the Unit 2 - Software Requirement Specifications (SRS) in the subject of Software Engineering

- SRS stands for Software Requirement Specification. It is a document that describes the requirements and functionalities of the software to be developed.
- It acts as a blueprint or contract between the client and the software development team. It helps the developers to understand the exact requirements and build the software accordingly.
- Some key points to be included in an SRS document are:

1. Introduction
- Purpose and scope of the software
- References to related documents
- Definitions and acronyms

2. Overall description
- Product features and capabilities
- User characteristics
- Constraints
- Assumptions and dependencies

3. System requirements
- Functional requirements - The capabilities and functions of the software along with inputs and outputs
- Non-functional requirements - Performance, security, quality, reliability, etc. requirements and constraints

4. Software System Attributes
- Availability
- Reliability
- Security
- Maintainability
- Portability
