### Transport layer protocols

The transport layer protocols provide end-to-end communication between processes running on different hosts. The key transport layer protocols are:

- TCP: Transmission Control Protocol is a connection-oriented, reliable protocol that provides in-order delivery of packets with error checking and correction. It is typically used for applications that require high reliability such as file transfer, email, and remote login.
- UDP: User Datagram Protocol is a connectionless and unreliable protocol that provides fast delivery of packets without error checking or correction. It is typically used for applications such as real-time video and audio that require fast delivery but can tolerate some loss or errors such as skipping frames.
- SCTP: Stream Control Transmission Protocol is a reliable, connection-oriented protocol that provides multiple streams and multi-homing capabilities. It is typically used for applications such as telecommunications that require more robustness and features than TCP.

The choice of transport layer protocol depends on the requirements of the application in terms of performance, reliability, and features. TCP is the most commonly used protocol but UDP and SCTP are suitable for certain types of applications. The transport layer protocols run on top of IP and provide services to the application layer protocols such as HTTP, FTP, SMTP, etc.

The key points to note about transport layer protocols are:

- They provide end-to-end communication between processes on different hosts.
- Key protocols are TCP, UDP, and SCTP which differ in connection-oriented vs connectionless and reliable vs unreliable.
- Choice of protocol depends on application requirements such as performance, reliability, and features.
- Transport layer protocols run on top of IP and below application layer protocols.
