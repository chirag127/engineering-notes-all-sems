### Object Oriented Design

- Object Oriented Design (OOD) is a design approach which focuses on modeling the problem space using objects and classes.
- The core principles of OOD are:
* Encapsulation - Hiding the internal details of objects and only exposing the interfaces to interact with them.
* Inheritance - The ability of a class to inherit the properties and behaviors of another class. Allows reuse of code and modeling of is-a relationships.
* Polymorphism - The ability of an object to take on different forms based on the context. Allows a single interface to have different underlying implementations.
* Abstraction - The process of identifying common patterns and behaviors to create a simplified model of a system.

Advantages of OOD:
* Models real world problems and scenarios effectively.
* Increases reusability of code through inheritance and interfaces.
* Provides a good separation of concerns through encapsulation and abstraction.
* Easy to maintain and extend existing systems.

Disadvantages of OOD:
* Can lead to over-abstraction and complex designs if taken to an extreme.
* The mapping between objects and real-world entities is not always straightforward.
* Inheritance hierarchies can become complicated and lead to fragile base class problems.

Applications of OOD:
* Building simulations and modeling systems.
* Graphical user interfaces which consist of objects and interactions.
* Server-side business logic and architectures.
* Gaming systems which consist of many interactive objects.
