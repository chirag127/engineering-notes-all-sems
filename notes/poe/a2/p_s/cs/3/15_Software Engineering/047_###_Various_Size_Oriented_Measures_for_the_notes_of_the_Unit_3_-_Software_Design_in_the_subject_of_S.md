### Various Size Oriented Measures for the notes of the Unit 3 - Software Design in the subject of Software Engineering

1. Lines of Code (LOC):
- Counts the number of lines of source code in a program.
- Usually counts the non-blank, non-comment lines of code.
- Used to get a rough estimate of the size of a software.
- Does not consider the complexity of the lines of code.
- Can be computed using tools like CLOC, SLOCCount, etc.

2. Function Points (FP):
- Counts the functional components of the software based on inputs, outputs, files, inquiries, and interfaces.
- Assigns complexity weights to each functional component and sums up to get the total function points which represents the size.
- Considers the functionality and complexity, but ignores the implementation details.
- Common methods are ISO-FP and COSMIC-FFP.

3. Object Points (OP):
- Similar to function points but counts the objects based on their types and complexity instead of functional components.
- Assumes object-oriented design and counts classes, interfaces, etc.
- Examples are NESMA, COSMIC-FFP, etc.
