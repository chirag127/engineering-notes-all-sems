### Test Data Suit Preparation

- Test data suit refers to the collection of test input data that is required to test a software system exhaustively.
- The test data suit should contain both valid and invalid input data to test the system's functionalities and to uncover errors.
- Preparation of a good test data suit is a tedious and time-consuming task. It requires good understanding of the system and its requirements.
- The steps involved in preparing a test data suit are:

1. Analyze the system requirements and identify the input domains for each input. For example, check for input ranges, possible values, formats, etc.
2. Prepare both valid and invalid input data for the system based on the identified input domains. Include boundary values and equivalence classes.
3. Prepare input data to test for common errors like division by zero, null pointer exceptions, etc.
4. Prepare input data to test complex scenarios and special cases in the system.
5. Review and refine the prepared test data suit to ensure maximum coverage and effectiveness.
6. Document the test data suit listing down the input data and expected outputs.

- The advantages of having a well-prepared test data suit are:
- Increased test coverage
- Higher chances of error detection
- Testing efficiency and effectiveness
- The disadvantages are:
- Time and effort required to prepare the test data suit
- Maintenance effort when requirements change

- Examples of test data preparation can be preparation of input values to test a basic calculator application.
- Test data suits find applications in both manual testing and automated testing to feed input and verify outputs.
