### Testing Objectives

1. Find defects/bugs: One of the primary goals of software testing is to find defects/bugs in the software. Early detection of bugs helps reduce cost of bug fixing.
2. Ensure software meets requirements: Testing helps ensure that the software meets the specified requirements and functionality. Requirements testing is done to validate if the software meets the documented requirements.
3. Improve software quality: Regular testing helps identify defects and areas of improvement, which in turn helps improve the quality of the software. Testing provides feedback to developers which helps in iterative refinement of the software.
4. Increase user satisfaction: Well tested, high quality software leads to happy and satisfied users as it meets the expectations and needs. On the other hand, low quality buggy software leads to user frustration.
5. Reduce risk: Testing reduces the risk of the software application not functioning as expected or having hidden bugs. It increases the likelihood of the software working as intended.
