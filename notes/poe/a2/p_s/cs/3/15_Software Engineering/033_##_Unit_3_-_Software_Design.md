## Unit 3 - Software Design

1. Software Architecture: The structural design of a software system. It includes the organization of components/modules and the patterns/styles of their interactions. Some types are:
- Client-server: Separates user interface and data storage.
- Peer-to-peer: Decentralized, all nodes have equal responsibilities.
- Layered: Hierarchical separation of concerns.
- Microkernel: Only essential services in kernel, rest in user space.
- Service-oriented: Applications built using communicating services.

2. Design Patterns: Reusable solutions to common software design problems. Some examples:
- Singleton: Ensures a class has only one object.
- Factory: Creates objects without specifying the exact class.
- Adapter: Converts one interface to another.
- Decorator: Attaches additional responsibilities to an object dynamically.
- Observer: Notifies observers of changes to a subject.
- Strategy: Interchangeable algorithms.
- Facade: Simplifies usage of a complex system.
