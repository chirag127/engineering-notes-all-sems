## Unit 1 - Introduction to Software Engineering

1. What is Software Engineering?
- Software Engineering is an engineering discipline which is concerned with all aspects of software production.
- It applies systematic, disciplined, quantifiable approach to development, operation, maintenance, and retirement of computer software.
- It involves studying, designing, developing and testing software or computer systems.

2. Software Crisis:
- The software crisis refers to the challenges faced during software development which results in software that is over budget, late, or does not meet expectations.
- Some reasons for software crisis are:
- Complex software requirements
- Inadequate project planning and management
- Shortage of skilled personnel
- Constantly changing requirements
- Inappropriate tools and techniques

3. Need for Software Engineering:
- The need for software engineering arose due to high demand for software, increased hardware capabilities and the complex nature of software.
- Some key reasons for need of software engineering are:
- Large software size
- Scalability and interoperability requirements
- Safety and security criticality
- Need for high quality, low cost and on time delivery
- Maintenance and evolution of software
