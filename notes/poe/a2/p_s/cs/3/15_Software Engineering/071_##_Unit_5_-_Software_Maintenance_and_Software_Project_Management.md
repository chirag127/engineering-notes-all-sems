## Unit 5 - Software Maintenance and Software Project Management

Software Maintenance:
- It refers to the process of modifying a software system after it has been delivered to correct defects, improve performance or other attributes, or adapt the system to a changed environment.
- Types: Corrective (fix bugs), Adaptive (port to new env), Perfective (improve attributes), Preventive (prepare for future changes).
- Challenges: Understanding existing code/docs, testing modifications, managing changes.
- Best practices: Good documentation, modular design, automate testing, skilled maintainers.

Software Project Management:
- The process of planning, organizing, coordinating, and controlling software projects.
- Project life cycle: Initiation, Planning, Execution, Monitoring & Control, Closure.
- Project planning: Estimate costs/timelines, assign resources, schedule tasks. Use Gantt charts, PERT charts.
- Risk management: Identify, assess, mitigate risks like delays, budget overruns, user requirements changes, etc.
- Configuration management: Control changes to software and related work products for correct version synchronization.
- Quality management: Processes to ensure high-quality software development and maintenance. Apply standards like ISO 9001.
- Key PM roles: Project manager, project sponsor, team members, stakeholders.
- Key success factors: Clear requirements, realistic planning, able team, senior management support, user involvement.
