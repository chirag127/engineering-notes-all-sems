Iterative Enhancement Model:
- It is a software development model that emphasizes incremental releases of the software.
- The software is developed through multiple iterations of the software development life cycle.
- Each iteration involves requirements analysis, design, implementation, testing, and deployment.
- The key features of the software are added in phases and the software is released in increments.
- The customer can provide feedback on each increment and changes/new requirements can be incorporated in the next increment.
- Advantages:
-- Customer involvement and satisfaction is high as incremental deliveries are made and feedback is taken.
-- Risks are mitigated as development is done in phases. A phase can be corrected if issues are found.
-- Flexible to changes as new requirements can be added in future increments.

Applications:
- When requirements are not well defined initially.
- For large and complex software projects.
- When budgets and timelines have to be met by releasing subsets of the software.

Examples: Spiral model, Evolutionary prototype model, Incremental build model.

Design elements:
- Each increment focuses on subsets of requirements and a subset of the system functionality.
- Good modular design and well-defined interfaces between modules are required to implement increments independently and integrate them.
- The increments need to be planned such that each is a usable subset of the functionality and provides business value.
