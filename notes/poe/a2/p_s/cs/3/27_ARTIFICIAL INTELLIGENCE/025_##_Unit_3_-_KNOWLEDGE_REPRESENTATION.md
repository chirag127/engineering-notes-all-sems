## Unit 3 - KNOWLEDGE REPRESENTATION

Knowledge representation refers to the ways used to represent knowledge in a computer so that it can be used to solve complex problems. Some of the key ways of knowledge representation are:

1. Rules: If-then rules are used to represent knowledge. The ‘if’ part specifies the conditions and the ‘then’ part specifies the conclusions. For example, 'If temperature is high and humidity is high, then advise drink plenty of water'
2. Frames: Frames are data structures used to represent concepts and relationships between them. A frame consists of slots which contain data values. For example, a 'student' frame may contain slots like 'name', 'age', 'course', 'college' etc. Each slot contains a value.
3. Semantic Networks: Knowledge is represented as nodes connected by labeled links. The nodes represent concepts and the links represent relationships between the concepts. For example, a node for 'Mona Lisa' may be connected to nodes for 'painting', 'Da Vinci' etc.
4. Concept Maps: Concepts are represented as boxes or circles connected by labeled links. The links represent relationships like hierarchies, associations, sequences between concepts. For example, a concept map may show 'Art' is a broader concept linked to more specific concepts like 'Painting', 'Sculpture' etc.

The choice of knowledge representation depends on the particular task and the kind of knowledge to be represented. Each method has its advantages and disadvantages. Representing knowledge in the ways computers can understand and process is a key step towards building expert and intelligent systems.
