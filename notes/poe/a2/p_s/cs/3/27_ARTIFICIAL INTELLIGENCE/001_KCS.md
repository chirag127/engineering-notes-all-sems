# KCS - Knowledge Centered Service

KCS stands for Knowledge Centered Service. It is an approach to provide technical support by leveraging knowledge. The key points about KCS are:

1. Knowledge is captured and stored in a central knowledge base. The knowledge base can be searched by support agents to find solutions to user queries.
2. Support agents do not resolve user queries themselves. They search the knowledge base and provide solutions from the existing articles to the users.
3. If no solution is found in the knowledge base, the support agent raises a ticket to capture the new query and solution. The ticket is then used to update the knowledge base with the new information.
4. The knowledge base is continuously improved over time as new user queries and solutions get captured. This enhances the capability of the support system to resolve more and more user queries through the knowledge base.
5. The key benefits of KCS are reduced support costs, increased speed of resolution, and enhanced consistency and accuracy of solutions. The users also get a self-service channel to find solutions to their queries through the searchable knowledge base.

The key components of a KCS system are:

1. Knowledge Base: Stores solutions to user queries in the form of articles
2. Search Engine: To search the knowledge base for relevant articles
3. Ticket System: To capture new queries and solutions to update the knowledge base
4. Agents: To verify and provide solutions from the knowledge base
5. Editors: To review and publish changes to the knowledge base

The following is an example of a KCS process:

1. User submits a query to the support system
2. Support agent searches the knowledge base for a solution
3. If a solution is found, the agent provides the solution article to the user
4. If no solution is found, the agent raises a ticket to capture the query and works with the user to find a solution
5. The ticket is then used to update the knowledge base with the new query and solution
6. The updated knowledge base can then be used to resolve similar user queries

Advantages: Reduced costs, faster resolutions, consistent accuracy
Disadvantages: Initial setup effort, knowledge base maintenance
Applications: Technical support systems, self-service knowledge bases
