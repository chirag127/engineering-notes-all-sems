### Reasoning with Default Information

- Default reasoning is a technique used to draw conclusions when there is incomplete information. It involves making assumptions about missing information using default values.
- For example, if we know that 'birds typically can fly' and we know that 'Tweety is a bird', then we can deduce that 'Tweety can fly' even though we don't have explicit information about Tweety's ability to fly. This is an example of default reasoning.
- Default reasoning is important for knowledge representation and reasoning with incomplete knowledge bases. It allows systems to draw plausible conclusions and make inferences even when all relevant information is not explicitly represented.
- However, default reasoning can lead to incorrect conclusions if the defaults do not reflect the actual state of the world. For example, if Tweety was a penguin, the default that 'birds can fly' would lead to the wrong conclusion. Handling exceptions and having more precise knowledge is important to reduce such errors.
- Some ways to represent default knowledge are:
-- Default rules: If P then normally Q. This means that Q holds by default if P is true and no exceptions are mentioned.
-- Inheritance hierarchies: More general classes inherit properties of subclasses unless overridden. For example, birds inherit properties of animals.
-- Circumscription: Limiting the extremes of variable denotations. This involves minimizing the number of exceptions to general rules.
- Advantages: Allows reasoning with incomplete knowledge. Makes common sense inferences possible.
- Disadvantages: Can lead to incorrect conclusions if defaults are wrong or overgeneralized. Needs mechanisms to handle exceptions.
