## Agent Communication

- Agents need to communicate with each other to coordinate and collaborate.
- The communication between agents can be either:
    - Indirect: Via the environment. Agents sense the environment and modify it, and other agents sense the changes. Eg: Ant colony optimization.
    - Direct: Using messages. Agents send and receive explicit messages to other agents. Eg: Contract net protocol.
- Direct communication has some advantages over indirect communication:
    - It is more efficient as changes do not need to be sensed and inferred. Messages can be more complex and convey more information.
    - It allows for more complex coordination and collaboration strategies.
    - However, it requires mechanisms for addressing, routing and understanding messages.
- Examples of direct agent communication:
    - Contract net protocol: Agents bid on tasks and a manager awards contracts.
    - Speech act based communication: Agents communicate using linguistic utterances that perform actions like requests, queries, assertions etc.
    - FIPA agent communication language: A standard for agent communication specifying contents and semantics of messages.
