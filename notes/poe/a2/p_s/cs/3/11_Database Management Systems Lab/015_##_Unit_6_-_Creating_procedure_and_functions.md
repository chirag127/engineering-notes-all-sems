## Unit 5 - Application Layer in Computer Networks

- The application layer is the topmost layer of the OSI model. It provides interfaces to the users through the application software.
- Some key functions of the application layer are:
    - Interface between the application software and the network.
    - Different applications use different protocols on this layer. For example, HTTP is used for web browsing, SMTP is used for email, FTP is used for file transfer, etc.
    - Provides user interface and accessibility to various network services.
    - Provides different applications with the ability to access transport layer services.
- Protocols in the application layer:
    - HTTP: Used for accessing web pages over the Internet. Uses client-server model.
    - SMTP: Used for sending and receiving emails. Also uses client-server model.
    - FTP: Used for file transfer over the network. Also uses client-server model.
    - DNS: Used for resolving domain names to IP addresses and vice-versa. Uses client-server model.
    - SNMP: Used for network management to monitor network-attached devices. Also uses client-server model.
- Advantages:
    - Supports various user applications and network services.
    - Hides the complexity of underlying layers from the users.
    - Provides interfaces to access network services.
- Disadvantages:
    - Vulnerable to application-specific attacks like SQL injections, cross-site scripting, etc.
    - Prone to vulnerabilities in application software.
    - Heavy traffic at this layer can degrade performance of the entire network.
