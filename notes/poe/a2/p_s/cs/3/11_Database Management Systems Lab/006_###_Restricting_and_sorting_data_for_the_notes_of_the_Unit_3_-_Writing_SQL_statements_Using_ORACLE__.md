### Restricting and sorting data for the notes of the Unit 3 - Writing SQL statements Using ORACLE /MYSQL in the subject of Database Management Systems Lab

1. Restricting Data:
- The WHERE clause is used to extract only those records that fulfill a specified condition.
- The WHERE clause follows the FROM clause in a SELECT statement.
- The WHERE clause takes a condition that evaluates to either true or false.
- Rows for which the condition evaluates to true are included in the result, and rows for which the condition evaluates to false are excluded.
- Conditions can use comparison operators like =, <>, >, <, >=, <= etc. to compare values.
- Logical operators like AND, OR and NOT can be used to combine multiple conditions.

2. Sorting Data:
- The ORDER BY clause is used to sort the result-set by one or more columns in ascending or descending order.
- The ORDER BY clause appears after the WHERE clause in a SELECT statement.
- By default, the ORDER BY clause sorts the data in ascending order. To sort in descending order, use the DESC keyword.
- The ORDER BY clause can take one or more column names to sort by multiple columns. It will prioritize sorting based on the first column, then the next, and so on.
- The ORDER BY clause is often used in conjunction with the LIMIT clause to get the top n rows or bottom n rows.
