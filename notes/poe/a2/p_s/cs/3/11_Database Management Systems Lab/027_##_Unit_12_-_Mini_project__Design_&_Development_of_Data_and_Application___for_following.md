## Unit 12 - Mini project (Design & Development of Data and Application )

Data modeling is the process of creating a data model for the data to be stored in a database. It is a conceptual representation of data structures required by a database.

-   Identify the entities and relationships: The first step is to identify the key entities and relationships among those entities. For example, in a university database, the key entities could be students, courses, teachers, etc. and relationships could be a student enrolled in a course, a teacher teaches a course, etc.
-   Define entities and attributes: Next, define each entity and its attributes. For example, student entity could have attributes like student_id, name, age, etc. Similarly, define attributes for other entities.
-   Define relationships: Then, define the relationships between entities. For example, define that a student can enroll in multiple courses and a course can have multiple students. Similarly, define other relationships.
-   Choose appropriate data types: Choose appropriate data types for different attributes. For example, student_id can be an integer, name can be a string, age can be an integer, etc.
-   Normalization: Normalize the data model to minimize data redundancy and ensure data integrity. The most common forms of normalization applied are first normal form, second normal form, and third normal form.

Once the data model is ready, it can be used to design a database and develop data-driven applications. The data model makes it easier to understand data requirements and to communicate with stakeholders. It also serves as a blueprint for implementing a database.
