## Unit 1 - Installing oracle/ MYSQL

1. Download Oracle/MySQL Community Edition - Download the latest version of Oracle/MySQL Community Edition from their official website. Select the appropriate installer for your operating system.

2. Install Oracle/MySQL - Double click the downloaded installer file and follow the on-screen instructions to install Oracle/MySQL. The installation process may take a few minutes to complete.

3. Configure Oracle/MySQL - After installation, you will be required to configure Oracle/MySQL by setting a password for the root user and selecting the services you want to use. Make sure to enable options to allow remote connections if you want to access your database from other machines.

4. Test the installation - Open a command prompt and type `mysql -u root -p` to login to MySQL with the root user and enter the password you set during configuration. If you are able to login successfully, your installation was successful. You can now create databases and tables, insert data, run queries, etc.
