## Unit 9 - Design and implementation of Library Information System

- A Library Information System (LIS) is a software application designed to manage and maintain a library's catalog of books, journals, magazines, audio/video recordings, etc along with the associated information like title, author, subject, ISBN, accession number, summary, etc.
- It helps to automate various library functions like acquiring, cataloging, indexing and abstracting, searching, and retrieval of information resources.
- The main components of an LIS are cataloging module, acquisition module, circulation module, and OPAC (Online Public Access Catalog).
- The cataloging module is used to catalog and index the library resources. The acquisition module helps in the acquisition of new resources. The circulation module maintains the circulation records. And OPAC allows users to search and access the library resources online.
- LIS offers many benefits like efficient management of resources, fast and easy access to resources, and reduction in manual work hence saving time and effort. However, it requires technical expertise to develop and maintain the system. It also needs to be constantly updated as per the changing needs.
- Some examples of open-source LIS are Koha, Evergreen, and LibSYS. Commercial LIS include products from companies like OCLC, Ex Libris, SirsiDynix, etc.

### World Wide Web

- The World Wide Web (WWW) refers to the collection of interlinked hypertext documents accessible via the Internet.
- It is a massive distributed client-server information system which uses the HTTP protocol, HTML documents, and URLs to retrieve and transport web resources.
- The key components of the web are web servers that store and share web resources, web browsers that access and render web resources, and the Internet which acts as the communication medium.
