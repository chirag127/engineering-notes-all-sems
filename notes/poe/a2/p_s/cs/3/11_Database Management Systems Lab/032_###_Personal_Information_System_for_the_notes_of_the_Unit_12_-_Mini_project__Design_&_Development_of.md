### Remote login in application layer

- Remote login allows a user to login to a remote system and access its resources from a local system. It enables access to a computer system from a remote location.
- The application layer protocols used for remote login are:
- SSH (Secure Shell): It is a secure network protocol that enables data communication and remote command-line login to the server. It provides encryption of data and authentication of the remote system.
- Telnet: It is a plain text network protocol used for remote login. It does not provide encryption of data and authentication, hence it is insecure.
- Advantages:
- Access resources from anywhere.
- Administer and manage remote systems.
- Disadvantages:
- Security issues in case of Telnet due to lack of encryption and authentication.
- Requirement of high bandwidth due to graphical data transmission in some applications.
- Examples: Logging in to a remote Linux server, accessing a desktop of a remote Windows machine, etc.
- Application: Remote system administration, remote file access, remote software deployment, etc.
