### Pseudo Codes in Software Design

- Pseudo codes are informal high-level descriptions of the steps required to solve a problem or achieve some goal.
- They are used to outline the structure of a program without going into details of a particular programming language.
- Pseudo codes help programmers develop algorithms before implementing them in a particular programming language.
- Some characteristics of pseudo codes are:
    - They use simple and easy to understand English statements.
    - They avoid complex programming language syntax.
    - They focus on the logic of the algorithm rather than the syntax.
    - They use indentation to show nesting of steps or blocks of code.
    - They use comments to describe the purpose of sections of code.
- Examples of pseudo code:
    - IF age > 65 THEN
        PRINT "Senior Citizen"
    END IF

    - REPEAT
        GET input
        DO processing
    UNTIL condition is met

    - FOR count = 1 TO 10
        PRINT count
    NEXT count

- Advantages:
    - Help understand the logic of an algorithm without getting bogged down in programming language details.
    - Aid in designing and developing programs in a systematic manner.
    - Can be understood by humans as well as translated into an actual programming language.

- Disadvantages:
    - May be ambiguous or inconsistent if not written carefully.
    - Still requires translation into an actual programming language which can introduce errors.
    - May not model all aspects of a programming language and can gloss over details.
