### Need for data compression for the notes of the Unit 5 - IMAGE COMPRESSION AND RECOGNITION

1. Images contain a huge amount of data - An image is made up of thousands or millions of pixels and each pixel contains information about its intensity or color. This amounts to a large amount of data required to store the image which can be inconvenient at times.
2. Reduces storage space - Due to the massive amount of data in images, a large amount of storage space is required to store them. Data compression helps reduce the storage space required by compressing the data and removing redundancies. This allows us to store more images in the same amount of storage space.
3. Faster transmission - The compressed image data takes lesser time to transmit over a network as compared to the original uncompressed image. This is helpful in applications like video calling or streaming where images need to be transmitted over the network.
4. Improves application efficiency - Many image processing applications work on compressed images as it reduces the processing time and provides a faster outcome. For example, face recognition systems can work on compressed face images to identify faces faster.

The key techniques for image compression include:
* Lossless compression - Runs-length encoding, Huffman coding, Lempel-Ziv-Welch (LZW) algorithm
* Lossy compression - JPEG, JPEG 2000, MP3

The choice of technique depends on the application - whether loss of data can be tolerated or not. Lossless methods are preferred if the original image data needs to be retained while lossy methods provide a higher compression ratio at the cost of some lost data.
