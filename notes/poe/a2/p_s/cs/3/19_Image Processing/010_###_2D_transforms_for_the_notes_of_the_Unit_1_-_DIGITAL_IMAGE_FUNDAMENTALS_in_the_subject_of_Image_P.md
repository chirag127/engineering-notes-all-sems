1. Introduction to 2D Transforms
- 2D transforms are used to analyze spatial frequency content of an image.
- They convert spatial domain into frequency domain which provides information about frequency content of an image.
- Common 2D transforms are Discrete Fourier Transform (DFT), Discrete Cosine Transform (DCT) and Discrete Wavelet Transform (DWT).

2. Discrete Fourier Transform (DFT)
- DFT is a Fourier-related transform that converts spatial domain into frequency domain.
- It gives magnitude and phase of each frequency component in an image.
- It provides global frequency information of an entire image.
- Applications: Image filtering, Image compression, Feature extraction, etc.

3. Discrete Cosine Transform (DCT)
- DCT is a lossy compression technique that converts spatial domain into frequency domain.
- It uses cosine functions for the conversion.
- It concentrates most of the signal into lower frequency components thereby achieving high compression.
- It is similar to DFT but uses only real values.
- Application: JPEG image compression standard uses DCT.

4. Discrete Wavelet Transform (DWT)
- DWT is a transform that converts spatial domain into frequency domain using wavelets.
- It uses filter banks to divide input into frequency subbands.
- It provides multiresolution frequency information.
- It is useful for non-stationary signals like images as it captures both high and low frequencies.
- Applications: Image compression, Denoising, Feature extraction, etc.
