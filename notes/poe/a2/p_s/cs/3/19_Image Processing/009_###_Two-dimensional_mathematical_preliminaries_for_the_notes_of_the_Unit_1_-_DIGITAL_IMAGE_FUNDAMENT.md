### Two-dimensional mathematical preliminaries for the notes of the Unit 1 - DIGITAL IMAGE FUNDAMENTALS in the subject of Image Processing

1. Cartesian coordinate system:
- A 2D coordinate system with two perpendicular axes (x and y)
- Each point on the plane is uniquely determined by its x and y coordinates
- Used to represent spatial locations in a 2D space
- Common in image processing to specify pixel locations

2. Pixels:
- Short for "picture elements"
- Smallest individual units of an image
- Arranged in a 2D grid
- Values represent light intensity or color information
- Specified by (x, y) Cartesian coordinates

3. Sampling:
- Conversion of a continuous signal (such as an image) to discrete values for digital processing
- Process of determining pixel values from a continuous image
- Must satisfy the Nyquist sampling theorem to recover the original signal
- Pixel values are estimates of the original continuous image values

4. Neighbors:
- Pixels surrounding a given pixel
- Used in processing to compute new pixel values based on nearby pixels
- Common neighborhoods: 4-neighbors (above, below, left, right), 8-neighbors (4-neighbors plus diagonals)
- Neighborhood size and shape depend on the particular application and desired results
