### Image Restoration
Image restoration is the process of estimating/recovering the original image from its degraded/blurry version. The degradation can be due to several factors like noise, blur, etc. The objective of image restoration is to undo the degradation and recover the original image as accurately as possible.

Some of the steps involved in image restoration are:

1. Image Acquisition - Capturing the degraded image
2. Image Modelling - Mathematically modelling the degradation process. This helps in understanding the type of degradation and estimating the parameters of degradation.
3. Image Prior - Using some prior knowledge about the original image to regularize the solution. This can be in the form of smoothness, edges, etc.
4. Inverse Problem - Solving the inverse problem to estimate the original image from the degraded image using the image model and image prior.

Based on the image degradation model, the different types of image restoration techniques are:

- Noise Removal - When the degradation is due to noise, techniques like averaging, median filter, wiener filter, etc. are used.
- Deblurring - When the degradation is due to blur, deblurring techniques like blind deconvolution, Wiener filter, etc. are used.
- Super Resolution - When the degradation is due to low resolution, super resolution techniques are used to enhance the resolution.

The performance of image restoration techniques depends on accurately modelling the degradation and choosing a suitable image prior. The results can be improved by incorporating constraints and using iterative optimization techniques.

Image restoration finds applications in photography, medical imaging, satellite imaging, etc. However, it has certain limitations like error in estimating the degradation model and amplifying the noise in the process of recovery.
