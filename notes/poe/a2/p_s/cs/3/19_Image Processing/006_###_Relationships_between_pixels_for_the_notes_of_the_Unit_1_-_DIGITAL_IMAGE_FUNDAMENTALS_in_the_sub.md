### Relationships between pixels

- Pixels in a digital image have a neighboring relationship with other pixels. The value of a pixel is affected by the values of its neighboring pixels.
- This spatial relationship between pixels is exploited in many image processing techniques like:
 - Smoothing/Blurring - The value of a pixel is replaced by a function of its neighbors to reduce noise.
 - Sharpening - The value of a pixel is replaced by a function of the difference between its value and its neighbors to increase edge contrast.
 - Gradient Estimation - The difference between neighboring pixels is used to estimate the strength and direction of intensity changes. This is used in edge detection.
- The nature of the relationship between pixels depends on the size and shape of the pixel neighborhood being considered. Common shapes are 4-connected (horizontally and vertically adjacent), 8-connected (diagonally adjacent also) and circular neighborhoods.

### SRS Document

- SRS stands for Software Requirements Specification. It is a document that describes the requirements for a software system.
- It includes both functional and non-functional requirements. Functional requirements describe the functions and capabilities of the system while non-functional requirements describe system properties such as performance, security, etc.
- The key sections of an SRS document are:
 - Introduction - Purpose, scope, definitions, acronyms, abbreviations, references
 - Overall description - Product perspective, user classes and characteristics, operating environment, design and implementation constraints
 - System features - Functional requirements organized by user class or feature
 - External interface requirements - User interfaces, hardware interfaces, software interfaces, communication interfaces
 - Performance requirements - Speed, throughput, response time, resource usage
 - Logical database requirements
 - Design constraints - Standards compliance, hardware limitations, software system attributes
 - System attributes - Reliability, availability, security, maintainability, portability
