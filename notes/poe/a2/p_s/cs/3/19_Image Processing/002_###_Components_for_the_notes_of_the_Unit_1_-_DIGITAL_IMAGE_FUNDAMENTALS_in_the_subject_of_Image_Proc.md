### 1. Pixels
- A digital image is composed of small rectangular blocks of color called pixels
- Pixels have a specific row and column address in the image
- The color of each pixel is defined by a numeric value representing its intensity
- The more pixels an image has, the higher its resolution and quality
- The number of pixels determines the image size and file size

### 2. Bit Depth
- Bit depth refers to the number of bits used to represent the color of a pixel
- Higher bit depth means more possible intensity values, resulting in better image quality
- Common bit depths are 8-bit (256 values), 16-bit (65,536 values), and 24-bit (16.8 million values)
- Higher bit depths are better for minimizing color distortion and loss of details, but result in larger file sizes

### 3. Color Models
- A color model is a mathematical model used to represent colors and their relationships
- The RGB model represents color using combinations of red, green, and blue light
- The CMYK model represents color using cyan, magenta, yellow, and black ink/pigment
- The HSV model represents color using hue, saturation, and value, which can be more intuitive for image processing tasks
- Choose a color model based on application and data compatibility
