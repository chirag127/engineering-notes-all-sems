### Basic Concept of Software Design

1. Problem Understanding - The first step is to understand the problem thoroughly. It involves analyzing the problem, identifying the input and output requirements and determining the goals and constraints.
2. Specification - The software requirements are documented in a specification which serves as a base for the design. It should be clear, complete and consistent.
3. Feasibility Study - A feasibility study is conducted to determine if the system can be developed with the available resources and to identify the possible risks involved with the development process.
4. Choice of Architecture - The software architecture is chosen based on the requirements specified. It provides an overview of the software structure in terms of components and connections between them.
5. Design - The component design is developed in detail. The data structures and interface of the components are defined in this phase. The design should be efficient, reliable, reusable and scalable.
6. Testing and Integration - Individual components are tested and integrated to test the software as a whole. Necessary modifications are made.
7. Documentation - Software architecture and component design are properly documented for the purpose of implementation and future reference.

### Band reject Filters for the notes of the Unit 3 - IMAGE RESTORATION in the subject of Image Processing

1. A band reject filter is a filter that passes all frequencies except those in a specific frequency band which are attenuated or rejected.
2. It is used to remove noise or interference at a known frequency/band of frequencies.
3. The ideal band reject filter has infinite attenuation in the stop band and unit gain in the pass band. Practical filters have finite attenuation in the stop band and ripples in the pass band.
4. Examples of band reject filters are notch filters (for narrow band rejection) and band stop filters (for wide band rejection).
5. The filter can be designed using analog methods like the twin-T or digital methods like the IIR filter. The filter order and width can be adjusted based on the requirements.
6. Band reject filters find applications in noise removal, signal analysis, biomedical signal processing, etc.
