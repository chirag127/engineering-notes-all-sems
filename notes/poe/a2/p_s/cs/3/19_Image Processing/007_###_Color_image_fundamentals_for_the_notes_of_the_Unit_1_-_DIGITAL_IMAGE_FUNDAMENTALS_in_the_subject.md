### Color image fundamentals

1. **RGB color model**: Color images are represented using the RGB color model. In this model, each pixel has three components - Red, Green and Blue which determines the color of the pixel. The intensity of each component ranges from 0 to 255. 0 indicates the absence of that color and 255 indicates the maximum intensity of that color. By varying the intensities of the 3 components, a wide variety of colors can be generated.

2. **CMYK color model**: The CMYK color model is used in printing. It uses Cyan, Magenta, Yellow and Black (Key) ink colors. Each pixel has 4 components which indicates the amount of each ink color. This model is suited for printing as it uses the subtractive color model, similar to how paints/inks work. However, the colors generated are not as vibrant as RGB.

3. **HSV (Hue, Saturation, Value) color model**: This model represents color in terms of Hue, Saturation and Value (also called Brightness). Hue indicates the color (like red, blue, etc.), Saturation indicates the intensity of the color (vibrant vs dull) and Value indicates how light or dark the color is. This model is more intuitive in terms of how humans perceive color. However, RGB model is more widely used in displays and processing.

The key advantages of color images are:
1. They can represent a wider range of real-world objects and scenes.
2. They contain more information than grayscale images which can be useful for computer vision and other applications.

The main disadvantages are:
1. Color images require more storage and processing power due to the additional components required per pixel.
2. There can be variability in how colors are perceived under different lighting conditions. This needs to be accounted for in some applications.
