### Generalization for the notes of the Unit 1 - Introduction in the subject of Database Management System

1. Database Management System (DBMS) - A software system that is used to manage database. It performs tasks such as creation, updating, and retrieval of data.

2. Database - A collection of related data that is organized and stored in a computer system. The data is structured in the form of tables, records, and files.

3. Data Redundancy - Storing the same data in multiple locations. This leads to data inconsistency and wastage of storage space. DBMS helps in minimizing data redundancy.

4. Data Inconsistency - Differences in multiple copies of the same data. This leads to incorrect or unreliable data. DBMS ensures data consistency by updating all copies of data simultaneously.

5. Data Independence - The ability to modify the database schema at one level without impacting the schema at another level. There are two types:

- Physical data independence - Upper level schema is unaffected by changes in lower level schema.
- Logical data independence - Schema can be changed without impacting the user application.

6. ACID Properties - Transactions in DBMS follow ACID properties to ensure reliability:

- Atomicity - Either all operations in a transaction complete successfully or none.
- Consistency - Transaction must bring the database from one consistent state to another.
- Isolation - Multiple transactions do not interfere with each other.
- Durability - Completed transactions are permanently stored in the system even after a failure.
