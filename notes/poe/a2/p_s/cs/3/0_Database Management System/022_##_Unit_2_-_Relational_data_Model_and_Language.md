## Unit 2 - Relational data Model and Language

1. Relational Model - The relational model is a database model based on first-order predicate logic. In the relational model, the data is represented in the form of relations or tables. A relation is made up of attributes or columns and tuples or rows.
    - Tables - A table is a two-dimensional structure that contains rows and columns. A table represents an entity with its attributes.
    - Columns - Columns represent attributes of an entity. Each column has a unique name and contains values of a particular data type.
    - Rows - Rows represent tuples or records and contain the actual data values of the attributes. Each row is uniquely identified by a primary key.
    - Relationships - Relationships between two tables are established through common columns. These common columns are known as foreign keys in one of the tables.
2. Relational Algebra - Relational algebra is a procedural query language consisting of a set of operations that take one or two relations as input and produce a new relation. The fundamental operators in relational algebra are:
    - Selection - ??SELECTS?? tuples that satisfy a given predicate.
    - Projection - Produces a relation with a subset of the attributes from the input relation.
    - Cartesian Product - Produces the cross product of two relations.
    - Union - Produces the set union of two relations with the same attributes.
    - Difference - Produces the set difference of two relations with the same attributes.
    - Join - Joins two relations based on the common attributes values.
3. Relational Calculus - Relational calculus is a non-procedural query language that describes what to retrieve rather than how to retrieve it. It provides an intuitive declarative way to formulate queries. The two variants of relational calculus are:
    - Tuple Relational Calculus - Specifies to select tuples that satisfy a given predicate. Uses variables to refer to attributes and tuples.
    - Domain Relational Calculus - Specifies to select attributes from tuples that satisfy a given predicate. Uses quantifiers variables to refer to attributes within the tuple.
