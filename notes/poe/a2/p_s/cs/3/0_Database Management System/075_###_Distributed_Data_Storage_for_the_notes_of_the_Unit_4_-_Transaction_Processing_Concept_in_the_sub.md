### Distributed Data Storage for the notes of the Unit 4 - Transaction Processing Concept in the subject of Database Management System

- Distributed database system is a database system in which storage devices are not physically connected and geographically separated. The system gives the appearance of a single database to the users. The distributed database system can be homogeneous or heterogeneous.
- The advantages of distributed database system are:
- Increased performance: The workload can be distributed to multiple servers based on the location of the data and transactions. This increases the performance of the system.
- Increased availability: The databases are distributed geographically, so the failure of one site does not affect the system. The other sites can continue operating even after one site failure. This increases the availability of the data.
- Scalability: The distributed database system can be extended easily by adding more database servers to the system. This allows the distributed database system to scale to large volumes of data and number of transactions.
- The disadvantages of distributed database system are:
- Increased complexity: The distributed database system is more complex to design, develop, and maintain compared to a centralized database system. The distributed system has to maintain consistency and concurrency control across various database sites.
- Reliability: The reliability of the system depends on the individual database servers and the network connections between them. This can affect the performance and availability of the system.
- Heterogeneity issues: When the system consists of heterogeneous database systems from multiple vendors, it introduces issues like different data models and query languages that need to be resolved.
- Some examples of distributed database systems are Oracle RAC, MySQL Cluster, etc. They are used in applications where large volumes of data and high performance are required like banking systems, airlines reservation systems, etc.
