### 1. What is a Database?
- A database is a collection of related data stored in a computer system.
- The data is organized and stored in a systematic manner for future retrieval, use, and processing.
- The DBMS is the software that interacts with users, applications, and the database itself to capture and analyze the data.

### 2. Difference between Database and File System
- A file system stores data in files while a database stores data in tables with rows and columns.
- A file system does not have the data structure and software to provide efficient data access, security, and concurrency while a DBMS does.
- A DBMS provides a systematic way to create, retrieve, update, and manage data.

### 3. Advantages of DBMS
- Reduced data redundancy and inconsistency.
- Insulation of programs and data.
- Improved data sharing.
- Better data security.
- Improved data integrity.
- Improved data accessibility.
- Improved data persistency.
- Improved data independence.
- Standardization.
