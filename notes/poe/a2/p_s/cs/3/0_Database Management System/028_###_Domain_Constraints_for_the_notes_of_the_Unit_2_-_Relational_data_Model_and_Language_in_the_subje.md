### Domain Constraints

- Domain constraints restrict the set of values that can be stored in a column of a relation.
- Each column of a relation is associated with a data type that defines a domain of values.
- The database system ensures that only values from the domain are stored in that column.
- Example: If a column is defined as integer, then only integer values can be stored in that column. Values like 'abc' or 4.5 are not allowed.
- Enforcing domain constraints ensures data integrity by preventing invalid data values from being stored in the database.
- Domain constraints are a fundamental part of the schema definition of a relation. The data type of a column determines the set of values that can be stored in that column.
- Appropriate choice of data types and domains is critical for the efficient use of storage space and the appropriate use of the values in application programs.
