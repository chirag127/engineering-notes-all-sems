### Overview for the notes of the Unit 1 - Introduction in the subject of Database Management System

1. **Introduction to Databases**:
- A database is a collection of related data which is organized so that it can be easily accessed, managed and updated.
- The common types of databases are:
-- Flat file databases: Data is stored in simple flat files. Eg: CSV files.
-- Hierarchical databases: Data is organized in a tree-like structure.
-- Network databases: Data is organized as records are connected to each other.
-- Relational databases: Data is organized into one or more tables with rows and columns.Eg: MySQL, Oracle, etc.
-- Object-oriented databases: Data is represented in the form of objects.
-- Semi-structured databases: Data does not have a fixed schema. Eg: XML databases.
-- NoSQL databases: Non-relational databases. Eg: MongoDB.

2. **Need for Databases**:
- There is a huge amount of data in the world which is increasing day by day. This data needs to be properly organized and managed which is done using databases.
- Some reasons to use databases are:
-- Data sharing: Databases allow data to be shared among multiple users and applications.
-- Data consistency: Databases follow ACID properties to maintain data consistency.
-- Security: Databases provide security mechanisms to prevent unauthorized access to data.
-- Data redundancy: Databases minimize data redundancy to save storage space.
-- Data integration: Databases can integrate data from multiple sources into a single database.

3. **DBMS**: A Database Management System (DBMS) is a software application that interacts with end users, applications, and the database itself to capture and analyze data. It helps to efficiently define, store, and retrieve data from the database. Some functions of a DBMS are: data definition, data manipulation, security management, concurrency control, backup and recovery, etc.
