# Tables

- A table is a collection of related data entries and it consists of columns and rows.
- Columns are the attributes of the data and rows are the records of the data.
- A table has a specified number of columns, but can have any number of rows.
- Each column has a unique name and a specific datatype associated with it.
- Each row contains a unique value for each of the columns.
- The columns in a table are grouped based on the common characteristics or theme of the data.
- The intersection of a row and column in a table is known as a field.
- The main components of a table are:
    - Column - The vertical entity in a table that indicates a specific attribute of a data.
    - Row - The horizontal entity in a table that contains the records of data.
    - Cell - The intersection of a row and column that contains the actual data value.
    - Schema - Defines the organization of the table and the datatypes and constraints of the columns.
    - Tuple - A single row of a table that contains a record of information.
    - Relation - An entire table that contains tuples/rows and columns/attributes.

- Tables provide an organized structure to store and access data efficiently.
- They help in maintaining the data integrity and reducing data redundancy.
- The relational model is based on the concept of tables with rows and columns.
- Tables facilitate easy retrieval of information and perform operations on the data.
