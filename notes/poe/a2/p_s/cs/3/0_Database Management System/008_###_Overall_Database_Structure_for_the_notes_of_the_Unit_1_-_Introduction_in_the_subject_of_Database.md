### Overall Database Structure for the notes of the Unit 1 - Introduction in the subject of Database Management System

1. Data: Data refers to the actual facts or information that is to be stored in the database. The data can be in any format like text, images, audio, video, etc.
2. Field: The smallest individual piece of data is known as a field. For example, in a table containing student data, the fields would be student ID, student name, age, course enrolled, etc.
3. Record: A collection of related fields forms a record. For example, the student ID, student name, age, and course enrolled of a particular student together form a record of that student.
4. File: A file is a collection of records of a particular type. For example, all the records of students can be stored in a student file.
5. Table: A table is a two-dimensional structure that organizes data into rows and columns. The columns represent the fields and the rows represent the records. For example, a student table would have student ID, student name, age, and course enrolled as columns and the data of individual students as rows.
6. Database: A database is an organized collection of data stored in a computer system. It is a repository or container for collections of logically related records or files. The database organizes the data in the form of tables to make it easier to store, manage, and retrieve data.
7. DBMS: Database Management System (DBMS) is a software application that interacts with the user, applications, and the database itself to capture and analyze data. The main purposes of a DBMS are to store and retrieve data, provide data security, provide data integrity, and share data.
