### Characteristics of SQL

1. SQL is a declarative language - In SQL, the user specifies what data is required and not how to get it. The database system determines the best method to retrieve the data.
2. SQL is a non-procedural language - The users do not specify the sequence of steps to access or manipulate the data. The database engine figures out the optimal way to execute queries and access data.
3. SQL supports Relational Model - SQL is based on the relational model of data. It supports data definition language and data manipulation language constructs to create and access relational data.
4. ANSI Standards - SQL has ANSI standards which make it portable so that SQL queries will function in a similar way on different systems. However, different database vendors have their own extensions and versions of SQL which are not always compatible.
5. Scalability - SQL is designed to efficiently retrieve and manipulate large volumes of data. It utilizes indexes and other techniques to optimize performance even for huge data sets.
6. Application Independence - In SQL, applications do not need to specify how the data is stored or accessed. The internal details are handled by the database system, providing location and storage independence.

Advantages -
1. Simple and easy to learn
2. Structured query language using operators and expressions
3. Does not require programming knowledge
4. Provides security and integrity through constraints and authorization
5. Can handle large volumes of data efficiently
6. Widely used and compatible with many database systems

Disadvantages -
1. Lack of procedural capabilities
2. Vendor specific extensions create incompatibility
3. Complex queries can be difficult to tune and optimize
4. JOINS on large tables can be resource intensive
