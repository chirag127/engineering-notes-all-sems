### Candidate Key

- A candidate key is a column or set of columns that can uniquely identify each row in a table.
- A candidate key must contain a unique value for each row and cannot contain NULL values.
- A table can have multiple candidate keys.
- One of the candidate keys is chosen to be the primary key of the table. The primary key is chosen based on which candidate key is most suitable for identifying rows and maintaining referential integrity with other tables.
