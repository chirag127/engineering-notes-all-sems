### Data Independence
- Data independence refers to the immunity of user applications to changes made in the database schema.
- There are two levels of data independence:
	1. Physical data independence: The application programs should be unaffected by changes in the physical structure of the data. e.g. the physical location of the data.
	2. Logical data independence: The application programs should be unaffected by changes in the logical structure of the data. e.g. relationships between entities.
- Data independence is achieved through the use of a data definition language to define the database schema and a data manipulation language to interact with the database.

### Database Languages and Interfaces
- Database languages are used to define, query and manipulate the database.
- The two main types are:
	1. Data Definition Language (DDL): Used to define the database schema. e.g. CREATE, ALTER, DROP.
	2. Data Manipulation Language (DML): Used to manipulate the data within the database. e.g. INSERT, UPDATE, DELETE, SELECT.
- Database interfaces provide an interface to the database and convert the database language into appropriate system calls.
- Examples of database languages are:
	- SQL: Widely used standard database language.
	- QBE (Query By Example): Uses a graphical user interface.
- The advantages of database languages are:
	- They are standardized ways of accessing data.
	- They provide data independence.
	- They can be embedded within general purpose programming languages.
