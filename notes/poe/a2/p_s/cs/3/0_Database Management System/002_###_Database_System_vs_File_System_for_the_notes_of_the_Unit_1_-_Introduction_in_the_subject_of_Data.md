### Database System vs File System

- A database system is a software system that is designed to store and manage data while a file system is a system that is designed to store and manage files on a storage device.
- A database system organizes data into tables with rows and columns while a file system organizes data into files and folders.
- A database system provides a structured query language (SQL) to retrieve and manipulate data while a file system provides basic operations to create, read, update and delete files.
- A database system ensures data integrity and security while a file system has limited data integrity and security features.
- A database system provides concurrency control to handle multiple users accessing the data simultaneously while a file system has limited concurrency control, often leading to issues like race conditions.
- A database system is suitable for storing and managing related data while a file system is suitable for storing and managing files and documents.
- Examples of database systems: MySQL, Oracle Database, Microsoft SQL Server. Examples of file systems: NTFS, Ext4, FAT32.

Advantages of database systems:
- Structured data organization.
- Powerful data manipulation capabilities.
- Data integrity and security features.
- Concurrency control mechanisms.

Disadvantages of database systems:
- Can be complex to set up and maintain.
- Require skilled personnel to handle the database.

Advantages of file systems:
- Simple to set up and use.
- Widely supported across platforms and operating systems.

Disadvantages of file systems:
- Limited data organization capabilities.
- Limited data integrity and security features.
- Limited concurrency control, can lead to issues when multiple users access files simultaneously.
