## Unit 3 - Data Base Design & Normalization

1. Database Design
- Database design is the process of producing a detailed data model of a database. 
- It is like creating a blueprint of a database which will be used to develop the actual database.
- The design activity takes into consideration both the data requirements of the organization served by the database and the transaction processing needs. 
- The main steps involved in database design are: determining data requirements, conceptual design, logical design, and physical design.

2. Conceptual Design
- The conceptual design is focused on defining the high-level data structures that will be required by the database. 
- The entities and relationships between different entities are defined during this stage. 
- The entity-relationship model is commonly used to represent the conceptual design.

3. Logical Design
- The logical design describes the database in detail, including the tables, fields, relationships, views, indexes, etc.
- The entity-relationship diagram is translated into tables with columns during logical design.
- It also defines data types for fields, primary keys, foreign key relationships, data validation, etc.
- The database users and applications will interact with the logical design to access the data.

4. Physical Design
- The physical design describes the actual database objects and structures that will be used by the DBMS to store and manage the data. 
- It includes translating the logical design into physical database structures such as tables, indexes, etc. 
- It also defines physical characteristics such as data types, storage, and access methods.
