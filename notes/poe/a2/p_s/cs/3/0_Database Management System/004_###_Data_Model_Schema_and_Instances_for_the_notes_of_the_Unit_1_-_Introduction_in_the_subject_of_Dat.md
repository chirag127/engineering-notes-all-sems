### Data Model Schema and Instances for the notes of the Unit 1 - Introduction in the subject of Database Management System

1. Data Model - A data model is a conceptual representation of data structures required for a database and is defined through a data definition language. It is a tool used to describe the data and its relationships, constraints, rules, etc. The following are the major types of data models:

- Hierarchical data model - Data is organized in a tree-like structure with parent-child relationships. Each record has only one parent and defines a hierarchical relationship. Eg: Organization chart.
- Network data model - Data is organized as records and sets with the help of pointers and links. It allows more than one relationship path between any two data records.
- Relational data model - Data is organized in the form of tables with rows and columns. Each row is a record and columns are the attributes. There exists a relationship between tables. Most widely used data model for databases.
- Object-oriented data model - Data is represented as objects with attributes and methods. It can handle complex data relationships.

2. Schema - The overall design of a database is defined by a schema. It describes the data structures, data types, constraints, etc. of the data. The schema can be represented by a diagram known as schema diagram. The schema is specified through a data definition language like SQL CREATE TABLE statement.

3. Instance - The data contained within the database at a particular moment is called an instance. The state of a database varies over time as data is inserted, updated or deleted. The instance matches the schema and contains the actual data values. Multiple instances may exist for a single schema as the database changes over time.
