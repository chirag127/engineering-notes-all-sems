
### Concepts for the Notes of the Unit 7 - Big Data and SOA in the Subject of Service Oriented Architecture

1. **Service Oriented Architecture (SOA)**: SOA is a way of designing software applications as a set of services that communicate with each other over a network. It is a distributed computing model that enables the creation of loosely coupled and reusable services. 

2. **Big Data**: Big Data is a term used to describe the large and complex datasets that are difficult to process using traditional data processing techniques. It is characterized by its volume, velocity, and variety.

3. **Mnemonics and Learning Tricks**: Mnemonics are memory aids that help you remember concepts and ideas. Learning tricks are techniques or strategies that help you learn and remember information. Examples of mnemonics and learning tricks include acronyms, visual aids, and rhymes. 

4. **Advantages of SOA and Big Data**: 
   - SOA enables the creation of reusable services, which can be used to quickly develop new applications. 
   - Big Data enables the analysis of large and complex datasets, which can lead to insights that would otherwise be difficult to obtain.

5. **Disadvantages of SOA and Big Data**: 
   - SOA can be difficult to implement, as it requires careful coordination between different services.
   - Big Data can be difficult to manage, as it requires specialized hardware and software.

6. **Examples of Applications Using SOA and Big Data**: 
   - Social media platforms such as Facebook and Twitter use SOA to manage user data. 
   - Retail companies such as Amazon and Walmart use Big Data to analyze customer behavior and optimize their operations.
