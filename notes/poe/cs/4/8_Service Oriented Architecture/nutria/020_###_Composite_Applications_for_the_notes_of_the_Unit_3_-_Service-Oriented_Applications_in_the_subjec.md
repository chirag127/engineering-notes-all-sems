
### Composite Applications for the notes of the Unit 3 - Service-Oriented Applications in the subject of Service Oriented Architecture

A composite application is a software application that is composed of multiple services and components. It is designed to offer a single user interface that is used to access multiple services or components. The services and components are usually hosted on different computers and networks, and the composite application provides a unified interface for the user to access all of them.

Composite applications are used in many areas, including enterprise software, web applications, and mobile applications. They are often used to create applications that are more complex than a single application can handle, or to provide a unified view of multiple services and components.
