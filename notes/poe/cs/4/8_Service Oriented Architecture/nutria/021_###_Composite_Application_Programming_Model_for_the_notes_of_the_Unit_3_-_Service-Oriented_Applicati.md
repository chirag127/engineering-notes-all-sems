
### Composite Application Programming Model for the notes of the Unit 3 - Service-Oriented Applications in the subject of Service Oriented Architecture

The Composite Application Programming Model (CAPM) is a software engineering approach for designing and developing service-oriented applications. It is based on the principles of service-oriented architecture (SOA), which is an architectural approach to designing distributed systems using loosely coupled services.

The CAPM consists of four main components:

1. Service Contract: A service contract defines the interface between the service provider and the service consumer. It specifies the operations that the service provides, the data types used by the service, and the expected behavior of the service.

2. Service Implementation: The service implementation is the code that implements the service contract. It is responsible for performing the operations defined in the service contract and returning the expected results.

3. Service Host: The service host is responsible for hosting the service implementation. It provides the infrastructure required to run the service, such as memory, threads, and network connections.

4. Service Registry: The service registry is a repository of service descriptions. It stores information about the services that are available and their associated service contracts.

The CAPM provides a structured approach for designing and developing service-oriented applications. It helps to ensure that the services are properly designed, implemented, and deployed.

Mnemonics: CAPM - Contract, Implementation, Host, Registry.
