
## Unit 5 - Technologies for SOA

* **Service-Oriented Architecture (SOA):** SOA is an architectural style that enables applications to be composed of loosely coupled services. SOA provides a way to define and expose services in a way that makes them easier to use and manage. It enables applications to be deployed and managed in a distributed environment.

* **Web Services:** Web services are a type of SOA that allows applications to communicate with each other over the internet. Web services are typically based on the Simple Object Access Protocol (SOAP) and Representational State Transfer (REST) standards.

* **Service Bus:** A service bus is a messaging platform that enables services to communicate with each other. It provides a way for services to send and receive messages, and to route messages to the appropriate services.

* **Service Registry:** A service registry is a repository of information about services that are available in an SOA environment. It provides a way for services to discover other services, and to publish and locate services.

* **Service Virtualization:** Service virtualization is a technique that enables services to be deployed and managed in a virtualized environment. It provides a way to simulate the behavior of services in a distributed environment.

* **Service Orchestration:** Service orchestration is a technique that enables services to be composed into larger, more complex services. It provides a way to define and manage the interactions between services.

* **Service Governance:** Service governance is a set of policies and procedures that govern how services are deployed and managed in an SOA environment. It provides a way to ensure that services are deployed and managed in a secure and reliable manner.
