
### Object-oriented Analysis and Design (OOAD) Process for the notes of the Unit 2 - Enterprise-Wide SOA in the subject of Service Oriented Architecture

Object-oriented Analysis and Design (OOAD) is a process used in software engineering to develop software applications. The process consists of five steps:

1. **Requirements Analysis**: This is the first step in the OOAD process. The purpose of this step is to identify the requirements of the system. This includes understanding the user's needs and the purpose of the system.

2. **Object Modeling**: This step involves creating a model of the system using object-oriented concepts such as classes, objects, attributes, and methods.

3. **Design**: This step involves designing the system using object-oriented principles such as abstraction, encapsulation, inheritance, and polymorphism.

4. **Implementation**: This step involves implementing the system using a programming language such as Java or C++.

5. **Testing**: This step involves testing the system to ensure that it meets the user's requirements.

Mnemonic:

RAOMDIP: Requirements Analysis, Object Modeling, Design, Implementation, and Testing.
