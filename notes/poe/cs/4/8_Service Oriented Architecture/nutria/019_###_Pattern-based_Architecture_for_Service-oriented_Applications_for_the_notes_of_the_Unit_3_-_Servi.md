
### Pattern-based Architecture for Service-oriented Applications 

Pattern-based architecture is a type of service-oriented architecture (SOA) that is based on a collection of design patterns that are used to create a system of services that are loosely coupled. This type of architecture is used to provide a robust, reliable, and maintainable system.

#### Advantages 
- Allows for the reuse of existing services 
- Provides a standard way to design and develop services 
- Improves scalability and performance 
- Improves maintainability and reliability 
- Reduces development and maintenance costs 

#### Disadvantages 
- Can be difficult to design and implement 
- Can be difficult to maintain 
- Can be difficult to debug 
- Can be difficult to scale 

#### Mnemonics and Learning Tricks 
- **P**attern-based **A**rchitecture for **S**ervice-oriented **A**pplications 
- **PASA** - Design patterns used to create a system of services that are loosely coupled. 

#### Examples 
- Amazon Web Services 
- Microsoft Azure 
- IBM Bluemix 

#### Applications 
- Banking 
- Healthcare 
- Retail 
- Telecommunications
