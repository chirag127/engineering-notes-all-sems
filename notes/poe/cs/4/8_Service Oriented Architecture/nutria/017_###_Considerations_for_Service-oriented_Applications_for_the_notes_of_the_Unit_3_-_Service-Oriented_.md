
### Considerations for Service-oriented Applications for the notes of the Unit 3 - Service-Oriented Applications in the subject of Service Oriented Architecture

* Service-oriented applications are a type of software architecture that enables applications to communicate with each other over a network.
* They are typically composed of multiple components, each of which provides a specific service or functionality.
* Service-oriented applications are designed to be scalable, reliable, and secure.
* They are also designed to be extensible, so that new services can be added without disrupting existing services.
* Service-oriented applications are built using various technologies, such as web services, distributed objects, and message-oriented middleware.
* Service-oriented applications are designed to be loosely coupled, so that components can be replaced or upgraded without affecting the entire system.
* Service-oriented applications are typically deployed in a distributed environment, such as a cloud, to maximize performance and availability.
* Service-oriented applications must adhere to certain principles, such as service-level agreements, in order to ensure that the system is reliable and secure.
* Service-oriented applications must be monitored and tested regularly to ensure that they meet the requirements of the system.
* Mnemonics and learning tricks for service-oriented applications include: 
    * SOA (Service-Oriented Architecture): A system architecture that enables applications to communicate with each other over a network.
    * SLA (Service-Level Agreement): An agreement between two parties that specifies the terms and conditions of a service.
    * API (Application Programming Interface): A set of protocols and tools that enable applications to communicate with each other.
    * MOM (Message-Oriented Middleware): Software that enables applications to send and receive messages over a network.
    * WS (Web Services): A type of distributed computing technology that enables applications to communicate with each other over a network.
