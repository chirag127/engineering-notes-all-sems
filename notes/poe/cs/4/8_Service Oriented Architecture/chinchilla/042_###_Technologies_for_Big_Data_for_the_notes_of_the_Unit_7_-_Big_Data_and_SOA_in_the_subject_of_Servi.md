### Technologies for Big Data for the notes of the Unit 7 - Big Data and SOA in the subject of Service Oriented Architecture

Big Data has become an essential aspect of modern-day businesses. With the increasing amount of data being generated, it is crucial to have the right technologies to handle, process, and analyze this data efficiently. In this unit, we will discuss some of the technologies used for Big Data in the context of Service Oriented Architecture (SOA).

#### Hadoop

Hadoop is an open-source software framework used for distributed storage and processing of large datasets on clusters of commodity hardware. It is based on the MapReduce programming model, which allows parallel processing of data across multiple nodes in a cluster. Hadoop also includes the Hadoop Distributed File System (HDFS), which provides reliable and scalable storage for Big Data.

##### Mnemonic: 
- Hadoop = Huge Amount of Data, Oh Please!

#### Spark

Apache Spark is another open-source distributed computing framework used for Big Data processing. It is designed to work with Hadoop and other Big Data technologies to perform real-time data processing, machine learning, and graph processing. Spark's primary abstraction is Resilient Distributed Datasets (RDDs), which are in-memory collections of objects that can be processed in parallel.

##### Mnemonic: 
- Spark = Fast and Bright like a Spark of Fire

#### NoSQL Databases

NoSQL databases are non-relational databases designed to handle unstructured and semi-structured data. They are highly scalable and provide high availability and fault tolerance. Some popular NoSQL databases used for Big Data include MongoDB, Cassandra, and HBase.

##### Mnemonic: 
- NoSQL = Not Only SQL

#### Apache Kafka

Apache Kafka is an open-source distributed streaming platform used for real-time data processing. It is designed to handle high volumes of data and provide low-latency data processing. Kafka uses a publish-subscribe messaging system for data exchange and can integrate with other Big Data technologies such as Hadoop and Spark.

##### Mnemonic: 
- Kafka = Keep All Fast-Flying Articles

#### Apache Storm

Apache Storm is another open-source distributed real-time processing system used for Big Data. It is designed to handle high-volume, high-velocity data streams and provides low-latency processing. Storm uses a topology-based approach for data processing, where data flows through a series of processing nodes called bolts.

##### Mnemonic: 
- Storm = Strong and quick like a Storm

In conclusion, these are some of the technologies used for Big Data in the context of Service Oriented Architecture. Each technology has its strengths and weaknesses, and it is essential to choose the right technology based on the specific requirements of your business. By understanding these technologies, you can make informed decisions and successfully implement Big Data solutions for your business.
