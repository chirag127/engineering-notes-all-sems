### Technologies for Service Enablement

The following technologies are used for service enablement in SOA:

- XML: Extensible Markup Language is used for defining services and exchanging data between services. It provides a standard way of tagging data and transmitting in a platform/language independent way.
- SOAP: Simple Object Access Protocol is a messaging protocol used for exchanging XML based messages between services. It forms the basis for web services.
- WSDL: Web Services Description Language is an XML based language used for describing the interface of web services. It provides all the details required to interact with a web service.
- UDDI: Universal Description Discovery and Integration is a registry where services can be registered and discovered. It acts as a directory of web services.

**Mnemonics:**

> X for eXchange,
> S for Simple,
> W for Web,
> U for Universal

To remember the technologies - XML, SOAP, WSDL and UDDI

**Advantages:**

- Platform and language independence due to use of XML
- Loose coupling between services due to messaging based interaction
- Service interface description in WSDL enables automation of service consumption
- UDDI enables service discovery and reuse

**Disadvantages:**

- Overhead due to XML wrapping/unwrapping and SOAP processing
- Complexity of WSDL and UDDI implementations
- Limited query capabilities in UDDI

**Examples:**

- Online shopping: Services for product catalog, shopping cart, payment, etc.
- Travel booking: Services for flight booking, hotel booking, car rental, etc.

**Applications:** Web services, Cloud services, Microservices, etc.
