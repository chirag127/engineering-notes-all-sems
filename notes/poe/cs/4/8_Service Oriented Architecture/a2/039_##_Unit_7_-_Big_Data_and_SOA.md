## Unit 7 - Big Data and SOA

### What is Big Data?

- Big data refers to extremely large data sets that may be analyzed computationally to reveal patterns, trends, and associations, especially relating to human behavior and interactions.
- The challenges include capture, storage, search, sharing, transfer, analysis, and visualization.
- The five Vs of big data:
    - Volume: Amount of data
    - Velocity: Speed of data in and out
    - Variety: Range of data types and sources
    - Veracity: Uncertainty of data
    - Value: Business value that can be derived

**Mnemonic:** The 5 V's of Big Data - Volume, Velocity, Variety, Veracity, Value

### Types of Big Data

- Structured data: Data that fits neatly into tables with rows and columns like customer records or sales data
- Semi-structured data: Data that does not have a strict data model with rows and columns but has some structure like XML and JSON data
- Unstructured data: Data with no internal structure like text, audio, video, images, etc.

### Characteristics of Big Data

- Volume: Amount of data is huge. Measured in zettabytes and yottabytes.
- Velocity: Data is streaming in at an incredible rate.
- Variety: Data comes from various sources in various formats. Both structured and unstructured data.
- Complexity: The complexity of data makes it difficult to process using traditional data processing tools and methods.
- Value: The data has potential value which can be extracted using big data analytics techniques.

### What is Service-Oriented Architecture (SOA)?

- SOA is a style of software design where applications are built as a set of services that can be used within multiple applications.
- Services are standalone units of functionality that are accessed via standard interfaces and communication protocols.
- The key benefits of SOA are:
    - Increased reusability of services
    - Easier maintenance as services can be updated independently
    - Platform and language independence using standard interfaces
    - Flexible applications that can be built by combining multiple services
