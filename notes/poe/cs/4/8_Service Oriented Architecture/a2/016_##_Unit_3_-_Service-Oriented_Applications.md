## Unit 3 - Service-Oriented Applications

Service-Oriented Applications are applications that are built by combining loosely coupled and interoperable services. These services can be reused, modified or replaced dynamically to meet changing business requirements.

 key points:

- Services are loosely coupled components that provide a specific functionality. They are platform and language independent.
- Services communicate with each other using standard protocols like HTTP and expose interfaces using standard formats like WSDL and JSON/XML.
- A service-oriented application consists of multiple services that are orchestrated using business processes to provide the required functionality.
- The key benefits of service-oriented applications are reusability, interoperability, modifiability and scalability.
- The challenges involved are maintaining service contracts and handling service compatibility, security, transaction management, etc.

Example: An e-commerce application can be built using services like Product Catalog service, Shopping Cart service, Payment service and Shipping service that are orchestrated using a business process to provide the complete functionality.

Advantages:

- Increased reusability: Services can be reused across applications.
- Interoperability: Services use standard protocols and formats to communicate, enabling heterogeneous systems to interoperate.
- Modifiability: Existing services can be modified or new services can be plugged in to meet changing requirements.
- Increased scalability: Services can be scaled independently to handle increasing loads.

Disadvantages:

- Complexity: Service-oriented applications are more complex to design and implement compared to monolithic applications.
- Managing service compatibility: It is challenging to manage service compatibility when services are modified or replaced.
- Performance overhead: There is extra overhead in service-oriented applications due to service calls and data conversion.
- Security: It is difficult to ensure end-to-end security in service-oriented applications as services are loosely coupled components.

Mnemonics and learning tricks:

- Think of a service-oriented application as an assembly of Lego blocks (services) of different colors (languages/platforms) that can be rearranged to build different structures (meet changing needs).
- Remember the key benefits using the acronym RIMS - Reusability, Interoperability, Modifiability, Scalability.
- The challenges can be remembered using the acronym SPCT - Service compatibility, Performance, Complexity, Security, Transaction management.
