## Unit 5 - Technologies for SOA

### Web Services

- Web Services are self-contained, self-describing, modular applications that can be published, located, and invoked over a network, such as the Internet.
- They are built on open standards and can be written in any programming language and run on any operating system and platform.
- The key technologies for Web Services are:

**XML** - Used for defining data formats and messaging protocols.
**SOAP** - Used as a messaging protocol for exchange of information in a decentralized and distributed environment.
**WSDL** - Used for describing the services offered by a Web Service.
**UDDI** - Used as a directory for publishing and discovering Web Services.

**Advantages** - Language/platform independence, interoperability, reuse
**Disadvantages** - Can be performance intensive, security issues
**Applications** - Business-to-business transactions, supply chain management

### REST

- REST stands for Representational State Transfer. It is an architectural style for building web services.
- REST uses HTTP requests to GET, PUT, POST and DELETE data.
- It emphasizes on resources with URIs, uniform interfaces, stateless interactions, and hypermedia as the engine of application state (HATEOAS).
- The key benefits of REST are scalability, simplicity, flexibility and better performance as compared to SOAP-based web services.

**Advantages** - Scalability, Simplicity, Performance
**Disadvantages** - Limited support for security, transactions, etc.
**Applications** - Social networks, e-commerce sites, etc.
