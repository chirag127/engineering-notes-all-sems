### Concepts for the notes of the Unit 7 - Big Data and SOA in the subject of Service Oriented Architecture

1. Big Data - Big data refers to extremely large data sets that may be analyzed computationally to reveal patterns, trends, and associations, especially relating to human behavior and interactions. Big data is data that contains greater variety arriving in increasing volumes and with ever-higher velocity. This means that the types of data are diverse (structured, unstructured, semi-structured), data arrives from various sources at high speeds, and in huge volumes.

- Examples: Social media, internet activity, sensors, machines, etc. generating huge volumes of data.
- Characteristics: Volume, Velocity, Variety, Veracity, Value
- Applications: Predictive analytics, personalized recommendations, fraud detection, improving business performance, etc.
- Tools: Hadoop, Spark, MongoDB, etc.

2. Service Oriented Architecture (SOA) - SOA is a style of software design where applications are built as a set of interoperable services. Each service is a discrete unit of functionality that can be accessed remotely via an interface and can be reused for other services or applications. The key characteristics of SOA are loose coupling, service contracts, autonomy, abstraction, reusability, composability, and discoverability.

- Advantages: Increased interoperability, reduced complexity, technology agnostic, increased reusability
- Disadvantages: Can be complex to implement, security concerns, governance challenges
- Examples: Online shopping, banking systems, etc.

3. Combining Big Data and SOA - When Big Data is combined with SOA, it enables building agile and scalable systems that can handle huge volumes of data and diverse data types. The services in SOA can be designed to handle and process big data efficiently. This combination is useful for building complex event processing systems, real-time analytics systems, and smart applications that can understand customer behavior by processing huge data in real-time and providing personalized responses.

- For example, a fraud detection system can use big data processing via services to analyze financial transactions in real-time and identify suspicious activities.
