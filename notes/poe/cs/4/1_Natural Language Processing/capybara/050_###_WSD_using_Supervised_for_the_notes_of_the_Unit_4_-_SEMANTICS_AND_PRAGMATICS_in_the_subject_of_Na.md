### WSD using Supervised for the notes of the Unit 4 - SEMANTICS AND PRAGMATICS in the subject of Natural Language Processing

Word Sense Disambiguation (WSD) is a crucial task in Natural Language Processing, which aims to identify the correct sense of a word in a given context. WSD using Supervised learning is one of the commonly used approaches for WSD. Here are some important points to note about WSD using Supervised learning:

1. Supervised Learning:
   - Supervised learning is a machine learning technique where a model learns from labeled data.
   - In WSD using Supervised learning, the model is trained on a labeled dataset, where each instance has a word and its correct sense label.
   - The model learns to associate the context of the word with the correct sense label.

2. Feature Extraction:
   - Feature extraction is a crucial step in WSD using Supervised learning.
   - The model needs to be provided with relevant features that capture the context of the word.
   - Some commonly used features for WSD include the surrounding words, part-of-speech tags, lexical features, and semantic features.

3. Machine Learning Models:
   - There are various machine learning models that can be used for WSD using Supervised learning, such as Decision Trees, Naive Bayes, Support Vector Machines (SVM), and Neural Networks.
   - SVM is one of the most commonly used models for WSD using Supervised learning because it has been shown to perform well on this task.

4. Evaluation Metrics:
   - To evaluate the performance of a WSD model, various evaluation metrics can be used, such as accuracy, precision, recall, and F1-score.
   - F1-score is a commonly used metric for WSD evaluation because it considers both precision and recall.

5. Advantages and Disadvantages:
   - WSD using Supervised learning has some advantages, such as high accuracy, the ability to handle new words, and the ability to learn from large labeled datasets.
   - However, it also has some disadvantages, such as the need for large labeled datasets, the difficulty of feature engineering, and the lack of generalizability to new domains.

Mnemonics and learning tricks:
Unfortunately, there are no easy-to-remember mnemonics or learning tricks for WSD using Supervised learning. However, practicing on labeled datasets and experimenting with different features and models can help improve the performance of the WSD model.
