
### Context Free Grammars for the notes of the Unit 3 - SYNTACTIC ANALYSIS in the subject of Natural Language Processing

Context Free Grammars (CFGs) are a type of formal grammar used to describe languages. They are used in Natural Language Processing (NLP) to generate syntactically correct sentences.

A CFG consists of a set of production rules, which are used to generate strings of symbols. The symbols can be words, phrases, or sentences. The production rules specify how the symbols can be combined to form a valid sentence.

The most common form of CFG is Backus-Naur Form (BNF). BNF consists of a set of production rules, which are written in the form of a BNF grammar. A BNF grammar consists of a set of non-terminal symbols, which are used to represent words or phrases, and a set of terminal symbols, which are used to represent individual words. The production rules specify how the non-terminal symbols can be combined with the terminal symbols to form a valid sentence.

Mnemonics and learning tricks for CFGs:

- **C**ontext **F**ree **G**rammars are used to generate syntactically correct sentences.
- **B**ackus-**N**aur **F**orm is the most common form of CFG.
- **N**on-**T**erminal symbols represent words or phrases.
- **T**erminal symbols represent individual words.
- **P**roduction rules specify how the non-terminal symbols can be combined with the terminal symbols to form a valid sentence.
