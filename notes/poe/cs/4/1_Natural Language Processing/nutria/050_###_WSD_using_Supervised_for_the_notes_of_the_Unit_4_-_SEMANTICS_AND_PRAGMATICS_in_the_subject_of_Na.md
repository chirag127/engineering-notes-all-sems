
### WSD using Supervised for the notes of the Unit 4 - SEMANTICS AND PRAGMATICS in the subject of Natural Language Processing

* Word Sense Disambiguation (WSD) using supervised learning is a process of assigning the correct meaning of a word based on the context in which it is used. 
* It is an important task in Natural Language Processing (NLP) and is used to improve the accuracy of language understanding.
* Supervised learning is used to train a machine learning model to identify the correct meaning of a word. The model is trained using labeled data, which is a collection of sentences with their corresponding word senses.
* By training the model on a large dataset, it is able to accurately identify the correct meaning of a word in a given context.
* WSD using supervised learning can be used to improve the accuracy of language understanding in many applications such as machine translation, speech recognition, question answering, and text classification.
* Advantages of WSD using supervised learning include: 
  * Higher accuracy of language understanding compared to unsupervised methods.
  * Can be used to improve the accuracy of many applications such as machine translation, speech recognition, question answering, and text classification.
  * Easy to implement and train.
* Disadvantages of WSD using supervised learning include: 
  * Requires a large labeled dataset for training.
  * Can be time consuming and expensive to create a labeled dataset.
  * The model may not be able to generalize to unseen data.
