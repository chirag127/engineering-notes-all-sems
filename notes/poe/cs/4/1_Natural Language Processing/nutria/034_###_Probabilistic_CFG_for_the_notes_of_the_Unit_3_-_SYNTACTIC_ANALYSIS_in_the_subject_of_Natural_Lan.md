
### Probabilistic CFG for the notes of the Unit 3 - SYNTACTIC ANALYSIS in the subject of Natural Language Processing

* Probabilistic Context-Free Grammars (PCFGs) are a type of formal grammar used in Natural Language Processing (NLP). 
* PCFGs are a type of grammar which can generate a set of valid sentences from a given set of rules and probabilities. 
* The main difference between PCFGs and other types of grammar is that PCFGs assign probabilities to the rules in order to determine the likelihood of a sentence being generated. 
* PCFGs are useful in NLP tasks such as parsing, machine translation, and text generation.
* PCFGs are composed of a set of rules which specify the structure of a sentence. 
* Each rule consists of a left-hand side (LHS) and a right-hand side (RHS). 
* The LHS is a non-terminal symbol which represents a phrase or a word. 
* The RHS is a sequence of symbols which can be either terminals or non-terminals. 
* Each rule is associated with a probability which determines the likelihood of the rule being used to generate a sentence.
* PCFGs can be used to generate parse trees which represent the structure of a sentence. 
* The parse tree is composed of nodes which represent the words in the sentence and the relationships between them. 
* The parse tree can be used to identify the syntactic structure of a sentence. 
* PCFGs can also be used to calculate the probability of a sentence being generated given a set of rules. 
* This can be used to determine the likelihood of a sentence being correct or incorrect. 
* PCFGs are a powerful tool in NLP and are used in many applications such as speech recognition, machine translation, and text generation.
