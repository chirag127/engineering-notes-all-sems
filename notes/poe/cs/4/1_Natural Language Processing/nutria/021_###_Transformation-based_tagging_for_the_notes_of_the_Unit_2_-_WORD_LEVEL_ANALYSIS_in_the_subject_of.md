
### Transformation-based tagging for the notes of the Unit 2 - WORD LEVEL ANALYSIS in the subject of Natural Language Processing

Transformation-based tagging is a type of natural language processing that uses rules to assign tags to words. The rules are based on the context of the word, which means that the tagger can accurately assign tags even to words that it has never seen before.

The basic idea behind transformation-based tagging is to start with a set of rules that have been previously learned, and then apply these rules to a new sentence. For each word in the sentence, the tagger will find the rule that best fits the context of the word and assign the corresponding tag.

In order to use transformation-based tagging, the tagger must first be trained on a set of tagged sentences. This training process involves finding the rules that best fit the tagged sentences. Once the tagger has been trained, it can then be applied to new sentences.

Transformation-based tagging has several advantages over other types of natural language processing. First, it is relatively fast and efficient. Second, it can accurately assign tags to words even if it has never seen them before. Third, it is highly accurate, as it takes into account the context of the word. Finally, it is relatively easy to implement, as the rules can be written in a simple language.
