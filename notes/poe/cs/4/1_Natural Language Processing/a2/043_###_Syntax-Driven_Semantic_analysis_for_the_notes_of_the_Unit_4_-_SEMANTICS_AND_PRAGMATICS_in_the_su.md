### Syntax-Driven Semantic analysis for the notes of the Unit 4 - SEMANTICS AND PRAGMATICS in the subject of Natural Language Processing

- Syntax-Driven Semantic analysis is a technique where the syntax of the input sentence is analyzed to derive the semantics(meaning) of the sentence.
- The syntax rules of the language are used to identify the syntactic components of the input sentence like nouns, verbs, subjects, objects, etc.
- Based on the syntactic components and their relations, semantic roles are assigned to the components. For example, the subject noun phrase is assigned the semantic role of agent, the direct object noun phrase is assigned the semantic role of patient, etc.
- This technique is easy to implement as it just uses the syntax rules but it has limitations in ambiguous sentences and sentences with implied meanings.
- Mnemonics: Syntax before Semantics. First analyze syntax, then infer semantics.
- Advantages: Easy to implement using syntax rules. Helps in basic semantic analysis.
- Disadvantages: Limited in cases of ambiguity and implied meanings. Syntax-semantics mismatch can occur.
- Examples: "John hit the ball". Using syntax, identify noun phrases and verb phrase. Assign semantic roles of agent to "John" and patient to "the ball".
- Applications: Used in basic semantic analysis systems. Can be used as a preprocessing step in advanced systems.
