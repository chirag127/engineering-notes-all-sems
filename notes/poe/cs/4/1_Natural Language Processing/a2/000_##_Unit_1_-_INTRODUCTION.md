## Unit 1 - INTRODUCTION

1. Software Engineering: Software Engineering is an engineering discipline concerned with the design, development and testing of software or computer programs which are a set of instructions to perform some specific task. Software Engineering principles and techniques are used to efficiently develop high quality, reliable and maintainable software solutions for the problems in a systematic manner.

Mnemonics: SE follows SDLC where S = Requirements, D = Design, L = Implementation, C = Testing and Deployment

2. Software Development Life Cycle (SDLC): SDLC or Software Development Life Cycle refers to the process of developing software through business needs analysis, requirements analysis, design, programming, testing, and deployment. SDLC provides a systematic approach to develop software in a high quality, reliable and cost-effective manner. The major phases of SDLC are:

- Requirements Analysis: Gathering and analyzing the software requirements specified by the customer.
- Design: Coming up with the technical design and architecture of the software to satisfy the requirements.
- Implementation: Coding and developing the software.
- Testing: Testing the software to identify and fix bugs or defects.
- Deployment: Deploying the final software and providing maintenance and support.

3. Programming Languages: Programming languages are the languages in which computer programs are written. Some popular programming languages are:

- Java: Object-oriented, platform independent, used to develop mobile apps and server-side apps.
- Python: Interpreted, high-level language, easy to learn and has many libraries for Machine Learning and Data Science.
- C++: Compiled, middle-level language, efficient and used to develop system software and games.
- JavaScript: Lightweight, interpreted scripting language, used to develop interactive effects within web browsers.
