

### Fiestal Structure for the Notes of the Unit 1 - Introduction to Security Attacks, Services and Mechanism, Classical Encryption Techniques, Substitution Ciphers and Transposition Ciphers, Cryptanalysis, Steganography, Stream and Block Ciphers. Modern Block Ciphers: 

- **Block Ciphers Principles:** A block cipher is a symmetric key encryption algorithm which takes a fixed-length string of plaintext bits and produces a ciphertext bit string of the same length. Block ciphers are secure when used in conjunction with an appropriate mode of operation and a message authentication code.

- **Shannon’s Theory of Confusion and Diffusion:** This theory is based on the idea that a cipher should make the relationship between the plaintext and the ciphertext as complicated as possible. This is achieved by making the relationship between the plaintext and the ciphertext as unpredictable as possible.

- **Fiestal Structure:** The Fiestal structure is a structure used in symmetric key block ciphers. It is named after Horst Fiestal, who designed the structure for the Data Encryption Standard (DES). The Fiestal structure consists of multiple rounds of processing, each of which consists of four stages: substitution, permutation, XOR, and key mixing.

- **Data Encryption Standard (DES):** The Data Encryption Standard (DES) is a symmetric-key block cipher which was developed by IBM and adopted by the US National Bureau of Standards (now the National Institute of Standards and Technology) in 1977. DES uses a 56-bit key and the Fiestal structure described above.

- **Strength of DES:** DES is considered to be a relatively secure cipher, although it has been broken in the past. The strength of DES lies in its key length; a 56-bit key is considered to be strong enough to prevent brute-force attacks.

- **Idea of Differential Cryptanalysis:** Differential cryptanalysis is a type of cryptanalysis which looks for differences in the output of a cipher when given two different inputs which differ in only one bit. This difference can be used to gain information about the cipher and its key.

- **Block Cipher Modes of Operations:** Block cipher modes of operations are techniques used to extend the use of a block cipher beyond encryption of a single block of data. Examples of block cipher modes of operations include Electronic Codebook (ECB), Cipher Block Chaining (CBC), Output Feedback (OFB), and Counter (CTR).

- **Triple DES:** Triple DES (3DES) is an enhanced version of the Data Encryption Standard (DES) which uses three different keys and three rounds of encryption. It is considered to be more secure than DES, but is still vulnerable to brute-force attacks.
