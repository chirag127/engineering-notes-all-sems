
### Stream and Block Ciphers for the Notes of the Unit 1 - Introduction to Security Attacks, Services and Mechanism, Classical Encryption Techniques

Substitution Ciphers and Transposition Ciphers: 
- Substitution ciphers involve replacing each plaintext character with another character, number, or symbol. The substitution is based on a key, which is a set of rules that determine how the substitution should be carried out. 
- Transposition ciphers involve rearranging the order of the characters in the plaintext. The rearrangement is based on a key, which is a set of rules that determine how the rearrangement should be carried out.

Cryptanalysis:
- Cryptanalysis is the process of analyzing encrypted data in order to determine the plaintext. It involves breaking the encryption algorithm or cipher used to create the encrypted data.

Steganography:
- Steganography is the process of hiding data within other data. It involves embedding a message within an image, audio, or other file in such a way that it is undetectable.

Stream and Block Ciphers:
- Stream ciphers are ciphers that encrypt data one bit or one byte at a time. They use a keystream, which is a sequence of random bits generated by a pseudorandom number generator, to encrypt the data.
- Block ciphers are ciphers that encrypt data in blocks of a fixed size. They use a key, which is a set of rules that determine how the encryption should be carried out.

Modern Block Ciphers:
- Block ciphers principles: Block ciphers use a series of mathematical operations to transform plaintext into ciphertext. These operations are based on a key, which is a set of rules that determine how the transformation should be carried out. 
- Shannon’s theory of confusion and diffusion: Shannon’s theory of confusion and diffusion states that a cipher should make it difficult for an attacker to determine the relationship between the plaintext and the ciphertext.
- Fiestal structure: The Fiestal structure is a structure used in block ciphers. It consists of multiple rounds of encryption, each round consisting of a substitution phase and a permutation phase. 
- Data Encryption Standard (DES): DES is a symmetric key block cipher developed by IBM in 1975. It uses a 56-bit key and operates on 64-bit blocks of data. 
- Strength of DES: DES is considered to be secure, but its 56-bit key length is considered to be too small to provide adequate security in the modern era.
- Idea of differential cryptanalysis: Differential cryptanalysis is a type of cryptanalysis that uses differences in plaintexts and ciphertexts to determine the key used to encrypt the data. 
- Block cipher modes of operations: Block cipher modes of operations are algorithms that determine how data is encrypted and decrypted using block ciphers. 
- Triple DES: Triple DES is a symmetric key block cipher developed by IBM in 1976. It uses a 168-bit key and operates on 64-bit blocks of data.
