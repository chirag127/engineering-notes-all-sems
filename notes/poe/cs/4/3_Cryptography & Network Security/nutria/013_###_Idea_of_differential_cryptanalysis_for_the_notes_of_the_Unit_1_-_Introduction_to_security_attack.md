
### Idea of Differential Cryptanalysis
Differential cryptanalysis is a type of cryptanalysis used to break block ciphers. It is based on the idea that the differences between plaintexts can be used to identify patterns in the ciphertext. The technique was first described by Eli Biham and Adi Shamir in 1991.

Differential cryptanalysis works by analyzing the differences between two plaintexts and the corresponding ciphertexts. The differences between the plaintexts can be used to identify patterns in the ciphertext that can be used to break the encryption.

The technique is used to break block ciphers, which are algorithms that encrypt data in blocks. Block ciphers use a key to encrypt data in blocks of a fixed size. Differential cryptanalysis can be used to identify patterns in the ciphertext that can be used to determine the key.

Differential cryptanalysis can be used to break ciphers such as Data Encryption Standard (DES), Triple DES, and Advanced Encryption Standard (AES). It can also be used to break stream ciphers, which are algorithms that encrypt data in streams of bits.
