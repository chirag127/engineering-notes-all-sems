
### Introduction to Security Attacks

This unit introduces the concept of security attacks, services, and mechanisms. It will cover classical encryption techniques, substitution ciphers, transposition ciphers, cryptanalysis, steganography, stream and block ciphers. It will also discuss modern block ciphers and their principles, Shannon’s theory of confusion and diffusion, the Feistel structure, the Data Encryption Standard (DES), the strength of DES, the idea of differential cryptanalysis, block cipher modes of operations, and Triple DES in the subject of cryptography and network security.

#### Classical Encryption Techniques

Classical encryption techniques are a set of methods used to encrypt plaintext (readable text) into ciphertext (unreadable text). These techniques include substitution ciphers, transposition ciphers, and steganography.

##### Substitution Ciphers

A substitution cipher is a type of encryption technique in which each letter of the plaintext is replaced with another letter or symbol. This is done by using a key, which is a set of rules that determine how the plaintext is converted into ciphertext.

##### Transposition Ciphers

A transposition cipher is another type of encryption technique in which the letters of the plaintext are rearranged. This is done by using a key, which is a set of rules that determine how the letters of the plaintext are rearranged.

##### Steganography

Steganography is a type of encryption technique in which a message is hidden within another message. This is done by using a key, which is a set of rules that determine how the message is hidden.

#### Modern Block Ciphers

Modern block ciphers are a set of methods used to encrypt plaintext into ciphertext. These techniques include the principles of block ciphers, Shannon’s theory of confusion and diffusion, the Feistel structure, the Data Encryption Standard (DES), the strength of DES, the idea of differential cryptanalysis, block cipher modes of operations, and Triple DES.

##### Block Ciphers Principles

Block ciphers are a type of encryption technique in which a message is divided into blocks and each block is encrypted independently. This is done by using a key, which is a set of rules that determine how the message is encrypted.

##### Shannon’s Theory of Confusion and Diffusion

Shannon’s theory of confusion and diffusion is a type of encryption technique in which the plaintext is confused and diffused in order to make it more difficult for an attacker to decrypt. This is done by using a key, which is a set of rules that determine how the plaintext is confused and diffused.

##### Feistel Structure

The Feistel structure is a type of encryption technique in which a message is divided into two halves and each half is encrypted independently. This is done by using a key, which is a set of rules that determine how the message is encrypted.

##### Data Encryption Standard (DES)

The Data Encryption Standard (DES) is a type of encryption technique in which a message is encrypted using a specific algorithm. This is done by using a key, which is a set of rules that determine how the message is encrypted.

##### Strength of DES

The strength of DES is determined by the length of the key used to encrypt the message. The longer the key, the more secure the encryption.

##### Idea of Differential Cryptanalysis

Differential cryptanalysis is a type of attack on an encryption system in which the attacker attempts to determine the key used to encrypt the message. This is done by using a set of rules that determine how the message is encrypted.

##### Block Cipher Modes of Operations

Block cipher modes of operations are a set of methods used to encrypt plaintext into ciphertext. These techniques include Electronic Codebook (ECB), Cipher Block Chaining (CBC), Cipher Feedback (CFB), Output Feedback (OFB), and Counter (CTR).

##### Triple DES

Triple DES is a type of encryption technique in which a message is encrypted three times using a specific algorithm. This is done by using a key, which is a set of rules that determine how the message is encrypted.
