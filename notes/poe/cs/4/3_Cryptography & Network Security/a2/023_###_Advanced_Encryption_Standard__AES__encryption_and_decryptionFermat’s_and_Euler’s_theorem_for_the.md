Advanced Encryption Standard (AES):
- AES is a symmetric block cipher standardized by NIST.
- It encrypts and decrypts blocks of 128 bits using cryptographic keys of 128, 192, and 256 bits.
- It is fast and secure, and is used in secure protocols such as SSL/TLS.
- The AES algorithm is based on substituting bytes, shifting rows, and mixing columns.

Fermat's Theorem:
- Fermat's little theorem states that if p is a prime number and a is an integer not divisible by p, then a^p ≡ a (mod p).
- This is used to compute discrete logarithms and prove primality.
- A special case is when a = 2, which shows that 2 is a quadratic non-residue modulo p if p is an odd prime.

Euler's Theorem:
- Euler's theorem states that if a and m are relatively prime, then a^φ(m) ≡ 1 (mod m), where φ is Euler's totient function.
- This is a generalization of Fermat's little theorem and is useful for proving further results in number theory.
