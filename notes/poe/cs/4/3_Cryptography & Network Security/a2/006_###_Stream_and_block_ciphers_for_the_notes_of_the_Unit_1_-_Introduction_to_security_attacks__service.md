Modern Block Ciphers:

Stream ciphers:
- encrypt plaintext digits/bytes one at a time with the corresponding digits/bytes of a keystream to generate the ciphertext.
- keystream is a pseudo-random sequence of digits/bytes generated by a key.
- Since encryption is done one digit/byte at a time, stream ciphers are typically faster than block ciphers.
- However, stream ciphers are more susceptible to attacks if the keystream is not truly random.

Block ciphers:
- encrypt plaintext blocks of fixed size one at a time with the corresponding blocks of a key to generate the ciphertext.
- operate on large blocks of digits/bytes instead of one digit/byte at a time.
- more secure than stream ciphers but slower.

Principles of block ciphers:
- Confusion - obscures the relationship between the plaintext and ciphertext.
- Diffusion - diffuses the influence of one plain/cipher text bit over the entire cipher text/plain text.
- Shannon's theory of confusion and diffusion states that a secure cipher must have both confusion and diffusion.

Feistel structure:
- uses a repeating structure of rounds consisting of transformation functions.
- In each round, half of the block is transformed using a function of the key and the other half. The halves are then swapped.
- The final round omits the swapping to produce the ciphertext.
- The advantage is that encryption and decryption use nearly identical steps and subkeys are easily generated.

Data Encryption Standard (DES):
- Block cipher with 64-bit block size and 56-bit key.
- Was the most widely used block cipher for many years but now considered insecure due to small key size.
- Uses a Feistel structure with 16 rounds.
- Strength - can be brute forced in reasonable time so 56-bit key is too small.
- Differential cryptanalysis - studies how differences in plain text propagate to differences in ciphertext. Can be used to attack DES.

Modes of operation for block ciphers:
- ECB - Electronic Code Book - Each block is independently encrypted. Same plaintext block will always encrypt to same ciphertext block. Vulnerable to certain attacks.
- CBC - Cipher Block Chaining - Each block is XORed with previous ciphertext block before encryption. More secure than ECB but error propagation is a concern.
- CFB - Cipher Feedback - Encryption is done by XORing the plaintext with the output of encrypting the previous ciphertext block. Vulnerable to error propagation.
- OFB - Output Feedback - Similar to CFB but ciphertext is encrypted instead of previous ciphertext block. No error propagation but more susceptible to attacks if nonce is repeated.
- CTR - Counter - Uses a counter block encrypted with the key to generate keystream which is XORed with plaintext to get ciphertext. No error propagation and parallelizable but nonce must never be repeated.

Triple DES:
- Uses DES algorithm 3 times with 2 or 3 different keys to strengthen security.
- 2-key Triple DES - Encrypt-Decrypt-Encrypt (EDE)
- 3-key Triple DES - Encrypt-Encrypt-Decrypt (EED)
- Provides increased security but is slower than DES due to multiple encryptions.
