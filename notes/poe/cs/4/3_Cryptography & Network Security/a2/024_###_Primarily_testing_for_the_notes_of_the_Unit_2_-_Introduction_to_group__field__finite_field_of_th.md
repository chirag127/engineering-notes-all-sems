### Group:
- A group is a set of elements with an associative binary operation that has an identity element and in which each element has an inverse.
- Example: Set of integers under addition is a group with identity 0 and inverse of x is -x.
- Applications: Used in abstract algebra and to study symmetry.

### Field:
- A field is a set of elements on which are defined addition, subtraction, multiplication and division, and the field axioms are satisfied.
- Example: Set of real numbers, integers modulo a prime, etc.
- Applications: Used in number theory and algebraic number theory.

### Finite field of the form GF(p):
- A finite field is a field with a finite number of elements. The most commonly studied finite fields are those of the form GF(p) which consists of integers modulo a prime p.
- Example: GF(5) = {0, 1, 2, 3, 4} where addition and multiplication are done modulo 5.
- Applications: Used in coding theory and cryptography.

### Modular arithmetic:
- Modular arithmetic is a system of arithmetic for integers modulo n, also known as "wrap around" arithmetic.
- The key theorem is a ≡ b (mod n) if and only if n|(a - b) which relates congruence to divisibility.
- Applications: Used in computer science, cryptography, music, art, etc. Common modular arithmetic is done modulo powers of primes.
