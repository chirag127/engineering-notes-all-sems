### Group
- A group is a set of elements with an operation that combines two elements to produce another element.
- The operation must satisfy four requirements - closure, associativity, identity, and inverses.
- Examples: Integer addition, multiplication, and rotation matrices.

### Field
- A field is a set of elements with two operations, addition and multiplication, that satisfy specific axioms.
- The field must contain a finite or infinite number of elements.
- Examples: The real numbers, rational numbers, and finite fields like GF(2) or GF(p) which are commonly used in cryptography.

### Finite field of the form GF(p)
- A finite field contains a finite number of elements and is denoted GF(p) where p is a prime number.
- Addition, subtraction, multiplication, and division are done modulo p.
- GF(p) has p elements and is useful in cryptography for operations like XOR and modulo 2 addition.
