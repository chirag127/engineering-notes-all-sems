### Introduction to security attacks for the notes of the Unit 1 - Introduction to security attacks, services and mechanism, Classical encryption techniquessubstitution ciphers and transposition ciphers, cryptanalysis, steganography, Stream and block ciphers. Modern Block Ciphers:

- Security attacks: Active and passive attacks, eavesdropping, replay attacks, man-in-the-middle attacks, denial of service attacks, software attacks, hardware attacks.
- Services and mechanisms: Authentication, authorization, access control, confidentiality, integrity, non-repudiation.
- Classical encryption techniques:
    - Substitution ciphers: Caesar cipher, monoalphabetic ciphers, homophonic substitution ciphers.
    - Transposition ciphers: Rail fence cipher, route cipher, Scytale cipher.
    - Cryptanalysis: Ciphertext-only attack, known-plaintext attack, chosen-plaintext attack.
    - Steganography: Hiding the existence of a message, using a cover object like an image or audio file.
- Stream ciphers and block ciphers: 
    - Stream ciphers: Combining plaintext with a pseudo-random key stream to produce ciphertext. RC4 is an example.
    - Block ciphers: Encrypt plaintext in fixed-size blocks using a cipher key. Modern block ciphers like AES use substitution-permutation networks.
- Modern block ciphers:
    - Block cipher principles: Confusion and diffusion by Shannon. Substitution-permutation networks in ciphers like AES.
    - Feistel structure: Used in ciphers like DES.
    - Data Encryption Standard (DES): Description, round functions, key schedule.
    - Strength and weaknesses of DES: Small key size, vulnerable to differential cryptanalysis.
    - Modes of operation: ECB, CBC, CFB, OFB, CTR modes to use block ciphers on large data.
    - Triple DES (3DES): Encrypt-decrypt-encrypt using two/three different keys to strengthen DES.

Learning tips:

- Understand the difference between active and passive attacks, confidentiality, integrity and availability.
- Memorize the steps in Feistel structure and working of DES round functions.
- Practice implementing simple substitution ciphers, transposition ciphers and basic cryptanalysis techniques.
- Understand the advantages and disadvantages of different modes of operation for block ciphers.
