## Steganography

Steganography is the technique of hiding secret information within an innocent-looking cover medium in such a way that the existence of the secret message is concealed. This technique is commonly used for covert communication purposes and is often used in conjunction with cryptography for added security.

### Applications of Steganography

- Digital watermarking
- Secret communication
- Copyright protection
- Data hiding

### Techniques of Steganography

- Least Significant Bit (LSB) insertion
- Masking and filtering
- Spread Spectrum
- Transform domain techniques

### Advantages of Steganography

- Hides existence of the message
- Can be used in conjunction with cryptography for added security
- Easy to implement

### Disadvantages of Steganography

- The size of the cover medium must be larger than the size of the message to be hidden
- The technique can be detected and the hidden message can be extracted with the use of steganalysis

### Examples of Steganography

- Hiding a message within an image by manipulating the least significant bits
- Hiding a message within an audio file by modifying the amplitude or frequency of the signal

### Mnemonics for Steganography

- S.T.E.G.O. : Secret Technique for Encoding and Generating Obscurity
