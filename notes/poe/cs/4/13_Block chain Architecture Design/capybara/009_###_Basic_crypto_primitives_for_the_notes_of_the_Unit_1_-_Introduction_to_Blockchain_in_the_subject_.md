### Basic Crypto Primitives for the Notes of the Unit 1 - Introduction to Blockchain in the Subject of Blockchain Architecture Design

In the world of blockchain, cryptography plays a crucial role in ensuring the security and privacy of data. Here are some of the basic crypto primitives you should know about:

1. Hash Functions:
A hash function takes an input (or 'message') and produces a fixed-size output (or 'hash'). It is a one-way function, meaning that it is easy to compute the hash of an input, but it is practically impossible to compute the original input from the hash. Hash functions are used to ensure the integrity of data in a blockchain.

2. Digital Signatures:
A digital signature is the digital equivalent of a handwritten signature. It is generated by using a private key to encrypt a hash of the message being signed. The recipient can then use the corresponding public key to verify the signature and ensure that the message has not been tampered with. Digital signatures are used to ensure the authenticity of data in a blockchain.

3. Symmetric Encryption:
In symmetric encryption, the same key is used for both encryption and decryption. The sender encrypts the message using the key, and the recipient decrypts it using the same key. Symmetric encryption is faster than asymmetric encryption, but it requires the sender and recipient to have access to the same key.

4. Asymmetric Encryption:
In asymmetric encryption, two different keys are used for encryption and decryption. The sender uses the recipient's public key to encrypt the message, and the recipient uses their own private key to decrypt it. Asymmetric encryption is slower than symmetric encryption but is more secure because the private key is never shared.

Mnemonics and Learning Tricks:
- For remembering the properties of hash functions, you can use the mnemonic "HIM": Hash is Irreversible, Message size is fixed, and a small change in the input results in a large change in the output.
- For remembering the difference between symmetric and asymmetric encryption, you can use the mnemonic "SASS": Symmetric uses the Same key for both encryption and decryption, Asymmetric uses different keys for encryption and decryption.

In conclusion, understanding the basic crypto primitives is essential for understanding the security and privacy mechanisms used in blockchain technology. These primitives form the foundation of the security measures used in blockchain architecture design, and they are crucial for maintaining the integrity and authenticity of data on the blockchain.
