## Unit 4 - Hyperledger Fabric (A)

Hyperledger Fabric is a permissioned blockchain platform that is designed for enterprise use cases. In this unit, we will learn about the architecture, components, and features of Hyperledger Fabric.

### Architecture

Hyperledger Fabric has a modular architecture that allows for flexibility and customization. The key components of the architecture are:

- Peer nodes: These nodes maintain the state of the ledger and execute transactions.
- Ordering service: This service orders transactions into blocks and distributes them to peer nodes.
- Membership service provider: This service manages the identities of participants in the network.
- Chaincode: This is the smart contract that defines the business logic of the network.

### Components

The key components of Hyperledger Fabric are:

- Channel: This is a private sub-network of peer nodes that can be used for specific use cases. Different channels can have different sets of participants and rules.
- Chaincode: This is the smart contract that defines the business logic of the network.
- Ledger: This is a record of all transactions that have been executed on the network.
- Membership service provider: This service manages the identities of participants in the network.
- Ordering service: This service orders transactions into blocks and distributes them to peer nodes.
- Peer nodes: These nodes maintain the state of the ledger and execute transactions.

### Features

Hyperledger Fabric has several features that make it suitable for enterprise use cases. Some of the key features are:

- Privacy and confidentiality: Different channels can have different sets of participants and rules, which allows for privacy and confidentiality.
- Modular architecture: The modular architecture of Hyperledger Fabric allows for flexibility and customization.
- Scalability: Hyperledger Fabric can handle thousands of transactions per second.
- Endorsement policy: Transactions can be endorsed by a subset of participants, which allows for more flexibility in the decision-making process.
- Consensus: Hyperledger Fabric uses a pluggable consensus mechanism, which allows for customization.

### Learning Tricks

- Remember the key components of Hyperledger Fabric with the acronym "CC LAMP", where CC stands for Chaincode, L for Ledger, A for Membership Service Provider, M for Ordering Service, and P for Peer nodes.
- Think of channels as private sub-networks that can be used for specific use cases, like different TV channels for different types of content.
