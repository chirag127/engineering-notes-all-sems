### Hyperledger composer tool for the notes of the Unit 5 - Hyperledger Fabric (B) in the subject of Block chain Architecture Design

Hyperledger Composer is a set of collaboration tools for building blockchain business networks that allow business owners and developers to quickly and easily model and deploy blockchain applications. It offers a simple way to define blockchain business networks and a powerful set of capabilities for end-users to interact with the networks.

Some key points about Hyperledger Composer:

- It is a toolset for rapidly developing blockchain applications or solutions. It allows you to create blockchain networks, deploy and test smart contracts and generate REST API clients.
- It provides a Playground environment which allows you to prototype and test interactions with a business network without the need to write any code. The playground can be used to create test identities, submit test transactions, evaluate transactions, and inspect the current state of the network.
- It has a set of command line tools and a Yeoman generator to develop blockchain applications. The Yeoman generator can create skeleton Angular applications that communicate with a business network.
- It defines business networks using a language called the Hyperledger Composer modeling language or `.cto` files. The business networks can then be deployed as Hyperledger Fabric smart contracts.
- It has a REST server that can be used to access a deployed business network and submit transactions to it. The REST server can use a generated Angular/Node.js SDK or a generic REST client.
- Some advantages of using Hyperledger Composer are the faster development of blockchain applications, easy testing and rapid prototyping of solutions. However, it currently only supports Hyperledger Fabric and has limited capabilities compared to directly developing smart contracts. It also generates code that can be hard to maintain or customize.
