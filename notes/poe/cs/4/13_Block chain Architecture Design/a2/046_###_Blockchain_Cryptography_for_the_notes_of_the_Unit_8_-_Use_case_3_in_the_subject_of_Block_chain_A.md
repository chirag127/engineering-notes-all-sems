### Blockchain Cryptography for the notes of the Unit 8 - Use case 3 in the subject of Block chain Architecture Design

- Cryptography is used in Blockchain to secure the data and transactions. The data in Blockchain is secured through cryptography techniques like digital signatures, hash functions, etc.
- Digital Signatures: Digital Signatures are used to authenticate the sender of a transaction and also ensures that the transaction data has not been modified or tampered. Digital Signatures are generated using Private and Public key cryptography. The Sender uses its Private key to sign the transaction and the signature is verified using the Sender's Public key.
- Hash Functions: Hash Functions are used to generate a unique hash value for each block in the Blockchain. The hash of the current block contains the hash of the previous block. This creates an immutable, tamper-evident link between blocks. If any data in a block is modified, the hash of that block and all subsequent blocks will change. This ensures data integrity in Blockchain.
- Mnemonics to remember: Digital Signatures - Authentication & Non-Repudiation, Hash Functions - Data Integrity
- Advantages: Data Security, Data Integrity, Non-Repudiation, Tamper-Evidence
- Disadvantages: Complex algorithms, Require more processing power
- Examples: Bitcoin, Ethereum, etc. use these cryptography techniques
- Applications: Financial Transactions, Smart Contracts, Voting, etc.
