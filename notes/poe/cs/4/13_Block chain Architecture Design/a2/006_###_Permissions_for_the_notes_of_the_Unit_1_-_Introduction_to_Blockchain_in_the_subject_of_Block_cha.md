### Permissions for the notes of the Unit 1 - Introduction to Blockchain in the subject of Block chain Architecture Design

- Read Permission: This permission allows a user to read and access the blockchain data. A user with read permission will not be able to modify or write any data onto the blockchain. This is the most basic permission level.
- Write Permission: This permission allows a user to write data onto the blockchain. A user with write permission will be able to add new blocks to the blockchain. However, they will not be able to modify existing data on the blockchain.
- Admin Permission: This is the highest permission level. A user with admin permission will have full access to the blockchain. They will be able to read, write and modify any data on the blockchain. Admin users will also be able to change the permissions of other users.

Advantages of permissioned blockchains:
- Better scalability as the number of nodes is limited.
- Faster transaction speeds due to limited number of nodes verifying transactions.
- Increased privacy as access is restricted to authorized members only.

Disadvantages of permissioned blockchains:
- Decentralization is limited as access is restricted to authorized members only.
- Single point of failure as the system depends on authorized members/nodes. If they fail or act maliciously, the system is compromised.
- Prone to sybil attacks where a single malicious actor gets control of majority of the nodes.
