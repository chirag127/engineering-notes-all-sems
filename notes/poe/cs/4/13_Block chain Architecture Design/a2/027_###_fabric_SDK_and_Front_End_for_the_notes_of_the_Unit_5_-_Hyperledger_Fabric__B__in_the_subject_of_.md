### Fabric SDK and Front End

- Fabric SDK provides APIs for applications to interact with a Hyperledger Fabric blockchain network. It allows applications to be developed in Node.js, Java, Go, and Python.
- The SDK provides APIs for:
-- Enrolling and managing users.
-- Interacting with channels (joining, updating, leaving).
-- Sending transaction proposals (commercial paper, trade finance, etc.).
-- Querying the ledger.
- The frontend application is used to interact with the blockchain network through the Fabric SDK. It can be a web app, mobile app, or any other type of app.
- The frontend app can:
-- Register and enroll users.
-- Create channels and join peers to channels.
-- Send transaction proposals.
-- Query the state of the ledger.
- Some good mnemonics to learn the Fabric SDK and frontend:
-- SDK = Software Development Kit. It's a set of tools for developing blockchain applications.
-- Enroll = Register. Enrolling and managing users means registering and managing identities.
-- Proposal = Transaction. Sending transaction proposals means sending transactions.
-- Query = Read. Querying the ledger means reading the state of the ledger.
- The advantages of the Fabric SDK and frontend are:
-- They abstract away the complexity of the underlying blockchain network.
-- They allow focusing on the business logic of applications rather than the blockchain infrastructure.
-- They provide a consistent set of APIs across different languages.
- The disadvantages are:
-- There is a learning curve to understand how the SDK works and interacts with the blockchain network.
-- The SDK has to be kept up-to-date with the evolution of the Hyperledger Fabric platform.
