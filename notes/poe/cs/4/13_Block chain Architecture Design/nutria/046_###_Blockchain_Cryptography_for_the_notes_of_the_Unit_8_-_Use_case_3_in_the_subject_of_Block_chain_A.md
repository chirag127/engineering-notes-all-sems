
### Blockchain Cryptography for the Notes of the Unit 8 - Use Case 3 in the Subject of Block Chain Architecture Design

* Blockchain cryptography is a type of cryptography used to secure and verify transactions in a blockchain network. It is based on the principles of public-key cryptography and is used to ensure that only the intended recipient can access the data stored in the blockchain. 
* Blockchain cryptography uses a combination of public and private keys to authenticate and verify transactions. The public key is used to encrypt the data, while the private key is used to decrypt it. 
* Blockchain cryptography is used in distributed ledger technology (DLT) to ensure the integrity and security of the data stored in the blockchain. It also helps to prevent double spending and other fraudulent activities. 
* Blockchain cryptography can also be used to create digital signatures, which are used to verify the authenticity of transactions. 
* By using blockchain cryptography, nodes in the network can trust each other and the data stored in the blockchain is secure. 
* Mnemonics and learning tricks for this topic include: 
    * P - Public key is used to encrypt data
    * R - Private key is used to decrypt data
    * D - Distributed ledger technology (DLT) is used to ensure data integrity
    * S - Digital signatures are used to verify authenticity of transactions
    * T - Trust between nodes is established through blockchain cryptography
