
## Unit 7 - Use Case 2

This unit covers the concept of use cases and their application in software development. A use case is a description of a system's behavior as it responds to a request from one of its users. It describes the user's goal, the sequence of steps the user needs to take to achieve the goal, and any alternative paths that may be taken.

### Mnemonics and Learning Tricks

* **U**se **C**ases **A**re **S**pecific **E**xamples: Use the acronym "UCASE" to remember that use cases are specific examples of how a system can respond to a user's request.
* **A**lternative **P**aths: Remember that use cases can have alternative paths that the user may take to achieve their goal.
* **E**xpect **R**esults: Remember that use cases are designed to achieve a specific result.

### Advantages

* Use cases provide a structured way to think about the behavior of a system.
* Use cases can be used to identify and document the requirements of a system.
* Use cases can be used to generate test cases for a system.

### Disadvantages

* Use cases can be difficult to create for complex systems.
* Use cases can be difficult to maintain as the system evolves.
* Use cases can be difficult to understand for non-technical stakeholders.

### Examples

* An online shopping system may have a use case for placing an order.
* An online banking system may have a use case for transferring funds.
* An online ticketing system may have a use case for purchasing tickets.

### Applications

* Use cases can be used to identify and document the requirements of a system.
* Use cases can be used to generate test cases for a system.
* Use cases can be used to generate user stories for a system.
* Use cases can be used to generate user interface designs for a system.
