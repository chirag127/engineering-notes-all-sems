
### Basic Crypto Primitives for the Notes of the Unit 1 - Introduction to Blockchain in the Subject of Blockchain Architecture Design

* Cryptographic hash functions: Hash functions are mathematical algorithms that take an input of any length and produce an output of a fixed length. They are used to securely store data and verify its integrity. The output of a hash function is known as a "hash" or "message digest".

* Digital signatures: Digital signatures are used to authenticate the identity of the sender of a message or document. They are created using public key cryptography and are used to prove that the message was sent by the sender and not modified in transit.

* Public key cryptography: Public key cryptography is a system in which two different keys are used to encrypt and decrypt data. The public key is used to encrypt data, and the private key is used to decrypt it.

* Symmetric key cryptography: Symmetric key cryptography is a system in which the same key is used to both encrypt and decrypt data. It is generally faster and more secure than public key cryptography.

* Mnemonics: Mnemonics are memory aids that help people remember information. For example, the mnemonic "Every Good Boy Does Fine" is used to remember the notes on a musical staff (EGBDF). Mnemonics can be used to remember cryptographic primitives such as hash functions, digital signatures, and public and symmetric key cryptography.

* Merkle trees: Merkle trees are data structures used to store and verify large amounts of data. They are used in blockchain technology to store and verify transactions. A Merkle tree consists of a series of hashes, each of which is the hash of two other hashes. The root of the tree is the hash of all the data in the tree.
