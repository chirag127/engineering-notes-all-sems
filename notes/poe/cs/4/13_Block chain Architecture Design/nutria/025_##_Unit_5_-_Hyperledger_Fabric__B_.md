
## Unit 5 - Hyperledger Fabric (B)

Hyperledger Fabric is an open-source distributed ledger technology (DLT) platform, designed for use in enterprise contexts, that delivers a uniquely modular and extensible architecture, enabling components such as consensus and membership services to be plug-and-play. It leverages container technology to host smart contracts called “chaincode” that comprise the application logic of the system.

Mnemonic: **FABRIC** - **F**or **A**dvanced **B**lockchain **R**ecord **I**nterchange **C**apabilities

**Key Features of Hyperledger Fabric**

- **Decentralized Control:** Hyperledger Fabric provides a decentralized control, meaning that no single entity has control over the network. This helps to ensure that the network remains secure and reliable.

- **Permissioned Network:** Hyperledger Fabric is a permissioned network, meaning that only authorized participants can join the network and access the data stored on it.

- **Privacy and Confidentiality:** Hyperledger Fabric provides privacy and confidentiality features that allow participants to share data securely and privately.

- **Flexible Consensus:** Hyperledger Fabric provides a flexible consensus mechanism that can be tailored to the needs of the network.

- **Modular Architecture:** Hyperledger Fabric has a modular architecture that allows for components such as consensus and membership services to be plug-and-play.

- **Smart Contracts:** Hyperledger Fabric supports smart contracts, which are programs that can execute transactions on the network.

- **Scalability:** Hyperledger Fabric is designed to be highly scalable, allowing it to support large networks with millions of transactions.
