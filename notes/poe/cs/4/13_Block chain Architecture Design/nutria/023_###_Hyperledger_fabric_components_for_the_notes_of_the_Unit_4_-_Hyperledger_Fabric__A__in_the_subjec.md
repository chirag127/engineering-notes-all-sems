
### Hyperledger fabric components for the notes of the Unit 4 - Hyperledger Fabric (A) in the subject of Block chain Architecture Design

Hyperledger Fabric is an open source distributed ledger technology (DLT) developed under the Linux Foundation's Hyperledger project. It is a platform for distributed ledger solutions, offering modular architecture with a variety of components that can be used to develop solutions for a range of use cases.

The main components of Hyperledger Fabric are: 

- **Peer nodes**: These nodes store and execute the smart contracts and maintain the ledger. They are also responsible for validating transactions and maintaining the state of the ledger.

- **Orderer nodes**: These nodes are responsible for ordering transactions and broadcasting them to the peers.

- **Consensus algorithm**: This algorithm is used to ensure that all peers agree on the state of the ledger.

- **Membership services**: This component is responsible for managing the identities of the participants in the network.

- **Smart contracts**: These are computer programs that execute transactions on the ledger.

- **Channels**: These are private communication channels that allow participants to communicate securely with each other.

- **Chaincode**: This is the code that is used to execute transactions on the ledger.

In addition to these components, Hyperledger Fabric also provides a number of tools and frameworks to help developers create applications on top of the platform. These include the Hyperledger Composer, an open source development framework for building blockchain applications, and the Hyperledger Explorer, a web-based blockchain explorer.

Mnemonics and learning tricks: 

- Peer nodes: PEERs (Process, Execute, Evaluate, and Record). 
- Orderer nodes: ORDER (Order, Record, Distribute, and Execute). 
- Consensus algorithm: CONSENSUS (Confirm, Order, Negotiate, Secure, Execute, Negotiate, Update, and Secure). 
- Membership services: MEMBERSHIP (Manage, Enroll, Monitor, Bind, Exchange, Register, Secure, and Protect). 
- Smart contracts: SMART (Secure, Monitor, Automate, Record, and Track). 
- Channels: CHANNELS (Communicate, Hide, Authenticate, Negotiate, Network, Lock, Exchange, and Secure). 
- Chaincode: CHAINCODE (Compile, Handle, Activate, Invoke, Network, Compile, Operate, and Execute).
