
### Hash for the notes of the Unit 1 - Introduction to Blockchain in the subject of Block chain Architecture Design

Hash is an important concept in blockchain technology. It is a cryptographic function that takes an input of any length and produces a fixed-length output. The output is called a hash value, or simply a hash. 

A hash is used to represent a large amount of data in a single, smaller value. It is used to store and retrieve data from a blockchain. A hash is also used to verify the integrity of the data stored in the blockchain.

Mnemonic: Hashing is like a fingerprint for data.

Learning Trick: Remember that a hash is a cryptographic function that takes an input of any length and produces a fixed-length output.

Hash functions are typically used in blockchain applications to store and retrieve data from the blockchain. They are also used to verify the integrity of the data stored in the blockchain. Hash functions are one-way functions, meaning that it is not possible to reverse the hash to obtain the original data.

Advantages: 
- Hash functions are secure and reliable. 
- They are computationally efficient. 
- They are used to verify the integrity of data stored in the blockchain. 

Disadvantages: 
- Hash functions are not reversible. 
- They are vulnerable to collision attacks. 
- They are vulnerable to preimage attacks.
