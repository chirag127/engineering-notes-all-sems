
### Consensus for the notes of the Unit 1 - Introduction to Blockchain in the subject of Block chain Architecture Design

Consensus is a fundamental concept in blockchain architecture design. It is a process by which all participants in a distributed system agree on the same set of data. In a blockchain system, this process is used to ensure that all nodes in the network have the same copy of the ledger.

Consensus algorithms are used to reach agreement among nodes in a distributed system. The most common consensus algorithms used in blockchain are Proof of Work (PoW), Proof of Stake (PoS), and Delegated Proof of Stake (DPoS).

Proof of Work (PoW) is the most widely used consensus algorithm. It involves miners competing to solve a cryptographic puzzle. The first miner to solve the puzzle is rewarded with a block reward. This algorithm is used by Bitcoin and Ethereum.

Proof of Stake (PoS) is a consensus algorithm that requires users to stake their coins in order to participate in the network. This algorithm is used by Dash and NEO.

Delegated Proof of Stake (DPoS) is a consensus algorithm that requires users to vote for a set of delegates who are responsible for validating transactions. This algorithm is used by EOS and Steem.
