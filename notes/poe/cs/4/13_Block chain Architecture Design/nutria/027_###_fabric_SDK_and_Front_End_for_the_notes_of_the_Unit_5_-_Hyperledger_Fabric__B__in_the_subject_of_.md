

### Fabric SDK and Front End for the Notes of the Unit 5 - Hyperledger Fabric (B) in the Subject of Blockchain Architecture Design

* Hyperledger Fabric (B) is an open source platform for developing distributed ledger applications and networks. It is designed to support highly secure, confidential and distributed applications.
* The Fabric SDK is a set of tools and libraries for developing applications on the Hyperledger Fabric platform. It provides a set of APIs, libraries and tools to help developers create, deploy and manage applications on the platform.
* The Fabric Front End is a web-based application that provides a graphical user interface (GUI) for users to interact with the Fabric network. It allows users to view and manage transactions, view ledger data, and submit transactions to the network.
* Fabric provides a set of mnemonics and learning tricks to help developers better understand the platform and its components. These include:
  * **T**ransactions: Transactions are the basic unit of work in Fabric. They are used to create, update, and delete data in the ledger.
  * **C**ontracts: Contracts are programs written in the Fabric programming language that define the logic for processing transactions.
  * **P**eers: Peers are nodes on the network that store and process transactions.
  * **C**hannels: Channels are communication pathways between peers on the network.
  * **C**onsensus: Consensus is a process by which peers on the network agree on the validity of transactions.
  * **A**pplication: Applications are programs written in the Fabric programming language that define the logic for processing transactions.
  * **S**mart contracts: Smart contracts are programs written in the Fabric programming language that define the logic for processing transactions.
* Fabric also provides a set of tools and libraries for developing applications on the platform. These include:
  * **L**ibraries: Libraries provide a set of APIs and tools for developing applications on the platform.
  * **C**ommand Line Interface (CLI): The CLI provides a set of commands for managing and deploying applications on the platform.
  * **D**evelopment Tools: Development tools provide a set of tools for developing, testing, and deploying applications on the platform.
  * **D**ebugging Tools: Debugging tools provide a set of tools for debugging applications on the platform.
* Fabric also provides a set of security features to protect the network and its applications. These include:
  * **E**ncryption: Encryption is used to protect data stored on the network.
  * **A**uthentication: Authentication is used to verify the identity of users on the network.
  * **A**ccess Control: Access control is used to restrict access to data and resources on the network.
  * **M**onitoring: Monitoring is used to detect and respond to malicious activity on the network.
