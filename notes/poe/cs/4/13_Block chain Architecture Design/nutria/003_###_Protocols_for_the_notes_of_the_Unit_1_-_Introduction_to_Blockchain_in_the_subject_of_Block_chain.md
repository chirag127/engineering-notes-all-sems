
### Protocols for the notes of the Unit 1 - Introduction to Blockchain in the subject of Block chain Architecture Design

1. Proof-of-Work (PoW): PoW is a consensus algorithm used by Bitcoin and other cryptocurrencies. It requires miners to solve complex mathematical problems in order to add a new block to the blockchain. The miner who solves the problem first is rewarded with a certain amount of cryptocurrency.

2. Proof-of-Stake (PoS): PoS is a consensus algorithm that is similar to PoW, but instead of miners competing to solve mathematical problems, they are competing to own a certain amount of cryptocurrency. The more cryptocurrency they own, the more likely they are to be chosen to add the next block to the blockchain.

3. Delegated Proof-of-Stake (DPoS): DPoS is a consensus algorithm that is similar to PoS, but instead of miners competing to own a certain amount of cryptocurrency, they are competing to be elected as a delegate. The delegates are responsible for validating transactions and adding blocks to the blockchain.

4. Byzantine Fault Tolerance (BFT): BFT is a consensus algorithm that is used in permissioned blockchains. It requires a certain number of nodes to agree on a transaction before it is added to the blockchain. This ensures that the blockchain is not vulnerable to malicious actors.

5. Practical Byzantine Fault Tolerance (PBFT): PBFT is a consensus algorithm that is similar to BFT, but it is more efficient and can handle larger networks. It requires a certain number of nodes to agree on a transaction before it is added to the blockchain.

Mnemonics and Learning Tricks:

- PoW: "Proof-of-Work - Solve Problems to Win Cryptocurrency" 
- PoS: "Proof-of-Stake - Own Cryptocurrency to Win" 
- DPoS: "Delegated Proof-of-Stake - Elect Delegates to Validate Transactions" 
- BFT: "Byzantine Fault Tolerance - Require Nodes to Agree on Transactions" 
- PBFT: "Practical Byzantine Fault Tolerance - More Efficient and Can Handle Larger Networks"
