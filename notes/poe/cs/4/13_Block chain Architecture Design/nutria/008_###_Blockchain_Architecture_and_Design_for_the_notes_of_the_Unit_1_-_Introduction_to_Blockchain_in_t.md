
### Blockchain Architecture and Design for the Notes of the Unit 1 - Introduction to Blockchain in the Subject of Blockchain Architecture Design

1. Blockchain is a distributed, decentralized, public ledger that stores data in a secure and immutable way.
2. It is composed of blocks, which are timestamped batches of recent valid transactions.
3. Each block contains a cryptographic hash of the previous block, a timestamp, and transaction data.
4. This chain of blocks is shared between all participating nodes in the network and is constantly updated with new blocks.
5. The ledger is secured using a consensus mechanism, such as Proof of Work (PoW) or Proof of Stake (PoS).
6. This consensus mechanism ensures that all nodes in the network agree on the state of the ledger.
7. The ledger is immutable, meaning that once a transaction is added to the ledger, it cannot be changed or reversed.
8. The ledger is transparent, meaning that all transactions are visible to all participating nodes in the network.
9. Blockchain technology can be used to create secure and efficient systems for data storage and transfer, such as cryptocurrency and smart contracts.
10. Mnemonic: Blockchain = Distributed + Decentralized + Secure + Immutable + Transparent.
