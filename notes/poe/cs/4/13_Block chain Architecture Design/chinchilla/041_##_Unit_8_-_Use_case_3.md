## Unit 8 - Use case 3

Use case 3 is a software engineering technique used to capture and document the functional requirements of a system. It is a powerful tool for understanding how a system will be used by its users and stakeholders. In this unit, we will explore the key concepts and techniques of use case modeling.

### Key Concepts

The following are the key concepts associated with use case modeling:

- Actor: An actor is a role played by a person or system that interacts with the system being modeled.
- Use Case: A use case is a sequence of actions performed by the system to achieve a specific goal for an actor.
- System Boundary: The system boundary defines the scope of the system being modeled and the actors that interact with it.
- Scenario: A scenario is a specific instance of a use case that describes a particular sequence of events.

### Techniques

The following techniques are used in use case modeling:

- Use Case Diagrams: A use case diagram is a graphical representation of the system being modeled, its actors, and the use cases that describe the system's functionality.
- Use Case Descriptions: A use case description is a textual description of the steps required to achieve the goal of a use case.
- Activity Diagrams: An activity diagram is a graphical representation of the steps required to achieve the goal of a use case.

### Advantages

The following are the advantages of use case modeling:

- Use case modeling is an effective way to capture and document the functional requirements of a system.
- Use case modeling helps to identify and clarify the roles of the actors interacting with the system.
- Use case modeling helps to identify and clarify the goals that the system must achieve.

### Disadvantages

The following are the disadvantages of use case modeling:

- Use case modeling can be time-consuming and expensive to develop.
- Use case modeling can be difficult to maintain and update as the system evolves.

### Examples

The following are some examples of use case modeling:

- Online Shopping System: A use case for an online shopping system might include the following actors: Customer, Administrator, and Payment Gateway. The use cases might include Browse Products, Add to Cart, Checkout, and Pay.
- ATM System: A use case for an ATM system might include the following actors: Customer and Bank. The use cases might include Withdraw Cash, Deposit Cash, and Check Balance.

### Applications

The following are some applications of use case modeling:

- Software Development: Use case modeling is commonly used in software development to capture and document the functional requirements of a system.
- Business Analysis: Use case modeling is used in business analysis to understand the goals and objectives of a business system and to identify the roles of the actors interacting with the system.
- System Design: Use case modeling is used in system design to define the system's functionality and to identify the components required to achieve that functionality.

### Mnemonics and Learning Tricks

- One learning trick for use case modeling is to focus on the actors and their goals. By understanding the goals of the actors, you can better understand the use cases required to achieve those goals.
- Another learning trick is to use diagrams and visual aids to help you understand the system being modeled. Use case diagrams and activity diagrams can help to clarify the steps required to achieve the goals of a use case.
