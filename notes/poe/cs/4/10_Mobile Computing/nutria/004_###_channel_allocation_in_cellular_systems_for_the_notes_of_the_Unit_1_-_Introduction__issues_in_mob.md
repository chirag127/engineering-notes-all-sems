
### Channel Allocation in Cellular Systems for the Notes of the Unit 1 - Introduction, Issues in Mobile Computing, Overview of Wireless Telephony: Cellular Concept, GSM:

Channel allocation in cellular systems is the process of assigning channels to different users within a cellular network. It is an important part of mobile communication and is used to ensure that the network is able to provide adequate coverage and capacity.

The most common channel allocation technique used in cellular systems is Frequency Division Multiple Access (FDMA). In this technique, different frequencies are allocated to different users. This technique is used in GSM networks.

Another channel allocation technique used in cellular systems is Time Division Multiple Access (TDMA). In this technique, each user is assigned a time slot in which they can transmit data. This technique is used in CDMA networks.

In addition to FDMA and TDMA, there are other channel allocation techniques such as Code Division Multiple Access (CDMA) and Orthogonal Frequency Division Multiple Access (OFDMA).

Mnemonics:

FDMA - Frequency Division Multiple Access

TDMA - Time Division Multiple Access

CDMA - Code Division Multiple Access

OFDMA - Orthogonal Frequency Division Multiple Access

Advantages:

- Allows for efficient use of spectrum resources
- Allows for better coverage and capacity
- Can be used to provide better quality of service

Disadvantages:

- Can be complex to implement
- Requires careful planning and management
- Can be expensive to implement

Examples:

- GSM networks use FDMA for channel allocation
- CDMA networks use TDMA for channel allocation
- OFDMA is used in LTE networks

Applications:

- Channel allocation is used in cellular networks to provide better coverage and capacity
- It is also used in satellite communication systems to provide better coverage and capacity
- It is used in wireless local area networks (WLANs) to provide better coverage and capacity
