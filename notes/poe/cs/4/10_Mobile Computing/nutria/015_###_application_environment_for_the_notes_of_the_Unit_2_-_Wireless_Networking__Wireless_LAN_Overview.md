
### Application Environment for the Notes of the Unit 2 - Wireless Networking, Wireless LAN Overview: MAC Issues, IEEE 802.11, Blue Tooth, Wireless in the Subject of Mobile Computing

1. **MAC Issues**: Media Access Control (MAC) is an essential part of wireless networking. It is a set of rules that govern the way devices interact with each other on a wireless network. The MAC layer is responsible for controlling the access to the wireless medium. It is responsible for ensuring that only one device at a time is transmitting data, and that all devices receive the data they need.

2. **IEEE 802.11**: IEEE 802.11 is a set of standards that define how wireless networks operate. It defines the physical and data link layers of the OSI model. The 802.11 standard defines the physical layer, which is the physical medium used for wireless communication, as well as the data link layer, which is responsible for establishing and maintaining connections between devices.

3. **Blue Tooth**: Bluetooth is a wireless technology that allows devices to communicate with each other over short distances. It is a popular technology used in mobile phones, laptops, and other wireless devices. It operates in the 2.4 GHz frequency range and is capable of transmitting data at speeds up to 3 Mbps.

4. **Wireless in Mobile Computing**: Wireless networks are becoming increasingly popular in mobile computing. They allow users to access the internet on the go, without having to be connected to a physical network. Wireless networks also enable users to share data and applications with each other, as well as access applications and services from remote locations.
