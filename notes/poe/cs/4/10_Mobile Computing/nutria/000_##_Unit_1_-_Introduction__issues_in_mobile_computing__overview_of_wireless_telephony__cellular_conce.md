
## Unit 1 - Introduction, issues in mobile computing, overview of wireless telephony: cellular concept, GSM:

1. Mobile Computing: Mobile computing is a technology that allows transmission of data, voice and video via a computer or any other wireless enabled device without having to be connected to a fixed physical link. 
2. Issues in Mobile Computing: Issues in mobile computing include battery life, security, data privacy, scalability, and network availability.
3. Overview of Wireless Telephony: Wireless telephony is the transmission of telephone calls and other forms of communication over a wireless network. It is commonly used in cellular phones, pagers, and other two-way radio systems.
4. Cellular Concept: Cellular concept is a system wherein the communication network is divided into smaller areas or cells. Each cell is served by a base station that transmits and receives signals from the user's device.
5. GSM: GSM (Global System for Mobile Communications) is a digital cellular network that is widely used in Europe and other parts of the world. It is a second-generation (2G) mobile phone system that supports data services such as SMS and MMS, as well as voice calls. GSM networks use time division multiple access (TDMA) technology to divide the radio spectrum into multiple time slots. 

Mnemonic: GSM stands for Global System for Mobile Communications. 
Learning Trick: To remember the different components of GSM, think of the acronym GSM as an acronym for “G”eneral “S”ystem for “M”obile Communications.
