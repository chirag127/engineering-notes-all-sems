
### TCP over Wireless for the Notes of the Unit 2 - Wireless Networking, Wireless LAN Overview: MAC Issues, IEEE 802.11, Bluetooth, Wireless in the Subject of Mobile Computing

- **TCP over Wireless** is a communication protocol that allows for the transmission of data over wireless networks. It is an important component of mobile computing, as it allows for the transfer of data between devices without the need for physical cables.

- **MAC Issues**: Media Access Control (MAC) is an important component of wireless networks. It is responsible for controlling access to the network and ensuring that only authorized users can access the network.

- **IEEE 802.11**: IEEE 802.11 is a set of standards that define the physical layer, data link layer, and management layer of wireless networks. It is the most widely used wireless networking standard and is used in most Wi-Fi networks.

- **Bluetooth**: Bluetooth is a wireless protocol that allows for the transfer of data between devices. It is widely used in mobile devices such as smartphones and tablets, and is also used in some wireless peripherals such as mice and keyboards.

- **Wireless in Mobile Computing**: Wireless networks are an important component of mobile computing. They allow for the transfer of data between devices without the need for physical cables, making them ideal for mobile applications.

- **Mnemonics and Learning Tricks**: Mnemonics can be a useful tool for learning and remembering key concepts. For example, the acronym "TCP" can be used to remember the key components of the TCP protocol: Transmission Control Protocol.
