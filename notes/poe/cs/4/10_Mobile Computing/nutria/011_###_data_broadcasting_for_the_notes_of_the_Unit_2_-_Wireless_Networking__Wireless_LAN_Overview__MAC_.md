
# Data Broadcasting for the Notes of the Unit 2 - Wireless Networking, Wireless LAN Overview: MAC Issues, IEEE 802.11, Blue Tooth, Wireless in the Subject of Mobile Computing

Data broadcasting is the transmission of data over a network to multiple recipients. It is a method of communication used in wireless networking, where data is broadcasted over a wide area, allowing multiple users to receive the data simultaneously. 

In this unit, we will discuss the following topics related to data broadcasting: 

* MAC Issues 
* IEEE 802.11 
* Blue Tooth 
* Wireless 

## MAC Issues 

Media Access Control (MAC) is a protocol used in data broadcasting to control the access of data to multiple recipients. It allows the network to identify which recipients should be allowed to access the data. MAC works by assigning a unique identifier to each recipient, which is then used to identify the recipient when broadcasting data.

## IEEE 802.11

The IEEE 802.11 standard is a set of standards for wireless networking. It is used to define the physical layer, data link layer, and MAC layer protocols for wireless networking. It is the most commonly used protocol for data broadcasting. 

## Blue Tooth 

Bluetooth is a short-range wireless communication protocol used for data broadcasting. It is used to transfer data between two devices in close proximity. Bluetooth is commonly used for transferring data between mobile devices, such as smartphones and tablets. 

## Wireless 

Wireless is a term used to describe any type of communication that does not require a physical connection. Wireless networks use radio waves to transmit data, allowing users to access data without the need for a physical connection. Wireless networks are commonly used for data broadcasting. 

Mnemonic:
