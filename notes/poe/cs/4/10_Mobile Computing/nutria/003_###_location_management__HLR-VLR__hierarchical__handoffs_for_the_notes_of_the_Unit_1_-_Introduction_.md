
### Location Management: HLR-VLR, Hierarchical, Handoffs for the Notes of the Unit 1 - Introduction, Issues in Mobile Computing, Overview of Wireless Telephony: Cellular Concept, GSM

Location management is an important concept in mobile computing and wireless telephony, as it is responsible for the efficient routing of calls and data packets to and from mobile devices. In order to understand how location management works, it is important to understand the concepts of Home Location Register (HLR) and Visitor Location Register (VLR).

**Home Location Register (HLR)**

The Home Location Register (HLR) is a centralized database that stores information about a mobile user's subscription and the services they are authorized to use. This information includes the mobile subscriber's phone number, their current location, and the services they are subscribed to. The HLR is responsible for providing the VLR with the necessary information about a given mobile user in order for the VLR to properly route calls and data packets to the mobile user.

**Visitor Location Register (VLR)**

The Visitor Location Register (VLR) is a database that stores information about the current location of a mobile user. This information includes the mobile user's phone number, current location, and the services they are subscribed to. The VLR is responsible for routing calls and data packets to the mobile user's current location.

**Hierarchical Location Management**

Hierarchical location management is a method of location management that is used to efficiently route calls and data packets to and from mobile users. This method involves the use of multiple levels of databases, such as the HLR and VLR, in order to efficiently route calls and data packets to the mobile user's current location.

**Handoffs**

Handoffs are a type of location management that occur when a mobile user moves from one cell to another. Handoffs are necessary in order to ensure that calls and data packets are routed to the mobile user's current location. Handoffs are managed by the HLR and VLR, which are responsible for providing the necessary information about a mobile user's current location in order for the handoff to be successful.

**Overview of Wireless Telephony: Cellular Concept, GSM**

Wireless telephony is the use of wireless technology to transmit voice or data over a distance. The most common type of wireless telephony is cellular technology, which is used by mobile phones and other wireless devices. Cellular technology is based on the concept of cells, which are small geographic areas that are covered by a single radio transmitter. Each transmitter is connected to a base station, which is responsible for routing calls and data packets to and from the cell. The most commonly used cellular technology is Global System for Mobile Communications (GSM), which is used by most mobile networks around the world.
