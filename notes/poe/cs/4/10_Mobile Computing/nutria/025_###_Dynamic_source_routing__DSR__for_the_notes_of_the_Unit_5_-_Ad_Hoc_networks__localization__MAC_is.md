
### Dynamic Source Routing (DSR)
Dynamic Source Routing (DSR) is a routing protocol used in mobile ad hoc networks (MANETs). It is a reactive routing protocol, meaning that it only establishes a route between two nodes when it is required. The protocol uses source routing, meaning that each node in the network must have knowledge of the route from the source to the destination. 

#### Features of DSR
- DSR is a simple and efficient routing protocol that can be used in both unicast and multicast routing. 
- It uses source routing instead of traditional routing tables, which reduces the amount of control traffic in the network. 
- DSR is a reactive protocol, meaning that it only establishes a route when it is needed. 
- DSR is capable of finding multiple routes between two nodes, which increases the robustness of the network. 
- DSR can be used in a variety of environments, including wireless, mobile, and ad hoc networks.

#### Advantages of DSR
- DSR is a simple and efficient routing protocol. 
- It requires less control traffic in the network, which reduces the amount of bandwidth used. 
- DSR is capable of finding multiple routes between two nodes, which increases the robustness of the network. 
- DSR can be used in a variety of environments, including wireless, mobile, and ad hoc networks.

#### Disadvantages of DSR
- DSR is a reactive protocol, meaning that it only establishes a route when it is needed. This can lead to delays in communication. 
- DSR is vulnerable to routing loops, which can cause packets to be routed in a loop and never reach their destination. 
- DSR is vulnerable to malicious nodes, as they can send false routing information. 
- DSR is not suitable for large networks, as the amount of control traffic increases with the size of the network.
