
### Destination sequenced distance vector routing (DSDV) for the notes of the Unit 5 - Ad Hoc networks, localization, MAC issues, Routing protocols, global state routing (GSR), in the subject of Mobile Computing

Destination sequenced distance vector routing (DSDV) is a routing protocol for mobile ad hoc networks (MANETs). It was developed by Charles E. Perkins in 1994. It is a table-driven routing protocol, meaning that it keeps track of the routes in a table and updates it periodically.

DSDV works by having each node in the network broadcast its routing table to its neighbors periodically. Each node's routing table contains the cost of each route to each destination and a sequence number that is assigned by the destination itself. This sequence number is used to determine which route is the most up-to-date.

The main advantage of DSDV is that it is loop-free, meaning that it does not create loops in the network. It also works well in a highly dynamic environment, where nodes are frequently joining and leaving the network.

One of the main disadvantages of DSDV is that it is not very efficient. Because it broadcasts its routing table to its neighbors periodically, it can generate a lot of traffic in the network. This can lead to congestion and slow down the network.

DSDV is used in a variety of applications, including military, emergency response, and vehicular networks. It is also used in some wireless sensor networks.

Mnemonics and learning tricks:
- DSDV: Destination Sequenced Distance Vector Routing 
- MANETs: Mobile Ad Hoc Networks 
- Table-driven: Keeps track of routes in a table 
- Sequence Number: Used to determine which route is most up-to-date 
- Loop-free: Does not create loops in the network 
- Highly Dynamic: Nodes frequently joining and leaving the network 
- Not Efficient: Generates a lot of traffic in the network
