

### QoS in Ad Hoc Networks

Quality of Service (QoS) in Ad Hoc Networks is a set of techniques used to guarantee the delivery of data packets over a wireless network. QoS techniques are used to ensure that data packets are delivered in a timely manner and with minimal packet loss. QoS techniques are also used to prioritize certain types of traffic, such as video and audio, over other types of traffic.

QoS techniques used in Ad Hoc Networks include:

- MAC Issues: Medium Access Control (MAC) protocols are used to control access to the wireless network. MAC protocols are used to ensure that only authorized users are allowed access to the network and to ensure that data packets are sent in an orderly manner.

- Localization: Localization techniques are used to determine the location of nodes in the network. This information is used to route data packets efficiently.

- Routing Protocols: Routing protocols are used to determine the best path for data packets to travel from source to destination. Routing protocols are used to ensure that data packets are delivered in a timely manner and with minimal packet loss.

- Global State Routing (GSR): Global State Routing (GSR) is a routing protocol used in Ad Hoc Networks. GSR is used to determine the best path for data packets to travel from source to destination. GSR is used to ensure that data packets are delivered in a timely manner and with minimal packet loss.

- LOC: Location
- ROU: Routing
- GSR: Global State Routing
