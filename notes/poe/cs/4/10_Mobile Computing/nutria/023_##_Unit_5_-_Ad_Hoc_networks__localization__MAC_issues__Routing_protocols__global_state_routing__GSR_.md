
## Unit 5 - Ad Hoc Networks, Localization, MAC Issues, Routing Protocols, Global State Routing (GSR)

Ad Hoc networks are decentralized wireless networks that do not rely on any infrastructure or centralized access points. They are self-organizing and self-configuring, and are designed to be used in situations where a wired network is not available or is not practical.

Localization is the process of determining the location of a node in an Ad Hoc network. Localization algorithms use a variety of techniques such as triangulation, time-of-flight, and signal strength to determine the location of a node.

MAC (Media Access Control) issues in Ad Hoc networks are related to the methods used to control access to the shared medium (e.g., the radio channel). The MAC layer is responsible for determining when a node can transmit, and for resolving collisions when two nodes attempt to transmit at the same time.

Routing protocols are used to determine the paths that data will take from one node to another. In Ad Hoc networks, routing protocols must be able to adapt to changes in the network topology, and must be able to route around failed nodes.

Global State Routing (GSR) is a type of routing protocol that uses a global view of the network to determine the best paths for data. GSR is based on the idea that each node in the network maintains an up-to-date view of the entire network, and uses this view to determine the best paths for data. GSR is well-suited for Ad Hoc networks, as it can quickly adapt to changes in the network topology.
