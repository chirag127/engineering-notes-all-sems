### Protocol Stack for the Notes of the Unit 2 - Wireless Networking, Wireless LAN Overview: MAC issues, IEEE 802.11, Blue Tooth, Wireless in the Subject of Mobile Computing

In wireless networking, a protocol stack refers to a set of protocols that work together to provide wireless communication. The protocol stack consists of various layers, each of which performs specific functions. The following are the layers of the protocol stack for the notes of the Unit 2 - Wireless Networking, Wireless LAN Overview: MAC issues, IEEE 802.11, Bluetooth, Wireless in the subject of Mobile Computing:

1. Application Layer: This is the topmost layer of the protocol stack and is responsible for providing user applications with access to the network. The application layer is responsible for managing data communication between applications and the network.

2. Presentation Layer: This layer is responsible for data representation and encoding. It converts data into a format that can be transmitted over the network.

3. Session Layer: This layer is responsible for managing communication sessions between devices. It is responsible for setting up, maintaining, and tearing down communication sessions between devices.

4. Transport Layer: This layer is responsible for end-to-end communication between devices. It ensures that data is transmitted reliably and without errors.

5. Network Layer: This layer is responsible for routing data between different networks. It determines the best path for data transmission and ensures that data is transmitted efficiently.

6. Data Link Layer: This layer is responsible for managing communication between devices on the same network. It is responsible for detecting and correcting errors in data transmission and managing access to the network.

7. Physical Layer: This layer is responsible for transmitting data over the physical medium. It is responsible for converting data into signals that can be transmitted over the physical medium.
