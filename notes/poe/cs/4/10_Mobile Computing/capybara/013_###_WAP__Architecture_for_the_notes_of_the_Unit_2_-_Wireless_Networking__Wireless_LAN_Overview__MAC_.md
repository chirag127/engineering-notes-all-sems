### WAP: Architecture for the notes of the Unit 2 - Wireless Networking, Wireless LAN Overview: MAC issues, IEEE 802.11, Blue Tooth, Wireless in the subject of Mobile Computing

Wireless Application Protocol (WAP) is a technical standard for accessing information over a mobile wireless network. WAP is designed to work with multiple wireless technologies, including Wireless LAN (WLAN). In this section, we will discuss the architecture of WAP and its relationship with wireless LAN, MAC issues, IEEE 802.11, Bluetooth, and wireless networks in the subject of Mobile Computing.

#### WAP Architecture

WAP architecture consists of five layers: 

1. Wireless Application Environment (WAE) - This layer defines the application framework for WAP. It includes the markup languages, scripting languages, and APIs used to create WAP applications.
2. Wireless Session Protocol (WSP) - This layer provides reliable data transfer between the client and server. It uses the Wireless Transaction Protocol (WTP) to handle packet fragmentation and reassembly.
3. Wireless Transaction Protocol (WTP) - This layer provides transaction-oriented transport services to WSP. It handles packet fragmentation and reassembly and ensures reliable data transfer.
4. Wireless Transport Layer Security (WTLS) - This layer provides security services to WAP. It ensures confidentiality, integrity, and authentication of WAP data.
5. Wireless Datagram Protocol (WDP) - This layer provides a common interface between the higher layers of the WAP stack and the underlying wireless network protocols.

#### Wireless LAN Overview

Wireless LAN (WLAN) is a wireless network that uses radio waves to transmit data between devices. WLANs can be used to provide wireless access to the internet or to create a wireless network within a building or campus. 

#### MAC Issues

The Media Access Control (MAC) layer is responsible for managing access to the wireless medium in WLANs. The following are the MAC issues of WLANs:

- Hidden Node Problem - In a WLAN, two nodes may not be able to hear each other due to obstacles such as walls or distance. If two nodes transmit data simultaneously, the signals may collide and cause a loss of data.
- Exposed Node Problem - In a WLAN, a node may refrain from transmitting data even though the other nodes are not transmitting data. This may happen because the node is afraid of interfering with the other nodes.
- MAC Addressing - In a WLAN, each wireless device has a unique MAC address. The MAC address is used by the MAC layer to address data packets to the correct destination.

#### IEEE 802.11

IEEE 802.11 is a family of standards for WLANs. The following are the different standards under IEEE 802.11:

- IEEE 802.11a - This standard uses the 5 GHz frequency band and supports data rates up to 54 Mbps.
- IEEE 802.11b - This standard uses the 2.4 GHz frequency band and supports data rates up to 11 Mbps.
- IEEE 802.11g - This standard uses the 2.4 GHz frequency band and supports data rates up to 54 Mbps.
- IEEE 802.11n - This standard uses both the 2.4 GHz and 5 GHz frequency bands and supports data rates up to 600 Mbps.

#### Bluetooth

Bluetooth is a wireless technology that provides short-range communication between devices. Bluetooth operates in the 2.4 GHz frequency band and supports data rates up to 3 Mbps. Bluetooth is commonly used to connect devices such as smartphones, headphones, and speakers.

#### Wireless Networks

Wireless networks are networks that use wireless technology to connect devices. Wireless networks can be classified into the following types:

- Wireless Personal Area Network (WPAN) - A WPAN is a wireless network that covers a small area, typically a few meters. Bluetooth is an example of a WPAN.
- Wireless Local Area Network (WLAN) - A WLAN is a wireless network that covers a larger area, typically a building or campus. WLANs use IEEE 802.11 standards.
- Wireless Metropolitan Area Network (WMAN) - A WMAN is a wireless network that covers a metropolitan area, typically a city. WiMAX is an example of a WMAN.
- Wireless Wide Area Network (WWAN) - A WWAN is a wireless network that covers a large area, typically a country or continent. Cellular networks are an example of a WWAN.
