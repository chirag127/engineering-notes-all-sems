## Unit 3 - Data management issues, data replication for mobile computers, adaptive clustering for mobile

In this unit, we will be discussing various data management issues that arise in the context of mobile computing. We will also cover two important techniques - data replication and adaptive clustering - that are commonly used to address these issues.

### Data Management Issues

Mobile computing poses a number of challenges for data management. Some of the key issues are:

- **Limited storage capacity:** Mobile devices typically have limited storage capacity, which means that data must be carefully managed to ensure that the device does not run out of space.
- **Intermittent connectivity:** Mobile devices may frequently lose connectivity with the network, which can make it difficult to ensure that data is always up-to-date.
- **Variable network bandwidth:** Mobile devices may be connected to networks with varying levels of bandwidth, which can impact the performance of data-intensive applications.
- **Security concerns:** Mobile devices are often used in environments that are less secure than traditional desktop environments, which can make data management more challenging.

### Data Replication for Mobile Computers

One technique that is commonly used to address the challenges of mobile data management is data replication. Data replication involves creating multiple copies of data and distributing them across multiple devices or servers. This can help to ensure that data is always available, even when devices lose connectivity with the network.

Two common types of data replication are:

- **Master-slave replication:** In this type of replication, one device or server (the master) is designated as the primary source of data. Other devices or servers (the slaves) periodically synchronize their data with the master.
- **Peer-to-peer replication:** In this type of replication, multiple devices or servers share data with each other. Changes made on one device or server are propagated to all other devices or servers.

### Adaptive Clustering for Mobile

Another technique that is commonly used in mobile data management is adaptive clustering. Adaptive clustering involves grouping devices or servers together based on their proximity to each other and their processing capabilities. This can help to improve the performance of data-intensive applications by reducing the amount of data that needs to be transmitted across the network.

Two common types of adaptive clustering are:

- **Static clustering:** In this type of clustering, devices or servers are grouped together based on pre-defined rules. For example, devices in the same geographic region may be grouped together.
- **Dynamic clustering:** In this type of clustering, devices or servers are grouped together based on real-time network conditions. For example, devices with similar processing capabilities may be grouped together to reduce the load on the network.

Mnemonics and learning tricks:

- To remember the two types of data replication, you can use the mnemonic "MSP" - Master-slave replication and Peer-to-peer replication.
- To remember the two types of adaptive clustering, you can use the mnemonic "SD" - Static clustering and Dynamic clustering.
