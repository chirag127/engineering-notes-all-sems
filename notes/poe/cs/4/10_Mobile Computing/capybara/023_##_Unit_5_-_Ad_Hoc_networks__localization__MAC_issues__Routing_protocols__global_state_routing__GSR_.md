## Unit 5 - Ad Hoc networks, localization, MAC issues, Routing protocols, global state routing (GSR)

Ad Hoc networks, also known as mobile networks, are temporary networks that are formed without any infrastructure or pre-existing network. They are self-organizing and can be set up quickly, making them ideal for emergency situations, military operations, and disaster relief efforts. In this unit, we will cover the following topics related to Ad Hoc networks:

### Localization

Localization refers to the process of determining the location of a node in a network. In Ad Hoc networks, localization is essential for routing and tracking nodes. There are several techniques for localization, including GPS-based localization, signal strength-based localization, and time-of-arrival (TOA) localization.

### MAC Issues

In Ad Hoc networks, the medium access control (MAC) layer plays a crucial role in managing the transmission of data between nodes. However, there are several MAC issues that need to be addressed, such as the hidden terminal problem, exposed terminal problem, and the deafness problem.

### Routing Protocols

Routing protocols are used to find the best path for data transmission between nodes in an Ad Hoc network. There are several routing protocols for Ad Hoc networks, including the Ad Hoc On-Demand Distance Vector (AODV) protocol, the Destination-Sequenced Distance Vector (DSDV) protocol, and the Dynamic Source Routing (DSR) protocol.

### Global State Routing (GSR)

Global State Routing (GSR) is a routing protocol that uses global state information to make routing decisions. It maintains a global view of the network and calculates the shortest path for data transmission between nodes. However, GSR is not suitable for large-scale Ad Hoc networks due to its high overhead.

#### Mnemonic: "GSR - Go Slow and Review"

Remember GSR as "Go Slow and Review," as it takes time to process global state information and calculate the shortest path.

In conclusion, Ad Hoc networks are versatile and useful in various situations. Understanding localization, MAC issues, and routing protocols is essential for designing and managing Ad Hoc networks. Remember to review and take things slow when dealing with GSR.
