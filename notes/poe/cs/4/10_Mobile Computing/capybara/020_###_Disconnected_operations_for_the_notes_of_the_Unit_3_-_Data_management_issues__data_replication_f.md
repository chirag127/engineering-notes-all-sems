### Disconnected operations for the notes of the Unit 3 - Data management issues, data replication for mobile computers, adaptive clustering for mobile in the subject of Mobile Computing

Disconnection is a common problem in mobile computing. Mobile devices are often disconnected from the network because of various reasons such as network failure, battery depletion, signal loss, or user preference. Disconnected operations refer to the ability of mobile devices to perform tasks even when they are disconnected from the network. 

There are several techniques for disconnected operations that are used in the field of mobile computing. Some of the most common techniques are:

1. Data Replication: Data replication is the process of copying data from a server to a mobile device. This technique is useful when a mobile device is disconnected from the network and needs access to the data. Data replication can be done in two ways: push replication and pull replication. In push replication, the server pushes data to the mobile device when it is connected to the network. In pull replication, the mobile device pulls data from the server when it is connected to the network.

2. Adaptive Clustering: Adaptive clustering is a technique used to group mobile devices based on their proximity and network connectivity. The devices in the same cluster can communicate with each other even when they are disconnected from the network. This technique is useful for applications that require collaboration among mobile devices.

3. Caching: Caching is the process of storing frequently accessed data on a mobile device. This technique is useful when a mobile device is frequently disconnected from the network. The cached data can be accessed even when the device is disconnected from the network.

Advantages of Disconnected Operations:
- Allows mobile devices to operate even when they are disconnected from the network.
- Increases the availability of data even in the absence of a network connection.
- Improves the performance of mobile applications by reducing the dependence on network connectivity.

Disadvantages of Disconnected Operations:
- Requires additional storage on mobile devices to store replicated data.
- Increases the complexity of mobile applications.
- Requires additional synchronization mechanisms to ensure consistency between the server and the mobile devices.

Mnemonics and Learning Tricks:
- Remember the acronym "DRAC" for the three techniques: Data Replication, Adaptive Clustering, and Caching.
- Think of Data Replication as a "copy and paste" technique, where the server "copies" the data and "pastes" it onto the mobile device.
- Imagine Adaptive Clustering as creating a "mobile network" among devices that are close to each other.
- Picture Caching as a "bookmark" for frequently accessed data on a mobile device.

Examples and Applications:
- Disconnected operations are commonly used in mobile applications that require access to data even in the absence of a network connection, such as email clients, messaging apps, and calendar apps.
- Adaptive clustering is used in collaborative applications, such as multi-player games and shared whiteboards.
- Data replication is used in mobile applications that require access to large amounts of data, such as video streaming apps and news apps.

In Conclusion, Disconnected operations are an essential aspect of mobile computing. They allow mobile devices to operate even when they are disconnected from the network, increasing the availability of data and improving the performance of mobile applications. Techniques such as data replication, adaptive clustering, and caching are commonly used to achieve disconnected operations in mobile computing.
