## Unit 4 - Mobile Agents computing, security and fault tolerance, transaction processing in mobile computing

Mobile computing has become an essential part of our lives. With the increasing use of mobile devices, the need for mobile computing has also increased. In this unit, we will study mobile agents computing, security, fault tolerance, and transaction processing in mobile computing.

### Mobile Agents Computing

Mobile agent computing is a type of distributed computing that involves the use of software agents that can move from one computer to another. These agents can execute a task on behalf of the user or the system. Mobile agents can be used for various purposes, such as data mining, network management, and e-commerce.

#### Advantages of Mobile Agents Computing

- Mobile agents can operate autonomously and perform tasks without human intervention.
- They can move from one computer to another, which makes them flexible and adaptable.
- Mobile agents can reduce network traffic by executing tasks locally.
- They can operate in a disconnected environment and synchronize data when connected.

#### Disadvantages of Mobile Agents Computing

- Mobile agents can be vulnerable to security threats, such as interception, modification, and replay attacks.
- There can be a lack of control over mobile agents, which can lead to unauthorized access and data leakage.
- Mobile agents can consume resources, such as memory and processing power, on the host computer.

### Security in Mobile Computing

Mobile computing devices are vulnerable to security threats due to their portability and wireless connectivity. Security in mobile computing involves protecting the devices, networks, and data from unauthorized access, modification, and theft.

#### Mnemonic

A good mnemonic for remembering the security issues in mobile computing is "S-A-F-E".

- S: Security threats – mobile devices are vulnerable to security threats, such as malware, phishing, and hacking.
- A: Authentication – it is essential to verify the identity of the user and the device before granting access to the system.
- F: Firewall – a firewall can protect the mobile device from unauthorized access and network attacks.
- E: Encryption – data should be encrypted to prevent interception and theft.

### Fault Tolerance in Mobile Computing

Fault tolerance in mobile computing involves ensuring that the system can continue to operate even in the event of a failure. Mobile devices can be prone to failures, such as battery drain, network disconnection, and hardware failure.

#### Mnemonic

A good mnemonic for remembering the fault tolerance in mobile computing is "R-A-I-D".

- R: Redundancy – redundant components can be used to ensure that the system can continue to operate even if one component fails.
- A: Availability – the system should be available to the user even if the network is disconnected or the device is in a low-power mode.
- I: Isolation – faults should be isolated to prevent them from affecting the rest of the system.
- D: Detection – faults should be detected and handled in a timely manner.

### Transaction Processing in Mobile Computing

Transaction processing in mobile computing involves ensuring that transactions are executed correctly and reliably, even in a disconnected environment. Mobile devices can be disconnected from the network, which can lead to data inconsistencies and conflicts.

#### Mnemonic

A good mnemonic for remembering the transaction processing in mobile computing is "A-C-I-D".

- A: Atomicity – transactions should be executed as a single unit of work, which means that either all the operations succeed or none of them succeed.
- C: Consistency – transactions should maintain the consistency of the data, which means that the data should be valid and conform to the constraints.
- I: Isolation – transactions should be isolated from each other to prevent conflicts and inconsistencies.
- D: Durability – transactions should be durable, which means that the changes made by the transactions should be permanent.
