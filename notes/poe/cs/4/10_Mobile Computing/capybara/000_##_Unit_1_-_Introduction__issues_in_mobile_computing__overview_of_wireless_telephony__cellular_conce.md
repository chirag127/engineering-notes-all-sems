## Unit 1 - Introduction, issues in mobile computing, overview of wireless telephony: cellular concept, GSM:

Mobile computing has become an integral part of our lives. It has revolutionized the way we communicate, work, and entertain ourselves. Mobile computing refers to the use of portable computing devices that can be carried along with us anywhere. In this unit, we will discuss the introduction to mobile computing, the issues that arise in mobile computing, and an overview of wireless telephony.

### Introduction to Mobile Computing:

Mobile computing refers to the use of portable computing devices that can be carried along with us anywhere. These devices include smartphones, tablets, laptops, and wearable devices. The main advantage of mobile computing is that it provides us with the flexibility to work from anywhere and anytime.

### Issues in Mobile Computing:

Mobile computing also faces several issues, such as security, battery life, network connectivity, and user interface design. Security is a major issue in mobile computing as these devices are highly vulnerable to cyber-attacks. Battery life is another issue as these devices consume a lot of power, and frequent charging is required. Network connectivity is also an issue in mobile computing as the signal strength varies depending on the location. User interface design is also a crucial issue as it determines the ease of use of these devices.

### Overview of Wireless Telephony:

Wireless telephony refers to the use of wireless networks for telecommunication. The cellular concept is the basis of wireless telephony. The cellular concept divides a geographical area into smaller areas called cells. Each cell has a base station that transmits and receives signals from the mobile devices. The Global System for Mobile Communications (GSM) is a standard used in wireless telephony. GSM is used for voice and data communication and has become the most widely used standard for mobile communication.

Mnemonics and learning tricks:
- To remember the cellular concept, you can think of it as a honeycomb structure where each cell is a hexagon-shaped area.
- To remember GSM, you can think of it as the abbreviation for "Global System for Mobile Communications."
