### Application Environment for the Notes of Unit 2: Wireless Networking, Wireless LAN Overview: MAC Issues, IEEE 802.11, Bluetooth, Wireless in the Subject of Mobile Computing

Wireless networking has become an essential part of our daily lives, and it has revolutionized the way we communicate and access information. In the following points, we will discuss the application environment for the notes of Unit 2, which covers Wireless Networking, Wireless LAN Overview: MAC issues, IEEE 802.11, Bluetooth, Wireless in the Subject of Mobile Computing.

1. Wireless Networking: 

Wireless networking is the transmission of data over a wireless medium. It allows devices to connect to the internet without the need for physical cables. Some common wireless technologies include Wi-Fi, Bluetooth, and Cellular Networks.

2. Wireless LAN Overview: 

Wireless LAN or WLAN is a type of wireless networking that is used for local area networking. WLAN uses radio waves to transmit data between devices, and it is commonly used in homes, offices, and public places. Some common WLAN technologies include Wi-Fi, which is based on IEEE 802.11 standards.

3. MAC Issues: 

Media Access Control or MAC is a protocol used to control access to a shared network medium. MAC issues can occur when multiple devices are trying to access the wireless network simultaneously. To avoid these issues, techniques like collision detection and collision avoidance are used.

4. IEEE 802.11: 

IEEE 802.11 is a set of standards that define the specifications for wireless LANs. These standards cover various aspects of wireless networking, including data rates, security, and power consumption. Some of the commonly used IEEE 802.11 standards include 802.11a, 802.11b, 802.11g, and 802.11n.

5. Bluetooth: 

Bluetooth is a wireless technology used for short-range communication between devices. It is commonly used for connecting devices like smartphones, headphones, and speakers. Bluetooth uses a low-power radio frequency to transmit data over short distances.

6. Wireless in Mobile Computing: 

Wireless technology has become an essential part of mobile computing. Mobile devices like smartphones, tablets, and laptops rely on wireless networking to access the internet and connect with other devices. Some common wireless technologies used in mobile computing include Wi-Fi, Cellular Networks, and Bluetooth.

Mnemonic or Learning Trick:

To remember the different types of wireless technologies, you can use the mnemonic "WBC", which stands for Wi-Fi, Bluetooth, and Cellular Networks. This can help you remember the different wireless technologies and their common uses in mobile computing.
