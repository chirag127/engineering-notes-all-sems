### WAP: Architecture for the notes of the Unit 2 - Wireless Networking, Wireless LAN Overview: MAC issues, IEEE 802.11, Blue Tooth, Wireless in the subject of Mobile Computing

Wireless Application Protocol (WAP) is a communication protocol designed specifically for wireless devices to access the internet. It enables mobile devices to access web pages, email, and other online services using wireless networks. The architecture of WAP consists of several layers, each of which has its own functionality.

#### WAP Architecture Layers

1. Wireless Application Environment (WAE): It is the top layer of the WAP protocol stack and provides an interface between the application and the underlying protocols. It includes the markup language, scripting language, and programming interfaces.

2. Wireless Session Protocol (WSP): It is responsible for the session management between the client and server. It establishes a connection between the two devices and manages the session state.

3. Wireless Transaction Protocol (WTP): It ensures reliable data transfer between the client and server. It provides error detection and correction mechanisms to ensure that the data is transferred without errors.

4. Wireless Transport Layer Security (WTLS): It provides security to the data transmitted between the client and server. It uses encryption and decryption techniques to ensure that the data is secure.

5. Wireless Datagram Protocol (WDP): It is responsible for the transmission of data over the wireless network. It provides a common interface for the upper layers to communicate with the lower layers.

#### Wireless LAN Overview

Wireless Local Area Networks (WLANs) are a type of wireless network that allows devices to connect to a local area network (LAN) without the use of wires. WLANs use radio waves to transmit data between devices.

#### MAC issues

The Media Access Control (MAC) layer is responsible for controlling access to the wireless medium. It is responsible for handling issues such as collisions, interference, and congestion. Some of the MAC issues related to WLANs are:

- Hidden node problem: This occurs when two nodes are out of range of each other, but both can communicate with a third node. This creates a collision when both nodes try to communicate with the third node simultaneously.

- Exposed node problem: This occurs when one node is in range of another node, but cannot communicate with it because it is busy communicating with a third node.

#### IEEE 802.11

The IEEE 802.11 standard is a set of protocols that define the operation of WLANs. It consists of several sub-standards, such as 802.11a, 802.11b, 802.11g, and 802.11n, each of which defines different aspects of WLANs.

Some of the features of IEEE 802.11 are:

- Multiple access points can be used to extend the coverage area of a WLAN.

- Data rates of up to 600 Mbps are supported.

- The 2.4 GHz and 5 GHz bands are used for transmission.

#### Bluetooth

Bluetooth is a wireless technology that allows devices to communicate with each other over short distances. It is commonly used for connecting devices such as smartphones, headphones, and speakers.

Some of the features of Bluetooth are:

- It uses low power radio waves for communication.

- It has a range of up to 10 meters.

- It supports data rates of up to 3 Mbps.

#### Wireless in Mobile Computing

Wireless communication is an essential component of mobile computing. It enables devices to connect to the internet and other devices without the need for wires. Some of the applications of wireless in mobile computing are:

- Mobile internet browsing

- Email and messaging

- Voice and video calling

- Location-based services

- Mobile payments
