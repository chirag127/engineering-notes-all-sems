## GPRS for the notes of the Unit 1 - Introduction, issues in mobile computing, overview of wireless telephony: cellular concept, GSM: in the subject of Mobile Computing

General Packet Radio Service (GPRS) is a wireless communication service that allows mobile devices to send and receive data over the internet. It is a 2G and 2.5G technology that enables higher data rates than traditional Circuit Switched Data (CSD) and Short Message Service (SMS).

### How GPRS works

GPRS uses a packet-switched network to transmit data, which means that data is broken down into small packets and sent over the network. Each packet is routed separately to its destination, which allows for more efficient use of network resources compared to circuit-switched networks.

GPRS uses the same radio frequencies as GSM and is typically implemented as an overlay on the existing GSM network. This means that GPRS can be added to existing GSM networks without requiring significant infrastructure changes.

### Advantages of GPRS

- Faster data transfer rates: GPRS provides data transfer rates of up to 114 kbps, which is much faster than traditional CSD and SMS services.
- Always-on connectivity: GPRS maintains a persistent connection to the internet, which eliminates the need to dial-up for each session.
- Cost-effective: GPRS uses network resources more efficiently, which reduces the cost of data transmission for both users and service providers.
- Compatibility with existing networks: GPRS can be added to existing GSM networks without requiring significant infrastructure changes, which makes it a cost-effective option for service providers.

### Disadvantages of GPRS

- Limited bandwidth: GPRS uses shared network resources, which can lead to slower data transfer speeds during peak usage periods.
- Limited coverage: GPRS coverage is limited to areas where GSM service is available.
- Security concerns: GPRS is vulnerable to security threats such as hacking and eavesdropping, which can compromise the privacy of user data.

### Applications of GPRS

- Mobile Internet access: GPRS allows users to access the internet from their mobile devices, which enables them to check email, browse websites, and use web-based applications on the go.
- Mobile commerce: GPRS enables mobile payments and other forms of mobile commerce by providing a secure and reliable connection to the internet.
- Fleet management: GPRS can be used to track the location and status of commercial vehicles, which enables businesses to optimize their operations and improve efficiency.

### Mnemonics and learning tricks

- Remember that GPRS stands for General Packet Radio Service, which can be abbreviated as GPRS.
- Think of GPRS as a faster and more efficient alternative to traditional CSD and SMS services.
- Remember that GPRS uses packet-switched technology, which allows for more efficient use of network resources compared to circuit-switched networks.
