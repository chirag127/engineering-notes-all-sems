## Unit 5 - Ad Hoc networks, localization, MAC issues, Routing protocols, global state routing (GSR)

In this unit, we will learn about Ad Hoc networks, localization, MAC issues, Routing protocols, and global state routing (GSR) in detail. 

### Ad Hoc Networks:

An ad hoc network is a wireless network, where nodes communicate directly with each other without the need for a centralized infrastructure, such as a router or access point. Ad hoc networks are also known as peer-to-peer networks.

Some of the key features of ad hoc networks are:

- They are self-organizing and self-configuring
- They can be set up quickly without any pre-existing infrastructure
- They are suitable for applications where infrastructure is not available or feasible

### Localization:

Localization refers to the process of determining the physical location of a node in a wireless network. Localization is a crucial aspect of many wireless applications such as asset tracking, surveillance, and emergency response.

There are several techniques for localization, including:

- GPS-based localization
- Triangulation-based localization
- Received Signal Strength Indicator (RSSI)-based localization
- Time of Arrival (TOA)-based localization
- Time Difference of Arrival (TDOA)-based localization

### MAC Issues:

MAC (Media Access Control) issues refer to the problems that arise in wireless networks due to the limitations of the MAC layer. Some of the common MAC issues in wireless networks include:

- Hidden terminal problem
- Exposed terminal problem
- MAC layer congestion
- MAC layer overhead
- MAC layer fairness

### Routing Protocols:

Routing protocols are used to determine the best path for data transmission in a network. There are several routing protocols for ad hoc networks, including:

- Ad Hoc On-Demand Distance Vector (AODV)
- Dynamic Source Routing (DSR)
- Destination-Sequenced Distance Vector (DSDV)
- Zone Routing Protocol (ZRP)
- Temporally Ordered Routing Algorithm (TORA)

Each routing protocol has its own advantages and disadvantages. The choice of routing protocol depends on the application requirements and network characteristics.

### Global State Routing (GSR):

Global State Routing (GSR) is a routing protocol for wireless sensor networks. GSR uses a global state database to make routing decisions. The global state database contains information about the current state of the network, including the location and status of all nodes.

GSR has several advantages, including:

- Efficient use of network resources
- Low overhead
- Scalability
- Resilience to node failures

However, GSR also has some disadvantages, including:

- High storage requirements for the global state database
- High communication overhead for maintaining the global state database
