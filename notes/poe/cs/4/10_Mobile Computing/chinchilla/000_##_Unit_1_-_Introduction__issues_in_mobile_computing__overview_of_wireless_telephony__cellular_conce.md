## Unit 1 - Introduction, issues in mobile computing, overview of wireless telephony: cellular concept, GSM:

Mobile computing has become an integral part of our lives, and we rely on it for our day-to-day activities. This unit provides an introduction to mobile computing and its challenges, as well as an overview of wireless telephony, including the cellular concept and GSM.

### Introduction to Mobile Computing:

- Mobile computing refers to the use of portable devices, such as smartphones, tablets, and laptops, for accessing and processing data on the move.
- The main challenges in mobile computing include limited battery life, limited processing power, limited storage capacity, and limited network bandwidth.
- Mobile computing applications can be categorized into three main types: standalone, client-server, and peer-to-peer.
- Standalone applications run entirely on the mobile device, while client-server applications rely on a server for data processing and storage. Peer-to-peer applications allow two or more devices to communicate directly with each other.

### Overview of Wireless Telephony:

- Wireless telephony refers to the transmission of voice and data over a wireless network.
- The cellular concept is the basis of wireless telephony, which divides a geographic region into cells, each served by a base station.
- The base station communicates with the mobile device using radio waves, and the mobile device communicates with the base station using a transceiver.
- The Global System for Mobile Communications (GSM) is a standard for wireless telecommunications that uses digital signaling to provide voice and data services.
- GSM operates on various frequency bands, depending on the region, and supports various services, such as voice calls, text messages, and internet access.

### GSM:

- GSM uses Time Division Multiple Access (TDMA) technology, which divides each frequency band into time slots, allowing multiple users to share the same frequency band.
- GSM supports various data services, such as Short Message Service (SMS), Multimedia Message Service (MMS), and General Packet Radio Service (GPRS).
- The Subscriber Identity Module (SIM) card is a small smart card that stores the user's mobile number, network authentication information, and other data.
- GSM provides various security features, such as encryption, authentication, and access control, to protect user data and prevent unauthorized access.
- GSM has several advantages, such as better call quality, wider coverage, and support for international roaming. However, it also has some disadvantages, such as limited bandwidth and slower data speeds compared to newer technologies like 4G and 5G.

Mnemonics and learning tricks:

- To remember the three types of mobile computing applications: Standalone, Client-server, and Peer-to-Peer, you can use the acronym SCP, which stands for "Standalone, Client-server, Peer-to-Peer."
- To remember the three main challenges in mobile computing: Battery, Processing power, and Storage, you can use the acronym BPS, which stands for "Battery, Processing, Storage."
- To remember the basic components of the cellular concept: Cells, Base stations, and Transceivers, you can use the acronym CBT, which stands for "Cells, Base stations, Transceivers."
