### Protocol Stack for the Notes of the Unit 2 - Wireless Networking, Wireless LAN Overview: MAC Issues, IEEE 802.11, Bluetooth, Wireless in the Subject of Mobile Computing

Wireless networking is crucial to mobile computing. It enables devices to communicate without the need for physical connections. To achieve this, wireless communication relies on a protocol stack, which specifies the rules for transmitting data over a wireless network. In this guide, we will discuss the protocol stack for wireless networking, including the MAC issues, IEEE 802.11, Bluetooth, and Wireless LAN Overview.

#### Protocol Stack for Wireless Networking

The protocol stack for wireless networking consists of several layers, each with its specific functionality. The layers are:

1. Application Layer: This is the top layer of the protocol stack and is responsible for providing services to the end-user. It includes applications such as web browsers, email clients, and instant messaging software.

2. Transport Layer: The transport layer is responsible for ensuring reliable delivery of data between applications. It includes protocols such as TCP (Transmission Control Protocol) and UDP (User Datagram Protocol).

3. Network Layer: The network layer is responsible for routing data between devices on different networks. It includes protocols such as IP (Internet Protocol).

4. Data Link Layer: The data link layer is responsible for transmitting data between devices on the same network. It includes protocols such as Ethernet and WiFi.

5. Physical Layer: The physical layer is responsible for transmitting signals over the wireless medium. It includes technologies such as radio waves, infrared, and microwave.

#### MAC Issues

MAC (Media Access Control) issues refer to the problems that arise when multiple devices attempt to access the same wireless network simultaneously. To address these issues, wireless networks use different MAC protocols such as:

1. CSMA/CA (Carrier Sense Multiple Access with Collision Avoidance): This protocol prevents two devices from transmitting data at the same time by requiring one device to wait while the other transmits.

2. TDMA (Time Division Multiple Access): This protocol divides the available bandwidth into different time slots, with each device assigned a specific time slot for transmitting data.

#### IEEE 802.11

IEEE 802.11 is a set of standards for wireless local area networks (WLANs). These standards specify the protocols for transmitting data between devices on the same network. The most commonly used IEEE 802.11 standards are:

1. 802.11a: This standard uses the 5 GHz band and provides higher data rates than other standards.

2. 802.11b: This standard uses the 2.4 GHz band and provides lower data rates than other standards.

3. 802.11g: This standard uses the 2.4 GHz band and provides higher data rates than 802.11b.

4. 802.11n: This standard uses both the 2.4 GHz and 5 GHz bands and provides higher data rates than 802.11g.

#### Bluetooth

Bluetooth is a wireless technology used for short-range communication between devices. It operates in the 2.4 GHz band and can transmit data at a rate of up to 3 Mbps. Bluetooth uses a frequency-hopping spread spectrum technique to avoid interference from other devices operating in the same band.

#### Wireless LAN Overview

A wireless LAN (WLAN) is a local area network that uses wireless communication to connect devices within a limited area such as a building or campus. WLANs use access points to transmit and receive data between devices on the same network. They provide several advantages over traditional wired networks, such as mobility and flexibility.
