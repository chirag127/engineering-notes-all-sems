### Disconnected operations for the notes of the Unit 3 - Data management issues, data replication for mobile computers, adaptive clustering for mobile in the subject of Mobile Computing

**Mnemonics:**

- D for Disconnected, D for Data management
- R for Replication, R for robust data access
- A for Adaptive, A for availability

**Learning tricks:**

- Think of disconnection as temporary loss of connectivity leading to data management issues
- Replication provides data redundancy for robust access in disconnected mode
- Adaptive techniques provide availability of data and services in dynamic mobile environments

**Points:**

1. Disconnected operation - When mobile devices lose connectivity, data access and updates are not possible. This leads to data management issues like data consistency, concurrency issues, etc. Caching and replication techniques are used to provide data availability in disconnected mode.
2. Data replication - Data is copied from server to mobile device cache/database. This provides robust data access in disconnected mode at the cost of increased storage and synchronization issues. Different replication techniques like full, partial, quorum replication etc are used based on requirements.
3. Adaptive clustering - In mobile environments, relationship between data, users, and services keep changing. Adaptive clustering algorithms group mobile devices into clusters based on relationships and movement patterns. This provides efficient data and service availability and management.
