### Multiple Access Protocols for Wireless Networking

- CSMA/CA (Carrier Sense Multiple Access with Collision Avoidance): Devices sense the medium before transmitting. If sensed busy, delay transmission using a random backoff timer. Used in 802.11 WiFi.
- TDMA (Time Division Multiple Access): Each device is allocated a different time slot to transmit data. Sync required between devices and base station. Used in 2G digital cellular systems.
- FDMA (Frequency Division Multiple Access): Each device uses a different frequency band to transmit data. Limited by available spectrum. Used in analog cellular systems and cordless phones.
- CDMA (Code Division Multiple Access): Each device uses a pseudo-random code to spread its signal over a frequency band. Multiple devices can send signals simultaneously over the same band as long as they use different codes. Used in 3G and 4G digital cellular systems.

Learning Tricks:

- CSMA/CA: Think "polite" devices that wait their turn and say "after you" if medium is busy.
- TDMA: Think time slots like timetable schedule. Each device gets its own time slot.
- FDMA: Think separate frequencies like radio stations. Each device gets its own frequency.
- CDMA: Think coded spread spectrum. Devices can share band as long as they use different codes.

Advantages:

- CSMA/CA: Simple, no centralized coordination.
- TDMA: Eliminates collisions. High spectral efficiency.
- FDMA: Eliminates interference between devices on different frequencies.
- CDMA: Very high spectral efficiency. "Soft capacity" that can be expanded with more codes.

Disadvantages:

- CSMA/CA: Potential for collisions and retransmissions lowering efficiency.
- TDMA: Requirements for strict timing synchronization.
- FDMA: Limited available spectrum can limit capacity.
- CDMA: Complexity of spread spectrum and code management. Interference from devices using same code.
