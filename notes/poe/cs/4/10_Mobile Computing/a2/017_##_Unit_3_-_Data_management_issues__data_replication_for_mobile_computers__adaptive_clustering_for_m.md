## Unit 3 - Data management issues, data replication for mobile computers, adaptive clustering for mobile

- Data management issues: As the data generated by mobile devices is huge and diverse, managing this data is a challenge. The issues include:
-- Heterogeneous data formats: Data is in various formats like images, videos, docs, etc. Standardization and integration of data is difficult.
-- Fast data growth: The amount of data generated is very large and fast-growing. This makes scaling of storage and processing a challenge.
-- Limited resources: Mobile devices have limited storage, memory and battery life, making efficient data management important.
-- Data security: Mobile data needs to be secured from loss, theft and hacking as the devices can be lost, stolen or misused.

- Data replication for mobile computers: Due to the data management challenges and limited resources on mobiles, data replication is used. It involves:
-- Storing copies of data on multiple devices or cloud to prevent single point of failure.
-- Syncing data periodically between the devices to maintain consistency.
-- Using caching and pre-fetching to optimize access and usage of data.
-- Employing compression and other techniques to optimize storage usage.

- Adaptive clustering for mobile: With numerous mobile devices, grouping them into clusters helps in efficient data management. The clusters can be formed adaptively based on:
-- Geolocation of devices which are physically near each other.
-- Similar data usage patterns or types of data accessed.
-- Social relationships or connections between users of devices.
-- Available resources like storage, battery, etc. and distributing data and tasks accordingly.
-- The clusters are reconfigured dynamically as devices move, resources change or usage patterns evolve.
