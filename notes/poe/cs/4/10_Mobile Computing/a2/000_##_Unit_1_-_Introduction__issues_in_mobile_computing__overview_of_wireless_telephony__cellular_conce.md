## Unit 1 - Introduction, issues in mobile computing, overview of wireless telephony: cellular concept, GSM:

- Introduction to mobile computing: Mobile computing refers to the use of computing devices that are portable and can be used while in motion. Examples are laptops, tablets, smartphones, smartwatches, etc. These devices have batteries and wireless connectivity, enabling computing on the go. However, they have limitations like small screen size, limited input mechanisms, limited processing power and storage, security issues due to wireless connectivity, etc.

- Issues in mobile computing: Some key issues in mobile computing are:

- Limited battery life: Mobile devices have limited battery life, so power efficient computing is important.
- Limited resources: Mobile devices have limited CPU, memory, and storage, so memory and resource management is important.
- Wireless connectivity issues: The wireless connectivity in mobile devices can face interference and security issues like eavesdropping and man-in-the-middle attacks. Robust security is required.
- Small screen size: The small display size makes the UI challenging to design and can limit the amount of information displayed.
- Location tracking: The wireless connectivity in mobile devices enables location tracking, which can compromise user privacy. Data usage policies may be required.

- Overview of wireless telephony: Wireless telephony refers to the technology that enables voice and data communication over radio waves instead of wires. The key components are:

- Radio waves: Radio frequency signals are used to transmit voice and data over the air.
- Base station: The base station is the transmitter/receiver that connects the wireless network to the main telephone network or other data network.
- Handset: The mobile device held by the user is called the handset or mobile station. It communicates with the base station to facilitate calls and data exchange.

- Cellular concept: In cellular networks, the coverage area is divided into small geographic areas called cells. Each cell has a base station and nearby handsets connect to the nearest base station. As the user moves and goes out of range of one base station, the call is handed over to the next base station. This enables mobile communication without any call drops. The key benefits of cellular networks are capacity, coverage, and frequency reuse.

- GSM: Global System for Mobile Communications or GSM is a digital cellular network standard. The key features of GSM are:

- Digital voice and data transmission using a TDMA technique
- Authentication of handsets using a pre-shared key and encryption for security
- Roaming and international roaming support across mobile networks in different countries
- Support for SMS, MMS, and internet access using GPRS and EDGE data technologies
- Use of a SIM card to store key user authentication data and information to identify a subscriber's account
