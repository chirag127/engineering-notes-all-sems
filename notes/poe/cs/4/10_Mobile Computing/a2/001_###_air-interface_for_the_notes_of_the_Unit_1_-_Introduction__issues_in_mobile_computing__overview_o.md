### Air-interface
The air-interface refers to the radio frequency channel between the mobile device and the base station. It is responsible for services like voice and data communication over the network. The key aspects of the air-interface are:

- Frequency bands - Wireless networks operate within licensed frequency bands allocated by the government. Example - GSM uses 900 MHz and 1800 MHz bands.
- Multiple access schemes - Schemes like FDMA, TDMA and CDMA are used to allocate bandwidth to multiple users within a cell. Example - GSM uses TDMA.
- Modulation schemes - Schemes like GMSK are used to encode the data to be transmitted over the air-interface.
- Duplexing schemes - Schemes like FDD and TDD are used to allocate uplink and downlink frequencies. Example - GSM uses FDD.
- Coding schemes - Schemes like convolutional coding and Reed-Solomon coding are used for error correction and detection.
- Protocols - Protocols like the Um interface protocol are used to communicate over the air-interface.

Mnemonics:
- AIR: Access, Interface, Radio
- FIFO: Frequency, Interface, Over-the-air

Advantages:
- Enables mobile wireless communication
- Inexpensive and globally available

Disadvantages:
- Limited bandwidth
- Prone to interference

Applications:
- Mobile networks
- Wireless internet
- Bluetooth and Wi-Fi
