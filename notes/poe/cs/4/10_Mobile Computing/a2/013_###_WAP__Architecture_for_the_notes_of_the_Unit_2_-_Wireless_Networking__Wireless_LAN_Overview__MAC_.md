### WAP: Architecture for the notes of the Unit 2 - Wireless Networking, Wireless LAN Overview: MAC issues, IEEE 802.11, Blue Tooth, Wireless in the subject of Mobile Computing

WAP stands for Wireless Application Protocol. It is a technical standard for accessing information over a mobile wireless network. A WAP browser is a web browser for mobile devices such as mobile phones that uses the WAP protocol.

WAP Architecture consists of:

- WAP Gateway: It acts as an interface between the mobile device and the Internet. It converts content from Internet servers into a format suitable for the mobile device.
- WAP Push: It is used to send notifications or updates to the mobile device.
- WAP Profiles: It defines a set of specifications for different device types and network characteristics. This helps in delivering the suitable content to the devices.

Some key points about WAP:

- It makes web content and internet services available to digital cellular phones and other wireless terminals.
- It provides a way to connect mobile devices to the internet using wireless networks.
- It uses a stripped-down version of XML and HDML which requires less bandwidth than traditional HTML web pages.
- It has limitations in graphics, speed, and memory as compared to web browsers on computers.

Mnemonics:

WAP - Wireless Application Protocol
Gateway - Acts as an interface
Push - Send notifications
Profiles - Specifications for devices

Advantages:

- It provides access to online services and information on mobile devices with limited capabilities.
- It requires less bandwidth as it uses compact data formats.

Disadvantages:

- Limited functionality as compared to traditional web browsers.
- Slow speed and limited graphics capability.

Applications:

- Accessing web content on mobile phones.
- Receiving notifications and updates on mobile devices.
- Location-based services.
