## Unit 4 - Mobile Agents computing, security and fault tolerance, transaction processing in mobile computing

Mobile Agents:
- Mobile agents are software programs that can migrate from one machine to another in a network.
- They are autonomous pieces of code that can decide where to move to get resources, services, etc.
- They can perform tasks on behalf of users even in disconnected network environments.
- Some key characteristics: autonomy, social ability, learning, adaptability.

Advantages:
- Reduced network traffic.
- Flexibility and adaptability.
- Robustness to network disconnections.
- Parallel and asynchronous processing.

Disadvantages:
- Security issues like malicious hosts.
- Difficult to debug and maintain.
- Reliability issues.

Applications:
- Information retrieval and filtering.
- Network management.
- Electronic commerce.
- Distributed systems, etc.

Security:
- Protect agents from malicious hosts or other agents.
- Use cryptography and digital signatures for authentication and integrity.
- Restrict agent's access to resources.
- Backup agents in case of failure.

Fault Tolerance:
- Use replication of agents and data.
- Use checkpointing to rollback to previous valid state.
- Use exception handling and error recovery techniques.

Transaction Processing:
- Ensure ACID properties: Atomicity, Consistency, Isolation, Durability.
- Use distributed concurrency control and commit protocols.
- Deal with failure recovery of transactions.
- Maintain database consistency in case of agent or host failures.

Mnemonics/Learning tricks:
- MADCAPS for Mobile Agent characteristics: Migration, Autonomy, Decision making, Collaboration, Adaptability, Parallelism, Social ability.
- CRASH for Fault Tolerance: Checkpoint, Rollback, Atomicity, State preservation on Host failure.
