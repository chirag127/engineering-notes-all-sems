### CDMA

**Code Division Multiple Access** is a spread spectrum multiple access technique used in 2G and 3G cellular networks.

**How it works:**

- Each user is assigned a unique code to modulate their data.
- All the users transmit on the same frequency simultaneously.
- The receiver uses the unique code to de-spread and extract the data for the intended user.
- This allows multiple users to share the same frequency spectrum at the same time.

**Advantages:**

- Higher capacity than TDMA as it can support more simultaneous users.
- Less vulnerable to interference as the signal is spread over a wider bandwidth.
- Soft handoff allows simultaneous communication with multiple cells, enabling smooth transitions and high mobility.

**Disadvantages:**

- Complex technology resulting in high infrastructure costs.
- Near-far problem: The signal from a nearby transmitter may drown out the signal from a farther transmitter. Power control is needed to handle this.
- Poor spectrum efficiency as a wide bandwidth is used.

**Applications:** 2G and 3G cellular networks like IS-95, CDMA2000, WCDMA, etc.

**Mnemonics:**

- "CDMA - Code, then Divide the MAximum (capacity)" to remember it divides up maximum capacity using codes.

**Learning tips:**

- Understand the basic mechanism of using unique codes to separate multiple users on the same frequency.
- Practice drawing diagrams showing the spread spectrum and de-spreading processes.
- Know the major pros and cons and where CDMA is used.
