### Data Broadcasting for the notes of the Unit 2 - Wireless Networking, Wireless LAN Overview: MAC issues, IEEE 802.11, Blue Tooth, Wireless in the subject of Mobile Computing

Data broadcasting is a technique used in wireless networks to transmit data from an access point to all the associated stations simultaneously. This is useful in scenarios where the same data needs to be sent to multiple receivers. Some key points about data broadcasting are:

- Data is transmitted only once from the access point but received by all associated stations. This reduces bandwidth usage and increases efficiency compared to unicasting the data individually to each station.
- However, data broadcasting may lead to increased collisions if the stations are located close to each other and transmitting on the same frequency band. Collisions can degrade performance.
- Data broadcasting is typically used for applications where the same information is relevant to multiple receivers such as sending firmware updates, emergency alerts, multimedia streaming etc.
- The medium access control (MAC) layer protocols in wireless networks like IEEE 802.11 support data broadcasting by using a special destination address to indicate broadcast transmissions and allowing all stations to accept and process such frames.

Some mnemonics for remembering data broadcasting:

- One send, all receive: Data is sent once but received by all
- Same data, less transmits: Efficient as data is sent only once
- Many receivers, more collisions: Potential for increased collisions
- Updates, alerts and streaming: Typical use cases for data broadcasting
