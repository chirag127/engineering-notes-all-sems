### GPRS for the notes of the Unit 1 - Introduction, issues in mobile computing, overview of wireless telephony: cellular concept, GSM: in the subject of Mobile Computing

#### Points:

- GPRS stands for General Packet Radio Service. It is a packet-based wireless communication service designed to provide packet data speeds from 56 up to 114 Kbps and continuous connectivity to the Internet for mobile phone and computer users.
- GPRS is built on top of the existing GSM network and uses its infrastructure, enhancing the GSM networks with the GPRS capability. It provides packet-switched data service on GSM networks.
- The key features of GPRS are:
- Always on connectivity: GPRS provides continuous connectivity and users are always online and reachable. Data can be sent or received at any time.
- Speed: GPRS provides speeds between 56 to 114 Kbps which is considerably faster than the 9.6 Kbps speed of SMS and circuit-switched data on GSM networks.
- Efficient use of network resources: GPRS allocates resources only when data needs to be sent or received, freeing up the resources when not in use. This efficient use of resources means higher throughput and lower costs than traditional dial-up connections.
- Compatibility: GPRS is compatible with existing GSM networks and can be introduced as an add-on to GSM networks. Users do not need new handsets and the network and billing systems are reused.
- Applications: GPRS is suitable for applications that require intermittent, bursty data flows like web browsing, email, instant messaging, location-based services, etc.

- Advantages: Speed, always on connectivity, efficient resource use, compatibility with GSM
- Disadvantages: Limited bandwidth, potential security issues
- Examples: Mobile internet, multimedia messaging, location tracking
- Applications: Mobile banking, mobile healthcare, fleet management, smart metering, etc.
