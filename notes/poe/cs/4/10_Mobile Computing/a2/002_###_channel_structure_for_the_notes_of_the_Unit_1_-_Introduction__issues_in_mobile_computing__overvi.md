### Channel structure for the notes of the Unit 1 - Introduction, issues in mobile computing, overview of wireless telephony: cellular concept, GSM: in the subject of Mobile Computing

I. Introduction
- Mobile computing: Computing using mobile devices that can be carried, worn, or implanted on the body. Eg: Laptops, tablets, smartphones, smart watches, etc.
- Issues in mobile computing: Limited battery life, small display size, limited storage capacity and processing power, connectivity issues, security issues, etc.

II. Overview of wireless telephony
- Cellular concept: Geographical area divided into cells with each cell served by a fixed-location transceiver known as base station. Users communicate with nearest base station. Frequency reuse across cells allows high capacity.
- Generations of mobile networks: 1G (analog), 2G (digital - GSM, CDMA), 3G (WCDMA, CDMA2000), 4G (LTE, WiMAX), 5G (faster speed, lower latency).

III. GSM (Global System for Mobile communications)
- Uses TDMA and FDMA for user and cell separation respectively.
- User data is encrypted and authenticated for security using algorithms like A5/1, A5/2.
- Support for data and messaging services in addition to voice.
- Subscriber Identity Module (SIM) card stores user subscription information and authentication key.
- Advantages: International roaming, security, high capacity.
- Disadvantages: Limited data rate, more complex infrastructure and handsets.

Mnemonics:
- Mobile computing: Anytime-anywhere computing but with limitations
- Cellular concept: Geographical division for frequency reuse and coverage
- GSM: TDMA-FDMA, encryption, SIM card, roaming but limited data rate
