### Embedded Computing Basics for the Notes of the Unit 3 - Embedded Platforms for IoT in the Subject of Internet of Things

Embedded computing is a vital aspect of the Internet of Things (IoT) and plays a critical role in the development of IoT devices. In this unit, we will be discussing the embedded platforms for IoT and the basics of embedded computing. Here are some key points to keep in mind:

1. **What is Embedded Computing?** 

Embedded computing refers to the integration of computing systems into non-computing devices, such as appliances, vehicles, and industrial machinery. These systems are designed to perform specific functions and are often built with limited resources, such as memory, processing power, and energy.

2. **Characteristics of Embedded Computing** 

Embedded computing systems have certain characteristics that set them apart from general-purpose computing systems. These include:

- Limited resources: Embedded systems are designed to work with limited resources, such as memory, processing power, and energy.

- Real-time operation: Embedded systems often operate in real-time, meaning they must respond to events within a specific time frame.

- Customized hardware: Embedded systems often have custom hardware that is designed specifically for the intended application.

3. **Components of an Embedded System** 

An embedded system typically consists of three main components:

- Processor: The processor is the heart of the embedded system and is responsible for executing instructions.

- Memory: The memory is used to store data and program instructions.

- Input/output devices: These devices are used to interact with the system, such as sensors, actuators, and displays.

4. **Programming Languages for Embedded Systems** 

Programming embedded systems requires specialized knowledge and skills. Some commonly used programming languages for embedded systems include:

- C/C++: C/C++ are widely used for embedded systems programming due to their efficiency and low-level access to hardware.

- Assembly language: Assembly language is used to write low-level code that interacts directly with the hardware.

5. **Mnemonics and Learning Tricks for Embedded Computing Basics** 

- Remember the three main components of an embedded system as "PIM" - Processor, Input/output devices, and Memory.

- To remember the characteristics of embedded computing, use the acronym "LRC" - Limited resources, Real-time operation, and Customized hardware.

Embedded computing is a complex and challenging field, but it is also essential for the development of IoT devices. By understanding the basics of embedded computing, you can gain the skills and knowledge needed to build and program embedded systems for IoT applications.
