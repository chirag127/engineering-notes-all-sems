### Additions in Arduino for the Notes of Unit 5 - Programming the Arduino in the Subject of Internet of Things

Arduino is an open-source electronics platform that is widely used for building various IoT applications. It is a microcontroller board that is equipped with various input/output pins, which can be used to connect different sensors and actuators. In addition to the basic functionalities, there are some additions in Arduino that can make programming easier and more efficient. Here are some of the important additions in Arduino that you should know:

1. Libraries: Arduino libraries are pre-written code that can be used to perform specific tasks. These libraries are written by experienced developers and can save a lot of time and effort. Some of the popular libraries include the Servo library for controlling servo motors, the LiquidCrystal library for controlling LCD displays, and the Wire library for I2C communication.

2. Functions: Functions are reusable blocks of code that can be called from different parts of the program. With functions, you can write modular code that is easy to maintain and debug. Arduino supports various types of functions, such as void functions, which do not return a value, and return functions, which return a value.

3. Interrupts: Interrupts are signals that can pause the normal execution of the program and trigger a specific function. Interrupts are commonly used in IoT applications to respond to events in real-time. Arduino supports different types of interrupts, such as external interrupts, which are triggered by external events, and timer interrupts, which are triggered by the internal timer.

4. Timers: Timers are used for time-based operations in Arduino. With timers, you can perform tasks at specific intervals, measure the duration of an event, or generate PWM signals for controlling motors and LEDs. Arduino supports different types of timers, such as the millis() function, which returns the number of milliseconds since the program started, and the delay() function, which pauses the program for a specific period.

5. Serial communication: Serial communication is a way of transmitting data between the Arduino board and a computer or another device. With serial communication, you can monitor the output of the program, send commands to the board, or exchange data with other devices. Arduino supports various types of serial communication, such as UART, SPI, and I2C.

Mnemonics and learning tricks:

- To remember the popular libraries, you can use the mnemonic "SLI" (Servo, LiquidCrystal, Wire).
- To remember the types of interrupts, you can use the mnemonic "Eternal TImer" (External interrupts, Timer interrupts).
- To remember the types of serial communication, you can use the mnemonic "USI" (UART, SPI, I2C).

In conclusion, Arduino is a powerful platform for building IoT applications, and with these additions, you can make programming easier and more efficient. By using libraries, functions, interrupts, timers, and serial communication, you can write modular and responsive programs that can interact with the physical world.
