## Unit 4 - Network & Communication aspects in IoT

The success of IoT depends heavily on the network and communication aspects of the devices. In this unit, we will explore the various network and communication technologies used in IoT and their applications. 

### Topics Covered:

1. Wireless Communication Protocols 
2. Wired Communication Protocols 
3. Internet Protocols 
4. IoT Network Topologies
5. Security in IoT Networks

### Wireless Communication Protocols:

Wireless communication protocols are used for communication between IoT devices and the internet. Some of the commonly used wireless communication protocols are:

- Wi-Fi: It is a widely used wireless communication protocol that provides high-speed internet connectivity. It is suitable for IoT devices that require high bandwidth and low latency communication.

- Bluetooth: It is a low-power wireless communication protocol that is commonly used for short-range communication between IoT devices. It is ideal for applications that require low power consumption and low data rates.

- Zigbee: It is a low-power wireless communication protocol used for IoT devices that require low data rates and low-power consumption. It is commonly used in smart home applications.

- LoRaWAN: It is a long-range wireless communication protocol used for IoT devices that require long-range communication and low-power consumption. It is ideal for applications that require long-distance communication, such as smart cities.

### Wired Communication Protocols:

Wired communication protocols are used for communication between IoT devices and the internet. Some of the commonly used wired communication protocols are:

- Ethernet: It is a widely used wired communication protocol that provides high-speed internet connectivity. It is suitable for IoT devices that require high bandwidth and low latency communication.

- RS485: It is a wired communication protocol that is commonly used for long-distance communication between IoT devices. It is ideal for applications that require long-distance communication, such as industrial automation.

### Internet Protocols:

Internet protocols are used for communication between IoT devices and the internet. Some of the commonly used internet protocols are:

- TCP/IP: It is a widely used internet protocol that provides reliable and secure communication between IoT devices and the internet.

- HTTP/HTTPS: It is a protocol used for web-based communication between IoT devices and the internet. It is commonly used in IoT applications that require web-based communication.

### IoT Network Topologies:

IoT network topologies define the structure of the network used for communication between IoT devices. Some of the commonly used IoT network topologies are:

- Star Network: In this topology, all IoT devices are connected to a central hub or router. It is commonly used in smart home applications.

- Mesh Network: In this topology, each IoT device is connected to multiple other IoT devices, forming a mesh network. It is commonly used in smart cities and industrial automation applications.

### Security in IoT Networks:

Security is a critical aspect of IoT networks as they are vulnerable to cyber-attacks. Some of the commonly used security measures in IoT networks are:

- Authentication: It is the process of verifying the identity of IoT devices before allowing access to the network.

- Encryption: It is the process of converting data into a secure format to prevent unauthorized access.

- Firewall: It is a network security system that monitors and filters incoming and outgoing network traffic.

Mnemonics and learning tricks:

- To remember the commonly used wireless communication protocols, you can use the mnemonic "WBLZ" which stands for Wi-Fi, Bluetooth, LoRaWAN, and Zigbee.
- To remember the commonly used wired communication protocols, you can use the mnemonic "ER" which stands for Ethernet and RS485.
- To remember the commonly used internet protocols, you can use the mnemonic "THIP" which stands for TCP/IP and HTTP/HTTPS.
