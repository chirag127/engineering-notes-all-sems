### Additions in Arduino for the notes of the Unit 5 - Programming the Arduino in the subject of Internet of Things

1. Libraries - Libraries provide extra functionality for use in sketches, e.g. for operating motors, reading sensors, displaying text on LCD screens etc. To use a library, you must include it at the beginning of the sketch using the include statement. Many libraries come pre-installed with the IDE, some need to be downloaded and installed separately.

2. Data Types - Data in Arduino sketches is typed. The main data types you will use are:

- int - for whole numbers, e.g. 1, 20, -5
- float - for decimal numbers, e.g. 1.2, 5.4, -9.81
- double - also for decimal numbers but with greater precision
- boolean - for true/false values
- char - for single characters, e.g. 'x', 'B', '?'
- string - for strings of characters

3. Variables - You use variables to store values to be used in a sketch. You need to declare a variable before using it, specifying its data type. For example:

int myInt;     // declares an int variable called myInt
float myFloat; // declares a float variable called myFloat

You can then assign values to the variables and use them in your sketch. Variables allow you to reuse values, and make your sketches more readable and maintainable.
