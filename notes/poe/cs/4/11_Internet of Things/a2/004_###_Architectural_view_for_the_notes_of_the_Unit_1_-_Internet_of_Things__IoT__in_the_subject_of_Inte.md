### Architectural view for the notes of the Unit 1 - Internet of Things (IoT) in the subject of Internet of Things

The architectural view of IoT can be classified into:

1. Perception layer: This layer consists of sensors and actuators which convert the physical parameters to electrical signals and vice-versa. For example, temperature sensors, motion sensors, LEDs, etc.

2. Network layer: This layer is responsible for establishing connections between the perception layer and application layer. It can be wired or wireless network using protocols like 6LoWPAN, Wi-Fi, Bluetooth, etc.

3. Application layer: This layer consists of software applications running on gateways or cloud servers. It processes the data collected from sensors and actuates the actuators accordingly. For example, smart home applications.

Some key points to remember:

- IoT is an integration of physical devices, networks, and software.
- The layers work in a hierarchical manner with the perception layer at the bottom and application layer at the top.
- The network layer is responsible for the connectivity across the layers.
- The applications can be local or cloud-based.
- IoT aims to make the things around us smart and interconnected.

Advantages:

- Automation of tasks
- Remote monitoring and control
- Increased efficiency and cost reduction
- Better data collection and analytics

Disadvantages:

- Security and privacy concerns
- Interoperability issues
- Reliability issues
- Lack of standards
