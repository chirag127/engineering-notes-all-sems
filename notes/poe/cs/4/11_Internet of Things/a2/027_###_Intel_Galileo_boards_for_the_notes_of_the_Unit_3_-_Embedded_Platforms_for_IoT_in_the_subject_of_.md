### Intel Galileo boards for the notes of the Unit 3 - Embedded Platforms for IoT in the subject of Internet of Things

Intel Galileo is a microcontroller board designed for hardware and software developers to create and innovate with the latest Intel computing technologies. It is based on the Intel Quark SoC X1000, the first product from the Intel Quark product family of low-power, small-core products.

Key features of Intel Galileo board -

- Intel Quark SoC X1000 processor with 400 MHz single core Pentium-class CPU
- 256 MB of DDR3 RAM
- 100 Mb Ethernet port
- Micro SD slot for storage
- USB 2.0 host port
- USB OTG port
- Analog input pins
- General purpose I/O pins
- SDRAM slot

Some applications of Intel Galileo board -

- Prototyping IoT products and wearable devices
- Learning hardware, software and programming skills
- Building creative projects using Arduino shields
- Industrial control systems
- Robotics projects

Advantages -

- Compatible with Arduino software and hardware ecosystem allowing reuse of many Arduino shields and software libraries
- Support for multiple operating systems like Linux, Windows and Mac OS
- Low cost and easy to get started
- Strong processing and connectivity capabilities suitable for variety of projects

Disadvantages -

- Limited processing power and memory for complex projects
- No onboard wireless connectivity
- Some compatibility issues with certain Arduino shields

Mnemonics -

Intel Quark = IoT projects on low power
Galileo = Explore hardware, software and Arduino ecosystem

Learning tricks -

- Start with basic LED blink projects to get familiar with the board
- Try out variety of Arduino shields to understand capabilities
- Refer to many online tutorials and communities for support
- Great for beginners to learn embedded system concepts
