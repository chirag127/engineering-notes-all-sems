### Coding for the notes of the Unit 5 - Programming the Arduino in the subject of Internet of Things

1. Learn the Arduino IDE
- The Arduino IDE is the software environment used to write, compile and upload programs to Arduino boards.
- It is open source and runs on Windows, Mac OS X, and Linux.
- The IDE includes a text editor for writing code, a message area, a text console, a toolbar with buttons for common functions and a series of menus.
- Learn about the Sketch, Verify, Upload and Serial Monitor buttons and their functions.

2. Learn Arduino programming language
- The Arduino programming language is a set of C/C++ functions that can be called from your sketch to perform common tasks.
- Learn basic syntax and structure of an Arduino sketch. Understand void setup() and void loop() functions.
- Learn about data types like int, float, boolean, char, etc. and variables.
- Learn about Arduino inputs and outputs and how to control them. Understand digitalWrite(), analogWrite(), digitalRead() and analogRead() functions.
- Learn about Arduino control structures like if-else statements, for loops, while loops, switch case, etc.
- Learn about Arduino arrays, strings and time functions.
