## Unit 4 - Network & Communication aspects in IoT

### Topic 1 - Communication Protocols

- IoT devices use various communication protocols to send and receive data. Some common protocols are:
- MQTT: Message Queue Telemetry Transport, a publish/subscribe messaging protocol ideal for constrained devices and low bandwidth, high latency networks.
- CoAP: Constrained Application Protocol, a specialized web transfer protocol for use with constrained nodes and constrained networks.
- AMQP: Advanced Message Queuing Protocol, an open standard application layer protocol for message-oriented middleware.
- XMPP: Extensible Messaging and Presence Protocol, a communication protocol for message-oriented middleware based on XML.

**Mnemonic:** CoMe QUiCk - CoAP, MQTT, XMPP

**Advantage:** Support resource constrained devices and different communication needs.
**Disadvantage:** Interoperability between protocols can be challenging.

### Topic 2 - Network Technologies

- The physical medium used for network communication in IoT can be:
- WiFi: Wireless local area networks, enables devices to connect to the internet and each other using radio waves.
- Ethernet: Wired local area networks, enables devices to connect to the internet and each other using physical cables.
- Cellular: Wide area networks using existing cell tower infrastructure, allowing IoT devices to connect to the internet over large geographical areas.
- Low power WAN: Wide area networks with lower bandwidth but longer range and lower power requirements, suited for remote IoT devices. Some technologies are LoRaWAN and Sigfox.

**Mnemonic:** WiFi at home, Ethernet at work, Cellular on the go, LPWAN everywhere.
