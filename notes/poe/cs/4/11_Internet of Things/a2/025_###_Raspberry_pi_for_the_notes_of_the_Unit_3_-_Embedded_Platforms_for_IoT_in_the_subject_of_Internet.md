### Raspberry pi for the notes of the Unit 3 - Embedded Platforms for IoT in the subject of Internet of Things

Raspberry Pi is a small single-board computer developed in the UK by the Raspberry Pi Foundation to promote teaching of basic computer science in schools and developing countries. It has the following key features:

- It is a credit-card sized single-board computer.
- It has a Broadcom BCM2835 system on a chip with an ARM1176JZF-S 700 MHz processor and a VideoCore IV GPU.
- It has 512 MB, 1 GB, or 2 GB of RAM.
- It has a SD card slot for storage and booting.
- It has USB ports, HDMI output, and Ethernet connectivity.
- It runs an operating system like Raspbian, a free operating system based on Debian.

Some key advantages and applications of Raspberry Pi are:

- It is inexpensive and portable.
- It supports various operating systems like Linux, Windows 10 IoT core, etc. allowing us to work on various software projects.
- It has GPIO pins that can be interfaced with sensors and actuators allowing us to build hardware projects.
- It can be used in various IoT projects like home automation, robotics, weather stations, etc.
- It is extensively used for STEM education to teach programming and basics of computers.

Some key disadvantages are:

- It has limited processing power and storage compared to a regular computer.
- The small size can make it difficult to handle the wiring and connections.
- There is a steep learning curve to get started with Raspberry Pi projects.

Thus, Raspberry Pi is a popular embedded platform used for developing and prototyping IoT and hardware projects due to its small size and low cost, though we need to consider its limited resources while building projects.
