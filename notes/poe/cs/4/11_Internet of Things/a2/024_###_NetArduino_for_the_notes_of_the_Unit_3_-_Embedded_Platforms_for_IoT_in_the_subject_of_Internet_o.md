### NetArduino for the notes of the Unit 3 - Embedded Platforms for IoT

Netduino is an open source electronics platform using the .NET Micro Framework. It is programmed using the C# programming language and supports many of the libraries and programming practices of the .NET Framework.

- Netduino is an embedded platform that runs .NET Micro Framework and can be programmed using C#. It is easier to program than Arduino as it uses a high level language like C# and the .NET framework.
- Netduino has a 32-bit microcontroller chip like Arduino and can be interfaced with sensors and actuators. It can connect to WiFi and Bluetooth modules to enable Internet connectivity.
- The .NET Micro Framework supports many of the .NET class libraries like networking, threading, collections, etc. So, it is easy to build cloud connected IoT projects on Netduino using C#.
- Some of the disadvantages of Netduino are that the community support is less than Arduino and fewer libraries and shields are available. Also, the hardware is more expensive than Arduino boards.
- Netduino can be used to build IoT projects where C# programming is preferred like home automation systems, weather monitoring systems, etc. It is a good option if you want to use a high level language and .NET framework for embedded IoT development.
