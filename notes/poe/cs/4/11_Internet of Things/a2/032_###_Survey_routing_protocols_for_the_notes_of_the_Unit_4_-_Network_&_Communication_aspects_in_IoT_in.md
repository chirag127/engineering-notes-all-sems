### Survey routing protocols for the notes of the Unit 4 - Network & Communication aspects in IoT in the subject of Internet of Things

- Routing protocols determine the paths that data takes through a network. Following are some of the common routing protocols used in IoT:

- Distance Vector Routing Protocols: These protocols determine the best path based on the total distance or number of hops to the destination. Examples are RIP and EIGRP.
- Link State Routing Protocols: These protocols determine the best path based on the state of the links between routers and the overall topology of the network. Examples are OSPF and IS-IS.
- Hierarchical Routing Protocols: These protocols organize routers into areas to improve scalability and efficiency. Examples are areas in OSPF and levels in IS-IS.
- Path Vector Routing Protocols: These protocols determine the best path based on the paths of gateways to the destination. The existing paths are explored to find the optimal path. Example is BGP.

**Mnemonics:**
> Distance Vector: Destination Distance
> Link State: Link Status
> Hierarchical: Highly Scalable
> Path Vector: Path Survey

**Advantages of routing protocols:**
- They enable automatic routing in the network which reduces manual configuration and errors.
- They respond to changes and failures in the network by finding alternate routes. This increases reliability and robustness.
- They use metrics to determine optimal paths which can optimize performance.

**Disadvantages of routing protocols:**
- Additional overhead on the network as the routers frequently exchange routing information.
- Complex to configure and manage especially in large networks.
- Sub-optimal routes may be chosen if the metrics are not appropriate.
- Security vulnerabilities may exist if the routing information is hacked or spoofed.
