## Unit 3 - Embedded Platforms for IoT

### Learning Objectives

- Understand the components and architecture of embedded systems used in IoT devices
- Learn about popular embedded hardware platforms like Raspberry Pi, Arduino, etc. used for IoT projects
- Gain hands-on experience with programming and interfacing sensors and actuators with embedded platforms
- Learn about real-time operating systems and their usage in embedded IoT systems

### Introduction

Embedded systems are microcontroller-based computers that are embedded inside various devices and machines. They are tailored for specific control functions within a larger system. Almost all IoT devices contain embedded systems that provide computing, networking and interface capabilities. Some of the key components of an embedded system are:

- Microcontroller - The brain of the system that executes program instructions
- Memory - For storing programs and data
- I/O interfaces - For interacting with sensors and actuators
- Timers and interrupts - For handling events and scheduling tasks
- Analog-to-digital and digital-to-analog converters - For interfacing with analog components

Popular embedded hardware platforms for IoT projects include:

- Raspberry Pi - Affordable, flexible board with a Linux operating system
- Arduino - Easy to use board with an simple IDE and lots of shields
- ESP8266/ESP32 - Inexpensive Wi-Fi modules with integrated microcontroller
- Intel Edison/Joule - Powerful boards for complex IoT applications

These platforms can be programmed using languages like C/C++, Python, etc. They facilitate easy interfacing with a variety of sensors and actuators. Many boards support Real-Time Operating Systems (RTOS) that provide hard real-time capabilities and efficient task scheduling required for responsive IoT systems.
