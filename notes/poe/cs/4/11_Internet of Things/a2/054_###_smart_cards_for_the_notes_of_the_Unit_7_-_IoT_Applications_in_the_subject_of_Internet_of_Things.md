### Smart cards for the notes of the Unit 7 - IoT Applications

Smart cards are credit card sized cards that contain integrated circuits for storing and processing data. They are used for security applications in IoT devices and systems.

* Advantages:
	* High storage capacity - Can store keys, certificates, credentials, etc. securely.
	* Tamper resistant - Difficult to access the data stored in the chip.
	* Portable - Can be used across devices and systems.
* Types:
	* Memory card - Stores data and information.
	* Microprocessor card - Has a CPU to perform operations like generate cryptographic keys, encrypt/decrypt data, etc.
* Uses in IoT:
	* Authentication - Storing keys and certificates for authentication of IoT devices.
	* Payment processing - Contactless payments in smart devices.
	* Access control - Storing access credentials for entry into secure premises or systems.

**Mnemonics:** A smart card is like a tiny secured vault carrying keys and treasures (data) safely.

**Learning trick:** Imagine a smart card as a James Bond style high security system card that stores secret information and unlocks secured systems. This imagery can help remember the secure features and uses of smart cards.
