
### Raspberry Pi for the Notes of the Unit 3 - Embedded Platforms for IoT in the Subject of Internet of Things 

Raspberry Pi is a small, single-board computer that is widely used in the Internet of Things (IoT) and embedded systems. It is a low-cost, low-power, and highly capable device that can be used for a variety of projects.

**Mnemonic and Learning Tricks**

- **R**emember **P**i is **I**nexpensive and **T**iny - This is a helpful mnemonic to remember the key features of the Raspberry Pi. 
- **R**aspberry **P**i is **A**ffordable and **C**ompact - Another mnemonic to help you remember the features of the Raspberry Pi.

**Advantages**

- Low cost and low power consumption: The Raspberry Pi is an inexpensive and energy-efficient device, making it ideal for projects that require a low-cost, low-power device.
- Highly capable: The Raspberry Pi is a powerful device that can be used for a variety of projects. It has a range of expansion options, including GPIO pins, USB ports, and an Ethernet port.

**Disadvantages**

- Limited memory and storage: The Raspberry Pi has limited memory and storage, making it unsuitable for some projects.
- Limited processing power: The Raspberry Pi has limited processing power, which can be a limitation for some projects.

**Applications**

- Home automation: The Raspberry Pi can be used to control home automation systems, such as lights and appliances.
- Robotics: The Raspberry Pi can be used to build robots and other automated systems.
- IoT: The Raspberry Pi can be used to create Internet of Things (IoT) devices, such as sensors and controllers.
