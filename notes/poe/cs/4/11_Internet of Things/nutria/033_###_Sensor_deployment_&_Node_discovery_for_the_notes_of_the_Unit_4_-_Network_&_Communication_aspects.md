
### Sensor Deployment & Node Discovery for the Notes of Unit 4 - Network & Communication Aspects in IoT in the Subject of Internet of Things

1. **Sensor Deployment**: Sensor deployment is the process of installing sensors in an environment to monitor for certain conditions. This is an important part of the Internet of Things (IoT) as it allows for data to be collected and used to make decisions.

2. **Node Discovery**: Node discovery is the process of finding nodes in a network. This is an important part of the Internet of Things (IoT) as it allows for devices to communicate with each other.

3. **Network & Communication Aspects in IoT**: Network and communication aspects in IoT are essential for the successful deployment of IoT devices. These aspects include network topology, communication protocols, and data transmission.

4. **Mnemonics & Learning Tricks**: Mnemonics and learning tricks can be used to help remember the different aspects of network and communication in IoT. For example, the following mnemonic can be used to remember the three main components of a network: “Network Topology is like a Map” (N for Network, T for Topology, and M for Map). Additionally, the acronym “IPC” can be used to remember the three main communication protocols used in IoT: Internet Protocol (IP), Constrained Application Protocol (CoAP), and Message Queuing Telemetry Transport (MQTT).
