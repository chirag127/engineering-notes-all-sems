
### Survey routing protocols for the notes of the Unit 4 - Network & Communication aspects in IoT in the subject of Internet of Things

Survey routing protocols are used to discover and monitor the topology of an Internet of Things (IoT) network. They are used to detect changes in the network and to optimize the routing of data packets. The most common survey routing protocols are:

- **Link State Routing (LSR)**: Link state routing is a distance-vector routing protocol that uses link-state advertisements to discover and monitor the topology of a network. It uses a flooding algorithm to determine the best path for data packets.

- **Distance Vector Routing (DVR)**: Distance vector routing is a routing protocol that uses a distance vector to determine the best path for data packets. It uses a flooding algorithm to discover and monitor the topology of a network.

- **Optimized Link State Routing (OLSR)**: Optimized link state routing is a routing protocol that uses link-state advertisements to discover and monitor the topology of a network. It uses a flooding algorithm to determine the best path for data packets. It is optimized for networks with high mobility and frequent topology changes.

- **Ad-hoc On-demand Distance Vector (AODV)**: Ad-hoc on-demand distance vector is a routing protocol that uses a distance vector to determine the best path for data packets. It is optimized for networks with low mobility and infrequent topology changes.

Mnemonics and learning tricks to remember these protocols:

- **LSR:** Link State Routing - Linked States Route
- **DVR:** Distance Vector Routing - Distant Vectors Route
- **OLSR:** Optimized Link State Routing - Optimized Linked States Route
- **AODV:** Ad-hoc On-demand Distance Vector - Ad-hoc On-demand Distant Vector
