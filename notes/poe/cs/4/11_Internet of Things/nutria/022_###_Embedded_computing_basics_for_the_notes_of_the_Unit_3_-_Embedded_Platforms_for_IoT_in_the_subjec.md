
### Embedded computing basics for the notes of the Unit 3 - Embedded Platforms for IoT in the subject of Internet of Things

Embedded computing is a type of computing that is designed to be used in applications where the computing device is embedded into the application itself. This type of computing is used in many different applications, including the Internet of Things (IoT).

In this unit, we will cover the basics of embedded computing and its application in the IoT. We will discuss the advantages and disadvantages of embedded computing, as well as the different types of embedded systems and their applications.

#### Advantages of Embedded Computing
- Lower power consumption
- Smaller form factor
- Increased reliability
- Increased performance
- Greater flexibility
- Easy integration

#### Disadvantages of Embedded Computing
- Cost of development
- Limited resources
- Limited processing power
- Security risks

#### Types of Embedded Computing
- Microcontrollers: These are small, single-chip computers that are used for controlling and monitoring devices.
- Digital Signal Processors (DSPs): These are specialized processors that are used for signal processing applications.
- System on Chips (SoCs): These are integrated circuits that contain both the processor and the memory.
- Field Programmable Gate Arrays (FPGAs): These are programmable chips that are used for complex logic and signal processing tasks.

#### Applications of Embedded Computing
- Automotive: Embedded computing is used in many automotive applications, such as engine control, powertrain control, and safety systems.
- Industrial: Embedded computing is used in many industrial applications, such as process control, machine vision, and robotics.
- Healthcare: Embedded computing is used in many healthcare applications, such as medical imaging, patient monitoring, and drug delivery systems.
- Consumer: Embedded computing is used in many consumer applications, such as smart TVs, gaming systems, and home automation systems.

Mnemonics and Learning Tricks:
- Microcontrollers: MCUs - Miniature Computer Units
- Digital Signal Processors (DSPs): DSPs - Digital Signal Processors
- System on Chips (SoCs): SoCs - System on Chips
- Field Programmable Gate Arrays (FPGAs): FPGAs - Field Programmable Gate Arrays
