
### Arduino Platform Boards Anatomy for the notes of the Unit 5 - Programming the Arduino in the subject of Internet of Things

1. Arduino is an open-source electronics platform based on easy-to-use hardware and software. It consists of a single-board microcontroller, which is programmed using the Arduino programming language and the Arduino development environment.

2. The Arduino platform consists of a range of boards with different features, such as the Arduino Uno, which is the most commonly used board. The board consists of an Atmel AVR microcontroller with various input and output pins, a USB port, and a power supply.

3. The board also includes various components, such as LEDs, buttons, and sensors, which can be used to create various projects. The board also includes a shield, which is a printed circuit board (PCB) designed to be plugged into the board to give it additional features.

4. The Arduino IDE (Integrated Development Environment) is the software used to program the Arduino board. It includes a text editor for writing code, a compiler for converting the code into a form the board can understand, and a serial monitor for debugging and testing the code.

5. The Arduino language is based on C and C++ and is designed to be easy to learn and use. It also includes a range of libraries for interfacing with various hardware components, such as LCD displays, servos, and sensors.

6. A good mnemonic for remembering the components of the Arduino platform is: "AVR USB Pins LEDs Buttons Sensors Shield IDE C++ Libraries". This can help to quickly recall the components of the Arduino platform.
