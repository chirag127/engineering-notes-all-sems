
### Overview of IOT supported Hardware platforms such as Arduino for the notes of the Unit 3 - Embedded Platforms for IoT in the subject of Internet of Things

- Internet of Things (IoT) is a network of physical objects, devices, vehicles, buildings, and other items embedded with electronics, software, sensors, and network connectivity, which enables these objects to collect and exchange data.
- Arduino is an open source prototyping platform based on easy-to-use hardware and software. It is an open-source physical computing platform based on a simple microcontroller board and a development environment for writing software for the board. Arduino boards are widely used in robotics, home automation, and other applications.
- Embedded platforms are designed to provide a complete hardware and software platform for developing applications for a specific purpose. These platforms are typically used in embedded systems, such as in IoT applications.
- The Arduino platform is a popular choice for embedded platforms due to its low cost, ease of use, and wide range of supported hardware. It can be used to create a wide range of applications, from simple home automation systems to complex industrial control systems.
- Arduino boards are typically programmed using the Arduino programming language, which is based on the C programming language. The Arduino IDE (Integrated Development Environment) is used to write, compile, and upload code to the board.
- There are many different types of Arduino boards available, including the Arduino Uno, Arduino Mega, Arduino Nano, and Arduino Pro Mini. Each board has its own set of features and capabilities.
- The Arduino platform also supports a wide range of peripherals, such as sensors, actuators, and displays. These peripherals can be used to create a wide range of applications.
- Arduino boards can be used to create a wide range of IoT applications, such as home automation systems, industrial control systems, and smart energy systems. The Arduino platform can also be used to create applications for other embedded platforms, such as Raspberry Pi.
