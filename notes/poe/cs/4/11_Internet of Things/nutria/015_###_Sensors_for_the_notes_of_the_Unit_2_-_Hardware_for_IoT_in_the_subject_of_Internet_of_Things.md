
### Sensors for the notes of the Unit 2 - Hardware for IoT in the subject of Internet of Things

Sensors are an important element in the Internet of Things (IoT). They are used to detect and measure changes in the environment, such as temperature, humidity, light, sound, and pressure. They can also be used to detect movement and changes in the environment.

The following are some of the most common types of sensors used in IoT:

- Temperature Sensors: These sensors measure temperature and can be used to detect changes in the environment.
- Humidity Sensors: These sensors measure humidity and can be used to detect changes in the environment.
- Light Sensors: These sensors measure light and can be used to detect changes in the environment.
- Sound Sensors: These sensors measure sound and can be used to detect changes in the environment.
- Pressure Sensors: These sensors measure pressure and can be used to detect changes in the environment.
- Motion Sensors: These sensors measure movement and can be used to detect changes in the environment.

Each type of sensor has advantages and disadvantages. For example, temperature sensors are accurate but can be affected by external factors such as wind and humidity. Humidity sensors are less accurate but can be used to detect changes in the environment over a longer period of time.

In addition to the types of sensors mentioned above, there are also more specialized sensors such as air quality sensors, gas sensors, and water quality sensors. These sensors can be used to detect changes in the environment that are specific to the type of sensor.

When using sensors in an IoT system, it is important to consider the type of sensor, its accuracy, and its range. It is also important to consider the environment in which the sensor will be used. For example, if the sensor will be used in a humid environment, it is important to choose a sensor that is designed to work in that type of environment.

Finally, it is important to remember that sensors are only one part of an IoT system. Other components such as actuators, communication protocols, and data processing are also important for a successful IoT system.
