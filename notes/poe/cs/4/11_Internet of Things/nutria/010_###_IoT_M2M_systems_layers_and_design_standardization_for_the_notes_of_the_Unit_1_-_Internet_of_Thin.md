
### IoT/M2M systems layers and design standardization for the notes of the Unit 1 - Internet of Things (IoT) in the subject of Internet of Things

1. **Physical Layer:** The physical layer of the IoT/M2M system consists of the hardware and software components that enable the communication of data between different devices. It includes the hardware components such as sensors, actuators, and communication modules, as well as the software components such as protocols and communication protocols.

2. **Network Layer:** The network layer is responsible for establishing and managing the network connections between the different devices. It includes the protocols and communication protocols that are used to establish the communication between devices.

3. **Application Layer:** The application layer is responsible for providing the applications and services that are used by the users. It includes the applications, services, and tools that are used to make the communication between the different devices possible.

4. **Security Layer:** The security layer is responsible for ensuring the security of the data that is being exchanged between the different devices. It includes the encryption, authentication, and authorization protocols that are used to protect the data from unauthorized access.

5. **Data Layer:** The data layer is responsible for collecting, storing, and managing the data that is exchanged between the different devices. It includes the databases, storage systems, and data management systems that are used to store and manage the data.

6. **Mnemonics and Learning Tricks:**
- **IoT/M2M** stands for **Internet of Things/Machine to Machine**
- **Physical Layer** is responsible for the **hardware and software components** that enable the communication of data between different devices
- **Network Layer** is responsible for **establishing and managing** the network connections between the different devices
- **Application Layer** is responsible for providing the **applications and services** that are used by the users
- **Security Layer** is responsible for ensuring the **security of the data** that is being exchanged between the different devices
- **Data Layer** is responsible for **collecting, storing, and managing** the data that is exchanged between the different devices
