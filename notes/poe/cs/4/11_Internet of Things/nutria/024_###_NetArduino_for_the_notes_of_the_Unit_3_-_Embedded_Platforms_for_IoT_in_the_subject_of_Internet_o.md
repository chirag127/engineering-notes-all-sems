
### NetArduino for the notes of the Unit 3 - Embedded Platforms for IoT in the subject of Internet of Things

NetArduino is an open source embedded platform for the Internet of Things (IoT). It is based on the Arduino platform and is designed to be a low-cost, low-power, and easy-to-use platform for creating connected devices.

**Key Features:**
* Low-cost and low-power
* Easy to use
* Open source
* Arduino compatible
* Built-in Wi-Fi connectivity
* Supports a variety of sensors and actuators
* Supports multiple programming languages

**Mnemonics and Learning Tricks:**
* NetArduino is a great platform for learning about embedded systems and the Internet of Things.
* Remember that NetArduino is based on the Arduino platform, so many of the same principles apply.
* Think of NetArduino as a way to quickly and easily create connected devices with minimal effort.
* Keep in mind that NetArduino is open source and can be used to create a variety of projects.

**Advantages:**
* Low cost and low power consumption
* Easy to use and program
* Open source and Arduino compatible
* Built-in Wi-Fi connectivity
* Supports a variety of sensors and actuators

**Disadvantages:**
* Limited memory and storage
* Limited processing power
* Limited support for some programming languages

**Applications:**
* Home automation
* Wearable devices
* Industrial automation
* Robotics
* Automated vehicles
* Smart cities
