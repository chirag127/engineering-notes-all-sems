### Basics of Virtualization for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

Virtualization is a crucial aspect of cloud computing technology. It enables the creation of virtual versions of resources such as operating systems, storage devices, and servers. These virtual resources can then be used by multiple users and applications simultaneously, making the best use of physical resources and reducing costs.

Here are some basics of virtualization that you should know for the Cloud Enabling Technologies Service Oriented Architecture unit:

1. **Hypervisor**: Also referred to as a Virtual Machine Manager (VMM), it is the software that creates and manages virtual machines (VMs). It allows multiple VMs to run on a single physical machine and ensures that they operate independently of each other.

2. **Virtual Machines**: They are the virtual versions of computers that run on top of a physical machine. Each VM has its own operating system, hardware resources, and applications. This enables multiple users to use the same physical machine without interfering with each other.

3. **Virtualization Types**: There are two types of virtualization - Full Virtualization and Para-virtualization. Full virtualization allows guest OSs to run on top of the hypervisor without any modification. Para-virtualization requires modifications to the guest OSs to enable them to communicate with the hypervisor.

4. **Advantages of Virtualization**: Virtualization provides many benefits, including:

   - Efficient use of resources
   - Reduced hardware costs
   - Faster deployment of services and applications
   - Improved scalability and flexibility
   - Increased security and isolation

5. **Disadvantages of Virtualization**: Despite its benefits, virtualization also has some drawbacks, including:

   - Increased complexity of management
   - Reduced performance due to the overhead of the hypervisor
   - Security risks due to the sharing of physical resources
   - Dependency on the hypervisor

6. **Applications of Virtualization**: Virtualization finds its applications in various areas, including:

   - Cloud computing
   - Server consolidation
   - Disaster recovery
   - Testing and development
   - High availability and fault tolerance

Learning Tricks:

- Mnemonic: HVM (Hardware Virtual Machine) stands for Full Virtualization and PVM (Para Virtual Machine) stands for Para-virtualization.
- To remember the advantages and disadvantages of virtualization, you can use the acronym 'FIRS' - Flexibility, Improved scalability, Reduced costs, Security risks. Similarly, 'CRID' - Complexity, Reduced performance, Increased dependency, Security risks can be used to remember the disadvantages.
