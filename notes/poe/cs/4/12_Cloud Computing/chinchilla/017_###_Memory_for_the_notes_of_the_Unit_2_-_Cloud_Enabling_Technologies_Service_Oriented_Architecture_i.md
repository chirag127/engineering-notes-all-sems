### Memory for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

Service Oriented Architecture (SOA) is an architectural approach that enables the creation of services that can be accessed over a network. In the context of Cloud Computing, SOA is one of the Enabling Technologies that make Cloud Computing possible. Here are some key points to remember about SOA in Cloud Computing:

1. SOA defines a set of principles and guidelines for designing and developing software systems as a set of loosely coupled, reusable services.

2. In an SOA system, each service is a self-contained unit of functionality that can be accessed by other services or applications over a network.

3. SOA promotes the separation of concerns, which means that different services can focus on different aspects of the overall functionality of the system.

4. SOA is technology-agnostic, which means that it can be implemented using any programming language, platform, or operating system.

5. SOA relies on standard protocols and interfaces such as SOAP, REST, and WSDL to enable communication between services.

6. SOA supports the creation of composite applications, which are applications that are composed of multiple services.

7. SOA enables the reuse of services, which can reduce development time and costs.

8. SOA supports the creation of distributed systems, which can improve fault-tolerance and scalability.

9. Some of the challenges of SOA include the need for careful design and governance to ensure that services are reusable and interoperable, and the need to manage the complexity of large-scale SOA systems.

Mnemonics and Learning Tricks:
- Remember the acronym "SOAP" for one of the standard protocols used in SOA: Simple Object Access Protocol.
- Think of SOA as a "lego set" for building software systems, where each service is a lego piece that can be assembled in different ways to create different applications.
- Think of composite applications as "Frankenstein" applications, where different services are stitched together to create a new application.
