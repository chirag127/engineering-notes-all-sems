## Unit 3 - Cloud Architecture, Services And Storage

Cloud computing has revolutionized the way businesses and individuals store and access their data. This unit focuses on the architecture, services, and storage options available in the cloud.

### Cloud Architecture

Cloud architecture refers to the design of the cloud computing system. The architecture of a cloud computing system consists of various components that work together to provide a seamless and efficient experience to the users. Some of the key components of cloud architecture include:

- Cloud Service Providers (CSPs): Companies that provide cloud computing services to customers.
- Cloud Consumers: Individuals or businesses who use cloud computing services.
- Cloud Service Models: Different types of cloud services, such as Infrastructure as a Service (IaaS), Platform as a Service (PaaS), and Software as a Service (SaaS).
- Cloud Deployment Models: Different ways of deploying cloud services, such as Public Cloud, Private Cloud, Hybrid Cloud, and Community Cloud.

### Cloud Services

Cloud services refer to the various services that are offered by cloud service providers. These services can be broadly classified into three categories:

- Infrastructure as a Service (IaaS): This service model provides virtualized computing resources, such as virtual machines, storage, and networking, to customers.
- Platform as a Service (PaaS): This service model provides a platform for customers to develop, run, and manage applications without the need for infrastructure management.
- Software as a Service (SaaS): This service model provides software applications that are hosted by the service provider and can be accessed by customers over the internet.

### Cloud Storage

Cloud storage refers to the storage of data on remote servers that can be accessed over the internet. Cloud storage offers several advantages over traditional on-premises storage, such as scalability, cost-effectiveness, and accessibility. Some of the popular cloud storage services include:

- Amazon S3: A scalable object storage service offered by Amazon Web Services (AWS).
- Google Cloud Storage: A scalable object storage service offered by Google Cloud Platform (GCP).
- Microsoft Azure Blob Storage: A scalable object storage service offered by Microsoft Azure.

#### Mnemonics and Learning Tricks

- For remembering the three cloud service models, use the mnemonic "IPS" as an acronym for IaaS, PaaS, and SaaS.
- To remember the popular cloud storage services, use the acronym "AGM" as a mnemonic for Amazon S3, Google Cloud Storage, and Microsoft Azure Blob Storage.
