### Cloud Characteristics for the notes of the Unit 1 - Introduction To Cloud Computing in the subject of Cloud Computing

Cloud computing has become an integral part of the IT infrastructure of many organizations. It offers numerous benefits such as scalability, cost-effectiveness, and high availability. However, not all cloud services are created equal. To understand the different types of cloud services and their capabilities, it is important to understand the cloud characteristics.

#### Cloud Characteristics

1. **On-demand self-service**: Users can provision and de-provision computing resources such as storage, processing power, and network bandwidth on an as-needed basis without any human intervention.

2. **Broad network access**: Cloud services can be accessed from any device with internet connectivity, such as desktops, laptops, tablets, and smartphones.

3. **Resource pooling**: Computing resources are pooled together to serve multiple users, with different physical and virtual resources dynamically assigned and reassigned according to demand. 

4. **Rapid elasticity**: Resources can be quickly scaled up or down to meet changing demand. This allows for efficient resource utilization and cost savings.

5. **Measured service**: Cloud providers monitor and measure resource usage and provide customers with detailed billing and usage reports. This allows customers to optimize their usage and reduce costs.

#### Mnemonic

One way to remember the cloud characteristics is to use the acronym "ORB2M":

- On-demand self-service
- Resource pooling
- Broad network access
- Rapid elasticity
- Measured service

#### Learning Trick

A helpful way to remember the cloud characteristics is to associate each characteristic with a visual image:

1. On-demand self-service: Imagine a vending machine where you can choose the resources you need and the machine automatically provides them to you.

2. Resource pooling: Picture a swimming pool where the water is shared by multiple swimmers, but each swimmer has their own lane.

3. Broad network access: Think of a network of roads that connect different cities, allowing people to travel between them easily.

4. Rapid elasticity: Imagine a balloon that can quickly expand or contract to accommodate changes in air pressure.

5. Measured service: Picture a gas pump that displays the amount of fuel you've pumped and the cost per gallon.
