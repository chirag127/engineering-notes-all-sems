## Unit 5 - Cloud Technologies And Advancements Hadoop

Cloud Technologies refer to the delivery of computing services over the internet, including storage, databases, software, and analytics. Hadoop is an open-source framework designed for distributed storage and processing of large-scale data sets on commodity hardware. In this unit, we will learn about the cloud technologies and advancements in Hadoop.

### Cloud Computing

Cloud computing is a model for enabling ubiquitous, convenient, on-demand network access to a shared pool of configurable computing resources that can be rapidly provisioned and released with minimal management effort or service provider interaction. The following are some of the key concepts related to cloud computing:

- Service Models: Cloud computing has three service models - Infrastructure as a Service (IaaS), Platform as a Service (PaaS), and Software as a Service (SaaS).
- Deployment Models: Cloud computing has four deployment models - Public cloud, Private cloud, Hybrid cloud, and Community cloud.
- Characteristics: Cloud computing has five essential characteristics - On-demand self-service, Broad network access, Resource pooling, Rapid elasticity, and Measured service.

### Hadoop

Hadoop is an open-source framework designed for distributed storage and processing of large-scale data sets on commodity hardware. The following are some of the key concepts related to Hadoop:

- Hadoop Distributed File System (HDFS): HDFS is a distributed file system that provides high-throughput access to application data. It is designed to be fault-tolerant and can scale to petabytes of data.
- MapReduce: MapReduce is a programming model for processing large data sets. It is designed to be fault-tolerant and can scale to petabytes of data.
- Hadoop Ecosystem: Hadoop ecosystem consists of various tools and services that can be used with Hadoop, such as Pig, Hive, HBase, and Spark.

### Advancements in Hadoop

Hadoop has evolved significantly over the years, and the following are some of the advancements in Hadoop:

- Hadoop 2: Hadoop 2 introduced YARN (Yet Another Resource Negotiator), which separates resource management from job scheduling/monitoring. This allows Hadoop to support a broader range of applications and workloads.
- Hadoop 3: Hadoop 3 introduced several improvements, such as support for erasure coding, GPU offloading, and container re-use.
- Hadoop on Cloud: Hadoop can now be deployed on cloud platforms such as Amazon Web Services (AWS), Google Cloud Platform (GCP), and Microsoft Azure. This allows users to take advantage of cloud benefits such as scalability, elasticity, and pay-as-you-go pricing.

### Mnemonics and Learning Tricks

- Mnemonic for cloud computing service models: IaaS - "Infrastructure as a Service" can be remembered as "I am renting Infrastructure"; PaaS - "Platform as a Service" can be remembered as "Platform is Provided as a Service"; SaaS - "Software as a Service" can be remembered as "Software is Available as a Service".
- Mnemonic for cloud computing deployment models: Public cloud - "Public" can be remembered as "People"; Private cloud - "Private" can be remembered as "Personal"; Hybrid cloud - "Hybrid" can be remembered as "Combination"; Community cloud - "Community" can be remembered as "Cooperation".
