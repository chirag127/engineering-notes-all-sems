### Virtualization Support and Disaster Recovery for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

Virtualization is a key technology that enables cloud computing by allowing multiple virtual machines (VMs) to run on a single physical machine. In cloud environments, virtualization is used to provide multi-tenancy, resource pooling, and elasticity. Disaster recovery is also an important aspect of cloud computing, as it ensures that data and services are available even in the event of a catastrophic failure.

Here are some key points to keep in mind when studying virtualization support and disaster recovery in the context of cloud computing:

1. Virtualization support:
   - Virtualization is a key technology that enables cloud computing by allowing multiple virtual machines (VMs) to run on a single physical machine.
   - In cloud environments, virtualization is used to provide multi-tenancy, resource pooling, and elasticity.
   - Virtualization technologies include hypervisors, which allow multiple operating systems to run on a single machine, and containers, which allow multiple applications to run on a single operating system.

2. Disaster recovery:
   - Disaster recovery is the process of restoring data and services in the event of a catastrophic failure.
   - Cloud environments typically have multiple layers of redundancy and failover mechanisms to ensure that data and services are available even in the event of a catastrophic failure.
   - Disaster recovery strategies include backup and restore, replication, and failover to a secondary site.

3. Virtualization and disaster recovery:
   - Virtualization is an important aspect of disaster recovery, as it allows for quick and easy migration of VMs to a different physical machine in the event of a failure.
   - Virtualization also allows for the creation of snapshots, which can be used for backup and restore purposes.
   - Disaster recovery strategies for virtualized environments include replication of VM images to a secondary site and failover to a secondary site.

Mnemonics and learning tricks:

- A simple mnemonic for virtualization support is "Virtually a single machine can run multiple machines"
- A useful trick for remembering disaster recovery strategies is "BFR" - Backup, Replication, Failover.
