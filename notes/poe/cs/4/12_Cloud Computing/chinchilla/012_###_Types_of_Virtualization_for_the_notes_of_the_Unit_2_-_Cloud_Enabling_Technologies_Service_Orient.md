### Types of Virtualization for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

Virtualization is the process of creating a virtual version of something, such as a server, storage device, network or operating system. Virtualization is a key technology that enables cloud computing by allowing multiple virtual machines to run on a single physical machine. There are different types of virtualization that are used in cloud computing. In this section, we will discuss the various types of virtualization.

1. Server Virtualization:
   Server virtualization is the process of dividing a physical server into multiple virtual servers. Each virtual server operates independently of the others, allowing multiple operating systems to run on a single physical server. This type of virtualization enables better utilization of server resources, reduces hardware costs, and improves server availability.

2. Storage Virtualization:
   Storage virtualization is the process of combining multiple physical storage devices into a single logical storage device. This enables better utilization of storage resources, improves storage performance, and simplifies storage management. With storage virtualization, multiple physical storage devices can be managed as a single logical entity, making it easier to manage and allocate storage resources.

3. Network Virtualization:
   Network virtualization is the process of creating multiple virtual networks on a single physical network. This enables better utilization of network resources, improves network performance, and simplifies network management. With network virtualization, multiple virtual networks can be created on a single physical network, allowing each virtual network to operate independently of the others.

4. Desktop Virtualization:
   Desktop virtualization is the process of creating multiple virtual desktops on a single physical desktop. This enables better utilization of desktop resources, improves desktop security, and simplifies desktop management. With desktop virtualization, multiple virtual desktops can be created on a single physical desktop, allowing each virtual desktop to operate independently of the others.

5. Application Virtualization:
   Application virtualization is the process of running applications on a virtual machine, rather than on a physical machine. This enables better utilization of application resources, improves application availability, and simplifies application management. With application virtualization, multiple applications can be run on a single virtual machine, allowing each application to operate independently of the others.

Mnemonics and Learning Tricks:

- For remembering the types of virtualization, you can use the mnemonic SNADA, which stands for Server, Network, Application, Desktop, and Storage virtualization.
- Another trick for remembering the types of virtualization is to think of them as different layers of a cake, with server virtualization at the bottom, storage virtualization in the middle, and network, desktop, and application virtualization on top.
