### Elasticity in Cloud

- Elasticity refers to the ability of a system to dynamically scale resources, up and down, as the workload demand changes.
- In cloud computing, elasticity is achieved through auto-scaling. The cloud platform automatically scales the resources up or down based on metrics like CPU utilization, memory usage, etc.
- This ensures that users always have enough resources to meet their needs and are not paying for unused resources.
- Some key benefits of elasticity in cloud computing are:
- Cost efficiency - User pays only for what they use. Resources can be scaled down when not needed to save costs.
- Improved performance - Additional resources can be instantly scaled up to handle load spikes and meet performance requirements.
- High availability - Elasticity ensures that the application has the required resources to function even under heavy loads or traffic.

 Mnemonics:
Think of elastic as elastic band which can stretch and shrink. Similarly, cloud elasticity stretches and shrinks resources as needed.

Examples:
- An e-commerce website scaling up number of servers during sale season to handle high traffic.
- A company scaling down servers during off-hours to save costs.

Applications:
Elasticity is crucial for applications with variable or unpredictable workloads like e-commerce websites, streaming applications, etc. It enables such applications to function with high performance and availability at optimal costs.
