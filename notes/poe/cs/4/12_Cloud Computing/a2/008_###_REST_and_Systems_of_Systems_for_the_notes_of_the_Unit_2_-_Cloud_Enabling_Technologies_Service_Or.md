### REST and Systems of Systems for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

REST (Representational State Transfer) is an architectural style for building web services. It relies on a stateless, client-server, cacheable communications protocol over HTTP. REST uses HTTP requests to get, put, post and delete data.

Benefits of REST:

- Simplicity: REST uses simple HTTP methods explicitly defined by the protocol
- Scalability: REST can handle huge numbers of requests due to being stateless
- Flexibility: REST can integrate with any system that can speak HTTP
- Interoperability: REST uses existing standards and can integrate with languages and systems

Examples of REST APIs:

- Twitter API
- Facebook API
- Google Maps API

A system of systems refers to multiple systems that have their own components and sub-systems connected and working together as a system to achieve a higher level goal. In cloud computing, combining multiple services together in this way allows complex applications and solutions to be created. For example:

- Using a database service, analytics service and machine learning service together to build an application
- Combining infrastructure services, storage services and serverless functions to process data

Systems of systems in cloud computing are enabled by APIs and architectural styles like REST that allow the different services and systems to communicate and interconnect. This is a key part of the service oriented architecture of cloud platforms.

Advantages of systems of systems:

- Reuse of components
- Flexibility to swap out and change components
- Complex solutions can be built from combining multiple systems
- Scalability through distributing work across systems

Disadvantages of systems of systems:

- Complex to manage
- Difficult to debug and troubleshoot issues
- Tight coupling between systems can cause cascading failures
- Security complexity increases

 Mnemonics/Learning tricks:
 - "REST uses simple methods to GET, PUT, POST and DELETE data"
 - "Systems of systems achieve a higher goal by connecting systems together"
