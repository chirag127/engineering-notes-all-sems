### laaS for the notes of the Unit 3 - Cloud Architecture, Services And Storage in the subject of Cloud Computing

* **IaaS**: Infrastructure as a Service. It provides hardware resources like servers, storage and networking over the internet. Some of the offerings are:
**Amazon EC2**: Provides virtual servers to scale up and down based on requirements.
**Amazon S3**: Provides scalable object storage.
** mnemonics**: **I** need **I**nfrastructure to build my services.
**advantages**: Highly Scalable and Flexible. Pay as you go model.
**disadvantages**: Complex to Manage and patch the infrastructure.

* **PaaS**: Platform as a Service. It provides a computing platform like operating system, software libraries and programming languages over the internet. Some examples are:
**AWS Lambda**: Provides serverless computing to run code.
**Heroku/Google App Engine**: Provides platform to deploy applications.
** mnemonics**: On the **P**latform, my services will be launched.
**advantages**: Faster development and deployment of applications. Scalability and Availability.
**disadvantages**: Limited set of languages and frameworks available. Vendor lock-in.

* **SaaS**: Software as a Service. It provides software applications over the internet. Some examples are:
**Google Drive/MS Office 365**: Provides productivity suites software.
**Salesforce/G Suite**: Provides business applications.
** mnemonics**: My **S**oftware services can be used from anywhere.
**advantages**: Convenient to access applications from anywhere. No installation or maintenance required.
**disadvantages**: Limited customization options. Rely on vendors for SLAs and security.

* **Storage Services**: Provide scalable and reliable storage over the internet. Some examples are:
**Amazon S3**: Object storage to store and retrieve data.
**Amazon EBS/EFS**: Block/File storage to store data for EC2 instances.
**Azure Storage**: Blob, File, Queue and Table storage for applications.
** mnemonics**: My data is stored **S**afely in the cloud.
**advantages**: Scalable and highly available. Pay as you go model.
**disadvantages**: Data can get locked in to a particular cloud vendor. Complex permissions and access control management.
