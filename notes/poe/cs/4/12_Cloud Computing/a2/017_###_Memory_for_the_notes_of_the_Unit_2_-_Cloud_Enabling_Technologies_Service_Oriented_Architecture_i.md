### Memory for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

- SOA stands for Service Oriented Architecture. It is a style of software design where applications are built as a set of independent services that can be accessed without knowledge of their internal implementation.
- Services in SOA communicate with each other by passing data from one service to another in a standardized way (e.g. XML, JSON).
- The key principles of SOA are:
-- Standardized service contract
-- Loose coupling
-- Service abstraction
-- Service reusability
-- Service composability
- Benefits of SOA:
-- Increased interoperability
-- Increased reusability
-- Reduced maintenance
-- Platform independence
-- Business and IT alignment
- Examples of SOA:
-- Exposing business logic/data as web services
-- Microservices architecture
- Disadvantages of SOA:
-- Can be complex to implement
-- Performance overhead due to XML processing
-- Versioning challenges with services
-- Security concerns
- To remember: SOA is about building applications using independent services that can communicate in a standardized way. The key principles revolve around standardization, loose coupling and reusability. The main benefits are increased interoperability and reusability while disadvantages include complexity and overhead.
