### Architectural Design Challenges for the notes of the Unit 3 - Cloud Architecture, Services And Storage in the subject of Cloud Computing

- Scalability: The cloud infrastructure must be able to scale up or down dynamically as per the demand. It should be able to accommodate sudden spikes or drops in traffic. This can be achieved through techniques like auto-scaling, load balancing, etc.
- Reliability: The cloud infrastructure must be highly reliable and fault-tolerant. It should have mechanisms to tackle server failures, network issues, etc. This can be achieved through replication, backups, disaster recovery plans, etc.
- Latency: The cloud infrastructure must provide low latency or delay. This is critical for applications like real-time streaming, gaming, etc. This can be achieved through caching, CDNs, server location optimization, etc.
- Security: The cloud infrastructure must provide robust security and protection against threats like DDoS attacks, data breaches, etc. This can be achieved through firewalls, encryption, access control, and other security measures.
- Data isolation: In a multi-tenant cloud environment, data isolation is important to prevent leakage of data between different tenants. This can be achieved through mechanisms like virtualization, secure shells, access controls, etc.

Some mnemonics and learning tricks for remembering the challenges:

- **SCaLeRS**: **S**calability, **C**ache, **a**uto-scale, **L**atency, **R**eliability, **S**ecurity
- **CARSS**: **C**ache, **A**ccess control, **R**eplication, **S**ecurity, **S**calability

The advantages of addressing these challenges are increased performance, availability, and security of cloud applications. The disadvantages are increased complexity and cost of cloud infrastructure.

Examples of applications where these challenges are critical:
- Real-time applications like streaming, gaming, etc. require low latency.
- E-commerce sites require high scalability and reliability to handle traffic spikes.
- Healthcare applications require high security and data isolation.
