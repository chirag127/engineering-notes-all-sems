### Resource Provisioning Methods
The following are the main resource provisioning methods used in cloud computing:

1. **Static Provisioning:** In static provisioning, the cloud consumer requests for a fixed amount of resources from the cloud provider. These resources are allocated permanently to the consumer. The consumer is charged based on the total resources allocated even if all the resources are not utilized. Static provisioning is simple but leads to wastage of resources and increased costs for the consumer.

2. **Dynamic Provisioning:** In dynamic provisioning, the resources are allocated to the consumer on demand. The consumer requests for resources as and when required and is charged only for the resources utilized. This method efficiently utilizes the resources and reduces costs for the consumer. However, the cloud provider has to constantly monitor the resource usage and allocate/de-allocate resources leading to overhead costs.

Mnemonics:

- Static: Fixed resources, more waste
- Dynamic: On-demand resources, more efficient

Advantages of Dynamic Provisioning:
- Optimal resource utilization and reduced costs for the consumer
- Scalability - Consumer can scale up or scale down resources easily based on demand
- Flexibility - Consumer has more control over the resources

Disadvantages of Dynamic Provisioning:
- Increased overhead for the cloud provider to constantly monitor and allocate resources
- Can lead to performance issues if resources are not allocated on time

Applications: Dynamic provisioning is suitable for workload that is variable and unpredictable. It is preferred for most cloud implementations. Static provisioning can be used for workloads with consistent and predictable resource needs.
