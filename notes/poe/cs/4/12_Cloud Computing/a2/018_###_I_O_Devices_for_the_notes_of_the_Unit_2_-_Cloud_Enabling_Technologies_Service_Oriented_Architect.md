### I/O Devices for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

I/O devices are required to enter input into a computer and produce output from a computer. For cloud computing, the following I/O devices are important:

1. Keyboard and Mouse: Keyboard and mouse are input devices used to enter data and instructions into a computer. They are used to interact with the cloud computing system and applications.

2. Monitor: Monitor is an output device used to display the results and output of the cloud computing system and applications. It is used to view the graphical user interface and output.

3. Microphone: Microphone is an input device used to enter audio such as voice input into the cloud computing system. It is used for applications such as voice recognition and voice assistants.

4. Speakers: Speakers are output devices used to produce audio output from the cloud computing system. They are used to play audio such as music, notifications, and voice assistants.

5. Webcam: Webcam is an input device used to capture video. It can be used for video conferencing and surveillance applications in cloud computing.

6. Storage devices: Storage devices such as hard drives and SSDs are used to store data in the cloud computing system. They provide persistent storage of data and applications.

Some tips to remember the I/O devices:

- Think of I/O devices as doors of a house: Input is entering the house and output is exiting the house.
- The first 3 letters of input and output can be used as a mnemonic: In-Keyboard, Mouse, Microphone and Out-Monitor, Speakers.
- The uses of the I/O devices can help remember them: Keyboard and mouse are used to interact, monitor displays output, microphone takes voice input, speakers produce audio output, webcam captures video input, storage stores data.

The I/O devices are essential interfaces between the user and the cloud computing system. They help enter data and instructions into the system and obtain the results from the system.
