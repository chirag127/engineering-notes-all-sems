## Unit 4 - Resource Management And Security In Cloud

### Resource Management

- Allocation of resources (compute, storage, network) to tenants/users/accounts.
- Monitoring resource usage and optimizing utilization.
- Elasticity - scaling resources up or down as per demand.
- Chargeback/Billing - accounting for resource usage and cost allocation.

Key concepts:

- Tenants/Accounts/Users - Logical isolation of resources.
- Quotas - Limit resource usage per tenant/account.
- Thresholds - Trigger scaling/notifications when resource usage crosses threshold.
- Resource pools - Logical grouping of resources.
- Elasticity - Scale up/down, expand/contract, grow/shrink resources dynamically.
- Chargeback - Accounting and cost allocation for resource usage.

### Security

- IAM (Identity and Access Management) - Control access to resources.
- RBAC (Role Based Access Control) - Assign privileges/permissions to roles.
- MFA (Multi Factor Authentication) - Additional layer of security using multiple factors.
- Encryption - Data encryption at rest and in transit.
- Web application firewalls - Protect against web based threats.
- DDoS (Distributed Denial of Service) mitigation - Protect against DDoS attacks.
- Vulnerability management - Identify and patch vulnerabilities.
- Compliance - Adhere to security standards and best practices.
- Auditing - Track security related events.
- Monitoring - Detecting anomalies and suspicious activities.

Advantages:

- On demand scalability.
- Optimized resource utilization and cost efficiency.
- High availability and redundancy.
- Automated deployment and management.
- Flexibility and agility.
- Global coverage and access.

Disadvantages:

- Vendor lock-in.
- Performance unpredictability.
- Complex architecture.
- Security concerns.
- Technical debt and migration challenges.

Examples:

- AWS (Amazon Web Services)
- GCP (Google Cloud Platform)
- Azure (Microsoft Azure)

Applications:

- Web applications
- Mobile applications
- Big data and analytics
- AI and ML
- IoT
- High performance computing
