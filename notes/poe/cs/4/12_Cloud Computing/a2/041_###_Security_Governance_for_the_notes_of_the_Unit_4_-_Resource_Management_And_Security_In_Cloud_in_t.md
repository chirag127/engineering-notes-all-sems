### Security Governance for the notes of the Unit 4 - Resource Management And Security In Cloud in the subject of Cloud Computing

- Cloud security governance refers to the overall framework that ensures that the cloud platform and services are properly secured and meeting security requirements. Some key aspects of cloud security governance are:
- Define security policies and procedures: Clearly define security policies, controls, and procedures for the cloud environment. These should be in line with the organization's security requirements and applicable laws/regulations.
- Assign security roles and responsibilities: Clearly assign security-related roles and responsibilities to different stakeholders like cloud customers, providers, auditors, etc.
- Monitor compliance: Continuously monitor compliance with security policies and take corrective actions if any discrepancies are found. This can include regular audits, security assessments, and incident monitoring.
- Risk management: Proactively identify and manage various risks to the security of cloud environment like data breaches, account hijacks, etc. Risk management strategies should be in place to mitigate high-impact risks.
- Adapt to changes: The cloud environment is dynamic and continues to evolve. The security governance framework should be able to adapt to changes in the cloud platform, new services, and new security threats. Periodic reviews and updates to governance controls are necessary.

Some tips for remembering:

- Think of governance as an overarching 'umbrella' that ensures security
- Key aspects spell out 'DEFCRM' - Define, Assign, Monitor, Risk management, Adapt
- Clear definition of roles and responsibilities is key to effective governance
- Continuous monitoring and adaptation to changes are necessary in dynamic cloud environments
