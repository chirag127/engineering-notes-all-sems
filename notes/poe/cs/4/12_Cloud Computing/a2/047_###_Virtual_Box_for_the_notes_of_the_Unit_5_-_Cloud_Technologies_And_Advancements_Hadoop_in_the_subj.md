### Virtual Box for the notes of the Unit 5 - Cloud Technologies And Advancements Hadoop in the subject of Cloud Computing

- VirtualBox is a general-purpose full virtualizer for x86 hardware, targeted at server, desktop and embedded use.
- It is a cross-platform virtualization software which allows you to run multiple virtual machines with different operating systems on a single physical machine.
- Each virtual machine has private virtualized hardware: a network card, disk, graphics adapter, etc.
- You can freely move virtual machines between hosts, provided that the host supports the same virtualization software.
- Advantages:
    - It's free and open source.
    - It's easy to install and use.
    - It supports a large number of guest operating systems including but not limited to Windows, Linux, Solaris, OS/2, etc.
    - Snapshots allow you to save a VM state and revert to it later if needed.
    - Seamless mode allows applications running in a VM to be embedded onto your host desktop.
- Disadvantages:
    - Performance overhead due to virtualization. VMs typically run a little slower than real hardware.
    - Limited hardware support. Not all hardware devices can be virtualized.
    - Software bugs can affect both host and guests.
- Applications:
    - Software testing and debugging.
    - Running different OSs for various needs.
    - Virtualization for server consolidation.
    - Creating sandbox environments.
    - Education and training.

- Mnemonics:
    - VBox - Think of a box containing many virtual machines.
    - Full virtualizer - It virtualizes the hardware to run OSs, not just some services.
- Learning tricks:
    - Practice installing and using multiple VMs to get familiar with the environment and options.
    - Compare performance of VMs to real hardware to understand the overhead.
    - Play around with snapshots and seamless mode to see their benefits.
