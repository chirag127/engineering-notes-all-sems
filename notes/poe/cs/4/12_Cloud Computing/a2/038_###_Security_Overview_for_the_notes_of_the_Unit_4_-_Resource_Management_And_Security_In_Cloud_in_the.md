### Security Overview for the notes of the Unit 4 - Resource Management And Security In Cloud in the subject of Cloud Computing

- Cloud computing moves the application software and databases to the large data centers, where the management of the data and services may not be fully trustworthy. Hence, it is important to ensure security in the cloud.
- The major security issues in cloud computing are:
- Data protection: Data in the cloud is accessed over the internet and there are chances of malicious attacks to steal sensitive data. Data should be encrypted before storing in the cloud.
- Identity and access management: Proper identity and access controls should be in place to authenticate users and give authorized access to resources.
- Application security: Vulnerabilities in the application software and APIs can be exploited to attack the cloud infrastructure and access customer data. Regular security audits and patching of the applications should be done.
- Compliance: The cloud service provider should comply with regulations like GDPR, HIPAA, etc. and maintain audit trails of security incidents and user activities.
- Isolation: Data and resources of different customers should be isolated and protected from unauthorized access by other users of the cloud.
- Recovery: The cloud service provider should have disaster recovery mechanisms in place to restore services and data in the event of attacks, disasters, or incidents.
- Monitoring: Continuous monitoring of the security of the cloud infrastructure and applications is necessary to detect and prevent security breaches.

Some useful mnemonics and tricks to remember the security issues are:
- DICE - Data protection, Identity management, Compliance, Encryption
- PIAA - Patching apps, IAM, Auditing, Application security

However, these mnemonics may not be easy to remember for everyone. It is better to understand the security issues in depth rather than relying on mnemonics. Detailed diagrams and examples can also be helpful to understand the security concepts in cloud computing.
