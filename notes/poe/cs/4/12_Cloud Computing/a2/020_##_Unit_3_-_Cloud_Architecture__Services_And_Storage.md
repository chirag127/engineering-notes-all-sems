## Unit 3 - Cloud Architecture, Services And Storage

### Cloud Architecture
- Cloud architecture refers to the components and subcomponents required for cloud computing. It typically consists of a front end platform, back end platforms, a network, and a cloud-based delivery.
- The front end platform (fat client, thin client, mobile app) is what the user interacts with to access the cloud services.
- The back end platforms include servers, storage, networking, virtualization, operating systems, etc. that power the cloud services.
- The network connects the front end and back end and can be public or private.
- Cloud-based delivery refers to services being delivered via the internet.

**Mnemonics:** CANS - Components, Applications, Network, Servers. Front end, back end, network, delivery.

### Cloud Services
- The three main types of cloud services are:
-- Infrastructure as a Service (IaaS) - Provides basic storage and computing resources.
-- Platform as a Service (PaaS) - Provides a computing platform allowing customers to develop, run, and manage applications.
-- Software as a Service (SaaS) - Provides access to application software and databases.
- Examples of IaaS include Amazon EC2, Microsoft Azure Virtual Machines. Examples of PaaS include Amazon Elastic Beanstalk, Google App Engine. Examples of SaaS include Google Workspace, Microsoft Office 365.

**Learning Trick:** Remember IaaS as the bottom layer, then PaaS, then SaaS as the top layer. IaaS deals with infrastructure, PaaS provides a platform, and SaaS provides software.

### Cloud Storage
- The three main types of cloud storage are:
-- Object storage - Stores data as objects with an ID, can store large amounts of unstructured data.
-- File storage - Stores data in a hierarchy of files and folders, can be accessed via a mount point.
-- Block storage - Stores data as blocks on a virtual hard disk, can be attached to cloud VMs.
- Cloud storage is highly scalable, available, and durable. It is a key part of cloud architecture and enables the delivery of cloud services.

**Advantages:** Scalability, availability, durability.
**Disadvantages:** Vendor lock-in, cost can increase with use.
**Applications:** File sharing, database storage, backup and archiving, Web serving.
