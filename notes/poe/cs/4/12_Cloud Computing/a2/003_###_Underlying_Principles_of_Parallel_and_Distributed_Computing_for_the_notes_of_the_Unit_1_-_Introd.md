### Underlying Principles of Parallel and Distributed Computing

- Parallel Computing: Performing multiple computations simultaneously to solve a problem faster. It uses multiple CPU cores or processors to achieve parallelism. Some key principles and techniques of parallel computing are:
-- Divide and conquer: Breaking down a large problem into smaller subproblems that can be solved concurrently.
-- Task parallelism: Different tasks of a problem are executed simultaneously on different cores or processors.
-- Data parallelism: The same task is executed on different data chunks in parallel.
- Distributed Computing: Splitting a large computational problem across multiple interconnected computers (nodes) to achieve a common goal. Key principles are:
-- Decentralization: The nodes operate independently and control is distributed.
-- latency and bandwidth: Consideration of communication time and throughput between nodes.
-- Fault tolerance: The system should be resilient to node failures and errors. Methods like replication and checkpointing are used.
-- Consistency: Ensuring all nodes have the same view of the data and system state. Methods like consensus and synchronization are used.

Some mnemonics and learning tricks for parallel and distributed computing:
- Parallel computing: More legs run faster (multiple processors running together).
- Divide and conquer: Break down to rise up (breaking down a problem leads to a solution).
- Task parallelism: Assigning tasks to workers (different tasks to different processors).
- Data parallelism: One task, multiple chunks (same task on different data parts).
- Distributed computing: United we stand, divided we compute (independent nodes working towards a common goal).
