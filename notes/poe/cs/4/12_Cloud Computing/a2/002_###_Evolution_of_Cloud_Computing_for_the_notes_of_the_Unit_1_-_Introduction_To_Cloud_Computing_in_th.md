### Evolution of Cloud Computing

The evolution of cloud computing can be traced through the following phases:

1.  Grid and Utility Computing - In the 1960s, the concept of utilities and grids was introduced. The idea was to provide computing resources as a metered service, just like electricity or water. However, the technology was not ready for this model to be implemented.
2.  Client-Server Computing - In the 1970s and 1980s, the client-server computing evolved. The servers became more powerful and able to handle requests from multiple clients. However, each client still had to maintain its own data and software.
3.  Application Service Provision (ASP) - In the 1990s, the ASP or application service provider model was introduced. In this model, service providers hosted software applications and made them available to customers over the internet. This was a precursor to SaaS services in cloud computing.
4.  On-Demand Resources and Pay-as-you-go - The key innovations that enabled cloud computing as we know today were the development of virtualization technology, service-oriented architecture, and the availability of high-speed networks. These allowed computing resources to be provided on-demand and as pay-as-you-go service over the internet. This is the cloud computing model that was popularized by Amazon Web Services in 2006.

Key advantages of the cloud computing model are on-demand scalability and reduced costs. The evolution has made powerful computing and storage resources available to all users and organizations, enabling many innovative applications and services.

 Mnemonics:

Grids and utilities -> share resources
Client-server -> split application into tiers
ASP -> host applications
On-demand and pay-as-you-go -> virtualization and high-speed networks enabled cloud computing

Applications:
- Web-based business services (Salesforce)
- Storage and backup (Dropbox)
- Infrastructure and platforms (AWS, Azure)
- Mobile and web applications

Disadvantages:
- Reliance on internet connectivity
- Vendor lock-in
- Security and privacy concerns
- Performance unpredictability
