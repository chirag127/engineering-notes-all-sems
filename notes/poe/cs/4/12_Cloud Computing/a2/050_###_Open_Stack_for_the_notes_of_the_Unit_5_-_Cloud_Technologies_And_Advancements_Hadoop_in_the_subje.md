### Open Stack for the notes of the Unit 5 - Cloud Technologies And Advancements Hadoop in the subject of Cloud Computing

OpenStack is a free and open-source software platform for cloud computing, mostly deployed as infrastructure-as-a-service (IaaS). It consists of interrelated components that control computing, storage, and networking resources throughout a datacenter—all managed through a dashboard.

Some key points about OpenStack are:

- It is used by private cloud operators and telcos to provide infrastructure as a service (IaaS).
- It has a modular architecture with various inter-operable components.
- It aims to offer complete automation of cloud infrastructure.
- It provides APIs for interacting with the cloud services.
- It has a large ecosystem of tools and partners.

The main components of OpenStack are:

1. Nova: Provides an API to manage and automate cloud compute resources. It handles scheduling, managing computing instances, etc.
2. Neutron: Provides network connectivity as a service between interface devices (e.g., vNICs) managed by other OpenStack services (e.g., Nova).
3. Cinder: Provides an API to manage block storage resources.
4. Glance: Provides an API to manage disk and server images.
5. Keystone: Provides an API for identity and access management.
6. Horizon: Provides a dashboard to access and manage various OpenStack services.

Some advantages of OpenStack are:

- Open source and highly customizable.
- Large ecosystem of supporting tools and vendors.
- Scalable and flexible architecture.
- Extensive API support.

Some disadvantages are:

- Steep learning curve.
- Complex deployment and maintenance.
- Limited load balancing and object storage capabilities.

Applications of OpenStack include:

- Public and private clouds.
- Telco clouds.
- Academic and research projects.
