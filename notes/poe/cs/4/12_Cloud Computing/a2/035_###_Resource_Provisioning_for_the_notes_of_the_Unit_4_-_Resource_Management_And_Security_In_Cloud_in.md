### Resource Provisioning

- Resource provisioning refers to the process of allocating and managing computing resources in a cloud environment.
- The cloud providers make computing resources available to the customers on-demand. The customers can request and release resources as per their requirements.
- The key steps involved in resource provisioning are:

1. Resource discovery - Discovering the availability of resources in the cloud infrastructure. The cloud management software keeps track of the resources and their utilization.
2. Resource allocation - Allocating the required resources to the customer based on the request and availability. The resources are allocated dynamically.
3. Resource configuration - Configuring the allocated resources as per the requirements of the customer. For example, configuring CPU, memory, storage, network bandwidth, etc.
4. Resource monitoring - Continuous monitoring of resource utilization and performance. The underutilized resources can be de-allocated and allocated to other customers.

- The goals of resource provisioning are:

- Maximizing resource utilization.
- Meeting customer performance expectations.
- Optimizing operational efficiency.
- Reducing costs through effective management of resources.

- The resource provisioning can be manual or automated. Automated provisioning using cloud management software is more efficient and cost-effective. It can quickly provision, de-provision, and scale resources based on demand.

- Advantages:

- On-demand self-service.
- Rapid elasticity.
- Meets variable demand.
- Pay-as-you-go model.
- Reduced costs.

- Disadvantages:

- Complex to implement.
- Challenging to optimize resource utilization.
- Require monitoring to avoid over or under-provisioning.

- Examples of cloud resource provisioning software: OpenStack, CloudStack, OpenNebula, etc.
