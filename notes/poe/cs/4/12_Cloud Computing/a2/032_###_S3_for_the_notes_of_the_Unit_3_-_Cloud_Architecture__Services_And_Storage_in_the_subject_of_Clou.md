### S3 - Simple Storage Service

- S3 is a cloud storage service provided by Amazon Web Services (AWS).
- It is highly scalable and provides secure and durable storage infrastructure.
- Data is stored in containers called buckets. Buckets are similar to folders in file systems.
- Objects containing data (files) are stored in S3 buckets. Each object has a unique key (name) and a version ID.
- S3 is:
    - Object based storage - Data is stored as objects (files)
    - Scalable - Can store from a few GB to PBs of data
    - Durable - 99.999999999% durability (11 9's)
    - Highly available - 99.99% availability
    - Secure - Authentication, access control, and encryption features
- Benefits:
    - Scalability - Easy to scale storage capacity and IOPS.
    - Cost effective - Pay for what you use.
    - Durability and availability - High durability and availability.
    - Security - Strong security features to protect data.
- Use cases:
    - Backup and archival storage.
    - Cloud storage for websites and mobile apps.
    - analytics and big data storage.
    - Media storage and distribution.
    - Software delivery.
- Mnemonics:
    - S3 = Store, Secure, Scale (to remember key features)
    - 11 9's = Almost indestructible data storage (to remember durability)
