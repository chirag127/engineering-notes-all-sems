### Four Levels of Federation for the notes of the Unit 5 - Cloud Technologies And Advancements Hadoop in the subject of Cloud Computing

The four levels of federation in cloud computing are:

1. **Data Level Federation**: Sharing of data across different cloud providers. The data is stored in a standard format across providers and applications can access the data easily. However, data security and privacy are major challenges.
2. **Application Level Federation**: Running of applications across multiple cloud providers. The applications are compatible to run on multiple platforms seamlessly. However, complex programming and compatibility issues may arise.
3. **Resource Level Federation**: Sharing of resources like compute and storage across multiple cloud providers. The resources are seamlessly shared based on demand and availability. However, efficient management of resources is a challenge.
4. **Service Level Federation**: Aggregation of services from multiple cloud providers. Customers can get a unified service from multiple specialized services from different providers. However, service compatibility and latency issues may occur.

Advantages of cloud federation:
- Increased resource utilization and scalability.
- Mitigation of provider lock-in.
- Increased reliability and availability.

Disadvantages of cloud federation:
- Data security and privacy issues.
- Complexity in programming and compatibility.
- Efficient management of resources.
- Service latency and compatibility issues.

Applications of cloud federation:
- Healthcare - sharing patient data and compute resources.
- Scientific research - sharing huge data sets and high performance computing resources.
- E-commerce - scaling resources based on demand.

 Mnemonics:
- Data - Data sharing
- Application - Application running
- Resource - Resource sharing
- Service - Service aggregation

Learning tricks:
- Think of the levels in a top-down approach. Data comes first, then applications consume data, then resources are required to run applications and finally aggregation of services.
- The first letter of each level spells DARS which is easy to remember.
