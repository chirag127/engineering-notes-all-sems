## Unit 5 - Cloud Technologies And Advancements Hadoop

### Introduction to Hadoop

- Hadoop is an open-source software framework for distributed storage and processing of very large data sets on computer clusters.
- It allows you to store and process big data in a distributed environment.
- The core components of Hadoop are:
- Hadoop Distributed File System (HDFS) - stores data on the cluster
- MapReduce - a programming model for processing large data sets
- Yet Another Resource Negotiator (YARN) - manages computing resources in clusters and offers a framework for job scheduling and cluster resource management

#### Advantages of Hadoop

- Scalable - can store and process huge amounts of data (petabytes)
- Fault tolerant - automatically stores multiple replicas of data and recovers from failures
- Low cost - uses commodity hardware and open-source software
- Flexible - offers a variety of options for data access (Hive, Pig) and integration with other tools/languages (Python, C++, etc.)

#### Hadoop Ecosystem

- The Hadoop ecosystem contains many other components/projects built around the core Hadoop framework:
- Hive - data warehouse to query and manage large datasets
- Pig - a high-level data-flow language and execution framework for parallel computation
- HBase - a distributed, scalable, big data store
- ZooKeeper - centralized service for maintaining configuration information, naming, providing distributed synchronization, and providing group services
- Oozie - a workflow scheduler system to manage Hadoop jobs
- Spark - a fast and general engine for large-scale data processing that runs on Hadoop
