### Tools and Mechanisms for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

Service Oriented Architecture (SOA) is an approach to software design where services are provided to other components by application components, through a communication protocol over a network. In Cloud Computing, SOA is used to provide scalable, flexible and cost-effective services to users. 

Here are some of the tools and mechanisms used in SOA:

1. Service Registry: A service registry is a database that holds information about available services. It helps to locate services, and also provides details about the location, version, and other important details of the service.

2. Service Broker: A service broker provides a platform for service providers to offer their services to users. It also provides a platform for users to discover and choose services that meet their requirements.

3. Service Bus: A service bus is an intermediary service that manages communication between different services. It provides features like routing, transformation, and protocol conversion.

4. Web Services: Web services are the foundation of SOA. They are self-contained, modular applications that can be described, published, located, and invoked over a network.

5. Enterprise Service Bus (ESB): An ESB is a middleware platform that provides a central communication hub for different services. It supports different communication protocols and provides features like message transformation, routing, and security.

6. SOAP (Simple Object Access Protocol): SOAP is a messaging protocol used for exchanging structured data between different systems. It uses XML for message formatting and can be used over different transport protocols like HTTP, SMTP, and TCP.

7. REST (Representational State Transfer): REST is an architectural style used for building web services. It uses HTTP for communication and supports different data formats like XML, JSON, and HTML.

Mnemonics and learning tricks:

- Remember the acronym "SWESRS" to remember the different tools and mechanisms used in SOA - Service Registry, Service Broker, Service Bus, Web Services, Enterprise Service Bus, SOAP, and REST.
- Think of the Enterprise Service Bus as a transportation hub, where different services connect to reach their destination.
- Remember that SOAP is used for structured data exchange, while REST is used for building web services.

In summary, understanding the tools and mechanisms used in SOA is important for building scalable, flexible, and cost-effective services in Cloud Computing. The above-listed tools and mechanisms are commonly used in SOA and can be remembered using different learning tricks and mnemonics.
