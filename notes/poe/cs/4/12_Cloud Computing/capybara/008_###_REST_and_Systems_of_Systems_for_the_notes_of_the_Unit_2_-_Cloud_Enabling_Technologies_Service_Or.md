### REST and Systems of Systems for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

REST or Representational State Transfer is a software architectural style that defines a set of constraints to be used for creating web services. RESTful web services allow clients to access and manipulate web resources through a uniform and predefined set of rules. Some key features of RESTful web services are statelessness, client-server architecture, cacheability, and layered system architecture.

Systems of Systems (SoS) is a collection of independent systems that are integrated to achieve a common goal. SoS are characterized by their large scale, complex interactions, and distributed nature. Cloud computing is an example of a SoS since it integrates various services and systems to provide a common set of functionalities.

Some key points to keep in mind about REST and Systems of Systems for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing are:

#### REST:

- REST is a software architectural style that defines a set of constraints to be used for creating web services.
- RESTful web services allow clients to access and manipulate web resources through a uniform and predefined set of rules.
- RESTful web services are stateless, meaning that each request from a client to a server must contain all the information necessary to understand the request, and cannot rely on any previous interactions.
- RESTful web services follow a client-server architecture, which means that the client and the server are independent of each other and can evolve separately.
- RESTful web services are cacheable, which means that clients can store responses to requests and reuse them later to reduce network traffic.
- RESTful web services follow a layered system architecture, which means that the components of the system are organized in a hierarchical order, with each layer providing a specific functionality.

#### Systems of Systems:

- Systems of Systems (SoS) is a collection of independent systems that are integrated to achieve a common goal.
- SoS are characterized by their large scale, complex interactions, and distributed nature.
- Cloud computing is an example of a SoS since it integrates various services and systems to provide a common set of functionalities.
- SoS require a high level of interoperability, which means that the individual systems must be able to communicate and exchange data with each other seamlessly.
- SoS require a robust and flexible architecture to handle the complexity and uncertainty of the interactions between the individual systems.
- SoS can provide numerous benefits such as increased flexibility, scalability, and cost savings, but also pose significant challenges such as security, governance, and management.
