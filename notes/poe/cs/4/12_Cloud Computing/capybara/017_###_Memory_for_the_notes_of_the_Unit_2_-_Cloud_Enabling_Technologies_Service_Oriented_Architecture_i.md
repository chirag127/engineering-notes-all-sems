### Memory for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

Service Oriented Architecture (SOA) is an important cloud enabling technology that is widely used in the cloud computing domain. To retain the knowledge gained from this unit, the following memory notes can be helpful:

1. Understanding SOA:
   - SOA is an architectural approach that involves the use of loosely coupled services to enable interoperability and reusability.
   - It is based on the concept of service, which is a self-contained, modular and independent unit of functionality that performs a specific task.
   - Services can be accessed and used by other services or applications through standard protocols like HTTP, SOAP, and REST.

2. Key components of SOA:
   - Service Broker: A service broker is responsible for managing and coordinating the interactions between services.
   - Service Registry: A service registry is used to store and manage the metadata of services.
   - Service Repository: A service repository is used to store the actual code and implementation of services.
   - Service Bus: A service bus is used to route messages between services.

3. Benefits of SOA:
   - SOA promotes reuse of services, which leads to reduced development time and cost.
   - It enables better interoperability between different systems and applications.
   - It provides flexibility and scalability to the system.

4. Drawbacks of SOA:
   - Implementation of SOA can be complex and time-consuming.
   - It requires a high level of coordination and governance to ensure the proper functioning of services.

5. Mnemonics and Learning Tricks:
   - Remember the acronym SOAP (Simple Object Access Protocol) as it is one of the commonly used protocols in SOA.
   - Think of services as Lego blocks that can be used to build different structures (applications).

By keeping these memory notes in mind, students can easily recall the concepts and principles of SOA, which can help them in their exams and professional careers in the cloud computing industry.
