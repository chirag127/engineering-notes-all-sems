### Types of Virtualization for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

Virtualization refers to the creation of a virtual version of a resource such as a server, network, operating system, or storage device. Virtualization is a key technology in cloud computing and enables the efficient use of computing resources. There are several types of virtualization, including:

1. Server Virtualization: Server virtualization involves dividing a physical server into multiple virtual servers, each of which can run its own operating system and applications. This enables the efficient use of server resources and can lead to cost savings.

2. Network Virtualization: Network virtualization involves creating a virtual network that is decoupled from the physical network, allowing multiple virtual networks to run on the same physical network infrastructure. This can improve network efficiency, scalability, and flexibility.

3. Storage Virtualization: Storage virtualization involves creating a virtual version of storage devices, allowing multiple physical storage devices to be managed as a single logical unit. This can improve storage efficiency and simplify management.

4. Desktop Virtualization: Desktop virtualization involves running multiple virtual desktops on a single physical machine, allowing multiple users to share the same physical resources. This can lead to cost savings and improved security.

Mnemonics and Learning Tricks:

To remember the types of virtualization, you can use the acronym SNDS, which stands for Server, Network, Desktop, and Storage virtualization.

Advantages of Virtualization:

- Better resource utilization
- Reduced hardware costs
- Improved scalability and flexibility
- Easier management and maintenance

Disadvantages of Virtualization:

- Increased complexity
- Performance overhead
- Security concerns

Examples of Virtualization:

- VMware ESXi for server virtualization
- Open vSwitch for network virtualization
- VMware Horizon for desktop virtualization
- EMC VPLEX for storage virtualization

Applications of Virtualization:

- Cloud computing
- Virtual desktop infrastructure (VDI)
- Disaster recovery
- Testing and development environments
