## Unit 3 - Cloud Architecture, Services And Storage

In this unit, we will learn about cloud architecture, services, and storage. Cloud computing is a technology that provides on-demand services over the internet. It offers a variety of services, including infrastructure, platform, and software services. Let's dive into the details of each of these services.

### Cloud Architecture

Cloud architecture refers to the design of the cloud computing system. It is the foundation for building cloud-based solutions. The cloud architecture is divided into three layers:

1. Infrastructure as a Service (IaaS): This layer provides virtualized computing resources over the internet, including servers, storage, and networking. Amazon AWS, Microsoft Azure, and Google Cloud Platform are examples of IaaS providers.

2. Platform as a Service (PaaS): This layer provides a platform for developers to build and deploy applications without worrying about the infrastructure. PaaS providers include Heroku, Google App Engine, and Microsoft Azure.

3. Software as a Service (SaaS): This layer provides software applications over the internet, allowing users to access them from anywhere. Examples of SaaS providers are Gmail, Salesforce, and Dropbox.

### Cloud Services

Cloud services are the services provided by the cloud computing system. There are various cloud services available, including:

1. Compute Services: These services provide computing resources, such as virtual machines, containers, and serverless computing.

2. Storage Services: These services provide storage resources, such as object, block, and file storage.

3. Database Services: These services provide database resources, such as SQL and NoSQL databases.

4. Networking Services: These services provide networking resources, such as virtual private cloud, load balancers, and DNS.

5. Security Services: These services provide security resources, such as identity and access management, encryption, and security monitoring.

### Cloud Storage

Cloud storage is a service provided by the cloud computing system that allows users to store and access data over the internet. There are various types of cloud storage available, including:

1. Object Storage: This type of storage is used to store unstructured data, such as images, videos, and documents. Examples of object storage providers are Amazon S3, Google Cloud Storage, and Microsoft Azure Blob Storage.

2. Block Storage: This type of storage is used to store structured data, such as databases and applications. Examples of block storage providers are Amazon EBS, Google Persistent Disk, and Microsoft Azure Disk Storage.

3. File Storage: This type of storage is used to store and share files over the internet. Examples of file storage providers are Google Cloud Filestore, Amazon EFS, and Microsoft Azure Files.

In conclusion, cloud computing is a powerful technology that provides a variety of services over the internet. Understanding cloud architecture, services, and storage is essential for building and deploying cloud-based solutions. Mnemonics and learning tricks can be helpful in remembering the different types of cloud services and storage. For example, "I Like People Saying Funny Things" can be used to remember the layers of cloud architecture (IaaS, PaaS, SaaS).
