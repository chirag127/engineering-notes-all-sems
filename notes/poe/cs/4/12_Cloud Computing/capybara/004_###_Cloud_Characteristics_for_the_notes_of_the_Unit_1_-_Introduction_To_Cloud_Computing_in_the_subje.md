### Cloud Characteristics for the notes of the Unit 1 - Introduction To Cloud Computing in the subject of Cloud Computing

Cloud computing is a model of delivering services over the internet. It has several characteristics that make it different from traditional computing models. These characteristics are as follows:

1. On-demand self-service: The cloud service providers offer services on-demand, meaning the users can provision and terminate services as per their requirement without any human intervention. It is similar to ordering a pizza online, where the user can choose the toppings and the size as per their preference.

2. Broad network access: Cloud services can be accessed from anywhere, anytime, using any device with an internet connection. It enables users to access services from their smartphones, tablets, laptops, and desktops.

3. Resource pooling: The cloud service providers pool their resources to provide services to multiple users simultaneously. It means that the users can share the resources like storage, processing power, memory, and network bandwidth, without knowing who else is using it.

4. Rapid elasticity: Cloud services can be scaled up or down as per the user's requirement. It means that the users can increase or decrease their resources as per their demand without any delay.

5. Measured service: Cloud services are metered and charged based on the usage. It means that the users only pay for what they use, and they can monitor their usage to manage their costs effectively.

Mnemonics for remembering the cloud characteristics are as follows:

1. OBSRM: On-demand self-service, Broad network access, Resource pooling, Rapid elasticity, Measured service.

2. ABCDE: Anywhere, Anytime, Any device, Broad network access, Cloud computing.

In conclusion, understanding the cloud characteristics is essential for anyone who wants to learn cloud computing. These characteristics differentiate cloud computing from traditional computing models and provide several benefits to the users, like scalability, cost-effectiveness, and flexibility.
