### Security Overview for the notes of the Unit 4 - Resource Management And Security In Cloud in the subject of Cloud Computing

Security is a major concern in cloud computing as it involves the storage and processing of sensitive data. Therefore, it is important to have a strong security framework in place to protect the data from unauthorized access and cyber-attacks. In this unit, we will discuss the security overview of cloud computing.

#### Key Concepts:

- Security threats in cloud computing
- Security measures in cloud computing
- Security models in cloud computing
- Access control in cloud computing

#### Security Threats in Cloud Computing:

Cloud computing is vulnerable to various security threats such as:

- Data breaches: Due to the large amount of data stored in the cloud, it becomes an easy target for hackers.
- Distributed Denial of Service (DDoS) attacks: It is a type of cyber-attack where the hackers overload the servers with requests, causing the system to crash.
- Malware attacks: Malware can be introduced into the cloud network through email attachments or downloads, which can then spread to other systems.
- Insider threats: Employees with access to sensitive data can misuse the information or leak it to outsiders.

#### Security Measures in Cloud Computing:

To protect the cloud infrastructure and data from security threats, the following security measures can be implemented:

- Encryption: Data can be encrypted before being stored in the cloud to prevent unauthorized access.
- Firewall: Firewall can be used to restrict access to the cloud network.
- Antivirus software: It can be used to detect and remove malware from the cloud network.
- Backup and recovery: Regular backup of data and a disaster recovery plan can be implemented to ensure that the data is safe in case of a security breach.

#### Security Models in Cloud Computing:

There are three security models in cloud computing:

- Public cloud: It is accessible to everyone and is managed by a third-party provider.
- Private cloud: It is accessible to a specific organization and is managed internally or by a third-party provider.
- Hybrid cloud: It is a combination of public and private cloud.

#### Access Control in Cloud Computing:

Access control is an important aspect of cloud security as it ensures that only authorized personnel can access the cloud network. The following access control mechanisms can be implemented:

- Authentication: It verifies the identity of the user before granting access to the cloud network.
- Authorization: It determines the level of access granted to the user based on their role and responsibilities.
- Accounting: It keeps track of the user's activities in the cloud network.

#### Learning Tricks:

- Remember the acronym CIA, which stands for Confidentiality, Integrity, and Availability. These are the three key principles of cloud security.
- Think of encryption as a lock and key mechanism, where the data is the lock and the encryption key is the key that unlocks it.
- Remember the difference between public, private, and hybrid cloud by thinking of them as houses. Public cloud is like a hostel, private cloud is like a single-family home, and hybrid cloud is like a duplex.
