### Basics of Virtualization for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

Virtualization is a fundamental technology that enables the cloud computing paradigm. It refers to the creation of a virtual version of something, such as an operating system, a server, a storage device, or a network resource. This virtual version behaves like the real thing but is actually running on top of another system, which is called the host system.

Here are some basics of virtualization that you should know for the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing:

1. **Hypervisor** - Hypervisor is also known as a virtual machine monitor (VMM). It is a software layer that allows multiple virtual machines (VMs) to run on a single physical machine. There are two types of hypervisors: Type 1 hypervisor, which runs directly on the host machine's hardware, and Type 2 hypervisor, which runs on top of a host operating system.

2. **Virtual Machine** - A virtual machine is a logical representation of a physical machine. It consists of a virtualized set of hardware devices, such as CPU, memory, storage, and network interface. Each VM runs its own operating system and applications, isolated from other VMs running on the same host machine.

3. **Guest Operating System** - A guest operating system is the operating system that runs inside a virtual machine. It is the same as a regular operating system, but it runs on top of a virtualized set of hardware devices instead of directly on the physical hardware.

4. **Virtualization Types** - There are three types of virtualization: Full virtualization, Para-virtualization, and Hardware-assisted virtualization.

5. **Advantages of Virtualization** - Virtualization offers several advantages, such as improved hardware utilization, reduced hardware costs, increased flexibility, easier maintenance, and greater scalability.

6. **Disadvantages of Virtualization** - Virtualization also has some disadvantages, such as increased complexity, potential performance degradation, and security risks.

Mnemonic and Learning Trick:

To remember the types of virtualization, you can use the mnemonic "FPH" which stands for "Full, Para, Hardware-assisted." This can help you remember the three types of virtualization quickly and easily for your exams.
