
### Architectural Design Challenges for the Notes of the Unit 3 - Cloud Architecture, Services and Storage in the Subject of Cloud Computing

1. **Service-Oriented Architecture (SOA):** This type of architecture is based on the idea of breaking down applications into smaller, independent services that can be used and reused by other applications. This allows for better scalability, flexibility, and agility. The main challenge is to ensure that the services are well-defined and adhere to the standards of the architecture.

2. **Cloud Computing:** Cloud computing is the delivery of computing services such as servers, storage, databases, networking, software, analytics, and more over the internet. The main challenge is to ensure that the cloud services are secure and reliable.

3. **Storage:** Cloud storage is the practice of storing data in multiple locations, such as on-premises, in the cloud, or in a hybrid environment. The main challenge is to ensure that the data is secure and accessible.

4. **Virtualization:** Virtualization is the process of creating a virtual version of a physical system, such as a server, storage, or network. The main challenge is to ensure that the virtual environment is secure and reliable.

5. **Mnemonics and Learning Tricks:** Mnemonics are memory aids that can help you remember difficult concepts. For example, the acronym "SOSA" can be used to remember the three main components of a service-oriented architecture: Services, Orchestration, and Security. Similarly, the acronym "CCSS" can be used to remember the three main components of cloud computing: Computing, Storage, and Security.
