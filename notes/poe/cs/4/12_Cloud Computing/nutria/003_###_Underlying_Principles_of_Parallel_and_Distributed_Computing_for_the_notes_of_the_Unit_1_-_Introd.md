
### Underlying Principles of Parallel and Distributed Computing for the notes of the Unit 1 - Introduction To Cloud Computing in the subject of Cloud Computing

Parallel and distributed computing are two of the most important concepts in cloud computing. Parallel computing is the use of multiple processors to execute multiple tasks simultaneously, while distributed computing is the use of multiple computers to perform a single task. Both of these concepts are used to improve the performance of cloud computing applications.

#### Advantages of Parallel and Distributed Computing

- Increased Performance: By using multiple processors to execute multiple tasks simultaneously, the performance of cloud computing applications can be greatly improved.
- Improved Scalability: By using multiple computers to perform a single task, the scalability of cloud computing applications can be improved. This means that the same task can be completed faster and more efficiently.
- Cost Savings: By using multiple computers to perform a single task, the cost of cloud computing applications can be reduced. This is because multiple computers can be used to complete the same task in less time.

#### Disadvantages of Parallel and Distributed Computing

- Complexity: Parallel and distributed computing can be complex to implement and manage.
- Security Risks: By using multiple computers to perform a single task, there is an increased risk of security breaches.
- Resource Consumption: By using multiple computers to perform a single task, the amount of resources consumed can be increased.

#### Mnemonics and Learning Tricks

- P: Parallel computing is used to increase Performance.
- D: Distributed computing is used for Improved Scalability and Cost Savings.
- C: Complexity, Security Risks, and Resource Consumption are the Disadvantages of Parallel and Distributed Computing.
