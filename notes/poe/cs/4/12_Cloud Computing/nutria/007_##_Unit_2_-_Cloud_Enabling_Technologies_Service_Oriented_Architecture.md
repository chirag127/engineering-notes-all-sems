
## Unit 2 - Cloud Enabling Technologies Service Oriented Architecture

Service Oriented Architecture (SOA) is a type of software architecture that enables applications to be designed and developed as a set of services. Services are self-contained, modular components that can be combined to form larger applications. SOA is based on the idea of breaking down large, complex applications into smaller, more manageable components that can be reused, combined, and recombined to create new applications.

SOA has several advantages, including: 

* Improved scalability: By breaking down applications into smaller components, it is easier to scale up or down as needed.
* Increased flexibility: Services can be combined and recombined to create new applications, allowing for greater flexibility and customization.
* Improved reliability: Services can be designed to be fault-tolerant, ensuring that if one service fails, the other services will continue to work.
* Reduced complexity: By breaking down applications into smaller components, it is easier to manage and maintain them.

SOA also has some drawbacks, including:

* Increased complexity: As the number of services increases, it can become difficult to manage and maintain them.
* Increased cost: SOA requires more resources and infrastructure than traditional architectures, resulting in higher costs.
* Slower performance: Because services are distributed across multiple systems, they can take longer to process requests.

Mnemonic: SOA = Scalability, Flexibility, Reliability, Complexity.
