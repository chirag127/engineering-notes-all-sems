
### Virtualization Structures for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

Virtualization is a process of creating a virtual version of something, such as a physical server, storage device, network resource or application. It allows multiple workloads to be run on a single physical server, which can improve resource utilization, reduce costs, and increase flexibility.

The most common type of virtualization is server virtualization, which is used to create virtual machines (VMs). A VM is a software-based emulation of a physical computer, which can be used to run multiple operating systems and applications on a single physical server.

Virtualization can also be used to create virtual networks, storage devices, and applications. Network virtualization is used to create virtual networks that can be used to segment networks and improve performance. Storage virtualization is used to create virtual storage devices, such as SANs and NASs, which can be used to store data more efficiently and securely. Application virtualization is used to create virtual applications, which can be used to deploy applications more quickly and securely.

Virtualization has many advantages, including improved resource utilization, cost savings, increased flexibility, and improved security. It can also help organizations meet regulatory compliance requirements and reduce the need for manual configuration and management.
