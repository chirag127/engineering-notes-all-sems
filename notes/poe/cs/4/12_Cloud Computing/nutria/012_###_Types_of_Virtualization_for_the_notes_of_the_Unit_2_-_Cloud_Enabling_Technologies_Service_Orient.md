
## Types of Virtualization for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

Virtualization is a process of creating a virtual version of something, such as an operating system, a server, a storage device, or a network resource. It allows multiple operating systems to run on a single physical machine, and it can be used to improve the performance, scalability, and availability of cloud computing services. 

There are three main types of virtualization: 

1. **Hardware Virtualization**: This type of virtualization uses hardware-level virtualization to create a virtualized environment. It allows multiple operating systems to run on a single physical machine, and it can also be used to improve the performance, scalability, and availability of cloud computing services. 

2. **Software Virtualization**: This type of virtualization uses software-level virtualization to create a virtualized environment. It allows multiple applications to run on a single physical machine, and it can also be used to improve the performance, scalability, and availability of cloud computing services.

3. **Network Virtualization**: This type of virtualization uses network-level virtualization to create a virtualized environment. It allows multiple networks to be connected to each other, and it can also be used to improve the performance, scalability, and availability of cloud computing services.

The main advantages of virtualization include improved resource utilization, increased scalability, improved availability, and improved performance. The main disadvantages include increased complexity, increased cost, and increased security risks.
