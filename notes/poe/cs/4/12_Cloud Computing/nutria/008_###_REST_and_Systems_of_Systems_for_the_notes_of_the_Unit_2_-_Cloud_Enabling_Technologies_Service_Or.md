
### REST and Systems of Systems for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

* Representational State Transfer (REST) is an architectural style that defines a set of constraints and properties based on HTTP. It is used to build distributed systems and web services.

* Systems of Systems (SoS) is an approach to designing and managing complex systems made up of multiple, interacting components. It is a way of linking together multiple autonomous systems to create a larger, more complex system.

* Service Oriented Architecture (SOA) is an architectural style that defines a set of principles and best practices for designing and implementing services. It is based on the idea of breaking down a system into smaller, independent services that can be reused and combined to create new applications.

* Cloud Computing is a model for delivering computing services over the internet. It is based on the idea of providing users with access to computing resources on demand, without having to purchase or manage the underlying hardware.
