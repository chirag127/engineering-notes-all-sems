
### Virtualization of CPU for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

Virtualization of CPU is a process that allows a single physical CPU to be used as multiple virtual CPUs. This is done by running multiple operating systems on a single CPU, allowing for more efficient use of the hardware. This process makes it possible to run multiple applications on the same CPU, which can increase the efficiency of the system.

Virtualization of CPU is a key component of cloud computing and enables the sharing of computing resources among multiple users. It also allows for the creation of virtual machines, which are isolated from each other and can be used for different tasks.

The benefits of virtualization of CPU include:

* Increased efficiency: By running multiple operating systems on a single CPU, the hardware is used more efficiently. This can reduce the cost of running multiple applications on the same CPU.
* Improved scalability: By creating virtual machines, users can easily scale up or down the resources they need. This makes it easier to manage the system.
* Improved security: Virtual machines are isolated from each other, which makes it harder for malicious software to access sensitive data.
* Improved availability: By using virtual machines, users can ensure that their applications are always available and running.

Mnemonic: CPUV (CPU Virtualization)
