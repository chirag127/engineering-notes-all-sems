
### Memory for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

* Service Oriented Architecture (SOA) is a type of software architecture which is based on the idea of providing services to other components through a network. 
* SOA allows for the integration of different services and applications, regardless of their underlying platform or technology. 
* It enables the development of distributed applications, which are composed of multiple services that can be located on different networks. 
* SOA is a key component of cloud computing, as it allows for the integration of cloud services with existing applications and services. 
* SOA is based on the concept of software components, which are services that provide a set of functions. These services are accessed through an interface, which is defined by the service provider. 
* SOA is composed of four main components: service providers, service requesters, service brokers, and service registries. 
* Service providers are the entities that provide services to other components. They define the interface and the functionality of the service. 
* Service requesters are the entities that request services from the service providers. 
* Service brokers are the entities that manage the communication between the service requesters and the service providers. 
* Service registries are the entities that store information about the services and the service providers. 
* SOA provides a number of benefits, such as increased flexibility, scalability, and cost savings. It also allows for the integration of existing applications and services with cloud services. 
* Mnemonics for SOA:
    * S - Service Oriented Architecture
    * O - Offers flexibility, scalability and cost savings
    * A - Allows for integration of existing applications and services with cloud services.
