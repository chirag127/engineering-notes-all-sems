
## Unit 5 - Cloud Technologies And Advancements Hadoop

1. Hadoop is an open-source software framework for distributed storage and processing of large volumes of data. It is designed to scale up from single servers to thousands of machines, each offering local computation and storage.
2. Hadoop enables businesses to quickly and cost-effectively process vast amounts of data. It is used by organizations to quickly analyze large amounts of data, such as customer data, web logs, sensor data, and other types of data.
3. Hadoop is composed of two main components: a distributed file system (HDFS) and a processing system (MapReduce). HDFS is a distributed file system that stores data across multiple machines. MapReduce is a processing system that performs distributed computing tasks on data stored in HDFS.
4. Hadoop is designed to be highly fault tolerant and can handle large amounts of data. It is also designed to be highly scalable, allowing businesses to add servers to the cluster as their data processing needs grow.
5. Hadoop is used in a variety of applications, including web indexing, data mining, log processing, machine learning, financial analysis, and more.
6. To learn more about Hadoop, it can be helpful to remember the acronym HDFS:
    - H: Hadoop is an open-source software framework
    - D: Distributed storage and processing of large volumes of data
    - F: Fault tolerant and highly scalable
    - S: Scalable, allowing businesses to add servers to the cluster as needed
