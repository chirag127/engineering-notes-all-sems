
### Cloud Characteristics for the notes of Unit 1 - Introduction To Cloud Computing in the subject of Cloud Computing

Cloud computing has several key characteristics that make it a powerful and versatile tool. These characteristics include:

* **On-Demand Self-Service:** Cloud users can access the services they need quickly and easily, without needing the help of an administrator or specialist.

* **Broad Network Access:** Cloud services are available from anywhere with an internet connection, allowing users to access their data from any device.

* **Resource Pooling:** Cloud providers pool resources from multiple users, allowing them to provide services to users at a lower cost.

* **Scalability:** Cloud services can be scaled up or down quickly and easily, depending on the user's needs.

* **Measured Service:** Cloud providers measure their services, allowing them to charge users based on their usage.

* **High Availability:** Cloud services are designed to be highly available, ensuring that users can access their data when they need it.

* **Fault Tolerance:** Cloud services are designed to be fault tolerant, meaning they are able to recover quickly from errors and outages.

* **Security:** Cloud providers take measures to ensure that their services are secure, protecting user data from unauthorized access.

Mnemonic: OSBRSM-SFMHAF

Explanation:

OSBRSM: On-Demand Self-Service, Broad Network Access, Resource Pooling, Scalability, Measured Service

SFMHAF: High Availability, Fault Tolerance, Security
