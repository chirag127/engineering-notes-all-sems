
### NIST Cloud Computing Reference Architecture for the notes of the Unit 3 - Cloud Architecture, Services And Storage in the subject of Cloud Computing

The NIST Cloud Computing Reference Architecture (CCRA) is a comprehensive set of guidelines for designing and implementing cloud computing solutions. It provides a comprehensive view of cloud computing, including its components, components' relationships, and their interactions. The CCRA also provides a set of design principles and guidelines for developing cloud-based solutions.

The CCRA consists of five layers:

1. Cloud Hosting Layer: This layer provides the hardware, software, and network infrastructure for a cloud computing environment.
2. Cloud Platform Layer: This layer provides the platform for cloud services, such as virtualization, storage, and networking.
3. Cloud Services Layer: This layer provides the services that are used by cloud applications, such as databases, web services, and messaging.
4. Cloud Applications Layer: This layer provides the applications that are used by users to access cloud services.
5. Cloud Management Layer: This layer provides the tools and processes for managing and monitoring the cloud environment.

The CCRA provides a set of best practices for designing and implementing cloud computing solutions. It also provides guidance on how to select the right cloud hosting provider, how to design and implement a cloud platform, and how to develop and deploy cloud applications. Additionally, the CCRA provides guidance on how to manage and monitor cloud resources, how to monitor performance and security, and how to ensure compliance with applicable laws and regulations.

Mnemonics and learning tricks for the CCRA include:

* C for Cloud Hosting Layer
* P for Platform Layer
* S for Services Layer
* A for Applications Layer
* M for Management Layer
