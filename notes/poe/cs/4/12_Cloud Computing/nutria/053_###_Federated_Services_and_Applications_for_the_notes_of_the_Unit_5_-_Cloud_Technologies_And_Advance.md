

### Federated Services and Applications for the notes of the Unit 5 - Cloud Technologies And Advancements Hadoop in the subject of Cloud Computing

Federated services and applications are an important part of cloud computing, as they allow for the sharing of resources across multiple cloud providers. Federated services and applications are used to provide a consistent experience for users, regardless of the underlying cloud provider.

#### Advantages
- Allows for the sharing of resources across multiple cloud providers
- Provides a consistent experience for users, regardless of the underlying cloud provider
- Allows for the development of applications that span multiple cloud providers
- Reduces the need for custom development for each cloud provider
- Increases scalability and reliability

#### Disadvantages
- Can be difficult to manage and maintain due to the complexity of the system
- Can lead to increased costs due to the need for additional infrastructure and resources
- Can lead to increased security risks due to the complexity of the system
- Can lead to increased latency due to the need for data to be transferred between cloud providers

#### Examples
- Google Cloud Platform’s Federated Services
- Amazon Web Services’ Federated Services
- Microsoft Azure’s Federated Services

#### Applications
- Large-scale distributed applications
- Multi-cloud deployments
- Hybrid cloud deployments
- Multi-tenant applications
- Cloud bursting
