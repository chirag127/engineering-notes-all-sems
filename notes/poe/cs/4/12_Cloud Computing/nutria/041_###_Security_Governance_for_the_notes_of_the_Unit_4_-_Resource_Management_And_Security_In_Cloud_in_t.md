
### Security Governance for the notes of the Unit 4 - Resource Management And Security In Cloud in the subject of Cloud Computing

* Security Governance is the process of establishing and maintaining a secure environment and ensuring that security policies are regularly reviewed, updated, and enforced. It is the responsibility of the organization to ensure that all resources are secured and protected from unauthorized access and misuse.

* Security Governance involves the implementation and monitoring of security policies, procedures, and standards that are designed to ensure the safety and security of data and resources. These policies should be regularly reviewed and updated to ensure that they are up-to-date and effective.

* Security Governance also involves the implementation of security controls, such as authentication and authorization, to ensure that only authorized users have access to the data and resources. Additionally, security controls should be regularly monitored and audited to ensure that they are functioning properly and are secure.

* Security Governance also involves the implementation of security measures, such as encryption, to ensure that data is protected from unauthorized access and misuse. Additionally, security measures should be regularly tested and monitored to ensure that they are secure and effective.

* Finally, Security Governance involves the creation of a secure environment in which data and resources can be accessed and used safely and securely. This includes the implementation of security policies and procedures, the implementation of security controls, and the implementation of security measures.
