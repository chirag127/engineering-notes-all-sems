
### Virtualization Support and Disaster Recovery for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

Virtualization is the process of creating a virtual version of a physical computer or server, which allows the user to run multiple operating systems and applications on the same server. Disaster recovery involves planning for and responding to potential disasters that could affect an organization's data, systems, and infrastructure. 

Virtualization support and disaster recovery are two important aspects of cloud computing. Virtualization helps organizations reduce costs by allowing them to run multiple operating systems and applications on the same server, while disaster recovery allows them to protect their data and systems in the event of a disaster.
