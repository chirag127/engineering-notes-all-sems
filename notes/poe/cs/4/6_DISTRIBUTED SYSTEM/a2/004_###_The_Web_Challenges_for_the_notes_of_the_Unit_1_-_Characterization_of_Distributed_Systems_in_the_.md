### The Web Challenges for the notes of the Unit 1 - Characterization of Distributed Systems in the subject of DISTRIBUTED SYSTEM

The web challenges for distributed systems are:

1. Scalability - As the number of users or resources grow, the system should be able to handle the load efficiently without performance degradation. This is a challenge as limited resources have to be distributed among many users and components.
2. Latency - Since requests have to travel over a network, there is inherent latency in a distributed system. Minimizing latency and ensuring performance is a key challenge.
3. Fault Tolerance - With many components and connections, there are more chances of faults or failures. The system should be designed to tolerate faults and ensure continuous operation. Mechanisms like replication, failover, etc. are used but add to complexity.
4. Concurrency - There may be many things happening at once in different parts of the system. Coordinating actions and accessing shared resources concurrently is a challenge. Mechanisms like mutual exclusion, locks, etc. are used but can affect performance.
5. Security - The open nature of networks and large number of components pose several security risks like breaches, malware, DDoS attacks, etc. Implementing proper security measures while still ensuring easy access is a challenge.

Some tips to learn:

- Remember the challenges using mnemonics like **SLFC** for **S**calability, **L**atency, **F**ault tolerance and **C**oncurrency.
- Understand the challenges in terms of limitations of resources and difficulties in coordination at large scale.
- Study examples of mechanisms used to address the challenges and their pros and cons.
- Learn through diagrams showing distributed system components and paths of requests/data to understand latencies and points of failures.
