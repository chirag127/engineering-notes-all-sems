### Fundamental Models for the notes of the Unit 1 - Characterization of Distributed Systems in the subject of DISTRIBUTED SYSTEM

The fundamental models for distributed systems are -

1. Client-Server Model - In this model, multiple clients request resources or services from centralized servers. The servers handle and process the requests and return responses to the clients. Eg - Web servers, file servers, database servers, etc.
Advantages - Efficient resource utilization, centralized control, easy security implementation.
Disadvantages - Single point of failure, bottleneck can occur if many clients access the server simultaneously.

2. Peer-to-Peer Model - In this model, all the nodes in the system are equal and there is no concept of clients or servers. The nodes act as both clients and servers to each other. Eg - BitTorrent, Gnutella, etc.
Advantages - Fault tolerance, decentralized control, efficient resource utilization.
Disadvantages - Difficult security implementation, inefficient lookup mechanisms.

3. Cloud Computing Model - In this model, computing resources like servers, storage, applications, and services are provided to the users over the internet on a pay-per-use basis. The users can access the resources through a thin client or web browser. Eg - AWS, Google Cloud, Azure, etc.
Advantages - On-demand scalability, reduced cost, easy access.
Disadvantages - Reliance on the internet, vendor lock-in, data security and privacy concerns.

Mnemonics -
C-S-P (Client-Server, Peer-to-Peer, Cloud)
