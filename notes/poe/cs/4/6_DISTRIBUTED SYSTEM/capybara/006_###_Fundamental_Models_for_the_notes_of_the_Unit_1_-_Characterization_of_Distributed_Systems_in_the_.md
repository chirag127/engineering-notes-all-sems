### Fundamental Models for the notes of the Unit 1 - Characterization of Distributed Systems in the subject of DISTRIBUTED SYSTEM

In distributed systems, there are various fundamental models that are used to represent the architecture of the system. These models are used to understand the overall structure of the system and how the components interact with each other. Here are the fundamental models that are important to know for the Unit 1 - Characterization of Distributed Systems:

1. Client-Server Model: 

The client-server model is the most basic and widely used model in distributed systems. In this model, there are two types of components: clients and servers. Clients request services from servers and servers provide services to clients. This model is used in many applications like web browsing, email, and file sharing.

2. Peer-to-Peer Model:

The peer-to-peer model is a decentralized model in which all the components in the system are equal. There is no hierarchy in this model, and all the components can act as both clients and servers. This model is commonly used in file sharing applications like BitTorrent.

3. Three-Tier Model:

The three-tier model is a more complex model that is used in large-scale distributed systems. In this model, there are three layers or tiers: the presentation tier, the application tier, and the database tier. The presentation tier is responsible for presenting information to the user, the application tier is responsible for processing information, and the database tier stores the information.

4. Object-Oriented Model:

The object-oriented model is a model that is based on the principles of object-oriented programming. In this model, each component in the system is represented as an object that has attributes and methods. These objects interact with each other to provide services to the clients.

Mnemonics and Learning Tricks:

To remember these models, you can use the mnemonic "CAPO". CAPO stands for Client-Server, Peer-to-Peer, Three-Tier, and Object-Oriented. Another trick is to remember the acronym CPTO, which stands for Client-Server, Peer-to-Peer, Three-Tier, and Object-Oriented in that order.

Advantages and Disadvantages:

Each model has its own advantages and disadvantages. For example, the client-server model is simple and easy to implement, but it can be a single point of failure. The peer-to-peer model is decentralized and fault-tolerant, but it can be difficult to manage. The three-tier model is scalable and flexible, but it can be complex and expensive to implement. The object-oriented model is modular and reusable, but it can be difficult to design and implement.

Examples and Applications:

Each model is used in different applications. For example, the client-server model is used in web browsing, email, and file sharing. The peer-to-peer model is used in file sharing applications like BitTorrent. The three-tier model is used in large-scale enterprise applications like banking and finance systems. The object-oriented model is used in software development and object-oriented databases.

In conclusion, understanding the fundamental models in distributed systems is important to understand the architecture of the system and how the components interact with each other. Remembering the mnemonic "CAPO" or "CPTO" can help in remembering the models. Each model has its own advantages and disadvantages and is used in different applications.
