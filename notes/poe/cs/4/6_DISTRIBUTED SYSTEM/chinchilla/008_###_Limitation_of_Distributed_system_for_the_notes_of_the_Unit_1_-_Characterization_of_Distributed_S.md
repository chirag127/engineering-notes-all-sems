### Limitation of Distributed system for the notes of the Unit 1 - Characterization of Distributed Systems in the subject of DISTRIBUTED SYSTEM

Distributed systems are a set of connected computers that work together to achieve a common goal. They are designed to provide high performance, reliability, and scalability. However, there are several limitations of distributed systems that need to be considered. In this section, we will discuss some of the limitations of distributed systems:

1. Network Latency: In distributed systems, multiple computers are connected to each other through a network. The time taken to transfer data between these computers is known as network latency. Network latency can be a major bottleneck for distributed systems, as it can cause delays in processing and communication.

2. Fault Tolerance: Distributed systems are designed to be fault-tolerant, meaning that they can continue to function even if one or more computers fail. However, achieving fault tolerance in distributed systems can be challenging, as it requires complex algorithms and protocols.

3. Security: Distributed systems are vulnerable to security threats such as hacking, data theft, and unauthorized access. Ensuring the security of a distributed system is crucial, as any breach can have serious consequences.

4. Consistency: Maintaining consistency in a distributed system can be challenging. Since data is spread across multiple computers, ensuring that all computers have the same data can be difficult. This can lead to inconsistencies in the system, which can cause problems.

5. Scalability: Distributed systems are designed to be scalable, meaning that they can handle an increasing number of users and requests. However, achieving scalability in distributed systems can be difficult, as it requires careful planning and design.

6. Complexity: Distributed systems are inherently complex, as they involve multiple computers, networks, and protocols. This complexity can make it difficult to design, implement, and maintain distributed systems.

- Remember the acronym "NFSCCS" to recall the limitations of distributed systems: Network Latency, Fault Tolerance, Security, Consistency, Complexity, and Scalability.
- To remember the challenges of achieving fault tolerance in distributed systems, think of the phrase "Failing Computers Can Cripple Systems".
