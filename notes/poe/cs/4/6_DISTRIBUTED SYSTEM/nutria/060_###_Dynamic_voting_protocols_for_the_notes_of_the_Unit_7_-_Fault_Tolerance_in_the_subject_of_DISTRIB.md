
### Dynamic voting protocols for the notes of the Unit 7 - Fault Tolerance in the subject of DISTRIBUTED SYSTEM

Dynamic voting protocols are algorithms used in distributed systems to ensure fault tolerance. They provide a way for nodes in a distributed system to come to an agreement on the same data.

#### Benefits of Dynamic Voting Protocols

- Improved reliability: Dynamic voting protocols allow distributed systems to remain operational even if one or more nodes fail.
- Increased scalability: Dynamic voting protocols allow distributed systems to scale up to large numbers of nodes without sacrificing reliability.
- Reduced latency: Dynamic voting protocols reduce latency by ensuring that nodes in a distributed system can come to an agreement quickly.

#### Mnemonics and Learning Tricks

- **V**ote: Dynamic voting protocols require nodes to vote on the same data.
- **A**gree: Nodes must agree on the same data in order for the distributed system to remain operational.
- **L**eader: One node is usually designated as the leader and is responsible for coordinating the voting process.
- **I**nteraction: Nodes must interact with each other in order to come to an agreement.
- **D**ecision: Dynamic voting protocols allow nodes to come to a consensus on the same data.

#### Examples

- Paxos: Paxos is a classic dynamic voting protocol used in distributed systems. It allows nodes to come to an agreement on the same data even if some nodes fail.
- Raft: Raft is a modern dynamic voting protocol used in distributed systems. It allows nodes to come to an agreement on the same data even if some nodes fail.
- Zab: Zab is a dynamic voting protocol used in distributed systems. It allows nodes to come to an agreement on the same data even if some nodes fail.

- Improved reliability: Dynamic voting protocols allow distributed systems to remain operational even if one or more nodes fail.
- Increased scalability: Dynamic voting protocols allow distributed systems to scale up to large numbers of nodes without sacrificing reliability.

#### Disadvantages

- Complexity: Dynamic voting protocols can be complex to implement and maintain.
- Overhead: Dynamic voting protocols can introduce overhead into distributed systems.
- Vulnerability: Dynamic voting protocols can be vulnerable to malicious attacks.
