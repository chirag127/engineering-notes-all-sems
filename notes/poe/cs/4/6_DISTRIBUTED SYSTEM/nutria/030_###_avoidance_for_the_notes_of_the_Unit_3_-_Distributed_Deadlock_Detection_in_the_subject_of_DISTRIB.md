
### Avoidance for the Notes of the Unit 3 - Distributed Deadlock Detection in the Subject of DISTRIBUTED SYSTEM

- The goal of distributed deadlock avoidance is to prevent deadlock from occurring in a distributed system.
- A distributed system is a system in which multiple computers are connected and share resources.
- Deadlock avoidance is achieved by using a distributed algorithm which ensures that no two processes can lock the same resource at the same time.
- The algorithm works by assigning a priority to each process and then allowing only the process with the highest priority to lock a resource.
- A distributed deadlock avoidance algorithm is used to ensure that all processes in the distributed system can access the resources they need without deadlocking.
- It is also important to note that the algorithm must be able to detect deadlocks and take appropriate action to prevent them.
- Common techniques used for distributed deadlock avoidance include resource ordering, resource reservation, and time-out protocols.
- Resource ordering is a technique in which resources are ordered in a specific way, so that processes can access them in a predetermined order.
- Resource reservation is a technique in which a process reserves a resource before attempting to use it.
- Time-out protocols are used to detect when a process has been waiting too long for a resource and take appropriate action.
- In addition, distributed deadlock avoidance algorithms can also be used to detect and recover from deadlocks.
- Finally, it is important to note that distributed deadlock avoidance algorithms are not foolproof and can be bypassed by malicious processes. Therefore, it is important to ensure that the system is secure and that all processes follow the distributed deadlock avoidance algorithm.
