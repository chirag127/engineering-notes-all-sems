
### Causal Order for the Notes of the Unit 1 - Characterization of Distributed Systems in the Subject of DISTRIBUTED SYSTEM

* Causal order is a concept used in distributed systems to ensure that messages sent between nodes are delivered in the same order in which they were sent. 
* This is important for ensuring consistency in a distributed system, as it ensures that all nodes have the same view of the system.
* In order to ensure causal ordering, nodes must be able to detect when a message has been sent from another node and must be able to determine the order in which the messages were sent.
* This can be done by assigning each message a unique identifier that is generated by the sending node.
* The receiving node then stores the identifier in a data structure called a causal history. 
* When a new message is received, the receiving node checks its own causal history to see if the message has already been received. 
* If it has, the message is discarded, otherwise it is processed. 
* This ensures that messages are delivered in the same order in which they were sent, thus preserving the causal order.
* Additionally, nodes can also use vector clocks to detect when messages are out of order.
* Vector clocks are a data structure that stores a timestamp for each node in the system. 
* When a node receives a message, it checks the vector clock of the sender to see if the message was sent before or after any other messages the node has already received. 
* If the message was sent after any other messages, the node discards it and requests a new copy from the sender.
* This ensures that all messages are delivered in the same order in which they were sent, thus preserving the causal order.
