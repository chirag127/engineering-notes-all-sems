
## Unit 1 - Characterization of Distributed Systems

* A distributed system is a collection of autonomous computers that communicate with each other through a network.
* The computers in a distributed system are connected via a communication network and can exchange both data and control information. 
* Distributed systems are designed to provide services that are reliable, highly available, and scalable.
* In a distributed system, each computer is referred to as a node and the communication network is referred to as the interconnect.
* Distributed systems are categorized into two types: distributed computing systems and distributed data systems.
* In a distributed computing system, the nodes are responsible for executing computations, such as solving complex problems, while in a distributed data system, the nodes are responsible for storing and managing data.
* Distributed systems can be further classified into homogeneous and heterogeneous systems. 
* In a homogeneous system, all the nodes are the same, while in a heterogeneous system, the nodes can be different.
* Distributed systems can be further classified into static and dynamic systems. 
* In a static system, the nodes are not allowed to change, while in a dynamic system, the nodes can be added or removed.
* Distributed systems can also be classified into open and closed systems. 
* In an open system, the nodes can communicate with other nodes outside the system, while in a closed system, the nodes can only communicate with each other within the system.
* Distributed systems can also be classified into centralized and decentralized systems. 
* In a centralized system, all the nodes are controlled by a single node, while in a decentralized system, the nodes are independent and can communicate with each other.
* Mnemonics: 
  * H-Homogeneous 
  * S-Static 
  * O-Open 
  * C-Centralized 
* Learning tricks: 
  * Think of a homogeneous system as an army of identical soldiers. 
  * Think of a static system as a rigid structure that cannot be changed. 
  * Think of an open system as a network that can communicate with the outside world. 
  * Think of a centralized system as a single leader controlling all the nodes.
