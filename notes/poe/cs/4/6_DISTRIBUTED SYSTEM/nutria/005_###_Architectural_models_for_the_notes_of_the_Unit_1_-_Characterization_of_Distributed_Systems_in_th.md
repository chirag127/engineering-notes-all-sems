
### Architectural models for the notes of the Unit 1 - Characterization of Distributed Systems in the subject of DISTRIBUTED SYSTEM

1. Client-Server Model: This model is the most popular and widely used model for distributed systems. In this model, the client requests a service from the server, and the server responds with the requested service. This model is highly scalable and can be used to serve multiple clients simultaneously. The main advantage of this model is that it is easy to implement, maintain, and manage.

2. Peer-to-Peer Model: This model is used for distributed systems where each node is a client as well as a server. In this model, the nodes communicate directly with each other without the need for a central server. This model is highly reliable and can be used to create distributed applications. The main advantage of this model is that it is decentralized, which makes it more secure.

3. Cloud Computing Model: This model is used for distributed systems where the resources are shared among multiple users. In this model, the resources are hosted on a cloud server and can be accessed by multiple users. This model is highly cost-effective and can be used to create applications that are highly scalable. The main advantage of this model is that it is highly reliable and secure.

4. Grid Computing Model: This model is used for distributed systems where the resources are shared among multiple computers. In this model, the resources are hosted on multiple computers and can be accessed by multiple users. This model is highly efficient and can be used to create applications that are highly reliable and secure. The main advantage of this model is that it is highly scalable and can be used to create distributed applications.

5. Mobile Computing Model: This model is used for distributed systems where the resources are shared among multiple mobile devices. In this model, the resources are hosted on mobile devices and can be accessed by multiple users. This model is highly efficient and can be used to create applications that are highly reliable and secure. The main advantage of this model is that it is highly portable and can be used to create distributed applications.
