
### Performance Metric for Distributed Mutual Exclusion Algorithms for the Notes of the Unit 2 - Distributed Mutual Exclusion in the Subject of DISTRIBUTED SYSTEM

* Performance metrics for distributed mutual exclusion algorithms are used to measure the effectiveness of the algorithm in question.
* The most commonly used performance metric is the **response time**, which is the amount of time it takes for a process to acquire the resource it is requesting. 
* Another important metric is **throughput**, which is the number of requests that can be served in a given time period. 
* Additionally, **scalability** is an important performance metric, which is the ability of the algorithm to handle an increasing number of requests. 
* **Fault tolerance** is also an important metric, which is the ability of the algorithm to continue functioning in the presence of faults.
* **Safety** is also an important metric, which is the ability of the algorithm to ensure that only one process can access the resource at a given time.
* A good mnemonic to remember these metrics is **RTFSFS**, which stands for Response Time, Throughput, Fault Tolerance, Scalability, and Safety.
