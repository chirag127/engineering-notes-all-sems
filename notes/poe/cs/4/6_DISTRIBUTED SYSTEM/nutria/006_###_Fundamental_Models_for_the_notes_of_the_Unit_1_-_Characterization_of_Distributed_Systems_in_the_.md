
### Fundamental Models for the notes of the Unit 1 - Characterization of Distributed Systems in the subject of DISTRIBUTED SYSTEM

* Client-Server Model: The Client-Server Model is the most basic model for distributed systems. It is composed of two components: a client and a server. The client is responsible for requesting services from the server, while the server is responsible for providing those services to the client. The client and server communicate with each other over a network.

* Peer-to-Peer Model: The Peer-to-Peer Model is an alternative to the Client-Server Model. In this model, each node in the network acts as both a client and a server. This model is often used in file sharing applications, where each node can both request and provide files.

* Replication Model: The Replication Model is a model for distributed systems that is focused on data replication. In this model, data is replicated across multiple nodes in the network. This ensures that the data is always available, even if one of the nodes fails.

* Event-Based Model: The Event-Based Model is a model for distributed systems that is focused on asynchronous communication. In this model, nodes communicate by sending events to each other. These events can be used to trigger different actions on the receiving node.

* Mobile Agent Model: The Mobile Agent Model is a model for distributed systems that is focused on mobile agents. In this model, agents are sent from one node to another in order to perform tasks. This allows for tasks to be performed in a distributed way, without the need for direct communication between nodes.

* Grid Computing Model: The Grid Computing Model is a model for distributed systems that is focused on distributed computing. In this model, nodes in the network are used to perform computing tasks in a distributed way. This allows for tasks to be completed more quickly, as multiple nodes can work on the same task simultaneously.
