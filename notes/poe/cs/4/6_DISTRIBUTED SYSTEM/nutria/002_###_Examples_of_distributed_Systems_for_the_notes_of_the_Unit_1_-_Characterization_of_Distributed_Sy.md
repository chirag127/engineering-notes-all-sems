
### Examples of Distributed Systems for the Notes of Unit 1 - Characterization of Distributed Systems in the Subject of DISTRIBUTED SYSTEM

* Client-Server Model: This is the most basic type of distributed system, in which the client requests services from the server and the server provides the services. The server can be a single machine or a collection of machines.
* Peer-to-Peer Model: This type of distributed system has no central server and instead, all the nodes in the network are equal and can communicate with each other directly.
* Grid Computing: This type of distributed system is composed of multiple computers that are connected to each other to form a grid. The grid can be used to solve complex problems that require a large amount of computing power.
* Cloud Computing: This type of distributed system is composed of multiple computers that are connected to each other to form a cloud. The cloud can be used to provide services such as storage, computing, and networking.
* Mobile Computing: This type of distributed system is composed of multiple mobile devices that are connected to each other to form a mobile network. The mobile network can be used to provide services such as data and voice communication.
* Distributed Databases: This type of distributed system is composed of multiple databases that are connected to each other to form a distributed database. The distributed database can be used to store and manage large amounts of data.
* Distributed File Systems: This type of distributed system is composed of multiple file systems that are connected to each other to form a distributed file system. The distributed file system can be used to store and manage large amounts of data.
