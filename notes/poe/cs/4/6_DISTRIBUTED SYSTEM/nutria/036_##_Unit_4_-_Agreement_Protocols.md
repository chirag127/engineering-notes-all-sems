

## Unit 4 - Agreement Protocols

Agreement protocols are a set of rules and principles that enable two or more entities to reach a consensus on a certain task. Agreement protocols are used in distributed systems to ensure that all entities involved in the system are in agreement on the state of the system. Agreement protocols are also used in distributed databases, distributed file systems, and distributed computing.

Some of the most commonly used agreement protocols are:

1. Two-Phase Commit Protocol (2PC): This is a distributed transaction protocol that ensures that all nodes involved in the transaction reach a consensus on whether to commit or abort the transaction. The protocol involves two phases: the prepare phase and the commit phase.

2. Paxos Protocol: This is a consensus protocol that is used to reach agreement among multiple nodes in a distributed system. The protocol uses a leader node to coordinate the consensus process.

3. Raft Protocol: This is a distributed consensus protocol that is used to ensure that all nodes in a distributed system are in agreement on the state of the system. The protocol uses a leader node to coordinate the consensus process.

4. Byzantine Fault Tolerance (BFT): This is a fault-tolerance protocol that is used to ensure that a distributed system can continue to operate even if some of the nodes in the system fail. BFT uses an algorithm called Byzantine Agreement to ensure that all nodes in the system are in agreement on the state of the system.

5. Consensus Algorithms: Consensus algorithms are algorithms that are used to reach agreement among multiple nodes in a distributed system. Examples of consensus algorithms include proof-of-work, proof-of-stake, and Byzantine Agreement.
