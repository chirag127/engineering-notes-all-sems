## Unit 3 - Structural Testing

Structural testing is a type of testing that evaluates the internal structure of the software or system under test. It is also known as white-box testing, clear-box testing or glass-box testing. In this type of testing, the tester has knowledge of the internal workings of the software, including its code and architecture.

### Types of Structural Testing

1. Statement Coverage: This type of testing aims to test each statement of the code at least once. In this type of testing, the tester ensures that every line of code is executed at least once.

2. Branch Coverage: This type of testing aims to test each branch of the code at least once. It checks whether all possible branching paths in the code have been tested.

3. Condition Coverage: This type of testing aims to test each condition of the code at least once. It checks whether all possible combinations of conditions have been tested.

4. Path Coverage: This type of testing aims to test all possible paths through the code. It ensures that every possible sequence of code execution has been tested.

### Advantages of Structural Testing

1. It ensures that all the code has been tested and executed at least once.

2. It helps to identify defects and errors in the code early in the development cycle.

3. It helps to improve the quality of the code and the overall software or system.

### Disadvantages of Structural Testing

1. It is time-consuming and requires a high level of expertise.

2. It may not be effective in identifying defects and errors that occur due to interactions between different parts of the system.

### Mnemonics and Learning Tricks for Structural Testing

1. STP (Statement, Branch, Condition, Path) - This is a simple mnemonic that can be used to remember the different types of structural testing.

2. Code Coverage - This is a term used to describe the level of code that has been tested. It can be used to keep track of the progress of structural testing.

3. Test Case Design - The design of test cases is an important aspect of structural testing. Test cases should be designed to cover all possible paths through the code.

In conclusion, structural testing is an important aspect of software testing that aims to evaluate the internal structure of the software or system under test. It helps to improve the quality of the code and identify defects and errors early in the development cycle. The different types of structural testing, advantages, and disadvantages should be understood by testers to ensure effective testing. Mnemonics and learning tricks can also be used to aid in the understanding and retention of this information.
