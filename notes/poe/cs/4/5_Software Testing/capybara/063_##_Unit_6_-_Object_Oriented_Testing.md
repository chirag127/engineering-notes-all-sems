## Unit 6 - Object Oriented Testing

Object Oriented Testing is a process of verifying the functionality and performance of an object-oriented system. It is an essential part of the software development life cycle and helps in identifying defects and ensuring the quality of the software. Here are some key points to understand about Object Oriented Testing:

### Types of Object Oriented Testing

1. Unit Testing: It is the process of testing individual units or components of a software application. It is done to ensure that each unit of the software is working as expected.

2. Integration Testing: It is the process of testing the interaction between different modules or components of a software application. It is done to ensure that the integrated system is working as expected.

3. System Testing: It is the process of testing the entire software system. It is done to ensure that the software system is working as per the requirements.

4. Acceptance Testing: It is the process of testing the software system with the customer's perspective. It is done to ensure that the software system meets the customer's requirements.

### Techniques of Object Oriented Testing

1. Black Box Testing: It is a testing technique in which the tester does not have any knowledge of the internal workings of the software system. It is done to ensure that the software system is working as per the requirements.

2. White Box Testing: It is a testing technique in which the tester has knowledge of the internal workings of the software system. It is done to ensure that the software system is working as expected.

3. Grey Box Testing: It is a testing technique in which the tester has partial knowledge of the internal workings of the software system. It is done to ensure that the software system is working as expected.

### Advantages of Object Oriented Testing

1. It helps in identifying defects early in the software development life cycle.

2. It ensures the quality of the software system.

3. It reduces the cost of software development by identifying defects early.

4. It helps in reducing the time required for testing.

### Disadvantages of Object Oriented Testing

1. It requires skilled testers who have knowledge of Object Oriented Programming.

2. It can be time-consuming as it involves testing at different levels.

3. It can be expensive as it requires specialized tools for testing.

### Mnemonics and Learning Tricks

There are no specific Mnemonics or learning tricks for Object Oriented Testing. However, it is important to have a clear understanding of the different types and techniques of testing to ensure the quality of the software system. It is also important to have hands-on experience in testing Object Oriented systems to become proficient in Object Oriented Testing.
