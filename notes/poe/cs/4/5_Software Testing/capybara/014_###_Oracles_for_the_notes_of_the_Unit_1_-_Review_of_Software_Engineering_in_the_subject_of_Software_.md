### Oracles for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing

In software testing, an oracle is a mechanism to determine the expected output for a given input during testing. It is used to compare the actual output of the software to the expected output to determine if the software is functioning correctly. Oracles are important in software testing as they help to ensure that the software is tested thoroughly and that all possible scenarios are covered.

Here are some of the oracles that are commonly used in software testing:

1. Specification oracles: These oracles are based on the software requirements specification. They are used to verify that the software meets the specified requirements. The tester compares the output of the software to the requirements specified in the document.

2. Programmatic oracles: These oracles are based on the code of the software. They are used to verify that the software is functioning correctly according to the code. The tester compares the output of the software to the expected output based on the code.

3. Domain oracles: These oracles are based on the domain knowledge of the tester. The tester uses their knowledge of the domain to determine the expected output of the software. For example, a tester with knowledge of accounting might use their knowledge to determine the expected output of a software program that performs accounting functions.

4. Historical oracles: These oracles are based on the history of the software. The tester uses previous versions of the software or previous test results to determine the expected output of the current version of the software.

Mnemonics and Learning Tricks:

Remember the acronym SPHD to remember the different types of oracles:
- Specification oracles
- Programmatic oracles
- Historical oracles
- Domain oracles

Using the acronym SPHD can help you remember the different types of oracles and their purposes in software testing.
