### Configuration Audits for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing

Configuration audit is a type of software testing that is performed to ensure that the software system has been built according to its specifications and that it meets the required standards. Configuration audits are critical because they help to identify and address defects and errors that may have been introduced during the development process.

Here are some important points to remember about configuration audits:

- Configuration audits are conducted to ensure that the software system has been built according to its specifications and that it meets the required standards.
- The purpose of a configuration audit is to identify and address defects and errors that may have been introduced during the development process.
- Configuration audits can be conducted at different stages of the software development life cycle, such as during the design, implementation, testing, and maintenance phases.
- During a configuration audit, the software system is reviewed to ensure that it meets the specified requirements, is free of defects, and is compliant with relevant standards and regulations.
- Configuration audits can be performed manually or using automated tools.
- There are different types of configuration audits, such as functional audits, design audits, and code audits.
- Functional audits are used to verify that the software system meets its functional requirements, while design audits are used to ensure that the software system has been designed correctly.
- Code audits are used to check the source code for defects, errors, and vulnerabilities.

Mnemonics and learning tricks can be helpful in remembering the different types of configuration audits. For example, you can use the acronym FDC (Functional, Design, and Code) to remember the three types of configuration audits. Another trick is to think of configuration audits as a way to ensure that the software system is "configured" correctly, meaning that it meets its specifications and standards.
