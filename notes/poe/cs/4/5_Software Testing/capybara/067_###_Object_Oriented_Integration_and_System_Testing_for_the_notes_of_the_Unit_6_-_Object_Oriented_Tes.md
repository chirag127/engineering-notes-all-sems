### Object Oriented Integration and System Testing for the notes of the Unit 6 - Object Oriented Testing in the subject of Software Testing

Object Oriented Integration Testing is the process of testing the interaction between different modules of a software system. It mainly focuses on the integration of various modules of the software system to ensure that they work together as expected. The main objective of Object-Oriented Integration Testing is to identify and resolve the defects in the integration of different modules.

System Testing, on the other hand, is the process of testing the complete software system as a whole. It focuses on the functional and non-functional requirements of the software system. The main objective of System Testing is to ensure that the software system meets the specified requirements and is free from defects.

Object Oriented Integration and System Testing are crucial parts of the software testing process. Here are some of the important points to remember while studying Object Oriented Integration and System Testing for the notes of the Unit 6 - Object Oriented Testing in the subject of Software Testing:

#### Object Oriented Integration Testing:

- Object-Oriented Integration Testing is done after unit testing and before system testing.
- It mainly focuses on the interaction between different modules of a software system.
- The main objective is to identify and resolve the defects in the integration of different modules.
- Test cases are designed to test the integration between different modules.
- Common defects found during Object-Oriented Integration Testing are interface defects, data flow defects, and control flow defects.
- Some of the testing techniques used in Object-Oriented Integration Testing are Big Bang Integration, Top-Down Integration, Bottom-Up Integration, and Hybrid Integration.

#### System Testing:

- System Testing is done after Object-Oriented Integration Testing.
- It focuses on the functional and non-functional requirements of the software system.
- The main objective is to ensure that the software system meets the specified requirements and is free from defects.
- Test cases are designed to test the complete software system as a whole.
- Common defects found during System Testing are functionality defects, usability defects, performance defects, and security defects.
- Some of the testing techniques used in System Testing are Functional Testing, Performance Testing, Security Testing, and Usability Testing.

Mnemonics and learning tricks can be helpful in remembering the different testing techniques used in Object Oriented Integration and System Testing. For example:

- Big Bang Integration - Think of a big explosion where all the modules are integrated at once.
- Top-Down Integration - Think of a hierarchy where the top-level module is tested first and then the lower-level modules are integrated.
- Bottom-Up Integration - Think of a building where the foundation is tested first and then the upper-level modules are integrated.
- Hybrid Integration - Think of a combination of Top-Down and Bottom-Up Integration.

In conclusion, Object Oriented Integration and System Testing are crucial parts of the software testing process. It is important to understand the different testing techniques used in Object Oriented Integration and System Testing and remember the common defects found during these testing phases.
