### Security Testing for the notes of the Unit 7 - Testing Web Applications in the subject of Software Testing

Security Testing is a type of software testing that uncovers vulnerabilities, weaknesses, and flaws in the system that can be exploited by attackers to compromise the system.

**Objectives of Security Testing:**

- Find vulnerabilities in the system that can be misused by attackers to compromise data, accounts, or resources.
- Identify weaknesses in the application that can be exploited to gain unauthorized access.
- Determine if the application is compliant with security standards and requirements.
- Assess the effectiveness of countermeasures and security controls.

**Types of Security Testing:**

- Penetration Testing: Simulating an attack on the system to identify vulnerabilities.
- Vulnerability Scanning: Automated scanning to detect known vulnerabilities.
- Fuzz Testing: Providing invalid or random data as input to find flaws that can lead to crashes or security vulnerabilities.
- Configuration Testing: Checking if the system is configured securely and all security features are enabled.
- Patch Testing: Verifying if patches or updates resolve the vulnerabilities as claimed.

**Tips for Effective Security Testing:**

- Have good knowledge of common vulnerabilities and attack techniques.
- Think like an attacker and try to breach the system's defenses.
- Test all input values and endpoints of the application.
- Try escalating privileges and bypassing access controls.
- Check for weak error handling and informative error messages.
- Test the application with and without authentication.
- Run automated scanning tools and review the results.
- Document all vulnerabilities and weaknesses found.

**Advantages of Security Testing:**

- Identifies vulnerabilities before attackers exploit them.
- Enhances the security posture of the system.
- Compliance with security standards and requirements.
- Gains confidence in the security of the system.

**Disadvantages of Security Testing:**

- Difficult to perform exhaustive testing.
- Requires highly skilled testers.
- Vulnerabilities found late in the development cycle can be expensive to fix.
- May disrupt or degrade system performance.
- False positives can occur.

**Mnemonics:**

- ATTACK - Assess, Test, Try, Analyze, Check, Know (Steps involved in penetration testing)
- DREAD - Damage potential, Reproducibility, Exploitability, Affected users, Discoverability (Risk assessment model)
