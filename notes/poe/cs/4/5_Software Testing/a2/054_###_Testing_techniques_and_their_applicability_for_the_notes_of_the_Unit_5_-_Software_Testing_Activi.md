### Testing techniques and their applicability for the notes of the Unit 5 - Software Testing Activities in the subject of Software Testing

- **White box testing**: Verifies the internal structure of the software and examines the code path. Applicable to test the logical paths and control flows of the software. Useful to detect the structural errors or flaws. Examples: branch coverage, statement coverage, path coverage.
- **Black box testing**: Verifies the functionality of the software without examining the internal code structure. Applicable to test the input and output behavior of the software based on the requirements. Useful to detect the functional errors or missing requirements. Examples: Boundary value analysis, Equivalence partitioning.
- **Grey box testing**: Combines both white box and black box testing techniques. Applicable to get the benefits of both techniques to comprehensively test the software.
- **Static testing**: Analyzes the software artifacts without executing the software. Applicable for reviewing documents, requirements, and code. Useful to detect defects early and reduce costs. Examples: Reviews, audits, inspections, static analysis tools.
- **Dynamic testing**: Involves executing the software and analyzing its behavior. Applicable for functional and non-functional testing. Useful to uncover defects and validate that the software meets specified requirements. Examples: Unit testing, integration testing, system testing, acceptance testing.

Advantages:
- Comprehensive testing of software using different techniques.
- Early detection of defects reduces costs and risks.
- Better software quality and reliability.

Disadvantages:
- Requires skilled testers and time to perform different types of testing.
- Not feasible to apply all types of testing for every software. Selection of appropriate techniques based on project objectives and constraints.

Applications: These techniques are commonly applied in the software testing life cycle to evaluate different aspects (structural, functional, non-functional) of the software and uncover defects to produce high quality software. The specific techniques to apply depend on the particular testing objectives and project requirements.
