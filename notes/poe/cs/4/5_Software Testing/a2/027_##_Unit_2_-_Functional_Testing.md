## Unit 2 - Functional Testing

Functional testing is a type of black-box testing that bases its test cases on the specifications of the software that is being tested. The key goal is to validate that the software meets the specified requirements.

Some key points about functional testing:

- Tests are designed based on the functional requirements of the software.
- Tests are conducted from an end-user perspective without knowledge of the internal code structure.
- Checks if the output is as expected for given inputs.
- Can be conducted either manually or using automated testing tools.
- Ensures that all stated functionality and performance requirements are met.
- Does not uncover bugs or flaws in the internal structure of the software.

Some advantages of functional testing:

- Easy to understand and create test cases from user requirements.
- Tests the software the way an end-user would use it so important functional flaws are detected early.
- With automated tools, regression testing is made easy as tests can be rerun quickly.

Some disadvantages of functional testing:

- May not detect structural or backend issues in the software.
- If requirements are missing or incorrect, functional tests also may not reveal problems.
- Resource-intensive to conduct thorough functional testing, especially if done manually.

 Mnemonics to remember key points:

- Think like a user (black-box)
- Based on specs (requirements)
- Input-output validation
- Manual or automated
- Advantages: Easy, end-user perspective, regression
- Disadvantages: May miss non-functional bugs, dependent on requirements

Examples of functional tests:

- Check if login is successful with valid credentials
- Verify if a purchase order can be placed successfully
- Confirm if a file can be uploaded and downloaded correctly
- Test calculators or other applications to ensure they work accurately

Applications: Most types of software including applications, calculators, e-commerce sites, etc. Functional testing is typically done as one of the initial levels of testing.
