### Identification of Independent Paths for the notes of the Unit 3 - Structural Testing in the subject of Software Testing

The following points can be included in the notes for Identification of Independent Paths -

1. Independent Paths - Unique execution paths in the software/program under test. They do not share common steps/statements in their execution path.
2. Methods to identify Independent Paths -
    - Control Flow Graphs - Graphical representation of the control flow of the program. Independent paths can be identified from the graph.
    - Cyclomatic Complexity - Numerically represents the number of independent paths. It can be calculated using control flow graphs. Higher the cyclomatic complexity, higher the number of independent paths.
3. Importance of identifying Independent Paths -
    - To achieve good statement and branch coverage during structural testing. Identifying and testing independent paths ensures maximum coverage.
    - To detect maximum number of faults/defects in the software. As independent paths are unique, maximum number of faults can be uncovered by testing them.
4. Examples -
    - For a sequence of if-else statements, each if and else block can represent an independent path.
    - For a switch case, each case represents an independent path.
5. Advantages - Helps maximize test coverage and increases chances of finding faults.
6. Disadvantages - Can be difficult to identify independent paths for complex control flows. May require tools to automatically generate independent paths for higher complexity.
