### Errors for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing

1. Syntax Error:
- Occurs due to violation of the syntax rules of the programming language.
- Compiler detects and reports the syntax error.
- Program cannot execute until the syntax error is resolved.
- Examples: Missing semicolon, unmatched parentheses, etc.
- Mnemonic: Think of syntax error as spelling mistakes in English. The program will not run if there are syntax errors just like a sentence will not make sense if there are spelling mistakes.

2. Logical Error:
- The program executes but does not produce the desired output.
- Difficult to detect and debug.
- Examples: Infinite loop, incorrect logic, etc.
- Mnemonic: Logical errors are like calculation mistakes. The steps to solve the problem are correct but there is a mistake in the logic leading to a wrong solution.

3. Runtime Error:
- The program executes for some time but crashes after encountering a runtime error.
- Examples: Division by zero, out of bounds array access, etc.
- Mnemonic: Runtime errors are like obstacles that stop a car. The program is running but encounters an error that stops the execution.

Advantages of detecting and resolving errors:
- The program gives the desired output.
- Avoid system crashes and unstable behavior.
- Debugging and resolving errors leads to a robust and high-quality software product.

Disadvantages of errors:
- Difficult and time-consuming to detect and resolve errors especially logical errors.
- Errors can lead to unexpected system crashes and unstable behavior if undetected.
- The final software product may not meet the requirements if there are unresolved errors.

Applications of error detection and resolution:
- Software testing and debugging.
- Static code analysis using linting tools.
- Formal verification methods.
