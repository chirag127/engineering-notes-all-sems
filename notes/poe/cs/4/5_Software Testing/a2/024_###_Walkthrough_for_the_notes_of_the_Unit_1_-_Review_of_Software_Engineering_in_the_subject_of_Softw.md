### Walkthrough for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing

1. Software Engineering - Software Engineering is an engineering discipline which is concerned with all aspects of software production. It includes technical skills and techniques required for the systematic development and implementation of software solutions to specific requirements or problems.

2. Software Development Life Cycle (SDLC) - SDLC is a process used by the software industry to design, develop and test high quality softwares. The SDLC aims to produce a high-quality software that meets or exceeds customer expectations, reaches completion within times and cost estimates. The basic SDLC models are:
    - Waterfall model - rigid and sequential method. Progress flows in one direction like a waterfall.
    - Iterative and incremental model - involves repeating a set of software development activities over a series of small periods or iterations.
    - Agile model - focuses on adaptive planning, evolutionary development, early delivery, and continuous improvements. Uses Scrum and Extreme Programming (XP).

3. Types of Software - System software and Application software. System software is software designed to directly operate a computer, eg. Operating systems. Application software is programs designed to perform specific tasks for users, eg. Microsoft Office.
