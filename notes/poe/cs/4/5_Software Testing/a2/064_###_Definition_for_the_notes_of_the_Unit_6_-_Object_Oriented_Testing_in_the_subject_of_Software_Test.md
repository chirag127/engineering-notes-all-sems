### Object Oriented Testing
- Object Oriented Testing involves testing individual objects/classes and their interactions.
- It focuses on testing the behavior and state of objects.
- Some key aspects of object oriented testing are:
-- Testing object creation and initialization
-- Testing object dependencies
-- Testing encapsulation
-- Testing inheritance and polymorphism
-- Testing exceptions
-- Testing concurrent access to objects

 Mnemonics/Learning tricks:
- Think OOT - Object Oriented Testing
- Check OBIE - Object creation, Behavior, Inheritance, Encapsulation
- DEPEND - Dependencies, Exceptions, Polymorphism, Concurrency

Advantages:
- Helps identify defects/bugs in the early stages of SDLC.
- Improves code quality and robustness.
- Detects architectural flaws and design issues proactively.

Disadvantages:
- Can be complex and time consuming for large systems with many objects and dependencies.
- Require skilled testers with good programming knowledge.
- Difficult to automate at times.

Examples:
- Testing a banking application by creating account objects and testing deposit, withdraw, interest calculation features.
- Testing a e-commerce application by creating product and order objects and testing their interactions.

Applications:
- Object Oriented Testing is commonly used to test software/applications developed using object oriented programming languages like Java, C++, Python, etc.
- It is a key technique in agile and DevOps methodologies to enable continuous testing and integration.
