### Performance Testing for the notes of the Unit 7 - Testing Web Applications in the subject of Software Testing

Performance Testing is done to determine the performance of a system to a certain load. It identifies the software bottlenecks and improves the performance of the system.

Some key points about Performance Testing -

- It is conducted to determine the speed, scalability, and/or stability of a software application under a given workload.
- It is usually measured in terms of response time, throughput, and resource-utilization.
- The key metrics used are - response time, throughput, CPU utilization, memory utilization, disk utilization, network utilization, etc.
- The performance of the system is measured and the results are analyzed to determine if it meets the performance requirements.
- Load Testing and Stress Testing are types of Performance Testing.
- Performance Testing is conducted in a controlled test environment with production-like data and scenarios.
- The results help identify and address software/hardware bottlenecks that could degrade system performance and take corrective actions before deployment.

Advantages of Performance Testing -

- It uncovers bottlenecks and helps improve performance.
- It ensures that the software meets the specified performance requirements.
- It helps evaluate and monitor the resource usage of the system.
- It provides concrete performance data and metrics to determine if the system is ready for deployment.

Disadvantages of Performance Testing -

- It is time-consuming and costly.
- It requires a controlled test environment and specific tools and expertise.
- The results could be affected by the test environment and data which may differ from the actual production environment and data.
- It is difficult to reproduce and isolate performance issues.

Some tips for effective Performance Testing -

- Identify the performance acceptance criteria and requirements.
- Prepare a detailed test plan and test cases.
- Choose the right performance testing tools and testing types (Load Testing, Stress Testing, etc.).
- Simulate real-world scenarios and load conditions.
- Monitor and measure key performance metrics.
- Analyze the results and identify bottlenecks.
- Take corrective actions and re-test.
