### Difference Between Verification and Validation

Verfication and Validation are two important processes in Software Testing that are often confused with each other. Let's understand the difference between them:

**Verification** - It is the process of checking whether the software meets the specified requirements. It is done at the development phase. It helps to determine whether the product is built according to the specifications and meets the expected requirements.

**Validation** - It is the process of checking whether the software meets the user needs and requirements. It is done at the testing phase. It helps to determine whether the product actually meets the user's needs.

In short, Verification is about building the product right while Validation is about building the right product.

**Mnemonics** - A simple mnemonics to remember the difference is -

V&V - Verification then Validation

 specification then user

**Advantages** - Performing both Verification and Validation leads to high quality software with less defects as it checks the software at multiple levels.

**Disadvantages** - It can be time consuming and expensive to perform exhaustive Verification and Validation. Programmers may get de-motivated if a lot of bugs are found which they have to fix.

**Examples** - Code reviews, inspections and walkthroughs are examples of Verification. Beta testing and acceptance testing are examples of Validation.

**Applications** - Verification and Validation techniques are widely used in the software industry to improve software quality and reliability.
