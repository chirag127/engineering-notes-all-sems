### Post Deployment Testing for the notes of the Unit 7 - Testing Web Applications in the subject of Software Testing

Post Deployment Testing is done after the software is deployed to ensure that it meets the required quality standards. Following are the types of Post Deployment Testing -

1. Recovery Testing - It checks if the software is able to recover from crashes, hardware failures or other similar problems. It verifies if the data is intact after a recovery.

2. Failover Testing - It checks if the software is able to shift to a backup system in case of a failure. For e.g. if a server fails, it checks if the software is able to failover to a backup server seamlessly.

3. Performance Testing - It checks if the software meets the performance requirements like response time, throughput, resource-utilization, etc. after deployment. Load Testing and Stress Testing are done under Performance Testing.

4. Security Testing - It verifies if the software is protected from threats and vulnerabilities like SQL Injection, Cross-Site Scripting, etc. after deployment. Penetration Testing and Vulnerability Assessment are done under Security Testing.

5. Scalability Testing - It checks if the software is able to handle increased workload by scaling up or scaling out after deployment. For e.g. if more users are added, it checks if the response time remains within acceptable limits.

6. Usability Testing - It verifies if the software is easy to use, provides good user experience and meets user requirements after deployment. Real users are made to use the software and their experience is noted.

7. Configuration Testing - It ensures that the software is configured correctly as per the requirements after deployment. Wrong configurations can lead to issues like performance degradation, security loopholes, etc.

8. Upgrade Testing - If the software is upgraded, it is important to test if the upgrade is successful and if the software works as expected after upgrade. Both functional and non-functional areas are tested in Upgrade Testing.

Mnemonics - POST DT for Post Deployment Testing.

Advantages - Helps release a high quality software, reduces customer complaints and costs due to defects, leads to happy customers and business growth.

Disadvantages - Can be time-consuming and expensive, requires careful planning and coordination.
