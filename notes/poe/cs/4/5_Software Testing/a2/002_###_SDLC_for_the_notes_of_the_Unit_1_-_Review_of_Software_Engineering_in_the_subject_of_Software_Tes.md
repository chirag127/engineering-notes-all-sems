### SDLC for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing

The Software Development Life Cycle (SDLC) is a process used by the software industry to design, develop and test high quality softwares. The SDLC aims to produce a high-quality software that meets or exceeds customer expectations, reaches completion within times and cost estimates.

The SDLC process includes the following stages:

1. Requirements Analysis: The first stage is to gather and analyze the requirements of the customer. The requirements are collected through user surveys, stakeholder interviews or focus groups. The requirements are then analyzed for their validity and the possibility of incorporating them in the software to be developed.

2. Design: The software design is formulated in this stage. The requirements are translated into block diagrams and architecture. The design phase follows a systematic approach to develop structure for the software that will satisfy the requirements.

3. Implementation: The design is translated into code in the required programming language in this phase. The code is developed or implemented as per the design specifications.

4. Testing: The software developed in the implementation phase is tested against the requirements to identify and fix any bugs or errors. Various tests like unit testing, integration testing, system testing are conducted.

5. Deployment: Once the software has passed all the tests, it is deployed to the customer. Final updates may be made based on user feedback.

6. Maintenance: The software is continuously monitored and upgraded to fix any issues and meet new requirements. It is an ongoing process to improve the functionality of the software.
