### Oracles for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing

- Oracles are mechanisms or techniques to determine if the actual output of a software is correct with respect to the expected output. They are used to evaluate the correctness of the software.
- Some common types of oracles are:
    - Exact Match: Comparing the actual output with the expected output. If they match exactly, the software is correct otherwise incorrect.
    - Compatibility: Checking if the actual output is compatible with the expected output using some compatibility criteria. For e.g. Checking if the actual output is within tolerable deviation from the expected output.
    - Human Expert: Getting the software evaluated by a human expert in the domain. The expert checks if the actual output is correct.
    - Specifications: The software is correct if it satisfies the specifications. The specifications act as the oracle in this case.
- Advantages: Helps in determining correctness of software. Useful for testing and evaluating software.
- Disadvantages: Difficult to automate oracles. Human oracles are prone to errors. Exact match oracle may not be feasible if expected outputs are complex. Specifications may be ambiguous or incomplete leading to incorrect evaluations.
- Examples: Testing a calculator app (exact match oracle), Testing an image processing software (compatibility oracle), Medical diagnosis software (human expert oracle), Testing a complex machine learning model (specifications oracle)
- Applications: Used in software testing, debugging and verification processes to evaluate correctness of software. Help in assessing quality of software.
