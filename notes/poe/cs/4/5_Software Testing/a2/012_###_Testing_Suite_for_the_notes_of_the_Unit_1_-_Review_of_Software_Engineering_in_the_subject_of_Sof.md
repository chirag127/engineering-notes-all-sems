### Testing Suite for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing

The following points cover the key topics and concepts from the Testing Suite for the notes of Unit 1 - Review of Software Engineering in the subject of Software Testing:

1. Software Testing - Software testing is a process used to identify the correctness, completeness and quality of developed computer software. It involves executing a program or application with the intent of finding software bugs (errors or other defects).

2. Testing Objectives - The main objectives of software testing are:

- To uncover and identify bugs, defects and errors.
- To verify and validate that the software meets requirements.
- To ensure that the software is reliable, usable, and meets high quality standards.

3. Software Testing Approaches - The main software testing approaches are:

- White box testing - Verifies the internal structure and coding of the software. Also known as glass box, open box or clear box testing.
- Black box testing - Verifies the functionality of the software without looking at the internal structure. Also known as behavioral testing or functional testing.
- Grey box testing - Combines black box and white box testing approaches. The tester has limited knowledge of the internal structure.

4. Testing Techniques - The main software testing techniques are:

- Static testing - Analysis of software without executing programs. Includes reviews and inspections.
- Dynamic testing - Testing of the software by executing programs or applications. Includes methods such as boundary value analysis, equivalence partitioning, error guessing, and fuzz testing.
