### Test for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing

1. Software Testing - Software testing is a process of evaluating a software item to detect differences between given input and expected output. It is a process of validating and verifying that a software program/application meets the business and technical requirements that guided its design and development.
2. Types of Software Testing - There are mainly two types of software testing:

- Manual Testing - Performed manually by a tester without using any automated tools. Tester performs test cases and verifies the results.
- Automated Testing - Performed using automated testing tools to quickly perform repetitive testing tasks. Automated tests are written in a scripting language to control the automation tools.

3. Software Testing Life Cycle - The Software Testing Life Cycle includes the following stages:

- Requirement Analysis - Analyzing the requirements to identify test scenarios.
- Test Planning - Creating a test plan document which acts as a guide to perform testing activities.
- Test Case Development - Developing test cases that will be used to test the software.
- Environment Setup - Setting up the test environment with required hardware and software.
- Test Execution - Executing the test cases and logging defects.
- Defect Reporting and Tracking - Reporting and tracking defects found during test execution.
- Test Completion - Finalizing testing and generating test reports.

4. Software Testing Types - The different types of software testing are:

- Unit Testing - Tests individual software components.
- Integration Testing - Tests integrated software modules.
- System Testing - Tests the complete software product.
- Acceptance Testing - Tests the software with the customer perspective.
- Performance Testing - Tests the performance of the software.
- Stress Testing - Tests the software under extreme workloads.
- Regression Testing - Tests the unchanged parts of the software if any changes were made.
- Alpha and Beta Testing - Forms of acceptance testing performed by potential users.
