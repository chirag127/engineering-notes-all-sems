## Unit 6 - Object Oriented Testing

### What is Object Oriented Testing?
- Object Oriented Testing (OOT) is a software testing approach based on Object Oriented Programming (OOP) concepts.
- In OOT, test cases are designed to test individual objects and their interactions.
- Objects are tested for their functionality, interactions, and data.
- The key aspects tested are:
-- Objects: Creation, initialization, state, behavior, relationships
-- Messages: Correct message passing between objects, proper method calls
-- Inheritance: Proper implementation and overrides of superclass methods
-- Polymorphism: Objects responding correctly based on type
-- Encapsulation: Private data and methods not being accessible improperly

### Advantages of OOT
- Mimics how software is designed (using OOP concepts) so is intuitive to developers.
- Can reuse test cases for objects and granularly test individual components.
- Easy to locate the source of faults by following object interactions and messages.
- Supports evolutionary testing - can add or change tests as objects evolve.

### Disadvantages of OOT
- Can be more complex to set up tests due to intricate object interactions and relationships.
- Verifying emergent behaviors arising from multiple objects collaborating can be difficult.
- May need multiple tests to fully exercise an object's functionality.
- Requires testers and developers to be proficient in OOP concepts.
