## Unit 3 - Structural Testing

Structural testing is a white box testing technique that validates the internal structure of the software/application. It helps to identify structural flaws & ensure that all statements and paths have been tested.

Some key points about Structural Testing:

- It examines the underlying code structure of the application.
- It verifies that all paths/branches in the code are executed.
- It ensures that all conditions in conditional logic have been tested.
- It analyses the internal logic of the software to identify potential issues.
- It requires access to the source code.
- It complements functional testing to provide better test coverage.
- Some techniques used are control flow testing, data flow testing, loop testing, etc.

Advantages:

- Increases the internal logic coverage of testing.
- Helps to detect logical flaws & ensure better quality code.
- Provides objective measures of test coverage like instruction/branch coverage.

Disadvantages:

- Requires access to the source code which may not always be available.
- Can be time-consuming to perform exhaustive testing of complex code.
- May encourage debugging oriented testing rather than functionality oriented testing.

In summary, structural testing plays an important role in software testing to uncover bugs related to the internal structure of the code. When combined with functional testing, it leads to more robust and high-quality software applications.
