### Web Testing
Web Testing involves testing of web applications on web browsers and servers. Following are the key types of Web Testing:

- Functional Testing: Testing the functional aspects of web applications like checking web forms, database connections, cookies, links, etc.
- Usability Testing: Testing the usability of web applications from user perspective like checking ease of navigation, understanding user requirements, consistency, etc.
- Performance Testing: Testing the performance of web applications under various loads like checking response time, throughput, resource usage, scalability, etc.
- Compatibility Testing: Testing the compatibility of web applications with different browsers, operating systems, devices, etc.
- Security Testing: Testing the security of web applications like checking for vulnerabilities to XSS, SQL Injections, cross-site request forgery, etc.

Some key steps in Web Testing:

1. Identify the web application to test
2. Analyze the requirements and specifications of the web application
3. Plan the Web Testing strategy covering types and depth of testing
4. Design Web Test cases and scripts
5. Set up the test environment with required software and tools
6. Execute the test cases and analyze the results
7. Report any bugs or issues and get them fixed
8. Retest the web application and verify fixes

Mnemonics:
FUNCUSPC - Functional, Usability, Performance, Compatibility, Security Testing

Advantages:
- Identifies issues early preventing customer dissatisfaction
- Improves quality and reliability of web applications
- Optimizes performance and security of web applications

Disadvantages:
- Testing all aspects and combinations is challenging
- Requires expertise and investments in tools and infrastructure
- Dynamic nature of web makes testing complex

Applications: E-commerce sites, educational portals, banking sites, social networking sites, etc.
