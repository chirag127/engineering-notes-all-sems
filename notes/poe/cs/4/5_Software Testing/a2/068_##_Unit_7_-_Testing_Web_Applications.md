## Unit 7 - Testing Web Applications

Testing web applications is an important part of the software development life cycle. It helps identify bugs and ensure that the application meets requirements. Here are some key points about testing web applications:

1. **Manual Testing** - This involves manually executing test cases and checking for defects. Some examples are:
- Functional Testing - Checking if components/features work as intended. e.g. login, search, checkout.
- Usability Testing - Checking ease of use and user experience.
- Exploratory Testing - Interacting with the app freely to find bugs.

2. **Automated Testing** - This uses automated tools to execute test scripts and compare actual vs expected results. Some types are:
- Unit Testing - Testing individual components in isolation.
- Integration Testing - Testing combined components/modules.
- Selenium - Popular tool for automating browser interactions.
- TestNG/JUnit - Frameworks for writing and running automated tests.

3. **Test Types** - The key types of tests for web apps are:
- Compatibility Testing - Checking compatibility with browsers, OS, devices, etc.
- Performance Testing - Checking response time, load handling, etc. under varying loads.
- Security Testing - Finding vulnerabilities to attacks like XSS, SQLi, etc.
- Accessibility Testing - Checking accessibility for disabled users.

Some tips for testing web applications:

- Have clear test plans and cases.
- Automate repetitive tests.
- Test on multiple browsers and devices.
- Check boundary values and exceptions.
- Get feedback from real users (usability testing).
- Continuously test and deploy (CI/CD).
