### Test Data Generation using Genetic Algorithm for the notes of the Unit 5 - Software Testing Activities in the subject of Software Testing

- Genetic Algorithms (GAs) are search techniques inspired by natural selection and evolution. They are good at searching large, complex spaces efficiently and have been applied to various software testing problems, including test data generation.
- In test data generation using GAs, individual test data are represented as 'chromosomes' (strings of values) and a population of such test data is evolved over multiple generations using genetic operators like selection, crossover and mutation to generate high quality test data that achieve good coverage.
- Advantages: Effective in generating test data for complex software, capable of handling constraints and generating useful test inputs even with incomplete specifications.
- Disadvantages: May take a long time to evolve good solutions, premature convergence can occur leading to sub-optimal solutions, interpretation of evolved test cases can be difficult.
- Examples: Test data generation for path coverage, mutation score evaluation, software with complex constraints like formulas or algorithms, etc.
- Mnemonics: GA tests breed (generate) test children (test cases) generation after generation to create high-fit (high coverage, boundary value coverage, etc.) species (test suites).
- Learning tricks: Understand how natural evolution principles are simulated to solve optimization problems. Focus on understanding representations, operators and control parameters in GAs. Implement a simple GA-based test data generator to understand concepts and process.
