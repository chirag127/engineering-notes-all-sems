
### Boundary Value Analysis for the notes of the Unit 2 - Functional Testing in the subject of Software Testing

Boundary Value Analysis (BVA) is a black box testing technique used to identify the boundary conditions of a software system. This technique is used to test the software system for its robustness and reliability.

BVA is a type of Equivalence Partitioning technique. It divides the input data of a software system into valid and invalid classes. The valid classes are those that should be accepted by the system, while the invalid classes are those that should be rejected by the system.

BVA tests the boundaries of the input data by using the valid and invalid classes. It can also be used to identify the boundary conditions of the software system.

Advantages:

- BVA is a cost-effective technique as it requires fewer test cases to be executed.
- It is an efficient technique as it helps to identify the boundary conditions of the software system.
- It helps to identify the errors that may occur when the input data is out of the boundary conditions.

Disadvantages:

- BVA may not be able to identify all the errors.
- It is a time-consuming technique as it requires the testing of all the boundary conditions.

Mnemonics and Learning Tricks:

- BVA stands for “Boundary Value Analysis”.
- BVA is a type of Equivalence Partitioning technique.
- BVA tests the boundaries of the input data by using the valid and invalid classes.
- BVA helps to identify the boundary conditions of the software system.
