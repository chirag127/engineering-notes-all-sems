
## Unit 4 - Regression Testing

Regression testing is a type of software testing that verifies that software previously developed and tested still performs correctly after it is changed or interfaced with other software. It is intended to establish confidence in the software after changes have been made. 

The goal of regression testing is to ensure that no new bugs or issues have been introduced in the existing system due to the changes made. It is usually done after the system has undergone maintenance or changes to its existing features.

### Mnemonic

A useful mnemonic for remembering the purpose of regression testing is "Reverse to Check".

### Advantages

- Helps identify any bugs or issues that have been introduced due to changes in the system.
- Helps ensure that the changes made have not affected the existing functionality of the system.
- Helps identify any areas of the system that may have been affected by the changes but have not been tested.

### Disadvantages

- It can be time consuming and costly.
- It can be difficult to determine which tests need to be run.
- It can be difficult to identify all the areas that need to be tested.
