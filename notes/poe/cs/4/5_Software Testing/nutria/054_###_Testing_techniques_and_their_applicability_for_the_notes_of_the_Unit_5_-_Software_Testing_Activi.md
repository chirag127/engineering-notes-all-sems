
### Testing techniques and their applicability for the notes of the Unit 5 - Software Testing Activities in the subject of Software Testing

* **Functional Testing**: Functional testing is a type of software testing that is used to verify that a system meets its requirements and works as expected. Functional testing should be conducted on all components of the system, including the user interface, back-end databases, and other components.

* **Regression Testing**: Regression testing is a type of software testing that is used to verify that changes to a system have not caused any unintended consequences. It is typically conducted after any major changes to the system have been made.

* **Usability Testing**: Usability testing is a type of software testing that is used to evaluate how easy it is for users to use a system. This type of testing should be conducted with actual users to ensure that the system is intuitive and easy to use.

* **Performance Testing**: Performance testing is a type of software testing that is used to evaluate the performance of a system. This type of testing should be conducted to ensure that the system is able to handle the expected load and can be scaled as needed.

* **Security Testing**: Security testing is a type of software testing that is used to evaluate the security of a system. This type of testing should be conducted to ensure that the system is secure and that any vulnerabilities are identified and addressed.

* **Compatibility Testing**: Compatibility testing is a type of software testing that is used to evaluate how well a system works with different hardware and software configurations. This type of testing should be conducted to ensure that the system is compatible with the expected configurations.
