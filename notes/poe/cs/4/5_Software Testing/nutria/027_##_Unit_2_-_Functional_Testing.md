
## Unit 2 - Functional Testing

Functional testing is a type of software testing that verifies that the application meets the requirements specified in the functional requirements document. It is one of the most important types of software testing, as it ensures that the application is working as expected and meets the user's needs.

Functional testing typically involves: 

* Verifying that the application is able to perform its intended functions correctly.
* Checking that the application responds correctly to valid and invalid input.
* Testing the application's user interface to ensure it is user-friendly and intuitive.
* Ensuring the application is able to handle large amounts of data.
* Testing the application's security features.

Mnemonics and Learning Tricks: 

* F.U.N. - Focus on the application's functionality, usability, and security.
* F.A.S.T. - Focus on functional requirements, application design, system integration, and testing.
* B.U.G.S. - Break the application down into its components and test each one individually.
* C.A.T. - Consider the application's context, architecture, and technology.
