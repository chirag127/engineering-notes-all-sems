

### Software Test Plan for the Notes of the Unit 5 - Software Testing Activities in the Subject of Software Testing

1. **Software Testing Activities:** Software testing activities involve the execution of a software component or system component to evaluate one or more properties of interest. Common software testing activities include:

- **Unit Testing**: Unit testing is a type of software testing where individual units of source code, such as functions, classes, or modules, are tested to determine if they are fit for use.
- **Integration Testing**: Integration testing is a type of software testing where individual units of source code are combined and tested as a group.
- **System Testing**: System testing is a type of software testing that evaluates the system as a whole. This includes testing the system's functionality, performance, usability, reliability, and security.
- **Acceptance Testing**: Acceptance testing is a type of software testing where the system is tested to ensure it meets the customer's requirements.

2. **Mnemonics and Learning Tricks for Software Testing Activities:**

- **Unit Testing:** To remember the purpose of unit testing, use the acronym "F.A.C.T.S." which stands for "Find Any Coding/Functionality/Logic/Syntax/Semantic Errors."
- **Integration Testing:** To remember the purpose of integration testing, use the acronym "C.L.E.A.R." which stands for "Check Linking/Exchange of Data/Execution of Interfaces/Accuracy of Results/Robustness."
- **System Testing:** To remember the purpose of system testing, use the acronym "T.E.S.T.S." which stands for "Test Functionality/Ease of Use/Stability/Throughput/Security."
- **Acceptance Testing:** To remember the purpose of acceptance testing, use the acronym "C.U.S.T.O.M." which stands for "Check Usability/Satisfy User Requirements/Test Operability/Meet Time Constraints/Meet Operational Requirements."
