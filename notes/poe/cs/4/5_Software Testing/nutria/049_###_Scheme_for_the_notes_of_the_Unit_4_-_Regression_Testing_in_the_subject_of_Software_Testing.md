

### Scheme for the Notes of the Unit 4 - Regression Testing in the Subject of Software Testing

* Regression testing is a type of software testing that verifies that software previously developed and tested still performs correctly after it has been changed or interfaced with other software.
* It is used to verify that a change in one part of the software does not adversely affect other parts of the software.
* Regression testing is usually done after enhancements, bug fixes, or configuration changes have been made to the software.
* Regression testing is designed to ensure that no new bugs have been introduced and that existing functionality has not been broken.
* A common approach to regression testing is to create a set of test cases that cover all the functional areas of the software.
* These test cases are then run each time a change is made to the software and the results are compared to the results of the previous run.
* If any discrepancies are found, the software is further analyzed to determine the cause of the problem.
* Another approach to regression testing is to use automated testing tools that can detect changes in the software and compare them to the expected results.
* Automated testing tools can save time and money by reducing the amount of manual testing that must be done.
* Mnemonic: RTR (Regression Testing Required)
