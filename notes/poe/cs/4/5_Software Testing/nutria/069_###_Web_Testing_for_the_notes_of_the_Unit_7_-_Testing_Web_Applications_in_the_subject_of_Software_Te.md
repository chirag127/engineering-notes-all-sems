
### Web Testing for the notes of the Unit 7 - Testing Web Applications in the subject of Software Testing

Web Testing is a type of software testing that focuses on testing web applications and websites for functionality, performance, and compatibility. It is an important part of the software development process and helps ensure that web applications are compatible across different browsers, devices, and operating systems.

Web Testing can be broken down into the following categories:

1. **Functional Testing**: This type of testing checks the functionality of the web application or website. This includes testing the user interface, navigation, data entry, data output, and other features.

2. **Performance Testing**: This type of testing checks the performance of the web application or website. This includes testing the response time, load time, memory usage, and other performance metrics.

3. **Compatibility Testing**: This type of testing checks the compatibility of the web application or website across different browsers, devices, and operating systems.

4. **Usability Testing**: This type of testing checks the usability of the web application or website. This includes testing the user experience, user interface, navigation, and other usability metrics.

5. **Security Testing**: This type of testing checks the security of the web application or website. This includes testing the authentication, authorization, encryption, and other security measures.

Mnemonics and Learning Tricks:

1. **F**unctional **P**erformance **C**ompatibility **U**sability **S**ecurity: This mnemonic can be used to remember the categories of Web Testing.

2. **T**est **E**verything **S**everal **T**imes: This mnemonic can be used to remember the importance of testing the web application or website multiple times.
