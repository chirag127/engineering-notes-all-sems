
## Unit 5 - Software Testing Activities

Software testing is an activity that is performed to ensure that a software system meets its intended requirements and performs as expected. It is a process of executing a program or system with the intent of finding errors.

The following are the main activities involved in software testing:

1. **Planning**: This involves creating a test plan and deciding on the appropriate testing strategy.

2. **Designing**: This involves designing the test cases that will be used to test the software.

3. **Execution**: This involves executing the test cases and recording the results.

4. **Analysis**: This involves analyzing the results of the test cases and determining whether the software meets its requirements.

5. **Reporting**: This involves reporting the results of the testing activities.

Software testing can be done manually or automated. Manual testing involves manually executing the test cases and analyzing the results. Automated testing involves using a tool or framework to automate the execution of the test cases and analyze the results.

Mnemonics and learning tricks for software testing activities:

1. **TEST**: Test plan, design, execute, and analyze.

2. **FAST**: Find, analyze, simulate, and track.

3. **STEP**: Set up the environment, test, evaluate, and present.

4. **CRASH**: Check, report, analyze, simulate, and halt.
