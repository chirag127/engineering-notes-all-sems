
### Test for the Notes of the Unit 1 - Review of Software Engineering in the Subject of Software Testing

- Testing is an important part of software engineering, as it ensures that the software is functioning as expected and is free of bugs. 
- A test is a set of conditions or variables under which a system or component is evaluated. 
- There are two main types of tests: functional tests and non-functional tests. 
- Functional tests evaluate the system's functionality and how it meets the requirements of the user. 
- Non-functional tests evaluate the system's performance and reliability. 
- Tests can be divided into manual and automated tests. Manual tests are performed by humans, while automated tests are performed with the help of software. 
- Tests can also be divided into black-box and white-box tests. Black-box tests evaluate the system's functionality without looking at the code, while white-box tests evaluate the system's functionality by looking at the code.
- Tests can also be divided into unit tests, integration tests, and system tests. Unit tests evaluate individual components of the system, integration tests evaluate the interactions between components, and system tests evaluate the entire system. 
- Tests should be performed regularly to ensure that the system is functioning as expected and is free of bugs. 
- Good testing practices include having a well-defined test plan, using test automation, and using test metrics to measure the effectiveness of the tests. 
- Mnemonics and learning tricks can be helpful for software testing, such as the acronym F.A.S.T. (Functional, Automated, System, and Test). This acronym can help you remember the types of tests that need to be performed.
