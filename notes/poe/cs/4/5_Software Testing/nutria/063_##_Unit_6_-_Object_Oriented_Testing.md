
## Unit 6 - Object Oriented Testing
Object-Oriented Testing (OOT) is a software testing approach that is used to validate the functionality of software applications. It is based on the object-oriented programming (OOP) paradigm, which involves the creation of objects that have specific attributes and behaviors. OOT focuses on testing the functionality of the objects that are created in the software application. 

The goal of OOT is to ensure that the software application meets the requirements of the user and that it is free of defects. OOT is typically performed in three stages: unit testing, integration testing, and system testing. 

### Unit Testing
Unit testing is the first stage of OOT. It involves testing the individual components of the software application to ensure that they are functioning correctly. This is done by creating test cases that are designed to simulate the user's interactions with the application. 

### Integration Testing
Integration testing is the second stage of OOT. It involves testing the interactions between the components of the software application. This is done by creating test cases that are designed to simulate the interactions between the components. 

### System Testing
System testing is the third stage of OOT. It involves testing the entire system as a whole. This is done by creating test cases that are designed to simulate the user's interactions with the entire system. 

### Mnemonics and Learning Tricks
One of the best ways to remember the different stages of OOT is to use the acronym "UIS". This stands for Unit Testing, Integration Testing, and System Testing. 

Another way to remember the different stages of OOT is to think of them as a pyramid. The base of the pyramid represents unit testing, the middle represents integration testing, and the top represents system testing. 

Finally, it is important to remember that OOT is focused on testing the functionality of the objects that are created in the software application. This means that it is important to create test cases that are designed to simulate the user's interactions with the objects in order to ensure that the software application meets the requirements of the user.
