
### Verification Methods for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing

Verification is the process of evaluating a software product to determine whether the products of a given development phase fulfill the conditions imposed at the start of that phase. It is the process of determining whether the products of a given phase of software development fulfill the requirements established during the previous phase.

The following are the verification methods used in software testing:

- **Inspection**: It is the most common and formal verification method. It involves a group of individuals analyzing the software product and evaluating it against a set of criteria.

- **Walkthrough**: It is similar to an inspection, but it is less formal and involves a less detailed review.

- **Static Analysis**: This is a technique that analyzes the source code of a program without executing it. It is used to find errors in the program's logic and structure.

- **Dynamic Analysis**: This is a technique that analyzes the behavior of a program while it is running. It is used to identify errors in the program's behavior.

- **Testing**: This is a technique that involves executing a program with known inputs and checking the output against expected results. It is used to identify errors in the program's implementation.

- **Formal Verification**: This is a technique that involves using mathematical methods to prove that a program meets its specification. It is used to ensure that a program meets its requirements.

- **Mnemonics and Learning Tricks**: Mnemonics are techniques that can be used to help remember information. Some common mnemonics used in software testing include the PIE (Process, Inputs, Expected Results) and the FIST (Familiarize, Identify, Specify, Test) methods. Additionally, learning tricks such as creating diagrams, using acronyms, and taking notes can be used to help remember information.
