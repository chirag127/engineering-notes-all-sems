
### Performance Testing for the Notes of the Unit 7 - Testing Web Applications in the Subject of Software Testing

Performance testing is a type of software testing that focuses on how a system performs under certain conditions. This type of testing is used to measure the performance of an application, system, or network. Performance testing can be done on applications, websites, and databases.

Performance testing is used to ensure that the system meets the expected performance criteria, such as response time, throughput, and resource utilization. It helps to identify any bottlenecks or potential areas of improvement.

Performance testing can be divided into two categories:

1. Load Testing: This type of testing is used to measure the system's performance under a given load. It is used to determine the system's response time and throughput under a given load.

2. Stress Testing: This type of testing is used to determine the system's response time and throughput under extreme conditions. It is used to identify any bottlenecks or potential areas of improvement.

Performance testing can also be divided into three types:

1. Functional Performance Testing: This type of testing is used to measure the system's performance against functional requirements. It is used to identify any potential areas of improvement.

2. Non-Functional Performance Testing: This type of testing is used to measure the system's performance against non-functional requirements. It is used to identify any potential areas of improvement.

3. Real-Time Performance Testing: This type of testing is used to measure the system's performance in real-time. It is used to identify any potential areas of improvement.

2. LLT – Load Testing
