
### Priority category for the notes of the Unit 4 - Regression Testing in the subject of Software Testing

Priority category is an important concept in software testing. It is a way of categorizing tests according to their importance. Tests are divided into three categories based on their priority:

- High Priority: Tests that must always be run and must pass in order for the software to be released.
- Medium Priority: Tests that should be run, but are not essential for the software to be released.
- Low Priority: Tests that are optional and may not be run.

High priority tests are typically the most important tests, as they must pass in order for the software to be released. These tests are usually the most comprehensive and thorough tests, and they must be run before any other tests.

Medium priority tests are usually less comprehensive than high priority tests. They are still important, but not as essential as high priority tests. These tests should be run, but if they fail, the software can still be released.

Low priority tests are the least important tests. These tests are optional and may not be run. They are typically the least comprehensive and thorough tests, and they are usually not essential for the software to be released.
