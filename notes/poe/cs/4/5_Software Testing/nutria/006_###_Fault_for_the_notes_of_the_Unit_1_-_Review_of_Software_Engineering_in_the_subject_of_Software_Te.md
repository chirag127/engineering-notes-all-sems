
### Fault for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing

* Fault is an error or defect in a software system that causes it to produce an incorrect or unexpected result, or to behave in unintended ways.
* Faults can be caused by incorrect coding, incorrect design, incorrect data, or a combination of these.
* Faults can be classified according to their severity and the impact they have on system performance.
* Common faults include:
  * Syntax errors, which occur when a program does not follow the syntax rules of a programming language.
  * Semantic errors, which occur when a program does not follow the semantics of a programming language.
  * Logical errors, which occur when a program does not follow the logic of a programming language.
  * Runtime errors, which occur when a program does not execute correctly during runtime.
  * Data errors, which occur when a program does not process the data correctly.
  * Hardware errors, which occur when a program does not interact correctly with the hardware it is running on.
* To detect and fix faults, software engineers use techniques such as debugging, testing, and code review.
* Mnemonics and learning tricks:
  * F-A-U-L-T: Find, Analyze, Uncover, Log, Test.
  * B-U-G-S: Break, Understand, Generate, Solve.
