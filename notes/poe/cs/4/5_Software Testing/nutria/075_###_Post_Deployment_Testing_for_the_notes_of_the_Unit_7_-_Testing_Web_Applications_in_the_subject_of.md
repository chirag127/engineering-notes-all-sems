
### Post Deployment Testing for the notes of the Unit 7 - Testing Web Applications in the subject of Software Testing

Post deployment testing is a process of testing software applications after they have been deployed or released into production. This type of testing is done to ensure that the software works as intended and meets the end-user's expectations. Post deployment testing should be done regularly, as it helps identify any issues that may have been missed during development and testing stages.

1. **Functional Testing**: This type of testing is used to verify that the software functions as expected. This includes verifying the user interface, system functionality, and integration with other applications.

2. **Performance Testing**: Performance testing is used to measure the response time, throughput, and resource usage of the application. This helps to identify any issues that may affect the user experience.

3. **Stress Testing**: Stress testing is used to identify the application's ability to handle extreme loads or conditions. This helps to ensure that the application can handle sudden spikes in usage or traffic.

4. **Security Testing**: Security testing is used to identify any security vulnerabilities in the application. This helps to ensure that the data is secure and protected from malicious attacks.

5. **Usability Testing**: Usability testing is used to verify that the application is easy to use and intuitive. This helps to ensure that the user experience is positive.

6. **Compatibility Testing**: Compatibility testing is used to verify that the application is compatible with different browsers, operating systems, and devices. This helps to ensure that the application can be used by all users.

7. **Regression Testing**: Regression testing is used to verify that any changes or updates to the application do not introduce any new issues. This helps to ensure that the application remains stable and reliable.

8. **Mnemonics & Learning Tricks**: To help remember the different types of post deployment testing, use the acronym “FPSSUC” (Functional, Performance, Stress, Security, Usability, Compatibility).
