
### Walkthrough for the Notes of the Unit 1 - Review of Software Engineering in the Subject of Software Testing

1. Software Engineering is the application of engineering principles to the development of software. This includes the use of processes, methods, and tools to design, develop, maintain, test, and evaluate software products.

2. Software Testing is the process of validating and verifying that a software product meets the requirements that guided its design and development. It is an important part of software engineering and helps to ensure that the software product is of high quality and meets the user’s needs.

3. There are several types of software testing, including unit testing, integration testing, system testing, acceptance testing, and regression testing. Each type of testing has its own purpose and is used to evaluate different aspects of the software product.

4. Unit testing is the process of testing individual units of source code. It is typically performed by the developer, and is used to ensure that the code is functioning as expected.

5. Integration testing is the process of testing how two or more units of source code interact with each other. It is used to ensure that the different components of the software product are working together properly.

6. System testing is the process of testing the entire system as a whole. It is used to ensure that the system meets the requirements of the user.

7. Acceptance testing is the process of testing the software product from the user’s perspective. It is used to ensure that the software product is meeting the user’s needs and expectations.

8. Regression testing is the process of testing the software product after changes have been made. It is used to ensure that the changes have not introduced any new bugs or issues.

9. Mnemonics and learning tricks can be helpful for studying for software testing exams. For example, the acronym “SITE” can be used to remember the different types of software testing: “S” for unit testing, “I” for integration testing, “T” for system testing, and “E” for acceptance testing.
