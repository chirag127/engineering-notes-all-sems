
### Usability Testing for the Notes of Unit 7 - Testing Web Applications in the Subject of Software Testing
Usability testing is a type of software testing that focuses on how easy and efficient a user can interact with a system. It is used to evaluate the user experience (UX) of a system, and is a key component of software development and maintenance.

Usability testing is typically conducted by a usability expert or tester, who will observe and evaluate the user’s interactions with the system. It is important to note that usability testing is not the same as user acceptance testing, which is conducted to determine if the system meets the user’s requirements. Usability testing is done after the system is built, and is used to evaluate the user experience.

Usability testing can be conducted in a variety of ways, including:

* Interviews: Interviews are conducted with users to understand how they interact with the system. This can be done in person, or over the phone or through a video call.

* Surveys: Surveys are used to collect feedback from users about their experience with the system.

* Task-Based Tests: Task-based tests are conducted to evaluate how easily a user can complete a specific task.

* Prototypes: Prototypes are used to evaluate the usability of a system before it is built.

* A/B Testing: A/B testing is used to compare two versions of a system to determine which one is more usable.

Mnemonic: Usability Testing is T.E.S.T.I.N.G. 

T – Task-Based Tests 
E – Evaluating the User Experience 
S – Surveys 
T – Testing Before Building 
I – Interviews 
N – A/B Testing 
G – Gathering Feedback 

Advantages: 
* Usability testing helps identify usability problems before the system is built, which can save time and money. 
* It can help identify usability issues that may not have been considered during the design phase. 
* It can help improve user satisfaction and increase user engagement. 

Disadvantages: 
* Usability testing can be time-consuming and expensive. 
* It can be difficult to find users who are willing to participate in usability testing. 
* It can be difficult to accurately measure user satisfaction.
