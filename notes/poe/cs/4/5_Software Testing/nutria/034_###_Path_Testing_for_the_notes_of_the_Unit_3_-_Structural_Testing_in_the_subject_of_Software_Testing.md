
### Path Testing for the notes of the Unit 3 - Structural Testing in the subject of Software Testing

Path testing is a type of software testing technique used to verify that all the possible paths of a program are tested. It is a white box testing technique that is used to test the logic of a program and to guarantee that all statements are executed at least once.

Path testing is used to ensure that all the logical paths of a program are tested. It is a white box testing technique that requires knowledge of the internal structure of the code.

##### Advantages of Path Testing

- Path testing helps to detect errors that are caused by incorrect logic in the code.
- It helps to ensure that all the possible paths of the program are tested.
- Path testing helps to reduce the number of test cases that need to be written.

##### Disadvantages of Path Testing

- Path testing can be difficult to perform when the program has a large number of paths.
- It is a time-consuming process and requires a lot of effort.
- Path testing may not be able to detect errors caused by incorrect data or incorrect input.
