
### Control Flow Testing for the notes of the Unit 3 - Structural Testing in the subject of Software Testing
Control flow testing is a type of software testing technique used to verify the sequence of operations and logical flow of a program or system. It is used to identify any errors in the control flow of the program and to ensure that the program behaves as expected.

Control flow testing is a type of white box testing, which means that the tester has access to the source code of the program. It is used to identify any errors in the control flow of the program and to ensure that the program behaves as expected.

Control flow testing involves executing the program and verifying that the program executes the statements in the correct order. It also involves verifying that the program takes the expected paths when it encounters conditional statements such as if-else and switch-case statements.

Mnemonics for Control Flow Testing:
* CFD - Control Flow Diagram
* CFG - Control Flow Graph
* CFM - Control Flow Map

Advantages of Control Flow Testing:
* It is a comprehensive approach to testing that can identify errors in the control flow of the program.
* It can detect errors in the logic of the program.
* It can identify errors in the sequence of operations.

Disadvantages of Control Flow Testing:
* It can be time-consuming and labor-intensive.
* It can be difficult to identify all possible paths through the program.
* It can be difficult to identify all possible errors in the control flow of the program.

Applications of Control Flow Testing:
* It can be used to test the logic of the program.
* It can be used to verify that the program executes the statements in the correct order.
