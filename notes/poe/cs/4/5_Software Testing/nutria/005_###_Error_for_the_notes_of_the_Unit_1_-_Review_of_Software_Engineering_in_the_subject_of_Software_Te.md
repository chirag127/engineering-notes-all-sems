
### Error for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing

* Error: An error is a mistake that leads to incorrect results or incorrect behavior. It is a flaw in the logic of a program or system that causes it to produce an incorrect result or behave unexpectedly.

* Types of Errors: 
  * Syntax Errors: Syntax errors occur when the code does not conform to the language's grammar or syntax. 
  * Logical Errors: Logical errors occur when the code is syntactically correct but produces an incorrect result. 
  * Runtime Errors: Runtime errors occur when the code is syntactically correct but produces an unexpected result due to incorrect data or a problem with the environment.

* Causes of Error: 
  * Incorrectly written code: This is the most common cause of errors. 
  * Poorly designed code: Poorly designed code is code that is not well-structured, which makes it difficult to debug. 
  * Inadequate testing: Inadequate testing can lead to errors that are not detected until the program is in use.

* Ways to Avoid Errors: 
  * Careful coding: Careful coding is the best way to avoid errors. Writing code that is well-structured and easy to read will help you to avoid errors. 
  * Testing: Thorough testing is essential to ensure that errors are detected before the program is used.
  * Mnemonics: Mnemonics are useful learning tricks that can help you to remember the different types of errors and how to avoid them. For example, the acronym "SLR" can be used to remember the three types of errors: Syntax, Logical, and Runtime.
