
### Levels of Testing for the notes of the Unit 5 - Software Testing Activities in the subject of Software Testing

Software Testing is an important process in the development of software applications. It involves the execution of a program or system to identify any errors, gaps or missing requirements in comparison to the actual requirements. Testing can be done at various levels, which are as follows:

1. Unit Testing: This is the first level of software testing and is done at the individual program or unit level. It is done by the programmer who developed the program. The goal of unit testing is to ensure that each unit of the software performs as expected.

2. Integration Testing: This is the second level of software testing and is done after unit testing is completed. It is done by the testers to ensure that the individual units of the software are integrated properly and work together as a whole.

3. System Testing: This is the third level of software testing and is done after integration testing is completed. It is done by the testers to ensure that the software meets the requirements specified in the software requirements specification (SRS).

4. Acceptance Testing: This is the fourth level of software testing and is done after system testing is completed. It is done by the customer or user of the software to ensure that the software meets the customer's requirements.

5. Usability Testing: This is the fifth level of software testing and is done after acceptance testing is completed. It is done by the testers to ensure that the software is easy to use and understand by the user.

Mnemonics and Learning Tricks:

1. Unit Testing: U-Understand, T-Test, E-Every, S-Small, T-Thing
2. Integration Testing: I-Integrate, T-Test, E-Everything
3. System Testing: S-Systematically, T-Test, E-Everything
4. Acceptance Testing: A-Accept, T-The, S-Software
5. Usability Testing: U-Use, T-Test, E-Ease
