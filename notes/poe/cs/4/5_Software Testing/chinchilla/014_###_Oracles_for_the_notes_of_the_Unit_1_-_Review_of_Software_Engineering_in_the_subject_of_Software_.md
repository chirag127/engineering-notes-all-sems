### Oracles for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing:

During software testing, Oracles are used to determine the expected result of a test case. An Oracle is a mechanism that helps in identifying whether the output generated by the software under test is correct or not. In other words, an Oracle is a means of validating the correctness of the output generated by the software. There are different types of Oracles that can be used in software testing.

Here are some of the commonly used Oracles in software testing:

1. **Requirement Oracles**: These Oracles are based on the requirements of the software. They are used to validate whether the software meets the specified requirements or not. Requirement Oracles are useful in determining whether the software is functioning as per the desired behavior.

2. **Functional Oracles**: These Oracles are based on the functionality of the software. They are used to validate whether the software is working as expected or not. Functional Oracles are useful in determining whether the software is performing the intended functions.

3. **Domain Oracles**: These Oracles are based on the domain knowledge of the software. They are used to validate whether the software is functioning as per the domain requirements or not. Domain Oracles are useful in determining whether the software is performing the intended functions within the specified domain.

4. **Comparative Oracles**: These Oracles are based on the comparison of the output generated by the software with the output generated by another system. They are used to validate whether the output generated by the software is similar to the output generated by the reference system.

5. **Historical Oracles**: These Oracles are based on the historical data of the software. They are used to validate whether the software is functioning as per the historical data or not. Historical Oracles are useful in determining whether the software is performing as per the expected behavior based on the past data.

6. **Statistical Oracles**: These Oracles are based on statistical analysis of the output generated by the software. They are used to validate whether the output generated by the software is within the acceptable statistical limits or not. Statistical Oracles are useful in determining whether the software is performing as per the expected statistical behavior.

Mnemonics and learning tricks:

1. Remember the acronym RFDCHS to recall the different types of Oracles: Requirement, Functional, Domain, Comparative, Historical, and Statistical.

2. To remember the purpose of each type of Oracle, you can use the following phrases:
- Requirement Oracles: "meet the requirements"
- Functional Oracles: "perform the intended functions"
- Domain Oracles: "within the specified domain"
- Comparative Oracles: "similar to the reference system"
- Historical Oracles: "as per the past data"
- Statistical Oracles: "within the acceptable statistical limits"

By using Oracles during software testing, we can ensure that the software is functioning correctly and meeting the intended requirements. It is important to choose the appropriate type of Oracle based on the requirements of the software and the testing objectives.
