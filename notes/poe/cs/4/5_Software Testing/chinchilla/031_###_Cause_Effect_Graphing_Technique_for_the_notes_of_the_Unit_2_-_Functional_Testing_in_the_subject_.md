### Cause Effect Graphing Technique for the notes of the Unit 2 - Functional Testing in the subject of Software Testing

The cause-effect graphing technique is a testing technique used to identify the different combinations of inputs that need to be tested to ensure that the software is functioning as intended. It is a black box testing technique that focuses on the relationship between the inputs and the outputs of the software.

The cause-effect graphing technique involves the following steps:

1. Identify the inputs and outputs of the software: The first step in using the cause-effect graphing technique is to identify the different inputs and outputs of the software. Inputs can be anything from user inputs to system variables, while outputs can be anything from screen displays to file outputs.

2. Create a cause-effect graph: The next step is to create a cause-effect graph that shows the relationship between the inputs and the outputs. The graph consists of two parts - the cause side and the effect side. The cause side lists all the inputs, while the effect side lists all the outputs.

3. Identify the rules: The next step is to identify the rules that govern the relationship between the inputs and the outputs. These rules can be identified by analyzing the software requirements or by talking to the developers.

4. Identify the test cases: Once the rules have been identified, the next step is to identify the different combinations of inputs that need to be tested. This can be done by looking at the cause-effect graph and identifying the different paths that lead to each output.

Advantages of Cause Effect Graphing Technique:
- Helps to identify the different combinations of inputs that need to be tested.
- Helps to reduce the number of test cases required.
- Helps to identify the most critical areas of the software that need to be tested.

Disadvantages of Cause Effect Graphing Technique:
- It can be time-consuming to create the cause-effect graph.
- It requires a good understanding of the software requirements and the rules governing the relationship between the inputs and outputs.

Mnemonics and Tricks:
- Use the acronym CEG to remember the Cause Effect Graphing Technique.
- Remember the steps as ICEI - Identify Inputs and Outputs, Create the cause-effect graph, Identify the rules, and Identify the test cases.
