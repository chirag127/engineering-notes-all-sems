### Difference Between Verification and Validation for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing

Verification and Validation are two important concepts in software testing, which are often used interchangeably but have different meanings. In this section, we will discuss the difference between Verification and Validation in detail.

#### Verification:
Verification is a process of checking whether the software product meets the specified requirements and specifications. This process involves reviewing and inspecting the software documentation and source code to ensure that it is consistent with the functional and non-functional requirements of the software.

Some of the key points to remember about Verification are:

- Verification is a static process that does not involve testing the software product.
- Verification is done in the early stages of software development, such as during the requirements gathering and design phase.
- The objective of Verification is to ensure that the software product meets the specified requirements and specifications.
- Verification is usually performed by software engineers, designers, and architects.

#### Validation:
Validation is a process of testing the software product to ensure that it meets the customer's requirements and performs as expected. This process involves executing the software and comparing the actual results with the expected results to identify any defects or issues.

Some of the key points to remember about Validation are:

- Validation is a dynamic process that involves testing the software product.
- Validation is done in the later stages of software development, such as during the testing phase.
- The objective of Validation is to ensure that the software product meets the customer's requirements and performs as expected.
- Validation is usually performed by software testers.

#### Differences between Verification and Validation:
The following are some of the key differences between Verification and Validation:

| Verification | Validation |
| --- | --- |
| It is a static process | It is a dynamic process |
| It is done in the early stages of software development | It is done in the later stages of software development |
| It checks whether the software product meets the specified requirements and specifications | It checks whether the software product meets the customer's requirements and performs as expected |
| It is performed by software engineers, designers, and architects | It is performed by software testers |
