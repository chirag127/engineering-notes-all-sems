### Testing techniques and their applicability for the notes of the Unit 5 - Software Testing Activities in the subject of Software Testing.

Software testing is the process of evaluating a software product or system to identify any defects, errors, or bugs in it. It is an essential part of the software development life cycle (SDLC) and helps ensure that the software meets the desired quality standards. In this unit on software testing activities, we will study various testing techniques that can be used to test software products.

Here are some of the testing techniques and their applicability that you should be aware of in the context of software testing activities:

1. **Black-box testing:** This technique is used to validate the functionality of a software product without examining its internal structure or design. The tester only needs to know the input and output specifications of the system. It is applicable for testing user interfaces, functionality, and usability of the software product.

2. **White-box testing:** Also known as structural testing, this technique involves examining the internal structure and design of the software product. It is used to validate the correctness and completeness of the code. It is applicable for testing the logic and functionality of the software product.

3. **Gray-box testing:** This technique is a combination of black-box and white-box testing. The tester has access to some of the internal workings of the software product without having complete knowledge of its design. It is applicable for testing the integration of different components of the software product.

4. **Unit testing:** This technique involves testing individual units or components of the software product. It is usually done by developers during the coding phase to ensure that each unit is working as expected. It is applicable for testing the correctness and completeness of the code.

5. **Integration testing:** This technique involves testing the interaction between different units or components of the software product. It is used to ensure that the different components are working together as expected. It is applicable for testing the integration of different modules of the software product.

6. **System testing:** This technique involves testing the entire software product as a whole. It is used to ensure that the software product meets the desired quality standards and fulfills its intended purpose. It is applicable for testing the functionality and performance of the software product.

7. **Regression testing:** This technique involves retesting the software product after any changes or modifications have been made to it. It is used to ensure that the software product still works as expected after the changes. It is applicable for testing the stability and reliability of the software product.

Mnemonics and learning tricks can be helpful to remember the different testing techniques and their applicability. For example, you can use the acronym BUGS to remember the different types of testing techniques - Black-box, Unit, Gray-box, System - and their applicability. Similarly, you can use the acronym IRIS to remember the different types of testing techniques - Integration, Regression, White-box, System - and their applicability.
