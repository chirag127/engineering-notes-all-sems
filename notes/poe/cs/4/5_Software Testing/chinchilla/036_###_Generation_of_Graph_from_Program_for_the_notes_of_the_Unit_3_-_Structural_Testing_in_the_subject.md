### Generation of Graph from Program for the notes of the Unit 3 - Structural Testing in the subject of Software Testing

In Structural Testing, the program's control flow graph is an essential element used for test suite generation. Generating the graph from the program is a crucial step in structural testing. This graph represents the control flow of the program, and it is used to determine the program's various paths.

The generation of the control flow graph can be done using the following methods:

1. Static Analysis: In this method, the program is analyzed without executing it. The control flow graph is generated by analyzing the program's code structure and syntax.

2. Dynamic Analysis: In this method, the program is executed, and the control flow graph is generated based on the program's execution path.

#### Mnemonics and Learning Tricks:

1. "Control Flow Graph is the Roadmap of a Program": This mnemonic helps in remembering that the control flow graph represents the program's flow and helps in generating test cases.

2. "Static Analysis = Code Structure": This mnemonic helps in remembering that the control flow graph is generated by analyzing the code structure and syntax in static analysis.

3. "Dynamic Analysis = Execution Path": This mnemonic helps in remembering that the control flow graph is generated based on the program's execution path in dynamic analysis.

Advantages of Control Flow Graph:

1. Helps in understanding the program's flow and structure.

2. Helps in identifying unreachable code and dead code.

3. Helps in generating test cases for structural testing.

4. Helps in identifying loops and conditional statements.

Disadvantages of Control Flow Graph:

1. Generation of the control flow graph can be time-consuming and complex.

2. Control flow graph generation may not be possible for some programs.

Example:

Consider the following program:

```
int main() {
   int a = 10;
   if (a == 10) {
      a = a + 1;
   }
   else {
      a = a - 1;
   }
   return 0;
}
```

The control flow graph for the above program is shown below:

```
+-------------+
| Start Node  |
+-------------+
        |
        v
+----------------+
| int a = 10;    |
+----------------+
        |
        v
+------------------------+
| if (a == 10)           |
+------------------------+
        |
        v
+------------------------+
| a = a + 1;             |
+------------------------+
        |
        v
+------------------------+
| return 0;              |
+------------------------+
```

Applications of Control Flow Graph:

1. Structural testing of software programs.

2. Program optimization.

3. Program understanding and maintenance.

The control flow graph represents the program's control flow and helps in generating test cases for structural testing.
