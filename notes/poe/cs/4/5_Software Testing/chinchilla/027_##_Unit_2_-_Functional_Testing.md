## Unit 2 - Functional Testing

Functional testing is an essential component of software testing that evaluates the functionality of a software application. It tests the software system against its functional requirements and specifications to ensure that the software is performing as expected. This unit covers the different aspects of functional testing, including types, techniques, and tools used for functional testing.

### Types of Functional Testing

1. Unit Testing: It tests the smallest units of software code to ensure that each unit is working correctly.
2. Integration Testing: It tests the interactions between different units of code to ensure that they work together correctly.
3. System Testing: It tests the entire software system to ensure that all components work together correctly.
4. Acceptance Testing: It tests the software system against the requirements of the end-users to ensure that it meets their expectations.

### Techniques Used in Functional Testing

1. Black Box Testing: It tests the software system without considering its internal structure or implementation details. Testers use inputs and expected outputs to evaluate the software's functionality.
2. White Box Testing: It tests the software system by considering its internal structure and implementation details. Testers use knowledge of the code to evaluate the software's functionality.
3. Gray Box Testing: It tests the software system by considering both its internal structure and external behavior to evaluate its functionality.

### Tools Used in Functional Testing

1. Selenium: It is an open-source tool used for automating web applications.
2. JMeter: It is an open-source tool used for performance and functional testing of web applications.
3. Appium: It is an open-source tool used for automating mobile applications.
4. SoapUI: It is an open-source tool used for testing SOAP and REST web services.

### Advantages of Functional Testing

1. It ensures that the software system is working as expected and meets the end-users' requirements.
2. It detects defects early in the software development lifecycle, reducing the cost of fixing defects.
3. It improves the quality of the software system by identifying and fixing defects.
4. It helps in improving the software system's usability, reliability, and performance.

### Disadvantages of Functional Testing

1. It can be time-consuming and expensive, depending on the complexity of the software system.
2. It may not be able to detect all defects in the software system.
3. It requires skilled and experienced testers to perform functional testing effectively.

Mnemonics and Learning Tricks:

1. Remember the acronym "FITA" to recall the four types of functional testing: Unit, Integration, System, and Acceptance.
2. Remember "BWG" to recall the three techniques used in functional testing: Black Box, White Box, and Gray Box.

Examples:

1. Unit Testing: Testing a single function or method that performs a specific task, such as calculating the sum of two numbers.
2. Integration Testing: Testing the interaction between two or more functions or methods, such as testing a login feature that interacts with a database.
3. System Testing: Testing the entire software system, such as testing a complete e-commerce website.
4. Acceptance Testing: Testing the software system against the requirements of end-users, such as testing a new mobile application before release.

Applications:

Functional testing is used in various industries, including software development, healthcare, finance, and government. It ensures that software systems meet their functional requirements and specifications and provide a positive user experience.
