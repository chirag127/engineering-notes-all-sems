### Storage for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing

When it comes to Cloud Computing, storage is a critical component. In this unit, we will discuss the various types of storage available in cloud computing, their advantages, and disadvantages. 

Here are some key points to keep in mind:

- Cloud storage is a service model in which data is maintained, managed, backed up remotely, and made available to users over the internet.
- There are three types of cloud storage - object, block, and file storage.
- Object storage is ideal for storing unstructured data like videos, images, and audio files. Examples of object storage services include Amazon S3 and Google Cloud Storage.
- Block storage is used for storing data in blocks or chunks. It is commonly used for databases and virtual machines. Examples of block storage services include Amazon EBS and Google Cloud Persistent Disk.
- File storage is used to store and access files, like documents and spreadsheets. Examples of file storage services include Amazon EFS and Google Cloud Filestore.
- Cloud storage offers several advantages over traditional storage, including scalability, reliability, and cost-effectiveness.
- Mnemonic: Remember the acronym OBF - Object, Block and File storage. This can help you recall the three types of cloud storage.

It is important to note that each type of storage has its own advantages and disadvantages. Therefore, it is essential to choose the right type of storage based on your specific needs. 

In summary, cloud storage is a critical component of cloud computing. It offers several advantages over traditional storage and comes in different types depending on the type of data you need to store. Remembering the OBF acronym can help you recall the three types of cloud storage.
