## Unit 5 - Overview of Cloud Computing

Cloud computing is the delivery of on-demand computing services, including servers, storage, databases, networking, software, analytics, and intelligence, over the internet. In this unit, we will discuss the following topics:

1. What is Cloud Computing?
2. Types of Cloud Computing
3. Advantages of Cloud Computing
4. Disadvantages of Cloud Computing
5. Examples of Cloud Computing
6. Applications of Cloud Computing

### What is Cloud Computing?

Cloud computing is a technology that allows users to access and use various computing resources like servers, storage, and software over the internet without the need for physical infrastructure. The cloud service provider is responsible for maintaining and managing the infrastructure, while the users can access and use the resources as needed.

### Types of Cloud Computing

There are three types of cloud computing:

1. Infrastructure as a Service (IaaS)
2. Platform as a Service (PaaS)
3. Software as a Service (SaaS)

IaaS provides users with access to virtualized computing resources like servers, storage, and networking. PaaS provides users with a platform to build and deploy applications. SaaS provides users with access to software applications over the internet.

### Advantages of Cloud Computing

Cloud computing has several advantages, including:

1. Cost-effective: Users can save money on IT infrastructure by using cloud computing services.
2. Scalability: Cloud computing allows users to scale up or down resources as needed.
3. Accessibility: Users can access cloud computing resources from anywhere with an internet connection.
4. Flexibility: Cloud computing allows users to choose the resources they need and pay only for what they use.
5. Security: Cloud service providers implement several security measures to protect user data.

### Disadvantages of Cloud Computing

Cloud computing also has some disadvantages, including:

1. Dependency: Users are dependent on the cloud service provider for maintaining and managing the infrastructure.
2. Downtime: Cloud service providers may experience downtime, which can affect user access to resources.
3. Security: Although cloud service providers implement security measures, there is always a risk of data breaches.
4. Limited control: Users have limited control over the infrastructure and software used by the cloud service provider.

### Examples of Cloud Computing

Some examples of cloud computing include:

1. Amazon Web Services (AWS)
2. Microsoft Azure
3. Google Cloud Platform
4. Dropbox
5. Salesforce

### Applications of Cloud Computing

Cloud computing is used in several applications, including:

1. Data storage and backup
2. Web hosting
3. Application development and deployment
4. Big data analytics
5. Machine learning and artificial intelligence

Mnemonics and learning tricks:
- Remember the acronym SPI, which stands for IaaS, PaaS, and SaaS.
- Think of the cloud as a virtual space where you can store and access information, just like a real cloud stores and releases rain.
