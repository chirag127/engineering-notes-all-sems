
### Infrastructure for the Notes of the Unit 5 - Overview of Cloud Computing in the Subject of High Performance Computing

1. Cloud Computing is a model for delivering computing services, such as storage, networking, software, and databases, over the Internet. It offers the ability to scale up or down quickly and cost-effectively, as well as access to the latest technologies.
2. Infrastructure as a Service (IaaS) is a form of cloud computing that provides virtualized computing resources over the Internet. It provides access to computing resources such as servers, storage, and networking, without the need to purchase or manage physical hardware.
3. Platform as a Service (PaaS) is a form of cloud computing that provides a platform for developers to build applications without having to worry about the underlying infrastructure. It provides access to the underlying infrastructure and tools necessary to build, deploy, and manage applications.
4. Software as a Service (SaaS) is a form of cloud computing that provides access to applications over the Internet. It provides access to software applications such as email, office suites, and customer relationship management (CRM) systems without the need to purchase or manage the underlying hardware or software.
5. Mnemonic: IaaS - Infrastructure as a Service, PaaS - Platform as a Service, SaaS - Software as a Service.
6. Advantages of Cloud Computing:
    - Cost savings: Cloud computing can reduce costs by eliminating the need to purchase, maintain, and upgrade hardware and software.
    - Scalability: Cloud computing allows for the easy scaling up or down of resources, depending on the needs of the organization.
    - Flexibility: Cloud computing provides the flexibility to access resources from anywhere, anytime.
    - Reliability: Cloud computing provides a reliable and secure environment for data and applications.
7. Disadvantages of Cloud Computing:
    - Security: Cloud computing can be vulnerable to security threats such as data breaches and cyberattacks.
    - Compliance: Organizations must ensure that their cloud computing services comply with applicable laws and regulations.
    - Performance: Cloud computing can be subject to performance issues such as latency and bandwidth constraints.
    - Vendor Lock-in: Organizations may become dependent on a particular cloud provider, making it difficult to switch to a different provider.
8. Examples of Cloud Computing:
    - Google Cloud Platform: A suite of cloud computing services offered by Google, including Compute Engine, App Engine, and Cloud Storage.
    - Amazon Web Services: A suite of cloud computing services offered by Amazon, including Amazon EC2, Amazon S3, and Amazon RDS.
    - Microsoft Azure: A suite of cloud computing services offered by Microsoft, including Azure Virtual Machines, Azure Storage, and Azure Functions.
9. Applications of Cloud Computing:
    - Web Hosting: Cloud computing can be used to host websites and web applications.
    - Business Applications: Cloud computing can be used to host and manage business applications such as customer relationship management (CRM) and enterprise resource planning (ERP) systems.
    - Data Storage and Backup: Cloud computing can be used to store and backup data in a secure and reliable environment.
    - Big Data Analytics: Cloud computing can be used to process and analyze large amounts of data.
