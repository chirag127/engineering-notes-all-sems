
### High‐Performance Grids for the notes of the Unit 1 - Overview of Grid Computing Technology in the subject of High Performance Computing

* Grid computing is a distributed computing architecture that enables the sharing of resources and data among computer systems and other devices on a network. It is a type of parallel computing that allows for the use of multiple computers to solve a single problem or multiple problems simultaneously.
* Grid computing is often used to solve complex problems that require large amounts of computing power. Examples of such problems include weather forecasting, financial modeling, and scientific research.
* Grid computing is composed of a set of computers connected by a network. This network can be either a local area network (LAN) or a wide area network (WAN). Each computer in the grid is called a node and is responsible for running a part of the problem.
* The nodes in the grid can be either dedicated machines or general-purpose computers. Dedicated machines are usually more powerful and have more memory and storage capacity than general-purpose computers.
* Grid computing is based on the concept of virtualization, which is the process of creating a virtual environment that can be accessed by multiple users. This virtual environment is composed of multiple computers connected by a network.
* Grid computing is used to solve problems that require large amounts of computing power. It is also used to manage large amounts of data, such as in data mining or data warehousing applications.
* Grid computing is used in many different fields, such as in healthcare, finance, and engineering. It is also used in scientific research, such as in climate modeling and in astronomy.
* Grid computing has many advantages, such as scalability, cost savings, and better resource utilization. It also allows for more efficient use of computing resources and data.
* Grid computing also has some disadvantages, such as security risks, complexity, and lack of standardization.
