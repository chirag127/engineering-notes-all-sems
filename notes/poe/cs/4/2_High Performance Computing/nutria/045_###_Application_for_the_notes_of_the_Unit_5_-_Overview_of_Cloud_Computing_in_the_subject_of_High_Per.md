
### Application for the Notes of the Unit 5 - Overview of Cloud Computing in the Subject of High Performance Computing

* Cloud computing is a type of computing that involves the use of a network of remote servers hosted on the Internet to store, manage, and process data, rather than a local server or a personal computer.
* Cloud computing provides users with access to a wide range of services, such as storage, networking, analytics, and software development.
* Cloud computing is beneficial for businesses and individuals alike, as it allows for increased scalability, flexibility, and cost savings.
* Cloud computing is divided into three main categories: Infrastructure as a Service (IaaS), Platform as a Service (PaaS), and Software as a Service (SaaS).
* IaaS provides users with access to virtualized computing resources, such as servers, storage, and networking, on a pay-as-you-go basis.
* PaaS provides users with access to a platform for developing, testing, and deploying applications.
* SaaS provides users with access to software applications and services, such as email, office suites, and customer relationship management (CRM) systems.
* Cloud computing can be used for a variety of applications, such as web hosting, data storage, and analytics.
* Cloud computing is becoming increasingly popular, as it offers users the ability to access data, applications, and services from anywhere, at any time.
* Mnemonics and learning tricks for cloud computing include:
  * IaaS: Infrastructure as a Service
  * PaaS: Platform as a Service
  * SaaS: Software as a Service
  * CSP: Cloud Service Provider
  * SLA: Service Level Agreement
  * API: Application Programming Interface
