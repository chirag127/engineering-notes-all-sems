
### Storage for the Notes of the Unit 5 - Overview of Cloud Computing in the Subject of High Performance Computing

- Cloud computing is a technology that enables organizations to store and access data, applications, and other resources over the internet.
- Cloud storage is a type of cloud computing that stores data on remote servers, allowing organizations to access that data from any location. 
- Cloud storage can be used to store a variety of data, including photos, videos, documents, and other files. 
- Cloud storage is secure, cost-effective, and scalable, making it an ideal solution for organizations of all sizes.
- There are two main types of cloud storage: public and private. 
- Public cloud storage is accessible to anyone with an internet connection, while private cloud storage requires authentication to access data. 
- Organizations can also use hybrid cloud storage, which combines public and private cloud storage to meet their specific needs.
- Cloud storage is also used for backup and disaster recovery. It provides organizations with an off-site location to store their data, ensuring that it is secure and accessible in the event of a disaster.
- In addition, cloud storage can be used to store and access data from multiple devices, making it easier for organizations to collaborate on projects. 
- Cloud storage is also used for analytics, allowing organizations to analyze large amounts of data quickly and efficiently.
