
### Grid Computing Model and Protocols for the notes of the Unit 1 - Overview of Grid Computing Technology in the subject of High Performance Computing

Grid Computing is a distributed computing model that enables the sharing of computing power and data storage across multiple computers. It is a type of distributed computing system that allows for the efficient use of computing resources by leveraging the power of multiple computers to solve complex problems. It is based on the concept of shared resources, which can be accessed and used by multiple users in a network.

Grid Computing Model:

- **Resource Sharing**: Grid Computing enables the sharing of resources across multiple computers in a network. This allows users to access and use resources from other computers in the network.

- **Data Sharing**: Grid Computing enables the sharing of data across multiple computers in a network. This allows users to access and use data from other computers in the network.

- **Resource Pooling**: Grid Computing enables the pooling of resources across multiple computers in a network. This allows users to access and use resources from multiple computers in the network.

- **Fault Tolerance**: Grid Computing enables the fault tolerance of resources across multiple computers in a network. This allows users to access and use resources from multiple computers in the network even when one or more of the computers fail.

- **Load Balancing**: Grid Computing enables the load balancing of resources across multiple computers in a network. This allows users to access and use resources from multiple computers in the network even when one or more of the computers become overloaded.

Grid Computing Protocols:

- **Grid Resource Management Protocol (GRMP)**: GRMP is a protocol for managing resources in a Grid Computing environment. It defines the rules for how resources are allocated, managed, and monitored in a Grid Computing network.

- **Grid Scheduling Protocol (GSP)**: GSP is a protocol for scheduling jobs in a Grid Computing environment. It defines the rules for how jobs are allocated, managed, and monitored in a Grid Computing network.

- **Grid Security Protocol (GSP)**: GSP is a protocol for securing resources in a Grid Computing environment. It defines the rules for how resources are secured in a Grid Computing network.

- **Grid Monitoring Protocol (GMP)**: GMP is a protocol for monitoring resources in a Grid Computing environment. It defines the rules for how resources are monitored in a Grid Computing network.
