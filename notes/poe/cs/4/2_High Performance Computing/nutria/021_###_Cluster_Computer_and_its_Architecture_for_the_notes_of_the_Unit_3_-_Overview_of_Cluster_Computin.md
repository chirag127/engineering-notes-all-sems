
### Cluster Computer and its Architecture for the notes of the Unit 3 - Overview of Cluster Computing in the subject of High Performance Computing

A cluster computer is a type of computer architecture that consists of multiple computers connected together to form a single, powerful machine. It is designed to improve the performance of large-scale applications and data processing tasks. Clusters are typically used for applications that require high availability, scalability, and reliability.

Cluster computers are made up of several individual computers, known as nodes, that are connected via a high-speed network. Each node is capable of running its own operating system and applications independently. The nodes can be located in the same physical location or in different locations.

The architecture of a cluster computer is typically divided into two parts: the cluster head node and the compute nodes. The cluster head node is responsible for managing the cluster and providing access to the network. It is responsible for scheduling jobs and distributing tasks to the compute nodes. The compute nodes are responsible for executing the tasks assigned to them by the head node.

Advantages of cluster computing include:

- High performance: By using multiple computers, cluster computing can increase the overall performance of a task or application.
- Scalability: Cluster computing can be scaled up or down as needed, allowing for greater flexibility and cost savings.
- Reliability: Cluster computing provides redundancy and can continue to operate even if one or more nodes fail.
- Cost-effectiveness: Cluster computing can be less expensive than other types of computing solutions.

Disadvantages of cluster computing include:

- Complexity: Cluster computing can be complex to set up and maintain.
- Security risks: Cluster computers can be vulnerable to security threats due to the multiple nodes and connections.
- Performance bottlenecks: Performance can be limited by the speed of the network connecting the nodes.
