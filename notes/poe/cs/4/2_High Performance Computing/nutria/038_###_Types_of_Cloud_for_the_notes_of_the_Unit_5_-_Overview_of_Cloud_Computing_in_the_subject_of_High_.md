

### Types of Cloud for the Notes of the Unit 5 - Overview of Cloud Computing in the Subject of High Performance Computing

1. **Public Cloud**: A public cloud is a cloud computing service that is open for public use. It is owned and operated by a third-party cloud service provider and delivered over the internet. It is the most widely used type of cloud computing due to its cost-effectiveness and scalability. Examples of public cloud services include Amazon Web Services, Microsoft Azure, and Google Cloud Platform.

2. **Private Cloud**: A private cloud is a cloud computing service that is dedicated to a single organization. It is hosted on a private network and can be managed by the organization or a third-party cloud service provider. Private clouds are more secure and reliable than public clouds, but they are also more expensive and require more maintenance. Examples of private cloud services include IBM SoftLayer and VMware vCloud.

3. **Hybrid Cloud**: A hybrid cloud is a cloud computing service that combines public and private cloud services. It allows organizations to use public cloud services for certain tasks while keeping sensitive data and applications on a private cloud. Hybrid clouds are more secure and reliable than public clouds, but they are also more expensive and require more maintenance. Examples of hybrid cloud services include Microsoft Azure Stack and Google Cloud Platform.

4. **Community Cloud**: A community cloud is a cloud computing service that is shared by multiple organizations. It is hosted on a private network and can be managed by the organizations or a third-party cloud service provider. Community clouds are more secure and reliable than public clouds, but they are also more expensive and require more maintenance. Examples of community cloud services include Salesforce Community Cloud and Oracle Cloud.

5. **Edge Computing**: Edge computing is a distributed computing model that brings computing and data storage closer to the edge of the network. It enables devices to process data locally instead of sending it to a central server. Edge computing is more secure and reliable than cloud computing, but it is also more expensive and requires more maintenance. Examples of edge computing services include AWS Greengrass and Microsoft Azure IoT Edge.
