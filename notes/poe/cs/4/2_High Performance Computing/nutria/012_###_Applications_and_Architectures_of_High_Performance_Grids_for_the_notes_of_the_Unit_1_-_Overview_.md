
### Applications and Architectures of High Performance Grids for the notes of the Unit 1 - Overview of Grid Computing Technology in the subject of High Performance Computing

- Grid Computing is a distributed computing system that enables the sharing, selection, and aggregation of a wide variety of geographically distributed computing resources. 
- It is a type of parallel and distributed system that enables the use of geographically distributed resources to solve complex computing problems.
- Grid Computing allows for the sharing of resources and the distribution of workloads across multiple computers in a network. 
- Grid Computing architectures are designed to provide an environment for the efficient and secure sharing of resources and services. 
- Common architectures for Grid Computing include the Client/Server architecture, the Peer-to-Peer architecture, and the Service-Oriented Architecture (SOA).
- Client/Server architecture is a type of distributed computing architecture that allows clients to request and receive services from servers. 
- In a peer-to-peer architecture, each node in the network can act as both a client and a server. 
- Service-Oriented Architecture (SOA) is an architecture that enables the integration of services from different sources. 
- Grid Computing technologies such as the Globus Toolkit, the Condor system, the Legion system, and the TeraGrid system are used to enable the sharing, selection, and aggregation of computing resources. 
- Grid Computing also provides an environment for the efficient and secure sharing of data and services. 
- Grid Computing technologies can be used to provide access to computing resources for scientific research, business applications, and other applications. 
- Grid Computing can also be used to provide access to large datasets and to provide access to distributed computing resources. 
- Grid Computing can also provide a platform for distributed computing applications such as web services and distributed databases. 
- Security is an important aspect of Grid Computing, and Grid Computing systems are designed to provide secure access to resources and services. 
- Grid Computing also enables the efficient utilization of computing resources, which can result in significant cost savings.
