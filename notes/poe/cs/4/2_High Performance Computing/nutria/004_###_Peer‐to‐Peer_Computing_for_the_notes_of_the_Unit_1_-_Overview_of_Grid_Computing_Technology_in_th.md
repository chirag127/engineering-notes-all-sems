
### Peer‐to‐Peer Computing for the notes of the Unit 1 - Overview of Grid Computing Technology in the subject of High Performance Computing

Peer-to-Peer (P2P) computing is a type of distributed computing system in which each computer in the network acts as both a client and a server. This type of computing is used for various applications, such as file sharing, video streaming, and distributed computing.

P2P computing is based on the idea of decentralizing the computing power of the network. Instead of relying on a centralized server to manage the network, each computer in the network acts as both a client and a server. This allows the network to be more efficient, as each computer can contribute its own resources to the network.

Advantages of P2P Computing: 

- Scalability: P2P networks are highly scalable, as each node in the network can be used to increase the computing power of the network.
- Cost Savings: P2P computing eliminates the need for a central server, which can save organizations money.
- Improved Performance: P2P computing can improve the performance of the network by distributing the computing power of the network among each node.
- Security: P2P networks are more secure than centralized networks, as there is no single point of failure.

Disadvantages of P2P Computing: 

- Network Congestion: P2P networks can become congested, as each node in the network is sending and receiving data.
- Lack of Quality Control: P2P networks lack quality control, as there is no central authority to ensure that the data being sent is of high quality.
- Legal Issues: P2P networks can be used for illegal activities, such as copyright infringement.

Mnemonic: P2P = Peer-to-Peer.
