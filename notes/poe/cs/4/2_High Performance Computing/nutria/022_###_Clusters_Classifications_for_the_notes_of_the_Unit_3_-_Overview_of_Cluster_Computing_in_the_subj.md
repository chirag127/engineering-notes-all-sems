
### Clusters Classifications for the notes of the Unit 3 - Overview of Cluster Computing in the subject of High Performance Computing

Clusters are a type of parallel computing system that can be used to increase the performance of High Performance Computing (HPC) systems. Clusters are composed of multiple interconnected computers, or nodes, which can be used to perform computations in parallel. Clusters can be classified based on the type of nodes used, the type of interconnection network deployed, and the type of scheduling algorithm used. 

**Types of Nodes**

Clusters can be classified based on the type of nodes used. The most common type of node used in clusters is a commodity node, which consists of an off-the-shelf computer running an operating system such as Linux or Windows. Commodity nodes are usually the most cost-effective type of node for clusters. Other types of nodes that can be used in clusters include specialized nodes, such as GPUs, and high-performance nodes, such as those used in supercomputers.

**Types of Interconnection Networks**

Clusters can also be classified based on the type of interconnection network deployed. The most common type of interconnection network used in clusters is Ethernet, which is a low-cost, low-latency network. Other types of interconnection networks used in clusters include InfiniBand, which is a higher-performance network, and Myrinet, which is a low-latency network.

**Types of Scheduling Algorithms**

Clusters can also be classified based on the type of scheduling algorithm used. The most common type of scheduling algorithm used in clusters is a static algorithm, which assigns tasks to nodes based on predetermined criteria. Other types of scheduling algorithms used in clusters include dynamic algorithms, which assign tasks to nodes based on their current availability, and adaptive algorithms, which adjust the assignment of tasks to nodes based on the current load on the system.

In summary, clusters are a type of parallel computing system that can be used to increase the performance of HPC systems. Clusters can be classified based on the type of nodes used, the type of interconnection network deployed, and the type of scheduling algorithm used.
