
### Cluster Computing for the Notes of the Unit 1 - Overview of Grid Computing Technology in the Subject of High Performance Computing

* Cluster Computing is a form of distributed computing that utilizes multiple computers, or nodes, to work together on a single task.
* The nodes in a cluster are usually connected via a high-speed network, such as Ethernet or InfiniBand.
* Cluster Computing is used for a variety of tasks, such as scientific computing, data analysis, and web hosting.
* In a cluster, each node is responsible for a portion of the task and the results are combined at the end.
* Cluster Computing is more cost-effective than traditional supercomputing solutions, as it allows for the use of commodity hardware.
* Cluster Computing is also more reliable than single-node solutions, as if one node fails, the other nodes can pick up the slack.
* Grid Computing is a form of distributed computing that utilizes multiple computers, or nodes, that are geographically dispersed and connected via a wide-area network.
* Grid Computing is used for a variety of tasks, such as scientific computing, data analysis, and web hosting.
* In a Grid Computing system, each node is responsible for a portion of the task and the results are combined at the end.
* Grid Computing is more cost-effective than traditional supercomputing solutions, as it allows for the use of commodity hardware.
* Grid Computing is also more reliable than single-node solutions, as if one node fails, the other nodes can pick up the slack.
* Grid Computing also has the advantage of being able to utilize resources from multiple locations, allowing for more efficient and cost-effective solutions.
* A good mnemonic for Grid Computing is "GReat Distributed Computing".
