
### Services for the Notes of the Unit 5 - Overview of Cloud Computing in the Subject of High Performance Computing 

1. **Infrastructure as a Service (IaaS)**: IaaS is a type of cloud computing service that provides customers with access to computing resources, such as virtual machines, storage and networking. Customers can use IaaS to quickly provision and scale computing resources on demand.

2. **Platform as a Service (PaaS)**: PaaS is a type of cloud computing service that provides customers with access to a platform on which they can develop, deploy, and manage applications. PaaS provides customers with the tools and services they need to develop and deploy applications without having to manage the underlying infrastructure.

3. **Software as a Service (SaaS)**: SaaS is a type of cloud computing service that provides customers with access to software applications that are hosted in the cloud. SaaS applications are typically accessed through a web browser and can be used without the need for any additional software or hardware.

4. **Storage as a Service (STaaS)**: STaaS is a type of cloud computing service that provides customers with access to storage resources, such as databases, file systems, and object stores. Customers can use STaaS to store and manage their data in the cloud.

5. **Backup as a Service (BaaS)**: BaaS is a type of cloud computing service that provides customers with access to backup and recovery services. BaaS enables customers to back up and restore their data in the cloud, ensuring that their data is secure and available in the event of an outage.

6. **Database as a Service (DBaaS)**: DBaaS is a type of cloud computing service that provides customers with access to databases in the cloud. DBaaS enables customers to quickly provision and scale databases without having to manage the underlying infrastructure.

7. **Network as a Service (NaaS)**: NaaS is a type of cloud computing service that provides customers with access to networking services, such as firewalls, load balancers, and virtual private networks. NaaS enables customers to quickly provision and scale their networks without having to manage the underlying infrastructure.
