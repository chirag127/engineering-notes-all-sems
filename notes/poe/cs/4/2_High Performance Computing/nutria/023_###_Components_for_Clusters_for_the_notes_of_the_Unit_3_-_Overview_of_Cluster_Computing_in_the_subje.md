
### Components for Clusters for the notes of the Unit 3 - Overview of Cluster Computing in the subject of High Performance Computing

Cluster computing is a method of parallel processing that involves using multiple computers to complete a single task. It is a type of distributed computing system where all the computers in the cluster are connected to one another and work together to solve a problem. Clusters are typically used for high-performance computing (HPC) applications that require large amounts of computing power.

The components of a cluster include:

* **Network:** The network is responsible for connecting the computers in the cluster and allowing them to communicate with each other. The type of network used in a cluster depends on the application, but typically it is an Ethernet or InfiniBand network.

* **Cluster Manager:** The cluster manager is responsible for managing the nodes in the cluster and ensuring that tasks are distributed evenly across the nodes. It is also responsible for monitoring the health of the nodes and taking action if any of the nodes fail.

* **Node:** A node is a single computer in the cluster. Each node is responsible for running a portion of the task.

* **Job Scheduler:** The job scheduler is responsible for scheduling tasks to be run on the nodes. It takes into account the resources available on each node and tries to distribute the tasks evenly across the nodes.

* **Software:** The software is responsible for running the tasks on the nodes. This can include applications such as web servers, databases, and scientific applications.

* **Storage:** The storage is responsible for storing the data that is used by the tasks. It can be a shared storage system such as a network-attached storage (NAS) device or a distributed storage system such as a Hadoop cluster.

Cluster computing is a powerful tool for solving complex problems that require a large amount of computing power. It is also a cost-effective way of utilizing existing hardware resources.
