
## Unit 5 - Overview of Cloud Computing

Cloud computing is a term used to describe a range of services, such as software, storage, and networking, that are delivered over the internet. It provides a way for organizations to access computing resources on demand, without having to purchase, install, and manage the hardware and software necessary to run their applications. 

The benefits of cloud computing include: 

* Cost savings: Cloud computing can reduce costs associated with purchasing, installing, and maintaining hardware and software. 
* Scalability: Cloud computing allows organizations to quickly and easily scale up or down their computing resources as needed. 
* Flexibility: Organizations can access their cloud-based applications and resources from anywhere, at any time. 
* Security: Cloud providers offer robust security measures to protect data and applications. 

There are three main types of cloud computing: 

* Infrastructure as a Service (IaaS): IaaS provides organizations with access to computing resources such as servers, storage, and networking. 
* Platform as a Service (PaaS): PaaS provides organizations with access to a platform for developing, testing, and running applications. 
* Software as a Service (SaaS): SaaS provides organizations with access to software applications that can be accessed over the internet. 

Mnemonic: IaaS = Infrastructure as a Service, PaaS = Platform as a Service, SaaS = Software as a Service.
