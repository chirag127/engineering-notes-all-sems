
### Cyber infrastructure for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing

* Cyber infrastructure refers to the combination of computer hardware, software, networks and data storage systems used to store, process and manage data. It is the backbone of modern computing systems and enables the efficient use of computing resources.

* Cloud computing is a type of computing that relies on shared computing resources instead of dedicated hardware. It is a cost-effective and efficient way to access computing resources, as it allows users to access these resources on demand.

* Cloud computing is divided into three main categories: Infrastructure as a Service (IaaS), Platform as a Service (PaaS), and Software as a Service (SaaS). IaaS provides users with access to computing resources such as storage, networking, and servers. PaaS provides users with access to a platform on which they can develop, test and deploy applications. SaaS provides users with access to software applications that can be used without the need for installation.

* Benefits of cloud computing include scalability, cost savings, flexibility, and reliability. It also enables users to access computing resources from anywhere in the world.

* Challenges of cloud computing include security, privacy, and regulatory compliance. It is important that users take the necessary steps to ensure that their data is secure and protected from unauthorized access.
