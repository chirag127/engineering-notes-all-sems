

### Cluster Applications for the Notes of the Unit 3 - Overview of Cluster Computing in the Subject of High Performance Computing

* Cluster Computing is a form of distributed computing which involves connecting multiple computers to form a cluster. This cluster can then be used to perform tasks which require more computing power than a single computer can provide.
* Clusters are typically composed of two or more computers, each with its own processor, memory and storage. The computers are connected via a network, such as Ethernet, and the cluster is managed by a software program, such as Apache Hadoop.
* Cluster Computing can be used for a variety of applications, including:
  * High-performance computing: Cluster Computing can be used to solve complex scientific and engineering problems which require a large amount of computing power.
  * Web applications: Cluster Computing can be used to provide web applications with high availability and scalability.
  * Data processing: Cluster Computing can be used to process large amounts of data, such as for data mining or machine learning applications.
  * Storage: Cluster Computing can be used to provide a distributed storage system, such as a distributed file system.
* Advantages of Cluster Computing include:
  * Cost-effectiveness: Cluster Computing is a cost-effective way to provide high-performance computing.
  * Scalability: Cluster Computing allows for the scaling of computing resources to meet the needs of the application.
  * Reliability: Cluster Computing provides redundancy and fault tolerance, allowing for the continued operation of the application even if one of the nodes fails.
* Disadvantages of Cluster Computing include:
  * Complexity: Cluster Computing can be complex to set up and manage.
  * Security: Cluster Computing can be vulnerable to security attacks, such as distributed denial of service attacks.
  * Performance: Cluster Computing can suffer from reduced performance due to network latency and the overhead of the cluster management software.
