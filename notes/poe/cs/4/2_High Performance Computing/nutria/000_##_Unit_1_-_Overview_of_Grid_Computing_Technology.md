
## Unit 1 - Overview of Grid Computing Technology

Grid computing is a type of distributed computing architecture that allows organizations to share computing resources across multiple networks. It is a form of distributed computing that enables the sharing of computing resources among multiple users and applications. Grid computing provides a way to access and manage distributed computing resources in a cost-effective and efficient manner.

**Mnemonics and Learning Tricks:**

- **G**rid **R**esources **I**n **D**istributed **C**omputing
- **G**rids **R**ely **I**n **D**istributed **C**omputing

**Advantages:**

- Cost savings: Grid computing allows organizations to share computing resources, resulting in cost savings. 
- Scalability: Grid computing allows organizations to scale their computing resources quickly and easily. 
- Fault tolerance: Grid computing is designed to be fault tolerant, meaning that if one node fails, the other nodes can take over. 

**Disadvantages:**

- Security: Grid computing can be vulnerable to security threats, such as malicious attacks and data theft. 
- Latency: Grid computing can suffer from latency issues due to the large distances between nodes. 
- Complexity: Grid computing can be complex to set up and manage. 

**Examples:**

- The World Community Grid is an example of a grid computing project that harnesses the power of volunteer computing to do research on global health and sustainability. 
- The European Grid Infrastructure (EGI) is an example of a grid computing project that provides access to distributed computing resources for research and education. 

**Applications:**

- Scientific research: Grid computing is often used for scientific research, such as climate modeling, drug discovery, and astronomy. 
- Business intelligence: Grid computing can be used to analyze large amounts of data for business intelligence purposes. 
- High performance computing: Grid computing can be used to run high performance computing applications, such as simulations and data mining.
