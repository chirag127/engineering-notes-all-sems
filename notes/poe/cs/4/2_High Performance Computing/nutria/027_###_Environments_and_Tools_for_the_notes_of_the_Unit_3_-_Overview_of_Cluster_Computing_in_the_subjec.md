
### Environments and Tools for the notes of the Unit 3 - Overview of Cluster Computing in the subject of High Performance Computing

* Cluster computing is a type of distributed computing that involves a large number of interconnected computers working together to solve complex problems.
* In order to use cluster computing, the user must have access to a distributed computing environment such as a grid computing platform or a cloud computing platform.
* The user must also have access to the necessary tools and software to be able to manage and control the cluster computing environment.
* Common tools used in cluster computing include job schedulers, resource managers, and monitoring tools.
* Job schedulers are used to manage the jobs that are submitted to the cluster. They are responsible for scheduling jobs and allocating resources accordingly.
* Resource managers are used to manage the resources available in the cluster. They are responsible for allocating resources to the jobs and ensuring that the jobs are running efficiently.
* Monitoring tools are used to monitor the performance of the cluster. They are used to track the performance of the jobs and to identify any issues that may arise during the execution of the jobs.
* In addition to the tools mentioned above, there are also programming frameworks that can be used to develop applications for cluster computing. Common frameworks include MPI, Hadoop, and Spark.
* Finally, it is important to remember that cluster computing requires a great deal of planning and coordination in order to be successful. This includes planning the layout of the cluster, allocating resources, and monitoring the performance of the jobs.
