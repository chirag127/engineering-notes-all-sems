
### Cluster Middleware and SSI for the Notes of the Unit 3 - Overview of Cluster Computing in the Subject of High Performance Computing

* Cluster middleware is a type of software that enables various nodes in a cluster to communicate with each other and share resources. It is also responsible for managing the cluster's resources and providing services to the applications running on the cluster. 

* SSI (Single System Image) is a type of cluster middleware that provides a single, unified view of the cluster resources to the applications running on the cluster. It enables applications to access and use the resources of the cluster as if they were running on a single system. 

* Cluster middleware and SSI are key components of high performance computing (HPC) systems. HPC systems are used to solve large and complex problems that require a significant amount of computing power. 

* Cluster middleware and SSI are used to manage the resources of the cluster and provide services to the applications running on the cluster. These services include scheduling, resource allocation, job submission, data management, and network communication. 

* Cluster middleware and SSI also provide fault tolerance, scalability, and load balancing capabilities to the cluster. Fault tolerance ensures the cluster can continue to operate even if one or more nodes fail. Scalability enables the cluster to grow or shrink as needed. Load balancing ensures that the cluster resources are used efficiently. 

* Cluster middleware and SSI are typically implemented using a distributed computing model. In this model, the nodes in the cluster are connected to each other via a network and can communicate with each other. The nodes can also access and use the resources of the cluster. 

* Cluster middleware and SSI are also used in cloud computing. Cloud computing is a type of distributed computing model where the nodes in the cluster are connected to each other via the internet. Cloud computing enables applications to access and use the resources of the cluster from anywhere in the world.
