
### Service Oriented Architecture for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing

Service-Oriented Architecture (SOA) is a style of software architecture that enables applications to communicate with each other over a network in order to exchange data and services. It is a distributed computing model that is based on the concept of services, which are self-contained units of functionality that are loosely coupled, meaning they can be deployed, changed, and managed independently. 

SOA is most commonly used in enterprise applications, where it is used to build large-scale, complex systems that are made up of many connected services. It is also used in web applications, where it is used to create multi-tier applications that are composed of multiple services.

**Advantages of SOA** 
- Service-oriented architecture enables applications to be built quickly, as the services can be reused and integrated into new applications. 
- SOA is also highly scalable, as services can be added or removed without affecting the entire system. 
- SOA is also flexible, as services can be changed or replaced without having to modify the entire system. 
- SOA is also secure, as services can be protected with authentication, authorization, and encryption. 

**Disadvantages of SOA** 
- SOA can be complex, as it requires a lot of integration between services. 
- SOA can also be expensive, as it requires a lot of infrastructure, such as servers and databases. 
- SOA can also be difficult to maintain, as changes to one service can affect the entire system.
