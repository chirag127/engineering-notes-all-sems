
### Cluster Systems for the Notes of the Unit 3 - Overview of Cluster Computing in the Subject of High Performance Computing

1. A cluster system is a type of computing system that consists of multiple computers connected together with the purpose of sharing resources, such as memory, storage, and processing power. 
2. Clusters are typically used in high-performance computing (HPC), where a number of computers are connected together to solve complex problems.
3. Clusters are also used in distributed computing, where a number of computers are connected together to perform a task that would normally require a single computer.
4. Cluster systems can be used for a variety of tasks, such as scientific computing, web hosting, data analysis, and machine learning.
5. Cluster systems are typically composed of two or more nodes, each of which is a computer with its own processor, memory, and storage.
6. The nodes are connected together using a network, such as Ethernet, InfiniBand, or Fibre Channel.
7. The nodes in the cluster system can be either physical computers or virtual machines.
8. A cluster system is typically managed by a cluster manager, which is responsible for managing the resources in the cluster and ensuring that the cluster is running optimally.
9. Cluster systems can be configured to use a variety of different scheduling algorithms, such as round-robin, first-come-first-served, and backfilling.
10. Cluster systems can be used to improve the performance of applications by distributing the workload across multiple nodes.
11. Cluster systems can also be used to increase the availability of applications by providing redundancy and failover capabilities.
12. Mnemonic for Cluster Systems: C for Cluster, P for Performance, D for Distribution, A for Availability.
