

### Cloud Computing Architecture for the Notes of the Unit 5 - Overview of Cloud Computing in the Subject of High Performance Computing

* Cloud computing is a type of computing that relies on sharing computing resources rather than having local servers or personal devices to handle applications.
* It is a model for enabling ubiquitous, convenient, on-demand network access to a shared pool of configurable computing resources (e.g., networks, servers, storage, applications, and services) that can be rapidly provisioned and released with minimal management effort or service provider interaction.
* Cloud computing architecture is the framework that defines the components and their relationships to each other in order to provide a platform for cloud computing.
* It typically consists of four layers: Infrastructure as a Service (IaaS), Platform as a Service (PaaS), Software as a Service (SaaS), and Function as a Service (FaaS).
* IaaS is the lowest layer and provides the basic components such as servers, storage, and networking.
* PaaS provides a platform for developers to build, run, and manage applications without having to manage the underlying infrastructure.
* SaaS is a software delivery model in which software and associated data are centrally hosted and managed.
* FaaS is a serverless computing model that allows developers to write code and deploy it without having to manage any underlying infrastructure.
* Mnemonic for Cloud Computing Architecture: IaaS PaaS SaaS FaaS (IPFSF)
