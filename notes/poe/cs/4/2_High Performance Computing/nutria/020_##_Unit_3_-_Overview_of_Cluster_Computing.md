
## Unit 3 - Overview of Cluster Computing

* Cluster computing is a type of distributed computing which involves a group of computers, known as nodes, working together to accomplish a single task.
* Each node in the cluster can be assigned a specific task, or multiple tasks, and the results of each task can be combined to produce the desired outcome.
* Cluster computing can be used for a variety of applications, such as large-scale data analysis, scientific research, and web hosting.
* It is also used in high-performance computing applications, such as weather forecasting, financial analysis, and engineering simulations.
* Cluster computing is an efficient way to use multiple computers to complete a task, as it allows for parallel processing, which reduces the amount of time needed to complete the task.
* Cluster computing is typically used in a distributed environment, where the nodes are connected through a network.
* The nodes in the cluster can be located in the same physical location, or they can be located in different locations, connected through the internet.
* A cluster can be composed of a variety of hardware, such as personal computers, workstations, and servers.
* The nodes in the cluster are usually connected through a high-speed network, such as Ethernet or Infiniband.
* Cluster computing requires specialized software, such as a distributed operating system, to manage the nodes in the cluster and coordinate the tasks.
* Cluster computing can be used to increase the speed and efficiency of a task, as multiple nodes can be used to process the same task in parallel.
* Cluster computing is also used to increase the reliability of a system, as if one node fails, the other nodes can continue to work on the task.
* Cluster computing can also be used to increase the scalability of a system, as more nodes can be added to the cluster to increase the amount of processing power available.
* Cluster computing can also help reduce costs, as it allows for the sharing of resources between nodes in the cluster.
