### Capabilities for the notes of the Unit 2 - Open Grid Services Architecture in the subject of High Performance Computing

1. Service Oriented Architecture (SOA): OGSA follows a service oriented architecture where applications are designed as a set of services that can be accessed and used over a network. These services can be discovered and composed dynamically to create complex applications.
2. Service Discovery: OGSA provides mechanisms to discover available grid services. This allows clients to find and use appropriate services as per their requirements. Service discovery is a key part of deploying and using a SOA.
3. Service Description: OGSA uses Web Services Description Language (WSDL) to describe the interfaces and capabilities of the grid services. This enables service discovery and facilitates interoperability between clients and services.
4. Dynamic Service Composition: OGSA enables dynamic composition of services into workflows and virtual organizations. This allows creating applications by composing services on-the-fly as per the requirements.
5. Interfaces and Protocols: OGSA leverages popular Web services standards like SOAP, WSDL, etc. This enables interoperability and reuse of tools and technologies. OGSA also defines some additional interfaces and protocols for grids like the Grid Service Handle and the Grid Service Container.
6. Quality of Service: OGSA provides mechanisms to specify and monitor QoS parameters like performance, reliability, access control, etc. This is important for grids to support computational economy and commercial usage.

The above points cover the key capabilities provided by the Open Grid Services Architecture (OGSA) which enable it to support service oriented grids. The service discovery, description, and composition abilities along with the use of standard interfaces make OGSA a flexible architecture for distributed, heterogeneous, and dynamic grid environments.
