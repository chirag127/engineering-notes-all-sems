## Unit 1 - Overview of Grid Computing Technology

Grid computing is a type of distributed computing that combines computer resources from multiple administrative domains to reach a common goal. It is a collection of heterogeneous computers and resources that are interconnected through a network to perform large-scale computational tasks.

Some key points about grid computing:

- It coordinates resources that are not subject to centralized control using standard, open, general-purpose protocols and interfaces.
- The resources are dynamically discovered and allocated.
- The resources may be heterogeneous, including clusters, distributed databases, scientific instruments, data archives, and computing grids.
- Users can access and control the resources remotely.
- The resource pool can be reconfigured dynamically and adapt to user demands.

Advantages of grid computing:

- Improves resource utilization as idle resources can be utilized.
- Scalability - additional resources can be added easily.
- Flexibility - heterogeneous resources at different locations can be used.
- Reduces cost - no need to invest in high-end machines and resources. Existing resources can be utilized efficiently.
- Increased computing power - combining power of multiple systems can solve complex problems.

Disadvantages of grid computing:

- Security concerns - resources are distributed and control is decentralized, so security is a challenge.
- Reliability - failure of one system can affect the overall grid. Fault tolerance mechanisms are required.
- Complexity - coordinating heterogeneous resources and ensuring efficient usage is complex.
- Data management - managing data in distributed environments is difficult. Data needs to be replicated for better access but it increases storage requirements.

Some applications of grid computing:

- Scientific applications - studying physics, astronomy, medicine, etc. that require heavy computation.
- Parameter sweep experiments - varying parameters of an experiment or algorithm and evaluating results.
- High throughput computing - processing a large number of independent tasks such as in drug discovery.
- Collaborative engineering - collaborative product development requiring sharing of resources.
