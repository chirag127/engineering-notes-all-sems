### Cluster Grids for the notes of the Unit 1 - Overview of Grid Computing Technology in the subject of High Performance Computing

- Cluster grids are a type of grid computing which consists of a group of clustered computers working together closely so that in many respects they form a single system.
- The nodes in a cluster grid consist of multiple computers that are connected via high-speed networks which allow processes to efficiently share data and resources.
- The main advantages of cluster grids are:
    - Increased performance: The combined power of multiple computers working in parallel allows cluster grids to solve complex computational problems much faster than a single computer.
    - Scalability: More computers can be added to a cluster grid to increase its capacity and performance.
    - Fault tolerance: If one node fails in a cluster grid, the task can be reassigned to other nodes to continue execution. This makes cluster grids robust and fault tolerant.
- Some applications of cluster grids are:
    - Scientific computing: Simulations and data analysis of complex physical and biological systems.
    - Business analytics: Processing large business data for trends and insights.
    - Rendering: Generating images, animations, etc. which require massive computing power.
- To remember:
    - Mnemonic: Cluster of computers with fast networking = Cluster grid
    - Learning trick: Think of a group of computers closely working together as a single powerful system to solve complex problems faster. The more computers added, the more powerful the system gets.
- In conclusion, cluster grids are a type of grid computing which harness the combined power of multiple computers working in parallel to solve complex problems much faster and more efficiently than a single computer. They are scalable, fault tolerant and suited for applications requiring massive computing power.
