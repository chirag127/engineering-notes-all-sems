### Services
The major services provided by cloud computing providers are:

1. Infrastructure as a Service (IaaS): It provides access to computing resources such as servers, storage, and networking. The user can deploy and run arbitrary software, including operating systems and applications. The provider is responsible for managing the infrastructure but the user is responsible for managing the operating system, storage, deployed applications, and security. Examples are Amazon EC2, Rackspace, Digital Ocean, etc.

2. Platform as a Service (PaaS): It provides a computing platform and a solution stack with tools and services. The user can deploy their applications onto the cloud infrastructure using programming languages and tools provided by the provider. The provider is responsible for infrastructure, operating system, security, and software updates but the user is responsible for deployed applications and configurations. Examples are Heroku, Google App Engine, OpenShift, etc.

3. Software as a Service (SaaS): It provides software applications that are hosted by the provider. The user does not manage the infrastructure and platform where the applications are running. The user can access the applications over the internet. Examples are Gmail, Office 365, Salesforce, Dropbox, etc.

Advantages:

- Scalability: Resources can be scaled up or down as per the requirements easily.
- Pay-as-you-go: Billing is based on the usage (pay-as-you-go model). No upfront investment is required.
- Automatic updates: Software and security updates happen automatically without user intervention.
- High availability: Resources are distributed and redundant for high availability.
- Easy access: Resources can be accessed from anywhere over the internet.

Disadvantages:

- Vendor lock-in: It can be difficult to migrate data and applications from one provider to another.
- Technical issues: The user has no control over the infrastructure, platform, and services. Technical issues can affect the availability and performance.
- Security: The user has to trust the provider to maintain the security of infrastructure, platform, and services.
- Complex architecture: The internal architecture of cloud computing is complex involving many components and layers.
