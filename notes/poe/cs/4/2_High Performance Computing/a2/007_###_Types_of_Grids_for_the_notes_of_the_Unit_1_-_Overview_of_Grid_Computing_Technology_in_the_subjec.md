## Types of Grids
The grids can be classified into following types:

### Public Grids
- Open to public use
- Anyone can join and utilize the resources
- Eg: SETI@home project
- Advantage: High resource utilization
- Disadvantage: Security and reliability issues

### Private Grids
- Limited to an organization
- Resources are only accessible to authorized users within an organization
- Eg: grids within a company to utilize idle CPU cycles
- Advantage: Better security
- Disadvantage: Underutilization of resources if not used properly

### Hybrid Grids
- Combines public and private grids
- Some resources are public while others are private
- Eg: Collaborations between companies and public institutions
- Advantage: Harnesses both public and private resources
- Disadvantage: Complex to manage security and resource sharing

**Mnemonics:** Imagine 'Public' as an 'open door', 'Private' as a 'locked door' and 'Hybrid' as a 'half-open door' to remember the types of grids.

**Learning trick:** Think of a shopping mall open to public, a gated community only for residents and a mall open for some stores to public and some only to members to understand the types of grids easily.

The types of grids can be used based on the applications and their requirements of security, cost, resource utilization, etc. The choice of a type of grid depends on effectively balancing these factors for optimal performance and output.
