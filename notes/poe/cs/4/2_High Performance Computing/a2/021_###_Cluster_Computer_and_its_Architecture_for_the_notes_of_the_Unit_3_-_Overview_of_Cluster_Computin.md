# Cluster Computer and its Architecture

A cluster computer is a group of loosely coupled computers that work together closely so that they can be viewed as a single system. Cluster computing is a type of parallel computing where multiple computers are connected together to solve a single problem simultaneously. This provides high performance, cost effectiveness and scalability.

The main components of a cluster computer are:

1. Nodes: Individual computers that are connected are called nodes. Each node acts as an independent computer with its own CPU, memory, storage, network interface, etc.
2. Interconnection network: The nodes are interconnected through a network which allows them to communicate and coordinate with each other. This could be a LAN, switch, etc.
3. Software: Specialized software is required to utilize the cluster and distribute work across nodes. This includes libraries, APIs, resource managers, etc.
4. Storage: The cluster will have shared storage to which all nodes have access to. This could be network attached storage or a storage area network.

The architecture of a cluster computer can be heterogeneous or homogeneous. In a heterogeneous cluster, the nodes can have different hardware configurations. In a homogeneous cluster, all nodes have the same hardware configuration. The architecture used depends on the application and its requirements.

The advantages of cluster computing are scalability, cost effectiveness and high performance. The disadvantages are complexity in setup and maintenance, single points of failure and programming challenges.

Cluster computing is used in applications such as scientific computing, web serving, database management, enterprise resource planning, etc.
