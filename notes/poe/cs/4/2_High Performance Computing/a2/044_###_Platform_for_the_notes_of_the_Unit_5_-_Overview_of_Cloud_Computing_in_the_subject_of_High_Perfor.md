### Platform for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing

- Cloud computing is the delivery of computing services over the Internet. Instead of companies hosting software, data, and computing resources on their own in-house servers, all of that is hosted by a cloud provider in their data centers.
- Some of the key characteristics of cloud computing are:
    - On-demand self-service: Computing resources can be provisioned as needed automatically without requiring human interaction.
    - Broad network access: Services are available over the network and accessed through standard mechanisms.
    - Resource pooling: Computing resources are pooled to serve multiple consumers using a multi-tenant model.
    - Rapid elasticity: Resources can be elastically provisioned and released, in some cases automatically, to scale rapidly outward and inward commensurate with demand.
    - Measured service: Cloud systems automatically control and optimize resource use by leveraging a metering capability at some level of abstraction appropriate to the type of service.
- The three main types of cloud computing services are:
    - Infrastructure as a Service (IaaS): The basic building blocks for cloud IT. It provides access to networking features, computers, and data storage space.
    - Platform as a Service (PaaS): Provides a computing platform and a solution stack as a service. It allows you to develop, run, and manage applications without the complexity of maintaining the infrastructure.
    - Software as a Service (SaaS): Provides access to application software and databases. The cloud provider manages the infrastructure and platforms that run the applications. Examples are G Suite, Office 365, Salesforce, etc.
- Some advantages of cloud computing are:
    - Increased agility and scalability: Resources can be provisioned and de-provisioned on demand.
    - Lower costs: No upfront capital expenditure on hardware and software licenses. Pay for what you use.
    - Automatic updates: Software and servers are always up-to-date with the latest updates.
    - Accessibility: Access resources and data from anywhere on any device.
- Some disadvantages of cloud computing are:
    - Reliance on Internet connectivity: Cannot access cloud resources without Internet connectivity.
    - Vendor lock-in: Can get locked into using a particular cloud provider's services. Difficult to move data and resources to another provider.
    - Security concerns: There are valid concerns about the security of data and resources in the cloud. Though cloud providers implement various controls, the customer is still dependent on the provider's security.
    - Cost unpredictability: Can lead to unexpected increases in costs due to pricing complexity or resource usage spikes.
