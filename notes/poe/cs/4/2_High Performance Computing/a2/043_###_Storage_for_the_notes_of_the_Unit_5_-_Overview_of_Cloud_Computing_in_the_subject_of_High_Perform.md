### Storage for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing

- **Cloud storage:** Data is stored in logical pools, the physical storage spans multiple servers (often in multiple locations), and the physical environment is owned and managed by a cloud storage provider.
- Examples: Amazon S3, Microsoft Azure Storage, Google Cloud Storage.
- **Advantages:** Highly scalable, highly durable (99.999999999% durability), highly available, managed service (cloud provider handles infrastructure), pay-as-you-go pricing.
- **Disadvantages:** Vendor lock-in, unpredictable costs, added latency for data access, security and compliance concerns.
- **When to use:** Need scalable storage, don't want to manage infrastructure, data is not sensitive.

Some mnemonics/learning tricks:
- For scalable storage without management headache: **C**loud **S**torage
- For high durability and availability: **3** nines (99.9%) or **9** nines (99.999999999%)
- For security: Avoid for sensitive data
