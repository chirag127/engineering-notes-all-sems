### Application for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing

1. Cloud computing is the delivery of computing services over the Internet. Instead of companies hosting software, data, and computing resources on their own in-house servers, all of that is hosted by a cloud provider in their data centers.

2. The key characteristics of cloud computing are:

- On-demand self-service: Compute resources can be provisioned as needed automatically without requiring human interaction.
- Broad network access: Capabilities are available over the network and accessed through standard mechanisms.
- Resource pooling: Resources are pooled to serve multiple consumers using a multi-tenant model.
- Rapid elasticity: Resources can be rapidly and elastically provisioned, in some cases automatically, to scale rapidly outward and inward commensurate with demand.
- Measured service: Resources usage can be monitored, controlled, and reported to provide transparency for both the provider and consumer.

3. The key advantages of cloud computing are:

- Increased agility and scalability: Resources can be quickly provisioned and de-provisioned to scale to meet demand.
- Reduced costs: No large upfront capital expenditures on hardware and software licenses and pay-as-you-go model.
- Automatic updates: Software and servers are automatically updated and patched by the cloud provider.
- High availability: Resources are distributed and redundant to prevent downtime.
- Easy accessibility: Resources can be accessed from anywhere via the Internet.

4. The key disadvantages of cloud computing are:

- Reliance on Internet connectivity: Cannot access resources without Internet connectivity.
- Vendor lock-in: Can be difficult to migrate data and applications away from a cloud provider.
- Performance unpredictability: Performance can be impacted by issues with the Internet or cloud provider infrastructure.
- Security concerns: There are valid concerns about securing data and applications in the cloud.

5. Some examples of cloud computing are:

- Amazon Web Services (AWS)
- Microsoft Azure
- Google Cloud Platform (GCP)

Cloud computing is used for a wide variety of applications such as web services, storage, databases, servers, networking, software, and more. It enables scalable and cost-effective computing for both individuals and organizations.
