## Unit 5 - Overview of Cloud Computing

- Cloud computing refers to the delivery of computing services over the Internet. Instead of companies hosting software, data, and computing resources on their own in-house servers, all of that is hosted by a cloud provider in their data centers.
- Some of the key characteristics of cloud computing are:

-- On-demand self-service: Users can provision computing resources like server time and network storage on-demand without requiring human interaction with each service provider.
-- Broad network access: Capabilities are available over the network and accessed through standard mechanisms that promote use by heterogeneous thin or thick client platforms (e.g., mobile phones, tablets, laptops, and workstations).
-- Resource pooling: The provider's computing resources are pooled to serve multiple consumers using a multi-tenant model, with different physical and virtual resources dynamically assigned and reassigned according to consumer demand.
-- Rapid elasticity: Capabilities can be elastically provisioned and released, in some cases automatically, to scale rapidly outward and inward commensurate with demand.
-- Measured service: Cloud systems automatically control and optimize resource use by leveraging a metering capability at some level of abstraction appropriate to the type of service (e.g., storage, processing, bandwidth, and active user accounts).

Some of the advantages of cloud computing are:

-- Increased agility and scalability: It is easy to provision and de-provision resources in the cloud as needed. This makes it easy for companies to scale their computing resources up or down as needed.
-- Reduced costs: Cloud computing eliminates the capital expenditure (CapEx) required for on-premise data centers and hardware. Companies only pay for the resources they use and these costs are operational expenditures (OpEx).
-- Automatic software updates: In the cloud, software updates happen automatically leaving no room for software to become outdated or vulnerable to security risks.
-- High availability: Cloud providers implement redundancies and backup to ensure high availability of resources and data.

Some of the disadvantages of cloud computing are:

-- Technical issues: There is dependency on the Internet and cloud provider's infrastructure. If there are technical issues, it can disrupt access to applications and data.
-- Vendor lock-in: It can be difficult to move data and applications from one cloud provider to another. This can create a vendor lock-in situation.
-- Security concerns: There are valid concerns around the security of data in the cloud as it is outside the internal network and systems. Proper security controls and encryption need to be implemented.
-- Compliance challenges: Meeting regulatory compliance requirements can be challenging in the cloud. Companies need to make sure cloud providers implement necessary controls and they have access/visibility into the security of their data.
