### Programming for the notes of the Unit 3 - Overview of Cluster Computing in the subject of High Performance Computing

- Cluster computing refers to the use of multiple computers, known as nodes, working together as a unified system to solve a common computing task.
- The nodes in a cluster are interconnected via a high-speed network and they work together and communicate with each other to solve a computing problem that is larger than any single node can solve efficiently.
- The key benefits of cluster computing are increased performance, cost-effectiveness, and improved availability and reliability.
- The programming models for cluster computing include message passing and shared-memory paradigms.
- In message passing, the program is divided into multiple processes that run on different nodes and communicate by exchanging messages through the network. Examples are MPI and PVM.
- In shared-memory, the nodes in a cluster share a virtual address space and the processes communicate by accessing shared data in the shared memory. OpenMP is a common API for shared-memory programming.
- The performance of a cluster application depends on minimizing communication delays and balancing the workload across the nodes. Efficient resource management and scheduling are important for high performance.
- Example applications of cluster computing include scientific simulations, data mining, web services, and enterprise computing tasks.
