### Cluster Middleware and SSI

- Cluster middleware refers to the software layer that sits between the operating system and the application software on each cluster node.
- It is responsible for communication and coordination between nodes.
- Examples of cluster middleware are Message Passing Interface (MPI) and Parallel Virtual Machine (PVM).
- The main functions of cluster middleware are:
-- Allowing applications to communicate and coordinate across nodes.
-- Masking the low-level communication details from the application software.
-- Providing mechanisms for synchronization, load balancing, fault tolerance, etc.
-- Single System Image (SSI) refers to a middleware feature that presents the cluster of nodes as if it were a single system.
-- The main benefits of SSI are:
- Application transparency - Applications see a single system and do not need modification to run on clusters.
- Load balancing - Work can be dynamically balanced across the nodes.
- Fault tolerance - The failure of a node is hidden from the user and work is redistributed to remaining nodes.
