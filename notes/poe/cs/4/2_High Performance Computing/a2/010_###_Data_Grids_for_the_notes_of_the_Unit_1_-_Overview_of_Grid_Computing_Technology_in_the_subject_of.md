### Data Grids

- Data grids provide access to large data collections over a network. They allow users to share, discover, replicate and process large data collections distributed across multiple sites.
- Data grids provide seamless access to distributed data collections giving the user the illusion of a single, integrated database.
- Some key capabilities provided by data grids are:
  - Data discovery: The ability to discover data collections relevant to user queries.
  - Data replication: The ability to replicate data for performance, redundancy and reliability.
  - Data access: The ability to access distributed data collections.
  - Data movement: The ability to move data efficiently between sites.
  - Data sharing: The ability to share data collections for collaborative work.
  - Processing: The ability to process data in parallel across multiple resources.
- Examples of data grids include: iVDGL, DART, and the EU data grid.
- Advantages of data grids:
  - Increased data access: Users can access more data than located at one site.
  - Increased storage: The aggregate storage capacity of multiple sites can be leveraged.
  - Increased computing power: The aggregate computing capacity of multiple sites can be leveraged to process large data sets in parallel.
  - Collaboration: Facilitates collaborative working and sharing of data collections.
- Disadvantages of data grids:
  - Complexity: Data grids are complex to develop, deploy and manage.
  - Reliability: Reliance on network connectivity and multiple heterogeneous components can affect reliability.
  - Security: There are security challenges involved with sharing and accessing data across multiple administrative domains.
  - Data consistency: Ensuring data consistency can be challenging in distributed data collections.

**Mnemonics:**
DART - Data Access, Replication and Transfer
iVDGL -  Internet-scale Virtual Data Grid Laboratory

**Learning tricks:**
- Remember the key capabilities (data discovery, access, replication, movement, sharing and processing) and the examples of data grids to understand data grids.
- Remember the advantages and disadvantages to understand when to use and when not to use data grids.
