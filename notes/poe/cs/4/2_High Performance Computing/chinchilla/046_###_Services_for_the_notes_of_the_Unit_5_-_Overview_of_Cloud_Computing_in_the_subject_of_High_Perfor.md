### Services for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing

Cloud computing has revolutionized the way businesses operate and has become the backbone of the modern IT landscape. It offers various services that can be used to build and deploy applications, store and manage data, and perform other computing tasks. In this unit, we will discuss the various services offered by cloud computing.

#### Infrastructure as a Service (IaaS)

Infrastructure as a Service (IaaS) is a service model in which cloud providers offer virtualized computing resources such as servers, storage, and networking infrastructure to customers. Customers can use these resources to build their own IT infrastructure and deploy their applications. The cloud provider is responsible for managing the underlying hardware and software infrastructure.

Mnemonic: "IaaS - Infrastructure as a Service provides virtualized Infrastructure to build your own IT infrastructure."

#### Platform as a Service (PaaS)

Platform as a Service (PaaS) is a service model in which cloud providers offer a platform for customers to develop, run, and manage applications without having to worry about the underlying infrastructure. The cloud provider is responsible for managing the hardware and software infrastructure, while the customer is responsible for developing and deploying their applications.

Mnemonic: "PaaS - Platform as a Service provides a platform to develop, run and manage applications."

#### Software as a Service (SaaS)

Software as a Service (SaaS) is a service model in which cloud providers offer software applications to customers over the internet. Customers can access these applications through a web browser or a mobile app without having to install them on their local devices. The cloud provider is responsible for managing the hardware, software infrastructure, and application data.

Mnemonic: "SaaS - Software as a Service provides software applications over the internet."

#### Function as a Service (FaaS)

Function as a Service (FaaS) is a service model in which cloud providers offer a way to run small pieces of code, called functions, without having to manage the underlying infrastructure. Customers can upload their code to the cloud provider, which will run it on demand and charge them based on usage. This service is also known as serverless computing.

Mnemonic: "FaaS - Function as a Service provides a way to run small code functions without managing infrastructure."

#### Database as a Service (DBaaS)

Database as a Service (DBaaS) is a service model in which cloud providers offer database management systems as a service. Customers can store and manage their data on the cloud provider's infrastructure without having to worry about managing the underlying hardware and software infrastructure. The cloud provider is responsible for managing the database infrastructure and ensuring data security and availability.

Mnemonic: "DBaaS - Database as a Service provides a database management system as a service."

In conclusion, cloud computing offers various services that can be used to build, deploy, and manage applications and IT infrastructure. Understanding these services is essential for anyone looking to work with cloud computing technology.
