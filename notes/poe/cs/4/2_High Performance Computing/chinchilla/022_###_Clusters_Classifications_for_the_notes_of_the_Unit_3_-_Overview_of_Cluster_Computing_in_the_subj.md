### Clusters Classifications for the notes of the Unit 3 - Overview of Cluster Computing in the subject of High Performance Computing

A cluster is a group of computers or nodes that work together to achieve a common goal. They are commonly used in High Performance Computing (HPC) to solve complex problems that cannot be handled by a single computer. Clusters can be classified into different categories based on their architecture and deployment.

#### 1. Homogeneous Clusters

In a homogeneous cluster, all the nodes are of the same type and have the same hardware and software configurations. Homogeneous clusters are easy to set up and maintain because all the nodes are identical. They are also cost-effective and provide a good balance between performance and cost.

#### 2. Heterogeneous Clusters

In a heterogeneous cluster, the nodes are of different types and have different hardware and software configurations. Heterogeneous clusters are more complex to set up and maintain because the nodes have different characteristics. However, they can provide better performance than homogeneous clusters because the nodes can be selected based on their strengths and weaknesses.

#### 3. Shared Memory Clusters

In a shared memory cluster, all the nodes share a common memory space. This means that any node can access any part of the memory at any time. Shared memory clusters are suitable for applications that require a large amount of shared memory, such as scientific simulations and data analysis.

#### 4. Distributed Memory Clusters

In a distributed memory cluster, each node has its own memory space and communicates with other nodes through a network. Distributed memory clusters are suitable for applications that require a large amount of memory or processing power, such as weather forecasting and molecular dynamics simulations.

#### 5. High Availability Clusters

In a high availability cluster, there are multiple nodes that work together to provide continuous availability of services. If one node fails, the other nodes take over its tasks to ensure that the services are not disrupted. High availability clusters are suitable for applications that require high uptime, such as web servers and databases.

#### 6. Load Balancing Clusters

In a load balancing cluster, there are multiple nodes that work together to distribute the workload evenly across the nodes. Load balancing clusters are suitable for applications that require high performance, such as video streaming and online gaming.

Mnemonics and learning tricks:
- For the classifications of clusters based on their architecture, remember the acronym "SHD" for Shared/Distributed memory clusters.
- For the classifications of clusters based on their deployment, remember the acronym "HHL" for Homogeneous/Heterogeneous and High Availability/Load Balancing clusters.
