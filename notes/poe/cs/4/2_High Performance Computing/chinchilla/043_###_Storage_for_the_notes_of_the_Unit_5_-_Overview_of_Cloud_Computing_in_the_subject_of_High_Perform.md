### Storage for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing

In cloud computing, storage is one of the most important aspects to consider. It is the backbone of cloud computing as it provides a place to store data and information that can be accessed from anywhere and anytime. This section will provide an overview of storage in cloud computing.

#### Types of Cloud Storage

There are three types of cloud storage:

1. Object Storage: It is a type of storage that stores data as objects. Each object has its unique identifier, and it is stored in a flat address space. It is highly scalable and can store vast amounts of data.

2. Block Storage: It is a type of storage that stores data in fixed-sized blocks. It is similar to traditional storage systems like hard drives and USB drives. It is suitable for storing structured data like databases and operating systems.

3. File Storage: It is a type of storage that stores data as files. It is similar to traditional file systems like NTFS and FAT. It is suitable for storing unstructured data like documents, images, and videos.

#### Storage Services in Cloud Computing

Cloud providers offer various storage services that can be used to store data in the cloud. Some of the popular storage services are:

1. Amazon S3: It is an object storage service provided by Amazon Web Services (AWS). It provides highly scalable, durable, and secure storage for objects.

2. Google Cloud Storage: It is an object storage service provided by Google Cloud Platform. It provides highly available, durable, and secure storage for objects.

3. Microsoft Azure Blob Storage: It is an object storage service provided by Microsoft Azure. It provides highly scalable, durable, and secure storage for objects.

4. Amazon EBS: It is a block storage service provided by AWS. It provides highly available, durable, and scalable storage for block-level data.

5. Google Cloud Persistent Disk: It is a block storage service provided by Google Cloud Platform. It provides highly available, durable, and scalable storage for block-level data.

6. Azure Disk Storage: It is a block storage service provided by Microsoft Azure. It provides highly available, durable, and scalable storage for block-level data.

#### Advantages of Cloud Storage

1. Scalability: Cloud storage can be easily scaled up or down based on the user's requirements.

2. Accessibility: Cloud storage can be accessed from anywhere and anytime using an internet connection.

3. Cost-effective: Cloud storage is cost-effective as users only pay for the storage they use.

4. Data backup and recovery: Cloud storage provides data backup and recovery features, ensuring data is safe and recoverable in case of disasters.

#### Disadvantages of Cloud Storage

1. Security: Cloud storage is vulnerable to security threats like cyber-attacks and data breaches.

2. Internet dependency: Cloud storage requires an internet connection to access and store data.

3. Limited control: Users have limited control over the storage infrastructure as it is managed by the cloud provider.

#### Learning Trick

To remember the types of cloud storage, remember the acronym OFB:

- Object Storage
- File Storage
- Block Storage
