### Components for Clusters for the notes of the Unit 3 - Overview of Cluster Computing in the subject of High Performance Computing

Cluster computing is a type of computing where interconnected computers work together as a single system. Clusters are composed of several components that work together to achieve a common goal. In this section, we will discuss the various components of cluster computing.

1. Nodes:
    - A node is a single computer or server that is part of a cluster.
    - Each node has its own processor, memory, and storage.
    - The nodes in a cluster are connected through a network.

2. Network:
    - A network is used to connect the nodes in a cluster.
    - The network can be either a LAN (Local Area Network) or a WAN (Wide Area Network).
    - The network should provide high-speed, low-latency communication between the nodes.

3. Cluster Management Software:
    - Cluster management software is used to manage the nodes in a cluster.
    - It provides tools for managing the nodes, scheduling jobs, and monitoring the performance of the cluster.
    - Examples of cluster management software include OpenMPI, Rocks Cluster, and Slurm.

4. File System:
    - A file system is used to store and manage the data used by the cluster.
    - The file system should be able to provide high-speed, concurrent access to the data.
    - Examples of file systems used in cluster computing include Lustre and GPFS.

5. Load Balancer:
    - A load balancer is used to distribute the workload evenly across the nodes in a cluster.
    - It ensures that no single node is overloaded with too much work.
    - Examples of load balancers include HAProxy and nginx.

6. Applications:
    - Applications are the programs that are run on the cluster.
    - They are designed to take advantage of the parallel computing capabilities of the cluster.
    - Examples of applications used in cluster computing include Hadoop, Spark, and MPI.

Mnemonic:
- Remember the acronym "NMCFLA" to recall the components of the cluster: Nodes, Network, Cluster Management Software, File System, Load Balancer, and Applications.

Learning Trick:
- Draw a diagram of the cluster and label each component. This will help you visualize how the components work together to achieve a common goal.
