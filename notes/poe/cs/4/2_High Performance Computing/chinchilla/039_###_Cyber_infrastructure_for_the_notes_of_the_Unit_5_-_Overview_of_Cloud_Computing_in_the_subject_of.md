### Cyber Infrastructure for the Notes of Unit 5 - Overview of Cloud Computing in High Performance Computing

Cloud computing is a type of computing that relies on shared computing resources rather than having local servers or personal devices to handle applications. Cyber infrastructure refers to the collection of hardware, software, and network resources that support cloud computing. In this unit, we will learn about the different components of cyber infrastructure and their roles in cloud computing.

#### Components of Cyber Infrastructure

1. **Hardware Resources**: Hardware resources include physical servers, storage devices, and networking equipment that are used to support cloud computing. These resources are housed in data centers and can be shared among multiple users.

2. **Software Resources**: Software resources include operating systems, middleware, and application software that are used to support cloud computing. These resources are typically provided by cloud service providers and can be accessed by users over the internet.

3. **Network Resources**: Network resources include switches, routers, and other networking equipment that are used to connect hardware and software resources in the cloud. These resources are critical for ensuring that cloud applications are accessible and reliable.

#### Learning Tricks and Mnemonics

1. **HAL**: This acronym can be used to remember the three components of cyber infrastructure - Hardware, Application, and Network resources.

2. **Clouds in the Sky**: Imagine clouds in the sky to represent the cloud computing environment. The hardware resources can be visualized as the foundation of the cloud, the software resources as the clouds themselves, and the network resources as the pathways between the clouds.

#### Advantages and Disadvantages of Cloud Computing

Advantages:

1. Scalability: Cloud computing allows businesses to easily scale up or down their computing resources as needed, making it a flexible and cost-effective option.

2. Accessibility: Cloud computing allows users to access their applications and data from anywhere with an internet connection.

3. Reliability: Cloud service providers often have redundant systems in place to ensure that applications remain available and data is not lost.

Disadvantages:

1. Security: Cloud computing can pose security risks, as sensitive data may be stored on shared servers.

2. Dependence on the Internet: Cloud computing requires a stable and fast internet connection to be accessible, which may not always be available or reliable.

#### Examples and Applications of Cloud Computing

1. Amazon Web Services (AWS): AWS is a popular cloud computing platform that provides a wide range of services, including computing, storage, and databases.

2. Microsoft Azure: Azure is another popular cloud computing platform that provides similar services to AWS.

3. Netflix: Netflix uses cloud computing to stream video content to users around the world.

4. Dropbox: Dropbox is a cloud storage service that allows users to store and share files online.

In conclusion, cyber infrastructure is an essential component of cloud computing, consisting of hardware, software, and network resources that support cloud applications. Understanding the components of cyber infrastructure is critical for gaining a comprehensive understanding of cloud computing and its advantages and disadvantages.
