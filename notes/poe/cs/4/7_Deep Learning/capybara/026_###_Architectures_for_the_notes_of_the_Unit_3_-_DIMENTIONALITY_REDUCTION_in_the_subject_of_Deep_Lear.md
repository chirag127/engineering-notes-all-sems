### Architectures for the notes of the Unit 3 - DIMENSIONALITY REDUCTION in the subject of Deep Learning

Dimensionality reduction is an essential technique in the field of Deep Learning that allows us to extract relevant features from high-dimensional data. Here are some architectures that can be used for dimensionality reduction:

1. Principal Component Analysis (PCA): PCA is a linear technique that transforms the original data into a lower-dimensional space while preserving the maximum variance of the data. It is widely used for feature extraction, data compression, and visualization.

2. Autoencoders: Autoencoders are neural networks that are trained to reconstruct the input data from a lower-dimensional representation. They consist of an encoder that maps the input data to a hidden representation and a decoder that reconstructs the input data from the hidden representation. Autoencoders can be used for dimensionality reduction, feature extraction, and data denoising.

3. t-SNE: t-SNE is a nonlinear technique that is used for visualizing high-dimensional data in a low-dimensional space. It is based on a probabilistic model that maps the high-dimensional data to a low-dimensional space while preserving the local structure of the data. t-SNE is widely used for data visualization and exploratory data analysis.

4. UMAP: UMAP is a nonlinear technique that is used for dimensionality reduction, clustering, and visualization of high-dimensional data. It is based on a topological representation of the data that preserves the global structure of the data. UMAP has been shown to perform better than t-SNE on large datasets with complex structure.

5. Generative Adversarial Networks (GANs): GANs are neural networks that are trained to generate new data that is similar to the training data. They consist of a generator that generates new data and a discriminator that distinguishes between real and fake data. GANs can be used for dimensionality reduction, data augmentation, and data synthesis.

Some mnemonics and learning tricks that can be helpful to remember these architectures are:

- PCA: "Preserve the maximum variance"
- Autoencoders: "Encode and decode to reduce dimensionality"
- t-SNE: "Tackle high-dimensional data with a probabilistic model"
- UMAP: "Use topology to preserve global structure"
- GANs: "Generate new data with a discriminator and a generator"

Remembering these mnemonics can help you recall the key concepts and applications of these architectures during exams.
