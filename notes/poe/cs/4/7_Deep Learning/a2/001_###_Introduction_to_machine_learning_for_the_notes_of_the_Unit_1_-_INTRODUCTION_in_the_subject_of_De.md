### Introduction to machine learning for the notes of the Unit 1 - INTRODUCTION in the subject of Deep Learning

Machine learning is a field of computer science that gives computers the ability to learn without being explicitly programmed. Machine learning focuses on the development of computer programs that can change when exposed to new data.

Some key points about machine learning are:

- Machine learning algorithms build a mathematical model based on sample data, known as "training data", in order to make predictions or decisions without being explicitly programmed to perform the task.
- Machine learning algorithms are often categorized as supervised learning, unsupervised learning, or reinforcement learning. Supervised learning uses labeled examples to learn a function that maps inputs to outputs. Unsupervised learning finds hidden patterns in unlabeled data. Reinforcement learning learns by interacting with a dynamic environment.
- Example tasks include predicting future prices of stocks, classifying emails as spam or not spam, identifying objects in images, translating between languages, and identifying speech.
- The iterative process of machine learning is:

1. Gather data
2. Prepare data
3. Choose an algorithm
4. Train and evaluate the model
5. Make predictions

Some advantages of machine learning are:

- Increased accuracy with increased data
- Automation of tedious tasks
- Adaptation to complex problems

Some disadvantages of machine learning are:

- Requirement of large amounts of data
- Inability to explain reasons/logical rationale for decisions
- Possibility of biased or unfair decisions due to flaws in data or algorithm
- Need for skilled professionals to develop and use machine learning
