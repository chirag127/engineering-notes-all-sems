### Joint Detection

- Joint detection is the task of localizing and classifying multiple joints or keypoints in an image.
- It is an important task in computer vision with applications in human pose estimation, action recognition, etc.
- Some common joints that are detected are shoulders, elbows, wrists, hips, knees and ankles.
- The joints can be detected using regression or classification techniques.
- Regression based methods predict the exact coordinates of the joints. Examples are Stacked Hourglass Networks, Convolutional Pose Machines.
- Classification based methods classify each pixel in the image as belonging to a particular joint or not. Examples are Part Affinity Fields, Mask R-CNN.
- Advantages of joint detection: Enables higher level task like pose estimation and action recognition. Provides spatial relationships between joints which can be used for further analysis.
- Disadvantages: Difficult task due to scale variation, occlusions, clothing, etc. Requires large annotated datasets for training.
- Some applications are: Human pose estimation, Action recognition, Gesture recognition, Virtual try-on, etc.
