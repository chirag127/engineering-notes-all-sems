## Unit 3 - DIMENSIONALITY REDUCTION

Dimensionality reduction is a set of techniques used to reduce the number of features or variables under consideration. This is usually done to aid in visualization, machine learning, and data compression.

Some key reasons to perform dimensionality reduction are:

- Dealing with the curse of dimensionality: As the number of dimensions or features grows, the volume of space increases exponentially and quickly leads to overfitting.
- Reducing training time: With fewer features, the time taken to train machine learning models decreases.
- Improving model performance: Removing redundant features can improve model performance as it reduces noise and avoids overfitting.
- Visualization: It becomes difficult to visualize data in high dimensional spaces. Dimensionality reduction can help project the data into 2D or 3D space for easier visualization and understanding.

There are two broad categories of dimensionality reduction techniques:

- Feature selection: Selecting a subset of the original features. This can be done using univariate, recursive, or embedded methods.
- Feature extraction: Deriving a set of new features from the original features. This includes techniques like PCA, LDA, Kernel PCA, t-SNE, etc.

Some pros and cons of dimensionality reduction are:

Pros:

- Avoid overfitting and the curse of dimensionality
- Faster training of models due to fewer features
- Better visualization and understanding of data
- Improved model performance due to removal of redundant features

Cons:

- May lose important information while reducing dimensions
- Needs to be performed carefully to not lose key characteristics of the data
- Finding the optimal number of dimensions to reduce to is challenging
- May need to be combined with other techniques to get the best results
