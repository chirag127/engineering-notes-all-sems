### What a shallow network computes for the notes of the Unit 1 - INTRODUCTION in the subject of Deep Learning

A shallow neural network is one that has only 1-2 hidden layers. Such a network can learn simple patterns in the data, but cannot learn complex non-linear relationships.

For example, a shallow network might be able to learn:

- Linear relationships (y = mx + c)
- Step functions (output is 0 if x < threshold, else output is 1)
- Simple combinations of the above (AND, OR, etc.)

However, a shallow network would not be able to learn:

- XOR - this requires a non-linear decision boundary
- Complex shapes/patterns in image data
- Time series with long-term dependencies

Key points:

- Shallow networks can learn simple patterns, but cannot learn complex non-linear relationships
- They are limited by their linear nature and inability to disentangle complex relationships
- Deeper networks are required to learn more complex patterns by stacking multiple non-linear layers

Mnemonics:

- Think of shallow networks as only being able to learn straight lines (linear relationships)
- They can't bend/curve to learn more complex shapes - you need depth for that!
