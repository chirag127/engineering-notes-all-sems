### Detection for the notes of the Unit 5 - CASE STUDY AND APPLICATIONS in the subject of Deep Learning

- Object Detection: Identifying and localizing objects in images and videos. Some applications are face detection, pedestrian detection, etc.
- - Mnemonic: Think of object detection as finding the coordinates of objects in an image.
- - Learning trick: Practice implementing object detection networks on various datasets to understand the concepts better.

- Semantic Segmentation: Assigning a semantic label to every pixel in an image. Some applications are self-driving cars, medical imaging, etc.
- - Mnemonic: Segment the image into parts and label each part.
- - Learning trick: Try using convolutional neural networks and recapitulation to learn semantic segmentation.

- Instance Segmentation: Identifying and outlining the precise shape of each object in an image. It is a combination of object detection and semantic segmentation.
- - Mnemonic: Detect and segment each instance or object in the image.
- - Learning trick: Understand object detection and semantic segmentation first to grasp instance segmentation better.

- Pose Estimation: Estimating the pose of a person or object in an image. Some applications are human pose estimation, robotics, etc.
- - Mnemonic: Think of estimating the position and orientation of the object.
- - Learning trick: Try implementing basic pose estimation networks and understand the key points and connections between points to learn the concepts.

- Other applications: Image captioning, visual question answering, machine translation, etc. Deep learning has been applied to various tasks in computer vision and natural language processing with significant achievements.
