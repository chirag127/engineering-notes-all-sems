### Scene Understanding

Scene understanding is the task of interpreting the semantic meaning of an image or video. Some of the common tasks under scene understanding are:

- Object detection: Identifying the presence and location of objects in an image or video.
- Semantic segmentation: Assigning a semantic label to every pixel in an image. For example, segmenting objects like road, cars, buildings, sky, etc. in a street scene image.
- Instance segmentation: Separating individual objects of the same class and assigning a unique label to each instance. For example, separating individual cars and labeling each car differently in a street scene image.
- Question answering: Answering questions about the contents of an image or video. For example, answering "How many people are there in the image?" or "What color is the car?"

Some tips and learning tricks for scene understanding:

- Focus on understanding the hierarchy of tasks under scene understanding and their differences. Object detection is the simplest while semantic/instance segmentation and question answering build upon object detection.
- For semantic/instance segmentation, understand the difference between assigning labels to pixels (semantic) vs separating instances of the same class (instance).
- Learn effective approaches like Faster R-CNN and Mask R-CNN which can solve multiple tasks like object detection and segmentation together in an efficient manner.
- Understand the importance of large, diverse, annotated datasets to train complex deep learning models for scene understanding. Some popular datasets are COCO, Pascal VOC, ADE20K, Cityscapes, etc.
- Explore recent advances like self-supervised learning and generative models which can utilize unlabelled data to improve scene understanding.
