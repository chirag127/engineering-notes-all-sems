
### Linear (PCA, LDA) and Manifolds for the Notes of the Unit 3 - Dimensionality Reduction in the Subject of Deep Learning

- **Principal Component Analysis (PCA)** is a linear dimensionality reduction technique that seeks to identify the most important components of a dataset. It does this by finding the directions of maximum variance in the data, and then projecting the data onto these directions. PCA is often used as a pre-processing step for machine learning tasks and can be used to reduce the number of dimensions in a dataset while preserving the most important information.

- **Linear Discriminant Analysis (LDA)** is a supervised linear dimensionality reduction technique used to identify the most important components of a dataset that are most useful for classification. It does this by finding the directions in the data that maximize the separation between different classes, and then projecting the data onto these directions.

- **Manifolds** are higher-dimensional spaces that can be embedded in lower-dimensional spaces. Manifolds are useful for dimensionality reduction because they allow for the representation of higher-dimensional data in lower-dimensional spaces. Manifold learning techniques, such as Isomap and t-SNE, can be used to identify the most important components of a dataset and project the data onto these components.
