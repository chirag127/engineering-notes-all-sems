
### Scene Understanding for the notes of the Unit 5 - CASE STUDY AND APPLICATIONS in the subject of Deep Learning

Scene understanding is a branch of deep learning that deals with the analysis of images, videos, and 3D data to identify objects and their relationships within a scene. It is used in various applications such as robotics, autonomous driving, medical imaging, and computer vision.

Scene understanding is based on the concept of feature extraction, which is the process of extracting meaningful features from images and videos. The extracted features are then used to classify and recognize objects in the scene.

Scene understanding also involves object detection and tracking, which is the process of locating and tracking objects in a scene. This is done by using algorithms such as convolutional neural networks (CNNs) and recurrent neural networks (RNNs).

In addition, scene understanding also involves scene segmentation, which is the process of dividing a scene into multiple parts based on their characteristics. This is done by using algorithms such as k-means clustering and graph-based segmentation.

Finally, scene understanding also involves scene classification, which is the process of assigning labels to objects in a scene. This is done by using algorithms such as support vector machines (SVMs) and random forests.

Mnemonics and Learning Tricks:
- Feature extraction: FEATure Extraction
- Object detection and tracking: OBJECT Detection And Tracking
- Scene segmentation: SCENE Segmentation
- Scene classification: SCENE Classification
