

### ResNet for the notes of the Unit 3 - DIMENTIONALITY REDUCTION in the subject of Deep Learning

- ResNet stands for Residual Network, and is a type of convolutional neural network (CNN) used for image recognition and classification.
- ResNet was introduced in 2015 by Kaiming He et al. and has since become one of the most popular architectures for deep learning.
- ResNet is based on the idea of “residual learning”, which is the concept of learning the residuals between the output of the convolutional layers and the desired output.
- ResNet is designed to tackle the problem of vanishing gradients, which is a common issue in deep learning.
- ResNet also uses skip connections, which are short-cuts between layers, to help the network learn more efficiently.
- ResNet can be used for a variety of tasks, including image classification, object detection, and semantic segmentation.
- ResNet is also used for dimensionality reduction, which is the process of reducing the number of features in a data set to make it easier to work with.
- ResNet can be used to reduce the number of features in an image, such as reducing the number of pixels or color channels.
- ResNet can also be used to reduce the number of features in a text document, such as reducing the number of words or characters.
- ResNet can also be used to reduce the number of features in a time series, such as reducing the number of time steps.
- A good mnemonic for remembering ResNet is: “Residual networks learn the residuals between the output of the convolutional layers and the desired output.”
