
### Linear models (SVMs and Perceptrons for the notes of the Unit 1 - INTRODUCTION in the subject of Deep Learning)

* Linear models are supervised machine learning algorithms used for classification and regression.
* Support Vector Machines (SVMs) are a type of linear model that uses the support vector method to find the optimal hyperplane that separates two classes of data points.
* Perceptrons are a type of linear model that consists of a single layer of neurons, each of which is connected to an input and an output. The output of a perceptron is determined by the sum of the weighted inputs.
* Both SVMs and perceptrons can be used for classification tasks, with SVMs being more powerful and able to handle a wider range of datasets.
* SVMs are also more efficient than perceptrons, as they use the kernel trick to map data points into a higher-dimensional space, allowing for more complex patterns to be detected.
* Both SVMs and perceptrons can be used for regression tasks, but SVMs are more powerful and can handle a wider range of datasets.
* SVMs and perceptrons can also be used together in an ensemble model, where the output of one is used as an input to the other. This can help improve the accuracy of the model.
* Mnemonics and learning tricks such as visualizing the data points as a graph and using the hyperplane equation to find the optimal hyperplane can be helpful in understanding and applying linear models.
