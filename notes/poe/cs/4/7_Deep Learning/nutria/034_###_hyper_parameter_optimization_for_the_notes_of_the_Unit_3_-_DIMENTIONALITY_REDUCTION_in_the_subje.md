
### Hyper Parameter Optimization for the Notes of the Unit 3 - Dimensional Reduction in the Subject of Deep Learning

* Hyperparameter optimization is the process of finding the best set of hyperparameters for a given model to optimize its performance.
* Hyperparameters are the parameters that are not learned directly from the data, but instead are set prior to training the model. Examples of hyperparameters include learning rate, number of layers, activation functions, and number of neurons.
* Dimensional reduction is a process of reducing the number of dimensions in a data set. It is used to reduce the complexity of the data set, and to make it easier to interpret and visualize.
* There are several techniques for dimensional reduction, such as principal component analysis (PCA), linear discriminant analysis (LDA), and non-negative matrix factorization (NMF).
* Hyperparameter optimization can be used to find the best set of hyperparameters for a given dimensional reduction technique. This can help to improve the performance of the model, and to reduce the complexity of the data set.
* It is important to note that hyperparameter optimization is a trial and error process, and it is not always possible to find the optimal set of hyperparameters. However, it is possible to find a set of hyperparameters that are good enough for the task at hand.
* Mnemonic techniques and learning tricks can be used to help remember the different hyperparameters and their effects. For example, a mnemonic for the learning rate could be “LR”, which stands for “Learning Rate”.
* Additionally, visual diagrams can be used to illustrate the effects of different hyperparameters on the performance of the model. This can help to understand the effects of different hyperparameters and to make informed decisions about which ones to use.
