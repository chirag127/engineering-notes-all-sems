
### Batch Normalization for the Notes of the Unit 2 - DEEP NETWORKS in the Subject of Deep Learning

Batch normalization is a technique used to normalize the inputs of a layer in a deep neural network. It is used to speed up training, reduce the internal covariate shift, and improve the generalization of the model. The technique normalizes the inputs of each layer to have a mean of 0 and a variance of 1. 

**Mnemonics and Learning Tricks**

1. BN stands for Batch Normalization
2. BN helps to reduce the internal covariate shift which helps to speed up training and improve generalization.
3. BN normalizes the inputs of each layer to have a mean of 0 and a variance of 1.
4. BN is used after the activation function to normalize the output of the layer.

**Advantages**

1. BN helps to reduce the internal covariate shift which helps to speed up training and improve generalization.
2. BN also helps to reduce the need for dropout and other regularization techniques.
3. BN helps to improve the performance of the model by reducing the variance in the inputs of each layer. 

**Disadvantages**

1. BN can slow down the training process as it adds an extra step in the forward pass.
2. BN can be unstable if the batch size is too small.

**Examples**

1. BN can be used in convolutional neural networks (CNNs) to normalize the inputs of each layer.
2. BN can also be used in recurrent neural networks (RNNs) to normalize the inputs of each layer.

**Applications**

1. BN can be used in image classification tasks to improve the performance of the model.
2. BN can be used in natural language processing (NLP) tasks to improve the performance of the model.
3. BN can be used in reinforcement learning (RL) tasks to improve the performance of the model.
