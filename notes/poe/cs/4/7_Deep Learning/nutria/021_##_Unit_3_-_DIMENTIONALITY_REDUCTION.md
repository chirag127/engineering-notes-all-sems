
## Unit 3 - DIMENSIONALITY REDUCTION

Dimensionality reduction is the process of reducing the number of random variables under consideration, while retaining the important information in the data. It is an important tool in machine learning and data science, as it can help to reduce the complexity of a model, reduce the time needed to train a model, and improve the accuracy of a model.

### Mnemonics and Learning Tricks

A useful mnemonic for remembering the purpose of dimensionality reduction is "DROP DIMS":

* **D**imensionality **R**eduction **O**ptimizes **P**erformance by **D**ropping **DIMS**. 

Another useful trick to remember is that dimensionality reduction is the opposite of feature engineering, which is the process of creating new features from existing ones.

### Advantages

* Dimensionality reduction can help to reduce the complexity of a model, making it easier to interpret and use.
* It can reduce the time needed to train a model, as fewer variables will need to be considered.
* It can improve the accuracy of a model, as less noise will be present in the data.

### Disadvantages

* Dimensionality reduction can lead to the loss of important information in the data, as some variables may be discarded.
* It can be difficult to determine which variables should be kept and which should be discarded.
* It can be difficult to interpret the results of a model that has undergone dimensionality reduction.

### Applications

Dimensionality reduction is used in a variety of applications, including:

* Image processing
* Natural language processing
* Recommender systems
* Computer vision
* Speech recognition
* Robotics
* Bioinformatics
