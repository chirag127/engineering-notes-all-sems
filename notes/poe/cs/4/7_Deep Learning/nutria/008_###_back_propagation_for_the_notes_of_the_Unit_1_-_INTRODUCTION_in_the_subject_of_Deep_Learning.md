

### Back Propagation for the Notes of the Unit 1 - INTRODUCTION in the Subject of Deep Learning

Back propagation is an important concept in deep learning that allows neural networks to learn from data. It is a method of training a neural network by adjusting the weights and biases of the network to minimize the error between the predicted output and the desired output.

#### Mnemonics and Learning Tricks

One way to remember back propagation is with the acronym: “WABBA”, which stands for Weight, Adjustment, Bias, and Backpropagation.

#### How Does Back Propagation Work?

Back propagation works by first calculating the error between the predicted output and the desired output. The weights and biases of the network are then adjusted in order to minimize the error. This process is repeated until the error is minimized.

#### Advantages and Disadvantages

The main advantage of back propagation is that it is a powerful and efficient method of training neural networks. It is also relatively easy to implement and can be used with any type of neural network architecture.

The main disadvantage of back propagation is that it can be computationally expensive, as it requires a large amount of data in order to be effective. Additionally, it can be difficult to implement in large networks, as the number of weights and biases can be quite large.

#### Examples and Applications

Back propagation is used in a variety of applications, including image recognition, natural language processing, and robotics. It is also used in many machine learning algorithms, such as support vector machines, decision trees, and neural networks.

Back propagation can also be used to optimize the parameters of a model in order to improve its performance. For example, back propagation can be used to optimize the weights and biases of a neural network in order to improve its accuracy.
