
### Introduction to Machine Learning for the Notes of the Unit 1 - INTRODUCTION in the Subject of Deep Learning

Machine Learning is a branch of Artificial Intelligence (AI) that focuses on enabling computers to learn from data and to make decisions without explicit programming. It is a subfield of computer science that uses algorithms to analyze data and make predictions. 

Machine Learning can be divided into three main categories: supervised learning, unsupervised learning, and reinforcement learning. 

In supervised learning, the goal is to identify patterns in a given data set and use them to make predictions. This is done by training a model with labeled data, which is data that has been labeled with a specific outcome. The model is then used to make predictions on new data. Examples of supervised learning include classification, regression, and forecasting. 

In unsupervised learning, the goal is to understand the underlying structure of a given data set without any labels. This is done by clustering the data into groups and then using techniques such as principle component analysis to identify patterns. Examples of unsupervised learning include clustering, anomaly detection, and dimensionality reduction. 

Finally, in reinforcement learning, the goal is to enable the computer to learn from its own mistakes and to make better decisions over time. This is done by providing the computer with rewards and punishments for certain actions. Examples of reinforcement learning include game playing and robotics.

* **U**nsupervised **L**earning is about **C**lustering and **D**imensionality **R**eduction.
