
### Training a Network for the Notes of the Unit 1 - INTRODUCTION in the Subject of Deep Learning

1. **What is Training a Network?** Training a network is the process of adjusting the weights and biases of a neural network in order to improve its performance on a task. This process is typically done using a supervised learning algorithm, where the input data is labeled and the network is trained to produce the correct output for each input.

2. **What is the Goal of Training a Network?** The goal of training a network is to minimize the error between the predicted output and the desired output. This is done by adjusting the weights and biases of the network in order to reduce the error.

3. **How is Training a Network Done?** Training a network is typically done using a supervised learning algorithm such as backpropagation or stochastic gradient descent. The algorithm is used to calculate the error between the predicted output and the desired output and then adjust the weights and biases of the network in order to reduce the error.

4. **What are the Advantages of Training a Network?** Training a network has several advantages, including:
- Improved accuracy: By training a network, it is possible to improve the accuracy of the predictions made by the network.
- Reduced overfitting: Training a network can help to reduce overfitting, which occurs when a network is overly complex and produces predictions that are too specific to the training data.
- Increased generalization: Training a network can help to increase the generalization of the network, which means that it is able to make predictions on data that it has not seen before.

5. **What are the Disadvantages of Training a Network?** Training a network has some disadvantages, including:
- Time consuming: Training a network can be time consuming, as it requires a lot of data and can take a long time to train.
- Costly: Training a network can be costly, as it requires a lot of data and computing power.
- Prone to overfitting: Training a network can be prone to overfitting, as it is possible to adjust the weights and biases too much and produce predictions that are too specific to the training data.
