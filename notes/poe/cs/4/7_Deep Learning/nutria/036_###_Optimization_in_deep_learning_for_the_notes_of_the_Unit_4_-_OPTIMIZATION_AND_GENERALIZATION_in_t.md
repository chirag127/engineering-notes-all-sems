
### Optimization in Deep Learning for the Notes of Unit 4 - OPTIMIZATION AND GENERALIZATION in the Subject of Deep Learning

Optimization in deep learning is a process of adjusting the parameters of a model to minimize a loss function. It is an important process for training deep learning models, as it helps to reduce the error rate and improve the accuracy of the model. Optimization techniques used in deep learning include:

* Gradient Descent: Gradient descent is the most commonly used optimization method in deep learning. It is an iterative process that adjusts the parameters of a model to minimize the loss function.
* Stochastic Gradient Descent: Stochastic gradient descent is a variation of gradient descent which uses random samples of the data to update the parameters of the model.
* Momentum: Momentum is a technique used to increase the speed of gradient descent. It helps to reduce the oscillations of the gradient descent process and helps the model converge faster.
* Adaptive Learning Rates: Adaptive learning rates are techniques used to adjust the learning rate of a model based on the current state of the model. This helps to reduce the chances of the model getting stuck in a local minimum.

Mnemonics and Learning Tricks:

* GDM: Gradient Descent, Momentum
* SGD: Stochastic Gradient Descent
* ALR: Adaptive Learning Rates
