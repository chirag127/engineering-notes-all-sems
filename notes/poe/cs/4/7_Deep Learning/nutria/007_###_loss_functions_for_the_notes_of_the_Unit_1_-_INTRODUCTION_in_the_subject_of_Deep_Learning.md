
### Loss Functions for the Notes of the Unit 1 - INTRODUCTION in the Subject of Deep Learning

Loss functions are a crucial component of deep learning models, as they are used to optimize the model's parameters and minimize the error between the predicted output and the desired output. Loss functions can be divided into two main categories: classification and regression. 

**Classification Loss Functions**

Classification loss functions are used to optimize models for classification tasks, such as image classification, text classification, and language modeling. Common classification loss functions include the following:

* Binary Cross Entropy (BCE): This is the most commonly used classification loss function. It measures the difference between the predicted probability distribution and the true probability distribution.

* Multi-class Cross Entropy (MCE): This is used when the model has to predict multiple classes. It measures the difference between the predicted probability distribution and the true probability distribution.

* Hinge Loss: This is used for maximum-margin classification tasks, such as support vector machines. It measures the difference between the predicted class and the true class.

**Regression Loss Functions**

Regression loss functions are used to optimize models for regression tasks, such as predicting a continuous value or a probability distribution. Common regression loss functions include the following:

* Mean Squared Error (MSE): This is the most commonly used regression loss function. It measures the difference between the predicted value and the true value.

* Mean Absolute Error (MAE): This is used when the model has to predict a continuous value. It measures the difference between the predicted value and the true value.

* Log Loss: This is used when the model has to predict a probability distribution. It measures the difference between the predicted probability distribution and the true probability distribution.
