### Visually pleasing composition for the notes of the Unit 3 - Screen Designing in the subject of Human Computer Interface.

Screen designing is a crucial element in the design of a Human-Computer Interface. The screen design should be visually appealing to help the user understand the interface better. Here are some tips for creating visually pleasing compositions for your notes for Unit 3 - Screen Designing.

1. Use a Grid System: A grid system helps to create a balanced and organized layout for the screen design. It helps to align the elements of the interface and create a sense of order in the design.

2. Use a Color Scheme: A color scheme is essential in creating a visually pleasing design. It helps to create a harmonious look and feel across the interface. You can use tools like Adobe Color to select a color scheme for your interface.

3. Use White Space: White space is the empty space around the elements of the interface. It helps to create a sense of balance and clarity in the design. It also makes the interface look less cluttered and more organized.

4. Use Consistent Typography: Typography is the art of selecting and arranging typefaces. Consistent typography helps to create a unified look and feel across the interface. You can use tools like Google Fonts to select a typeface for your interface.

5. Use Visual Hierarchy: Visual hierarchy refers to the arrangement of elements in the interface in order of importance. It helps the user to understand the interface better by guiding them through the interface in a logical sequence.

6. Use Images and Icons: Images and icons are a great way to convey information quickly and effectively. They can be used to highlight important elements of the interface or to provide additional information to the user.

In conclusion, creating a visually pleasing composition for the notes of Unit 3 - Screen Designing is crucial in designing a Human-Computer Interface. By using a grid system, color scheme, white space, consistent typography, visual hierarchy, and images/icons, you can create a visually appealing design that is easy for the user to understand.
