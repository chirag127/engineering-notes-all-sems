## Unit 4 - Dynamic Programming with Examples Such as Knapsack. All Pair Shortest Paths – Warshal’s and Floyd’s Algorithms, Resource Allocation Problem. Backtracking, Branch and Bound with Examples Such as Travelling Salesman Problem, Graph Coloring, n-Queen Problem, Hamiltonian Cycles and Sum of Subsets.

Dynamic Programming is a method of solving complex problems by breaking them down into simpler subproblems and solving each subproblem only once. This technique is used to solve optimization problems, where the goal is to minimize or maximize some quantity. This unit covers various dynamic programming problems and their solutions.

### Knapsack Problem
The Knapsack Problem is a classic optimization problem where we are given a set of items, each with its own weight and value, and a knapsack with a limited capacity. The goal is to select a subset of items that maximizes the total value while keeping the total weight within the knapsack's capacity. This problem can be solved using dynamic programming by building a table of subproblems and their solutions.

### All Pair Shortest Paths – Warshal’s and Floyd’s Algorithms
The All Pair Shortest Paths problem is to find the shortest path between every pair of vertices in a given graph. Warshal’s and Floyd’s Algorithms are two popular algorithms used to solve this problem. Warshal’s algorithm is based on matrix multiplication and can be used to find the transitive closure of a given directed graph. Floyd’s algorithm is based on dynamic programming and can be used to find the shortest path between every pair of vertices in a given graph.

### Resource Allocation Problem
The Resource Allocation Problem is a classic optimization problem where we are given a set of tasks and a set of resources, each with its own cost and availability. The goal is to assign tasks to resources in a way that minimizes the total cost while satisfying all the constraints. This problem can be solved using dynamic programming by building a table of subproblems and their solutions.

### Backtracking
Backtracking is a general algorithm for finding all (or some) solutions to a problem that incrementally builds candidates to the solutions, and abandons a candidate ("backtracks") as soon as it determines that the candidate cannot possibly be completed to a valid solution. This technique can be used to solve problems such as the Travelling Salesman Problem, Graph Coloring, n-Queen Problem, Hamiltonian Cycles, and Sum of Subsets.

### Branch and Bound
Branch and Bound is a general algorithm for solving optimization problems by dividing the problem into smaller subproblems, solving each subproblem separately, and then combining the solutions to obtain the optimal solution. This technique can be used to solve problems such as the Travelling Salesman Problem, Graph Coloring, n-Queen Problem, Hamiltonian Cycles, and Sum of Subsets.

In conclusion, this unit covers various dynamic programming problems and techniques to solve them. These techniques are useful in solving optimization problems and can be applied to a wide range of real-world problems. It is important to understand the concepts and techniques covered in this unit to solve complex problems efficiently.
