### Divide and Conquer

Divide and Conquer is a problem-solving strategy used in computer science and mathematics. The approach involves breaking down a complex problem into smaller and simpler sub-problems, solving them individually, and combining the solutions to solve the original problem. This approach is widely used in various algorithms and is an important concept in the study of Design and Analysis of Algorithms.

Some examples of Divide and Conquer algorithms are:

- Searching
- Sorting
- Matrix Multiplication
- Convex Hull

#### Searching

Searching is a fundamental operation in computer science. The Divide and Conquer approach can be used to solve searching problems efficiently. The following are some examples of searching algorithms that use the Divide and Conquer approach:

- Binary Search: This algorithm works by dividing the search space in half at each step. It is a very efficient algorithm and can be used to search large arrays or lists.
- Ternary Search: This algorithm is similar to Binary search but divides the search space into three parts instead of two. It is useful when the search space is not sorted.

#### Sorting

Sorting is another important problem in computer science. The Divide and Conquer approach can be used to solve sorting problems efficiently. The following are some examples of sorting algorithms that use the Divide and Conquer approach:

- Merge Sort: This algorithm works by dividing the input array into two halves, sorting each half, and then merging the two sorted halves into a single sorted array.
- Quick Sort: This algorithm works by choosing a pivot element, dividing the input array into two sub-arrays, one containing elements smaller than the pivot and the other containing elements larger than the pivot, and then recursively sorting the two sub-arrays.

#### Matrix Multiplication

Matrix multiplication is an important operation in linear algebra. The Divide and Conquer approach can be used to solve matrix multiplication problems efficiently. The following is an example of a matrix multiplication algorithm that uses the Divide and Conquer approach:

- Strassen's Algorithm: This algorithm works by dividing the input matrices into smaller sub-matrices, performing some operations on the sub-matrices, and then combining the results to obtain the final product.

#### Convex Hull

Convex Hull is a fundamental problem in computational geometry. The Divide and Conquer approach can be used to solve the Convex Hull problem efficiently. The following is an example of a Convex Hull algorithm that uses the Divide and Conquer approach:

- Graham's Scan: This algorithm works by selecting a point on the hull, sorting the other points in increasing order of angle with the selected point, and then scanning the sorted points to add them to the hull.

### Greedy Methods

Greedy Methods is another problem-solving strategy used in computer science and mathematics. The approach involves making locally optimal choices at each step to obtain a globally optimal solution. This approach is widely used in various algorithms and is an important concept in the study of Design and Analysis of Algorithms.

Some examples of Greedy Methods algorithms are:

- Optimal Reliability Allocation
- Knapsack
- Minimum Spanning Trees – Prim’s and Kruskal’s Algorithms
- Single Source Shortest Paths - Dijkstra’s and Bellman Ford Algorithms.

#### Optimal Reliability Allocation

Optimal Reliability Allocation is a problem in system reliability engineering. The Greedy approach can be used to solve this problem efficiently. The following is an example of an algorithm that uses the Greedy approach:

- Minimum-Cut Algorithm: This algorithm works by finding the minimum cut in a graph representing the reliability of a system.

#### Knapsack

Knapsack is a problem in combinatorial optimization. The Greedy approach can be used to solve this problem efficiently. The following is an example of an algorithm that uses the Greedy approach:

- Fractional Knapsack Algorithm: This algorithm works by selecting items based on their value/weight ratio until the knapsack is full.

#### Minimum Spanning Trees

Minimum Spanning Trees is a problem in graph theory. The Greedy approach can be used to solve this problem efficiently. The following are some examples of algorithms that use the Greedy approach:

- Prim's Algorithm: This algorithm works by starting with a single vertex and adding the next closest vertex to the tree until all vertices are included.
- Kruskal's Algorithm: This algorithm works by sorting the edges by weight, adding the next smallest edge to the tree, and avoiding cycles.

#### Single Source Shortest Paths

Single Source Shortest Paths is a problem in graph theory. The Greedy approach can be used to solve this problem efficiently. The following are some examples of algorithms that use the Greedy approach:

- Dijkstra's Algorithm: This algorithm works by maintaining a set of vertices whose shortest path from the source vertex is known and gradually adding vertices to this set until all vertices are included.
- Bellman-Ford Algorithm: This algorithm works by relaxing all edges repeatedly until the shortest path is found. It can handle negative edge weights unlike Dijkstra's algorithm.
