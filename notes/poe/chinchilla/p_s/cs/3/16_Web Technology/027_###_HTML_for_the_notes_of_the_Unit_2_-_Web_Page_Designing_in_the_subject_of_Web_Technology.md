## HTML for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

HTML stands for Hypertext Markup Language. It is a markup language used to create web pages. It is the standard language used to create web pages and is the backbone of the web. In this unit, you will learn the basics of HTML and how to use it to create web pages. 

### Basics of HTML

HTML is a markup language that uses tags to structure content. A tag is a code that tells the browser how to display content. HTML tags are enclosed in angle brackets (<>) and come in pairs. The first tag is the opening tag, and the second tag is the closing tag. The content between the tags is the text or other elements that are being marked up. 

```html
<!-- Example of an HTML tag -->
<p>This is a paragraph.</p>
```

### HTML Elements

HTML elements are the building blocks of HTML pages. An HTML element is defined by a starting tag, some content, and an ending tag. The content is the information that is displayed on the web page. 

```html
<!-- Example of an HTML element -->
<h1>This is a heading</h1>
```

### HTML Attributes

HTML attributes are used to provide additional information about an HTML element. Attributes are always specified in the opening tag of an HTML element and come in name/value pairs.

```html
<!-- Example of an HTML attribute -->
<img src="image.jpg" alt="An image">
```

### HTML Structure

An HTML document consists of two parts: the head and the body. The head contains information about the document, such as the title and meta data. The body contains the content that is displayed on the web page.

```html
<!DOCTYPE html>
<html>
<head>
	<title>Page Title</title>
</head>
<body>
	<h1>This is a heading</h1>
	<p>This is a paragraph.</p>
</body>
</html>
```

### Advantages of HTML

- HTML is easy to learn and use.
- HTML is a widely used standard for web development.
- HTML allows for the creation of dynamic web pages through the use of scripts and other technologies.

### Disadvantages of HTML

- HTML can be limited in its ability to create complex web applications.
- HTML can be difficult to maintain on large websites.

### Applications of HTML

- Creating static web pages
- Developing web applications
- Designing email newsletters

In conclusion, HTML is an essential language for web page designing. It is a markup language that uses tags to structure content and is the backbone of the web. With its easy-to-learn syntax and wide array of applications, HTML is an indispensable tool for anyone interested in web development.
