### List for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

In this unit, we will learn about the basics of web page designing. Web page designing is a crucial aspect of web technology. It involves creating web pages using various technologies like HTML, CSS, and JavaScript. Let's dive into the important topics that we will cover in this unit:

1. Introduction to HTML:
   - HTML stands for HyperText Markup Language.
   - It is used to create the structure of a web page.
   - HTML uses tags to define the elements on a web page.
   - Tags are enclosed in angle brackets and have attributes that provide additional information about the element.

2. Introduction to CSS:
   - CSS stands for Cascading Style Sheets.
   - It is used to style the HTML elements on a web page.
   - CSS separates the presentation of a web page from its content.
   - CSS uses selectors to target specific HTML elements and apply styles to them.

3. Introduction to JavaScript:
   - JavaScript is a programming language used to add interactivity to web pages.
   - It can be used to create animations, validate forms, and perform other actions on a web page.
   - JavaScript code is embedded in HTML using the <script> tag.

4. Layout Design:
   - Layout design is the process of arranging the elements on a web page.
   - A good layout design should be visually appealing and easy to navigate.
   - Grid systems and flexbox are commonly used for layout design.

5. Responsive Design:
   - Responsive design is the process of designing web pages that can adapt to different screen sizes.
   - Media queries and flexible layouts are used in responsive design.

6. Accessibility:
   - Accessibility refers to the design of web pages so that they can be used by people with disabilities.
   - Web Content Accessibility Guidelines (WCAG) provide guidelines for creating accessible web pages.

In conclusion, web page designing is an essential aspect of web technology. Understanding the basics of HTML, CSS, and JavaScript is crucial for creating visually appealing and user-friendly web pages. Proper layout design, responsive design, and accessibility are also important factors that should be considered while designing web pages.
