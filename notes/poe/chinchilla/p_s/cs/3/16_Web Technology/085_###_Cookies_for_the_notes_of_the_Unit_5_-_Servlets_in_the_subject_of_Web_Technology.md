### Cookies for the notes of the Unit 5 - Servlets in the subject of Web Technology

Cookies are small text files that are stored on a user's device by a web server. They are used to store user-specific information such as preferences, shopping cart items, user authentication status, and more. Cookies are an important part of web development and are widely used by web applications to provide a personalized experience to users.

#### Working of Cookies

When a user visits a website, the web server sends a cookie to the user's browser, which stores it on the user's device. The cookie contains a key-value pair that represents the information to be stored. The browser then sends the cookie back to the server with each subsequent request, allowing the server to retrieve the information stored in the cookie.

#### Types of Cookies

There are two types of cookies:

- Session cookies: These cookies are stored in memory and are deleted when the user closes the browser. They are used to store temporary information such as items in a shopping cart or user authentication status.

- Persistent cookies: These cookies are stored on the user's device and are not deleted when the user closes the browser. They are used to store long-term information such as user preferences or browsing history.

#### Advantages of Cookies

- Personalization: Cookies allow web applications to provide a personalized experience to users by storing user-specific information.

- Efficiency: Cookies reduce the need for the server to store user-specific information, as the information can be stored on the user's device.

- Tracking: Cookies can be used to track user behavior on a website, allowing web applications to analyze user behavior and make improvements.

#### Disadvantages of Cookies

- Security: Cookies can be a security risk if they are used to store sensitive information such as passwords or credit card numbers.

- Privacy: Cookies can be used to track user behavior across multiple websites, raising privacy concerns.

#### Examples of Cookie Usage

- User authentication: Cookies can be used to store user authentication status, allowing users to remain logged in across multiple pages.

- Shopping carts: Cookies can be used to store items in a user's shopping cart, allowing users to continue shopping without losing their cart contents.

- Personalization: Cookies can be used to store user preferences such as language or theme.

#### Conclusion

Cookies are an important part of web development and are widely used by web applications to provide a personalized experience to users. They are used to store user-specific information such as preferences, shopping cart items, user authentication status, and more. However, they can also be a security and privacy risk if used improperly. Therefore, it is important for web developers to use cookies responsibly and with appropriate security measures in place.
