### Images for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

In web page designing, images play a crucial role in making the webpage visually appealing and attractive. Images can convey information, emotions, and ideas that may not be easily expressed through text alone. In this unit, we will learn about the use of images in web page designing.

#### Types of Images

There are various types of images that can be used in web page designing. Some of the commonly used types of images are:

- **JPEG** (Joint Photographic Experts Group): JPEG images are widely used on the web because of their small file size and high quality. They are best suited for photographs and images with a lot of detail.
- **PNG** (Portable Network Graphics): PNG images are best suited for images with transparency, such as logos and icons. They are larger in size than JPEG images but offer higher quality.
- **GIF** (Graphics Interchange Format): GIF images are best suited for simple animations and images with a limited color palette. They are smaller in size than JPEG and PNG images.

#### Image Formats

In web page designing, it is important to use the right image format for the right purpose. Some of the common image formats used in web page designing are:

- **JPEG**: Best suited for photographs and images with many colors and details.
- **PNG**: Best suited for images with transparency, such as logos and icons.
- **GIF**: Best suited for simple animations and images with a limited color palette.
- **SVG** (Scalable Vector Graphics): Best suited for images with simple shapes and lines that need to be resized without losing quality.

#### Image Optimization

Images can significantly slow down the loading time of a web page, which can negatively impact the user experience. Therefore, it is important to optimize images for the web. The following techniques can be used to optimize images:

- **Compression**: Compressing images reduces their file size without significantly affecting their quality. There are various tools available online that can be used to compress images.
- **Resizing**: Resizing images to the exact size required for the web page can significantly reduce their file size.
- **Caching**: Caching images can reduce the number of requests made to the server, which can speed up the loading time of the web page.

#### Image Accessibility

It is important to make images accessible to users with disabilities. The following techniques can be used to make images accessible:

- **Alt Text**: Alt text provides a description of the image for users who are visually impaired or have a slow internet connection. Alt text should be descriptive and include keywords related to the image.
- **Title Attribute**: The title attribute provides additional information about the image when the user hovers over it. The title attribute should be used sparingly and only for important information.

#### Conclusion

Images play a crucial role in web page designing. By using the right type and format of images, optimizing images for the web, and making images accessible, we can create visually appealing and user-friendly web pages.
