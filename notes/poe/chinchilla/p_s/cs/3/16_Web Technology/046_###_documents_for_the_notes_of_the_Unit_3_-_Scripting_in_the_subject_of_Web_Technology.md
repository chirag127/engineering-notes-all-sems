### Documents for the Notes of Unit 3 - Scripting in the Subject of Web Technology

Documentation is an essential part of any project, especially in the field of web technology. In this unit, we will learn about the different types of documents that are required for scripting in the subject of web technology. Here are some important points to keep in mind:

1. **Functional Requirements Document (FRD):** This document describes the functionalities that a script should perform. It includes the user requirements and specifications of the project. It also outlines the scope of the project and the constraints that should be considered while developing the script.

2. **Technical Design Document (TDD):** This document explains the technical architecture of the script. It includes the database design, system flow diagram, and data flow diagram. The TDD also outlines the coding standards and the programming languages that will be used to develop the script.

3. **Test Plan Document (TPD):** This document describes the testing strategy for the script. It includes the test cases that will be used to check the functionality of the script. It also outlines the testing environment and the testing tools that will be used for testing.

4. **User Manual Document (UMD):** This document is created for the end-users of the script. It includes step-by-step instructions on how to use the script. It also includes screenshots and diagrams to make it easy for the user to understand the functionality of the script.

5. **Maintenance Document (MD):** This document outlines the maintenance procedures for the script. It includes the procedures for updating the script, fixing bugs, and adding new features to the script.

Advantages of Documentation:

- Documentation helps to maintain the quality of the script.
- It helps to keep track of the project and makes it easy for developers to understand the functionality of the script.
- Documentation helps to reduce the development time and cost of the project.
- It makes it easy for new developers to understand the code and make changes to it.

Disadvantages of Documentation:

- Documentation can be time-consuming and costly.
- It can become outdated quickly if not maintained regularly.
- It can be difficult to keep the documentation up-to-date if there are frequent changes to the project.

Examples of Scripts:

- JavaScript for adding interactivity to web pages.
- PHP for server-side scripting.
- Python for data analysis and web development.

Applications of Scripting:

- Creating dynamic web pages.
- Automating tasks on the web.
- Developing web applications.

In conclusion, documentation is an essential part of scripting in web technology. It helps to maintain the quality of the script and makes it easy for developers to understand the functionality of the script. It's necessary to create different types of documents like FRD, TDD, TPD, UMD, and MD to ensure the success of the project.
