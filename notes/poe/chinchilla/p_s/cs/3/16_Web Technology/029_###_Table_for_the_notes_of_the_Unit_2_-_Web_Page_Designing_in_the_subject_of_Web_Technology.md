### Table for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

Web page designing is a crucial aspect of web technology. It is the process of creating visually appealing and user-friendly web pages that provide a seamless browsing experience to users. This unit focuses on the key concepts and techniques involved in web page designing. Below is a table summarizing the important points to remember:

| Topic | Description |
|-------|-------------|
| HTML | HTML stands for Hypertext Markup Language. It is used to create the structure and content of web pages. HTML tags are used to define different elements of a web page, such as headings, paragraphs, images, links, and more. |
| CSS | CSS stands for Cascading Style Sheets. It is used to define the appearance and layout of web pages. CSS can be used to change the font, color, size, and position of different elements on a web page. |
| Responsive Design | Responsive design is an approach to web page designing that ensures that web pages are optimized for different screen sizes and devices. This is achieved by using flexible layouts, images, and media queries. |
| Accessibility | Accessibility is the practice of designing web pages that are accessible to people with disabilities. This includes using alternative text for images, providing captions for videos, and using semantic HTML. |
| User Experience | User experience (UX) is the overall experience that a user has while interacting with a web page. It includes factors such as ease of use, navigation, and visual appeal. Good UX design is essential for creating a positive user experience. |

In addition to the above topics, it is important to keep in mind the following best practices for web page designing:

- Keep the design simple and uncluttered
- Use high-quality images and graphics
- Ensure fast loading times
- Use consistent branding elements
- Test the web page on different browsers and devices

By mastering the concepts and techniques covered in this unit, you will be able to create effective and visually appealing web pages that provide a positive user experience.
