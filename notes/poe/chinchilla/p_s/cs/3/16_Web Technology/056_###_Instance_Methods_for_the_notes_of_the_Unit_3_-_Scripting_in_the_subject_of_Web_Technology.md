### Instance Methods for the notes of the Unit 3 - Scripting in the subject of Web Technology

Instance methods are the methods that are defined for an instance of a class, and they operate on the data members of that instance. In this section, we will discuss some of the instance methods that are commonly used in scripting for web technologies.

1. `getElementById()`: This method is used to get a reference to an HTML element by its ID. This method returns a reference to the first element that has the specified ID.

2. `getElementsByTagName()`: This method is used to get a collection of elements with a specified tag name. This method returns a NodeList object, which is a collection of elements.

3. `getElementsByClassName()`: This method is used to get a collection of elements with a specified class name. This method returns a NodeList object, which is a collection of elements.

4. `setAttribute()`: This method is used to set the value of a specified attribute for an element. This method takes two parameters, the name of the attribute and the value to be set.

5. `getAttribute()`: This method is used to get the value of a specified attribute for an element. This method takes one parameter, the name of the attribute.

6. `removeAttribute()`: This method is used to remove a specified attribute from an element. This method takes one parameter, the name of the attribute.

7. `appendChild()`: This method is used to add a new child node to an element. This method takes one parameter, the node to be added.

8. `removeChild()`: This method is used to remove a child node from an element. This method takes one parameter, the node to be removed.

9. `replaceChild()`: This method is used to replace a child node with a new node. This method takes two parameters, the new node and the node to be replaced.

10. `addEventListener()`: This method is used to add an event listener to an element. This method takes two parameters, the name of the event and the function to be executed when the event is triggered.

These instance methods are widely used in scripting for web technologies. Understanding these methods and how to use them can greatly improve the efficiency and effectiveness of web scripting.
