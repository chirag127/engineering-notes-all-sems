### Methods & Classes for the notes of the Unit 1 - Introduction in the subject of Web Technology

In the field of web technology, methods and classes are essential components for creating dynamic and interactive web pages. Here are some of the essential methods and classes that are commonly used:

#### Methods

1. `getElementById()`: This method is used to access an element in the HTML document by its ID. It returns a reference to the element object, which can be used to manipulate the element's properties and attributes.

2. `getElementsByTagName()`: This method is used to access all elements in the HTML document with a specified tag name. It returns an array-like object called a NodeList, which can be used to manipulate the elements.

3. `createElement()`: This method is used to create a new HTML element. It takes a tag name as an argument and returns a reference to the newly created element object.

4. `appendChild()`: This method is used to add a new child node to an element. It takes a node object as an argument and appends it to the end of the list of child nodes of the parent element.

#### Classes

1. `Document`: This class represents the HTML document itself. It provides properties and methods for accessing and manipulating the document's structure and contents.

2. `Element`: This class represents an HTML element. It provides properties and methods for accessing and manipulating the element's properties and attributes.

3. `Node`: This class represents a node in the HTML document tree. It provides properties and methods for accessing and manipulating the node's properties and attributes.

4. `Event`: This class represents an event that occurs in the HTML document, such as a mouse click or a keyboard press. It provides properties and methods for accessing and manipulating the event's properties.

These methods and classes are essential building blocks for creating dynamic and interactive web pages. By learning how to use them effectively, you can create web pages that respond to user input and provide a rich and engaging user experience.
