## Unit 3 - Hadoop Eco System and YARN , no SQL databases , MongoDB , Spark , Scala

### Hadoop Eco System
- Hadoop is an open-source framework used to store and process vast amounts of data in a distributed environment
- Hadoop ecosystem consists of various components that work together to provide a complete solution for big data processing
- Some of the essential components of the Hadoop ecosystem are:
  - HDFS (Hadoop Distributed File System)
  - YARN (Yet Another Resource Negotiator)
  - MapReduce
  - Pig
  - Hive
  - HBase
  - Sqoop
  - Flume
  - Oozie
  - ZooKeeper
- Hadoop provides a scalable and fault-tolerant platform for processing and storing large datasets.


### YARN (Yet Another Resource Negotiator)
- YARN is a resource management framework in Hadoop that allows multiple data processing engines such as Spark, MapReduce, etc. to run on the same Hadoop cluster
- YARN separates the resource management and job scheduling functions of Hadoop, making it easier to manage large data sets
- YARN provides a central platform for managing resources such as CPU, memory, and disk across the Hadoop cluster


### NoSQL Databases
- NoSQL databases are non-relational databases that do not use a traditional table-based schema for storing data
- Instead of using tables, NoSQL databases use document-based, key-value, or graph-based data models
- NoSQL databases are designed to handle large volumes of unstructured data and provide high scalability, availability, and performance.


### MongoDB
- MongoDB is a popular NoSQL database that stores data in JSON-like documents with dynamic schemas
- MongoDB is designed to handle large volumes of unstructured data and provides high scalability, availability, and performance
- MongoDB supports a flexible data model, allowing the addition of new fields or changes to existing fields without impacting the application


### Spark
- Spark is a fast and general-purpose distributed computing engine that is used for large-scale data processing
- Spark provides an API for distributed data processing in Java, Scala, Python, and R
- Spark can run on top of Hadoop YARN, allowing it to leverage the resources of a Hadoop cluster
- Spark provides high performance and fault-tolerance, making it an excellent choice for processing large datasets


### Scala
- Scala is a programming language that is used for building high-performance, scalable, and distributed systems
- Scala is designed to run on the Java Virtual Machine (JVM) and is interoperable with Java code
- Scala provides advanced features such as higher-order functions, type inference, and pattern matching, making it a popular choice for building big data applications.


In conclusion, Hadoop Eco System, YARN, NoSQL Databases, MongoDB, Spark, and Scala are essential topics for understanding distributed data processing and big data analytics. These technologies provide a scalable and fault-tolerant platform for processing and storing large datasets, making them an essential part of modern data processing and analytics.
