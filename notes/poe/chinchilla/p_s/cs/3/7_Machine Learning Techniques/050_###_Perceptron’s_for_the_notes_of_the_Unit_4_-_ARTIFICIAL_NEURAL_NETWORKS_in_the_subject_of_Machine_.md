### Perceptron’s for the notes of the Unit 4 - ARTIFICIAL NEURAL NETWORKS in the subject of Machine Learning Techniques

The Perceptron is a type of artificial neural network that was introduced by Frank Rosenblatt in 1957. It is one of the simplest and oldest neural network models used for binary classification problems. The perceptron consists of a single layer of neurons, which are connected to the input layer. In this section, we will discuss the structure, working, advantages, disadvantages, and applications of the perceptron.

#### Structure of Perceptron:

The perceptron consists of the following components:

- Input layer: It is the first layer of the perceptron, which receives the input values.
- Neurons: The perceptron has a single layer of neurons, which are connected to the input layer. Each neuron has a weight and a bias associated with it.
- Activation function: The activation function is used to determine the output of each neuron. The most commonly used activation function in perceptrons is the step function.
- Output layer: The output layer consists of a single neuron that produces the final output of the perceptron.

#### Working of Perceptron:

The working of the perceptron can be explained in the following steps:

1. The input values are fed into the input layer of the perceptron.
2. Each neuron in the perceptron calculates the weighted sum of its inputs and adds a bias term to it.
3. The output of each neuron is then passed through the activation function, which produces the output of the neuron. In the case of the step function, if the weighted sum of inputs is greater than the threshold value, the output of the neuron is 1, otherwise, it is 0.
4. The output of the neurons is then combined to produce the final output of the perceptron.

#### Advantages of Perceptron:

- It is simple and easy to understand.
- It can be trained using the perceptron learning rule, which is a simple and efficient algorithm for updating the weights and biases of the neurons.
- It can be used for binary classification problems.

#### Disadvantages of Perceptron:

- It cannot handle non-linearly separable problems.
- It is not suitable for complex classification problems.

#### Applications of Perceptron:

- It can be used for image classification and recognition.
- It can be used for speech recognition.
- It can be used for pattern recognition.

In conclusion, the perceptron is a simple and efficient artificial neural network model that can be used for binary classification problems. It has advantages such as simplicity and a simple learning rule, but it also has limitations such as its inability to handle complex problems. The perceptron has various applications in image recognition, speech recognition, and pattern recognition.
