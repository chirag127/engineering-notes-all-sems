## Unit 5 - REINFORCEMENT LEARNING

Reinforcement Learning is a type of machine learning where an agent learns to behave in an environment by performing certain actions and observing the rewards it receives from those actions. It is one of the most popular machine learning techniques that has been used to solve a variety of real-world problems.

2. Markov Decision Processes (MDPs)
3. Value Functions
4. Policy Optimization
5. Q-Learning
