## Unit 4 - C++ Basics

C++ is a high-level programming language that is widely used in the development of operating systems, device drivers, game engines, and other software applications. This unit covers the fundamental concepts of C++ programming.

### Topics Covered

1. Introduction to C++ programming
2. Variables and data types
3. Operators in C++
4. Basic input/output in C++
5. Control structures: If-else, switch, loops
6. Arrays and strings
7. Functions in C++
8. Pointers and dynamic memory allocation
9. Object-oriented programming concepts: Classes and objects
10. Inheritance and polymorphism

### Learning Objectives

By the end of this unit, you should be able to:

1. Understand the basic syntax and structure of C++ programming language.
2. Create and use variables of different data types.
3. Perform basic arithmetic and logical operations using operators.
4. Use input/output statements to read and write data from/to the console.
5. Implement control structures like if-else, switch, and loops to control program flow.
6. Work with arrays and strings to store and manipulate data.
7. Define and call functions in C++.
8. Use pointers to manipulate data and allocate memory dynamically.
9. Understand the concepts of object-oriented programming and create classes and objects in C++.
10. Implement inheritance and polymorphism in C++.

### Advantages of C++

1. C++ is a powerful language that allows for low-level memory manipulation and high-performance computing.
2. It is widely used in the development of operating systems, device drivers, and other system-level software.
3. C++ supports object-oriented programming and provides features like classes, objects, inheritance, and polymorphism.
4. It is a versatile language that can be used for a wide range of applications, including game development, scientific computing, and web development.
5. C++ is a popular language with a large community of developers, which means there are many resources available for learning and troubleshooting.

### Disadvantages of C++

1. C++ is a complex language that can be difficult to learn, especially for beginners.
2. It requires a lot of coding to achieve even basic functionality, which can be time-consuming.
3. C++ programs can be harder to debug and maintain than programs written in other languages.
4. The memory management in C++ can be tricky, which can lead to memory leaks and other issues.
5. C++ code can be less portable than code written in other languages, which means it may not run on all platforms.

### Applications of C++

1. Operating systems: C++ is widely used in the development of operating systems like Windows, macOS, and Linux.
2. Game development: C++ is a popular language for game development because of its performance and memory management capabilities.
3. Scientific computing: C++ is used in scientific computing applications that require high-performance computing and low-level memory manipulation.
4. Web development: C++ can be used to develop web applications using frameworks like CGI and FastCGI.
5. System-level programming: C++ is used in the development of device drivers, embedded systems, and other system-level software.

### Example Code

```
#include <iostream>
using namespace std;

int main() {
   cout << "Hello, World!";
   return 0;
}
```

This code displays the message "Hello, World!" on the console. The `cout` statement is used to output the message, and the `return` statement is used to exit the program.
