### Object Oriented Design for the notes of the Unit 3 - Object Oriented Analysis in the subject of Object Oriented System Design

Object-oriented design is a methodology of designing a software system using objects, their attributes, and their interactions. It is a process of defining the architecture, components, modules, interfaces, and data for a system to satisfy specified requirements. Object-oriented design is a crucial stage in the development of a software system as it determines the overall structure of the system and its behavior.

#### Key concepts in Object Oriented Design

1. Abstraction: It is the process of defining the essential characteristics of an object that distinguishes it from all other kinds of objects.

2. Encapsulation: It is the process of hiding the details of an object from the outside world and exposing only the necessary information.

3. Inheritance: It is the process of creating new classes from existing classes, inheriting their attributes and behaviors.

4. Polymorphism: It is the ability of objects to take on different forms or behaviors depending upon the context in which they are used.

#### Steps in Object Oriented Design

1. Identify the classes and objects: Identify the objects and their attributes in the problem domain.

2. Define the relationships: Define the relationships between the objects, their attributes, and their behaviors.

3. Create a class diagram: Create a class diagram to represent the classes and their relationships.

4. Define the interface: Define the interface for each class to specify how the objects will interact with each other.

5. Implement the classes: Implement the classes by writing the code for each class.

6. Test the system: Test the system to ensure that it meets the requirements.

#### Advantages of Object Oriented Design

1. Reusability: Object-oriented design promotes code reusability by creating classes that can be used in multiple applications.

2. Maintainability: Object-oriented design makes it easier to maintain and modify the code as the system evolves.

3. Modularization: Object-oriented design promotes modularization, which makes it easier to test and debug the code.

4. Encapsulation: Object-oriented design promotes encapsulation, which protects the data and prevents unauthorized access.

#### Disadvantages of Object Oriented Design

1. Complexity: Object-oriented design can become complex as the number of classes and their relationships increases.

2. Overhead: Object-oriented design can result in overhead due to the creation of multiple objects.

3. Performance: Object-oriented design can impact performance due to the overhead and complexity.

#### Examples of Object Oriented Design

1. Banking system: A banking system can be designed using object-oriented design by creating classes for customers, accounts, and transactions.

2. Online shopping: An online shopping system can be designed using object-oriented design by creating classes for customers, products, and orders.

#### Applications of Object Oriented Design

1. Software development: Object-oriented design is widely used in software development to create robust and maintainable code.

2. Game development: Object-oriented design is used in game development to create complex and interactive games.

3. Web development: Object-oriented design is used in web development to create scalable and maintainable web applications.

In conclusion, object-oriented design is a crucial stage in the development of a software system as it determines the overall structure of the system and its behavior. It is a methodology of designing a software system using objects, their attributes, and their interactions. Object-oriented design promotes reusability, maintainability, and modularization, but can become complex and impact performance. It is widely used in software development, game development, and web development.
