### Procedural v/s OOP for the notes of the Unit 3 - Object Oriented Analysis in the subject of Object Oriented System Design

In the world of programming, two common methodologies are widely used: Procedural and Object-Oriented Programming (OOP). Both the methodologies have their own advantages and disadvantages. In this unit, we will discuss the differences between procedural and OOP, and which one is better suited for Object-Oriented System Design.

#### Procedural Programming:

Procedural programming is a traditional programming methodology that follows a step-by-step approach. In this methodology, the program is divided into smaller modules, where each module performs a specific task. These modules are called procedures or functions. 

##### Advantages of Procedural Programming:

- It is easy to learn and understand
- It is easy to maintain and modify the code
- It is efficient in terms of memory and processing

##### Disadvantages of Procedural Programming:

- It is not suitable for a large and complex system
- It is difficult to reuse the code
- It is difficult to implement data hiding and encapsulation

#### Object-Oriented Programming:

Object-Oriented Programming (OOP) is a modern programming methodology that is based on the concept of objects. An object is an instance of a class that contains data and the methods that operate on the data. OOP follows the principle of data hiding, encapsulation, inheritance, and polymorphism.

##### Advantages of OOP:

- It is suitable for a large and complex system
- It is easy to reuse the code
- It provides better data hiding and encapsulation
- It provides better security and protection of data
- It supports inheritance and polymorphism

##### Disadvantages of OOP:

- It is difficult to learn and understand
- It is difficult to maintain and modify the code
- It is inefficient in terms of memory and processing

#### Conclusion:

Both procedural and OOP methodologies have their own advantages and disadvantages. However, when it comes to Object-Oriented System Design, OOP is more suitable because it provides better data hiding, encapsulation, and supports inheritance and polymorphism. OOP is also suitable for a large and complex system, which is required in Object-Oriented System Design.
