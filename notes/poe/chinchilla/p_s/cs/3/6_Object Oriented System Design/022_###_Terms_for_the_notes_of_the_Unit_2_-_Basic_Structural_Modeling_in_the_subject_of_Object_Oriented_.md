### Terms for the notes of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design

In Object Oriented System Design, Basic Structural Modeling is an important concept that helps in representing the structure of a system. It is essential to understand the terms related to this concept to develop efficient and effective software systems. Here are some key terms to keep in mind:

1. Class: A class is a blueprint or a template for creating objects. It defines the properties and behaviors of objects that belong to that class. It is a fundamental building block of object-oriented programming.

2. Object: An object is an instance of a class. It represents a real-world entity and has a state and behavior. Objects interact with each other to perform a certain task.

3. Attribute: An attribute is a data member of a class that represents the state of an object. It defines the properties of an object and can be accessed and modified by methods.

4. Method: A method is a function or a procedure that performs a specific task for an object. It defines the behavior of an object and interacts with other objects to achieve a certain goal.

5. Inheritance: Inheritance is a mechanism that allows a class to inherit the properties and methods of another class. It promotes code reuse and reduces redundancy in the code.

6. Polymorphism: Polymorphism is a concept that allows objects of different classes to be treated as if they belong to the same class. It is achieved through method overriding and method overloading.

7. Encapsulation: Encapsulation is a technique that hides the internal details of an object and provides a public interface for accessing and modifying its state. It promotes data security and enhances code maintainability.

8. Association: Association is a relationship between two or more classes that defines how they are connected. It can be one-to-one, one-to-many, or many-to-many.

9. Aggregation: Aggregation is a type of association that represents a has-a relationship. It is used when an object is composed of other objects and can exist independently.

10. Composition: Composition is a type of aggregation that represents a part-of relationship. It is used when an object is composed of other objects and cannot exist independently.

These are some of the key terms related to Basic Structural Modeling in Object Oriented System Design. Understanding these terms is essential for designing and developing efficient and effective software systems.
