### Terms for the notes of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design

Object Oriented System Design is a crucial field in computer science that deals with designing and developing software systems using the principles of Object-oriented programming. Basic Structural Modeling is an essential concept in Object Oriented System Design. In this unit, we will discuss various terms related to Basic Structural Modeling that every student must know to excel in this field.

Here are the terms related to Basic Structural Modeling:

1. Class: A class is a blueprint for creating objects. It defines the attributes and behaviors that objects of a certain type will have.

2. Object: An object is an instance of a class. It represents a specific entity of a certain type defined by the class.

3. Attribute: An attribute is a characteristic of an object, such as its name, size, color, etc.

4. Method: A method is a function defined in a class that performs a specific action on an object.

5. Inheritance: Inheritance is a mechanism that allows a new class to be based on an existing class, inheriting its attributes and methods.

6. Polymorphism: Polymorphism is the ability of an object to take on many forms. It allows objects of different classes to be treated as if they were of the same class.

7. Association: Association is a relationship between two classes where one class uses the other class.

8. Aggregation: Aggregation is a special form of association where a class is composed of one or more instances of another class.

9. Composition: Composition is a stronger form of aggregation where a class is composed of one or more instances of another class, and the instances cannot exist without the parent class.

10. Dependency: Dependency is a relationship between two classes where one class depends on the other class.

In conclusion, understanding the basic structural modeling terms is essential for designing and developing software systems using the principles of Object-oriented programming. By knowing these terms, students can create efficient and effective software systems that meet the requirements of their clients.
