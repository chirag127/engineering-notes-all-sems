### Constants for the Notes of the Unit 4 - C++ Basics in the Subject of Object Oriented System Design

In C++, constants are used to define fixed values that cannot be modified during the execution of a program. Constants can be of different data types such as integer, character, float, double, etc. In this unit, we will learn about the following topics related to constants:

1. Types of constants:
   * Integer constants
   * Floating-point constants
   * Character constants
   * String constants
   * Boolean constants

2. Defining constants:
   * Using the #define preprocessor directive
   * Using the const keyword

3. Advantages of using constants:
   * Constants make the code more readable and maintainable.
   * Constants help in avoiding errors caused by typos or accidental modification of values.
   * Constants can improve the performance of the program by allowing the compiler to optimize the code.

4. Disadvantages of using constants:
   * Constants may increase the size of the program.
   * Constants can make the code less flexible and harder to modify.
   * Constants may cause confusion if not named properly.

5. Examples of using constants:
   * Defining a constant for the value of pi: 
   ```c++
   #define PI 3.14159
   const double PI = 3.14159;
   ```
   * Defining a constant for the maximum number of elements in an array:
   ```c++
   #define MAX_SIZE 100
   const int MAX_SIZE = 100;
   ```

6. Applications of constants:
   * Constants are used in mathematical calculations.
   * Constants are used in defining limits and boundaries in programs.
   * Constants are used in defining default values for variables.

In conclusion, understanding constants is an important aspect of C++ programming. They help in writing more efficient and error-free code. By using constants, we can make our code more readable and maintainable.
