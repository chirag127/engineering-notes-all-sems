### Regression Testing for the notes of the Unit 4 - Software Testing in the subject of Software Engineering

Regression Testing is a type of software testing that is performed to ensure that changes made to the software application have not adversely affected the existing functionality of the software. It is an essential step in the software development life cycle (SDLC) and is performed after making any changes, enhancements, or bug fixes to the software application. 

The primary objective of Regression Testing is to ensure that the application still works as expected, even after the changes have been made. It involves re-executing a subset of tests that have already been performed on the software application to check if there are any new defects or issues that have been introduced due to the changes made.

Some of the key features of Regression Testing are:

- It helps to ensure that the software application continues to function as expected even after changes have been made.
- It helps to identify any defects or issues that may have been introduced due to the changes made.
- It helps to ensure that the overall quality of the software application is maintained.
- It is an essential part of the software development life cycle (SDLC) and helps to save time and money by identifying defects early in the process.

There are various types of Regression Testing that can be performed, including:

- Unit Regression Testing: This involves testing individual units of the software application to ensure that they still function correctly after changes have been made.
- Integration Regression Testing: This involves testing the integration between different units of the software application to ensure that they still function correctly after changes have been made.
- Functional Regression Testing: This involves testing the functionality of the software application to ensure that it still works as expected after changes have been made.
- Full Regression Testing: This involves executing all the tests that have been previously performed on the software application to ensure that it still works as expected after changes have been made.

Advantages of Regression Testing:

- Helps to ensure that the overall quality of the software application is maintained.
- Helps to identify defects early in the process, which can save time and money.
- Helps to ensure that the software application continues to function as expected even after changes have been made.

Disadvantages of Regression Testing:

- It can be time-consuming and costly.
- It can be difficult to determine which tests should be executed as part of the regression testing process.
- It may not be possible to automate all regression tests.

Example of Regression Testing:

Suppose a banking application is being developed, and a new feature is added that allows customers to transfer funds between accounts. After the feature has been added, the application must undergo Regression Testing to ensure that the existing functionality of the application, such as account balance calculations and transaction history, is not affected.

Applications of Regression Testing:

Regression Testing is used in various industries, including software development, healthcare, finance, and manufacturing. It is essential in any industry where changes are made to software applications or systems, and the existing functionality must be maintained.
