## Unit 1 - Introductory Concepts of Computer Networks and Physical Layer

This unit covers the basics of computer networks and the physical layer, which is the first layer of the OSI model. Here are the main topics covered in this unit:

### 1. Introduction to Computer Networks

- Definition of computer networks
- Types of computer networks (LAN, WAN, MAN, PAN)
- Advantages and disadvantages of computer networks
- Network topologies (bus, star, mesh, ring)
- Network protocols (TCP/IP, HTTP, FTP, SMTP)

### 2. Physical Layer

- Introduction to the OSI model
- Definition of the physical layer
- Functions of the physical layer
- Types of transmission media (guided and unguided)
- Transmission modes (simplex, half-duplex, full-duplex)
- Encoding techniques (NRZ, Manchester, Differential Manchester, Biphase)

### 3. Network Devices

- Network interface cards (NIC)
- Repeaters, hubs, switches, and routers
- Modems and codecs
- Wireless access points (WAP) and wireless routers

### 4. Network Addressing

- IP addressing (IPv4 and IPv6)
- Subnetting and supernetting
- Classful and classless addressing
- Network Address Translation (NAT)

### 5. Network Security

- Types of network attacks (DDoS, phishing, malware)
- Network security protocols (SSL, TLS, IPSec)
- Firewalls and intrusion detection systems (IDS)

Overall, this unit provides a solid foundation for understanding computer networks and the physical layer. By the end of this unit, students should be able to explain the basics of computer networks, understand the functions of the physical layer, and identify the different types of network devices and their functions. They should also be able to configure IP addressing and subnetting, and explain the basics of network security.
