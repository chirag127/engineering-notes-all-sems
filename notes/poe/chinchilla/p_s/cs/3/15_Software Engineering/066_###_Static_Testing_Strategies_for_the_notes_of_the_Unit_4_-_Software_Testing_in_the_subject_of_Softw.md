### Static Testing Strategies for the notes of the Unit 4 - Software Testing in the subject of Software Engineering

Static testing strategies are used to detect defects in software without executing the program. It is a cost-effective technique that can be used early in the software development process. Here are some static testing strategies that are commonly used:

1. **Code Review:** Code review is a manual technique that involves examining the source code for errors and defects. This technique helps to identify coding errors, security vulnerabilities, and design issues. Code review can be done either formally or informally.

2. **Walkthrough:** Walkthrough is a peer review process that involves a group of people who review the software documentation, design documents, and code. The purpose of walkthrough is to identify defects and ensure that the software meets the requirements.

3. **Inspection:** Inspection is a formal review process that involves a team of people who review the software documentation, design documents, and code. The purpose of inspection is to identify defects and ensure that the software meets the requirements. Inspection is more structured and formal than walkthrough.

4. **Static Analysis:** Static analysis is an automated technique that involves analyzing the code without executing the program. Static analysis tools can be used to detect coding errors, security vulnerabilities, and design issues. Static analysis can be done either manually or using automated tools.

Advantages of Static Testing Strategies:

- Early detection of defects
- Cost-effective
- Improves software quality
- Helps to identify coding errors, security vulnerabilities, and design issues

Disadvantages of Static Testing Strategies:

- Time-consuming
- Requires skilled personnel
- Cannot detect all defects

Examples of Static Testing Strategies:

- Code review using a checklist
- Walkthrough of software documentation
- Inspection of source code
- Static analysis using automated tools

Applications of Static Testing Strategies:

- Used in software development process
- Used in software maintenance process
- Used in software testing process

In conclusion, static testing strategies are an essential part of software testing. It helps to detect defects early in the software development process and improves software quality. Code review, walkthrough, inspection, and static analysis are the most commonly used static testing strategies.
