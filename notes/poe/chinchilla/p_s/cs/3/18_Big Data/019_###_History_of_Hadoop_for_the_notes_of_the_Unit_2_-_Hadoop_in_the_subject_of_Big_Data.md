### History of Hadoop

Apache Hadoop is an open-source software framework that is used to store and process big data in a distributed computing environment. It was first developed by Doug Cutting and Mike Cafarella in 2005, and was based on Google's MapReduce and Google File System (GFS) papers.

Here's a brief overview of the history of Hadoop:

- In 2006, Yahoo! was the first company to use Hadoop in production. They used it to process petabytes of data across thousands of servers.

- In 2008, Hadoop became an Apache Software Foundation (ASF) project, and was released as Apache Hadoop 0.18.0.

- In 2009, Hadoop 0.20.0 introduced support for Apache HBase, which is a NoSQL database that runs on top of Hadoop Distributed File System (HDFS).

- In 2011, Hadoop 0.20.205.0 introduced support for Apache ZooKeeper, which is a distributed coordination service that is used to manage Hadoop clusters.

- In 2012, Hadoop 1.0.0 became generally available, and included support for Apache HBase, Apache Pig, and Apache Hive.

- In 2013, Hadoop 2.0.0-alpha was released, which introduced support for Apache YARN, a new resource manager that allows Hadoop to support more applications than just MapReduce.

- In 2014, Hadoop 2.4.0 was released, which included support for Apache Tez, a new data processing engine that is optimized for complex data processing tasks.

- In 2015, Hadoop 2.7.0 was released, which included support for Apache Spark, a fast and general-purpose data processing engine that is used to process data in-memory.

- In 2017, Hadoop 3.0.0 was released, which included several new features and improvements, including support for erasure coding, a new YARN timeline service, and improved performance and scalability.

Today, Hadoop is widely used across various industries and organizations for processing and analyzing big data. Its popularity is due to its scalability, fault-tolerance, and cost-effectiveness. It has become an integral part of the big data ecosystem, and is often used in conjunction with other technologies such as Apache Spark, Apache Hive, and Apache Pig.
