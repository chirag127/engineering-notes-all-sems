### Classification for the notes of the Unit 5 - 3D INTERACTION TECHNIQUES in the subject of Augmented & Virtual Reality

In the field of Augmented and Virtual Reality (AR/VR), 3D Interaction Techniques play a crucial role in providing users with a seamless and intuitive experience. These techniques allow users to interact with virtual objects and environments in a natural and immersive way. In this section, we will discuss the classification of 3D interaction techniques that are used in AR/VR applications.

#### 1. Manipulation Techniques
Manipulation techniques allow users to manipulate virtual objects in the 3D space. These techniques include:

- Translation: Moving virtual objects in the 3D space.
- Rotation: Rotating virtual objects around a specific axis.
- Scaling: Changing the size of virtual objects.

#### 2. Selection Techniques
Selection techniques allow users to select virtual objects or parts of objects for further manipulation. These techniques include:

- Raycasting: Selecting objects by pointing at them with a virtual ray or laser.
- Gaze-based selection: Selecting objects by looking at them for a certain amount of time.
- Gesture-based selection: Selecting objects by performing specific gestures.

#### 3. Navigation Techniques
Navigation techniques allow users to move around virtual environments. These techniques include:

- Walking: Moving around a virtual environment by physically walking or using a joystick.
- Teleportation: Moving instantly to a different location in the virtual environment.
- Flying: Moving around a virtual environment in a flying mode.

#### 4. Annotation Techniques
Annotation techniques allow users to add notes or comments to virtual objects or environments. These techniques include:

- Voice-based annotation: Adding notes or comments by speaking to the virtual environment.
- Text-based annotation: Adding notes or comments by typing them in a virtual keyboard.

#### 5. Feedback Techniques
Feedback techniques provide users with feedback on their actions in the virtual environment. These techniques include:

- Haptic feedback: Providing users with a tactile sensation when they interact with virtual objects.
- Audio feedback: Providing users with audio feedback on their actions in the virtual environment.

Overall, 3D interaction techniques play a vital role in enhancing the user experience in AR/VR applications. By understanding the different types of techniques available, developers can create more intuitive and immersive experiences for users.
