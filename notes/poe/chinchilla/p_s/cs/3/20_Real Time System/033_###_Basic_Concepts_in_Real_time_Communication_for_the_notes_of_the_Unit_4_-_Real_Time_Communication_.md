### Basic Concepts in Real time Communication for the notes of the Unit 4 - Real Time Communication in the subject of Real Time System

Real-time communication is a type of communication that takes place in real-time or with minimal delay. It is used in various applications like telephony, video conferencing, and instant messaging. In this unit, we will be studying the basic concepts of real-time communication. Here are some of the basic concepts that you should know:

1. Latency: Latency is the delay between the initiation of a request and the response. In real-time communication, latency should be kept to a minimum to ensure that the communication is seamless.

2. Bandwidth: Bandwidth is the amount of data that can be transmitted over a network in a given time. The higher the bandwidth, the more data can be transmitted, which is important in real-time communication.

3. Jitter: Jitter is the variation in the latency of the data packets. In real-time communication, jitter should be minimized to ensure that the communication is smooth.

4. Quality of Service (QoS): QoS is a set of technologies that prioritize real-time communication traffic over other types of traffic on a network. This ensures that real-time communication traffic is given priority over other types of traffic, which is important for ensuring that the communication is seamless.

5. Protocols: Real-time communication protocols are used to ensure that the communication is seamless. Some of the common protocols used in real-time communication include RTP (Real-time Transport Protocol), RTSP (Real-time Streaming Protocol), and SIP (Session Initiation Protocol).

6. Codecs: Codecs are used to compress and decompress audio and video data. They are essential in real-time communication to ensure that the data can be transmitted efficiently.

7. Security: Security is an important consideration in real-time communication. Encryption and authentication are used to ensure that the communication is secure and free from eavesdropping.

In conclusion, these are some of the basic concepts that you need to know about real-time communication. Understanding these concepts is important for ensuring that you have a solid foundation in real-time communication, which is essential for various applications like telephony, video conferencing, and instant messaging.
