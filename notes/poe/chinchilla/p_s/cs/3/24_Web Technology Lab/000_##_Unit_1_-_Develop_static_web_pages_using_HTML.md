## Unit 1 - Develop static web pages using HTML

In this unit, we will learn about the basics of developing static web pages using HTML. HTML (Hypertext Markup Language) is the foundation of any website and is used to structure content on the web. By the end of this unit, you will be able to create your own web pages using HTML.

### Learning Objectives

- Understand the basics of HTML and its structure
- Create a basic HTML web page
- Use HTML tags to structure content
- Add images and links to web pages
- Understand the importance of accessibility in web development

### HTML Basics

HTML is a markup language that is used to structure content on the web. It uses tags to define the structure of a web page. HTML tags are enclosed in angle brackets (<>) and usually come in pairs, with a start tag and an end tag. The content that is enclosed by the tags is the element.

Here is an example of a basic HTML web page:

```
<!DOCTYPE html>
<html>
  <head>
    <title>My Web Page</title>
  </head>
  <body>
    <h1>Welcome to my web page</h1>
    <p>This is my first web page.</p>
  </body>
</html>
```

### HTML Tags

HTML tags are used to structure content on a web page. There are many different tags available, each with its own purpose. Here are some of the most commonly used tags:

- `<html>`: Defines the start of an HTML document
- `<head>`: Contains information about the document such as the title and links to external stylesheets
- `<title>`: Defines the title of the document
- `<body>`: Contains the content of the document
- `<h1>` to `<h6>`: Defines headings of different levels
- `<p>`: Defines a paragraph
- `<a>`: Defines a link
- `<img>`: Defines an image

### Adding Images and Links

Images and links are important elements of any web page. Here is an example of how to add an image and a link to a web page:

```
<!DOCTYPE html>
<html>
  <head>
    <title>My Web Page</title>
  </head>
  <body>
    <h1>Welcome to my web page</h1>
    <p>This is my first web page.</p>
    <a href="https://www.google.com">Click here to go to Google</a>
    <br>
    <img src="image.jpg" alt="My Image">
  </body>
</html>
```

In this example, we have added a link to Google using the `<a>` tag and an image using the `<img>` tag.

### Accessibility

Accessibility is an important consideration in web development. It ensures that web pages can be accessed by everyone, including people with disabilities. Here are some tips for creating accessible web pages:

- Use descriptive alt text for images
- Ensure that all content is accessible using a keyboard
- Use headings to structure content
- Use color contrast that is easy to read

By following these tips, you can make your web pages more accessible to everyone.
