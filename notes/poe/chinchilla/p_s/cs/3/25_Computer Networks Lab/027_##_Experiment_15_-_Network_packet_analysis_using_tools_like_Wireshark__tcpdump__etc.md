## Experiment 15 - Network packet analysis using tools like Wireshark, tcpdump, etc.

In this experiment, we will learn about network packet analysis using tools like Wireshark, tcpdump, etc. Network packet analysis is the process of capturing, analyzing, and interpreting the traffic on a network. It helps in identifying network problems, security issues, and optimizing network performance.

Tools like Wireshark and tcpdump are used for network packet analysis. Let's understand how these tools work and their advantages and disadvantages.

### Wireshark

Wireshark is a popular open-source network packet analyzer. It is used for network troubleshooting, analysis, software and protocol development, and education. Wireshark captures network traffic and displays it in a graphical user interface. It can analyze traffic from Ethernet, Wi-Fi, Bluetooth, and other networks.

Advantages of Wireshark:

- Wireshark is free and open-source.
- It can capture and analyze traffic from a wide range of networks.
- It has a user-friendly GUI that makes it easy to use.
- It supports a wide range of protocols and can decode them in real-time.
- Wireshark has powerful filtering and search capabilities that make it easy to find specific packets.

Disadvantages of Wireshark:

- Wireshark can be resource-intensive and may slow down the system.
- It requires some technical knowledge to use effectively.
- It may not be suitable for real-time analysis of large networks.

### tcpdump

tcpdump is a popular command-line network packet analyzer. It captures network traffic and displays it in a text-based format. tcpdump can analyze traffic from Ethernet, Wi-Fi, Bluetooth, and other networks.

Advantages of tcpdump:

- tcpdump is free and open-source.
- It is lightweight and does not require a GUI to run.
- It can capture and analyze traffic from a wide range of networks.
- tcpdump has powerful filtering capabilities that make it easy to find specific packets.

Disadvantages of tcpdump:

- tcpdump requires technical knowledge to use effectively.
- It has a steeper learning curve compared to Wireshark.
- It may not be suitable for real-time analysis of large networks.

Overall, network packet analysis using tools like Wireshark and tcpdump is an essential skill for network administrators, security professionals, and anyone working with networks. With the right tools and knowledge, it is possible to troubleshoot network issues, identify security threats, and optimize network performance.
