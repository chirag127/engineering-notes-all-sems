## Experiment 13 - Configuration of Router, Hub, Switch etc. (using real devices or simulators)

In this experiment, we will learn how to configure routers, hubs, switches, and other networking devices using real devices or simulators. This experiment is important for anyone studying computer networking or working in the IT industry.

### Equipment Required
- Router
- Switch
- Hub
- Ethernet cables
- Computer(s)
- Network simulator software (optional)

### Steps to Perform the Experiment
1. Connect the router, switch, and hub using Ethernet cables.
2. Connect the computers to the switch or hub using Ethernet cables.
3. Configure the IP addresses and subnet masks for each device.
4. Configure the router to connect to the internet or another network.
5. Configure the switch to manage traffic between the connected devices.
6. Configure the hub to broadcast traffic to all connected devices.

### Advantages of Using Real Devices
- Provides hands-on experience with physical equipment.
- Helps to better understand the layout and design of a network.
- Can troubleshoot physical issues such as faulty cables or ports.

### Disadvantages of Using Real Devices
- Can be expensive to purchase and maintain.
- Limited availability of equipment for large groups or classrooms.
- Can be time-consuming to set up and troubleshoot.

### Advantages of Using Simulators
- Can be more cost-effective.
- Can simulate a variety of network topologies and scenarios.
- Can be easily shared and accessed by multiple users.

### Disadvantages of Using Simulators
- May not provide the same level of hands-on experience as real devices.
- Limited to the features and capabilities of the simulator software.
- May not accurately reflect real-world network conditions.

### Examples of Networking Devices
- Router: Connects multiple networks together and manages traffic between them.
- Switch: Connects multiple devices within a network and manages traffic between them.
- Hub: Connects multiple devices within a network and broadcasts traffic to all connected devices.

### Applications of Computer Networking
- Business networks for communication and data sharing.
- Home networks for internet access and media streaming.
- Educational networks for online learning and collaboration.
- Government networks for secure communication and data storage.

In conclusion, understanding how to configure routers, hubs, switches, and other networking devices is essential for anyone working in the IT industry or studying computer networking. Whether using real devices or simulators, this experiment provides valuable hands-on experience in setting up and managing a network.
