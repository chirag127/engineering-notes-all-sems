### Experiment 9.1 - DNS

DNS or Domain Name System is a system that translates human-readable domain names into IP addresses that computers can understand. DNS is an essential part of the internet and is used by every device that connects to the internet.

In this experiment, we will learn about the DNS system and how it works. The experiment will cover the following topics:

1. Introduction to DNS: The experiment will begin with an introduction to DNS and its importance. We will learn about the structure of a domain name and the different types of DNS records.

2. Installing DNS server: Next, we will install a DNS server on a Linux machine. We will use BIND (Berkeley Internet Name Domain) as our DNS server. We will also configure the DNS server to act as a caching server to improve the DNS resolution speed.

3. Configuring DNS zones: In this section, we will learn how to configure DNS zones on the server. We will create a forward and reverse zone and add DNS records to these zones.

4. Testing DNS resolution: Finally, we will test the DNS resolution by querying the DNS server for the IP address of a domain name. We will also use the nslookup command to perform DNS queries and troubleshoot DNS resolution issues.

Some key takeaways from this experiment are:

- DNS is a critical component of the internet and is used by every device that connects to the internet.
- DNS translates human-readable domain names into IP addresses that computers can understand.
- BIND is a popular DNS server used in Linux environments.
- DNS zones are used to organize DNS records for a domain name.
- DNS caching can improve the DNS resolution speed.
- Nslookup is a useful tool for troubleshooting DNS resolution issues.

Overall, this experiment will provide a comprehensive understanding of DNS and its role in the internet. The practical experience gained from configuring and testing a DNS server will be valuable for anyone interested in network administration or cybersecurity.
