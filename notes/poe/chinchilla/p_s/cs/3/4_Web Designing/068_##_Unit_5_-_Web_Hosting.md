## Unit 5 - Web Hosting

Web hosting is the process of storing and serving website files on a server so that the website can be accessed by users through the internet. In this unit, we will learn about the different types of web hosting, how to choose a web host, and how to set up and manage a website on a web host.

### Types of Web Hosting

1. Shared Hosting - In shared hosting, multiple websites are hosted on the same server, sharing its resources such as CPU, RAM, and disk space. It is the most affordable type of web hosting, but it may have limitations on bandwidth and storage.

2. VPS Hosting - In VPS hosting, a virtual private server is created by dividing a physical server into multiple virtual servers. Each VPS has its own resources and operating system, which gives more control and flexibility to the website owner.

3. Dedicated Hosting - In dedicated hosting, the website is hosted on a physical server that is exclusively used by the website owner. It provides the highest level of performance, security, and customization, but it is also the most expensive type of web hosting.

### Choosing a Web Host

When choosing a web host, consider the following factors:

1. Reliability - Look for a web host that has a high uptime guarantee and provides reliable customer support.

2. Performance - Choose a web host that has fast server response times and provides caching and content delivery network (CDN) services.

3. Security - Make sure the web host provides SSL certificates, daily backups, and malware protection.

4. Price - Compare the pricing plans of different web hosts and choose the one that fits your budget.

### Setting up and Managing a Website on a Web Host

1. Register a domain name - Choose a domain name that is easy to remember and reflects your website's purpose.

2. Choose a web host - Sign up for a web hosting plan that meets your website's requirements.

3. Install a content management system (CMS) - Use a CMS such as WordPress, Joomla, or Drupal to create and manage your website's content.

4. Customize your website - Choose a theme, install plugins, and add content to your website.

5. Monitor and maintain your website - Regularly update your CMS, plugins, and themes to ensure security and performance. 

In conclusion, web hosting is an essential aspect of creating and managing a website. By understanding the different types of web hosting, how to choose a web host, and how to set up and manage a website on a web host, you can create a website that is reliable, fast, secure, and affordable.
