### Background for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

Cascading Style Sheets, commonly known as CSS, is a style sheet language used for describing the presentation of a document written in a markup language. CSS is used to add styling and visual appeal to web pages. In this unit, we will be discussing the concept of CSS and its importance in web designing.

Here are some important points to keep in mind:

- CSS was first introduced in 1996 and was designed to separate the presentation of a document from its content.
- CSS allows developers to create consistent styling across multiple pages of a website, making it easier to maintain and update the design.
- CSS uses a cascade mechanism to determine the style of an element. This means that if multiple styles are applied to an element, CSS will use the most specific style to determine the final style of the element.
- CSS has a wide range of selectors that allow developers to target specific elements on a web page. These selectors include class selectors, ID selectors, and attribute selectors.
- CSS can be used to control the layout of a web page, including the placement of elements and the size of the page. This allows developers to create responsive designs that look good on a range of devices.
- CSS can be applied to web pages in three ways: inline, internal, and external. Inline styles are applied directly to an element, while internal and external styles are stored in separate files and linked to the web page.
- CSS has a number of advantages over traditional styling methods, such as using HTML tags or inline styles. These advantages include better organization, easier maintenance, and improved page load times.
- Despite its advantages, CSS also has some disadvantages. One of the main disadvantages is the complexity of the language, which can make it difficult for beginners to learn.
- CSS is widely used in web design and is an essential skill for any web developer or designer. Understanding the concepts of CSS and how to apply them is crucial for creating modern, responsive websites.

In conclusion, CSS is a powerful tool for adding style and visual appeal to web pages. By understanding the concepts of CSS and how to apply them, developers and designers can create beautiful, responsive websites that look great on a range of devices.
