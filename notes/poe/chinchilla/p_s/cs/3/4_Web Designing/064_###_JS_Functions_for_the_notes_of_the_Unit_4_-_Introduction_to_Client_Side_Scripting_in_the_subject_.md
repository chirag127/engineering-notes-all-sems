### JS Functions for the notes of the Unit 4 - Introduction to Client Side Scripting in the subject of Web Designing

JavaScript functions are block of codes that are designed to perform specific tasks. They are the building blocks of JavaScript programming language. JavaScript functions are reusable code and are used to perform a specific action when called.

Functions are an important aspect of JavaScript programming as they help break down complex problems into smaller, manageable parts. Functions can be used to perform a wide range of tasks such as calculations, validation, and manipulating data. In this unit, we will be looking at some of the key features of JavaScript functions.

Here are some of the key features of JavaScript functions:

1. Function Declaration:

In JavaScript, functions can be declared using the function keyword followed by the function name and a set of parentheses. The function declaration can also include parameters and a code block that defines the function.

```
function functionName(parameters) {
  // code block
}
```

2. Function Parameters:

Function parameters are used to pass values into a function. They are defined in the function declaration and are separated by commas.

```
function functionName(parameter1, parameter2) {
  // code block
}
```

3. Function Calls:

To execute a function, we need to call it. This is done by using the function name followed by a set of parentheses with any required parameters.

```
functionName(parameter1, parameter2);
```

4. Return Statement:

The return statement is used to return a value from a function. It can be used to pass information back to the calling statement or to terminate the function.

```
function functionName() {
  return value;
}
```

5. Function Expressions:

Function expressions are functions that are assigned to variables. They can be used in the same way as regular functions.

```
const functionName = function() {
  // code block
}
```

In conclusion, JavaScript functions are an important concept in web development. They allow us to break down complex problems into smaller, more manageable parts. By understanding the key features of JavaScript functions, we can write more efficient and effective code.
