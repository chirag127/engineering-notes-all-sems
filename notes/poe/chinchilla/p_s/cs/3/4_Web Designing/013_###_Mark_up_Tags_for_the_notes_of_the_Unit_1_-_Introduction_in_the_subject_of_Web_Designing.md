### Mark up Tags for the notes of the Unit 1 - Introduction in the subject of Web Designing

In web designing, markup tags are used to structure and present the content on a web page. Markup tags are a set of instructions that define how the content should be displayed in a web browser. In this unit, we will learn about the different types of markup tags and how they are used in web designing.

#### 1. HTML Markup Tags

HTML (Hypertext Markup Language) is the standard markup language used to create web pages. HTML markup tags are used to define the structure and content of a web page. Some of the commonly used HTML markup tags are:

- `<html>`: Defines the beginning of an HTML document.
- `<head>`: Defines the head section of an HTML document.
- `<title>`: Defines the title of the document.
- `<body>`: Defines the body section of an HTML document.
- `<h1>` to `<h6>`: Defines headings of different sizes.
- `<p>`: Defines a paragraph.
- `<a>`: Defines a hyperlink.

#### 2. CSS Markup Tags

CSS (Cascading Style Sheets) is used to style and format the content on a web page. CSS markup tags are used to define the style and appearance of the content. Some of the commonly used CSS markup tags are:

- `color`: Defines the color of the text.
- `font-size`: Defines the size of the font.
- `background-color`: Defines the background color of an element.
- `margin`: Defines the margin around an element.
- `padding`: Defines the padding around an element.
- `border`: Defines the border around an element.

#### 3. JavaScript Markup Tags

JavaScript is a scripting language that is used to create interactive web pages. JavaScript markup tags are used to define the behavior of the content on a web page. Some of the commonly used JavaScript markup tags are:

- `onclick`: Defines the action to be taken when an element is clicked.
- `onmouseover`: Defines the action to be taken when the mouse is moved over an element.
- `onload`: Defines the action to be taken when the page is loaded.
- `setInterval`: Defines a function to be executed at specified intervals.

#### Advantages of Markup Tags

- Markup tags make it easier to structure and present the content on a web page.
- Markup tags make it easier to maintain and update the content on a web page.
- Markup tags make it easier to optimize the content for search engines.

#### Disadvantages of Markup Tags

- Markup tags can be complex and difficult to understand for beginners.
- Improper use of markup tags can lead to errors and compatibility issues.

#### Examples of Markup Tags

- `<html><head><title>My Title</title></head><body><h1>Hello World!</h1></body></html>`
- `color: red; font-size: 24px; background-color: yellow; margin: 10px; padding: 20px; border: 1px solid black;`
- `<button onclick="alert('Hello World!')">Click Me!</button>`
- `setInterval(myFunction, 1000);`

#### Applications of Markup Tags

Markup tags are used in various applications such as:

- Web development
- Content management systems
- E-commerce websites
- Online forums and communities

In conclusion, markup tags are an essential part of web designing as they define the structure, style, and behavior of the content on a web page. By understanding the different types of markup tags and how they are used, web designers can create effective and engaging web pages that meet the needs of their audience.
