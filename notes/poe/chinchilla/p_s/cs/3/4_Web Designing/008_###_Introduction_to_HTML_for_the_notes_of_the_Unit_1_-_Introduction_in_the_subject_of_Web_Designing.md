### Introduction to HTML for the notes of the Unit 1 - Introduction in the subject of Web Designing

HTML, which stands for HyperText Markup Language, is a programming language used to create web pages. HTML is the foundation of all web pages and it provides the structure and content of a webpage. In this unit, we will be learning about the basics of HTML and how to create simple web pages using HTML.

#### Anatomy of HTML

HTML is composed of different elements that are used to structure and display content on a webpage. Some of the basic elements of HTML are:

- **Tags:** HTML tags are used to define different elements on a webpage. Each tag has a specific purpose and is enclosed in angle brackets.
- **Attributes:** HTML attributes provide additional information about an element. They are added to the opening tag of the element and are written in the format of "attribute_name=attribute_value".
- **Content:** HTML content is the text or media that is displayed within an element.

#### Creating a Basic HTML Page

To create a basic HTML page, we need to follow these steps:

1. Open a text editor such as Notepad or Sublime Text.
2. Type the following code into the text editor:

```html
<!DOCTYPE html>
<html>
<head>
	<title>My First HTML Page</title>
</head>
<body>
	<h1>Hello, World!</h1>
	<p>This is my first HTML page.</p>
</body>
</html>
```

3. Save the file with the ".html" extension.
4. Open the file in a web browser.

#### HTML Tags

HTML tags are used to define different elements on a webpage. Here are some of the common HTML tags and their usage:

- **\<html>**: Defines the beginning and end of an HTML document.
- **\<head>**: Contains information about the document such as the title and links to external files.
- **\<title>**: Defines the title of the document, which is displayed in the browser's title bar.
- **\<body>**: Contains the visible content of the document.
- **\<h1> to \<h6>**: Defines headings of different sizes.
- **\<p>**: Defines a paragraph.
- **\<a>**: Defines a hyperlink.
- **\<img>**: Displays an image.
- **\<ul>** and **\<ol>**: Defines unordered and ordered lists respectively.
- **\<li>**: Defines a list item.

#### Advantages of HTML

- Easy to learn and use.
- Supported by all web browsers.
- Allows for easy integration with other web technologies such as CSS and JavaScript.
- Provides a standardized way to structure web content.

#### Disadvantages of HTML

- Limited in terms of dynamic content.
- Can be difficult to maintain large and complex web pages.
- Limited layout options.

#### Applications of HTML

HTML is used in a wide range of applications such as:

- Web development
- Mobile app development
- E-commerce
- Social media platforms
- Online education platforms

In conclusion, HTML is a fundamental technology used in web development. It provides the structure and content of a webpage and allows for easy integration with other web technologies. By understanding the basics of HTML, we can create simple web pages and lay the groundwork for more advanced web development.
