### Introduction to Java Script for the notes of the Unit 4 - Introduction to Client Side Scripting in the subject of Web Designing

JavaScript is a client-side scripting language that is used to create interactive and dynamic web pages. In this unit, we will learn the basics of JavaScript and its applications in web designing. 

#### What is JavaScript?

JavaScript is a programming language that is used to create interactive websites. It is a client-side scripting language, which means that it runs on the user's web browser and not on the server. JavaScript is commonly used for creating dynamic web pages, adding functionality to forms, and creating interactive effects. 

#### Advantages of Using JavaScript

- JavaScript can be used to create dynamic and interactive web pages that respond to user input.
- It is easy to learn and implement.
- JavaScript is a client-side scripting language, which means that it can be used to create web pages that do not require server interaction. 
- JavaScript is compatible with all modern web browsers.

#### Disadvantages of Using JavaScript

- JavaScript can be disabled on some web browsers, which means that some users may not be able to access certain features of a website.
- JavaScript can slow down the loading time of a web page if it is not optimized properly.

#### Examples of JavaScript Applications

- Adding interactivity to web pages, such as dropdown menus, sliders, and pop-up windows.
- Validating user input in forms to ensure that the data entered is correct.
- Creating animations and special effects on web pages.
- Creating games and interactive applications.

#### Basic Syntax of JavaScript

JavaScript code can be added to an HTML file using the `<script>` tag. Here is an example:

```html
<!DOCTYPE html>
<html>
<head>
	<title>My Website</title>
</head>
<body>
	<h1>Welcome to my website!</h1>
	<script>
		alert("Hello, world!");
	</script>
</body>
</html>
```

In the above example, the `<script>` tag is used to add JavaScript code to the HTML file. The code inside the `<script>` tags will be executed when the web page loads.
