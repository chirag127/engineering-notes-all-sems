### HTML Tags for the notes of the Unit 2 - Elements of HTML in the subject of Web Designing

HTML (Hypertext Markup Language) is the standard markup language used to create web pages. HTML tags are the building blocks of HTML documents, and they define the structure and content of a web page. In this unit, we will learn about various HTML tags that are used to create web pages.

Here are some of the most commonly used HTML tags:

1. `<html>` tag: The `<html>` tag is the root tag of an HTML document. It indicates the beginning and end of an HTML document.

2. `<head>` tag: The `<head>` tag is used to define the head section of an HTML document. It contains meta information about the document, such as the title, keywords, and description.

3. `<title>` tag: The `<title>` tag is used to define the title of the document. It is displayed in the title bar of the web browser.

4. `<body>` tag: The `<body>` tag is used to define the body section of an HTML document. It contains the main content of the web page.

5. `<h1>` to `<h6>` tags: The `<h1>` to `<h6>` tags are used to define headings in an HTML document. `<h1>` is the largest heading, and `<h6>` is the smallest.

6. `<p>` tag: The `<p>` tag is used to define paragraphs in an HTML document. It is used for text content.

7. `<img>` tag: The `<img>` tag is used to insert images into an HTML document.

8. `<a>` tag: The `<a>` tag is used to create hyperlinks in an HTML document.

9. `<ul>` and `<li>` tags: The `<ul>` and `<li>` tags are used to create unordered lists in an HTML document.

10. `<ol>` and `<li>` tags: The `<ol>` and `<li>` tags are used to create ordered lists in an HTML document.

11. `<table>` and `<tr>` tags: The `<table>` and `<tr>` tags are used to create tables in an HTML document.

12. `<form>` tag: The `<form>` tag is used to create a form in an HTML document. It contains various form elements such as text boxes, radio buttons, checkboxes, and buttons.

HTML tags are essential for creating well-structured and organized web pages. By using these tags correctly, we can create web pages that are easy to read and navigate. It is important to note that HTML tags must be used correctly to ensure that the web page is displayed correctly in different browsers.

In conclusion, HTML tags are the foundation of creating web pages. As a web designer, it is essential to have a good understanding of HTML tags to create beautiful and functional web pages.
