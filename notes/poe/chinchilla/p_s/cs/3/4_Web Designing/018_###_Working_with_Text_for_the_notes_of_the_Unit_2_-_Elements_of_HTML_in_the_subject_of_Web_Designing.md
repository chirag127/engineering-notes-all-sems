### Working with Text

In HTML, text is an important element that is used to convey information to the user. To make the text more attractive and readable, it is important to use the appropriate formatting and styling techniques. In this section, we will discuss various techniques that can be used to work with text in HTML.

#### Text Formatting

HTML provides several formatting tags that can be used to style text. Some of the commonly used formatting tags are:

- `<b>` tag: This tag is used to make the text bold.
- `<i>` tag: This tag is used to make the text italic.
- `<u>` tag: This tag is used to underline the text.
- `<strike>` tag: This tag is used to strike through the text.

#### Text Alignment

To align text in HTML, we can use the following tags:

- `<center>` tag: This tag is used to center align the text.
- `<left>` tag: This tag is used to left align the text.
- `<right>` tag: This tag is used to right align the text.
- `<justify>` tag: This tag is used to justify the text.

#### Text Size

To change the size of the text, we can use the `<font>` tag. This tag has attributes like `size` and `face` that can be used to specify the size and font of the text.

#### Text Color

To change the color of the text, we can use the `<font>` tag with the `color` attribute. This attribute takes the color value in hexadecimal format.

#### Text Links

We can create links to other web pages or resources using the `<a>` tag. This tag has an attribute `href` that specifies the URL of the resource.

#### Text Lists

HTML provides two types of lists:

- Ordered list: This list is created using the `<ol>` tag. Each item in the list is represented by the `<li>` tag.
- Unordered list: This list is created using the `<ul>` tag. Each item in the list is represented by the `<li>` tag.

#### Text Tables

HTML provides the `<table>` tag to create tables. Tables are created by combining rows and columns. Each row is represented by the `<tr>` tag and each cell in the row is represented by the `<td>` tag.

#### Text Forms

HTML provides the `<form>` tag to create forms. Forms are used to collect user input. The `<input>` tag is used to create different types of form elements like text boxes, radio buttons, checkboxes, etc.

In conclusion, working with text in HTML involves various formatting, alignment, size, color, links, lists, tables, and forms techniques. By using these techniques, we can create attractive and readable web pages.
