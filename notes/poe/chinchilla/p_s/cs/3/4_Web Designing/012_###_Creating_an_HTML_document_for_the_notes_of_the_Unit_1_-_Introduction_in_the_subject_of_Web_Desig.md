### Creating an HTML document for the notes of the Unit 1 - Introduction in the subject of Web Designing

HTML or HyperText Markup Language is a standard markup language used to create web pages. It is the building block of every website and helps in creating a structure for the content to be displayed on the website.

To create an HTML document for the notes of the Unit 1 - Introduction in the subject of Web Designing, follow the below steps:

1. Open a text editor such as Notepad, Notepad++, or Sublime Text.
2. Create a new file and save it with the .html extension.
3. Begin by writing the HTML boilerplate, which is the basic structure of an HTML document. It includes the doctype declaration, html tags, head tags, and body tags. Here's an example:

```
<!DOCTYPE html>
<html>
<head>
	<title>Unit 1 - Introduction</title>
</head>
<body>
	<h1>Unit 1 - Introduction</h1>
	<p>This is the first unit in the subject of Web Designing. In this unit, we will be learning about the basics of web designing, including HTML, CSS, and JavaScript.</p>
</body>
</html>
```

4. The title tag inside the head tag is used to define the title of the webpage, which will be displayed in the browser tab.
5. The body tag is used to define the main content of the webpage. Inside the body tag, we can add various HTML elements such as headings, paragraphs, images, links, and more to structure the content of the webpage.
6. Save the file and open it in a web browser to see how it looks.

Advantages of using HTML:

- Easy to learn and use.
- Compatible with different operating systems and web browsers.
- Provides a structure to the content, making it easy to read and understand.
- Can be used to create static as well as dynamic web pages.

Disadvantages of using HTML:

- Limited design and layout options.
- Unable to create interactive web pages without the use of CSS and JavaScript.
- Requires regular updates to keep up with new technologies and standards.

In conclusion, HTML is an essential language for web design and development. By following the above steps, you can create an HTML document for the notes of the Unit 1 - Introduction in the subject of Web Designing.
