## Unit 2 - Physical Layer

The Physical Layer is the first layer in the OSI reference model, which is responsible for transmitting raw data bits over a communication channel. It establishes and maintains the physical link between the sender and receiver devices. In this unit, we will learn about the Physical Layer in detail.

### Topics Covered in this Unit

1. Introduction to Physical Layer
2. Physical Layer Functions
3. Transmission Media
4. Data Encoding Techniques
5. Transmission Modes
6. Multiplexing Techniques
7. Transmission Impairments
8. Error Detection and Correction

### Introduction to Physical Layer

The Physical Layer is responsible for transmitting bits from the sender device to the receiver device. It defines the physical characteristics of the transmission medium, such as the type of cable or wireless medium used, the method of data transmission, etc. The primary functions of the Physical Layer are to convert the digital data into a physical signal that can be transmitted over the communication channel and to ensure the reliability of the data transmission.

### Physical Layer Functions

The following are the primary functions of the Physical Layer:

1. Signal Encoding: It converts the digital data into a physical signal that can be transmitted over the communication channel. This includes modulation, line coding, and scrambling techniques.

2. Transmission: It transmits the encoded signal over the communication channel. This includes the selection of the appropriate transmission medium, transmission modes, and multiplexing techniques.

3. Reception: It receives the transmitted signal and converts it back to digital data.

4. Signal Decoding: It decodes the received signal and performs error detection and correction.

### Transmission Media

The transmission medium is the physical path over which the data is transmitted from one device to another. The following are the types of transmission media:

1. Guided Media: It includes twisted pair cable, coaxial cable, and fiber optic cable.

2. Unguided Media: It includes radio waves, microwave, and satellite.

### Data Encoding Techniques

Data encoding techniques are used to convert the digital data into a physical signal that can be transmitted over the communication channel. The following are the types of data encoding techniques:

1. Analog-to-Digital Conversion (ADC)
2. Pulse Code Modulation (PCM)
3. Delta Modulation (DM)
4. Differential Pulse Code Modulation (DPCM)

### Transmission Modes

Transmission modes determine the direction of data flow between the sender and receiver devices. The following are the types of transmission modes:

1. Simplex Mode: In this mode, data can flow in only one direction.

2. Half-Duplex Mode: In this mode, data can flow in both directions, but not at the same time.

3. Full-Duplex Mode: In this mode, data can flow in both directions simultaneously.

### Multiplexing Techniques

Multiplexing techniques are used to transmit multiple signals over a single communication channel. The following are the types of multiplexing techniques:

1. Frequency-Division Multiplexing (FDM)
2. Time-Division Multiplexing (TDM)
3. Code-Division Multiplexing (CDM)

### Transmission Impairments

Transmission impairments are the factors that affect the quality of data transmission. The following are the types of transmission impairments:

1. Attenuation
2. Distortion
3. Noise

### Error Detection and Correction

Error detection and correction techniques are used to detect and correct errors that occur during data transmission. The following are the types of error detection and correction techniques:

1. Parity Check
2. Checksum
3. Cyclic Redundancy Check (CRC)

In conclusion, the Physical Layer is a crucial layer in the OSI reference model that is responsible for the transmission of raw data bits over a communication channel. It performs various functions such as signal encoding, transmission, reception, and signal decoding. This unit covers various topics related to the Physical Layer, including transmission media, data encoding techniques, transmission modes, multiplexing techniques, transmission impairments, and error detection and correction techniques.
