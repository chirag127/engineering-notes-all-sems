### Attribute and Data Types for the Notes of Unit 6 - Frameworks and Visualization in the Subject of Data Analytics

Data analytics is the process of analyzing and interpreting data to extract valuable insights that can be used to make informed decisions. In order to perform data analytics, it is essential to understand the various data types and attributes that are used to represent data. This unit focuses on frameworks and visualization techniques that can be used to analyze and interpret data.

#### Attributes

Attributes are the characteristics of an object or entity that can be measured or observed. In data analytics, attributes are used to define the properties of data objects. The different types of attributes are:

1. Nominal Attributes - Nominal attributes represent data that is qualitative in nature and cannot be ordered or ranked. For example, gender or color.

2. Ordinal Attributes - Ordinal attributes represent data that is qualitative in nature but can be ordered or ranked. For example, education level or customer satisfaction.

3. Interval Attributes - Interval attributes represent data that is quantitative in nature and has a fixed unit of measurement. For example, temperature or time.

4. Ratio Attributes - Ratio attributes represent data that is quantitative in nature and has a fixed unit of measurement, but also has a natural zero point. For example, weight or height.

#### Data Types

Data types are the different formats in which data can be stored, processed, and analyzed. The different types of data are:

1. Numeric Data - Numeric data represents data that is numerical in nature and can be processed mathematically. The different subtypes of numeric data are integer, floating-point, and double-precision.

2. Text Data - Text data represents data that is textual in nature and can be processed using text analysis techniques. The different subtypes of text data are character, string, and boolean.

3. Date and Time Data - Date and time data represent data that is temporal in nature and can be processed using time-series analysis techniques. The different subtypes of date and time data are date, time, and timestamp.

4. Categorical Data - Categorical data represents data that is qualitative in nature and can be processed using categorical analysis techniques. The different subtypes of categorical data are nominal and ordinal.

#### Frameworks

Frameworks are sets of rules, guidelines, and best practices that are used to organize and structure data analytics projects. The different types of frameworks are:

1. CRISP-DM - CRISP-DM (Cross Industry Standard Process for Data Mining) is a widely used framework for data analytics projects. It consists of six phases - business understanding, data understanding, data preparation, modeling, evaluation, and deployment.

2. KDD - KDD (Knowledge Discovery in Databases) is a framework that focuses on the entire process of knowledge discovery, from data selection to interpretation.

3. SEMMA - SEMMA (Sample, Explore, Modify, Model, Assess) is a framework that focuses on the data mining process, from selecting a sample to assessing the model.

#### Visualization

Visualization is the process of representing data visually using charts, graphs, and other visual aids. The different types of visualization techniques are:

1. Bar Chart - Bar chart is a graphical representation of data that uses bars to compare different categories.

2. Line Chart - Line chart is a graphical representation of data that uses lines to show changes over time.

3. Pie Chart - Pie chart is a graphical representation of data that uses slices of a circle to show proportions of a whole.

4. Scatter Plot - Scatter plot is a graphical representation of data that uses points to show the relationship between two variables.

In conclusion, understanding the different types of attributes, data types, frameworks, and visualization techniques is essential for performing data analytics. These concepts provide a foundation for analyzing and interpreting data, and can help in making informed decisions based on data insights.
