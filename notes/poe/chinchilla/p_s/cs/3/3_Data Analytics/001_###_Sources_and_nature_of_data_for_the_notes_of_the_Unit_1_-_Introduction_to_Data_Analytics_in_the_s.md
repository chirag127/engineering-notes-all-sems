### Sources and Nature of Data for the Notes of the Unit 1 - Introduction to Data Analytics in the Subject of Data Analytics

Data analytics is the process of examining data sets in order to draw conclusions about the information they contain, with the help of specialized software and systems. The first step in data analytics is to identify the sources and nature of data that will be used in the analysis. In this section, we will discuss the various sources of data and their nature that are used for the notes of Unit 1 - Introduction to Data Analytics in the subject of Data Analytics.

Sources of Data:

1. Internal Sources: Data that is generated within the organization is called internal data. This data is usually collected through various systems like ERP (Enterprise Resource Planning), CRM (Customer Relationship Management), POS (Point of Sale) systems, etc. Internal data sources provide accurate, reliable, and relevant data for the analysis.

2. External Sources: Data that is collected from outside the organization is called external data. This data is usually collected from various sources like government agencies, market research firms, social media platforms, etc. External data sources provide a broader perspective of the market and help in identifying the trends and patterns.

Nature of Data:

1. Structured Data: Data that is organized in a structured format like tables, spreadsheets, or databases is called structured data. Structured data is easy to analyze as it is well-organized and can be easily processed using data analysis tools.

2. Unstructured Data: Data that is not organized in a structured format like text, images, videos, or audio files is called unstructured data. Unstructured data is difficult to analyze as it requires advanced data analysis tools like Natural Language Processing (NLP), Image and Video Analytics, etc.

Advantages of Data Analytics:

1. Helps in making informed decisions.

2. Provides a competitive advantage.

3. Helps in identifying the trends and patterns.

4. Improves the efficiency of the organization.

Disadvantages of Data Analytics:

1. Requires a skilled workforce.

2. Data privacy and security issues.

3. Expensive data analysis tools.

Examples of Data Analytics Applications:

1. Predictive Analytics: Predictive analytics uses statistical techniques to analyze historical data and make predictions about future events.

2. Fraud Detection: Data analytics is used to identify fraudulent activities by analyzing the patterns and trends in the data.

3. Sentiment Analysis: Sentiment analysis is used to analyze the sentiment of the customers towards the products and services of the organization.

In conclusion, data analytics is a powerful tool that helps in making informed decisions, identifying trends and patterns, and improving the efficiency of the organization. The sources and nature of data play a crucial role in the analysis and the selection of appropriate data sources is important for the success of the analysis.
