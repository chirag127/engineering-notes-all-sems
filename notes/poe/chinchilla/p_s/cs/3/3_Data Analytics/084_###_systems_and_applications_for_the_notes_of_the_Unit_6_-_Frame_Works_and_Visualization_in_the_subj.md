### Systems and Applications for the Notes of Unit 6 - Frameworks and Visualization in the Subject of Data Analytics

In the field of data analytics, frameworks and visualization play a crucial role in analyzing and interpreting large datasets. Various systems and applications have been developed to aid in this process. In this section, we will discuss some of the popular systems and applications used in data analytics.

#### 1. Apache Hadoop
Apache Hadoop is a popular big data processing framework that allows distributed storage and processing of large datasets. It is an open-source framework that supports various data processing tools like MapReduce, Hive, Pig, and Spark. Hadoop is widely used in data analytics for its scalability, fault-tolerance, and easy integration with other data processing tools.

#### 2. Apache Spark
Apache Spark is a fast and general-purpose distributed computing system that is used for processing large datasets in real-time. It provides various APIs for programming in Java, Python, and Scala. Spark is widely used in data analytics for its speed, ease of use, and compatibility with various data processing tools like Hadoop, Cassandra, and Kafka.

#### 3. Tableau
Tableau is a data visualization tool that allows users to create interactive and visually appealing dashboards, reports, and charts. It provides a drag-and-drop interface for creating visualizations and supports various data sources like Excel, SQL, and cloud-based data storage. Tableau is widely used in data analytics for its ease of use, interactivity, and ability to handle large datasets.

#### 4. R Programming Language
R is a popular programming language that is widely used in data analytics for statistical computing and graphical visualization. It provides various libraries and packages for data manipulation, visualization, and modeling. R is widely used in data analytics for its ease of use, flexibility, and ability to handle large datasets.

#### 5. Python Programming Language
Python is a popular programming language that is widely used in data analytics for its simplicity, ease of use, and ability to handle large datasets. It provides various libraries and packages for data manipulation, visualization, and modeling. Python is widely used in data analytics for its compatibility with various data processing tools like Hadoop, Spark, and Cassandra.

#### 6. Power BI
Power BI is a business analytics service that provides interactive visualizations and business intelligence capabilities with an interface simple enough for end-users to create their reports and dashboards. It provides a drag-and-drop interface for creating visualizations and supports data sources like Excel, SQL, and cloud-based data storage. Power BI is widely used in data analytics for its ease of use and integration with other Microsoft technologies.

In conclusion, the systems and applications discussed above have revolutionized the field of data analytics by providing powerful tools for processing, analyzing, and visualizing large datasets. These tools have made it possible for organizations to make data-driven decisions and gain a competitive edge in the market. As a data analytics student, it is essential to have a good understanding of these systems and applications to excel in the field.
