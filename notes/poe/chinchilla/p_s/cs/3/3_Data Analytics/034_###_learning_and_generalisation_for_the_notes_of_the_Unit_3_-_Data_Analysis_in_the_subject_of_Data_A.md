### Learning and Generalisation

In data analytics, learning and generalisation are two important concepts used in machine learning models. It is important to understand these concepts to build accurate models that can make predictions on new data. In this section, we will discuss the basics of learning and generalisation.

#### Learning

Learning is the process of a model adjusting itself to the data it is trained on. In other words, a model "learns" from the data it is provided. The goal of learning is to create a model that can accurately predict outcomes on new, unseen data.

There are several types of learning, including supervised learning, unsupervised learning, and reinforcement learning. In supervised learning, the model is trained on labeled data, where the correct outcome is provided for each input. In unsupervised learning, the model is trained on unlabeled data, where the goal is to find patterns or structure in the data. In reinforcement learning, the model learns through trial and error by receiving feedback on its actions.

#### Generalisation

Generalisation is the ability of a model to make accurate predictions on new data that it has not seen before. The ultimate goal of training a model is to produce a model that can generalise well, meaning it can make accurate predictions on new data.

Overfitting and underfitting are two common issues that can affect a model's ability to generalise. Overfitting occurs when a model is too complex and learns the noise in the training data, resulting in poor performance on new data. Underfitting occurs when a model is too simple and cannot capture the underlying patterns in the data, resulting in poor performance on both the training and new data.

To avoid overfitting and underfitting, it is important to use techniques such as regularization, cross-validation, and early stopping. Regularization adds a penalty to the model's loss function to prevent it from becoming too complex. Cross-validation is a technique that allows a model to be evaluated on multiple subsets of data to ensure it can generalise well. Early stopping is a technique that stops training the model when the performance on a validation set stops improving.

#### Conclusion

Learning and generalisation are essential concepts in machine learning models used in data analytics. By understanding these concepts and applying techniques to avoid overfitting and underfitting, we can build accurate models that can make predictions on new data.
