### Physical models for the notes of the Unit 1 - Compression Techniques in the subject of Data Compression

Data compression is a technique that is widely used in various fields to reduce the size of data. It is essential to understand the physical models for the notes of the Unit 1 - Compression Techniques in the subject of Data Compression. These models are useful in understanding how data compression works and how it can be applied in various fields.

Here are some important physical models that you need to know:

1. Entropy Coding: This model is based on the concept of entropy, which measures the amount of uncertainty in a random variable. In data compression, this model is used to reduce the number of bits required to represent data by exploiting the statistical properties of the data. This model includes the Huffman coding and arithmetic coding techniques.

2. Transform Coding: This model is based on the concept of transforming the data into a new domain, where it can be efficiently compressed. In this model, the data is transformed into a frequency domain using techniques such as Discrete Fourier Transform (DFT) and Discrete Cosine Transform (DCT). This model includes the JPEG and MP3 compression techniques.

3. Predictive Coding: This model is based on the concept of predicting the next value in a sequence based on the previous values. In this model, the data is compressed by storing the difference between the predicted value and the actual value. This model includes the Delta modulation and Linear Predictive Coding (LPC) techniques.
