### Referential Integrity for the Notes of Unit 3 - Relational Database Concepts

Referential Integrity is a very important concept in relational database management systems. It is a set of rules that ensure that the relationships between tables in a database are consistent and valid. Referential integrity ensures that data is accurate and consistent across tables and helps prevent errors that can occur due to inconsistent data.

Here are some important points to keep in mind about referential integrity:

1. Referential integrity is enforced through the use of foreign keys. A foreign key is a column in one table that refers to a primary key in another table. The foreign key ensures that the data in the referencing table is consistent with the data in the referenced table.

2. Referential integrity rules can be classified into two types: cascading and non-cascading. Cascading referential integrity means that changes made to a primary key in the referenced table will be automatically reflected in the referencing table. Non-cascading referential integrity means that changes made to a primary key in the referenced table will not be reflected in the referencing table.

3. Referential integrity can be enforced at the database level or at the application level. Database-level referential integrity means that the database management system enforces the rules automatically. Application-level referential integrity means that the rules are enforced by the application code.

4. The advantages of referential integrity include improved data accuracy, improved data consistency, and reduced risk of data corruption. The disadvantages of referential integrity include increased complexity and reduced flexibility.

5. Examples of referential integrity in action include a customer table that references an order table, or an employee table that references a department table.

Overall, referential integrity is an essential concept in relational database management systems. It helps ensure that data is accurate and consistent across tables, and helps prevent errors that can occur due to inconsistent data.
