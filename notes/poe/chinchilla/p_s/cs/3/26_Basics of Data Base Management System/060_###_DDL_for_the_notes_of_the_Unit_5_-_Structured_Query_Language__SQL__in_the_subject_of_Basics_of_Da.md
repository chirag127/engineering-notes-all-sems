### DDL for the notes of the Unit 5 - Structured Query Language (SQL) in the subject of Basics of Data Base Management System

DDL stands for Data Definition Language. It is a part of SQL that is used to define and manage the structure of a database. In this unit, we will learn about the different DDL commands and the role they play in creating and modifying database objects.

Here are some of the topics that we will cover in this unit:

1. CREATE Statement: The CREATE statement is used to create new database objects such as tables, views, indexes, etc. We will learn about the syntax and different options available in the CREATE statement.

2. ALTER Statement: The ALTER statement is used to modify the structure of existing database objects. We will learn about the different options available in the ALTER statement and how it can be used to add, modify or delete columns from a table.

3. DROP Statement: The DROP statement is used to delete database objects such as tables, views, and indexes. We will learn about the syntax and different options available in the DROP statement.

4. Constraints: Constraints are used to define rules for the data that is stored in a table. We will learn about different types of constraints such as NOT NULL, UNIQUE, PRIMARY KEY, FOREIGN KEY, and CHECK.

5. Indexes: Indexes are used to improve the performance of queries by providing quick access to the data. We will learn about different types of indexes such as clustered and non-clustered indexes.

6. Views: Views are virtual tables that are created from one or more tables. We will learn about the syntax and different options available in creating views.

7. Synonyms: Synonyms are used to provide an alternative name for a database object. We will learn about the syntax and different options available in creating synonyms.

In conclusion, this unit on DDL commands is essential for understanding how to create, modify and manage the structure of a database. By mastering these commands, you will be able to create efficient and effective database systems that meet the needs of your organization.
