### Types of SQL Commands

Structured Query Language (SQL) is a standard language used to manage databases. There are several types of SQL commands that can be used to manipulate data in a database. In this section, we will discuss the different types of SQL commands that you need to know for the Basics of Database Management System exam.

1. Data Definition Language (DDL)
DDL is used to define the structure of the database. The commands included in DDL are CREATE, ALTER, and DROP. CREATE is used to create a new table or database, ALTER is used to modify the structure of an existing table or database, and DROP is used to delete a table or database.

2. Data Manipulation Language (DML)
DML is used to manipulate the data in a database. The commands included in DML are SELECT, INSERT, UPDATE, and DELETE. SELECT is used to retrieve data from a table, INSERT is used to add new data to a table, UPDATE is used to modify existing data in a table, and DELETE is used to remove data from a table.

3. Data Control Language (DCL)
DCL is used to control access to the database. The commands included in DCL are GRANT and REVOKE. GRANT is used to give permission to a user or role to access the database, and REVOKE is used to remove permission from a user or role to access the database.

4. Transaction Control Language (TCL)
TCL is used to manage transactions in a database. The commands included in TCL are COMMIT, ROLLBACK, and SAVEPOINT. COMMIT is used to make changes to the database permanent, ROLLBACK is used to undo changes made in a transaction, and SAVEPOINT is used to mark a point in a transaction where a rollback can be performed.

Knowing these SQL commands is essential for managing and manipulating data in a database. By understanding these commands, you can efficiently create, modify, and retrieve data from a database.
