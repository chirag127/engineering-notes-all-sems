## Unit 5 - Structured Query Language (SQL)

Structured Query Language (SQL) is a standard language for managing data held in Relational Database Management Systems (RDBMS). It is a language that is used to create, modify, and manage relational databases. SQL is used to store, retrieve, and manipulate data in a database. 

### SQL Syntax

SQL syntax is very simple and easy to learn, it consists of various statements that can be used to create a database, create a table, insert, update, and delete data from the table. 

### SQL Commands

SQL provides a variety of commands to deal with a relational database. Some of the commonly used commands are:

- SELECT: Used to retrieve data from one or more tables. 
- INSERT: Used to insert data into a table. 
- UPDATE: Used to modify data in a table. 
- DELETE: Used to delete data from a table. 
- CREATE: Used to create a table, database, or index. 
- ALTER: Used to modify an existing database object, such as a table. 
- DROP: Used to delete a database object, such as a table, database, or index. 

### SQL Constraints

SQL constraints are rules that are applied to the data in a table. They are used to ensure the accuracy and consistency of data in a database. 

Some of the commonly used constraints are:

- NOT NULL: Ensures that a column cannot have a NULL value. 
- UNIQUE: Ensures that all values in a column are unique. 
- PRIMARY KEY: Ensures that a column or set of columns uniquely identifies each row in a table. 
- FOREIGN KEY: Ensures that a column or set of columns in one table corresponds to a column or set of columns in another table. 
- CHECK: Ensures that the data in a column meets a specific condition. 

### SQL Joins

SQL joins are used to combine data from two or more tables. There are different types of joins such as:

- INNER JOIN: Returns only the rows that have matching values in both tables. 
- LEFT JOIN: Returns all the rows from the left table and matching rows from the right table. 
- RIGHT JOIN: Returns all the rows from the right table and matching rows from the left table. 
- FULL OUTER JOIN: Returns all the rows from both tables.

### SQL Views

SQL views are virtual tables that are created by a query. They do not store any data, but they provide a way to simplify complex queries by combining data from multiple tables into a single view. 

### Advantages of SQL

- SQL is a standard language that is widely used and supported by many database systems. 
- SQL provides a simple and easy-to-learn syntax for managing data in a database. 
- SQL allows for efficient and fast data retrieval and manipulation. 

### Disadvantages of SQL

- SQL may not be suitable for large-scale and complex data sets. 
- SQL can be slow when dealing with large amounts of data. 
- SQL requires a good understanding of database design and normalization. 

### Applications of SQL

SQL is used in a variety of applications such as:

- Web development 
- Data analysis and reporting 
- Business intelligence 
- E-commerce and online transactions 

Overall, SQL is an essential tool for managing relational databases and is widely used in various industries. Understanding SQL and its syntax, commands, constraints, joins, and views will help you create, maintain, and manipulate databases efficiently.
