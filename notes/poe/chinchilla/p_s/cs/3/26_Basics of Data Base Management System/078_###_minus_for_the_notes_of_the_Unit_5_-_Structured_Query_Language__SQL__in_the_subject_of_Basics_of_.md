### Unit 5 - Structured Query Language (SQL)

Structured Query Language (SQL) is a standard language that is used to manage relational databases. It is a powerful tool that allows users to create, modify, and manipulate data in a database. In this unit, we will learn about the basic concepts of SQL and how to use it to manage databases.

#### Introduction to SQL

SQL is a declarative language, which means that users specify what they want to do, and the database management system (DBMS) figures out how to do it. It consists of a set of commands that are used to create, modify, and query databases. Some of the basic concepts of SQL are:

- Tables: A table is a collection of data that is organized into rows and columns. Each column represents a field, and each row represents a record.
- Queries: A query is a request for data from a database. It is used to retrieve data from one or more tables.
- Statements: A statement is a command that is used to perform an action in a database. Some of the commonly used statements in SQL are SELECT, INSERT, UPDATE, and DELETE.

#### SQL Commands

SQL commands are used to perform various operations on databases. Some of the commonly used SQL commands are:

- SELECT: The SELECT statement is used to retrieve data from one or more tables in a database.
- INSERT: The INSERT statement is used to insert new data into a table.
- UPDATE: The UPDATE statement is used to modify existing data in a table.
- DELETE: The DELETE statement is used to delete data from a table.
- CREATE: The CREATE statement is used to create a new table in a database.
- ALTER: The ALTER statement is used to modify the structure of a table.
- DROP: The DROP statement is used to delete a table from a database.

#### SQL Operators

SQL operators are used to perform various operations on data in a database. Some of the commonly used SQL operators are:

- Arithmetic operators: +, -, *, /, %
- Comparison operators: =, <>, >, <, >=, <=
- Logical operators: AND, OR, NOT
- String operators: CONCAT, LIKE

#### Advantages of SQL

SQL has several advantages, such as:

- Easy to use: SQL is easy to learn and use, even for non-technical users.
- Flexible: SQL is flexible and can be used to perform a wide range of operations on databases.
- Portable: SQL is a standard language, which means that it can be used with different database management systems.
- Scalable: SQL can be used to manage databases of any size, from small to large.

#### Disadvantages of SQL

SQL has some disadvantages, such as:

- Limited functionality: SQL is designed to manage relational databases, which means that it has limited functionality when it comes to managing other types of databases.
- Security: SQL databases can be vulnerable to security threats, such as SQL injection attacks.
- Performance: SQL databases can become slow when dealing with large amounts of data.

#### Examples of SQL

Here are some examples of SQL commands:

- SELECT * FROM customers: This command retrieves all the data from the customers table.
- INSERT INTO customers (name, email) VALUES ('John Doe', 'john.doe@example.com'): This command inserts a new record into the customers table.
- UPDATE customers SET email='jane.doe@example.com' WHERE name='Jane Doe': This command updates the email address of the record with the name Jane Doe in the customers table.
- DELETE FROM customers WHERE name='John Doe': This command deletes the record with the name John Doe from the customers table.

#### Applications of SQL

SQL is used in a wide range of applications, such as:

- E-commerce websites: SQL is used to manage product catalogs, customer data, and order information.
- Banking and finance: SQL is used to manage customer accounts, transaction data, and financial information.
- Healthcare: SQL is used to manage patient data, medical records, and billing information.
- Social media: SQL is used to manage user profiles, posts, and comments.
