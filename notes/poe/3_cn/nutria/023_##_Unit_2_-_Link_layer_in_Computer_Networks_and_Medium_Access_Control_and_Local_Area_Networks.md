
## Unit 2 - Link layer in Computer Networks and Medium Access Control and Local Area Networks

* **Link Layer:** The link layer is the bottom layer of the OSI model. It provides the physical connection between two computers in a network. It also provides the data link layer protocol, which is responsible for error detection and correction, flow control, and addressing.

* **Medium Access Control (MAC):** MAC is a sub-layer of the link layer that is responsible for controlling access to the shared medium. It uses mechanisms such as Carrier Sense Multiple Access (CSMA) and Token Passing to control access.

* **Local Area Networks (LANs):** LANs are networks that are typically used within a single building or campus. They are usually high-speed networks that are used to connect computers and other devices within a single organization.

* **Mnemonics:** Mnemonics are memory aids that can be used to help remember important concepts and facts. For example, the acronym "OSI" can be used to remember the seven layers of the OSI model. 

* **Advantages of LANs:** LANs provide high-speed data transmission, increased reliability, and increased security compared to WANs. Additionally, they are relatively inexpensive to install and maintain.

* **Disadvantages of LANs:** The main disadvantage of LANs is that they are limited to a single geographical area. Additionally, they are prone to interference from other networks and devices.

* **Applications of LANs:** LANs are used in a variety of applications, including file sharing, printing, gaming, and video conferencing. They are also used to connect multiple computers within a single organization.
