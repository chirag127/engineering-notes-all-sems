
### Static and dynamic routing in cn

* **Static routing** is a type of routing protocol that requires the network administrator to manually add routes to the routing table. This type of routing protocol does not use any dynamic updates or broadcast messages to update the routing table. 

* **Dynamic routing** is a type of routing protocol that uses dynamic updates and broadcast messages to update the routing table. Dynamic routing protocols use algorithms to determine the best path for data to travel from one network to another.

* Static routing is typically used in small networks where the network topology does not change often. It is simple to configure and requires less overhead than dynamic routing protocols.

* Dynamic routing protocols are used in larger networks where the network topology changes often. Dynamic routing protocols are more complex to configure and require more overhead than static routing protocols.

* In terms of security, static routing is generally considered to be more secure than dynamic routing protocols as it does not rely on broadcasts or dynamic updates to update the routing table. 

* One of the main advantages of dynamic routing protocols is that they can quickly adapt to changes in the network topology.

* Common dynamic routing protocols include RIP (Routing Information Protocol), OSPF (Open Shortest Path First), and BGP (Border Gateway Protocol).
