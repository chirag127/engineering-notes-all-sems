
#### Protocols and Standards in Networks Architecture in Computer Networks

* **Open Systems Interconnection (OSI) Model**: The OSI model is a seven-layer reference model used to describe the functions of a network and how different protocols interact with each other. It is used to standardize the communication between different types of systems.

* **Transmission Control Protocol (TCP)**: TCP is a connection-oriented protocol used to ensure reliable data transmission over a network. It is responsible for establishing and maintaining a connection between two systems and ensuring that all data is received correctly.

* **User Datagram Protocol (UDP)**: UDP is a connectionless protocol used for transmitting data over a network. It does not guarantee reliable delivery of data and is used for applications that require low latency.

* **Internet Protocol (IP)**: IP is a network layer protocol used to route data packets between different networks. It is responsible for addressing, routing, and providing best-effort delivery of packets.

* **Address Resolution Protocol (ARP)**: ARP is a protocol used to map an IP address to a physical address (e.g. MAC address). It is used to determine the physical address of a device on a network.

* **Internet Control Message Protocol (ICMP)**: ICMP is a protocol used to send error messages and control messages between two systems. It is used to send messages such as "destination unreachable" or "echo request/reply".

* **Network Time Protocol (NTP)**: NTP is a protocol used to synchronize the clocks of two systems. It is used to ensure that all systems on a network have the same time.

* **Routing Information Protocol (RIP)**: RIP is a distance-vector routing protocol used to determine the best route for data packets to take when traveling between two networks. It is used to maintain routing tables on routers.
