

#### LAN Standards in Local Area Network

* Ethernet: Ethernet is the most common local area network (LAN) data-link protocol. It is a wired, broadcast-based protocol that operates on the physical layer of the OSI (Open Systems Interconnection) model and uses CSMA/CD (Carrier Sense Multiple Access/Collision Detection) to control access to the network. Ethernet is used to connect computers, printers, and other network devices in a LAN.

* Token Ring: Token Ring is a network protocol developed by IBM and standardized by IEEE 802.5. It is a token-passing protocol that operates on the physical layer of the OSI model. Token Ring networks use a token-passing mechanism to control access to the network.

* FDDI (Fiber Distributed Data Interface): FDDI is a protocol developed by ANSI (American National Standards Institute) that uses fiber-optic cables to transmit data over a LAN. It operates on the physical layer of the OSI model and uses a token-passing mechanism to control access to the network.

* ATM (Asynchronous Transfer Mode): ATM is a network protocol developed by ANSI that uses high-speed switching technology to transmit data over a LAN. It operates on the physical layer of the OSI model and uses a cell-based switching mechanism to control access to the network.

* Wi-Fi (Wireless Fidelity): Wi-Fi is a wireless network protocol developed by IEEE 802.11. It operates on the physical layer of the OSI model and uses CSMA/CA (Carrier Sense Multiple Access/Collision Avoidance) to control access to the network. Wi-Fi is used to connect computers, printers, and other network devices in a LAN.

* Bluetooth: Bluetooth is a wireless network protocol developed by the Bluetooth Special Interest Group (SIG). It operates on the physical layer of the OSI model and uses a frequency-hopping spread spectrum technique to control access to the network. Bluetooth is used to connect computers, printers, and other network devices in a LAN.
