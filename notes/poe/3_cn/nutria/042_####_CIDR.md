
### CIDR

CIDR stands for Classless Inter-Domain Routing. It is a way to assign IP addresses and route Internet traffic more efficiently. CIDR was introduced to replace the older system of IP address classes (A, B, C, etc.).

CIDR is based on variable-length subnet masks (VLSM). It allows for more flexible and efficient use of IP address space by allowing a single IP address to represent a range of IP addresses. This means that it is possible to assign a single IP address to a large number of devices, rather than having to assign a unique IP address to each device.

CIDR notation is used to represent a range of IP addresses. It consists of an IP address followed by a slash and a number. The number is the number of bits used for the network portion of the IP address. For example, if the IP address is 192.168.1.0 and the number is 24, the CIDR notation would be 192.168.1.0/24.

A good mnemonic for remembering CIDR notation is "slash equals slash": the slash after the IP address indicates the number of bits used for the network portion of the IP address.

CIDR provides a number of advantages over the older IP address classes. It is more efficient, as it allows for more flexibility in assigning IP addresses. It also allows for more efficient routing of Internet traffic, as it is easier to identify ranges of IP addresses that belong to the same network. Finally, it is easier to manage IP address space, as it is easier to identify which IP addresses are available for assignment.
