
#### DHCP

- **Dynamic Host Configuration Protocol (DHCP)** is a network protocol used to assign IP addresses and other network configuration parameters to devices on a network. 
- It is used to automate the process of configuring devices on a network, eliminating the need for manual configuration.
- DHCP is based on the client-server model, where a DHCP server provides configuration information to DHCP clients.
- The DHCP server maintains a pool of IP addresses and leases an IP address to a DHCP client for a specified period of time. 
- The DHCP client sends a broadcast request on the network to locate a DHCP server. 
- The DHCP server responds with an offer that includes the IP address, subnet mask, gateway address, and other information.
- The DHCP client then sends a request message to the DHCP server to accept the offer.
- Upon acceptance, the DHCP server sends an acknowledgment message to the client and the configuration process is complete.
- DHCP also provides a mechanism for clients to release their IP address and return it to the pool of available IP addresses.
- The DHCP protocol is used in most home networks, as well as in corporate networks.
