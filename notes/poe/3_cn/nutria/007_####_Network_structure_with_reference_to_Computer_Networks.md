

#### Network Structure with Reference to Computer Networks

* A network structure is a combination of hardware, software, and protocols that enable computers to communicate with each other.
* It is the foundation of any computer network, as it provides the necessary infrastructure for the exchange of data and information.
* The most common network structures are:
    * Client/Server: In this structure, one computer acts as a server, while the other computers are clients. The server provides services, such as file storage and printing, while the clients request and receive services from the server.
    * Peer-to-Peer: In this structure, all computers are equal and can act as both clients and servers. This structure is used in home networks and for file sharing.
    * Mesh: In this structure, each computer is connected to every other computer in the network. This structure is used in large networks, such as in the Internet.
* Network protocols are used to define the rules for communication between computers. The most common protocols used in computer networks are:
    * TCP/IP: Transmission Control Protocol/Internet Protocol is the most commonly used protocol in computer networks. It defines the rules for communication between computers.
    * Ethernet: This is the most common protocol used in local area networks. It defines the rules for communication between computers in a local area network.
    * Wi-Fi: This is the most common protocol used in wireless networks. It defines the rules for communication between computers in a wireless network.
* Mnemonics for Network Structure:
    * CSP: Client/Server/Peer
    * PTM: Peer-to-Peer/TCP/IP/Mesh
