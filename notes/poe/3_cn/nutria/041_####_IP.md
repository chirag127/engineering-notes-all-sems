
#### IP

* IP stands for Internet Protocol, which is a set of rules used to govern how data is exchanged over the internet. 
* It is the primary protocol used for communication between computers on a network.
* IP defines the format of packets, which are the units of data sent over the internet.
* It also defines how these packets are routed from one computer to another.
* IP is a connectionless protocol, meaning that each packet is sent independently and is not related to any other packets.
* Each packet contains the IP address of the sender and the IP address of the recipient, as well as other information such as the packet's size and type.
* IP is a layer 3 protocol and is part of the TCP/IP protocol suite.
* IP is used for both unicast and multicast communication.
* IP is an unreliable protocol, meaning that packets may be lost or arrive out of order. 
* IP is responsible for routing packets from one computer to another, using a routing table to determine the best path.
* IP is used in conjunction with other protocols such as TCP and UDP to provide reliable communication over the internet.
