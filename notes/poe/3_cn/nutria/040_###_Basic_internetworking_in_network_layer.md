
### Basic Internetworking in Network Layer

- Internetworking is the process of connecting two or more computer networks together to form an internetwork.
- Internetworking is a key component of network architecture, as it allows for the formation of a single, large network from many smaller networks.
- The network layer is responsible for providing logical addressing and routing of packets between different networks.
- The most common protocol used for internetworking at the network layer is the Internet Protocol (IP).
- IP provides a connectionless service, meaning that each packet is routed independently and can take different paths to reach its destination.
- IP also provides a best-effort delivery service, meaning that it does not guarantee delivery of packets.
- IP is used to route packets between different networks, and is the most widely used protocol for internetworking.
- Other protocols used for internetworking at the network layer include the Address Resolution Protocol (ARP), the Reverse Address Resolution Protocol (RARP), and the Internet Control Message Protocol (ICMP).
