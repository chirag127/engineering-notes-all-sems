
#### Framing in Link Layer in Computer Networks

* Framing is the process of dividing a data stream into discrete frames for the purpose of efficient transmission over the network. It is one of the main tasks of the link layer in the OSI model. 
* Frames are typically composed of a header, which contains control information, and a payload, which contains the actual data to be transmitted. 
* The header and payload are usually separated by a flag sequence, which indicates the beginning and end of the frame. 
* The header can also contain an error detection field, which is used to detect any errors that may have occurred during transmission.
* There are several types of frames used in link layer protocols, including Ethernet frames, Token Ring frames, and Point-to-Point Protocol (PPP) frames. 
* Ethernet frames are the most commonly used type of frame, and they contain a source and destination address, a type or length field, and a frame check sequence (FCS) field. 
* Token Ring frames are similar to Ethernet frames, but they contain a token field instead of an FCS field. 
* PPP frames are used for point-to-point connections and contain a control field, a protocol field, and an information field. 
* Framing is an important part of the link layer because it provides a way to divide the data stream into manageable chunks for efficient transmission. 
* It also provides a way to detect errors that may have occurred during transmission, and it helps to ensure that the data is received in the correct order. 
* Mnemonics such as "SLIP FITS" can be used to remember the types of frames used in link layer protocols. The letters stand for Ethernet, Token Ring, PPP, FDDI, and ATM, respectively.
