
### Logical addressing in network layer

- Logical addressing is the process of assigning a unique address to each device on a network. It is the most common way of addressing network devices, and it is used to identify and locate them on the network.
- Logical addressing is used to determine the path that data should take when travelling across the network. It is based on the idea of a logical topology, which is a virtual representation of the physical layout of the network.
- Logical addresses are typically assigned using one of two protocols: IP (Internet Protocol) or MAC (Media Access Control). 
- IP addresses are 32-bit numbers that are typically written as four numbers separated by periods, such as 192.168.1.1. Each number represents 8 bits of the address. 
- MAC addresses are 48-bit numbers that are typically written as 12 hexadecimal digits, such as 00-00-00-00-00-00. 
- Logical addressing is used to identify and locate devices on a network, and it is also used to control access to network resources.
- It is important to remember that the logical address of a device does not necessarily correspond to its physical location on the network.
- Logical addressing is also used for routing, which is the process of determining the best path for data to take when travelling across the network. Routers use logical addresses to determine the best path for data to take.
- Logical addressing can also be used to create virtual networks, which are networks that exist within a larger network. Virtual networks can be used to create isolated networks within a larger network, which can be used to control access to resources or to provide additional security.
- Logical addressing is an important part of network design, and it is essential for creating efficient and secure networks.
