
### File Transfer Protocol in Application Layer

* File Transfer Protocol (FTP) is an application layer protocol used for transferring files between two hosts over a Transmission Control Protocol/Internet Protocol (TCP/IP) network.
* FTP is based on a client-server model, with a control connection established between the client and server to manage the transfer of data.
* The client initiates a connection to the server and requests a file. The server then sends the file to the client.
* FTP is a connection-oriented protocol, meaning that it establishes a connection between two hosts before any data can be exchanged.
* FTP supports both text and binary files, and is able to transfer any type of file.
* FTP is an insecure protocol, as it does not use any encryption or authentication. Therefore, it is important to use secure protocols such as Secure FTP (SFTP) or Secure Shell (SSH) for secure file transfers.
* FTP is widely used for transferring files over the Internet, and is the preferred protocol for transferring large files.
* Mnemonics and learning tricks for FTP:
  * F - File Transfer
  * T - Transmission Control Protocol/Internet Protocol
  * P - Protocol
