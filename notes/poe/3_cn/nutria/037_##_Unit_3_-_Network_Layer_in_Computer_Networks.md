
## Unit 3 - Network Layer in Computer Networks

* The network layer is responsible for the delivery of packets from the source to the destination. It is responsible for providing end-to-end delivery of packets.
* It is responsible for routing packets from source to destination over multiple hops. It also provides flow control, congestion control and error control mechanisms. 
* The network layer provides logical addressing, which is used to identify the source and destination nodes in the network. 
* It also provides services such as path selection, packet fragmentation, quality of service (QoS) and virtual circuit creation.
* The network layer is responsible for the connection-oriented and connectionless services.
* The network layer protocols are responsible for establishing, maintaining and releasing the virtual circuits. 
* The network layer protocols are also responsible for error detection and correction.
* The network layer also provides routing algorithms such as distance vector, link state and path vector. 
* The network layer also provides reliability and security services.
