
### Transport Layer Protocols

* Transmission Control Protocol (TCP): TCP is a connection-oriented protocol that provides reliable communication between two hosts. It is used to establish and maintain a connection between two endpoints, and it provides flow control, error correction, and reliable data transfer. TCP is a reliable protocol, meaning it will ensure that all data is received in the same order it was sent.
* User Datagram Protocol (UDP): UDP is a connectionless protocol that provides unreliable communication between two hosts. It is used to send data quickly and efficiently, but it does not guarantee that all data will be received. UDP is an unreliable protocol, meaning it does not guarantee that all data will be received in the same order it was sent.
* Internet Control Message Protocol (ICMP): ICMP is a protocol used for network maintenance and troubleshooting. It is used to send error messages and other information about the network. ICMP is not used to transfer data, but it is used to provide feedback about the state of the network.

Mnemonics and Learning Tricks: 
* TCP: "Take Care Please"
* UDP: "Unreliable Delivery Protocol"
* ICMP: "Internet Control Message Protocol"
