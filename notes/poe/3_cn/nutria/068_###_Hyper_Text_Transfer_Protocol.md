
### Hyper Text Transfer Protocol

- Hyper Text Transfer Protocol (HTTP) is a protocol that enables communication between web servers and web clients.
- HTTP is a stateless protocol, meaning that each request is independent and does not require any information from previous requests.
- HTTP is a request-response protocol, meaning that a request is sent from the client to the server and the server responds to the request.
- HTTP uses the TCP/IP protocol for communication.
- The client sends a request to the server, and the server responds with a status code and a response message.
- The response message can be either HTML, XML, JSON, or other types of data.
- HTTP supports different methods of request such as GET, POST, PUT, DELETE, etc.
- HTTP is used to transfer data from web servers to web browsers.
- HTTP is also used for streaming audio and video, and for downloading files.
