

#### Flow Control in Link Layer in Computer Networks

* Flow control is a mechanism used in the link layer of the OSI model to control the amount of data that can be transmitted between two connected devices.
* It is used to prevent data loss due to buffer overflow.
* Flow control can be implemented in two ways:
  * Stop and Wait: In this method, the sender sends a single frame and waits for the acknowledgement from the receiver before sending the next frame.
  * Sliding Window: In this method, the sender sends multiple frames at a time and the receiver sends an acknowledgement for each frame.
* Flow control helps in ensuring reliable data transfer by providing error control, flow control and congestion control.
* Advantages of flow control:
  * Prevents data loss due to buffer overflow.
  * Ensures reliable data transfer.
  * Reduces the chances of network congestion.
* Disadvantages of flow control:
  * Slows down the data transfer rate.
  * Increases the overhead of data transmission.
* Examples of flow control:
  * Ethernet Flow Control
  * Wi-Fi Flow Control
  * ATM Flow Control
* Applications of flow control:
  * Networking
  * Telecommunication
  * Video streaming
  * Voice over IP (VoIP)
