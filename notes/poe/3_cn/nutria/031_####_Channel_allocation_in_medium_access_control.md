
#### Channel Allocation in Medium Access Control

* Channel allocation in medium access control is a process of assigning channels to different users in a shared communication medium.
* The main goal of channel allocation is to make sure that all users have access to the communication medium with minimum interference. 
* Channel allocation can be done in two ways: static and dynamic. In static channel allocation, the channels are assigned to users manually and remain unchanged during the communication session. On the other hand, in dynamic channel allocation, the channels are assigned to users automatically according to the current usage of the communication medium.
* There are several techniques used for channel allocation such as frequency division multiple access (FDMA), time division multiple access (TDMA), and code division multiple access (CDMA). 
* FDMA divides the communication medium into several frequency bands and assigns each user a different frequency band. TDMA divides the communication medium into several time slots and assigns each user a different time slot. CDMA assigns each user a unique code and allows multiple users to share the same frequency band.
* Advantages of channel allocation include improved performance, better utilization of resources, and improved reliability. Disadvantages include increased complexity, increased cost, and increased latency.
* Examples of applications of channel allocation include cellular networks, wireless networks, and satellite communication networks.
