

### Network Architecture with Reference to Computer Networks

1. Network architecture is the design of a computer network, which includes its topology, protocol and the method of connecting different nodes and communication media.
2. Network topology is the arrangement of the various elements (links, nodes, etc.) of a computer network. The most common types of network topologies are bus, star, ring, mesh, and tree.
3. Network protocols are the rules and standards that govern the communication between two or more computers. The most common network protocols are TCP/IP, HTTP, FTP, and SMTP.
4. Network media is the physical connection between two or more computers. The most common types of network media are twisted pair cables, coaxial cables, optical fibers, and wireless networks.
5. Network security is the process of protecting a computer network from unauthorized access. The most common types of network security are authentication, encryption, and firewalls.
6. Network routing is the process of forwarding data packets from one node to another in a computer network. The most common types of network routing protocols are distance vector, link state, and path vector.
7. Network management is the process of managing a computer network. The most common types of network management are network monitoring, network configuration, and network optimization.
8. Network performance is the measure of the speed and reliability of a computer network. The most common methods of measuring network performance are throughput, latency, and jitter.
9. Mnemonics can be a helpful tool for remembering concepts related to network architecture. For example, the phrase "Please Do Not Throw Sausage Pizza Away" can help remember the order of the layers of the OSI model (Physical, Data Link, Network, Transport, Session, Presentation, and Application).
