
#### Services in Networks Architecture in Computer Networks

* Layer 4 Protocols: Layer 4 protocols are responsible for providing end-to-end communication between two systems. They provide reliable data transfer and error-checking services. Examples include TCP, UDP, and SCTP. 

* Application Layer Protocols: Application layer protocols provide the interface between applications and the network. Examples include HTTP, FTP, Telnet, and SMTP. 

* Network Layer Protocols: Network layer protocols are responsible for routing of packets between two systems. Examples include IP, ICMP, and IGMP. 

* Data Link Layer Protocols: Data link layer protocols are responsible for providing reliable data transfer between two systems. Examples include Ethernet, PPP, and Token Ring. 

* Physical Layer Protocols: Physical layer protocols are responsible for encoding and decoding of data. Examples include RS-232, Ethernet, and ATM. 

* Network Security Protocols: Network security protocols are responsible for providing secure communication between two systems. Examples include SSL, SSH, and IPsec.
