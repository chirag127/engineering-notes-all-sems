
#### ICMP
- Internet Control Message Protocol (ICMP) is a protocol used by network devices to send error messages and exchange information about network conditions.
- ICMP messages are sent as part of the IP protocol and are used to troubleshoot and check the status of a network.
- ICMP messages are composed of a header, data, and checksum. The header contains the type, code, and checksum of the message, while the data contains the message payload.
- ICMP is used for various purposes, including: 
  - Echo Request/Reply: Used for ping and traceroute.
  - Destination Unreachable: Used when a packet cannot reach its destination.
  - Source Quench: Used to control network congestion.
  - Redirect: Used to inform a host of a better route to a destination.
  - Time Exceeded: Used when a packet exceeds the maximum hop count.
  - Parameter Problem: Used when there is an issue with a packet header.
- ICMP is an important part of the IP protocol and is used to diagnose and troubleshoot network problems. It is also used to measure network performance and detect potential problems.
