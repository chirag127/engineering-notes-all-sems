

#### RARP

Reverse Address Resolution Protocol (RARP) is a protocol that allows a computer to request its Internet Protocol (IP) address from a network gateway server. RARP is used in cases where the computer has no other way of obtaining its IP address, such as when a computer is first installed on a network or when a computer's IP address has been changed.

RARP is an older protocol that has largely been replaced by the more modern BOOTP and DHCP protocols, which provide more features and flexibility.

RARP works by sending a request from a computer to a gateway server. The gateway server looks up the computer's MAC address in its database, and then sends back the IP address associated with that MAC address.

Mnemonics and Learning Tricks:

- RARP stands for Reverse Address Resolution Protocol
- RARP is used when a computer needs to obtain its IP address
- RARP is an older protocol that has been replaced by BOOTP and DHCP
