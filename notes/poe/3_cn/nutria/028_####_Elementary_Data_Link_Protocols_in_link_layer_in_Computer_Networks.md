

#### Elementary Data Link Protocols in Link Layer in Computer Networks

* The link layer is the second layer of the seven-layer OSI model. It provides reliable data transmission between two devices over a physical medium. 
* Elementary Data Link Protocols (EDLP) are protocols used in the link layer to provide reliable data transmission.
* Common EDLP protocols include Ethernet, Point-to-Point Protocol (PPP), and High-Level Data Link Control (HDLC).
* Ethernet is a widely used EDLP protocol that provides reliable data transmission over a shared medium. It uses a Media Access Control (MAC) address to identify each device on the network.
* PPP is a connection-oriented protocol used to establish a point-to-point connection between two network devices. It provides authentication and encryption to ensure secure data transmission.
* HDLC is a bit-oriented protocol used to provide reliable data transmission over point-to-point links. It uses a frame structure to provide error detection and correction.
* Mnemonic for EDLP: EPHD (Ethernet, PPP, HDLC).
