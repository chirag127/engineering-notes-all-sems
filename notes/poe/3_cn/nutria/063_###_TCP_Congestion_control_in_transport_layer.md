
### TCP Congestion Control in Transport Layer

* TCP Congestion Control is a process used by the Transmission Control Protocol (TCP) to manage network congestion.
* It is a mechanism used by TCP to reduce the amount of data sent over a network at any given time.
* The goal of TCP Congestion Control is to ensure that the data is sent at a rate that does not exceed the capacity of the network and does not cause congestion.
* It does this by monitoring the amount of data sent, the amount of data received, and the amount of data lost due to congestion.
* If the amount of data sent exceeds the capacity of the network, the TCP Congestion Control algorithm will reduce the rate of data transmission.
* This is done by using a number of algorithms, such as the Additive Increase Multiplicative Decrease (AIMD) algorithm, which increases the amount of data sent by a certain amount until the network is congested and then decreases the amount of data sent by a certain amount until the network is no longer congested.
* Other algorithms, such as the Slow Start algorithm, can also be used to control the rate of data transmission.
* The TCP Congestion Control algorithm is an important part of ensuring that the data is transmitted in an efficient and reliable manner.
* It is also important for ensuring that the network is not overloaded and that the data is received in a timely manner.

Mnemonics and Learning Tricks:
* AIMD = Additive Increase Multiplicative Decrease
* SS = Slow Start
