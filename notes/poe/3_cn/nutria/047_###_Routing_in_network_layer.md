
### Routing in network layer

Routing in network layer is the process of forwarding packets of data from one network to another. It is one of the most important functions of the network layer. It is responsible for the delivery of packets from the source to the destination.

Routing algorithms are used to determine the best path for the data to travel. These algorithms use metrics such as hop count, delay, bandwidth, and cost to determine the best path.

Mnemonic: 

* **H**op **C**ount, **D**elay, **B**andwidth, **C**ost 

Advantages:

* Routing helps in efficient utilization of network resources.
* It helps in reducing congestion in the network by avoiding loops.
* It reduces the complexity of the network by providing multiple paths for data transfer.

Disadvantages:

* It requires a large amount of memory to store the routing tables.
* It is difficult to configure and manage the routing protocols.
* It is vulnerable to malicious attacks.

Examples:

* Routing protocols such as RIP, OSPF, BGP, and EIGRP are used for routing in network layer.
* Routing protocols such as VRRP and HSRP are used for redundancy and fault tolerance.

Applications:

* Routing is used in local area networks (LANs), wide area networks (WANs), and the Internet.
* It is used in wireless networks such as Wi-Fi and cellular networks.
* It is used in virtual private networks (VPNs) and cloud computing.
