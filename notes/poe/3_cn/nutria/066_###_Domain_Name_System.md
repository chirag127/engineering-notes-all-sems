
### Domain Name System

* The Domain Name System (DNS) is a hierarchical and decentralized naming system for computers, services, or any resource connected to the Internet or a private network. 
* It associates various information with domain names assigned to each of the participating entities. 
* Most prominently, it translates more readily memorized domain names to the numerical IP addresses needed for locating and identifying computer services and devices with the underlying network protocols. 
* By providing a worldwide, distributed keyword-based redirection service, the Domain Name System is an essential component of the functionality of the Internet.
* DNS is used to resolve human-readable hostnames into computer-readable IP addresses. 
* DNS is the foundation of the internet and is used to provide access to websites, email, and other services. 
* DNS is also used to protect users from malicious websites and to improve the performance of web applications.
* DNS consists of a hierarchy of domain names. 
* At the top of the hierarchy are the root domains, such as .com, .org, and .net. 
* Below the root domains are the top-level domains, such as .gov and .edu. 
* Below the top-level domains are the second-level domains, such as example.com. 
* And below the second-level domains are the third-level domains, such as www.example.com. 
* Each level is separated by a dot (.). 
* A fully qualified domain name (FQDN) is a domain name that includes all of the levels, such as www.example.com.
* DNS uses a distributed database system, which consists of many different servers located around the world. 
* When a DNS query is made, the DNS server contacts other DNS servers around the world to find the IP address associated with the domain name. 
* This process is known as DNS resolution. 
* DNS resolution is an important part of the internet infrastructure, as it allows users to access websites and other services without having to remember the IP address.
* To improve the performance of DNS resolution, many DNS servers use caching. 
* Caching stores the results of previous DNS queries so that they can be quickly retrieved when the same query is made again. 
* This reduces the amount of time required to resolve a domain name and improves the performance of web applications.
* To help users remember domain names, many people use mnemonics. 
* For example, the domain name for Google is google.com, which can be remembered by the mnemonic “googol” (a number equal to 10 to the 100th power). 
* Similarly, the domain name for Yahoo is yahoo.com, which can be remembered by the mnemonic “yahoo” (an exclamation of joy or surprise).
