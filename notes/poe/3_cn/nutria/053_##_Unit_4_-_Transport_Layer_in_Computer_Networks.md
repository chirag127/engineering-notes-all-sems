
## Unit 4 - Transport Layer in Computer Networks

The Transport Layer is the fourth layer in the seven-layer OSI model of computer networking. It is responsible for providing reliable, end-to-end communication between two peers. It provides services such as connection establishment and tear-down, flow control, segmentation, and error control.

### Mnemonics and Learning Tricks 

One way to remember the purpose of the Transport Layer is the acronym **C-F-E-E**, which stands for Connection, Flow, Error, and End-to-End. 

**Connection**: The Transport Layer is responsible for establishing and tearing down connections between two peers.

**Flow**: The Transport Layer is responsible for controlling the flow of data between two peers.

**Error**: The Transport Layer is responsible for detecting and correcting errors in the data stream.

**End-to-End**: The Transport Layer is responsible for providing reliable, end-to-end communication between two peers.

### Services 

The Transport Layer provides the following services:

* Connection establishment and tear-down 
* Flow control 
* Segmentation 
* Error control 

### Protocols 

The Transport Layer uses two main protocols to provide its services:

* Transmission Control Protocol (TCP): TCP is a connection-oriented protocol that provides reliable, end-to-end communication between two peers. 
* User Datagram Protocol (UDP): UDP is a connectionless protocol that provides unreliable, best-effort communication between two peers. 

### Advantages 

* The Transport Layer provides reliable, end-to-end communication between two peers. 
* The Transport Layer provides flow control, which prevents data from being sent too quickly. 
* The Transport Layer provides error control, which ensures that data is received correctly. 

### Disadvantages 

* The Transport Layer can be slow, as it requires more overhead than other protocols. 
* The Transport Layer can be vulnerable to attacks, as it is responsible for establishing and maintaining connections.
