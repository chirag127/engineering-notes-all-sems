
### Electronic mail in application layer

* Electronic mail (e-mail) is an application layer protocol used for exchanging messages between two or more users over the Internet.
* E-mail messages are composed of two parts: the header and the body. The header contains information about the sender and recipient, as well as the subject of the message. The body contains the actual message.
* E-mail messages are sent and received using the Simple Mail Transfer Protocol (SMTP). SMTP is a text-based protocol that is used to send and receive e-mail messages.
* E-mail messages can be sent to multiple recipients at once using the Multipurpose Internet Mail Extensions (MIME). MIME is an extension to SMTP that allows for the sending of multimedia content, such as images, audio, and video.
* E-mail messages can be encrypted using the Secure/Multipurpose Internet Mail Extensions (S/MIME). S/MIME is an extension to MIME that allows for the encryption of e-mail messages.
* E-mail messages can be stored on the server using the Post Office Protocol (POP). POP is a protocol that is used to retrieve e-mail messages from the server.
* E-mail messages can be retrieved using the Internet Message Access Protocol (IMAP). IMAP is a protocol that is used to retrieve e-mail messages from the server.
* Mnemonics and learning tricks for e-mail:
    * S - SMTP (Simple Mail Transfer Protocol)
    * M - MIME (Multipurpose Internet Mail Extensions)
    * S - S/MIME (Secure/Multipurpose Internet Mail Extensions)
    * P - POP (Post Office Protocol)
    * I - IMAP (Internet Message Access Protocol)
