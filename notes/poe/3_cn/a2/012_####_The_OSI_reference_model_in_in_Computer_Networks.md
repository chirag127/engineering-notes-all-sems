#### The OSI reference model in in Computer Networks

The OSI reference model is a conceptual framework used to describe and standardize the functions of a communications system. It's made up of seven layers, each representing a different level of abstraction.

The seven layers of the OSI model are:

1. Physical layer - deals with the physical connections between devices. It converts data into signals that can be transmitted over a network.

2. Data link layer - handles data transmission between devices. It uses MAC addresses to identify devices and performs error checking.

3. Network layer - handles routing of data between networks. It uses IP addresses to route data to the correct destination network.

4. Transport layer - ensures reliable data delivery. It uses port numbers to deliver data to the correct application.

5. Session layer - manages sessions between applications. It can establish, maintain and terminate sessions.

6. Presentation layer - handles data formatting and conversion. It converts data to a suitable format for the application layer.

7. Application layer - provides network services to applications. Examples include HTTP, FTP, SMTP, etc.

**Mnemonics:**

- Please Do Not Throw Sausage Pizza Away - for remembering the layers from bottom to top.
- All People Seem To Need Data Processing - for the functions of the layers.

**Advantages:** Provides a structured framework for networking. Divides complex functions into manageable layers with standard interfaces.

**Disadvantages:** Can be inefficient as each layer adds overhead. Not all layers are always required leading to unnecessary processing.

**Examples:** The Internet Protocol suite (TCP/IP) is the most widely used networking model which maps to the OSI model. HTTP and FTP work at the application layer. IP works at the network layer.
