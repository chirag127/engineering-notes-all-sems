#### Organization of the Internet

The Internet is organized into a hierarchical structure consisting of the following layers:

1.  **Network Access Layer:** This is the bottom layer that consists of the physical infrastructure and devices required to connect devices to the network, e.g. Ethernet cables, Wi-Fi routers, modems, etc.

2.  **Internet Layer:** This layer is responsible for packet routing between networks and hosts. It uses IP addresses to identify hosts and move packets between them. The key protocols at this layer are IP, ICMP, and IGMP.

3.  **Transport Layer:** This layer provides end-to-end connectivity between applications running on different hosts. It handles things like reliable data transmission, flow control, and congestion control. Key protocols at this layer are TCP and UDP.

4.  **Application Layer:** This is the topmost layer that consists of the actual applications and services we use, e.g. the Web, email, video streaming, etc. The protocols at this layer are HTTP, SMTP, FTP, etc.

**Mnemonics:** A mnemonic to remember the layers is ** PLEASE DO NOT THROW SAUSAGE PIZZAS AWAY **, where each word represents a layer: Physical, Link, Internet, Transport, Session, Presentation, Application.

**Advantages:** The hierarchical structure has several advantages like modular design, flexibility, and interoperability between networks and technologies. It has been crucial to the growth and wide adoption of the Internet.

**Examples and Applications:** The layered model forms the basis for the design of the Internet and networking protocols and technologies. For e.g. when you open a web page, data is transmitted between layers: Application layer (HTTP) -> Transport layer (TCP) -> Internet layer (IP) -> Network access layer (Ethernet) and so on. This layered design enables diverse networks and technologies to work together seamlessly.
