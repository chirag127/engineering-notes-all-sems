### IPv6 in cn

- IPv6 stands for Internet Protocol version 6. It is the latest version of the Internet Protocol (IP) and is designed to succeed IPv4.
- IPv6 addresses are 128-bit long, written in hexadecimal, colon-separated, and grouped into 8 groups of 4 hexadecimal digits each. For example, 2001:db8:85a3:0:0:8a2e:370:7334. This huge address space allows for many more possible unique IP addresses than IPv4.
- Some tips to remember IPv6 addresses:
-- Use leading 0s: Replace each group of 4 hex digits with a word that starts with that letter, e.g. 0:0:0:0:0:0:1347:6267 can be remembered as "Oh oh oh oh optimistic jumper".
-- Use rhyming words: Make rhyming words/phrases out of groups of hex digits, e.g. 2001:4860:4860::8888 can be remembered as "20-won racehorse was too late".
-- Use familiar numbers/words: If there are some familiar numbers/words in the address, focus on them, e.g. 2001:db8:1f70::999 can be remembered as "2001 won (db8), won 1F70, 999".

- Some advantages of IPv6 over IPv4 are:
-- Huge address space: The 128-bit address space of IPv6 allows for 3.4x10^38 unique addresses, solving the addressing exhaustion problem of IPv4.
-- Auto-configuration: IPv6 hosts can auto-configure themselves with a link-local unicast address without the need for DHCP, making network setup easier.
-- Integrated support for services: IPv6 specifications have built-in support for features like quality of service, authentication, and privacy.

- Some applications of IPv6 are:
-- Allowing many more devices to connect to the Internet as the number of devices with network connectivity grows exponentially with IoT.
-- Enabling new services like peer-to-peer and point-to-point transmissions.
-- Facilitating mobile and wireless access as mobility is a key requirement in the proliferation of portable and wireless devices.
