# Computer Networks

## Overview

- A computer network is a group of computers that are interconnected and able to communicate with each other to share resources and data.
- Networks are built with a combination of hardware and software and allow users to access shared files, programs, and other resources like printers.
- The most common types of networks are:
    - Local Area Networks (LANs): Networks covering a small physical area, like an office building or a home.
    - Wide Area Networks (WANs): Networks that cover large geographical areas, typically using telephone lines or satellites. The Internet is the largest WAN.

## Components

The main components of a computer network include:

- Network Interface Cards (NICs): These adapt the computer to the network and allow it to send and receive data.
- Network cables: Cables to connect network devices. The most common types are Ethernet and fiber optic cables.
- Routers: Direct traffic between networks and the Internet. They select the best path for transferring data packets based on network conditions and traffic.
- Switches: Connect network devices and direct traffic within a network. They use MAC addresses to forward data packets to the correct destination.
- Servers: Powerful computers that provide resources, services, and applications to other computers on the network.
- Protocols: Sets of rules that govern data communications between network devices. The main protocols for the Internet are TCP/IP.

## Learning Tips

Here are some tips to learn about computer networks:

- Understand the OSI and TCP/IP models to learn how network devices and technologies work together.
- Get hands-on experience by setting up a small home or office network. This will help understand the hardware and configuration requirements.
- Learn about key protocols like IP, Ethernet, ARP, DNS, DHCP, TCP, and UDP. Understanding how they work and interact is key to networking.
- Study concepts like routing, switching, network security, wireless networking, and network topologies.
- Use network simulation tools and technologies to experiment with different setups and technologies.
- Stay up-to-date with new advancements in networking like SDN, 5G, and IPv6.
