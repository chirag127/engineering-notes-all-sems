### Static and dynamic routing in cn

Static routing:
- Pre-defined routing paths are configured manually between the source and destination.
- Routes do not change unless manually reconfigured.
- Examples: Routing traffic through a default gateway, routing traffic between VLANs.

Mnemonics: Think of static routing as predefined, unchanging routes like a static map.

Dynamic routing:
- Routes are learned automatically via routing protocols (OSPF, BGP, EIGRP, etc.).
- Routes can change as network topology changes (link failures, etc.)
- Examples: Routing internet traffic, routing between autonomous systems.

Mnemonics: Think of dynamic routing as routes that can change and adapt to a changing network, like a GPS recalculating your route.

Advantages of dynamic routing:
- Self-convergence: Routes are automatically updated as topology changes.
- Scalability: Dynamic routing protocols can handle larger, more complex networks.

Disadvantages of dynamic routing:
- Routing loops can occur if misconfigured.
- Additional overhead on routers running dynamic routing protocols.

Applications:
- Static routing: Simple networks, default gateways.
- Dynamic routing: Large or complex networks, especially those with redundant paths and frequent topology changes.
