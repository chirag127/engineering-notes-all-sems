#### Protocols and Standards in Networks Architecture in Computer Networks

The protocols and standards that enable communication and interoperability in computer networks are:

- OSI Model: The Open Systems Interconnection (OSI) model is a conceptual framework for communicating in a network. It consists of 7 layers - Physical, Data Link, Network, Transport, Session, Presentation, Application. Each layer has specific functions and protocols that facilitate communication between networks devices. Following the OSI model helps in troubleshooting and understanding the interworking of the network.

- IP - Internet Protocol: The IP enables routing of data packets over the Internet. It defines the format of the data packets and the addressing scheme used to identify the source and destination of the packets. The current version is IPv4, gradually transitioning to IPv6 which has a larger address space.

- UDP - User Datagram Protocol: A connectionless and fast protocol that enables transmission of data packets over the network. It is used for time-sensitive transmissions such as video streaming. As it is connectionless, there is no guarantee of delivery or ordering of packets.

- TCP - Transmission Control Protocol: A connection-oriented protocol that provides reliable and ordered delivery of data packets over the network. It is used for data transmission such as web browsing and email where correct delivery and ordering of packets is necessary. TCP establishes a dedicated end-to-end connection between two hosts for data transmission.

- Ethernet: A family of wired computer networking technologies for local area networks (LANs). It defines cables, networking equipment, and protocols for the physical and data link layers of the OSI model. The most widely installed Ethernet variants are 10BASE-T, 100BASE-TX, and 1000BASE-T. Ethernet is scalable, inexpensive, and reliable, making it ideal for LANs.

- Wi-Fi: A wireless networking technology based on the IEEE 802.11 standards. It enables devices to connect to the network and Internet wirelessly using radio frequency waves. The widespread adoption of Wi-Fi allows devices to connect to the network in any location where there is network coverage. However, Wi-Fi has limitations in range and can be interfered by obstacles.

- HTTP - Hypertext Transfer Protocol: The protocol that enables data communication for the World Wide Web. It defines how messages should be formatted and transmitted, and what actions web servers and browsers should take in response to various commands. For example, when a user enters a URL into the browser, an HTTP command is sent to the web server directing it to fetch and transmit the requested webpage.
