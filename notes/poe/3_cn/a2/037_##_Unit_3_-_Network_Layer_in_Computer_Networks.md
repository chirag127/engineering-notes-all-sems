## Unit 3 - Network Layer in Computer Networks

The Network Layer is responsible for the following main functions:

1. Routing: Determining paths/routes between source and destination hosts. It uses routing protocols and routing tables to determine the best path for data transmission. Some popular routing protocols are RIP, OSPF, BGP, etc.
2. Forwarding: Transferring data from an input interface to an output interface based on the destinations address. The forwarding table is used to determine the output interface.
3. Addressing: The network layer assigns logical addresses known as IP addresses to devices. It uses the IP address to identify the source and destination hosts.
4. Fragmentation: Data packets may need to be fragmented if they are too large for the MTU (Maximum Transmission Unit). The fragmented packets are reassembled at the destination.
5. Congestion control: Detecting and controlling congestion to avoid network collapse. Methods like packet drops, queue management, etc are used for congestion control.

**Advantages:** Provides connection between networks, enables inter-networking, efficient transfer of data, predictable and consistent performance, etc.
**Disadvantages:** Complexity, latency can increase due to packet processing and queuing delays, security threats like IP spoofing, etc.
