### Electronic mail in application layer

Electronic mail (email) is one of the core applications running on the application layer of the OSI model. Some key points about email in the application layer are:

1. Email uses protocols like Simple Mail Transfer Protocol (SMTP), Post Office Protocol (POP), and Internet Message Access Protocol (IMAP) to send and receive messages.
2. SMTP is used to transfer email messages between servers. Email clients use POP or IMAP to retrieve email from servers.
3. Email messages are composed of headers (metadata like sender, recipient, subject, date, etc.) and the body which contains the actual message contents. Headers are structured using MIME types.
4. Email has advantages like convenience, low cost, and asynchrony but also disadvantages like spam, phishing, viruses, and security issues.
5. To help remember protocols:

- **S**end **M**ail **T**ransfer **P**rotocol (SMTP)
- **P**ost **O**ffice **P**rotocol (POP)
- **I**nternet **M**essage **A**ccess **P**rotocol (IMAP)
