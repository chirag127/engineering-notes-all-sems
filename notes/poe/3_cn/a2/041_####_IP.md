#### IP

IP stands for Internet Protocol. It is the primary communications protocol used for relaying packets of data across a packet-switched internetwork, like the Internet.

IP specifies the format of packets, also called IP datagrams, and the addressing scheme. The most widely used version today is IPv4, although the next generation IPv6 is growing in popularity.

**Key Points:**

- IP is a layer 3 protocol in the OSI model and is responsible for logical addressing and routing.
- An IP address is a unique identifier for a device on a network and allows communication between devices.
- IP specifies the format of packets and the addressing scheme. The current widely used version is IPv4 which uses 32-bit addresses. The next generation IPv6 uses 128-bit addresses to support a much larger number of devices and addresses.
- IP datagrams include a header containing source and destination IP addresses, protocol information, etc. The contents of the data portion depend on the specific higher layer protocol being used.
- IP uses routing to determine the best path for sending packets between networks based on available connections and network conditions. IP is an unreliable protocol and does not guarantee delivery of packets. Higher layer protocols handle reliable data transmission.
- Key learning mnemonics:
	- IP addresses: Every Device Gets One (IPv4), Lots More Addresses Now (IPv6)
	- OSI layers: Please Do Not Throw Sausage Pizza Away (Physical, Data link, Network, Transport, Session, Presentation, Application)
	- IPv4 header fields: Version, IHL, Type of Service, Total Length, Identification, Flags, Fragment Offset, TTL, Protocol, Header Checksum, Source Address, Destination Address
