### Cryptography in application layer

The application layer is where cryptography is implemented to provide secure communication services and applications. Some of the common cryptography techniques used in the application layer are:

- Digital signatures: Used to authenticate the sender of a message and verify the integrity of the message. For example, digital signatures are used to sign software updates, financial transactions, etc. Mnemonic: Digital signatures involve *signing* a message with a secret key so others can *verify* it is authentic.
- HTTPS: Uses SSL/TLS to provide encrypted communication over the internet. Websites use HTTPS to protect login credentials, credit card numbers, etc. transferred between the browser and web server.
- VPN: Creates an encrypted tunnel between two points to provide secure private networking. Corporate networks often use VPNs to allow employees to access the internal network securely from remote locations.
- End-to-end encryption: Used in messaging apps like WhatsApp, Signal, etc. to provide encrypted communication between two endpoints so only the sender and recipient can read the messages.
- Password managers: Store passwords in an encrypted database and use a master password to log in. This protects against compromised passwords and ensures unique, complex passwords for websites.

Advantages of cryptography in the application layer:
- Protects sensitive data and communications from unauthorized access or modification.
- Allows secure applications and services to be built on top of an inherently insecure internet.

Disadvantages:
- Increases computational requirements and can reduce performance.
- Complex to implement correctly - vulnerabilities can lead to serious security issues.
- Reliance on keys/passwords - loss of keys or weak passwords can compromise security.
