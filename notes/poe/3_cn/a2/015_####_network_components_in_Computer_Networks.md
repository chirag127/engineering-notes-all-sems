#### Network components in Computer Networks

The major components of a computer network are:

1. Network interface card (NIC): Acts as an interface between the computer and the transmission medium. It is used to send and receive data in the form of packets.

2. Cables: Used as a transmission medium to connect two or more computers. Different types of cables used are coaxial cables, optical fibers, and twisted pair cables.

3. Hub: Acts as a central connecting device. All the computers and other network devices are connected to the hub. When a packet arrives at a hub, it is sent to all the ports of the hub.

4. Switch: Similar to a hub but works in an intelligent manner. It maintains a table of MAC addresses of connected devices and sends data only to the destined device. This saves bandwidth and increases performance as compared to a hub.

5. Router: Forwards data packets between networks based on network addresses. It finds the best path in a network between the source and destination. It works at the network layer.

6. Server: Provides services/resources to other computers on the network like shared storage, hosting websites, handling emails, etc. Clients send requests to the server to access/share resources.

7. DNS: Translates domain names to IP addresses as domain names are easier to remember than IP addresses. This makes it possible to access websites by using domain names.

Mnemonics:

NIC - Connects to network
Cables - Transmission medium
Hub - Central connecting device
Switch - Intelligent hub
Router - Forwards between networks
Server - Provides services
DNS - Translates names to addresses

Advantages: Efficiency, resource sharing, communication
Disadvantages: Security issues, system vulnerabilities
Applications: Internet, office/home networks, etc.
