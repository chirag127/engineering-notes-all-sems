#### Network architecture with reference to Computer Networks

The network architecture refers to the design of a computer network which includes the components, their arrangement, and the functional specifications of how they interconnect and interact. The commonly used network architectures with reference to computer networks are:

1. Client-server architecture: In this architecture, there are dedicated server machines that provide resources, data, services, or applications to client machines. The client machines request for services or resources that are provided by the server. For example, a web server provides web pages to client computers.

2. Peer-to-peer architecture: In this architecture, there are no dedicated server machines. Each machine can act as both a client and a server. The nodes in the network act as both suppliers and consumers of resources. For example, Napster is a peer-to-peer file sharing system where users can share MP3 files directly between their computers.

**Mnemonics**: 'C' for client and 'S' for server in client-server architecture. 'P' for peer-to-peer architecture where each machine is a peer.

**Advantages of client-server architecture**: Centralized control, enhanced security, efficient resource utilization.
**Advantages of peer-to-peer architecture**: No single point of failure, distributed processing, efficient bandwidth utilization.
