#### LAN standards in local area network

- Ethernet: Ethernet is a family of computer networking technologies commonly used in local area networks (LAN), metropolitan area networks (MAN) and wide area networks (WAN). It defines wiring and signaling for the physical layer and data link layer of the OSI model. Ethernet is standardized as IEEE 802.3. Some important features of Ethernet are:
    - bus, star or tree topology
    - uses CSMA/CD access method
    - data rates of 10 Mbps, 100 Mbps, 1 Gbps and 10 Gbps are commonly used
- Token Ring: Token Ring is a LAN technology where devices are connected in a ring topology and a special packet called a token is passed around the ring. Devices can transmit data only when they have the token. It uses a token passing access method and is standardized as IEEE 802.5. Key features:
    - ring topology
    - token passing access method
    - data rates of 4 Mbps and 16 Mbps
- FDDI: Fibre Distributed Data Interface (FDDI) is a LAN technology designed to use optical fiber cable as the physical medium. It is a token passing ring network that provides a data rate of 100 Mbps. Being fiber optic based, it can support longer distances and is resistant to electromagnetic interference. However, it is more expensive than Ethernet and Token Ring.
