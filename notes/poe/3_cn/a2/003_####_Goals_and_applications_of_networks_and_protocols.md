#### Goals and applications of networks and protocols

The major goals and applications of computer networks and protocols are:

1. Sharing resources: Networks allow sharing of resources like printers, storage devices, applications, etc. This reduces cost and increases efficiency.
2. Communication: Efficient communication between people across the world is enabled using email, instant messaging, video calling, etc. over networks.
3. Access to information: The World Wide Web and internet allow access to a vast repository of information on almost any topic. This enables self-learning and research.
4. Entertainment: Streaming services for music, movies, TV shows, etc. are possible due to networking. Online gaming is also enabled by networks.
5. Business: E-commerce, banking transactions, stock trading, etc. are feasible using networks. This boosts business and economy.

Some key protocols and their purposes:

- HTTP: Used for accessing web pages and transferring web content.
- SMTP: Used for sending and receiving emails.
- FTP: Used for file transfer between systems.
- DNS: Used for mapping hostnames to IP addresses.
- TCP: Provides reliable data transmission with error checking and correction.
- IP: Enables data routing between networks based on IP addresses.
- UDP: Provides fast but unreliable data transmission without error correction.
