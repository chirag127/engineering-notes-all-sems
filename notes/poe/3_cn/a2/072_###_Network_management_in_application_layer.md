### Network management in application layer

The application layer protocols and services provide functionality for network management. Some of the key network management functions in the application layer are:

- Monitoring: Protocols like SNMP (Simple Network Management Protocol) are used to monitor the network devices and servers. SNMP collects management information from the managed devices in the network. The SNMP agents running on the devices collect the information like device up/down status, CPU utilization, memory usage, interface status, etc. and store in a management information base (MIB). The SNMP manager can query the MIB to get the monitoring information.
- Configuration management: Protocols like NETCONF and RESTCONF can be used to configure the network devices. The network operators can push the configuration changes to the devices using these protocols.
- Fault management: Protocols like syslog are used to log the system and error messages which can be used for fault management. The logs can be analyzed to detect and diagnose any faults or issues in the network.
- Accounting management: Protocols like RADIUS and TACACS+ are used for authentication, authorization and accounting management. They are used to control access to network resources and log the usage information.
- Performance management: Application protocols can be used to measure and monitor performance metrics like bandwidth usage, latency, jitter, etc. and generate performance reports.
- Security management: Application layer protocols are used to manage security of the network and monitor for any security incidents or attacks. Firewalls, intrusion detection systems, etc. use application protocols to configure the security policies and exchange the security monitoring information.

Some mnemonics and learning tricks for application layer network management:

- "Sniffing" the network for "Problems": SNMP is used for monitoring
- "Network Configuration" using NETCONF
- "Error logs" using syslog
- "Accounting" using RADIUS/TACACS+
- "Performance" management using application protocols
- "Security" management using application protocols
