#### Link layer switches & bridges in local area network

- Link layer switches operate at the data link layer (layer 2) of the OSI model. They forward traffic based on MAC addresses and are faster than software-based bridges.
- Bridges connect two LAN segments and forward traffic based on MAC addresses. They filter unwanted traffic and reduce network traffic by only forwarding traffic from one LAN segment to another when the destination device is located on the other segment.
- Link layer switches are specialized hardware devices that provide bridging functionality at a higher performance than software-based bridges. They have many ports to connect multiple devices and filter and forward traffic very quickly using application-specific integrated circuits (ASICs).
- Some key features of link layer switches are:

- Spanning tree protocol (STP) to prevent network loops
- Simple network management protocol (SNMP) for monitoring and management
- Virtual LANs (VLANs) to logically group devices
- Quality of service (QoS) features to prioritize traffic
- Port mirroring and VLAN tagging

- Learning aspects:

- MAC address table: Link layer switches build a MAC address table by examining the source MAC address of incoming frames on each port. The table is used to forward outgoing frames quickly to the correct port.
- Filtering: Link layer switches forward only necessary traffic between LAN segments, filtering out unnecessary broadcasts and packets destined for other LAN segments. This reduces network traffic and improves performance.
- High speed: Link layer switches use hardware and ASICs to forward traffic based on MAC addresses extremely quickly with low latency. This provides a high-performance bridge between LAN segments.
