### Routing in network layer

The network layer is responsible for routing the packets across the network from source to destination. Routing is a process of selecting paths in a network along which to send network traffic. Routing algorithms determine the specific choice of route.

Following are some key points about routing in network layer:

1. Routing tables: Routing tables contain routing information to forward the packets. The routing table is built using routing protocols and contains destination IP addresses and the outgoing interface to reach the destinations.
2. Routing protocols: Routing protocols are used to communicate and share routing information between routers. They allow routers to select paths to networks and destinations dynamically. Some examples are OSPF, BGP, RIP, IGRP, EIGRP, etc.
3. Dynamic vs static routing: In dynamic routing, routing information is automatically shared and updated using routing protocols where as in static routing, routes are configured manually on routers and remain fixed. Dynamic routing is more scalable but static routing provides more security.
4. Route aggregation: It is a method of combining multiple routes into a single route to reduce routing table size and improve routing efficiency.
5. Load balancing: It distributes traffic across multiple paths to utilize the bandwidth and resources efficiently. Equal cost multipath routing can be used to achieve load balancing.
6. Packet switching: Packets are transmitted across the network by forwarding them from one router to the next until they reach the destination. The packets may take different paths to reach the destination due to routing.

Some mnemonics to remember:
- RIP: Routing Information Protocol, distance vector, hop count
- OSPF: Open Shortest Path First, link state, area based
- EIGRP: Enhanced Interior Gateway Routing Protocol, advanced distance vector, bandwidth and delay
