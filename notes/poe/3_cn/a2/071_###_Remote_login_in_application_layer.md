### Remote login in application layer

- Remote login refers to logging into a computer or server from a remote location. In the application layer, remote login is achieved using client-server applications and protocols.
- Some commonly used protocols for remote login are:
    - SSH (Secure Shell): Uses encryption to establish a secure connection between the client and server. It provides a command-line interface and secure file transfer. Mnemonic: SSH = Secure SHell.
    - Telnet: Provides a command-line interface but the connection is unencrypted. Not recommended for use as the data can be seen by others. Mnemonic: Telnet = unsecured network.
    - RDP (Remote Desktop Protocol): Developed by Microsoft. Provides a graphical user interface to control the remote computer. Used to remotely access Windows machines.
- Advantages of remote login:
    - Access resources from anywhere.
    - Manage servers/computers without being physically present.
    - Troubleshoot issues remotely.
- Disadvantages of remote login:
    - Security risks if proper authentication and encryption are not used.
    - Requires stable network connectivity to work seamlessly.
    - Command delays can occur due to latency.
- Examples: Logging into a work computer from home, accessing a server to manage files/resources, technical support accessing a user's computer, etc.
- To learn: Understand the protocols, their security features, and use cases. Practice setting up remote login and experiencing the pros and cons firsthand.
