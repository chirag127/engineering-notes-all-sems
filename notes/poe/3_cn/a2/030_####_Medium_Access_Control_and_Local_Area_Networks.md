#### Medium Access Control and Local Area Networks

- Medium Access Control (MAC) is a protocol that controls how devices in a network access the shared medium (bandwidth) and transmit data. It prevents collisions of data packets and ensures efficient utilization of the medium.
- Some popular MAC protocols for LANs (Local Area Networks) are:

- CSMA/CD (Carrier Sense Multiple Access with Collision Detection): Used in Ethernet LANs. Devices sense the medium before transmitting and detect collisions. On collision, they wait for a random time and retry.
- Token Passing: A token is passed around the network. Only the device holding the token can transmit. After transmission, it passes the token to the next device. Used in ring topology LANs like Token Ring.

- Learning Trick: Remember `CD' in CSMA/CD stands for `Collision Detection'.

- Advantages: Prevents data loss due to collisions, efficient bandwidth utilization.
- Disadvantages: Complex protocol, wastage of bandwidth in collision and retry.

- Examples: Ethernet uses CSMA/CD, Token Ring uses Token Passing.
- Applications: LANs, Wi-Fi networks.
