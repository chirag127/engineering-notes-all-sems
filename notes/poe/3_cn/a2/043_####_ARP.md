#### ARP

ARP stands for Address Resolution Protocol. It is a protocol used to map IP addresses to MAC addresses.

- ARP is used when a device needs to know the MAC address of another device in the same network. It sends a broadcast ARP request asking for the MAC address of the target IP address. The device with that IP address responds with its MAC address.
- The ARP request and response contain the sender and target IP and MAC addresses. This allows devices to maintain ARP tables that map IP addresses to MAC addresses and vice versa.
- ARP is a stateless protocol and there is no recurring ARP request to keep the ARP table updated. The entries eventually timeout if they are not used.
- ARP spoofing is a type of attack where a malicious actor sends spoofed ARP responses to associate the attacker's MAC address with the IP address of another device. This allows the attacker to intercept traffic meant for that device. Protecting against ARP spoofing involves using techniques like ARP inspection and DHCP snooping.

Some mnemonics to remember ARP:

- A sks R: ARP request asks for resolution
- P airs I P and M AC: ARP pairs IP address and MAC address
- S tateless: ARP is a stateless protocol
- Vulnerable to S poofing: ARP is vulnerable to spoofing attacks
