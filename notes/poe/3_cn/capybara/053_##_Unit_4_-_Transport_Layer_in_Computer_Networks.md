## Unit 4 - Transport Layer in Computer Networks

The Transport Layer is the fourth layer of the OSI Model, responsible for the end-to-end delivery of data between two devices on a network. It is responsible for ensuring that data is transported reliably and efficiently across the network.

### Functions of Transport Layer

The Transport Layer provides the following functions:

- **Segmentation and Reassembly:** The Transport Layer breaks down data into smaller segments and reassembles them at the receiving end.

- **Error Control:** The Transport Layer ensures that data is delivered without errors by implementing error detection and correction techniques.

- **Flow Control:** The Transport Layer manages the rate at which data is transmitted between devices to prevent congestion.

- **Congestion Control:** The Transport Layer monitors network traffic and adjusts the rate at which data is sent to prevent congestion.

- **Multiplexing and Demultiplexing:** The Transport Layer allows multiple applications to use the network simultaneously by multiplexing data from different applications into a single stream and demultiplexing the data at the receiving end.

### Mnemonics and Learning Tricks

- **SRFCDM:** This stands for Segmentation, Reassembly, Flow Control, Congestion Control, Error Control, Multiplexing, and Demultiplexing, which are the key functions of the Transport Layer.

- **TCP/IP:** This stands for Transmission Control Protocol/Internet Protocol, which are the two most common protocols used in the Transport Layer.

### Transport Layer Protocols

There are two main transport layer protocols used in computer networks:

- **Transmission Control Protocol (TCP):** TCP is a connection-oriented protocol that provides reliable data transmission. It establishes a connection between two devices before transmitting data and ensures that all data is received correctly by using sequence numbers and acknowledgements.

- **User Datagram Protocol (UDP):** UDP is a connectionless protocol that provides unreliable data transmission. It does not establish a connection before transmitting data and does not guarantee that all data will be received correctly. However, it is faster and requires less overhead than TCP.

### Applications of Transport Layer

The Transport Layer is used in a wide range of applications, including:

- **Web Browsing:** HTTP, the protocol used for browsing the web, operates at the Transport Layer.

- **Email:** SMTP, the protocol used for sending and receiving email, operates at the Transport Layer.

- **File Transfer:** FTP, the protocol used for transferring files, operates at the Transport Layer.

- **Video Streaming:** RTP, the protocol used for real-time video streaming, operates at the Transport Layer.

### Conclusion

The Transport Layer is an essential part of computer networks, responsible for ensuring that data is transported reliably and efficiently between devices. Understanding the functions, protocols, and applications of the Transport Layer is crucial for anyone working in the field of computer networking.
