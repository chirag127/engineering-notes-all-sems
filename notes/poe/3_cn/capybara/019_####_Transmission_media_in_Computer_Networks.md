#### Transmission Media in Computer Networks

Transmission media refers to the physical medium or channel that is used to transmit data from one device to another in a computer network. The transmission media can be classified into two categories: guided media and unguided media.

1. Guided Media:
Guided media are those transmission media that use a physical medium to transmit data from one device to another. The guided media can be further classified into three categories:
   - Twisted Pair Cable: It is a type of guided media that consists of two insulated copper wires twisted together. It is commonly used for telephone lines and Ethernet networks. The twisted pair cable can be further classified into two categories: Unshielded Twisted Pair (UTP) and Shielded Twisted Pair (STP).
   - Coaxial Cable: It is a type of guided media that consists of a central conductor, surrounded by an insulating layer, a metallic shield, and an outer jacket. It is commonly used for cable TV networks and Ethernet networks.
   - Fiber Optic Cable: It is a type of guided media that uses light to transmit data. It consists of a thin glass or plastic fiber that is surrounded by a protective coating. It is commonly used for long-distance communication and high-speed data transfer.

2. Unguided Media:
Unguided media are those transmission media that do not use a physical medium to transmit data from one device to another. The unguided media can be further classified into two categories:
   - Wireless Communication: It is a type of unguided media that uses radio waves to transmit data from one device to another. It is commonly used for mobile communication, Wi-Fi networks, and Bluetooth devices.
   - Satellite Communication: It is a type of unguided media that uses satellites to transmit data from one device to another. It is commonly used for long-distance communication, remote sensing, and GPS devices.

Advantages of Transmission Media:
- Guided media provides higher data transfer rates and better security than unguided media.
- Unguided media provides flexibility and mobility to the devices.
- Fiber optic cable provides high bandwidth and is immune to electromagnetic interference.

Disadvantages of Transmission Media:
- Guided media is expensive to install and maintain.
- Unguided media is susceptible to interference and signal attenuation.
- Fiber optic cable is fragile and requires specialized equipment to install and maintain.

Mnemonic:
A popular mnemonic for remembering the types of guided media is "TFC" which stands for "Twisted Pair Cable", "Fiber Optic Cable", and "Coaxial Cable".
