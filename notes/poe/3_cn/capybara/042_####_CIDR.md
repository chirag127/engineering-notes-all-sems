#### CIDR

CIDR stands for Classless Inter-Domain Routing. It is a method used to allocate IP addresses more efficiently and flexibly than the previous system, which used classes of IP addresses. Here are some key points to know about CIDR:

- CIDR is a way to specify IP addresses and their associated network prefixes. It works by combining the IP address and a prefix length, separated by a slash. For example, 192.168.1.1/24 specifies the IP address 192.168.1.1 with a prefix length of 24 bits. This means that the network includes all IP addresses that start with the first 24 bits (or 3 bytes) of the address, which in this case is 192.168.1.
- CIDR notation is often used in routing tables to specify which networks can be reached through which interfaces. For example, a router might have two interfaces, one connected to a network with IP addresses in the range 192.168.1.0/24 and another connected to a network with IP addresses in the range 10.0.0.0/8. The routing table would specify that traffic destined for 192.168.1.0/24 should be sent out the first interface, while traffic destined for 10.0.0.0/8 should be sent out the second interface.
- CIDR allows for more efficient use of IP addresses than the previous system of classes. With classes, IP addresses were divided into three classes: A, B, and C. Each class had a fixed number of bits for the network prefix and the host address. This led to inefficiencies where some networks had more IP addresses than they needed, while others didn't have enough. CIDR allows for more flexible allocation of IP addresses, so that networks can be sized more appropriately.
- There are some useful mnemonics to remember CIDR notation. One is the "slash" notation, where the prefix length is separated from the IP address by a slash. Another is the "subnet mask" notation, where the prefix length is converted to a binary subnet mask. For example, a prefix length of 24 would have a subnet mask of 255.255.255.0 in decimal notation, or 11111111.11111111.11111111.00000000 in binary notation.
- CIDR has some advantages over the previous class-based system. It allows for more efficient use of IP addresses, which is important as the number of devices connected to the internet continues to grow. It also allows for more flexibility in how IP addresses are allocated, which can make it easier to manage and scale networks. However, CIDR can be more complex to understand and configure than the previous system, so it may take some time to get used to.
