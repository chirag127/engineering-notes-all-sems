
### Information Modelling in Software Requirement Specification (SRS)
Information modelling is a process used to create a formal representation of a system's requirements, which can then be used to develop software. It is a step-by-step process that involves gathering, analyzing, and organizing the data and information related to a system. The result of the information modelling process is a software requirement specification (SRS), which is a document that describes the system's requirements in detail.

The process of information modelling is used to create a formal representation of a system's requirements. It involves gathering, analyzing, and organizing the data and information related to the system. This data and information is used to create a detailed description of the system's requirements.

The main objectives of information modelling are to:

- Identify the system's requirements
- Create a formal representation of the system's requirements
- Design a software system to meet the requirements
- Validate the software system's design

Information modelling is a process that involves several steps. The first step is to gather the data and information related to the system. This data and information can be gathered from various sources, such as documents, interviews, surveys, and observations.

The second step is to analyze the data and information gathered. This involves breaking down the data and information into smaller pieces and understanding how they are related to each other.

The third step is to organize the data and information into a logical structure. This involves creating diagrams and models that represent the system's requirements.

The fourth step is to create a software requirement specification (SRS). This is a document that describes the system's requirements in detail. It includes information such as the system's objectives, functional requirements, non-functional requirements, and user interface requirements.

The fifth and final step is to validate the software system's design. This involves testing the system to ensure that it meets the requirements specified in the SRS.

To help remember the steps of information modelling, a useful mnemonic is GADV: Gather, Analyze, Design, Validate.
