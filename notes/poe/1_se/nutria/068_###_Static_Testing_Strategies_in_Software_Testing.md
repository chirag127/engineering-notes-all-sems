
### Static Testing Strategies in Software Testing

Static testing is a type of software testing that is performed without executing the code. It is also known as non-execution testing and is typically used to review the code and ensure that it meets the software requirements. The main goal of static testing is to identify defects in the code early in the development process, before they become more difficult and costly to fix.

Static testing strategies include:

* Code reviews: Code reviews are conducted by developers or other experts to review the source code and identify any potential issues. Code reviews are typically done in a collaborative environment and involve discussing the code with the team to identify any issues.

* Static analysis: Static analysis is a process of analyzing the source code for potential bugs and errors. This is done by running the source code through a static analysis tool, which will detect any issues with the code.

* Automated testing: Automated testing is a type of software testing that is done using a computer program. This type of testing can be used to detect errors in the code and to ensure that the code meets the software requirements.

* Formal methods: Formal methods are a type of software testing that uses mathematical models to prove the correctness of the code. This type of testing is often used to verify safety-critical systems.

* Mnemonics and learning tricks: Mnemonics and learning tricks are techniques used to help remember key concepts and terms. These techniques can be used to help quickly recall information when needed, such as during an exam.
