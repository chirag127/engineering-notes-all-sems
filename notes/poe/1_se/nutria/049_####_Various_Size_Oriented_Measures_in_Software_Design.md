

#### Various Size Oriented Measures in Software Design

* **Lines of Code (LOC):** This measure is used to count the total number of lines in a software program, including comments and blank lines. This measure is not very reliable as it does not take into account the complexity of the code.

* **Function Points (FP):** This measure is used to measure the size of a software by counting the number of functions it performs. It is a more reliable measure than LOC as it takes into account the complexity of the code.

* **Cyclomatic Complexity (CC):** This measure is used to measure the complexity of a software by counting the number of independent paths through the code. It is a more reliable measure than LOC and FP as it takes into account the complexity of the code.

* **Halstead Complexity Metrics (HCM):** This measure is used to measure the size and complexity of a software by counting the number of distinct operators and operands in the code. It is a more reliable measure than LOC, FP and CC as it takes into account the complexity of the code.

* **Mnemonic:** To remember the various size oriented measures in software design, use the acronym "LFCH": Lines of Code (LOC), Function Points (FP), Cyclomatic Complexity (CC) and Halstead Complexity Metrics (HCM).
