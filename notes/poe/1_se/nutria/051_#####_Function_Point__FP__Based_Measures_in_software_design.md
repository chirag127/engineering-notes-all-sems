
##### Function Point (FP) Based Measures in software design

Function Point (FP) Based Measures are a type of software design metric which can be used to measure the size of a software system. The Function Point (FP) metric is based on the number of functions provided by the software system. It is a measure of the complexity of the software system and is used to assess the cost and effort required to develop, maintain, and enhance the software system.

Function Points (FPs) are calculated by counting the number of input, output, and inquiry transactions that the system is designed to process. A transaction is an action that the system performs in order to accomplish a particular task. The Function Point (FP) metric is based on the number of transactions that the system is designed to process.

The Function Point (FP) metric is often used to compare the size of different software systems. It is also used to compare the cost and effort required to develop, maintain, and enhance different software systems.

Mnemonics and Learning Tricks:

FP = Function Point

Input = I

Output = O

Inquiry = Q

Function Point = I + O + Q
