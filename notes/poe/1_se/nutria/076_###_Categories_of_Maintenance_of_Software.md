

### Categories of Maintenance of Software

1. **Corrective Maintenance:** This type of maintenance is used to fix errors and bugs in the software. It involves making changes to the existing code or architecture in order to fix problems.

2. **Adaptive Maintenance:** This type of maintenance is used to make changes to the software in order to adapt it to a changing environment or to new requirements. It involves making changes to the existing code or architecture in order to make the software compatible with its new environment.

3. **Perfective Maintenance:** This type of maintenance is used to improve the performance of the software. It involves making changes to the existing code or architecture in order to optimize the software for better performance.

4. **Preventive Maintenance:** This type of maintenance is used to prevent future problems from occurring. It involves making changes to the existing code or architecture in order to make the software more resistant to future problems.

5. **Mnemonic:** C.A.P.P. (Corrective, Adaptive, Perfective, Preventive)
