
#### Compliance with Design and Coding Standards (Coding Standards) Static testing strategy 

Static testing is a type of software testing in which the software is tested without executing the code. It is also known as non-execution based testing and is used to detect errors in the software design and coding standards. Static testing is an important part of the software development process as it helps to identify errors and ensure the quality of the software before it is released.

Static testing involves checking the code for errors and inconsistencies, such as: 

- Syntax errors: These are errors that occur when the code does not follow the syntax rules of the programming language.
- Semantic errors: These are errors that occur when the code does not follow the semantic rules of the programming language.
- Coding standards violations: These are errors that occur when the code does not adhere to the coding standards of the organization.

Static testing is usually done manually by a software engineer or a team of software engineers. It can also be done using automated tools that can scan the code and detect errors.

Static testing is beneficial in that it can help to identify errors early in the development process and ensure the quality of the software before it is released. It is also cost-effective as it does not require the code to be executed in order to test it.
