

#### Walk Through (Walkthrough) Static testing strategy

Static testing is a type of software testing that involves analyzing the code of a program without actually executing it. It is used to find errors in the code before the software is released.

Static testing involves the following steps:

1. Analyze the code: This involves examining the code for errors, such as syntax errors, logical errors, and incorrect variable types.

2. Prepare test cases: Test cases are created to test the various aspects of the code, such as input and output, looping, and branching.

3. Execute the test cases: Test cases are executed to check the accuracy of the code.

4. Review the results: The results of the test cases are reviewed to ensure that the code is error-free.

Advantages of Static Testing:

- It is cost-effective, as it does not require the use of expensive hardware or software.
- It is faster than dynamic testing, as it does not require the code to be executed.
- It can detect errors that may not be detected by dynamic testing.

Disadvantages of Static Testing:

- It cannot detect errors related to the functionality of the code.
- It cannot detect errors related to the performance of the code.
- It is not suitable for testing complex programs.
