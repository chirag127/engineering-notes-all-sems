

### Pseudo Codes in Software Design

Pseudo codes are a type of structured language used to describe algorithms. They are written in a format similar to programming languages, but are not actual code. Pseudo codes are used by software engineers and computer scientists to design and document algorithms.

* Advantages:
    * Pseudo codes are easy to read and understand, even for non-programmers.
    * They can be used to quickly document algorithms and ideas.
    * They can be used to help plan out the structure of a program before coding it.
    * They can be used to help explain complex algorithms to others.
* Disadvantages:
    * Pseudo codes are not actual code, and so cannot be run on a computer.
    * They are not consistent across different programming languages.
    * They can be difficult to debug, as they do not have the same level of detail as actual code.
* Mnemonics and Learning Tricks:
    * PSEUDO: Plan, Structure, Explain, Understand, Debug, Optimize 
    * Focus on the structure and flow of the algorithm, rather than the details of the code.
    * Break down complex algorithms into smaller, simpler steps.
    * Use diagrams or flow charts to help visualize algorithms.
    * Use comments to explain complex sections of code.
    * Use descriptive variable names.
    * Test algorithms as you write them.
