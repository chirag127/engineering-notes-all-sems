

## Unit 4 - Software Testing
Software testing is the process of evaluating a software system or application to detect any errors, bugs, or missing features. It is an important part of the software development process, as it helps to ensure that the final product is of the highest quality and meets the requirements set by the user.

Software testing can be divided into two main categories: functional testing and non-functional testing. 

### Functional Testing
Functional testing is the process of testing the functionality of a software system or application. This type of testing is used to ensure that the system meets the requirements set by the user and that it works as expected. Functional testing is usually done using manual testing or automated testing. 

### Non-Functional Testing
Non-functional testing is the process of testing the non-functional aspects of a software system or application. This type of testing is used to ensure that the system meets the performance and reliability requirements set by the user. Non-functional testing is usually done using automated testing.

### Mnemonics and Learning Tricks
When studying software testing, it can be helpful to use mnemonics and learning tricks. A few examples include:

- **FAT:** Functionality, Availability, and Testing
- **BITE:** Basic, Intermediate, and Testing Evaluation
- **FIST:** Functional, Integration, System, and Testing
- **CAGE:** Compatibility, Accessibility, Graphical, and Error Testing
