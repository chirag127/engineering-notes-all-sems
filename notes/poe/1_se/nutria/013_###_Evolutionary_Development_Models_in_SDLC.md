

### Evolutionary Development Models in SDLC

* Evolutionary development models are a type of software development life cycle (SDLC) model that is iterative and incremental.
* It is a combination of both the waterfall and spiral models, as it includes both the linear and cyclical development methodologies.
* It is an agile methodology that focuses on delivering the highest value features first and then iterating on them as needed.
* The evolutionary development model is based on the idea of continuous improvement and involves frequent feedback from stakeholders.
* It is an iterative process that involves several stages, such as planning, analysis, design, implementation, testing, and deployment.
* The main advantage of the evolutionary development model is that it is highly flexible and can be adapted to changing requirements.
* It is also cost-effective since it allows for incremental development, which reduces the overall cost of the project.
* Another advantage is that it allows for rapid prototyping, which allows developers to quickly create a working prototype of the software.
* Disadvantages of the evolutionary development model include the fact that it can be difficult to manage, as it requires frequent feedback from stakeholders.
* Additionally, it can be difficult to estimate the cost of the project, as the requirements may change during the development process.

Mnemonics: EDM-SDLC (Evolutionary Development Model-Software Development Life Cycle)
