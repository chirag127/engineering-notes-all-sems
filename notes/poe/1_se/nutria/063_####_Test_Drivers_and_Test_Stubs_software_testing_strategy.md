
#### Test Drivers and Test Stubs software testing strategy

* Test Drivers are programs that are used to invoke a module under test and provide test inputs, monitor outputs, and compare the actual and expected results.
* Test Stubs are programs that simulate the behavior of components or modules that are not available during testing.
* Mnemonic: TDTS = Test Drivers and Test Stubs
* Test Drivers and Test Stubs are used to test the functionality of a software system.
* Test Drivers are used to test the functionality of a module in isolation, while Test Stubs are used to test the integration of two or more modules.
* Test Drivers and Test Stubs are used to provide test inputs, monitor outputs, and compare the actual and expected results.
* Advantages of using Test Drivers and Test Stubs include:
  * Isolation of modules for testing
  * Easier to debug
  * Faster execution
  * Reduced cost
* Disadvantages of using Test Drivers and Test Stubs include:
  * Increased complexity of the system
  * Increased time for development
  * Difficulty in maintaining the system
* Examples of Test Drivers and Test Stubs include:
  * Unit tests
  * Integration tests
  * System tests
  * Functional tests
* Applications of Test Drivers and Test Stubs include:
  * Automated testing
  * Regression testing
  * Performance testing
  * Security testing
