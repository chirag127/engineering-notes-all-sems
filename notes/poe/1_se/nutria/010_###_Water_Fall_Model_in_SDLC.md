
### Water Fall Model in SDLC

The Waterfall Model is a software development process that is linear and sequential. This model is used in software development life cycles (SDLC) to create a system with a specific set of requirements. It is also known as the classic life cycle model.

The Waterfall Model has a number of distinct phases which are followed sequentially:

1. Requirements Analysis: The requirements of the system are identified, documented, and analyzed.
2. Design: The system and software design are developed.
3. Implementation: The software code is written according to the design.
4. Testing: The software is tested for correctness, completeness, security, and other quality attributes.
5. Deployment: The software is deployed and made available for use.
6. Maintenance: The software is maintained and updated as needed.

Advantages of Waterfall Model:

- It is simple and easy to understand and use.
- It is rigid and structured, and thus helps in managing the complexity of software development.
- It is easy to manage due to the rigidity of the model – each phase has specific deliverables and a review process.
- It allows for departmentalization and control.

Disadvantages of Waterfall Model:

- It does not allow for much revision and changes once the project has begun.
- It does not allow for much flexibility or adaptation to changing requirements.
- It is not suitable for large and complex projects.
- It is not suitable for projects where requirements are not very well understood.
