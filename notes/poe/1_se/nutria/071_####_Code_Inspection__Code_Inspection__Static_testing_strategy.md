

#### Code Inspection (Code Inspection) Static Testing Strategy

* Code Inspection, also known as Static Testing, is a software testing strategy that involves analyzing the source code of a program in order to identify errors and potential issues. 
* It is a form of white-box testing, as the tester has access to the internal structure of the program.
* Code Inspection is a manual process, meaning that it requires a human tester to manually analyze the code.
* It is typically conducted by a team of experienced developers who review the code to identify any potential problems.
* The goal of Code Inspection is to identify any potential errors or bugs that could cause the program to malfunction.
* It is a form of verification, as it verifies that the code meets the requirements of the program.
* Code Inspection is typically conducted in a series of steps, such as:
    * Reviewing the code for syntax and logical errors
    * Identifying any potential security vulnerabilities
    * Identifying any potential performance issues
    * Identifying any potential usability issues
    * Identifying any potential scalability issues
* Code Inspection is a cost-effective way to identify potential issues in a program before it is released.
* It is also an effective way to ensure that the code meets the requirements of the program.
* A common mnemonic for remembering Code Inspection is "Check Before Launch". This is a reminder to conduct a thorough code inspection before releasing a program.
