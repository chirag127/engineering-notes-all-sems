
### Structural Testing (White Box Testing) software testing strategy
Structural Testing (also known as White Box Testing) is a software testing strategy that focuses on the internal structure of the code. It is used to verify that the code is functioning correctly and is free of any errors. This type of testing is performed by examining the code line-by-line and ensuring that the logic is correct.

Structural testing focuses on the following components:

1. **Control Flow**: This involves testing the flow of the program to ensure that the code is executing in the correct order and that the logic is correct.

2. **Data Flow**: This involves testing the data that is being passed through the program to ensure that it is valid and that it is being manipulated correctly.

3. **Boundary Values**: This involves testing the boundaries of the program to ensure that the code is not going out of bounds.

4. **Error Handling**: This involves testing the error handling code to ensure that it is handling errors correctly.

Structural testing is a very effective way of ensuring that the code is functioning correctly. It is also a good way to detect any potential errors that may be present in the code.
