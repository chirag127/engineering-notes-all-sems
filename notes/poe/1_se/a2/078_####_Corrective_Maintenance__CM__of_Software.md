#### Corrective Maintenance (CM) of Software

Corrective Maintenance (CM) refers to the repairs made to correct faults or fix defects that are detected in software. The defects or errors could be due to bugs in the coding or implementation flaws. The main goals of CM are:

- Fix the defects or errors in software to ensure proper functioning
- Improve software reliability and performance
- Meet the changing requirements and expectations of users

Some key points about CM of software:

- CM is undertaken once the software is in use to rectify issues
- CM requires thorough debugging and testing to locate and fix the root cause of problems
- CM may involve modifications to software code, design or documentation
- CM includes steps like problem identification, defining modifications, implementation and testing
- Effective CM requires maintaining an error log/record to track issues and resolutions
- CM aims to improve software quality and user experience over time through continuous fixes

Advantages of CM:

- Improves software functionality and reliability
- Rectifies issues or bugs that affect performance
- Provides updates or fixes as per user feedback or changing needs
- Extends software lifecycle through ongoing maintenance

Disadvantages of CM:

- Finding and fixing defects can be time-consuming and costly
- CM may introduce new bugs or errors if not implemented properly
- Frequent CM can make software complex and harder to maintain
- CM has to be done carefully to not affect existing software capabilities
