## Unit 4 - Software Testing

Software Testing is a process of evaluating a software item to detect differences between given input and expected output. It helps to identify errors, gaps or missing requirements in order to ensure that the software meets the specified requirements.

Following are the main types of Software Testing:

1. Unit Testing - Testing individual software components/units.
2. Integration Testing - Testing integrated software modules/components to detect interface errors.
3. System Testing - Testing the complete software product as a whole.
4. Acceptance Testing - Testing the software with the customer specified requirements.
5. Performance Testing - Testing the software for determining performance parameters like speed, scalability, load handling etc.
6. Stress Testing - Testing the software with workloads that overrun the normal capacity to identify weaknesses.
7. Recovery Testing - Testing the software's ability to recover from crashes, hardware failures or other catastrophic problems.
8. Security Testing - Testing the software for vulnerabilities, threats and security weaknesses.
9. Usability Testing - Testing the software for user friendliness and ease of use.
10. Install/uninstall Testing - Testing the process of software installation and uninstallation.

Major Test Activities:
1. Test Planning - Developing a test plan document identifying test items, features to be tested, testing tasks, responsibilities, schedule etc.
2. Test Case Design - Designing test cases that will exercise various functionalities and components of the software to uncover errors.
3. Test Environment Setup - Setting up the required hardware, software and other resources needed for testing.
4. Test Execution - Executing the test cases and recording results.
5. Defect Reporting - Logging and reporting defects/bugs found during testing.
6. Test Closure - Finalizing testing and evaluating exit criteria.

Advantages:
- Identifies bugs/defects early and reduces costs of bug fixes.
- Increases software quality and reliability.
- Provides objective measures of software quality.
- Gives confidence for software delivery.

Disadvantages:
- Time consuming and expensive process.
- Difficult to test all possible input combinations.
- Subjective nature of defining test cases.
- Infeasible to uncover all bugs.
