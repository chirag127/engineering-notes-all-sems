### Software Measurement and Metrics in Software Design

Software measurement and metrics are critical for software quality management and control. Some key metrics and measurements in software design are:

1. Size Metrics:
- Lines of Code (LOC): Counts the number of lines of executable code. Gives a measure of program size but does not indicate complexity or quality.
- Program Volume: Measures size in units such as thousands of instructions.
- Function Points: Counts the inputs, outputs, logical files, and external interfaces of a software program to measure size and estimate effort/costs.

2. Complexity Metrics:
- Cyclomatic Complexity: Measures the number of independent paths through a program. High complexity indicates difficult testing and fault-finding.
- Nested Conditionals: Counts the number of conditionals inside conditionals to indicate complexity.
- Parameters: Counts the number of parameters passed to procedures/functions. High number may indicate complex programming.

3. Quality Metrics:
- Reliability: Measures the probability of failure-free operation of a software program for a specified period of time under specified conditions.
- Defect Density: Measures the number of defects identified in a component or system per unit size (e.g. defects/KLOC). A lower value indicates higher quality.
- Maintainability: Measures how easily software can be modified, corrected, or adapted. Factors like readability, complexity, cohesion, coupling, etc. are considered.
