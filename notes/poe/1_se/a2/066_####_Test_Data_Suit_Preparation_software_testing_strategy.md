#### Test Data Suit Preparation software testing strategy

- Test data suit preparation is a software testing strategy in which the tester prepares input data to test the software application thoroughly.
- The test data is prepared based on the following:
-- Requirements of the software application.
-- Boundary values of input.
-- Valid and invalid inputs.
-- Combinations of inputs.
-- Extreme inputs.
- The prepared test data suit should have data to test both normal and exception scenarios of the software application.
- The advantages of using this strategy are:
-- Increased test coverage.
-- Detection of defects at early stages.
-- Regression defects can be detected.
-- The software application can be tested systematically with prepared test data.
- The disadvantages of using this strategy are:
-- Preparation of test data suit requires time and effort.
-- For complex software applications, preparation of test data suit can be challenging.
-- Dynamic testing requirements may require modification in the prepared test data suit.
- Mnemonics to remember:
-- Think of all input types - PRINCE - Positive, Negative, Range, Invalid, Combination, Extreme
-- Cover both normal and exception paths
-- Regression bugs can be caught early
- Examples of test data:
-- For a login screen - correct username and password, incorrect username and correct password, blank username and password, special characters in username and password, etc.
-- For an interest calculator - different interest rates, different loan amounts, different number of years, etc.
