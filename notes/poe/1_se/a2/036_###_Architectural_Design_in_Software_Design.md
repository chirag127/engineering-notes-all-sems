### Architectural Design in Software Design

Architectural design is the process of defining a collection of hardware and software components and their interfaces to establish the framework for the development of a computer system. The key steps in architectural design are:

1. Identify major system components - This involves identifying major system modules needed to satisfy the functional requirements. E.g. For an e-commerce application, the major components could be: product catalog, shopping cart, order management, inventory management, etc.

2. Allocate responsibilities to components - This involves determining the key responsibilities of each component and its interfaces with other components. The design should aim for loose coupling between components.

3. Define interfaces between components - This involves precisely specifying the interfaces between components in terms of the functions/methods to be supported, the data to be exchanged, etc. The interfaces should be clearly defined to enable modularity.

4. Analyze architectural trade-offs - This involves evaluating the pros and cons of the architecture and exploring alternative possibilities. Trade-offs to consider include performance vs modifiability, scalability vs complexity, etc.

Some key qualities of a good software architecture are:

- Modularity - The system is divided into modules with well-defined interfaces. This enhances understandability, maintainability and reusability.
- Loose coupling - Components interact through well-defined interfaces and have minimal dependencies on the internal details of other components. This increases flexibility and robustness to changes.
- Separation of concerns - The system is separated into distinct features or responsibilities. This makes the system easier to understand and manage.
- Scalability - The architecture allows for growth in scope and size. It should be possible to add new features and extra load capacity with minimal impact on existing system structure.

 Mnemonics: ACE IT - Analyze, Components, Interfaces, Evaluate Trade-offs.
Some example architectures: Layered architecture, Pipe and filter, Blackboard, etc.
