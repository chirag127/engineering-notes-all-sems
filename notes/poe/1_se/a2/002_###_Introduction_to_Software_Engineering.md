### Introduction to Software Engineering

1. Software Engineering is an engineering discipline which is concerned with all aspects of software production.
2. It applies engineering principles to software development.
3. It involves a systematic approach to the development, operation, maintenance, and retirement of computer software.
4. The goals of software engineering are to produce software that is:
 - Reliable - consistent, error-free functionality
 - Maintainable - easy to update and change
 - Usable - intuitive and easy to interact with
5. The software engineering process consists of the following activities:
 - Software Requirements Analysis: Determining what the software should do.
 - Software Design: Developing a design that satisfies the requirements.
 - Implementation: Translating the design into a machine-readable form.
 - Testing: Evaluating the software to identify and fix defects.
 - Deployment: Delivering the software to users.
 - Maintenance: Identifying and correcting defects after deployment.
6. Software engineering emphasizes on well-defined engineering approaches with a strong focus on processes, methods, and tools. It involves disciplines like:
 - Project management
 - Software architecture
 - Software testing
 - Software quality assurance
 - Requirements engineering
 - Software configuration management
