#### Compliance with Design and Coding Standards (Coding Standards) Static testing strategy

- Coding standards static testing involves reviewing the source code against a set of well-defined coding standards.
- The coding standards specify programming rules and guidelines for the software to ensure consistent style, readability and functionality.
- Some key points checked in coding standards testing are:
- Naming conventions for variables, functions, classes, etc.
- Formatting rules like indentation, spacing, brackets, etc.
- Comments requirements
- Error handling guidelines
- Restrictions on use of certain programming constructs, etc.
- Benefits of coding standards testing:
- Improves readability and understandability of the code.
- Reduces complexity and potential bugs.
- Ensures a consistent style and functional approach throughout the codebase.
- Helps in onboarding new members to the project easily.
- Some tips for effective coding standards testing:
- Clearly define comprehensive coding standards.
- Automate the testing process using linting tools as much as possible.
- Check for compliance at regular intervals, not just at the end of project.
- Treat violations as bugs and track them closely.
- Overall, coding standards testing increases the quality and reliability of software and is a best practice to follow.
