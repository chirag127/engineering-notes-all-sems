### Constructive Cost Models (COCOMO) in software project management

COCOMO stands for Constructive Cost Models. It is a regression model based on LOC (Lines of Code) to estimate effort, schedule, and cost for software projects.

There are 3 versions of COCOMO:

1. Basic COCOMO - Estimates effort and cost. Requires only 5 inputs.
2. Intermediate COCOMO - Estimates effort, schedule, and cost. Requires 12 inputs.
3. Detailed COCOMO - Provides more detailed estimates. Requires 15 inputs.

**Advantages of COCOMO:**

- Easy to understand and use. Only requires a few inputs to get estimates.
- Considered to be reasonably accurate for initial estimates.
- Can be calibrated for organization/team specific parameters to increase accuracy.

**Disadvantages of COCOMO:**

- Accuracy suffers if requirements are not well-defined.
- Based only on LOC which is a limited measure of software size.
- Does not consider the effects of newer technologies/tools on productivity.
- Accuracy of estimates depends heavily on the values of cost/effort multipliers which are difficult to determine.

**Mnemonics/Learning tricks:**

- Remember 'COCOMO' as 'COst COnstructive MOdel'
- BASIC COCOMO needs only 5 inputs - Bi-weekly, Authorized budget, Schedule, In-house/Organic, Complexity
- Think of Intermediate COCOMO as more detailed than Basic, and Detailed COCOMO as the most detailed of the 3 versions.

**Application:** COCOMO can be used in the early stages of project planning to get an initial estimate of the effort and cost required. The estimates can then be refined further as the project progresses and more details are available.
