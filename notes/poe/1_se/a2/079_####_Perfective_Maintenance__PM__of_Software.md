#### Perfective Maintenance (PM) of Software
Perfective Maintenance (PM) involves making improvements or enhancements to the software. It is also known as preventive software maintenance. The goals of perfective maintenance are:

- Improving the performance of the software
- Improving the usability and user-friendliness of the software
- Aligning the software with the changing requirements and needs of the users
- Adapting the software to work with new operating systems or hardware
- Refactoring the code to make it more readable, maintainable and extensible

Some tips and mnemonics to learn Perfective Maintenance:

- Think of PM as Preventive Maintenance or Performance and Usability Improvement
- Ensure the software is upgraded and not outdated
- Anticipate and address future changes to avoid reactive maintenance
- Improve the software before problems arise
- Enhance the software to exceed user expectations

Advantages:

- Improves the quality and performance of the software
- Increases user satisfaction
- Future-proofs the software
- Reduces technical debt

Disadvantages:

- Requires time and effort
- Increased costs
- Risk of introducing new bugs or defects

Applications:

- Operating system upgrades (e.g. Windows 10 update)
- Software updates (e.g. Adobe Reader update)
- New feature additions (e.g. new filters in Instagram)
- Code refactoring
