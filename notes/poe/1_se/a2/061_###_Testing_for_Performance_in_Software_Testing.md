### Testing for Performance in Software Testing

Following are the key points to cover under Performance Testing in Software Testing:

1. Load Testing: It is done to determine a system's behavior under both normal and peak load conditions. It helps to identify the maximum operating capacity of the software within acceptable response time. Some key parameters to monitor in load testing are:
- Throughput - Number of transactions per second.
- Response time - Time taken to respond to a request.
- Resource utilization - CPU, memory, disk usage, etc.

Mnemonics to remember: As the LOAD increases, check RESPONSE TIME and RESOURCE UTILIZATION.

2. Stress Testing: It is done to determine the system's behavior under abnormal load conditions. The load is increased beyond the maximum capacity to check the system's robustness and identify breaking point. Key checks are:
- Application crash
- Memory leaks
- Resources exhaustion

Mnemonics: Take the system to STRESS to find the BREAKING POINT.

3. Endurance Testing: It is done to ensure that the system can sustain the load for a longer duration. The system is tested under peak load for an extended period of time to identify memory leaks and other performance issues.

The key goals of performance testing are:
- Determine system's response time under normal and peak loads
- Find the system's maximum operating capacity
- Detect performance bottlenecks
- Compare performance against requirements
- Identify ways to scale the system if needed

Performance testing is highly important to:
- Ensure acceptable performance of the system
- Provide good user experience
- Meet performance SLAs
- Optimize costs by proper resource planning
