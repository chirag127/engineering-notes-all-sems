## Unit 1 - Introduction to Software Engineering

1. Software Engineering: Software Engineering is the systematic and disciplined approach to the development, operation, maintenance, and retirement of computer software. It involves applying engineering principles to software development.
2. Software Applications: Software applications or apps are computer programs designed to perform a group of coordinated functions, tasks, or activities for the benefit of the user. Examples include office suites, media players, databases, educational software, etc.
3. Software Development Process: The software development process involves the following phases -

- Requirements Analysis: Determining the requirements of the software to be developed.
- Design: Coming up with a design that satisfies the requirements.
- Implementation: Implementing the design in a programming language.
- Testing: Testing the software to identify and fix bugs.
- Deployment: Deploying the software for user use.
- Maintenance: Making modifications to the software as required.

4. Software Development Methodologies: The methodologies define a systematic process for software development. Some popular methodologies are:

- Waterfall Model: Sequential development process. Rigid phases.
- Agile Methodology: Iterative development process. Accommodates changes. Eg. Scrum, XP, etc.
- DevOps: Integrates software development and IT operations. Focuses on collaboration and automation.

5. Software Quality Attributes: The key software quality attributes are:

- Correctness: Meeting functional requirements.
- Reliability: Ability to perform without failure.
- Security: Protection from unintended access or malicious attacks.
- Efficiency: Good performance with optimal resource utilization.
- Maintainability: Ease of making changes and fixing issues.
- Portability: Ability to be used on different platforms or environments.
