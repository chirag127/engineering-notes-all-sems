### Feasibility Study in Software Requirement Specification (SRS)

- Feasibility study is an assessment of the practicality of a proposed project or system. It is conducted to determine if a project idea is viable and worth pursuing.
- In SRS, feasibility study is performed to check if the software can be developed with available resources and technologies within the given time and cost constraints. It evaluates the project from technical, economic and operational feasibility perspectives.
- **Technical Feasibility** - Checks if the software can be developed with available technology and resources. It considers if the organization has skilled developers and necessary tools/software required for the project.
- **Economic Feasibility** - Estimates if the software can be developed within the budget constraints. It calculates costs vs benefits to determine if the project is profitable.
- **Operational Feasibility** - Evaluates if the software can be integrated with existing systems and if the organization can support and maintain the software. It checks if the software meets business requirements and user needs.

**Mnemonics:**

- Can we build it? (Technical)
- Can we afford it? (Economic)
- Can we use it? (Operational)

**Advantages:**

- Saves time and cost by avoiding unfeasible projects.
- Increases chances of project success by evaluating feasibility early on.
- Identifies potential issues and provides solutions before implementation.

**Applications:** Feasibility study is performed for all software/system development projects to determine if the project should be undertaken. It provides a structured approach to assess the viability and practicality of a project.
