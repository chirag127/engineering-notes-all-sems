#### Various Size Oriented Measures in Software Design

Following are the various size oriented software measures -

1. Lines of Code (LOC) - It is the count of lines in the source code of a software. It is a basic measure but not a good measure as it does not considers the complexity of lines.

2. Number of Modules - It is the count of number of modules or components in a software. It gives a coarse level measure of size but does not capture the internal complexity of modules.

3. Function Points - It is a measure that counts the functionalities provided by the software based on number of inputs, outputs, inquiries, files, and interfaces. It is a better measure than LOC but difficult to calculate and not very objective.

4. Object Points - Similar to Function Points but counts the objects and their interactions in an object oriented software. It faces similar challenges as Function Points.

5. Use Case Points - It is based on use cases in a software and counts various factors like actors, use cases, and complexity to get a size measure. It is also subjective and difficult to calculate.

**Advantages** - These measures can give a rough idea of size of software which can be useful for effort and cost estimation.
**Disadvantages** - These measures are not very objective, difficult to calculate, and do not consider the complexity of internal components.
**Applications** - These are mostly used in academia to introduce the concept of software size measures. In industry, LOC is used occasionally but other measures are not very popular.
