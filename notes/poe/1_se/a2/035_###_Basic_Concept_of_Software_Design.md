### Basic Concept of Software Design

The basic concepts of software design are:

1. Modularity: The software should be divided into modules that are loosely coupled and highly cohesive. Each module should have a specific functionality. This increases reusability, maintainability, and comprehensibility of the software.

Mnemonic: Divide and Conquer - Break down the problem into smaller modules.

2. Abstraction: The complexity of the software is hidden and its functionality is exposed to the user without explicit implementation details. This separates the implementation and interface.

Mnemonic: Hide the complexity, show the simplicity.

3. Hierarchy: The modules are arranged in a hierarchical order where higher level modules utilize the services of lower level modules. This promotes decomposition and better management.

4. Encapsulation: The internal details of a module are hidden from other modules and only the interface is exposed. This promotes information hiding and reduces dependencies between modules.

5. Loose Coupling: Modules are loosely dependent on each other and the changes in one module does not affect other modules. This increases reusability, robustness, and stability of the software.

Tightly Coupled: Changes in one module affect other modules. This should be avoided.

The advantages of these concepts are:
- Increased reusability of modules
- Increased maintainability as modules can be modified independently
- Increased comprehensibility as the complexity is divided and managed
- Increased scalability and flexibility to changes

The software design concepts can be applied while designing complex enterprise software, interactive user interfaces, distributed systems, etc. to tackle their complexity and build robust and high quality software solutions.
