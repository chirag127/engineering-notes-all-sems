#### Object Oriented Design in Software Design

- Object Oriented Design (OOD) is a software design approach based on objects and classes.
- Key principles of OOD:
    - Encapsulation - Hiding internal details and showing functionality through interfaces.
    - Inheritance - Inheriting common properties from a base/parent class.
    - Polymorphism - Override methods to provide specific implementation.
    - Abstraction - Hiding complexities and showing essential features.
- Advantages of OOD:
    - Modular design - Easy to maintain and extend.
    - Reusability - Common logic can be reused.
    - Simulation - Closely models real-world scenarios.
    - Flexibility - New classes can be easily added.
- Disadvantages of OOD:
    - Inefficient if not designed properly - can lead to redundant code.
    - Steep learning curve for beginners.
    - Difficult to debug and test.
- Examples of OOD:
    - Vehicle class extended to Car, Bike, etc.
    - Animal class extended to Dog, Cat, etc.
- Applications of OOD:
    - Software modeling complex real-world systems.
    - Large enterprise application development.
    - Game development.

Some mnemonics to remember OOD:

- Encapsulate - Hide secrets (data)
- Inherit - Use family traits (reuse code)
- Polymorph - Mimic your kind (override methods)
- Abstract - Simplify and generalize
