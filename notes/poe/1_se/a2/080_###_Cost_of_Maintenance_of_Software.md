### Cost of Maintenance of Software

The cost of maintaining software includes:

1. Fixing bugs or errors: As software is used, bugs or errors are discovered which need to be fixed. This requires time and effort of programmers which adds to the cost.
2. Updating software: Software needs to be updated frequently to fix bugs, add new features and make it compatible with new hardware/software. This updating process requires time and resources leading to maintenance cost.
3. Providing technical support: Software companies have to provide technical support to users facing issues. This support is provided via emails, phone calls or chat which adds to the cost of maintaining the software.
4. Training users: When software is updated with new features, users need to be trained to use the new features. This training also adds to the overall maintenance cost of the software.

Some tips to reduce maintenance cost:

- Hire experienced programmers to write high quality bug-free code which requires less fixing.
- Adopt modular approach which makes updating specific modules easy without affecting the entire software.
- Provide self-help documentation to reduce technical support requests.
- Offer online video tutorials to train users at their own pace.

In conclusion, though maintenance costs are inevitable, they can be optimized by taking certain measures during and after the software development process. Keeping maintenance costs low is important to maximize profits from software.
