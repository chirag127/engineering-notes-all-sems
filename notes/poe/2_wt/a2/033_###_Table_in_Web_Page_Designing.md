### Table in Web Page Designing

- A table is a structured two-dimensional data represented in rows and columns. Tables are used to organize data and make it readable.
- In web page designing, tables are used to arrange data in an orderly form. They help in structuring and formatting the layout of a web page.
- The main elements of a table are:

1. Table - Defines a table. It is wrapped around the whole table.
2. Table Row - Defines a row in the table.
3. Table Header - Defines a header for a group of columns.
4. Table Data/Cell - Defines a cell in the table that contains data.
5. Colspan - Used to extend a cell across multiple columns.
6. Rowspan - Used to extend a cell across multiple rows.

- Some important attributes used with tables are:

1. Border - Used to specify the width of the border of the table and cells.
2. Cellpadding - Used to specify the space between the cell wall and the cell content.
3. Cellspacing - Used to specify the space between cells.
4. Width - Used to specify the width of the table.
5. Height - Used to specify the height of the table.
6. Alignment - Used to specify the alignment of content in a column or a cell.

- Advantages: Tables provide an organized structure to data and layout. They are supported by all browsers and are easy to create.
- Disadvantages: Tables can make web pages load slowly. They are not much flexible and accessing data from tables using scripts is difficult.
- Mnemonics: Think of a table as a grid. The table element is the whole grid. Rows and cells are parts of the grid. Colspan and Rowspan extend the grid.
