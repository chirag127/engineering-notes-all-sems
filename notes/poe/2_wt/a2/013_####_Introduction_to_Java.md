#### Introduction to Java

- Java is a programming language and computing platform initially released by Sun Microsystems in 1995. It is one of the most popular programming languages in the world and is used to develop mobile apps, server-side apps, and more.
- Some key points about Java:

1. It is object-oriented: Java supports object-oriented programming and concepts like inheritance, encapsulation, polymorphism, etc. are fundamental to Java.

2. It is platform independent: Java bytecode can run on any machine that has a Java Virtual Machine. This makes Java platform independent and portable.

3. It is secure: Java has a security model that prevents unauthorized access of resources.

4. It is robust: Java compilers detect many errors and bugs that are handled automatically by the Java runtime system. This makes Java robust and less prone to crashing.

5. It is multithreaded: Java provides inbuilt support for multithreaded programming which allows concurrent execution of two or more parts of a program to maximize performance.

6. It is architecture neutral: Java source code is compiled into bytecode which can run on any system architecture as long as a JVM is available for it.

7. It is high performance: With the use of just-in-time compilers, Java enables high performance.

8. It is dynamic: Java is considered to be more dynamic than C or C++ as it supports features like reflection, libraries, and garbage collection.

Some key terms to know:

- JVM: Java Virtual Machine is the runtime environment for Java bytecode. It is the interface between the compiled Java program and the underlying OS.
- JDK: Java Development Kit contains the JVM, Java tools and libraries to develop Java programs.
- JRE: Java Runtime Environment contains the JVM and Java libraries but does not include development tools like the compiler.
