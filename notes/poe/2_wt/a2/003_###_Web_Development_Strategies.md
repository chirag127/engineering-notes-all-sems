### Web Development Strategies

1. Responsive Web Design:
- Develop websites that work on all devices and window or screen sizes.
- Advantage: Single website for all devices, easy maintenance.
- Disadvantage: Increased development time and cost.
- Key techniques: Fluid layouts, media queries, flexible grids, images, and videos.

2. Mobile-First Approach:
- Develop for mobile devices first and then scale up for larger screens.
- Advantage: Prioritize core features and functionalities, faster loading websites.
- Disadvantage: May not utilize larger screen space effectively.
- Key techniques: Minimalist design, hamburger menu, modal windows.

3. Progressive Web Apps (PWAs):
- Websites that behave like native mobile apps.
- Advantage: App-like experience, work offline, push notifications.
- Disadvantage: Require service workers and manifest files, limited device support.
- Key features: Web app manifest, service worker, HTTPS, and app shell architecture.

4. AMP (Accelerated Mobile Pages):
- Open-source initiative to build fast-loading mobile pages.
- Advantage: Near-instant load times, increased visibility and traffic.
- Disadvantage: Limited customization and functionality.
- Key requirements: AMP HTML, AMP JS, and cached AMP JS files.

Mnemonics and learning tricks:
- RWD: Think of a shape-shifter website that responds to the device.
- Mobile-first: Think of a narrow viewport and then expanded for larger screens.
- PWAs: Think of websites behaving like apps and working offline with notifications.
- AMP: Think of fast-loading web pages for a quick mobile reading experience.
