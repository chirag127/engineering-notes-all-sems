### History of Web

The World Wide Web has a history spanning back to the 1980s and early 1990s. Here are the major milestones in the history of the Web:

- **1989:** Tim Berners-Lee invents the World Wide Web while at CERN in Switzerland. He creates the first web browser computer program and the first web pages.
- **1990:** Tim Berners-Lee creates the first web server computer program and the HTML markup language. The first web browser is introduced.
- **1991:** The first web pages are created and the first web servers are introduced. The first images are introduced, embedded in web pages.
- **1993:** The first commercial web browser is introduced, Mosaic. The first commercial web servers and web hosting companies are formed.
- **1994:** The first online stores and web advertising enters the scene. SSL encryption is introduced to support e-commerce and web-based email.
- **1995:** The JavaScript and Java programming languages are introduced, enabling interactive websites and web applications.
- **1998:** The Google search engine is launched, ushering in a new era of searching and finding information on the Web.
- **2004:** The term "Web 2.0" is coined, referring to interactive and user-generated content websites. Services like Gmail, Facebook, and Flickr gain popularity.
- **2006:** The term "social media" starts being used, referring to websites and apps focused on social interaction and content creation.
- **2008-2010:** Smartphones and tablets gains widespread adoption, making the Web accessible from mobile devices and introducing the mobile Web.
- **Today:** The Web has become deeply integrated into many areas of business and personal life. AI and machine learning powers new types of web experiences. More of the world comes online for the first time via mobile devices.

Some learning tricks to remember the history:

- Tim Berners-Lee invented the Web in 1989 ( ends in 89 )
- First images, browsers, servers in 1990s ( ends in 90s )
- E-commerce, JavaScript, Java in mid-1990s ( mid-90s )
- Google in 1998 ( ends in 98 )
- Web 2.0 & social media in 2000s ( 00s )
- Mobile web & today's AI-powered web ( present )
