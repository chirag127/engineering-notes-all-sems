### Protocols Governing Web

The World Wide Web works on the client-server model. The web browsers act as clients and the web servers act as servers. For the communication between the clients and servers, certain protocols are followed:

1. Hypertext Transfer Protocol (HTTP): It is the underlying protocol of the World Wide Web. It defines how messages should be formatted and transmitted between the clients (web browsers) and the servers (web servers), and what actions web servers and browsers should take in response to various commands. For example, when a web page is requested, an HTTP command is sent to the web server directing it to fetch and transmit the requested webpage.

HTTP works on TCP/IP protocol for transmission of data over the Internet. Some key aspects of HTTP are:

- It is a stateless protocol. Each command is executed independently, without any knowledge of the commands that came before it.

- It allows the transfer of web pages that contain hypertext links to other pages.

- The latest version is HTTP/2 which is faster than HTTP/1.1 and reduces latency.

2. Hypertext Markup Language (HTML): It is the main markup language for creating web pages. It uses a series of elements consisting of tags enclosed in angle brackets. HTML elements tell the browser how to display the content such as text, images, links, tables, etc. The latest version is HTML5 which allows the incorporation of multimedia and graphical content without the use of plugins.

3. Cascading Style Sheets (CSS): CSS is used to style the HTML elements and define properties such as color, font, layout, etc. It helps in separating the presentation aspect of a web page from its content. Multiple style sheets can be defined, and the one which is listed last takes the highest precedence (hence the term "cascading").
