### JavaScript in Scripting

JavaScript is a lightweight, interpreted programming or scripting language that is typically embedded into web pages. This allows web pages to be interactive and more dynamic. JavaScript is versatile and can be used for both client-side and server-side scripting.

Some key points about JavaScript in scripting:

1. JavaScript is used to create interactive effects within webpages such as buttons, popups, sliders, etc. It can react to user events such as clicks or mouse movements.
2. JavaScript can be embedded into HTML pages directly or via JavaScript files. The `<script>` tag is used to embed JavaScript code into HTML.
3. JavaScript code is interpreted by a browser and executed by a JavaScript engine. This allows webpages to be more responsive and dynamic without needing to refresh the page.
4. JavaScript follows a prototype-based object model and supports functions, objects literals, etc. It is loosely based on Java language syntax, but the two languages are distinct and incompatible.
5. Common uses of JavaScript for scripting include:
   - Validating web forms before submission
   - Creating cookies and sessions to remember users
   - Animations and dynamic styling effects
   - Interactive maps
   - Online calculators
   - Mobile app development (using frameworks like React Native or Flutter)

Some mnemonics/learning tricks for JavaScript:

- "Java" Script = it is related to Java in name only. The languages are quite different.
- "Javascript" (one word) = the official name is JavaScript, not two separate words "Java Script".
- "ECMAScript" = JavaScript is an implementation of the ECMAScript standard. ECMAScript defines the language syntax/features.
- "It's just a script!" = JavaScript is run/interpreted at runtime and is lighter weight than a compiled language. It's suited for scripting/gluing together webpages.
