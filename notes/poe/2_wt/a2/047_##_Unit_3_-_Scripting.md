## Unit 3 - Scripting

1. Scripting languages are interpreted languages that are executed at runtime. They are easy to write and flexible but slower than compiled languages.
2. Some popular scripting languages are:
- Python - Easy to learn, versatile, powerful scripts and applications. Used for both scripting and application development.
- JavaScript - Used to create interactive effects within web browsers. Core part of web development.
- PHP - Server side scripting language used to create dynamic web pages.
- Shell Script - Scripts that provide a shell, the interface to an OS, with additional automation and functionality. Used for task automation and system administration.

**Advantages of scripting languages:**
- Easy and quick to code.
- Flexible and can adapt to changing requirements.
- Used for both simple and complex tasks.
- Portable across systems/platforms.

**Disadvantages of scripting languages:**
- Typically slower than compiled languages.
- Prone to errors/bugs as languages are interpreted at runtime.
- May face dependency issues.

**Some examples and use cases:**

- Python scripts to automate regular tasks like data processing or generating reports.
- JavaScript to create interactive web pages and front-end logic.
- PHP scripts to create serverside logic and dynamic web pages.
- Shell scripts to automate admin tasks on Linux/Unix systems like backups or software deployments.

**Mnemonics/memory tricks:**

- "Scripting languages are slipping and sliding but compiled languages are fast and flying." - To remember scripting languages are interpreted and slower but more flexible than compiled languages.
- "PHP, a scripting language, makes web pages happy." - To remember PHP is a scripting language used to create dynamic web pages.
