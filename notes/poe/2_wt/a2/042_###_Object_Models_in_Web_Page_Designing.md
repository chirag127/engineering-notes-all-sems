### Object Models in Web Page Designing

The following are the key object models used in web page designing:

1. Document Object Model (DOM):
- It is a programming interface for HTML and XML documents.
- It represents the page so that programs can change the document structure, style, and content.
- The DOM is updated as the page is loaded to represent the constructed document.
- Mnemonic: The DOM models the document as objects which can be manipulated.

2. Cascading Style Sheets Object Model (CSSOM):
- It is the object model that represents style sheets as objects.
- It allows CSS to be manipulated by programs.
- The CSSOM represents styles as objects and relationships between them as properties of the objects.
- Mnemonic: The CSSOM models styles as objects which can cascade.

3. Abstract Syntax Tree (AST):
- It represents the structure of source code as a tree of nodes.
- It allows source code to be processed programmatically.
- The AST is platform and language independent and can be generated from the source code.
- Mnemonic: The AST models the syntax abstractly as a tree structure.

Advantages:
- Object models provide a programmatic interface to interact with and manipulate web pages.
- They enable dynamic web pages which can change in response to user actions, server interactions, etc.
- They enable web development frameworks and tools to be built.

Disadvantages:
- Object models can add processing overhead.
- They require programming knowledge to utilize.
- The DOM can become complex for large, interactive web pages.
