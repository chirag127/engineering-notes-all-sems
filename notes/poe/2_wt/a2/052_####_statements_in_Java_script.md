#### FOR Loop

**Mnemonics:** For each loop, specify start, end and increment.

**Format:**
for (init counter; condition; increment) {
    // code block to be executed
}

**Example:**
for (let i = 0; i < 5; i++) {
    console.log(i);
}

**Advantages:**
- It is used to repeat a block of code a known number of times.
- It is often used when the number of iterations is known beforehand.

**Disadvantages:**
- It can lead to infinite loops if the condition is not properly handled.

**Applications:** Used to iterate over arrays or objects, repeat executions, etc.

#### WHILE Loop

**Mnemonics:** While a condition is true, the loop will keep executing.

**Format:**
while (condition) {
    // code block to be executed
}

**Example:**
let i = 0;
while (i < 5) {
    console.log(i);
    i++;
}

**Advantages:**
- It is used when the number of iterations is not known beforehand. The loop continues until the condition evaluates to false.

**Disadvantages:**
- It can lead to infinite loops if the condition is not properly handled.

**Applications:** Used to iterate until a condition is met, repeat executions, etc.
