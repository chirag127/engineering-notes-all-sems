#### Internet Addressing in Networking

- IP addresses are used to uniquely identify devices on a network and route data between networks. They consist of 32 bits expressed in decimal notation as four octets separated by periods (e.g. 192.168.1.1).
- The IP address space is divided into five classes (A, B, C, D, and E) to aid efficient routing and traffic management:
    - Class A addresses have a first octet between 1 and 126 and are assigned to large organizations.
    - Class B addresses have a first octet between 128 and 191 and are assigned to medium-sized organizations.
    - Class C addresses have a first octet between 192 and 223 and are assigned to small organizations and businesses.
- A private IP address range (10.0.0.0 - 10.255.255.255, 172.16.0.0 - 172.31.255.255, and 192.168.0.0 - 192.168.255.255) is reserved for local networks not connected directly to the Internet.
- IP addresses can be assigned dynamically (via DHCP) or statically. Dynamic IP addresses are leased to devices temporarily and can change, while static IP addresses are permanently allocated to devices.
- The IPv6 protocol was created to address the limited supply of IPv4 addresses. It uses 128-bit addresses expressed in hexadecimal notation and supports a vastly larger address space than IPv4.
- Learning tricks:
    - Memorize the IP address classes by mnemonics like 'Adam Buys Candy Everyday' for A, B, C, D, and E.
    - Songs and rhymes can help memorize the private IP ranges.
    - For IPv6 addresses, focus on recognizing the hexadecimal format and know that it has a much larger address space than IPv4.
