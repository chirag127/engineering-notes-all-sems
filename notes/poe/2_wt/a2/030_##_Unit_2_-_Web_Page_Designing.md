## Unit 2 - Web Page Designing

1. HTML: Hypertext Markup Language is the main markup language used to create web pages. It uses tags like <html>, <head>, <title>, <body>, <h1>, <p>, etc. to structure a web page and add content. Some important points to remember:
- Tags are enclosed in angular brackets <>.
- There are opening tags <p> and closing tags </p> for most HTML elements.
- The <html> tag specifies the root/parent element of an HTML document.
- The <head> tag contains meta information about the HTML document. The <title> tag inside <head> specifies the title of the web page.
- The <body> tag contains the visible page content. Headings are specified using <h1> to <h6> tags. <p> denotes a paragraph.
- Attributes provide additional information about elements. They are always specified in the opening tag. For e.g. <a href="link"> is a link with href as the attribute.

2. CSS: Cascading Style Sheets is used to style the HTML elements and specify the layout of a web page. Some key points:
- CSS rules are made up of selectors and declarations. Selectors specify the HTML elements to be styled. Declarations consist of properties and values.
- Common CSS selectors are element selectors (select elements by name), id selectors (select by id attribute), class selectors (select by class attribute), and universal selector (select all elements).
- Common properties for text styling include color, background-color, font-family, font-size, etc. Some properties for layout styling are width, height, margin, padding, float, etc.
- Internal, external and inline stylesheets can be used to add CSS to HTML. External stylesheets are preferred as they separate the style from the content and allow styles to be reused.
- The Box model in CSS treats every element as a box with properties like margin, border and padding surrounding the content.
