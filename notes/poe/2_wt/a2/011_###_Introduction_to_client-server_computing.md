### Introduction to client-server computing

Client-server computing refers to a distributed application structure that separates tasks between the **client** and the **server**. In this model -

- The client makes requests to the server.
- The server processes the requests and returns a response to the client.

Some key points about client-server computing -

1. The client handles the user interface and input. It sends requests to the server to retrieve or store data as needed.
2. The server handles data storage and processing. It retrieves or manipulates data as per the client's requests and returns the response.
3. The client and server can be computers, applications or devices and communicate over a network.
4. This separation of concerns improves modularity, scalability, security and resource utilization.
5. Popular examples are websites (client is browser, server is web server) and mobile apps (client is app, server is API).

_Mnemonics_ - A clever phrase to remember could be - "Client requests, server addresses".

_Advantages_ - Scalability, Flexibility, Maintainability, Resource optimization.
_Disadvantages_ - Extra overhead of network communication, Additional servers and infrastructure required.

_Applications_ - Websites, Mobile apps, Enterprise software, Cloud computing, etc.
