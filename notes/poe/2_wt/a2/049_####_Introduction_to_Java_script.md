#### Introduction to Java script

Java Script is a lightweight, interpreted programming or scripting language that is typically embedded into web pages. It allows web pages to be interactive and more dynamic. Some key points about Java Script are:

- It is case sensitive. Variable and function names are case sensitive.
- It is interpreted, not compiled. Java Script code is executed directly by the browser.
- It is embedded in HTML pages. Java Script code is enclosed within <script> and </script> tags in an HTML page.
- It is an object-based language. In Java Script, almost everything is an object.
- It is a weakly typed language. You do not need to specify data types of variables, functions, etc.

Some mnemonics to remember characteristics of Java Script:

- JS is not Java: Though the names are similar, Java and Java Script are quite different. Java is a compiled language, Java Script is interpreted.
- JS loves objects: Almost everything in Java Script is an object which makes it easy to use and learn.
- JS in the browser: Java Script code is embedded in HTML and runs in the browser.

Key applications of Java Script are:

- Client side form validation: You can use Java Script to validate form data before submitting to the server. For example, check if all fields are filled, validate email address format, etc.
- Dynamic HTML: You can change the content and styling of a web page dynamically using Java Script. For example, show/hide elements, change images, animate elements, etc.
- JavaScript Object Notation (JSON): JSON is a data interchange format based on Java Script object syntax. It is often used to transmit data in web applications.
- JavaScript frameworks: There are many popular JavaScript frameworks like React, Angular, Vue, etc. to develop single page applications and dynamic web pages.
- Node.js: You can run Java Script on the server-side using Node.js to build fast and scalable network applications.
