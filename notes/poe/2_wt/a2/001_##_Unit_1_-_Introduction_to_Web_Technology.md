## Unit 1 - Introduction to Web Technology

- Web technology refers to the languages and tools used to create web pages and web applications. The key languages and technologies are:
    - HTML - Hypertext Markup Language: Used to structure and layout web pages.
    - CSS - Cascading Style Sheets: Used to style web pages and control presentation.
    - JavaScript: Used to add interactivity and dynamic features to web pages.
    - APIs - Application Programming Interfaces: Interfaces to interact with databases, servers, and other services.
- The web is built on top of the Internet, which is a global network of computers that can communicate with each other using a common language/protocol called HTTP (Hypertext Transfer Protocol).
- Key terms:
    - Web server: A computer that delivers web pages.
    - Web browser: A software application used to access and display web pages.
    - URL (Uniform Resource Locator): The address of a web page.
    - Web hosting: The service of storing a website/web application and making it accessible via the Internet.
- Mnemonics:
    - HTML is for Structure
    - CSS is for Style
    - JavaScript is for Interaction
- Learning tricks:
    - Practice writing HTML, CSS and JavaScript code to understand how they work.
    - View the source code of websites to see how they are constructed.
    - Try modifying the code of simple web pages to see the effect of changes.
    - Build some basic web pages/applications to apply the learning.
- Advantages: The web provides a vast amount of information and services that can be accessed from almost any device with an Internet connection.
- Disadvantages: The web has enabled new forms of criminal activity like fraud, scams, and dissemination of misinformation. Privacy and security are ongoing concerns.
- Examples: Google, Facebook, Wikipedia, E-commerce sites, etc.
- Applications: The web is used extensively for information access, e-commerce, social networking, business applications, and more. It has transformed numerous aspects of society.
