#### AWT controls

The AWT (Abstract Windowing Toolkit) contains a set of GUI components/controls like buttons, labels, text fields, etc. that can be used to develop GUI based Java applications.

- **Buttons:** Used to get user input in the form of clicks. Ex: Push buttons, Radio buttons, Check boxes, etc.
- **Labels:** Used to display text/images on the UI. Ex: Text labels.
- **Text fields:** Used to get single line text input from the user. Ex: TextField.
- **Text areas:** Used to get multi-line text input from the user. Ex: TextArea.
- **Lists:** Used to display a list of items and get selections from the user. Ex: List, Choice.
- **Scroll panes:** Used to add scrolling functionality to a container like a frame. Ex: ScrollPane.
- **Menus:** Used to provide pull-down/pop-up menu functionality. Ex: Menu, MenuItem, etc.
- **Layout managers:** Used to arrange the components in a organized way within the container. Ex: FlowLayout, BorderLayout, GridLayout, etc.

**Mnemonics:**
- B for Buttons, L for Labels, T for Text fields/areas, Li for Lists, etc.
- Also, radio buttons are round, check boxes have a tick, etc. for visual cues to remember.

**Advantages:**
- Simple and easy to learn API.
- Provides basic GUI components to develop desktop applications.
- Cross-platform compatibility.

**Disadvantages:**
- Heavy and inefficient as it is based on native system components.
- Limited functionality as compared to Swing and JavaFX.
- Not suitable for complex and dynamic GUI applications.

**Applications:** Can be used to develop basic desktop applications with simple GUI requirements like calculators, notification apps, etc.
