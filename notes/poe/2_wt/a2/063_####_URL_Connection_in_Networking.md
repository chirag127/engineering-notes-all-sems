#### URL Connection in Networking

- URL stands for Uniform Resource Locator. It is an address that specifies the location of a resource on the Internet.
- A URL has the following structure:

Protocol://Hostname:Port/Path?Query#Fragment

For example: https://www.wikipedia.org/wiki/URL

- The protocol specifies the protocol to use to access the resource. For example, HTTP, FTP, SMTP, etc.
- The hostname specifies the domain name of the server that hosts the resource.
- The port number specifies the port to connect to on the server. If omitted, default ports are used (80 for HTTP, 21 for FTP, etc.).
- The path specifies the path to the resource on the server.
- The query string contains query parameters that are passed to CGI scripts or server-side programs.
- The fragment identifier refers to a portion of the resource, often used for anchor links in HTML pages.

Mnemonics to remember URL structure:

Please Phone Sally At Work Before Evening Party

P - Protocol
H - Host
S - Slash (Path)
A - At (Username/Password)
W - With (Query String)
B - Before (Fragment)
E - Evening (Port)
P - Party (Path)

Advantages:
- URLs allow resources to be located and accessed.
- They are human-readable and standardized.

Disadvantages:
- URLs can be long and complex.
- They expose the underlying structure of the server and resources.

Applications:
- Browsing the web
- Hyperlinking between web pages
- Accessing web services
- And more...
