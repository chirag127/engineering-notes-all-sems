# Web Technology

## HTTP (Hypertext Transfer Protocol)
- Mnemonic: Every Good Boy Does Fine (for remembering request methods: GET, POST, PUT, DELETE, HEAD, OPTIONS, TRACE, CONNECT)
- HTTP is a stateless protocol built on top of TCP that is used for communication between web clients and servers.
- It defines methods (GET, POST, etc.) for indicating the desired action to be performed on the identified resource.
- It includes status codes (200, 404, 500, etc.) for indicating the outcome of the request.
- HTTP is the foundation of data communication for the World Wide Web.

## HTML (Hypertext Markup Language)
- HTML is the main markup language for creating web pages and web applications.
- It uses tags like <html>, <head>, <title>, <body>, <h1>, <p>, <img>, etc. to structure and give meaning to web content.
- Key features include ease of learning, platform/vendor independence, extensibility, and reduced bandwidth usage compared to other common formats.
- HTML has evolved through versions from HTML 1.0 to the current HTML5 with new features like video, audio, canvas, etc. added while maintaining backward compatibility.
