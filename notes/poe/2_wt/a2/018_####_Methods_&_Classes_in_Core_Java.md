#### Methods & Classes in Core Java

- **Class:** A class is a blueprint that defines the structure and behavior of a particular type of object. It encapsulates data and functions into a single unit.
- **Methods:** A method is essentially a block of code that performs a specific task. It is also known as a function and is used to perform certain actions, and they are bundled as part of a class.
- **Constructors:** A constructor is a special type of method that is used to instantiate (create) objects. It has the same name as the class and is used to set up the initial state of the object.
- **Access Modifiers:** Access modifiers are keywords that are used to specify the access level of classes, methods, and other members. The main access modifiers are:
	- Public: Accessible from anywhere
	- Private: Only accessible from within the declaring class
	- Protected: Accessible from the declaring class and subclasses
	- (No modifier): Default access, only accessible from within the package
- **Inheritance:** Inheritance is a mechanism in which one class acquires the properties and behaviors of another class. The class that inherits the properties of another class is called a subclass, and the class being inherited from is called a superclass. This allows code reuse and promotes abstraction.
- **Polymorphism:** Polymorphism means having many forms. In OOP, polymorphism means that a call to a member function will cause a different function to be executed depending on the type of object that invokes the function. There are two types: compile-time polymorphism and runtime polymorphism.
- **Abstraction:** Abstraction is a key concept in object-oriented programming. It refers to the act of representing essential features without including the background details or explanations. Java uses abstraction through abstract classes and interfaces.
- **Encapsulation:** Encapsulation in Java is a mechanism of wrapping the data (variables) and code acting on the data (methods) together as a single unit. In encapsulation, the variables of a class will be hidden from other classes, and can be accessed only through the methods of their current class. Therefore, it is also known as data hiding.

Mnemonics and Learning Tricks:
- Class = Blueprints
- Methods = Actions
- Constructors = Creators
- Access Modifiers = Access Levels
- Inheritance = Acquiring Properties
- Polymorphism = Many Forms
- Abstraction = Hiding Details
- Encapsulation = Data Hiding
