### Introduction to Web Technology

- The World Wide Web (WWW) refers to the massive network of information available on the Internet. The Web is a way of accessing information on the Internet via websites.
- The basic technologies of the Web are Hypertext Transfer Protocol (HTTP), Hypertext Markup Language (HTML), and URLs.
- **Hypertext Transfer Protocol (HTTP)**: HTTP is the set of rules for transferring web pages on the Internet. It defines how messages should be formatted and transmitted and what actions web servers and browsers should take in response to various commands.
- **Hypertext Markup Language (HTML)**: HTML is the main markup language used to create web pages. It uses tags like <html>, <head>, and <body> to structure a web page and uses additional tags to add images, links, formatting, etc.
- **Uniform Resource Locators (URLs)**: URLs are addresses that specify the location of a resource on the Web. They include the protocol (like http://), domain name, and path to the resource.
- Mnemonics: Never Eat Soggy Waffles (for HTTP, HTML, URLs)
- Learning tricks: Practice building simple web pages using HTML to understand the language and see how web pages are constructed. Play around with adding images, links, and formatting to get a hands-on feel for how HTML works.
- Advantages: The Web is a highly accessible way to share information globally. It is easy to navigate and is built on open standards and technologies.
- Disadvantages: The massive amount of information on the Web can be overwhelming and difficult to search. The open nature of the Web also introduces security and privacy issues.
- Applications: The Web has a wide range of applications, including accessing information, e-commerce, social networking, streaming media, and more. It has transformed numerous aspects of society and enables constant global communication and access to resources.
