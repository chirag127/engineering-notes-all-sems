### XML schemes in Web Page Designing

1. XHTML - eXtensible Hypertext Markup Language
- It is a stricter and cleaner version of HTML.
- Follows XML rules.
- Must have a root element.
- Elements must be properly nested.
- Attributes must have quotes.
- All elements must be closed.
- Example: `<html xmlns="http://www.w3.org/1999/xhtml">`

Mnemonics: XHTML is like a perfectionist HTML which follows all rules strictly.

2. SVG - Scalable Vector Graphics
- Uses XML-based image format.
- Contains shapes like circles, rectangles, lines, curves, etc. defined in XML.
- Scales well and can be searched, indexed, scripted, and compressed.
- Useful for logos, icons, graphs, diagrams, illustrations, etc.
- Example: `<svg width="100%" height="100%">`

Mnemonics: SVG is a drawing in XML.

3. MathML - Mathematical Markup Language
- XML application for describing mathematical notations and capturing both its structure and content.
- Allows mathematics to be served, received, and processed on the Web.
- Used by LaTeX, Mathematica, etc. for rendering mathematics.
- Consists of elements for structure, style, and content.
- Example: `<math>` ... `</math>`

Advantages: Platform independent, accessible to technologies like speech synthesizers, supports internationalization, etc.

Disadvantages: Limited browser support, steep learning curve.

Applications: Scientific documents, education, etc.
