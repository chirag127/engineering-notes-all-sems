### Core Java

* Java is a class-based, object-oriented programming language that is designed to be platform independent.
* Some key points to remember:

**Platform Independence:** Code once, run anywhere. Java bytecode can run on any Java Virtual Machine (JVM).
**Object Oriented:** Everything in Java is an Object. It supports features like Inheritance, Abstraction, Polymorphism, Encapsulation.
**Simple:** Java removes pointers and uses references instead for memory management. It is designed to be simpler than C/C++.
**Secure:** Java has a Security Manager that defines access rights for classes. It also has other security features like sandboxing, JVM verification, etc.
**Architecture Neutral:** Java compiler generates an architecture-neutral object file format, which makes the compiled code executable on many processors.
**Portable:** Being architecture-neutral and having no implementation dependent aspects of the language makes Java portable.
**Robust:** Java provides exception handling and type checking mechanisms for a robust application.
**Multithreaded:** Java supports multithreaded programming which allows us to achieve performance by executing several tasks simultaneously.
**Dynamic:** Java is considered to be more dynamic than C or C++ as it supports features like reflection, loading and unloading of classes at runtime, etc.

Some useful mnemonics and tricks to remember:

- **OOPS** stands for **O**bject **O**riented **P**rogramming **S**trategy
- The 4 pillars of OOPS are **Inheritance, Encapsulation, Polymorphism, Abstraction**
- **JVM** is Java **V**irtual **M**achine that provides runtime environment
- **JIT** compiler is **J**ust-**I**n-**T**ime compiler that converts bytecode to native machine code
