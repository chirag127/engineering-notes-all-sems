### HTML in Web Page Designing

HTML stands for Hypertext Markup Language. It is the main markup language used to create web pages. Some key points to learn about HTML for web page designing are:

1. HTML uses tags like <html>, <head>, <title>, <body>, <h1>, <p>, etc. to structure a web page and add content.
2. HTML tags are enclosed within angle brackets <>. Some tags have opening and closing tags with content in between while some have just one tag.
3. The <html> tag encloses the whole HTML document. The <head> tag encloses the document metadata and <title> tag specifies the page title. The visible page content is inside the <body> tag.
4. Headings are specified using <h1> to <h6> tags. <h1> is the highest heading and <h6> is the lowest. They are used for section headings.
5. Paragraphs are denoted using <p> tags. Words and sentences inside the <p> tags get formatted as a paragraph.
6. Images are added using the <img> tag which has a src attribute specifying the image source/location.
7. Links to other pages are added using the <a> anchor tag having an href attribute with the link URL. The link text is placed between the opening and closing <a> tag.
8. HTML documents are viewed in browsers which arrange the tags and content in a human readable format based on CSS stylesheets.
9. Mnemonics: Every Good Boy Does Fine (for remembering order of notes on lines of music staff); <html> starts a web page, <head> has metadata, <title> names the page, <body> has visible content.

The above points cover the basic HTML tags and structure for designing simple web pages. More advanced features like tables, forms, iframes, etc. can also be included in HTML pages by using the appropriate tags. HTML is easy to learn and can be used to create web pages with images, links, and formatted text.
