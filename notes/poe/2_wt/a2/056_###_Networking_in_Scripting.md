### Networking in Scripting

- Scripting languages like Python, PHP, Ruby, etc. provide built-in modules and libraries to work with networking concepts.
- Some key networking concepts handled by scripting languages are:

#### IP Addresses
- IP addresses are represented as strings - '192.168.1.1'
- Scripting languages provide functions to validate IP addresses, get IP address of a system, get local network IP range, etc.
- E.g. in Python - ipaddress module can be used to handle IP addresses as objects and perform operations on them.

#### Ports
- Ports are identified by numbers - 80 (for HTTP), 22 (for SSH), etc.
- Scripts can bind to a specific port to listen for incoming connections or connect to a port on a remote host.
- E.g. in Python - socket programming can be used to bind to and connect on ports.

#### Protocols
- Different network protocols can be implemented using socket programming concepts.
- E.g. in Python - TCP socket can be used to implement TCP (for reliable communication) and UDP socket can be used to implement UDP (for fast communication).
- Scripts can act as clients or servers for protocols like HTTP, FTP, SMTP, etc.

#### DNS
- Domain Name System (DNS) can be accessed through scripting languages to get IP address of domain names and vice versa.
- E.g. in Python - the dnslib module can be used to work with DNS servers and perform DNS queries.
