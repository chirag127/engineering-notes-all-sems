## Unit 1 - Introduction to Web Technology

Web technology is a vast field that encompasses various tools, techniques, and technologies used to design, develop, and maintain web applications. This unit will introduce you to the basics of web technology and its underlying concepts. Here are the key topics that you will cover in this unit:

1. Introduction to the World Wide Web (WWW)
   - Definition of the WWW
   - History of the WWW
   - Evolution of the WWW

2. Client-Server Architecture
   - Definition of Client-Server Architecture
   - Components of Client-Server Architecture
   - Advantages of Client-Server Architecture

3. Internet Protocols
   - Definition of Internet Protocols
   - Types of Internet Protocols
   - Examples of Internet Protocols

4. Markup Languages
   - Definition of Markup Languages
   - Types of Markup Languages
   - Examples of Markup Languages

5. Cascading Style Sheets (CSS)
   - Definition of CSS
   - Types of CSS
   - Advantages of CSS

   - Definition of JavaScript

   - Advantages of JavaScript

7. Web Development Tools and Technologies
   - Introduction to Web Development Tools and Technologies

Mnemonics and Learning Tricks:

1. Remember the acronym WWW as "World Wide Web" and associate it with the idea of a global network of interconnected websites.

2. Think of Client-Server Architecture as a waiter and customer relationship. The waiter (server) provides services to the customer (client) and fulfills their requests.

3. To remember different types of Internet Protocols, use the acronym TCP/IP (Transmission Control Protocol/Internet Protocol) and associate it with the idea of controlling transmission of data over the internet.

4. For Markup Languages, think of them as a way to mark up or annotate text with codes that dictate how it should be displayed on a webpage.

5. To remember different types of CSS, use the acronym ITC-PF (Internal, External, Inline, and Precedence and Formatting) and associate it with the idea of controlling the style and layout of a webpage.

6. For JavaScript, think of it as a scripting language that adds interactivity to webpages and enhances the user experience.

Overall, this unit will provide a solid foundation for understanding web technology and its underlying concepts. By the end of this unit, you will have a clear understanding of the basics of web development and the tools and technologies used in the industry.
