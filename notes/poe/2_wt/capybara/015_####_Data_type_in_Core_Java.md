#### Data type in Core Java

A data type is an attribute of a variable that defines the type of data it can hold. In Java, there are two types of data types: primitive and non-primitive. Primitive data types are the basic or fundamental data types that Java supports, whereas non-primitive data types are derived from primitive data types or are reference types.

##### Primitive Data Types

Primitive data types are the most basic data types in Java. They are classified into four categories: integer, floating-point, character, and boolean. Here are the details of each type:

1. Integer
    - byte: 8-bit signed two's complement integer (-128 to 127)
    - short: 16-bit signed two's complement integer (-32,768 to 32,767)
    - int: 32-bit signed two's complement integer (-2,147,483,648 to 2,147,483,647)
    - long: 64-bit signed two's complement integer (-9,223,372,036,854,775,808 to 9,223,372,036,854,775,807)

2. Floating-Point
    - float: 32-bit single-precision floating-point number
    - double: 64-bit double-precision floating-point number

3. Character
    - char: 16-bit Unicode character (0 to 65,535)

4. Boolean
    - boolean: true or false

##### Non-Primitive Data Types

Non-primitive data types are also known as reference types. They are derived from primitive data types or are reference types. They include arrays, classes, and interfaces.

###### Learning Tricks

- The acronym **BISC** can be used to remember the primitive data types in Java: byte, int, short, and char.
- To remember the range of byte, you can use the phrase "bite the smallest elephant" as byte has the smallest range among the integer data types.

In conclusion, data types are the fundamental building blocks of Java programs. Understanding them is crucial to writing efficient and reliable code.
