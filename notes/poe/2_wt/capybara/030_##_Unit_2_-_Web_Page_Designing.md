## Unit 2 - Web Page Designing

Web page designing is an essential skill for anyone who wants to create a website. In this unit, you will learn the basics of web page designing and how to create a visually appealing and functional web page. Here are the topics covered in this unit:

### 1. Introduction to Web Page Designing

- Definition of web page designing
- Importance of web page designing
- Basic principles of web page designing

### 2. HTML and CSS

- Introduction to HTML and CSS
- HTML tags and attributes
- CSS selectors and properties
- How to use HTML and CSS to create a web page

### 3. Layout and Design

- Principles of layout and design
- Design elements and principles
- Types of layouts
- How to create a layout using HTML and CSS

### 4. Typography

- Introduction to typography
- Types of fonts
- Font families and styles
- How to use typography to enhance a web page

### 5. Color Theory

- Introduction to color theory
- Color models and systems
- Color schemes and palettes
- How to use color to create a visually appealing web page

### 6. Images and Multimedia

- Types of images and multimedia
- Image formats and optimization
- How to use images and multimedia to enhance a web page

### 7. Accessibility

- Introduction to accessibility
- Importance of accessibility in web page designing
- Techniques for creating accessible web pages

### 8. Responsive Web Design

- Introduction to responsive web design
- Importance of responsive web design
- Techniques for creating responsive web pages

Mnemonics and learning tricks:

- Remember the acronym "HTML" as "HyperText Markup Language".
- To remember the different types of color schemes, use the acronym "VIBGYOR" (Violet, Indigo, Blue, Green, Yellow, Orange, Red). These are the colors of the rainbow and can be used to create different color schemes.
- To remember the different types of font styles, use the acronym "BASED" (Bold, Italic, Underline, Strikethrough, Emphasis, Different Size).
