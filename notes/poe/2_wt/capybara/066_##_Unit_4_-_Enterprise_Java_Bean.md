## Unit 4 - Enterprise Java Bean

Enterprise Java Beans (EJB) is a server-side component architecture for building distributed business applications in Java. It provides a set of services to manage the life cycle of business objects, handle transactions, and security. 

### Types of EJB

There are three types of EJB:

1. Session Beans: It represents a single client-session and is used to perform business logic for the client.

2. Entity Beans: It represents a persistent object and is used to store and retrieve data from a database.

3. Message-Driven Beans: It is used to receive and process messages asynchronously.

### Advantages of EJB

Some of the advantages of EJB are:

1. Scalability: EJB provides a scalable architecture for building distributed applications.

2. Transaction Management: EJB provides a built-in mechanism to handle transactions.

3. Security: EJB provides a built-in mechanism for handling security.

4. Reusability: EJB provides a reusable architecture for building distributed applications.

### Disadvantages of EJB

Some of the disadvantages of EJB are:

1. Complexity: EJB is a complex technology that requires a lot of configuration and setup.

2. Performance: EJB can be slower than other technologies due to its overhead.

3. Licensing: EJB requires a license to use in a commercial environment.

### Learning Tricks

1. Remember the three types of EJB by using the mnemonic "SME" which stands for Session, Message-Driven, and Entity.

2. Remember the advantages of EJB by using the mnemonic "SCoReR" which stands for Scalability, Transaction Management, Security, and Reusability.

Overall, EJB is a powerful technology for building distributed business applications. It provides a set of services to manage the life cycle of business objects, handle transactions, and security. By understanding its advantages and disadvantages and using learning tricks, one can easily master EJB for building scalable and secure business applications.
