## Unit 3 - Scripting

Scripting is the process of creating a set of instructions that a computer can follow to complete a task. It is an essential part of programming and can be used for a variety of purposes. This unit covers some of the most important scripting languages and techniques used in the industry.

### 1. Bash Scripting

Bash is a Unix shell that provides a command-line interface for interacting with the operating system. It is a popular choice for writing scripts on Unix-based systems. Some of the key features of Bash scripting include:

- Ability to automate repetitive tasks
- Command-line interface for interacting with the operating system
- Ability to redirect input and output to files and other programs
- Support for variables, loops, and conditionals
- Built-in commands for common tasks like file manipulation and text processing

Mnemonic: "Bash" stands for "Bourne-Again SHell," which is a reference to the original Unix shell called "sh."

### 2. Python Scripting

Python is a high-level programming language that has gained popularity in recent years due to its ease of use and versatility. It is often used for scripting because of its simple syntax and powerful libraries. Some of the key features of Python scripting include:

- Easy-to-learn syntax
- Support for variables, loops, and conditionals
- Large standard library with modules for a wide range of tasks
- Interpreted language, meaning that code can be executed without compilation
- Cross-platform compatibility

Mnemonic: "Python" was named after the British comedy group Monty Python, whose humor is known for being both clever and easy to understand.

### 3. Regular Expressions

Regular expressions are a powerful tool for manipulating text. They are used in many scripting languages, including Bash and Python. Some of the key features of regular expressions include:

- Ability to search for patterns within text
- Support for wildcards, character classes, and quantifiers
- Can be used for text validation and data cleansing
- Can be combined with other scripting languages to automate tasks

Mnemonic: "Regular expressions" can be abbreviated as "regex," which sounds similar to the word "wrecked." This is because regular expressions can be powerful, but also have the potential to cause chaos if used incorrectly.

### 4. Advantages and Disadvantages of Scripting

Advantages:

- Can automate repetitive tasks, saving time and reducing errors
- Can be used for a wide range of tasks, from file manipulation to web scraping
- Easy to learn and use, especially for simple tasks
- Can be combined with other programming languages to create more complex applications

Disadvantages:

- May not be suitable for complex tasks that require more advanced programming languages
- Scripts can be less efficient than compiled programs
- May require additional tools and libraries to work with specific file formats or data sources

### 5. Examples and Applications of Scripting

Examples:

- Writing a Bash script to automate a backup process
- Using Python to scrape data from a website
- Using regular expressions to validate user input in a web form

Applications:

- System administration and automation
- Data analysis and visualization
- Web development and automation
- DevOps and continuous integration/continuous deployment (CI/CD)
