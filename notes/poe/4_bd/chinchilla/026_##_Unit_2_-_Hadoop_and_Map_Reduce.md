## Unit 2 - Hadoop and Map Reduce

Hadoop is an open-source framework that is widely used for processing large and complex data sets. It is based on the MapReduce programming model, which allows for parallel processing of large data sets across multiple computing nodes. In this unit, we will learn about Hadoop and its key components, as well as the MapReduce programming model and how it works.

### 1. Hadoop

Hadoop is a distributed computing framework that allows for the storage and processing of large data sets across clusters of computers. It was initially developed by Doug Cutting and Mike Cafarella in 2005 and was inspired by Google's MapReduce and Google File System (GFS). Hadoop is widely used in big data applications and has become the de facto standard for processing large data sets.

#### Key Components of Hadoop

- Hadoop Distributed File System (HDFS): HDFS is a distributed file system that provides high-throughput access to large data sets. It is designed to be fault-tolerant and can handle large files by breaking them into smaller blocks and storing them across multiple nodes in a cluster.
- MapReduce: MapReduce is a programming model that allows for parallel processing of large data sets across multiple computing nodes. It breaks down a large job into smaller tasks that can be executed in parallel.
- YARN: YARN (Yet Another Resource Negotiator) is a cluster management technology that allows for the allocation of computing resources to different applications running on a Hadoop cluster.
- Hadoop Common: Hadoop Common is a set of common utilities and libraries used by other Hadoop modules.

### 2. MapReduce

MapReduce is a programming model that allows for parallel processing of large data sets across multiple computing nodes. It was initially developed by Google and later adapted by Hadoop. MapReduce consists of two main phases: the map phase and the reduce phase.

#### Map Phase

In the map phase, the input data is divided into smaller chunks and processed in parallel across multiple nodes in a cluster. Each node applies a map function to the data, which transforms the input data into a set of key/value pairs.

#### Reduce Phase

In the reduce phase, the output of the map phase is combined and reduced into a smaller set of key/value pairs. Each node applies a reduce function to the output data, which aggregates the data and produces a final output.

#### Advantages of MapReduce

- Scalability: MapReduce can scale horizontally by adding more nodes to a cluster.
- Fault-tolerance: MapReduce is designed to be fault-tolerant, which means that it can handle failures in individual nodes without affecting the overall processing of data.
- Parallel processing: MapReduce allows for parallel processing of large data sets, which can significantly reduce processing time.
- Simplifies programming: MapReduce abstracts away the complexities of distributed computing, making it easier to write distributed applications.

#### Disadvantages of MapReduce

- Overhead: MapReduce introduces overhead due to the need to transfer data between nodes in a cluster.
- Limited support for iterative algorithms: MapReduce is not well-suited for iterative algorithms, which require repeated processing of data.

### 3. Applications of Hadoop and MapReduce

Hadoop and MapReduce are widely used in big data applications, including:

- Web indexing: Hadoop is used by search engines such as Yahoo and Bing to index the web.
- Log processing: Hadoop is used to process large volumes of log data generated by web servers and other applications.
- Social media analysis: Hadoop is used to analyze large volumes of data generated by social media platforms such as Twitter and Facebook.
- Recommendation systems: Hadoop is used to build recommendation systems that analyze user behavior and make recommendations based on that data.

#### Mnemonic

- Hadoop: Hadoop is like a big elephant that can store and process large amounts of data.
- MapReduce: MapReduce is like a map that breaks down a large area into smaller sections that can be explored in parallel, and a reduce function that combines the results of each section into a final output.
