### Pig

Pig is a high-level platform for creating big data applications that run on Apache Hadoop. It is an open-source technology that provides a scripting language called Pig Latin, which is used to write data transformation queries. Pig Latin abstracts the complexity of MapReduce programming, making it easier to process large datasets.

#### Pig Latin

Pig Latin is a data flow language that allows developers to express data transformations in a concise and readable manner. It is similar to SQL in many ways, but it is specifically designed for processing big data. Pig Latin scripts are compiled into MapReduce jobs that are executed on a Hadoop cluster.

#### Mnemonics and Learning Tricks

- Pigs are known for their love of eating, and Pig Latin is all about processing large amounts of data. You can think of Pig Latin as the language that pigs use to process their food.
- Another way to remember Pig Latin is to think of it as a simplified version of MapReduce. Pig Latin abstracts away some of the complexity of MapReduce programming, making it easier to write and understand data transformation queries.

#### Advantages of Pig

- Pig Latin is a high-level language that is easy to learn and use. It allows developers to write data transformation queries in a concise and readable manner.
- Pig Latin abstracts the complexity of MapReduce programming, making it easier to process large datasets.
- Pig Latin scripts are compiled into MapReduce jobs, which can be executed on a Hadoop cluster.

#### Disadvantages of Pig

- Pig is not suitable for real-time data processing, as it is designed for batch processing of large datasets.
- Pig Latin has limited support for complex data types, such as arrays and maps.
- Pig Latin does not support all the features of SQL, which may be a limitation for some developers.

#### Examples

Here is an example of a Pig Latin script that computes the average salary of employees by department:

```
employee = LOAD 'employee_data' USING PigStorage(',') AS (name:chararray, age:int, department:chararray, salary:int);
department_group = GROUP employee BY department;
avg_salary = FOREACH department_group GENERATE group AS department, AVG(employee.salary) AS avg_salary;
STORE avg_salary INTO 'output';
```
