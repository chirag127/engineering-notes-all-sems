## Unit 3 - Hadoop Eco System and YARN, NoSQL Databases, MongoDB, Spark, Scala

This unit covers various technologies and tools that are commonly used in the big data world. The topics covered in this unit are as follows:

### Hadoop Eco System and YARN

- Apache Hadoop is a distributed computing framework that allows users to process large datasets across multiple nodes. It consists of several components, including Hadoop Distributed File System (HDFS), MapReduce, and Yet Another Resource Negotiator (YARN).
- YARN is a resource management system that coordinates resources across the Hadoop cluster. It manages resources such as CPU, memory, and network bandwidth and allocates them to different applications running on the cluster.
- Hadoop also includes several ecosystem projects that provide additional functionality, such as Apache Hive for data warehousing, Apache Pig for data analysis, and Apache Spark for data processing.

### NoSQL Databases

- NoSQL databases are non-relational databases that provide a flexible data model and are designed for scalability and high availability.
- Some examples of NoSQL databases include MongoDB, Cassandra, and Couchbase.
- NoSQL databases are often used in big data applications because they can handle unstructured data and can scale horizontally across multiple nodes.

### MongoDB

- MongoDB is a popular NoSQL document database that stores data in JSON-like documents.
- It is designed for scalability and high availability and can be used to store and retrieve large volumes of data.
- MongoDB also supports features such as indexing, replication, and sharding for performance and scalability.

### Spark

- Apache Spark is a fast and general-purpose distributed computing system that is designed for processing large datasets.
- It provides several APIs for data processing, including Spark SQL, Spark Streaming, and MLlib.
- Spark can run on Hadoop clusters and can also be run standalone or on other cluster managers.

### Scala

- Scala is a general-purpose programming language that is designed to be scalable and concise.
- It is often used for developing applications that run on the Java Virtual Machine (JVM) and is popular in the big data world because it integrates well with Spark and other big data tools.
- Scala provides features such as functional programming, type inference, and pattern matching that make it a powerful and expressive language.

### Learning tricks and mnemonics

- For remembering the components of Hadoop, you can use the mnemonic "HDFS MapReduce YARN" (pronounced "hadoop mapreduce yarn").
- To remember the benefits of NoSQL databases, you can use the mnemonic "NoSQL = Not Only SQL" to remind yourself that NoSQL databases provide more than just SQL-based querying.
- For remembering the different APIs provided by Spark, you can use the mnemonic "SQL Stream ML" to remind yourself of Spark SQL, Spark Streaming, and MLlib.
