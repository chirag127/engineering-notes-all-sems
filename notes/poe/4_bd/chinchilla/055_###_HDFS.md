### HDFS

Hadoop Distributed File System (HDFS) is a distributed file system that provides scalable and fault-tolerant storage for big data applications. HDFS is a core component of the Apache Hadoop ecosystem and is designed to store very large files that are distributed across multiple machines in a cluster.

#### Architecture

HDFS is designed with a master-slave architecture, where a single NameNode acts as the master and multiple DataNodes act as the slaves. The NameNode is responsible for managing the file system namespace, maintaining the metadata, and coordinating access to files. The DataNodes are responsible for storing the actual data and serving read and write requests from clients.

#### Features

- Scalability: HDFS is designed to scale horizontally by adding more DataNodes to the cluster as the amount of data grows.

- Fault-tolerance: HDFS is designed to tolerate hardware failures by replicating data across multiple DataNodes. The NameNode keeps track of the locations of all replicas and can instruct clients to read from another replica if one is unavailable.

- High throughput: HDFS is optimized for sequential read and write access, which makes it well-suited for processing large datasets.

- Data locality: HDFS is designed to store data on the same node where it will be processed, which reduces network traffic and improves performance.

- Access control: HDFS supports access control lists (ACLs) and POSIX permissions to control who can read, write, and execute files.

#### Mnemonics and learning tricks

- HDFS can be thought of as a big filing cabinet where files are stored across multiple drawers (DataNodes) and a master index (NameNode) keeps track of where everything is.

- Another way to think of HDFS is as a library, where the NameNode is the librarian who manages the catalog of books (metadata) and the DataNodes are the shelves where the books (data) are stored.

#### Advantages

- Scalability: HDFS can store and process very large datasets that would be difficult or impossible to handle with traditional file systems.

- Fault-tolerance: HDFS is designed to withstand hardware failures and can recover from failures automatically.

- Cost-effective: HDFS can be run on commodity hardware, which makes it much more cost-effective than traditional storage solutions.

#### Disadvantages

- High latency: HDFS is optimized for sequential read and write access, which can result in high latency for random access patterns.

- Complexity: HDFS has a complex architecture and requires a lot of configuration to set up and maintain.

#### Examples

- HDFS is used by many big data applications, including Apache Spark, Apache Hive, and Apache Pig.

- HDFS is used by companies like Facebook, Yahoo, and Twitter to store and process large amounts of data.

#### Applications

- Big data processing: HDFS is well-suited for processing large datasets in parallel across a cluster of machines.

- Data warehousing: HDFS can be used as a data warehouse to store and analyze large amounts of structured and unstructured data.

- Log processing: HDFS can be used to store and analyze log data generated by servers, applications, and devices.
