#### Pig - Introduction to PIG

Pig is a high-level scripting language that is used to analyze large data sets. It converts queries into a series of MapReduce jobs which are processed on a Hadoop cluster.

Some key points about Pig are:

- Pig Latin is the language used to write Pig scripts. It is a procedural language with similarities to SQL.
- Pig Latin abstracts away the complexities of MapReduce and allows the user to focus on the analysis task.
- Pig Latin scripts are compiled into a series of MapReduce jobs which are executed on a Hadoop cluster.
- Pig Latin has a variety of built-in functions for data processing and allows user-defined functions to be written in Java, Python, JavaScript, Ruby or Groovy.
- Pig provides a graphical interface called the Pig Editor / Grunt shell for interactively creating and running Pig Latin scripts.
- Pig's strengths lie in very complex, nested data transformations and joins over large data sets. It is not suitable for low latency queries.
- Some advantages of Pig are it's easy to learn, it's extensible and it provides good performance with large data sets. Some disadvantages are that it can be inefficient for small jobs and it can be limiting for unstructured data.

Some examples of applications using Pig are:

- Processing log data to calculate statistics
- Transforming XML data into relational data
- Joining large data sets
- Grouping / aggregating data
- Feature extraction from image data
