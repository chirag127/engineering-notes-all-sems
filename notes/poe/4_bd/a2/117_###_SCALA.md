### SCALA

SCALA is a statically typed programming language that runs on the Java Virtual Machine (JVM) and also can be compiled to JavaScript source code.

Points to remember:

1. SCALA is a general-purpose programming language providing support for functional programming and a strong static type system.
2. It is designed to be concise, many common programming patterns can be expressed in just a few lines of code in SCALA.
3. SCALA source code is intended to be compiled to Java bytecode, allowing the resulting executable code to run on any Java virtual machine.
4. SCALA provides language interoperability with Java, such that libraries written in Java can be referenced directly from SCALA code.
5. SCALA's static type system supports a style of functional programming that incorporates features like immutability, lazy evaluation, and pattern matching.
6. SCALA aims to be simple and easy to use for Scalable development. The main design principles are:

- It should be concise, safe and suitable for large scale development.
- It should support multiple programming paradigms and functional programming constructs.
- It should integrate with the Java platform and execute on the JVM.

Mnemonics:

- Think of SCALA as 'SCALE-able' as it is designed for scalable software.

Advantages:

- Concise and expressive syntax.
- Blends object-oriented and functional programming concepts.
- Strongly typed language with type inference.
- Interoperates smoothly with Java and runs on JVM.
- Supports lazy evaluation, immutability, pattern matching, etc.

Disadvantages:

- Steep learning curve for programmers unfamiliar with functional programming concepts.
- Runtime performance can sometimes be slower than equivalent Java code.
- Style of coding may be confusing for programmers new to Scala.

Applications:

- Used by companies like Twitter, LinkedIn, Foursquare, Guardian, etc. for high load applications.
- Useful for Big Data tasks like data processing, machine learning, scientific computing, etc.
- Convenient for developing Domain-Specific Languages (DSLs).
- Great fit for reactive and asynchronous programming.
