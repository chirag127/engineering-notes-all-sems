#### Introduction to BigInsights

BigInsights is IBM's Hadoop-based distribution and one of the industry's leading enterprise-ready Hadoop platform. It provides an open source framework for distributed storage and processing of large datasets. Some key points about BigInsights are:

- It is built on the Hadoop ecosystem and provides Hadoop MapReduce along with other frameworks like Pig, Hive, Oozie, etc. for processing data.
- It offers enterprise level capabilities like high availability, security, and management capabilities which are required to run Hadoop in production.
- It provides analytics tools and interfaces which allow data scientists and analysts to easily access and analyze data without going into the complexities of MapReduce programming. Some of these are BigSheets, Streams, and Big SQL.
- It is highly scalable and can process and store huge amounts of unstructured and structured data. The storage and compute capabilities can be easily scaled up as per the requirements.
- It enables processing data in a distributed manner across multiple servers, thereby accelerating the processing speed and enabling processing of large data.

Some Mnemonics to remember key capabilities of BigInsights:

- 'E' for Enterprise - Provides enterprise level capabilities
- 'P' for Processing - Provides distributed processing of large data using Hadoop frameworks
- 'I' for Interfaces - Provides easy to use interfaces for analytics like BigSheets and Big SQL

Advantages:

- Cost effective as commodity hardware can be used.
- Scalable to handle huge volumes and variety of data.
- Parallel and distributed processing leads to faster processing of large data.
- Open source frameworks provide a lot of capabilities for analytics and integration.
