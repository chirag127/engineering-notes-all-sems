## Hadoop Eco System Frameworks , Pig , Hive and HBase

### Hadoop Eco System

- Hadoop is an open-source software framework for distributed storage and processing of very large data sets on computer clusters.
- It provides massive storage for any kind of data, enormous processing power and the ability to handle virtually limitless concurrent tasks or jobs.
- The Hadoop ecosystem consists of various modules/frameworks to solve different problems. Some of the major components are:
	- HDFS - Hadoop Distributed File System - For storage
	- MapReduce - For processing and computing
	- YARN - Yet Another Resource Negotiator - For job scheduling and cluster resource management
	- Hive - For querying and managing large datasets
	- Pig - For analyzing large data sets
	- HBase - A scalable NoSQL database for random read/write access of large datasets

**Mnemonic:** *HDFS stores, MapReduce processes, YARN manages, Hive queries, Pig analyzes, HBase databases*

### Pig

- Pig is a high-level platform for creating MapReduce programs used with Hadoop.
- It uses Pig Latin, a scripting language, to perform analysis on large data sets.
- Pig Latin abstracts the complexities of MapReduce and allows users to focus on the analysis task.
- It can handle nested data and has various in-built functions for data processing and transformation.
- Some advantages are:
	- Simplicity - Easy to learn and use
	- Extensibility - Ability to extend with custom functions
	- Optimization - Pig compilers automatically optimize and translate the Pig Latin scripts into efficient MapReduce jobs.

**Learning trick:** *Think of Pig as a high-level tool doing grunt work (complex MapReduce tasks) for you.*
