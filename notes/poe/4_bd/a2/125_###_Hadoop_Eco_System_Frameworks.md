### Hadoop Eco System Frameworks

The Hadoop ecosystem refers to the framework and various related projects developed by the Apache Software Foundation for distributed storage and processing of large data sets across clusters of servers. The core frameworks of the Hadoop ecosystem are:

1. Hadoop Common: The common utilities that support other Hadoop modules. It includes filesystem interfaces, utilities, configuration files, etc.
2. Hadoop Distributed File System (HDFS): A distributed file system that stores data on commodity machines, providing very high aggregate bandwidth across the cluster.
3. MapReduce: A programming model for large scale data processing. Users specify the map and reduce functions, and the MapReduce framework handles the parallelization and distribution of tasks across the cluster.
4. YARN: A framework for job scheduling and cluster resource management. It enables execution of Apache Hadoop ecosystem applications using multiple data processing engines.

Some other notable projects in the Hadoop ecosystem include:

- Pig: A high-level dataflow language and execution framework for parallel computation.
- Hive: A data warehouse infrastructure built on top of Hadoop for providing data summarization, query, and analysis.
- HBase: A distributed, scalable, big data store for large tables -- billions of rows X millions of columns.
- ZooKeeper: A centralized service for maintaining configuration information, naming, providing distributed synchronization, and providing group services.
- Oozie: A workflow scheduler system to manage Apache Hadoop jobs.
- Flume: A distributed, reliable, and available service for efficiently collecting, aggregating, and moving large amounts of log data.
- Sqoop: A tool for transferring data between Hadoop and relational databases.
