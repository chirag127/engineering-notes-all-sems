### Spark

Spark is a fast and general-purpose cluster computing system. It provides high-level APIs in Scala, Java, Python, and R, and an optimized engine that supports general computation graphs for data analysis. It also supports a rich set of higher-level tools including Spark SQL for SQL and DataFrames, MLlib for machine learning, GraphX for graph processing, and Structured Streaming for stream processing.

Some key points about Spark:

- Spark is fast - It can run programs up to 100x faster than Hadoop MapReduce in memory, or 10x faster on disk.
- Spark is easy to use - It has simple and expressive APIs in Java, Scala, Python and R.
- Spark is robust and flexible - It has a number of specialized components like Spark SQL, Spark Streaming, GraphX, and MLlib for diverse workloads.
- Spark runs everywhere - It can run on Hadoop, standalone, Mesos, Kubernetes, and can access diverse data sources including HDFS, Cassandra, HBase, S3.

Some mnemonics and learning tricks for Spark:

- Think of Spark as a lightning-fast cluster computing system. Its speed comes from caching and in-memory processing.
- The Spark architecture has Drivers, Executors and Clusters. The Driver coordinates the execution of applications, Executors run tasks and cache data, and Clusters provide resources for the executors.
- The main APIs of Spark are the Core/RDD API, Spark SQL, DataFrames API, and Spark Streaming. Think of them for batch data, structured data, tabular data, and stream processing respectively.
- Some advantages of Spark are speed, ease of use, advanced analytics, and active development community. Some disadvantages are resource management, dependencies, and cost.
