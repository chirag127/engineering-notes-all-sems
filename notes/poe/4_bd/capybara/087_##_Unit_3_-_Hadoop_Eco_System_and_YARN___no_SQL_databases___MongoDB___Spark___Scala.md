## Unit 3 - Hadoop Eco System and YARN, NoSQL Databases, MongoDB, Spark, Scala

### Hadoop Eco System and YARN

- Hadoop is an open-source framework for processing and storing large datasets in a distributed manner.
- Hadoop Eco System is a collection of various tools and applications that work with Hadoop to enhance its functionality.
- YARN (Yet Another Resource Negotiator) is a resource management layer in Hadoop that manages resources and schedules tasks across the cluster.
- Hadoop Eco System consists of various components such as HDFS, MapReduce, Pig, Hive, HBase, Sqoop, Flume, Oozie, and ZooKeeper.
- HDFS (Hadoop Distributed File System) is a distributed file system that provides high-throughput access to data.
- MapReduce is a programming model used for processing large datasets in a distributed manner.
- Pig is a high-level platform for creating MapReduce programs used for processing large datasets.
- Hive is a data warehouse infrastructure that provides data summarization, query, and analysis.
- HBase is a distributed, non-relational database that provides random access to large amounts of structured data.
- Sqoop is a tool used for importing and exporting data between Hadoop and relational databases.
- Flume is a distributed, reliable, and available service used for efficiently collecting, aggregating, and moving large amounts of log data.
- Oozie is a workflow scheduler system used to manage Hadoop jobs.
- ZooKeeper is a distributed coordination service used for maintaining configuration information, naming, providing distributed synchronization, and providing group services.

### NoSQL Databases

- NoSQL (Not Only SQL) databases are non-relational databases that provide flexible schema design and horizontal scalability.
- They are designed to handle large volumes of unstructured and semi-structured data.
- NoSQL databases are classified into four categories: document, key-value, column-family, and graph databases.
- Document databases store data in a document format, usually in JSON or BSON format.
- Key-value databases store data in a key-value pair format, where the key is used to uniquely identify the value.
- Column-family databases store data in columns, and each column can have multiple values.
- Graph databases store data in nodes and edges, and they are used to represent complex relationships between data.
- Some popular NoSQL databases are MongoDB, Cassandra, Couchbase, Redis, and Neo4j.

### MongoDB

- MongoDB is a popular document-oriented NoSQL database.
- It stores data in BSON (Binary JSON) format, which allows for flexible schema design.
- MongoDB supports dynamic queries, indexing, and aggregation.
- It provides high availability and automatic sharding for horizontal scalability.
- MongoDB is widely used in web applications, real-time analytics, and content management systems.

### Spark

- Apache Spark is a fast and general-purpose cluster computing system.
- It provides an interface for programming entire clusters with implicit data parallelism and fault tolerance.
- Spark provides various libraries for processing data, such as Spark SQL, Spark Streaming, MLlib, and GraphX.
- Spark SQL is a module for working with structured data using SQL queries.
- Spark Streaming is a module for processing real-time data streams.
- MLlib is a library for machine learning algorithms.
- GraphX is a library for graph processing algorithms.

### Scala

- Scala is a programming language that combines functional programming and object-oriented programming.
- It is designed to be concise, expressive, and type-safe.
- Scala runs on the Java Virtual Machine (JVM) and can interoperate with Java code.
- It provides various features such as pattern matching, higher-order functions, and type inference.
- Scala is widely used in data processing, web development, and machine learning.
