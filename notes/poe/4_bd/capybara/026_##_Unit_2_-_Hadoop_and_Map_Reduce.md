## Unit 2 - Hadoop and Map Reduce

Hadoop is an open-source distributed storage and processing system that can handle large amounts of data. MapReduce is a programming model for processing large amounts of data in parallel across a large number of nodes in a Hadoop cluster. In this unit, we will learn more about Hadoop and MapReduce and how they can be used to process big data.

### Hadoop

Here are some important things to know about Hadoop:

- Hadoop is designed to store and process large amounts of data across a distributed cluster of computers.
- It consists of two main components: Hadoop Distributed File System (HDFS) and MapReduce.
- HDFS is a distributed file system that allows data to be stored across multiple nodes in a Hadoop cluster.
- MapReduce is a programming model that allows large data sets to be processed in parallel across a cluster of computers.
- Hadoop also includes other tools and frameworks, such as Pig, Hive, and HBase, which can be used to process and analyze data stored in Hadoop.

### MapReduce

Here are some important things to know about MapReduce:

- MapReduce is a programming model that allows large data sets to be processed in parallel across a cluster of computers.
- The programming model consists of two main functions: map and reduce.
- The map function takes a set of input data and produces a set of key-value pairs.
- The reduce function takes the output of the map function and combines the values for each key to produce a set of output data.
- MapReduce can be used to process a wide variety of data, including structured and semi-structured data, as well as unstructured data such as text and images.

### Mnemonics and Learning Tricks

One mnemonic that can be helpful for remembering the MapReduce programming model is "MRR" or "Map-Reduce-Result". This can help you remember the three main parts of the programming model: the map function, the reduce function, and the result that is produced.

Another learning trick for understanding Hadoop is to think of it as a set of Lego blocks. Each block represents a different tool or framework, such as HDFS, MapReduce, Pig, Hive, or HBase. By combining these blocks in different ways, you can create a customized solution for processing and analyzing your data.

### Conclusion

Hadoop and MapReduce are powerful tools for processing and analyzing big data. By understanding how they work and how to use them effectively, you can unlock insights and value from your data that might otherwise be hidden. Whether you are a data scientist, a business analyst, or a software developer, Hadoop and MapReduce can help you turn your data into actionable insights.
