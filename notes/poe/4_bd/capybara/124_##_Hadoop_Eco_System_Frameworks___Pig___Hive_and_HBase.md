## Hadoop Eco System Frameworks , Pig , Hive and HBase

The Hadoop Eco System Frameworks are a set of tools and frameworks that are built on top of the Hadoop Distributed File System (HDFS). These tools are designed to help manage and process large amounts of data in a distributed computing environment. Here are some of the key frameworks:

### Hadoop MapReduce

Hadoop MapReduce is a programming model and software framework for processing large datasets in parallel across a cluster of computers. It is the core processing engine of the Hadoop Eco System Frameworks.

### Pig

Pig is a high-level platform for creating MapReduce programs used with Hadoop. It allows developers to write complex MapReduce transformations using a simple scripting language called Pig Latin. A useful mnemonic for remembering Pig is "Pig eats your data and spits out bacon."

### Hive

Hive is another high-level platform for creating MapReduce programs used with Hadoop. It allows developers to write SQL-like queries to analyze data stored in Hadoop. A useful mnemonic for remembering Hive is "Hive queries are like SQL, but with a Hadoop buzz."

### HBase

HBase is a distributed, scalable, and highly available NoSQL database built on top of Hadoop. It provides random, real-time read/write access to large amounts of structured and unstructured data. A useful mnemonic for remembering HBase is "HBase is like a big table with lots of legs."

Overall, these frameworks are essential tools for managing and processing large amounts of data in a distributed computing environment. Whether you're using Pig to write MapReduce transformations, Hive to analyze data with SQL-like queries, or HBase to store and access large amounts of data, these frameworks can help you make sense of your big data.
