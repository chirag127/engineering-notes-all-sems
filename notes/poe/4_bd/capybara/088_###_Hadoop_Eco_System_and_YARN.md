### Hadoop Eco System and YARN

Hadoop is an open-source framework that allows for the distributed processing of large datasets across clusters of computers. It includes a variety of tools and technologies that make it easier to work with big data. One of the key components of Hadoop is YARN, which stands for Yet Another Resource Negotiator.

Here are some important points to understand about the Hadoop Eco System and YARN:

1. Hadoop Eco System is a collection of software tools that are used to store, process, and analyze large volumes of data.
2. YARN is a core component of Hadoop that manages resources and schedules tasks across a cluster of machines.
3. YARN allows multiple data processing engines to run on the same Hadoop cluster, making it a versatile platform for big data processing.
4. YARN divides the resources of a cluster into containers, which are allocated to applications running on the cluster.
5. YARN provides a fair scheduling mechanism that ensures all applications get a fair share of the resources available on the cluster.
6. YARN has a pluggable architecture that allows developers to add new processing engines to the Hadoop Eco System.
7. Some of the popular processing engines that run on YARN include Apache Spark, Apache Flink, Apache Tez, and Apache HBase.
8. Hadoop also includes other tools like HDFS (Hadoop Distributed File System), MapReduce, Pig, Hive, and HBase that work together to provide a complete big data processing solution.

Learning tricks and mnemonics:

1. Remember that YARN stands for Yet Another Resource Negotiator. This can help you to remember that it is a tool for managing resources in a Hadoop cluster.
2. Think of Hadoop as a toolbox for working with big data. Each tool in the toolbox has a specific purpose, but they all work together to help you process and analyze large datasets.

In conclusion, Hadoop Eco System and YARN are important tools for working with big data. Understanding how they work and how they are used together can help you to process and analyze large datasets more efficiently. Remembering some of the key features of YARN and using mnemonics to help you remember them can make it easier to study and learn about this important technology.
