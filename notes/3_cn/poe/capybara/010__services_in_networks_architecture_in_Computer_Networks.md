#### Services in Networks Architecture in Computer Networks

Computer networks are designed to provide various services to the users. The following are the services offered by network architecture in computer networks:

1. **Communication Service**
   - Communication service is the fundamental service provided by computer networks, which allows users to communicate with each other using various communication protocols like TCP, IP, and UDP.
   
2. **File Sharing Service**
   - File sharing service allows users to share files with each other over the network, either locally or remotely.
   
3. **Print Service**
   - Print service enables users to print documents or images from any computer connected to the network, using a shared printer.
   
4. **Email Service**
   - Email service provides a platform for users to send and receive emails over the network.
   
5. **Web Service**
   - Web service allows users to access and browse the internet over the network, using web browsers like Google Chrome, Mozilla Firefox, etc.
   
6. **Remote Access Service**
   - Remote access service enables users to remotely access and control other computers on the network. This service is useful in situations where a user needs to access another computer from a different location.
   
7. **Database Service**
   - Database service provides a platform for users to store and access data over the network. This service is used extensively in businesses and organizations to store and manage large amounts of data.
   
8. **Directory Service**
   - Directory service provides a centralized platform for managing user accounts and network resources like printers, files, and applications. It simplifies the process of managing network resources and enhances network security.
   
9. **Security Service**
   - Security service provides a secure platform for users to access network resources without the fear of unauthorized access or data theft. This service includes various security measures like firewalls, antivirus software, and data encryption.
   
10. **Voice and Video Service**
   - Voice and video service allows users to communicate with each other using voice and video calls over the network. This service is extensively used in businesses and organizations for remote meetings and conferences.
