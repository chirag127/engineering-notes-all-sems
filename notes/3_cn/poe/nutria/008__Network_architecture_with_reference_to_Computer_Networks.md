
#### Network architecture with reference to Computer Networks

1. A network architecture is a set of rules and guidelines that determine how computers and other devices communicate with each other on a network. 
2. The two main types of network architecture are client-server and peer-to-peer architectures. 
3. In a client-server architecture, one or more computers act as servers that provide services to other computers, known as clients.
4. In a peer-to-peer architecture, each computer acts as both a client and a server, allowing it to both request and provide services to other computers.
5. A network architecture must also define the protocols used to communicate between computers. Protocols define the format of the data being sent and received, as well as the rules for how the data is sent and received.
6. The most common protocol used in computer networks is the Transmission Control Protocol/Internet Protocol (TCP/IP). This protocol is used to communicate between computers on the Internet.
7. Other protocols, such as the Address Resolution Protocol (ARP) and the Internet Control Message Protocol (ICMP), are used to provide additional functionality, such as address resolution and error reporting.
8. The network architecture must also define the physical topology of the network, which is the physical layout of the network connections. 
9. The two most common physical topologies are bus and star. In a bus topology, all computers are connected to a single cable, while in a star topology, the computers are connected to a central hub or switch.
10. Network architectures must also define the logical topology, which is the way the network appears to the computers on the network. The two most common logical topologies are bus and ring. In a bus topology, all computers are connected together, while in a ring topology, the computers are connected in a circular pattern.
