
### Logical Addressing in Network Layer

1. Logical addressing is a method of assigning addresses to networked devices in order to identify them on a network. 
2. Each device on a network must have a unique address in order to be identified and communicate with other devices. 
3. Logical addressing is used for both local area networks (LANs) and wide area networks (WANs). 
4. The most common logical addressing system is the Internet Protocol (IP) address. 
5. IP addresses are 32-bit numbers that are divided into four octets, or 8-bit numbers. 
6. Each octet is represented by a decimal number between 0 and 255. 
7. The IP address is used to identify a device on a network and provide the location of the device. 
8. The IP address is divided into two parts: the network address and the host address. 
9. The network address identifies the network on which the device is located. 
10. The host address identifies the specific device on the network. 
11. The subnet mask is used to determine which bits of the IP address are used for the network address and which bits are used for the host address. 
12. The subnet mask is used to divide the IP address into two parts: the network address and the host address. 
13. In addition to IP addresses, other logical addressing systems include IPX/SPX and AppleTalk.
