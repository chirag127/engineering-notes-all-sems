
## Unit 3 - Network Layer in Computer Networks

1. The Network Layer is the third layer of the Open Systems Interconnection (OSI) model. It is responsible for the delivery of packets from the source to the destination over the network.
2. The Network Layer is responsible for routing of packets, which involves selecting the best path for the packets to take from the source to the destination. It also performs the fragmentation and reassembly of packets, which is necessary when the packets must traverse different networks with different packet sizes.
3. The Network Layer also provides services such as Quality of Service (QoS) and congestion control. QoS is used to ensure that packets are delivered with the desired quality, such as minimum delay or minimum packet loss. Congestion control is used to prevent the network from becoming overloaded.
4. The Network Layer provides features such as addressing and routing. Addressing is used to identify the source and destination of each packet. Routing is used to determine the path that the packets will take from the source to the destination.
5. The Network Layer also provides security features such as encryption and authentication. Encryption is used to protect the data from unauthorized access. Authentication is used to ensure that the packets are sent from an authorized source.
6. The Network Layer is responsible for the delivery of packets from the source to the destination over the network. It also provides features such as addressing, routing, Quality of Service (QoS), congestion control, encryption and authentication.
