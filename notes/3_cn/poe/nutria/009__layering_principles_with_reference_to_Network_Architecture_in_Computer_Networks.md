
#### Layering Principles with Reference to Network Architecture in Computer Networks

1. Layering is a concept used in computer networking to divide the network architecture into different layers. 
2. Each layer is responsible for a specific set of tasks and protocols, which are designed to make it easier for different systems to communicate with each other. 
3. The Open Systems Interconnection (OSI) model is the most widely used model for layering. It divides the network architecture into seven layers: Physical, Data Link, Network, Transport, Session, Presentation and Application. 
4. The Physical layer is responsible for transmitting raw bits over the network medium. It defines the type of cables and connectors used, as well as the type of signal used. 
5. The Data Link layer is responsible for providing reliable communication between devices. It is responsible for detecting and correcting errors in the data. 
6. The Network layer is responsible for routing packets through the network. It is responsible for addressing and routing packets from one node to another. 
7. The Transport layer is responsible for providing reliable communication between two hosts. It is responsible for providing end-to-end communication between two hosts. 
8. The Session layer is responsible for establishing, maintaining and terminating sessions between two hosts. It is responsible for setting up and maintaining a connection between two hosts. 
9. The Presentation layer is responsible for formatting and translating data between two hosts. It is responsible for translating data from one format to another. 
10. The Application layer is responsible for providing services to the end user. It is responsible for providing user-level services such as web browsing, email, file transfer and other services.
