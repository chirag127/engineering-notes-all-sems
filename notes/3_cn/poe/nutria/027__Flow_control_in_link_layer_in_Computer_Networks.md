
#### Flow control in link layer in Computer Networks

1. Flow control is the process of regulating the amount of data that is sent over a network in order to prevent data loss.

2. In the link layer of the OSI model, flow control is used to ensure that data is sent in a reliable manner.

3. Flow control works by sending a signal from the receiving device to the sending device when the receiving device is overwhelmed with data.

4. The sending device then stops sending data until it receives a signal from the receiving device that it is ready to receive more data.

5. Flow control can be implemented in two ways: window-based flow control and buffer-based flow control.

6. Window-based flow control works by setting a limit on the amount of data that can be sent at one time.

7. Buffer-based flow control works by setting a limit on the amount of data that can be stored in the receiving device's buffer.

8. Flow control is necessary in order to ensure that data is sent reliably and efficiently over a network.
