

### Basic Concepts of Cryptography in Application Layer

1. Cryptography is the practice and study of techniques for secure communication in the presence of third parties, known as adversaries.

2. Cryptography is used to protect the confidentiality, integrity, and authenticity of data in application layer.

3. Cryptography is used to protect data from unauthorized access and modification.

4. Cryptography is used to ensure the authenticity of data, so that only the intended recipient can access it.

5. Cryptography is used to ensure the integrity of data, so that it cannot be modified or tampered with.

6. Cryptography is used to ensure the non-repudiation of data, so that the sender cannot deny sending it.

7. Cryptography is used to protect data from eavesdropping, so that only the intended recipient can access the data.

8. Cryptography is used to protect data from spoofing, so that only the legitimate sender can send data.

9. Cryptography is used to protect data from man-in-the-middle attacks, so that only the intended recipient can access the data.

10. Cryptography is used to protect data from replay attacks, so that the data cannot be intercepted and replayed.
