
#### TCP Transport Layer Protocol

- TCP (Transmission Control Protocol) is a connection-oriented, reliable transport layer protocol used in the Internet protocol suite.
- It is responsible for providing reliable, ordered delivery of data between two endpoints.
- TCP is a full-duplex protocol, meaning it can send and receive data simultaneously.
- TCP is a connection-oriented protocol, meaning that it establishes a connection between two endpoints before any data is sent.
- TCP uses a three-way handshake to establish a connection between two endpoints.
- It also uses a sliding window protocol to ensure reliable delivery of data.
- TCP provides flow control by using a window size field in the header of each packet.
- TCP also provides congestion control to prevent overloading of the network.
- TCP implements checksums to detect errors in the data.
- TCP also allows for multiplexing of data across multiple connections.
