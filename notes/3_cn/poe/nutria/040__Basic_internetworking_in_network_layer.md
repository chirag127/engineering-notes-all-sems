
### Basic Internetworking in Network Layer 

1. Network layer is responsible for the delivery of packets from the source host to the destination host across multiple network links. 
2. It is responsible for logical addressing, routing, and flow control.
3. Network layer protocols include Internet Protocol (IP), Internet Control Message Protocol (ICMP), Address Resolution Protocol (ARP), and Reverse Address Resolution Protocol (RARP).
4. IP is a connectionless protocol used for packet delivery. It is responsible for logical addressing, fragmentation and reassembly of packets, and routing.
5. ICMP is a connectionless protocol used to provide feedback about the state of the network. It provides error messages, echo requests and replies, and other control messages.
6. ARP is a protocol used to map IP addresses to MAC addresses.
7. RARP is a protocol used to map MAC addresses to IP addresses.
8. Network layer protocols are used to provide end-to-end delivery of packets from the source host to the destination host.
