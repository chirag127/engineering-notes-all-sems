

#### ARP

ARP (Address Resolution Protocol) is a protocol used for resolving IP addresses to physical network addresses. It is used to map a host's IP address to its corresponding MAC address. ARP works by broadcasting a request to the local network, asking for the MAC address associated with a given IP address. The host with the corresponding IP address will then respond with its MAC address. ARP is a layer-2 protocol and is used by devices on the same local network.
