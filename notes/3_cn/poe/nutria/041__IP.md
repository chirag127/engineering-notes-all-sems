
#### IP

- IP stands for Internet Protocol, which is the primary protocol used for communication over the internet.
- IP addresses are unique numerical identifiers assigned to each device connected to a network.
- IP packets are used to transfer data between two devices on a network.
- IP routing is the process of directing packets to their destination by forwarding them through a series of routers.
- IP version 4 (IPv4) is the most widely used version of the protocol, while IP version 6 (IPv6) is the newer version that is gradually being adopted.
- Network Address Translation (NAT) is a technique used to allow multiple devices on a private network to access the internet using a single public IP address.
- IP Security (IPSec) is a protocol used to secure communications over the internet by encrypting IP packets.
