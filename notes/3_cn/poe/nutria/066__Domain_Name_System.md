
### Domain Name System

- The Domain Name System (DNS) is a hierarchical distributed naming system for computers, services, or any resource connected to the internet or a private network. 
- DNS is used to translate domain names into numerical IP addresses that are used to locate and identify computer services and devices with the underlying network protocols. 
- DNS also provides a list of mail exchange servers that accept emails for each domain name. 
- DNS is an essential component of the internet, as without it, it would be impossible to locate web servers and other services by name. 
- DNS is a client–server protocol, with the server providing the service of translating domain names into IP addresses. 
- DNS servers are organized in a hierarchy, with the root zone at the top of the hierarchy. 
- Each domain name is associated with an authoritative name server, which stores the DNS records for that domain name. 
- DNS records contain information such as the list of mail servers that accept email for a particular domain and the IP address of the web server that serves web pages for the domain. 
- DNS is also used for other services such as distributed hash tables and peer-to-peer networks.
