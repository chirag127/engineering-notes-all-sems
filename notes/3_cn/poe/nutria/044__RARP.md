
#### RARP

RARP stands for Reverse Address Resolution Protocol. It is a network protocol used to convert an Internet Protocol (IP) address into a physical address, such as an Ethernet address. It is used to map a network address to a physical address. 

RARP is a broadcast-based protocol, meaning that it sends out a request to all devices on the local area network (LAN) and waits for a response. The device that responds with the correct physical address is then mapped to the IP address. 

RARP is used primarily in local area networks (LANs) where IP addresses are assigned by a DHCP server. It is also used in remote access scenarios, such as dial-up connections, to map an IP address to a physical address. 

RARP is an older protocol and has been replaced by BOOTP and DHCP in most networks.
