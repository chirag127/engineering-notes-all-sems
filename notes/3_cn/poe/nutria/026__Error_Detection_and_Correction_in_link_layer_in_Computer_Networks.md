

#### Error Detection and Correction in link layer in Computer Networks

* Error detection and correction is a process used to detect and correct errors in data transmission over a network.
* Errors can be caused by noise, interference, or faulty hardware.
* Error detection is the process of detecting errors in data transmission. This is done by adding a checksum or parity bit to the data, which is used to detect any errors.
* Error correction is the process of correcting errors in data transmission. This is done by using error-correcting codes (ECC) which can detect and correct errors in data transmission.
* Error detection and correction is important in computer networks as it ensures data is transmitted accurately and reliably. It also helps to reduce the amount of data that needs to be retransmitted due to errors.
