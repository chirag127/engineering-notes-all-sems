
### Transport Layer Protocols

1. **Transmission Control Protocol (TCP)** is a reliable, connection-oriented protocol used to provide reliable communication between two hosts. It ensures that data is delivered in the correct order, without any data loss.

2. **User Datagram Protocol (UDP)** is an unreliable, connectionless protocol used for applications that do not require reliable communication. UDP does not guarantee the delivery of data, and does not ensure that data is delivered in the correct order.

3. **Stream Control Transmission Protocol (SCTP)** is a reliable, connection-oriented protocol used to provide reliable communication between two hosts. It is similar to TCP, but provides additional features such as multi-homing, multi-streaming, and message bundling.

4. **Datagram Congestion Control Protocol (DCCP)** is an unreliable, connection-oriented protocol used for applications that require low latency and congestion control. It provides congestion control, but does not guarantee the delivery of data.
