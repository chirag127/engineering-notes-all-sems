## Unit 3 - Network Layer in Computer Networks

The network layer is the third layer in the OSI model of computer networks. It is responsible for providing logical addressing and routing services to data packets. The main objectives of the network layer are to enable communication between different networks, to provide a means of addressing and identifying devices on a network, and to facilitate the movement of data packets between devices.

In this unit, we will cover the following topics related to the network layer:

1. Introduction to the Network Layer:
    - Definition and purpose of the network layer
    - Functions of the network layer
    - Network layer protocols (e.g., IP, ICMP)

2. Network Layer Addressing:
    - Types of network addresses (e.g., IP addresses, MAC addresses)
    - Structure of IP addresses
    - Subnetting and CIDR notation

3. Routing:
    - Definition and purpose of routing
    - Types of routing (e.g., static routing, dynamic routing)
    - Routing algorithms (e.g., distance vector, link-state)

4. Internet Protocol (IP):
    - Overview of IP
    - IPv4 versus IPv6
    - IP header format
    - Fragmentation and reassembly

5. Internet Control Message Protocol (ICMP):
    - Overview of ICMP
    - ICMP message types
    - ICMP error messages

6. Quality of Service (QoS):
    - Definition of QoS
    - Traffic management techniques (e.g., queuing, shaping, policing)
    - QoS protocols (e.g., DiffServ, IntServ)

7. Network Address Translation (NAT):
    - Definition and purpose of NAT
    - Types of NAT (e.g., static NAT, dynamic NAT)
    - NAT traversal techniques (e.g., STUN, TURN)

By the end of this unit, you should have a solid understanding of the network layer in computer networks, including its purpose, functions, and key protocols. Additionally, you should be familiar with network addressing, routing, IP, ICMP, QoS, and NAT. This knowledge will be essential for understanding the inner workings of computer networks and for designing and troubleshooting network infrastructures.
