#### DHCP

The Dynamic Host Configuration Protocol (DHCP) is a network management protocol used to automatically assign IP addresses and other network configuration parameters to devices on a network.

Here are some key points to understand about DHCP:

- DHCP uses a client-server model, where a DHCP server is responsible for assigning IP addresses and other configuration parameters to DHCP clients.
- When a device (client) connects to a network, it sends a DHCP request to the DHCP server to obtain an IP address and other configuration parameters.
- The DHCP server responds with a DHCP offer, which includes the IP address and other configuration parameters for the client to use.
- The client can then request to accept the offer and use the configuration parameters provided by the DHCP server.
- DHCP also supports the concept of lease time, which is the amount of time that a DHCP client can use the assigned IP address and other configuration parameters before it must renew them from the DHCP server.
- DHCP can also be used to provide other network configuration parameters such as subnet mask, default gateway, DNS server, and more.
- DHCP can be configured to provide either dynamic IP addresses, which are assigned for a limited time and can be reused, or static IP addresses, which are assigned permanently to a specific device.
- DHCP can be implemented on both IPv4 and IPv6 networks.

Overall, DHCP makes it easier to manage IP addresses and other network configuration parameters on a network by automating the assignment process and allowing for dynamic allocation of resources.
