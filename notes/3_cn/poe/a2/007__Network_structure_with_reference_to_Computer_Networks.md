#### Network structure with reference to Computer Networks.

1. Physical Layer:
    - Deals with the physical connection between devices.
    - Specifications for cabling, connectors, signal levels, etc.
    - Data transmitted as bits (0s and 1s).
2. Link Layer:
    - Nodes on the network are identified using MAC addresses.
    - Handles transmission of data between devices on the same network segment.
    - Performed using protocols like Ethernet, Token Ring, etc.
    - Handles errors and provides reliable data transmission.
3. Internet Layer:
    - Devices are identified using IP addresses.
    - Packets are forwarded between networks based on IP addresses.
    - Performed by Internet Protocol (IP).
    - Fragmentation and reassembly of packets is performed.
    - Routing of packets between networks is performed.
4. Transport Layer:
    - Provides end-to-end delivery of data across the network.
    - Protocols like TCP and UDP operate at this layer.
    - TCP provides reliable data delivery with error correction and ordering.
    - UDP provides fast but unreliable data delivery without error correction.
5. Application Layer:
    - Provides interfaces for applications to access network services.
    - Includes protocols like HTTP, SMTP, FTP, DNS, etc.
    - Data is delivered to applications at this layer.
