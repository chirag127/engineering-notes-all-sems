## Unit 2 - Link layer in Computer Networks and Medium Access Control and Local Area Networks

1. Link layer: The link layer is the lowest layer in the TCP/IP model. It is responsible for data transmission between devices on the same local network. It handles data encapsulation, physical addressing, network interface card addressing, error detection and correction. Some protocols at the link layer are Ethernet, Token Ring, FDDI, etc.

2. Medium Access Control (MAC): MAC is a sublayer of the link layer which controls access to the physical medium. It coordinates access among multiple devices so that they can share the medium and communicate efficiently. Example MAC protocols are CSMA/CD used in Ethernet and token passing used in Token Ring.

3. Local Area Networks (LANs): A LAN is a network that connects devices within a limited geographical area like an office, building or campus. Data transmission speeds are very high and devices can be connected using physical cables or wireless technologies. Examples of LANs are Ethernet, Token Ring, Wi-Fi, etc. Devices on a LAN can share resources like internet access, files and printers.
