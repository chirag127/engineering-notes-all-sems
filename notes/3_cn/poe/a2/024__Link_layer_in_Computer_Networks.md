#### Link layer in Computer Networks.

1. The link layer is the lowest layer in the TCP/IP model. It is responsible for transferring data between adjacent network nodes over a physical medium.
2. The primary functions of the link layer are:
- Framing: The link layer frames the packets received from the network layer into data units called frames. This is done by prepending headers and trailers to the packets.
- Error control: The link layer implements techniques to detect and retransmit corrupted or lost frames. This is done using checksums and acknowledgement mechanisms.
- Flow control: The link layer implements mechanisms to regulate the rate of data transmission between two nodes to prevent buffer overflows.
- Access control: The link layer coordinates shared access to the physical medium. It is responsible for MAC (Media Access Control) addressing and MAC protocols.
3. Examples of link layer technologies are Ethernet, Token Ring, FDDI, etc. Ethernet is the most popular link layer technology used in local area networks.
4. The link layer adds overhead in the form of headers and trailers. This overhead reduces the effective throughput of the network. However, the link layer performs critical functions to ensure reliable data delivery over the network.
