#### Network architecture with reference to Computer Networks

1. Client-Server Architecture:
    - Computing devices are divided into clients and servers.
    - Servers provide resources and services to clients.
    - Clients request and access the resources and services from servers.
    - Examples: Web servers, database servers, file servers, etc.
2. Peer-to-Peer Architecture:
    - All devices share resources and services equally.
    - There are no dedicated servers.
    - Devices can act as both clients and servers.
    - Examples: File sharing networks, distributed computing systems, etc.
3. Hybrid Architecture:
    - Combines aspects of client-server and peer-to-peer architectures.
    - Some resources are centralized on servers while others are shared in a peer-to-peer manner.
    - Allows leveraging benefits of both architectures.
