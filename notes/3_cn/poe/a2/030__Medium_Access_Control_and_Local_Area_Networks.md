#### Medium Access Control and Local Area Networks

1. Medium Access Control (MAC) - MAC protocols govern the rules by which multiple devices/nodes share a common communications channel (medium). They facilitate efficient transmission of data between nodes on a local area network (LAN). Some common MAC protocols are:
- Carrier Sense Multiple Access (CSMA) - Nodes check for carrier signal from other transmitting nodes before transmitting. If the channel is clear, nodes transmit. If collision occurs, nodes wait for a random time and try again.
- CSMA/Collision Detection (CSMA/CD) - Nodes check for collisions while transmitting. If collision is detected, transmitting nodes stop sending signal and wait for a random time before trying to retransmit. Ethernet uses CSMA/CD.
- Token Passing - A special data packet (token) is passed between nodes. Only the node possessing the token can transmit. After transmission, the token is passed to the next node. Token Ring uses token passing.

2. Local Area Networks (LANs) - LANs cover a small physical area, like an office building, and allow devices to share resources like internet access, storage, applications, and peripherals. Some characteristics of LANs are:
- High transmission speeds and low error rates
- Inexpensive to set up and maintain
- Limited geographic area
- Homogeneous systems/equipment
- Examples: Ethernet, Token Ring, FDDI
