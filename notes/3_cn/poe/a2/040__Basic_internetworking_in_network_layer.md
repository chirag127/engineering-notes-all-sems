### Basic internetworking in network layer

1. Two or more networks connect together to form an internetwork. The network layer provides the functional and procedural means of transferring variable length data sequences from a source host on one network to a destination host on a different network.

2. The two key functions of the network layer are:

- Routing: Determining a path through an internetwork between any two end systems.
- Forwarding: Moving network layer packets from a router's input interface to the appropriate output interface based on destination network address.

3. The network layer uses logical addressing to identify the destination network and the packet's destination host. Network layer protocols forward packets between networks based on the network address. The network address is hierarchical and uses variable-length subnet masks to allow aggregation of multiple networks into a single routing entry.

4. Key protocols at the network layer are:

- Internet Protocol (IP): Connectionless network layer protocol that provides best effort delivery of datagrams.
- Internet Control Message Protocol (ICMP): Used for diagnostic or control purposes.
- Address Resolution Protocol (ARP): Used to map IP addresses to MAC addresses.

5. Key concepts at the network layer are:

- Logical addressing
- Routing
- Packet forwarding
- Variable length subnet masks (VLSMs)
- Route aggregation
