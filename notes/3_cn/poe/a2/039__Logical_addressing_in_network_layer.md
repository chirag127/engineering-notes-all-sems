### Logical addressing in network layer

1. Logical addressing refers to identifying devices/hosts in a network using logical addresses like IP addresses rather than physical addresses like MAC addresses.
2. In the network layer, the source and destination devices are identified using logical addresses. The network layer protocol (IP) is responsible for logical addressing.
3. The logical addresses are assigned to devices independently of their physical locations in the network. This decoupling of logical and physical addressing enables devices to be moved to different physical locations without changing their logical addresses.
4. The logical addresses are hierarchical in nature, allowing networks to be grouped into subnets for efficient routing. The IP addresses have a network prefix and host identifier which aids in hierarchical addressing and routing.
5. Logical addressing enables internetworking between different physical networks and facilitates global connectivity between devices/networks. The border gateway protocol is used to exchange reachability information between autonomous systems and route traffic based on logical addresses.
