#### IP

1. IP stands for Internet Protocol. It is a numerical label assigned to each device connected to a network that uses the Internet Protocol for communication.

2. An IP address is a 32-bit number that identifies each device on the network. It has four parts, or octets, separated by periods. For example, 192.168.1.1 could be an IP address.

3. The four octets are each converted from decimal to binary and represented by eight binary digits, or bits. The 32 bits allow for over four billion unique IP addresses on the Internet.

4. IP addresses are classified into five classes - A, B, C, D, and E based on the number of networks and hosts they can support. Class A, B and C are used for hosts on the Internet, while Class D is used for multicast applications.

5. With the growing number of devices connecting to the Internet, IPv4 addresses are running out. IPv6 has been introduced to provide a much larger set of numerical labels to identify devices on the network. IPv6 addresses are 128 bits long and written in hexadecimal format.

6. DHCP or Dynamic Host Configuration Protocol is commonly used to automatically assign IP addresses to devices on a network. Static IP addresses can also be manually assigned to devices for identification and access.

7. The network portion of an IP address is used to identify the local network and direct data to the correct destination network. The host portion identifies the specific device on that network. This enables efficient routing of information on the Internet.
