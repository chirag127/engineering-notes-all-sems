## Unit 3 - Network Layer in Computer Networks

1. Introduction to Network Layer
- The network layer is responsible for packet forwarding including routing through intermediate routers.
- It also handles addressing and controlling flow of data packets between networks.
- The protocols used at network layer are IP, ICMP, ARP, RARP.

2. IP Protocol
- IP is a best effort delivery protocol providing packet delivery service.
- It is a connectionless protocol and packets may arrive out of order.
- IP addresses are logical addresses of devices connected to a network. They are needed for routing packets across networks.
- IP uses address classes for hierarchical routing and subnet masks to identify network and host portions of an address.

3. Subnetting
- It is a technique of dividing a network into smaller, more efficient networks.
- It allows optimal utilization of a large network and also enhances security and ease of management.
- Subnet mask is used to divide an IP address into network and host addresses and to identify the subnet an address belongs to.

4. CIDR
- Classless Inter-Domain Routing (CIDR) is a method for allocating IP addresses and routing Internet Protocol packets.
- CIDR eliminates need for classful network design and subnetting a network.
- It uses variable length subnet masks for routing and addressing purposes.
