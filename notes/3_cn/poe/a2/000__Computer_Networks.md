# Computer Networks

1. Introduction
- A computer network is a group of computers that use a set of common protocols to communicate and exchange data, resources and services.
- Networks allow sharing of resources and information.

2. Components
- Hardware: Network interface cards, routers, switches, cables, etc.
- Software: Protocols and applications that facilitate network communication like HTTP, FTP, SMTP, etc.
- Transmission media: Wired (Twisted pair, coaxial, fiber optic cable) or wireless (Wi-Fi, cellular, satellite, etc.)

3. Internetwork
- Interconnection of multiple individual networks to form an internet.
- Uses a common set of protocols (TCP/IP) to facilitate internetworking and global connectivity.
