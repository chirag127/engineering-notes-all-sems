#### ICMP

1. ICMP stands for Internet Control Message Protocol.
2. It is used for diagnostic or control purposes.
3. ICMP messages are encapsulated within IP packets.
4. Types of ICMP messages:
 - Echo Reply and Echo Request (Ping) - To check reachability of a host.
 - Destination Unreachable - Sent by a router if the destination is unreachable.
 - Time Exceeded - Sent by a router if TTL expires.
 - Parameter Problem - Sent by a router if there is a error in the IP header.
 - Redirect - Used by routers to inform hosts of better routes.
5. ICMP is a integral part of IP and used by network devices for monitoring, diagnostics and troubleshooting.
6. Note: Certain ICMP types like Echo Request can be used in attacks like Ping of Death hence security mechanisms should be in place to protect against such attacks.
