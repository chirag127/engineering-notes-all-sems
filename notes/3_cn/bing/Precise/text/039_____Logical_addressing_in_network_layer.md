### Logical addressing in network layer

- Logical addressing is used to provide a universal addressing scheme for identifying hosts on a network.
- The network layer is responsible for providing logical addressing and routing services in a communication network.
- Logical addresses are assigned to network devices by the network layer protocol and are used to route data between devices on different networks.
- The most common logical addressing scheme used in the network layer is the Internet Protocol (IP) addressing scheme.
- IP addresses are hierarchical, with the network portion of the address identifying the network and the host portion identifying the specific device on the network.
- The network layer uses routing protocols to determine the best path for data to travel from the source to the destination.
- Logical addressing and routing are essential for enabling communication between devices on different networks.
