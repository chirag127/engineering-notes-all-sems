### Static and dynamic routing in CN

1. **Static routing** is a type of routing in computer networks where the routing table is manually configured by a network administrator. This means that the routes to different destinations are fixed and do not change unless the administrator manually updates the routing table.

2. **Dynamic routing**, on the other hand, is a type of routing where the routing table is automatically updated by routing protocols. This means that the routes to different destinations can change dynamically based on network conditions, such as link failures or congestion.

3. Static routing is simple to configure and can be useful in small networks where the network topology is relatively stable. However, it can be difficult to manage in larger networks where the network topology changes frequently.

4. Dynamic routing is more complex to configure, but it can be more scalable and adaptable to changing network conditions. It is commonly used in larger networks where the network topology changes frequently.

5. Some common dynamic routing protocols include OSPF, EIGRP, BGP, and RIP.

6. The choice between static and dynamic routing depends on the size and complexity of the network, as well as the level of control and flexibility required by the network administrator. In some cases, a combination of both static and dynamic routing may be used.
