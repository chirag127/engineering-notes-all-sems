#### ARP

- ARP stands for Address Resolution Protocol.
- It is a protocol used to map an IP address to a physical address, also known as a MAC address, on a local network.
- ARP operates at the Data Link Layer of the OSI model.
- ARP is used when a device on a local network wants to communicate with another device on the same network, but only knows its IP address.
- The device sends an ARP request, which is a broadcast message, to all devices on the network.
- The device with the matching IP address responds with an ARP reply, which contains its MAC address.
- The requesting device can then use this MAC address to communicate with the target device directly.
- ARP is a stateless protocol, meaning it does not keep track of previous requests or replies.
- ARP cache is used to store recent ARP replies to reduce the number of ARP requests needed.
- ARP cache entries have a limited lifetime and are removed after a certain period of time.
- ARP can be vulnerable to attacks, such as ARP spoofing, where an attacker sends false ARP replies to redirect traffic to their own device.
