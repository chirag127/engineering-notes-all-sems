### Routing in network layer

Routing is the process of selecting a path for traffic in a network or between or across multiple networks. It is performed by a special device called a router. The network layer is responsible for routing packets from the source to the destination.

1. **Routing algorithms:** There are several routing algorithms used in the network layer, such as shortest path, flooding, distance vector, and link state. These algorithms determine the best path for a packet to take based on various factors such as the number of hops, cost, and congestion.

2. **Routing tables:** Routers maintain routing tables that contain information about the network topology and the best path to reach each destination. These tables are updated periodically or when there is a change in the network.

3. **Routing protocols:** Routing protocols are used to exchange routing information between routers. Some common routing protocols include RIP, OSPF, and BGP.

4. **Static and dynamic routing:** Static routing is when the routing table is manually configured by the network administrator. Dynamic routing is when the routing table is automatically updated using routing protocols.

5. **Advantages of routing in the network layer:** Routing in the network layer provides several advantages such as load balancing, fault tolerance, and scalability.

6. **Mnemonics:** A mnemonic to remember the OSI model layers in order is "Please Do Not Throw Sausage Pizza Away" where the first letter of each word represents a layer: Physical, Data Link, Network, Transport, Session, Presentation, Application.

7. **Learning trick:** To remember the difference between static and dynamic routing, think of static as something that does not change, like a statue, while dynamic is something that changes, like the weather. Static routing is manually configured and does not change unless the network administrator changes it, while dynamic routing automatically updates based on changes in the network.
