#### IP

- IP stands for Internet Protocol.
- It is a set of rules that govern the format of data sent over the internet or other networks.
- IP is a connectionless protocol, which means that it does not establish a connection before sending data.
- IP is responsible for routing data packets between devices on a network.
- IP is the primary protocol in the Internet Layer of the Internet Protocol Suite.
- The current version of IP is IPv4, but IPv6 is gradually being adopted to replace it.
- IPv4 addresses are 32-bit numbers, while IPv6 addresses are 128-bit numbers.
- IP addresses are written in dotted decimal notation for IPv4 and in hexadecimal notation for IPv6.
- A mnemonic to remember the difference between IPv4 and IPv6 is: "IPv4 has 4 numbers, IPv6 has 6 groups of numbers".
- IP provides a best-effort delivery service, which means that it does not guarantee that packets will be delivered or that they will arrive in the same order they were sent.
- IP can be used in conjunction with other protocols, such as TCP and UDP, to provide reliable data transmission.
- Some advantages of IP include its scalability, flexibility, and ability to support multiple network architectures.
- Some disadvantages of IP include its susceptibility to security threats and the limited number of available IPv4 addresses.
- IP is used in a wide range of applications, including web browsing, email, file transfer, and online gaming.
