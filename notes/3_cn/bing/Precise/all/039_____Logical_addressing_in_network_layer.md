### Logical addressing in network layer

- Logical addressing is used to provide a universal addressing scheme for identifying hosts on a network.
- It is used to route data between networks and to identify devices on different networks.
- The most common logical addressing scheme is the Internet Protocol (IP) addressing scheme.
- IP addresses are hierarchical and consist of two parts: the network ID and the host ID.
- The network ID identifies the network to which the host belongs, while the host ID identifies the specific host on that network.
- IP addresses are assigned to devices by the network administrator or by a Dynamic Host Configuration Protocol (DHCP) server.
- IP addresses can be either static or dynamic. Static IP addresses are manually assigned and do not change, while dynamic IP addresses are assigned by a DHCP server and can change over time.
- The network layer uses logical addresses to route data between networks. Routers use routing tables to determine the best path for forwarding data based on the destination IP address.
- Logical addressing is essential for communication between devices on different networks and is a key component of the network layer.
