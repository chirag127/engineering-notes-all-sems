#### Framing in link layer in Computer Networks

Framing is a function of the link layer in computer networks. It is the process of encapsulating data into frames for transmission over the network. Here are some key points to remember about framing in the link layer:

1. The link layer is responsible for providing a reliable connection between two directly connected nodes in a network.
2. Framing is the process of dividing the data stream into smaller units called frames for transmission over the network.
3. Each frame contains a header, payload, and trailer. The header contains information such as the source and destination addresses, while the trailer contains error-detection information.
4. The link layer uses various framing methods to encapsulate data into frames. Some common framing methods include character counting, byte stuffing, and bit stuffing.
5. The link layer is also responsible for error detection and correction. It uses techniques such as checksums and cyclic redundancy checks to detect errors in the transmitted frames.
6. Once the frames are received at the destination, the link layer decapsulates the data and passes it to the upper layers for further processing.
