#### Protocols and standards in networks architecture in Computer Networks

- **Protocols** are a set of rules and standards that define how data is transmitted and received over a network. They ensure that devices can communicate with each other and exchange information in a standardized way.

- **Standards** are technical specifications that define how different components of a network should operate and interact with each other. They are developed by organizations such as the International Organization for Standardization (ISO) and the Institute of Electrical and Electronics Engineers (IEEE).

- Some common protocols used in computer networks include:
  - **Transmission Control Protocol (TCP)**: This protocol is responsible for establishing connections between devices and ensuring that data is transmitted reliably and in the correct order.
  - **Internet Protocol (IP)**: This protocol is responsible for routing data packets between devices on a network. It assigns unique addresses to each device, allowing data to be sent to the correct destination.
  - **User Datagram Protocol (UDP)**: This protocol is used for transmitting data that does not require reliable delivery, such as streaming media or online gaming.
  - **Hypertext Transfer Protocol (HTTP)**: This protocol is used for transmitting web pages and other data over the internet.

- Some common standards used in computer networks include:
  - **Ethernet**: This is a standard for transmitting data over a local area network (LAN). It defines the physical and data link layers of the network.
  - **Wi-Fi**: This is a standard for transmitting data wirelessly over a local area network. It is based on the IEEE 802.11 family of standards.
  - **Bluetooth**: This is a standard for short-range wireless communication between devices.

- A mnemonic to remember the OSI model layers is **"Please Do Not Throw Sausage Pizza Away"**, which stands for Physical, Data Link, Network, Transport, Session, Presentation, and Application.

- A learning trick to remember the difference between TCP and UDP is that **TCP** is like making a **phone call** where you have to establish a connection before communicating, while **UDP** is like sending a **postcard** where you just send the message without establishing a connection.

- It is important to follow protocols and standards in network architecture to ensure interoperability between different devices and systems. This allows for seamless communication and data exchange, improving the efficiency and reliability of the network.
