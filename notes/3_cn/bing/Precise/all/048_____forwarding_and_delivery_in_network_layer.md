### Forwarding and Delivery in Network Layer

1. The network layer is responsible for forwarding and delivering data packets from the source to the destination.
2. Forwarding refers to the process of moving a packet from one network element to another, while delivery refers to the process of delivering the packet to the final destination.
3. The network layer uses routing algorithms to determine the best path for forwarding packets.
4. The network layer also handles congestion control, which is the process of managing network traffic to prevent congestion and ensure efficient data transmission.
5. The network layer can use various techniques for forwarding and delivery, such as virtual circuit switching, datagram switching, and source routing.
6. Virtual circuit switching involves establishing a dedicated path between the source and destination before data transmission begins.
7. Datagram switching, on the other hand, involves forwarding packets on a hop-by-hop basis, with each network element making independent forwarding decisions.
8. Source routing involves the source specifying the entire path for the packet to follow.
9. Each technique has its advantages and disadvantages, and the choice of technique depends on the specific requirements of the network and the data being transmitted.
10. A helpful mnemonic to remember the functions of the network layer is "Please Do Not Throw Sausage Pizza Away", where the first letter of each word corresponds to the first letter of the layers of the OSI model, with the network layer being the third layer represented by the letter "N" for "Not".
