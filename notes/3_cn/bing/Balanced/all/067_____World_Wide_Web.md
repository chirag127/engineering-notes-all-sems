### World Wide Web

- The World Wide Web (WWW) is a collection of different websites around the world, containing different information shared via local servers (or computers) .
- The WWW was invented by Tim Berners-Lee and his colleagues at CERN, an international scientific organization based in Geneva, Switzerland, in 1989  .
- They created a protocol, HyperText Transfer Protocol (HTTP), which standardized communication between servers and clients .
- HTTP allows users to access web pages by typing a Uniform Resource Locator (URL) in a web browser, such as Google Chrome or Mozilla Firefox.
- A web page is a document that contains text, images, videos, audio, or other multimedia elements, formatted using HyperText Markup Language (HTML).
- HTML uses tags to define the structure and appearance of a web page, such as headings, paragraphs, lists, tables, links, etc.
- A web page can also contain scripts, such as JavaScript, that add interactivity and functionality to the web page, such as validating user input, performing calculations, or displaying dynamic content.
- A web page can also link to other web pages using hyperlinks, which are clickable text or images that direct the user to another URL.
- The WWW is different from the internet, which is the global network of computers and devices that communicate using various protocols, such as TCP/IP, FTP, SMTP, etc.
- The internet is the infrastructure that enables the WWW and other applications, such as email, instant messaging, online gaming, etc.
- The WWW is one of the most popular and widely used applications of the internet, as it allows users to access and share information easily and conveniently.

#### Mnemonics and learning tricks

- To remember the difference between the WWW and the internet, you can use the following analogy: The internet is like a highway system that connects different cities, while the WWW is like the buildings and attractions that you can visit in each city.
- To remember the meaning of HTTP, you can use the following acronym: HyperText Transfer Protocol = How To Talk Properly.
- To remember the meaning of HTML, you can use the following acronym: HyperText Markup Language = How To Make Layouts.
