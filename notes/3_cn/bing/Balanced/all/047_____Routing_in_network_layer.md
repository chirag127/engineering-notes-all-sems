### Routing in network layer

- Routing is the process of finding the best possible path from the source host to the destination host in a network.
- Routing is performed by a special device known as a router, which works at the network layer in the OSI model and internet layer in TCP/IP model.
- A router forwards the packets based on the information available in the packet header and forwarding table, which contains the mapping of destination addresses and next-hop routers.
- Routing can be based on static tables that are rarely changed, or dynamic tables that are automatically updated depending on network conditions.
- Routing algorithms are used to determine the optimal routes for the packets. There are two main types of routing algorithms: distance vector and link state.
- Distance vector routing algorithms use the principle of "bellman-ford", which means that each router only knows the distance and direction to its neighbors, and exchanges this information periodically with them. The distance can be measured by hop count, delay, bandwidth, or other metrics. An example of distance vector routing algorithm is RIP (Routing Information Protocol).
- Link state routing algorithms use the principle of "dijkstra", which means that each router knows the entire topology of the network, and calculates the shortest path to every other router using a graph algorithm. The routers exchange their link state information periodically or when there is a change in the network. An example of link state routing algorithm is OSPF (Open Shortest Path First).
- Routing can also be classified into two categories: unicast and multicast. Unicast routing is the routing of packets from one source to one destination, while multicast routing is the routing of packets from one source to multiple destinations.
- Unicast routing can be further divided into two types: intra-domain and inter-domain. Intra-domain routing is the routing of packets within a single network domain, such as a LAN or a WAN. Inter-domain routing is the routing of packets between different network domains, such as the internet. An example of intra-domain routing protocol is IGRP (Interior Gateway Routing Protocol), and an example of inter-domain routing protocol is BGP (Border Gateway Protocol).
- Multicast routing can be further divided into two types: dense mode and sparse mode. Dense mode multicast routing is the routing of packets to all routers in the network, and then pruning the branches that do not have any receivers. Sparse mode multicast routing is the routing of packets to only the routers that have receivers, and then building the branches from them. An example of dense mode multicast routing protocol is DVMRP (Distance Vector Multicast Routing Protocol), and an example of sparse mode multicast routing protocol is PIM (Protocol Independent Multicast).

- A mnemonic to remember the types of routing algorithms is "DID LID", which stands for Distance vector, Intra-domain, Dense mode, Link state, Inter-domain, Sparse mode.
