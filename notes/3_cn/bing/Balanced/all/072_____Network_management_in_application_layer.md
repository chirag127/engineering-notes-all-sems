### Network management in application layer

- Network management is the process of configuring, monitoring, and managing the performance and security of a network and its resources, such as routers, switches, servers, printers, etc.
- Network management is usually performed by network administrators using specialized software tools and protocols that communicate with the network devices and collect information about their status, configuration, performance, and faults.
- Network management can be divided into five functional areas: fault management, configuration management, performance management, security management, and accounting management.
- The application layer is the topmost layer of the OSI model, which provides the interface between the network and the user applications, such as web browsers, email clients, file transfer programs, etc.
- The application layer protocols define the rules and formats for exchanging data between different applications over the network, such as HTTP, FTP, SMTP, DNS, etc.
- Some of the application layer protocols are also used for network management purposes, such as Simple Network Management Protocol (SNMP), Common Management Information Protocol (CMIP), and Remote Network Monitoring (RMON).
- SNMP is the most widely used application layer protocol for network management. It uses UDP port number 161/162 to communicate between network management stations (NMS) and network agents (NA) that are installed on the network devices.
- SNMP allows the NMS to query the NA for information about the device's configuration, performance, and faults, and to receive notifications (traps) from the NA when certain events occur on the device. SNMP also allows the NMS to modify the configuration of the device by sending commands (sets) to the NA.
- SNMP has three versions: SNMPv1, SNMPv2c, and SNMPv3. SNMPv1 is the original and simplest version, but it has limited security and functionality. SNMPv2c adds some enhancements, such as bulk data transfer and 64-bit counters, but it still uses plain text community strings for authentication. SNMPv3 adds security features, such as encryption, authentication, and access control, but it is more complex and requires more resources.
- CMIP is another application layer protocol for network management, which is based on the OSI model and uses TCP port number 163/164. CMIP is more powerful and flexible than SNMP, but it is also more complex and less popular. CMIP supports object-oriented data modeling, event notification, and operation invocation, and it uses Abstract Syntax Notation One (ASN.1) for data encoding.
- RMON is an application layer protocol that defines a set of statistics and functions for remote network monitoring. RMON can be used to monitor traffic, errors, utilization, and performance of network segments and devices. RMON uses SNMP as the transport protocol to communicate between the NMS and the RMON probes that are deployed on the network.
- A mnemonic to remember the five functional areas of network management is FCAPS, which stands for Fault, Configuration, Accounting, Performance, and Security.
- A learning trick to understand the difference between SNMP and CMIP is to compare them with HTTP and SOAP. HTTP is a simple and widely used protocol for web communication, but it has limited security and functionality. SOAP is a more powerful and flexible protocol for web services, but it is more complex and less popular. SOAP uses XML for data encoding, which is similar to ASN.1 used by CMIP.
