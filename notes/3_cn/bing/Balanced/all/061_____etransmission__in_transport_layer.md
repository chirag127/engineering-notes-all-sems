### etransmission in transport layer

- The transport layer is the fourth layer of the OSI model and the third layer of the TCP/IP model. It provides end-to-end communication services for applications, such as reliable data transfer, flow control, congestion control, error detection and correction, and multiplexing.
- etransmission is a term that refers to the process of sending and receiving data packets over a network using the transport layer protocols, such as TCP and UDP  .
- etransmission involves the following steps:
  - Segmentation: The transport layer divides the data stream from the application layer into smaller units called segments, which have a header and a payload. The header contains information such as the source and destination port numbers, sequence numbers, and checksums.
  - Multiplexing: The transport layer assigns a unique port number to each application process that communicates over the network, and uses the port numbers to identify the segments belonging to different processes. This allows multiple processes to share the same network connection.
  - Error detection and correction: The transport layer uses checksums to verify the integrity of the segments, and sends acknowledgements (ACKs) or negative acknowledgements (NACKs) to inform the sender about the status of the data transmission. If a segment is lost, corrupted, or duplicated, the transport layer can request a retransmission of the segment using the sequence numbers  .
  - Flow control: The transport layer regulates the rate of data transmission between the sender and the receiver, to avoid overwhelming the receiver or the network. The transport layer uses mechanisms such as sliding window, stop-and-wait, and backpressure to control the amount of data that can be sent or received at a time .
  - Congestion control: The transport layer monitors the network conditions and adjusts the data transmission rate accordingly, to avoid or reduce congestion in the network. The transport layer uses mechanisms such as additive increase multiplicative decrease (AIMD), slow start, congestion avoidance, and fast recovery to control the congestion .
- etransmission can be performed using different transport layer protocols, such as TCP and UDP. TCP is a connection-oriented, reliable, and full-duplex protocol that provides all the features of etransmission, such as segmentation, multiplexing, error detection and correction, flow control, and congestion control. UDP is a connectionless, unreliable, and simplex protocol that provides only segmentation and multiplexing, and does not guarantee the delivery, order, or integrity of the segments .
- etransmission is important for ensuring the quality of service (QoS) and the performance of the network applications, such as web browsing, email, file transfer, video streaming, online gaming, and voice over IP (VoIP). etransmission enables the applications to communicate effectively and efficiently over the network, without worrying about the details of the lower layers.
