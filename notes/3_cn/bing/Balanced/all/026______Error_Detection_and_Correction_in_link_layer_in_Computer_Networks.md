#### Error Detection and Correction in link layer in Computer Networks

- Error detection and correction in link layer is the process of detecting and correcting data frames that have been corrupted or lost during transmission .
- The link layer uses various error control techniques for this purpose. The basic approach is the use of redundancy, where additional bits are added to facilitate the detection and correction of errors .
- There are three main techniques for detecting errors in frames: Parity Check, Checksum and Cyclic Redundancy Check (CRC) .
  - Parity Check: The parity check is done by adding an extra bit, called parity bit to the data to make a number of 1s either even in case of even parity or odd in case of odd parity. For example, if the data is 1011 and even parity is used, the parity bit will be 0 to make the total number of 1s even. If odd parity is used, the parity bit will be 1 to make the total number of 1s odd. The receiver can check the parity bit and detect if there is a single bit error in the data. However, this technique cannot detect multiple bit errors or burst errors.
  - Checksum: The checksum is a value calculated from the data by applying some mathematical function, such as addition or XOR. The sender appends the checksum to the data and sends it to the receiver. The receiver recalculates the checksum from the received data and compares it with the received checksum. If they match, the data is assumed to be error-free. Otherwise, there is an error in the data. For example, if the data is 1011 and 1100, the checksum can be the sum of the two values, which is 10111. The receiver can add the received data and compare it with the received checksum. However, this technique cannot detect errors that cancel out each other, such as 1011 and 0100.
  - Cyclic Redundancy Check (CRC): The CRC is a value calculated from the data by applying a polynomial function, such as x^3 + x + 1. The sender appends the CRC to the data and sends it to the receiver. The receiver divides the received data by the same polynomial and checks the remainder. If the remainder is zero, the data is assumed to be error-free. Otherwise, there is an error in the data. For example, if the data is 1011 and the polynomial is x^3 + x + 1, the CRC can be the remainder of dividing 1011000 by the polynomial, which is 011. The receiver can divide the received data by the same polynomial and compare the remainder with the received CRC. However, this technique cannot detect errors that are multiples of the polynomial.
- Error correction in link layer is the process of recovering the original data from the corrupted or lost data frames. There are two main techniques for error correction in link layer: Automatic Repeat Request (ARQ) and Forward Error Correction (FEC) .
  - Automatic Repeat Request (ARQ): The ARQ is a technique that uses feedback from the receiver to the sender to request retransmission of corrupted or lost data frames. The sender keeps a copy of the sent data frames until it receives an acknowledgment (ACK) from the receiver. The receiver sends an ACK for each error-free data frame it receives. If the sender does not receive an ACK within a certain time, it assumes that the data frame was corrupted or lost and retransmits it.
