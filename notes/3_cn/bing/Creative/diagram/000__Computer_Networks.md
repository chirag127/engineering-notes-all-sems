A computer network diagram is a schematic depicting the nodes and connections among nodes in a computer network or, more generally, any telecommunications network. A network diagram can be either physical or logical, showing the actual physical arrangement of the components or the way information flows through the network. A network diagram can also show different types of network topologies, such as star, ring, bus, mesh, etc.

The following is an example of a basic network diagram in ASCII art, showing a local area network (LAN) with four computers, a switch, a router, and a firewall. The diagram uses the following symbols:

- C: Computer
- S: Switch
- R: Router
- F: Firewall
- -: Wired connection
- ~: Wireless connection
