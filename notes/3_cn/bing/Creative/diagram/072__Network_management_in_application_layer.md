Network management in application layer is the process of managing and monitoring the network services and applications that run on top of the network layer. It involves tasks such as configuration, fault detection, performance analysis, security enforcement, and resource allocation. One of the protocols that is used for network management in application layer is Simple Network Management Protocol (SNMP), which allows network devices to exchange information and status reports. SNMP uses a client-server model, where the network management system (NMS) acts as the client and the network devices act as the servers. The NMS can send requests to the network devices to get or set their configuration parameters, and the network devices can send responses or notifications (also called traps) to the NMS to report their status or events.
