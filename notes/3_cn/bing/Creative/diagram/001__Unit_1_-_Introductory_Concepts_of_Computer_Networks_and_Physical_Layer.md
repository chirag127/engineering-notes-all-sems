## Unit 1 - Introductory Concepts of Computer Networks and Physical Layer

A computer network is a group of interconnected computing devices that can send or receive data. A computing device can be any device that can run a program, such as a computer, tablet, phone, or smart sensor. A physical layer is the lowest layer of the OSI model of computer networking, which provides an electrical, mechanical, and procedural interface to the transmission medium.

The following diagram illustrates the basic architecture of a computer network and the physical layer:

```
+-----------------+     +-----------------+     +-----------------+
|                 |     |                 |     |                 |
|  Computing      |     |  Computing      |     |  Computing      |
|  Device         |     |  Device         |     |  Device         |
|                 |     |                 |     |                 |
+-----------------+     +-----------------+     +-----------------+
|                 |     |                 |     |                 |
|  Physical       |     |  Physical       |     |  Physical       |
|  Layer          |     |  Layer          |     |  Layer          |
|                 |     |                 |     |                 |
+-----------------+     +-----------------+     +-----------------+
|                 |     |                 |     |                 |
|  Transmission   |     |  Transmission   |     |  Transmission   |
|  Medium         |     |  Medium         |     |  Medium         |
|                 |     |                 |     |                 |
+-----------------+     +-----------------+     +-----------------+
```

The computing devices are the sources and destinations of data in a network. They can run various applications and protocols to communicate with each other. The physical layer is responsible for encoding, transmitting, and receiving data over the transmission medium, which can be a wire, a cable, a fiber, or a wireless channel. The physical layer also defines the characteristics of the transmission medium, such as the bandwidth, the signal strength, the noise level, and the error rate.

Some of the concepts and topics covered in this unit are:

- Goals and applications of networks, such as sharing resources, accessing information, and enabling communication.
- Network structure and architecture, such as the OSI reference model, the TCP/IP model, and the network topology.
- Services provided by the physical layer, such as bit transmission, synchronization, multiplexing, and modulation.
- Switching methods used by the physical layer, such as circuit switching, packet switching, and message switching.
- Transmission media used by the physical layer, such as twisted pair, coaxial cable, optical fiber, and radio waves.
- ISDN, a set of standards for digital transmission over telephone lines.
- Terminal handling, a process of connecting and controlling terminals to a network.
