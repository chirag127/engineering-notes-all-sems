Logical addressing is a way of identifying devices on a network using a logical address, such as an IP address, that is assigned by a network layer protocol. Logical addressing is used to route packets across different networks and to distinguish between the source and destination of a packet. Logical addressing is different from physical addressing, which is based on the hardware address (MAC address) of a device and is used to deliver frames within a local network.

### Logical addressing in network layer

The network layer is the third layer of the OSI model, and it is responsible for providing logical addressing and routing functions. The network layer defines an addressing scheme that can uniquely identify each device on an internetwork. The network layer also uses routing protocols and algorithms to determine the best path for a packet to reach its destination.
