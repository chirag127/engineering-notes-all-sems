#### ARP
The Address Resolution Protocol (ARP) is a communication protocol used for discovering the link layer address, such as a MAC address, associated with a given internet layer address, typically an IPv4 address. This mapping is a critical function in the Internet protocol suite.

The ARP packet structure consists of the following fields:

- Hardware type (HTYPE): specifies the network link protocol type, such as Ethernet.
- Protocol type (PTYPE): specifies the internetwork protocol for which the ARP request is intended, such as IPv4.
- Hardware address length (HLEN): specifies the length of the link layer address, such as 6 for MAC address.
- Protocol address length (PLEN): specifies the length of the internetwork address, such as 4 for IPv4 address.
- Operation (OPER): specifies the operation that the sender is performing, such as 1 for request and 2 for reply.
- Sender hardware address (SHA): specifies the MAC address of the sender.
- Sender protocol address (SPA): specifies the IPv4 address of the sender.
- Target hardware address (THA): specifies the MAC address of the intended receiver. This field is ignored in requests.
- Target protocol address (TPA): specifies the IPv4 address of the intended receiver.

The following diagram illustrates the basic operation of ARP:

```
+--------+      ARP request      +--------+
| Host A |--------------------->| Host B |
|        |<---------------------|        |
|        |      ARP reply       |        |
+--------+                      +--------+
| IP: X  |                      | IP: Y  |
| MAC: M |                      | MAC: N |
+--------+                      +--------+
```
