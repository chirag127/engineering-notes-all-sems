### Hyper Text Transfer Protocol

- Hyper Text Transfer Protocol (HTTP) is an application-layer protocol for transmitting hypermedia documents, such as HTML, between web browsers and web servers.  
- HTTP was developed by Tim Berners-Lee at CERN in 1989 and has evolved through several versions, such as HTTP/1.0, HTTP/1.1, HTTP/2 and HTTP/3.    
- HTTP follows a client-server model, where a client (such as a web browser) sends a request to a server (such as a web server) and waits for a response. The request and response messages are formatted according to the HTTP specifications and contain headers and optionally a body. 
- HTTP is a stateless protocol, meaning that the server does not keep any data (state) between two requests. However, HTTP can use cookies, which are small pieces of data sent by the server and stored by the client, to enable stateful interactions. 
- HTTP supports different methods (also called verbs) for the requests, such as GET, POST, PUT, DELETE, etc. Each method has a specific meaning and purpose, and is used to indicate the desired action on the server. For example, GET is used to retrieve a resource, POST is used to submit data to a resource, and DELETE is used to remove a resource. 
- HTTP also defines a set of status codes for the responses, such as 200 OK, 404 Not Found, 500 Internal Server Error, etc. Each status code has a specific meaning and indicates the outcome of the request. For example, 200 OK means that the request was successful, 404 Not Found means that the requested resource was not found on the server, and 500 Internal Server Error means that the server encountered an unexpected error. 
- HTTP can use encryption and authentication mechanisms to provide security and privacy for the communication. The most common way to secure HTTP is to use HTTPS, which is HTTP over Transport Layer Security (TLS). HTTPS encrypts the data exchanged between the client and the server, and verifies the identity of the server using certificates.
