#### Flow control in link layer in Computer Networks

Flow control is a technique that allows two stations working at different speeds to communicate with each other. It is a set of measures taken to regulate the amount of data that a sender sends so that a fast sender does not overwhelm a slow receiver. Flow control is essential for the data link layer because it determines the amount of data that a sender can send before waiting for an acknowledgment from the receiver.  

There are two main approaches to flow control: feedback-based and rate-based. Feedback-based flow control relies on the receiver sending back information to the sender about its readiness to receive more data. Rate-based flow control limits the rate at which the sender transmits data without any feedback from the receiver.  

There are two common techniques of feedback-based flow control in the data link layer: stop-and-wait and sliding window. Stop-and-wait flow control is the simplest method, where the sender sends one frame at a time and waits for an acknowledgment from the receiver before sending the next frame. This method is inefficient if the propagation delay is much longer than the transmission delay. Sliding window flow control is a more advanced method, where the sender can send multiple frames without waiting for acknowledgments, but the number of frames in transit is limited by a window size. This method improves the utilization of the channel and reduces the waiting time.  

A special case of feedback-based flow control is the pause frame, which is used in Ethernet networks. A pause frame is a media access control (MAC) frame that halts the transmission of the sender for a specified period of time. A pause frame can be sent by a receiver that is overwhelmed by the incoming data, or by a network switch that is congested. A pause frame can be sent to a unique destination address or to a reserved multicast address. 

Rate-based flow control is usually implemented by a built-in mechanism in the protocol that restricts the overall rate at which the sender transmits data. This can be done by using timers, counters, or tokens. Rate-based flow control is suitable for data center bridging (DCB) networks, where different classes of service (CoS) can have different priorities and bandwidth requirements. A standard for rate-based flow control in DCB networks is the priority-based flow control (PFC), which provides a link-level flow control mechanism that can be controlled independently for each CoS.
