### Point-to-point networks in network layer

- Point-to-point networks are networks that connect two nodes directly without any intermediate devices or networks.
- Point-to-point networks can use different physical media, such as copper wire, fiber optic, satellite, or dial-up modem.
- Point-to-point networks can also use different data link layer protocols, such as High-level Data Link Control (HDLC), Point-to-Point Protocol (PPP), or Point-to-Point Tunneling Protocol (PPTP).
- Point-to-Point Protocol (PPP) is a common data link layer protocol for point-to-point networks. It has the following features :
  - It can encapsulate different network layer protocols, such as IP, IPX, or AppleTalk.
  - It can negotiate connection options and features, such as authentication, encryption, or compression.
  - It can establish, configure, and test the link using Link Control Protocol (LCP).
  - It can use different Network Control Protocols (NCP) for different network layer protocols, such as Internet Protocol Control Protocol (IPCP) for IP.
- Point-to-point networks are useful for providing dedicated and secure connections between two nodes, such as a client and a server, or a router and another router.
- Point-to-point networks are also useful for tunneling network layer traffic over another network, such as the Internet, using protocols such as PPTP or PPP over Ethernet (PPPoE).
