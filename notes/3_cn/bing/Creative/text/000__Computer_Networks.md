# Computer Networks

A computer network is a system that connects two or more computing devices for transmitting and sharing information. Computing devices include everything from a mobile phone to a server. These devices are connected using physical wires such as fiber optics, but they can also be wireless  .

The main components of a computer network are:

- Network devices or nodes: These are the computing devices that need to be linked in the network. They can be classified into end devices (such as laptops, smartphones, printers, etc.) and intermediary devices (such as routers, switches, firewalls, etc.).
- Network links or media: These are the physical or logical connections that enable data transmission between the network devices. They can be wired (such as copper cables, fiber optics, etc.) or wireless (such as radio waves, infrared, etc.).
- Network protocols: These are the rules and standards that govern how the network devices communicate and exchange data. They define the format, timing, sequence, and error control of the data packets. Some common network protocols are TCP/IP, Ethernet, Wi-Fi, HTTP, etc..

The main types of computer networks are:

- Local Area Network (LAN): This is a network that connects devices within a limited physical area, such as a home, office, or campus. LANs are usually fast, secure, and easy to manage. They can use different network architectures, such as Ethernet, Token Ring, etc. .
- Wide Area Network (WAN): This is a network that connects devices across a large geographic area, such as a country, continent, or the world. WANs are usually slower, less secure, and more complex to manage than LANs. They use different network technologies, such as ATM, Frame Relay, MPLS, etc. The Internet is the largest WAN, which connects billions of devices across the world .
- Metropolitan Area Network (MAN): This is a network that connects devices within a metropolitan area, such as a city or a town. MANs are usually larger than LANs, but smaller than WANs. They can use different network technologies, such as Ethernet, WiMAX, etc. .
- Personal Area Network (PAN): This is a network that connects devices within a personal range, such as a few meters. PANs are usually used for personal or individual purposes, such as connecting a smartphone to a headset, a laptop to a printer, etc. They can use different network technologies, such as Bluetooth, NFC, etc. .
- Wireless Local Area Network (WLAN): This is a network that connects devices using wireless media, such as radio waves or infrared. WLANs are usually based on the IEEE 802.11 standard, which is commonly known as Wi-Fi. WLANs can provide wireless access to a LAN or the Internet .

The main objectives of creating and deploying a computer network are:

- To share data and resources: A computer network allows users to access and exchange data and resources, such as files, printers, scanners, etc., among different devices. This can improve the efficiency, productivity, and collaboration of the users .
- To communicate and interact: A computer network enables users to communicate and interact with each other, using different applications, such as email, instant messaging, video conferencing, social media, etc. This can enhance the social and professional relationships of the users .
- To access information and services: A computer network provides users with access to information and services, such as web pages, online databases, cloud computing, e-commerce, etc., that are available on the Internet or other networks. This can expand the knowledge and opportunities of the users .
- To reduce costs and improve performance: A computer network can reduce the costs and improve the performance of the devices and applications, by using shared resources, distributed processing, load balancing, caching, etc. This can optimize the utilization and availability of the network .
