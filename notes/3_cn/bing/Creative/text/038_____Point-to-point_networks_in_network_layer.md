### Point-to-point networks in network layer

- A point-to-point network is a network topology that connects two nodes directly using a single link.
- A point-to-point network can be used to connect two routers, two hosts, or a router and a host without any intermediate devices or networks.
- A point-to-point network can provide high bandwidth, low latency, and reliable communication between the two nodes.
- A point-to-point network can also support authentication, encryption, and compression of the data transmitted over the link.
- A common protocol used for point-to-point networks is the Point-to-Point Protocol (PPP), which operates at the data link layer (layer 2) of the OSI model.
- PPP can encapsulate different types of network layer (layer 3) packets, such as IP, IPX, or AppleTalk, into frames for transmission over the point-to-point link.
- PPP also has a Link Control Protocol (LCP) that establishes, configures, and tests the data link connection, and a Network Control Protocol (NCP) that negotiates the network layer parameters, such as IP address, for each encapsulated protocol.
- PPP can also use other protocols, such as Point-to-Point Tunneling Protocol (PPTP), to create virtual point-to-point links over other networks, such as the Internet.
