### Network management in application layer

- Network management is the process of configuring, monitoring, and managing the performance of a network, as well as the platform that IT and NetOps teams use to complete these ongoing tasks.
- The application layer is the topmost layer in the Open System Interconnection (OSI) model, which provides services directly for application processes and allows users to access network resources.
- The application layer is also an abstraction layer that specifies the shared protocols and interface methods used by hosts in a communication network, such as HTTP, FTP, SMTP, DNS, etc .
- The application layer helps to identify communication partners, synchronize communication, and handle issues such as network transparency and resource allocation.
- The application layer interacts with the presentation layer, which carries the syntax and semantics of the information transmitted, and the operating system, which preserves the data in a suitable manner.
- The application layer handles network services, such as file and printing, name resolution, and redirector services. Name resolution is the process of mapping an IP address to a human-readable name, such as a domain name.
- Network management systems collect data from network elements and endpoint devices using protocols such as SNMP or streaming telemetry, and use this data to provide insights into the health and performance of the network.
- Network management systems also give network administrators fine-grained control over how network elements operate and interact with each other, and enable them to proactively identify and resolve issues, monitor security and segmentation, and optimize network performance.
- Network management systems have evolved to support more complex and diverse networks, such as LANs, SD-WANs, security, and IoT, and to operate in more agile ways, incorporating advanced analytics, machine learning, and intelligent automation.
- Network management systems are increasingly deployed in cloud and hosted environments, as organizations adapt to a more distributed workforce and need to unify sites and remote workers.
