### Basic concepts of cryptography in application layer

Cryptography is the process of hiding or coding information so that only the intended recipient can read it. Cryptography is used to protect the confidentiality, integrity, and authenticity of data and communication in various applications, such as web browsing, email, messaging, and e-commerce. Cryptography uses mathematical concepts and algorithms to transform plain text into cipher text, which is unintelligible to unauthorized parties, and vice versa. Cryptography also uses cryptographic keys and digital signatures to ensure the security of data and communication.

Some of the basic concepts of cryptography in application layer are:

- Symmetric key cryptography: This is a type of cryptography that uses the same key to encrypt and decrypt data. The key is shared between the sender and the receiver, and must be kept secret from anyone else. Symmetric key cryptography is fast and efficient, but it has the problem of key distribution and management. For example, if Alice and Bob want to communicate securely using symmetric key cryptography, they have to exchange the key in person or through a secure channel, and they have to change the key frequently to prevent compromise. Symmetric key cryptography is used for encrypting data at rest, such as files and databases, and for encrypting data in transit, such as VPNs and TLS sessions. Some examples of symmetric key algorithms are AES, DES, and RC4. 

- Asymmetric key cryptography: This is a type of cryptography that uses a pair of keys to encrypt and decrypt data. The keys are called public key and private key, and they have a mathematical relationship such that data encrypted with one key can only be decrypted with the other key. The public key can be shared with anyone, while the private key must be kept secret by the owner. Asymmetric key cryptography solves the problem of key distribution and management, as the sender can use the receiver's public key to encrypt data, and the receiver can use their own private key to decrypt data. Asymmetric key cryptography is slower and less efficient than symmetric key cryptography, but it provides more security and functionality. For example, asymmetric key cryptography can be used for digital signatures, which verify the identity and integrity of the sender and the data. Asymmetric key cryptography is used for key exchange, authentication, and digital signatures in various applications, such as SSL/TLS, SSH, and PGP. Some examples of asymmetric key algorithms are RSA, DSA, and ECC.  

- Cryptographic hash functions: This is a type of function that takes any input data and produces a fixed-length output, called a hash or a digest, that uniquely identifies the input data. The hash function has the properties of being one-way, meaning that it is easy to compute the hash from the input, but hard to find the input from the hash, and collision-resistant, meaning that it is hard to find two different inputs that produce the same hash. Cryptographic hash functions are used to ensure the integrity and authenticity of data and communication, as any modification or tampering of the input data will result in a different hash. For example, cryptographic hash functions can be used for checksums, message authentication codes (MACs), and digital signatures. Some examples of cryptographic hash functions are SHA-1, SHA-2, and SHA-3. 

- Cryptographic protocols: This is a set of rules and procedures that define how cryptographic algorithms and keys are used to achieve a specific security goal. Cryptographic protocols are used to establish secure communication channels, exchange keys, authenticate parties, and protect data and communication in various applications. For example, cryptographic protocols can be used for secure web browsing (HTTPS), secure email (S/MIME), secure file transfer (SFTP), and secure wireless network (WPA2). Some examples of cryptographic protocols are SSL/TLS, SSH, and PGP.
