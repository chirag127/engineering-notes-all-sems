### Routing in network layer

- Routing is the process of selecting a path across one or more networks for data packets to travel from their source to their destination .
- Routing is performed by a special device known as a router, which works at the network layer in the OSI model and internet layer in TCP/IP model.
- A router is a networking device that forwards the packet based on the information available in the packet header and forwarding table.
- The routing algorithms are used for routing the packets. They can be static or dynamic .
- Static routing algorithms do not change and are manually set up by a network administrator.
- Dynamic routing algorithms update automatically and use various routing protocols to determine the shortest and fastest paths based on network conditions.
- Routing is different from forwarding, which is the process of moving a packet from one interface to another within a router .
- Forwarding is based on the forwarding table, which maps the destination address to the outgoing interface .
- Routing and forwarding are two of the main functions of the network layer, along with packetizing, addressing, and error control .
