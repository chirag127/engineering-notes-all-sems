### Domain Name System

- The Domain Name System (DNS) is a hierarchical and decentralized system that translates human-readable domain names (such as www.example.com) into numerical IP addresses (such as 192.0.2.1) that identify the devices and services on the Internet.
- The DNS consists of four main components: domain names, name servers, resolvers, and resource records.
- Domain names are the alphanumeric labels that are used to refer to specific websites or services on the Internet. They are organized into a tree-like structure, with the root domain at the top, followed by top-level domains (TLDs), such as .com, .org, .net, etc., and then subdomains, such as www, mail, etc. Each domain name has a unique owner and administrator, who can delegate authority to subdomains or subordinates.
- Name servers are the devices that store and provide the mapping between domain names and IP addresses. They are organized into a distributed and hierarchical network, with the root name servers at the top, followed by authoritative name servers for each TLD, and then authoritative name servers for each subdomain. Name servers communicate with each other using the DNS protocol, which defines the format and semantics of the queries and responses.
- Resolvers are the devices that initiate and process the DNS queries on behalf of the end users or applications. They are typically part of the operating system or the network configuration of the user's device. Resolvers send DNS queries to the name servers, starting from the root name servers and following the referrals until they reach the authoritative name server that has the answer. Resolvers cache the answers for a specified time to reduce the network traffic and latency.
- Resource records are the data elements that store the information about the domain names and IP addresses. They are stored in name servers and transferred in DNS queries and responses. Each resource record has a type, a name, a value, and a time-to-live (TTL). The type specifies the kind of information that the record contains, such as A (address), NS (name server), MX (mail exchange), etc. The name specifies the domain name that the record applies to, such as www.example.com. The value specifies the data that the record provides, such as 192.0.2.1, ns1.example.com, mail.example.com, etc. The TTL specifies how long the record can be cached by the resolvers before it expires and needs to be refreshed.
