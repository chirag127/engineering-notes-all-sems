## Unit 3 - Network Layer in Computer Networks

The network layer is responsible for routing packets from the source to the destination across multiple hops and networks. It also provides services such as addressing, congestion control, error detection and correction, fragmentation and reassembly, and quality of service.

Some of the main topics covered in this unit are:

- Network layer functions and design issues: This topic explains the role of the network layer in the Internet architecture, the principles of network layer design, and the challenges faced by network layer protocols.
- Network layer protocols: This topic introduces the main network layer protocols used in the Internet, such as IP, ICMP, ARP, DHCP, and NAT. It also describes the format, functions, and operations of these protocols.
- Routing algorithms: This topic covers the basic concepts and techniques of routing, such as routing tables, forwarding, and routing metrics. It also discusses the types and characteristics of routing algorithms, such as static, dynamic, centralized, distributed, adaptive, and non-adaptive.
- Routing protocols: This topic explains the operation and features of various routing protocols used in the Internet, such as RIP, OSPF, BGP, and multicast routing protocols. It also compares and contrasts the advantages and disadvantages of these protocols.
- Congestion control and quality of service: This topic addresses the problem of congestion in networks, and the methods and mechanisms to prevent, detect, and control congestion. It also introduces the concept and requirements of quality of service, and the techniques and protocols to provide different levels of service to different applications and users.
