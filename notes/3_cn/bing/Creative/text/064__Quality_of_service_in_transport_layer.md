### Quality of service in transport layer

- Quality of service (QoS) is the use of mechanisms or technologies that work on a network to control traffic and ensure the performance of critical applications with limited network capacity.
- QoS enables organizations to adjust their overall network traffic by prioritizing specific high-performance applications, such as videoconferencing, online gaming, or VoIP.
- QoS is typically applied to networks that carry traffic for resource-intensive systems that require low latency, high bandwidth, and low packet loss.
- QoS can also be seen as the enhancement of the service provided by the network layer, which may be unreliable, unpredictable, or insufficient for some applications .
- The transport layer is responsible for providing QoS to the application layer by using various techniques, such as :
  - Transport addresses: The transport layer defines end points for communication, which are usually pairs of IP addresses and port numbers. These addresses identify the source and destination processes that wish to communicate.
  - Connection establishment and termination: The transport layer can set up and tear down connections between processes using service primitives, such as T-CONNECT, T-DISCONNECT, T-ACCEPT, etc. These primitives allow the transport layer to negotiate the QoS parameters, such as reliability, throughput, delay, etc., for each connection.
  - Reliable data transport: The transport layer can ensure the delivery of data without errors, losses, duplications, or reordering by using techniques, such as checksums, sequence numbers, acknowledgments, timers, retransmissions, etc. These techniques can be applied to single packets or blocks of packets.
  - Congestion control and rate control: The transport layer can regulate the flow of data to avoid network congestion and ensure fair allocation of bandwidth among different connections. This can be done by using techniques, such as window-based flow control, feedback-based flow control, random early detection, etc. These techniques can adjust the sending rate or the window size of the sender based on the network conditions or the feedback from the receiver.
- QoS in the transport layer can be classified into two categories: best-effort and guaranteed.
  - Best-effort QoS: This is the default QoS provided by the transport layer, which does not guarantee any specific level of performance or reliability. The transport layer tries to deliver the data as fast and as reliably as possible, but does not make any promises. This QoS is suitable for applications that can tolerate some degree of variability or degradation in the service, such as web browsing, email, file transfer, etc. The most common transport protocol that provides best-effort QoS is the Transmission Control Protocol (TCP).
  - Guaranteed QoS: This is the QoS that provides a certain level of performance or reliability that is agreed upon by the sender and the receiver before the communication starts. The transport layer ensures that the data is delivered within the specified QoS parameters, such as bandwidth, delay, jitter, packet loss, etc. This QoS is suitable for applications that require strict and consistent service, such as real-time audio, video, or interactive gaming. The most common transport protocol that provides guaranteed QoS is the User Datagram Protocol (UDP).
