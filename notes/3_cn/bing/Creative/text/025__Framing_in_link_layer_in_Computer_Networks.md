#### Framing in link layer in Computer Networks

Framing is a function of the data link layer that provides a way for a sender to transmit a set of bits that are meaningful to the receiver. Framing uses frames to send or receive data. The data link layer receives packets from the network layer and converts them into frames. Frames have headers that contain information such as error-checking codes, source and destination addresses, and protocol identifiers. Frames are the result of the final layer of encapsulation before the data is transmitted over the physical layer .

Framing is an important aspect of data link layer protocol design because it allows the transmission of data to be organized and controlled, ensuring that the data is delivered accurately and efficiently. Framing also helps to identify the boundaries of the frames and to distinguish them from each other. There are different methods of framing, depending on the data link layer technology and the characteristics of the physical layer .

Some of the common methods of framing are:

- Fixed size: The frame is of fixed size and there is no need to provide boundaries to the frame, the length of the frame itself acts as a delimiter. This method is simple and efficient, but it suffers from internal fragmentation if the data size is less than the frame size. Padding can be used to fill the empty space in the frame.
- Variable size with length field: The frame has a variable size and a length field in the header to indicate the length of the frame. This method is flexible and avoids internal fragmentation, but it requires an extra field in the header and it can be corrupted by errors in transmission .
- Variable size with end delimiter: The frame has a variable size and a special bit pattern or character to indicate the end of the frame. This method is also flexible and avoids internal fragmentation, but it requires a unique end delimiter that does not occur in the data. If the end delimiter occurs in the data, it can be escaped or stuffed with another bit or character to differentiate it from the actual end delimiter .
- Variable size with encoding violations: The frame has a variable size and uses a specific encoding scheme to represent the data and the end of the frame. This method does not require any extra field or delimiter, but it requires a consistent encoding scheme that can be violated to indicate the end of the frame. For example, in Manchester encoding, a transition from high to low or low to high in the middle of a bit period represents a 0 or a 1, respectively. A transition at the beginning of a bit period can be used to indicate the end of the frame .
