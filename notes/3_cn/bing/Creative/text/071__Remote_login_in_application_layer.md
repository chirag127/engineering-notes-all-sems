### Remote login in application layer

- Remote login is a process in which a user can login into a remote computer and use the services that are available on that computer .
- Remote login is implemented using Telnet, which is a protocol that allows a user to communicate with a remote device or server over the Internet .
- Telnet uses a universal character set called Network Virtual Terminal (NVT) to exchange data and commands between the local and remote computers.
- NVT has two sets of characters, one for data and one for control. The data characters are 8-bit bytes with the highest bit set to 0 and the lower 7 bits as ASCII. The control characters are 8-bit bytes with the highest bit set to 1 and the lower 7 bits as commands.
- The procedure of remote login is as follows:
  - The user types something on the local computer, and the local operating system accepts the characters.
  - The local computer does not interpret the characters, but sends them to the Telnet client.
  - The Telnet client transforms the characters to NVT characters and passes them to the local TCP/IP protocol stack.
  - The NVT characters travel through the Internet and arrive at the TCP/IP stack at the remote computer.
  - The TCP/IP stack delivers the characters to the operating system, which passes them to the Telnet server.
  - The Telnet server converts the characters from NVT to the format that the remote computer can understand.
  - The remote operating system receives the characters from a pseudo-terminal driver, which is a software that pretends that the characters are coming from a terminal.
  - The remote operating system passes the characters to the appropriate application program, such as a shell or a text editor.
- Remote login is an example of an application layer service, which is the topmost layer in the OSI model and the TCP/IP model  .
- The application layer provides several functions, such as  :
  - Identifying communication partners and determining resource availability.
  - Synchronizing communication and managing sessions.
  - Providing access to various network services, such as email, file transfer, directory services, etc.
  - Presenting meaningful data and information to the users and applications.
  - Handling issues such as network transparency, resource allocation, security, etc.
