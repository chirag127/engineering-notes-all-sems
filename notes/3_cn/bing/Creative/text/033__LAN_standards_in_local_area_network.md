#### LAN standards in local area network

- A local area network (LAN) is a data communication network connecting various terminals or computers within a building or limited geographical area. The connection among the devices could be wired or wireless.
- The IEEE 802 is a family of standards for LAN, personal area network (PAN), and metropolitan area network (MAN) maintained by the IEEE 802 LAN/MAN Standards Committee (LMSC).
- The IEEE 802 standards map to the lower two layers (data link and physical) of the OSI networking reference model.
- The most widely used IEEE 802 standards are:
  - IEEE 802.1: Higher Layer LAN Protocols Working Group
  - IEEE 802.3: Ethernet, a wired LAN technology that uses a bus or star topology and supports data transfer rates of 10 Mbps to 100 Gbps 
  - IEEE 802.11: Wireless LAN, a wireless LAN technology that uses radio waves or infrared signals to transmit and receive data over the air 
  - IEEE 802.15: Wireless PAN, a wireless PAN technology that enables communication among devices such as personal computers, printers, cameras, and mobile phones 
  - IEEE 802.16: Wireless MAN, a wireless MAN technology that provides broadband wireless access to fixed and mobile subscribers 
- Some other IEEE 802 standards that are not widely used or have been disbanded are:
  - IEEE 802.2: Logical Link Control (LLC), a sublayer of the data link layer that provides a common interface for different MAC protocols
  - IEEE 802.4: Token bus, a wired LAN technology that uses a bus topology and a token-passing scheme for media access control
  - IEEE 802.5: Token Ring, a wired LAN technology that uses a ring topology and a token-passing scheme for media access control
  - IEEE 802.6: Metropolitan Area Network (MAN), a wired MAN technology that uses a dual bus and a distributed queue for data transmission
  - IEEE 802.7: Broadband LAN using Coaxial Cable, a wired LAN technology that uses coaxial cable as the transmission medium
  - IEEE 802.8: Fiber Optic TAG, a technical advisory group that provided guidelines for the use of fiber optic cable in LANs
  - IEEE 802.9: Integrated Services LAN (ISLAN or isoEthernet), a wired LAN technology that supports the integration of voice, video, and data on a single network
  - IEEE 802.10: Interoperable LAN Security, a standard that defines security mechanisms for LANs
