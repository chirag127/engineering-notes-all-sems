#### Network devices in Computer Networks

Network devices are physical devices that enable communication and interaction between hardware on a computer network. Each networking device operates in a distinct computer network segment and performs distinct functions. A network may require hundreds or thousands of different network devices to maintain and build out various LAN and WAN.

Some of the common types of network devices are:

- **Repeater**: A repeater is a device that operates at the physical layer of the OSI model. Its job is to regenerate the signal over the same network before the signal becomes too weak or corrupted to extend the length to which the signal can be transmitted over the same network. A repeater is a two-port device that does not filter or modify the data.
- **Hub**: A hub is a device that operates at the physical layer of the OSI model. It is a multi-port repeater that connects multiple wires coming from different branches of a network. A hub cannot filter data, so data packets are sent to all connected devices. A hub creates a single collision domain and a single broadcast domain. There are different types of hubs, such as active, passive, and intelligent hubs.
- **Bridge**: A bridge is a device that operates at the data link layer of the OSI model. It is a two-port device that connects two LANs or two segments of the same LAN that use the same protocol. A bridge filters data by reading the MAC addresses of the source and destination. It also reduces network traffic by dividing the network into smaller segments. There are different types of bridges, such as transparent, source routing, and remote bridges.
- **Switch**: A switch is a device that operates at the data link layer or the network layer of the OSI model. It is a multi-port device that connects multiple devices on a network and forwards data packets to the intended destination. A switch creates multiple collision domains and a single broadcast domain. A switch can also perform filtering, learning, and forwarding functions based on the MAC addresses or the IP addresses of the devices .
- **Router**: A router is a device that operates at the network layer of the OSI model. It is a multi-port device that connects different networks or subnets and forwards data packets based on the IP addresses. A router creates multiple broadcast domains and can also perform routing, filtering, and NAT functions. A router can also use routing protocols to find the best path for data packets .
- **Gateway**: A gateway is a device that operates at the application layer of the OSI model. It is a network node that connects discrete networks or systems that use different protocols, enabling data to flow between them. A gateway can also perform protocol conversion, data encryption, and data compression functions. A gateway can be a router, a firewall, a proxy server, or a server.
- **Access point**: An access point is a device that operates at the data link layer of the OSI model. It is a device that sends and receives data wirelessly over radio frequencies, using 2.4 GHz or 5 GHz bands. Clients, such as laptops or mobile phones, connect to an access point using a wireless signal, enabling them to join the wireless LAN created by the access point. An Ethernet cable physically connects the access point to a router or switch in a wired LAN, which provides the access point with access to the internet and the rest of the network.
- **NIC**: A network interface card (NIC) is a device that operates at the physical layer and the data link layer of the OSI model. It is a hardware component that enables a device to connect to a network and communicate with other devices. A NIC has a unique MAC address that identifies the device on the network. A NIC can be wired or wireless, depending on the type of network it connects to .
