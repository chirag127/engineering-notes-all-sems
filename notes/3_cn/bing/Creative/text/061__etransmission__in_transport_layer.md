### etransmission in transport layer

- The transport layer is a conceptual division of methods in the layered architecture of protocols in the network stack in the Internet protocol suite and the OSI model. 
- The transport layer provides end-to-end communication services for applications, such as connection-oriented communication, reliability, flow control, and multiplexing. 
- The transport layer protocols in the Internet protocol suite are the Transmission Control Protocol (TCP), the User Datagram Protocol (UDP), the Datagram Congestion Control Protocol (DCCP), and the Stream Control Transmission Protocol (SCTP). 
- TCP is the most widely used transport protocol, as it provides reliable, ordered, and error-checked delivery of data. TCP uses a connection-oriented approach, which means that it establishes a connection with the destination before sending any data. TCP also uses mechanisms such as sequence numbers, acknowledgements, retransmission, and congestion control to ensure the quality of service.  
- UDP is a simpler transport protocol, as it provides connectionless and unreliable delivery of data. UDP does not guarantee that the data will arrive in order, without errors, or at all. UDP is useful for applications that require speed and efficiency, such as streaming media, online gaming, and voice over IP. UDP also supports multicast and broadcast communication. 
- DCCP is a transport protocol that provides congestion control for unreliable datagrams. DCCP is designed for applications that can tolerate packet loss, but need to avoid congestion collapse, such as multimedia streaming and interactive telephony. DCCP uses a four-way handshake to establish a connection, and a feature negotiation mechanism to allow the application to choose the appropriate congestion control algorithm. 
- SCTP is a transport protocol that provides reliable, ordered, and unordered delivery of data. SCTP supports multiple streams of data within a single connection, which can improve the performance and flexibility of applications. SCTP also supports multihoming, which allows a connection to use multiple network paths for resilience and load balancing. SCTP is suitable for applications that require message-oriented communication, such as telecommunication signaling and web services.
