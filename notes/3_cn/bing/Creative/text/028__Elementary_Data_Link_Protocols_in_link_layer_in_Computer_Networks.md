#### Elementary Data Link Protocols in link layer in Computer Networks

- Protocols in the data link layer are designed to perform the basic functions of framing, error control and flow control.
- Framing is the process of dividing the bit-streams from the physical layer into data frames whose size ranges from a few hundred to a few thousand bytes.
- Error control mechanisms deal with transmission errors and retransmission of corrupted or lost frames.
- Flow control regulates the speed of delivery so that a fast sender does not overwhelm a slow receiver.
- Data link protocols can be broadly divided into two categories, depending on whether the transmission channel is noiseless or noisy.
- Noiseless channel protocols assume that the channel is error-free and do not provide any error control facilities. They only focus on flow control to prevent buffer overflow at the receiver.
- Noisy channel protocols assume that the channel is prone to errors and provide both error control and flow control mechanisms. They use techniques such as acknowledgements, timers, sequence numbers and retransmission to ensure reliable data delivery.
- Some of the elementary data link protocols are:

  - Simplex protocol: A hypothetical protocol for unidirectional data transmission over an ideal channel. The sender simply sends all its data frames as soon as they are available and the receiver processes them instantly. There is no flow control or error control in this protocol.
  - Stop-and-wait protocol: A protocol for unidirectional data transmission over a noiseless channel. It provides flow control by requiring the sender to wait for an acknowledgement from the receiver before sending the next frame. There is no error control in this protocol.
  - Stop-and-wait ARQ: A protocol for unidirectional data transmission over a noisy channel. It provides both flow control and error control by using acknowledgements, timers and retransmission. The sender keeps a copy of the sent frame and waits for a positive acknowledgement from the receiver. If the timer expires or a negative acknowledgement is received, the frame is retransmitted. If a positive acknowledgement is received, the sender sends the next frame.
  - Go-back-N ARQ: A protocol for bidirectional data transmission over a noisy channel. It provides both flow control and error control by using a sliding window technique. The sender can send multiple frames before receiving the acknowledgement for the first frame. The frames are sequentially numbered and a finite number of frames are sent. If the acknowledgement of a frame is not received within the time period, all frames starting from that frame are retransmitted.
  - Selective repeat ARQ: A protocol for bidirectional data transmission over a noisy channel. It provides both flow control and error control by using a sliding window technique. The sender can send multiple frames before receiving the acknowledgement for the first frame. However, here only the erroneous or lost frames are retransmitted, while the good frames are received and buffered. The receiver sends a selective acknowledgement for the correctly received frames.
