### Introductory Concepts of Computer Networks

- A computer network is a group of computers that are connected to each other using cables, wireless signals, or other media, for the purpose of transmitting, exchanging, or sharing data and resources.
- A computer network can be classified based on its size, topology, architecture, and protocols .
- The size of a network refers to the number and distance of the connected devices. Some common network sizes are:
  - Local Area Network (LAN): A network that connects devices within a small area, such as a building or a campus.
  - Metropolitan Area Network (MAN): A network that connects devices within a large area, such as a city or a region.
  - Wide Area Network (WAN): A network that connects devices across a large geographical area, such as a country or the world.
- The topology of a network refers to the physical or logical arrangement of the connected devices. Some common network topologies are:
  - Bus: A network where every device is directly connected to a main cable.
  - Ring: A network where devices are connected in a loop, so each device has exactly two neighbors.
  - Star: A network where devices are connected to a central hub or switch.
  - Mesh: A network where devices are connected to each other in a redundant and flexible way.
- The architecture of a network refers to the design and structure of the network layers and protocols. Some common network architectures are:
  - Peer-to-peer (P2P): A network where devices can communicate directly with each other without a central server or authority.
  - Client-server: A network where devices can request and provide services to each other through a central server or authority.
  - Hybrid: A network that combines elements of both P2P and client-server architectures.
- The protocols of a network refer to the rules and standards that govern how devices communicate and exchange data in the network. Some common network protocols are:
  - Transmission Control Protocol/Internet Protocol (TCP/IP): A suite of protocols that defines how data is transmitted and routed over the Internet and other networks.
  - Hypertext Transfer Protocol (HTTP): A protocol that defines how web browsers and web servers communicate and exchange web pages and other resources.
  - File Transfer Protocol (FTP): A protocol that defines how files are transferred between devices in a network.
  - Simple Mail Transfer Protocol (SMTP): A protocol that defines how email messages are sent and received between devices in a network.
  - Domain Name System (DNS): A protocol that translates human-readable domain names into numerical IP addresses that identify devices in a network.
