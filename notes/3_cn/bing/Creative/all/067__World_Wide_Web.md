### World Wide Web

- The World Wide Web, also known as the Web, is a part of the Internet that allows users to access and share information through hypertext links and graphical user interfaces  .
- The Web is not the same as the Internet, which is the global network of computers that communicate using protocols such as TCP/IP. The Web is one of the services that runs on the Internet, along with others such as email, FTP, and VoIP.
- The Web was invented in 1989 by Tim Berners-Lee, a British computer scientist working at CERN, a European research organization. He developed the first Web browser, server, and protocol (HTTP) to create a system of interconnected documents that could be accessed from any computer .
- The Web uses a standard format called HTML (HyperText Markup Language) to structure and present text, images, sounds, videos, and other multimedia content. Each Web document has a unique address called a URL (Uniform Resource Locator) that identifies its location on the Internet .
- The Web is based on the principle of hypertext, which means that any word or phrase in a document can be linked to another document or resource. Users can navigate the Web by clicking on these links, which are usually highlighted or underlined. The links can also be embedded in images, icons, buttons, or menus .
- The Web is also based on the principle of hypermedia, which means that different types of media can be integrated and linked together. For example, a Web document can contain text, images, sounds, animations, and videos that can be played or interacted with by the user. The Web also supports interactive features such as forms, scripts, applets, and plugins that can enhance the functionality and interactivity of Web documents .
- The Web operates on a client-server model, which means that there are two types of programs involved in the communication process: clients and servers. A client is a program that requests and displays Web documents, such as a Web browser. A server is a program that stores and transmits Web documents, such as a Web server. The client and the server communicate using HTTP, which is the protocol that defines how Web requests and responses are formatted and exchanged .
- The Web is a dynamic and evolving system that is constantly growing and changing. New technologies, standards, and applications are being developed and adopted to improve the performance, security, accessibility, and usability of the Web. Some of the current trends and challenges of the Web include:

  - Semantic Web: a vision of the Web that aims to make the information on the Web more understandable and usable by machines, by adding metadata and ontologies that describe the meaning and context of the data .
  - Web 2.0: a term that refers to the Web as a platform for social interaction, collaboration, and user-generated content, by enabling users to create, share, and modify Web content and services, such as blogs, wikis, social networks, and mashups .
  - Web 3.0: a term that refers to the Web as a platform for intelligent and personalized services, by integrating artificial intelligence, natural language processing, and machine learning techniques to provide users with more relevant and customized information and experiences .
  - Web accessibility: a goal of the Web that aims to make the Web content and services accessible and usable by everyone, regardless of their physical, mental, or situational abilities or limitations, by following the Web Content Accessibility Guidelines (WCAG) and using assistive technologies such as screen readers, magnifiers, and voice recognition .
  - Web security: a challenge of the Web that involves protecting the Web content and services from unauthorized access, modification, or damage, by using encryption, authentication, authorization, and other security mechanisms and best practices .
