#### IP

- IP stands for Internet Protocol, which is a set of rules for routing and addressing packets of data across networks.
- IP is the network layer protocol in the Internet protocol suite, which also includes transport layer protocols such as TCP and UDP.
- IP enables internetworking, which means connecting different networks together and forming the Internet.
- IP has two main functions: encapsulation and routing.
  - Encapsulation means adding an IP header to each packet of data, which contains the source and destination IP addresses and other metadata.
  - Routing means finding the best path for each packet to reach its destination, based on the IP addresses and the network topology.
- IP packets are divided into two components: a header and a payload.
  - The header contains the IP version, the packet length, the protocol type, the time to live, the checksum, and the source and destination IP addresses.
  - The payload contains the data that is being transported, such as an HTTP request or a DNS query.
- IP addresses are unique identifiers for devices or domains that connect to the Internet. They are written as a series of numbers separated by dots, such as 192.168.1.1.
  - There are two versions of IP addresses: IPv4 and IPv6.
    - IPv4 addresses are 32 bits long and can support up to 4.3 billion addresses. However, due to the rapid growth of the Internet, IPv4 addresses are running out.
    - IPv6 addresses are 128 bits long and can support up to 340 undecillion addresses. IPv6 is designed to replace IPv4, but the transition is not yet complete.
- IP is a connectionless and unreliable protocol, which means it does not guarantee that packets will be delivered in order or without errors. It is up to the transport layer protocols to ensure reliability and order.
  - TCP is a connection-oriented and reliable protocol, which means it establishes a connection between the sender and the receiver, and ensures that packets are delivered in order and without errors. TCP is used for applications that require reliability, such as web browsing or email.
  - UDP is a connectionless and unreliable protocol, which means it does not establish a connection or ensure reliability. UDP is used for applications that require speed and efficiency, such as streaming or gaming.

Some mnemonics and learning tricks for IP are:

- IP stands for Internet Protocol, which can be remembered as IP = I Pack(et) data for the Internet.
- IP is the network layer protocol, which can be remembered as IP = I'm a Packet router.
- IP addresses are written as four numbers separated by dots, which can be remembered as IP = I'm a Pointed number.
- IPv4 addresses are 32 bits long, which can be remembered as IPv4 = I'm a 4-bit number.
- IPv6 addresses are 128 bits long, which can be remembered as IPv6 = I'm a 6-bit number.
