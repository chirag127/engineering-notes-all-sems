#### Network components in Computer Networks

A computer network is a system that connects two or more computing devices for transmitting and sharing information. Computing devices include everything from a mobile phone to a server. These devices are connected using physical wires such as fiber optics, but they can also be wireless. The way these links carry the information is defined by communication protocols.

The main components of a computer network are:

- **Network devices or nodes**: These are the computing devices that need to be linked in the network. They can be classified into three types:
  - **Server**: A server is a computer that serves the data to other computers and users. For example, a web server hosts the web pages and responds to the requests from the web browsers. A server can perform multiple functions, such as file sharing, email, database, printing, etc.
  - **Client**: A client is a device that receives requests and responses from the server. For example, a web browser is a client that requests web pages from the web server. A client can also perform some functions on its own, such as word processing, gaming, etc.
  - **Peer**: A peer is a device that can act as both a server and a client. For example, in a peer-to-peer network, each device can share files and resources with other devices without a central server.
- **Transmission media**: These are the medium through which data is transferred from one device to another in a network. They can be classified into two types:
  - **Wired media**: These are the physical cables that connect the devices in a network. They can be made of copper, fiber optics, or coaxial cables. They offer high speed, reliability, and security, but they are also costly, bulky, and difficult to install and maintain.
  - **Wireless media**: These are the electromagnetic waves that carry the data in a network. They can be radio waves, microwaves, infrared, or satellite signals. They offer mobility, flexibility, and scalability, but they also have lower speed, reliability, and security than wired media.
- **NIC (Network Interface Card)**: This is a hardware component that enables a device to connect to a network. It provides a physical interface between the device and the transmission media. It also converts the data from the device into a format that can be transmitted over the network, and vice versa. A NIC can be built-in or external to the device. It can also support wired or wireless media.
- **Switch**: This is a device that connects multiple devices in a network and forwards data packets to the appropriate destination. It operates at the data link layer of the OSI model and uses the MAC address of the devices to identify them. A switch can improve the performance and security of a network by reducing collisions and broadcast traffic.
- **Router**: This is a device that connects multiple networks and forwards data packets between them. It operates at the network layer of the OSI model and uses the IP address of the devices to identify them. A router can perform routing functions, such as finding the best path for the data packets, and filtering functions, such as blocking unwanted traffic.
- **Firewall**: This is a device or software that monitors and controls the incoming and outgoing network traffic based on predefined rules. It operates at the network layer or above of the OSI model and uses the IP address, port number, protocol, or application of the traffic to identify them. A firewall can protect a network from unauthorized access, malicious attacks, or unwanted traffic.
- **Access point**: This is a device that allows wireless devices to connect to a wired network. It operates at the data link layer of the OSI model and uses the SSID (Service Set Identifier) of the wireless network to identify it. An access point can extend the range and coverage of a wireless network by acting as a relay between the wireless devices and the wired network.
- **Software**: These are the programs that enable the communication and functionality of a network. They can be classified into two types:
  - **Operating system**: This is the software that manages the resources and operations of a device. It provides a user interface, a file system, a memory management, a process management, and a network management. For example, Windows, Linux, MacOS, etc.
  - **Protocols**: These are the rules and standards that govern the communication and interaction of the devices in a network. They define the format, syntax, semantics, and synchronization of the data packets. They also provide functions such as error detection, error correction
