### World Wide Web

- The World Wide Web (WWW) or the Web is a part of the Internet that allows users to access and view documents and other resources using a web browser and a graphical user interface (GUI)   .
- The Web was invented by Tim Berners-Lee in 1989 at CERN, the European Organization for Nuclear Research .
- The Web is based on the concept of hypertext, which is a way of linking and presenting information using text and graphics that can be clicked to access other documents or resources  .
- The Web uses a set of protocols and standards to communicate and exchange information, such as:
  - HTTP (Hypertext Transfer Protocol): the protocol that defines how web browsers and web servers communicate and request and deliver web pages .
  - HTML (Hypertext Markup Language): the language that defines the structure and content of web pages using tags and attributes .
  - URL (Uniform Resource Locator): the address that identifies the location and name of a web resource, such as a web page, an image, or a video .
  - CSS (Cascading Style Sheets): the language that defines the style and appearance of web pages, such as fonts, colors, and layouts .
  - JavaScript: the scripting language that adds interactivity and functionality to web pages, such as animations, forms, and validations .
- The Web is composed of billions of web pages that are stored on web servers, which are computers that host and deliver web resources over the Internet .
- The Web is accessed by web browsers, which are software applications that allow users to view and interact with web pages and other web resources .
- The Web is organized by web sites, which are collections of related web pages that share a common domain name, such as www.bing.com .
- The Web is searched by web search engines, which are web sites that allow users to find and retrieve web pages and other web resources based on keywords or queries, such as Bing, Google, or Yahoo .

Some mnemonics and learning tricks for the World Wide Web are:

- WWW stands for World Wide Web, which can be remembered as "W3" or "3W".
- HTTP stands for Hypertext Transfer Protocol, which can be remembered as "Hi, To The Page".
- HTML stands for Hypertext Markup Language, which can be remembered as "How To Make Links".
- URL stands for Uniform Resource Locator, which can be remembered as "U R Lucky".
- CSS stands for Cascading Style Sheets, which can be remembered as "Cool Styling Stuff".
- JavaScript can be remembered as "Java + Script", where Java is a programming language and Script is a written text.
