## Unit 5 - Application Layer in Computer Networks

- The application layer is the topmost layer in the Open Systems Interconnection (OSI) model and the Internet Protocol Suite (TCP/IP) model.
- It provides services and protocols that enable communication and data exchange between applications on different computer systems and networks.
- It is not an application itself, but a component within an application that controls the communication method to other devices.
- It is an abstraction layer that masks the rest of the application from the transmission process and the lower layers of the OSI model.
- It relies on the presentation layer, the session layer, the transport layer, the network layer, the data link layer and the physical layer to complete its process.
- It presents the data or the application in a visual form that the user can understand.

### Functions of the application layer

- The application layer performs the following functions:

  - It identifies the receiving device, checks its availability and readiness to accept data.
  - It enables authentication between devices for an extra layer of network security, when appropriate.
  - It makes sure necessary communication interfaces exist, such as Ethernet or Wi-Fi.
  - It ensures agreement at both ends on error recovery procedures, data integrity and privacy.
  - It determines protocol and data syntax rules at the application level.
  - It provides network-aware applications, such as email, web browsing, file transfer, remote login, etc.
  - It provides application-level services, such as print spooling, directory services, network resources, etc.
  - It handles issues such as network transparency, resource allocation, etc.
  - It serves as a window for users and application processes to access network services.
  - It identifies communication partners and synchronizes communication.

### Benefits of the application layer

- The application layer provides several benefits, such as:

  - It enables interoperability and compatibility between different applications and systems.
  - It simplifies the development and maintenance of applications by abstracting the lower-level details of the network.
  - It enhances the user experience and usability of the network by providing visual and meaningful data.
  - It supports a variety of services and protocols that cater to different user needs and preferences.
  - It facilitates information exchange and collaboration across the network.

### Examples of application layer protocols

- Some of the common application layer protocols are:

  - HTTP (Hypertext Transfer Protocol): It is used for transferring web pages and other resources over the Internet.
  - SMTP (Simple Mail Transfer Protocol): It is used for sending and receiving email messages.
  - FTP (File Transfer Protocol): It is used for transferring files between computers.
  - Telnet (Telecommunication Network): It is used for remote login and command execution.
  - DNS (Domain Name System): It is used for resolving domain names to IP addresses.
  - DHCP (Dynamic Host Configuration Protocol): It is used for assigning IP addresses to devices on a network.
  - SNMP (Simple Network Management Protocol): It is used for monitoring and managing network devices and resources.
