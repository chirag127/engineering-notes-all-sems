#### Medium Access Control and Local Area Networks

- Medium Access Control (MAC) is a sublayer of the data link layer that defines how multiple devices can access a shared medium in a local area network (LAN).
- MAC protocols can be classified into two categories: contention-based and token-passing.
- Contention-based protocols allow devices to compete for the medium access, such as Carrier Sense Multiple Access with Collision Detection (CSMA/CD) used in Ethernet networks. These protocols are simple and efficient, but may suffer from collisions and performance degradation when the network is congested.
- Token-passing protocols use a special frame called a token to grant the medium access to one device at a time, such as Token Ring and Fiber Distributed Data Interface (FDDI). These protocols can guarantee a bounded access delay and avoid collisions, but may introduce overhead and complexity in maintaining the token circulation.
- Wireless LANs (WLANs) are a type of LANs that use radio waves or light as the transmission medium. WLANs have some unique challenges for MAC design, such as hidden terminal problem, exposed terminal problem, and fading.
- IEEE 802.11 is the most widely used standard for WLANs, which defines one MAC and several physical layer (PHY) specifications for wireless connectivity. The 802.11 MAC is based on a distributed coordination function (DCF), which is a contention-based protocol that uses CSMA with Collision Avoidance (CSMA/CA) and a random backoff mechanism. The 802.11 MAC also supports an optional point coordination function (PCF), which is a token-passing protocol that uses a centralized controller called a point coordinator to poll devices for medium access.
- The 802.11 PHY specifications define different modulation schemes, coding rates, channel bandwidths, and operating frequencies for wireless transmission. Some of the most common PHY specifications are 802.11a, 802.11b, 802.11g, 802.11n, 802.11ac, and 802.11ax, which offer different trade-offs between data rate, range, and power consumption.
- The 802.11 standard is constantly evolving to meet the increasing demands for wireless communication, such as higher throughput, lower latency, better reliability, and wider coverage. Some of the recent amendments to the standard are 802.11ay, which enables terahertz communication, 802.11az, which enables precise indoor positioning, and 802.11bb, which enables light communication.
