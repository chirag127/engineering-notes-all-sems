### Basic concepts of Cryptography in application layer

- Cryptography is the process of hiding or coding information so that only the intended recipient can read it. It is used to protect data privacy, integrity, authenticity, and non-repudiation in various applications, such as messaging, web browsing, email, and ecommerce.
- Cryptography uses algorithms and mathematical concepts to transform messages into difficult-to-decipher codes through techniques like cryptographic keys and digital signatures.
- Cryptography can be classified into two main types: symmetric key cryptography and asymmetric key cryptography.
  - Symmetric key cryptography uses the same key to encrypt and decrypt a message. The key must be shared securely between the sender and the receiver. Symmetric key algorithms are fast and efficient, but they have the problem of key distribution and management. Examples of symmetric key algorithms are AES, DES, and RC4.
  - Asymmetric key cryptography uses a pair of keys: a private key and a public key. The private key is kept secret by the owner, while the public key is distributed to anyone who wants to communicate with the owner. The public key can be used to encrypt a message, which can only be decrypted by the private key. The private key can also be used to sign a message, which can be verified by the public key. Asymmetric key algorithms are more secure and solve the key distribution problem, but they are slower and more computationally intensive than symmetric key algorithms. Examples of asymmetric key algorithms are RSA, DSA, and ECC.
- Cryptography can be applied in various ways in the application layer, such as:
  - Secure Sockets Layer (SSL) and Transport Layer Security (TLS) are protocols that provide secure communication between a client and a server over the internet. They use a combination of symmetric and asymmetric key cryptography to establish a secure session, encrypt and decrypt data, and authenticate the identities of the parties involved. SSL and TLS are widely used in web browsers, email clients, and other applications that require secure data transmission.
  - Pretty Good Privacy (PGP) and GNU Privacy Guard (GPG) are software tools that enable users to encrypt and decrypt files, emails, and messages using symmetric and asymmetric key cryptography. They also allow users to create and manage their own public and private keys, and to sign and verify the authenticity of messages using digital signatures.
  - Secure Shell (SSH) is a protocol that allows users to remotely access and control another computer over a network. It uses asymmetric key cryptography to authenticate the user and the host, and symmetric key cryptography to encrypt and decrypt the data exchanged. SSH can also be used to create secure tunnels between two computers, which can be used to forward other protocols or applications.
  - Bitcoin is a decentralized digital currency that uses cryptography to create and verify transactions, and to prevent double-spending and counterfeiting. Bitcoin uses a public ledger called the blockchain, which records all the transactions that have ever occurred. Each transaction is signed by the sender's private key, and verified by the receiver's public key. Bitcoin also uses a proof-of-work system, which requires the participants to solve a hard mathematical problem to create new blocks and earn rewards.
