#### Network devices in Computer Networks

Network devices are physical devices that enable communication and interaction between hardware on a computer network. Each networking device operates in a distinct computer network segment and performs distinct functions. A network may require hundreds or thousands of different network devices to maintain and build out various LAN and WAN.

Some of the common types of network devices are:

- **Repeater**: A repeater is a device that operates at the physical layer of the OSI model. Its job is to regenerate the signal over the same network before it becomes weak or corrupted due to attenuation. A repeater can extend the transmission distance of a network segment, but it cannot filter or segment the traffic.

- **Hub**: A hub is a device that operates at the physical layer of the OSI model. It is a multiport repeater that connects multiple wires coming from different branches. A hub broadcasts the data received from one port to all other ports. A hub can increase the number of devices on a network, but it cannot reduce the network congestion or collision.

- **Bridge**: A bridge is a device that operates at the data link layer of the OSI model. It is used to connect two or more network segments that use the same or different physical media. A bridge can filter the traffic based on the MAC addresses of the devices. A bridge can reduce the network congestion and collision by dividing the network into smaller segments.

- **Switch**: A switch is a device that operates at the data link layer or the network layer of the OSI model. It is a multiport bridge that can store and forward the data frames based on the MAC addresses or the IP addresses of the devices. A switch can create multiple collision domains and broadcast domains within a network. A switch can improve the network performance and security by reducing the network congestion and collision .

- **Router**: A router is a device that operates at the network layer of the OSI model. It is used to connect two or more networks that use the same or different network protocols. A router can route the data packets based on the IP addresses of the devices. A router can create multiple broadcast domains within a network. A router can enable the communication between different networks and support various network services such as NAT, DHCP, VPN, etc .

- **Gateway**: A gateway is a device that operates at the application layer of the OSI model. It is used to connect two or more networks that use different network architectures or protocols. A gateway can translate the data formats and protocols between different networks. A gateway can enable the communication between heterogeneous networks and support various network applications such as email, web, FTP, etc.

- **Brouter**: A brouter is a device that combines the functions of a bridge and a router. It can operate at both the data link layer and the network layer of the OSI model. It can filter and route the data packets based on the MAC addresses or the IP addresses of the devices. A brouter can provide the benefits of both a bridge and a router, such as reducing the network congestion and collision, creating multiple broadcast domains, and enabling the communication between different networks.

- **NIC**: A NIC (Network Interface Card) is a device that operates at the physical layer and the data link layer of the OSI model. It is a hardware component that connects a computer or a device to a network. A NIC can encode and decode the data signals and provide the MAC address for the device. A NIC can support various network standards and speeds, such as Ethernet, Wi-Fi, Bluetooth, etc.
