#### Various Size Oriented Measures in Software Design

In software engineering, there are several measures that are used to evaluate the size of a software system. These measures help in estimating the cost of software development, testing, and maintenance. The following are some of the various size-oriented measures used in software design:

1. **Lines of Code (LOC):** This is one of the most commonly used measures of software size. LOC is the count of the number of lines of code in a software system. It is a simple measure that is easy to calculate. However, it has several limitations, such as not accounting for differences in programming languages and coding styles.

2. **Function Points (FP):** FP is a measure of the functionality provided by a software system. It takes into account the number of inputs, outputs, and user interactions in a software system to calculate its size. FP is a more accurate measure of software size than LOC as it accounts for the complexity of the software system.

3. **Object Points (OP):** OP is a measure of the number of objects in a software system. It takes into account the number of classes, methods, and attributes in a software system to calculate its size. OP is a more accurate measure of software size than LOC as it accounts for the complexity of the software system.

4. **Source Lines of Code (SLOC):** SLOC is a measure of the number of lines of code in a software system that is executable. It does not include comments or blank lines. SLOC is a more accurate measure of software size than LOC as it accounts for the quality of the code.

5. **Delivered Source Instructions (DSI):** DSI is a measure of the number of executable instructions in a software system. It takes into account the number of statements, loops, and conditionals in a software system to calculate its size. DSI is a more accurate measure of software size than LOC as it accounts for the quality of the code.

6. **Kilo Lines of Code (KLOC):** KLOC is a measure of the number of thousands of lines of code in a software system. It is a simple measure that is easy to calculate. However, it has several limitations, such as not accounting for differences in programming languages and coding styles.

Mnemonics and learning tricks to remember the various size-oriented measures in software design are not necessary as they are straightforward and easy to remember. It is important to note that these measures should not be used in isolation, and it is recommended to use a combination of measures to get a more accurate estimate of software size.
