##### Function Point (FP) Based Measures in software design

Function Point (FP) is a metric used to measure the size and complexity of software systems. It is a unitless measure that takes into account the functionality provided by a software system. FP measures are widely used in software engineering to estimate the cost, schedule, and effort required to develop and maintain software systems.

Here are some important points about Function Point (FP) Based Measures in software design:

- FP measures are based on the idea that software systems can be decomposed into a set of user functions. These functions include data input, data output, data inquiry, and file maintenance. Each of these functions is assigned a weight based on the complexity of the function.

- The complexity of a function is determined by the number of inputs, the number of outputs, the number of files accessed, and the complexity of the processing required.

- The total number of function points for a software system is calculated by summing the weighted functions.

- FP measures are used to estimate the size of software systems, which is an important factor in determining the cost, schedule, and effort required to develop and maintain software systems.

- FP measures can also be used to compare the size and complexity of different software systems.

- The use of FP measures in software engineering has some advantages and disadvantages. The advantages include the ability to estimate the size and complexity of software systems, the ability to compare the size and complexity of different software systems, and the ability to estimate the cost, schedule, and effort required to develop and maintain software systems. The disadvantages include the complexity of the calculation process and the subjectivity involved in assigning weights to functions.

- There are some Mnemonics and learning tricks that can be used to remember the different function types and their weights. For example, the acronym CRUD (Create, Read, Update, Delete) can be used to remember the four types of data function, and the acronym ILF (Internal Logical File) can be used to remember the three types of file function.

- FP measures are widely used in software engineering, and there are several tools and techniques available for calculating FP measures. Examples of these tools and techniques include the Use Case Points (UCP) method, the Mark II FPA method, and the COSMIC-FFP method.
