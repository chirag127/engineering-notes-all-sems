#### Function Oriented Design in Software Design

Function Oriented Design is a software design approach that focuses on designing the functions or operations that a software system should perform. It is a top-down approach that starts with the identification of the system functions and then divides them into sub-functions until the lowest level of detail is reached.

##### Advantages of Function Oriented Design

- It is a simple and easy-to-understand approach that is suitable for small to medium-sized software systems.
- It helps in identifying the functions of the system and their interdependencies, which helps in better understanding the system requirements.
- It facilitates modular design by breaking down the system into smaller functional units, which can be developed and tested independently.
- It enables easy maintenance and modification of the system by making it easy to identify the functions that need to be changed.
- It helps in reducing the complexity of the system by breaking it down into smaller manageable parts.

##### Disadvantages of Function Oriented Design

- It may not be suitable for large and complex software systems as it may result in too many functions and sub-functions, making it difficult to manage.
- It may lead to a lack of focus on data and data relationships, which are equally important in software design.
- It may result in a rigid design that may not be able to accommodate future changes and requirements.

##### Mnemonics and Learning Tricks

- One possible mnemonic for Function Oriented Design is "FOD", which can be remembered as "Functions Over Details". This emphasizes the importance of focusing on the functions of the system rather than getting bogged down in the details.
- Another possible learning trick is to visualize the system as a series of interconnected functions, with each function performing a specific task. This can help in understanding the system requirements and designing the functions accordingly.

##### Example

Consider the design of a simple calculator application. The functions of the system can be identified as:

- Addition
- Subtraction
- Multiplication
- Division

Each of these functions can be further broken down into sub-functions, such as input validation, error handling, and result display. The functions can be designed and developed independently, and then integrated to form the final system.

##### Applications

Function Oriented Design is commonly used in the design of small to medium-sized software systems, such as calculators, inventory management systems, and payroll systems. It is also used in the design of certain types of software systems, such as embedded systems and real-time systems, where the focus is on the system functions rather than the user interface.
