### Schedule/Duration of Maintenance in software project management

-   **Corrective maintenance:** Fixing defects/bugs. Generally scheduled as soon as bugs are found. Duration depends on severity of bugs.
-   **Adaptive maintenance:** Modifying software to accommodate changes to operating system, environment, or other software/hardware. Scheduled periodically or when changes occur. Duration depends on scale of changes required.
-   **Perfective maintenance:** Refining/improving software after initial release to improve functionality/usability. Scheduled periodically or based on user feedback. Duration depends on scale of improvements planned.
-   **Preventive maintenance:** Modifying software to prevent potential bugs or defects. Scheduled periodically based on risk analysis and software metrics. Duration depends on scale of preventive changes required.

**Mnemonics:**

-   CRAP - Corrective, Refinement, Adaptive, Perfective (maintenance types)
-   SCRUM - Schedule maintenance regularly and based on urgency (when/how scheduled)

**Advantages:** Keeps software functional/usable, satisfies user needs, improves quality/reliability.
**Disadvantages:** Increases cost/effort, can introduce new bugs, difficult to estimate proper schedule/duration.
