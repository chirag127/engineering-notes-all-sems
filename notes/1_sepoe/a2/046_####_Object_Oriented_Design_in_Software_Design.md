#### Object Oriented Design in Software Design

- Object Oriented Design (OOD) is a software design approach focused on modeling applications using objects and their interactions.
- Key principles of OOD:
  - Encapsulation: Hiding the internal details of an object and only exposing its interfaces to the outside.
  - Inheritance: Inheriting properties from a parent/base class. Allows reusability of code and modeling is-a relationships.
  - Polymorphism: Having multiple classes that can respond to the same interface, allowing similar objects to be handled similarly.
  - Abstraction: Simplifying complex problems by ignoring unnecessary details and focusing on the essential aspects.
- Benefits of OOD:
  - Modular design: Breaking the system into components (objects) that can be re-used and independently replaced or modified.
  - Flexibility: New features can be added by extending and modifying existing components.
  - Maintainability: Changes to one component does not affect others as long as the interfaces remain the same.
  - Parallel development: Different components can be worked on simultaneously.
- Some drawbacks of OOD:
  - Added complexity from many classes and interfaces.
  - Extra time required for careful design and planning.
  - Risk of over-engineering or over-abstracting a system.
- Examples of OOD: GUI programming (buttons, menus), simulations (animals, vehicles), business software (employees, invoices).
- Tips for OOD:
  - Identify objects and responsibilities first before diving into implementation.
  - Keep objects and logic loosely coupled.
  - Apply the Single Responsibility Principle (SRP) - each class has one job.
  - Use inheritance wisely and avoid deep class hierarchies.
  - Keep interfaces simple and focus on high-level abstraction.
