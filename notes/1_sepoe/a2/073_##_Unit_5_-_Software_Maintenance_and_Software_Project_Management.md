## Unit 5 - Software Maintenance and Software Project Management

Software Maintenance:
- Once the software is delivered, it undergoes changes and modifications to fix bugs or provide new functionality. This phase is known as software maintenance.
- Types: Corrective (fix bugs), Adaptive (port to new environment), Perfective (improve performance), Preventive (fix potential bugs)
- Challenges: Understanding existing code, testing changes, dealing with tight deadlines
- Tools: Version control, debugging and monitoring tools, documentation

Software Project Management:
- The process of planning, organizing, securing and managing resources to deliver a software project.
- Project Life Cycle: Initiation, Planning, Execution, Monitoring, Closure
- Project Management Activities: Plan schedule and budget, Assign tasks, Monitor progress, Report status, Manage risks, Control changes
- Methodologies: Waterfall, Agile, Spiral
- Tools: Gantt charts, PERT charts, Issue tracking systems, Version control

Advantages of using project management:
- Increased visibility into project status
- Tighter control over schedule and budget
- Issues are identified early on avoiding costly rework
- Higher quality through systematic planning and review
- Customer satisfaction due to on-time delivery and meeting requirements

Some useful mnemonics and tips:
- Corrective maintenance - think of 'correcting mistakes'
- 'CATS' for types of maintenance - Corrective, Adaptive, Perfective, Preventive
- 'PIPE' for project life cycle - Planning, Initiation, Execution, Closure
- 'RAMP' for risk management - Risk identification, Assessment, Mitigation, Prioritization
- Use Gantt charts for scheduling, PERT charts show probability of task completion
- Keep version control for orderly changes and easy rollback if required
