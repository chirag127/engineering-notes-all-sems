### Software Characteristics

The key characteristics of software are:

1. **Complex:** Software systems are complex in nature. Even a small software can have millions of states and paths. This makes software debugging and testing challenging.
2. **Intangible:** Software is intangible i.e. it cannot be touched or seen physically. It exists as lines of code. This makes software difficult to visualize and can lead to miscommunications.
3. ** brittle:** Software is brittle in the sense that even a small change can have large unintended consequences. For example, changing a single line of code can break the entire software system. This makes software difficult to maintain and requires high precision.
4. **Conformable:** Software is conformable i.e. it can be changed easily. While this makes software adaptive to changes, it can also lead to unintended side-effects due to frequent changes. Proper software architecture and testing is required to handle conformability.
5. **Cost of change:** The cost of change tends to increase over time in software. This is also known as software entropy. As more features are added and code gets complex, any changes made to the software in the future become increasingly expensive to implement. This emphasizes the importance of good initial design and maintainable code.

Some mnemonics to remember software characteristics:

- COMIC: Complex, Intangible, Brittle, Conformable
- COST: Cost of change increases over time
