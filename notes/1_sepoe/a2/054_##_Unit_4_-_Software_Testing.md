## Unit 4 - Software Testing

Software Testing is a process of evaluating the functionality of a software application with the intent of finding software bugs (errors or other defects). It involves operating the system or application under controlled conditions and evaluating the results (output) against the expected results. The main aim of software testing is to detect errors in the software and fix them before releasing the software product in the market or to clients.

Some key points about Software Testing:

- Software Testing is a process, not a single activity. It involves multiple steps to rigorously check the software.
- Software Testing must be done at every stage of the Software Development Lifecycle (SDLC) - from requirements analysis to maintenance.
- The different types of Software Testing include:
    - Unit Testing - Testing individual software components (units)
    - Integration Testing - Testing combined software modules/units
    - System Testing - Testing the whole system as a whole
    - Acceptance Testing - Testing the system with the customer requirements
    - Performance Testing - Testing the performance of the software under various load conditions
    - Security Testing - Testing the software for vulnerabilities and threats
    - Usability Testing - Testing the ease of use of the software
    - Compatibility Testing - Testing the software with various hardware, OS, browsers, etc.
- The goals of Software Testing are:
    - Finding bugs and defects
    - Ensuring that the software meets the specified requirements
    - Improving the quality of the software
    - Increasing user satisfaction by delivering a quality software product
- Some effective Software Testing techniques include:
    - Equivalence Partitioning - Dividing the input data into partitions
    - Boundary Value Analysis - Evaluating boundary values of partitions
    - Decision Table Testing - Evaluating system functionality based on combinations of conditions and actions
    - State Transition Testing - Testing state changes in the software based on events
    - Error Guessing - Trying to guess where and what type of errors might occur in the software
    - Using Fault Injection Techniques to simulate software faults to observe system behavior
- Software Testing also involves documenting bugs/defects and following them up to resolution. Effective bug reporting is important for the testing and development teams to understand and fix the bugs.
