### Software Quality Attributes

The Software Quality Attributes are the desirable characteristics of a software system. They are also known as Quality Factors or Quality Properties. There are commonly considered to be 6 core software quality attributes:

1. Functional Correctness - The software should function as per the specified requirements and expectations. It should produce correct outputs for given inputs. Mnemonic: **Does it do what it's supposed to do?**
2. Reliability - The software should be failure resistant and fault tolerant. It should perform consistently and accurately over a period of time. Mnemonic: **Does it consistently work?**
3. Usability - The software should be easy to learn, understand, operate and attractive to the user. It should have a user-friendly interface. Mnemonic: **Is it easy and pleasant to use?**
4. Efficiency - The software should not consume more resources like time, memory, etc. than necessary. It should have good performance like fast response times. Mnemonic: **Does it use resources efficiently?**
5. Maintainability - The software should be easy to modify, update, repair or expand. It should have simple and well-structured code and documentation. Mnemonic: **Is it easy to change or enhance?**
6. Portability - The software should be able to run on multiple systems/environments without changes to the code. It should not be dependent on a specific hardware or software platform. Mnemonic: **Can it be transferred to other environments?**

The quality attributes are often prioritized based on the type of software and user requirements. They can conflict with each other and balancing them is an important aspect of software engineering.
