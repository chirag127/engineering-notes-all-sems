

### Cohesion Measures in Software Design

Cohesion measures in software design are measures used to assess the degree of coupling between software components. Cohesion measures are used to evaluate the design of a software system and to decide whether certain components should be combined or separated.

#### Mnemonics and Learning Tricks

To help remember the different types of cohesion measures, try the following mnemonic:

* **C**oupling: How closely related are the components?
* **I**nterfaces: Are the interfaces between components well-defined?
* **R**esponsibilities: Are the responsibilities of each component clearly defined?
* **E**xtensibility: Is the system extensible?
* **A**bstraction: Is the system abstracted correctly?

#### Types of Cohesion Measures

1. **Functional Cohesion**: This measure is used to assess how closely related the components are to each other. It is determined by looking at the functions that each component performs and how closely related they are.

2. **Logical Cohesion**: This measure is used to assess the degree to which the components are logically related. It is determined by looking at the data structures and algorithms used in the system.

3. **Temporal Cohesion**: This measure is used to assess how closely related the components are in terms of when they are executed. It is determined by looking at the order in which the components are executed.

4. **Communicational Cohesion**: This measure is used to assess how closely related the components are in terms of the data they exchange. It is determined by looking at the data structures used to exchange information between components.

5. **Sequential Cohesion**: This measure is used to assess how closely related the components are in terms of their execution order. It is determined by looking at the order in which the components are executed.

#### Advantages of Cohesion Measures

* Cohesion measures help to identify areas of a software system that need improvement.
* Cohesion measures can be used to assess the complexity of a software system.
* Cohesion measures can be used to identify potential problems in a software system.
* Cohesion measures can be used to create a more maintainable software system.

#### Disadvantages of Cohesion Measures

* Cohesion measures can be difficult to apply in practice.
* Cohesion measures can be subjective and open to interpretation.
* Cohesion measures can be difficult to measure accurately.
* Cohesion measures can be time-consuming to implement.
