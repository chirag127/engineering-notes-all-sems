
### Static Testing Strategies in Software Testing

Static Testing is a type of software testing that is performed without executing the code. It is a process of verifying and validating the software application without actually running the program.

The main objective of static testing is to find errors in the software application before it is executed. This helps in avoiding costly and time consuming debugging processes.

Static testing strategies include:

* Code Reviews: Code reviews involve inspecting the code manually to identify errors and potential problems.
* Code Walkthroughs: Code walkthroughs involve a group of people discussing the code line by line to identify any errors or potential problems.
* Automated Static Analysis: Automated static analysis is a process of using automated tools to analyze the source code and identify any errors or potential problems.
* Structured Walkthroughs: Structured walkthroughs involve a group of people discussing the code line by line to identify any errors or potential problems, but with a structured approach.
* Design and Code Inspections: Design and code inspections involve a group of people inspecting the design and code of the software application to identify any errors or potential problems.

Mnemonics and Learning Tricks:

* S.T.A.T.I.C. - Stands for: Code Reviews, Code Walkthroughs, Automated Static Analysis, Structured Walkthroughs and Design and Code Inspections. 
* C.A.R.E. - Stands for: Check, Analyze, Review and Evaluate.
