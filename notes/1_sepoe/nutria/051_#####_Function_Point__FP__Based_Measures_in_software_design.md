
##### Function Point (FP) Based Measures in software design

Function Point (FP) based measures are a method of measuring the complexity of software systems. It is a quantitative measure of the amount of functionality provided by a software system, and is used to estimate the effort required to develop a system.

The FP measure is based on a set of five components:

1. **Data Functions**: These are functions that process and manipulate data within the system. Examples include data entry, data retrieval, data updating, data deletion and data sorting.

2. **External Interface Functions**: These are functions that interact with the system from outside. Examples include user interfaces, system interfaces and other communications.

3. **Logic Functions**: These are functions that control the flow of logic within the system. Examples include decision points, calculations and processing of data.

4. **Application Functions**: These are functions that provide the application-specific functionality. Examples include calculation of interest, data validation and generation of reports.

5. **System Functions**: These are functions that manage the overall system. Examples include error handling, system security and system maintenance.

Function Points are calculated by counting the number of each type of function and assigning a weight to each type. The weights are determined by the complexity of the function, and the total number of Function Points is calculated by multiplying the number of functions by the weight of each function.

Function Points are used to estimate the effort required to develop a system. The effort is calculated by multiplying the number of Function Points by a factor called the Function Point Index (FPI). The FPI is determined by the type of system being developed, the complexity of the system, and the experience of the development team.

Function Point based measures are widely used in the software development industry, and provide an accurate and reliable measure of the complexity of a system.
