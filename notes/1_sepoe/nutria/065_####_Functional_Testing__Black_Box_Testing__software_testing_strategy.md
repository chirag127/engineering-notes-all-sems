
### Functional Testing (Black Box Testing) software testing strategy
Functional testing is a software testing strategy that focuses on verifying the functionality of an application or system. This type of testing is also referred to as black box testing, since the tester does not have access to the internal workings of the application or system. 

Functional testing is typically done after the application or system has been integrated and is ready for testing. The goal of functional testing is to ensure that the application or system meets the requirements and performs the desired functions correctly.

The following are some of the key concepts related to functional testing:

- **Inputs:** Functional testing involves validating the behavior of an application or system when given certain inputs. The inputs used in functional testing should be valid, invalid, boundary, extreme, and unexpected.

- **Expected Outputs:** The expected outputs of an application or system should be known prior to functional testing. This allows the tester to compare the actual outputs to the expected outputs and determine if the application or system is working correctly.

- **Mnemonics:** Mnemonics can be helpful for remembering the key concepts related to functional testing. For example, the acronym “VIBE” can be used to remember the types of inputs used in functional testing: valid, invalid, boundary, extreme, and unexpected.

- **Test Cases:** Functional testing requires the development of test cases that will be used to validate the behavior of the application or system. Test cases should be developed to cover all possible scenarios in order to ensure that the application or system is functioning correctly.

- **Test Data:** Test data is used to validate the behavior of the application or system. Test data should be valid, invalid, boundary, extreme, and unexpected in order to cover all possible scenarios.

- **Tools:** There are many tools available to assist with functional testing. These tools can help automate the testing process and reduce the amount of time and effort required.

- **Advantages:** Functional testing can help identify any issues with the application or system before it is released. This can help reduce the cost of fixing any issues after the application or system is released.

- **Disadvantages:** Functional testing can be time consuming and expensive. Additionally, it can be difficult to test for all possible scenarios and the results of functional testing may not be reliable.
