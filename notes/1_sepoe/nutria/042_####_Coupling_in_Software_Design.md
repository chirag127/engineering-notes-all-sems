
#### Coupling in Software Design

Coupling in software design is the degree of interdependence between software components. It is an important concept in software engineering and is used to measure the strength of relationships between components of a system. Coupling is used to determine the flexibility, maintainability, and scalability of a software system.

* Tight coupling: Tight coupling occurs when two components are highly dependent on each other. This type of coupling makes the system difficult to maintain as changes in one component can affect the other.

* Loose coupling: Loose coupling occurs when components are only loosely connected, meaning that changes to one component will not necessarily affect the other. This type of coupling makes the system more flexible and maintainable.

* Message coupling: Message coupling occurs when components communicate via messages. This type of coupling allows components to be developed independently, making the system more flexible and maintainable.

* Content coupling: Content coupling occurs when components share data. This type of coupling makes the system more rigid as changes to one component can affect the other.

* Common coupling: Common coupling occurs when two components share the same data. This type of coupling makes the system more rigid as changes to one component can affect the other.

* Control coupling: Control coupling occurs when one component controls the flow of the other. This type of coupling makes the system rigid as changes to one component can affect the other.

Mnemonic: 
TLCMCC: Tight, Loose, Message, Content, Common, Control
