

#### Pseudo Codes in Software Design

* Pseudo codes are a way of representing an algorithm without using a specific programming language. 
* They are used for writing algorithms and for documenting the design process. 
* Pseudo codes are written in natural language and use the conventions of a programming language.
* Pseudo codes are written in a structured way and use logical statements such as if-then-else and loops.
* Pseudo codes are used to describe the logic of a program without having to write actual code.
* They are helpful for understanding the logic of a program and for debugging.
* Pseudo codes can also be used to explain a program to other people.
* Mnemonics can be used to help remember the syntax of pseudo codes. For example, "IF" is often remembered as "If I Follow" and "WHILE" is remembered as "While He Loops".
* Learning tricks such as diagrams and flowcharts can also be used to help understand the structure of a pseudo code.
* Pseudo codes are a useful tool for software design and can help make the design process easier.
