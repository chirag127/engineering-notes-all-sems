

#### Formal Technical Reviews (Peer Reviews) Static Testing Strategy

* Formal technical reviews (FTR) are a type of static testing strategy used to review software code and other technical documents.
* This type of review is conducted by a team of experts who review the code and documents for accuracy, completeness, and correctness.
* The goal of the FTR is to identify any errors or potential improvements that can be made to the code or documents.
* The review process is divided into two phases: the inspection phase and the review phase.
* During the inspection phase, the code and documents are examined for errors and potential improvements.
* During the review phase, the team of experts reviews the code and documents and makes recommendations for improvements or changes.
* The review process is usually conducted using a checklist that outlines the criteria for the review.
* The checklist typically includes items such as:
  * Code structure
  * Naming conventions
  * Documentation
  * Error-handling
  * Performance
  * Security
  * Accessibility
  * User experience
* After the review is complete, the team of experts can provide feedback and recommendations for improvement.
* FTR is a useful tool for ensuring the quality and accuracy of code and documents. It can help identify potential issues before they become problems and can help ensure the code and documents are up to industry standards.
