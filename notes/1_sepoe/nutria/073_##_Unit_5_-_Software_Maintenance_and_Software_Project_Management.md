
## Unit 5 - Software Maintenance and Software Project Management

Software maintenance is the process of modifying and correcting errors in existing software applications. It also involves making changes and additions to existing software applications in order to keep them up to date with changing user requirements and technology. Software project management is the application of knowledge, skills, tools and techniques to project activities in order to meet the project requirements.

Some of the key topics covered in this unit include:

* Change Management: This involves the process of managing changes to existing software applications. It includes planning for changes, implementing changes, and monitoring the effects of the changes.

* Software Configuration Management: This involves the process of controlling and tracking changes to software applications. It includes version control, release management, and maintaining an audit trail.

* Quality Assurance: This involves the process of ensuring that software applications meet the requirements of the users. It includes testing, defect tracking, and quality control.

* Documentation: This involves the process of creating and maintaining user manuals, technical manuals, and other documents related to software applications.

Mnemonics and learning tricks for this unit include:

* CHANGE: Change Management, Hardware, Applications, Network, Environment
* SCM: Software Configuration Management
* QA: Quality Assurance
* DOC: Documentation
