
### Water Fall Model in SDLC

The Waterfall Model is a linear software development process, used in software engineering to structure and plan the development of a software product. It is also known as the classic life cycle model. The Waterfall Model is a sequential design process, where progress is seen as flowing steadily downwards (like a waterfall) through the phases of Conception, Initiation, Analysis, Design, Construction, Testing, Production/Implementation, and Maintenance. 

- **Conception**: During this phase, the idea for the project is discussed and the project is initiated.
- **Initiation**: After the project is approved, the project plan is created.
- **Analysis**: During this phase, the requirements for the project are gathered and analyzed.
- **Design**: During this phase, the design of the system is created.
- **Construction**: During this phase, the actual coding of the system takes place.
- **Testing**: During this phase, the system is tested to ensure that it meets the requirements.
- **Production/Implementation**: During this phase, the system is deployed and put into use.
- **Maintenance**: During this phase, any changes or updates to the system are made.
