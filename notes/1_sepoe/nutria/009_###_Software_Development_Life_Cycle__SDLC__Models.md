
### Software Development Life Cycle (SDLC) Models

* SDLC is a process that consists of a series of steps or phases used to create software products. 
* It is also known as the software development process.
* The different models of SDLC are:
  * Waterfall Model
  * V-Shaped Model
  * Iterative Model
  * Spiral Model
  * Agile Model
  * DevOps Model
  
#### Waterfall Model
The Waterfall Model is a linear sequential flow process, where progress is seen as flowing steadily downwards (like a waterfall) through the phases of Conception, Initiation, Analysis, Design, Construction, Testing, Production/Implementation, and Maintenance.

#### V-Shaped Model
The V-Shaped Model is an extension of the Waterfall Model and is based on the association of the two models. It is also known as Verification and Validation model. The V-Shaped Model follows the same sequence as the Waterfall Model but with more emphasis on testing.

#### Iterative Model
The Iterative Model is a process of developing software through repeated cycles. It is also known as the incremental model. In this model, the whole requirement is divided into various builds. Each build is tested and improved upon until the entire requirement is fulfilled.

#### Spiral Model
The Spiral Model is an evolutionary software process model that combines elements of both design and prototyping-in-stages, in an effort to combine advantages of top-down and bottom-up concepts. In this model, development of software is done in increments.

#### Agile Model
The Agile Model is a process of developing software through iterative and incremental processes. It is also known as the adaptive software development model. In this model, the development process is divided into various phases, such as planning, designing, coding, testing, and deployment.

#### DevOps Model
The DevOps Model is an approach to software development that combines the development and operations teams in order to create a unified process for developing, testing, and deploying software. This model is based on the idea of continuous delivery and continuous integration.
