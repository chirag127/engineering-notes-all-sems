
### Software Re- Engineering (SR) of Software

Software re-engineering refers to the process of restructuring existing software systems to improve their performance, maintainability, and/or portability. This process involves analyzing the existing system and then making changes to its structure and/or components to meet the desired objectives.

#### Mnemonics and Learning Tricks

1. **S**oftware **R**e-**E**ngineering: **S**tructural **R**e-**E**valuation and **E**nhancement
2. **R**e-**E**ngineering: **R**e-**E**structuring **E**xisting **E**lements

#### Advantages

1. Improved performance: Re-engineering can help improve the performance of the software system by making it more efficient and reliable.
2. Reduced cost: Re-engineering can help reduce the cost of software development by eliminating redundant code and making the code more maintainable.
3. Improved maintainability: Re-engineering can help improve the maintainability of the software system by making it easier to debug and maintain.

#### Disadvantages

1. Complexity: Re-engineering can be a complex and time-consuming process.
2. Risk of errors: Re-engineering can introduce errors into the system if not done correctly.
3. Loss of functionality: Re-engineering can lead to the loss of functionality if the existing system is not thoroughly analyzed before making changes.

#### Examples

1. An existing software system can be re-engineered to improve its performance by restructuring its code to reduce the number of redundant lines of code.
2. An existing software system can be re-engineered to improve its maintainability by restructuring its code to make it easier to debug and maintain.
3. An existing software system can be re-engineered to improve its portability by restructuring its code to make it easier to port to different platforms.

#### Applications

1. Re-engineering can be used to improve the performance and maintainability of existing software systems.
2. Re-engineering can also be used to improve the portability of existing software systems.
3. Re-engineering can be used to reduce the cost of software development by eliminating redundant code and making the code more maintainable.
