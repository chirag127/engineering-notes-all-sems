

#### Various Size Oriented Measures in Software Design

* Lines of Code (LOC): This is a measure of the total number of lines of code in a program. It is often used to measure the size of a software project.

* Cyclomatic Complexity (CC): This is a measure of the complexity of a program. It is calculated by counting the number of decision points (e.g. if-else statements) in the program.

* Function Points (FP): This is a measure of the size of a software project based on the number of functions it contains. It is used to estimate the cost and effort required to develop a software project.

* Halstead Complexity Metrics (HCM): This is a measure of the complexity of a program. It is calculated by counting the number of distinct operators and operands used in a program.

* Number of Entities (NOE): This is a measure of the size of a software system. It is calculated by counting the number of software entities (e.g. classes, methods, functions, etc.) in the system.

* Mnemonic: A mnemonic is a memory aid used to help remember complex concepts. It is often used to help remember various size oriented measures in software design. For example, the mnemonic "LOC, CC, FP, HCM, NOE" can be used to remember the five size oriented measures discussed above.
