#### Function Oriented Design in Software Design

Function Oriented Design (FOD) is a software design methodology that focuses on decomposing a system into a set of functions or procedures. In this approach, the system is viewed as a collection of functions that work together to accomplish a specific task. 

Some of the key characteristics of Function Oriented Design are:

- It emphasizes on the functional aspects of the system rather than the data or objects.
- It is a top-down approach, where the system is decomposed into functions that are further divided into sub-functions.
- It is a modular approach, where each function performs a specific task and can be reused in other parts of the system.
- It is a structured approach, where each function has a well-defined input, output, and processing logic.

Advantages of Function Oriented Design:
- It is easy to understand and implement.
- It facilitates modular programming and code reusability.
- It allows for easy maintenance and modification of the system.
- It is suitable for systems that have a large number of functions that need to be performed.

Disadvantages of Function Oriented Design:
- It can lead to a complex and convoluted system if not implemented properly.
- It can be difficult to maintain if the functions are not well-structured and documented.
- It may not be suitable for systems that require a lot of data processing or manipulation.

Mnemonics and Learning Tricks:
- One mnemonic to remember the key characteristics of Function Oriented Design is "FOMS" which stands for Functional, Top-down, Modular, and Structured.
- Another learning trick is to think of each function as a small machine that takes in some input, processes it, and produces some output. This can help in understanding the purpose and functionality of each function in the system.

Example:
Suppose we need to develop a system to perform some mathematical operations like addition, subtraction, multiplication, and division. We can use Function Oriented Design to decompose the system into four functions: add, subtract, multiply, and divide. Each function takes two inputs (operands) and produces an output (result). These functions can be reused in other parts of the system where mathematical operations are required.

Applications:
Function Oriented Design can be used in various applications, including:
- Mathematical and scientific computing
- Database management systems
- Operating systems
- Business applications
