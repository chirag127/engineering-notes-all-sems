## Unit 3 - Network Layer in Computer Networks

- The network layer is the third layer in the OSI model and the internet layer in the TCP/IP model.
- The network layer is responsible for transmitting data segments between networks in the form of packets.
- The network layer assigns source and destination IP addresses to the data segments and determines the best paths for data delivery using routing protocols.
- The network layer also manages sub-networks and internetworking, which are the processes of connecting different types of networks using routers, gateways, or bridges.
- The network layer provides logical addressing, which is independent of the physical addressing used by the data link layer.
- The network layer can also perform fragmentation, which is the division of large packets into smaller ones to fit the maximum transmission unit (MTU) of the underlying network.
- The network layer can also perform reassembly, which is the opposite of fragmentation, and involves putting the fragmented packets back together at the destination.
- The network layer can also perform error control, which is the detection and correction of errors that may occur during transmission.
- The network layer can also perform congestion control, which is the prevention or reduction of network congestion by regulating the flow of packets.
- The network layer can also perform quality of service (QoS), which is the provision of different levels of service to different types of traffic based on their requirements and priorities.

Some examples of network layer protocols are:

- Internet Protocol (IP): The main protocol of the network layer that provides logical addressing and routing for packets.
- Internet Control Message Protocol (ICMP): A protocol that sends and receives error and control messages between hosts and routers.
- Internet Group Management Protocol (IGMP): A protocol that manages multicast groups of hosts and routers.
- Address Resolution Protocol (ARP): A protocol that maps IP addresses to MAC addresses of the data link layer.
- Reverse Address Resolution Protocol (RARP): A protocol that maps MAC addresses to IP addresses of the network layer.
- Internet Protocol version 6 (IPv6): The latest version of IP that provides a larger address space and improved features.

Some mnemonics and learning tricks for the network layer are:

- To remember the main functions of the network layer, use the acronym **PARFERQ** (Pronounced as "par-fair-q"), which stands for **P**acketization, **A**ddressing, **R**outing, **F**ragmentation, **E**rror control, **R**eassembly, and **Q**oS.
- To remember the difference between logical and physical addressing, use the analogy of a **house**. The logical address is like the **postal address** of the house, which is unique and independent of the location. The physical address is like the **GPS coordinates** of the house, which depend on the location and may change if the house is moved.
- To remember the difference between fragmentation and reassembly, use the analogy of a **pizza**. Fragmentation is like **cutting** a large pizza into smaller slices to fit into a box. Reassembly is like **putting** the slices back together to form the original pizza.
