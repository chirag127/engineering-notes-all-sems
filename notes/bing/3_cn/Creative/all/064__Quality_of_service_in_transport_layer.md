### Quality of service in transport layer

- Quality of service (QoS) refers to the ability of a network to provide different levels of service to different types of traffic, such as voice, video, or data.
- QoS in transport layer is mainly concerned with the end-to-end performance of a communication session, such as delay, jitter, bandwidth, reliability, and error rate.
- QoS in transport layer can be achieved by using different protocols, mechanisms, and techniques, such as:
  - TCP and UDP: TCP provides reliable, ordered, and error-free delivery of data, but may incur high overhead and delay. UDP provides fast and low-overhead delivery of data, but does not guarantee reliability, order, or error correction. Depending on the application requirements, either TCP or UDP can be used to provide different QoS levels.
  - Congestion control and flow control: Congestion control is the process of adjusting the sending rate of data packets in response to network congestion, to avoid packet loss and improve network utilization. Flow control is the process of regulating the amount of data that a sender can transmit to a receiver, to avoid overwhelming the receiver's buffer. Both congestion control and flow control can help to improve QoS by preventing packet loss, delay, and jitter.
  - Stream Control Transmission Protocol (SCTP): SCTP is a transport layer protocol that provides reliable, ordered, and error-free delivery of data, similar to TCP. However, SCTP also supports multiple streams within a single connection, which can improve QoS by allowing different types of data to be transmitted in parallel, without blocking or reordering. SCTP also supports multihoming, which can improve QoS by allowing a connection to switch between multiple network paths, in case of failure or congestion.
  - Real-time Transport Protocol (RTP): RTP is a transport layer protocol that is designed for real-time applications, such as voice and video. RTP provides features such as timestamping, sequencing, and payload identification, which can help to synchronize and identify the data packets. RTP also supports QoS feedback mechanisms, such as Real-time Transport Control Protocol (RTCP), which can provide information about the network conditions, such as packet loss, delay, and jitter. RTP can be used with UDP or SCTP to provide different QoS levels for real-time applications.
  - Differentiated Services (DiffServ): DiffServ is a network architecture that provides QoS by classifying and marking the data packets according to their priority and service level. DiffServ uses a 6-bit field in the IP header, called the Differentiated Services Code Point (DSCP), to indicate the QoS level of each packet. DiffServ routers can then apply different policies and treatments to the packets based on their DSCP values, such as queuing, scheduling, shaping, or dropping. DiffServ can provide QoS in transport layer by allowing the applications to specify their QoS requirements and preferences, and by enabling the network to deliver the packets accordingly.
