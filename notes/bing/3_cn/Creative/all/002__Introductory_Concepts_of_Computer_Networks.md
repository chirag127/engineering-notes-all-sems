### Introductory Concepts of Computer Networks

- A computer network is a system of interconnected devices that can communicate and share resources with each other.
- The devices in a network can be computers, servers, routers, switches, printers, scanners, cameras, etc.
- The devices are also called nodes or hosts in a network.
- A network can be classified based on its size, topology, architecture, and protocols.
- The size of a network refers to the number and distance of the devices in the network. Some common network sizes are:
  - Local Area Network (LAN): A network that covers a small geographical area, such as a home, office, or building. LANs are usually owned and managed by a single organization or individual.
  - Metropolitan Area Network (MAN): A network that covers a larger geographical area, such as a city or a campus. MANs are usually owned and managed by a consortium of organizations or service providers.
  - Wide Area Network (WAN): A network that covers a very large geographical area, such as a country or a continent. WANs are usually owned and managed by multiple organizations or service providers, and use public or leased communication links.
- The topology of a network refers to the physical or logical arrangement of the devices and the links in the network. Some common network topologies are:
  - Bus: A network where all the devices are connected to a single cable or backbone. The cable acts as a shared medium for data transmission. A bus network is simple and cheap, but has low performance and reliability.
  - Star: A network where all the devices are connected to a central device, such as a hub or a switch. The central device acts as a point of connection and control for data transmission. A star network is easy to install and manage, but has high cost and dependency on the central device.
  - Ring: A network where all the devices are connected to form a closed loop. The data travels in one direction around the loop. A ring network is simple and reliable, but has low scalability and fault tolerance.
  - Mesh: A network where each device is connected to every other device. The data can take multiple paths to reach the destination. A mesh network is robust and resilient, but has high complexity and overhead.
  - Tree: A network where the devices are arranged in a hierarchical structure, such as a parent-child relationship. The data flows from the root node to the leaf nodes, or vice versa. A tree network is scalable and efficient, but has high latency and maintenance.
  - Hybrid: A network that combines two or more of the above topologies. A hybrid network can have the advantages of different topologies, but also the disadvantages and compatibility issues.
- The architecture of a network refers to the design and organization of the network layers, functions, and protocols. Some common network architectures are:
  - Peer-to-peer (P2P): A network where each device can act as both a client and a server, and communicate directly with each other. A P2P network is decentralized and self-organizing, but has low security and quality of service.
  - Client-server: A network where some devices act as servers that provide services or resources to other devices, which act as clients that request or consume the services or resources. A client-server network is centralized and efficient, but has high cost and vulnerability.
  - Cloud: A network where the services or resources are provided by a network of servers that are hosted on the internet, and accessed by the devices through a web browser or an application. A cloud network is scalable and flexible, but has low privacy and control.
- The protocols of a network refer to the rules and standards that govern the communication and interaction of the devices in the network. Some common network protocols are:
  - Transmission Control Protocol/Internet Protocol (TCP/IP): A suite of protocols that defines the basic functions of the internet, such as addressing, routing, error control, and data transmission. TCP/IP consists of four layers: application, transport, internet, and network access.
  - Hypertext Transfer Protocol (HTTP): A protocol that defines how web browsers and web servers communicate and exchange web pages and other resources. HTTP is based on the request-response model, where the client sends a request to the server, and the server sends a response to the client.
  - File Transfer Protocol (FTP): A protocol that defines how files are transferred between devices over a network. FTP uses two connections: a control connection for exchanging commands and messages, and a data connection for transferring files.
  - Simple Mail Transfer Protocol (SMTP): A protocol that defines how email messages are sent and received over a network. SMTP uses a store-and-forward mechanism, where the messages are stored in intermediate servers until they reach the destination.
