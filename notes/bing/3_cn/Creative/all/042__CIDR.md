#### CIDR

- CIDR stands for **Classless Inter-Domain Routing**  , a method for allocating IP addresses and for IP routing .
- CIDR was introduced in 1993 to replace the previous classful network addressing architecture on the Internet , which was based on fixed classes of IP addresses (A, B, and C).
- CIDR allows blocks of IP addresses to be grouped into single routing table entries, which reduces the size and complexity of routing tables on routers across the Internet  .
- CIDR is based on a bitwise, prefix-based representation of IP addresses and their routing properties. A CIDR IP address looks like a normal IP address followed by a slash and a number, called the **network prefix**. For example, `192.168.1.0/24` is a CIDR IP address.
- The network prefix indicates how many bits of the IP address are used to identify the network, and how many bits are used to identify the host within the network. The network prefix can range from 0 to 32 for IPv4 addresses, and from 0 to 128 for IPv6 addresses.
- The network prefix can be used to calculate the **network address**, the **broadcast address**, and the **host range** of a CIDR block. The network address is the first IP address in the block, obtained by setting all the host bits to zero. The broadcast address is the last IP address in the block, obtained by setting all the host bits to one. The host range is the set of IP addresses between the network address and the broadcast address, excluding the network address and the broadcast address themselves.
- For example, the CIDR block `192.168.1.0/24` has a network address of `192.168.1.0`, a broadcast address of `192.168.1.255`, and a host range of `192.168.1.1` to `192.168.1.254`. It can accommodate up to 254 hosts in the network.
- CIDR allows more efficient and flexible use of IP addresses, as it can create networks of different sizes based on the network prefix. For example, a /24 network can be divided into four /26 networks, each with 62 hosts, or two /25 networks, each with 126 hosts. Conversely, a /24 network can be combined with another /24 network to form a /23 network, with 510 hosts.
- CIDR also enables **supernetting**, which is the process of aggregating multiple contiguous networks into a larger network. For example, four /24 networks can be aggregated into a /22 network, with 1022 hosts. Supernetting reduces the number of routing entries and improves routing efficiency.
- CIDR is an essential technique for managing the limited IP address space, especially for IPv4 addresses, which have been exhausted since 2011. CIDR also facilitates the transition to IPv6 addresses, which have a much larger address space and use a similar notation.
