#### Link layer in Computer Networks

- The link layer is the lowest layer in the Internet protocol suite, the networking architecture of the Internet.
- The link layer is the group of methods and communications protocols confined to the link that a host is physically connected to.
- The link layer is responsible for transferring data between nodes on a network segment across the physical layer.
- The link layer may also provide the means to detect and possibly correct errors that can occur in the physical layer.
- The link layer is concerned with local delivery of frames between nodes on the same level of the network.
- The link layer usually provides and gives data reliability and provides various tools to establish, maintain, and also release data link connections between network nodes.
- The link layer can be divided into two sublayers: the logical link control (LLC) sublayer and the media access control (MAC) sublayer.
- The LLC sublayer provides services such as flow control, error control, and multiplexing to the upper layers.
- The MAC sublayer provides services such as addressing, channel access, and framing to the LLC sublayer.
- The link layer can use different protocols depending on the type of link, such as Ethernet, Wi-Fi, Bluetooth, PPP, etc.
- The link layer can also use different techniques to handle issues such as collision, congestion, and synchronization, such as CSMA/CD, CSMA/CA, token ring, etc.

Some mnemonics and learning tricks for the link layer are:

- To remember the functions of the link layer, use the acronym **FAE** (Framing, Addressing, Error control).
- To remember the sublayers of the link layer, use the acronym **LM** (Logical link control, Media access control).
- To remember the types of link layer protocols, use the acronym **EWBPP** (Ethernet, Wi-Fi, Bluetooth, PPP).
- To remember the types of link layer techniques, use the acronym **CTC** (Collision, Congestion, Synchronization).
