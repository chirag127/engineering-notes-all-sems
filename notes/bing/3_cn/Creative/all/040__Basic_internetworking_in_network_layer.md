### Basic internetworking in network layer

- Internetworking is the process of connecting different networks using routers and other devices to form a larger network that can exchange data across different protocols and technologies.
- The network layer is responsible for providing logical addressing, routing, and packet forwarding between different networks.
- The standard reference model for internetworking is the Open Systems Interconnection (OSI) model, which defines seven layers of communication functions. The network layer is the third layer in this model.
- The most notable example of internetworking is the Internet, which is a global network of networks that uses the Internet Protocol (IP) as the common network layer protocol.
- There are three main types of internetworking: Internet, Intranet, and Extranet.
  - Internet: A public network that connects millions of networks and devices worldwide using IP and other protocols. Anyone can access the Internet through an Internet Service Provider (ISP) or a public network access point.
  - Intranet: A private network that connects networks and devices within an organization using IP and other protocols. Only authorized users can access the intranet through a firewall or a virtual private network (VPN).
  - Extranet: A private network that connects networks and devices of different organizations using IP and other protocols. Only authorized users can access the extranet through a firewall or a VPN. An extranet can be used for business-to-business (B2B) communication, collaboration, or e-commerce.
- There are three kinds of internetwork addresses that are commonly used: data-link layer addresses, Media Access Control (MAC) addresses, and network-layer addresses.
  - Data-link layer addresses: These are physical addresses that uniquely identify each network interface of a device. They are usually assigned by the manufacturer of the device and are stored in the hardware. Data-link layer addresses are used for communication within a single network.
  - MAC addresses: These are a type of data-link layer addresses that are 48 bits long and are written in hexadecimal format. MAC addresses are used for communication within Ethernet, Wi-Fi, and other networks that use the IEEE 802 standards.
  - Network-layer addresses: These are logical addresses that uniquely identify each device or network on an internetwork. They are usually assigned by the network administrator or the ISP and are stored in the software. Network-layer addresses are used for communication across different networks. IP addresses are a type of network-layer addresses that are 32 bits long (IPv4) or 128 bits long (IPv6) and are written in decimal or hexadecimal format.
- A mnemonic to remember the difference between data-link layer addresses and network-layer addresses is: **D**ata-link layer addresses are **D**evice-specific, while **N**etwork-layer addresses are **N**etwork-specific.
- A mnemonic to remember the difference between MAC addresses and IP addresses is: **M**AC addresses are **M**anufacturer-assigned, while **I**P addresses are **I**nternet-assigned.
