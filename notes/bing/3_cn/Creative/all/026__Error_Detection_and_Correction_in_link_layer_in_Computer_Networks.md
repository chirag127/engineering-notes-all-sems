#### Error Detection and Correction in link layer in Computer Networks

- Error detection and correction in link layer is the process of detecting and correcting data frames that have been corrupted or lost during transmission .
- Error detection and correction is important to ensure reliable and accurate data communication in computer networks .
- The basic approach for error detection and correction is the use of redundancy, where additional bits are added to the data to facilitate the detection and correction of errors .
- There are three main techniques for error detection in link layer: parity check, checksum and cyclic redundancy check (CRC) .
- Parity check is the simplest technique, where an extra bit, called parity bit, is added to the data to make the number of 1s either even (in case of even parity) or odd (in case of odd parity) .
- Parity check can detect single-bit errors, but not multiple-bit errors.
- Checksum is a technique where the sender computes a value, called checksum, by adding the data bytes and sends it along with the data .
- The receiver computes the checksum of the received data and compares it with the received checksum .
- If the checksums match, the data is assumed to be error-free, otherwise an error is detected .
- Checksum can detect multiple-bit errors, but not all of them .
- CRC is a technique where the sender and the receiver agree on a polynomial, called generator polynomial, and use it to generate a value, called CRC, by dividing the data by the polynomial .
- The sender appends the CRC to the data and sends it to the receiver .
- The receiver divides the received data by the same polynomial and checks if the remainder is zero .
- If the remainder is zero, the data is assumed to be error-free, otherwise an error is detected .
- CRC can detect multiple-bit errors and burst errors (where a sequence of bits are corrupted) .
- Error correction is the process of identifying and correcting the corrupted bits in the data .
- There are two main techniques for error correction in link layer: automatic repeat request (ARQ) and forward error correction (FEC) .
- ARQ is a technique where the sender and the receiver use acknowledgements (ACKs) and negative acknowledgements (NAKs) to communicate the status of the received data .
- The sender sends a data frame and waits for an ACK from the receiver .
- The receiver sends an ACK if the data frame is error-free, or a NAK if an error is detected .
- The sender retransmits the data frame if it does not receive an ACK or receives a NAK within a specified time .
- ARQ can correct errors by retransmission, but it requires feedback and increases the delay .
- FEC is a technique where the sender adds extra bits, called error-correcting codes, to the data to enable the receiver to correct errors without retransmission .
- The receiver uses the error-correcting codes to detect and correct errors in the data .
- FEC can correct errors without feedback and reduce the delay, but it requires more bandwidth and computation .
- There are different types of error-correcting codes, such as Hamming code, Reed-Solomon code, and convolutional code .
