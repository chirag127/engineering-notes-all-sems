#### protocols and standards in networks architecture in Computer Networks

- Network protocols are a set of guidelines governing the exchange of information in a simple, dependable and secure way.
- Network protocols define how devices communicate within a network, including the formats, procedures, and rules of data transmission.
- Network standards are formal specifications that ensure compatibility and interoperability among different network devices, systems, and applications.
- Network standards are usually developed by standard organizations, such as IEEE, ISO, IETF, etc., or by industry consortia, such as W3C, Bluetooth SIG, etc.
- Network architecture is the design and structure of a network, including its components, connections, and functions.
- Network architecture components include hardware, software, transmission media (wired or wireless), network topology, and communications protocols.
- Network architecture can be classified into two main types: peer-to-peer (P2P) and client/server.
- In a P2P network, each node can act as both a client and a server, and there is no central authority or server.
- In a client/server network, one or more servers provide services to clients, and there is a clear distinction between the roles of each node.
- Network protocols and standards are usually organized into layers, which abstract the functionality and complexity of each level.
- The most common layered models are the OSI model and the TCP/IP model, which have seven and four layers respectively.
- The OSI model consists of the following layers: physical, data link, network, transport, session, presentation, and application.
- The TCP/IP model consists of the following layers: network access, internet, transport, and application.
- Each layer in a model uses protocols and standards to communicate with the same layer in another node, and to provide services to the upper and lower layers.
- Some of the common network protocols and their functions are:
  - Transmission Control Protocol (TCP): provides reliable, ordered, and error-checked delivery of data between applications
  - Internet Protocol (IP): provides addressing and routing of data packets across networks
  - User Datagram Protocol (UDP): provides fast and efficient delivery of data without error-checking or ordering
  - Hypertext Transfer Protocol (HTTP): provides the rules for web browsers and servers to exchange web pages and other resources
  - File Transfer Protocol (FTP): provides the rules for transferring files between computers over a network
  - Simple Mail Transfer Protocol (SMTP): provides the rules for sending and receiving email messages
  - Domain Name System (DNS): provides the rules for translating domain names into IP addresses
  - Secure Sockets Layer (SSL) / Transport Layer Security (TLS): provides the rules for encrypting and authenticating data transmission over a network
  - Wireless Application Protocol (WAP): provides the rules for accessing web content and services on mobile devices
  - Bluetooth: provides the rules for short-range wireless communication between devices
  - Ethernet: provides the rules for data transmission over a wired local area network (LAN)
  - Wi-Fi: provides the rules for data transmission over a wireless local area network (LAN)
