#### IP

- IP stands for Internet Protocol, which is a set of rules that governs how data packets are transmitted over a network.
- IP is one of the core protocols of the TCP/IP suite, which is the most widely used network protocol stack in the world.
- IP is responsible for addressing, routing, and fragmenting data packets across different networks and devices.
- IP operates at the network layer (layer 3) of the OSI model, which means it can work with any type of link layer (layer 2) protocol, such as Ethernet, Wi-Fi, or PPP.
- IP has two main versions: IPv4 and IPv6, which differ in the size and format of the addresses they use.
- IPv4 uses 32-bit addresses, which can support up to 4.3 billion unique devices on the network. However, due to the rapid growth of the Internet, IPv4 addresses are running out, and many devices have to share the same address using techniques like NAT (Network Address Translation).
- IPv6 uses 128-bit addresses, which can support up to 3.4 x 10^38 unique devices on the network. IPv6 also has some other features and improvements over IPv4, such as simplified header format, enhanced security, and support for multicast and anycast.
- IP addresses are divided into two parts: network prefix and host identifier. The network prefix identifies the network or subnet that the device belongs to, and the host identifier identifies the specific device within that network or subnet.
- The network prefix and host identifier are separated by a slash (/) followed by a number that indicates the length of the network prefix in bits. For example, 192.168.1.100/24 means that the network prefix is 192.168.1 and the host identifier is 100, and the network prefix is 24 bits long.
- IP addresses can be classified into different classes based on the length and range of the network prefix. For example, class A addresses have a network prefix of 8 bits and a host identifier of 24 bits, and can support up to 126 networks and 16 million hosts per network. Class B addresses have a network prefix of 16 bits and a host identifier of 16 bits, and can support up to 16,384 networks and 65,536 hosts per network. Class C addresses have a network prefix of 24 bits and a host identifier of 8 bits, and can support up to 2 million networks and 254 hosts per network.
- IP addresses can also be categorized into different types based on their function and scope. For example, unicast addresses are used to identify a single device on the network, and are the most common type of IP addresses. Broadcast addresses are used to send data to all devices on the same network or subnet, and are usually the last address in the network or subnet range. Multicast addresses are used to send data to a group of devices that share a common interest, and are usually in the range of 224.0.0.0 to 239.255.255.255. Anycast addresses are used to send data to the nearest device that provides a certain service, and are usually assigned to multiple devices that have the same address.
- IP packets consist of two parts: header and payload. The header contains information such as the source and destination addresses, the protocol version, the length, the time to live, and the checksum. The payload contains the actual data that is being transmitted, such as an HTTP request or a DNS query.
- IP packets can be fragmented if they are larger than the maximum transmission unit (MTU) of the link layer protocol. Fragmentation is the process of breaking a large packet into smaller packets that can fit the MTU. Each fragment has its own header, which includes a fragment offset and a flag to indicate whether it is the last fragment or not. The fragments are reassembled at the destination device based on the fragment offset and the identification field in the header.
- IP routing is the process of finding the best path for a packet to reach its destination. IP routing is done by routers, which are devices that connect different networks and forward packets based on their destination addresses. Routers use routing tables, which are databases that store information about the networks and subnets that they are connected to, and the next hop router for each destination. Routers can learn routing information from static configuration, dynamic protocols, or both.
