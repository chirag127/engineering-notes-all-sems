## Unit 5 - Application Layer in Computer Networks

- The application layer is the highest layer of the Open Systems Interconnection (OSI) model and the Internet Protocol Suite (TCP/IP) model. It is where users interact with the network, download information and send data.
- The application layer is not an application itself, but an abstraction layer that specifies the shared communications protocols and interface methods used by hosts in a communications network. It ensures that an application can effectively communicate with other applications on different computer systems and networks.
- The application layer provides various services and functions to the users and applications, such as:
  - Email: The application layer provides a facility by which users can forward several emails and it also provides a storage facility. Some of the protocols used for email are Simple Mail Transfer Protocol (SMTP), Post Office Protocol (POP) and Internet Message Access Protocol (IMAP).
  - File Transfer: The application layer allows users to access, retrieve and manage files in a remote computer. Some of the protocols used for file transfer are File Transfer Protocol (FTP), Trivial File Transfer Protocol (TFTP) and Secure File Transfer Protocol (SFTP).
  - Remote Login: The application layer allows users to log on as a remote host. Some of the protocols used for remote login are Telnet, Secure Shell (SSH) and Remote Desktop Protocol (RDP).
  - Directory Services: The application layer provides access to global information about various objects and services on the network. Some of the protocols used for directory services are Lightweight Directory Access Protocol (LDAP), Domain Name System (DNS) and Active Directory.
  - Web Browsing: The application layer enables users to access and view web pages on the internet. Some of the protocols used for web browsing are Hypertext Transfer Protocol (HTTP), Hypertext Transfer Protocol Secure (HTTPS) and HyperText Markup Language (HTML).
  - Multimedia: The application layer supports various types of multimedia applications, such as voice over IP, video conferencing, streaming and online gaming. Some of the protocols used for multimedia are Real-time Transport Protocol (RTP), Real-time Transport Control Protocol (RTCP), Session Initiation Protocol (SIP) and H.323.
  - Network Management: The application layer provides tools and functions for monitoring and controlling the network devices and resources. Some of the protocols used for network management are Simple Network Management Protocol (SNMP), Common Management Information Protocol (CMIP) and Network Time Protocol (NTP).
- The application layer protocols are classified into two types: specific and generic. Specific protocols are designed for a particular application, such as HTTP for web browsing and SMTP for email. Generic protocols are designed to support multiple applications, such as TCP and UDP for data transmission and IP for addressing and routing.
- The application layer protocols use different methods of communication, such as request-response, client-server, peer-to-peer and publish-subscribe. Request-response is a method where one party sends a request and the other party sends a response. Client-server is a method where one party acts as a client and requests a service from another party that acts as a server. Peer-to-peer is a method where both parties act as peers and exchange data directly without a central server. Publish-subscribe is a method where one party publishes a message and the other party subscribes to receive the message.
- The application layer protocols use different formats of data representation, such as text, binary, XML and JSON. Text is a format where data is represented as human-readable characters. Binary is a format where data is represented as bits and bytes. XML is a format where data is represented as tags and attributes. JSON is a format where data is represented as key-value pairs.
- The application layer protocols use different methods of data compression, encryption and authentication to reduce the size, protect the confidentiality and verify the identity of the data. Data compression is a method where data is reduced by removing redundant or irrelevant information. Data encryption is a method where data is transformed by using a secret key or algorithm. Data authentication is a method where data is verified by using a password, certificate or token.
