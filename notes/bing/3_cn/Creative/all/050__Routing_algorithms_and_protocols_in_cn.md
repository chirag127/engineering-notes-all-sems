### Routing algorithms and protocols in cn

- Routing is the process of finding a path from a source to a destination in a network of nodes.
- Routing algorithms are the methods or rules that determine how to select the best path for a packet to travel from the source to the destination.
- Routing protocols are the set of rules or standards that define how routers communicate with each other to exchange routing information and maintain routing tables.
- There are two main types of routing algorithms: static and dynamic.
  - Static routing algorithms use fixed or predefined routes that do not change unless manually configured by the network administrator. Static routing is simple, fast, and secure, but it is not adaptive to network changes or failures, and it requires manual intervention to update the routes.
  - Dynamic routing algorithms use current network conditions, such as traffic load, link status, or topology changes, to update the routes automatically. Dynamic routing is adaptive, flexible, and scalable, but it is more complex, slower, and less secure than static routing, and it requires more network resources and overhead to exchange routing information.
- There are two main types of routing protocols: distance vector and link state.
  - Distance vector routing protocols use the distance or hop count as the metric to select the best path. Each router maintains a routing table that contains the distance and the next hop to reach each destination. The routers exchange their routing tables periodically with their neighbors, and update their own tables based on the information received. Distance vector routing protocols are simple, easy to implement, and suitable for small networks, but they are slow to converge, prone to routing loops, and do not consider other factors such as bandwidth or delay.
  - Link state routing protocols use the link cost as the metric to select the best path. Each router maintains a link state database that contains the status and the cost of each link in the network. The routers exchange link state packets with all other routers in the network, and use a shortest path algorithm, such as Dijkstra's algorithm, to compute the best path to each destination. Link state routing protocols are fast to converge, loop-free, and consider multiple factors, but they are complex, difficult to implement, and require more network resources and overhead to exchange link state packets.
- Some examples of routing algorithms and protocols are:
  - RIP (Routing Information Protocol): a distance vector routing protocol that uses hop count as the metric and has a maximum hop count of 15. RIP is simple and widely used, but it has slow convergence, routing loops, and poor scalability.
  - OSPF (Open Shortest Path First): a link state routing protocol that uses link cost as the metric and supports multiple areas and hierarchical routing. OSPF is fast, loop-free, and scalable, but it is complex and requires more network resources.
  - EIGRP (Enhanced Interior Gateway Routing Protocol): a hybrid routing protocol that combines the features of distance vector and link state routing protocols. EIGRP uses a composite metric that includes bandwidth, delay, reliability, and load, and supports unequal cost load balancing. EIGRP is fast, loop-free, and scalable, but it is proprietary and requires more network resources.
  - BGP (Border Gateway Protocol): a path vector routing protocol that is used to exchange routing information between autonomous systems (AS) on the Internet. BGP uses attributes, such as AS path, next hop, local preference, and origin, to select the best path. BGP is flexible, robust, and scalable, but it is complex and requires manual configuration.
