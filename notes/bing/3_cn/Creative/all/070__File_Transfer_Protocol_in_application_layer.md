### File Transfer Protocol in application layer

- File Transfer Protocol (FTP) is an application layer protocol that allows users to transfer files between hosts over a TCP/IP network.
- FTP uses two TCP connections: a control connection and a data connection.
- The control connection is used to exchange commands and responses between the client and the server. The data connection is used to transfer the actual files.
- FTP follows a client-server model, where the client initiates the connection and requests files from the server. The server responds to the client's requests and sends the files.
- FTP supports two modes of operation: active mode and passive mode.
- In active mode, the client opens a random port for the data connection and sends its port number to the server through the control connection. The server then connects to the client's port to send the files.
- In passive mode, the server opens a random port for the data connection and sends its port number to the client through the control connection. The client then connects to the server's port to receive the files.
- Passive mode is preferred over active mode because it avoids the problem of firewalls blocking incoming connections to the client.
- FTP supports two types of file transfer: binary and ASCII.
- Binary transfer is used to transfer files that are not text-based, such as images, audio, video, etc. Binary transfer preserves the exact format and content of the files.
- ASCII transfer is used to transfer text-based files, such as HTML, XML, etc. ASCII transfer converts the files to a standard text format that can be read by different systems.
- FTP supports various commands and responses to perform different operations, such as:
  - USER and PASS: to authenticate the user and password.
  - LIST and NLST: to list the files and directories in the current directory.
  - CWD and CDUP: to change the current directory and move up one level.
  - RETR and STOR: to retrieve and store files from and to the server.
  - PORT and PASV: to switch between active and passive mode.
  - TYPE: to specify the type of file transfer (binary or ASCII).
  - QUIT: to terminate the FTP session.
- FTP uses the following format for commands and responses:
  - Commands: `<command> <argument>\r\n`
  - Responses: `<status code> <message>\r\n`
- FTP uses three-digit status codes to indicate the status of the commands and responses, such as:
  - 1xx: positive preliminary reply, indicating that the command is accepted but more information is needed.
  - 2xx: positive completion reply, indicating that the command is successfully completed.
  - 3xx: positive intermediate reply, indicating that the command is accepted but another command is needed.
  - 4xx: transient negative reply, indicating that the command is not accepted due to a temporary error.
  - 5xx: permanent negative reply, indicating that the command is not accepted due to a permanent error.
- FTP is widely used for transferring files over the Internet, such as downloading software, uploading web pages, etc.
- FTP has some advantages and disadvantages, such as:
  - Advantages:
    - FTP is simple and easy to use.
    - FTP can transfer large files efficiently and reliably.
    - FTP can resume interrupted transfers.
    - FTP can support different types of file transfer.
  - Disadvantages:
    - FTP is not secure, as it sends the user credentials and data in plain text.
    - FTP does not support encryption or compression of the data.
    - FTP does not support file synchronization or version control.
    - FTP does not support concurrent access or locking of the files.
