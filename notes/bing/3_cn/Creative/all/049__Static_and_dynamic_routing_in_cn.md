### Static and dynamic routing in cn

- Static routing and dynamic routing are two methods of configuring routing tables in a network.
- Routing tables are data structures that store information about the best paths to reach different destinations in a network.
- Static routing means that the routing tables are manually configured by the network administrator and do not change unless the administrator updates them.
- Dynamic routing means that the routing tables are automatically updated by routing protocols that exchange information with other routers in the network.
- Some advantages of static routing are:
  - It is simple and easy to implement in small networks.
  - It is more secure and predictable than dynamic routing, as the administrator has full control over the routes.
  - It consumes less bandwidth and CPU resources than dynamic routing, as there is no routing protocol overhead.
- Some disadvantages of static routing are:
  - It is difficult and time-consuming to implement and maintain in large and complex networks.
  - It is not scalable or adaptable to network changes, such as link failures, congestion, or topology changes.
  - It can lead to suboptimal routing and performance issues, as the administrator may not have complete or accurate knowledge of the network topology and conditions.
- Some advantages of dynamic routing are:
  - It is easier and faster to implement and maintain in large and dynamic networks, as the routing tables are automatically updated by the routing protocols.
  - It is more scalable and adaptable to network changes, as the routing protocols can discover new routes, avoid failed links, and balance traffic load.
  - It can lead to optimal routing and performance, as the routing protocols can select the best paths based on various metrics, such as hop count, bandwidth, delay, or cost.
- Some disadvantages of dynamic routing are:
  - It is more complex and difficult to implement in small and simple networks, as the routing protocols require configuration and tuning of various parameters and options.
  - It is less secure and predictable than static routing, as the routing tables can be manipulated or compromised by malicious or faulty routers.
  - It consumes more bandwidth and CPU resources than static routing, as the routing protocols generate and exchange routing information periodically or on demand.
- Some examples of static routing are:
  - Default routes, which are used to direct packets to a default gateway when no specific route is available for the destination.
  - Host routes, which are used to direct packets to a specific host or device in the network.
  - Network routes, which are used to direct packets to a specific network or subnet in the network.
- Some examples of dynamic routing are:
  - Distance vector routing protocols, such as RIP and EIGRP, which use the hop count as the metric and exchange routing information with their immediate neighbors.
  - Link state routing protocols, such as OSPF and IS-IS, which use the shortest path algorithm and exchange routing information with all routers in the same area or domain.
  - Path vector routing protocols, such as BGP, which use the path attributes and exchange routing information with selected routers in different autonomous systems.
