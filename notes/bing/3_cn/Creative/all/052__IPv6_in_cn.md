### IPv6 in cn

- IPv6 stands for Internet Protocol version 6, which is the latest version of the Internet Protocol (IP) that is used to identify and communicate with devices on the Internet.
- IPv6 was developed to overcome the limitations of IPv4, such as the exhaustion of address space, the lack of security features, the complexity of configuration and management, and the poor support for mobility and quality of service (QoS).
- IPv6 has the following features and advantages over IPv4:
  - Larger address space: IPv6 uses 128-bit addresses, which can support 2^128 (approximately 3.4 x 10^38) possible addresses, compared to 32-bit addresses in IPv4, which can support 2^32 (approximately 4.3 x 10^9) possible addresses. This allows for more devices to be connected to the Internet, and for more efficient and hierarchical address allocation.
  - Stateless address autoconfiguration (SLAAC): IPv6 enables devices to automatically configure their own addresses without the need for a server, such as a Dynamic Host Configuration Protocol (DHCP) server. This simplifies the network configuration and management, and reduces the overhead and latency of address assignment.
  - Enhanced security: IPv6 supports the mandatory use of the IP Security (IPsec) protocol, which provides encryption and authentication for the data packets. This improves the confidentiality, integrity, and availability of the communication, and prevents attacks such as spoofing, replay, and denial of service (DoS).
  - Improved performance: IPv6 has a simplified header format, which reduces the processing and routing overhead of the packets. IPv6 also supports extension headers, which allow for the inclusion of optional information, such as routing, fragmentation, mobility, and QoS. IPv6 also eliminates the need for network address translation (NAT), which can cause problems for some applications and protocols, such as peer-to-peer (P2P) and Voice over IP (VoIP).
  - Support for mobility: IPv6 supports the Mobile IPv6 (MIPv6) protocol, which enables devices to move from one network to another without changing their addresses or losing their connections. This enhances the user experience and the efficiency of the network resources.
  - Support for QoS: IPv6 supports the Differentiated Services (DiffServ) and Integrated Services (IntServ) models, which enable the prioritization and reservation of network resources for different types of traffic, such as real-time, interactive, and bulk data. This improves the quality and reliability of the communication, and reduces the delay and jitter of the packets.

- A mnemonic to remember the IPv6 address format is: **8 groups of 4 hex digits separated by colons**. For example, 2001:0db8:85a3:0000:0000:8a2e:0370:7334 is a valid IPv6 address.
- A learning trick to convert between binary and hexadecimal is to **group the binary digits into four and map them to the corresponding hexadecimal digit**. For example, 1010 0001 1100 1111 in binary is equivalent to A1CF in hexadecimal.
