#### Inheritance in Scala

- Inheritance is an important pillar of OOP (Object Oriented Programming).
- It is the mechanism in Scala by which one class is allowed to inherit the features (fields and methods) of another class.
- The class whose features are inherited is known as superclass (or a base class or a parent class).
- The class that inherits the features is known as subclass (or a derived class or a child class).
- We use the `extends` keyword to indicate that a class inherits from another class .
- Scala supports various types of inheritance, such as single, multilevel, multiple, and hierarchical .
- Single inheritance is when one class inherits from a single other class.
- Multilevel inheritance is when one class extends another, which in turn extends another.
- Hierarchical inheritance is when more than one class inherits from a single class.
- Multiple inheritance is when one class inherits from more than one class .
- Hybrid inheritance is a combination of multiple and hierarchical inheritance .
- Scala does not support multiple and hybrid inheritance directly in classes, but it can be achieved by using traits .
- Traits are abstract types that can contain fields and methods, and can be mixed in with classes using the `with` keyword .
- Traits can also extend other traits or classes, and can be used to implement multiple interfaces .
- Inheritance allows us to reuse code, avoid duplication, and achieve polymorphism .
- Polymorphism is the ability of an object to behave differently depending on its type or context .
- Scala supports two types of polymorphism: static (or compile-time) and dynamic (or run-time) .
- Static polymorphism is when the method to be invoked is determined at compile time, based on the type of the reference variable .
- Dynamic polymorphism is when the method to be invoked is determined at run time, based on the type of the object referred by the variable .
- Static polymorphism can be achieved by using method overloading, which is when a class has more than one method with the same name but different parameters .
- Dynamic polymorphism can be achieved by using method overriding, which is when a subclass redefines a method inherited from a superclass .
- Scala also supports abstract classes and methods, which are classes and methods that are declared but not defined .
- Abstract classes and methods are used to specify the general behavior of a class, but leave the implementation details to the subclasses .
- Abstract classes and methods are marked with the `abstract` keyword .
- Abstract classes cannot be instantiated, but can be extended by concrete classes .
- Abstract methods must be overridden by concrete methods in the subclasses .
- Scala also supports final classes and methods, which are classes and methods that cannot be extended or overridden .
- Final classes and methods are marked with the `final` keyword .
- Final classes and methods are used to prevent inheritance and polymorphism, and to improve performance .
- Inheritance in Scala is a powerful feature that allows us to design and organize our code in a modular and reusable way .
