#### Write operations in HDFS

- Write operations in HDFS are used to store data in the distributed file system by creating new files or appending to existing ones.
- Write operations in HDFS follow these steps:

  1. The client initiates the write operation by calling the `create()` method of the `DistributedFileSystem` object, which is a wrapper over the `FileSystem` class. This method takes the file name, replication factor, block size, and other parameters as arguments.
  2. The `DistributedFileSystem` object communicates with the `NameNode` to check if the file already exists, if the user has the permission to write, and if there is enough space in the cluster. If all the conditions are met, the `NameNode` grants the write permission and returns a list of `DataNode` addresses where the file blocks can be stored.
  3. The client then creates a `DFSOutputStream` object, which is responsible for splitting the data into packets, adding checksums, and sending them to the `DataNode` pipeline. The `DFSOutputStream` also maintains a buffer to store the packets before sending them to the pipeline.
  4. The client writes the data to the `DFSOutputStream`, which divides the data into fixed-size blocks (default 128 MB) and assigns a sequence number to each block. The `DFSOutputStream` then creates a packet for each block and adds it to the buffer.
  5. The `DFSOutputStream` periodically flushes the packets from the buffer to the `DataNode` pipeline, which consists of a chain of `DataNode`s that are responsible for storing the replicas of the blocks. The first `DataNode` in the pipeline is the primary `DataNode`, which receives the packets from the client and forwards them to the next `DataNode` in the pipeline. The last `DataNode` in the pipeline sends an acknowledgment to the previous `DataNode`, and so on, until the acknowledgment reaches the primary `DataNode`, which then sends it back to the client.
  6. The client receives the acknowledgment from the primary `DataNode` and updates the file metadata in the `NameNode` by calling the `close()` method of the `DFSOutputStream`. The `NameNode` then commits the file creation or append operation in the file system namespace.
