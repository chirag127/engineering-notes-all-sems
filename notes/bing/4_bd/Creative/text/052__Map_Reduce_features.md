#### Map Reduce features

- Map Reduce is a programming model and an associated implementation for processing and generating large data sets with a parallel, distributed algorithm on a cluster.
- Map Reduce consists of two phases: map and reduce. The map phase applies a user-defined function to each input key-value pair and produces a set of intermediate key-value pairs. The reduce phase merges all intermediate values associated with the same intermediate key and produces the final output.
- Map Reduce can handle various types of data, such as structured, semi-structured, and unstructured data. It can also process data that is too large to fit in memory or disk.
- Map Reduce is fault-tolerant, scalable, and easy to use. It automatically handles the distribution of data and computation, the load balancing, the failure recovery, and the network communication. It also provides a simple interface for the user to specify the map and reduce functions.
- Map Reduce can be used for various applications, such as word count, inverted index, web link analysis, machine learning, data mining, and statistical analysis.
