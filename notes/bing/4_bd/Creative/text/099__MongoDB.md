### MongoDB

- MongoDB is an open source, nonrelational database management system (DBMS) that uses flexible documents instead of tables and rows to process and store various forms of data  .
- MongoDB is a document database, which means it stores data in JSON-like documents with optional schemas . This allows for more flexibility and scalability than traditional relational databases that use fixed schemas and tables.
- MongoDB is a distributed database at its core, so high availability, horizontal scaling, and geographic distribution are built in and easy to use. MongoDB can run on multiple servers and replicate data across them for fault tolerance and load balancing.
- MongoDB supports ad-hoc queries, secondary indexing, and real-time aggregations to provide powerful ways to access and analyze your data. MongoDB also supports various programming languages and frameworks through its drivers and APIs.
- MongoDB is free to use under the Server Side Public License (SSPL), which is a copyleft license that requires users to make their source code available if they offer MongoDB as a service . MongoDB also offers a cloud-based version called MongoDB Atlas, which is a fully managed and secure database service .
