## Unit 3 - Hadoop Eco System and YARN , no SQL databases , MongoDB , Spark , Scala

- Hadoop is a framework and suite of tools that tackle the many challenges in dealing with big data. It consists of several components, such as HDFS, MapReduce, YARN, Hive, Pig, Spark, Oozie, Zookeeper, Mahout, etc. 
- HDFS is the distributed file system that stores large volumes of data across multiple nodes in a cluster. It provides high availability, fault tolerance, scalability and reliability. 
- MapReduce is the programming model that allows parallel processing of large data sets using a map function and a reduce function. It divides the data into smaller chunks and assigns them to different nodes for processing. The results are then aggregated and returned. 
- YARN (Yet Another Resource Negotiator) is the resource management layer that allocates and monitors the resources (CPU, memory, disk, network) for the applications running on the cluster. It also provides scheduling, security and isolation features. YARN is also called as the operating system of Hadoop. 
- Hive is a data warehouse tool that provides SQL-like interface to query and analyze data stored in HDFS. It supports various data formats, such as text, JSON, ORC, Parquet, etc. It also allows creating tables, views, partitions, indexes and user-defined functions. 
- Pig is a scripting language that allows data analysis and transformation using a set of operators, such as load, store, filter, join, group, etc. It can run on top of MapReduce or Tez engines and can handle structured, semi-structured and unstructured data. 
- Spark is a fast and general-purpose engine for large-scale data processing. It supports batch, streaming, interactive and machine learning applications. It can run on top of Hadoop, Mesos, Kubernetes or standalone clusters and can access data from various sources, such as HDFS, Hive, HBase, Cassandra, MongoDB, etc. 
- Scala is a programming language that combines object-oriented and functional paradigms. It is concise, expressive and interoperable with Java. It is one of the main languages used to write Spark applications, along with Python, R and Java. 
- NoSQL databases are databases that do not use SQL as the query language and do not follow the relational model. They are designed to handle large volumes of data with high performance, scalability and availability. They typically use key-value, document, columnar, graph or hybrid data models. 
- MongoDB is a popular NoSQL database that uses the document data model. It stores data as JSON-like documents with dynamic schemas. It supports various features, such as indexing, aggregation, replication, sharding, transactions, etc. It can be integrated with Hadoop and Spark for data analysis and processing.
