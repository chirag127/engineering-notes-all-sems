### Introduction to Big Data Platform

- A big data platform is a type of IT solution that combines the features and capabilities of several big data applications and utilities within a single solution.
- A big data platform acts as an organized storage medium for large amounts of data that are hard to manage with traditional data systems.
- A big data platform usually utilizes a combination of data management hardware and software tools to store aggregated data sets, usually onto the cloud.
- A big data platform also supports custom development, querying and integration with other systems.
- A big data platform enables organizations to develop, deploy, operate and manage a big data infrastructure or environment.
- A big data platform also provides business intelligence and analytics tools to process and analyze the data and derive insights and value from it .
- A big data platform is different from typical data assets because of its volume, complexity and need for advanced business intelligence tools to process and analyze it.
- The attributes that define big data are volume, velocity, variety, veracity and value .
- Some examples of big data platforms are Google Cloud Platform, Amazon Web Services, Microsoft Azure, Hadoop, Spark, MongoDB, etc .
