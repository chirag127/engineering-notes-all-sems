#### Hive shell

- Hive shell is a command-line interface for interacting with Hive.
- Hive shell allows users to execute Hive queries and commands, such as creating tables, loading data, querying data, and managing the Hive metastore.
- Hive shell can be launched by typing `hive` in the terminal, or by specifying a script file to run with `hive -f script.hql`.
- Hive shell supports various options and parameters, such as `-e` to execute a single query, `-v` to enable verbose mode, `-h` to display help, and `-S` to run in silent mode. To see the full list of options, type `hive --help`.
- Hive shell uses the HiveServer2 service to communicate with the Hive metastore and the execution engine. HiveServer2 can be configured to use different authentication and authorization mechanisms, such as Kerberos, LDAP, or SQL standards-based authorization.
- Hive shell supports multiple modes of operation, such as interactive mode, batch mode, and embedded mode. Interactive mode allows users to enter queries and commands one by one and see the results immediately. Batch mode allows users to run a script file containing multiple queries and commands. Embedded mode allows users to embed Hive queries and commands in a Java application using the Hive JDBC driver.
- Hive shell supports various commands and keywords, such as `SHOW`, `DESCRIBE`, `CREATE`, `DROP`, `ALTER`, `LOAD`, `INSERT`, `SELECT`, `JOIN`, `GROUP BY`, `ORDER BY`, `LIMIT`, `HAVING`, `WHERE`, `PARTITION`, `BUCKET`, `CLUSTER BY`, `DISTRIBUTE BY`, `SORT BY`, `UNION`, `INTERSECT`, `EXCEPT`, `EXPLAIN`, `ANALYZE`, `SET`, `ADD`, `DELETE`, `LIST`, `RELOAD`, `RESET`, `DFS`, `!`, and `QUIT`. To see the full list of commands and keywords, type `help` in the Hive shell.
- Hive shell supports various data types, such as `BOOLEAN`, `TINYINT`, `SMALLINT`, `INT`, `BIGINT`, `FLOAT`, `DOUBLE`, `DECIMAL`, `STRING`, `VARCHAR`, `CHAR`, `BINARY`, `DATE`, `TIMESTAMP`, `INTERVAL`, `ARRAY`, `MAP`, `STRUCT`, and `UNIONTYPE`. To see the full list of data types, type `help data types` in the Hive shell.
