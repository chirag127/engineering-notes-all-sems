## Unit 3 - Hadoop Eco System and YARN , no SQL databases , MongoDB , Spark , Scala

- Hadoop is a framework for distributed storage and processing of large-scale data sets using clusters of commodity hardware. It consists of several components, such as Hadoop Distributed File System (HDFS), MapReduce, YARN, and others, that work together to provide fault-tolerance, scalability, and high performance.
- Hadoop Ecosystem is a collection of tools and applications that interact with the core components of Hadoop to provide additional functionalities, such as data ingestion, data analysis, data visualization, machine learning, etc. Some of the popular tools in the Hadoop Ecosystem are Hive, Pig, Spark, Oozie, Zookeeper, Mahout, etc.
- YARN (Yet Another Resource Negotiator) is a component of Hadoop that provides resource management and scheduling for the applications running on Hadoop clusters. YARN is responsible for allocating resources (such as CPU, memory, disk, network) to different applications, monitoring their status, and enforcing policies and constraints. YARN also supports multiple programming models, such as MapReduce, Spark, etc., to run on the same cluster.
- NoSQL databases are databases that do not follow the relational model and do not use SQL as the query language. NoSQL databases are designed to handle large volumes of unstructured or semi-structured data, such as documents, graphs, key-value pairs, etc. NoSQL databases offer advantages such as schema flexibility, horizontal scalability, high availability, and performance.
- MongoDB is a popular NoSQL database that stores data as documents in JSON-like format. MongoDB supports dynamic schemas, meaning that the documents in a collection can have different fields and structures. MongoDB also provides features such as indexing, aggregation, replication, sharding, etc., to support various data operations and use cases.
- Spark is a fast and general-purpose framework for large-scale data processing. Spark can run on Hadoop clusters using YARN or other cluster managers, such as Mesos or Kubernetes. Spark supports multiple programming languages, such as Scala, Python, Java, etc., and provides APIs for batch processing, streaming processing, SQL queries, machine learning, graph processing, etc. Spark also leverages in-memory computing and lazy evaluation to achieve high performance and efficiency.
- Scala is a programming language that combines the features of object-oriented and functional programming. Scala is designed to be concise, expressive, and interoperable with Java. Scala is also the native language of Spark, meaning that Spark applications can be written and executed in Scala without any overhead. Scala also supports advanced features, such as pattern matching, higher-order functions, implicit conversions, etc., that make it suitable for data analysis and manipulation.
