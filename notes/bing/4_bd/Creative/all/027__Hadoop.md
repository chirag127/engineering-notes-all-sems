### Hadoop

- Hadoop is an open-source framework that allows distributed processing of large-scale data sets across clusters of computers using simple programming models.
- Hadoop consists of four main components: Hadoop Common, Hadoop Distributed File System (HDFS), Hadoop MapReduce, and Hadoop YARN.
- Hadoop Common provides the common utilities and libraries that are used by other Hadoop modules.
- HDFS is a distributed file system that stores data across multiple nodes in a cluster, providing high availability, fault tolerance, and scalability.
- Hadoop MapReduce is a programming model that enables parallel processing of large data sets using a map function and a reduce function.
- Hadoop YARN is a resource management system that allocates and schedules resources for applications running on Hadoop clusters.
- Hadoop can handle structured, semi-structured, and unstructured data, such as text, images, videos, logs, etc.
- Hadoop can run on commodity hardware, reducing the cost and complexity of data processing.
- Hadoop can scale up from a single node to thousands of nodes, depending on the data size and processing needs.
- Hadoop can be integrated with other frameworks and tools, such as Apache Spark, Apache Hive, Apache Pig, Apache HBase, etc.

Some mnemonics and learning tricks for Hadoop are:

- Hadoop can be remembered as **HA**ve **D**ata, **O**perate **O**n it, **P**arallelize it.
- HDFS can be remembered as **H**ighly **D**istributed **F**ile **S**ystem.
- MapReduce can be remembered as **MAP**ping data to key-value pairs and **REDUCE**ing them to aggregate results.
- YARN can be remembered as **Y**et **A**nother **R**esource **N**egotiator.
