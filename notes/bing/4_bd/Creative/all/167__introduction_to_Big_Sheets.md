#### Introduction to Big Sheets

- Big Sheets is a web-based spreadsheet application that can process large-scale data sets using Apache Hadoop and IBM BigInsights.
- Big Sheets allows users to explore, visualize, and analyze data using familiar spreadsheet functions and formulas, without requiring any programming skills.
- Big Sheets can handle data sets that are too large or complex for traditional spreadsheet applications, such as Excel or Google Sheets.
- Big Sheets can import data from various sources, such as HDFS, Hive, Pig, Flume, or Sqoop, and export data to CSV, PDF, or HTML formats.
- Big Sheets can also integrate with other BigInsights components, such as Big SQL, Big R, or BigSheetsML, to perform advanced analytics and machine learning on the data.
- Big Sheets provides a web-based interface that consists of the following elements:
  - A workbook, which is a collection of sheets that contain data and formulas.
  - A sheet, which is a grid of cells that can store data, formulas, or charts.
  - A cell, which is the smallest unit of data or formula in a sheet.
  - A formula bar, which is a text box that displays and edits the formula or value of the selected cell.
  - A toolbar, which provides various options and commands for working with the workbook, sheet, or cell.
  - A status bar, which shows information about the workbook, sheet, or cell, such as the number of rows and columns, the cell format, or the calculation status.
  - A sidebar, which provides access to various features and functions, such as data sources, filters, charts, macros, or functions.

- A possible mnemonic to remember the elements of the Big Sheets interface is: **Wish Cell Formula Tool Status Side** (Workbook, Sheet, Cell, Formula bar, Toolbar, Status bar, Sidebar).
- A possible learning trick to understand the concept of Big Sheets is to compare it with a traditional spreadsheet application, such as Excel or Google Sheets, and note the similarities and differences. For example:
  - Similarities: Both Big Sheets and traditional spreadsheet applications use the same basic concepts of workbooks, sheets, cells, formulas, and charts. Both Big Sheets and traditional spreadsheet applications provide a range of functions and formulas to manipulate and analyze data. Both Big Sheets and traditional spreadsheet applications allow users to export data to various formats, such as CSV, PDF, or HTML.
  - Differences: Big Sheets can handle much larger and more complex data sets than traditional spreadsheet applications, using Apache Hadoop and IBM BigInsights. Big Sheets can import data from various sources, such as HDFS, Hive, Pig, Flume, or Sqoop, while traditional spreadsheet applications usually import data from local files or databases. Big Sheets can integrate with other BigInsights components, such as Big SQL, Big R, or BigSheetsML, to perform advanced analytics and machine learning on the data, while traditional spreadsheet applications usually require external tools or add-ons for such tasks. Big Sheets provides a web-based interface, while traditional spreadsheet applications usually provide a desktop-based interface.
