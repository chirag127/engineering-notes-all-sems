#### History of Hadoop

- Hadoop is an open-source software framework for storing and processing big data. 
- Hadoop was started with Doug Cutting and Mike Cafarella in the year 2002 when they both started to work on Apache Nutch project. 
- Apache Nutch project was the process of building a search engine system that can index 1 billion pages. 
- Hadoop was named after an extinct specie of mammoth, a so called Yellow Hadoop, which was the toy of Cutting's son. 
- Hadoop was inspired by a white paper written by Google in 2003 that described the Google File System (GFS) and the MapReduce programming model. 
- GFS is a distributed file system that can store large amounts of data across multiple machines. 
- MapReduce is a programming model that can process large amounts of data in parallel by dividing the work into smaller tasks. 
- In 2006, Hadoop became a sub-project of Apache Lucene, a search engine library. 
- In 2008, Hadoop defeated the supercomputers and became the fastest system on the planet for sorting terabytes of data. 
- In 2009, Hadoop became a top-level Apache project. 
- In 2010, Hadoop reached the milestone of sorting 1 petabyte of data in 16.25 hours. 
- In 2011, Hadoop reached the milestone of sorting 100 terabytes of data in 72 minutes. 
- In 2012, Hadoop 2.0 was released, which introduced YARN, a resource management layer that allows multiple applications to run on Hadoop. 
- In 2013, Hadoop 2.2.0 was released, which supported high availability of the NameNode, the master node of HDFS. 
- In 2014, Hadoop 2.6.0 was released, which supported rolling upgrades of HDFS clusters. 
- In 2015, Hadoop 2.7.0 was released, which supported erasure coding, a technique that can reduce the storage overhead of HDFS. 
- In 2016, Hadoop 3.0.0-alpha1 was released, which supported multiple NameNodes, improved security, and better resource utilization. 
- In 2017, Hadoop 3.0.0-beta1 was released, which supported Java 8, GPU isolation, and containerized execution. 
- In 2018, Hadoop 3.1.0 was released, which supported cloud storage integration, opportunistic containers, and intra-datanode balancing. 
- In 2019, Hadoop 3.2.0 was released, which supported native S3A committers, ABFS file system connector, and HDFS RBF router-based federation. 
- In 2020, Hadoop 3.3.0 was released, which supported ARM architecture, S3A magic committers, and HDFS disk balancer. 
- In 2021, Hadoop 3.3.1 was released, which fixed some bugs and improved performance.
