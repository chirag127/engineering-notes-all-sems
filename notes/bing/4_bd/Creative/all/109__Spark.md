### Spark

- Spark is an open-source, distributed computing framework that provides a fast and general way to process large-scale data.
- Spark supports multiple programming languages, such as Scala, Python, Java, and R, and provides various libraries for data analysis, machine learning, graph processing, streaming, and SQL.
- Spark runs on a cluster of machines, where each machine is called a node. The nodes are organized into a master-slave architecture, where one node acts as the driver or master, and the rest are workers or slaves.
- Spark uses a data abstraction called resilient distributed dataset (RDD), which is a collection of elements that can be partitioned across the nodes and operated on in parallel.
- Spark also supports a higher-level data abstraction called DataFrame, which is a distributed collection of rows organized into named columns, similar to a relational table or a spreadsheet.
- Spark can read and write data from various sources, such as HDFS, S3, Cassandra, Hive, Kafka, etc.
- Spark can run on various cluster managers, such as YARN, Mesos, Kubernetes, or its own standalone mode.
- Spark has a web-based user interface (UI) that shows the status and metrics of the applications, jobs, stages, and tasks.
- Spark has a shell or REPL (read-eval-print loop) that allows users to interactively run commands and queries using Scala, Python, or R.
- Spark has a core API that provides basic operations, such as map, filter, reduce, join, etc., on RDDs and DataFrames.
- Spark has a SQL API that allows users to run SQL queries on DataFrames and view them as tables or views.
- Spark has a streaming API that allows users to process real-time data from various sources, such as Kafka, Flume, Twitter, etc., and apply transformations and actions on them.
- Spark has a machine learning library (MLlib) that provides various algorithms and tools for classification, regression, clustering, recommendation, etc., on RDDs and DataFrames.
- Spark has a graph processing library (GraphX) that provides various algorithms and tools for manipulating and analyzing graphs on RDDs.
- Spark has a natural language processing library (Spark NLP) that provides various algorithms and tools for text analysis, sentiment analysis, named entity recognition, etc., on DataFrames.
