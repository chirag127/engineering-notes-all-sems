#### Hive services

Hive services are the components that enable users to interact with Hive and perform various operations on data stored in Hive tables. Hive services include:

- **HiveServer2**: This is the main service that provides a JDBC/ODBC interface for clients to execute queries and access the metadata. HiveServer2 supports multiple concurrent users and sessions, and provides security features such as authentication and authorization. HiveServer2 also supports dynamic service discovery through ZooKeeper.
- **Hive Metastore**: This is the service that stores the metadata of Hive tables, partitions, schemas, columns, etc. in a relational database. The Hive Metastore can be embedded in HiveServer2 or run as a separate service. The Hive Metastore communicates with the NameNode to get the location of data files on HDFS.
- **Hive CLI**: This is the command-line interface for users to interact with Hive. The Hive CLI can connect to HiveServer2 or directly to the Hive Metastore. The Hive CLI supports Hive QL, which is a SQL-like language for querying and manipulating data in Hive.
- **Hive Web UI**: This is the web-based interface for users to browse the Hive metadata, execute queries, and monitor the query progress and logs. The Hive Web UI can connect to HiveServer2 or directly to the Hive Metastore. The Hive Web UI also provides a graphical view of the query execution plan and statistics.
- **Beeline**: This is a JDBC client that can connect to HiveServer2 and execute queries using Hive QL. Beeline is based on SQLLine, which is a generic JDBC client. Beeline supports multiple output formats, such as table, csv, json, etc. Beeline can also run queries from a file or a script.
- **Hive Warehouse Connector**: This is a library that enables users to read and write data between Hive and Spark. The Hive Warehouse Connector supports ACID transactions, bucketing, and partitioning on Hive tables. The Hive Warehouse Connector also provides a DataFrame API for Spark to access Hive tables as DataFrames.
