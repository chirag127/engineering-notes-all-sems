### Core Java

Core Java is the term used to refer to the basic concepts and features of the Java programming language. It is the part of Java SE (Standard Edition) platform, which is used for developing desktop or window-based applications. Core Java includes the following topics:

- Data types, variables, operators, and expressions
- Control flow statements, such as if-else, switch-case, loops, and break
- Arrays and strings
- Classes, objects, methods, and constructors
- Inheritance, polymorphism, abstraction, and encapsulation
- Interfaces and abstract classes
- Packages and access modifiers
- Exception handling and assertions
- Input and output streams
- Collections and generics
- Threads and concurrency
- Enums and annotations
- Lambda expressions and functional interfaces
- Java 8 features, such as streams, optional, and date-time API

Core Java is the foundation of Java programming, and it is essential to master it before moving on to advanced topics, such as Java EE (Enterprise Edition) or Java ME (Micro Edition). Core Java helps to understand the syntax, semantics, and logic of the Java language, and to write efficient, reliable, and maintainable code. Core Java also prepares the programmer for the various certification exams offered by Oracle and other vendors.
