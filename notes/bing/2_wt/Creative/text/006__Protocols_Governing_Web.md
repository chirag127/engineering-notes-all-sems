### Protocols Governing Web

- Protocols are a set of rules or standards that enable different devices or applications to communicate over a network, such as the internet.
- The web is a system of interlinked documents or resources that are accessed through the internet using web browsers and web servers.
- The web relies on various protocols to function properly and efficiently. Some of the most common protocols governing the web are:

  - **TCP/IP (Transmission Control Protocol/Internet Protocol)**: This is the fundamental protocol suite that provides the basic functionality of the internet. It consists of two main protocols: TCP and IP. TCP is responsible for ensuring reliable and ordered delivery of data packets between devices, while IP is responsible for routing and addressing the packets across the network. TCP/IP also supports other protocols that provide additional services, such as DNS, HTTP, FTP, etc. 
  - **DNS (Domain Name System)**: This is a protocol that translates human-readable domain names, such as www.example.com, into numerical IP addresses, such as 192.168.1.1, that are used by devices to locate and access resources on the internet. DNS also provides other information, such as the mail server or the name server of a domain. DNS operates in a hierarchical and distributed manner, using a network of servers that store and update the mappings between domain names and IP addresses.
  - **HTTP (HyperText Transfer Protocol)**: This is a protocol that defines how web browsers and web servers communicate and exchange information, such as web pages, images, videos, etc. HTTP is based on a request-response model, where a web browser sends a request for a resource to a web server, and the web server responds with the resource or an error message. HTTP also supports various methods, such as GET, POST, PUT, DELETE, etc., that indicate the action to be performed on the resource. HTTP also supports various headers, such as Content-Type, Content-Length, Cookie, etc., that provide additional information about the request or the response.
  - **FTP (File Transfer Protocol)**: This is a protocol that enables the transfer of files between devices over a network, such as the internet. FTP uses two connections: a control connection and a data connection. The control connection is used to establish the session, authenticate the user, and send commands, while the data connection is used to transfer the files. FTP supports various modes, such as binary, ASCII, passive, active, etc., that affect how the data is transferred and the ports used.
