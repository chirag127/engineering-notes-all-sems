## Unit 1 - Introduction to Web Technology

- Web technology is the use of various tools and protocols to create and deliver information and services over the internet.
- Web technology consists of two main components: the client and the server.
- The client is the device or software that requests and displays web content, such as a web browser or a mobile app.
- The server is the device or software that responds to client requests and provides web content, such as a web server or a web application.
- Web content is the information and data that is transmitted between the client and the server, such as text, images, audio, video, etc.
- Web content is formatted using various languages and standards, such as HTML, CSS, JavaScript, XML, JSON, etc.
- Web technology enables various applications and services, such as e-commerce, social media, online education, gaming, etc.
- Web technology is constantly evolving and improving, with new tools and protocols being developed and adopted.
