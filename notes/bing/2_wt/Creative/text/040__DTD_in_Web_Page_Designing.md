### DTD in Web Page Designing

- DTD stands for Document Type Definition .
- A DTD defines the structure and the legal elements and attributes of an XML document .
- A DTD can be declared internally or externally in an XML document.
- A DTD can be used to validate an XML document against a set of rules .
- A DTD can also be used to declare entities, notations, and processing instructions.
- In HTML 4.01, the DOCTYPE declaration refers to a DTD .
- The DOCTYPE declaration is an instruction to the web browser about what version of HTML the page is written in .
- The DOCTYPE declaration ensures that the web page is parsed the same way by different web browsers .
- There are three types of DTDs in HTML 4.01 :
  - Strict DTD: Used for web pages that exclude attributes and elements that W3C expects to phase out as CSS support grows .
  - Transitional DTD: Used for web pages that include attributes and elements that W3C expects to phase out as CSS support grows .
  - Frameset DTD: Used for web pages with frames .
- In HTML5, the DOCTYPE declaration is simplified and does not refer to a DTD.
- The DOCTYPE declaration in HTML5 is <!DOCTYPE html> and it tells the browser to render the page in standards mode.
