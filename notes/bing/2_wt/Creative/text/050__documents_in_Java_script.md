#### Documents in JavaScript

- A document in JavaScript is an object that represents a web page loaded in a browser and provides access to its content, such as HTML elements, text, images, etc. 
- A document is also an instance of the Document interface, which defines the properties and methods that can be used to manipulate the document object. 
- A document is part of the Document Object Model (DOM), which is a tree-like structure that represents the logical relationship between the document and its elements. 
- A document can be accessed and modified by using the global document object, which is a property of the window object. 
- Some of the common properties and methods of the document object are:

  - document.body: returns the body element of the document. 
  - document.title: returns or sets the title of the document. 
  - document.getElementById(id): returns the element with the specified id attribute. 
  - document.createElement(tagName): creates a new element with the specified tag name. 
  - document.appendChild(child): appends a new child element to the document. 
  - document.querySelector(selector): returns the first element that matches the specified CSS selector. 
  - document.querySelectorAll(selector): returns a collection of all elements that match the specified CSS selector. 
  - document.addEventListener(type, listener): registers an event listener for the specified event type on the document. 
  - document.removeEventListener(type, listener): removes an event listener for the specified event type from the document. 
  - document.write(text): writes the specified text to the document. 
  - document.close(): closes the document after writing.
