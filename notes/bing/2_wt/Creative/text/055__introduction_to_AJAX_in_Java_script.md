#### Introduction to AJAX in JavaScript

- AJAX stands for **Asynchronous JavaScript and XML**  .
- AJAX is not a programming language, but a technique for creating dynamic and interactive web applications .
- AJAX uses a combination of the following technologies  :
  - **JavaScript** to make requests and handle responses
  - **XMLHttpRequest** object to communicate with the web server
  - **XML**, **JSON**, or **plain text** to exchange data
  - **HTML** and **CSS** to display the data
  - **DOM** to manipulate the web page elements
- AJAX allows you to send and receive data **asynchronously** without reloading the web page  .
- AJAX can improve the user experience and performance of web applications by reducing the bandwidth and latency.
- AJAX can also enable web applications to communicate with other web services and APIs.
