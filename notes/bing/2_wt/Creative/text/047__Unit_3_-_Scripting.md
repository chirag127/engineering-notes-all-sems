## Unit 3 - Scripting

Scripting is a way of automating tasks or creating programs using a scripting language. A scripting language is a high-level programming language that is interpreted or executed by another program, such as a shell, a browser, or a web server. Scripting languages are often used for tasks that are repetitive, complex, or require user interaction.

Some of the advantages of scripting are:

- Scripting languages are usually easy to learn and write, as they have a simple syntax and less strict rules than compiled languages.
- Scripting languages are portable, as they can run on different platforms and environments without requiring compilation or installation.
- Scripting languages are flexible, as they can interact with other programs and data formats, and can be modified or extended at runtime.
- Scripting languages are expressive, as they can perform complex operations with fewer lines of code than compiled languages.

Some of the disadvantages of scripting are:

- Scripting languages are usually slower than compiled languages, as they have to be interpreted or executed by another program, which adds overhead and reduces performance.
- Scripting languages are less secure than compiled languages, as they can be easily modified or accessed by unauthorized users or malicious code.
- Scripting languages are less reliable than compiled languages, as they may have errors or bugs that are not detected until runtime, and may not handle exceptions or errors gracefully.

Some of the examples of scripting languages are:

- Shell scripting: A way of automating tasks or commands in a shell, such as Bash, PowerShell, or CMD. Shell scripts can manipulate files, directories, processes, and environment variables, and can invoke other programs or scripts.
- Python: A general-purpose, multi-paradigm scripting language that is widely used for data analysis, web development, machine learning, and automation. Python has a simple and elegant syntax, a large standard library, and many third-party modules and frameworks.
- JavaScript: A scripting language that is mainly used for creating dynamic and interactive web pages. JavaScript can run in a browser, a web server, or a standalone environment, and can manipulate the Document Object Model (DOM), the Hypertext Transfer Protocol (HTTP), and the JavaScript Object Notation (JSON).
- Ruby: A scripting language that is designed to be expressive, concise, and elegant. Ruby supports multiple programming paradigms, such as object-oriented, functional, and procedural, and has a rich set of built-in methods and libraries, as well as a popular web framework called Ruby on Rails.
- Perl: A scripting language that is known for its powerful text processing and regular expression capabilities. Perl can handle various data formats, such as XML, JSON, and CSV, and can interface with databases, web servers, and network protocols. Perl has a motto of "There's more than one way to do it", which reflects its flexibility and versatility.
