### History of Web

- The World Wide Web (WWW) is a system of interconnected documents that can be accessed through the Internet using a web browser.
- The Web was invented by Tim Berners-Lee, a British scientist, in 1989, while working at CERN, a European research organization .
- The Web was originally conceived and developed to meet the demand for automated information-sharing between scientists in universities and institutes around the world.
- The Web is based on several concepts and technologies, the most fundamental of which are:
  - HyperText: a way of linking and accessing information of various kinds as a web of nodes in which the user can browse at will.
  - HyperText Markup Language (HTML): a language for creating and formatting web pages.
  - HyperText Transfer Protocol (HTTP): a protocol for transferring web pages and other data over the Internet.
  - Uniform Resource Locator (URL): a unique address for identifying and locating a web resource.
- The first web browser, called WorldWideWeb, was also created by Berners-Lee in 1990. It was later renamed Nexus to avoid confusion with the Web itself.
- The first web server, which hosted the first web page, was installed at CERN in 1990. The first web page, which described the project and its goals, can still be viewed at http://info.cern.ch/hypertext/WWW/TheProject.html.
- The Web became publicly available in 1991, when CERN announced that the Web would be free and open for anyone to use.
- The Web grew rapidly in popularity and usage in the 1990s, with the emergence of more web browsers, such as Mosaic, Netscape, and Internet Explorer, and more web sites, such as Yahoo!, Amazon, and eBay.
- The Web also enabled new forms of communication, collaboration, and creativity, such as email, social media, blogs, wikis, podcasts, and web applications.
- The Web continues to evolve and expand, with new standards, technologies, and trends, such as HTML5, CSS3, JavaScript, AJAX, Web 2.0, Web 3.0, Semantic Web, and Web of Things.
