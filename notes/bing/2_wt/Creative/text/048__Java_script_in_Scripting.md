### JavaScript in Scripting

- JavaScript is a **lightweight**, **interpreted**, or **just-in-time compiled** programming language with **first-class functions**.
- JavaScript is most well-known as the **scripting language for Web pages**, but it can also be used in many non-browser environments, such as Node.js, Apache CouchDB and Adobe Acrobat.
- Scripting is a type of programming that allows you to **implement complex features** on web pages, such as displaying timely content updates, interactive maps, animated graphics, scrolling video jukeboxes, etc.
- JavaScript scripts are **interpreted by the browser** and run in the browser's **execution environment** .
- JavaScript scripts can be **embedded** in HTML documents or **linked** to external files.
- JavaScript scripts can **access and manipulate** the HTML elements and CSS styles of the web page, as well as **respond to user events** such as clicks, mouse movements, keyboard inputs, etc.
- JavaScript scripts can also **communicate** with web servers, databases, web APIs, and other web services using various methods, such as XMLHttpRequest, Fetch, WebSocket, etc.
- JavaScript scripts can also **use libraries and frameworks** that provide additional features and functionalities, such as jQuery, React, Angular, Vue, etc.
- JavaScript is a **dynamic**, **weakly typed**, **prototype-based**, and **multi-paradigm** language, which means it can support different programming styles, such as imperative, declarative, functional, object-oriented, etc .
- JavaScript has a **standard specification** called ECMAScript, which defines the core features and syntax of the language. There are also various **extensions** and **dialects** of JavaScript, such as TypeScript, CoffeeScript, etc, that add or modify some aspects of the language .
