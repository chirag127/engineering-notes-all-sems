#### Stateful Session bean in Enterprise Java Bean

- A stateful session bean is a type of enterprise bean that maintains a conversational state with a client.
- A stateful session bean can store the state of a client across multiple method invocations, such as the items in a shopping cart or the progress of a workflow.
- A stateful session bean is identified by a unique identifier that is assigned by the container when the bean is created. The identifier is used to locate the bean instance when the client invokes a method on it.
- A stateful session bean can be passivated by the container to conserve memory. Passivation means that the bean instance is serialized and written to a secondary storage, such as a file or a database. The bean instance is reactivated when the client invokes a method on it again.
- A stateful session bean can be removed by the container when it is not needed anymore, such as when the client invokes a method annotated with @Remove or when the bean instance exceeds a timeout period. The bean instance can also be removed by the client explicitly by invoking a method on the EJBHome or EJBLocalHome interface.
- A stateful session bean can implement the SessionSynchronization interface to receive notifications from the container before and after the bean instance is passivated or activated. The bean can use these notifications to perform any necessary cleanup or initialization tasks.
- A stateful session bean can implement the javax.ejb.SessionBean interface to receive lifecycle callbacks from the container, such as ejbCreate, ejbRemove, ejbActivate, and ejbPassivate. The bean can use these callbacks to perform any custom logic or resource management.
- A stateful session bean can be accessed by local or remote clients through a business interface or a home interface. A business interface defines the business methods of the bean, while a home interface defines the methods for creating, finding, and removing the bean instances. A stateful session bean can also expose a web service endpoint by annotating the bean class or the business interface with @WebService.
