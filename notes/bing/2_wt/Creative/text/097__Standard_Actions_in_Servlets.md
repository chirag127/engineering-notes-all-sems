#### Standard Actions in Servlets

- Standard actions are predefined tags that perform some common tasks in servlets, such as including other resources, forwarding requests, or handling errors.
- Standard actions start with `<jsp:` and end with `/>`. They have attributes that specify the parameters for the action.
- Some of the standard actions are:

  - `<jsp:include>`: This action includes the output of another resource, such as a servlet, JSP page, or HTML file, in the current JSP page. It has two attributes: `page`, which specifies the relative URL of the resource to be included, and `flush`, which indicates whether the output buffer should be flushed before including the resource. The default value of `flush` is `false`.
  - `<jsp:forward>`: This action forwards the current request to another resource, such as a servlet, JSP page, or HTML file. It has one attribute: `page`, which specifies the relative URL of the resource to be forwarded to. The action terminates the execution of the current JSP page and transfers the control to the forwarded resource.
  - `<jsp:param>`: This action is used to pass parameters to the `<jsp:include>` or `<jsp:forward>` actions. It has two attributes: `name`, which specifies the name of the parameter, and `value`, which specifies the value of the parameter. The action must be nested inside the `<jsp:include>` or `<jsp:forward>` tags.
  - `<jsp:plugin>`: This action generates the necessary HTML code to invoke a Java applet or a JavaBean component in the browser. It has several attributes, such as `type`, `code`, `codebase`, `width`, `height`, etc., that specify the details of the applet or the component. The action can also have nested `<jsp:params>` tags to pass parameters to the applet or the component.
  - `<jsp:useBean>`: This action creates or locates a JavaBean component and associates it with a scripting variable. It has four attributes: `id`, which specifies the name of the scripting variable, `class`, which specifies the fully qualified name of the JavaBean class, `scope`, which specifies the scope of the bean (page, request, session, or application), and `beanName`, which specifies the name of the bean as a String or a runtime expression. The action can also have a body that contains `<jsp:setProperty>` or `<jsp:getProperty>` tags to set or get the properties of the bean.
  - `<jsp:setProperty>`: This action sets the value of a property of a JavaBean component. It has three attributes: `name`, which specifies the name of the scripting variable that references the bean, `property`, which specifies the name of the property to be set, and `value`, which specifies the value of the property as a String or a runtime expression. The action can also use the `param` attribute to set the property value from a request parameter with the same name as the property.
  - `<jsp:getProperty>`: This action gets the value of a property of a JavaBean component and writes it to the output. It has two attributes: `name`, which specifies the name of the scripting variable that references the bean, and `property`, which specifies the name of the property to be retrieved.
