### Session Tracking with Http Session in Servlets

- Session tracking is a mechanism to maintain the state of a user across multiple requests.
- Http session is one of the ways to implement session tracking in servlets.
- Http session is an object that represents a unique session between a client and a server.
- Http session is created by the server and assigned to the client when the client makes the first request to the server.
- Http session is identified by a session ID, which is a unique string generated by the server and sent to the client as a cookie or a URL parameter.
- Http session can store attributes, which are key-value pairs of data that can be accessed by the servlets within the same session.
- Http session has a timeout period, which is the maximum time interval between two consecutive requests from the same client. If the timeout period expires, the session is invalidated by the server and the attributes are discarded.
- Http session can be manipulated by the servlets using the methods of the javax.servlet.http.HttpSession interface, such as:
  - getId(): returns the session ID of the session.
  - getCreationTime(): returns the time when the session was created.
  - getLastAccessedTime(): returns the time when the session was last accessed by the client.
  - getMaxInactiveInterval(): returns the timeout period of the session in seconds.
  - setMaxInactiveInterval(int interval): sets the timeout period of the session in seconds.
  - getAttribute(String name): returns the value of the attribute with the given name, or null if not found.
  - setAttribute(String name, Object value): sets the value of the attribute with the given name and value.
  - removeAttribute(String name): removes the attribute with the given name from the session.
  - invalidate(): invalidates the session and removes all the attributes.
  - isNew(): returns true if the session is new, i.e., the client has not yet received the session ID, or false otherwise.
