### Static Testing Strategies in Software Testing

Static testing is a software testing method that examines a program and its associated documents without executing the code. It is used to find and remove errors and ambiguities in the software development process at an early stage. It also helps to improve the quality and efficiency of software products.

There are two main types of static testing techniques:

- Review: This is a manual examination of the software artifacts, such as requirements, design, code, and test cases, to find defects and inconsistencies. Review can be done by the author of the artifact, by peers, by experts, or by customers. Review can be formal, informal, walkthrough, inspection, or audit, depending on the level of rigor and documentation required.
- Static analysis: This is an automated analysis of the software code using tools to detect defects, vulnerabilities, code smells, and other quality issues. Static analysis can be done by compilers, code analyzers, code metrics, code coverage, and code standards tools. Static analysis can help to enforce coding standards, improve code readability, optimize code performance, and prevent security breaches.
