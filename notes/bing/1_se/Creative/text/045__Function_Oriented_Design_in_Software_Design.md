#### Function Oriented Design in Software Design

- Function Oriented Design is an approach to software design where the design is decomposed into a set of interacting units or modules where each unit or module has a clearly defined function  .
- The main focus of Function Oriented Design is on the functions or operations that the software performs, rather than the data or objects that it manipulates.
- Function Oriented Design is based on the principle of top-down decomposition, where the system is divided into smaller and simpler sub-systems, and each sub-system is further divided into smaller and simpler modules, until the modules are simple enough to be implemented.
- Function Oriented Design uses various notations and diagrams to represent the functional structure and behavior of the software, such as:
  - Data Flow Diagrams (DFDs): DFDs show the flow of data and control among the modules and external entities .
  - Data Dictionaries: Data dictionaries store information about the data items defined in the DFDs, such as their names, types, formats, sources, destinations, etc.
  - Structure Charts: Structure Charts show the hierarchical relationship and communication among the modules .
  - Pseudo-code: Pseudo-code is a textual representation of the algorithm or logic of a module.
- Function Oriented Design has some advantages, such as:
  - It is easy to understand and communicate, as it uses natural language and graphical notations.
  - It is suitable for small and simple systems that have well-defined functions and data flows.
  - It supports modularization and reusability of code, as the modules can be tested and maintained independently.
- Function Oriented Design also has some disadvantages, such as:
  - It does not capture the data abstraction and encapsulation aspects of the software, as it does not focus on the data or objects that the software manipulates.
  - It does not support inheritance and polymorphism, which are the key features of object-oriented design.
  - It may lead to poor design quality and performance, as the modules may have high coupling and low cohesion, which means that they depend on each other too much and do not perform a single function well.
