### Unit Testing in Software Testing

- Unit testing is a type of software testing that focuses on verifying the functionality and quality of individual units of code, such as functions, methods, classes, or modules.
- Unit testing is usually performed by the developers who write the code, using tools and frameworks that automate the execution and verification of test cases.
- Unit testing helps to ensure that each unit of code works as expected, and to detect and fix errors or bugs at an early stage of development.
- Unit testing also facilitates code refactoring, debugging, integration, and maintenance, by providing a reliable and fast way to verify the correctness of the code.
- Unit testing follows the principle of "test early, test often", and is typically integrated into the software development process as part of an agile or iterative methodology.
- Unit testing can be done in various ways, such as using assertions, mock objects, stubs, test doubles, or code coverage tools.
- Unit testing can be classified into two categories: black-box testing and white-box testing.
  - Black-box testing treats the unit of code as a black box, and only tests its inputs and outputs, without knowing its internal structure or logic.
  - White-box testing examines the unit of code as a white box, and tests its internal structure, logic, and branches, using the knowledge of the code implementation.
- Unit testing can be further divided into positive testing and negative testing.
  - Positive testing verifies that the unit of code behaves correctly when given valid inputs and expected scenarios.
  - Negative testing checks that the unit of code handles invalid inputs, errors, exceptions, and unexpected scenarios gracefully.
