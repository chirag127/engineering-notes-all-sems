#### Flow Charts in Software Design

- A flow chart is a graphical or symbolic representation of a process or an algorithm that shows the steps, decisions, and data flows involved in solving a problem or achieving a goal .
- Flow charts are useful in software design because they can help in planning, documenting, testing, debugging, and communicating the logic and structure of a program or an algorithm .
- Flow charts use standard symbols and shapes to represent different types of actions, inputs, outputs, and conditions in a process or an algorithm . Some of the common symbols are:

| Symbol | Meaning |
|:------:|:-------:|
| ![Oval](https://upload.wikimedia.org/wikipedia/commons/thumb/0/0e/Flowchart_Symbol_Start_End.svg/1200px-Flowchart_Symbol_Start_End.svg.png) | Start or end of a process or an algorithm |
| ![Rectangle](https://upload.wikimedia.org/wikipedia/commons/thumb/3/3b/Flowchart_Symbol_Process.svg/1200px-Flowchart_Symbol_Process.svg.png) | A step or an action to be performed |
| ![Diamond](https://upload.wikimedia.org/wikipedia/commons/thumb/9/91/Flowchart_Symbol_Decision.svg/1200px-Flowchart_Symbol_Decision.svg.png) | A decision or a branching point with two or more possible outcomes |
| ![Parallelogram](https://upload.wikimedia.org/wikipedia/commons/thumb/4/4d/Flowchart_Symbol_Input_Output.svg/1200px-Flowchart_Symbol_Input_Output.svg.png) | An input or an output of data or information |
| ![Arrow](https://upload.wikimedia.org/wikipedia/commons/thumb/2/2e/Flowchart_Symbol_Connector.svg/1200px-Flowchart_Symbol_Connector.svg.png) | A direction or a flow of control |

- Flow charts can be drawn using various software tools, such as Lucidchart, Textografo, Visio, etc. that offer features like drag-and-drop, text-based, or template-based flowchart creation   .
- Flow charts can be used to design different types of software processes or algorithms, such as:

  - Sequential processes or algorithms that follow a linear order of steps or actions, such as calculating the factorial of a number, sorting an array, etc.
  - Conditional processes or algorithms that involve branching or looping based on certain conditions or criteria, such as finding the maximum element in an array, checking if a number is prime, etc.
  - Parallel processes or algorithms that involve concurrent or simultaneous execution of multiple steps or actions, such as multithreading, multiprocessing, etc.
