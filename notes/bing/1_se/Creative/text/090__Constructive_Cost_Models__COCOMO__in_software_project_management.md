### Constructive Cost Models (COCOMO) in software project management

- Constructive Cost Models (COCOMO) are a set of algorithms and equations that estimate the effort, cost and schedule of software projects based on various inputs and assumptions.
- COCOMO was developed by Barry Boehm in 1981 and has been revised and updated over the years to reflect the changes in software engineering practices and technologies.
- COCOMO consists of three levels of models: basic, intermediate and detailed, each with increasing accuracy and complexity.
- The basic COCOMO model estimates the effort and duration of a software project based on the size of the software product measured in lines of code (LOC) or function points (FP) and a mode of development (organic, semi-detached or embedded).
- The intermediate COCOMO model refines the basic model by introducing a set of cost drivers that account for various factors that affect the productivity and quality of software development, such as personnel capability, experience, complexity, reliability, etc.
- The detailed COCOMO model further refines the intermediate model by dividing the software product into different components or modules and applying different cost drivers and effort multipliers to each component based on its characteristics and dependencies.
- COCOMO can be used for planning, budgeting, monitoring and controlling software projects, as well as for comparing and evaluating alternative software development methods and tools.
