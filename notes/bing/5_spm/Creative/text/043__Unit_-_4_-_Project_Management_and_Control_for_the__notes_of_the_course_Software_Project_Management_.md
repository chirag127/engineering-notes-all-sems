## Unit - 4 - Project Management and Control

- Project management and control is the process of planning, organizing, directing, monitoring and controlling the activities and resources of a software project to achieve its objectives within the constraints of scope, time, cost and quality.
- Project management and control involves the following activities:
  - Defining the project scope, objectives, deliverables, stakeholders and success criteria.
  - Developing the project management plan, which includes the project schedule, budget, risk management plan, quality management plan, communication plan, procurement plan and other subsidiary plans.
  - Executing the project management plan, which involves coordinating and managing the project team, stakeholders, resources, tasks, deliverables and changes.
  - Monitoring and controlling the project performance, which involves measuring and reporting the project progress, variances, issues, risks, quality and changes, and taking corrective and preventive actions as needed.
  - Closing the project, which involves finalizing and delivering the project outputs, evaluating the project outcomes, documenting the project lessons learned, and releasing the project resources.
- Project management and control requires the use of various tools and techniques, such as:
  - Work breakdown structure (WBS), which is a hierarchical decomposition of the project scope into manageable and measurable work packages and tasks.
  - Gantt chart, which is a graphical representation of the project schedule, showing the start and finish dates, durations, dependencies and milestones of the project tasks and work packages.
  - Critical path method (CPM), which is a technique for identifying the longest sequence of dependent tasks that determines the minimum possible duration of the project.
  - Earned value management (EVM), which is a technique for measuring the project performance in terms of the value of the work completed, the planned value of the work scheduled, and the actual cost of the work performed.
  - Risk register, which is a document that records the identified risks, their probability and impact, their risk response strategies, and their current status and ownership.
  - Quality assurance (QA) and quality control (QC), which are processes for ensuring that the project outputs meet the quality standards and requirements of the project stakeholders.
  - Change management, which is a process for managing the changes that occur during the project life cycle, including the changes in the project scope, schedule, cost, quality, resources and stakeholders.
  - Stakeholder management, which is a process for identifying, analyzing, engaging and communicating with the project stakeholders, and managing their expectations and interests.
