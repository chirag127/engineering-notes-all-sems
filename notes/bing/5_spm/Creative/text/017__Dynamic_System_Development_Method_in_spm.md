### Dynamic System Development Method in spm

- Dynamic System Development Method (DSDM) is an agile project delivery framework, initially used as a software development method.
- DSDM provides a framework of controls and best practices for Rapid Application Development (RAD), which is a software development approach that emphasizes speed and flexibility.
- DSDM is based on the following principles :
  - Focus on the business need: The project should deliver what the business requires, not what the technical team prefers.
  - Deliver on time: The project should respect the agreed deadlines and budgets, using timeboxes and prioritization techniques.
  - Collaborate: The project should involve active participation and feedback from all stakeholders, including users, developers, managers, and testers.
  - Never compromise quality: The project should ensure that the quality of the deliverables meets the agreed standards and expectations, using testing and review processes.
  - Build incrementally from firm foundations: The project should start with a clear and stable vision and scope, and then deliver the system in small and frequent increments, based on user feedback and changing requirements.
  - Develop iteratively: The project should use an iterative and adaptive approach, where each iteration produces a working and tested system that can be evaluated and improved.
  - Communicate continuously and clearly: The project should use effective and transparent communication methods, such as workshops, meetings, demonstrations, and documentation, to share information and knowledge among the project team and stakeholders.
  - Demonstrate control: The project should use appropriate management and governance structures, such as roles, responsibilities, plans, and reports, to monitor and control the project progress and quality.
- DSDM consists of the following phases :
  - Pre-project: This phase involves the identification and selection of the project, based on the business case and feasibility analysis.
  - Feasibility: This phase involves the exploration and validation of the project scope, objectives, constraints, and risks, as well as the development of a high-level plan and prototype.
  - Foundations: This phase involves the definition and agreement of the project vision, scope, architecture, priorities, and timeboxes, as well as the establishment of the project team and governance.
  - Evolutionary Development: This phase involves the iterative and incremental delivery of the system, based on the user requirements and feedback, using timeboxed iterations and testing cycles.
  - Deployment: This phase involves the delivery and acceptance of the system by the users and the business, as well as the preparation and execution of the deployment plan and activities.
  - Post-project: This phase involves the review and evaluation of the project outcomes and benefits, as well as the identification and implementation of the lessons learned and best practices.
