Resource allocation in SPM (software project management) is the process of assigning and scheduling available resources in the most effective and economical way possible. Resources include staff, budgets, materials, and equipment needed for the successful completion of a project .

The following diagram illustrates the basic architecture of resource allocation in SPM using ASCII characters:

### Resource Allocation in SPM

```
+------------------+      +------------------+      +------------------+
|                  |      |                  |      |                  |
|  Project Scope   |----->| Resource Demand  |----->| Resource Supply  |
|                  |      |                  |      |                  |
+------------------+      +------------------+      +------------------+
       |                         |                         |
       |                         |                         |
       |                         |                         |
       V                         V                         V
+------------------+      +------------------+      +------------------+
|                  |      |                  |      |                  |
|  Work Breakdown  |----->| Resource Plan    |----->| Resource Pool    |
|  Structure (WBS) |      |                  |      |                  |
+------------------+      +------------------+      +------------------+
       |                         |                         |
       |                         |                         |
       |                         |                         |
       V                         V                         V
+------------------+      +------------------+      +------------------+
|                  |      |                  |      |                  |
|  Task List       |----->| Resource Schedule|----->| Resource Tracking|
|                  |      |                  |      |                  |
+------------------+      +------------------+      +------------------+
```

The diagram shows the following steps:

- The project scope defines the goals, deliverables, and requirements of the project.
- The resource demand estimates the amount and type of resources needed for the project.
- The resource supply identifies the availability and cost of resources from internal and external sources.
- The work breakdown structure (WBS) decomposes the project scope into manageable tasks and subtasks.
- The resource plan assigns resources to each task and subtask based on the resource demand and supply.
- The resource pool is the collection of all resources that can be used for the project.
- The resource schedule allocates resources to specific time slots and durations based on the resource plan and the project timeline.
- The resource tracking monitors and reports the actual usage and performance of resources against the resource schedule.
