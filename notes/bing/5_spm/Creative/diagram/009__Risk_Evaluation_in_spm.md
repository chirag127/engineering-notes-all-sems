Risk evaluation is an important part of the Software Project Management (SPM) process. It is used to identify potential risks and to assess their impact on the project. The risk evaluation process consists of four steps: analyzing the project environment, identifying risks, assigning risk ratings, and creating a risk management plan.

The following diagram illustrates the basic steps of risk evaluation in SPM using ASCII art:

```
+---------------------+      +---------------------+      +---------------------+      +---------------------+
| Analyze project     |      | Identify risks      |      | Assign risk ratings |      | Create risk         |
| environment         |----->|                     |----->|                     |----->| management plan     |
+---------------------+      +---------------------+      +---------------------+      +---------------------+
| - Scope             |      | - Technical risks   |      | - Probability       |      | - Risk avoidance    |
| - Stakeholders      |      | - Business risks    |      | - Impact            |      | - Risk mitigation   |
| - Resources         |      | - Organizational    |      | - Priority          |      | - Risk transfer     |
| - Constraints       |      |   risks             |      |                     |      | - Risk monitoring   |
| - Assumptions       |      | - External risks    |      |                     |      | - Risk contingency  |
+---------------------+      +---------------------+      +---------------------+      +---------------------+
```
