Management control in software project management is the process of monitoring and controlling project activities to ensure the project meets its goals and stays on budget. It involves setting performance targets, measuring progress towards those targets, and taking corrective action to ensure the project is on track.

The diagram shows the following steps:

- Project plan: The project plan defines the scope, objectives, schedule, budget, and deliverables of the project. It also identifies the risks, assumptions, and constraints that may affect the project.
- Project metrics: The project metrics are the quantitative and qualitative measures that are used to track the progress and performance of the project. They include cost, time, quality, scope, and customer satisfaction metrics.
- Project reports: The project reports are the documents that communicate the status and results of the project to the stakeholders. They include status reports, progress reports, variance reports, and final reports.
- Project management: The project management is the application of knowledge, skills, tools, and techniques to plan, execute, monitor, and control the project activities. It involves initiating, planning, executing, monitoring and controlling, and closing the project phases.
- Project measurement: The project measurement is the process of collecting, analyzing, and reporting the project metrics. It involves defining, selecting, collecting, validating, and reporting the project metrics.
- Project evaluation: The project evaluation is the process of assessing the project performance and outcomes against the project plan and metrics. It involves comparing the actual results with the planned results, identifying the variances, and evaluating the customer satisfaction.
- Project execution: The project execution is the process of performing the project tasks and producing the project deliverables. It involves coordinating, directing, and managing the project resources, processes, and outputs.
- Project monitoring: The project monitoring is the process of tracking and reviewing the project progress and performance. It involves measuring, recording, and reporting the project metrics, identifying the issues and risks, and communicating the project status and results.
- Project control: The project control is the process of ensuring the project stays on track and meets its goals and objectives. It involves analyzing the project variances, taking corrective and preventive actions, and updating the project plan and metrics.
