Decision making in software product management (SPM) is the process of choosing among different alternatives to achieve the best outcomes for the product and the organization. SPM decisions can be classified into three levels: strategic, tactical and operational. Each level has different goals, criteria, methods and challenges. The following diagram illustrates the basic architecture of a decision making in SPM using ASCII characters:

```

|                   |      |                   |      |                   |

|                   |      |                   |      |                   |
```
