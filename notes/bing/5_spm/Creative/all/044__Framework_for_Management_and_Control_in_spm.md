### Framework for Management and Control in spm

- Framework for Management and Control in spm is a set of processes and tools that help software project managers to monitor and control the project activities and outcomes.
- The main objectives of the framework are to ensure that the project meets its goals, stays on budget, and delivers quality software products to the customers.
- The framework consists of four main components  :
  - Creating Framework: This involves defining the project scope, objectives, deliverables, milestones, tasks, resources, risks, and quality standards. It also involves establishing the project organization, communication, and reporting mechanisms.
  - Collecting Data: This involves gathering and recording the project data, such as the actual work done, the actual cost incurred, the actual quality achieved, and the actual issues and changes encountered. The data can be collected from various sources, such as project team members, customers, stakeholders, and tools.
  - Visualizing Progress: This involves analyzing and presenting the project data in a clear and concise way, such as using charts, graphs, tables, dashboards, and reports. The visualization helps to compare the actual project performance with the planned or expected performance, and to identify any deviations, trends, or patterns.
  - Cost Monitoring: This involves tracking and controlling the project cost, such as the budget, the expenses, the revenue, and the profit. It also involves using techniques such as earned value management (EVM) to measure the project value and progress in terms of cost and schedule.
  - Prioritizing Monitoring: This involves focusing on the most critical and important aspects of the project, such as the scope, the quality, the risks, and the customer satisfaction. It also involves using techniques such as risk management, quality management, and stakeholder management to manage and mitigate the potential threats and issues that may affect the project success.
  - Getting Project Back to Target: This involves taking corrective and preventive actions to address the project problems and deviations, and to bring the project back on track. It also involves using techniques such as change management, configuration management, and issue management to handle and document the changes and issues that may arise during the project execution.
  - Change Control: This involves managing and controlling the changes that may occur in the project scope, requirements, design, implementation, testing, deployment, or maintenance. It also involves using techniques such as change request, change impact analysis, change approval, change implementation, and change verification to ensure the changes are justified, authorized, implemented, and verified.
  - Managing Contracts: This involves managing and controlling the contracts that may exist between the project and the external parties, such as the customers, the suppliers, the subcontractors, or the partners. It also involves using techniques such as contract types, contract stages, contract terms, and contract administration to ensure the contracts are clear, fair, and compliant.

- A possible mnemonic to remember the components of the framework is **CCVP CGCM** (Creating, Collecting, Visualizing, Prioritizing, Cost, Getting, Change, Managing).
- A possible learning trick to understand the framework is to use a project management software tool, such as Microsoft Project, that can help to create, collect, visualize, and monitor the project data and activities. The tool can also help to perform cost, risk, quality, change, and contract management functions.
