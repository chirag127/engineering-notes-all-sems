### COCOMO II in spm

- COCOMO II stands for **COnstructive COst MOdel II** and is a model that allows one to estimate the cost, effort, and schedule when planning a new software development activity.
- COCOMO II is the revised version of the original COCOMO (COCOMO 81) model published in 1981. It is developed at the University of Southern California.
- COCOMO II is designed to address software development practices in the 1990s and 2000s, such as rapid application development, reuse, re-engineering, and object-oriented development.
- COCOMO II consists of three sub-models:
  - **Application Composition Model**: This model is used for projects that are based on rapid application development using graphical user interface builders, code generators, or other composition tools. It estimates the effort based on the number of object points, which are a measure of the functionality and complexity of the software components.
  - **Early Design Model**: This model is used for projects that are in the early stages of design, where the requirements are not fully defined and the architecture is not yet decided. It estimates the effort based on the size of the software in terms of unadjusted function points, which are a measure of the user functions and data processed by the software. It also considers the product, platform, personnel, and project attributes that affect the productivity and quality of the software.
  - **Post-Architecture Model**: This model is used for projects that have a defined architecture and a detailed design. It estimates the effort based on the size of the software in terms of source lines of code, which are a measure of the physical volume of the software. It also considers the cost drivers that affect the effort, such as the required reliability, complexity, reuse, documentation, and team experience.
- COCOMO II uses the following formula to estimate the effort in person-months (PM):
  - PM = A * Size^E * M
  - Where:
    - A is a constant that depends on the sub-model used
    - Size is the size of the software in object points, function points, or source lines of code
    - E is an exponent that depends on the sub-model used and the scale factors that reflect the project characteristics
    - M is a multiplier that depends on the cost drivers that affect the effort
- COCOMO II uses the following formula to estimate the schedule in months (TDEV):
  - TDEV = 3 * (PM)^F
  - Where:
    - PM is the effort in person-months
    - F is an exponent that depends on the sub-model used and the scale factors that reflect the project characteristics
- COCOMO II also provides a range of estimates for the effort and schedule based on different levels of confidence, such as most likely, optimistic, and pessimistic.
- COCOMO II is a simple and well-tested model that provides about 20% cost and 70% time estimate accuracy. It can be calibrated and tailored to specific organizations and projects using historical data and expert judgment.
- COCOMO II is useful for estimating the cost, effort, and schedule of software projects of different types, sizes, and complexities. It can also be used for comparing alternative design and development strategies, and for planning and managing software projects.
