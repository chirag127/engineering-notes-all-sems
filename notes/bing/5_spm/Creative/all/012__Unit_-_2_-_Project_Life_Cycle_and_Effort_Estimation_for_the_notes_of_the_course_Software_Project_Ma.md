## Unit - 2 - Project Life Cycle and Effort Estimation for the notes of the course Software Project Management

- Project life cycle is the sequence of phases that a project goes through from its initiation to its closure. It provides a framework for managing the project activities and deliverables. 
- Project life cycle can vary depending on the type, size, scope, and complexity of the project. However, a common project life cycle model consists of four phases: initiating, planning, executing, and closing. 
- Initiating phase is where the project is defined, authorized, and funded. It involves identifying the project objectives, scope, stakeholders, risks, assumptions, and constraints. It also involves selecting the project manager and the project team, and developing the project charter. 
- Planning phase is where the project is planned in detail, including the scope, schedule, budget, quality, resources, communication, risk, procurement, and stakeholder management plans. It also involves defining the project deliverables, milestones, tasks, dependencies, and baselines. 
- Executing phase is where the project deliverables are produced, monitored, and controlled. It involves executing the project plans, managing the project team, performing quality assurance, communicating with stakeholders, managing risks, and procuring resources. 
- Closing phase is where the project is finalized, reviewed, and closed. It involves delivering the project deliverables to the customer, obtaining the customer acceptance, conducting the project evaluation, performing the lessons learned, releasing the project resources, and archiving the project documents. 

- Effort estimation is the process of predicting how much time, energy, or money a project or a task will require. It is used to help draft project plans and budgets, allocate resources, monitor progress, and control costs. 
- Effort estimation can be done at different levels of detail and accuracy, depending on the stage of the project and the availability of information. It can be done at the project level, the phase level, the deliverable level, or the task level. 
- Effort estimation can be done using various methods and techniques, such as expert judgment, analogy, parametric, bottom-up, top-down, three-point, or Delphi. Each method has its own advantages and disadvantages, and the choice of the method depends on the project characteristics, the estimator's experience, and the stakeholder's expectations.  
- Effort estimation can be improved by using historical data, applying estimation standards, involving multiple experts, adjusting for risks and uncertainties, and updating the estimates regularly. It can also be improved by using tools and software that can automate and facilitate the estimation process.
