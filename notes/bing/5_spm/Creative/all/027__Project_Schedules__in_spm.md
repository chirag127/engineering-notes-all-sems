### Project Schedules in spm

- Project schedules are the core of the project plan. They show how the work will be performed, who will do it, when it will be done, and what resources are needed. 
- Project schedules are created and tracked with project scheduling software, which has features that allow project managers to monitor the progress of tasks, resources and costs in real time. 
- Project schedules are based on the project scope, the work breakdown structure (WBS), the activity list, the activity attributes, the resource requirements, the resource calendars, the activity duration estimates, and the project management plan. 
- Project schedules use different techniques to represent the sequence and dependencies of activities, such as network diagrams, Gantt charts, milestone charts, and critical path method (CPM).  
- Project schedules are subject to change due to various factors, such as risks, issues, changes, delays, and uncertainties. Project managers need to update and communicate the project schedule regularly to stakeholders and team members.  
- Project schedules are part of the schedule management plan (SMP), which is a document that details how the project schedule will be created, managed, and monitored. The SMP includes information about the scheduling methodology, tools, processes, roles, responsibilities, and performance measures. 

Some mnemonics and learning tricks for project schedules in spm are:

- To remember the inputs of project schedule development, use the acronym **SWARADP** (Scope, WBS, Activity list, Resource requirements, Activity attributes, Duration estimates, Project management plan).
- To remember the tools and techniques of project schedule development, use the acronym **NAPES** (Network diagrams, Activity resource estimating, Parametric estimating, Expert judgment, Scheduling software).
- To remember the outputs of project schedule development, use the acronym **SAC** (Schedule baseline, Activity attributes updates, Change requests).
- To remember the four types of dependencies between activities, use the acronym **FSLS** (Finish-to-start, Start-to-start, Finish-to-finish, Start-to-finish).
- To remember the six steps of creating a schedule management plan, use the acronym **DAMPER** (Define, Analyze, Monitor, Perform, Evaluate, Report).
