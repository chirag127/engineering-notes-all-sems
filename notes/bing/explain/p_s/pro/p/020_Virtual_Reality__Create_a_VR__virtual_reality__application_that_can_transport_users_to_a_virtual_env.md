Virtual reality (VR) is a simulated experience that employs pose tracking and 3D near-eye displays to give the user an immersive feel of a virtual world. VR applications immerse the user in a computer-generated environment that simulates reality through the use of interactive devices, such as controllers, gloves, headsets and sensors . VR can be used for entertainment (particularly video games), education (such as medical or military training) and business (such as virtual meetings).

To create a VR application that can transport users to a virtual environment and allow them to interact with it, you will need some technologies such as Unity, VRTK, Oculus SDK, HTC Vive SDK and C. Unity is a cross-platform game engine that allows you to create 3D scenes and assets for your VR application. VRTK is a collection of scripts and prefabs that simplify the development of VR interactions and locomotion. Oculus SDK and HTC Vive SDK are software development kits that provide access to the features and functionality of their respective VR headsets . C is a programming language that you can use to write scripts for your VR application logic and behavior.
