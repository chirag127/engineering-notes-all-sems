Augmented Reality: Create an AR (augmented reality) application that can display digital objects in the real world and interact with them. Technologies: Unity, ARKit, ARCore, Vuforia, C#.

Some examples of AR applications using Unity are:

- **AR Foundation Samples**: A collection of example scenes that demonstrate the features of AR Foundation, such as plane detection, image tracking, face tracking, light estimation and more. You can download the project from GitHub and modify or copy the code into your own project.
- **AR Weather app**: An app that uses OpenWeatherMap API to display weather information on a virtual screen in AR. You can also use light estimation to adjust the brightness of the screen according to the real world lighting conditions.
- **AR Portal**: An app that creates a portal effect in AR, where you can walk through a doorway and enter a different environment. You can use occlusion shaders to make the portal look realistic and interact with virtual objects inside it.
- **AR Business Card**: An app that scans a business card and displays additional information about the person or company on top of it. You can use image tracking to recognize the card and anchor the content to it.

These are just some examples of what you can create with Unity and AR technologies. You can find more tutorials and resources on Unity's website  or online communities. I hope this helps you get started with your AR project! 😊
