### Automata

- Automata are abstract machines that can perform computations on inputs and produce outputs.
- Automata theory is the study of the properties and limitations of different types of automata, as well as the computational problems that can be solved using them.
- Automata theory is a branch of theoretical computer science that has applications in areas such as compiler design, formal verification, artificial intelligence, cryptography, and natural language processing.
- The word automata comes from the Greek word αὐτόματος, which means "self-acting, self-willed, self-moving".
- There are different classes of automata, depending on the type and amount of memory they have, the number and type of states they can be in, and the type of input and output they can handle.
- Some of the most common types of automata are:

  - Finite automata (FA): These are the simplest type of automata, which have a finite number of states and can only process finite inputs. They can be either deterministic (DFA) or nondeterministic (NFA), depending on whether they have a unique or multiple possible transitions for each state and input symbol. FA can recognize regular languages, which are the languages that can be defined by regular expressions.
  - Pushdown automata (PDA): These are automata that have a finite number of states and a stack, which is a type of memory that can store and retrieve symbols in a last-in first-out (LIFO) manner. They can process inputs that have a nested structure, such as parentheses or brackets. PDA can recognize context-free languages, which are the languages that can be defined by context-free grammars.
  - Linear bounded automata (LBA): These are automata that have a finite number of states and a tape, which is a type of memory that can store and retrieve symbols in a random-access manner. However, the tape is bounded by the length of the input, so the automaton can only use a linear amount of space. LBA can recognize context-sensitive languages, which are the languages that can be defined by context-sensitive grammars.
  - Turing machines (TM): These are the most powerful type of automata, which have a finite number of states and a tape, which is unbounded in both directions. They can perform any computation that is algorithmically possible, given enough time and space. TM can recognize recursively enumerable languages, which are the languages that can be generated by a TM. However, not all recursively enumerable languages are decidable, meaning that there may not exist a TM that can always halt and give a yes or no answer for any input. The halting problem is an example of an undecidable problem.

Some possible mnemonics and learning tricks for the topic are:

- To remember the hierarchy of automata and languages, you can use the acronym **FPLC** (Finite, Pushdown, Linear, Turing), which sounds like "flip".
- To remember the difference between deterministic and nondeterministic automata, you can use the analogy of a **maze**. A deterministic automaton is like a person who follows a single path in the maze, while a nondeterministic automaton is like a person who can split into multiple copies and explore different paths at the same time.
- To remember the difference between a stack and a tape, you can use the analogy of a **book**. A stack is like a book that you can only open from the last page and read or write on it, while a tape is like a book that you can open from any page and read or write on it.
