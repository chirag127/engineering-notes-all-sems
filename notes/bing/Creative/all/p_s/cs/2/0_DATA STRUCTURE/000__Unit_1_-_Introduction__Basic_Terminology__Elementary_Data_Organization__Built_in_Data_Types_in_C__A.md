- **Basic Terminology**:
  - **Data**: Data refers to a value or set of values.
  - **Data item**: Data item refers to a single or group of values within the data. E.g. Marks obtained by the students.
  - **Entity**: An entity is a thing that has some properties which can take values.
  - **Attribute**: An attribute is a property of an entity. E.g. Name, Roll number, Age, etc.
  - **Record**: A record is a collection of related attributes of an entity. E.g. Student record.
  - **File**: A file is a collection of related records of one or more entities. E.g. Student file.
  - **Data structure**: A data structure is a way of organizing data items that considers not only the elements stored but also their relationship to each other. E.g. Array, Linked list, Stack, Queue, etc.
  - **Abstract Data Type (ADT)**: An ADT is a mathematical model for a certain class of data structures that have similar behavior. An ADT specifies the logical operations that can be performed on the data, without defining the implementation details. E.g. Stack ADT, Queue ADT, etc.

- **Elementary Data Organization**:
  - **Primitive data organization**: The data items are not divided into smaller sub-items. E.g. Integer, Float, Character, etc.
  - **Non-primitive data organization**: The data items are divided into smaller sub-items. E.g. Array, Structure, Union, etc.
  - **Linear data organization**: The data items are arranged in a linear sequence, where each item has a unique successor and predecessor, except the first and last item. E.g. Array, Linked list, Stack, Queue, etc.
  - **Non-linear data organization**: The data items are not arranged in a linear sequence, and each item may have more than one successor or predecessor. E.g. Tree, Graph, etc.

- **Built in Data Types in C** :
  - **char**: It is the most basic data type in C. It stores a single character and requires a single byte of memory in almost all compilers. Range: (-128 to 127) or (0 to 255) Size: 1 byte Format Specifier: %c
  - **int**: It is used to store an integer (whole number). It requires 2 or 4 bytes of memory, depending on the compiler. Range: -32,768 to 32,767 or -2,147,483,648 to 2,147,483,647 Size: 2 or 4 bytes Format Specifier: %d
  - **float**: It is used to store a floating-point number (decimal number). It requires 4 bytes of memory. Range: 3.4E-38 to 3.4E+38 Size: 4 bytes Format Specifier: %f
  - **double**: It is used to store a double-precision floating-point number. It requires 8 bytes of memory. Range: 1.7E-308 to 1.7E+308 Size: 8 bytes Format Specifier: %lf
  - **void**: It is used to specify that a function does not return any value or that a pointer does not point to any specific type. Size: N/A Format Specifier: N/A

Mnemonics are techniques that help you remember information by associating it with something else, such as words, sounds, images, or feelings. They can be very useful for learning new topics, especially if they are creative, funny, or meaningful to you. Some examples of mnemonics are:

- Acronyms: using the first letter of each word in a phrase or list to form a new word, such as ROYGBIV for the colors of the rainbow (red, orange, yellow, green, blue, indigo, violet).
- Acrostics: using the first letter of each word in a phrase or list to form a sentence, such as Every Good Boy Deserves Fudge for the notes on the treble clef (E, G, B, D, F).
- Rhymes: using words that sound alike to help you remember something, such as In 1492, Columbus sailed the ocean blue.
- Images: using pictures or symbols to represent something, such as drawing a fish to remember the word piscine (French for fish).
- Stories: using a narrative or a sequence of events to help you remember something, such as the story of King Henry VIII and his six wives (divorced, beheaded, died, divorced, beheaded, survived).

To use mnemonics effectively, you should follow these guidelines:

- Choose the appropriate mnemonic for your situation. For example, if your goal is to learn how to spell a word, you may want to use the spelling mnemonic technique.
- Practice the technique. You may want to practice your mnemonic several times to help you remember it.
- Repeat the mnemonic to others. This can help you reinforce your memory and also share your knowledge with others.
