### Elementary Data Organization

- Elementary data organization is the way of arranging and storing data in a computer system for efficient access and manipulation.
- Data are simply values or sets of values that represent some information. A single unit of value is called a data item. For example, a student's name, roll number, marks, etc. are data items.
- Data items are divided into subgroups called group items. For example, a student's personal details, academic details, etc. are group items.
- An entity is something that has certain attributes or properties that can take values. For example, a student is an entity that has attributes like name, roll number, marks, etc.
- An entity set is a collection of entities that have similar attributes. For example, a class of students is an entity set that has attributes like name, roll number, marks, etc.
- A data type is a classification of data that defines the possible values, operations, and representation of data. For example, int, char, float, etc. are data types in C language.
- A data structure is a logical or mathematical arrangement of data that defines the way of storing and accessing data. For example, array, linked list, stack, queue, tree, etc. are data structures.
- A data structure can be classified into two categories: primitive and non-primitive.
  - Primitive data structures are the built-in data types that are supported by the programming language. For example, int, char, float, etc. are primitive data structures in C language.
  - Non-primitive data structures are the user-defined data types that are derived from the primitive data structures. For example, array, linked list, stack, queue, tree, etc. are non-primitive data structures in C language.
- A data structure can also be classified into two categories: linear and non-linear.
  - Linear data structures are the data structures that store and access data in a sequential manner. For example, array, linked list, stack, queue, etc. are linear data structures.
  - Non-linear data structures are the data structures that store and access data in a non-sequential manner. For example, tree, graph, etc. are non-linear data structures.
- A data structure can also be classified into two categories: static and dynamic.
  - Static data structures are the data structures that have a fixed size and memory allocation at compile time. For example, array is a static data structure in C language.
  - Dynamic data structures are the data structures that have a variable size and memory allocation at run time. For example, linked list, stack, queue, tree, etc. are dynamic data structures in C language.

Some possible mnemonics and learning tricks for the topic are:

- To remember the difference between primitive and non-primitive data structures, think of the acronym PUN: Primitive data structures are Understood by the language, Non-primitive data structures are Not.
- To remember the difference between linear and non-linear data structures, think of the acronym LENS: Linear data structures are Easy to traverse, Non-linear data structures are Structured.
- To remember the difference between static and dynamic data structures, think of the acronym SAD: Static data structures are Allocated at compile time, Dynamic data structures are Determined at run time.
- To remember the order of precedence of the asymptotic notations, think of the acronym OBT: Big Oh is the Upper bound, Big Theta is the Tight bound, Big Omega is the Lower bound.
