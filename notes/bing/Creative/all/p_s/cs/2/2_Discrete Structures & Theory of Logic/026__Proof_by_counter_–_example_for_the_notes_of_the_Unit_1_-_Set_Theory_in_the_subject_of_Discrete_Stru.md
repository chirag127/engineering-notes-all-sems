### Proof by counterexample

- A proof by counterexample is a method of disproving a universal statement of the form "for all x, P(x)" by finding a specific value of x for which P(x) is false.
- A counterexample is a value of x that makes the statement false. For example, to disprove the statement "for all integers n, n^2 is even", we can find a counterexample n = 3, since 3^2 = 9 is not even.
- A proof by counterexample can also be used to disprove a conditional statement of the form "if P, then Q" by finding a case where P is true and Q is false. For example, to disprove the statement "if n is prime, then 2^n - 1 is prime", we can find a counterexample n = 11, since 11 is prime but 2^11 - 1 = 2047 is not prime.
- A proof by counterexample is often easier than a direct proof, since it only requires finding one instance that contradicts the statement, rather than showing that the statement holds for all possible cases.
- However, a proof by counterexample is not always possible, since some statements are true and cannot be disproved. For example, there is no counterexample to the statement "for all natural numbers n, n + 1 > n", since this statement is true for any natural number n.
