### Permutation and Symmetric Groups

- A permutation is a bijective function from a set to itself, that is, a function that rearranges the elements of the set. For example, if S = {a, b, c, d}, then a possible permutation of S is f(a) = b, f(b) = d, f(c) = a, f(d) = c.
- A permutation can also be represented by a list of the elements in their new order, such as (b, d, a, c). This is called the one-line notation of the permutation. Another way to represent a permutation is by using cycles, which are sequences of elements that are mapped to each other in a circular way. For example, the permutation (b, d, a, c) can be written as (a b d)(c), which means that a maps to b, b maps to d, d maps to a, and c maps to itself. This is called the cycle notation of the permutation.
- A permutation group is a group whose elements are permutations of a given set and whose group operation is the composition of permutations. For example, if S = {a, b, c, d}, then the set of all permutations of S forms a permutation group, denoted by Sym(S) or S4. The identity element of this group is the permutation that maps each element to itself, denoted by e or (1). The inverse of a permutation is the permutation that undoes its effect, denoted by f^-1 or (f)^-1. For example, the inverse of (a b d)(c) is (a d b)(c).
- A permutation group is a subgroup of the symmetric group, which is the group of all permutations of a finite set. The symmetric group of a set with n elements is denoted by Sn and has n! elements. For example, S4 has 4! = 24 elements. By Cayley's theorem, every finite group is isomorphic to some permutation group, that is, there is a one-to-one correspondence between the elements of the group and the permutations of some set that preserves the group structure.
- Permutation groups and symmetric groups are important concepts in discrete mathematics and algebra, as they can be used to study the symmetries and patterns of various objects, such as graphs, polynomials, matrices, and puzzles. They also have applications in cryptography, coding theory, combinatorics, and group theory.

Some possible mnemonics and learning tricks for the topic are:

- To remember the one-line notation of a permutation, you can use the acronym OLA, which stands for Order, List, and Arrange. This means that you first order the elements of the set in some way, then list them in their new order after applying the permutation, and then arrange them in parentheses. For example, if S = {a, b, c, d} and f(a) = b, f(b) = d, f(c) = a, f(d) = c, then you can order the elements as a, b, c, d, list them as b, d, a, c, and arrange them as (b, d, a, c).
- To remember the cycle notation of a permutation, you can use the acronym CCA, which stands for Choose, Cycle, and Append. This means that you first choose an element of the set that has not been used yet, then cycle through the elements that it maps to until you reach the original element, and then append the cycle to the notation. You repeat this process until all elements are used. For example, if S = {a, b, c, d} and f(a) = b, f(b) = d, f(c) = a, f(d) = c, then you can choose a, cycle through b, d, and a, append (a b d), choose c, cycle through c, and append (c). The final notation is (a b d)(c).
- To remember the composition of permutations, you can use the acronym RLA, which stands for Right, Left, and Apply. This means that you first write the permutations from right to left, then apply them to the elements of the set from left to right. For example, if S = {a, b, c, d} and f(a) = b, f(b) = d, f(c) = a, f(d) = c, and g(a) = c, g(b) = a, g(c) = d, g(d) = b, then the composition of f and g is f(g(x)), which can be written as (a b d)(c)(c a d b) from right to left, and applied as (a b d)(c)(c a d b)(a) = (a b d)(c)(b) = (a b d)(b) = (a b d)(d) = (a b d)(a) = (a b d)(b) = d from left to right.
