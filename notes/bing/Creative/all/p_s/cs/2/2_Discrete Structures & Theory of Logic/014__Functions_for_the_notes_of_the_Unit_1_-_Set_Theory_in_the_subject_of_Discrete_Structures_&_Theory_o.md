### Functions

- A function in set theory is a rule that assigns to each element of a set A (called the domain) exactly one element of a set B (called the codomain).
- A function can be represented by a set of ordered pairs, where the first element of each pair belongs to the domain and the second element belongs to the codomain.
- A function can also be represented by a diagram, where the elements of the domain and the codomain are shown as points and the function is shown as arrows from the domain to the codomain.
- A function can also be represented by an expression, where the input variable represents an element of the domain and the output value represents an element of the codomain.
- For example, the function f that assigns to each natural number n the number n + 1 can be represented by the set of ordered pairs {(0, 1), (1, 2), (2, 3), ...}, by the diagram:

```
  0  1  2  3  ...
 / \/ \/ \/ \
1  2  3  4  ...
```

- or by the expression f(n) = n + 1.

- The range of a function is the set of all elements of the codomain that are assigned by the function to some element of the domain.
- For example, the range of the function f defined above is the set of all natural numbers except 0, since 0 is not assigned by f to any natural number.
- A function is said to be one-to-one (or injective) if it assigns different elements of the domain to different elements of the codomain. That is, no two elements of the domain have the same image under the function.
- For example, the function f defined above is one-to-one, since f(n) = f(m) implies that n = m.
- A function is said to be onto (or surjective) if it assigns every element of the codomain to some element of the domain. That is, the range of the function is equal to the codomain.
- For example, the function f defined above is not onto, since 0 is not in the range of f.
- A function is said to be bijective if it is both one-to-one and onto. That is, it establishes a one-to-one correspondence between the elements of the domain and the elements of the codomain.
- For example, the function g that assigns to each natural number n the number 2n is bijective, since g(n) = g(m) implies that n = m, and every even natural number is in the range of g.

Some possible mnemonics and learning tricks for the topic are:

- To remember the definition of a function, think of a function as a **fun**ction that **assigns** to each element of a set A (the domain) exactly one element of a set B (the codomain).
- To remember the difference between one-to-one and onto functions, think of one-to-one functions as **injecting** different elements of the domain into different elements of the codomain, and onto functions as **covering** every element of the codomain with some element of the domain.
- To remember the definition of a bijective function, think of a bijective function as a **bijection** that **matches** every element of the domain with exactly one element of the codomain.
