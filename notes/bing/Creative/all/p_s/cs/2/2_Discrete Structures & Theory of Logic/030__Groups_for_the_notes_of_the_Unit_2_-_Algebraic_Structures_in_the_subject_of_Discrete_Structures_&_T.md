### Groups

- A group is an algebraic structure that consists of a set of elements and a binary operation that satisfies certain properties.
- The binary operation is usually denoted by a symbol such as `+` or `*`, and it is applied to two elements of the set to produce another element of the set.
- For example, the set of integers with the operation of addition is a group, denoted by `(Z, +)`.
- The properties that a group must satisfy are:

  - **Closure**: For any two elements `a` and `b` in the set, the result of the operation `a + b` is also in the set.
  - **Associativity**: For any three elements `a`, `b`, and `c` in the set, the result of the operation `(a + b) + c` is the same as the result of `a + (b + c)`.
  - **Identity**: There exists an element in the set, called the identity element, denoted by `e`, such that for any element `a` in the set, the result of the operation `a + e` is the same as `a`.
  - **Inverse**: For any element `a` in the set, there exists another element in the set, called the inverse of `a`, denoted by `a'`, such that the result of the operation `a + a'` is the same as the identity element `e`.

- Some examples of groups are:

  - `(Z, +)`, the set of integers with addition.
  - `(Q, +)`, the set of rational numbers with addition.
  - `(R, +)`, the set of real numbers with addition.
  - `(Zn, +)`, the set of integers modulo n with addition modulo n, where n is a positive integer.
  - `(Z*, *)`, the set of nonzero integers with multiplication.
  - `(Q*, *)`, the set of nonzero rational numbers with multiplication.
  - `(R*, *)`, the set of nonzero real numbers with multiplication.
  - `(Zn*, *)`, the set of integers modulo n that are relatively prime to n with multiplication modulo n, where n is a positive integer.
  - `(Sn, o)`, the set of permutations of n elements with composition, where n is a positive integer.
  - `(Dn, o)`, the set of symmetries of a regular n-gon with composition, where n is a positive integer.

- Some properties of groups are:

  - The identity element of a group is unique, that is, there is only one element that satisfies the identity property for any group.
  - The inverse of an element of a group is unique, that is, there is only one element that satisfies the inverse property for any element of any group.
  - The operation of a group is commutative if and only if for any two elements `a` and `b` in the set, the result of the operation `a + b` is the same as the result of `b + a`. A group that satisfies this property is called an abelian group.
  - A group is cyclic if there exists an element in the set, called a generator, such that every element of the set can be obtained by applying the operation to the generator repeatedly. For example, the group `(Zn, +)` is cyclic, and any element `k` in the set is a generator if and only if `k` and `n` are relatively prime. A cyclic group is always abelian.
