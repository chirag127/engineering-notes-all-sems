### Classification of Functions

Functions are one of the most important concepts in discrete mathematics. A function is a rule that assigns each input exactly one output. A function can be represented as f: A -> B, where A is the domain of the function, B is the codomain of the function, and f maps each element of A to a unique element of B.

Functions can be classified into different types based on their properties, such as:

- **One-to-one function**: A function f: A -> B is one-to-one or injective, if for all elements x1, x2 in A such that f(x1) = f(x2), then x1 = x2. In other words, a one-to-one function maps distinct elements of A to distinct elements of B. For example, the function f: R -> R defined by f(x) = 2x + 3 is one-to-one, as f(x1) = f(x2) implies x1 = x2.

- **Onto function**: A function f: A -> B is onto or surjective, if for every element b in B, there exists an element a in A such that f(a) = b. In other words, an onto function maps every element of B to some element of A. For example, the function f: R -> R defined by f(x) = x^2 is not onto, as there is no element in R that maps to -1.

- **Bijection**: A function f: A -> B is a bijection or bijective, if it is both one-to-one and onto. In other words, a bijection is a function that maps every element of A to a unique element of B, and vice versa. For example, the function f: R -> R defined by f(x) = x + 1 is a bijection, as f(x1) = f(x2) implies x1 = x2, and for every y in R, there exists x = y - 1 such that f(x) = y.

- **Constant function**: A function f: A -> B is a constant function, if f(a) = b for some fixed b in B and for all a in A. In other words, a constant function maps every element of A to the same element of B. For example, the function f: R -> R defined by f(x) = 5 is a constant function, as f(x) = 5 for all x in R.

- **Identity function**: A function f: A -> A is an identity function, if f(a) = a for all a in A. In other words, an identity function maps every element of A to itself. For example, the function f: R -> R defined by f(x) = x is an identity function, as f(x) = x for all x in R.

- **Inverse function**: A function f: A -> B has an inverse function, if there exists a function g: B -> A such that f(g(b)) = b for all b in B and g(f(a)) = a for all a in A. In other words, an inverse function reverses the mapping of the original function. For example, the function f: R -> R defined by f(x) = 2x + 3 has an inverse function g: R -> R defined by g(y) = (y - 3) / 2, as f(g(y)) = y and g(f(x)) = x for all x and y in R.

- **Composition of functions**: A function f: A -> B and a function g: B -> C can be composed to form a new function h: A -> C, denoted by h = g o f, such that h(a) = g(f(a)) for all a in A. In other words, a composition of functions applies the first function to the input, and then applies the second function to the output of the first function. For example, if f: R -> R is defined by f(x) = x + 1 and g: R -> R is defined by g(x) = x^2, then h = g o f is a function from R to R defined by h(x) = (x + 1)^2.
