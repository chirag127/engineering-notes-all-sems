### Definition

Set theory is a branch of mathematics that studies sets, which are collections of objects, such as {blue, white, red} or the (infinite) set of all prime numbers . A set is a well-defined collection of distinct objects, which means that the objects in a set can be identified and distinguished from each other. The objects in a set are called elements or members of the set. For example, the set {1, 2, 3} has three elements: 1, 2, and 3.

Set theory is one of the foundations of discrete mathematics, as it provides the basic concepts and notations for many other topics, such as logic, relations, functions, algorithms, and graphs. Set theory also has applications in computer science, such as data structures, databases, cryptography, and artificial intelligence.

Some of the basic concepts and operations in set theory are:

- Set notation: A set can be denoted by listing its elements inside curly braces, such as {a, b, c}, or by using a predicate that describes the property that all elements of the set share, such as {x | x is an even integer} .
- Subset: A set A is a subset of another set B if every element of A is also an element of B. We write A ⊆ B to indicate that A is a subset of B. For example, {1, 2} is a subset of {1, 2, 3}, but {1, 4} is not .
- Equality: Two sets are equal if they have exactly the same elements. We write A = B to indicate that A and B are equal sets. For example, {1, 2, 3} = {3, 2, 1}, but {1, 2, 3} ≠ {1, 2, 4} .
- Empty set: The empty set is the set that has no elements. It is denoted by ∅ or {}. The empty set is a subset of every set .
- Cardinality: The cardinality of a set is the number of elements in the set. It is denoted by |A| or #A. For example, |{1, 2, 3}| = 3, and |∅| = 0 .
- Union: The union of two sets A and B is the set that contains all the elements that are in A or in B or in both. It is denoted by A ∪ B. For example, {1, 2, 3} ∪ {3, 4, 5} = {1, 2, 3, 4, 5} .
- Intersection: The intersection of two sets A and B is the set that contains all the elements that are in both A and B. It is denoted by A ∩ B. For example, {1, 2, 3} ∩ {3, 4, 5} = {3} .
- Complement: The complement of a set A with respect to a universal set U is the set that contains all the elements that are in U but not in A. It is denoted by A<sup>c</sup> or U \ A. For example, if U = {1, 2, 3, 4, 5}, then {1, 2, 3}<sup>c</sup> = {4, 5} .

- To remember the symbols for union, intersection, and complement, think of the letters U, I, and C as shapes. The union symbol ∪ looks like a U, the intersection symbol ∩ looks like an I, and the complement symbol c looks like a C.
- To remember the difference between subset and proper subset, think of the symbols ⊆ and ⊂ as mouths. The subset symbol ⊆ has a line under it, which means it can eat everything, including itself. The proper subset symbol ⊂ has no line under it, which means it can only eat some things, but not itself.
- To remember the difference between difference and symmetric difference, think of the symbols - and ∆ as operations. The difference symbol - means to subtract or take away, which is what the difference operation does. The symmetric difference symbol ∆ means to change or flip, which is what the symmetric difference operation does.
- To remember the formula for the cardinality of the union of two sets, think of the word "union" as having four letters. The formula is |A ∪ B| = |A| + |B| - |A ∩ B|, which has four terms.
- To remember the formula for the cardinality of the intersection of two sets, think of the word "intersect" as having eight letters. The formula is |A ∩ B| = |A| + |B| - |A ∪ B|, which has eight terms.
