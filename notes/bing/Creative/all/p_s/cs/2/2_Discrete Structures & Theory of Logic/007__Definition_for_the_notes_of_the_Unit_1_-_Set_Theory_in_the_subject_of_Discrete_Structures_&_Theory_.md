### Definition

Set theory is a branch of mathematics that studies sets, which are collections of objects, such as {blue, white, red} or the (infinite) set of all prime numbers . A set is a well-defined collection of distinct objects, which means that the objects in a set can be identified and distinguished from each other. The objects in a set are called elements or members of the set. For example, the set {1, 2, 3} has three elements: 1, 2, and 3.

Set theory is the foundation of many branches of discrete mathematics, such as logic, combinatorics, graph theory, and algorithms. It also has applications in computer science, cryptography, and database theory. Set theory provides a language and a notation to express and manipulate sets and their properties.

Some basic concepts and operations in set theory are:

- Set notation: A set can be denoted by listing its elements inside curly braces, such as {a, b, c}, or by using a predicate that describes the property of the elements, such as {x | x is an even integer}.
- Subset: A set A is a subset of another set B if every element of A is also an element of B. We write A ⊆ B to indicate that A is a subset of B. For example, {1, 2} ⊆ {1, 2, 3}, but {1, 4} ⊈ {1, 2, 3}.
- Equality: Two sets are equal if they have the same elements, regardless of the order or repetition. We write A = B to indicate that A and B are equal sets. For example, {1, 2, 3} = {3, 2, 1} = {1, 1, 2, 3}.
- Empty set: The empty set is the set that has no elements. It is denoted by ∅ or {}. The empty set is a subset of every set.
- Cardinality: The cardinality of a set is the number of elements in the set. It is denoted by |A| or #A. For example, |{1, 2, 3}| = 3 and |∅| = 0.
- Union: The union of two sets A and B is the set that contains all the elements that are in A or in B or in both. It is denoted by A ∪ B. For example, {1, 2, 3} ∪ {3, 4, 5} = {1, 2, 3, 4, 5}.
- Intersection: The intersection of two sets A and B is the set that contains all the elements that are in both A and B. It is denoted by A ∩ B. For example, {1, 2, 3} ∩ {3, 4, 5} = {3}.
- Complement: The complement of a set A with respect to a universal set U is the set that contains all the elements that are in U but not in A. It is denoted by A<sup>c</sup> or U \ A. For example, if U = {1, 2, 3, 4, 5}, then {1, 2, 3}<sup>c</sup> = {4, 5}.
- Difference: The difference of two sets A and B is the set that contains all the elements that are in A but not in B. It is denoted by A - B or A \ B. For example, {1, 2, 3} - {3, 4, 5} = {1, 2}.
- Symmetric difference: The symmetric difference of two sets A and B is the set that contains all the elements that are in either A or B but not in both. It is denoted by A ∆ B. For example, {1, 2, 3} ∆ {3, 4, 5} = {1, 2, 4, 5}.

Some possible mnemonics and learning tricks for the topic are:

- To remember the symbols for union, intersection, and complement, think of the letters U, I, and C. U stands for union, which looks like a U. I stands for intersection, which looks like an upside-down U. C stands for complement, which is a C with a line over it.
- To remember the formula for the cardinality of the union of two sets, think of the word "union" as "you and I". The formula is |A ∪ B| = |A| + |B| - |A ∩ B|. This means that the number of elements in the union is the sum of the number of elements in each set, minus the number of elements that are in both sets (the intersection).
- To remember the formula for the cardinality of the Cartesian product of two sets, think of the word "product" as "multiply". The formula is |A × B| = |A| × |B|. This means that the number of ordered pairs in the product is the product of the number of elements in each set.
