### Exponential curves

- An exponential curve is a graph of an exponential function of the form y = kx, where x and y are variables and k is a constant (a numerical value). x is the exponent and k is the base.
- An exponential curve can either grow or decay depending on the value of k. If k > 1, the curve is increasing and represents exponential growth. If 0 < k < 1, the curve is decreasing and represents exponential decay.
- An exponential curve has the following properties :
  - The y-intercept of an exponential curve (at x = 0) is 1, since any non-zero number raised to the power 0 is 1.
  - The x-axis is an asymptote to the curve. The curve gets very close to the horizontal asymptote but does not touch it.
  - The curve is always positive, since any non-zero number raised to any power is positive.
  - The curve is always increasing or decreasing, never constant.
  - The rate of change of the curve increases or decreases over time, depending on the value of k.
- An example of an exponential curve is the graph of the function y = 2x, which shows exponential growth. The graph is shown below:

```
  y
  |
  |       *
  |     *
  |   *
  | *
  |_________________________ x
  |
  |
```

- An example of an exponential curve is the graph of the function y = 0.5x, which shows exponential decay. The graph is shown below:

```
  y
  |
  | *
  |   *
  |     *
  |       *
  |_________________________ x
  |
  |
```

- Exponential curves are useful for modeling phenomena that involve constant percentage changes, such as population growth, radioactive decay, compound interest, etc .

Some possible mnemonics and learning tricks for the topic are:

- To remember the formula for an exponential function, think of the word **KIX**. The base is **K**, the exponent is **X**, and the output is **Y**. So, y = kx.
- To remember the difference between exponential growth and decay, think of the word **GOD**. If the base is **G**reater than 1, the curve is **O**n the rise and shows exponential **G**rowth. If the base is less than 1, the curve is **D**ropping and shows exponential **D**ecay.
- To remember the properties of an exponential curve, think of the acronym **YAXPIR**. The **Y**-intercept is 1, the **X**-axis is an asymptote, the curve is always **P**ositive, **I**ncreasing or decreasing, and the **R**ate of change varies.
