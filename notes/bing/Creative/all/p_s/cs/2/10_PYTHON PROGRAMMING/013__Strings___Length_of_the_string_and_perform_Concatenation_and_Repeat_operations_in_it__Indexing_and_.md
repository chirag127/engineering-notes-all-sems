### Strings: Length of the string and perform Concatenation and Repeat operations in it. Indexing and Slicing of Strings.

- A string is a sequence of characters enclosed in quotation marks, such as "Hello" or 'Python'.
- Strings are immutable, which means they cannot be modified once created.
- Strings can be accessed by indexing, which returns a single character, or slicing, which returns a substring.
- Strings can be concatenated, which means joining them together, using the + operator, such as "Hello" + "World".
- Strings can be repeated, which means creating a new string with multiple copies of the original string, using the * operator, such as "Hello" * 3.
- The length of a string can be obtained using the len() function, which returns the number of characters in the string, such as len("Hello") == 5.

#### Examples:

- To access the first character of a string, use the index 0, such as "Hello"[0] == "H".
- To access the last character of a string, use the index -1, such as "Hello"[-1] == "o".
- To access a substring of a string, use the slicing notation [start:end], where start is the inclusive starting index and end is the exclusive ending index, such as "Hello"[1:4] == "ell".
- To access the whole string, use the slicing notation [:], such as "Hello"[:] == "Hello".
- To access a substring from the beginning to a certain index, use the slicing notation [:end], such as "Hello"[:3] == "Hel".
- To access a substring from a certain index to the end, use the slicing notation [start:], such as "Hello"[2:] == "llo".
- To concatenate two strings, use the + operator, such as "Hello" + "World" == "HelloWorld".
- To repeat a string a certain number of times, use the * operator, such as "Hello" * 3 == "HelloHelloHello".
- To get the length of a string, use the len() function, such as len("Hello") == 5.
