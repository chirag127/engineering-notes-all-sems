## Unit 3 - Function: Parts of A Function , Execution of A Function , Keyword and Default Arguments ,Scope Rules.

- A function is a block of code that performs a specific task and can be reused in a program.
- A function has four main parts: the name, the parameters, the body and the return value.
- The name is the identifier that is used to call the function. It should be descriptive and follow the naming conventions of Python.
- The parameters are the variables that are passed to the function when it is called. They are enclosed in parentheses after the name. A function can have zero or more parameters.
- The body is the indented block of code that contains the statements that define the logic of the function. It starts with a colon after the parameters and ends with a return statement or the end of the block.
- The return value is the result that the function produces and sends back to the caller. It is specified by the return statement in the body. A function can return one or more values, or None if there is no return statement.

- To execute a function, it must be called by using its name followed by parentheses. If the function has parameters, the arguments that match the parameters must be passed inside the parentheses. The arguments can be positional or keyword, depending on how they are specified in the function definition.
- Positional arguments are the arguments that are passed in the same order as the parameters in the function definition. They are matched by position, not by name.
- Keyword arguments are the arguments that are passed by using the name of the parameter and an equal sign, followed by the value. They are matched by name, not by position. Keyword arguments can be used to pass the arguments in any order, or to skip some optional arguments.
- Default arguments are the arguments that have a default value assigned in the function definition. They are optional and can be omitted when calling the function. If they are not passed, the function will use the default value. Default arguments should follow non-default arguments in the function definition.
- Arbitrary arguments are the arguments that can accept any number of values when calling the function. They are specified by using an asterisk (*) for positional arguments or a double asterisk (**) for keyword arguments in the function definition. They are stored as a tuple or a dictionary in the function body, respectively.

- Scope is the region of code where a variable or a name is defined and can be accessed. Python has four types of scopes: local, enclosing, global and built-in.
- Local scope is the scope of a function or a comprehension. It is created when the function or the comprehension is executed and destroyed when it is finished. Variables or names defined in the local scope are only accessible within the function or the comprehension.
- Enclosing scope is the scope of a nested function. It is created when the nested function is defined and destroyed when the enclosing function is finished. Variables or names defined in the enclosing scope are accessible within the nested function, but not outside of it.
- Global scope is the scope of the module or the script. It is created when the module or the script is executed and destroyed when the program ends. Variables or names defined in the global scope are accessible throughout the module or the script, but not inside a function or a comprehension, unless they are declared as global using the global keyword.
- Built-in scope is the scope of the Python interpreter. It is created when the interpreter starts and destroyed when it ends. Variables or names defined in the built-in scope are the predefined names that are part of the Python language, such as print, len, range, etc. They are accessible in any scope, unless they are shadowed by a local or a global name.

- The scope of a variable or a name is determined by the place where it is defined, not by the place where it is used. Python follows the LEGB rule to resolve the scope of a name, which means it looks for the name in the following order: local, enclosing, global, built-in. If the name is not found in any of these scopes, a NameError is raised.
- The scope of a default argument is the scope where the function is defined, not where it is called. This means that the default value is evaluated only once, when the function is defined, and not every time the function is called.
