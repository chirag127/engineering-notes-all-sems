### Python Data Structure : Tuples , Unpacking Sequences , Lists , Mutable Sequences , List Comprehension , Sets , Dictionaries

- **Tuples** are a collection type data structure that store a fixed sequence of heterogeneous elements. They are immutable, meaning they cannot be modified after creation. Tuples are created by using parentheses `()` and separating the elements by commas `,`. For example: `t = (1, 2, 3, 'a', 'b', 'c')`. Tuples can be indexed, sliced, and iterated over like lists, but they cannot be appended, extended, or removed. Tuples are faster and more memory-efficient than lists, and can be used as keys in dictionaries or as elements of sets. Tuples can also be used to return multiple values from a function or to assign multiple variables in one statement. For example: `def min_max(lst): return min(lst), max(lst)` and `x, y = 10, 20`.
- **Unpacking sequences** is a feature of Python that allows assigning multiple variables from a single sequence, such as a tuple or a list. The number of variables must match the length of the sequence, and the variables will be assigned the corresponding elements from the sequence. For example: `a, b, c = (1, 2, 3)` or `x, y, z = [4, 5, 6]`. Unpacking sequences can also be used to swap the values of two variables without using a temporary variable. For example: `x, y = y, x`. Unpacking sequences can also be used with the `*` operator to assign the remaining elements of a sequence to a variable. For example: `a, *b, c = (1, 2, 3, 4, 5)` will assign `a = 1`, `b = [2, 3, 4]`, and `c = 5`.
- **Lists** are a collection type data structure that store a mutable sequence of homogeneous or heterogeneous elements. They are created by using square brackets `[]` and separating the elements by commas `,`. For example: `l = [1, 2, 3, 'a', 'b', 'c']`. Lists can be indexed, sliced, and iterated over like tuples, but they can also be modified by using methods such as `append`, `extend`, `insert`, `remove`, `pop`, `sort`, `reverse`, etc. Lists are versatile and flexible, but they are slower and less memory-efficient than tuples. Lists can be used to store and manipulate data, such as numbers, strings, or other objects. Lists can also be nested, meaning they can contain other lists as elements. For example: `m = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]`.
- **Mutable sequences** are a category of data structures that include lists and other types that can be modified after creation. They support the common sequence operations, such as indexing, slicing, and iteration, as well as the mutable sequence operations, such as item assignment, item deletion, and slice assignment. For example: `l[0] = 10`, `del l[1]`, or `l[2:4] = [20, 30]`. Mutable sequences also support the `+=` and `*=` operators, which modify the sequence in place. For example: `l += [40, 50]` or `l *= 2`. Mutable sequences can be used to store and manipulate data that changes over time, such as user input, sensor readings, or game states.
