### Sorting Algorithms-Non-Recursive

- A sorting algorithm is an algorithm that puts elements of a list into an order. The most frequently used orders are numerical order and lexicographical order, and either ascending or descending.
- A non-recursive sorting algorithm is a sorting algorithm that does not use recursion, which is a technique of calling a function within itself to solve a smaller subproblem.
- Non-recursive sorting algorithms typically use loops, such as for or while, to iterate over the elements of the list and compare or swap them as needed.
- Some examples of non-recursive sorting algorithms are:
  - Bubble sort: This algorithm compares adjacent elements and swaps them if they are in the wrong order. It repeats this process until no more swaps are needed. The worst-case time complexity of bubble sort is O(n^2), where n is the number of elements in the list.
  - Insertion sort: This algorithm iterates over the list and inserts each element into its correct position in a sorted sublist. The worst-case time complexity of insertion sort is also O(n^2).
  - Selection sort: This algorithm finds the smallest (or largest) element in the list and swaps it with the first (or last) element. It repeats this process for the remaining sublist until the list is sorted. The worst-case time complexity of selection sort is also O(n^2).
  - Heap sort: This algorithm builds a heap, which is a special type of binary tree, from the list and repeatedly extracts the root (which is the smallest or largest element) and places it at the end of the sorted sublist. The worst-case time complexity of heap sort is O(n log n), where log n is the base-2 logarithm of n.
  - Quick sort: This algorithm chooses a pivot element from the list and partitions the list into two sublists, one with elements smaller than the pivot and one with elements larger than the pivot. It then recursively sorts the sublists using the same algorithm. The worst-case time complexity of quick sort is O(n^2), but the average-case time complexity is O(n log n).
  - Merge sort: This algorithm divides the list into two sublists, recursively sorts them using the same algorithm, and then merges them into a sorted list. The worst-case time complexity of merge sort is O(n log n).

- The advantages of non-recursive sorting algorithms are:
  - They are easier to implement and understand than recursive algorithms.
  - They do not use extra memory for the function call stack, which can be a limitation for recursive algorithms.
  - They can be more efficient for small lists, as they do not have the overhead of function calls.

- The disadvantages of non-recursive sorting algorithms are:
  - They can be less efficient for large lists, as they may have higher time complexity than recursive algorithms.
  - They can be less elegant and concise than recursive algorithms, as they may require more code and variables.

- Some applications of non-recursive sorting algorithms are:
  - Sorting data for display, analysis, or search purposes, such as in databases, spreadsheets, or web pages.
  - Sorting items for ordering, packing, or delivery, such as in e-commerce, inventory, or logistics systems.
  - Sorting elements for comparison, selection, or ranking, such as in algorithms, games, or tests.

Mnemonics are memory tricks that can help you remember new information by connecting it to something you already know. There are different types of mnemonics, such as rhymes, acronyms, diagrams, or images. For example, you can use the acronym HOMES to remember the names of the Great Lakes: Huron, Ontario, Michigan, Erie, and Superior. Or you can use the rhyme "Thirty days hath September, April, June, and November" to remember how many days are in each month.

Some mnemonics are easy to remember because they are catchy, funny, or make sense. Others may be harder to remember because they are too long, complicated, or nonsensical. The best mnemonics are the ones that work for you, so you may want to create your own mnemonics based on your interests, hobbies, or experiences. For example, if you like music, you can use a song lyric to remember a fact. Or if you like sports, you can use a player's name or number to remember a date.

To use mnemonics effectively, you need to practice them regularly and repeat them to others. This will help you reinforce the information in your memory and recall it when you need it. You can also use mnemonics in combination with other memory strategies, such as reviewing, testing, or organizing the information. Mnemonics are not a substitute for understanding the material, but they can help you remember it better.
