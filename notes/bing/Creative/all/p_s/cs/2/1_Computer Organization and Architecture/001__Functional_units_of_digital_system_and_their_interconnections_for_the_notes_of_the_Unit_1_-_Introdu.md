### Functional units of digital system and their interconnections

A digital system is a system that processes and stores data in binary form, using electronic devices such as transistors, logic gates, and memory cells. A digital system can perform various functions, such as arithmetic, logic, control, communication, and data processing. To perform these functions, a digital system consists of several functional units that are interconnected by buses. A bus is a set of wires or lines that carry data, address, and control signals between different components of the system. The main functional units of a digital system are:

- **Input unit**: This unit is responsible for taking the input from the user or an external device and converting it into binary code that can be processed by the system. The input unit consists of input devices, such as keyboards, mouse, scanners, microphones, etc. The input unit also performs error checking and buffering of the input data.

- **Output unit**: This unit is responsible for converting the binary data produced by the system into a form that can be displayed or transmitted to the user or an external device. The output unit consists of output devices, such as monitors, printers, speakers, etc. The output unit also performs formatting and buffering of the output data.

- **Memory unit**: This unit is responsible for storing the data and instructions that are needed by the system for processing. The memory unit consists of memory devices, such as RAM, ROM, cache, hard disk, etc. The memory unit also performs read and write operations on the data and instructions.

- **Arithmetic and logic unit (ALU)**: This unit is responsible for performing the arithmetic and logic operations on the data, such as addition, subtraction, multiplication, division, comparison, etc. The ALU consists of arithmetic and logic circuits, such as adders, subtractors, multipliers, dividers, comparators, etc. The ALU also performs shifting and rotating of the data.

- **Control unit (CU)**: This unit is responsible for controlling the operation of the system by fetching, decoding, and executing the instructions stored in the memory. The control unit consists of control circuits, such as registers, counters, decoders, multiplexers, etc. The control unit also generates and sends the control signals to the other units of the system.

The interconnection between the functional units of a digital system can be represented by a bus architecture, which shows how the data, address, and control buses are connected to the different units. A bus architecture can be classified into three types:

- **Single-bus architecture**: In this type, there is only one bus that connects all the units of the system. This bus carries the data, address, and control signals simultaneously. This type of architecture is simple and cheap, but it has low performance and scalability, as the bus can become a bottleneck for the communication.

- **Multiple-bus architecture**: In this type, there are more than one bus that connect the units of the system. Each bus carries a specific type of signal, such as data, address, or control. This type of architecture is more complex and expensive, but it has high performance and scalability, as the buses can operate in parallel and reduce the communication delay.

- **Hybrid-bus architecture**: In this type, there are a combination of single and multiple buses that connect the units of the system. Some units are connected by a single bus, while some units are connected by multiple buses. This type of architecture is a trade-off between the simplicity and cost of the single-bus architecture and the performance and scalability of the multiple-bus architecture.
