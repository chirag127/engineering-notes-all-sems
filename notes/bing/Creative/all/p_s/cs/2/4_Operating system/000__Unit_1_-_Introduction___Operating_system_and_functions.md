## Unit 1 - Introduction : Operating system and functions

- An operating system (OS) is a **software** that controls the operation of a computer and directs the processing of the user's programs.
- An operating system acts as a **communication bridge** (interface) between the user and the computer hardware.
- An operating system provides three essential capabilities:
  - It offers a **user interface** (UI) through a command-line interface (CLI) or graphical user interface (GUI).
  - It launches and manages the **application execution**.
  - It identifies and exposes system hardware resources to those applications, typically through a standardized **application program interface** (API).
- An operating system also carries out the **allocation of resources and services**, such as the allocation of memory, devices, processors, and information.
- An operating system can be classified into different types based on various criteria, such as the number of users, the number of tasks, the type of hardware, the type of interface, the type of distribution, etc.
- Some examples of operating systems are Windows, Linux, MacOS, Android, iOS, etc.
