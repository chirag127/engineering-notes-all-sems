The segment registers are CS, DS, SS, and ES, which are used to store the base addresses of the code, data, stack, and extra segments respectively. The pointer and index registers are SP, BP, SI, and DI, which are used to store the offsets of the stack, base, source, and destination operands respectively. The flag register is a 16-bit register that contains 9 flags, which indicate the status of the result of the previous operation or the state of the processor. The flags are CF (carry flag), PF (parity flag), AF (auxiliary carry flag), ZF (zero flag), SF (sign flag), TF (trap flag), IF (interrupt flag), DF (direction flag), and OF (overflow flag).

The BIU also handles the data transfers between the processor and the memory or I/O devices. The BIU consists of the segment registers, the instruction pointer (IP), and the instruction queue. The ALU is a 16-bit unit that performs the arithmetic and logical operations on the operands. The control unit is a unit that generates the control signals for the execution of the instructions and the data transfers.
