### Data Transfer Schemes in Microprocessor

- Data transfer schemes are the methods by which data can be transferred between the microprocessor and the memory or I/O devices.
- Data transfer schemes can be classified into three types: programmed data transfer, interrupt-driven data transfer, and direct memory access (DMA) data transfer.

#### Programmed Data Transfer

- In this scheme, data transfer takes place under the control of a program that resides in the main memory of the microcomputer system.
- The microprocessor executes the program to perform all data transfers between the memory and I/O devices via registers.
- Programmed data transfer can be further divided into two types: synchronous and asynchronous.

##### Synchronous Data Transfer

- This type of programmed data transfer scheme is used when the processor and the I/O devices match in speed.
- The processor and the I/O devices are synchronized by a common clock signal.
- The processor initiates the data transfer by sending a control signal to the I/O device, and then waits for the data to be ready or accepted by the I/O device.
- The data transfer takes place in one clock cycle.

##### Asynchronous Data Transfer

- This type of programmed data transfer scheme is used when the speeds of I/O devices and the microprocessor do not match and also when the timing characteristics of the I/O devices are not predictable.
- The processor and the I/O devices are not synchronized by a common clock signal.
- The processor initiates the data transfer by sending a control signal to the I/O device, and then proceeds with other tasks without waiting for the data to be ready or accepted by the I/O device.
- The I/O device signals the processor when the data is ready or accepted by using a handshake signal, such as a ready or acknowledge signal.
- The data transfer takes place in multiple clock cycles.

#### Interrupt-Driven Data Transfer

- In this scheme, data transfer takes place between the CPU and I/O device with the help of an interrupt signal.
- The interrupt signal is generated by the I/O device to request the CPU to suspend its current task and service the I/O device.
- The CPU responds to the interrupt signal by saving the current state of the program and jumping to a predefined interrupt service routine (ISR) that handles the data transfer with the I/O device.
- After the data transfer is completed, the CPU resumes the execution of the previous program from where it was interrupted.

#### Direct Memory Access (DMA) Data Transfer

- In this scheme, data is directly transferred from the memory to the I/O device or vice versa without going through the microprocessor.
- This scheme is used when there is a requirement to send bulk data. Transferring bulk data using a microprocessor consumes more time and resources.
- Therefore, the microprocessor delegates the data transfer task to a special hardware device called the DMA controller (DMAC).
- The DMAC takes over the control of the system bus from the microprocessor and transfers the data between the memory and the I/O device.
- The microprocessor is freed from the data transfer task and can perform other tasks or remain idle.
- The DMAC signals the microprocessor when the data transfer is completed by using an interrupt signal.
