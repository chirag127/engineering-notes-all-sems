- An instruction is a binary command that tells the microprocessor to perform a specific operation on some data.
- An instruction set is a collection of all the instructions that a microprocessor can execute.
- The 8085 microprocessor has 74 operation codes (opcodes) that result in 246 instructions.
- The instruction set of 8085 microprocessor can be classified into five functional groups    :
  - Data Transfer/Copy Operations: These instructions move data from one location to another, without changing the source data. Examples are MOV, MVI, LXI, LDA, STA, LHLD, SHLD, LDAX, STAX, XCHG, PUSH, POP, IN, OUT, etc.
  - Arithmetic Operations: These instructions perform arithmetic operations on data in registers or memory. Examples are ADD, ADC, SUB, SBB, INR, DCR, INX, DCX, DAD, SUI, SBI, CPI, etc.
  - Logical Operations: These instructions perform logical operations on data in registers or memory, such as AND, OR, XOR, NOT, etc. Examples are ANA, ANI, ORA, ORI, XRA, XRI, CMA, CMC, STC, RLC, RRC, RAL, RAR, etc.
  - Branching Operations: These instructions change the sequence of execution of the program, by jumping to a different address or by calling a subroutine. Examples are JMP, JC, JNC, JZ, JNZ, JPE, JPO, JP, JM, CALL, CC, CNC, CZ, CNZ, CPE, CPO, CP, CM, RET, RC, RNC, RZ, RNZ, RPE, RPO, RP, RM, etc.
  - Machine Control and Assembler Directives: These instructions control the operation of the microprocessor or the assembler. Examples are HLT, NOP, DI, EI, SIM, RIM, ORG, EQU, DB, DW, DS, etc.
- The instruction format of 8085 microprocessor is as follows:
  - Each instruction consists of one to three bytes, where the first byte is always the opcode and the remaining bytes (if any) are the operands.
  - The opcode specifies the operation to be performed and the addressing mode of the operands.
  - The operands can be registers, memory locations, immediate data, or I/O ports.
  - The operands can be 8-bit or 16-bit, depending on the instruction.
  - The instruction format can be classified into four types:
    - One byte instruction: This type of instruction has only one byte, which is the opcode. No operands are required. Example: CMA, HLT, NOP, etc.
    - Two byte instruction: This type of instruction has two bytes, where the first byte is the opcode and the second byte is the operand. The operand can be an 8-bit register, an 8-bit memory location, an 8-bit immediate data, or an 8-bit I/O port. Example: MOV A,B, MVI A,55H, IN 05H, etc.
    - Three byte instruction: This type of instruction has three bytes, where the first byte is the opcode and the second and third bytes are the operands. The operands can be a 16-bit register pair, a 16-bit memory location, a 16-bit immediate data, or a 16-bit address. Example: LXI H,1234H, LDA 5678H, JMP 9ABC, etc.
    - Variable byte instruction: This type of instruction has variable number of bytes, depending on the condition. The first byte is the opcode and the second byte is the condition code. The third byte is the operand, which is a 16-bit address, if the condition is true. Otherwise, the instruction is treated as a one byte instruction. Example: JC 1234H, JZ 5678H, etc.
- The addressing modes

- The addressing modes of 8085 microprocessor are the ways of specifying the operands for an instruction .
- The addressing modes of 8085 microprocessor can be classified into five types :
  - Immediate Addressing Mode: In this mode, the operand is an 8-bit or 16-bit immediate data, which is specified in the instruction itself. Example: MVI A,55H, LXI H,1234H, etc.
  - Register Addressing Mode: In this mode, the operand is an 8-bit register or a 16-bit register pair, which is specified in the instruction itself. Example: MOV A,B, INX H, etc.
  - Direct Addressing Mode: In this mode, the operand is an 8-bit or 16-bit memory location, whose address is specified in the instruction itself. Example: LDA 5678H, STA 9ABC, etc.
  - Indirect Addressing Mode: In this mode, the operand is an 8-bit memory location, whose address is stored in a 16-bit register pair. The register pair is specified in the instruction itself. Example: MOV A,M, LDAX B, etc.
  - I/O Port Addressing Mode: In this mode, the operand is an 8-bit I/O port, whose address is specified in the instruction itself. Example: IN 05H, OUT 06H, etc.
