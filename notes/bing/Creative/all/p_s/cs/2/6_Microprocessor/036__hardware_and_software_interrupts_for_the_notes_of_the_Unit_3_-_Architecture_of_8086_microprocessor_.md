### Hardware and Software Interrupts

- An interrupt is a signal that causes the CPU to temporarily stop its current execution and switch to a different task. Interrupts can be generated by hardware devices or by software instructions.
- The 8086 microprocessor supports two types of hardware interrupts and 256 types of software interrupts.

#### Hardware Interrupts

- Hardware interrupts are caused by external devices that send a signal to the CPU through a dedicated pin. The CPU responds by executing a predefined interrupt service routine (ISR) that handles the device request.
- The 8086 microprocessor has two hardware interrupt pins: NMI and INTR.
  - NMI stands for Non-Maskable Interrupt. It is a high-priority interrupt that cannot be ignored or disabled by the CPU. It is used for critical events such as power failure, memory parity error, or watchdog timer expiration. The NMI pin is connected to the interrupt vector 2, which points to the NMI ISR at the memory address 00008H.
  - INTR stands for Maskable Interrupt. It is a low-priority interrupt that can be enabled or disabled by the CPU using the interrupt enable (IF) flag in the flags register. It is used for normal device requests such as keyboard input, disk access, or printer output. The INTR pin is connected to an external programmable interrupt controller (PIC) that prioritizes and multiplexes the interrupt requests from various devices. The PIC sends an interrupt type (or vector) to the CPU, which points to the corresponding ISR at the memory address 4 x vector.

#### Software Interrupts

- Software interrupts are caused by software instructions that explicitly request the CPU to execute a predefined ISR. Software interrupts can be used for system calls, exception handling, debugging, or user-defined functions.
- The 8086 microprocessor supports 256 types of software interrupts, numbered from 0 to 255. Each software interrupt has a corresponding interrupt vector, which points to the ISR at the memory address 4 x vector.
- The software interrupt instruction in the 8086 microprocessor is INT n, where n is the interrupt type (or vector). For example, INT 21H is a software interrupt that invokes the DOS system call ISR.
