# Real Time System

A real time system is a system that can process and respond to inputs or events within a specified time limit. The time limit is usually determined by the requirements of the application or the environment that the system is controlling. A real time system must be able to meet its deadlines, otherwise it may cause a system failure or undesirable consequences.

## Types of real time systems

Real time systems can be classified into two types based on their timing constraints:

- **Hard real time system**: This type of system can never miss its deadline. Missing the deadline may have disastrous effects on the system or the environment. For example, a flight control system, a nuclear reactor control system, or a pacemaker are hard real time systems.
- **Soft real time system**: This type of system can miss its deadline occasionally with some acceptably low probability. Missing the deadline may degrade the performance or the quality of service of the system, but it will not cause a system failure or harm. For example, a video streaming system, a voice recognition system, or a web server are soft real time systems.

## Characteristics of real time systems

Real time systems have some common characteristics that distinguish them from other types of systems:

- **Concurrency**: Real time systems often have to handle multiple inputs or events simultaneously or in parallel. For example, a robot may have to process sensor data, control its motors, and communicate with other robots at the same time.
- **Determinism**: Real time systems must be able to produce the same output for the same input every time, regardless of the system state or the execution order. For example, a traffic light system must always switch the lights in the same sequence and duration, regardless of the traffic conditions or the power supply.
- **Reactivity**: Real time systems must be able to react to inputs or events as soon as they occur, without any delay or buffering. For example, an airbag system must be able to deploy the airbag within milliseconds of detecting a collision, without waiting for any other processing or communication.
- **Predictability**: Real time systems must be able to guarantee that they can meet their deadlines under all possible scenarios and conditions. For example, a radar system must be able to detect and track any incoming object within a certain range and time, regardless of the weather or the interference.

## Applications of real time systems

Real time systems are used in a variety of industries and domains, where timeliness and reliability are critical. Some examples of real time systems are:

- **Process control systems**: These systems are used to monitor and control physical processes, such as chemical reactions, temperature, pressure, or flow. For example, a thermostat, a boiler, or a refinery are process control systems.
- **Machine vision systems**: These systems are used to help machines interpret visual data, such as images, videos, or scans. For example, a face recognition system, a barcode scanner, or a self-driving car are machine vision systems.
- **Robotics systems**: These systems are used to control machines that can perform tasks autonomously or semi-autonomously, such as movement, manipulation, or coordination. For example, a robot arm, a drone, or a surgical robot are robotics systems.
- **Multimedia systems**: These systems are used to process and deliver audio, video, or graphics data, such as streaming, editing, or rendering. For example, a video conferencing system, a video game, or a virtual reality system are multimedia systems.
