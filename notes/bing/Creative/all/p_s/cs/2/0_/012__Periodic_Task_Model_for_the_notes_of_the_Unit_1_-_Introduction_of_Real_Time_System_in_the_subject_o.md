### Periodic Task Model

- The periodic task model is a well-known deterministic workload model that characterizes accurately many traditional hard real-time applications, such as digital control, real-time monitoring, and constant bit-rate voice/video transmission .
- A periodic task is a task that is activated repeatedly at fixed time intervals, called periods. Each activation of a periodic task is called a job. A job has a worst-case execution time (WCET), which is the maximum amount of time it can take to complete on a given processor. A job also has a relative deadline, which is the maximum amount of time it can wait after its release before it must finish. A job is said to be feasible if it can finish before its deadline .
- A periodic task set is a collection of periodic tasks that share a processor. A periodic task set is said to be schedulable if there exists a scheduling algorithm that can ensure the feasibility of all the jobs of all the tasks in the set. A periodic task set is said to be feasible if it is schedulable by some optimal scheduling algorithm, such as Earliest Deadline First (EDF) or Rate Monotonic (RM) .
- A periodic task can be represented by a tuple (T, C, D), where T is the period, C is the WCET, and D is the relative deadline. Sometimes, the deadline is assumed to be equal to the period, in which case the tuple can be simplified to (T, C). A periodic task set can be represented by a set of tuples, such as {(10, 3), (15, 4), (20, 5)} .
- A periodic task model can be extended by adding a jitter J for each task, which is the maximum deviation of the actual release time of a job from the exact start time of the period. For example, a task with period 10 and jitter 2 can release a job anywhere between 8 and 12 time units after the previous job. Jitter can be used to model uncertainties in the arrival times of periodic tasks, such as those caused by network delays or sensor sampling .
- A periodic task model can also be extended by adding a phase P for each task, which is the offset of the first release time of a task from the start of the system. For example, a task with period 10 and phase 3 will release its first job at time 3, and then every 10 time units thereafter. Phase can be used to model the initial alignment of periodic tasks, such as those caused by different power-on times or synchronization protocols .
- A periodic task model can be analyzed using various metrics, such as utilization, response time, schedulability test, and feasibility test. Utilization is the ratio of the WCET to the period of a task, which measures how much of the processor time is consumed by the task. Response time is the time elapsed from the release of a job to its completion, which measures how fast the job can be executed. Schedulability test is a method to check if a given periodic task set is schedulable by a given scheduling algorithm, which can be based on sufficient or necessary conditions. Feasibility test is a method to check if a given periodic task set is feasible, which can be based on exact or approximate methods  .
