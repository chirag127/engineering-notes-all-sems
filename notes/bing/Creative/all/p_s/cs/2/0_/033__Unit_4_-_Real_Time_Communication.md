## Unit 4 - Real Time Communication

- Real time communication (RTC) is a category of software protocols and communication hardware media that gives real time guarantees, which is necessary to support real time guarantees of real time computing.
- Real time communication is also any mode of telecommunications in which all users can exchange information instantly or with negligible latency or transmission delays.
- In real time communication, there is always a direct path between the source and the destination, and the data and messages are not stored between transmission and reception.
- Examples of real time communication include: voice over landlines and mobile phones, video conferencing, instant messaging, chat, online gaming, etc.
- Real time communication can be classified into two types: synchronous and asynchronous.
  - Synchronous communication is when both parties are present and active at the same time, and can interact in a live capacity. For example, a phone call, a video call, or a live chat.
  - Asynchronous communication is when the parties are not present or active at the same time, and can interact at their own convenience. For example, an email, a text message, or a voicemail.
- Real time communication can be implemented using different technologies and protocols, such as:
  - Real time Transport Protocol (RTP): a standard protocol for delivering audio and video over IP networks. It provides end-to-end network transport functions for applications transmitting real time data, such as payload type identification, sequence numbering, timestamping, and delivery monitoring.
  - Real time Streaming Protocol (RTSP): a network control protocol designed for use in entertainment and communications systems to control streaming media servers. It establishes and controls either a single or several time-synchronized streams of continuous media such as audio and video.
  - Real time Messaging Protocol (RTMP): a proprietary protocol developed by Adobe Systems for streaming audio, video, and data over the Internet, between a Flash player and a server. It can also be used for live broadcasting and video on demand services.
  - Web Real time Communication (WebRTC): a collection of standards, protocols, and JavaScript APIs that enable peer-to-peer communication of audio, video, and data in web browsers and mobile applications. It allows web applications to access the device's camera and microphone, and to establish direct connections with other peers without intermediaries.

Some possible mnemonics and learning tricks for the topic are:

- To remember the difference between synchronous and asynchronous communication, think of the words "same" and "any". Synchronous communication happens at the same time, while asynchronous communication can happen at any time.
- To remember the four main protocols for real time communication, think of the acronym RTRW: RTP, RTSP, RTMP, and WebRTC. You can also associate each letter with a word related to the protocol, such as R for Real time, T for Transport, S for Streaming, M for Messaging, and W for Web.
- To remember the functions of RTP, think of the phrase "Real Time PIST": Payload type identification, Sequence numbering, Timestamping, and delivery monitoring. You can also use the word "PIST" to recall the order of the fields in the RTP header.
