## Unit 1 - Introduction of Real Time System

- A real-time system is a system that can process information and respond to events within a predictable and specific time constraint  .
- A real-time system is characterized by its ability to produce the expected result within a defined deadline (timeliness) and to coordinate independent clocks and operate together in unison (time synchronization) .
- A real-time system can be classified into two types based on the timing constraints: hard real-time system and soft real-time system .
- A hard real-time system has absolute deadlines, and if those allotted time spans are missed, a system failure will occur. For example, flight control systems, airbag systems, etc.  .
- A soft real-time system has relative deadlines, and if those allotted time spans are missed, the system performance will degrade but not fail. For example, video streaming, online gaming, etc. .
- A real-time system can also be classified into two types based on the data processing: event-triggered system and time-triggered system .
- An event-triggered system performs data processing only when an event occurs, such as a sensor input, a user command, etc. For example, a fire alarm system, a traffic light system, etc. .
- A time-triggered system performs data processing at regular intervals, regardless of the occurrence of events. For example, a clock system, a periodic backup system, etc. .
- A real-time system can have various advantages, such as increased reliability, safety, efficiency, and responsiveness  .
- A real-time system can also have various challenges, such as meeting the timing constraints, handling concurrency, managing resources, testing and debugging, etc.  .
- A real-time system can have various applications, such as industrial automation, robotics, aerospace, medical, multimedia, etc.  .
