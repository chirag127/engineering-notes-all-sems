Some possible mnemonics and learning tricks for Excel are:

- To remember the order of operations in Excel formulas, use the acronym PEMDAS, which stands for Parentheses, Exponents, Multiplication and Division, Addition and Subtraction. 
- To remember the basic functions in Excel, use the acronym SUMIF, which stands for SUM, IF, AVERAGE, COUNT, and MAX. 
- To remember the keyboard shortcuts for Excel, use the rhyme "Ctrl + C, Ctrl + V, Ctrl + X, Ctrl + Z". These shortcuts are for copying, pasting, cutting, and undoing, respectively. 
- To remember the difference between relative and absolute cell references in Excel, use the keyword "dollar". A dollar sign ($) before a row or column number means that it is fixed and will not change when copied or moved. A cell reference without a dollar sign means that it is relative and will change according to its position. 
- To remember the steps for creating a pivot table in Excel, use the acronym SLARF, which stands for Select, Insert, Arrange, Refresh, and Format. 
- To remember the steps for creating a chart in Excel, use the acronym SIT, which stands for Select, Insert, and Tweak.
