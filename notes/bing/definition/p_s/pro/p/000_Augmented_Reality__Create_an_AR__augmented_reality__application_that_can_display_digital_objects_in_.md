Augmented Reality: Create an AR (augmented reality) application that can display digital objects in the real world and interact with them. Technologies: Unity, ARKit, ARCore, Vuforia, C#.

According to OxfordDictionaries, augmented reality means a technology that superimposes a computer-generated image on a user's view of the real world, thus providing a composite view. It can span multiple sensory modalities, such as visual, auditory, haptic and olfactory. Some examples of augmented reality applications are Pokemon Go, Snapchat filters and IKEA Place.

To create an AR application that can display digital objects in the real world and interact with them, you will need some technologies such as Unity, ARKit, ARCore or Vuforia. Unity is a game engine that allows you to create 3D models and animations. ARKit and ARCore are frameworks that enable you to use your device's camera and sensors to track the position and orientation of the device in relation to the real world. Vuforia is a platform that provides features such as image recognition, object detection and cloud services for AR development. C is a programming language that you can use to write scripts for your AR application.
