## Unit 5 - Quantum Error Correction

- Quantum error correction (QEC) is a set of methods to protect quantum information—that is, quantum states—from errors due to decoherence and other quantum noise .
- Quantum information is stored in a quantum error-correcting code, which is a subspace in a larger Hilbert space. The code is designed to detect and correct errors that affect a subset of the physical qubits that encode the logical qubits.
- Quantum error correction is essential to achieve fault tolerant quantum computing that can reduce the effects of noise on stored quantum information, faulty quantum gates, faulty quantum preparation, and faulty measurements . This would allow algorithms of greater circuit depth and complexity to be executed reliably.
- A quantum error-correcting code is characterized by three parameters: the number of physical qubits n, the number of logical qubits k, and the distance d. The distance is the minimum number of physical qubits that need to be corrupted to cause an undetectable error on a logical qubit.
- A quantum error-correcting code can correct up to t errors if d > 2t. The code rate is defined as R = k/n, which measures the efficiency of the code. The code threshold is the maximum error rate per physical qubit per gate below which the code can correct errors and maintain the fidelity of the logical qubits.
- There are different types of quantum error-correcting codes, such as stabilizer codes, topological codes, subsystem codes, and concatenated codes. Each type has its own advantages and disadvantages in terms of encoding, decoding, and fault tolerance.
- A quantum error correction protocol consists of three steps: encoding, syndrome measurement, and correction. Encoding is the process of preparing the logical qubits in the code subspace using a unitary transformation or a quantum circuit. Syndrome measurement is the process of extracting information about the errors that occurred on the physical qubits using ancillary qubits and non-destructive measurements. Correction is the process of applying appropriate recovery operations to the physical qubits based on the syndrome information.
- A quantum error correction protocol can be either active or passive. Active QEC involves periodic syndrome measurements and corrections, while passive QEC relies on the inherent error-resilience of the code and does not require syndrome measurements or corrections.
- A quantum error correction protocol can be either hardware-efficient or software-efficient. Hardware-efficient QEC minimizes the number of physical qubits and gates required for the code, while software-efficient QEC minimizes the overhead and complexity of the encoding, decoding, and correction algorithms.
- A quantum error correction protocol can be either local or non-local. Local QEC restricts the interactions between the physical qubits to a limited neighborhood, while non-local QEC allows long-range interactions between the physical qubits. Local QEC is more realistic for physical implementations, while non-local QEC can achieve higher code rates and thresholds.
- A long quantum computation will require many cycles of quantum error correction. Each cycle would consist of gates acting on encoded qubits (performing the computation), followed by syndrome measurements from which errors can be inferred, and corrections.
- Quantum error correction is a challenging and active area of research, as it involves trade-offs between various factors such as code parameters, error models, physical architectures, gate sets, and computational resources . Quantum error correction is also a rich source of mathematical and physical insights, as it connects concepts from information theory, coding theory, algebra, geometry, topology, and complexity theory .
