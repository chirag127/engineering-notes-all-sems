## Unit 1 - Fundamental Concepts of Computer Science

The following diagram illustrates the basic architecture of a computer system:

```
+-----------------+     +-----------------+
|                 |     |                 |
|    Keyboard     |     |    Monitor      |
|                 |     |                 |
+--------+--------+     +--------+--------+
         |                      ^
         |                      |
         v                      |
+--------+--------+     +-------+-------+
|                 |     |               |
|    CPU          +---->+    Memory     |
|                 |     |               |
+--------+--------+     +-------+-------+
         |
         |
         v
+--------+--------+
|                 |
|    Hard Disk    |
|                 |
+-----------------+
```

The keyboard is an input device that allows the user to enter data and commands into the computer. The CPU (central processing unit) is the brain of the computer that performs arithmetic and logical operations and controls the execution of programs. The memory is a storage device that holds data and instructions temporarily while the CPU is processing them. The monitor is an output device that displays the results of the computation or the program. The hard disk is a storage device that holds data and instructions permanently for long-term use.
