### Theory of Quantum Error –Correction for the notes of the Unit 5 - Quantum Error Correction in the subject of Quantum Computing

- Quantum error correction (QEC) is used in quantum computing to protect quantum information from errors due to decoherence and other quantum noise.
- Quantum error correction is theorised as essential to achieve fault tolerant quantum computing that can reduce the effects of noise on stored quantum information, faulty quantum gates, faulty quantum measurements, and faulty quantum communication channels.
- Quantum error correction is based on encoding states into larger Hilbert spaces subject to known interactions. The encoded states are called logical states, and the unencoded states are called physical states.
- Quantum error correction relies on the following principles:
  - Redundancy: The logical state is encoded into a larger number of physical qubits, such that the loss or corruption of some qubits does not destroy the information.
  - Error detection: The errors that occur on the physical qubits can be detected by measuring some observables that do not disturb the logical state. These observables are called error syndromes.
  - Error correction: The errors that are detected can be corrected by applying some unitary operations that restore the logical state. These operations are called recovery operations.
- Quantum error correction codes are classified into different types based on their properties and methods of construction . Some examples are:
  - Stabilizer codes: These are codes that use ancilla qubits to protect the logical qubit, and are based on the stabilizer formalism of quantum mechanics. The stabilizer of a code is a set of operators that commute with each other and with the logical operators, and have eigenvalue +1 on the code space. The stabilizer codes can be further divided into subtypes such as CSS codes, Calderbank-Shor-Steane codes, and surface codes.
  - Topological codes: These are codes that use a lattice of qubits arranged on a surface such as a torus, and are based on the topological properties of the surface. The logical operators are defined by non-trivial loops on the surface, and the error syndromes are defined by local measurements on the qubits. The topological codes can be further divided into subtypes such as Kitaev's toric code, color codes, and quantum double models.
  - Concatenated codes: These are codes that use a hierarchical structure of encoding and decoding, where each level of encoding uses a smaller code to protect the logical qubits of the previous level. The concatenated codes can be further divided into subtypes such as Shor's code, Knill-Laflamme codes, and Bacon-Shor codes.
- Quantum error correction codes are characterized by some parameters that measure their performance and efficiency. Some examples are:
  - Code distance: This is the minimum number of physical qubits that need to be corrupted to cause an undetectable error on the logical qubit. The code distance determines the error threshold of the code, which is the maximum error rate that the code can tolerate.
  - Code rate: This is the ratio of the number of logical qubits to the number of physical qubits used by the code. The code rate determines the overhead of the code, which is the extra resources needed to implement the code.
  - Code dimension: This is the dimension of the code space, which is the subspace of the Hilbert space that contains the logical states. The code dimension determines the information capacity of the code, which is the amount of information that can be encoded by the code.

- A possible mnemonic to remember the principles of quantum error correction is **RED** (Redundancy, Error detection, Error correction).
- A possible mnemonic to remember the types of quantum error correction codes is **STaC** (Stabilizer codes, Topological codes, Concatenated codes).
- A possible mnemonic to remember the parameters of quantum error correction codes is **DRaD** (Distance, Rate, Dimension).
