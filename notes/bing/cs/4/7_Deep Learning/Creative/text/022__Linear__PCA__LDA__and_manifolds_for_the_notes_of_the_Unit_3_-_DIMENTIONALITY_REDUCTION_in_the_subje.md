### Linear (PCA, LDA) and manifolds for the notes of the Unit 3 - DIMENTIONALITY REDUCTION in the subject of Deep Learning

- Dimensionality reduction is the process of reducing the number of features or variables in a dataset, while preserving as much information as possible.
- Dimensionality reduction can help to improve the performance, speed, and interpretability of machine learning models, as well as to visualize high-dimensional data in lower dimensions.
- There are two main types of dimensionality reduction methods: linear and non-linear.
- Linear methods assume that the data lies on or near a linear subspace, and use linear transformations to project the data onto a lower-dimensional space.
- Non-linear methods assume that the data lies on or near a non-linear manifold, and use non-linear transformations to map the data onto a lower-dimensional space.
- Principal component analysis (PCA) and linear discriminant analysis (LDA) are two popular linear methods for dimensionality reduction.
- PCA is an unsupervised method, which means it does not use class labels or any other information about the data, except for the covariance matrix.
- PCA aims to find the directions of maximum variance in the data, and project the data onto those directions, called principal components.
- PCA can be used for data compression, noise reduction, feature extraction, and data visualization.
- LDA is a supervised method, which means it uses class labels or any other information about the data, except for the mean vectors and the within-class and between-class scatter matrices.
- LDA aims to find the directions that maximize the separation between different classes, and project the data onto those directions, called linear discriminants.
- LDA can be used for classification, feature extraction, and data visualization.
- Manifolds are mathematical objects that locally resemble Euclidean spaces, but globally may have a more complex structure.
- Manifolds can be used to model high-dimensional data that lies on or near a lower-dimensional surface, such as images, speech, text, or graphs.
- Non-linear methods for dimensionality reduction, such as t-distributed stochastic neighbor embedding (t-SNE), isometric mapping (Isomap), locally linear embedding (LLE), or autoencoders, can be used to discover and preserve the manifold structure of the data, and map the data onto a lower-dimensional space.
- Non-linear methods can capture the intrinsic geometry and topology of the data, and reveal the hidden patterns and clusters in the data.
- Non-linear methods can be used for data visualization, clustering, anomaly detection, and feature extraction.
