### Linear (PCA, LDA) and manifolds for the notes of the Unit 3 - DIMENTIONALITY REDUCTION in the subject of Deep Learning

- Dimensionality reduction is the process of reducing the number of features or variables in a dataset, while preserving as much information as possible.
- Dimensionality reduction can help to improve the performance, speed, and interpretability of machine learning models, as well as to visualize high-dimensional data in lower dimensions.
- There are two main types of dimensionality reduction methods: linear and non-linear.
- Linear methods assume that the data lies on or near a linear subspace of the original feature space, and they use linear transformations to project the data onto a lower-dimensional space.
- Non-linear methods assume that the data lies on or near a non-linear manifold of the original feature space, and they use non-linear transformations to map the data onto a lower-dimensional space.
- Principal component analysis (PCA) and linear discriminant analysis (LDA) are two popular linear methods for dimensionality reduction.
- PCA is an unsupervised method, which means it does not use class labels or any other information about the data, except for the covariance matrix.
- PCA aims to find the directions of maximum variance in the data, and to project the data onto the orthogonal principal components, which are the eigenvectors of the covariance matrix.
- PCA can be used for data compression, noise reduction, feature extraction, and data visualization.
- LDA is a supervised method, which means it uses class labels or any other information about the data, except for the mean vectors and the scatter matrices.
- LDA aims to find the directions of maximum discrimination between different classes in the data, and to project the data onto the linear discriminants, which are the eigenvectors of the ratio of the between-class scatter matrix and the within-class scatter matrix.
- LDA can be used for classification, feature extraction, and data visualization.
- A mnemonic to remember the difference between PCA and LDA is: PCA preserves variance, LDA preserves discrimination.
- Manifolds are mathematical objects that locally resemble Euclidean spaces, but globally may have a more complex structure.
- Manifolds can be used to model high-dimensional data that lies on or near a lower-dimensional surface, such as images, speech, text, or graphs.
- Manifold learning is a class of non-linear methods for dimensionality reduction that aim to discover the underlying manifold structure of the data, and to map the data onto a lower-dimensional space that preserves the intrinsic geometry of the manifold.
- Manifold learning can be used for data visualization, clustering, anomaly detection, and feature extraction.
- Some examples of manifold learning methods are: Isomap, Locally Linear Embedding (LLE), Laplacian Eigenmaps, Hessian Eigenmaps, and t-distributed Stochastic Neighbor Embedding (t-SNE).
- A mnemonic to remember the difference between linear and non-linear methods is: Linear methods preserve global structure, non-linear methods preserve local structure.
