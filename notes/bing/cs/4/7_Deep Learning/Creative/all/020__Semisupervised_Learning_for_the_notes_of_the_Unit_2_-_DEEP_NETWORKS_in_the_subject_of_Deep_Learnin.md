### Semi-supervised Learning for the notes of the Unit 2 - DEEP NETWORKS in the subject of Deep Learning

- Semi-supervised learning is a type of machine learning that uses both labeled and unlabeled data for training and inference .
- Semi-supervised learning allows neural networks to mimic human inductive logic and sort unknown information fast and accurately without human intervention.
- Semi-supervised learning is useful for problems where there is a large amount of input data but only a few reference points available, such as image classification, natural language processing, speech recognition, etc .
- Semi-supervised learning can be divided into two main categories: generative and discriminative.
  - Generative methods assume that the data is generated by some underlying probabilistic model and try to learn the parameters of the model from both labeled and unlabeled data.
  - Discriminative methods directly learn the decision boundary or the conditional probability of the labels given the inputs from both labeled and unlabeled data.
- Some common techniques for semi-supervised learning are   :
  - Self-training: The model is first trained on the labeled data and then used to predict labels for the unlabeled data. The most confident predictions are added to the labeled set and the model is retrained on the enlarged set.
  - Co-training: The model is split into two independent classifiers that operate on different views or features of the data. Each classifier is trained on the labeled data and then used to label the unlabeled data for the other classifier. The most confident predictions are added to the labeled set and the process is repeated.
  - Pseudo-labeling: The model is trained on the labeled data and then used to generate pseudo-labels for the unlabeled data. The pseudo-labeled data is added to the labeled set with a lower weight and the model is retrained on the enlarged set.
  - Graph-based methods: The model constructs a graph where the nodes are the data points and the edges represent the similarity or distance between them. The labels are propagated from the labeled nodes to the unlabeled nodes based on the graph structure.
  - Consistency regularization: The model is trained to produce consistent outputs for the unlabeled data under different perturbations, such as noise, augmentation, dropout, etc. The intuition is that the model should learn the invariant features of the data that are robust to the perturbations.
- Some advantages of semi-supervised learning are :
  - It can improve the performance and generalization of the model by leveraging the unlabeled data that is usually abundant and cheap to obtain.
  - It can reduce the dependency on human annotation that is often costly, time-consuming, and prone to errors.
  - It can capture the underlying structure and distribution of the data that may not be reflected by the labeled data alone.
- Some disadvantages of semi-supervised learning are:
  - It can introduce noise and bias to the model by using unreliable or inaccurate labels from the unlabeled data.
  - It can suffer from the domain shift problem, where the unlabeled data may come from a different distribution than the labeled data, leading to poor generalization.
  - It can be challenging to design and implement effective semi-supervised learning algorithms that can balance the trade-off between exploiting the labeled data and exploring the unlabeled data.
