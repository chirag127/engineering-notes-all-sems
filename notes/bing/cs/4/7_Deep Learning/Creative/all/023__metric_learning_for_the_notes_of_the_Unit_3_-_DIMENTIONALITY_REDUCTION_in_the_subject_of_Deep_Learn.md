### Metric learning for the notes of the Unit 3 - DIMENTIONALITY REDUCTION in the subject of Deep Learning

- Metric learning is a branch of machine learning that aims to learn a similarity or distance function that can measure how similar or dissimilar two or more objects are.
- Metric learning can be useful for tasks such as face recognition, person re-identification, semantic textual similarity, speaker verification, etc. where the goal is to compare and match different instances of the same or different classes.
- Metric learning can also be used for dimensionality reduction, where the goal is to project the high-dimensional data into a lower-dimensional space that preserves the relevant information for the task at hand.
- Metric learning can be performed in a supervised or unsupervised way, depending on the type and amount of supervision available for the data.
  - Supervised metric learning: the algorithm has access to a set of data points, each of them belonging to a class (label) as in a standard classification problem. The algorithm tries to learn a metric that can separate the data points of different classes and bring the data points of the same class closer together.
  - Unsupervised metric learning: the algorithm has no access to any class labels or pairwise constraints for the data. The algorithm tries to learn a metric that can capture the intrinsic structure or distribution of the data, such as clusters, manifolds, etc.
- Metric learning can be implemented using deep neural networks, which can learn complex and nonlinear mappings from the input space to the output space. Deep metric learning can leverage the advantages of deep learning, such as high expressiveness, scalability, end-to-end learning, etc.
- Deep metric learning can be formulated as an optimization problem, where the objective is to minimize a loss function that measures the discrepancy between the desired and the actual metric. The loss function can be designed based on different criteria, such as contrastive, triplet, quadruplet, etc.
  - Contrastive loss: the loss function is based on pairs of data points, where each pair consists of an anchor point and a positive or negative point. The loss function tries to minimize the distance between the anchor and the positive point, and maximize the distance between the anchor and the negative point.
  - Triplet loss: the loss function is based on triplets of data points, where each triplet consists of an anchor point, a positive point, and a negative point. The loss function tries to minimize the distance between the anchor and the positive point, and maximize the margin between the distance of the anchor-positive pair and the distance of the anchor-negative pair.
  - Quadruplet loss: the loss function is based on quadruplets of data points, where each quadruplet consists of two anchor points, a positive point, and a negative point. The loss function tries to minimize the distance between the two anchor points and the positive point, and maximize the margin between the distance of the anchor-positive pair and the distance of the anchor-negative pair.

- A possible mnemonic to remember the difference between contrastive, triplet, and quadruplet loss is: **C**ontrastive loss uses **P**airs, **T**riplet loss uses **T**riplets, and **Q**uadruplet loss uses **Q**uadruplets. Alternatively, one can think of the number of data points involved in each loss function as the first letter of the loss function name: **C**ontrastive loss uses **2** data points, **T**riplet loss uses **3** data points, and **Q**uadruplet loss uses **4** data points.
