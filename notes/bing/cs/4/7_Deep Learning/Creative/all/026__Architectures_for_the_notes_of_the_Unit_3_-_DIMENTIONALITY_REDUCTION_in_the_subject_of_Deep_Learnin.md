### Architectures for the notes of the Unit 3 - DIMENTIONALITY REDUCTION in the subject of Deep Learning

- Dimensionality reduction is the process of reducing the number of features or variables in a dataset, while preserving the essential information or structure of the data.
- Dimensionality reduction can help to improve the performance, efficiency, and interpretability of deep learning models, as well as to reduce the risk of overfitting and the curse of dimensionality.
- There are two main types of dimensionality reduction techniques: feature selection and feature extraction.
- Feature selection methods select a subset of the original features that are most relevant or informative for the task, such as filter methods, wrapper methods, and embedded methods.
- Feature extraction methods transform the original features into a lower-dimensional space, where each new feature is a combination of the original features, such as principal component analysis (PCA), linear discriminant analysis (LDA), and kernel PCA.
- Some of the popular architectures for dimensionality reduction in deep learning are:

  - Autoencoder: An autoencoder is a type of neural network that learns to reconstruct its input from a lower-dimensional representation, called the latent space or the bottleneck. The autoencoder consists of two parts: an encoder that maps the input to the latent space, and a decoder that maps the latent space back to the input. The autoencoder can be trained by minimizing the reconstruction error, which is the difference between the input and the output. An autoencoder can perform nonlinear dimensionality reduction, and can also learn useful features for other tasks, such as classification or clustering. 

  - Kronecker Multi-layer Architecture: This is a novel type of dimensionality reduction architecture that is based on fast matrix multiplication of a Kronecker product decomposition. The Kronecker product is a way of combining two matrices into a larger matrix, such that each element of the first matrix is multiplied by the entire second matrix. The Kronecker product decomposition is a way of approximating a large matrix by a Kronecker product of smaller matrices. The Kronecker multi-layer architecture can be viewed as a sparsification of an extended fully connected network, where the weight matrix of each layer is decomposed into a Kronecker product of smaller matrices. This reduces the number of parameters and the computational complexity of the network, while preserving the expressive power and the accuracy.  

  - Self-Organized Map (SOM): A SOM is a type of unsupervised neural network that learns to map high-dimensional data into a low-dimensional grid of neurons, called the map. The SOM preserves the topology and the similarity of the data, such that nearby neurons in the map correspond to similar data points in the input space. The SOM can be trained by updating the weights of the neurons based on their distance to the input vector and their neighborhood in the map. The SOM can perform dimensionality reduction, clustering, and visualization of the data.
