### Hyperledger composer tool for the notes of the Unit 5 - Hyperledger Fabric (B) in the subject of Block chain Architecture Design

- Hyperledger composer is a set of open source tools that allows business owners, operators, and developers a way to create blockchain applications and smart contracts aimed at solving business problems and/or improving operational efficiencies.
- It is an example of a commercial application of blockchain-as-a-service (BaaS), which means that users can access the blockchain infrastructure and platform as a cloud-based service.
- Hyperledger composer is part of the Hyperledger project, which is a collaborative effort to advance cross-industry blockchain technologies hosted by the Linux Foundation .
- Hyperledger composer was designed to facilitate the creation of open-source blockchain applications that fostered collaboration within organizations and business networks.
- Hyperledger composer was built on top of Hyperledger Fabric, which is a permissioned blockchain framework that supports pluggable consensus, smart contracts, and data privacy .
- Hyperledger composer provides a high-level abstraction layer that simplifies the development of blockchain applications by using a modeling language, a RESTful API, and a web-based user interface .
- Hyperledger composer allows developers to define the business network, which consists of the participants, assets, transactions, and access control rules .
- Hyperledger composer also allows developers to write the business logic, which is the code that implements the transactions and the smart contracts .
- Hyperledger composer supports various programming languages, such as JavaScript, TypeScript, and Go, for writing the business logic .
- Hyperledger composer enables the deployment and testing of the blockchain applications on a local or cloud-based environment, as well as the integration with existing systems and data sources .
- Hyperledger composer has a web-based user interface called Playground, which allows users to interact with the business network, create and submit transactions, and monitor the blockchain state .
- Hyperledger composer also has a command-line interface (CLI) that allows users to perform various tasks, such as installing, starting, and upgrading the business network, generating the RESTful API, and creating the network cards .

Some possible mnemonics and learning tricks for Hyperledger composer are:

- To remember the components of the business network, use the acronym **PATA**: **P**articipants, **A**ssets, **T**ransactions, and **A**ccess control rules.
- To remember the steps of developing a blockchain application with Hyperledger composer, use the acronym **DIDIT**: **D**efine the business network, **I**mplement the business logic, **D**eploy and test the application, **I**ntegrate with existing systems, and **T**ry out the user interface.
- To remember the difference between Hyperledger composer and Hyperledger Fabric, use the analogy of a car: Hyperledger Fabric is the engine and the chassis, while Hyperledger composer is the dashboard and the steering wheel.
