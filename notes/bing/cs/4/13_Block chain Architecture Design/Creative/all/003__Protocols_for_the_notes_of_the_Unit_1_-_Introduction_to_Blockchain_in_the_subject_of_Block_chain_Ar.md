### Protocols for the notes of the Unit 1 - Introduction to Blockchain in the subject of Block chain Architecture Design

- Protocols are basic sets of rules that ensure data sharing between computers or computing systems.
- In the case of cryptocurrencies, they set out the structure of the blockchain and the rules for managing the distributed database, which will guarantee that assets are traded securely online.
- Blockchain protocols are a set of protocols used to govern the blockchain network. The rules define the interface of the network, interaction between the computers, incentives, kind of data, etc.
- The protocols aim to address the four principles:
  - Decentralization: The network should not be controlled by any single entity or authority.
  - Security: The network should be able to resist attacks and ensure the validity and integrity of the data.
  - Scalability: The network should be able to handle a large number of transactions and users without compromising performance or security.
  - Consensus: The network should be able to reach an agreement on the state of the data among all the participants.
- Blockchain protocols can be classified into different types based on various factors, such as the consensus mechanism, the level of permission, the type of data, the target industry, etc .
- Some of the common types of blockchain protocols are :
  - Hyperledger: Hyperledger is an open-source framework that is developed by Linux. It helps the enterprises to provide solutions for various industries, such as finance, healthcare, supply chain, etc. It is a permissioned blockchain protocol that uses various consensus mechanisms, such as Proof of Authority, Practical Byzantine Fault Tolerance, etc.
  - Quorum: Quorum is another enterprise blockchain protocol that aims to address the problems related to finance. It is a permissioned blockchain protocol that is based on Ethereum. It uses a voting-based consensus mechanism that allows the participants to validate transactions in a private and secure way.
  - Ethereum: Ethereum is a public blockchain protocol that enables the creation and execution of smart contracts and decentralized applications. It uses a Proof of Work consensus mechanism that requires the miners to solve complex mathematical problems to validate transactions and earn rewards. It also supports a transition to a Proof of Stake consensus mechanism that requires the validators to stake their coins to validate transactions and earn rewards.
  - Bitcoin: Bitcoin is the first and the most popular cryptocurrency that runs on a public blockchain protocol. It uses a Proof of Work consensus mechanism that requires the miners to solve complex mathematical problems to validate transactions and earn rewards. It is designed to be a peer-to-peer electronic cash system that enables fast and secure transactions without intermediaries.
  - Cardano: Cardano is a public blockchain protocol that aims to provide a platform for smart contracts and decentralized applications. It uses a Proof of Stake consensus mechanism that requires the validators to stake their coins to validate transactions and earn rewards. It is designed to be scalable, secure, and interoperable with other blockchain protocols.

- A possible mnemonic to remember the four principles of blockchain protocols is **DSSC** (Decentralization, Security, Scalability, Consensus).
- A possible mnemonic to remember the five types of blockchain protocols is **HQECB** (Hyperledger, Quorum, Ethereum, Cardano, Bitcoin).
