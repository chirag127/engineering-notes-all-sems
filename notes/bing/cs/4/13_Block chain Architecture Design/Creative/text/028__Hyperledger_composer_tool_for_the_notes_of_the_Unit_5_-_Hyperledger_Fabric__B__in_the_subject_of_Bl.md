### Hyperledger Composer Tool

- Hyperledger Composer is a set of open source tools that allows business owners, operators, and developers a way to create blockchain applications and smart contracts aimed at solving business problems and/or improving operational efficiencies .
- It is an example of a commercial application of blockchain-as-a-service (BaaS) .
- It is part of the Hyperledger project, which is a collaborative effort to advance cross-industry blockchain technologies  .
- Hyperledger Composer provides a high-level abstraction layer for developing blockchain applications, hiding the complexity of the underlying blockchain infrastructure and protocols  .
- Hyperledger Composer allows users to model their business network, define the assets, participants, and transactions, and write the business logic using JavaScript  .
- Hyperledger Composer also provides a web-based user interface for testing and deploying the blockchain applications, as well as generating REST APIs and client SDKs for interacting with the blockchain network  .
- Hyperledger Composer was designed to work with Hyperledger Fabric, which is a permissioned blockchain platform that supports pluggable consensus, smart contracts, and data privacy  .
- As of August 2021, Hyperledger Composer is End of Life. None of the maintainers are actively developing new features or providing support via GitHub issues.
