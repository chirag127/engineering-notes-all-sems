### Basic crypto primitives for the notes of the Unit 1 - Introduction to Blockchain in the subject of Block chain Architecture Design

- Cryptographic primitives are the low-level algorithms that are used to build security protocols and applications in blockchain  .
- Cryptographic primitives provide the following functions in blockchain  :
  - **Security**: To protect the transactions and data from unauthorized access, modification, or deletion.
  - **Privacy**: To ensure that only the intended parties can access the sensitive information or identity of the users.
  - **Integrity**: To verify that the transactions and data have not been tampered with or corrupted.
  - **Authenticity**: To prove the origin and validity of the transactions and data.
  - **Non-repudiation**: To prevent the parties from denying their involvement or responsibility in the transactions and data.
- Some of the common cryptographic primitives used in blockchain are  :
  - **Hash functions**: These are mathematical functions that map any input data to a fixed-length output, called a hash or digest. Hash functions have the following properties:
    - **One-way**: It is easy to compute the hash from the input, but hard to find the input from the hash.
    - **Collision-resistant**: It is hard to find two different inputs that produce the same hash.
    - **Deterministic**: The same input always produces the same hash.
    - **Uniform**: The hash values are evenly distributed over the output space.
    - Hash functions are used in blockchain to create unique identifiers for transactions and blocks, to verify the integrity of the data, and to implement proof-of-work consensus algorithms.
    - Examples of hash functions used in blockchain are SHA-256, SHA-512, and Ethash.
  - **Digital signatures**: These are schemes that allow the parties to sign and verify messages using public-key cryptography. Digital signatures have the following properties:
    - **Unforgeable**: It is hard to create a valid signature without knowing the private key of the signer.
    - **Verifiable**: Anyone can verify the signature using the public key of the signer and the message.
    - **Non-repudiable**: The signer cannot deny having signed the message.
    - Digital signatures are used in blockchain to authenticate the transactions and the blocks, to prove the ownership of the assets, and to implement access control mechanisms.
    - Examples of digital signature schemes used in blockchain are Elliptic Curve Digital Signature Algorithm (ECDSA) and Schnorr signatures.
  - **Encryption**: These are schemes that allow the parties to encrypt and decrypt messages using secret keys or public-key cryptography. Encryption has the following properties:
    - **Confidentiality**: Only the authorized parties can decrypt the message using the correct key.
    - **Integrity**: The message cannot be modified or corrupted without being detected.
    - **Privacy**: The message does not reveal any information about the content or the parties involved.
    - Encryption is used in blockchain to protect the sensitive data or identity of the users, to implement confidential transactions, and to enable secure communication channels.
    - Examples of encryption schemes used in blockchain are AES, RSA, and homomorphic encryption.
