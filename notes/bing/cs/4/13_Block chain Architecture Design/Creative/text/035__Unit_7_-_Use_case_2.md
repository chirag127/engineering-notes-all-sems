## Unit 7 - Use case 2

- Use case 2 is a scenario where a user wants to book a flight ticket online using an AI assistant.
- The AI assistant should be able to perform the following tasks:
  - Understand the user's intent and preferences for the flight, such as the destination, date, time, budget, airline, etc.
  - Search for the best available options that match the user's criteria and present them in a clear and concise way.
  - Handle the user's queries and requests regarding the flight details, such as the duration, layovers, baggage allowance, cancellation policy, etc.
  - Confirm the user's selection and proceed to the payment process, such as asking for the user's credit card information, billing address, etc.
  - Send the user a confirmation email with the flight itinerary and ticket details.
- The AI assistant should also be able to handle the following situations:
  - If the user changes their mind or wants to modify their flight details, the AI assistant should be able to cancel the previous booking and start a new one.
  - If the user encounters any issues or errors during the booking process, the AI assistant should be able to provide assistance and guidance to resolve them.
  - If the user wants to cancel their flight after booking, the AI assistant should be able to inform them about the cancellation policy and process their refund if applicable.
