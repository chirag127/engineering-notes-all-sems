## Unit 4 - Beowulf Cluster

- A Beowulf cluster is a type of parallel computing system that consists of a collection of commodity computers connected by a local area network.
- The computers in a Beowulf cluster run the same operating system, usually Linux or another Unix-like system, and share the same file system.
- The main purpose of a Beowulf cluster is to provide high-performance computing at a low cost, by using off-the-shelf hardware and open-source software.
- The term Beowulf cluster was coined by Thomas Sterling and Donald Becker, who built the first such system at NASA in 1994, named after the epic hero Beowulf.
- The design of a Beowulf cluster is based on the following principles:
  - Single-system image: The cluster should appear as a single system to the user and the applications, hiding the complexity and heterogeneity of the underlying hardware and software.
  - Scalability: The cluster should be able to grow in size and performance by adding more nodes, without requiring major changes to the system architecture or software.
  - High availability: The cluster should be able to tolerate failures of individual nodes or components, and provide mechanisms for fault detection, recovery, and redundancy.
  - High performance: The cluster should be able to exploit the parallelism of the applications and the network, and provide efficient communication and synchronization among the nodes.
- The main components of a Beowulf cluster are:
  - Nodes: The individual computers that perform the computation and run the applications. Nodes can be classified into master nodes and worker nodes. The master node is responsible for coordinating the cluster, distributing the tasks, and collecting the results. The worker nodes are the ones that execute the tasks assigned by the master node. Nodes can have different hardware specifications, such as CPU, memory, disk, and network interface.
  - Network: The medium that connects the nodes and enables data transfer and communication among them. The network can be wired or wireless, and can use different protocols and topologies, such as Ethernet, InfiniBand, or mesh. The network performance is measured by the bandwidth, latency, and reliability.
  - Software: The programs and tools that run on the nodes and provide the functionality and services of the cluster. The software can be divided into three layers: operating system, middleware, and application. The operating system is the basic software that manages the hardware resources and provides the interface to the user and the applications. The middleware is the software that implements the parallel programming models and libraries, such as MPI, PVM, or OpenMP, and provides the features for cluster management, such as scheduling, load balancing, monitoring, and security. The application is the software that performs the specific task or problem that the cluster is designed to solve, such as scientific computing, data analysis, or machine learning.
