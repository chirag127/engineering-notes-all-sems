### Parallel Virtual Machine (PVM) for Beowulf Cluster

- Parallel Virtual Machine (PVM) is a software system that enables a collection of heterogeneous computers to be used as a coherent and flexible concurrent computational resource, or a "parallel virtual machine".
- PVM can be used to create and manage a Beowulf cluster, which is a type of high-performance computing system that consists of a group of personal computers (PCs) running a Unix-like operating system and connected by a fast network.
- PVM provides a set of library functions that allow a user to
  - add or remove computers from the parallel virtual machine dynamically, 
  - spawn parallel tasks on any of the available computers, 
  - exchange data and messages among the tasks using various communication patterns, and 
  - synchronize and coordinate the tasks using barriers, broadcasts, and groups.
- PVM supports multiple programming languages, such as C, C++, Fortran, Java, and Python, and multiple communication protocols, such as TCP/IP, UDP, and shared memory.
- PVM can be used to implement various parallel algorithms and applications, such as matrix multiplication, image processing, genetic algorithms, and molecular dynamics.
- PVM can also be used to combine multiple Beowulf clusters at a site into a grid of clusters, which can increase the scalability and fault tolerance of the parallel virtual machine.
- PVM was first released in the early 1990s as an outgrowth of an ongoing computing research project involving Oak Ridge National Laboratory, the University of Tennessee, and Emory University.
- PVM is available as a free and open source software under the BSD license.
