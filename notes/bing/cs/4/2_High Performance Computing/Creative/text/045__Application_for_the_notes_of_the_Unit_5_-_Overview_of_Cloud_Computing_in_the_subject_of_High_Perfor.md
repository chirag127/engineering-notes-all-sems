### Application for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing

- Cloud computing is the delivery of computing services over the internet, such as servers, storage, databases, networking, software, analytics, and intelligence.
- Cloud computing offers various benefits, such as scalability, elasticity, cost-efficiency, reliability, security, and innovation.
- Cloud computing can be classified into three service models: Infrastructure as a Service (IaaS), Platform as a Service (PaaS), and Software as a Service (SaaS).
- IaaS provides the basic computing resources, such as virtual machines, storage, networks, and operating systems, that can be rented and managed by the user.
- PaaS provides the development and deployment environment, such as programming languages, tools, libraries, and frameworks, that can be used by the user to create and run applications.
- SaaS provides the ready-made applications, such as email, office, CRM, and ERP, that can be accessed by the user through a web browser or a mobile app.
- Cloud computing can also be classified into four deployment models: public cloud, private cloud, hybrid cloud, and community cloud.
- Public cloud is the cloud service that is offered by a third-party provider to the general public over the internet, such as Amazon Web Services, Microsoft Azure, and Google Cloud Platform.
- Private cloud is the cloud service that is operated and maintained by a single organization for its own use, either on-premise or off-premise, such as VMware, OpenStack, and IBM Cloud Private.
- Hybrid cloud is the cloud service that combines the public and private clouds, allowing the data and applications to move between them, such as AWS Outposts, Azure Stack, and Google Anthos.
- Community cloud is the cloud service that is shared and managed by a group of organizations that have common goals, interests, or requirements, such as government, education, or healthcare.
- Cloud computing poses various challenges and issues, such as data privacy, security, compliance, interoperability, portability, performance, availability, and vendor lock-in.
- Cloud computing requires various technologies and standards, such as virtualization, containerization, orchestration, RESTful APIs, JSON, XML, OAuth, OpenID Connect, and Cloud Native Computing Foundation (CNCF).
- Cloud computing is closely related to high performance computing (HPC), which is the use of specialized hardware and software to solve complex and large-scale problems that require a lot of computing power, such as scientific simulations, big data analytics, and artificial intelligence.
- Cloud computing can enable HPC by providing on-demand and scalable computing resources, reducing the capital and operational costs, and enhancing the collaboration and innovation.
- Cloud computing can also benefit from HPC by improving the performance, efficiency, and reliability of the cloud services, and enabling new applications and use cases, such as edge computing, serverless computing, and quantum computing.
