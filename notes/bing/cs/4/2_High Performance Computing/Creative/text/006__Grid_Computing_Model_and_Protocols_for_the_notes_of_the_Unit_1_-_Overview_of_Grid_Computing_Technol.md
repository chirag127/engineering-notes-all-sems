### Grid Computing Model and Protocols

- Grid computing is a distributed architecture of multiple computers connected by networks to accomplish a joint task. These tasks are compute-intensive and difficult for a single machine to handle. 
- Grid computing is enabled via an open set of standards and protocols such as open grid services architecture (OGSA) that allow communication across heterogeneous systems and environments that are geographically dispersed. 
- Grid computing is specially made for scientific application but now a day is becoming important model in the commercial application. 
- Grid computing can be thought of as a distributed system with non-interactive workloads that involve many files. 
- Grid computing is distinguished from conventional high-performance computing systems such as cluster computing in that grid computers have each node set to perform a different task/application. 
- Grid computing model consists of four main components: resources, middleware, brokers, and users. 
  - Resources are the hardware and software components that provide computing power, storage, network, and other services. 
  - Middleware is the software layer that enables the coordination, communication, and management of resources across the grid. 
  - Brokers are the agents that match the user requests with the available resources and schedule the execution of tasks. 
  - Users are the individuals or organizations that submit tasks to the grid and receive the results. 
- Grid computing protocols are the rules and conventions that govern the interaction and communication among the grid components. 
- Grid protocols can be classified into three broad categories: TCP based, UDP based, and application layer protocols. 
  - TCP based protocols are reliable, connection-oriented, and congestion-controlled, but they may suffer from high latency and overhead. Examples are TCP, SCTP, and DCCP. 
  - UDP based protocols are unreliable, connectionless, and fast, but they may suffer from packet loss and congestion. Examples are UDP, UDT, and RUDP. 
  - Application layer protocols are designed to meet the specific requirements and challenges of grid computing, such as security, scalability, fault-tolerance, and adaptability. Examples are GridFTP, GSI, and OGSA.
