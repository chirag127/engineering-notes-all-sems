### Platform for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing

- Cloud computing is the delivery of computing services over the internet, such as servers, storage, databases, networking, software, analytics, and intelligence  .
- Cloud computing offers faster innovation, flexible resources, and economies of scale, as users only pay for the services they use and can scale up or down as needed  .
- Cloud computing has several characteristics, such as on-demand self-service, broad network access, resource pooling, rapid elasticity, and measured service.
- There are three primary types of cloud deployments: public cloud, private cloud, and hybrid cloud.
  - Public cloud: The cloud services are provided by a third-party provider over the public internet and are available to anyone who wants to use them. Examples of public cloud providers are Microsoft Azure, IBM Cloud, Google Cloud, and Amazon Web Services.
  - Private cloud: The cloud services are used exclusively by a single organization and are hosted on a private network. The organization can either manage the cloud infrastructure itself or hire a third-party provider to do so. Private cloud offers more control, security, and customization than public cloud.
  - Hybrid cloud: The cloud services are a combination of public and private cloud, allowing data and applications to move between them. Hybrid cloud offers more flexibility, scalability, and cost-efficiency than using only one type of cloud.
- There are three main categories of cloud computing services: Infrastructure as a Service (IaaS), Platform as a Service (PaaS), and Software as a Service (SaaS).
  - IaaS: The cloud provider offers the basic computing infrastructure, such as servers, storage, and networking, and the user can install and run any software on it. The user has more control and responsibility over the configuration and management of the infrastructure. Examples of IaaS providers are Microsoft Azure, IBM Cloud, Google Cloud, and Amazon Web Services.
  - PaaS: The cloud provider offers the computing platform, such as operating system, middleware, and development tools, and the user can create and deploy applications on it. The user has less control and responsibility over the underlying infrastructure, but more flexibility and productivity in developing applications. Examples of PaaS providers are Microsoft Azure, IBM Cloud, Google Cloud, and Amazon Web Services.
  - SaaS: The cloud provider offers the software applications, such as email, office, CRM, and ERP, and the user can access them over the internet. The user has no control or responsibility over the infrastructure or the platform, but can use the applications as a service. Examples of SaaS providers are Microsoft Office 365, Google Workspace, Salesforce, and SAP.
