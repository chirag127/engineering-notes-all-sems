A cluster system is a type of parallel or distributed computing system that consists of a collection of interconnected stand-alone computers that work together as a single, integrated computing resource. A cluster system can provide faster computational speed, enhanced data integrity, and higher availability than a single computer . A cluster system can be classified into different types based on the hardware and software architecture, such as symmetric multiprocessing (SMP), massively parallel processing (MPP), and grid computing.
