## Unit 5 - Overview of Cloud Computing

Cloud computing is the delivery of computing services such as servers, storage, databases, networking, software, analytics, and intelligence over the internet. Cloud computing enables users to access scalable, on-demand, and pay-as-you-go resources without having to invest in physical infrastructure.

The following diagram illustrates the basic architecture of a cloud computing system:

```

|                 |       |                 |       |                 |

|                 |       |                 |       |                 |

|                 |       |                 |       |                 |
+-----------------+       +-----------------+       +-----------------+
|                 |       |                 |       |                 |
|  Web Browser    |       |  Application    |       |  Database       |
|                 |       |  Server         |       |                 |
+-----------------+       +-----------------+       +-----------------+
```

The front end is the part of the cloud computing system that the user interacts with. It consists of user devices, web browsers, cloud clients, and cloud platforms. The user devices can be any device that can access the internet, such as a computer, a smartphone, or a tablet. The web browser is the software that allows the user to access web-based applications and services. The cloud client is the software that runs on the user device and communicates with the cloud services. The cloud platform is the software that provides the tools and frameworks for developing and deploying cloud applications.

The back end is the part of the cloud computing system that provides the core functionality and resources. It consists of cloud servers, application servers, middleware, operating systems, virtualization, hardware, and cloud providers. The cloud servers are the physical or virtual machines that run the cloud applications and services. The application server is the software that hosts and executes the cloud applications. The middleware is the software that connects the different components of the cloud system and enables communication and data exchange. The operating system is the software that manages the hardware and software resources of the cloud servers. The virtualization is the technology that allows the creation and management of multiple virtual machines on a single physical machine. The hardware is the physical equipment that supports the cloud system, such as processors, memory, disks, and network devices. The cloud provider is the organization that owns and operates the cloud infrastructure and offers cloud services to the users.

The cloud services are the specific capabilities and functions that the cloud system provides to the users. They can be categorized into three main types: infrastructure as a service (IaaS), platform as a service (PaaS), and software as a service (SaaS). IaaS is the provision of basic computing resources such as servers, storage, and networking. PaaS is the provision of tools and frameworks for developing and deploying cloud applications. SaaS is the provision of ready-to-use cloud applications and software. The cloud services also include other types of services, such as storage, database, analytics, security, networking, and intelligence. These services enable the users to store, process, analyze, secure, and optimize their data and applications in the cloud.
