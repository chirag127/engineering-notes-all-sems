Service Oriented Architecture (SOA) is a software design approach that focuses on discrete services that can be reused and combined to create applications. Services are self-contained units of functionality that provide a simple interface to the requester and hide the underlying complexity. Services can communicate with each other using a common language and protocol over a network.
