### Cyber infrastructure for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing

- Cloud computing is a model of delivering computing resources as services over the internet, such as software, platforms, infrastructure, and data.
- Cloud infrastructure is a collection of the components and elements required to provide cloud computing. This includes:
  - Computing power: The servers, processors, and virtual machines that perform the computation and processing of data and applications.
  - Networking: The routers, switches, firewalls, load balancers, and other devices that enable the communication and connectivity of cloud resources.
  - Storage: The disks, drives, and databases that store the data and applications in the cloud.
  - Interface: The software, APIs, and portals that enable users to access, manage, and monitor the cloud resources.
- Cloud infrastructure can be deployed in different models, such as:
  - Public cloud: The cloud infrastructure is owned and operated by a third-party provider, such as Amazon Web Services, Microsoft Azure, or Google Cloud Platform, and is shared by multiple users or tenants.
  - Private cloud: The cloud infrastructure is owned and operated by a single organization, and is dedicated to its own use. It can be hosted on-premise or off-premise by a cloud provider or a third-party vendor.
  - Hybrid cloud: The cloud infrastructure is a combination of public and private clouds, and allows the organization to use the best of both worlds. It can enable data and application portability, scalability, and security.
  - Multi-cloud: The cloud infrastructure is a combination of multiple public clouds, and allows the organization to use the best services and features from different providers. It can enable cost optimization, performance improvement, and risk mitigation.
- Cloud infrastructure can be accessed and consumed in different service models, such as:
  - IaaS (Infrastructure-as-a-Service): The cloud provider offers the basic infrastructure components, such as servers, storage, and networking, and the user can provision, configure, and manage them as needed. The user is responsible for the operating system, middleware, and applications. Examples: Amazon EC2, Google Compute Engine, Microsoft Azure Virtual Machines.
  - PaaS (Platform-as-a-Service): The cloud provider offers the infrastructure components, as well as the platform layer, such as operating system, middleware, and runtime environment, and the user can deploy and run their own applications. The user is responsible for the application code and data. Examples: Amazon Elastic Beanstalk, Google App Engine, Microsoft Azure App Service.
  - SaaS (Software-as-a-Service): The cloud provider offers the infrastructure components, the platform layer, and the application layer, and the user can access and use the software applications over the internet. The user is responsible for the input and output data. Examples: Google Workspace, Microsoft Office 365, Salesforce.
- Cloud infrastructure security is a multi-faceted endeavor, involving best practices in user access and privileges, hardware and software security, virtualization, firewalls, and other processes used to protect data and infrastructure . Some of the challenges and solutions for cloud infrastructure security are:
  - Data security: The data stored and transmitted in the cloud can be vulnerable to unauthorized access, modification, or deletion. To ensure data security, the user can encrypt the data at rest and in transit, use strong authentication and authorization mechanisms, and backup and restore the data regularly.
  - Infrastructure security: The infrastructure components in the cloud can be vulnerable to attacks, such as denial-of-service, malware, or ransomware. To ensure infrastructure security, the user can apply patches and updates, use antivirus and anti-malware software, and monitor and audit the infrastructure activities.
  - Compliance security: The cloud infrastructure can be subject to various regulations and standards, such as GDPR, HIPAA, or PCI DSS, depending on the industry and location of the user. To ensure compliance security, the user can follow the best practices and guidelines of the cloud provider, use encryption and tokenization, and conduct regular audits and assessments.
  - Shared responsibility security: The cloud infrastructure security is a shared responsibility between the cloud provider and the user, depending on the service model. The cloud provider is responsible for the security of the cloud, while the user is responsible for the security in the cloud. The user should understand the roles and responsibilities of both parties, and follow the security policies and procedures of the cloud provider.
