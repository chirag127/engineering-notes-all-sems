### Cloud Computing Components for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing

Cloud computing is a model of delivering computing resources as a service over a network, such as the internet. Cloud computing allows users to access applications, data, and services without having to manage or own the underlying infrastructure. Cloud computing can provide benefits such as scalability, cost-efficiency, reliability, and security.

Cloud computing architecture refers to the components and subcomponents required for cloud computing. These components typically consist of a front end platform, a back end platform, a cloud based delivery, and a network. The following are some of the main components of cloud computing architecture:

- **Front end platform**: This is the component that provides the user interface for accessing the cloud services. The front end platform can be a fat client, a thin client, a mobile device, or a web browser. The front end platform communicates with the back end platform through a network, such as the internet.
- **Back end platform**: This is the component that provides the computing resources, such as servers, storage, databases, and applications, for the cloud services. The back end platform can be composed of multiple distributed servers and data centers, which can be located in different geographical locations. The back end platform is managed by the cloud service provider, who is responsible for ensuring the availability, performance, and security of the cloud services.
- **Cloud based delivery**: This is the component that defines the type and level of service that the cloud service provider offers to the users. The cloud based delivery can be classified into three main categories: Software as a Service (SaaS), Platform as a Service (PaaS), and Infrastructure as a Service (IaaS). SaaS provides users with access to software applications that are hosted and maintained by the cloud service provider. PaaS provides users with access to a platform that allows them to develop, deploy, and run their own applications without having to manage the underlying infrastructure. IaaS provides users with access to the basic computing resources, such as servers, storage, and networks, that they can use to run their own applications and operating systems.
- **Network**: This is the component that connects the front end platform and the back end platform, and enables the data transmission and communication between them. The network can be the internet, an intranet, or an intercloud. The internet is the most common network for cloud computing, as it provides a global and public access to the cloud services. An intranet is a private and restricted network that is used by an organization or a group of organizations to access the cloud services. An intercloud is a network of interconnected clouds that allows the exchange and integration of cloud services among different cloud service providers.

Some of the advantages of cloud computing are:

- **Scalability**: Cloud computing allows users to scale up or down the computing resources according to their needs and demands, without having to invest in or maintain the physical infrastructure.
- **Cost-efficiency**: Cloud computing allows users to pay only for the resources and services that they use, without having to incur the capital and operational costs of owning and managing the infrastructure.
- **Reliability**: Cloud computing provides users with high availability and fault tolerance, as the cloud services are hosted and replicated across multiple servers and data centers, which can handle failures and disasters.
- **Security**: Cloud computing provides users with various security mechanisms, such as encryption, authentication, authorization, and auditing, to protect the data and applications from unauthorized access and malicious attacks.

Some of the disadvantages of cloud computing are:

- **Dependency**: Cloud computing makes users dependent on the cloud service provider, who has the control and ownership of the infrastructure and the data. Users may face issues such as service outages, data breaches, vendor lock-in, and limited customization and interoperability.
- **Latency**: Cloud computing may introduce latency and performance issues, as the data and applications are accessed over a network, which can be affected by bandwidth, congestion, and distance.
- **Compliance**: Cloud computing may pose challenges for complying with the legal and regulatory requirements of different jurisdictions, as the data and applications are stored and processed in different locations, which may have different laws and policies.
