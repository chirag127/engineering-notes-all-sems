### Parallel Virtual Machine (PVM) for the notes of the Unit 4 - Beowulf Cluster in the subject of High Performance Computing

- Parallel Virtual Machine (PVM) is a software tool for parallel networking of computers.
- It allows a network of heterogeneous Unix and/or Windows machines to be used as a single distributed parallel processor .
- It provides a set of libraries and daemons that enable message passing, task and resource management, and fault tolerance .
- It can be used as a stand-alone software or as a foundation for other heterogeneous network software.
- It is one of the parallel processing libraries used in Beowulf clusters, which are clusters of commodity computers connected by a local area network.
- Beowulf clusters are designed to provide high performance computing at low cost by using off-the-shelf hardware and open source software.
- The name Beowulf in Beowulf clusters came from a computer built by Thomas Sterling and Donald Becker at NASA in 1994, which was named after an English poem of the same name.

Some mnemonics and learning tricks for PVM are:

- PVM stands for Parallel Virtual Machine, which can be remembered as PVM = Parallel + Virtual + Machine.
- PVM enables message passing, which can be remembered as PVM = Pass + Virtual + Messages.
- PVM is used in Beowulf clusters, which can be remembered as PVM = Beowulf + Virtual + Machine.
- PVM supports heterogeneous machines, which can be remembered as PVM = Heterogeneous + Virtual + Machine.
