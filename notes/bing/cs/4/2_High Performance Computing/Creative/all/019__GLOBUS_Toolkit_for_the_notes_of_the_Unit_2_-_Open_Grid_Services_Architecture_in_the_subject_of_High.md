### GLOBUS Toolkit for the notes of the Unit 2 - Open Grid Services Architecture in the subject of High Performance Computing

- GLOBUS Toolkit is an open-source toolkit for grid computing developed and provided by the Globus Alliance.
- Grid computing is a distributed computing paradigm that enables the sharing of resources and services across multiple administrative domains.
- Open Grid Services Architecture (OGSA) is a standard specification for grid services that defines a common set of interfaces and behaviors for building interoperable grid systems.
- GLOBUS Toolkit contains a set of libraries and programs that provides the developers of specific tools or apps with solutions for common problems that are encountered when creating a distributed system services and applications.
- GLOBUS Toolkit components and capabilities include:
  - Security: provides authentication, authorization, and delegation mechanisms for secure grid interactions.
  - Data management: provides efficient and reliable data transfer, replication, and access services for large-scale data movement and management.
  - Execution management: provides job submission, monitoring, and management services for distributed execution of applications and workflows.
  - Information services: provides discovery, monitoring, and aggregation of information about grid resources and services.
  - Common runtime: provides common libraries and utilities for developing and deploying grid services and applications.
- GLOBUS Toolkit is no longer available as a do-it-yourself distributed computing toolkit, but its spirit lives on in a mature, full-featured and easy to use service for research data management – Globus.org!
- Globus.org is a cloud-based platform that offers data transfer, sharing, and publication services for researchers and institutions.
- Globus.org allows users to efficiently, securely, and reliably transfer data directly between systems separated by an office wall or an ocean.
- Globus.org also enables users to share data with collaborators, publish data to repositories, and manage data across its lifecycle.
- Globus.org is compatible with most storage systems, including laptops, servers, clusters, supercomputers, and cloud storage.
