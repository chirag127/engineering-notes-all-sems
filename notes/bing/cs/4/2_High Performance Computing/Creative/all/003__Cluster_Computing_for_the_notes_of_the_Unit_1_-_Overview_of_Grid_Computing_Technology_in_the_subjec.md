### Cluster Computing for the notes of the Unit 1 - Overview of Grid Computing Technology in the subject of High Performance Computing

- Cluster computing is a form of parallel computing that involves connecting multiple computers (called nodes) on a network and using them as a single system for high-performance tasks .
- Cluster computing can provide faster computational speed, enhanced data integrity, better reliability, and lower cost than using a single computer or a traditional supercomputer .
- Cluster computing can be classified into two types: loosely coupled and tightly coupled.
  - Loosely coupled clusters have nodes that are independent and autonomous, and communicate with each other through a network interface. They are also called distributed clusters or grid clusters.
  - Tightly coupled clusters have nodes that share memory and disk space, and communicate with each other through a high-speed interconnect. They are also called shared-memory clusters or symmetric multiprocessing (SMP) clusters.
- Cluster computing can be used for various applications, such as scientific computing, data analysis, web hosting, load balancing, database management, and fault tolerance .
- Cluster computing can be implemented using different software and hardware components, such as operating systems, middleware, network protocols, cluster management tools, and cluster architectures .
- Cluster computing can be compared with other forms of parallel computing, such as grid computing, cloud computing, and supercomputing, based on factors such as scalability, heterogeneity, security, and cost.
