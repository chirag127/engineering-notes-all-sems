### Storage for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing

- Storage is one of the essential components of cloud computing, which allows users to save important data or media files on remote, third-party servers.
- Users can access these servers at any time over the internet, and the servers are maintained and managed by a cloud service provider, who is responsible for hosting, securing, and scaling the data stored on its infrastructure .
- Cloud storage offers several benefits over traditional data storage, such as:
  - Cost-effectiveness: Cloud storage eliminates the need for purchasing, maintaining, and upgrading expensive hardware and software for data storage. Users only pay for the amount of storage they use, and can scale up or down as needed.
  - Scalability: Cloud storage can handle large volumes of data and accommodate fluctuations in demand. Users can easily add or remove storage capacity without affecting the performance or availability of their applications.
  - Availability: Cloud storage ensures high availability and durability of data, by replicating it across multiple servers and locations. Users can access their data from anywhere and anytime, and can also recover it in case of disasters or failures .
  - Security: Cloud storage provides various security features to protect data from unauthorized access, modification, or deletion. These include access control policies, data encryption, retention policies, retention policy locks, and signed URLs.
- Cloud storage can be classified into different types, based on the level of abstraction, accessibility, and performance. These are:
  - Object storage: This is the most basic and common type of cloud storage, which stores data as discrete units called objects. Each object has a unique identifier, metadata, and data. Object storage is ideal for storing unstructured or semi-structured data, such as images, videos, documents, etc. Object storage offers high scalability, durability, and availability, but low performance and latency .
  - File storage: This is a type of cloud storage that stores data as files in a hierarchical structure, similar to a traditional file system. File storage allows users to access and manipulate data using standard protocols, such as NFS or SMB. File storage is suitable for storing structured or organized data, such as databases, logs, configuration files, etc. File storage offers moderate scalability, durability, and availability, and high performance and latency .
  - Block storage: This is a type of cloud storage that stores data as blocks of fixed size, which are assigned to a unique address. Block storage is the lowest level of abstraction, and allows users to have direct control over the data layout and performance. Block storage is ideal for storing high-performance or transactional data, such as virtual machines, databases, etc. Block storage offers low scalability, durability, and availability, and very high performance and latency .
- Some examples of cloud storage services are:
  - Amazon S3: This is an object storage service that offers high scalability, durability, and availability, and supports various features, such as versioning, lifecycle management, encryption, etc.
  - Google Cloud Storage: This is an object storage service that offers similar features as Amazon S3, and also supports different storage classes, such as standard, nearline, coldline, and archive, based on the frequency and latency of data access.
  - Azure Blob Storage: This is an object storage service that offers similar features as Google Cloud Storage, and also supports different access tiers, such as hot, cool, and archive, based on the performance and cost of data access.
  - Amazon EFS: This is a file storage service that offers high scalability, durability, and availability, and supports various features, such as encryption, backup, access points, etc.
  - Google Cloud Filestore: This is a file storage service that offers similar features as Amazon EFS, and also supports different service tiers, such as standard and premium, based on the performance and cost of data access.
  - Azure Files: This is a file storage service that offers similar features as Google Cloud Filestore, and also supports different performance tiers, such as standard and premium, based on the throughput and latency of data access.
  - Amazon EBS: This is a block storage service that offers high performance and low latency, and supports various features, such as encryption, snapshot, volume types, etc.
