### Cloud Computing Architecture for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing

- Cloud computing architecture refers to the components and subcomponents required for cloud computing.
- Cloud computing is a model of delivering IT services over the internet, on demand and pay-per-use basis.
- Cloud computing architecture consists of two main components: front-end and back-end.
  - Front-end: The part of the cloud that is accessible to the users and provides the interface for using the cloud services. It can be a web browser, a mobile app, a desktop application, or a cloud client device.
  - Back-end: The part of the cloud that consists of the servers, storage, databases, networks, and software that provide the cloud services. It can be a single data center or a distributed network of data centers.
- Cloud computing architecture also involves a cloud-based delivery model, which defines how the cloud services are delivered to the users. There are three main types of cloud service models:
  - Software as a Service (SaaS): The cloud provider delivers software applications to the users over the internet, without requiring them to install or maintain them. The users can access the applications from any device and location. Examples of SaaS are Gmail, Google Docs, Salesforce, etc.
  - Platform as a Service (PaaS): The cloud provider delivers a platform for developing, testing, and deploying software applications to the users over the internet, without requiring them to manage the underlying infrastructure. The users can use the platform to create and run their own applications or use the pre-built applications provided by the cloud provider. Examples of PaaS are Google App Engine, Microsoft Azure, Heroku, etc.
  - Infrastructure as a Service (IaaS): The cloud provider delivers the basic computing resources, such as servers, storage, networks, and virtual machines, to the users over the internet, without requiring them to manage the physical hardware. The users can use the resources to run any software or operating system they want. Examples of IaaS are Amazon Web Services, Google Cloud Platform, Microsoft Azure, etc.
- Cloud computing architecture also involves a cloud deployment model, which defines how the cloud resources are shared and accessed by the users. There are four main types of cloud deployment models:
  - Public cloud: The cloud resources are owned and operated by a third-party cloud provider and are available to the general public over the internet. The users share the resources with other users and pay only for what they use. Examples of public cloud are Amazon Web Services, Google Cloud Platform, Microsoft Azure, etc.
  - Private cloud: The cloud resources are owned and operated by a single organization and are used exclusively by its members. The resources can be located on-premise or off-premise, and can be managed by the organization or a third-party cloud provider. The users have more control and security over the resources, but also have more responsibility and cost. Examples of private cloud are VMware, OpenStack, IBM Cloud Private, etc.
  - Hybrid cloud: The cloud resources are a combination of public and private clouds, and are connected by a common network. The users can move the resources and data between the clouds, depending on their needs and preferences. The users can benefit from the scalability and cost-effectiveness of the public cloud, and the security and control of the private cloud. Examples of hybrid cloud are AWS Outposts, Google Anthos, Microsoft Azure Stack, etc.
  - Multi-cloud: The cloud resources are a combination of multiple public and private clouds, and are not necessarily connected by a common network. The users can use different clouds for different purposes, such as performance, reliability, compliance, or cost. The users can benefit from the diversity and flexibility of the cloud providers, but also have more complexity and risk. Examples of multi-cloud are IBM Cloud Pak, Dell Technologies Cloud, Cisco CloudCenter, etc.
- Cloud computing architecture provides several benefits, such as:
  - Scalability: The cloud resources can be increased or decreased according to the demand, without affecting the performance or availability of the cloud services.
  - Elasticity: The cloud resources can be provisioned or released automatically, without requiring human intervention or planning.
  - Availability: The cloud resources can be accessed from anywhere and anytime, as long as there is an internet connection.
