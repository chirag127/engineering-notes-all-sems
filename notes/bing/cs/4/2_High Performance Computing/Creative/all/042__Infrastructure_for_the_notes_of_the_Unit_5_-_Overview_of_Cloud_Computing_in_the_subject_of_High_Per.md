### Infrastructure for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing

- Cloud computing is the delivery of computing services such as servers, storage, databases, networking, software, analytics, and intelligence over the internet, or the cloud.
- Cloud infrastructure is the collection of hardware and software elements needed to enable cloud computing. It includes the following components:
  - Hardware: Cloud infrastructure relies on an intricate set of hardware devices, such as servers, routers, switches, firewalls, load balancers, and storage arrays, that provide the physical resources for cloud computing.
  - Virtualisation: Virtualisation is a process that separates IT functions and services from the hardware that supports them. It allows multiple virtual machines (VMs) to run on a single physical server, each with its own operating system and applications. Virtualisation enables cloud providers to offer scalable, flexible, and efficient cloud services to customers.
  - Storage: Storage is the component that allows cloud providers to store and manage data for their customers. Cloud storage can be either block, file, or object-based, depending on the type and structure of the data. Cloud storage can also be either local, attached to a specific server, or distributed, spread across multiple servers and locations.
  - Network: Network is the component that connects the hardware, virtualisation, and storage components of cloud infrastructure. It enables data transmission and communication between cloud resources, as well as between cloud and on-premise resources. Network can be either public, using the internet, or private, using dedicated or leased lines.
  - Interface: Interface is the component that enables users to access and manage cloud resources. It can be either graphical, using a web browser or a mobile app, or programmatic, using an application programming interface (API) or a command-line interface (CLI).

- Cloud infrastructure types usually also include a service model, which defines the level of abstraction and responsibility for the cloud provider and the customer. The most common service models are:
  - Infrastructure as a service (IaaS): IaaS provides the basic building blocks of cloud computing, such as servers, storage, and network. The customer is responsible for installing, configuring, and managing the operating system, middleware, and applications on the cloud infrastructure. The cloud provider is responsible for maintaining and securing the physical infrastructure and the virtualisation layer. Examples of IaaS providers are Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP).
  - Platform as a service (PaaS): PaaS provides a higher level of abstraction than IaaS, offering a platform for developing, testing, deploying, and managing applications. The customer is responsible for writing and running the application code on the cloud platform. The cloud provider is responsible for providing and managing the underlying infrastructure, the operating system, the middleware, and the runtime environment. Examples of PaaS providers are Heroku, Salesforce, and IBM Cloud.
  - Software as a service (SaaS): SaaS provides the highest level of abstraction than IaaS and PaaS, offering a complete software solution that runs on the cloud. The customer is responsible for accessing and using the software application through a web browser or a mobile app. The cloud provider is responsible for developing, hosting, and maintaining the software application, as well as the underlying infrastructure, the operating system, the middleware, and the data. Examples of SaaS providers are Gmail, Dropbox, and Netflix.
  - Serverless: Serverless is a special type of cloud service model that abstracts away the concept of servers and infrastructure from the customer. The customer is responsible for writing and deploying small pieces of code, called functions, that are triggered by events or requests. The cloud provider is responsible for dynamically allocating and managing the resources needed to run the functions, as well as billing the customer based on the execution time and memory usage. Examples of serverless providers are AWS Lambda, Azure Functions, and Google Cloud Functions.

- Cloud infrastructure can also be classified based on the deployment model, which defines the location and ownership of the cloud resources. The main deployment models are:
  - Public cloud: Public cloud is a type of cloud infrastructure that is owned and operated by a third-party cloud provider, and is accessible to anyone over the internet. Public cloud offers the benefits of scalability, cost-effectiveness, and reliability, but may have less control and security than other deployment models. Examples of public cloud providers are AWS, Azure, and GCP.
