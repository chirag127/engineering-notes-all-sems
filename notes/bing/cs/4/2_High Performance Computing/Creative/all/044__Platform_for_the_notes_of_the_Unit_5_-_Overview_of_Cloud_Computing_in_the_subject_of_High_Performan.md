### Platform for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing

- A platform for cloud computing is a set of cloud services that provide complementary functionality for developing, running, and managing applications in the cloud.
- A platform for cloud computing can consist of different service models, such as Infrastructure-as-a-Service (IaaS), Platform-as-a-Service (PaaS), and Database-as-a-Service (DBaaS).
- A platform for cloud computing can also support different deployment models, such as public cloud, private cloud, and hybrid cloud.
- Some of the advantages of using a platform for cloud computing are:
  - Reduced capital expenditure and operational costs
  - Increased scalability and elasticity
  - Faster and easier application development and deployment
  - Enhanced security and reliability
  - Access to a variety of tools and services
- Some of the disadvantages of using a platform for cloud computing are:
  - Dependency on the platform provider and internet connectivity
  - Potential vendor lock-in and interoperability issues
  - Compliance and regulatory challenges
  - Limited control and customization
- Some of the examples of popular platforms for cloud computing are:
  - Amazon Web Services (AWS): An IaaS platform that offers a wide range of cloud services, such as compute, storage, networking, database, analytics, security, and more. AWS supports hybrid, private, and public cloud deployment models.
  - Microsoft Azure: A PaaS platform that provides a comprehensive set of cloud services, such as app development, data management, AI, IoT, DevOps, and more. Azure supports private cloud deployment model .
  - Google Cloud Platform (GCP): An IaaS platform that delivers cloud services, such as compute, storage, networking, database, machine learning, big data, and more. GCP supports hybrid, private, and public cloud deployment models.
- A mnemonic to remember the three service models of cloud computing is: I Prefer Databases (IaaS, PaaS, DBaaS).
- A mnemonic to remember the three deployment models of cloud computing is: Public Health Policy (Public, Hybrid, Private).
