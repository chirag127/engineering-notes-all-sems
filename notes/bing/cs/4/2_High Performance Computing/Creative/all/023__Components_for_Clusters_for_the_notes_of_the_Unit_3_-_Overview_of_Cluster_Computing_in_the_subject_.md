### Components for Clusters for the notes of the Unit 3 - Overview of Cluster Computing in the subject of High Performance Computing

A cluster is a collection of interconnected computers that work together as a single system to perform high-performance computing tasks. The components of a cluster can be classified into three categories: hardware, software, and facilities .

- Hardware components: These include the compute nodes, the network, the storage, and the file system. 
  - Compute nodes: These are the processing units of the cluster that execute the workloads using local resources, such as CPU, GPU, FPGA, memory, and network adapter . The compute nodes can be homogeneous (same hardware configuration) or heterogeneous (different hardware configuration) depending on the application requirements. 
  - Network: This is the communication medium that connects the compute nodes and allows data transfer and synchronization among them. The network can be classified into two types: interconnect and external. The interconnect is the high-speed, low-latency network that connects the nodes within the cluster. The external network is the network that connects the cluster to the outside world, such as the internet or other clusters. The network can use different technologies, such as Ethernet, InfiniBand, or Omni-Path .
  - Storage: This is the component that stores the applications and the user data that are used by the cluster. The storage can be local or remote. Local storage is the storage that is attached to the compute nodes, such as hard disks or solid state drives. Remote storage is the storage that is accessed over the network, such as network attached storage (NAS) or storage area network (SAN) .
  - File system: This is the component that organizes the data on the storage devices and provides a uniform interface for accessing them. The file system can be general-purpose or specialized. General-purpose file systems are the ones that are commonly used for storing and retrieving data, such as NTFS, ext4, or FAT. Specialized file systems are the ones that are designed for high-performance computing, such as parallel file systems or distributed file systems. Parallel file systems are the ones that allow concurrent access to the same file from multiple nodes, such as Lustre, GPFS, or PVFS. Distributed file systems are the ones that distribute the data across multiple nodes, such as HDFS, Ceph, or GlusterFS .

- Software components: These include the operating system, the cluster provisioner, the scheduler, and the applications. 
  - Operating system: This is the software that manages the hardware resources and provides the basic services for the cluster. The operating system can be a single one or a combination of multiple ones, depending on the cluster configuration. For example, a cluster can use Linux, Windows, or a mix of both. The operating system can also be customized or optimized for high-performance computing, such as using a lightweight kernel, a real-time kernel, or a specialized distribution .
  - Cluster provisioner: This is the software that ensures the homogeneity and consistency of the cluster by installing and configuring the operating system and the software packages on the compute nodes. The cluster provisioner can use different methods, such as disk cloning, network booting, or image-based provisioning. Some examples of cluster provisioners are MAAS, Rocks, or Warewulf .
  - Scheduler: This is the software that manages the workload distribution and execution on the cluster by allocating the compute nodes and the resources to the jobs submitted by the users. The scheduler can use different policies, such as first-come first-served, priority-based, or fair-share. Some examples of schedulers are Slurm, PBS, or Torque .
  - Applications: These are the software programs that perform the high-performance computing tasks on the cluster. The applications can be classified into two types: parallel or distributed. Parallel applications are the ones that use multiple processors or cores to execute the same program or task, such as MPI, OpenMP, or CUDA. Distributed applications are the ones that use multiple nodes to execute different programs or tasks, such as MapReduce, Spark, or TensorFlow .
