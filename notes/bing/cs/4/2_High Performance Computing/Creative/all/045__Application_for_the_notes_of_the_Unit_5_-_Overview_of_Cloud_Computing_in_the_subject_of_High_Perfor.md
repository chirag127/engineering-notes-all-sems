### Application for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing

- Cloud computing is the on-demand availability of computer system resources, especially data storage and computing power, without direct active management by the user.
- Cloud computing offers online data storage, infrastructure, and application, as well as platform independency, as the software is not required to be installed locally on the PC.
- Cloud computing provides an alternative to the on-premises datacentre, where the user has to manage everything, such as purchasing and installing hardware, virtualization, operating system, applications, network, firewall, and storage.
- Cloud computing is based on the following key characteristics:
  - On-demand self-service: The user can provision computing resources as needed without human intervention from the service provider.
  - Broad network access: The computing resources are accessible over the network through standard mechanisms and devices.
  - Resource pooling: The computing resources are pooled and shared among multiple users, with different physical and virtual resources dynamically assigned according to demand.
  - Rapid elasticity: The computing resources can be scaled up or down quickly and automatically to meet the changing needs of the user.
  - Measured service: The computing resources are monitored and measured by the service provider, and the user pays only for the resources used.
- Cloud computing can be classified into the following service models:
  - Software as a Service (SaaS): The user can access and use software applications that are hosted and managed by the service provider over the network.
  - Platform as a Service (PaaS): The user can deploy and run their own applications using the platform and tools provided by the service provider over the network.
  - Infrastructure as a Service (IaaS): The user can provision and use computing resources, such as servers, storage, and network, that are hosted and managed by the service provider over the network.
- Cloud computing can also be classified into the following deployment models:
  - Public cloud: The computing resources are owned and operated by a third-party service provider and are available to the general public over the internet.
  - Private cloud: The computing resources are owned and operated by a single organization and are available only to its members over a private network.
  - Hybrid cloud: The computing resources are a combination of public and private clouds, with some degree of integration and interoperability between them.
  - Community cloud: The computing resources are shared and operated by a group of organizations that have common interests and goals over a community network.
- Cloud computing technologies and advancements include the following:
  - Hadoop: An open-source framework for distributed storage and processing of large-scale data using a cluster of commodity hardware and a programming model called MapReduce.
  - Virtual Box: An open-source software for creating and running virtual machines on a host operating system, allowing the user to run multiple operating systems simultaneously.
  - Google App Engine: A cloud platform for developing and hosting web applications using Google's infrastructure and services, such as data storage, authentication, and caching.
  - Open Stack: An open-source software for creating and managing private and public clouds, offering various components for computing, networking, storage, identity, and orchestration.
  - Federation in the cloud: The concept of integrating and collaborating multiple cloud providers and users to achieve interoperability, scalability, and efficiency.
  - Future of federation: The possible scenarios and challenges of federating cloud services and applications at different levels, such as infrastructure, platform, software, and data.

Some possible mnemonics and learning tricks for the notes are:

- To remember the key characteristics of cloud computing, use the acronym **ONRRM** (On-demand, Network, Resource, Rapid, Measured).
- To remember the service models of cloud computing, use the acronym **SPI** (Software, Platform, Infrastructure).
- To remember the deployment models of cloud computing, use the acronym **PHCC** (Public, Hybrid, Community, Private).
- To remember some of the cloud technologies and advancements, use the acronym **HVGOF** (Hadoop, Virtual Box, Google App Engine, Open Stack, Federation).
