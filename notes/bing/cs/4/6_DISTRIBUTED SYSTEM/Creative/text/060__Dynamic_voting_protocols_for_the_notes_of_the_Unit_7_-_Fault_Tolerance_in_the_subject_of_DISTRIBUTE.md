### Dynamic voting protocols for the notes of the Unit 7 - Fault Tolerance in the subject of DISTRIBUTED SYSTEM

- Dynamic voting protocols are a class of algorithms that allow a distributed system to maintain consistency and availability of replicated data in the presence of failures and network partitions.
- Dynamic voting protocols are based on the idea of assigning a variable number of votes to each replica, depending on the current state of the system. The number of votes can change dynamically as replicas join, leave, or fail.
- Dynamic voting protocols use a quorum-based approach to ensure that any read or write operation on the replicated data is performed by a majority of the replicas that have the most recent version of the data. A quorum is a subset of replicas that satisfies some condition, such as having a minimum number of votes or being connected to each other.
- Dynamic voting protocols can be classified into two categories: primary-based and primary-free. Primary-based protocols elect a single replica as the primary, which has the highest number of votes and coordinates all the read and write operations. Primary-free protocols do not have a designated primary, and allow any replica to initiate a read or write operation, as long as it can obtain a quorum of votes.
- Dynamic voting protocols have several advantages over static voting protocols, which assign a fixed number of votes to each replica. Dynamic voting protocols can adapt to changes in the system configuration, such as failures, recoveries, or network partitions. Dynamic voting protocols can also improve the performance and availability of the system, by reducing the number of replicas that need to be contacted for each operation, and by allowing concurrent operations on different partitions of the data. Dynamic voting protocols can also tolerate more failures than static voting protocols, by adjusting the number of votes and the quorum size accordingly.
