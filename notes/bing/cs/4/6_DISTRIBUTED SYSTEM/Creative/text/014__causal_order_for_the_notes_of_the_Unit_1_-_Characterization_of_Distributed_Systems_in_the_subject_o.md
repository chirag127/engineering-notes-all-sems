### Causal order

- Causal order is a relation between events in a distributed system that captures the notion of cause and effect.
- Causal order is defined as follows: if event A causally precedes event B, then A must have happened before B and A must have influenced B in some way.
- Causal order is transitive, meaning that if A causally precedes B and B causally precedes C, then A causally precedes C.
- Causal order is also irreflexive, meaning that no event can causally precede itself.
- Causal order is not a total order, meaning that there may be events that are not causally related to each other, such as concurrent or independent events.

Lamport timestamps can be used to compare the causal order of events by using the following rule: A causally precedes B if and only if the timestamp of A is less than the timestamp of B.
