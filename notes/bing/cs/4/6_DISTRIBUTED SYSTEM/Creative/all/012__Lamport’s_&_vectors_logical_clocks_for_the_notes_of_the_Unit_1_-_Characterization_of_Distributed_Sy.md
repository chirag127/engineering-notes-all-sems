### Lamport’s & vectors logical clocks for the notes of the Unit 1 - Characterization of Distributed Systems in the subject of DISTRIBUTED SYSTEM

- Lamport’s logical clock is a procedure to determine the order of events occurring in a distributed system, based on the concept of a logical clock.
- A logical clock is a numerical software counter value maintained in each process, that only has meaning in relation to messages moving between processes.
- Lamport’s logical clock assigns a timestamp to each event in a process, such that if event A causally precedes event B, then the timestamp of A is less than the timestamp of B.
- Lamport’s logical clock works as follows:
  - Each process maintains a local counter, initialized to zero.
  - Each time a process performs an internal event, it increments its counter by one.
  - Each time a process sends a message, it increments its counter by one and attaches its counter value to the message as a timestamp.
  - Each time a process receives a message, it updates its counter to the maximum of its own value and the timestamp received, and then increments it by one.
- Lamport’s logical clock provides a total ordering of events consistent with causality, but it does not capture the concurrency of events.
- A vector clock is a generalization of Lamport’s logical clock, that allows to determine if any two arbitrarily selected events are causally dependent or concurrent.
- A vector clock of a system of N processes is an array /vector of N logical clocks, one clock per process; a local "largest possible values" copy of the global clock-array is kept in each process.
- Vector clock works as follows:
  - Initially, all clocks are zero.
  - Each time a process performs an internal event, it increments its own clock in the vector by one.
  - Each time a process sends a message, it increments its own clock in the vector by one and attaches the vector to the message.
  - Each time a process receives a message, it increments its own clock in the vector by one and updates each element in its vector by taking the maximum of its own value and the value received.
- Vector clock provides a partial ordering of events, such that if event A causally precedes event B, then the vector clock of A is less than the vector clock of B in all components. If the vector clocks of A and B are incomparable, then A and B are concurrent.
- A possible mnemonic to remember the difference between Lamport’s and vector clocks is: Lamport’s clock is **L**inear, vector clock is **V**ariable.
- A possible learning trick to understand the concept of logical clocks is to use a simulation tool, such as [this one](https://lamport-vector-clock.herokuapp.com/), to visualize how the clocks work in different scenarios.
