## Unit 3 - Cloud Architecture, Services And Storage

- Cloud architecture is the design of the components and systems that make up a cloud computing platform. It includes the hardware, software, network, security, and service models that enable cloud services to be delivered and consumed.
- Cloud services are the resources and capabilities that are offered by cloud providers to cloud users. They can be categorized into three main types: Infrastructure as a Service (IaaS), Platform as a Service (PaaS), and Software as a Service (SaaS).
- IaaS provides access to low-level computing resources, such as servers, storage, and networks. Users can provision and manage these resources according to their needs, and pay only for what they use. Examples of IaaS providers are Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP).
- PaaS provides access to high-level computing resources, such as development tools, databases, and middleware. Users can build and deploy applications and services on top of these resources, without worrying about the underlying infrastructure. Examples of PaaS providers are Heroku, Firebase, and AWS Elastic Beanstalk.
- SaaS provides access to ready-made applications and services that run on the cloud. Users can access these applications and services via web browsers or mobile apps, without installing or maintaining any software. Examples of SaaS providers are Gmail, Dropbox, and Netflix.
- Cloud storage is the service of storing and accessing data on the cloud. It can be used for various purposes, such as backup, archiving, synchronization, sharing, and analysis. Cloud storage can be classified into four types: object storage, file storage, block storage, and database storage.
- Object storage stores data as discrete units, called objects, that have a unique identifier, metadata, and data. Objects can be accessed via HTTP or RESTful APIs, and can be stored and retrieved in any order. Object storage is suitable for storing unstructured or semi-structured data, such as images, videos, and documents. Examples of object storage services are Amazon S3, Google Cloud Storage, and Azure Blob Storage.
- File storage stores data as files and folders, that have a name, path, and attributes. Files can be accessed via standard protocols, such as NFS and SMB, and can be organized in a hierarchical structure. File storage is suitable for storing structured or semi-structured data, such as spreadsheets, logs, and configuration files. Examples of file storage services are Amazon EFS, Google Cloud Filestore, and Azure Files.
- Block storage stores data as fixed-sized blocks, that have a unique address, but no metadata. Blocks can be accessed via low-level protocols, such as iSCSI and Fibre Channel, and can be arranged in any logical order. Block storage is suitable for storing raw or binary data, such as operating systems, databases, and virtual machines. Examples of block storage services are Amazon EBS, Google Cloud Persistent Disk, and Azure Disk Storage.
- Database storage stores data as records, that have a schema, key, and value. Records can be accessed via query languages, such as SQL and NoSQL, and can be manipulated in various ways. Database storage is suitable for storing structured or semi-structured data, such as transactions, profiles, and analytics. Examples of database storage services are Amazon RDS, Google Cloud SQL, and Azure SQL Database.
