### Security Governance for the notes of the Unit 4 - Resource Management And Security In Cloud in the subject of Cloud Computing

- Security governance in cloud computing is a framework of policies designed to dictate what cloud resources can be used, how they should be used, and who can use them.
- Security governance also enforces rules governing how individual resources should be secured to prevent their misuse by malicious actors.
- Security governance bridges the business priorities with the technical implementation of security architecture, standards, and policy.
- Security governance teams provide oversight and monitoring to sustain and improve the security posture of the cloud environment over time.
- Security governance teams also report compliance as required by regulating bodies or industry standards.
- Security governance in cloud computing can be divided into five disciplines: cost management, security baseline, resource consistency, identity baseline, and deployment acceleration.
- Cost management involves developing policies for controlling the cloud spending and optimizing the cloud usage.
- Security baseline involves establishing the security requirements and applying them across the network, data, and asset configurations.
- Resource consistency involves ensuring that the cloud resources are aligned with the business and technical standards and best practices.
- Identity baseline involves defining the roles and permissions for accessing the cloud resources and enforcing the identity and access management policies.
- Deployment acceleration involves enabling the rapid and secure delivery of cloud solutions by automating the deployment processes and integrating the security controls.
- Security governance in cloud computing requires a collaborative approach among the business stakeholders, the cloud service providers, and the cloud users.
- Security governance in cloud computing also requires a continuous improvement cycle that involves assessing the current state, defining the desired state, implementing the changes, and monitoring the outcomes.
- Security governance in cloud computing can help to achieve the business objectives by reducing the security risks, enhancing the security performance, and increasing the security agility .
