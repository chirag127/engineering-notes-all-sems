## Unit 1 - Introduction To Cloud Computing

- Cloud computing is the delivery of computing services over the internet, such as servers, storage, databases, networking, software, analytics, and intelligence.
- Cloud computing offers many benefits, such as scalability, reliability, security, cost-efficiency, and innovation.
- There are different types of cloud computing models, such as public cloud, private cloud, hybrid cloud, and multi-cloud.
- Public cloud is when a cloud provider offers computing resources to the general public over the internet, such as Amazon Web Services, Microsoft Azure, or Google Cloud Platform.
- Private cloud is when a cloud provider offers computing resources to a single organization or a limited group of users over a private network, such as an on-premises data center or a dedicated hosting service.
- Hybrid cloud is when a cloud provider offers a combination of public and private cloud services, allowing the users to move data and applications between them, such as Microsoft Azure Stack or AWS Outposts.
- Multi-cloud is when a cloud provider offers multiple public cloud services from different providers, allowing the users to choose the best service for their needs, such as IBM Cloud Pak or Google Anthos.
- There are different types of cloud computing services, such as Infrastructure as a Service (IaaS), Platform as a Service (PaaS), Software as a Service (SaaS), and Function as a Service (FaaS).
- IaaS is when a cloud provider offers the basic computing infrastructure, such as servers, storage, and networking, allowing the users to install and run their own operating systems and applications, such as Amazon EC2, Microsoft Azure Virtual Machines, or Google Compute Engine.
- PaaS is when a cloud provider offers the computing platform, such as operating systems, middleware, and development tools, allowing the users to create and deploy their own applications, such as Amazon Elastic Beanstalk, Microsoft Azure App Service, or Google App Engine.
- SaaS is when a cloud provider offers the computing software, such as applications or databases, allowing the users to access and use them over the internet, such as Amazon RDS, Microsoft Office 365, or Google Workspace.
- FaaS is when a cloud provider offers the computing function, such as a piece of code or a logic, allowing the users to execute it on demand, without managing any servers or infrastructure, such as Amazon Lambda, Microsoft Azure Functions, or Google Cloud Functions.
