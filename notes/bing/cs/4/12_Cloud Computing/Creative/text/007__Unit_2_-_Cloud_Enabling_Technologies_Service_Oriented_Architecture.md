## Unit 2 - Cloud Enabling Technologies Service Oriented Architecture

- Service Oriented Architecture (SOA) is an architectural style that focuses on discrete services instead of a monolithic design.
- A service is a software component that provides a business capability and can communicate with other services across platforms and languages.
- SOA aims to make software components reusable and interoperable via service interfaces that use common standards and protocols.
- SOA allows users to combine large chunks of functionality to form applications that are built purely from existing services and combining them in an ad hoc manner.
- SOA benefits include increased agility, reduced costs, improved quality, and enhanced scalability.
