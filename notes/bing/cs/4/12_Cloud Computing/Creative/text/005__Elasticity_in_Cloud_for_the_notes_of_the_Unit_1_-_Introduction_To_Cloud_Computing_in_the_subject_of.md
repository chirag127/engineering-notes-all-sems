### Elasticity in Cloud

- Elasticity is the ability of a cloud system to dynamically adjust the amount of resources allocated to a service or an application according to the current demand or workload.
- Elasticity enables a cloud system to provide optimal performance, availability, and cost-efficiency for the users and the providers of the service or the application.
- Elasticity can be achieved by using various techniques, such as:
  - Scaling: adding or removing resources (such as servers, storage, or network bandwidth) to match the demand or workload.
  - Load balancing: distributing the workload across multiple resources to optimize the utilization and the response time.
  - Migration: moving a service or an application from one resource to another to improve the performance, availability, or cost-efficiency.
  - Provisioning: creating or deleting resources on demand to meet the requirements of a service or an application.
- Elasticity can be measured by using various metrics, such as:
  - Response time: the time it takes for a service or an application to process a request or a task.
  - Throughput: the number of requests or tasks that a service or an application can process in a given time period.
  - Utilization: the percentage of the capacity of a resource that is used by a service or an application.
  - Cost: the amount of money that is spent or saved by using a cloud system.
- Elasticity can be influenced by various factors, such as:
  - Demand: the number and the type of requests or tasks that a service or an application receives from the users.
  - Workload: the amount and the complexity of the processing that a service or an application needs to perform for each request or task.
  - Resource: the type, the capacity, and the availability of the resources that a cloud system can use to run a service or an application.
  - Policy: the rules and the constraints that a cloud system follows to allocate, manage, and optimize the resources for a service or an application.
