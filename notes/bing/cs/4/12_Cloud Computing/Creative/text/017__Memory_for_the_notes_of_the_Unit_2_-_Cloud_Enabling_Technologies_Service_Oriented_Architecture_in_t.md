### Memory for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

- Service Oriented Architecture (SOA) is a method of software development that uses software components called services to create business applications.
- Each service provides a business capability, and services can also communicate with each other across platforms and languages.
- SOA enables the construction of applications from loosely coupled services that can be easily integrated and reused.
- SOA is a critical technology for cloud computing as it enables the creation of loosely coupled services that can be accessed over the internet and the use of WAN.
- SOA has become a central component of modern cloud computing and virtualization in things like middleware and microservices.
- SOA uses common interface standards and an architectural pattern so that services can be rapidly incorporated into new applications.
- SOA benefits include increased agility, reusability, scalability, interoperability, and alignment with business goals.
- SOA challenges include complexity, governance, security, testing, and performance.
