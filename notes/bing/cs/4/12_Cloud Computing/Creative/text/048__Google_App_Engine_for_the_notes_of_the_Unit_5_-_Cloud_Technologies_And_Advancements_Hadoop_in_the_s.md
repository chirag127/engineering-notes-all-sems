### Google App Engine

- Google App Engine (GAE) is a platform-as-a-service (PaaS) product that provides web app developers and enterprises with access to Google's scalable hosting and tier 1 internet service.
- GAE requires that applications be written in Java or Python, store data in Google Bigtable and use the Google query language.
- GAE is a fully managed, serverless platform for developing and hosting web applications at scale .
- GAE supports popular development languages with a range of developer tools.
- GAE uses the same infrastructure as Google’s large-scale internet services.
- GAE is mostly used to run web applications that dynamically scale as demand change over time because of Google’s vast computing infrastructure.
- The App Engine application is a top-level container that includes the service, version, and instance resources that make up your app.
- When you create your App Engine app, all your resources are allocated to a default service.
- You can create additional services within your app to isolate functionality and independently scale your app.
- You can also deploy different versions of your app, each running within one or more instances, and migrate traffic gradually between versions.
- GAE offers two environments for running your app: the standard environment and the flexible environment.
- The standard environment runs your app in a sandboxed environment with preconfigured runtime environments and automatic scaling.
- The flexible environment runs your app in a Docker container on Google Compute Engine virtual machines with custom runtime environments and manual or automatic scaling.
- GAE provides a number of built-in services that you can use in your app, such as Datastore, Cloud Storage, Cloud SQL, Cloud Firestore, Cloud Tasks, Cloud Pub/Sub, Cloud Logging, Cloud Monitoring, Cloud Trace, Cloud Debugger, Cloud Scheduler, and Cloud Endpoints.
- GAE also integrates with other Google Cloud products and services, such as Cloud Functions, Cloud Run, Cloud Build, Cloud CDN, Cloud Load Balancing, Cloud Armor, Cloud Identity, Cloud IAM, Cloud Billing, and Cloud Marketplace.
- GAE is a cost-effective and reliable platform for running web applications that can scale to millions of users and handle complex business logic .
