### Types of Virtualization for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

Virtualization is the process of creating a virtual version of something, such as a server, a storage device, a network, or an application. Virtualization allows multiple virtual entities to share the same physical resources, thus improving efficiency, scalability, and flexibility. Virtualization is one of the key enabling technologies for cloud computing, as it allows cloud providers to offer various services and resources to customers on demand.

There are different types of virtualization, depending on the level of abstraction and the type of resource being virtualized. Some of the common types of virtualization in cloud computing are:

- **Server virtualization**: Server virtualization is the process of partitioning a physical server into multiple virtual servers, each with its own operating system and applications. Server virtualization allows cloud providers to optimize the utilization of server resources, reduce power consumption and maintenance costs, and increase security and reliability. Server virtualization can be implemented using different techniques, such as hypervisor-based, container-based, or paravirtualization. Examples of server virtualization software are VMware, Hyper-V, KVM, Docker, and LXC.

- **Storage virtualization**: Storage virtualization is the process of pooling and abstracting the physical storage devices into a single logical storage unit, which can be accessed by multiple virtual servers or applications. Storage virtualization allows cloud providers to manage and allocate storage resources more efficiently, improve performance and availability, and enable data backup and recovery. Storage virtualization can be implemented at different levels, such as block-level, file-level, or object-level. Examples of storage virtualization software are SAN, NAS, Ceph, and GlusterFS.

- **Network virtualization**: Network virtualization is the process of creating and managing virtual networks that are independent of the underlying physical network infrastructure. Network virtualization allows cloud providers to offer various network services and capabilities to customers, such as bandwidth, security, routing, and load balancing. Network virtualization can be implemented using different techniques, such as overlay networks, software-defined networking (SDN), or network function virtualization (NFV). Examples of network virtualization software are Open vSwitch, OpenFlow, and OpenStack Neutron.

- **Data virtualization**: Data virtualization is the process of integrating and presenting data from different sources and formats as a single logical data layer, which can be accessed by multiple applications or users. Data virtualization allows cloud providers to offer data services and analytics to customers, such as data warehousing, data mining, and business intelligence. Data virtualization can be implemented using different techniques, such as data federation, data abstraction, or data transformation. Examples of data virtualization software are Denodo, Informatica, and Microsoft SQL Server.

- **Application virtualization**: Application virtualization is the process of isolating and running an application from the underlying operating system and hardware, using a virtual application layer. Application virtualization allows cloud providers to offer software as a service (SaaS) to customers, without requiring installation or configuration on the customer's device. Application virtualization can be implemented using different techniques, such as streaming, encapsulation, or emulation. Examples of application virtualization software are Citrix XenApp, Microsoft App-V, and VMware ThinApp.

- **Desktop virtualization**: Desktop virtualization is the process of delivering a virtual desktop environment to a user's device, using a remote display protocol. Desktop virtualization allows cloud providers to offer desktop as a service (DaaS) to customers, without requiring a physical desktop or laptop. Desktop virtualization can be implemented using different techniques, such as hosted virtual desktops (HVDs), virtual desktop infrastructure (VDI), or remote desktop services (RDS). Examples of desktop virtualization software are VMware Horizon, Citrix XenDesktop, and Microsoft Remote Desktop Services.
