### S3 for the notes of the Unit 3 - Cloud Architecture, Services And Storage in the subject of Cloud Computing

- S3 stands for **Simple Storage Service** and it is a **cloud object storage** service offered by **Amazon Web Services (AWS)**  .
- S3 allows users to store and retrieve any amount of data from anywhere on the web, using a simple web interface .
- S3 is designed for **scalability**, **durability**, **availability**, **security**, and **performance**.
- S3 is ideal for **data lakes**, **mobile applications**, **backup and restore**, **archival**, **IoT devices**, **machine learning**, **artificial intelligence**, and **analytics**.
- S3 is an **object storage** service, which differs from other types of cloud storage, such as **block** and **file** storage.
  - **Object storage** stores data as **objects**, which are files with **metadata** and a unique **identifier** .
  - **Block storage** stores data as **blocks**, which are fixed-sized chunks of data that can be combined to form a file system.
  - **File storage** stores data as **files**, which are organized in a hierarchical structure of folders and subfolders.
- S3 has two main components: **buckets** and **objects**.
  - A **bucket** is a container for objects stored in S3. 
    - You can store any number of objects in a bucket.
    - You can create up to 100 buckets per AWS account by default.
    - You can configure various properties and permissions for each bucket, such as access control, encryption, versioning, lifecycle management, logging, and replication.
  - An **object** is the fundamental entity stored in S3.
    - An object consists of **object data** and **metadata**.
    - Object data is the actual content of the object, such as a text file, an image, or a video.
    - Metadata is a set of name-value pairs that describe the object, such as its size, type, date, and custom attributes.
    - An object is identified by a unique **key**, which is the name of the object in the bucket.
    - An object can be up to 5 terabytes in size.
    - You can upload, download, copy, delete, and modify objects using the S3 web interface, the AWS CLI, the AWS SDK, or the S3 REST API.
- S3 offers different **storage classes** for different use cases and cost requirements .
  - **S3 Standard** is the default storage class, which provides high durability, availability, and performance for frequently accessed data .
  - **S3 Intelligent-Tiering** is a storage class that automatically moves data between two access tiers (frequent and infrequent) based on the access patterns, to optimize the cost and performance .
  - **S3 Standard-Infrequent Access (S3 Standard-IA)** is a storage class that provides lower storage cost than S3 Standard, but higher retrieval cost, for data that is accessed less frequently, but requires rapid access when needed .
  - **S3 One Zone-Infrequent Access (S3 One Zone-IA)** is a storage class that provides lower storage cost than S3 Standard-IA, but stores the data in only one availability zone, for data that is accessed less frequently, but does not require high availability .
  - **S3 Glacier** is a storage class that provides low-cost storage for data archiving, with retrieval times ranging from minutes to hours .
  - **S3 Glacier Deep Archive** is a storage class that provides the lowest-cost storage for data archiving, with retrieval times of 12 hours .
