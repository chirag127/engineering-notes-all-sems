## Unit 5 - Cloud Technologies And Advancements Hadoop

- Hadoop is an open-source framework that allows distributed processing of large-scale data sets across clusters of computers using simple programming models.
- Hadoop consists of four main components: Hadoop Distributed File System (HDFS), MapReduce, YARN, and Hadoop Common.
- HDFS is a distributed file system that provides high-throughput access to data stored across multiple nodes in a cluster. It also provides fault tolerance, replication, and scalability.
- MapReduce is a programming model that enables parallel processing of large data sets by dividing them into smaller chunks (maps) and then combining the results (reduces).
- YARN is a resource management layer that allocates and schedules computing resources (such as CPU, memory, disk, and network) for applications running on Hadoop.
- Hadoop Common is a set of libraries and utilities that support the other components of Hadoop.

- Some of the advantages of Hadoop are:
  - It can handle structured, semi-structured, and unstructured data from various sources.
  - It can scale up or down according to the data volume and processing needs.
  - It can provide cost-effective and reliable storage and processing of large data sets.
  - It can support multiple types of applications, such as batch processing, streaming, interactive, and machine learning.
  - It can leverage the existing skills and tools of developers and analysts.

- Some of the disadvantages of Hadoop are:
  - It has a steep learning curve and requires specialized knowledge and skills.
  - It has a high initial setup and maintenance cost and complexity.
  - It has a low level of security and data governance.
  - It has a limited support for real-time and transactional processing.
  - It has a lack of standardization and compatibility across different versions and distributions.

- Some of the examples of applications that use Hadoop are:
  - Facebook uses Hadoop to store and analyze user data, such as likes, comments, posts, and messages.
  - Netflix uses Hadoop to process and recommend movies and shows to its subscribers based on their preferences and behavior.
  - Amazon uses Hadoop to optimize its product catalog, pricing, and delivery by analyzing customer data and feedback.
  - Spotify uses Hadoop to generate personalized playlists and recommendations for its users based on their listening history and preferences.
  - LinkedIn uses Hadoop to build and maintain its professional network and provide insights and suggestions to its members.

- A possible mnemonic to remember the four main components of Hadoop is: **H**ave **F**un **M**aking **Y**arn (HDFS, MapReduce, YARN, Hadoop Common).
