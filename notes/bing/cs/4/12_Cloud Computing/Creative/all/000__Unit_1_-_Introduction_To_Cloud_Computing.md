## Unit 1 - Introduction To Cloud Computing

- Cloud computing is a model for enabling **ubiquitous**, **convenient**, **on-demand** network access to a **shared pool** of **configurable computing resources** (e.g., networks, servers, storage, applications, and services) that can be **rapidly provisioned and released** with **minimal management effort or service provider interaction**.
- Cloud computing is also the **technology** that makes cloud work. This includes some form of **virtualized IT infrastructure**— servers, operating system software, networking, and other infrastructure that’s **abstracted**, using special software, so that it can be **pooled and divided** irrespective of physical hardware boundaries.
- Cloud computing is the **delivery** of computing services—including servers, storage, databases, networking, software, analytics, and intelligence—over the **Internet** (“the cloud”) to offer **faster innovation**, **flexible resources**, and **economies of scale**.

### Advantages of Cloud Computing

- Cloud computing offers many benefits to both users and providers of computing services. Some of the main advantages are:

  - **Cost savings**: Cloud computing eliminates the need for upfront capital investment in hardware and software, as well as the ongoing costs of maintenance, security, and upgrades. Users only pay for what they use, and providers can achieve economies of scale by sharing resources among multiple customers.
  - **Scalability**: Cloud computing allows users to easily scale up or down their computing resources according to their changing needs and demands. Providers can also dynamically allocate and reallocate resources to meet the varying demands of different customers and applications.
  - **Accessibility**: Cloud computing enables users to access their data and applications from anywhere, anytime, and on any device, as long as they have an Internet connection. Providers can also offer global coverage and availability by distributing their resources across multiple regions and zones.
  - **Reliability**: Cloud computing enhances the reliability and availability of computing services by using redundant and backup systems, as well as automatic failover and recovery mechanisms. Providers can also guarantee certain levels of service quality and performance through service level agreements (SLAs).
  - **Security**: Cloud computing improves the security and privacy of data and applications by using encryption, authentication, authorization, and auditing techniques. Providers can also offer compliance with various standards and regulations, such as GDPR, HIPAA, PCI DSS, etc.
  - **Innovation**: Cloud computing fosters innovation and creativity by enabling users to access a wide range of services and tools, such as artificial intelligence, machine learning, big data analytics, Internet of Things, etc. Providers can also offer new and improved services and features by leveraging the latest technologies and trends.

### Types of Cloud Computing

- Cloud computing can be classified into different types based on the service model, the deployment model, and the architecture. Some of the common types are:

  - **Service model**: This refers to the type of service that is offered by the cloud provider to the user. The three main service models are:

    - **Infrastructure as a Service (IaaS)**: This is the most basic level of cloud service, where the provider offers access to raw computing resources, such as servers, storage, network, and virtualization. The user is responsible for managing and configuring these resources, as well as installing and running the operating system and applications. Examples of IaaS providers are Amazon Web Services (AWS), Microsoft Azure, Google Cloud Platform, etc.
    - **Platform as a Service (PaaS)**: This is the next level of cloud service, where the provider offers access to a platform that consists of a set of tools and services for developing, testing, deploying, and managing applications. The user does not have to worry about the underlying infrastructure, but only focuses on the application logic and code. Examples of PaaS providers are Heroku, Google App Engine, AWS Elastic Beanstalk, etc.
    - **Software as a Service (SaaS)**: This is the highest level of cloud service, where the provider offers access to a software application that is hosted and managed by the provider. The user does not have to install or maintain anything, but only uses the application through a web browser or a mobile app. Examples of SaaS providers are Gmail, Dropbox, Netflix, Salesforce, etc.
