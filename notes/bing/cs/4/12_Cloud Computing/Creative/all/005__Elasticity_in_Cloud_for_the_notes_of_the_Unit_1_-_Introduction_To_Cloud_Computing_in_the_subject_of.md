### Elasticity in Cloud for the notes of the Unit 1 - Introduction To Cloud Computing in the subject of Cloud Computing

- Elasticity is the degree to which a cloud system can adapt to workload changes by provisioning and de-provisioning resources in an autonomic manner, such that at each point in time the available resources match the current demand as closely as possible.
- Elasticity is a defining characteristic that differentiates cloud computing from previously proposed computing paradigms, such as grid computing.
- Elasticity can refer to 'cloudbursting' from on-premises infrastructure into the public cloud for example to meet a sudden or seasonal demand. Elasticity can also refer to the ability to grow or shrink the resources used by a cloud-based application.
- Elasticity is best defined as a cloud computing service's ability to dynamically adapt to meet an organization's changing demands. This could include growing the capacity of a cloud-based system's central processing unit (CPU), for instance, or its storage resources or memory.
- Elasticity in cloud computing is the ability for the organization to adjust its storage requirements in terms of capacity and processing with respect to operational requirements.
- Elasticity has the following benefits:
  - Cost efficiency: The organization pays only for the resources it uses and avoids over-provisioning or under-provisioning of resources.
  - Scalability: The organization can easily scale up or down the resources according to the workload fluctuations.
  - Availability: The organization can ensure high availability of the resources by using multiple cloud providers or regions.
  - Performance: The organization can optimize the performance of the resources by using load balancing, caching, or compression techniques.
- Elasticity can be measured by using metrics such as response time, throughput, resource utilization, or cost.
- Elasticity can be achieved by using techniques such as virtualization, containerization, orchestration, automation, or monitoring.
- A mnemonic to remember the benefits of elasticity is **C-SAP** (Cost efficiency, Scalability, Availability, Performance).
- A mnemonic to remember the techniques to achieve elasticity is **V-COAM** (Virtualization, Containerization, Orchestration, Automation, Monitoring).
