### Inter Cloud Resource Management for the notes of the Unit 4 - Resource Management And Security In Cloud in the subject of Cloud Computing

- Inter Cloud Resource Management is the process of managing the resources of multiple clouds that are interconnected and interdependent.
- Inter Cloud Resource Management aims to achieve scalability, reliability, efficiency, and cost-effectiveness for cloud applications and services.
- Inter Cloud Resource Management can be classified into four types:
  - Federation Clouds: A federation cloud is a kind of inter-cloud where several cloud service providers willingly link their cloud infrastructures together to exchange resources. Cloud service providers in the federation trade resources in an open manner.
  - Aggregation Clouds: An aggregation cloud is a kind of inter-cloud where a cloud broker aggregates the resources of multiple cloud service providers and offers them to the customers. The cloud broker acts as an intermediary between the customers and the cloud service providers and manages the resource allocation, pricing, and SLA negotiation.
  - Multi-Cloud Services: A multi-cloud service is a kind of inter-cloud where a cloud application or service is composed of multiple cloud services from different cloud service providers. The cloud application or service can leverage the best features and capabilities of each cloud service and achieve higher performance, availability, and functionality.
  - Multi-Cloud Libraries: A multi-cloud library is a kind of inter-cloud where a cloud API is used to access and manipulate the resources of multiple cloud service providers. The cloud API provides a uniform and consistent interface for the customers and hides the heterogeneity and complexity of the underlying cloud infrastructures.
- Inter Cloud Resource Management faces several challenges, such as:
  - Resource discovery and selection: How to find and choose the best resources from multiple clouds that meet the customer's requirements and preferences.
  - Resource allocation and scheduling: How to allocate and schedule the resources from multiple clouds to optimize the performance, cost, and QoS of the cloud applications and services.
  - Resource monitoring and adaptation: How to monitor and adapt the resources from multiple clouds to cope with the dynamic changes in the workload, environment, and SLA.
  - Resource pricing and billing: How to price and bill the resources from multiple clouds to ensure fairness, transparency, and profitability for both the customers and the cloud service providers.
- Inter Cloud Resource Management can benefit from several techniques, such as:
  - Semantic web and ontology: Semantic web and ontology can provide a common vocabulary and a formal representation of the resources, services, and policies of multiple clouds, which can facilitate the resource discovery and selection, as well as the SLA negotiation and enforcement.
  - Multi-agent systems and game theory: Multi-agent systems and game theory can model the interactions and behaviors of the multiple stakeholders involved in the inter-cloud resource management, such as the customers, the cloud service providers, and the cloud brokers, and can provide mechanisms for coordination, cooperation, and competition among them.
  - Optimization and machine learning: Optimization and machine learning can provide algorithms and methods for solving the complex and NP-hard problems of resource allocation and scheduling, resource monitoring and adaptation, and resource pricing and billing in the inter-cloud resource management, and can also learn from the historical data and feedback to improve the decision making and performance.
