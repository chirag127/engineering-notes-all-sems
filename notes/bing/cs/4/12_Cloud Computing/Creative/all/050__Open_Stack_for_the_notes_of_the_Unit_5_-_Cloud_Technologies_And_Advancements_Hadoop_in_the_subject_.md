### Open Stack for the notes of the Unit 5 - Cloud Technologies And Advancements Hadoop in the subject of Cloud Computing

- Open Stack is an open source cloud computing platform that provides a set of software tools for building and managing cloud infrastructure and services.
- Open Stack consists of several components, each of which provides a specific function for the cloud, such as compute, storage, networking, identity, image, orchestration, etc.
- Open Stack can run on any hardware and can integrate with various hypervisors, such as KVM, Xen, VMware, etc.
- Open Stack can support both public and private cloud models, as well as hybrid and multi-cloud scenarios.
- Open Stack is designed to be scalable, modular, interoperable, and extensible, allowing users to customize and enhance their cloud environment according to their needs and preferences.
- Open Stack is governed by the Open Stack Foundation, a non-profit organization that oversees the development, promotion, and adoption of the platform.
- Open Stack is supported by a large and active community of developers, users, and vendors, who contribute to the project through code, documentation, testing, feedback, etc.

Some of the advantages of Open Stack are:

- It is free and open source, which reduces the cost and vendor lock-in of cloud computing.
- It is flexible and adaptable, which enables users to tailor their cloud solutions to their specific requirements and preferences.
- It is compatible and interoperable, which facilitates the integration and migration of cloud resources and services across different platforms and providers.
- It is innovative and dynamic, which fosters the development and adoption of new features and technologies for cloud computing.

Some of the disadvantages of Open Stack are:

- It is complex and challenging, which requires a high level of technical expertise and resources to deploy and manage the cloud infrastructure and services.
- It is evolving and unstable, which may result in bugs, errors, and compatibility issues among different versions and components of the platform.
- It is fragmented and inconsistent, which may cause conflicts and discrepancies among the various projects and standards within the Open Stack ecosystem.

Some of the applications of Open Stack are:

- It can be used to create and operate public cloud services, such as Amazon Web Services, Google Cloud Platform, Microsoft Azure, etc.
- It can be used to build and manage private cloud infrastructure, such as for enterprises, universities, research institutes, etc.
- It can be used to support hybrid and multi-cloud scenarios, such as for disaster recovery, load balancing, data sovereignty, etc.
- It can be used to enable cloud-native applications, such as microservices, containers, serverless, etc.

A mnemonic to remember the main components of Open Stack is:

- **N**ova: compute service that manages the virtual machines and containers
- **S**wift: object storage service that stores and retrieves unstructured data
- **C**inder: block storage service that provides persistent volumes for virtual machines and containers
- **N**eutron: networking service that enables the connectivity and communication among cloud resources
- **K**eystone: identity service that handles the authentication and authorization of users and services
- **G**lance: image service that stores and manages the disk images for virtual machines and containers
- **H**eat: orchestration service that automates the deployment and management of cloud resources and services
- **H**orizon: dashboard service that provides a web-based graphical user interface for the cloud

The mnemonic is: **NSCNKGHH** or **No Sugar Can Not Keep Good Health**.
