### NIST Cloud Computing Reference Architecture for the notes of the Unit 3 - Cloud Architecture, Services And Storage in the subject of Cloud Computing

- The NIST Cloud Computing Reference Architecture (NIST CCRA) is a framework that defines the essential components and relationships of cloud computing systems and services  .
- The NIST CCRA aims to facilitate communication, understanding, and analysis of cloud computing offerings and scenarios, as well as to support interoperability, portability, and security requirements .
- The NIST CCRA consists of five major architectural components  :
  - Cloud Consumer: The entity that uses cloud services, such as end users, applications, or systems.
  - Cloud Provider: The entity that provides cloud services, such as infrastructure, platform, or software, to cloud consumers.
  - Cloud Auditor: The entity that conducts independent assessments of cloud services, such as performance, security, privacy, or compliance, on behalf of cloud consumers or providers.
  - Cloud Broker: The entity that intermediates between cloud consumers and providers, such as by aggregating, integrating, or customizing cloud services, or by offering value-added services.
  - Cloud Carrier: The entity that transports data and communications between cloud consumers and providers, such as network operators, telecommunication companies, or internet service providers.
- The NIST CCRA also defines a cloud computing taxonomy that categorizes cloud services and deployment models based on the NIST cloud computing definition:
  - Cloud Service Categories: The types of cloud services that can be offered by cloud providers, such as:
    - Infrastructure as a Service (IaaS): The provision of processing, storage, network, and other fundamental computing resources to cloud consumers, who can deploy and run arbitrary software, including operating systems and applications.
    - Platform as a Service (PaaS): The provision of a platform that allows cloud consumers to deploy and run applications or services created using programming languages, libraries, tools, and frameworks supported by the cloud provider.
    - Software as a Service (SaaS): The provision of applications or services that are accessible by cloud consumers through various devices, such as web browsers, mobile phones, or tablets.
  - Cloud Deployment Models: The types of cloud environments that can be used by cloud consumers or providers, such as:
    - Private Cloud: The cloud infrastructure is provisioned for exclusive use by a single organization comprising multiple consumers, and is owned, managed, and operated by the organization, a third party, or some combination of them, and it may exist on or off premises.
    - Community Cloud: The cloud infrastructure is provisioned for exclusive use by a specific community of consumers from organizations that have shared concerns, and is owned, managed, and operated by one or more of the organizations in the community, a third party, or some combination of them, and it may exist on or off premises.
    - Public Cloud: The cloud infrastructure is provisioned for open use by the general public, and is owned, managed, and operated by a cloud provider, a business, an academic, or a government organization, or some combination of them, and it exists on the premises of the cloud provider.
    - Hybrid Cloud: The cloud infrastructure is a composition of two or more distinct cloud infrastructures (private, community, or public) that remain unique entities, but are bound together by standardized or proprietary technology that enables data and application portability.

- A possible mnemonic to remember the five architectural components of the NIST CCRA is: **CAP-BC** (Cloud Auditor, Cloud Provider, Cloud Broker, Cloud Consumer, Cloud Carrier).
- A possible mnemonic to remember the three service categories of the NIST CCRA is: **SPI** (Software, Platform, Infrastructure).
- A possible mnemonic to remember the four deployment models of the NIST CCRA is: **PCHP** (Public, Community, Hybrid, Private).
