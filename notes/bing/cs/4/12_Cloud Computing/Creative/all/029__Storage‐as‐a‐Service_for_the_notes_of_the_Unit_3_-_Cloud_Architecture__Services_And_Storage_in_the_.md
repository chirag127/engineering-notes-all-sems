### Storage‐as‐a‐Service for the notes of the Unit 3 - Cloud Architecture, Services And Storage in the subject of Cloud Computing

- Storage‐as‐a‐Service (STaaS) is a cloud service model where a storage provider supplies access to storage and compute resources both on premises and/or over the cloud .
- STaaS saves money through operating expenditure (OPEX) agility, as the users only pay for the storage they need, when they need it .
- STaaS also provides basic ways to access the storage, such as web interfaces, APIs, or file systems .
- STaaS can be used for various purposes, such as multimedia storage, data repositories, data backup and recovery, and disaster recovery .
- STaaS is different from other cloud service models, such as Infrastructure‐as‐a‐Service (IaaS), Platform‐as‐a‐Service (PaaS), and Software‐as‐a‐Service (SaaS), in the following ways:
  - IaaS provides on-demand access to cloud-hosted physical and virtual servers, storage and networking, which can be used to run any software or application.
  - PaaS provides on-demand access to cloud-hosted development and deployment tools, such as databases, middleware, and frameworks, which can be used to create and run applications.
  - SaaS provides on-demand access to cloud-hosted software applications, such as email, CRM, or ERP, which can be used by end-users without installation or maintenance.
  - STaaS provides on-demand access to cloud-hosted storage and compute resources, which can be used to store and process data without managing the underlying infrastructure.

- A possible mnemonic to remember the difference between the cloud service models is:

  - IaaS: I need a server, storage, and network.
  - PaaS: I need a platform to develop and deploy my app.
  - SaaS: I need a software to use for my business.
  - STaaS: I need a storage to save and access my data.
