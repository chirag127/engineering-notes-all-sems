### Public, Private and Hybrid Clouds for the notes of the Unit 3 - Cloud Architecture, Services And Storage in the subject of Cloud Computing

- Public, private and hybrid clouds are different ways of deploying infrastructure and applications in a cloud computing model.
- A public cloud is an environment made available over the internet, that anyone can subscribe to and then access. A private cloud, as the name implies, is the infrastructure used by just one organization. A hybrid cloud is any environment that uses both public and private clouds.
- In general, public, private and hybrid clouds are all capable of providing access to the same types of cloud services. For example, you can run hosted VM instances, object storage services and serverless functions as a service on any type of cloud.
- The crucial differences between the cloud models lie in the following aspects:

  - **Cost**: Public clouds are typically cheaper than private clouds, as the provider can leverage economies of scale and charge customers based on usage. Private clouds require upfront investment in hardware and software, as well as ongoing maintenance and security costs. Hybrid clouds can offer a balance between cost and control, as the organization can choose which workloads to run on which cloud based on their needs and budget.
  - **Control**: Private clouds offer more control over the infrastructure and data, as the organization can customize and configure the cloud according to their preferences and policies. Public clouds offer less control, as the provider manages the underlying resources and sets the rules and standards for the cloud. Hybrid clouds can offer a degree of control, as the organization can decide which data and applications to keep on-premises and which to migrate to the public cloud.
  - **Scalability**: Public clouds offer more scalability than private clouds, as the provider can allocate more resources on demand and handle peak loads without affecting performance. Private clouds have limited scalability, as the organization has to provision and manage the resources themselves and may face capacity constraints. Hybrid clouds can offer some scalability, as the organization can use the public cloud for bursty or unpredictable workloads and the private cloud for steady or predictable workloads.
  - **Security**: Private clouds offer more security than public clouds, as the organization can implement their own security measures and policies and isolate their data and applications from external threats. Public clouds offer less security, as the provider is responsible for securing the cloud and the organization has to trust the provider and share the cloud with other customers. Hybrid clouds can offer a level of security, as the organization can choose which data and applications to keep on-premises and which to encrypt and transfer to the public cloud.

- Some examples of public cloud providers are Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). Some examples of private cloud platforms are VMware, OpenStack, and Microsoft Azure Stack. Some examples of hybrid cloud solutions are AWS Outposts, Azure Arc, and Google Anthos.
- A possible mnemonic to remember the differences between public, private and hybrid clouds is:

  - Public cloud: Pay as you go, Popular, Plenty of resources, Potentially risky
  - Private cloud: Personal, Pricey, Precise, Protected
  - Hybrid cloud: Half and half, Handy, Heterogeneous, Hybrid
