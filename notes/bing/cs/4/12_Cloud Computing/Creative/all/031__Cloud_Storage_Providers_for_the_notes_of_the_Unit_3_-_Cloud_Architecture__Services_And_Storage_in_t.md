### Cloud Storage Providers for the notes of the Unit 3 - Cloud Architecture, Services And Storage in the subject of Cloud Computing

- Cloud storage providers are companies that offer online storage services for personal or business use. They allow users to store, access, and share data over the internet, without having to manage their own physical storage devices.
- Cloud storage providers typically use one or more of the following storage models:
  - **Object storage**: Data is stored as discrete units called objects, which have a unique identifier, metadata, and data. Object storage is suitable for unstructured data, such as images, videos, documents, etc. Object storage is scalable, durable, and cost-effective, but has high latency and low performance.
  - **Block storage**: Data is stored as fixed-sized chunks called blocks, which are assigned a unique address. Block storage is suitable for structured data, such as databases, applications, etc. Block storage is fast, reliable, and high-performance, but has low scalability and high cost.
  - **File storage**: Data is stored as files in a hierarchical structure, similar to a traditional file system. File storage is suitable for shared data, such as documents, spreadsheets, etc. File storage is easy to use, compatible, and accessible, but has low security and efficiency.
