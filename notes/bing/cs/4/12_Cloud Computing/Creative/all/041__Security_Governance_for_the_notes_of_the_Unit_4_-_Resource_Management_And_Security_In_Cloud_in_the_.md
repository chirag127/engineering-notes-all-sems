### Security Governance for the notes of the Unit 4 - Resource Management And Security In Cloud in the subject of Cloud Computing

- Security governance in cloud computing is a framework of policies designed to dictate what cloud resources can be used, how they should be used, and who can use them.
- Security governance in cloud computing also enforces rules governing how individual resources should be secured to prevent their misuse by malicious actors.
- Security governance in cloud computing is a management model that facilitates effective and efficient security management and operations in a cloud computing environment.
- Security governance in cloud computing also incorporates executive mandates, operational practices, structures, and metrics.
- Security governance in cloud computing is a set of policies and rules used by companies who build or work in the cloud.
- Security governance in cloud computing is designed to ensure data security, system integration and the deployment of cloud computing are properly managed.
- Security governance in cloud computing bridges the business priorities with technical implementation like architecture, standards, and policy.
- Security governance in cloud computing provides oversight and monitoring to sustain and improve security posture over time.
- Security governance in cloud computing also reports compliance as required by regulating bodies.
- Security governance in cloud computing can be divided into five disciplines: cost management, security baseline, resource consistency, identity baseline, and deployment acceleration.
- Security governance in cloud computing requires establishing security requirements, cloud governance policies and enforcement mechanisms across network, data, and asset configurations .
- Security governance in cloud computing involves assessing the risks, threats, and vulnerabilities of the cloud environment and applying the appropriate controls and mitigation strategies.

#### Mnemonics and learning tricks

- To remember the five disciplines of cloud governance, use the acronym CSRID: Cost, Security, Resource, Identity, Deployment.
- To remember the components of security governance in cloud computing, use the acronym POMER: Policies, Oversight, Monitoring, Enforcement, Reporting .
- To remember the elements of technical implementation of security governance in cloud computing, use the acronym ASP: Architecture, Standards, Policy.
