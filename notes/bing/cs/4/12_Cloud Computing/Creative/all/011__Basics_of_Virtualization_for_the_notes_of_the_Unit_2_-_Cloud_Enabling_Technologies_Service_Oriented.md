### Basics of Virtualization for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

- Virtualization is a process that allows for more efficient utilization of physical computer hardware and is the foundation of cloud computing.
- Virtualization enables the hardware resources of a single computer—processors, memory, storage and more—to be divided into multiple virtual machines (VMs), each with its own operating system and applications.
- Virtualization also allows for the creation of virtual networks, storage, data and applications that are independent of the underlying physical infrastructure .
- Virtualization technology makes cloud computing possible. Cloud providers set up and maintain their own data centers. They create different virtual environments that use the underlying hardware resources. You can then program your system to access these cloud resources by using APIs.
- Virtualization has many benefits for cloud computing, such as:
  - Cost reduction: Virtualization reduces the need for physical hardware and maintenance, which lowers the capital and operational expenses of cloud providers and users.
  - Scalability: Virtualization allows for the dynamic allocation and deallocation of resources according to the demand, which enables cloud computing to scale up or down as needed.
  - Flexibility: Virtualization allows for the creation of customized and isolated virtual environments that can run different operating systems and applications, which gives cloud users more choice and control over their computing needs.
  - Security: Virtualization provides a layer of abstraction between the physical and virtual layers, which can enhance the security and privacy of cloud data and applications by isolating them from potential threats.
  - Availability: Virtualization improves the availability and reliability of cloud services by enabling the migration and backup of virtual machines and data across different physical servers and locations.
- There are different types of virtualization in cloud computing, such as:
  - Server virtualization: Server virtualization is a process that partitions a physical server into multiple virtual servers. It is an efficient and cost-effective way to utilize the server resources and run multiple applications on the same hardware.
  - Storage virtualization: Storage virtualization is a process that combines multiple physical storage devices into a single virtual storage device. It is a convenient and flexible way to manage and access the storage resources and data in the cloud.
  - Network virtualization: Network virtualization is a process that creates a virtual network that is independent of the physical network infrastructure. It is a secure and efficient way to connect and communicate between different virtual machines and cloud services.
  - Data virtualization: Data virtualization is a process that abstracts the data from its source and location and presents it as a single logical data source. It is a powerful and agile way to access and integrate the data from different sources and formats in the cloud.
  - Application virtualization: Application virtualization is a process that encapsulates an application from its underlying operating system and hardware. It is a portable and compatible way to run and deliver the applications in the cloud.

- A possible mnemonic to remember the types of virtualization is **S**torage, **N**etwork, **D**ata, **A**pplication, **S**erver, which spells **SN-DAS**. You can think of it as "Send us" the virtualization types.
