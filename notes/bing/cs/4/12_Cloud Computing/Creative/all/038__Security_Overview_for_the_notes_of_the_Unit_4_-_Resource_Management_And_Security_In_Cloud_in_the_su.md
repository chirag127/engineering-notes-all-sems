### Security Overview for the notes of the Unit 4 - Resource Management And Security In Cloud in the subject of Cloud Computing

- Cloud security, also known as cloud computing security, consists of a set of policies, controls, procedures and technologies that work together to protect cloud-based systems, data, and infrastructure.
- Cloud security challenges include:
  - Data breaches: unauthorized access to sensitive or confidential data stored in the cloud.
  - Data loss: accidental or malicious deletion, corruption, or theft of data stored in the cloud.
  - Denial of service (DoS) attacks: intentional or unintentional disruption of the availability or performance of cloud services or resources.
  - Malicious insiders: employees, contractors, or third parties who abuse their access privileges to compromise cloud security or data.
  - Insecure APIs: application programming interfaces (APIs) that expose cloud services or data to external or internal users without proper authentication, authorization, or encryption.
  - Shared technology vulnerabilities: flaws or weaknesses in the underlying hardware, software, or network components that are shared by multiple cloud tenants or users.
- Cloud security solutions include:
  - Security as a service (SaaS): a cloud service model that provides security functions or features to cloud users, such as identity and access management (IAM), encryption, firewall, antivirus, etc.
  - Security governance: a framework of policies, standards, guidelines, and best practices that define the roles, responsibilities, and processes for managing cloud security.
  - Virtual machine security: a set of techniques and tools that protect the integrity, confidentiality, and availability of virtual machines (VMs) running on cloud platforms, such as hypervisor security, VM isolation, VM monitoring, etc.
  - IAM: a system that manages the identities and access rights of cloud users, such as authentication, authorization, auditing, etc.
  - Security standards: a set of specifications or requirements that define the minimum level of security for cloud services or data, such as ISO/IEC 27017, NIST SP 800-144, CSA CCM, etc.

- A possible mnemonic to remember the cloud security challenges is **DID MIS** (Data breaches, Data loss, DoS attacks, Malicious insiders, Insecure APIs, Shared technology vulnerabilities).
- A possible mnemonic to remember the cloud security solutions is **SAS VIM** (SaaS, Security governance, Virtual machine security, IAM, Security standards).
