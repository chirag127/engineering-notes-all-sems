### Virtualization Structures for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

- Virtualization is a technology that can manipulate hardware and create virtual machines that can run multiple operating systems and applications.
- Cloud computing is a service that is the result of virtualization and delivers shared resources as a service-on-demand via the internet.
- Virtualization is the foundation element of cloud computing, whereas cloud technology is the delivery of virtualization.
- The architecture of virtualization is a model that describes how virtualization works conceptually. It consists of four layers: hardware layer, virtualization layer, guest layer and application layer.
- Hardware layer: This is the physical layer that provides the resources such as CPU, memory, disk, network, etc. for virtualization.
- Virtualization layer: This is the layer that creates and manages the virtual machines and allocates the resources from the hardware layer to them. It also provides the interface for the guest layer to access the resources. Examples of virtualization layer are hypervisors, virtual machine monitors, etc.
- Guest layer: This is the layer that contains the operating systems and applications that run on the virtual machines. Each virtual machine can have a different operating system and application. Examples of guest layer are Windows, Linux, etc.
- Application layer: This is the layer that contains the services and applications that are delivered to the end-users via the internet. Examples of application layer are web services, cloud services, etc.
- There are different types of virtualization, such as server virtualization, storage virtualization, network virtualization, desktop virtualization, application virtualization, etc. Each type of virtualization has its own advantages and disadvantages, depending on the use case and the requirements.
- There are also different levels of virtualization, such as full virtualization, para-virtualization, hardware-assisted virtualization, operating system-level virtualization, etc. Each level of virtualization has its own degree of isolation, performance, compatibility and overhead.
- Virtualization structures are the ways of organizing the virtual machines and the resources in the virtualization layer. There are two main types of virtualization structures: hosted and bare-metal.
- Hosted virtualization structure: This is the structure where the virtualization layer runs on top of an existing operating system, which acts as the host. The host operating system provides the drivers and the access to the hardware layer. The virtual machines run as processes on the host operating system and share the resources with it. Examples of hosted virtualization structure are VMware Workstation, VirtualBox, etc.
- Bare-metal virtualization structure: This is the structure where the virtualization layer runs directly on the hardware layer, without any host operating system. The virtualization layer provides the drivers and the access to the hardware layer. The virtual machines run as independent entities on the virtualization layer and have exclusive access to the resources. Examples of bare-metal virtualization structure are VMware ESXi, Hyper-V, etc.
- Virtualization tools and mechanisms are the software and hardware components that enable and support the virtualization process. Some of the common virtualization tools and mechanisms are:
  - Hypervisor: This is the software that creates and manages the virtual machines and allocates the resources to them. It also provides the interface for the guest layer to access the resources. Examples of hypervisors are VMware ESXi, Hyper-V, Xen, etc.
  - Virtual machine monitor (VMM): This is the software that monitors the state and the performance of the virtual machines and the resources. It also provides the functionality for the migration, backup, recovery, etc. of the virtual machines. Examples of VMMs are VMware vCenter, Microsoft System Center, etc.
  - Virtual machine (VM): This is the software that emulates a physical machine and runs an operating system and an application. It has its own virtual CPU, memory, disk, network, etc. Examples of VMs are Windows VM, Linux VM, etc.
  - Virtual CPU (vCPU): This is the software that emulates a physical CPU and executes the instructions of the guest operating system and the application. It can be mapped to one or more physical CPUs, depending on the configuration and the workload. Examples of vCPUs are Intel VT-x, AMD-V, etc.
  - Virtual memory (vRAM): This is the software that emulates a physical memory and stores the data of the guest operating system and the application. It can be mapped to one or more physical memories, depending on the configuration and the workload. Examples of vRAM are VMware ballooning, memory overcommitment, etc.
