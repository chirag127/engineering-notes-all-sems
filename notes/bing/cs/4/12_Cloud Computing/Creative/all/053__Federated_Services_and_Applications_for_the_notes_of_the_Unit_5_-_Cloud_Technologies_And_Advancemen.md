### Federated Services and Applications for the notes of the Unit 5 - Cloud Technologies And Advancements Hadoop in the subject of Cloud Computing

- Cloud federation, also known as federated cloud, is the deployment and management of multiple external and internal cloud computing services to match business needs.
- Cloud federation enables the sharing of resources and services among different cloud providers, such as private, public, and community clouds, to create a scalable and flexible computing platform.
- Cloud federation can be achieved at four levels: infrastructure, platform, application, and data.
- Infrastructure federation involves the sharing of physical and virtual resources, such as servers, storage, and networks, among different cloud providers. This can improve resource utilization, load balancing, and fault tolerance.
- Platform federation involves the sharing of middleware and development tools, such as databases, web servers, and frameworks, among different cloud providers. This can enable interoperability, portability, and compatibility of applications across different cloud platforms.
- Application federation involves the sharing of software and services, such as email, social media, and e-commerce, among different cloud providers. This can enhance functionality, performance, and user experience of applications across different cloud domains.
- Data federation involves the sharing of information and analytics, such as business intelligence, data mining, and machine learning, among different cloud providers. This can enable data integration, aggregation, and processing across different cloud sources.
- Federated services and applications are the future of cloud computing, as they can provide the following benefits:
  - Cost reduction: By sharing resources and services among different cloud providers, cloud federation can reduce the operational and capital expenses of cloud computing.
  - Scalability: By leveraging the resources and services of multiple cloud providers, cloud federation can increase the capacity and performance of cloud computing.
  - Availability: By distributing the resources and services among different cloud providers, cloud federation can improve the reliability and resilience of cloud computing.
  - Diversity: By accessing the resources and services of different cloud providers, cloud federation can offer a variety of options and features for cloud computing.
  - Compliance: By selecting the resources and services of different cloud providers, cloud federation can meet the regulatory and legal requirements of cloud computing.
- Hadoop is an Apache open source framework written in Java that allows distributed processing of large datasets across clusters of computers using simple programming models .
- Hadoop is designed to scale up from single server to thousands of machines, each offering local computation and storage .
- Hadoop runs applications using the MapReduce algorithm, where the data is processed in parallel on different CPU nodes .
- Hadoop consists of two core components: Hadoop Distributed File System (HDFS) and Hadoop MapReduce .
- HDFS is a distributed file system inspired by Google File System (GFS) that organizes files and stores their data on a distributed computing system. HDFS provides high throughput, fault tolerance, and scalability for large data sets .
- Hadoop MapReduce is a programming model and software framework for writing applications that process large amounts of data in parallel on clusters of computers. MapReduce consists of two phases: map and reduce. The map phase applies a user-defined function to each input key-value pair and produces a set of intermediate key-value pairs. The reduce phase applies another user-defined function to all the intermediate values associated with the same intermediate key and produces a set of output key-value pairs .
- Hadoop also provides a number of other components, such as Hadoop Common, Hadoop YARN, Hadoop ZooKeeper, Hadoop Oozie, Hadoop Hive, Hadoop Pig, Hadoop HBase, Hadoop Spark, and Hadoop Mahout, that support various aspects of data management, resource management, coordination, workflow, query, analysis, and machine learning on Hadoop clusters .
- Hadoop is widely used for big data analytics, data warehousing, data mining, machine learning, and artificial intelligence applications in various domains, such as web, social media, e-commerce, finance, health care, and education .
