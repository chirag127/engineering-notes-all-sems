### Underlying Principles of Parallel and Distributed Computing for the notes of the Unit 1 - Introduction To Cloud Computing in the subject of Cloud Computing

- Parallel and distributed computing are two models of computation that allow multiple tasks to be executed simultaneously by using multiple processors or computing devices .
- Parallel computing refers to a model in which the computation is divided among several processors sharing the same memory and communication network . Parallel computing can be classified into two types: shared-memory and distributed-memory.
  - Shared-memory parallel computing uses a single memory space that is accessible by all the processors. The processors communicate by reading and writing to the shared memory. An example of shared-memory parallel computing is a multi-core processor in a single computer.
  - Distributed-memory parallel computing uses multiple memory spaces that are distributed among the processors. The processors communicate by sending and receiving messages over a network. An example of distributed-memory parallel computing is a cluster of computers connected by a network.
- Distributed computing refers to a model in which the computation is distributed among several independent and autonomous computing devices that may have different memory and communication capabilities . Distributed computing can be classified into two types: centralized and decentralized.
  - Centralized distributed computing uses a single coordinator or master that assigns tasks to the other computing devices or workers. The coordinator is responsible for managing the communication and synchronization among the workers. An example of centralized distributed computing is a web server that handles requests from multiple clients.
  - Decentralized distributed computing uses no coordinator or master, and each computing device or peer can initiate and perform tasks independently. The peers communicate and cooperate with each other to achieve a common goal. An example of decentralized distributed computing is a peer-to-peer network that shares files among multiple users.
- Parallel and distributed computing builds on fundamental systems concepts, such as concurrency, mutual exclusion, consistency, synchronization, scalability, fault tolerance, and load balancing  .
  - Concurrency refers to the ability of multiple tasks to run at the same time, either in parallel or interleaved. Concurrency requires mechanisms to coordinate and control the execution of the tasks, such as threads, locks, semaphores, and monitors.
  - Mutual exclusion refers to the property that ensures that only one task can access a shared resource at a time, such as a file, a variable, or a device. Mutual exclusion prevents data corruption and inconsistency due to concurrent access. Mutual exclusion can be achieved by using algorithms, such as Lamport's bakery algorithm, or protocols, such as token passing or leader election.
  - Consistency refers to the property that ensures that the state of a shared resource is the same for all the tasks that access it, regardless of the order and timing of the access. Consistency requires mechanisms to update and propagate the changes to the shared resource, such as atomic operations, transactions, or replication.
  - Synchronization refers to the property that ensures that the tasks that depend on each other are executed in the correct order and at the correct time. Synchronization requires mechanisms to coordinate and communicate the progress and status of the tasks, such as barriers, clocks, or signals.
  - Scalability refers to the property that ensures that the performance and efficiency of the system can be improved by adding more processors or computing devices. Scalability requires mechanisms to distribute and balance the workload among the processors or computing devices, such as partitioning, mapping, or scheduling.
  - Fault tolerance refers to the property that ensures that the system can continue to function correctly even if some of the processors or computing devices fail or malfunction. Fault tolerance requires mechanisms to detect and recover from the failures, such as redundancy, checkpointing, or rollback.
  - Load balancing refers to the property that ensures that the workload is evenly distributed among the processors or computing devices, such that no processor or computing device is overloaded or underutilized. Load balancing requires mechanisms to monitor and adjust the workload allocation, such as feedback, migration, or replication.
- Parallel and distributed computing are essential for cloud computing, as they enable the efficient and scalable execution of complex and large-scale applications on a network of virtualized and distributed resources.
  - Cloud computing is a model of computing that provides on-demand access to a pool of shared and configurable computing resources, such as servers, storage, networks, software, and services, over the internet.
