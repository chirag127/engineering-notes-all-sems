### I/O Devices for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

- I/O devices are hardware components that can take, output, or process data. They receive data as input and provide it to a computer, as well as send computer data to storage media as a storage output.
- Some examples of I/O devices are keyboards, mouses, printers, hard disks, monitors, cameras, sensors, etc .
- I/O devices are essential for cloud computing, as they enable the communication and interaction between the users and the cloud services. They also allow the collection and analysis of data from various sources, such as sensors, cameras, or other IoT devices .
- Cloud computing provides many connectivity options, implying large network access. People use a wide range of devices to gain access to cloud computing resources: mobile devices, tablets, laptops, etc. This is convenient for users but creates the problem of the need for network access points.
- Edge computing is a solution that aims to reduce the latency and bandwidth issues of cloud computing by processing data closer to the source, i.e., the I/O devices. Edge devices include smart cameras, thermometers, robots, drones, vibration sensors, and other IoT devices. Although some devices have built-in compute, memory, and storage capabilities, not all do. Processors are the CPUs, GPUs, and associated memory that power edge computing systems.
- I/O devices can be classified into three types based on their functionality: input devices, output devices, and input/output devices. Input devices are those that send data to the computer, such as keyboards, mouses, scanners, etc. Output devices are those that display or store data from the computer, such as monitors, printers, speakers, etc. Input/output devices are those that can perform both functions, such as hard disks, diskettes, writable CD-ROMs, etc.
- Some mnemonics and learning tricks for I/O devices are:

  - To remember the types of I/O devices, use the acronym **IOP**: **I**nput, **O**utput, and **I**nput/**O**utput devices.
  - To remember some examples of input devices, use the phrase **KMS**: **K**eyboard, **M**ouse, and **S**canner.
  - To remember some examples of output devices, use the phrase **MPS**: **M**onitor, **P**rinter, and **S**peaker.
  - To remember some examples of input/output devices, use the phrase **HDC**: **H**ard disk, **D**iskette, and writable **C**D-ROM.
