## Unit 3 - Cloud Architecture, Services And Storage

- Cloud architecture is the way technology components combine to build a cloud, in which resources are pooled through virtualization technology and shared across a network.
- Cloud architecture consists of a front-end platform (the client or device used to access the cloud), a back-end platform (servers and storage), a cloud-based delivery model, and a network (Internet, Intranet, Intercloud).
- Cloud services are the software, platforms, and infrastructure that are hosted and managed by a cloud service provider and delivered to users over the network.
- Cloud services can be classified into three main types: Software as a Service (SaaS), Platform as a Service (PaaS), and Infrastructure as a Service (IaaS).
- SaaS is a software delivery model that provides users with access to applications and data through a web browser, without requiring installation or maintenance on the user's device.
- PaaS is a platform delivery model that provides users with a development environment and tools to create and deploy cloud-based applications, without requiring management of the underlying infrastructure.
- IaaS is an infrastructure delivery model that provides users with access to computing resources such as servers, storage, network, and operating systems, without requiring ownership or control of the physical hardware.
- Cloud storage is a service that allows users to store and access data on remote servers that are managed by a cloud service provider.
- Cloud storage can be used for various purposes, such as backup, archiving, disaster recovery, synchronization, collaboration, and data analytics.
- Cloud storage can be accessed through different interfaces, such as web-based, application programming interface (API), file system, or block device.
- Cloud storage can be classified into four main types: object storage, file storage, block storage, and data lake storage.
- Object storage is a storage model that stores data as objects, which consist of data, metadata, and a unique identifier.
- Object storage is suitable for storing unstructured or semi-structured data, such as images, videos, documents, and logs.
- Object storage can be accessed through RESTful APIs, which allow users to perform operations such as create, read, update, and delete (CRUD) on objects.
- File storage is a storage model that stores data as files, which are organized in a hierarchical structure of folders and subfolders.
- File storage is suitable for storing structured or semi-structured data, such as databases, spreadsheets, and documents.
- File storage can be accessed through file system protocols, such as Server Message Block (SMB) or Network File System (NFS), which allow users to perform operations such as open, read, write, and close on files.
- Block storage is a storage model that stores data as blocks, which are fixed-sized chunks of data that are assigned a unique address.
- Block storage is suitable for storing low-latency and high-performance data, such as operating systems, applications, and databases.
- Block storage can be accessed through block device protocols, such as Internet Small Computer System Interface (iSCSI) or Fibre Channel, which allow users to perform operations such as read and write on blocks.
- Data lake storage is a storage model that stores data as files or objects, which are organized in a flat structure of folders and subfolders.
- Data lake storage is suitable for storing large-scale and diverse data, such as structured, semi-structured, or unstructured data, for big data analytics and machine learning.
- Data lake storage can be accessed through multiple interfaces, such as web-based, API, file system, or block device, depending on the data type and the analysis tool.
