### Cloud Characteristics for the notes of the Unit 1 - Introduction To Cloud Computing in the subject of Cloud Computing

Cloud computing is a model for enabling convenient, on-demand network access to a shared pool of configurable computing resources (e.g., networks, servers, storage, applications, and services) that can be rapidly provisioned and released with minimal management effort or service provider interaction.

There are eight key characteristics of cloud computing that distinguish it from traditional computing models:

- **On-demand self-service**: Cloud computing allows users to provision and manage computing resources without human intervention from the service provider. Users can select and use single or multiple services depending on their needs. For example, a user can create a virtual machine, a database, or a web application on a cloud platform with a few clicks.
- **Resource pooling**: Cloud computing relies on multi-tenant architectures to accommodate more users at the same time. The service provider dynamically assigns and reassigns resources to different users according to their demand. The resources are pooled from a large-scale infrastructure that is distributed across multiple locations. For example, a cloud storage service can store data from multiple users on the same physical disk, but each user can only access their own data.
- **Broad network access**: Cloud computing services are accessible over standard networks and protocols, such as the internet, from various devices, such as laptops, smartphones, tablets, etc. The users can access the services anytime and anywhere, as long as they have a network connection. For example, a user can access their email, documents, or photos from any device with a web browser.
- **Rapid elasticity and scalability**: Cloud computing services can scale up or down quickly and automatically to meet the changing demand of the users. The users can request more or less resources as needed, and pay only for what they use. The service provider can also adjust the capacity of the infrastructure to optimize the performance and cost. For example, a web application can handle a sudden spike in traffic by adding more servers, and then release them when the traffic decreases.
- **Measured service**: Cloud computing services are monitored and measured by the service provider and the user. The service provider can track the usage and performance of the resources, and charge the user accordingly. The user can also monitor and control the consumption and quality of the services. For example, a user can view the billing and usage reports of their cloud services on a dashboard.
- **Reliability**: Cloud computing services are designed to be reliable and fault-tolerant, by using techniques such as replication, backup, redundancy, and failover. The service provider can ensure the availability and continuity of the services, even in the event of hardware or software failures, power outages, network disruptions, or natural disasters. For example, a cloud service can store multiple copies of the data in different locations, and switch to another location if one fails.
- **Security**: Cloud computing services are protected by various security mechanisms, such as encryption, authentication, authorization, firewalls, etc. The service provider can safeguard the data and resources from unauthorized access, modification, or deletion. The user can also configure and manage the security settings and policies of their cloud services. For example, a user can encrypt their data, set passwords, and grant permissions to their cloud services.
- **Cost-effectiveness**: Cloud computing services can reduce the capital and operational expenses of the users, by eliminating the need to purchase, install, maintain, and upgrade hardware and software. The users can also benefit from the economies of scale and the pay-per-use model of the service provider. The service provider can also optimize the utilization and efficiency of the resources, and pass the savings to the users. For example, a user can save money by using a cloud service instead of buying a server.

- **R**apid elasticity and scalability
