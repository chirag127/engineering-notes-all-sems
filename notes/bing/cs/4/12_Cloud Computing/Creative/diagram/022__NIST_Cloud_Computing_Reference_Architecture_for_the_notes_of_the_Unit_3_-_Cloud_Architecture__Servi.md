The NIST Cloud Computing Reference Architecture is a framework that defines the essential components and relationships of a cloud computing system. It is based on the NIST cloud computing definition and the NIST cloud computing model  .

The following diagram illustrates the basic architecture of a cloud computing system using ASCII characters:

```
|                  |  |                  |  |                  |
+------------------+  +------------------+  +------------------+
```

The diagram shows the five major components of the NIST Cloud Computing Reference Architecture:

- Cloud Consumer: The entity that uses cloud services, such as end users or applications.
- Cloud Provider: The entity that provides cloud services, such as infrastructure, platform, or software.
- Cloud Auditor: The entity that conducts independent assessment of the cloud services, such as security, performance, or compliance.
- Cloud Broker: The entity that intermediates between cloud consumers and providers, such as by aggregating, integrating, or customizing cloud services.
- Cloud Carrier: The entity that transports data between cloud consumers and providers, such as network operators or communication providers.

The diagram also shows the relationships among the components, such as service usage, service management, service negotiation, service auditing, and service delivery .
