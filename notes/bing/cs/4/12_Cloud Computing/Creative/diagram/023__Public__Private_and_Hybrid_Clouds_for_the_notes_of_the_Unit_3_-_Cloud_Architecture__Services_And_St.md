A public cloud is a cloud computing environment that is shared by multiple users and accessed over the internet. The service provider owns and manages the cloud infrastructure and resources, and offers them to the service consumers on a pay-per-use or subscription basis. Examples of public cloud providers are Amazon Web Services, Microsoft Azure, and Google Cloud Platform.

A private cloud is a cloud computing environment that is dedicated to a single user or organization and accessed over a private network.
