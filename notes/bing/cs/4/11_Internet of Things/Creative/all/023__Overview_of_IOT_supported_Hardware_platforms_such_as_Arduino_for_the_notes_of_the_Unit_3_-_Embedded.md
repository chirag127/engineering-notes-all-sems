### Overview of IOT supported Hardware platforms such as Arduino for the notes of the Unit 3 - Embedded Platforms for IoT in the subject of Internet of Things

- IoT hardware platforms are devices that enable the development and deployment of IoT solutions, such as sensors, actuators, controllers, gateways, and cloud services.
- IoT hardware platforms can be classified into two categories: low-power boards and single-board computers.
- Low-power boards are microcontrollers that run on batteries or solar power and have limited processing and memory capabilities. They are suitable for simple and cost-effective IoT applications that require low data rates and long battery life, such as environmental monitoring, smart agriculture, and wearable devices.
- Single-board computers are miniaturized computers that run on Linux or Windows and have more processing and memory capabilities. They are suitable for complex and high-performance IoT applications that require high data rates and advanced features, such as video streaming, facial recognition, and machine learning.
- Some of the most popular and accessible IoT hardware platforms are:

  - Arduino: Arduino is an open source platform that consists of various microcontroller boards, such as Arduino Uno, Arduino Nano, Arduino Mega, and Arduino Yun, and a software development environment, called Arduino IDE, that allows users to write and upload code to the boards. Arduino boards are easy to use, compatible with various sensors and actuators, and support various communication protocols, such as WiFi, Bluetooth, GSM, and Sigfox  .
  - Raspberry Pi: Raspberry Pi is a single-board computer that runs on Linux and has a 40-pin GPIO header that allows users to connect various sensors and actuators. Raspberry Pi also has USB ports, HDMI port, Ethernet port, and a microSD card slot for storage. Raspberry Pi can run various programming languages, such as Python, C, and Java, and supports various communication protocols, such as WiFi, Bluetooth, and LoRa  .
  - Intel Galileo: Intel Galileo is a single-board computer that runs on Linux and has a 14-pin GPIO header that is compatible with Arduino shields. Intel Galileo also has USB ports, Ethernet port, and a microSD card slot for storage. Intel Galileo can run various programming languages, such as C, C++, and Python, and supports various communication protocols, such as WiFi, Bluetooth, and Zigbee.
  - Tibbo Project System: Tibbo Project System is a modular platform that allows users to create custom IoT devices by combining various modules, such as CPU, power, display, network, and sensor modules. Tibbo Project System also has a software development environment, called Tibbo IDE, that allows users to write and upload code to the devices. Tibbo Project System supports various communication protocols, such as WiFi, Ethernet, and RS232.
  - Cloud-based IoT Platforms: Cloud-based IoT platforms are online services that provide various features and functionalities for IoT development and deployment, such as device management, data storage, data processing, data visualization, and data analytics. Some of the examples of cloud-based IoT platforms are Microsoft Azure IoT, Amazon Web Services IoT, Google Cloud IoT, and IBM Watson IoT .

- Some of the advantages of using IoT hardware platforms are:

  - They reduce the time and cost of IoT development and deployment by providing ready-made and standardized components and tools.
  - They enable the integration and interoperability of various IoT devices and applications by supporting various communication protocols and standards.
  - They enhance the performance and functionality of IoT solutions by providing advanced features and capabilities, such as data encryption, data compression, and machine learning.
  - They facilitate the scalability and reliability of IoT solutions by providing cloud-based services and support.

- Some of the disadvantages of using IoT hardware platforms are:

  - They may limit the customization and flexibility of IoT solutions by imposing certain constraints and specifications on the hardware and software components.
  - They may increase the security and privacy risks of IoT solutions by exposing the data and devices to online threats and attacks.
  - They may require additional skills and knowledge to use and maintain the hardware and software components.

- Some of the applications of IoT hardware platforms are:

  - Smart Home: IoT hardware platforms can be used to create smart home devices and applications, such as smart lights, smart locks, smart thermostats, and smart cameras, that can be controlled and monitored remotely via smartphones or voice assistants.
