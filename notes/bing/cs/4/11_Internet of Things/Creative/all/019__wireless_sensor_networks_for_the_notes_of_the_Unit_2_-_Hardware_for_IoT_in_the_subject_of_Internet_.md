### Wireless Sensor Networks for the notes of the Unit 2 - Hardware for IoT in the subject of Internet of Things

- A wireless sensor network (WSN) is a network of small, low-power devices that can sense, process and communicate data wirelessly over a certain area .
- A WSN consists of three main components: sensor nodes, base stations and gateways.
  - Sensor nodes are the devices that collect data from the environment using various sensors, such as temperature, humidity, light, sound, etc. They can also perform some local processing and communicate with other nodes or base stations using wireless protocols, such as ZigBee, Bluetooth, Wi-Fi, etc .
  - Base stations are the devices that receive data from sensor nodes and forward it to the gateways or the cloud. They can also perform some aggregation, filtering and analysis of the data. They can be fixed or mobile, and can use wired or wireless connections.
  - Gateways are the devices that connect the WSN to the Internet or other networks. They can also perform some security, authentication and management functions. They can use various technologies, such as cellular, satellite, optical fiber, etc.
- A WSN can be classified into different types based on the topology, architecture, communication, application, etc.
  - Based on the topology, a WSN can be star, tree, mesh or hybrid. In a star topology, each sensor node communicates directly with the base station. In a tree topology, each sensor node communicates with a parent node, which communicates with the base station. In a mesh topology, each sensor node can communicate with any other node, forming a multi-hop network. In a hybrid topology, a combination of the above topologies is used.
  - Based on the architecture, a WSN can be flat, hierarchical or location-based. In a flat WSN, all sensor nodes have the same role and functionality. In a hierarchical WSN, sensor nodes are organized into clusters, and each cluster has a leader node that communicates with the base station. In a location-based WSN, sensor nodes are aware of their geographic location and use it for routing and data processing.
  - Based on the communication, a WSN can be single-hop or multi-hop. In a single-hop WSN, each sensor node communicates directly with the base station or the gateway. In a multi-hop WSN, each sensor node can relay data through other nodes to reach the base station or the gateway.
  - Based on the application, a WSN can be environmental, health, industrial, military, smart city, etc. Environmental WSNs monitor the natural phenomena, such as weather, wildlife, pollution, etc. Health WSNs monitor the vital signs, activities and location of patients or elderly people. Industrial WSNs monitor the production, quality and safety of industrial processes and machines. Military WSNs monitor the battlefield, enemy movements, weapons and vehicles. Smart city WSNs monitor the traffic, energy, water, waste, etc  .
- A WSN has many advantages, such as low cost, scalability, flexibility, self-organization, fault tolerance, etc. However, it also faces many challenges, such as limited resources, security, reliability, interoperability, etc .
- A WSN can be integrated with other technologies, such as cloud computing, fog computing, edge computing, machine learning, etc., to enhance its capabilities and performance.
- A WSN can be used for various purposes, such as data collection, data processing, data analysis, data visualization, data transmission, data storage, data sharing, etc .
