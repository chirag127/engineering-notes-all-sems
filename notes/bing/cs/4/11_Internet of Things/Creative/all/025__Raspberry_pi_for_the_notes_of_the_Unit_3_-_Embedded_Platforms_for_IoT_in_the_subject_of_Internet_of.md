### Raspberry pi for the notes of the Unit 3 - Embedded Platforms for IoT in the subject of Internet of Things

- Raspberry pi is a small, low-cost, single-board computer that can run various operating systems such as Linux, Windows 10 IoT Core, and Raspbian.
- Raspberry pi can be used for various IoT projects, such as smart home devices, robotics, automation, security, and environmental monitoring.
- Raspberry pi has a 40-pin GPIO (general-purpose input/output) header that can be used to connect sensors, actuators, and other peripherals to the board.
- Raspberry pi can communicate with other devices and the internet using various protocols, such as Wi-Fi, Bluetooth, Ethernet, USB, UART, SPI, and I2C.
- Raspberry pi can be programmed using various languages, such as Python, C, C++, Java, and Node.js.
- Raspberry pi can be controlled and managed remotely using cloud platforms, such as AWS IoT, Azure IoT, Google Cloud IoT, and Ubidots.

Some advantages of using Raspberry pi for IoT are:

- It is cheap and widely available, making it accessible to anyone who wants to learn and experiment with IoT.
- It is versatile and flexible, allowing users to customize and adapt it to their needs and preferences.
- It is powerful and capable, offering a high-performance CPU, GPU, and RAM, as well as a large storage capacity with a microSD card.
- It is compatible and interoperable, supporting various operating systems, protocols, languages, and platforms.
- It is community-supported and well-documented, providing users with a lot of resources, tutorials, and examples to learn from and troubleshoot with.

Some disadvantages of using Raspberry pi for IoT are:

- It is not very robust and durable, requiring a protective case and proper cooling to prevent overheating and damage.
- It is not very secure and reliable, exposing users to potential cyberattacks and data breaches if not configured and updated properly.
- It is not very energy-efficient and battery-friendly, consuming a lot of power and requiring a constant power supply or a large battery pack.
- It is not very scalable and modular, limiting the number and type of devices that can be connected and integrated with it.

Some examples of IoT projects using Raspberry pi are:

- Smart doorbell: A Raspberry pi can be used to create a smart doorbell that can detect visitors, capture their images, and send notifications to the user's smartphone or email.
- Rosie IoT Brick: A Raspberry pi can be used to create a wearable device that can track the user's location, speed, and distance during a marathon run and send the data to a cloud platform.
- PiRoomba: A Raspberry pi can be used to enhance a robot vacuum cleaner with face recognition, voice control, and remote monitoring features.
- Sleepbuddy: A Raspberry pi can be used to create a robot babysitter that can monitor the user's baby, play soothing sounds, and activate a night light.
- Furlexa: A Raspberry pi can be used to create a voice assistant for pets that can respond to their commands, play games, and dispense treats.
- Smart home bulb: A Raspberry pi can be used to create a smart home bulb that can be controlled by clapping or using a smartphone app.
- MudPi: A Raspberry pi can be used to create an automated gardening system that can monitor the soil moisture, temperature, and light levels and water the plants accordingly.
- Raspberry Pi AI Teasmade: A Raspberry pi can be used to create a smart tea maker that can brew a cup of tea at a specified time and temperature using artificial intelligence.

Some mnemonics and learning tricks for Raspberry pi for IoT are:

- To remember the number of pins in the GPIO header, use the rhyme: "Forty pins are plenty, to connect to Raspberry pi."
- To remember the order of the GPIO pins, use the acronym: "PWR GND GPIO", which stands for Power, Ground, and General-Purpose Input/Output pins.
- To remember the names of the communication protocols, use the acronym: "WUBESI", which stands for Wi-Fi, USB, Bluetooth, Ethernet, SPI, and I2C.
- To remember the names of the cloud platforms, use the acronym: "AAGU", which stands for AWS, Azure, Google, and Ubidots.
