### Netduino for the notes of the Unit 3 - Embedded Platforms for IoT in the subject of Internet of Things

- Netduino is an open source hardware platform that runs applications built with the .NET Micro Framework, a subset of the .NET Framework that is designed for embedded devices.
- Netduino supports C# and Visual Basic programming languages, and can be programmed using Visual Studio or Xamarin Studio on Windows or Mac OS.
- Netduino has several models, such as Netduino 2, Netduino 3, Netduino Go, and Netduino Plus 2. The latter is the most advanced model, with features such as:
  - 168 MHz ARM Cortex-M4 processor with 192 KB RAM and 1 MB flash memory.
  - Ethernet port for network connectivity.
  - Micro SD card slot for additional storage.
  - 6 analog inputs and 14 digital I/O pins, some of which support PWM, SPI, I2C, and UART protocols.
  - Power jack and micro USB port for power supply and debugging.
- Netduino can be used for various IoT applications, such as:
  - Home automation, such as controlling lights, fans, thermostats, etc. using web or mobile interfaces.
  - Sensor networks, such as monitoring temperature, humidity, light, motion, etc. using wireless or wired communication.
  - Robotics, such as controlling motors, servos, cameras, etc. using sensors and actuators.
  - Industrial control, such as regulating valves, pumps, switches, etc. using feedback loops and PID algorithms.
- Netduino has a rich ecosystem of libraries, drivers, and modules that can be used to extend its functionality and compatibility with various peripherals and devices. Some examples are:
  - Netduino.Foundation, a library that provides drivers and helpers for common components, such as LEDs, buttons, LCDs, sensors, etc..
  - IoT Starter Core, a library that provides modules for IoT protocols, such as MQTT, CoAP, REST, etc..
  - Netduino.IP, a library that provides a TCP/IP stack for Netduino devices.
  - Netduino Plus Shield Base, a module that allows Netduino Plus 2 to use Arduino shields.
  - Netduino Go Shield Base, a module that allows Netduino Go to use Gadgeteer modules.
- Netduino is compatible with Arduino, a popular open source hardware platform that also supports IoT applications. Netduino and Arduino share the same form factor, pin layout, and voltage levels, which makes them interchangeable and interoperable.
- Netduino is also compatible with Meadow, a newer open source hardware platform that runs full .NET Standard applications on embeddable microcontrollers. Meadow supports C#, F#, and VB.NET programming languages, and can be programmed using Visual Studio or Visual Studio Code on Windows, Mac OS, or Linux.
- Netduino is a powerful and versatile platform for IoT development, as it offers the benefits of both .NET and Arduino ecosystems, such as:
  - High-level and object-oriented programming languages, such as C# and VB.NET, that are easy to learn and use.
  - Integrated development environments, such as Visual Studio and Xamarin Studio, that provide code completion, debugging, testing, and deployment tools.
  - A large and active community of developers, makers, and enthusiasts, that provide support, tutorials, examples, and projects .
  - A wide range of hardware and software components, such as shields, modules, libraries, and drivers, that can be used to create complex and diverse IoT applications .
