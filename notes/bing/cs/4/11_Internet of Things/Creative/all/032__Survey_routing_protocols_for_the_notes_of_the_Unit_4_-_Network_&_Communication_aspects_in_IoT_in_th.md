### Survey routing protocols for the notes of the Unit 4 - Network & Communication aspects in IoT in the subject of Internet of Things

- Routing protocols are the rules and algorithms that determine how data packets are transmitted from one node to another in a network.
- Routing protocols are essential for the Internet of Things (IoT), which is a network of physical objects that can sense, communicate, and interact with each other and other networks.
- Routing protocols for IoT have to deal with various challenges, such as:
  - Low-power and resource-constrained devices
  - Dynamic and heterogeneous network topology
  - Scalability and reliability issues
  - Security and privacy threats
- There are different types of routing protocols for IoT, based on different criteria, such as:
  - Network architecture: flat or hierarchical
  - Routing strategy: proactive, reactive, or hybrid
  - Routing metric: hop count, energy, delay, etc.
  - Routing objective: energy efficiency, load balancing, quality of service, etc.
- Some of the common routing protocols for IoT are:
  - **Ant Colony Optimization (ACO)**: A swarm intelligence-based protocol that mimics the behavior of ants to find the optimal path between nodes. It uses pheromone trails to guide the routing decisions and adapts to the network changes. It is suitable for large-scale and dynamic IoT networks. 
  - **Bee Swarm Optimization (BSO)**: Another swarm intelligence-based protocol that mimics the behavior of bees to find the optimal path between nodes. It uses a fitness function to evaluate the quality of the paths and employs a probabilistic approach to select the best path. It is suitable for energy-efficient and reliable IoT networks. 
  - **Context-Based Routing Protocol (CBRP)**: A protocol that considers the context information of the nodes, such as location, speed, direction, etc., to route the packets. It uses a clustering mechanism to form groups of nodes with similar context and employs a hybrid routing strategy to balance the trade-off between proactive and reactive routing. It is suitable for mobile and dynamic IoT networks. 
  - **Constrained Application Protocol (CoAP)**: A protocol that enables the communication between IoT devices and other networks, such as the Internet. It is based on the RESTful architecture and uses a lightweight and simple message format. It supports various features, such as multicast, caching, discovery, etc. It is suitable for constrained and low-power IoT devices. 
  - **MQTT (Message Queuing Telemetry Transport)**: A protocol that enables the communication between IoT devices and a central broker, which acts as an intermediary. It is based on the publish-subscribe model and uses a reliable and efficient message delivery mechanism. It supports various features, such as quality of service, security, etc. It is suitable for high-latency and unreliable IoT networks.
