The sources of the IoT are the devices, sensors, networks, and platforms that enable the collection, transmission, processing, and analysis of data from the physical world to the digital world. The following diagram illustrates the basic architecture of a typical IoT system using ASCII art:

```
+-----------------+      +-----------------+      +-----------------+
|                 |      |                 |      |                 |
|     Devices     |----->|     Networks    |----->|     Platforms   |
|                 |      |                 |      |                 |
+-----------------+      +-----------------+      +-----------------+
|                 |      |                 |      |                 |
| Sensors, tags,  |      | Wi-Fi, cellular,|      | Cloud, edge,    |
| cameras, etc.   |      | satellite, etc. |      | hybrid, etc.    |
|                 |      |                 |      |                 |
+-----------------+      +-----------------+      +-----------------+
```

The devices are the sources of data generation and capture. They can be embedded in various objects, such as machines, vehicles, appliances, or even living beings. The devices can have different capabilities, such as sensing, computing, actuating, or communicating.

The networks are the sources of data transmission and connectivity. They can use different technologies, such as Wi-Fi, cellular, satellite, or radio frequency identification (RFID). The networks can have different characteristics, such as bandwidth, latency, reliability, or security.

The platforms are the sources of data processing and analysis. They can use different architectures, such as cloud, edge, or hybrid. The platforms can have different functions, such as storage, computation, analytics, or visualization.
