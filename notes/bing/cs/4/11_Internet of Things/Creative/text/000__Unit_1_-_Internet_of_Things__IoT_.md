## Unit 1 - Internet of Things (IoT)

- The Internet of Things (IoT) is a network of physical objects that are embedded with sensors, actuators, and communication devices that can interact with each other and with other devices or systems over the internet.
- The IoT enables various applications and services that can improve the quality of life, efficiency, productivity, and sustainability in different domains such as smart homes, smart cities, smart health, smart agriculture, smart industry, etc.
- The IoT also poses various challenges and issues such as security, privacy, interoperability, scalability, reliability, etc. that need to be addressed by the researchers and practitioners.
- The IoT can be classified into different types based on the characteristics of the devices, the communication technologies, the architectures, the protocols, the applications, etc. Some of the common types are:

  - Device-to-Device (D2D) IoT: This type of IoT involves direct communication between devices without the need of a central server or cloud. For example, Bluetooth, NFC, RFID, etc.
  - Device-to-Cloud (D2C) IoT: This type of IoT involves communication between devices and a cloud server or platform that provides data storage, processing, and analytics. For example, AWS IoT, Google Cloud IoT, etc.
  - Device-to-Gateway (D2G) IoT: This type of IoT involves communication between devices and a gateway device that acts as an intermediary between the devices and the cloud or other networks. For example, Zigbee, Z-Wave, etc.
  - Back-end Data-Sharing (BDS) IoT: This type of IoT involves communication between different cloud platforms or servers that share data and services among each other. For example, MQTT, CoAP, etc.

- The IoT can be described by using the following components or layers:

  - Device Layer: This layer consists of the physical objects or devices that are equipped with sensors, actuators, and communication modules. The devices can sense, actuate, and communicate with each other or with other systems.
  - Network Layer: This layer consists of the communication technologies and protocols that enable data transmission and exchange between the devices and other systems. The network layer can use wired or wireless technologies such as Wi-Fi, Bluetooth, cellular, etc.
  - Middleware Layer: This layer consists of the software platforms and tools that provide data management, processing, and analytics functions for the IoT. The middleware layer can use cloud computing, fog computing, edge computing, etc. to provide scalable and efficient services.
  - Application Layer: This layer consists of the end-user applications and services that utilize the data and functions provided by the IoT. The application layer can cover various domains such as smart homes, smart cities, smart health, smart agriculture, smart industry, etc.
