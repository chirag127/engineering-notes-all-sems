### Communicating data with H/W units

- In IoT applications, data communication is the process of transferring data between hardware (H/W) units, such as sensors, actuators, gateways, and servers.
- Data communication can be classified into two types: wired and wireless.
- Wired communication uses physical cables or wires to connect H/W units and transmit data. Examples of wired communication protocols are Ethernet, USB, Serial, and SPI.
- Wireless communication uses electromagnetic waves or signals to connect H/W units and transmit data. Examples of wireless communication protocols are Wi-Fi, Bluetooth, Zigbee, and LoRaWAN.
- Data communication can also be categorized into two modes: simplex and duplex.
- Simplex communication is a one-way data transfer from a sender to a receiver. For example, a sensor sending data to a gateway is a simplex communication.
- Duplex communication is a two-way data transfer between a sender and a receiver. For example, a gateway sending data to a server and receiving a response is a duplex communication.
- Data communication can involve different levels of abstraction, such as physical, data link, network, transport, and application.
- Physical level deals with the transmission and reception of raw bits over a medium. For example, the voltage levels or radio frequencies used to encode bits.
- Data link level deals with the framing and error detection of data packets over a medium. For example, the MAC addresses or CRC codes used to identify and verify packets.
- Network level deals with the routing and addressing of data packets over a network. For example, the IP addresses or protocols used to locate and deliver packets.
- Transport level deals with the reliability and flow control of data packets over a network. For example, the TCP or UDP ports or protocols used to establish and maintain connections and ensure data integrity.
- Application level deals with the representation and interpretation of data packets over a network. For example, the HTTP or MQTT methods or protocols used to exchange and process data.
