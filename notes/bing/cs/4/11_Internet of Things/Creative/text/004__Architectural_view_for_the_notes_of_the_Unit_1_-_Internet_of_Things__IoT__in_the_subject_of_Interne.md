### Architectural view for the notes of the Unit 1 - Internet of Things (IoT) in the subject of Internet of Things

- The Internet of Things (IoT) is a network of physical devices (so-called “things”) that collect and exchange data with other devices and systems over the internet.
- The architecture of an IoT system is a key consideration when designing and implementing IoT solutions. IoT architecture can be broken down into four layers :
  - Device layer: This is the layer closest to the physical world and consists of the sensors, actuators, and other devices that collect data and perform actions. Examples of devices are smart meters, wearable devices, cameras, etc.
  - Gateway and data acquisition layer: This is the layer that connects the device layer to the network layer and provides data processing, filtering, and aggregation functions. Examples of gateways are routers, modems, hubs, etc.
  - Network layer: This is the layer that provides communication and data transfer between the gateway and data acquisition layer and the cloud and application layer. Examples of network technologies are Wi-Fi, Bluetooth, cellular, satellite, etc.
  - Cloud and application layer: This is the layer that provides data storage, analysis, and visualization functions, as well as the business logic and user interface of the IoT system. Examples of cloud and application platforms are AWS, Azure, Google Cloud, etc.
- IoT architecture can also be divided into four stages based on the data flow  :
  - Data generation: This is the stage where the devices collect data from the physical environment and send it to the gateways.
  - Data transmission: This is the stage where the gateways transmit the data to the cloud or edge devices using the network technologies.
  - Data processing: This is the stage where the cloud or edge devices process, analyze, and filter the data using various algorithms and techniques.
  - Data consumption: This is the stage where the processed data is presented to the end-users or other systems using dashboards, reports, alerts, etc.
- IoT architecture can vary depending on the specific use case, requirements, and constraints of the IoT system. However, the basic principles and components of IoT architecture remain the same across different domains and applications.
