### Sensor deployment & Node discovery for the notes of the Unit 4 - Network & Communication aspects in IoT in the subject of Internet of Things

- Sensor deployment is the process of placing and configuring sensor nodes in an IoT network to collect and transmit data from the physical world.
- Sensor nodes are the devices that have sensing, processing, communication, and power capabilities, and can be deployed in various environments, such as smart homes, smart cities, smart agriculture, smart healthcare, etc.
- Sensor deployment can be done in different ways, depending on the application requirements, such as coverage, connectivity, reliability, scalability, energy efficiency, etc.
- Some of the common sensor deployment methods are:
  - Random deployment: Sensor nodes are scattered randomly in the target area, without any prior knowledge or planning. This method is suitable for large-scale and dynamic environments, where precise node placement is not feasible or necessary.
  - Deterministic deployment: Sensor nodes are placed at predefined locations, based on some optimization criteria, such as minimizing the number of nodes, maximizing the coverage, or minimizing the energy consumption. This method is suitable for small-scale and static environments, where precise node placement is possible and desirable.
  - Hybrid deployment: Sensor nodes are deployed in a combination of random and deterministic methods, to balance the trade-offs between the two methods. For example, some nodes can be placed at fixed locations to ensure connectivity and reliability, while others can be scattered randomly to increase coverage and flexibility.
- Node discovery is the process of identifying and locating sensor nodes in an IoT network, and establishing communication links among them.
- Node discovery is essential for the proper functioning of an IoT network, as it enables data collection, routing, synchronization, security, etc.
- Node discovery can be done in different ways, depending on the network characteristics, such as topology, size, mobility, heterogeneity, etc.
- Some of the common node discovery methods are:
  - Broadcast-based discovery: Sensor nodes broadcast their presence and information to their neighbors, and listen to the broadcasts from other nodes. This method is simple and robust, but can cause high overhead and collisions in large and dense networks.
  - Query-based discovery: Sensor nodes send queries to their neighbors, and receive responses from them. This method is efficient and selective, but can cause high latency and failures in dynamic and sparse networks.
  - Hybrid discovery: Sensor nodes use a combination of broadcast and query methods, to balance the trade-offs between the two methods. For example, some nodes can use broadcast to announce their presence, while others can use query to request information.
