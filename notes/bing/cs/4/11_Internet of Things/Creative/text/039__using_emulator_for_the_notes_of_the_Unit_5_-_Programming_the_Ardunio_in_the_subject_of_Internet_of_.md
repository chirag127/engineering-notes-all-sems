### Using emulator for the notes of the Unit 5 - Programming the Ardunio in the subject of Internet of Things

- An emulator is a software tool that simulates the behavior of a hardware device, such as an Arduino board, on a computer.
- An emulator can be useful for testing and debugging Arduino programs without having to connect a physical board and sensors.
- An emulator can also help to learn the basics of Arduino programming and electronics without investing in hardware components.
- There are different types of emulators available for Arduino, such as online emulators, desktop emulators, and mobile emulators.
- Some examples of online emulators are:
  - Tinkercad Circuits: A web-based platform that allows users to create and simulate Arduino circuits and code. It has a library of components, such as LEDs, buttons, potentiometers, sensors, etc. Users can also share their projects with others and view tutorials. https://www.tinkercad.com/circuits
  - Wokwi Arduino Simulator: A web-based simulator that supports various Arduino boards and shields, such as Uno, Nano, Mega, Ethernet, etc. It also has a library of components, such as LCDs, servos, NeoPixels, etc. Users can edit and run their code in the browser and see the simulation results. https://wokwi.com/arduino
  - Arduino Web Editor: A web-based editor that allows users to write and upload Arduino code to their boards. It also has a simulator feature that lets users test their code on a virtual board and see the output on a serial monitor. https://create.arduino.cc/editor
- Some examples of desktop emulators are:
  - Proteus: A software suite that enables users to design and simulate electronic circuits, including Arduino boards and components. It also has a code editor and compiler that supports various programming languages, such as C, C++, Basic, etc. Users can also debug their code and view the simulation results. https://www.labcenter.com/
  - Simuino: A software application that simulates the Arduino Uno and Mega boards. It also has a code editor and compiler that supports the Arduino language. Users can also view the simulation results on a serial monitor and a graphical display. http://simuino.com/
  - Virtual Breadboard: A software platform that mimics a physical breadboard and allows users to create and simulate Arduino circuits and code. It also has a code editor and compiler that supports the Arduino language. Users can also view the simulation results on a serial monitor and a graphical display. http://www.virtualbreadboard.com/
- Some examples of mobile emulators are:
  - ArduinoDroid: An Android app that allows users to write and upload Arduino code to their boards using their smartphones or tablets. It also has a code editor and compiler that supports the Arduino language. Users can also view the output on a serial monitor. https://play.google.com/store/apps/details?id=name.antonsmirnov.android.arduinodroid2&hl=en&gl=US
  - Arduino Simulator: An iOS app that simulates the Arduino Uno board and some components, such as LEDs, buttons, potentiometers, etc. Users can write and run their code on their devices and see the simulation results. https://apps.apple.com/us/app/arduino-simulator-full-pack/id449133483
  - ArduinoCode: An iOS app that allows users to write and upload Arduino code to their boards using their devices. It also has a code editor and compiler that supports the Arduino language. Users can also view the output on a serial monitor. https://apps.apple.com/us/app/arduinocode-arduino-ide/id1176880246
