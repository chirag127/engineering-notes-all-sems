### Netduino

- Netduino is a series of open source hardware boards that run .NET Micro Framework (NETMF) and can be programmed using C# and Visual Studio.
- Netduino boards are compatible with Arduino shields and can communicate with sensors, actuators, and other devices using digital and analog pins, serial ports, I2C, SPI, and PWM.
- Netduino boards have built-in Ethernet, Wi-Fi, or Bluetooth modules for network connectivity and can be used for IoT applications that require cloud services or remote access.
- Netduino boards support the Windows Remote Arduino library, which allows them to be controlled from a Windows 10 device using the Windows.Devices.Arduino namespace.
- Netduino boards also support the Microsoft Azure IoT Hub SDK, which enables them to send and receive messages from Azure IoT Hub, a cloud platform for IoT solutions.
- Some of the Netduino boards available are:

  - Netduino 3: A board with a 168 MHz Cortex-M4 processor, 140 KB of RAM, 1 MB of flash, 22 GPIO pins, 6 analog inputs, 4 UARTs, 2 SPIs, 2 I2Cs, and an Ethernet port.
  - Netduino 3 Wi-Fi: A board with the same features as Netduino 3, plus a Wi-Fi module that supports 802.11b/g/n protocols and WEP, WPA, and WPA2 security.
  - Netduino 3 Ethernet: A board with the same features as Netduino 3, plus a microSD card slot for additional storage and an Ethernet port that supports Power over Ethernet (PoE).
  - Netduino Go: A modular board with a 168 MHz Cortex-M4 processor, 192 KB of RAM, 384 KB of flash, 8 GoBus ports, and a microUSB port. GoBus ports can be connected to various GoBus modules, such as sensors, displays, buttons, LEDs, etc.
  - Netduino Plus 2: A board with a 168 MHz Cortex-M4 processor, 192 KB of RAM, 384 KB of flash, 22 GPIO pins, 6 analog inputs, 4 UARTs, 2 SPIs, 2 I2Cs, a microSD card slot, and an Ethernet port.
