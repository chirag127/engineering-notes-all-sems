## Unit 3 - Embedded Platforms for IoT

- Embedded platforms for IoT are software and hardware systems that enable the development, deployment, and management of IoT applications on embedded devices.
- Embedded devices are typically small, low-power, and specialized computers that perform specific tasks and communicate with other devices or networks.
- Embedded platforms for IoT provide various features and benefits, such as:
  - Simplifying the software development process by offering ready-made libraries, frameworks, and tools .
  - Supporting multiple connectivity protocols and standards, such as Wi-Fi, Bluetooth, Zigbee, LoRa, MQTT, CoAP, etc.
  - Enabling edge computing capabilities, such as data processing, analytics, machine learning, and decision making on the device .
  - Enhancing the security and reliability of IoT applications by providing encryption, authentication, firmware updates, and remote management .
- Some examples of embedded platforms for IoT are:
  - Mbed OS: An open source operating system for ARM-based microcontrollers that supports cloud services, device management, and security features.
  - Amazon FreeRTOS: A real-time operating system for microcontrollers that integrates with AWS IoT services and offers libraries for connectivity, security, and OTA updates.
  - AMD Ryzen Embedded: A family of processors that combine high-performance CPU and GPU cores with integrated security and connectivity features for IoT gateways and edge devices.
  - Azure IoT: A suite of cloud services and tools that enable IoT solutions across devices, edge, and cloud, with support for data ingestion, analytics, AI, and digital twins.
