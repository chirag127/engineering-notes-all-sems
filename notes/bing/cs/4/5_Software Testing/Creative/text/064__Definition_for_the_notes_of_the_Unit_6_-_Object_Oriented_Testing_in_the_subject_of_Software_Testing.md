### Definition

Object Oriented Testing (OOT) is a testing technique that focuses on the testing of software systems that are developed using object oriented programming languages and paradigms. OOT aims to verify the functionality, quality, and reliability of the software objects and their interactions.

Some of the characteristics of OOT are:

- OOT treats each software object as a unit of testing and applies various testing methods to verify its state and behavior.
- OOT considers the inheritance, polymorphism, and encapsulation features of object oriented programming and tests the software objects accordingly.
- OOT also tests the integration of software objects and their communication with other objects and external systems.
- OOT uses various tools and frameworks that support the creation, execution, and reporting of test cases for object oriented software systems.

Some of the benefits of OOT are:

- OOT can improve the test coverage and quality of the software system by testing each software object individually and in combination with other objects.
- OOT can reduce the testing effort and cost by reusing the test cases and test data for the software objects that are inherited or reused in the software system.
- OOT can facilitate the maintenance and evolution of the software system by testing the impact of changes on the software objects and their interactions.
- OOT can enhance the readability and understandability of the test cases and test results by using the terminology and concepts of object oriented programming.
