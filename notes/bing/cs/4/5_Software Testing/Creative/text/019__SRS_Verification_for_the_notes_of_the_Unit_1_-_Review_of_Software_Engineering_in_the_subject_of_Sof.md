### SRS Verification for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing

- SRS stands for Software Requirements Specification, which is a document that captures the complete description of how the system is expected to perform.
- SRS determines the features and functions of the system, as well as the non-functional requirements such as performance, reliability, security, etc .
- SRS serves as the main point of reference for the software development team and the stakeholders, and helps to avoid ambiguity, inconsistency, and incompleteness in the requirements.
- SRS verification is the process of checking whether the SRS document is consistent, complete, correct, and feasible.
- SRS verification can be done by using various methods such as peer reviews, walkthroughs, inspections, etc.
- SRS verification aims to ensure that the SRS document meets the quality standards and satisfies the customer needs.
- SRS verification can help to reduce the cost and time of software development, as well as to improve the quality and reliability of the software product.
