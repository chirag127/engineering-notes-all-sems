### Configuration Audits

- Configuration audits are independent evaluations of the software product's functionality, performance, and consistency with the relevant requirement specifications .
- Configuration audits help ensure that the configuration items (CIs) have been developed and completed in accordance with the documents and requirements that define them .
- Configuration audits are performed for all releases; however, audits of interim, internal releases may be less formal and rigorous, as defined by the project.
- There are two types of configuration audits: the Functional Configuration Audit (FCA) and the Physical Configuration Audit (PCA).
  - The FCA verifies that the software product meets the functional and performance requirements specified in the software requirements specification (SRS).
  - The PCA verifies that the software product conforms to the physical characteristics and design documentation specified in the software design description (SDD).
- Configuration audits are part of the software configuration management (SCM) process, which is a systems engineering process that tracks and monitors changes to a software system's configuration metadata.
- Configuration audits are conducted by a team of independent reviewers, who may include internal or external stakeholders, such as customers, users, developers, testers, quality assurance personnel, or auditors .
- Configuration audits are usually performed at the end of each software development phase or iteration, or before a software product is delivered or deployed.
- Configuration audits may involve reviewing the software product, the configuration management plan, the configuration management records, the configuration status accounting reports, the configuration baselines, the change requests, and the change control board decisions.
- Configuration audits may use various methods and tools, such as checklists, interviews, inspections, walkthroughs, demonstrations, tests, or automated tools.
- Configuration audits may result in findings, recommendations, corrective actions, or approvals, depending on the outcome of the evaluation.
