### Regression Test cases selection

- Regression testing is the process of retesting the modified parts of a software system and the parts that might be affected by the modifications to ensure that no new defects have been introduced.
- Regression test cases are the test cases that are selected for regression testing based on some criteria or techniques.
- Regression test cases selection is an important activity in regression testing as it can affect the effectiveness and efficiency of the testing process.
- Some of the criteria or techniques for regression test cases selection are:

  - Retest all: This technique involves retesting all the test cases in the test suite regardless of the changes made to the software. This technique is simple and thorough, but it can be very costly and time-consuming, especially for large and complex software systems.
  - Retest modified: This technique involves retesting only the test cases that are directly affected by the changes made to the software. This technique is more selective and efficient than retest all, but it can miss some defects that are caused by the interactions between the modified and unmodified parts of the software.
  - Retest risky: This technique involves retesting the test cases that are associated with the parts of the software that have a high risk of failure or a high impact of failure. This technique is based on the risk analysis and prioritization of the software components and features. This technique can improve the effectiveness of regression testing by focusing on the most critical parts of the software, but it can also overlook some less risky but still important parts of the software.
  - Retest optimal: This technique involves retesting the test cases that are selected by using some optimization methods or algorithms, such as genetic algorithms, simulated annealing, or greedy algorithms. This technique aims to find the optimal subset of test cases that can cover the most code or functionality of the software with the least cost or effort. This technique can achieve a high level of efficiency and effectiveness of regression testing, but it can also be complex and difficult to implement and maintain.
