## Unit 7 - Testing Web Applications

- Web applications are software systems that run on web browsers and servers, and provide various functionalities and services to users over the internet.
- Testing web applications is the process of verifying and validating that the web applications meet the specified requirements and expectations of the stakeholders, such as functionality, usability, security, performance, compatibility, etc.
- Testing web applications involves different types of testing techniques and tools, such as:
  - Unit testing: testing individual components or modules of the web application in isolation, using frameworks like JUnit, TestNG, etc.
  - Integration testing: testing the interactions and interfaces between different components or modules of the web application, using tools like Selenium, Postman, etc.
  - System testing: testing the web application as a whole, as a complete system, using tools like JMeter, LoadRunner, etc.
  - User acceptance testing: testing the web application from the perspective of the end users, using tools like Cucumber, Robot Framework, etc.
- Testing web applications also involves different types of testing levels and approaches, such as:
  - Static testing: testing the web application without executing it, by reviewing and analyzing the code, design, documentation, etc., using tools like SonarQube, PMD, etc.
  - Dynamic testing: testing the web application by executing it, by providing inputs and observing outputs, using tools like WebDriver, SoapUI, etc.
  - White-box testing: testing the web application by having access to and knowledge of the internal structure and logic of the code, using tools like Eclipse, Visual Studio, etc.
  - Black-box testing: testing the web application by having no access to or knowledge of the internal structure and logic of the code, using tools like BrowserStack, Sauce Labs, etc.
  - Gray-box testing: testing the web application by having partial access to or knowledge of the internal structure and logic of the code, using tools like Burp Suite, Fiddler, etc.
- Testing web applications also involves different types of testing strategies and methods, such as:
  - Manual testing: testing the web application by manually performing the test cases and verifying the results, using tools like TestRail, TestLink, etc.
  - Automated testing: testing the web application by using scripts or programs that execute the test cases and verify the results, using tools like TestNG, NUnit, etc.
  - Exploratory testing: testing the web application by exploring and discovering its features and functionalities, using tools like Chrome DevTools, Firebug, etc.
  - Regression testing: testing the web application after making changes or updates, to ensure that the existing features and functionalities are not affected, using tools like Jenkins, Bamboo, etc.
  - Smoke testing: testing the web application by performing a quick and basic check of its main features and functionalities, using tools like Selenium IDE, Katalon Recorder, etc.
  - Sanity testing: testing the web application by performing a detailed and thorough check of its main features and functionalities, using tools like Selenium WebDriver, Protractor, etc.
  - Functional testing: testing the web application by verifying that it performs the functions and operations that it is supposed to, using tools like TestComplete, Ranorex, etc.
  - Non-functional testing: testing the web application by verifying that it meets the non-functional requirements and expectations, such as performance, security, usability, compatibility, etc., using tools like WebLOAD, OWASP ZAP, etc.
