### Failure

- A failure is an event that occurs when the delivered service deviates from the correct service.
- A failure is the result of a fault, which is a defect or error in the software system.
- A failure can be observed by the user or the tester, but the fault may not be visible or known.
- A failure can have different consequences, such as incorrect output, system crash, data loss, security breach, etc.
- A failure can be classified according to different criteria, such as severity, frequency, impact, cause, etc.
- A failure can be detected by testing, monitoring, debugging, or analyzing the system behavior.
- A failure can be prevented by applying software engineering principles, such as requirements engineering, design, coding, testing, etc.
- A failure can be corrected by fixing the fault, verifying the fix, and deploying the updated system.
