## Unit 6 - Object Oriented Testing

- Object oriented testing is a testing technique that focuses on the behavior and structure of objects, classes, and components in an object oriented system.
- Object oriented testing can be divided into two categories: class testing and system testing.
- Class testing is the testing of individual classes or components in isolation, using techniques such as state-based testing, fault-based testing, and scenario-based testing.
- System testing is the testing of the interactions and collaborations among classes or components, using techniques such as integration testing, regression testing, and use case testing.
- Object oriented testing can also be applied at different levels of abstraction, such as unit testing, integration testing, system testing, and acceptance testing.
- Object oriented testing can benefit from the use of tools and frameworks that support the creation, execution, and evaluation of test cases, such as JUnit, TestNG, NUnit, etc.
- Object oriented testing can also leverage the concepts and principles of object oriented design, such as abstraction, encapsulation, inheritance, polymorphism, etc., to improve the quality, reusability, and maintainability of test cases.
