### Testing techniques and their applicability

- Testing techniques are methods or procedures used to test a software system or component for its quality, functionality, reliability, security, usability, etc.
- Testing techniques can be classified into two main categories: static and dynamic.
- Static testing techniques are those that do not require the execution of the software system or component. They include reviews, inspections, walkthroughs, audits, static analysis, etc.
- Dynamic testing techniques are those that involve the execution of the software system or component. They include functional testing, non-functional testing, structural testing, etc.
- The applicability of testing techniques depends on various factors, such as the type of software system or component, the development stage, the testing objectives, the available resources, the risks involved, the standards and regulations, etc.
- Some general guidelines for choosing testing techniques are:
  - Use a combination of static and dynamic testing techniques to achieve maximum coverage and effectiveness.
  - Use testing techniques that are appropriate for the level of testing (unit, integration, system, acceptance, etc.).
  - Use testing techniques that are suitable for the test basis (requirements, design, code, etc.).
  - Use testing techniques that are aligned with the test criteria (test conditions, test cases, test data, etc.).
  - Use testing techniques that are consistent with the test strategy and test plan.
  - Use testing techniques that are feasible and cost-effective.
  - Use testing techniques that are supported by the test tools and test environment.
