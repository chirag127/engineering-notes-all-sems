## Unit 1 - Review of Software Engineering

- Software engineering is the application of engineering principles and practices to the development, operation, and maintenance of software systems.
- Software engineering covers the entire software life cycle, from requirements analysis, design, implementation, testing, deployment, to evolution and maintenance.
- Software engineering aims to deliver software products that meet the needs and expectations of the stakeholders, within the constraints of budget, schedule, and quality.
- Software engineering involves various activities, such as:

  - Software process: the set of activities and tasks that define how software is developed, delivered, and maintained.
  - Software project management: the planning, organizing, monitoring, and controlling of software projects, including risk management, quality assurance, and configuration management.
  - Software requirements engineering: the elicitation, analysis, specification, validation, and management of software requirements, which define what the software should do and how it should behave.
  - Software design: the creation of the software architecture and components, which describe how the software is structured, organized, and implemented.
  - Software implementation: the coding, testing, debugging, and integration of software components, which realize the software design and functionality.
  - Software testing: the verification and validation of software products, which check whether the software meets the requirements and quality standards, and identify and correct defects.
  - Software deployment: the delivery and installation of software products to the end users or customers, and the provision of technical support and documentation.
  - Software evolution and maintenance: the modification and improvement of software products to cope with changing requirements, environments, and technologies, and to fix errors and enhance performance.

- Software engineering also involves various disciplines, such as:

  - Software engineering ethics: the study and application of moral principles and values to software engineering practice, which address issues such as professionalism, responsibility, accountability, and social impact.
  - Software engineering standards: the norms and guidelines that define the best practices and quality criteria for software engineering processes and products, which are established by professional organizations, such as IEEE, ISO, and ACM.
  - Software engineering models and methods: the abstract representations and systematic approaches that describe and support software engineering activities and tasks, such as software process models, software development methodologies, software design patterns, and software testing techniques.
  - Software engineering tools and environments: the software applications and systems that facilitate and automate software engineering activities and tasks, such as software development tools, software testing tools, software configuration management tools, and software project management tools.
