### Decision Table Based Testing

- Decision table based testing is a technique for testing the functionality of a system based on its inputs, outputs, and logical conditions.
- A decision table is a matrix that represents the possible combinations of inputs and outputs for a given system or function.
- A decision table consists of four quadrants: condition stubs, condition entries, action stubs, and action entries.
- Condition stubs are the names of the inputs or conditions that affect the system or function.
- Condition entries are the values or states of the inputs or conditions for each test case.
- Action stubs are the names of the outputs or actions that the system or function performs.
- Action entries are the values or states of the outputs or actions for each test case.
- A decision table can be represented in different formats, such as horizontal, vertical, or tabular.
- A decision table can be simplified by eliminating impossible, redundant, or inconsistent combinations of inputs and outputs.
- A decision table can be used to derive test cases that cover all the possible scenarios of the system or function.
- A decision table can help to identify gaps, errors, or ambiguities in the system or function specification.
