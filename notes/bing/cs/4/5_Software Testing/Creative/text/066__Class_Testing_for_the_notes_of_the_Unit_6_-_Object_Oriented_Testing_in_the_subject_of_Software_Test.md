### Class Testing

- Class testing is the base of object-oriented software testing.
- It involves verifying that the implementation of a class corresponds exactly with the specification for that class .
- It also involves testing the relations among class methods and testing the inheriting relation between class and subclass.
- Class testing can be done at different levels, such as:
  - Algorithmic level: testing each method of every class in isolation .
  - Class level: testing each class as an individual entity, using stubs and drivers to simulate other classes .
  - Cluster level: testing a group of related classes that interact with each other .
  - System level: testing the whole system as a single unit .
- Class testing can be based on different techniques, such as:
  - Fault based testing: designing test cases based on the user specification or the design document, and trying to find faults in the implementation.
  - State based testing: designing test cases based on the state transitions and state invariants of the class.
  - Scenario based testing: designing test cases based on the use cases and scenarios that describe the expected behavior of the class.
  - Random testing: generating test cases randomly or using some heuristic algorithm.
- Class testing can be done manually or using automated tools that support object-oriented testing.
