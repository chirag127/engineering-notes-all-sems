### Walkthrough for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing

- Software engineering is the branch of computer science that deals with the design, development, testing, and maintenance of software applications .
- Software engineers apply engineering principles and knowledge of programming languages to build software solutions for end users.
- Software engineering involves various activities, such as:
  - Requirements analysis: identifying and specifying the needs and expectations of the stakeholders and users of the software system.
  - Design: creating a blueprint or a model of the software system that defines its structure, behavior, and interfaces.
  - Implementation: writing the source code and documentation of the software system using the chosen programming language and tools.
  - Testing: verifying and validating the software system to ensure that it meets the requirements and specifications and is free of defects and errors.
  - Deployment: delivering and installing the software system to the target environment and making it available for use.
  - Maintenance: providing support and updates to the software system to fix bugs, improve performance, and add new features or functionalities.
- Software engineering follows different models or methodologies to manage the software development process, such as:
  - Waterfall model: a linear and sequential approach that divides the software development process into distinct phases, such as requirements, design, implementation, testing, and deployment. Each phase must be completed before moving to the next one, and changes are difficult to accommodate once the phase is finished.
  - Agile model: an iterative and incremental approach that breaks down the software development process into small and manageable units, called sprints or iterations, that deliver working software in short time frames. Each sprint involves planning, designing, implementing, testing, and reviewing the software, and changes are welcome and easy to implement.
  - Spiral model: a risk-driven and evolutionary approach that combines the linear and iterative aspects of the waterfall and agile models. The software development process is divided into four quadrants: planning, risk analysis, engineering, and evaluation. Each quadrant is repeated until the software system is complete, and each repetition involves more details and complexity.
- Software engineering requires various skills and competencies, such as:
  - Programming skills: the ability to write, debug, and optimize code using one or more programming languages, such as Java, Python, C++, etc.
  - Software design skills: the ability to create and document the architecture and design of the software system using various techniques, such as UML diagrams, flowcharts, pseudocode, etc.
  - Testing skills: the ability to design and execute test cases and scenarios to check the functionality, usability, reliability, and security of the software system using various tools, such as JUnit, Selenium, etc.
  - Communication skills: the ability to communicate effectively and clearly with the stakeholders and users of the software system, as well as with other software engineers and developers, using various modes, such as oral, written, graphical, etc.
  - Problem-solving skills: the ability to analyze and solve complex and challenging problems that arise during the software development process, such as bugs, errors, conflicts, etc.
  - Teamwork skills: the ability to collaborate and coordinate with other software engineers and developers to achieve the common goals and objectives of the software project, as well as to share knowledge and feedback.

- A possible mnemonic to remember the activities of software engineering is **RADITM** (Requirements, Analysis, Design, Implementation, Testing, Maintenance).
- A possible mnemonic to remember the models of software engineering is **WAS** (Waterfall, Agile, Spiral).
- A possible mnemonic to remember the skills of software engineering is **PSTCPT** (Programming, Software design, Testing, Communication, Problem-solving, Teamwork).
