### Testing Process for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing

- Testing is a process of evaluating a software product or system to determine whether it meets the specified requirements and expectations .
- Testing can help to identify and correct defects, improve quality, reduce risks, and increase user satisfaction.
- Testing can be performed at different levels of granularity, such as unit testing, integration testing, and acceptance testing.
- Testing can also be classified based on the objectives and strategies, such as functional testing, non-functional testing, white-box testing, black-box testing, and grey-box testing.
- Testing can be done manually or with the help of automated tools.
- Testing follows a common process that consists of the following steps:
  - Test Strategy and Test Plan: These documents describe the scope, objectives, approach, resources, schedule, and deliverables of the testing activities.
  - Test Design: This step involves creating a test suite that consists of test cases, test scenarios, test data, and test scripts that cover the test objectives and requirements.
  - Test Execution: This step involves running the test cases and test scripts on the software product or system under test and recording the test results.
  - Test Analysis and Reporting: This step involves analyzing the test results, identifying defects, reporting issues, and tracking their resolution.
  - Test Closure: This step involves evaluating the test process, documenting the test outcomes, and providing feedback and recommendations for improvement.
- A mnemonic to remember the testing process steps is **STEDAR** (Strategy, Test, Execute, Analyze, Report).
- A learning trick to understand the testing process is to compare it to a cooking process, where the test strategy and test plan are like the recipe, the test design is like the ingredients and utensils, the test execution is like the cooking, the test analysis and reporting is like the tasting and serving, and the test closure is like the cleaning and feedback.
