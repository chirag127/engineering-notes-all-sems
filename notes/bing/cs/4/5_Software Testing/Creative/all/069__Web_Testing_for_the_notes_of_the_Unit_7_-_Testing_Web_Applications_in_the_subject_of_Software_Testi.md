### Web Testing for the notes of the Unit 7 - Testing Web Applications in the subject of Software Testing

- Web testing is a software testing technique to test web applications or websites for finding errors and bugs  .
- A web application must be tested properly before it goes to the end-users. Also, testing a web application does not only mean finding common bugs or errors but also testing the quality-related risks associated with the application.
- Web testing can be done manually or automatically using various tools and frameworks .
- Web testing involves testing various aspects of a web application, such as :
  - Functionality: Testing the specified functionality, features, and operations of the web application, such as links, forms, buttons, navigation, etc.
  - Usability: Testing the user-friendliness, accessibility, and intuitiveness of the web application, such as layout, design, content, help, etc.
  - Compatibility: Testing the web application's performance and behavior across different browsers, devices, operating systems, and resolutions.
  - Performance: Testing the web application's speed, load, stress, scalability, and reliability under different conditions and scenarios.
  - Security: Testing the web application's ability to protect data and prevent unauthorized access, attacks, and breaches.
- Web testing can be done at different levels of the software development life cycle, such as unit testing, integration testing, system testing, and acceptance testing.
- Web testing can be done using various techniques and methods, such as black-box testing, white-box testing, gray-box testing, exploratory testing, etc.
- Web testing can be done using various tools and frameworks, such as Selenium, WebDriver, TestNG, JUnit, Cucumber, etc .
- Web testing can be done using various strategies and approaches, such as agile testing, test-driven development, behavior-driven development, etc.

#### Mnemonics and learning tricks for web testing

- A possible mnemonic to remember the aspects of web testing is **FUCPS** (pronounced as fooks), which stands for **F**unctionality, **U**sability, **C**ompatibility, **P**erformance, and **S**ecurity.
- A possible learning trick to remember the tools and frameworks for web testing is to associate them with their logos or icons, such as:
  - Selenium: A green and white circle with a letter S and a chemical symbol for selenium (Se).
  - WebDriver: A blue and white circle with a letter W and a car steering wheel.
  - TestNG: A red and white circle with a letter T and a star.
  - JUnit: A green and white square with a letter J and a plus sign.
  - Cucumber: A green and white oval with a letter C and a cucumber slice.
