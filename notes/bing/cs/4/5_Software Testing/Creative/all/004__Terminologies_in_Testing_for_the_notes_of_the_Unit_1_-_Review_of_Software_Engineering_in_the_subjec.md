### Terminologies in Testing for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing

- Software testing is the process of verifying and validating that a software product meets the requirements and expectations of the stakeholders. Software testing involves various activities, techniques, tools, and artifacts that help to ensure the quality and reliability of the software.
- Some of the common terminologies used in software testing are:

  - **SDLC (Software Development Life Cycle)**: It is an international standard for software life-cycle processes that defines all the tasks required for developing and maintaining software. SDLC consists of different phases, such as planning, analysis, design, implementation, testing, deployment, and maintenance.
  - **Test Level**: It is a specific instantiation of a test process that corresponds to a particular stage of the SDLC. There are four main test levels: unit testing, integration testing, system testing, and acceptance testing.
  - **Test Type**: It is a group of test activities that aim to evaluate a specific quality attribute of the software, such as functionality, performance, usability, security, etc. There are many test types, such as functional testing, non-functional testing, regression testing, load testing, etc.
  - **Test Design Technique**: It is a method or procedure for deriving and selecting test cases based on the test objectives, test criteria, and test data. There are three main categories of test design techniques: specification-based, structure-based, and experience-based.
  - **STLC (Software Testing Life Cycle)**: It is a subset of the SDLC that focuses on the testing activities and deliverables. STLC consists of different phases, such as test planning, test analysis, test design, test implementation, test execution, test evaluation, and test closure.
  - **Informal Testing**: It is a type of testing that does not follow any formal process, documentation, or standards. Informal testing is usually done by the developers or testers during the development or testing phases to check the basic functionality or usability of the software.
  - **Test Planning**: It is the first phase of the STLC that involves defining the scope, objectives, strategy, resources, schedule, risks, and deliverables of the testing process. Test planning also includes preparing the test plan document that describes the test approach and activities in detail.
  - **Test Documentation**: It is the set of artifacts that are produced and used during the testing process, such as test plan, test cases, test data, test scripts, test results, test reports, etc. Test documentation helps to communicate, monitor, control, and evaluate the testing process.
  - **Test Case**: It is a set of input values, preconditions, expected results, and postconditions that are used to verify a specific test objective or requirement. A test case defines what to test, how to test, and what to expect from the testing.
  - **Test Data**: It is the data that is used as input for the test cases. Test data can be either real or simulated, and it should be valid, invalid, and boundary values to cover different scenarios and conditions of the testing.
  - **Test Script**: It is a set of instructions or commands that are executed by a test tool or a test driver to automate the test execution. A test script can be either written in a programming language or a scripting language, or generated by a test tool.
  - **Test Execution**: It is the phase of the STLC that involves running the test cases or test scripts on the software under test and comparing the actual results with the expected results. Test execution can be either manual or automated, and it can be done in different environments and configurations.
  - **Test Result**: It is the outcome of the test execution that shows whether the test case or test script passed or failed. A test result can also include additional information, such as error messages, screenshots, logs, etc.
  - **Test Report**: It is the document that summarizes and communicates the test results and the status of the testing process. A test report can include various metrics, such as test coverage, defect density, defect severity, test efficiency, etc.
  - **Test Evaluation**: It is the phase of the STLC that involves analyzing and assessing the test results and the test process to determine the quality and the readiness of the software for release.
