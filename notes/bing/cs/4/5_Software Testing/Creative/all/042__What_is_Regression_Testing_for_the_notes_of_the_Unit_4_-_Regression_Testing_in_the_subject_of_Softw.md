### What is Regression Testing for the notes of the Unit 4 - Regression Testing in the subject of Software Testing

- Regression testing is a type of software testing that re-runs functional and non-functional tests to ensure that previously developed and tested software still performs as expected after a change  .
- A change can be any modification in the software, such as a code change, an update, a revision, an improvement, or an optimization .
- Regression testing is responsible for the overall stability and functionality of the existing features. It helps to detect any defects or errors that may have been introduced by the change.
- Regression testing is an integral part of the extreme programming software development method, where design documents are replaced by extensive, repeatable, and automated testing of the entire software package throughout each stage of the software development process .
- Regression testing can be performed at different levels, such as unit, integration, system, or acceptance. It can also be classified into different types, such as retest-all, selective, progressive, or complete.
- Regression testing can be done manually or with the help of automated tools . Automated regression testing is preferred as it saves time, effort, and resources, and ensures consistency and accuracy .
- Some of the tools that can be used for regression testing are Katalon Studio, Selenium, TestComplete, UFT, and Ranorex .
- A mnemonic to remember the definition of regression testing is: **Re**-run **G**ood **R**elevant **E**xisting **S**oftware **S**cenario **I**n **O**rder to **N**otice **T**roubles.
- An example of regression testing is: Suppose a software application has a feature that allows users to login with their credentials. A new feature is added that allows users to login with their social media accounts. Regression testing is done to ensure that the existing login feature still works as expected after the new feature is added.
