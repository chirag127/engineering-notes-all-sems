A software project audit is a review of a software program to check its quality, progress or adherence to plans, standards and regulations. It can be conducted by internal or external auditors, and it can cover various aspects of the software development lifecycle, such as the mission, the timeline, the technologies, the documentation, the organizational structure, the code quality and the teamwork effectiveness .
