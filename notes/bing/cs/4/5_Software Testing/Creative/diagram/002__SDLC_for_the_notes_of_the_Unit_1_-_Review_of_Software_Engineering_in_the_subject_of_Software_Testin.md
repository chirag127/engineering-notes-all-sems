The following text and diagram illustrate the basic stages of a software development life cycle (SDLC) for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing.

The SDLC is a methodology that defines the processes and tasks involved in creating high-quality software. It consists of the following phases:

- **Requirement analysis**: This phase involves gathering and analyzing the needs and expectations of the users and stakeholders of the software. The output of this phase is a document that specifies the functional and non-functional requirements of the software, such as features, performance, security, usability, etc.
- **Planning**: This phase involves defining the scope, objectives, budget, schedule, and resources of the software project. The output of this phase is a project plan that outlines the tasks, milestones, deliverables, and dependencies of the software development process.
- **Software design**: This phase involves designing the architecture, components, interfaces, and data models of the software. The output of this phase is a software design document that describes the structure, behavior, and interactions of the software system.
- **Software development**: This phase involves coding, testing, debugging, and integrating the software components according to the software design document. The output of this phase is a software product that meets the requirements and specifications of the software project.
- **Software testing**: This phase involves verifying and validating the quality, functionality, reliability, and usability of the software product. The output of this phase is a test report that documents the results of the testing activities and identifies any defects or issues in the software product.
- **Software deployment**: This phase involves installing, configuring, and launching the software product in the target environment. The output of this phase is a software release that is ready for use by the end-users and stakeholders of the software project.
- **Software maintenance**: This phase involves providing ongoing support, updates, enhancements, and bug fixes for the software product. The output of this phase is a software product that is maintained and improved according to the changing needs and expectations of the users and stakeholders of the software project.
