A software test plan is a document that outlines the objectives, scope, approach, and focus of a software testing effort. It also includes the schedule, resources, risks, and deliverables of the testing activities. A software test plan is usually based on a software test strategy, which defines the high-level goals and principles of the testing process.

A possible ASCII diagram for a software test plan is:

```
+---------------------+      +---------------------+
|                     |      |                     |
|  Test Plan Overview |      |  Test Plan Details  |
|                     |      |                     |
+---------------------+      +---------------------+
|                     |      |                     |
|  - Introduction     |      |  - Test Scope       |
|  - Test Strategy    |      |  - Test Approach    |
|  - Test Objective   |      |  - Test Environment |
|  - Test Criteria    |      |  - Test Resources   |
|  - Resource Plan    |      |  - Test Schedule    |
|  - Test Environment |      |  - Test Risks       |
|  - Schedule &       |      |  - Test Deliverables|
|    Estimation       |      |                     |
|  - Test Deliverables|      +---------------------+
|                     |
+---------------------+
```

The test plan overview provides a summary of the testing process and the main objectives and principles of the test strategy. The test plan details provide more specific information about the testing activities, such as the scope, approach, environment, resources, schedule, risks, and deliverables of the testing. The test plan details may also include test cases, test procedures, test data, test scripts, test tools, and test reports. The test plan details may vary depending on the type, level, and complexity of the testing.
