A probabilistic lexicalized CFG (L-PCFG) is a type of probabilistic context-free grammar (PCFG) that incorporates lexical information into the non-terminal symbols. This means that each non-terminal symbol is associated with a head word that determines its syntactic and semantic properties. A L-PCFG assigns a probability to each production rule based on the left-hand side non-terminal and its head word. A L-PCFG can be used to model natural language syntax and to perform statistical parsing.

The following diagram illustrates the basic architecture of a L-PCFG:

```
  S(likes)              0.5
   /   \               /   \
  /     \             /     \
NP(John) VP(likes)  0.8     0.6
  |       /   \      |      /   \
  |      /     \     |     /     \
John   V(likes) NP(Mary) likes   Mary
  |      |       |      |       |
 1.0    1.0     0.7    1.0     1.0
```

The diagram shows a parse tree for the sentence "John likes Mary" generated by a L-PCFG. Each node is labeled with a non-terminal symbol and its head word in parentheses. Each edge is labeled with the probability of the corresponding production rule. For example, the edge from S(likes) to NP(John) has a probability of 0.8, which means that P(NP(John) | S(likes)) = 0.8. The probability of the whole parse tree is the product of the probabilities of all the edges, which is 0.5 * 0.8 * 0.6 * 1.0 * 1.0 * 0.7 * 1.0 * 1.0 = 0.168.
