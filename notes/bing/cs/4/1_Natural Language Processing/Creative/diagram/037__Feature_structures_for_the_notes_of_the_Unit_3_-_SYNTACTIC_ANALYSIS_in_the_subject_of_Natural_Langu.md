A feature structure is a representation of a structure made up of feature-value pairs, where a feature is a formal property of a syntactic object and a value is the expression of that property. Feature structures are used to capture the syntactic and semantic information of sentences or parts of sentences in a natural language. A feature structure analysis is a way of assigning feature structures to syntactic objects and showing how they interact with syntactic constraints and operations.

One way to draw a feature structure diagram in markdown is to use a table format, where each row represents a feature-value pair and each column represents a different syntactic object. For example, the following table shows the feature structure analysis of the noun phrase "the lion" in the sentence "The lion is a ferocious animal."

| Feature | Value | Value |
| --- | --- | --- |
| Category | Noun Phrase | Determiner |
| Number | Singular | Singular |
| Gender | Masculine | - |
| Case | Nominative | - |
| Head | lion | - |
| Specifier | - | the |

The table can be interpreted as follows: The noun phrase has the category feature with the value noun phrase, the number feature with the value singular, the gender feature with the value masculine, the case feature with the value nominative, and the head feature with the value lion. The determiner has the category feature with the value determiner, the number feature with the value singular, and the specifier feature with the value the. The noun phrase and the determiner agree on the number feature, and the determiner is the specifier of the noun phrase. The head feature indicates the main word of the noun phrase, and the case feature indicates the grammatical role of the noun phrase in the sentence.
