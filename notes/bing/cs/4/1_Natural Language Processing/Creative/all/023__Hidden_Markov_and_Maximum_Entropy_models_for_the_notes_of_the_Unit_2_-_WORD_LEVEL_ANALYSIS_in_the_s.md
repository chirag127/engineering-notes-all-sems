### Hidden Markov and Maximum Entropy models for the notes of the Unit 2 - WORD LEVEL ANALYSIS in the subject of Natural Language Processing

- Hidden Markov Model (HMM) is a probabilistic graphical model that allows us to calculate a sequence of unknown or unobserved variables (hidden states) from a set of observed variables (emissions).
- HMM can be used for various natural language processing tasks, such as part-of-speech tagging, named entity recognition, speech recognition, text segmentation, etc.
- HMM consists of two components: a transition model and an emission model. The transition model defines the probability of moving from one hidden state to another, while the emission model defines the probability of generating an observed variable from a hidden state.
- HMM can be represented by a 5-tuple: (Q, V, A, B, pi), where Q is the set of hidden states, V is the set of observed variables, A is the transition matrix, B is the emission matrix, and pi is the initial state distribution.
- HMM can be trained using the Baum-Welch algorithm, which is a special case of the Expectation-Maximization (EM) algorithm. The Baum-Welch algorithm iteratively updates the parameters of the HMM until convergence, using the forward-backward algorithm to compute the expected counts of the hidden states and the transitions.
- HMM can be decoded using the Viterbi algorithm, which is a dynamic programming algorithm that finds the most probable sequence of hidden states given a sequence of observed variables. The Viterbi algorithm uses a trellis structure to store the best path and the best score for each state at each time step, and then backtracks to find the optimal sequence.
- HMM has some limitations, such as the independence assumption between the observed variables, the limited context information for the hidden states, and the difficulty of incorporating complex features into the model.
- Maximum Entropy Markov Model (MEMM) is an extension of HMM that overcomes some of its limitations. MEMM is also a probabilistic graphical model that allows us to calculate a sequence of unknown or unobserved variables (hidden states) from a set of observed variables (emissions).
- MEMM differs from HMM in two ways: first, it uses a maximum entropy classifier instead of a multinomial distribution to model the emission probabilities, and second, it conditions the transition probabilities on both the current and the previous hidden states, instead of only the previous hidden state.
- MEMM can use arbitrary features of the observed variables to compute the emission probabilities, such as the word itself, the prefix, the suffix, the capitalization, etc. This allows MEMM to capture more information and dependencies between the observed variables and the hidden states.
- MEMM can also use more context information for the hidden states, such as the previous state, the next state, the surrounding words, etc. This allows MEMM to capture more long-range dependencies and complex patterns in the data.
- MEMM can be trained using the Generalized Iterative Scaling (GIS) algorithm, which is a gradient-based algorithm that maximizes the conditional likelihood of the hidden states given the observed variables. The GIS algorithm iteratively updates the parameters of the MEMM until convergence, using the forward-backward algorithm to compute the expected counts of the features and the transitions.
- MEMM can be decoded using the Viterbi algorithm, similar to HMM. However, MEMM suffers from the label bias problem, which means that some states tend to have higher transition probabilities than others, regardless of the observed variables. This can lead to suboptimal sequences and poor performance.
- MEMM has some advantages over HMM, such as the ability to incorporate complex features, the flexibility to model different types of data, and the ease of implementation. However, MEMM also has some disadvantages, such as the label bias problem, the high computational cost, and the difficulty of smoothing.
