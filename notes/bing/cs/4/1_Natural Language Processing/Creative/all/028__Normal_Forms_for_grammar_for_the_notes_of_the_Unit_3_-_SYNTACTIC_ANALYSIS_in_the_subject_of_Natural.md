### Normal Forms for grammar for the notes of the Unit 3 - SYNTACTIC ANALYSIS in the subject of Natural Language Processing

- Normal forms for grammar are ways of transforming a grammar into a simpler or more standardized form that is equivalent to the original grammar in terms of the language it generates or recognizes.
- Normal forms for grammar are useful for natural language processing (NLP) because they can simplify the parsing and analysis of natural language sentences, as well as the generation of natural language output.
- There are different types of normal forms for grammar, depending on the type of grammar and the desired properties of the transformed grammar. Some of the most common normal forms for grammar are:

  - **Chomsky Normal Form (CNF)**: A normal form for context-free grammars (CFGs) that requires every production rule to have either two non-terminal symbols or one terminal symbol on the right-hand side. For example, the rule `S -> NP VP` is in CNF, but the rule `S -> NP VP PP` is not. CNF is useful for NLP because it can reduce the number of possible parses for a given sentence, and it can be used to construct efficient bottom-up parsers such as the CYK algorithm.
  - **Greibach Normal Form (GNF)**: A normal form for context-free grammars that requires every production rule to have a terminal symbol followed by zero or more non-terminal symbols on the right-hand side. For example, the rule `S -> aAB` is in GNF, but the rule `S -> ABa` is not. GNF is useful for NLP because it can be used to construct efficient top-down parsers such as the LL algorithm.
  - **Backus-Naur Form (BNF)**: A normal form for context-free grammars that uses a specific notation to represent the production rules, using `::=` to separate the left-hand side and the right-hand side, and using `|` to separate alternative choices. For example, the rule `S -> NP VP | VP` can be written in BNF as `S ::= NP VP | VP`. BNF is useful for NLP because it is a widely used and readable way of defining the syntax of natural languages and programming languages.
  - **Kuroda Normal Form (KNF)**: A normal form for context-sensitive grammars (CSGs) that requires every production rule to have either one non-terminal symbol or two non-terminal symbols on both sides. For example, the rule `S -> aSb` is in KNF, but the rule `S -> aSbS` is not. KNF is useful for NLP because it can show that CSGs are equivalent to linear bounded automata, which are a subclass of Turing machines that can recognize some natural language phenomena that CFGs cannot, such as cross-serial dependencies and agreement.
  - **Head Normal Form (HNF)**: A normal form for lexicalized grammars that requires every production rule to have a head symbol that determines the syntactic and semantic properties of the phrase. For example, the rule `NP -> Det N` has `N` as the head symbol, and the rule `VP -> V NP` has `V` as the head symbol. HNF is useful for NLP because it can capture the hierarchical and linear structure of natural language phrases, and it can be used to construct probabilistic parsers that can assign probabilities to different parses based on the frequency of the head symbols.
