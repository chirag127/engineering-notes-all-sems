### Multiple access protocols for the notes of the Unit 2 - Wireless Networking, Wireless LAN Overview: MAC issues, IEEE 802.11, Blue Tooth, Wireless in the subject of Mobile Computing

Multiple access protocols are techniques that allow multiple nodes or users to share a common communication channel, such as a wireless network or a satellite network. These protocols are used to coordinate the access to the channel and avoid collisions or interference among the transmissions. Some of the common multiple access protocols that are used in wireless networking are:

- **Carrier-sense multiple access with collision avoidance (CSMA/CA)**: This protocol is used in IEEE 802.11 / WiFi networks, and it relies on a distributed coordination function (DCF) to avoid collisions. The basic idea is that before transmitting a frame, a node senses the channel and waits until it is idle. Then, it transmits a short request-to-send (RTS) frame to the intended receiver, which replies with a clear-to-send (CTS) frame if the channel is also idle for it. The RTS and CTS frames contain the duration of the upcoming data transmission, which is used by other nodes to defer their transmissions until the channel is free. This way, the hidden node problem is solved and collisions are reduced. However, collisions may still occur if two nodes sense the channel at the same time and transmit RTS frames simultaneously. To reduce this probability, a random backoff time is used before each transmission attempt. CSMA/CA also supports an optional point coordination function (PCF), which uses a central controller to poll the nodes and grant them access to the channel in a deterministic manner.

- **ALOHA and slotted ALOHA**: These protocols are used in ALOHAnet, which was the first wireless packet network. The basic idea is that a node transmits a frame whenever it has data to send, without sensing the channel or waiting for an acknowledgment. If a collision occurs, the node retransmits the frame after a random time. The slotted ALOHA protocol improves the performance by dividing the time into equal slots and requiring the nodes to transmit only at the beginning of a slot. This way, the collisions are reduced by half, but the channel utilization is still low.

- **Reservation ALOHA (R-ALOHA)**: This protocol is a variation of ALOHA that uses a reservation scheme to avoid collisions. The basic idea is that a node transmits a short reservation request (RR) frame in a random slot, and waits for an acknowledgment from the receiver. If the RR is successful, the node transmits the data frame in the next slot. If the RR collides, the node retransmits it in another random slot. This way, the data frames are transmitted without collisions, but the channel utilization is still low due to the overhead of the RR frames.

- **Mobile Slotted Aloha (MS-ALOHA)**: This protocol is a variation of slotted ALOHA that adapts to the mobility of the nodes. The basic idea is that a node transmits a frame in a random slot, and waits for an acknowledgment from the receiver. If the acknowledgment is received, the node transmits the next frame in the next slot. If the acknowledgment is not received, the node assumes that it has moved out of the range of the receiver, and retransmits the frame in another random slot. This way, the collisions are reduced and the channel utilization is improved.

- **Code-division multiple access (CDMA)**: This protocol is used in cellular networks and satellite networks, and it relies on spreading codes to allow multiple transmissions to coexist in the same channel. The basic idea is that each node is assigned a unique code, which is a sequence of chips (binary digits) that modulates the data bits. The code has the property that it is orthogonal to the codes of other nodes, meaning that the cross-correlation between them is zero. This way, the receiver can recover the data bits of a node by correlating the received signal with the code of that node, and ignoring the signals of other nodes. CDMA can achieve high channel utilization and resistance to interference, but it requires precise synchronization and power control among the nodes.
