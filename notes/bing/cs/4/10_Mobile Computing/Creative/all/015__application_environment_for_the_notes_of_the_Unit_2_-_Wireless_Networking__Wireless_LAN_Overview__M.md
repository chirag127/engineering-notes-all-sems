### Application environment for the notes of the Unit 2 - Wireless Networking, Wireless LAN Overview: MAC issues, IEEE 802.11, Blue Tooth, Wireless in the subject of Mobile Computing

- Application environment refers to the set of software and protocols that enable wireless devices to access various applications and services over wireless networks.
- One of the most widely used application environments for wireless networking is the Wireless Application Protocol (WAP), which is a specification for a set of communication protocols based on the concept of the World Wide Web (WWW) .
- WAP consists of four main layers: Wireless Application Environment (WAE), Wireless Session Protocol (WSP), Wireless Transaction Protocol (WTP), and Wireless Transport Layer Security (WTLS)   .
- WAE is the uppermost layer in the WAP stack, which provides an environment that enables a wide range of applications to be used on the wireless devices, such as web browsing, email, instant messaging, etc.  .
- WAE consists of several components, such as:
  - Wireless Markup Language (WML), which is a markup language similar to HTML, but optimized for small screens and low bandwidth.
  - Wireless Markup Language Script (WMLScript), which is a scripting language similar to JavaScript, but with less functionality and more compact syntax.
  - Wireless Telephony Application Interface (WTAI), which is a set of functions that allow WML and WMLScript to access telephony features of the wireless device, such as making and receiving calls, sending and receiving SMS, etc.
  - Wireless Telephony Application (WTA), which is a framework for developing voice-based applications that can be accessed through WAP.
  - Wireless Datagram Protocol (WDP), which is a transport layer protocol that provides a common interface for WAP to various wireless network technologies, such as GSM, CDMA, etc.   .
- WSP is the session layer protocol that provides a reliable and efficient way of exchanging data between the wireless device and the server. WSP supports two modes of operation: connection-oriented and connectionless. In the connection-oriented mode, WSP establishes a session between the device and the server, and maintains it until it is explicitly terminated. In the connectionless mode, WSP does not establish a session, but sends each request and response as a separate datagram   .
- WTP is the transaction layer protocol that provides a reliable and efficient way of exchanging requests and responses between the wireless device and the server. WTP supports three classes of transactions: reliable, unreliable, and unreliable with result. In the reliable class, WTP ensures that each request and response is delivered exactly once, and in the correct order. In the unreliable class, WTP does not guarantee the delivery or the order of the messages, but provides a faster and more efficient service. In the unreliable with result class, WTP provides a compromise between the reliable and the unreliable classes, by ensuring that the final result of the transaction is delivered, but not the intermediate messages   .
- WTLS is the security layer protocol that provides data integrity, confidentiality, and authentication for the wireless communication. WTLS is based on the Transport Layer Security (TLS) protocol, but with some modifications to suit the wireless environment, such as smaller message sizes, lower computational requirements, and support for datagram transport   .

- Some of the advantages of WAP are:
  - It provides a standard and interoperable way of accessing various applications and services over wireless networks, regardless of the device type, network technology, or content format.
  - It leverages the existing technologies and infrastructure of the WWW, such as web servers, browsers, markup languages, etc., but adapts them to the wireless environment, such as small screens, low bandwidth, etc.
  - It supports a wide range of applications and services, such as web browsing, email, instant messaging, voice-based applications, etc., that can enhance the user experience and satisfaction.
  - It provides a secure and reliable communication between the wireless device and the server, by using encryption, authentication, and error correction techniques    .
