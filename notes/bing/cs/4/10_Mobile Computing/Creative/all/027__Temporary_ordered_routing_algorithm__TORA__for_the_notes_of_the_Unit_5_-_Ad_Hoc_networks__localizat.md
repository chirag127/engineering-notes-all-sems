### Temporary ordered routing algorithm (TORA) for the notes of the Unit 5 - Ad Hoc networks, localization, MAC issues, Routing protocols, global state routing (GSR), in the subject of Mobile Computing

- TORA (Temporally Ordered Routing Algorithm) is a source initiated on-demand routing protocol for wireless ad hoc networks .
- It was developed by Vincent Park and Scott Corson at the University of Maryland and the Naval Research Laboratory in 1997 .
- TORA is based on link reversal algorithm, which is a distributed algorithm for finding multiple node-disjoint paths between a source and a destination .
- TORA is efficient, highly adaptive, loop-free and scalable routing protocol that can handle network dynamics such as node mobility, link failures and network partitions  .
- TORA consists of three main phases: route creation, route maintenance and route erasure .
- Route creation: When a source node wants to send data to a destination node, it broadcasts a query packet containing the destination ID. The query packet propagates through the network until it reaches the destination or a node that has a route to the destination. The nodes that receive the query packet assign a height to themselves based on the height of the sender and the direction of the link. The height is a metric that determines the logical distance to the destination. The nodes that have a lower height than their neighbors are called downstream nodes, and the nodes that have a higher height than their neighbors are called upstream nodes. The destination node assigns itself a height of zero, and the nodes that do not have a route to the destination assign themselves a height of NULL. The nodes that receive the query packet also record the previous hop as their route to the destination. When the query packet reaches the destination or a node with a route to the destination, it sends back an update packet containing its height to the previous hop. The update packet propagates back to the source along the reverse path of the query packet, updating the height and the route of the intermediate nodes. When the source node receives the update packet, it has a route to the destination.
- Route maintenance: When a link failure occurs, the nodes that are affected by the link failure adjust their height to restore connectivity. The node that detects the link failure increases its height by adding a reference level to its previous height. The reference level is a large number that indicates the occurrence of a link failure. The node then broadcasts an update packet containing its new height to its neighbors. The neighbors that receive the update packet compare their height with the sender's height. If the neighbor's height is lower than the sender's height, it means that the neighbor is still downstream of the sender, and no action is needed. If the neighbor's height is higher than the sender's height, it means that the neighbor is upstream of the sender, and it has to find a new route to the destination. The neighbor then increases its height by adding a reference level to its previous height, and broadcasts an update packet to its neighbors. This process continues until all the nodes that are affected by the link failure have a new height and a new route to the destination. The link reversal algorithm ensures that there is no loop in the routing process, and that multiple node-disjoint paths are created between the source and the destination.
- Route erasure: When a source node no longer needs a route to a destination node, it broadcasts a clear packet containing the destination ID. The clear packet propagates through the network, erasing the route information of the nodes that have a route to the destination. The nodes that receive the clear packet reset their height and their route to NULL.

- Advantages of TORA:
  - TORA can handle network dynamics such as node mobility, link failures and network partitions efficiently and adaptively  .
  - TORA can find multiple node-disjoint paths between a source and a destination, which increases the reliability and the load balancing of the network  .
  - TORA is loop-free and scalable, as it does not rely on global network information or periodic updates  .

- Disadvantages of TORA:
  - TORA may generate a large number of control packets during route creation and route maintenance, which consumes bandwidth and energy  .
