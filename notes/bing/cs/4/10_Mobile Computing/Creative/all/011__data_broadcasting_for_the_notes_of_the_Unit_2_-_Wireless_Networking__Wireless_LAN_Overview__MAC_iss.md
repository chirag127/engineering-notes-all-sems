### Data broadcasting for the notes of the Unit 2 - Wireless Networking, Wireless LAN Overview: MAC issues, IEEE 802.11, Blue Tooth, Wireless in the subject of Mobile Computing

- Data broadcasting is a group communication, where a sender sends data to receivers simultaneously .
- Data broadcasting can be used for efficient information dissemination in wireless networks, such as traffic information, weather updates, news, etc.
- Data broadcasting can be characterized by locality of client demands, meaning that different clients may be interested in different subsets of data.
- Data broadcasting can be performed over wireless broadcast channels, which are shared by multiple senders and receivers.
- Data broadcasting can be improved by using techniques such as network coding, cooperation, smart antennas, etc.
- Data broadcasting can be implemented in different types of wireless networks, such as Wi-Fi, 5G, Bluetooth, etc .
- Data broadcasting can be affected by various MAC (Medium Access Control) issues, such as collision, contention, hidden terminal, exposed terminal, etc.
- Data broadcasting can be standardized by protocols such as IEEE 802.11, which defines the physical and MAC layers for wireless LANs.

#### Mnemonics and learning tricks

- To remember the definition of data broadcasting, you can use the acronym BAG: Broadcasting is All-to-all Group communication.
- To remember the types of wireless networks that can support data broadcasting, you can use the acronym W5B: Wi-Fi, 5G, Bluetooth.
- To remember the MAC issues that can affect data broadcasting, you can use the acronym CCEH: Collision, Contention, Exposed terminal, Hidden terminal.
