### Wireless networks for the notes of the Unit 3 - Data management issues, data replication for mobile computers, adaptive clustering for mobile in the subject of Mobile Computing

- Wireless networks are networks that use radio waves or other wireless technologies to connect devices without cables or wires.
- Wireless networks enable mobile computing, which is the ability to use computing devices and access data and services anywhere and anytime.
- Mobile computing poses several challenges for data management, such as:
  - Limited bandwidth and high latency of wireless links
  - Frequent disconnections and mobility of devices
  - Limited resources and power of mobile devices
  - Security and privacy of data transmission and storage
- Data management issues in wireless networks can be classified into three categories:
  - Data dissemination: how to efficiently deliver data from servers to mobile devices
  - Data synchronization: how to maintain consistency between data stored on mobile devices and servers
  - Data adaptation: how to tailor data to the needs and preferences of mobile devices and users
- Data replication is a technique to improve data availability and performance in wireless networks by creating and maintaining copies of data on multiple devices.
- Data replication can be performed at different levels, such as:
  - Database level: replicating entire databases or tables
  - Query level: replicating query results or views
  - Object level: replicating data objects or files
- Data replication can be performed using different strategies, such as:
  - Static replication: predefining the location and number of replicas
  - Dynamic replication: adjusting the location and number of replicas based on network conditions and user requests
  - Hybrid replication: combining static and dynamic replication
- Data replication can be performed using different methods, such as:
  - Eager replication: propagating updates to all replicas as soon as they occur
  - Lazy replication: propagating updates to replicas periodically or on demand
  - Semi-eager replication: propagating updates to some replicas eagerly and to others lazily
- Data replication can improve data availability, reliability, and performance in wireless networks, but it also introduces challenges, such as:
  - Replica placement: how to select the optimal location and number of replicas
  - Replica consistency: how to ensure that replicas are synchronized and reflect the latest updates
  - Replica maintenance: how to handle replica creation, deletion, and migration
  - Replica access: how to route user requests to the most suitable replica
- Adaptive clustering is a technique to improve network scalability and efficiency in wireless networks by organizing nodes into groups or clusters .
- Adaptive clustering can be performed using different criteria, such as:
  - Node ID: clustering nodes based on their identifiers
  - Node location: clustering nodes based on their geographic coordinates
  - Node mobility: clustering nodes based on their speed and direction
  - Node connectivity: clustering nodes based on their link quality and stability
  - Node resources: clustering nodes based on their battery level and processing power
- Adaptive clustering can be performed using different algorithms, such as:
  - Lowest-ID algorithm: selecting the node with the lowest ID as the cluster head
  - Highest-degree algorithm: selecting the node with the highest degree (number of neighbors) as the cluster head
  - Weighted clustering algorithm: selecting the node with the highest weight (a combination of degree, mobility, battery, and transmission power) as the cluster head
  - Distributed mobility-adaptive clustering algorithm: selecting the node with the lowest mobility as the cluster head and adjusting the cluster membership based on node movement
  - Mobile agent-based clustering algorithm: using mobile agents (software entities that can migrate from node to node) to form and maintain clusters
- Adaptive clustering can improve network scalability, efficiency, and robustness in wireless networks, but it also introduces challenges, such as:
  - Cluster formation: how to select the optimal cluster size and cluster head
  - Cluster maintenance: how to handle cluster head changes and cluster reorganization
  - Cluster communication: how to route messages within and between clusters
  - Cluster coordination: how to synchronize and cooperate among clusters
