### Destination sequenced distance vector routing (DSDV) for the notes of the Unit 5 - Ad Hoc networks, localization, MAC issues, Routing protocols, global state routing (GSR), in the subject of Mobile Computing

- Destination sequenced distance vector routing (DSDV) is a proactive routing protocol for ad hoc networks, which means that each node maintains a routing table with the next hop and the cost to reach every other node in the network.
- The routing table is updated periodically or when a significant change occurs in the network topology. Each entry in the routing table has a sequence number, which is used to avoid loops and stale routes.
- The sequence number is assigned by the destination node and incremented whenever the node changes its route. A higher sequence number indicates a more recent route. If two routes have the same sequence number, the one with the lower cost is preferred.
- DSDV uses two types of packets to exchange routing information: full dump and incremental. A full dump packet contains all the entries in the routing table, while an incremental packet contains only the entries that have changed since the last update. Full dump packets are sent less frequently than incremental packets, to reduce the overhead.
- DSDV can be classified into two variants: DSDV-SQ and DSDV-IM. DSDV-SQ uses only sequence numbers to indicate the freshness of routes, while DSDV-IM uses both sequence numbers and timestamps. DSDV-IM can handle route changes more efficiently, but requires more synchronization among nodes.
- A possible mnemonic to remember the main features of DSDV is: **D**estination **S**equenced **D**istance **V**ector - **P**roactive, **S**equence numbers, **F**ull dump and **I**ncremental packets.
- A possible learning trick to understand the working of DSDV is to imagine a network of nodes as a map of cities, where each city has a signpost with the distance and the direction to reach every other city. The signposts are updated regularly or when a road is blocked or a new road is built. The sequence number on the signpost indicates how recent the information is. A traveler can use the signposts to find the shortest and the most up-to-date route to their destination.
