### Dynamic source routing (DSR) for the notes of the Unit 5 - Ad Hoc networks, localization, MAC issues, Routing protocols, global state routing (GSR), in the subject of Mobile Computing

- Dynamic source routing (DSR) is an on-demand routing protocol for wireless ad hoc networks .
- It does not require periodic table updates or beacon messages, unlike table-driven protocols .
- It uses source routing, which means the sender of a packet determines the complete sequence of nodes through which the packet has to pass .
- The sender explicitly lists this route in the packet's header, identifying each forwarding hop by the address of the next node to which to transmit the packet on its way to the destination host.
- DSR has two main mechanisms: route discovery and route maintenance .
- Route discovery is the process of finding a route from a source to a destination when there is no existing route in the source's cache .
- Route discovery uses two types of control packets: route request (RREQ) and route reply (RREP) .
- When a source node wants to send a packet to a destination node, it first checks its route cache for a valid route .
- If there is no valid route, it broadcasts a RREQ packet to its neighbors, which contains the source and destination addresses, a unique request ID, and a list of intermediate nodes that have processed the RREQ .
- Each intermediate node that receives the RREQ checks its route cache for a route to the destination .
- If it has a route, it unicasts a RREP packet back to the source, which contains the route from the source to the destination .
- If it does not have a route, it appends its address to the list of intermediate nodes and rebroadcasts the RREQ to its neighbors .
- The RREQ propagation creates a reverse path from the destination to the source, which is used to route the RREP back to the source .
- The source node stops broadcasting RREQs when it receives the first RREP, or when a timeout occurs .
- The source node then updates its route cache with the route from the RREP and sends the data packet along that route .
- Route maintenance is the process of detecting and repairing route errors in the network .
- Route maintenance uses route error (RERR) packets to notify the source of a broken link in the route .
- When a node encounters a link failure, it sends a RERR packet to the source, which contains the address of the node that detected the error, the address of the node that is unreachable, and the list of nodes that are affected by the error .
- The source node then removes the invalid route from its cache and initiates a new route discovery if needed .
- DSR has some advantages and disadvantages .
- Advantages:
  - It is simple and efficient, as it does not need any periodic messages or routing tables .
  - It is adaptive to network changes, as it can discover new routes on demand .
  - It can support multiple routes to the same destination, which can improve load balancing and fault tolerance .
  - It can reduce the control overhead by using route caching and route shortening techniques .
- Disadvantages:
  - It may incur high latency during route discovery, especially for large networks or high mobility scenarios .
  - It may consume more bandwidth due to the large size of the packet header, which contains the entire route .
  - It may suffer from stale routes in the cache, which can cause routing loops or incorrect forwarding .
  - It may not scale well for large networks, as the number of control packets may increase exponentially with the network size
