## Unit 1 - Introduction, issues in mobile computing, overview of wireless telephony: cellular concept, GSM:

The cellular concept is a system design approach that allows a large number of mobile users to communicate over a given area. The basic idea is to divide the service area into smaller regions called cells, and assign a set of radio channels to each cell. The cells are arranged in a hexagonal pattern to cover the entire area. The same set of channels can be reused in different cells, as long as they are separated by a minimum distance to avoid interference. This is called frequency reuse.
