Multiple access protocols are methods that allow multiple nodes or users to access a shared network channel without interfering with each other. They are used in both wired and wireless networks, such as LANs and satellite networks. Some of the common multiple access protocols that are used in wireless networking are:

- Carrier-sense multiple access with collision avoidance (CSMA/CA), used in IEEE 802.11 / WiFi, potentially using a distributed coordination function
- ALOHA and slotted ALOHA, used in ALOHAnet
- Reservation ALOHA (R-ALOHA)
- Mobile Slotted Aloha (MS-ALOHA)
- Code-division multiple access (CDMA)
- Orthogonal frequency-division multiple access (OFDMA)
- Orthogonal frequency-division multiplexing (OFDM)
