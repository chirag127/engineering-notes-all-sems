### Temporary ordered routing algorithm (TORA) for the notes of the Unit 5 - Ad Hoc networks, localization, MAC issues, Routing protocols, global state routing (GSR), in the subject of Mobile Computing

- TORA is a source initiated on-demand routing protocol for wireless mobile ad hoc networks .
- TORA is based on the link reversal algorithm, which is a distributed algorithm for finding multiple routes from a source to a destination in a network .
- TORA has three main phases: route creation, route maintenance, and route erasure .
- Route creation: The source node broadcasts a query packet containing the destination address and a unique identifier. The nodes that receive the query packet update their height (a metric used to establish a directed acyclic graph) and propagate the query packet until it reaches the destination or a node that has a route to the destination. The destination or the intermediate node then broadcasts an update packet containing its height, which is propagated back to the source along the reverse path of the query packet. The nodes that receive the update packet update their height and establish a downstream link to the node from which they received the update packet. This way, multiple routes are created from the source to the destination .
- Route maintenance: When a link failure occurs, the nodes adjacent to the failed link update their height and broadcast an update packet to their neighbors. The nodes that receive the update packet update their height and either find a new downstream link or propagate the update packet further. This process continues until the network reaches a consistent state or the source node is notified of the link failure. If the source node is notified, it can either reinitiate the route creation phase or stop sending data packets to the destination .
- Route erasure: When a source node no longer needs a route to a destination, it broadcasts a clear packet containing the destination address and the unique identifier of the query packet that initiated the route creation. The nodes that receive the clear packet erase all the routing information related to that destination and propagate the clear packet further. This way, the routes are erased from the network .
- TORA is efficient, highly adaptive, loop-free, and scalable, as it can handle frequent topology changes and find multiple routes to a destination  .
- TORA can also support quality of service (QoS) components, such as bandwidth, delay, jitter, and packet loss, by using a QoS routing extension (QoSR) that modifies the height metric and the update packet format.
