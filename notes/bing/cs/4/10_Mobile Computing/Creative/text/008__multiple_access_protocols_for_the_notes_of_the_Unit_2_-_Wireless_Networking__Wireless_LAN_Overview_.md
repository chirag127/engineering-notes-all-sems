### Multiple Access Protocols

- Multiple access protocols are used to coordinate the access of multiple nodes or users to a shared network channel, such as a wireless LAN or a satellite network.
- Multiple access protocols can be classified into three categories: random access, controlled access, and channelization.
- Random access protocols allow nodes to transmit data whenever they have data to send, without any coordination with other nodes. However, this may result in collisions, which degrade the network performance and require retransmission mechanisms. Examples of random access protocols are ALOHA, CSMA, CSMA/CA, and CSMA/CD.
- Controlled access protocols require nodes to obtain permission before transmitting data, either from a central controller or from other nodes. This reduces the probability of collisions, but introduces some overhead and delay. Examples of controlled access protocols are reservation, polling, and token passing.
- Channelization protocols divide the network channel into smaller subchannels, either in time, frequency, or code domain, and assign them to different nodes or groups of nodes. This prevents collisions, but may waste some bandwidth if the subchannels are not fully utilized. Examples of channelization protocols are TDMA, FDMA, CDMA, and OFDMA.

- Some of the common multiple access protocols that are used in wireless networking are:

  - Carrier-sense multiple access with collision avoidance (CSMA/CA), used in IEEE 802.11 / WiFi, potentially using a distributed coordination function. This protocol allows nodes to sense the channel before transmitting, and to back off if the channel is busy. It also uses an acknowledgment mechanism to confirm the successful reception of data frames, and a request-to-send/clear-to-send (RTS/CTS) handshake to avoid the hidden terminal problem.
  - ALOHA and slotted ALOHA, used in ALOHAnet. These protocols allow nodes to transmit data at any time, without sensing the channel. However, they suffer from high collision rates, especially when the network load is high. Slotted ALOHA improves the performance by dividing the time into discrete slots and requiring nodes to transmit only at the beginning of a slot.
  - Code-division multiple access (CDMA), used in cellular networks and some wireless LANs. This protocol allows multiple nodes to transmit data simultaneously on the same channel, by using different spreading codes to distinguish their signals. CDMA can achieve high spectral efficiency and resistance to interference, but requires complex synchronization and power control techniques.
  - Orthogonal frequency-division multiple access (OFDMA), used in IEEE 802.11ax / WiFi 6, IEEE 802.16 / WiMAX, and 4G/5G cellular networks. This protocol allows multiple nodes to transmit data simultaneously on different subcarriers of the same channel, by using orthogonal frequency-division multiplexing (OFDM) to split the channel into multiple subchannels. OFDMA can achieve high data rates and flexibility in resource allocation, but requires sophisticated signal processing and synchronization.
