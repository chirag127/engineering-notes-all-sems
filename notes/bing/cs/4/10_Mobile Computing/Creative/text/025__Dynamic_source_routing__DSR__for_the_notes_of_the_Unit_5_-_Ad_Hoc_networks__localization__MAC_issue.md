### Dynamic Source Routing (DSR) for the notes of the Unit 5 - Ad Hoc networks, localization, MAC issues, Routing protocols, global state routing (GSR), in the subject of Mobile Computing

- Dynamic Source Routing (DSR) is a routing protocol for wireless mesh networks .
- It is similar to AODV in that it forms a route on-demand when a transmitting node requests one .
- However, it uses source routing instead of relying on the routing table at each intermediate device .
- Source routing means that the sender of a packet determines the complete sequence of nodes through which to forward the packet.
- The sender explicitly lists this route in a header of the packet, which is processed by each node along the path.
- DSR consists of two main mechanisms: route discovery and route maintenance.
- Route discovery is the process of finding a route from a source to a destination when there is no existing route in the source's cache.
- Route discovery uses a query-reply mechanism, where the source broadcasts a route request packet to its neighbors, and the neighbors forward it until it reaches the destination or a node that knows a route to the destination.
- The route request packet contains the source and destination addresses, a unique request ID, and a list of nodes that have forwarded the request.
- The destination or the intermediate node that knows a route to the destination sends a route reply packet back to the source, following the reverse path of the route request packet.
- The route reply packet contains the source and destination addresses, and the list of nodes that constitute the route.
- The source caches the route for future use.
- Route maintenance is the process of detecting and repairing link failures along an active route.
- Route maintenance uses a feedback mechanism, where the node that detects a link failure sends a route error packet to the source, indicating the broken link.
- The source removes the broken link from its cache, and initiates a new route discovery if necessary.
- DSR has some advantages and disadvantages over other routing protocols .
- Advantages:
  - It reduces the overhead of periodic route updates and table maintenance.
  - It allows multiple routes to be cached and used for load balancing and fault tolerance.
  - It adapts quickly to topology changes and supports asymmetric links.
- Disadvantages:
  - It may incur high overhead and latency for route discovery, especially in large and dynamic networks.
  - It may consume more bandwidth and energy due to the source routing header in each packet.
  - It may suffer from stale routes in the cache, which may cause routing loops and packet losses.
