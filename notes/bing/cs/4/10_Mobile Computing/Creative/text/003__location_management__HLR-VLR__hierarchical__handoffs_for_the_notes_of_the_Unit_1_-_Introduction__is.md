### Location Management: HLR-VLR, Hierarchical, Handoffs

- Location management is the process of tracking and updating the location of mobile users in a wireless cellular network.
- Location management enables the network to deliver calls and messages to the mobile users, and to support mobility and handoffs.
- Location management consists of three main tasks: location update, location lookup, and paging.
- Location update is the process of informing the network about the current location of the mobile user, usually initiated by the mobile device when it moves across a predefined boundary.
- Location lookup is the process of finding the current location of the mobile user, usually initiated by the network when it receives a call or a message for the user.
- Paging is the process of notifying the mobile user about an incoming call or a message, usually initiated by the network after locating the user.
- Location management involves two types of databases: Home Location Register (HLR) and Visitor Location Register (VLR).
- HLR is a centralized database that stores the permanent information of all the users in the network, such as their phone numbers, service profiles, and location areas.
- VLR is a local database that stores the temporary information of the users who are currently visiting a specific service area, such as their current cell or base station.
- Each service area is divided into smaller regions called location areas (LAs), which are further divided into cells or base stations.
- Each LA has a VLR associated with it, and each VLR can serve multiple LAs.
- Each user has a unique HLR associated with it, and each HLR can serve multiple users.
- When a user moves from one LA to another, it performs a location update by sending a message to the new VLR, which then contacts the HLR to obtain the user's information and update the user's location.
- When a network receives a call or a message for a user, it performs a location lookup by querying the HLR to find the current VLR of the user, and then querying the VLR to find the current cell or base station of the user.
- When the network finds the current cell or base station of the user, it performs a paging by sending a message to the user's device, which then responds with an acknowledgment.
- Location management can be classified into two types: flat and hierarchical.
- Flat location management is a simple scheme where the network maintains a single database for all the users, and performs location update and lookup for every cell or base station change.
- Flat location management has low update cost but high lookup and paging cost, and is not scalable for large networks.
- Hierarchical location management is a more complex scheme where the network maintains multiple databases at different levels of hierarchy, and performs location update and lookup only for certain boundaries or thresholds.
- Hierarchical location management has high update cost but low lookup and paging cost, and is more scalable for large networks.
- HLR-VLR scheme is an example of hierarchical location management, where the network maintains two levels of hierarchy: HLR and VLR.
- HLR-VLR scheme reduces the lookup and paging cost by grouping the cells or base stations into LAs, and reduces the update cost by allowing the user to stay in the same LA without updating the VLR.
- Handoff is the process of transferring the ongoing call or connection of a mobile user from one cell or base station to another, without interrupting the service quality or dropping the call.
- Handoff is necessary to support mobility and continuity of service in a wireless cellular network.
- Handoff can be classified into two types: horizontal and vertical.
- Horizontal handoff is the process of transferring the call or connection of a mobile user from one cell or base station to another within the same network or technology, such as GSM or CDMA.
- Horizontal handoff can be further classified into two types: hard and soft.
- Hard handoff is the process of breaking the connection with the old cell or base station before establishing the connection with the new cell or base station, resulting in a brief interruption or gap in the service.
- Soft handoff is the process of establishing the connection with the new cell or base station before breaking the connection with the old cell or base station, resulting in a seamless or overlapping service.
