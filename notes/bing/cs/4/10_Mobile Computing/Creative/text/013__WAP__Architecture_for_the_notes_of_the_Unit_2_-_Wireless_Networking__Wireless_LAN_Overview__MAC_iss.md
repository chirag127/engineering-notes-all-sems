### WAP: Architecture

- WAP stands for Wireless Application Protocol, which is a standard for accessing information and services over wireless networks, such as mobile phones, PDAs, and pagers.
- WAP is designed in a layered fashion, so that it can be extensible, flexible, and scalable. As a result, the WAP protocol stack is divided into five layers:
  - Application Layer: This layer contains the Wireless Application Environment (WAE), which provides a framework for developing and delivering wireless applications. The WAE includes an XML-based markup language called the Wireless Markup Language (WML), which is used to create user interfaces and content for wireless devices. The WAE also includes a scripting language called WMLScript, which is similar to JavaScript and allows dynamic interaction and logic on the client side. The WAE also supports other content formats, such as images, audio, video, and vCard/vCalendar.
  - Session Layer: This layer contains the Wireless Session Protocol (WSP), which provides a consistent interface for the application layer to access different types of services, such as HTTP, WTA, and WTP. The WSP also supports features such as session resume, session suspend, and push services, which enable the server to initiate data transfer to the client without a request.
  - Transaction Layer: This layer contains the Wireless Transaction Protocol (WTP), which provides a reliable and efficient mechanism for exchanging data between the client and the server. The WTP supports features such as segmentation and reassembly, acknowledgement and retransmission, and user datagram and transaction modes, which allow different levels of reliability and performance depending on the application needs.
  - Security Layer: This layer contains the Wireless Transport Layer Security (WTLS), which provides encryption, authentication, and data integrity for the wireless communication. The WTLS is based on the Transport Layer Security (TLS) protocol, which is widely used on the Internet. The WTLS also supports features such as compression, datagram support, and optimized handshake, which are tailored for the wireless environment.
  - Transport Layer: This layer contains the Wireless Datagram Protocol (WDP), which provides a common interface for the upper layers to access different types of wireless networks, such as GSM, CDMA, TDMA, and SMS. The WDP also supports features such as port numbers, fragmentation and reassembly, and broadcast and multicast, which enable the upper layers to communicate with multiple devices and services.

- The WAP architecture also includes two types of entities: the WAP client and the WAP gateway. The WAP client is the wireless device that runs the WAE and communicates with the WAP gateway using the WAP protocols. The WAP gateway is the intermediary between the WAP client and the Internet or other networks. The WAP gateway performs functions such as protocol translation, content adaptation, caching, and filtering, which enable the WAP client to access various types of information and services. The WAP gateway also acts as a proxy for the WAP client, which enhances the security and privacy of the wireless communication.
