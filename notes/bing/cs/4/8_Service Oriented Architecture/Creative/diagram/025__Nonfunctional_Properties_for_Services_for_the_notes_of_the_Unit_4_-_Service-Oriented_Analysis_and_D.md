Nonfunctional properties for services are the qualities and features that are desirable by the service users, but are not directly related to the functionality of the service. They include aspects such as availability, performance, security, reliability, scalability, usability, etc.   

A possible diagram to illustrate the nonfunctional properties for services is:

```

|                     |     |                     |
|    Service User     |     |    Service Provider |
|                     |     |                     |

+---------------------+     +---------------------+

          |                          |

          |                          |
+---------------------+     +---------------------+
|                     |     |                     |
|    Service Contract |     |    Service Contract |

+---------------------+     +---------------------+

+---------------------+     +---------------------+
|                     |     |                     |
| Nonfunctional       |     | Nonfunctional       |
| Properties          |     | Properties          |
|                     |     |                     |
+---------------------+     +---------------------+
```

The diagram shows that the nonfunctional properties are part of the service contract, which is an agreement between the service user and the service provider that specifies the terms and conditions of the service consumption. The service contract also defines the functional properties, which are the tangible functionalities provided by the service. The service request and the service response are the messages exchanged between the service user and the service provider that invoke and deliver the service functionality. The nonfunctional properties affect the quality and performance of the service request and the service response, as well as the satisfaction and trust of the service user and the service provider.
