## Unit 3 - Service-Oriented Applications

Service-oriented applications are applications that are built from existing services and components that communicate with each other over a network. A service is a software component that provides a business capability and has a well-defined interface that can be invoked by other components. Service-oriented architecture (SOA) is a design approach that uses services as the building blocks of applications.
