The diagram shows the four main types of big data technologies: data storage, data mining, data analytics, and data visualization. Each type has some examples of tools or platforms that can be used for big data applications. The diagram also shows how the data flows from the sources to the storage, then to the mining and analytics, and finally to the visualization.

The diagram is based on the information from the search results    .
