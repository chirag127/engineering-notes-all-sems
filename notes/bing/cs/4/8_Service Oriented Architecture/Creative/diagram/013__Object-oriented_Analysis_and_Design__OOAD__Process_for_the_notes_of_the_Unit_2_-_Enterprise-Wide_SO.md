According to , OOAD is a technical approach for analyzing and designing an application, system, or business by applying object-oriented programming, as well as using visual modeling throughout the software development process to guide stakeholder communication and product quality.

The basic steps of OOAD process are:

- Identify the objects and classes in the problem domain
- Define the attributes and methods of each class
- Establish the relationships and collaborations among the classes
- Organize the classes into a hierarchy using inheritance and abstraction
- Design the interactions and behaviors of the objects using diagrams and scenarios
- Implement the design using an object-oriented programming language
