## Unit 5 - Technologies for SOA

- Service-Oriented Architecture (SOA) is a software development model that allows services to communicate across different platforms and languages to form applications.
- A service is a self-contained unit of software designed to complete a specific task.
- SOA is independent of vendors and technologies. This means a wide variety of products can be used to implement the architecture. The decision of what to use depends on the end goal of the system.
- Some standard protocols to implement SOA include the following:
  - Simple Object Access Protocol (SOAP): A protocol for exchanging structured data between web services using XML and HTTP.
  - RESTful HTTP: A style of web service architecture that uses HTTP methods (GET, POST, PUT, DELETE) to perform operations on resources identified by URIs.
  - Apache Thrift: A framework for defining and implementing cross-language services using an interface definition language (IDL) and a binary serialization format.
  - Apache ActiveMQ: A message broker that supports various messaging protocols and patterns, such as publish-subscribe, point-to-point, and request-reply.
  - Java Message Service (JMS): A Java API for sending and receiving messages between distributed applications using a message-oriented middleware (MOM).
- You can even use more than one protocol in your SOA implementation.
- SOA is typically implemented with web services such as SOAP and WSDL.
  - Web Services Description Language (WSDL): A XML-based language for describing the functionality, location, and format of web services.
  - Universal Description, Discovery & Integration (UDDI): A registry for publishing and discovering web services.
- SOA can also be implemented with microservices, which are small, independent, and loosely coupled services that communicate via APIs.
  - Microservices can be deployed and scaled independently, allowing for greater flexibility and resilience.
  - Microservices can be run in managed containers, such as AWS Fargate or AWS Lambda, to simplify operations and reduce management overhead.
- SOA can enable cloud computing, which is a broad movement towards internet and the use of WAN and enable smooth interaction between IT service providers of many types and consumers.
  - Cloud technology brings with it a number of key benefits and risks, such as scalability, availability, security, and cost.
  - Cloud services can be classified into three types: Infrastructure as a Service (IaaS), Platform as a Service (PaaS), and Software as a Service (SaaS).
- Some mnemonics and learning tricks for Unit 5 - Technologies for SOA are:
  - SOAP: Simple Object Access Protocol
    - SOAP is a simple way to access objects (data) over the web using XML and HTTP.
  - REST: Representational State Transfer
    - REST is a way to transfer the state (information) of resources (things) using HTTP methods (verbs) and URIs (names).
  - WSDL: Web Services Description Language
    - WSDL is a language that describes web services using XML.
  - UDDI: Universal Description, Discovery & Integration
    - UDDI is a registry that helps you find web services using description, discovery, and integration.
  - JMS: Java Message Service
    - JMS is a service that lets you send and receive messages using Java.
  - IaaS: Infrastructure as a Service
    - IaaS is a service that provides you with infrastructure (hardware) on demand.
  - PaaS: Platform as a Service
    - PaaS is a service that provides you with platform (software) on demand.
  - SaaS: Software as a Service
    - SaaS is a service that provides you with software (application) on demand.
