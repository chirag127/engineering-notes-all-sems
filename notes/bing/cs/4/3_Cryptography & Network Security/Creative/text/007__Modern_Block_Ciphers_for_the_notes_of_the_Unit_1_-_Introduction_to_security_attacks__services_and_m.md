### Modern Block Ciphers

- A modern block cipher is a cipher which encrypts m-bit block of plaintext and decrypts m-bit block of ciphertext .
- For encryption or decryption, modern block cipher facilitate a K bit key and the decryption algorithm should be inverse of encryption algorithms and for both encryption and decryption similar key is used.
- Most modern block ciphers are designed to encrypt data in fixed-size blocks of either 64 or 128 bits.
- A block cipher uses a symmetric key and algorithm to encrypt and decrypt a block of data.
- Modern block ciphers are based on the design of an iterated product cipher, which consists of repeated rounds of a simple function .
- Each round of a block cipher uses a different subkey derived from the main key using a key schedule.
- Block ciphers can operate in different modes of operation, such as electronic codebook (ECB), cipher block chaining (CBC), cipher feedback (CFB), output feedback (OFB), and counter (CTR) mode.
- Each mode of operation has different advantages and disadvantages in terms of security, efficiency, and error propagation.
- Some of the most widely used modern block ciphers are Data Encryption Standard (DES), Advanced Encryption Standard (AES), and Triple DES (3DES).
- Block ciphers are specified elementary components in the design of many cryptographic protocols and are widely used to encrypt large amounts of data, including in data exchange protocols.
