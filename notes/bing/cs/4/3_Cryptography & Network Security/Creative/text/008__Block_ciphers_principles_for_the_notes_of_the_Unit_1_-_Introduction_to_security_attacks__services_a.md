### Block ciphers principles

- A block cipher is a symmetric encryption algorithm that operates on a fixed-size block of plaintext and produces a ciphertext of the same size. The encryption and decryption algorithms are inverse functions of each other and use the same secret key .
- A block cipher can be seen as a function that maps n-bit plaintext blocks to n-bit ciphertext blocks, where n is the block size and the function depends on the key. The function must be one-to-one, meaning that each plaintext block has a unique ciphertext block and vice versa.
- A block cipher must be resistant to various types of attacks, such as brute force, differential cryptanalysis, linear cryptanalysis, etc. To achieve this, a block cipher typically employs several rounds of transformations, each using a subkey derived from the main key  .
- The most common structure for a block cipher is the Feistel cipher, which consists of alternating substitution and permutation layers. The substitution layer applies a nonlinear function F to the input block and the subkey, while the permutation layer swaps the bits of the output block. The Feistel cipher can be easily inverted by reversing the order of the subkeys and the direction of the permutation .
- Some examples of block ciphers are Data Encryption Standard (DES), Triple DES (3DES), Advanced Encryption Standard (AES), Blowfish, Twofish, etc. Each of these ciphers has a different block size, key size, number of rounds, and design of function F .
- A block cipher can be used in various modes of operation, such as Electronic Codebook (ECB), Cipher Block Chaining (CBC), Cipher Feedback (CFB), Output Feedback (OFB), Counter (CTR), etc. These modes define how the plaintext blocks are processed and how the initialization vector (IV) is used. The choice of the mode depends on the security and performance requirements of the application .
