- A primality test is an algorithm for determining whether an input number is prime or not .
- A prime number is a natural number greater than 1 that has no positive divisors other than 1 and itself.
- Primality testing is used for cryptography, especially for public key crypto systems, where large prime numbers are needed to generate keys and perform encryption and decryption.
- There are two types of primality tests: deterministic and probabilistic.
  - Deterministic primality tests can always give a correct answer, but they are usually slow or impractical for large numbers.
  - Probabilistic primality tests can give a wrong answer with a very small probability, but they are usually fast and practical for large numbers.
- Some examples of deterministic primality tests are:
  - Trial division: This method checks if the input number is divisible by any prime number up to its square root. If it is, then it is composite; otherwise, it is prime. This method is simple but inefficient for large numbers.
  - Sieve of Eratosthenes: This method generates all the prime numbers up to a certain limit by marking the multiples of each prime number as composite. Then, it checks if the input number is in the list of primes or not. This method is efficient for generating many primes, but it requires a lot of memory and time for large limits.
  - AKS algorithm: This is a polynomial-time algorithm that can determine the primality of any number in a deterministic way. It is based on the following theorem: A number n is prime if and only if the polynomial (x-1)^n - (x^n - 1) is divisible by n for any integer x. This method is theoretically optimal, but it is still slower than probabilistic methods in practice.
- Some examples of probabilistic primality tests are:
  - Fermat's primality test: This method is based on Fermat's little theorem, which states that if p is a prime number, then a^(p-1) is congruent to 1 modulo p for any integer a that is not divisible by p. This method chooses a random number a and checks if a^(p-1) is congruent to 1 modulo p. If it is not, then p is definitely composite; otherwise, p is probably prime. This method can be fooled by some composite numbers called Carmichael numbers, which satisfy Fermat's condition for any a.
  - Miller-Rabin primality test: This method is an improvement of Fermat's test, which avoids the problem of Carmichael numbers. It is based on the following observation: If p is an odd prime number, then p-1 can be written as 2^s * d, where s and d are positive integers and d is odd. Then, for any integer a that is not divisible by p, either a^d is congruent to 1 modulo p, or a^(2^r * d) is congruent to -1 modulo p for some r between 0 and s-1. This method chooses a random number a and checks if these conditions hold. If they do not, then p is definitely composite; otherwise, p is probably prime. This method can be repeated with different values of a to increase the confidence of the result.
  - Solovay-Strassen primality test: This method is based on the Euler's criterion, which states that if p is an odd prime number, then a^((p-1)/2) is congruent to the Jacobi symbol (a/p) modulo p for any integer a that is not divisible by p. The Jacobi symbol is a generalization of the Legendre symbol, which indicates whether a is a quadratic residue modulo p or not. This method chooses a random number a and checks if this condition holds. If it does not, then p is definitely composite; otherwise, p is probably prime. This method can also be repeated with different values of a to increase the confidence of the result.
