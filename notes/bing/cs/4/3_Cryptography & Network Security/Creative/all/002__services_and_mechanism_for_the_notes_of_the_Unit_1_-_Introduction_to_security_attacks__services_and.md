- Security attacks are any actions that compromise the security of information owned by an organization or an individual. They can be classified into two categories: passive attacks and active attacks. Passive attacks are those that do not affect the normal functioning of the system, but only attempt to eavesdrop or analyze the data. Active attacks are those that alter or disrupt the system, such as modifying, deleting, or injecting data, or denying service. Examples of passive attacks are traffic analysis, monitoring, and cryptanalysis. Examples of active attacks are replay, masquerade, modification, and denial of service.
- Security services are the countermeasures that are designed to protect the system from security attacks. They can be classified into five categories and fourteen specific services, according to the X.800 standard. The five categories are: authentication, access control, data confidentiality, data integrity, and non-repudiation. The fourteen specific services are:

  - Authentication: The assurance that the communicating entity is the one that it claims to be. It can be subdivided into peer entity authentication, which verifies the identity of the other party in a communication, and data origin authentication, which verifies the source of the data.
  - Access control: The prevention of unauthorized use of a resource. It can be implemented by using encryption, passwords, biometrics, or other mechanisms.
  - Data confidentiality: The protection of data from unauthorized disclosure. It can be applied to the entire data stream, or to selected fields or messages. It can also be subdivided into traffic flow confidentiality, which conceals the pattern of communication, and connection confidentiality, which protects the identities of the communicating parties.
  - Data integrity: The assurance that data has not been altered or destroyed in an unauthorized manner. It can be applied to the entire data stream, or to selected fields or messages. It can also be subdivided into connection integrity, which provides end-to-end integrity, and selective field connection integrity, which provides integrity for selected fields within a message.
  - Non-repudiation: The prevention of denying one's involvement in a communication. It can be subdivided into non-repudiation of origin, which proves that the sender sent the message, and non-repudiation of delivery, which proves that the receiver received the message.
- Security mechanisms are the tools or methods that are used to implement the security services. They can be classified into two categories: specific security mechanisms and pervasive security mechanisms. Specific security mechanisms are those that are applied to a specific service or protocol, such as encryption, digital signatures, or access control lists. Pervasive security mechanisms are those that are not specific to any service or protocol, but are applicable to a wide range of situations, such as security labels, audit trails, or security management.
- A model for network security is a framework that describes how the security services and mechanisms can be applied to a communication system. One such model is the OSI security architecture, which defines the security aspects of the OSI reference model. The OSI security architecture consists of three layers: the security service layer, the security mechanism layer, and the security policy layer. The security service layer defines the security services that are provided by the system. The security mechanism layer defines the security mechanisms that are used to implement the security services. The security policy layer defines the rules and regulations that govern the use of the security services and mechanisms.
- Classical encryption techniques are the methods of encryption that were used before the advent of modern cryptography. They are based on two basic principles: substitution and transposition. Substitution ciphers are those that replace each letter or symbol of the plaintext with another letter or symbol, according to a fixed rule or key. Transposition ciphers are those that rearrange the order of the letters or symbols of the plaintext, according to a fixed rule or key. Cryptanalysis is the art of breaking the encryption and recovering the plaintext from the ciphertext, without knowing the key. Steganography is the art of hiding the existence of a message, by embedding it in another medium, such as an image, a sound, or a text.
