- Stream and block ciphers are two types of symmetric encryption algorithms that can be used to encrypt data.
- Symmetric encryption means that the same key is used for both encryption and decryption of data.
- Stream ciphers encrypt data one bit or byte at a time, while block ciphers encrypt data in fixed-size blocks.
- Stream ciphers use a pseudorandom bit generator to produce a keystream, which is then combined with the plaintext using a bitwise operation, such as XOR.
- Block ciphers use a key and a cryptographic algorithm to transform each block of plaintext into a block of ciphertext.
- Stream ciphers are faster and more suitable for continuous data streams, such as audio and video, while block ciphers are more secure and more suitable for discrete data, such as files and messages.
- Stream ciphers are vulnerable to attacks if the same key is reused for different messages, or if the keystream is predictable or has low entropy.
- Block ciphers are vulnerable to attacks if the same key is used for too many blocks, or if the algorithm has weak properties, such as low diffusion or confusion.
- Diffusion means that a small change in the plaintext or the key should result in a large change in the ciphertext, making it hard to find patterns or correlations.
- Confusion means that the relationship between the plaintext, the key, and the ciphertext should be complex and obscure, making it hard to deduce the key or the plaintext from the ciphertext.
- Fiestel structure is a common design for block ciphers, where the plaintext block is divided into two halves, and each half is processed by a round function that involves the key and some permutation and substitution operations. The two halves are then swapped and the process is repeated for a number of rounds.
- Data Encryption Standard (DES) is a widely used block cipher that has a 64-bit block size and a 56-bit key size. It uses a fiestel structure with 16 rounds and a complex key schedule.
- DES is considered insecure today, as it can be broken by brute force attacks or by differential cryptanalysis, which is a technique that exploits the statistical properties of the cipher to find the key.
- Differential cryptanalysis involves finding pairs of plaintexts that have a fixed difference, and observing the difference in the corresponding ciphertexts. By analyzing the distribution of the differences, the attacker can deduce some bits of the key or reduce the search space.
- Block cipher modes of operation are different ways of using a block cipher to encrypt data that is larger than the block size. Some common modes are:
  - Electronic Codebook (ECB): The data is divided into blocks and each block is encrypted independently with the same key. This mode is insecure, as it reveals patterns and repetitions in the data.
  - Cipher Block Chaining (CBC): The data is divided into blocks and each block is XORed with the previous ciphertext block before being encrypted with the same key. The first block is XORed with an initialization vector (IV), which is a random value. This mode provides diffusion and prevents identical plaintext blocks from producing identical ciphertext blocks.
  - Cipher Feedback (CFB): The data is divided into segments that are smaller than the block size, and each segment is XORed with a part of the previous ciphertext block before being encrypted with the same key. The first segment is XORed with an IV. This mode allows the block cipher to act as a stream cipher.
