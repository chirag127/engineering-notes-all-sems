- Steganography is the practice of hiding a secret message inside of (or even on top of) something that is not secret.
- The word steganography comes from the Greek words steganos (covered) and graphein (writing).
- The purpose of steganography is to conceal and deceive. The hidden message should not be detectable by human or machine analysis.
- Steganography can be used both for constructive and destructive purposes. For example, education and business institutions, intelligence agencies, the military, and certified ethical hackers use steganography to embed confidential messages and information in plain sight. On the other hand, cybercriminals, terrorists, and spies use steganography to hide malicious code, commands, or communication in innocent-looking files or media.
- Steganography can be classified into two types: technical and linguistic.
  - Technical steganography uses physical or digital methods to hide the message. For example, writing with invisible ink, embedding text in a picture, hiding data in a file header, or using a covert channel to transmit information  .
  - Linguistic steganography uses language techniques to hide the message. For example, using acrostics, ciphers, codes, or jargon to disguise the meaning of words, or using null ciphers to insert meaningless characters or words in a text.
- Steganography can be applied to various types of media, such as text, image, audio, video, or network.
  - Text steganography hides the message in the text by changing the format, structure, or content of the text. For example, using different fonts, colors, sizes, or spaces to encode the message, or inserting the message in the whitespace or punctuation marks of the text.
  - Image steganography hides the message in the image by modifying the pixels, colors, or metadata of the image. For example, using the least significant bit (LSB) technique to embed the message in the least important bits of the image, or using the discrete cosine transform (DCT) technique to embed the message in the frequency domain of the image .
  - Audio steganography hides the message in the audio by altering the sound waves, frequency, or phase of the audio. For example, using the LSB technique to embed the message in the least audible bits of the audio, or using the phase coding technique to embed the message in the phase shift of the audio signal.
  - Video steganography hides the message in the video by modifying the frames, pixels, or metadata of the video. For example, using the LSB technique to embed the message in the least significant bits of each frame, or using the motion vector technique to embed the message in the motion of the objects in the video.
  - Network steganography hides the message in the network by manipulating the network protocols, headers, or packets. For example, using the TCP/IP header technique to embed the message in the unused or optional fields of the TCP/IP header, or using the packet length technique to embed the message in the length of the network packets.
- Steganography can be combined with encryption as an extra step for hiding or protecting data. Encryption transforms the message into an unreadable form, while steganography conceals the message in another medium. The combination of encryption and steganography can provide more security and robustness against detection and attacks.
- Steganography can be detected and attacked by various methods, such as visual analysis, statistical analysis, structural analysis, or steganalysis. Visual analysis involves inspecting the media for any visible signs of alteration or distortion. Statistical analysis involves comparing the statistical properties of the media with the expected or normal values. Structural analysis involves examining the format, structure, or metadata of the media for any anomalies or inconsistencies. Steganalysis involves using specialized tools or algorithms to extract or destroy the hidden message
