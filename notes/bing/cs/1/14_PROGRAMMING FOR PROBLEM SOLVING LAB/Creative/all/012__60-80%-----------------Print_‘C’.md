## 60-80%-----------------Print ‘C’

- This is a programming problem that requires printing the letter 'C' using the character '-' (dash) for 60 to 80 percent of the width and height of the screen.
- The problem can be solved using different programming languages, such as C, Python, Java, etc. Here, we will use Python as an example.
- The main steps to solve the problem are:

  - Get the width and height of the screen using the `os` module.
  - Calculate the number of dashes to print for each row and column based on the percentage given.
  - Use nested loops to print the dashes and spaces for each row and column.
  - Use conditional statements to print the dashes only for the first, last, and middle rows and columns.
