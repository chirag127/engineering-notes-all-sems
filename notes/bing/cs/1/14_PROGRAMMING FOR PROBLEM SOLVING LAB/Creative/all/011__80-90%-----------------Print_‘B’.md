## 80-90%-----------------Print ‘B’

- This is a topic related to conditional statements in programming languages.
- A conditional statement is a statement that executes a block of code only if a certain condition is met.
- For example, in Python, a conditional statement can be written as:

```python
if condition:
    # do something
else:
    # do something else
```

- In this topic, the condition is that a percentage value is between 80 and 90, inclusive.
- If the condition is true, then the program should print 'B' as the output.
- If the condition is false, then the program should print nothing or some other message.
- For example, in Python, a possible program for this topic can be written as:

```python
# get the percentage value from the user
percentage = float(input("Enter the percentage: "))

# check if the percentage is between 80 and 90
if percentage >= 80 and percentage <= 90:
    # print 'B' as the output
    print("B")
else:
    # print nothing or some other message
    print("Not in the range")
```

- A possible mnemonic or learning trick for this topic is to remember the acronym BEE: Between Eighty and Ninety, print 'E'.
- This can help to recall the condition and the output for this topic.
