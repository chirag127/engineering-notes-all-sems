## 60-80%-----------------Print ‘C’

- This is a programming problem that requires the use of conditional statements and output functions.
- The problem statement is: Write a program that takes a percentage value as input from the user and prints ‘C’ if the value is between 60 and 80 (both inclusive).
- The steps to solve this problem are:

  - Declare a variable to store the percentage value and assign it the input from the user. For example, in Python, you can use `percentage = float(input("Enter the percentage: "))`
  - Use an if statement to check if the percentage value is between 60 and 80 (both inclusive). For example, in Python, you can use `if 60 <= percentage <= 80:`
  - If the condition is true, print ‘C’ using the output function. For example, in Python, you can use `print("C")`
  - If the condition is false, do nothing or print a different message. For example, in Python, you can use `else: print("Not C")`
  - End the program.

- Here is an example of the program in Python:

```python
# Declare a variable to store the percentage value and assign it the input from the user
percentage = float(input("Enter the percentage: "))

# Use an if statement to check if the percentage value is between 60 and 80 (both inclusive)
if 60 <= percentage <= 80:
  # If the condition is true, print ‘C’ using the output function
  print("C")
else:
  # If the condition is false, do nothing or print a different message
  print("Not C")

# End the program
```
