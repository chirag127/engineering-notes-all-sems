The virtual lab link that you have provided is for the simulation of series RL circuits. A series RL circuit is a circuit that consists of a resistor and an inductor connected in series with a voltage source. The following diagram illustrates the basic architecture of a series RL circuit:

```
+---+     +---+     +---+
|   |     |   |     |   |
| V |-----| R |-----| L |-----+
|   |     |   |     |   |     |
+---+     +---+     +---+     |
                              |
                              |
                             ===
                             GND
```

In this diagram, V is the voltage source, R is the resistor, L is the inductor, and GND is the ground. The current flows from the positive terminal of the voltage source to the negative terminal, passing through the resistor and the inductor. The voltage across the resistor is equal to the product of the current and the resistance, and the voltage across the inductor is equal to the product of the current and the inductive reactance. The inductive reactance is a function of the frequency of the voltage source and the inductance of the inductor. The phase angle between the voltage and the current is determined by the ratio of the inductive reactance to the total impedance of the circuit. The total impedance is the sum of the resistance and the inductive reactance. The simulator allows you to vary the values of the voltage source, the resistor, and the inductor, and to measure the current and the voltages across the components using an ammeter and a voltmeter. You can also observe the waveforms of the voltage and the current on an oscilloscope. The simulator helps you to verify the theoretical concepts and calculations of series RL circuits.
