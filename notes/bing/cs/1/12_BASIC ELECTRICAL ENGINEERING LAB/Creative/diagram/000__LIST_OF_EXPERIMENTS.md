## LIST OF EXPERIMENTS

The following diagram illustrates the basic architecture of a list experiment:

```
+---------------------+        +---------------------+
| Direct Response     |        | Veiled Response    |
| Group               |        | Group              |
+---------------------+        +---------------------+
| How many of these   |        | How many of these  |
| statements are true |        | statements are true|
| for you?            |        | for you?           |
|                     |        |                    |
| - I like chocolate  |        | - I like chocolate |
| - I like coffee     |        | - I like coffee    |
| - I like tea        |        | - I like tea       |
|                     |        | - I have cheated   |
|                     |        |   on a test        |
+---------------------+        +---------------------+
| Respondent reports  |        | Respondent reports |
| the number of true  |        | the number of true |
| statements, e.g. 2  |        | statements, e.g. 3 |
+---------------------+        +---------------------+
```

The difference in the average number of true statements between the two groups is an estimate of the proportion of people who have cheated on a test. This technique can be used to elicit information about sensitive topics without directly asking the respondents.
