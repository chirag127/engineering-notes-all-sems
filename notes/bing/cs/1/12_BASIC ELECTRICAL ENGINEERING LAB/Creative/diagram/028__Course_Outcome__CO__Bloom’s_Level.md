Course Outcome (CO) is a statement that describes what a student is expected to learn from a course. Bloom's Level is a measure of the complexity of thinking required to achieve a CO. Bloom's Taxonomy is a framework that classifies COs into six levels: remember, understand, apply, analyze, evaluate, and create. The following diagram illustrates the basic structure of a CO Bloom's Level using ASCII art:

#### Course Outcome (CO) Bloom's Level

```
+-----------------+    +-----------------+    +-----------------+
|                 |    |                 |    |                 |
|    Remember     |    |    Apply        |    |    Evaluate     |
|                 |    |                 |    |                 |
+-----------------+    +-----------------+    +-----------------+
       |                     |                     |
       |                     |                     |
       |                     |                     |
       V                     V                     V
+-----------------+    +-----------------+    +-----------------+
|                 |    |                 |    |                 |
|   Understand    |    |    Analyze      |    |    Create       |
|                 |    |                 |    |                 |
+-----------------+    +-----------------+    +-----------------+
```

Each level of the taxonomy has a set of verbs that can be used to write COs. For example, some verbs for the remember level are: define, list, recall, identify, etc. Some verbs for the create level are: design, construct, produce, invent, etc. The higher the level of the taxonomy, the more complex and challenging the CO is. A well-written CO should have a clear and measurable verb, a specific and relevant content, and a suitable context or condition. For example, a CO for the create level could be: "Design and implement a web application using HTML, CSS, and JavaScript."
