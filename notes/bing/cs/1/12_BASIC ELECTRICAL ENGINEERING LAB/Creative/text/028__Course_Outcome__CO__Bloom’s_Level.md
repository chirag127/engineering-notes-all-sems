#### Course Outcome (CO) Bloom’s Level

- A course outcome (CO) is a statement that describes what a student is expected to learn and demonstrate after completing a specific course.
- A CO should be specific, measurable, achievable, relevant, and time-bound (SMART).
- A CO should also be aligned with the program outcomes (POs) and the course objectives (COs) of the curriculum.
- Bloom’s taxonomy is a framework that classifies the cognitive skills and abilities that are involved in learning and assessment.
- Bloom’s taxonomy consists of six levels of cognitive complexity: remember, understand, apply, analyze, evaluate, and create.
- Each level of Bloom’s taxonomy requires a higher degree of cognitive processing and mastery than the previous one.
- Bloom’s taxonomy can be used to select appropriate verbs and indicators for writing and assessing COs.
- The verbs and indicators should match the level of cognitive complexity and mastery that is expected of the students for each CO.
- The following table shows some examples of verbs and indicators for each level of Bloom’s taxonomy.

| Level | Verbs | Indicators |
| --- | --- | --- |
| Remember | Define, list, recall, identify, name, recognize, etc. | Facts, terms, concepts, principles, etc. |
| Understand | Explain, describe, summarize, illustrate, interpret, etc. | Meaning, main idea, relationships, implications, etc. |
| Apply | Use, apply, solve, demonstrate, implement, etc. | Methods, procedures, techniques, rules, etc. |
| Analyze | Compare, contrast, differentiate, classify, organize, etc. | Elements, components, structure, patterns, etc. |
| Evaluate | Assess, evaluate, justify, critique, argue, etc. | Criteria, standards, quality, relevance, etc. |
| Create | Design, create, construct, produce, synthesize, etc. | Products, models, solutions, plans, etc. |

- Some examples of COs written using Bloom’s taxonomy are:

  - CO1: Recall the basic concepts and principles of computer science and engineering. (Remember)
  - CO2: Explain the functioning and applications of various hardware and software components of a computer system. (Understand)
  - CO3: Apply the concepts of data structures and algorithms to solve computational problems. (Apply)
  - CO4: Analyze the performance and complexity of different algorithms and data structures. (Analyze)
  - CO5: Evaluate the ethical, social, and environmental implications of computer science and engineering. (Evaluate)
  - CO6: Design and create software solutions for real-world problems using appropriate tools and techniques. (Create)
