### Note: A minimum of ten experiments from the following should be performed.

- Experiment 1: To verify the truth table of logic gates (AND, OR, NOT, NAND, NOR, XOR, XNOR) using ICs.
- Experiment 2: To design and implement a half adder and a full adder circuit using logic gates.
- Experiment 3: To design and implement a half subtractor and a full subtractor circuit using logic gates.
- Experiment 4: To design and implement a 4-bit binary to gray code converter and vice versa using logic gates.
- Experiment 5: To design and implement a 4-bit binary to BCD code converter and vice versa using logic gates.
- Experiment 6: To design and implement a 4-bit magnitude comparator using logic gates.
- Experiment 7: To design and implement a multiplexer and a demultiplexer using logic gates.
- Experiment 8: To design and implement an encoder and a decoder using logic gates.
- Experiment 9: To design and implement a flip-flop (SR, JK, D, T) using logic gates and verify its truth table and excitation table.
- Experiment 10: To design and implement a shift register (SIPO, PISO, SISO, PIPO) using flip-flops and verify its operation.
- Experiment 11: To design and implement a counter (asynchronous and synchronous, up and down, modulo-n) using flip-flops and verify its operation.
- Experiment 12: To design and implement a ring counter and a Johnson counter using flip-flops and verify its operation.
- Experiment 13: To design and implement a 7-segment display driver using a decoder and verify its operation.
- Experiment 14: To design and implement an arithmetic logic unit (ALU) using logic gates and verify its operation.
