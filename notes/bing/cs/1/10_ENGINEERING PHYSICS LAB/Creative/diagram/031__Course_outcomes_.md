## Course outcomes:

A course outcome is a statement that describes what a student should be able to do or demonstrate after completing a course. A course outcome can be represented by an ASCII diagram that shows the relationship between the course, the outcome, the assessment, and the evidence.

One possible diagram is:

```
+----------------+       +----------------+       +----------------+
|                |       |                |       |                |
|    Course      |------>|   Outcome      |------>|   Assessment   |
|                |       |                |       |                |
+----------------+       +----------------+       +----------------+
       |                       |                       |
       |                       |                       |
       |                       |                       |
       |                       |                       |
       |                       |                       |
       |                       |                       |
       |                       |                       |
       |                       |                       |
       |                       |                       |
       |                       |                       |
       |                       |                       |
       |                       |                       |
       |                       |                       |
       |                       |                       |
       |                       |                       |
       |                       |                       |
       |                       |                       |
       |                       |                       |
       |                       |                       |
       |                       |                       |
       V                       V                       V
+----------------+       +----------------+       +----------------+
|                |       |                |       |                |
|   Content      |<------|   Evidence     |<------|   Feedback     |
|                |       |                |       |                |
+----------------+       +----------------+       +----------------+
```

The diagram shows that a course leads to an outcome, which is measured by an assessment, which provides feedback to the student. The outcome also produces evidence, which is based on the content of the course. The content and the feedback can be used to improve the course and the outcome.
