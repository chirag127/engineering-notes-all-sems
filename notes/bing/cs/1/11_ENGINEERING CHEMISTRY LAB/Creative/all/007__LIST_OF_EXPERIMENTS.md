## LIST OF EXPERIMENTS

- An experiment is a scientific procedure that is carried out to test a hypothesis, observe a phenomenon, or measure a variable.
- A list of experiments is a collection of experiments that are related to a specific topic, field, or course of study.
- A list of experiments can help students to learn the theoretical concepts, practical skills, and analytical methods of a subject.
- A list of experiments can also help teachers to design, plan, and evaluate the learning outcomes of a subject.
- A list of experiments can vary depending on the level, scope, and objectives of the subject.
- Some examples of lists of experiments are:

  - List of experiments for physics: This list can include experiments on mechanics, optics, electricity, magnetism, thermodynamics, waves, etc. For example, an experiment on measuring the acceleration due to gravity using a simple pendulum, an experiment on verifying Snell's law of refraction using a glass slab, an experiment on determining the resistance of a wire using a voltmeter and an ammeter, etc.
  - List of experiments for chemistry: This list can include experiments on qualitative and quantitative analysis, organic and inorganic synthesis, chemical kinetics, equilibrium, electrochemistry, etc. For example, an experiment on testing the presence of different ions in a given salt, an experiment on preparing aspirin from salicylic acid and acetic anhydride, an experiment on studying the rate of reaction between sodium thiosulfate and hydrochloric acid, etc.
  - List of experiments for biology: This list can include experiments on microscopy, cell biology, genetics, ecology, physiology, etc. For example, an experiment on observing the structure of an onion peel cell under a microscope, an experiment on extracting DNA from a banana, an experiment on testing the effect of light on the growth of plants, etc.
  - List of experiments for computer science: This list can include experiments on programming, data structures, algorithms, databases, networks, etc. For example, an experiment on writing a program to calculate the factorial of a number, an experiment on implementing a stack using an array, an experiment on sorting a list of numbers using bubble sort, an experiment on creating a table and inserting data using SQL, etc.

- A list of experiments can be organized in different ways, such as by topic, by difficulty, by duration, by equipment, by outcome, etc.
- A list of experiments can be accompanied by instructions, diagrams, codes, tables, graphs, results, observations, calculations, inferences, etc. to help the students and teachers to perform, understand, and evaluate the experiments.
