## LIST OF EXPERIMENTS

The following diagram illustrates the basic architecture of a list experiment:

```
+------------------+     +------------------+     +------------------+
|                  |     |                  |     |                  |
|  Direct Response |     |  Veiled Response |     |  List Experiment |
|     Group        |     |     Group        |     |                  |
|                  |     |                  |     |                  |
+------------------+     +------------------+     +------------------+
|                  |     |                  |     |                  |
|  How many of the |     |  How many of the |     |  Randomly assign |
|  following items |     |  following items |     |  respondents to  |
|  apply to you?   |     |  apply to you?   |     |  either group    |
|                  |     |                  |     |                  |
|  - Item A        |     |  - Item A        |     +------------------+
|  - Item B        |     |  - Item B        |     |                  |
|  - Item C        |     |  - Item C        |     |  Compare the     |
|                  |     |  - Item D        |     |  average number  |
|                  |     |                  |     |  of items        |
|                  |     |  (Item D is the  |     |  reported by     |
|                  |     |  sensitive one)  |     |  each group      |
|                  |     |                  |     |                  |
+------------------+     +------------------+     +------------------+
```

The list experiment is a questionnaire design technique used to mitigate respondent social desirability bias when eliciting information about sensitive topics. With a large enough sample size, list experiments can be used to estimate the proportion of people for whom a sensitive statement is true.

Some examples of list experiments are:

- Harry Harlow's experiments with baby monkeys and wire and cloth surrogate mothers (1957–1974) 
- Stanley Milgram's experiments on human obedience (1963) 
- Walter Mischel's marshmallow experiment showing the importance to life outcomes of the ability to delay gratification (beginning late 1960s) 
- Science experiments you can do at home, such as kitchen chemistry, DIY mini drones, or slime making  
- Lilo & Stitch's experiments, which are genetically engineered creatures with different abilities and personalities
