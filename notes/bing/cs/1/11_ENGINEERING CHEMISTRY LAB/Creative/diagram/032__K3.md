K3 is a lightweight Kubernetes distribution that can run on a variety of architectures, including edge devices. It supports a highly available topology with an external database and a load balancer. The following diagram illustrates the basic architecture of a K3 cluster with an external database:

### K3

```
+-----------------+       +-----------------+       +-----------------+
|                 |       |                 |       |                 |
|  K3s Server 1   |       |  K3s Server 2   |       |  K3s Server 3   |
|                 |       |                 |       |                 |
+-----------------+       +-----------------+       +-----------------+
|                 |       |                 |       |                 |
|  K3s Agent 1    |       |  K3s Agent 2    |       |  K3s Agent 3    |
|                 |       |                 |       |                 |
+-----------------+       +-----------------+       +-----------------+
       |                       |                       |
       |                       |                       |
       +-----------------------+-----------------------+
                               |
                               |
                               v
+-----------------+       +-----------------+       +-----------------+
|                 |       |                 |       |                 |
|  Load Balancer  | <---- |  External DB    | ----> |  Backup DB      |
|                 |       |                 |       |                 |
+-----------------+       +-----------------+       +-----------------+
```

The load balancer distributes the traffic among the K3s servers, which are the control plane nodes of the cluster. The external database stores the cluster state and can be backed up by another database. The K3s agents are the worker nodes of the cluster, which run the pods and services. Each K3s server can also run an agent, which allows it to join the cluster as a worker node. The K3s cluster can be scaled up by adding more servers or agents, or scaled down by removing them.
