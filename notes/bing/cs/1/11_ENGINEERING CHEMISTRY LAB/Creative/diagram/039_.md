There are different tools and methods to draw ASCII diagrams. One of them is to use Graphviz, a software for creating graphs and diagrams from text. Graphviz can output ASCII diagrams using the Graph::Easy module, which can be installed using the following commands:

```bash
sudo apt-get install cpanminus
sudo cpanm Graph::Easy
```

Then, you can use Graphviz to create a dot file, which is a text file that describes the graph structure and attributes. For example, the following dot file defines a simple directed graph with three nodes and two edges:

```dot
digraph G {
  A -> B;
  B -> C;
  A [label="Node A"];
  B [label="Node B"];
  C [label="Node C"];
}
```

To convert this dot file to an ASCII diagram, you can use the graph-easy command as follows:

```bash
cat graph.dot | graph-easy --from=dot --as_ascii
```

This will produce the following output:

```ascii
+-------+     +-------+     +-------+
| Node A| --> | Node B| --> | Node C|
+-------+     +-------+     +-------+
```

Another tool to draw ASCII diagrams is Asciidoctor Diagram, which is a plugin for Asciidoctor, a text processor that converts AsciiDoc documents to HTML, PDF, and other formats. Asciidoctor Diagram can generate diagrams from various sources, such as ditaa, PlantUML, and Graphviz. To use Asciidoctor Diagram, you need to install Asciidoctor and the asciidoctor-diagram script, and then use it to process your AsciiDoc document that contains diagram blocks. For example, the following AsciiDoc document defines a ditaa diagram block, which is a text-based way to draw diagrams using ASCII characters:

```asciidoc
= My Document
:imagesdir: images

[ditaa]
----
    +--------+   +-------+    +-------+
    |        +---+       +----+       |
    | Alice  |   | Bob   |    | Carol |
    |        +---+       +----+       |
    +--------+   +-------+    +-------+
----
```

To convert this AsciiDoc document to HTML with the diagram image, you can use the following command:

```bash
asciidoctor-diagram my-doc.adoc
```

This will create a file called my-doc.html and a folder called images that contains the diagram image. The HTML file will look like this:

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My Document</title>
</head>
<body>
  <h1>My Document</h1>
  <img src="images/my-doc-ditaa.png" alt="ditaa diagram">
</body>
</html>
```

The diagram image will look like this:

```ascii
    +--------+   +-------+    +-------+
    |        +---+       +----+       |
    | Alice  |   | Bob   |    | Carol |
    |        +---+       +----+       |
    +--------+   +-------+    +-------+
```

You can create boxes, lines, arrows, and text, and export your diagram as text or HTML. To use ASCIIFlow, you can visit the website and start drawing your diagram.
