Course Outcomes Bloom’s is a model of cognitive skills used to classify educational learning objectives and to help develop learning outcomes. It consists of six levels of thinking, from lower-order to higher-order: remember, understand, apply, analyze, evaluate, and create. Each level requires the mastery of the previous one, and each level has a set of verbs that can be used to write learning outcomes.

### Course Outcomes Bloom’s

```
+----------------+----------------------------------------------------+
| Level          | Verbs                                              |
+----------------+----------------------------------------------------+
| Remember       | Define, list, recall, identify, name, match, etc.  |
+----------------+----------------------------------------------------+
| Understand     | Explain, describe, summarize, interpret, etc.      |
+----------------+----------------------------------------------------+
| Apply          | Use, demonstrate, solve, calculate, apply, etc.    |
+----------------+----------------------------------------------------+
| Analyze        | Compare, contrast, classify, categorize, etc.      |
+----------------+----------------------------------------------------+
| Evaluate       | Assess, judge, critique, justify, argue, etc.      |
+----------------+----------------------------------------------------+
| Create         | Design, construct, produce, synthesize, etc.       |
+----------------+----------------------------------------------------+
```
