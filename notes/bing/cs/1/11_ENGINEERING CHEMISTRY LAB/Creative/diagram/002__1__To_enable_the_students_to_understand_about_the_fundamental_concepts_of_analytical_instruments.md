Analytical instruments are devices that measure physical, chemical, or biological properties of samples or substances. They can be classified into different categories based on the type of stimulus and response they use, such as spectroscopy, chromatography, mass spectrometry, etc.

The following diagram illustrates the basic architecture of an analytical instrument using ASCII characters:

```
+-----------------+       +-----------------+       +-----------------+
|                 |       |                 |       |                 |
|    Stimulus     |------>|    Analyte      |------>|    Response     |
|                 |       |                 |       |                 |
+-----------------+       +-----------------+       +-----------------+
|                 |       |                 |       |                 |
|  Source of      |       |  Sample or      |       |  Detector or    |
|  energy or      |       |  substance      |       |  transducer     |
|  signal         |       |  under study    |       |  that converts  |
|                 |       |                 |       |  response into  |
+-----------------+       +-----------------+       +-----------------+
|                 |       |                 |       |                 |
|  Examples:      |       |  Examples:      |       |  Examples:      |
|  - Light        |       |  - Molecules    |       |  - Photons      |
|  - Electricity  |       |  - Ions         |       |  - Electrons    |
|  - Magnetism    |       |  - Atoms        |       |  - Current      |
|  - Heat         |       |  - Crystals     |       |  - Voltage      |
|                 |       |                 |       |                 |
+-----------------+       +-----------------+       +-----------------+
```
