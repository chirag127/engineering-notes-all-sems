### 5. Characteristic of BJT: BJT in CE configuration.

- BJT stands for Bipolar Junction Transistor, which is a three-terminal device that can amplify electrical signals.
- CE configuration stands for Common Emitter configuration, which is one of the most widely used modes of operation for BJT.
- In CE configuration, the emitter terminal is common to both the input and output circuits, the base terminal is the input, and the collector terminal is the output.
- The main characteristics of BJT in CE configuration are:

  - Input characteristics: These are the curves that show the relation between the base current (Ib) and the base-emitter voltage (Vbe) for different values of collector-emitter voltage (Vce). The input characteristics are similar to that of a forward-biased diode, as the base-emitter junction is forward-biased in CE configuration. The input resistance (Rin) is the ratio of change in Vbe to the change in Ib, and it is typically low (50 to 1000 ohms).

  - Output characteristics: These are the curves that show the relation between the collector current (Ic) and the collector-emitter voltage (Vce) for different values of base current (Ib). The output characteristics have three regions: active region, saturation region, and cutoff region. In the active region, the collector current is proportional to the base current, and the collector-emitter voltage is high. This is the region where the BJT acts as an amplifier. In the saturation region, the collector current reaches a maximum value, and the collector-emitter voltage is low. This is the region where the BJT acts as a switch that is ON. In the cutoff region, the collector current is zero, and the collector-emitter voltage is high. This is the region where the BJT acts as a switch that is OFF. The output resistance (Rout) is the ratio of change in Vce to the change in Ic, and it is typically high (50k to 100k ohms).

  - Current gain: This is the ratio of the output current to the input current, and it is denoted by beta (β). The current gain is the slope of the output characteristics in the active region, and it is typically high (50 to 500). The current gain is also related to the alpha (α) parameter, which is the ratio of the collector current to the emitter current. The relation between alpha and beta is: β = α / (1 - α).

- Some mnemonics and learning tricks for the characteristics of BJT in CE configuration are:

  - To remember the three regions of the output characteristics, use the acronym SAC: Saturation, Active, Cutoff.
  - To remember the relation between alpha and beta, use the formula: B = A / (1 - A), where B stands for beta and A stands for alpha.
  - To remember the input and output resistances, use the rule: Rin is low, Rout is high.
  - To remember the common terminal, use the word Emitter, which starts with E, the same as CE configuration.
