### 5. Characteristic of BJT: BJT in CE configuration.

- BJT stands for bipolar junction transistor, which is a three-terminal device that can amplify electrical signals.
- CE configuration means common emitter configuration, which is one of the most widely used modes of operation for BJT. In this mode, the emitter terminal is common to both the input and output circuits.
- The characteristic of BJT in CE configuration can be divided into two types: input characteristic and output characteristic.
- Input characteristic shows the relation between the base current (I<sub>B</sub>) and the base-emitter voltage (V<sub>BE</sub>) for a given collector-emitter voltage (V<sub>CE</sub>). It can be obtained by plotting I<sub>B</sub> versus V<sub>BE</sub> for different values of V<sub>CE</sub>.
- Output characteristic shows the relation between the collector current (I<sub>C</sub>) and the collector-emitter voltage (V<sub>CE</sub>) for a given base current (I<sub>B</sub>). It can be obtained by plotting I<sub>C</sub> versus V<sub>CE</sub> for different values of I<sub>B</sub>.
- The input characteristic of BJT in CE configuration has the following features:
  - It is nonlinear and exponential in nature, meaning that a small change in V<sub>BE</sub> can cause a large change in I<sub>B</sub>.
  - It has a negative temperature coefficient, meaning that the base current decreases with the increase in temperature.
  - It has a cut-off region, where the base current is negligible and the transistor is off.
  - It has an active region, where the base current is significant and the transistor is on.
  - It has a saturation region, where the base current is maximum and the transistor is fully on.
- The output characteristic of BJT in CE configuration has the following features:
  - It is nonlinear and piecewise linear in nature, meaning that it has different slopes for different regions of operation.
  - It has a cut-off region, where the collector current is negligible and the transistor is off.
  - It has an active region, where the collector current is proportional to the base current and the transistor is on.
  - It has a saturation region, where the collector current is maximum and the transistor is fully on.
  - It has a knee voltage, which is the minimum value of V<sub>CE</sub> required to keep the transistor in the active region.
  - It has a load line, which is the graphical representation of the external circuit connected to the transistor. The load line intersects the output characteristic at the operating point, which determines the values of I<sub>C</sub> and V<sub>CE</sub> for a given I<sub>B</sub>.
