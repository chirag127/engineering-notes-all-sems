### 7. Verification of Truth Table of Various Logic Gate.

- A logic gate is an electronic circuit that performs a logical operation on one or more input signals and produces a single output signal.
- The input and output signals can have only two values: 0 (low) or 1 (high), which represent the binary digits or bits.
- The basic logic gates are AND, OR, NOT, NAND, NOR, XOR and XNOR. Each logic gate has a specific symbol and a truth table that shows the output for all possible combinations of inputs.
- The truth table of a logic gate can be verified by using a circuit diagram or a breadboard with the corresponding components, such as switches, LEDs, resistors and ICs (integrated circuits).
- The following steps can be followed to verify the truth table of various logic gates:

  - Identify the logic gate to be verified and its symbol, inputs and output.
  - Draw the circuit diagram of the logic gate using the appropriate components and connections. Alternatively, set up the breadboard with the components and wires as per the circuit diagram.
  - Label the input and output terminals of the logic gate and connect them to the switches and LED respectively. The switches will act as the input signals and the LED will indicate the output signal.
  - Turn on the power supply and test the logic gate by changing the positions of the switches and observing the state of the LED. Record the output for each combination of inputs in a table.
  - Compare the table with the truth table of the logic gate and verify that they match. If they do not match, check for any errors in the circuit diagram, breadboard or components and correct them.
  - Repeat the steps for other logic gates as required.
