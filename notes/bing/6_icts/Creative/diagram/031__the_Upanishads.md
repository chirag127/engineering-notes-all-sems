The Upanishads are ancient Hindu scriptures that contain the philosophical and spiritual teachings of the Vedas. They explore the nature of reality, the self, and the supreme being. The Upanishads are also known as Vedanta, meaning "the end of the Vedas".

The following diagram illustrates the basic structure of the Upanishads:

### The Upanishads

```
+-----------------+     +-----------------+     +-----------------+
|                 |     |                 |     |                 |
|   Rigveda       |     |   Samaveda      |     |   Yajurveda     |
|                 |     |                 |     |                 |
+-----------------+     +-----------------+     +-----------------+
|                 |     |                 |     |                 |
|   Aitareya      |     |   Chandogya     |     |   Brihadaranyaka|
|   Kaushitaki    |     |   Kena          |     |   Taittiriya    |
|                 |     |                 |     |   Katha         |
+-----------------+     +-----------------+     +-----------------+
|                 |     |                 |     |                 |
|   Atharvaveda   |     |   Other Upanishads    |   Muktika Upanishad
|                 |     |                 |     |                 |
+-----------------+     +-----------------+     +-----------------+
|                 |     |                 |     |                 |
|   Mundaka      |     |   Shvetashvatara|     |   List of 108   |
|   Mandukya     |     |   Kaivalya      |     |   Upanishads    |
|   Prashna       |     |   Maitri        |     |                 |
+-----------------+     +-----------------+     +-----------------+
```

The diagram shows the four Vedas and the Upanishads associated with each of them. The Rigveda, Samaveda, and Yajurveda have the oldest and most important Upanishads, while the Atharvaveda has some later ones. There are also other Upanishads that are not part of any Veda, but are considered authoritative by some traditions. The Muktika Upanishad is a meta-Upanishad that lists 108 Upanishads as the canonical ones. Each Upanishad contains various topics, such as the nature of brahman, the self, the soul, the mind, the senses, the ethics, the meditation, the liberation, and the rebirth.
