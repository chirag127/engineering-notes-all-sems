#### Inheritance in Core Java
Inheritance is a mechanism in Java that allows one class to inherit the properties and behaviors of another class. This is achieved by using the `extends` keyword. Here is an example of inheritance in Core Java using ASCII diagram:

```
+----------------+
|    Parent      |
| +------------+ |
| |  property  | |
| +------------+ |
| |  behavior  | |
| +------------+ |
+----------------+
         |
         |
         |
         |
         |
+----------------+
|     Child      |
| +------------+ |
| |  property  | |
| +------------+ |
| |  behavior  | |
| +------------+ |
+----------------+
```

In this diagram, the `Child` class extends the `Parent` class, inheriting its properties and behaviors. The `Child` class can also have its own properties and behaviors, in addition to those inherited from the `Parent` class.
