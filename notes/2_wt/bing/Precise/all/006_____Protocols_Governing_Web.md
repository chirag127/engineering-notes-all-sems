### Protocols Governing Web

1. **HTTP (Hypertext Transfer Protocol):** This is the primary protocol used for transmitting web pages and other information on the World Wide Web. It defines how messages are formatted and transmitted, and what actions Web servers and clients should take in response to various commands.

2. **HTTPS (Hypertext Transfer Protocol Secure):** This is a secure version of HTTP, which uses encryption to protect the data being transmitted between the client and the server. It is commonly used for online transactions and other sensitive information.

3. **FTP (File Transfer Protocol):** This protocol is used for transferring files between computers on a network. It is commonly used for uploading and downloading files to and from a web server.

4. **TCP/IP (Transmission Control Protocol/Internet Protocol):** This is the fundamental protocol suite that provides the foundation for the Internet. It defines how data is transmitted between devices on a network, and includes several different protocols for handling different types of data.

5. **DNS (Domain Name System):** This protocol is used for translating human-readable domain names (such as www.example.com) into the numerical IP addresses that computers use to identify each other on a network.

6. **SMTP (Simple Mail Transfer Protocol):** This protocol is used for sending email messages between servers. It is commonly used by email clients to send messages to a mail server for delivery.

7. **IMAP (Internet Message Access Protocol):** This protocol is used for retrieving email messages from a mail server. It allows an email client to access and manipulate email messages as though they were stored locally on the client device.

8. **POP3 (Post Office Protocol version 3):** This is another protocol used for retrieving email messages from a mail server. Unlike IMAP, it is designed to support offline email access, where messages are downloaded to the client device and then deleted from the server.

These are some of the main protocols that govern the functioning of the web. Each protocol serves a specific purpose and plays a crucial role in enabling communication and data transfer on the Internet.
