#### Introduction to AWT in Core Java

- AWT stands for Abstract Window Toolkit.
- It is a package in the Java programming language that provides a platform-independent interface for creating Graphical User Interfaces (GUIs).
- AWT is part of the Java Foundation Classes (JFC) and is included in the java.awt package.
- AWT provides a set of classes for creating windows, dialogs, buttons, text fields, labels, lists, menus, and other GUI components.
- AWT also provides classes for handling events, such as mouse clicks and key presses, and for drawing graphics and images.
- AWT is considered to be heavyweight because it relies on the underlying operating system's native GUI components.
- AWT components are not as customizable as Swing components, which are another set of GUI components provided by Java.
- AWT is still used in some applications, but Swing is generally preferred for creating modern GUIs in Java.
