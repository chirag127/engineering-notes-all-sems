## Unit 3 - Scripting

Scripting is a type of programming that is used to automate tasks and manipulate data. It is often used for tasks such as system administration, web development, and data analysis.

1. **Scripting languages:** Some common scripting languages include Python, Perl, Ruby, and JavaScript. These languages are often interpreted, rather than compiled, which means that the code is executed directly, rather than being translated into machine code first.

2. **Advantages of scripting:** Scripting can save time and effort by automating repetitive tasks. It can also be used to manipulate data, generate reports, and perform other tasks that would be difficult or time-consuming to do manually.

3. **Disadvantages of scripting:** Scripting can be less efficient than compiled code, and may not be suitable for tasks that require high performance. It can also be more difficult to debug, as errors may not be detected until runtime.

4. **Examples of scripting:** Some examples of tasks that can be accomplished using scripting include:
    - Automating system administration tasks, such as creating user accounts or managing backups.
    - Generating reports from data stored in a database or spreadsheet.
    - Creating dynamic web pages that respond to user input.
    - Automating data analysis tasks, such as cleaning and preprocessing data, or performing statistical analysis.

5. **Applications of scripting:** Scripting is used in a wide variety of fields, including system administration, web development, data analysis, and scientific research. It is a versatile tool that can be used to automate tasks, manipulate data, and perform other tasks that would be difficult or time-consuming to do manually.

6. **Mnemonics and learning tricks:** One way to remember the difference between scripting and programming is to think of scripting as being like writing a script for a play, while programming is like building the set. Scripting is used to automate tasks and manipulate data, while programming is used to create more complex software applications.
