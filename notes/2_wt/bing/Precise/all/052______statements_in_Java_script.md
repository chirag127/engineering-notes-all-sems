#### Statements in JavaScript

- A statement is a command that tells the computer to perform a specific action.
- In JavaScript, statements are separated by semicolons (;).
- There are several types of statements in JavaScript, including variable declarations, assignments, conditionals, loops, and function declarations.
- Variable declarations use the `var`, `let`, or `const` keyword to declare a variable and optionally assign it a value.
- Assignments use the `=` operator to assign a value to a variable.
- Conditional statements, such as `if` and `switch`, allow the program to make decisions based on certain conditions.
- Loops, such as `for` and `while`, allow the program to repeat a block of code a certain number of times or until a certain condition is met.
- Function declarations define a new function that can be called later in the program.
