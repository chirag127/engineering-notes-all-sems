#### AWT Controls

AWT (Abstract Window Toolkit) is a set of Java classes used to create graphical user interfaces (GUIs). AWT controls, also known as components, are the basic building blocks of a GUI application. These controls include buttons, text fields, labels, checkboxes, and more.

Here are some of the commonly used AWT controls:

1. **Button**: A button is a component that triggers an action when clicked. It is typically used to submit data or perform a specific task.
2. **Label**: A label is a component used to display text. It is typically used to provide information or instructions to the user.
3. **TextField**: A text field is a component that allows the user to enter text. It is typically used to collect input from the user.
4. **TextArea**: A text area is a component that allows the user to enter multiple lines of text. It is typically used to collect longer input from the user.
5. **Checkbox**: A checkbox is a component that allows the user to select one or more options. It is typically used to collect multiple choices from the user.
6. **Choice**: A choice is a component that allows the user to select one option from a list. It is typically used to collect a single choice from the user.
7. **List**: A list is a component that displays a list of items and allows the user to select one or more items. It is typically used to collect multiple choices from the user.

These are just a few examples of the many AWT controls available. AWT controls can be combined and customized to create complex and interactive GUIs.
