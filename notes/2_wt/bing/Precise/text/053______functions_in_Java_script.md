#### Functions in JavaScript

- A function is a block of code designed to perform a particular task.
- A function is executed when it is invoked (called).
- Functions can be defined using a function declaration or a function expression.
- Functions can accept parameters and return a value.
- Functions can be stored in variables, passed as arguments to other functions, and returned as values from other functions.
- Functions can be used to create reusable code and improve code organization.
- Functions can be nested, meaning a function can be defined inside another function.
- Functions have access to the variables and functions defined in the same scope, as well as any outer scopes.
- Functions can be used to create closures, which allow data to be kept private.
- Functions can be used as constructors to create objects using the `new` keyword.
