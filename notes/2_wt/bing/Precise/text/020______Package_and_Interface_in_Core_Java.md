#### Package and Interface in Core Java

- A **package** in Java is a way to organize and group related classes and interfaces.
- Packages help to avoid naming conflicts and make it easier to manage and maintain code.
- To create a package, use the `package` keyword followed by the package name at the top of the Java file.
- To use classes or interfaces from a package, use the `import` keyword followed by the package name and class or interface name.
- An **interface** in Java is a collection of abstract methods (methods without a body) and constants.
- Interfaces are used to define a contract or behavior that classes must implement.
- To create an interface, use the `interface` keyword followed by the interface name.
- A class can implement an interface by using the `implements` keyword followed by the interface name.
- A class that implements an interface must provide an implementation for all of the methods defined in the interface.
- Interfaces can also be used to achieve multiple inheritance in Java, as a class can implement multiple interfaces.
