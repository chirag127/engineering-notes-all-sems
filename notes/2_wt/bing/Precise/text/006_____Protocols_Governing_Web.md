### Protocols Governing Web

1. **Hypertext Transfer Protocol (HTTP)**: This is the protocol used for transmitting web pages over the Internet. It defines how messages are formatted and transmitted, and what actions Web servers and clients should take in response to various commands.

2. **Transmission Control Protocol (TCP)**: This protocol is responsible for establishing a connection between two devices and ensuring that data is transmitted reliably between them.

3. **Internet Protocol (IP)**: This protocol is responsible for routing data packets between devices on a network. It defines the format of the packets and the addressing scheme used to identify devices.

4. **File Transfer Protocol (FTP)**: This protocol is used for transferring files between devices on a network. It is commonly used for uploading files to a web server or downloading files from a server.

5. **Simple Mail Transfer Protocol (SMTP)**: This protocol is used for sending email messages between servers. It is used by email clients to send messages to a mail server for delivery.

6. **Domain Name System (DNS)**: This protocol is used for translating human-readable domain names into IP addresses. It is used by web browsers to resolve the IP address of a web server when a user enters a URL.
