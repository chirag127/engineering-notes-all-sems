#### Statements in JavaScript

- A statement is a piece of code that performs a specific action.
- Statements are the building blocks of a program and are executed in the order in which they appear.
- JavaScript supports several types of statements, including variable declarations, assignments, conditionals, loops, and function declarations.
- Statements can be grouped together into blocks, which are delimited by curly braces `{}`.
- A semicolon `;` is used to separate statements.
- The `if` statement is used to execute a block of code only if a certain condition is true.
- The `for` and `while` loops are used to repeatedly execute a block of code.
- The `switch` statement is used to execute different blocks of code depending on the value of an expression.
- The `break` and `continue` statements are used to control the flow of execution within loops.
- The `return` statement is used to specify the value that a function should return.
- The `throw` statement is used to raise an exception.
- The `try...catch` statement is used to catch exceptions that are thrown within a block of code.
