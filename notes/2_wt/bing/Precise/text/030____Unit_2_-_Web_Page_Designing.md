## Unit 2 - Web Page Designing

1. **Introduction to Web Page Designing:** Web page designing involves the creation and arrangement of web pages that make up a website. This includes the use of HTML, CSS, and JavaScript to create a visually appealing and functional website.

2. **HTML:** HTML (Hypertext Markup Language) is the standard markup language used to create web pages. It is used to structure content and define the layout of a web page.

3. **CSS:** CSS (Cascading Style Sheets) is a style sheet language used to describe the look and formatting of a web page. It is used to separate the presentation of a web page from its content, making it easier to maintain and update.

4. **JavaScript:** JavaScript is a programming language used to create interactive and dynamic web pages. It is used to add functionality to a web page, such as form validation, animation, and user interaction.

5. **Web Design Principles:** There are several principles to consider when designing a web page, including usability, accessibility, and visual design. A well-designed web page should be easy to use, accessible to all users, and visually appealing.

6. **Responsive Design:** Responsive design is an approach to web design that aims to create web pages that provide an optimal viewing experience across a wide range of devices, from desktop computers to mobile phones. This is achieved through the use of flexible layouts, images, and CSS media queries.

7. **Web Design Tools:** There are many tools available to assist in the design of web pages, including text editors, graphic design software, and web design software. These tools can help to streamline the design process and improve the quality of the final product.

8. **Conclusion:** Web page designing is an important aspect of creating a successful website. By understanding the principles of web design and utilizing the appropriate tools, it is possible to create a visually appealing and functional web page.
