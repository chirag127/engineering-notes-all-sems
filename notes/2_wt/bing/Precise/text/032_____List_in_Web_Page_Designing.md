### List in Web Page Designing

1. Lists are an essential part of web page designing as they help in organizing and presenting information in a structured manner.
2. There are two main types of lists used in web page designing: ordered lists and unordered lists.
3. Ordered lists are used to present a sequence of items in a specific order. The items in an ordered list are usually numbered.
4. Unordered lists are used to present a collection of items without any specific order. The items in an unordered list are usually marked with a bullet point.
5. Lists can be nested within one another to create sub-lists.
6. Lists can be styled using CSS to change their appearance and layout.
7. Lists are commonly used to present navigation menus, steps in a process, or a collection of related items.
8. Proper use of lists can improve the readability and accessibility of a web page.
