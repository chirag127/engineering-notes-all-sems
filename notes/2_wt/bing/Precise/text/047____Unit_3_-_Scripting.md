## Unit 3 - Scripting

1. Scripting is a type of programming that is used to automate tasks and manipulate data.
2. Scripts are usually written in a scripting language, such as Python, JavaScript, or Ruby.
3. Scripting languages are interpreted, which means that the code is executed line by line, rather than being compiled into machine code and executed all at once.
4. Scripts can be used for a wide variety of tasks, including data processing, web scraping, and system administration.
5. Scripting languages are often easier to learn and use than traditional programming languages, making them a popular choice for beginners and non-programmers.
6. Scripts can be run from the command line, or they can be embedded in other programs or web pages.
7. Scripting can save time and effort by automating repetitive tasks, and can also be used to perform complex operations on large datasets.
8. Many scripting languages have large and active communities, with extensive libraries of pre-written code that can be used to perform common tasks.
9. Scripting can be a powerful tool for data analysis, allowing users to quickly and easily manipulate and visualize large datasets.
10. Scripting is an essential skill for many jobs in the tech industry, including data analysis, web development, and system administration.
