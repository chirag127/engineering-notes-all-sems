## Unit 4 - Enterprise Java Bean

1. Enterprise Java Beans (EJB) is a server-side component architecture for the Java Platform, Enterprise Edition (Java EE).
2. EJBs are used to encapsulate business logic and provide a way to develop scalable, distributed, and transactional applications.
3. EJBs can be either session beans or message-driven beans.
4. Session beans are used to manage the interactions between clients and the EJB container, while message-driven beans are used to process messages asynchronously.
5. EJBs can be deployed in an EJB container, which manages their lifecycle, security, and transactions.
6. EJBs can be accessed remotely using the Java Naming and Directory Interface (JNDI) or through web services.
7. EJBs support declarative transaction management, allowing developers to specify transactional behavior using annotations or deployment descriptors.
8. EJBs also support container-managed persistence, allowing developers to map Java objects to relational database tables using the Java Persistence API (JPA).
9. EJBs can be used in combination with other Java EE technologies such as Servlets, JavaServer Pages (JSP), and JavaServer Faces (JSF) to develop enterprise applications.
10. EJBs provide a way to develop scalable, distributed, and transactional applications that can be easily maintained and extended.
