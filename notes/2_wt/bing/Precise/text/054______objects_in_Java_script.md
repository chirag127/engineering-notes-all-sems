#### Objects in JavaScript

- An object is a collection of properties, and a property is an association between a name (or key) and a value.
- A property's value can be a function, in which case the property is known as a method.
- Objects can be created using the `Object()` constructor or the object initializer / literal syntax.
- Properties of an object can be accessed using dot notation or bracket notation.
- The `Object` class provides several methods for working with objects, such as `Object.keys()`, `Object.values()`, and `Object.entries()`.
- Objects can be used to represent complex data structures, such as a person with a name, age, and address.
- Inheritance can be achieved in JavaScript through the use of prototypes.
- The `this` keyword refers to the object that the function is a method of.
- Objects are mutable, meaning their properties can be changed after they are created.
- Objects can be used to organize code into reusable, modular components.
