## Unit 3 - Scripting

- Scripting is the process of writing and executing a series of commands or instructions that can be interpreted by a program or a system.
- Scripting languages are high-level languages that are designed for scripting, such as Python, Perl, Ruby, JavaScript, etc.
- Scripting languages have some advantages over compiled languages, such as:
  - They are easier to learn and use, as they have simpler syntax and less strict rules.
  - They are more portable, as they can run on different platforms without recompilation.
  - They are more flexible and dynamic, as they can handle different types of data and perform runtime modifications.
  - They are more interactive, as they can provide immediate feedback and allow user input.
- Scripting languages also have some disadvantages over compiled languages, such as:
  - They are slower, as they have to be interpreted every time they run.
  - They are less secure, as they can expose the source code and allow unauthorized access or modification.
  - They are less efficient, as they consume more memory and resources.
  - They are less reliable, as they can have more errors and bugs due to the lack of type checking and debugging tools.
- Scripting can be used for various purposes and applications, such as:
  - Automating tasks and processes, such as file management, data processing, web scraping, etc.
  - Developing web applications and interfaces, such as dynamic web pages, web servers, web services, etc.
  - Testing and debugging software and systems, such as unit testing, regression testing, performance testing, etc.
  - Creating games and animations, such as graphical user interfaces, game logic, physics, etc.
  - Data analysis and visualization, such as data mining, machine learning, statistics, etc.

- A simple example of a Python script that prints "Hello, world!" is:

```python
# This is a comment
print("Hello, world!") # This is a print statement
```

- A simple example of a JavaScript script that creates an alert box with "Hello, world!" is:

```javascript
// This is a comment
alert("Hello, world!"); // This is an alert statement
```

- A simple example of a Bash script that prints "Hello, world!" is:

```bash
# This is a comment
echo "Hello, world!" # This is an echo statement
```

- A mnemonic to remember the advantages of scripting languages is: EPIF
  - E for Easier
  - P for Portable
  - I for Interactive
  - F for Flexible
- A mnemonic to remember the disadvantages of scripting languages is: SLER
  - S for Slow
  - L for Less secure
  - E for Less efficient
  - R for Less reliable
