### History of Web

- The World Wide Web (WWW or Web) is a global information medium that users can access via computers connected to the Internet. It allows users to view and interact with hypertext documents that contain text, images, audio, video, and other multimedia content.
- The Web was invented by Tim Berners-Lee, a British scientist working at CERN, the European Organization for Nuclear Research, in 1989. He proposed a "universal linked information system" that would enable scientists to share data and documents across different platforms and networks. 
- Berners-Lee developed the first Web server, the first Web browser, and the first Web page using a document formatting protocol called Hypertext Markup Language (HTML). He also created the HyperText Transfer Protocol (HTTP), which standardized communication between servers and clients, and the Uniform Resource Identifier (URI), which identified the location and name of a resource on the Web. 
- Berners-Lee published the first Web page in 1991 and released the browser source code for public use in 1993. This sparked the development of many other Web browsers, such as Mosaic, Netscape Navigator, and Internet Explorer, which made the Web more accessible and popular to the general public. 
- The Web grew rapidly in the 1990s, as more and more websites were created for various purposes, such as e-commerce, entertainment, education, social networking, and news. The Web also became a platform for innovation and creativity, as users could create and share their own content using tools such as blogs, wikis, podcasts, and web applications. 
- The features of HTML evolved over time, leading to HTML version 2 in 1995, HTML3 and HTML4 in 1997, and HTML5 in 2014. HTML was enhanced with advanced formatting and styling capabilities by Cascading Style Sheets (CSS) and with programming functionality by JavaScript. AJAX programming enabled dynamic and interactive content delivery to users, which ushered in a new era of Web design, known as Web 2.0. 
- The Web became ubiquitous in everyday life in the 21st century, as more and more devices, such as smartphones, tablets, smart TVs, and wearable gadgets, were connected to the Internet and enabled users to access the Web anytime and anywhere. The Web also became a source of big data, as users generated and consumed massive amounts of information on the Web. The Web also faced challenges, such as security, privacy, censorship, and digital divide, which required ethical and legal solutions.
