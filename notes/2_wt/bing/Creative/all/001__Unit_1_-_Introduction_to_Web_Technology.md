## Unit 1 - Introduction to Web Technology

- Web technology is the development of the mechanism that allows two or more computer devices to communicate over a network .
- Web technology includes various tools and techniques that are used to create, display, and interact with web pages and web applications on the internet .
- Web technology can be classified into the following sections:

  - World Wide Web (WWW): The WWW is a system of interlinked hypertext documents that can be accessed via the internet using a web browser .
  - Web Browser: A web browser is an application software that displays web pages and allows users to navigate and interact with the web .
  - Web Server: A web server is a program that processes the requests of web browsers and serves them with files that create web pages. The communication between web browsers and web servers is based on the Hypertext Transfer Protocol (HTTP) .
  - Web Pages: A web page is a digital document that is linked to the WWW and viewable by anyone connected to the internet using a web browser. A web page is usually written in Hypertext Markup Language (HTML) and may contain other elements such as images, videos, audio, scripts, and stylesheets .
  - Web Development: Web development is the process of building, creating, and maintaining websites and web applications. It involves aspects such as web design, web publishing, web programming, and database management .
  - Web Development can be further divided into two parts:

    - Frontend Development: The frontend is the part of a website or web application that the user interacts with directly. It is also referred to as the client-side of the application. The frontend is usually built using languages such as HTML, CSS, and JavaScript.
    - Backend Development: The backend is the part of a website or web application that the user cannot see or interact with directly. It is also referred to as the server-side of the application. The backend is responsible for storing and manipulating data, processing logic, and communicating with the frontend. The backend is usually built using languages such as PHP, Python, Ruby, Java, etc.

- Some examples of web technology are:

  - HTML: HTML is the standard markup language for creating web pages. It defines the structure and content of web pages using tags and attributes.
  - CSS: CSS is the language that describes the presentation of web pages. It allows web developers to apply styles, colors, fonts, layouts, and animations to web pages.
  - JavaScript: JavaScript is the scripting language that enables dynamic and interactive features on web pages. It allows web developers to manipulate the HTML elements, access the browser's functionality, communicate with the web server, and create web applications.
  - AngularJS: AngularJS is a JavaScript framework that simplifies the development of single-page web applications. It allows web developers to create reusable components, bind data to the HTML elements, and implement the Model-View-Controller (MVC) pattern.
  - jQuery: jQuery is a JavaScript library that simplifies the manipulation of the HTML document, the handling of events, the animation of elements, and the communication with the web server using Ajax.
  - ReactJS: ReactJS is a JavaScript library that allows web developers to create user interfaces for web applications. It uses a declarative and component-based approach to render the HTML elements efficiently and dynamically.
  - PHP: PHP is a server-side scripting language that is widely used for web development. It allows web developers to embed code within HTML documents, connect to databases, process user input, and generate dynamic web pages.
  - TypeScript: TypeScript is a superset of JavaScript that adds static typing and object-oriented features to the language. It allows web developers to write more robust and maintainable code for web applications.
  - JSON: JSON is a lightweight data-interchange format that is commonly used for exchanging data between web browsers and web servers. It is based on a subset of the JavaScript syntax and can be easily parsed and generated by JavaScript.
  - SVG: SVG is a vector graphics format that allows web developers to create scalable and interactive graphics for web pages. It is based on XML and can be styled and animated using CSS and JavaScript.
