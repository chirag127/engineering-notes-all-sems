#### Directives in Servlets

- Directives are special instructions to the servlet container that affect the structure and behavior of a servlet or JSP page.
- Directives are not part of the servlet or JSP code, but they are placed at the top of the file, before any HTML or Java code.
- Directives are enclosed in `<%` and `%>` symbols, and have the following syntax: `<%@ directive attribute="value" %>`
- There are three types of directives in servlets: page, include, and taglib.

##### Page directive

- The page directive defines attributes that apply to an entire JSP page, such as the content type, the scripting language, the error page, etc.
- The page directive can be used multiple times in a JSP page, but it is recommended to use it only once for readability and maintainability.
- The page directive has many attributes, but some of the commonly used ones are:

  - contentType: specifies the MIME type and character encoding of the response generated by the JSP page. The default value is `text/html; charset=ISO-8859-1`.
  - import: allows the JSP page to import Java classes or packages. Multiple classes or packages can be imported by separating them with commas.
  - errorPage: specifies the path of another JSP page that will handle any uncaught exceptions thrown by the current JSP page. The error page must have the `isErrorPage` attribute set to `true`.
  - isErrorPage: indicates whether the current JSP page is an error page or not. The default value is `false`. If set to `true`, the JSP page can access the exception object using the implicit variable `exception`.
  - session: indicates whether the JSP page participates in an HTTP session or not. The default value is `true`. If set to `false`, the JSP page cannot access the implicit variable `session`.
  - isThreadSafe: indicates whether the JSP page can handle multiple concurrent requests or not. The default value is `true`. If set to `false`, the servlet container will synchronize the access to the JSP page, which may affect the performance.
  - buffer: specifies the size of the output buffer used by the JSP page. The default value is `8kb`. If set to `none`, no buffering is used, and the output is flushed to the client immediately.
  - autoFlush: indicates whether the output buffer should be flushed automatically when it is full or not. The default value is `true`. If set to `false`, an exception will be thrown when the buffer is full.

- An example of a page directive is:

  ```jsp
  <%@ page contentType="text/html; charset=UTF-8" import="java.util.*, java.text.*" errorPage="error.jsp" %>
  ```

##### Include directive

- The include directive allows the JSP page to include the content of another file, such as an HTML file, a JSP file, or a plain text file, at the time of translation.
- The include directive is also known as static include, because the inclusion is done once at the translation phase, and the included file is treated as part of the JSP page.
- The include directive has only one attribute: file, which specifies the path of the file to be included, relative to the current JSP page.
- The include directive can be used multiple times in a JSP page, and can be nested inside other include directives.
- The include directive can improve the modularity and reusability of the JSP code, by allowing the common parts of the web application to be stored in separate files and included as needed.
- An example of an include directive is:

  ```jsp
  <%@ include file="header.html" %>
  ```

##### Taglib directive

- The taglib directive allows the JSP page to use custom tags, which are reusable components that encapsulate the logic and presentation of a web application.
- The taglib directive declares a tag library, which is a collection of custom tags, identified by a unique URI (Uniform Resource Identifier).
- The taglib directive has two attributes: uri and prefix. The uri attribute specifies the URI of the tag library, and the prefix attribute specifies the prefix that will be used to invoke the custom tags in the JSP page.
- The taglib directive can be used multiple times in a JSP page, to declare different tag libraries with different prefixes.
