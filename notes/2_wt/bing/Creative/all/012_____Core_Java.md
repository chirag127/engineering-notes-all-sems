# Core Java

- Core Java is the basic and fundamental part of the Java programming language that defines the syntax, data types, operators, control structures, classes, interfaces, exceptions, and input/output operations.
- Core Java is also known as Java Standard Edition (Java SE) or Java Platform Standard Edition (Java SE).
- Core Java is the foundation for developing various types of Java applications, such as desktop applications, web applications, mobile applications, and embedded systems.
- Core Java covers the following topics:

  - Java Basics: Introduction to Java, features of Java, Java Virtual Machine (JVM), Java Development Kit (JDK), Java Runtime Environment (JRE), Java bytecode, Java comments, Java identifiers, Java keywords, Java literals, Java data types, Java variables, Java operators, Java expressions, Java statements, Java control structures, Java arrays, Java enums, Java varargs, Java command-line arguments, etc.
  - Object-Oriented Programming in Java: Introduction to object-oriented programming, principles of object-oriented programming, classes and objects, constructors, methods, access modifiers, inheritance, polymorphism, abstract classes, interfaces, inner classes, anonymous classes, lambda expressions, method references, etc.
  - Exception Handling in Java: Introduction to exception handling, types of exceptions, try-catch-finally blocks, throw and throws keywords, custom exceptions, etc.
  - Input/Output in Java: Introduction to input/output, streams and readers/writers, byte streams and character streams, buffered streams, data streams, object streams, file streams, console input/output, scanner class, print stream and print writer classes, serialization and deserialization, etc.
  - Collections Framework in Java: Introduction to collections framework, collection interfaces, collection classes, iterator interface, list interface and classes, set interface and classes, map interface and classes, queue interface and classes, deque interface and classes, comparator and comparable interfaces, etc.
  - Generics in Java: Introduction to generics, generic classes, generic methods, generic interfaces, type parameters, type arguments, type inference, type erasure, bounded type parameters, wildcards, etc.
  - Multithreading in Java: Introduction to multithreading, thread class, runnable interface, thread states, thread methods, thread priority, thread synchronization, inter-thread communication, deadlock, thread pool, executor framework, concurrent collections, etc.
  - Functional Programming in Java: Introduction to functional programming, functional interfaces, predicate interface, consumer interface, supplier interface, function interface, optional class, stream API, etc.
  - Java 8 Features: Introduction to Java 8 features, lambda expressions, method references, default methods, static methods, functional interfaces, stream API, optional class, date and time API, etc.
  - Java 9 Features: Introduction to Java 9 features, modules, jshell, private methods in interfaces, diamond operator for anonymous classes, try-with-resources enhancement, etc.
  - Java 10 Features: Introduction to Java 10 features, local variable type inference, unmodifiable collections, optional.orElseThrow() method, etc.
  - Java 11 Features: Introduction to Java 11 features, lambda parameters with var, string methods, files methods, optional.isEmpty() method, etc.
  - Java 12 Features: Introduction to Java 12 features, switch expressions, text blocks, pattern matching for instanceof, etc.
  - Java 13 Features: Introduction to Java 13 features, text blocks, switch expressions, dynamic CDS archives, etc.
  - Java 14 Features: Introduction to Java 14 features, switch expressions, text blocks, pattern matching for instanceof, records, etc.
  - Java 15 Features: Introduction to Java 15 features, text blocks, sealed classes, records, pattern matching for instanceof, etc.

- Core Java is the prerequisite for learning advanced Java topics, such as Java Enterprise Edition (Java EE) or Java Platform Enterprise Edition (Java EE), which covers web development, distributed computing, web services, etc., and Java Micro Edition (Java ME) or Java Platform Micro Edition (Java ME), which covers mobile and embedded development, etc.
