## Unit 1 - Introduction to Web Technology

- Web technology is the use of various tools and techniques to create, manage, and deliver web-based applications and services over the internet or intranet.
- Web technology consists of several components, such as web browsers, web servers, web protocols, web languages, web frameworks, web databases, web APIs, and web security.
- Web browsers are software applications that allow users to access and view web pages and web applications. Examples of web browsers are Google Chrome, Mozilla Firefox, Microsoft Edge, and Safari.
- Web servers are software applications that store and serve web pages and web applications to web browsers. Examples of web servers are Apache, Nginx, IIS, and Tomcat.
- Web protocols are rules and standards that define how web browsers and web servers communicate and exchange data. Examples of web protocols are HTTP, HTTPS, FTP, SMTP, and WebSocket.
- Web languages are programming languages that are used to create and manipulate web pages and web applications. Examples of web languages are HTML, CSS, JavaScript, PHP, Python, and Java.
- Web frameworks are software libraries that provide common functionalities and features for web development. Examples of web frameworks are Bootstrap, jQuery, Angular, Laravel, Django, and Spring.
- Web databases are software applications that store and manage data for web applications. Examples of web databases are MySQL, MongoDB, PostgreSQL, and Oracle.
- Web APIs are interfaces that allow web applications to interact with other web applications or services. Examples of web APIs are RESTful API, SOAP API, GraphQL API, and Web Service API.
- Web security is the practice of protecting web applications and data from unauthorized access, modification, or destruction. Examples of web security are encryption, authentication, authorization, and firewall.
