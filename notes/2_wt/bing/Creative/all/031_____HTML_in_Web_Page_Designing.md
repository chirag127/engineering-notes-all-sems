# HTML in Web Page Designing

- HTML stands for HyperText Markup Language  . It is used to design web pages using a markup language .
- A markup language is a set of symbols or tags that define the structure and content of a document. HTML tags are enclosed in angle brackets (< and >) and usually come in pairs, such as <p> and </p> for paragraphs .
- HTML documents consist of a head and a body section  . The head section contains information about the document, such as the title, meta tags, style sheets, and scripts  . The body section contains the actual content of the document, such as text, images, links, tables, and forms  .
- HTML documents are saved with a .html or .htm extension and can be viewed in any web browser  .
- HTML uses different tags, elements, attributes, and values to create web pages and their content  . Tags are the keywords that define the start and end of an element  . Elements are the building blocks of HTML documents that represent different types of content  . Attributes are additional information that modify the behavior or appearance of an element  . Values are the specific data that are assigned to attributes  .
- HTML elements can be nested inside other elements to create complex structures and layouts  . For example, a <div> element can contain multiple <p> elements, each representing a paragraph of text  .
- HTML elements can be classified into two categories: block-level and inline-level  . Block-level elements occupy the entire width of their parent element and start on a new line  . Examples of block-level elements are <div>, <p>, <h1>, <ul>, and <table>   . Inline-level elements occupy only the space needed by their content and do not start on a new line  . Examples of inline-level elements are <span>, <a>, <img>, <em>, and <strong>   .
- HTML elements can be styled using CSS (Cascading Style Sheets), which is a language that defines the presentation of HTML documents   . CSS can be applied to HTML elements using inline styles, internal style sheets, or external style sheets   . CSS can change the color, font, size, position, layout, and animation of HTML elements   .
- HTML elements can be made interactive using JavaScript, which is a scripting language that can manipulate the content and behavior of HTML documents  . JavaScript can be embedded in HTML documents using the <script> element or linked from external files  . JavaScript can respond to user events, such as clicks, mouse movements, keyboard inputs, and form submissions  .
- HTML is one of the most popular languages to design web pages and their content. HTML uses different tags, elements, images, and some latest components to make web pages more attractive and user-friendly. With the help of some CSS and JavaScript, the look and feel of the web page can be easily changed .
