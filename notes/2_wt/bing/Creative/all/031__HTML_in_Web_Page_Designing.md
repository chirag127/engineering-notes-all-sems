### HTML in Web Page Designing

- HTML stands for HyperText Markup Language. It is the standard language for creating web pages and web applications.
- HTML uses tags to define the structure and content of a web page. Tags are enclosed in angle brackets (< and >) and usually come in pairs, such as <p> and </p>.
- HTML tags can have attributes that provide additional information or functionality to the tags. Attributes are written inside the opening tag, after the tag name, and consist of a name and a value, separated by an equal sign (=). For example, <p style="color:red;">This is a red paragraph.</p>
- HTML elements are the building blocks of a web page. An element consists of a start tag, an end tag, and the content between them. For example, <h1>This is a heading</h1> is an element that defines a level-one heading.
- HTML elements can be nested inside other elements, creating a hierarchical structure that represents the web page. For example, <html> <head> <title>My Web Page</title> </head> <body> <h1>Welcome to my web page</h1> <p>This is a paragraph.</p> </body> </html> is a basic HTML document that has a head element and a body element, each containing other elements.
- HTML documents must start with a declaration that specifies the version and syntax of HTML. The declaration is written as <!DOCTYPE html> and should be the first line of the document.
- HTML documents must also have a root element that contains all other elements. The root element is <html> and it should be the second line of the document.
- HTML documents should have a head element that contains information about the document, such as the title, the character encoding, the style sheets, and the scripts. The head element is written as <head> and should be inside the root element.
- HTML documents should have a body element that contains the visible content of the web page, such as headings, paragraphs, images, links, forms, and tables. The body element is written as <body> and should be inside the root element, after the head element.
- HTML supports various types of elements, such as:

  - Text elements, such as headings (<h1> to <h6>), paragraphs (<p>), lists (<ul>, <ol>, and <li>), and preformatted text (<pre>).
  - Formatting elements, such as bold (<b>), italic (<i>), underline (<u>), and strike-through (<s>).
  - Semantic elements, such as emphasis (<em>), strong (<strong>), quotation (<q>), and citation (<cite>).
  - Hyperlink elements, such as anchor (<a>) and image map (<map> and <area>).
  - Image elements, such as image (<img>) and picture (<picture> and <source>).
  - Multimedia elements, such as audio (<audio> and <source>), video (<video> and <source>), and embed (<embed>).
  - Scripting elements, such as script (<script>) and noscript (<noscript>).
  - Style elements, such as style (<style>) and link (<link>).
  - Meta elements, such as meta (<meta>) and base (<base>).
  - Structural elements, such as section (<section>), article (<article>), header (<header>), footer (<footer>), and div (<div>).
  - Grouping elements, such as span (<span>) and blockquote (<blockquote>).
  - Table elements, such as table (<table>), caption (<caption>), thead (<thead>), tbody (<tbody>), tfoot (<tfoot>), tr (<tr>), th (<th>), and td (<td>).
  - Form elements, such as form (<form>), input (<input>), textarea (<textarea>), button (<button>), select (<select>), option (<option>), label (<label>), and fieldset (<fieldset>).
  - Interactive elements, such as details (<details> and <summary>), dialog (<dialog>), and menu (<menu> and <menuitem>).

- HTML supports various types of attributes, such as:

  - Global attributes, which can be applied to any element, such as id, class, style, title, and data-*.
  - Event attributes, which can be used to define event handlers for elements, such as onclick, onmouseover, and onsubmit.
  - Specific attributes, which can only be used with certain elements, such as href, src, alt, and type.
