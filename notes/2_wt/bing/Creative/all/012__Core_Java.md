### Core Java
Core Java is the basic and fundamental part of the Java programming language. It covers the essential concepts and features of Java that are required to create any Java application. Core Java includes topics such as:

- Data types, variables, operators, control statements, arrays, and strings
- Object-oriented programming principles such as classes, objects, inheritance, polymorphism, abstraction, and encapsulation
- Java methods, constructors, access modifiers, and static keyword
- Exception handling, inner classes, and multithreading
- Input/output streams, networking, and serialization
- Java collections framework, generics, and lambda expressions
- Reflection, annotations, and enums

Some of the advantages of Core Java are:

- It is simple, portable, robust, secure, and high-performance
- It supports multiple paradigms such as imperative, declarative, and functional
- It has a rich set of APIs and libraries for various tasks and domains
- It is the foundation for developing other Java technologies such as Java EE, Java ME, and Java FX

Some of the applications of Core Java are:

- Desktop applications such as media players, antivirus, editors, etc.
- Web applications such as e-commerce, banking, social media, etc.
- Enterprise applications such as ERP, CRM, SCM, etc.
- Mobile applications such as games, utilities, etc.
- Embedded systems such as smart cards, sensors, etc.

Some of the mnemonics and learning tricks for Core Java are:

- To remember the order of precedence of operators, use the acronym PEMDAS: Parentheses, Exponents, Multiplication/Division, Addition/Subtraction
- To remember the difference between checked and unchecked exceptions, use the acronym IO: Input/Output exceptions are checked, others are unchecked
- To remember the difference between abstract classes and interfaces, use the acronym CAIN: Classes can have Abstract and Implement methods, Interfaces can have only Abstract methods
- To remember the difference between overloading and overriding, use the acronym SAME: Same method name, Arguments different for overloading, Method signature same, Exceptions narrower for overriding
- To remember the difference between ArrayList and LinkedList, use the acronym RAIL: Random access is fast for ArrayList, Insertion and deletion are fast for LinkedList
