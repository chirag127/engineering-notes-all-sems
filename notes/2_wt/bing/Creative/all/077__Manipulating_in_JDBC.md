#### Manipulating in JDBC

- JDBC stands for Java Database Connectivity, which is an API for connecting and executing queries on databases.
- JDBC allows Java programs to communicate with different types of databases using a common interface.
- JDBC uses drivers to connect to specific databases. A driver is a software component that implements the JDBC API for a particular database.
- JDBC supports four types of drivers: JDBC-ODBC bridge, native-API, network-protocol, and pure Java.
- JDBC provides classes and interfaces to perform various operations on databases, such as creating connections, executing statements, retrieving results, updating data, managing transactions, and handling errors.
- Some of the main classes and interfaces in JDBC are:
  - DriverManager: This class manages the registered drivers and provides methods to get connections to databases.
  - Connection: This interface represents a connection to a database and provides methods to create statements, manage transactions, and get metadata.
  - Statement: This interface represents a SQL statement that can be executed on a database and provides methods to execute queries, update data, and get results.
  - ResultSet: This interface represents the result of a query and provides methods to access and manipulate the data.
  - PreparedStatement: This interface extends Statement and represents a precompiled SQL statement that can be executed multiple times with different parameters.
  - CallableStatement: This interface extends PreparedStatement and represents a SQL stored procedure that can be invoked from Java.
  - SQLException: This class represents an exception that occurs in JDBC and provides methods to get error information.
- To manipulate data in JDBC, the following steps are typically followed:
  - Load the driver class using Class.forName() method.
  - Get a connection to the database using DriverManager.getConnection() method.
  - Create a statement object using Connection.createStatement(), Connection.prepareStatement(), or Connection.prepareCall() method.
  - Execute the statement using Statement.execute(), Statement.executeQuery(), or Statement.executeUpdate() method.
  - Process the result using ResultSet.next(), ResultSet.getXXX(), or ResultSet.updateXXX() method.
  - Close the resources using ResultSet.close(), Statement.close(), and Connection.close() method.
- JDBC supports different types of result sets, which determine the level of functionality in terms of cursor movement, concurrency, and updatability. The types of result sets are:
  - TYPE_FORWARD_ONLY: This type allows the cursor to move only forward in the result set.
  - TYPE_SCROLL_INSENSITIVE: This type allows the cursor to move forward and backward in the result set, but does not reflect the changes made to the underlying data source.
  - TYPE_SCROLL_SENSITIVE: This type allows the cursor to move forward and backward in the result set, and reflects the changes made to the underlying data source.
- JDBC also supports different modes of concurrency, which determine how the result set can be updated. The modes of concurrency are:
  - CONCUR_READ_ONLY: This mode does not allow the result set to be updated.
  - CONCUR_UPDATABLE: This mode allows the result set to be updated using the ResultSet.updateXXX() and ResultSet.deleteRow() methods.
- JDBC allows batch updates, which means executing multiple statements in one request to the database. This can improve the performance and reduce the network traffic. To perform batch updates, the following steps are followed:
  - Create a statement object using Connection.createStatement() or Connection.prepareStatement() method.
  - Add the statements to the batch using Statement.addBatch() method.
  - Execute the batch using Statement.executeBatch() method.
  - Process the result using Statement.getUpdateCounts() method.
  - Clear the batch using Statement.clearBatch() method.
- JDBC allows inserting rows in the result set using the ResultSet.moveToInsertRow(), ResultSet.insertRow(), and ResultSet.moveToCurrentRow() methods. To insert rows in the result set, the following steps are followed:
  - Create a statement object with TYPE_SCROLL_SENSITIVE and CONCUR_UPDATABLE parameters using Connection.createStatement() method.
  - Execute a query using Statement.executeQuery() method and get a result set object.
  - Move the cursor to the insert row using ResultSet.moveToInsertRow() method.
  - Set the values for the new row using ResultSet.updateXXX() method.
  - Insert the row into the result set and the database using ResultSet.insertRow() method.
  - Move the cursor back to the current row using ResultSet.moveToCurrentRow() method.
