### Java Server Pages (JSP) in Servlets

- Java Server Pages (JSP) are a technology that allows web developers to create dynamic web pages using HTML, XML, or other document types, with embedded Java code that runs on the server side.
- JSP are similar to PHP, ASP, or other scripting languages, but they use Java as the programming language and can access the full range of Java APIs and libraries.
- JSP are compiled into servlets by a JSP compiler, which is usually part of a web server or a web container, such as Apache Tomcat, Jetty, or GlassFish.
- JSP have a special syntax that allows the developer to insert Java code snippets, called scriptlets, into the HTML or XML document. Scriptlets are enclosed by `<%` and `%>` tags, and can contain any valid Java code.
- JSP also support expressions, which are evaluated and inserted into the output stream. Expressions are enclosed by `<%=` and `%>` tags, and can contain any Java expression that returns a value, such as a variable, a method call, or an arithmetic operation.
- JSP can also use directives, which are instructions to the JSP compiler or the web container. Directives are enclosed by `<%@` and `%>` tags, and can specify the page language, the content type, the import statements, the error page, and other settings.
- JSP can also use declarations, which are used to declare variables or methods that are accessible throughout the JSP page. Declarations are enclosed by `<%!` and `%>` tags, and can contain any valid Java declaration, such as a field, a method, or a class.
- JSP can also use comments, which are ignored by the JSP compiler and the web container. Comments are enclosed by `<%--` and `--%>` tags, and can contain any text.
- JSP can also use actions, which are predefined XML tags that perform specific tasks, such as including another JSP page, forwarding the request to another resource, or creating and accessing JavaBeans. Actions are enclosed by `<jsp:` and `/>` tags, and can have attributes that specify the parameters for the action.
- JSP can also use custom tags, which are user-defined XML tags that encapsulate reusable functionality, such as validation, formatting, or database access. Custom tags are defined by tag libraries, which are collections of Java classes and XML files that implement the custom tag logic. Custom tags are enclosed by `<prefix:` and `/>` tags, where prefix is the name of the tag library.
- JSP can also use implicit objects, which are predefined variables that are automatically available in every JSP page. Implicit objects are instances of Java classes that provide access to the request, the response, the session, the application, the out, the config, the page, the pageContext, and the exception objects.
- JSP can also use scopes, which are mechanisms that control the visibility and lifetime of variables and objects in a web application. Scopes are defined by the web container, and can be page, request, session, or application scope. Page scope means that the variable or object is only accessible within the current JSP page. Request scope means that the variable or object is accessible within the current request, which may span multiple JSP pages or servlets. Session scope means that the variable or object is accessible within the current session, which may span multiple requests from the same client. Application scope means that the variable or object is accessible within the entire web application, which may span multiple sessions and clients.
- JSP can also use expression language (EL), which is a simple and powerful language that allows the developer to access and manipulate data from JavaBeans, implicit objects, and other sources. EL uses a dot (.) notation to access properties and methods of objects, and a bracket ([]) notation to access elements of arrays, lists, or maps. EL also supports arithmetic, logical, relational, and ternary operators, as well as literals, constants, and reserved words.
- JSP can also use standard tag libraries (JSTL), which are collections of custom tags that provide common functionality for web development, such as iteration, conditional, formatting, database, XML, and internationalization tags. JSTL are defined by the Java Community Process (JCP) and are part of the Java EE specification. JSTL can be used in conjunction with EL to simplify and enhance the JSP development.
