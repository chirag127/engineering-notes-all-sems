### History of Web

- The World Wide Web (WWW) is a global information medium that users can access via computers connected to the Internet.
- The Web is not the same as the Internet, which is a network of interconnected computers that can communicate using various protocols.
- The Web uses a protocol called HyperText Transfer Protocol (HTTP) to exchange information between servers and clients (such as web browsers).
- The Web also uses a document formatting language called HyperText Markup Language (HTML) to define the structure and content of web pages.
- The Web was invented by Tim Berners-Lee, a British scientist working at CERN, a European research organization, in 1989.
- Berners-Lee proposed a "universal linked information system" that would allow scientists to share and access data across different platforms and locations.
- He developed the first web server, the first web browser, and the first web page, which described the project and provided links to other resources.
- He released the browser source code for public use in 1993, which led to the development of many other web browsers, such as Mosaic, Netscape Navigator, and Internet Explorer.
- The Web became popular among the general public in the mid-1990s, as more websites emerged that offered various services, such as e-commerce, entertainment, education, and social media.
- The Web also evolved in terms of features and functionality, with the introduction of new technologies, such as Cascading Style Sheets (CSS), JavaScript, AJAX, and HTML5, which enhanced the design, interactivity, and multimedia capabilities of web pages.
- The Web is now a ubiquitous and essential part of modern life, as it enables people to access and create information, communicate and collaborate, and participate in various social and economic activities.
