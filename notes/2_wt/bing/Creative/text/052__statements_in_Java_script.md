#### Statements in JavaScript

- Statements are programming instructions written in a program.
- Statements are composed of values, expressions, operators, comments, and keywords.
- Statements are separated by semicolons (;) and can span multiple lines or be on the same line.
- Statements control the flow of a program and specify what actions to perform.
- Statements can be grouped together in code blocks, inside curly brackets {...}.
- Statements can start with a keyword to identify the JavaScript action to be performed, such as `var`, `let`, `const`, `function`, `if`, `for`, `return`, etc.
- Statements can also be empty, which means they provide no statement, although the JavaScript syntax would expect one.
