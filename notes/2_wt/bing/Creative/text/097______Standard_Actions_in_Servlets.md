#### Standard Actions in Servlets

- Standard actions are predefined tags that perform some common tasks in JSP pages.
- They have the syntax `<jsp:action_name attribute="value" />` where `action_name` is the name of the standard action and `attribute` is a parameter that modifies the behavior of the action.
- Some of the standard actions are:

  - `<jsp:include>`: This action includes the content of another resource (such as a JSP page, an HTML file, or a servlet) at the time of request processing. It has two attributes: `page` and `flush`. The `page` attribute specifies the relative URL of the resource to be included, and the `flush` attribute indicates whether the output buffer should be flushed before including the resource. The default value of `flush` is `false`.
  - `<jsp:forward>`: This action forwards the request to another resource (such as a JSP page, an HTML file, or a servlet) for further processing. It has one attribute: `page`. The `page` attribute specifies the relative URL of the resource to be forwarded to. The `<jsp:forward>` action terminates the current JSP page and discards any output generated so far.
  - `<jsp:param>`: This action adds a parameter to the query string of the request. It is used inside the `<jsp:include>` or `<jsp:forward>` actions to pass additional information to the included or forwarded resource. It has two attributes: `name` and `value`. The `name` attribute specifies the name of the parameter, and the `value` attribute specifies the value of the parameter.
  - `<jsp:plugin>`: This action generates the necessary HTML code to invoke a Java applet or a JavaBean component in the browser. It has two attributes: `type` and `code`. The `type` attribute specifies whether the plugin is an applet or a bean, and the `code` attribute specifies the name of the class file or the JAR file that contains the plugin. The `<jsp:plugin>` action also supports nested `<jsp:params>` actions to pass parameters to the plugin.
  - `<jsp:useBean>`: This action creates or locates a JavaBean component and associates it with a scripting variable. It has three attributes: `id`, `class`, and `scope`. The `id` attribute specifies the name of the scripting variable, the `class` attribute specifies the fully qualified name of the JavaBean class, and the `scope` attribute specifies the visibility of the bean. The possible values of `scope` are `page`, `request`, `session`, or `application`. The `<jsp:useBean>` action also supports nested `<jsp:setProperty>` and `<jsp:getProperty>` actions to set and get the properties of the bean.
  - `<jsp:setProperty>`: This action sets the value of a property of a JavaBean component. It has three attributes: `name`, `property`, and `value`. The `name` attribute specifies the name of the scripting variable that refers to the bean, the `property` attribute specifies the name of the property to be set, and the `value` attribute specifies the value of the property. Alternatively, the `value` attribute can be replaced by a nested `<jsp:param>` action to set the property value from a request parameter.
  - `<jsp:getProperty>`: This action gets the value of a property of a JavaBean component and writes it to the output stream. It has two attributes: `name` and `property`. The `name` attribute specifies the name of the scripting variable that refers to the bean, and the `property` attribute specifies the name of the property to be retrieved.
