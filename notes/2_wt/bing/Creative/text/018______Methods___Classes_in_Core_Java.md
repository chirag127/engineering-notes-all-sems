#### Methods & Classes in Core Java

- A method is a block of code that performs a specific task. A method can be invoked or called by another method, by an object, or by itself.
- A class is a blueprint or template for creating objects. A class defines the attributes and behaviors of the objects of that type.
- A class can have one or more methods that define the actions or operations that the objects of that class can perform.
- A method can have zero or more parameters that specify the input values for the method. A method can also have a return type that specifies the output value of the method.
- A method can be declared as static or non-static. A static method belongs to the class and can be called without creating an object of the class. A non-static method belongs to the object and can be called only by using an object of the class.
- A method can be declared as public, private, protected, or default. These are called access modifiers and they determine the visibility or accessibility of the method from other classes or methods.
- A method can be declared as final, abstract, or synchronized. These are called non-access modifiers and they provide additional information or functionality to the method.
- A method can be overloaded or overridden. Method overloading means defining multiple methods with the same name but different parameters. Method overriding means redefining a method in a subclass that was already defined in a superclass.
- A class can be declared as public, private, protected, or default. These are also access modifiers and they determine the visibility or accessibility of the class from other classes or packages.
- A class can be declared as final, abstract, or interface. These are also non-access modifiers and they provide additional information or functionality to the class.
- A class can be inherited or extended by another class. This means that the subclass inherits or acquires all the attributes and behaviors of the superclass, and can also add its own attributes and behaviors.
- A class can implement one or more interfaces. An interface is a collection of abstract methods that a class must implement. An interface defines a contract or a specification for the class that implements it.
- A class can have one or more constructors that are used to initialize the objects of the class. A constructor has the same name as the class and does not have a return type.
- A class can have one or more fields or variables that store the state or data of the objects of the class. A field can be declared as static or non-static, and as public, private, protected, or default. A field can also be declared as final, transient, or volatile. These are also non-access modifiers and they provide additional information or functionality to the field.
