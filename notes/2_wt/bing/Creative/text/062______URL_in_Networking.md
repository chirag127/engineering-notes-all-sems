#### URL in Networking

- A URL (Uniform Resource Locator) is a string of characters that identifies a resource on the Internet and provides a way to locate it.
- A URL consists of several components, such as the scheme, the authority, the path, the query, and the fragment.
- The scheme specifies the protocol used to access the resource, such as http, https, ftp, mailto, etc.
- The authority identifies the host name and the port number of the server that hosts the resource, such as www.example.com:80, user@host.com, etc.
- The path specifies the location of the resource on the server, such as /index.html, /images/logo.png, etc.
- The query is an optional part that contains additional information or parameters for the resource, such as ?q=keyword, ?page=2, etc. The query is separated from the path by a question mark (?).
- The fragment is an optional part that identifies a specific part of the resource, such as #section1, #top, etc. The fragment is separated from the rest of the URL by a hash sign (#).
- A URL can be absolute or relative. An absolute URL contains all the components and starts with the scheme. A relative URL omits some components and is interpreted based on the context of the base URL.
- A URL can be encoded or decoded to handle special characters or spaces. The encoding process replaces some characters with a percent sign (%) followed by two hexadecimal digits that represent the ASCII code of the character. The decoding process reverses the encoding process and restores the original characters.
- A URL can be normalized or canonicalized to remove any ambiguity or redundancy. The normalization process applies some rules to simplify or standardize the URL, such as converting the scheme and the host name to lower case, removing the default port number, removing dot-segments from the path, etc.
