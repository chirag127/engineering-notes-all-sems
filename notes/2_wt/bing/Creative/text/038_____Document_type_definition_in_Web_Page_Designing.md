### Document type definition in Web Page Designing

- A document type definition (DTD) is an instruction that tells the web browser about the markup language in which the current page is written.
- A DTD defines the structure and the legal elements and attributes of an XML document.
- A DTD can be declared inside an XML document as internal or as an external reference.
- A DTD helps to ensure that the web page is parsed the same way by different web browsers and that the XML data is valid.
- A DTD can also be used to agree on a standard format for interchanging data between independent groups of people.
- A DTD is not mandatory for HTML documents, but it is recommended to use one to avoid rendering mode differences.
- A DTD is part of the Document interface, which represents any web page loaded in the browser and serves as an entry point into the web page's content, which is the DOM tree.
