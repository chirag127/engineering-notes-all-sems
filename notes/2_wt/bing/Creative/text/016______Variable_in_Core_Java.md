#### Variable in Core Java

- A variable is a named memory location that can store a value of a specific data type.
- Variables are used to store data and manipulate it during the execution of a program.
- Variables have three main characteristics: name, type and value.
- The name of a variable is an identifier that follows the naming rules and conventions of Java.
- The type of a variable determines the range of values that it can store and the operations that can be performed on it.
- The value of a variable is the data that is stored in the memory location associated with the variable name.
- Variables can be classified into two categories: primitive and reference.
- Primitive variables store the basic data types such as int, char, boolean, etc.
- Reference variables store the addresses of objects or arrays that are created dynamically in the heap memory.
- Variables can also be categorized based on their scope and lifetime: local, instance and static.
- Local variables are declared inside a method or a block and are accessible only within that method or block. They are created when the method or block is entered and destroyed when it is exited.
- Instance variables are declared inside a class but outside any method or block and are associated with each object of the class. They are created when the object is instantiated and destroyed when the object is garbage collected.
- Static variables are declared inside a class but outside any method or block and are associated with the class itself. They are created when the class is loaded and destroyed when the class is unloaded. They are shared by all the objects of the class.
