#### Operator in Core Java

Operators in Core Java are symbols that are used to perform operations on variables and values. They can be classified into the following categories:

- Arithmetic operators: They are used to perform common mathematical operations such as addition, subtraction, multiplication, division and modulo. For example, `x + y`, `x - y`, `x * y`, `x / y`, `x % y`.
- Unary operators: They are used to perform operations on a single operand. They include unary minus, unary plus, increment, decrement and logical not. For example, `-x`, `+x`, `++x`, `--x`, `!x`.
- Assignment operators: They are used to assign values to variables. They include the simple assignment operator (`=`) and the compound assignment operators (`+=`, `-=`, `*=`, `/=`, `%=`, `&=`, `|=`, `^=`, `>>=`, `<<=`). For example, `x = 10`, `x += 5`, `x -= 3`, `x *= 2`, `x /= 4`, `x %= 2`, `x &= 1`, `x |= 2`, `x ^= 3`, `x >>= 2`, `x <<= 2`.
- Relational operators: They are used to compare two operands and return a boolean value. They include equal to, not equal to, greater than, less than, greater than or equal to, less than or equal to. For example, `x == y`, `x != y`, `x > y`, `x < y`, `x >= y`, `x <= y`.
- Logical operators: They are used to combine two or more boolean expressions and return a boolean value. They include logical and, logical or, logical xor. For example, `x && y`, `x || y`, `x ^ y`.
- Ternary operator: It is a conditional operator that takes three operands and returns a value based on a condition. It has the form `condition ? value1 : value2`. For example, `x > y ? x : y`.
- Bitwise operators: They are used to perform operations on individual bits of integers. They include bitwise and, bitwise or, bitwise xor, bitwise complement, left shift, right shift, unsigned right shift. For example, `x & y`, `x | y`, `x ^ y`, `~x`, `x << n`, `x >> n`, `x >>> n`.
- Instanceof operator: It is used to check if an object is an instance of a specific class or interface. It has the form `object instanceof type`. For example, `str instanceof String`.
