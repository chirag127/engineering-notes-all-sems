#### Arrays in Core Java

- An array is a data structure that can store a fixed number of elements of the same type in a contiguous memory location.
- An array can be declared by specifying the type of its elements, followed by square brackets, and optionally an expression that determines the size of the array. For example, `int[] numbers = new int[10];` declares an array of 10 integers.
- An array can also be initialized by specifying the values of its elements in curly braces, separated by commas. For example, `String[] names = {"Alice", "Bob", "Charlie"};` initializes an array of 3 strings.
- An array element can be accessed by using its index, which is an integer value that starts from 0 and goes up to the length of the array minus one. For example, `names[0]` returns the first element of the array, which is "Alice".
- An array can be iterated over by using a for loop, a for-each loop, or a while loop. For example, `for (String name : names) { System.out.println(name); }` prints each element of the array on a new line.
- An array can be passed as an argument to a method, or returned as a result from a method. For example, `public static int sum(int[] numbers) { int total = 0; for (int num : numbers) { total += num; } return total; }` defines a method that takes an array of integers as a parameter and returns the sum of its elements.
- An array can be multidimensional, which means that it can have more than one dimension, or an array of arrays. For example, `int[][] matrix = {{1, 2, 3}, {4, 5, 6}, {7, 8, 9}};` declares a two-dimensional array of integers, or a 3 by 3 matrix.
- A multidimensional array can be accessed by using multiple indices, one for each dimension. For example, `matrix[1][2]` returns the element at the second row and the third column of the matrix, which is 6.
- A multidimensional array can also be iterated over by using nested loops, one for each dimension. For example, `for (int i = 0; i < matrix.length; i++) { for (int j = 0; j < matrix[i].length; j++) { System.out.print(matrix[i][j] + " "); } System.out.println(); }` prints each element of the matrix in a tabular format.
- A multidimensional array can be passed as an argument to a method, or returned as a result from a method, just like a one-dimensional array. For example, `public static int[][] transpose(int[][] matrix) { int[][] result = new int[matrix[0].length][matrix.length]; for (int i = 0; i < matrix.length; i++) { for (int j = 0; j < matrix[i].length; j++) { result[j][i] = matrix[i][j]; } } return result; }` defines a method that takes a two-dimensional array of integers as a parameter and returns its transpose, which is a matrix with the rows and columns swapped.
