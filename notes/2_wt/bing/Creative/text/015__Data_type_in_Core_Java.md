#### Data type in Core Java

A data type is a classification of data that specifies the type, size, and range of values that a variable can store or an expression can produce. Data types are important for ensuring the correctness and efficiency of a program.

There are two types of data types in Java:

- Primitive data types: These are the basic data types that are predefined by the Java language and are named by reserved keywords. They are:

  - byte: An 8-bit signed integer that can store values from -128 to 127.
  - short: A 16-bit signed integer that can store values from -32,768 to 32,767.
  - int: A 32-bit signed integer that can store values from -2,147,483,648 to 2,147,483,647. It can also be used to represent an unsigned 32-bit integer in Java SE 8 and later.
  - long: A 64-bit signed integer that can store values from -9,223,372,036,854,775,808 to 9,223,372,036,854,775,807. It can also be used to represent an unsigned 64-bit integer in Java SE 8 and later.
  - float: A 32-bit floating-point number that can store fractional values up to 6 to 7 decimal digits.
  - double: A 64-bit floating-point number that can store fractional values up to 15 decimal digits.
  - char: A 16-bit Unicode character that can store any single character or ASCII value.
  - boolean: A 1-bit value that can store either true or false.

- Non-primitive data types: These are the data types that are defined by the programmer or the Java API and are named by identifiers. They are:

  - Class: A blueprint for creating objects that have state (fields) and behavior (methods).
  - Interface: A contract for implementing classes that specify the methods they must provide.
  - Array: A collection of elements of the same data type that are stored in contiguous memory locations and accessed by index.
  - String: A sequence of characters that is immutable and can be manipulated using various methods.
  - Enum: A special type of class that defines a set of constants that can be used as values for a variable.
  - Annotation: A special type of interface that provides metadata for classes, methods, fields, parameters, etc.
