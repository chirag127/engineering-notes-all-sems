#### AWT controls

- AWT controls are components that allow a user to interact with the graphical user interface (GUI) in various ways .
- AWT controls are platform-dependent, meaning they are displayed according to the view of the operating system.
- AWT controls are heavy-weight, meaning they use the resources of the underlying operating system.
- AWT controls are defined in the `java.awt` package, which provides classes for various types of controls, such as `TextField`, `Label`, `TextArea`, `RadioButton`, `CheckBox`, `Choice`, `List`, etc .
- AWT controls are organized in a hierarchy of classes, where the `Component` class is the root of all controls.
- AWT controls can be added to a container, which is a component that can contain other components and control their layout.
- AWT controls can implement various interfaces, such as `Adjustable`, `ItemSelectable`, `Composite`, `Paint`, `Stroke`, etc., to provide different functionalities.
- AWT controls can respond to various types of events, such as `ActionEvent`, `ItemEvent`, `KeyEvent`, `MouseEvent`, etc., by registering listeners or using adapters .
