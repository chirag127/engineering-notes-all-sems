### DTD in Web Page Designing

- DTD stands for Document Type Definition. It defines the structure and the legal elements and attributes of an XML document.
- A DTD can be declared inside the XML document using the <!DOCTYPE> definition, or in an external file that is referenced by the XML document.
- A DTD can also be used to declare special characters or strings, called entities, that can be used in the XML document.
- A DTD is useful for validating the XML data and ensuring that it conforms to a standard format that can be interchanged between different groups of people.
- In HTML, the DOCTYPE declaration is an instruction to the web browser about what version of HTML the page is written in. This ensures that the web page is parsed the same way by different web browsers .
- In HTML 4.01, the DOCTYPE declaration refers to a DTD that specifies the rules for the markup language. There are three types of DTDs in HTML 4.01: Strict, Transitional, and Frameset .
- In HTML5, the DOCTYPE declaration is much simpler and does not refer to a DTD. It is just <!DOCTYPE html> and it tells the browser to render the page in standards mode .
