#### Java Applet in Core Java

- A Java applet is a small application written in the Java programming language, or another programming language that compiles to Java bytecode, and delivered to users in the form of Java bytecode .
- A Java applet can be embedded in a web page using the `<applet>` tag (deprecated in HTML5) or the `<object>` or `<embed>` tags, and executed by a Java-compatible web browser that has a Java virtual machine (JVM) installed  .
- A Java applet can provide interactive features to web applications that cannot be provided by HTML alone, such as capturing mouse input, displaying graphics, playing sounds, or accessing hardware acceleration  .
- A Java applet can communicate with the web server, the web browser, and other applets running on the same or different web pages, using various mechanisms such as parameters, sockets, remote method invocation (RMI), or Java Database Connectivity (JDBC)  .
- A Java applet runs in a separate process from the web browser, and has a restricted access to the local file system, network, and system resources, to prevent malicious actions  .
- A Java applet can be digitally signed to request additional permissions from the user, such as reading and writing local files, or executing external programs  .
- A Java applet is deprecated by Java 9 in 2017, and is no longer supported by most web browsers, due to security issues, performance limitations, and the popularity of other web technologies such as JavaScript, HTML5, and WebGL      .
