## Unit 1 - Introduction to Web Technology

- Web technology is the use of various tools and protocols to create, store, transmit, and display information on the World Wide Web (WWW).
- The WWW is a global network of interconnected documents, or web pages, that are accessed through web browsers and hyperlinks.
- Web pages are composed of different elements, such as text, images, videos, audio, and interactive features, that are formatted using a markup language, such as HTML (Hypertext Markup Language).
- Web pages can also include dynamic content, such as animations, forms, and user interactions, that are generated using scripting languages, such as JavaScript, or server-side technologies, such as PHP (Hypertext Preprocessor).
- Web pages are identified by unique addresses, called URLs (Uniform Resource Locators), that specify the location and name of the resource on the web server.
- Web servers are computers that store and deliver web pages to web browsers, using a protocol, such as HTTP (Hypertext Transfer Protocol).
- Web browsers are software applications that allow users to view and navigate web pages, using a graphical user interface (GUI) or a command-line interface (CLI).
- Web browsers can also support additional features, such as bookmarks, history, tabs, extensions, and plugins, that enhance the user experience and functionality of the web.
- Web technology is constantly evolving and improving, with new standards, tools, and frameworks being developed and adopted by the web community. Some of the current trends and challenges in web technology are:

  - Responsive web design: the ability to adapt the layout and content of web pages to different screen sizes and devices, such as desktops, laptops, tablets, and smartphones.
  - Web accessibility: the practice of ensuring that web pages are usable and understandable by people with different abilities and preferences, such as visual, auditory, motor, or cognitive impairments.
  - Web security: the protection of web pages and data from unauthorized access, modification, or destruction, by using encryption, authentication, authorization, and other techniques.
  - Web performance: the optimization of web pages and resources to reduce the loading time and bandwidth consumption, by using compression, caching, minification, and other techniques.
  - Web development: the process of designing, creating, testing, and maintaining web pages and applications, by using various tools, languages, and frameworks, such as HTML, CSS, JavaScript, Bootstrap, jQuery, Angular, React, Node.js, and many more.
