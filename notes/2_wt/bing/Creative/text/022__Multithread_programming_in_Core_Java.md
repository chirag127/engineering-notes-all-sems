#### Multithread programming in Core Java

- Multithreading is a programming concept that allows a program to execute multiple tasks concurrently, or in parallel.
- A thread is a lightweight sub-process that can run independently within a process. A process can have multiple threads that share the same memory space and resources.
- In Java, every program has at least one thread, called the main thread, which is created by the Java Virtual Machine (JVM) when the program starts. The main thread can create other threads, called child threads, to perform specific tasks.
- To create a thread in Java, there are two ways:
  - Extend the `java.lang.Thread` class and override the `run()` method. The `run()` method contains the code that the thread will execute.
  - Implement the `java.lang.Runnable` interface and provide an implementation for the `run()` method. Then, create an instance of the `Thread` class and pass the `Runnable` object as a parameter to the constructor.
- To start a thread, call the `start()` method on the `Thread` object. This will invoke the `run()` method in a separate thread of execution.
- To control the execution of threads, the `Thread` class provides some methods, such as:
  - `sleep(long millis)`: Causes the current thread to pause for the specified number of milliseconds.
  - `join()`: Causes the current thread to wait until another thread terminates.
  - `interrupt()`: Interrupts a thread that is waiting, sleeping, or otherwise blocked.
  - `isAlive()`: Returns true if the thread is still running, false otherwise.
  - `setPriority(int priority)`: Sets the priority of the thread, which affects the scheduling of the thread by the JVM. The priority can range from 1 (lowest) to 10 (highest).
  - `setName(String name)`: Sets the name of the thread, which can be useful for debugging purposes.
  - `getState()`: Returns the current state of the thread, which can be one of the following: NEW, RUNNABLE, BLOCKED, WAITING, TIMED_WAITING, or TERMINATED.
- To synchronize the access of shared resources among multiple threads, Java provides some mechanisms, such as:
  - The `synchronized` keyword: It can be used to mark a block of code or a method as synchronized, which means that only one thread can execute it at a time. The thread that enters the synchronized block or method acquires a lock on the object that is used as a monitor, and releases the lock when it exits the block or method.
  - The `volatile` keyword: It can be used to mark a variable as volatile, which means that its value will be always read from and written to the main memory, and not cached by any thread. This ensures that the variable is always visible to all threads and prevents memory inconsistency errors.
  - The `wait()`, `notify()`, and `notifyAll()` methods: They can be used to coordinate the communication between threads that are waiting for a condition to be satisfied. The `wait()` method causes the current thread to release the lock on the monitor object and wait until another thread calls `notify()` or `notifyAll()` on the same object. The `notify()` method wakes up one thread that is waiting on the monitor object, and the `notifyAll()` method wakes up all threads that are waiting on the monitor object. These methods can only be called from within a synchronized block or method.
