#### Statements in JavaScript

- Statements are programming instructions written in a program .
- Statements are composed of values, expressions, operators, comments, and keywords.
- Statements are separated by semicolons (;) in JavaScript.
- Statements control the flow of a program and specify what scripts will do and how they will do it.
- There are different types of statements in JavaScript, such as conditional statements, loop statements, function declarations, variable declarations, etc .
- Conditional statements are used to perform different actions based on different conditions, such as if, else, switch, etc.
- Loop statements are used to execute a block of code repeatedly until a certain condition is met, such as for, while, do...while, etc.
- Function declarations are used to define a function that can be called later in the program, such as function, return, etc.
- Variable declarations are used to declare and initialize variables that can store data, such as var, let, const, etc.
