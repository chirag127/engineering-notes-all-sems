### Protocols Governing Web

- Protocols are a set of rules that govern the communication and exchange of data over the internet. Both the sender and receiver should follow the same protocols in order to communicate the data.
- Protocols are needed to manage the flow control, access control, error control, and security of data transmission over the internet.
- The most common protocols used on the web are:
  - TCP/IP (Transmission Control Protocol/Internet Protocol): These are a set of standard rules that allow different types of computers to communicate with each other. The IP protocol ensures that each computer that is connected to the Internet has a specific serial number called the IP address. TCP specifies how data is exchanged over the internet and how it should be broken into IP packets. It also makes sure that the packets have information about the source and destination of the data, the sequence in which the data should be re-assembled, and checks if the data has been sent correctly to the specific destination. The TCP is also known as a connection-oriented protocol .
  - HTTP (HyperText Transfer Protocol): This protocol is used to request and transfer webpages and other resources over the internet. HTTP defines the format and structure of the messages exchanged between the web browser and the web server. HTTP also supports different methods of data transfer, such as GET, POST, PUT, DELETE, etc. HTTP can also use TLS (Transport Layer Security) protocol to serve the webpages over a secure, encrypted connection.
  - DNS (Domain Name System): This protocol is used to convert a domain name, such as www.google.com, into an IP address, such as 172.217.160.78. DNS is a hierarchical and distributed naming system that maps domain names to IP addresses and vice versa. DNS also provides other information about the domain, such as its mail servers, name servers, etc. DNS is essential for the functioning of the web, as it allows users to access websites using human-readable names instead of numerical addresses.
  - SMTP (Simple Mail Transfer Protocol): This protocol is used to send and distribute outgoing emails over the internet. SMTP defines the format and structure of the email messages and the commands used to transfer them between the mail servers and the mail clients. SMTP also supports different types of email addresses, such as local, global, and aliases. SMTP can also use TLS protocol to secure the email communication.
  - FTP (File Transfer Protocol): This protocol is used to transfer files between two computers over the internet. FTP allows users to upload and download files from a remote server using a FTP client program. FTP also supports different modes of data transfer, such as binary, ASCII, and image. FTP can also use TLS protocol to encrypt the file transfer.
