Data type in Core Java is an attribute of a variable that specifies the type and size of the value it can store. There are two types of data types in Java: primitive and non-primitive. Primitive data types are the basic types that represent raw values such as numbers, characters and boolean values. Non-primitive data types are the complex types that are derived from primitive types or defined by the programmer, such as classes, interfaces and arrays.
