CSS stands for Cascading Style Sheets. It is a language that is used to style and format the layout of web pages that contain HTML elements. With CSS, you can control various aspects of the presentation of a web page, such as the color, font, size, spacing, position, and layout of the elements, as well as the background images, colors, and displays for different devices and screen sizes .

CSS can be applied to HTML elements in three different ways: inline, internal, and external.

- Inline CSS: The style attribute is used to apply CSS directly to a specific HTML element. This method is not recommended as it makes the HTML code messy and hard to maintain.
- Internal CSS: The `<style>` element is used to define CSS rules inside the `<head>` section of an HTML document. This method is useful for applying CSS to a single web page, but it still mixes the presentation with the structure of the document.
- External CSS: The `<link>` element is used to link an external CSS file to an HTML document. This method is the most preferred as it separates the presentation from the structure of the document, and allows the same CSS file to be reused for multiple web pages.
