A table in web page designing is a structured set of data made up of rows and columns. A table allows you to quickly and easily arrange and present data on a web page. A table in HTML consists of table cells inside rows and columns. Each table cell is defined by a <td> and a </td> tag. Each table row starts with a <tr> and ends with a </tr> tag. Sometimes you want your cells to be table header cells. In those cases use the <th> tag instead of the <td> tag.

To draw a table in web page designing, you can use the HTML tags mentioned above, or you can use a tool like the Draw Table feature in Microsoft Word. To use the Draw Table feature, you can follow these steps:

- Go to the Insert tab and click the Table drop-down arrow.
- Select Draw Table. You’ll see your cursor change to a pencil icon.
- Drag to draw the outline of the table first.
- Draw horizontal and vertical lines inside the outline to create the rows and columns.
- To erase a line, click the Eraser button on the Table Tools Layout tab and drag over the line.
- To add text to a cell, click inside the cell and type.
- To format the table, use the options on the Table Tools Design and Layout tabs.
