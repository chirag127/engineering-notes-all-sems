## Unit 3 - Scripting

Scripting is a type of programming that uses a high-level language to automate tasks, manipulate data, or create dynamic web pages. Scripting languages are usually interpreted, meaning they are translated into machine code at run time, rather than compiled beforehand. Scripting languages are often designed for specific domains or platforms, such as web scripting, shell scripting, or game scripting.

The following diagram shows the general process of scripting:

```
+-----------------+      +-----------------+      +-----------------+
|                 |      |                 |      |                 |
|  Script source  |----->|  Script engine  |----->|  Script output  |
|                 |      |                 |      |                 |
+-----------------+      +-----------------+      +-----------------+
```

- Script source: This is the code written by the programmer in a scripting language, such as Python, JavaScript, or Perl. The script source can be stored in a file, entered in a command line, or embedded in another document, such as HTML.
- Script engine: This is the program that interprets the script source and executes it. The script engine can be a standalone application, a library, or a component of another program, such as a web browser or a game engine. The script engine may also provide access to other resources, such as files, databases, or network connections.
- Script output: This is the result of running the script, which can be displayed on the screen, saved to a file, sent to another program, or used to modify the state of the system. The script output can be text, graphics, audio, or any other type of data.
