#### I/O in Core Java

- I/O stands for input/output, which refers to the process of reading and writing data from and to various sources and destinations, such as files, network, console, etc.
- Core Java provides a rich set of classes and interfaces in the `java.io` package to handle different types of I/O operations.
- The main concepts and components of I/O in Core Java are:

  - Streams: A stream is an abstract representation of a sequence of bytes that can be read from or written to a source or destination. Streams can be categorized into two types: input streams and output streams. Input streams are used to read data from a source, while output streams are used to write data to a destination.
  - Readers and Writers: Readers and writers are subclasses of streams that deal with character data, rather than byte data. Readers are used to read characters from a source, while writers are used to write characters to a destination. Readers and writers are useful for handling text data, such as plain text files, XML files, etc.
  - Buffers: Buffers are temporary storage areas that can improve the performance and efficiency of I/O operations. Buffers can be used to store data in memory before writing it to a destination, or to store data in memory after reading it from a source. Buffered streams, readers, and writers are classes that use buffers to enhance I/O operations.
  - Channels and Selectors: Channels and selectors are advanced features of I/O in Core Java that allow for non-blocking and multiplexed I/O operations. Channels are similar to streams, but they can be used for both input and output, and they can be operated in non-blocking mode, which means that they do not block the current thread while performing I/O operations. Selectors are objects that can monitor multiple channels and notify the current thread when a channel is ready for I/O operation.
  - Serialization: Serialization is the process of converting an object into a stream of bytes that can be written to a destination, such as a file or a network socket. Deserialization is the reverse process of converting a stream of bytes into an object that can be read from a source. Serialization and deserialization are useful for transferring objects between different Java applications or platforms. Core Java provides the `java.io.Serializable` interface and the `java.io.ObjectInputStream` and `java.io.ObjectOutputStream` classes to support serialization and deserialization of objects.
