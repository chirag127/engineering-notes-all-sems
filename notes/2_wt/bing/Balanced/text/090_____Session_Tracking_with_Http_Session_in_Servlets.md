### Session Tracking with Http Session in Servlets

- Session tracking is a mechanism to maintain the state of a user across multiple requests.
- Http session is one of the techniques to implement session tracking in servlets.
- Http session is an object that represents a unique session between a client and a server.
- Http session is created by the server and assigned to the client when the client makes the first request to the server.
- Http session is identified by a session ID, which is a unique string generated by the server and sent to the client as a cookie or a URL parameter.
- Http session can store attributes, which are key-value pairs of data that can be accessed by the servlets within the same session.
- Http session has a timeout period, which is the maximum time interval between two consecutive requests from the same client. If the timeout period expires, the session is invalidated and the attributes are removed.
- Http session can be manipulated by the servlets using the methods of the HttpSession interface, such as:
  - `getSession()`: returns the current session or creates a new one if none exists.
  - `getId()`: returns the session ID of the current session.
  - `getAttribute(String name)`: returns the value of the attribute with the given name, or null if not found.
  - `setAttribute(String name, Object value)`: sets the value of the attribute with the given name, or creates a new one if not found.
  - `removeAttribute(String name)`: removes the attribute with the given name, if any.
  - `invalidate()`: invalidates the current session and removes all the attributes.
  - `isNew()`: returns true if the current session is newly created, or false otherwise.
- Http session can be configured by the web application using the `<session-config>` element in the web.xml file, such as:
  - `<session-timeout>`: specifies the timeout period in minutes for the sessions.
  - `<cookie-config>`: specifies the properties of the session cookie, such as name, domain, path, secure, and http-only.
  - `<tracking-mode>`: specifies the mode of session tracking, such as cookie, url, or ssl.
