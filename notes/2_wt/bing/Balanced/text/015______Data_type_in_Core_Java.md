#### Data type in Core Java

- A data type specifies the type of value a variable can store or the type of an expression in a Java program.
- Java is a strongly typed language, which means that every variable must have a declared data type before it can be used.
- Data types in Java are divided into two groups: primitive and non-primitive   .
- Primitive data types are the basic types of data that are built-in to the Java language. They are not objects and have no methods .
- There are eight primitive data types in Java: byte, short, int, long, char, float, double, and boolean     .
- Each primitive data type has a fixed size and range of values that it can store.
- Non-primitive data types are user-defined types that are based on classes, interfaces, and arrays  .
- Non-primitive data types are also called reference types because they store references to objects in memory, not the actual values.
- Non-primitive data types can have methods and attributes that define their behavior and state.
- Non-primitive data types can be null, which means they do not point to any object in memory.
