#### Objects in JavaScript

- An object is a collection of properties that store values and functions that perform actions.
- An object can be created using an object literal, which is a pair of curly braces `{}` that enclose a list of property names and values separated by commas.
- An object can also be created using an object constructor, which is a function that defines the properties and methods of the object and returns a new instance of the object.
- An object can be accessed and modified using dot notation `object.property` or bracket notation `object['property']`.
- An object can inherit properties and methods from another object using prototypal inheritance, which is a mechanism that links objects together using the `prototype` property.
- An object can be tested for the presence of a property using the `hasOwnProperty` method or the `in` operator.
- An object can be iterated over using a `for...in` loop, which enumerates the names of the properties in the object.
- An object can be converted to a string using the `toString` method or the `JSON.stringify` function.
