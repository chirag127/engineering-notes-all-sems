#### AWT controls

- AWT stands for Abstract Window Toolkit, which is a set of APIs for creating graphical user interfaces (GUIs) in Java.
- AWT controls are components that allow a user to interact with the GUI in various ways, such as entering text, selecting options, clicking buttons, etc.
- AWT controls are also called heavyweight components, because they rely on the native operating system (OS) for their appearance and functionality.
- The java.awt package contains the classes and interfaces for AWT controls, such as Label, Button, Checkbox, Choice, List, Scrollbar, TextField, TextArea, etc .
- AWT controls can be added to containers, such as Frame, Panel, or Dialog, which are also components that can hold other components.
- AWT controls can be arranged in different layouts, such as FlowLayout, BorderLayout, GridLayout, etc, which are classes that implement the LayoutManager interface.
- AWT controls can respond to user events, such as mouse clicks, keyboard inputs, etc, by registering listeners, which are objects that implement the EventListener interface.
- AWT controls can be customized by setting their properties, such as size, color, font, text, etc, using their methods, such as setSize, setBackground, setFont, setText, etc .
- AWT controls can be inherited and extended to create new components with additional features or behaviors.
