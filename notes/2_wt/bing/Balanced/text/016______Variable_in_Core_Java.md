#### Variable in Core Java

- A variable is a name given to a memory location that stores a value of a specific data type in a program.
- Variables are used to store, manipulate, and retrieve data in a program.
- Variables have three main characteristics: name, type, and value.
- The name of a variable is an identifier that follows the naming rules and conventions of Java.
- The type of a variable determines the range of values that it can store and the operations that can be performed on it.
- The value of a variable is the data that is stored in the memory location associated with the variable name.
- Variables can be classified into two categories: primitive and reference.
- Primitive variables store the values of primitive data types, such as int, char, boolean, etc.
- Reference variables store the references or addresses of objects, such as arrays, strings, classes, etc.
- Variables can also be categorized based on their scope and lifetime, such as local, instance, and static variables.
- Local variables are declared and used within a method or a block of code. They are created when the method or block is executed and destroyed when the method or block exits. They are not accessible outside the method or block where they are declared.
- Instance variables are declared within a class but outside any method or block. They are created when an object of the class is instantiated and destroyed when the object is garbage collected. They are accessible by all the methods and blocks within the class and by other classes through the object reference.
- Static variables are declared within a class but outside any method or block with the static keyword. They are created when the class is loaded and destroyed when the class is unloaded. They are accessible by all the methods and blocks within the class and by other classes through the class name. They are also known as class variables.
