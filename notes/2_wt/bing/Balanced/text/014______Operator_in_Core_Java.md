#### Operator in Core Java

- Operators in Java are symbols that are used to perform operations on variables and manipulate the values of the operands  .
- Each operator performs specific operations and has a certain precedence and associativity.
- Java divides the operators into the following groups:
  - Arithmetic operators: They are used to perform simple arithmetic operations on primitive data types, such as addition, subtraction, multiplication, division, modulus, and unary negation .
  - Assignment operators: They are used to assign values to variables, such as `=` (simple assignment), `+=` (add and assign), `-=` (subtract and assign), and so on .
  - Relational operators: They are used to compare two values and return a boolean result, such as `==` (equal to), `!=` (not equal to), `>` (greater than), `<` (less than), and so on .
  - Logical operators: They are used to perform logical operations on boolean values, such as `&&` (logical and), `||` (logical or), `!` (logical not), and so on .
  - Bitwise operators: They are used to perform bit-level operations on integer values, such as `&` (bitwise and), `|` (bitwise or), `^` (bitwise xor), `~` (bitwise complement), and so on .
  - Conditional operators: They are used to evaluate a condition and return one of two possible values, such as `?:` (ternary operator) and `instanceof` (type comparison operator) .
  - Shift operators: They are used to shift the bits of an integer value to the left or right, such as `<<` (left shift), `>>` (right shift), and `>>>` (unsigned right shift) .
  - Special operators: They are used to perform some special functions, such as `.` (dot operator), `[]` (array index operator), `()` (method call operator), and so on .
