### Core Java

Core Java is the basic and fundamental part of the Java programming language that defines the syntax, data types, operators, control structures, classes, interfaces, exceptions, and input/output operations. It is also known as Java Standard Edition (Java SE) or Java Platform Standard Edition (Java SE).

Some of the main features of Core Java are:

- It is an object-oriented programming language that supports encapsulation, inheritance, polymorphism, and abstraction.
- It is a platform-independent language that can run on any machine that has a Java Virtual Machine (JVM) installed.
- It is a compiled language that generates bytecode that can be executed by the JVM.
- It is a strongly typed language that checks the data types of variables and expressions at compile-time and run-time.
- It is a multi-threaded language that supports concurrency and parallelism.
- It is a robust language that handles errors and exceptions gracefully.
- It is a secure language that prevents unauthorized access to data and code.
- It is a high-performance language that optimizes the execution speed and memory usage of the program.
- It is a dynamic language that supports dynamic loading, linking, and binding of classes and methods.
- It is a simple language that has a clear and concise syntax and avoids complex features like pointers, multiple inheritance, operator overloading, etc.
