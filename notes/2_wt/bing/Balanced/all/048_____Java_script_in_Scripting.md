### JavaScript in Scripting

- JavaScript (JS) is a lightweight, interpreted, or just-in-time compiled programming language with first-class functions.
- It is most well-known as the scripting language for web pages, but it can also be used in other environments, such as Node.js, Apache CouchDB and Adobe Acrobat.
- JavaScript can create dynamic and interactive features on web pages, such as content updates, maps, graphics, video, etc.
- JavaScript can interact with the Document Object Model (DOM), which is a representation of the web page structure and content.
- JavaScript follows the ECMAScript specification, which defines the syntax, types, operators, statements, and built-in objects of the language.
- JavaScript has evolved over the years and has introduced many new features, such as classes, modules, promises, generators, arrow functions, etc.
- Some mnemonics and learning tricks for JavaScript are:
  - **J**ust **S**tart **S**cripting: A reminder that JavaScript is easy to get started with and can be embedded in HTML or included from external files.
  - **F**unctions **A**re **F**irst-class: A way to remember that functions in JavaScript can be assigned to variables, passed as arguments, returned from other functions, and stored in data structures.
  - **T**his **I**s **T**ricky: A warning that the `this` keyword in JavaScript can have different meanings depending on the context, such as the global object, the current object, or the bound object.
  - **L**et **C**onst **V**ar: A mnemonic to recall the three ways to declare variables in JavaScript, and their differences in scope and reassignment.
  - **N**ot **E**verything **I**s **N**umber: A reminder that JavaScript has different data types, such as string, boolean, null, undefined, symbol, object, and bigint, besides number.
