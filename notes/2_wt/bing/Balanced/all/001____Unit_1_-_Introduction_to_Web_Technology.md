## Unit 1 - Introduction to Web Technology

- Web technology is the development of the mechanism that allows two or more computer devices to communicate over a network.
- Web technology includes markup languages, programming interfaces, standards to define document identity and display, and web browsers .
- Web technology enables the creation, storage, and delivery of web pages, web applications, web services, and web content over the internet.
- Web technology is constantly evolving and improving, with new trends and innovations emerging every year.
- Some of the current trends and topics in web technology are:

  - Responsive web design: the ability to adapt web pages to different screen sizes and devices.
  - Progressive web apps: web applications that offer native-like features and performance, such as offline access, push notifications, and home screen icons.
  - WebAssembly: a low-level binary format that allows high-performance execution of code in web browsers.
  - Web components: reusable and customizable elements that can be used to create complex web interfaces.
  - Web security: the protection of web resources and users from malicious attacks, such as phishing, malware, and data breaches.
