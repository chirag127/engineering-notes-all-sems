#### Java Applet in Core Java

- A Java applet is a small application written in the Java programming language, or another programming language that compiles to Java bytecode, and delivered to users in the form of Java bytecode .
- A Java applet can be transferred via the Internet and run by a Java-compatible web browser. The user launches the Java applet from a web page, and the applet is then executed within a Java virtual machine (JVM) in a process separate from the web browser.
- A Java applet has limited functionality compared to a standalone Java application. It can only perform tasks that are allowed by the security policy of the web browser and the JVM. For example, a Java applet cannot access the local file system, create new processes, or load native libraries.
- A Java applet can provide web applications with interactive and dynamic features that HTML cannot offer, such as animations, games, calculators, charts, etc. A Java applet can also communicate with other applets, the web server, or the web browser using various protocols.
- A Java applet is typically executed in an AppletViewer or a <applet> tag in HTML. The <applet> tag specifies the name, size, and parameters of the applet class. For example:

```html
<applet code="HelloWorld.class" width="300" height="100">
</applet>
```

- A Java applet follows a life cycle that consists of four stages: initialization, start, stop, and destroy. The applet class must override the methods init(), start(), stop(), and destroy() to perform the corresponding actions in each stage. For example:

```java
import java.applet.Applet;
import java.awt.Graphics;

public class HelloWorld extends Applet {
   public void init() {
      // initialization code
   }

   public void start() {
      // start or resume execution
   }

   public void stop() {
      // pause execution
   }

   public void destroy() {
      // perform cleanup
   }

   public void paint(Graphics g) {
      // display output
      g.drawString("Hello World", 50, 50);
   }
}
```

- A Java applet can also implement the interface Runnable to create a separate thread of execution for animation or other tasks. The applet class must override the method run() to define the behavior of the thread. For example:

```java
import java.applet.Applet;
import java.awt.Graphics;

public class Animation extends Applet implements Runnable {
   private Thread animator;
   private int x = 0;

   public void init() {
      // initialization code
   }

   public void start() {
      // start or resume execution
      animator = new Thread(this);
      animator.start();
   }

   public void stop() {
      // pause execution
      animator = null;
   }

   public void destroy() {
      // perform cleanup
   }

   public void run() {
      // define the behavior of the thread
      while (animator != null) {
         x = (x + 1) % getWidth();
         repaint();
         try {
            Thread.sleep(10);
         } catch (InterruptedException e) {
            // handle exception
         }
      }
   }

   public void paint(Graphics g) {
      // display output
      g.fillOval(x, 50, 50, 50);
   }
}
```
