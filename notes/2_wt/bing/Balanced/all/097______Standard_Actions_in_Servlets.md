#### Standard Actions in Servlets

- Standard actions are predefined tags that perform some common tasks in JSP pages, such as including other files, forwarding requests, or creating Java objects.
- Standard actions start with `<jsp:` and end with `/>`. They have one or more attributes that specify their behavior.
- Some of the standard actions are:

  - `<jsp:include>`: This action includes the content of another resource, such as a JSP page, an HTML file, or a servlet, at the time of request processing. It has two attributes: `page`, which specifies the relative URL of the resource to be included, and `flush`, which indicates whether the output buffer should be flushed before including the resource. The default value of `flush` is `false`.
  - `<jsp:forward>`: This action forwards the current request to another resource, such as a JSP page, an HTML file, or a servlet, for further processing. It has one attribute: `page`, which specifies the relative URL of the resource to be forwarded to. The action terminates the current page execution and discards any output generated so far.
  - `<jsp:plugin>`: This action generates the necessary HTML code to invoke a Java applet or a JavaBean component in the client browser. It has several attributes, such as `type`, `code`, `codebase`, `width`, `height`, etc., that specify the properties of the applet or the component. It also has an optional `<jsp:params>` subelement, which can contain one or more `<jsp:param>` subelements, to pass parameters to the applet or the component.
  - `<jsp:useBean>`: This action creates an instance of a JavaBean component and associates it with a scripting variable. It has four attributes: `id`, which specifies the name of the scripting variable, `class`, which specifies the fully qualified class name of the bean, `scope`, which specifies the scope of the bean (page, request, session, or application), and `type`, which specifies the type of the bean (usually the same as the class name or a superclass or interface name). If the bean already exists in the specified scope, the action simply returns the existing bean. Otherwise, it creates a new bean and stores it in the specified scope.
  - `<jsp:setProperty>`: This action sets the properties of a JavaBean component using either the request parameters or the values of other expressions. It has three attributes: `name`, which specifies the name of the bean, `property`, which specifies the name of the property to be set, and `value`, which specifies the value of the property. The `property` attribute can also take the special values `*` or `param`, which indicate that all the properties of the bean should be set using either the request parameters or the values of the expressions with the same names as the properties, respectively.
  - `<jsp:getProperty>`: This action gets the value of a property of a JavaBean component and writes it to the output stream. It has two attributes: `name`, which specifies the name of the bean, and `property`, which specifies the name of the property to be retrieved.

- A mnemonic to remember the standard actions is: **I Forgive People Using Some Goodwill**. This stands for: **Include, Forward, Plugin, UseBean, SetProperty, GetProperty**.
