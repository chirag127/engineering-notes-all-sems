
### List in Web Page Designing

1. HTML: HTML (HyperText Markup Language) is the most basic building block of web page design. It defines the structure and layout of a web page. HTML consists of a series of elements that you use to enclose, format, and link different parts of your web page.

2. CSS: CSS (Cascading Style Sheets) is used to define the look and feel of a web page. It uses a set of rules to format the text, images, and other content on a web page.

3. JavaScript: JavaScript is a scripting language that is used to add interactive elements to web pages. It is used to create dynamic web pages that respond to user input.

4. jQuery: jQuery is a JavaScript library that makes it easy to add interactive elements to web pages. It simplifies common tasks such as animating elements, making Ajax requests, and handling events.

5. AJAX: AJAX (Asynchronous JavaScript and XML) is a technique used to make asynchronous requests to a server. It allows web pages to update content without reloading the entire page.

6. Bootstrap: Bootstrap is a framework for building responsive websites. It includes a set of HTML, CSS, and JavaScript components that can be used to create customized web pages.
