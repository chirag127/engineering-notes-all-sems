
### Types of Beans in Enterprise Java Bean

1. Session Beans: Session beans are used to represent the transient conversation between the client and the enterprise bean. They are created and removed by the container as needed.

2. Message-Driven Beans: Message-driven beans are used to process messages asynchronously. They are created by the container and are used to process JMS messages.

3. Entity Beans: Entity beans are used to represent persistent data in the database. They are created and removed by the container as needed.

4. Singleton Beans: Singleton beans are used to represent a single instance of an enterprise bean. They are created by the container when the application starts and are removed when the application shuts down.
