
#### Introduction to AWT in Core Java

* Abstract Window Toolkit (AWT) is a set of Java classes used to create graphical user interfaces (GUIs) and add rich graphics functionality to Java applications. 
* AWT is part of the Java Foundation Classes (JFC) and includes classes for creating and managing windows, buttons, check boxes, scrollbars, text fields, labels, menus, and other components. 
* AWT also provides the ability to add images, colors, fonts, and layout managers to Java applications. 
* AWT components are platform-independent, meaning they can be used on any operating system that supports Java. 
* AWT components are created with the help of the java.awt package. 
* AWT components are lightweight, meaning they are rendered using the host operating system’s native GUI components. 
* AWT is event-driven, meaning it responds to user input such as mouse clicks, key presses, and other events. 
* AWT also provides support for drag and drop operations.
