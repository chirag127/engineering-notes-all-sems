
### Introduction to Client-Server Computing

1. Client-server computing is a model of computing architecture in which a client computer requests services or resources from a server computer over a network. 
2. The server computer is responsible for providing the requested services or resources to the client computer. 
3. The client computer can be any type of computer such as a desktop, laptop, tablet, or smartphone. 
4. The server computer is typically a powerful computer that can handle multiple requests from multiple clients. 
5. The server computer is responsible for storing, managing, and providing access to data and applications. 
6. The client-server model is used in many types of applications, such as web applications, email, file sharing, database access, and remote desktop access. 
7. The client-server model is also used in distributed computing, where multiple computers work together to provide a service or application. 
8. The client-server model provides a more secure and reliable way of delivering services and applications than other models, such as peer-to-peer. 
9. The client-server model also allows for scalability, as more clients can be added to the system without affecting the performance of the server.
