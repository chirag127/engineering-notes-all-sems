

#### Methods & Classes in Core Java

* Methods are the building blocks of a program. They are used to perform tasks or actions and can be used to create complex programs. 
* A class is a template for an object. It defines the data and behavior of a type of object. Classes are used to create objects which can then be used to store data and interact with other objects.
* In Java, methods are declared within a class. They can be public, private, or protected. Public methods can be called by any other code, while private methods can only be called by the class itself.
* Classes can contain both instance and static methods. Instance methods are associated with a specific instance of a class, while static methods are associated with the class itself.
* Classes can also contain data, which is referred to as fields or variables. These fields can be accessed using the dot (.) operator.
* Classes can also contain constructors, which are special methods used to create an instance of the class. Constructors can take parameters, allowing for the creation of objects with different data.
* Classes can also contain inner classes, which are classes that are declared within another class. Inner classes can be used to group related methods and data together.
* Classes can also contain interfaces, which are special types of classes that define the behavior of an object. Interfaces can be used to enforce certain behaviors and ensure that objects are used in a consistent manner.
