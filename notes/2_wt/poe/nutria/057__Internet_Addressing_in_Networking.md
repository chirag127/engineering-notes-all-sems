
#### Internet Addressing in Networking

1. Internet addressing is a system of assigning numerical identifiers to devices connected to a network. These numerical identifiers are known as **IP addresses**.
2. IP addresses are used to identify and communicate with devices on a network. Each device on a network must be assigned a unique IP address in order to communicate with other devices.
3. IP addresses can be either static or dynamic. Static IP addresses are assigned manually and do not change, while dynamic IP addresses are assigned automatically by a DHCP server and can change over time.
4. IP addresses are composed of four 8-bit numbers separated by periods. Each 8-bit number is called an octet and can range from 0 to 255.
5. IP addresses are divided into two classes: Class A, B, and C. Class A addresses are used for large networks, Class B addresses are used for medium-sized networks, and Class C addresses are used for small networks.
6. IP addresses can also be divided into public and private. Public IP addresses are used to access the internet, while private IP addresses are used to access internal networks.
7. In addition to IP addresses, networks also use subnet masks and gateways to control access to the network. Subnet masks are used to identify which parts of the IP address are used for the network address, while gateways are used to route traffic between networks.
