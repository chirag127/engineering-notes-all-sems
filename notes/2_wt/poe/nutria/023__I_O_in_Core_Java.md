
#### I/O in Core Java 
1. Input/Output (I/O) is a set of programming techniques used to read and write data to and from external sources.
2. Java provides a wide range of I/O classes and methods to read and write data to and from external sources.
3. Java I/O is divided into two categories: character-based I/O and byte-based I/O.
4. Character-based I/O is used to read and write text data, while byte-based I/O is used to read and write binary data.
5. Java I/O classes are organized into a hierarchy, with the top-level class being the abstract class java.io.InputStream.
6. The java.io.File class is used to represent a file or directory in the file system.
7. The java.io.FileInputStream and java.io.FileOutputStream classes are used to read and write data from and to a file.
8. The java.io.BufferedReader and java.io.BufferedWriter classes are used to read and write text data from and to a file.
9. The java.io.DataInputStream and java.io.DataOutputStream classes are used to read and write binary data from and to a file.
10. The java.io.PrintWriter class is used to write formatted text data to a file or other output stream.
