

#### AWT Controls

* An AWT control is a GUI component that is used to interact with the user.
* AWT controls are components such as buttons, checkboxes, radio buttons, text fields, and labels.
* AWT controls can be used to create graphical user interfaces (GUIs).
* AWT controls are used to provide user input and to display output.
* AWT controls are platform-independent, meaning they are not dependent on the operating system.
