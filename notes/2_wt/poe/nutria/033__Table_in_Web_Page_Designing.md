
### Table in Web Page Designing
- Tables are used to present data in a structured format on web pages.
- Tables are created using HTML tags such as `<table>`, `<tr>`, `<th>` and `<td>`.
- The `<table>` tag defines a table, while the `<tr>` tag defines a table row, `<th>` defines a table header and `<td>` defines a table cell.
- Tables can be used to display tabular data, such as a product catalog, or to create a layout for a web page.
- Tables can also be styled with CSS to give them a customized look and feel.
- Tables should be used with caution, as they can cause accessibility issues for users with impaired vision or other disabilities.
