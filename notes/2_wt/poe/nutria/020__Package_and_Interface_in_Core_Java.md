

#### Package and Interface in Core Java

- A package is a collection of related classes and interfaces that provide access protection and namespace management. 
- Packages are used to categorize classes and interfaces so that they can be easily maintained. 
- An interface is a collection of abstract methods and constants that form a common set of base rules for a class to implement. 
- Interfaces provide a way to achieve abstraction and multiple inheritance in Java. 
- All methods in an interface are implicitly public and abstract. 
- Interfaces can be used to achieve loose coupling and to provide a contract between the class and the outside world. 
- Classes can implement multiple interfaces, but can only extend one class.
