
### Java Database Connectivity (JDBC)

1. JDBC is an API for the Java programming language that defines how a client may access a database.
2. It provides methods for querying and updating data in a database.
3. JDBC is a Java-based data access technology that defines how a client may access a database.
4. JDBC is a low-level API that enables the developer to interact with databases using SQL.
5. JDBC provides a set of classes and interfaces that enable a Java program to interact with a database.
6. JDBC drivers are used to connect to a database and execute SQL statements.
7. JDBC provides a set of classes and interfaces that enable a Java program to interact with a database.
8. JDBC provides a set of standard methods for executing SQL statements, such as PreparedStatement and Statement.
9. JDBC also provides support for batch processing, which allows multiple SQL statements to be executed as a single unit.
10. JDBC provides support for distributed transactions, which allow multiple databases to be updated as a single unit.
