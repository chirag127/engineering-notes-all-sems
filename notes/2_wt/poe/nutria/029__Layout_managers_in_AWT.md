
#### Layout managers in AWT

1. Layout managers are components that help define the position and size of other components within a container. 
2. AWT (Abstract Window Toolkit) is a platform-independent widget toolkit for Java that includes layout managers. 
3. The layout managers available in AWT are: 
    * FlowLayout: components are laid out in a single row or column, with each component taking up the same amount of space. 
    * BorderLayout: components are laid out in five regions (north, south, east, west and center). 
    * GridLayout: components are laid out in a grid with a specified number of rows and columns. 
    * CardLayout: components are laid out in a stack, with only one component visible at a time. 
4. The LayoutManager interface is the superclass of all layout managers in AWT. It defines methods for adding, removing and retrieving components from a container.
