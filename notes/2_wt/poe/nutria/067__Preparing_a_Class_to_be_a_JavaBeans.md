
### Preparing a Class to be a JavaBeans
1. A JavaBean is a reusable software component written in the Java programming language.
2. A JavaBean must follow certain conventions to be considered a JavaBean.
3. All JavaBeans must have a no-argument constructor.
4. All JavaBeans must implement the Serializable interface.
5. All JavaBeans must have public getter and setter methods for all of its properties.
6. All JavaBeans must have a public static final String field named serialVersionUID.
7. All JavaBeans must be able to be stored and retrieved from a persistent storage medium.
8. All JavaBeans must be able to be instantiated, manipulated, and used with standard tools.
