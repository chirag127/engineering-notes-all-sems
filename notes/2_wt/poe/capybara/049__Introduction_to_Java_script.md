#### Introduction to Java script

Java Script is a programming language used to create interactive and dynamic websites. Here are some key points to keep in mind when learning about Java Script:

- Java Script was first created in 1995 by Brendan Eich and became the official programming language for web browsers in 1996.
- Java Script is a client-side language, meaning that it is executed on the user's computer rather than the server.
- Java Script is used to add interactivity to websites, such as form validation, animations, and dynamic content.
- Java Script can be used in conjunction with HTML and CSS to create a complete website.
- Java Script is a high-level language, meaning that it is closer to human language than low-level languages like Assembly.
- Java Script is an interpreted language, meaning that it is executed line-by-line rather than being compiled into machine code.
- Java Script is a dynamically-typed language, meaning that variable types are determined at runtime rather than being explicitly defined.
- Java Script has a number of built-in functions and methods, as well as a large number of libraries and frameworks that can be used to simplify coding.
- Java Script is constantly evolving, with new features and updates being released on a regular basis.
- Java Script is a useful skill to have for front-end web development, and is often a requirement for jobs in this field.
