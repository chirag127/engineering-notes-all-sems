## Unit 3 - Scripting

In this unit, you will learn about scripting, which is the process of designing and writing scripts to automate tasks on a computer system. Scripting is an essential skill for any programmer, system administrator or network engineer. Here are some of the key topics that will be covered in this unit:

- **Introduction to scripting:** You will learn about the basics of scripting, including what it is, why it is used, and what the benefits of scripting are. You will also get an overview of some of the most common scripting languages, such as Bash, Python, and PowerShell.

- **Scripting in Bash:** Bash is a popular scripting language used on Unix and Linux systems. You will learn how to create simple Bash scripts, including how to use variables, loops, and conditional statements. You will also learn how to use command-line arguments and input/output redirection in Bash scripts.

- **Scripting in Python:** Python is a versatile scripting language used in a wide range of applications, including web development, scientific computing, and machine learning. You will learn how to create simple Python scripts, including how to use variables, loops, and conditional statements. You will also learn how to use modules and functions in Python scripts.

- **Scripting in PowerShell:** PowerShell is a scripting language developed by Microsoft for use on Windows systems. You will learn how to create simple PowerShell scripts, including how to use variables, loops, and conditional statements. You will also learn how to use cmdlets and modules in PowerShell scripts.

- **Scripting for system administration:** You will learn how to use scripting to automate common system administration tasks, such as user management, file management, and network configuration. You will also learn how to use scheduling tools, such as cron and Task Scheduler, to run scripts at specific times.

- **Scripting for network engineering:** You will learn how to use scripting to automate common network engineering tasks, such as network device configuration and monitoring. You will also learn how to use APIs to interact with network devices and how to use scripting to generate reports and visualizations.

Overall, this unit will provide you with a solid foundation in scripting and equip you with the skills you need to automate tasks on a computer system.
