#### Methods & Classes in Core Java

In Java, classes and methods are the fundamental building blocks of a program. Understanding them is essential for any Java developer. Here are some key points to keep in mind when working with methods and classes in Core Java:

##### Classes

- A class is a blueprint or template for creating objects in Java.
- It encapsulates data and behavior that are related to a specific entity or concept.
- A class can have fields, methods, and constructors.
- Fields are variables that hold data for an object.
- Methods are functions that perform tasks and manipulate data.
- Constructors are special methods that create and initialize objects.
- A class can be extended to create a new class that inherits its fields and methods.
- The class hierarchy in Java is a tree structure with a single root class, which is the Object class.

##### Methods

- A method is a block of code that performs a specific task.
- It can take parameters and return a value.
- The return type of a method specifies the type of value it returns or void if it does not return anything.
- A method can be defined inside a class or interface.
- Access modifiers, such as public, private, and protected, can be used to control the visibility of a method.
- Overloading is a feature in Java that allows a class to have multiple methods with the same name but different parameters.
- Overriding is a feature that allows a subclass to provide its own implementation of a method defined in its superclass.
- A static method is a method that belongs to a class rather than an instance of the class.

##### Commonly Used Classes

- The Object class is the root class of the Java class hierarchy.
- The String class is used to represent a sequence of characters.
- The Math class provides methods for performing mathematical operations.
- The Scanner class is used for reading user input from the console.
- The ArrayList class is a resizable array that provides methods for adding, removing, and accessing elements.
- The HashMap class is a collection that stores key-value pairs and provides methods for adding, removing, and accessing elements.
- The File class is used to represent a file or directory in the file system.

By understanding these concepts, you can create classes and methods that are well-designed, reusable, and easy to maintain.
