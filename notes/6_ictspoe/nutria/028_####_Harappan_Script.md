

#### Harappan Script

* Harappan Script is an ancient script used in the Indus Valley Civilization, one of the oldest civilizations in the world. It is believed to have been in use from around 2600 BC to 1900 BC.
* The script is believed to be a logo-syllabic script, which means that each sign stands for a syllable or a word.
* The script is written in a variety of directions, including left to right, right to left, and even boustrophedon (alternating directions).
* It is believed that the script is related to the Brahmi script, an ancient script used in India, but this has not been confirmed.
* The script is composed of around 400 symbols, of which only around 100 have been deciphered.
* It is believed that the script was used to write a variety of languages, including Dravidian and Indo-Aryan.
