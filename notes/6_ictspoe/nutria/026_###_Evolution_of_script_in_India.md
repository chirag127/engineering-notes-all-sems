
### Evolution of Script in India

1. The earliest known script used in India is the Indus script, which is believed to have been used from around 3000 BCE to 1500 BCE. 
2. After the Indus script declined, Brahmi script became the most commonly used script in India. It is believed to have been developed around 600 BCE and is the oldest surviving script in India. 
3. In the middle ages, the Nagari script became the most widely used script in India. It was developed around the 9th century CE and is still in use today.
4. In the 16th century, the Devanagari script was developed. This script is still in use today and is used for writing Hindi, Marathi, and other languages. 
5. In the 19th century, the Bengali script was developed. This script is still in use today and is used for writing Bengali, Assamese, and other languages.
6. In the 20th century, the Tamil script was developed. This script is still in use today and is used for writing Tamil, Malayalam, and other languages.
7. In the 21st century, the Kannada script was developed. This script is still in use today and is used for writing Kannada, Tulu, and other languages.
