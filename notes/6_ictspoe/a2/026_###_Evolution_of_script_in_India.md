### Evolution of script in India

The evolution of writing systems in India can be broadly classified into the following phases:

1. Pre-Harappan script (3300 BCE - 2600 BCE): The Indus script is the earliest writing system developed in the Indus Valley Civilization. Around 400 distinct signs have been found but the script has not yet been deciphered.

2. Brahmi script (3rd century BCE): The Brahmi script was the first widely used writing system in India. It was developed in the 3rd century BCE and was used to write Prakrit and Sanskrit. All modern Indian scripts descend from the Brahmi script. Some important variants of Brahmi are:

- Kharoshthi: Used in the northwestern regions of ancient India to write Gandhari and Sanskrit.
- Gupta script: Developed during the Gupta Empire and used to write Sanskrit.
- Siddham script: Developed in the 7th century CE and used to write Sanskrit and Buddhist texts.

3. Development of modern scripts (from 4th century CE): The major modern scripts of India like Devanagari, Bengali, Tamil, etc. evolved from the Brahmi script starting from the 4th century CE. These scripts were developed to write regional languages. For example, Devanagari evolved from the Siddham script and was used to write Sanskrit and Hindi.

Some key points to remember:

- The Indus script is the earliest writing system in India but has not been deciphered yet.
- The Brahmi script was the first widely used writing system in India and evolved around the 3rd century BCE.
- All major modern Indian scripts like Devanagari, Bengali, Tamil, etc. evolved from the Brahmi script.
- The evolution of scripts in India was tied to the evolution of languages. Scripts were developed to write different regional languages.
