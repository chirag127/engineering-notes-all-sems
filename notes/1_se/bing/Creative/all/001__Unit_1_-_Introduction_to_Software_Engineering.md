## Unit 1 - Introduction to Software Engineering

- Software engineering is the discipline of designing, developing, testing, and maintaining software systems that meet the needs and expectations of users and stakeholders.
- Software engineering is not only about writing code, but also about applying engineering principles and methods to software projects, such as analysis, design, documentation, quality assurance, project management, and ethics.
- Software engineering is important because software systems are ubiquitous and critical in many domains, such as business, education, health, entertainment, and security. Software systems can also be complex, large-scale, and evolving, requiring systematic and rigorous approaches to ensure their quality and reliability.
- Software engineering can be divided into several sub-disciplines, such as:

  - Software requirements engineering: the process of eliciting, analyzing, specifying, and validating the functional and non-functional requirements of a software system.
  - Software design: the process of defining the architecture, components, interfaces, and data structures of a software system, as well as the algorithms and protocols that implement its functionality.
  - Software construction: the process of writing, testing, debugging, and integrating the source code of a software system, following coding standards and guidelines.
  - Software testing: the process of verifying and validating that a software system meets its requirements and specifications, and that it is free of defects and errors.
  - Software maintenance: the process of modifying and updating a software system after its deployment, to fix bugs, improve performance, add features, or adapt to changing environments and user needs.
  - Software configuration management: the process of controlling and managing the changes and versions of a software system and its artifacts, such as code, documentation, and test cases.
  - Software project management: the process of planning, organizing, coordinating, monitoring, and controlling the resources, activities, and deliverables of a software project, to achieve its objectives within the constraints of time, budget, and quality.
  - Software quality assurance: the process of ensuring that a software system meets the standards and criteria of quality, such as functionality, reliability, usability, efficiency, maintainability, and portability.
  - Software engineering ethics: the study and practice of the moral and professional responsibilities and obligations of software engineers, such as honesty, integrity, respect, accountability, and public interest.

- Software engineering can also be categorized into different types, depending on the nature and scope of the software system, such as:

  - Generic software engineering: the application of software engineering principles and methods to general-purpose software systems, such as operating systems, databases, compilers, and web browsers.
  - Application software engineering: the application of software engineering principles and methods to specific-domain software systems, such as banking, gaming, e-commerce, and social media.
  - Embedded software engineering: the application of software engineering principles and methods to software systems that are integrated with hardware devices, such as sensors, controllers, and microprocessors.
  - Real-time software engineering: the application of software engineering principles and methods to software systems that have strict timing and performance constraints, such as avionics, robotics, and telecommunication.
  - Distributed software engineering: the application of software engineering principles and methods to software systems that are composed of multiple components that communicate and coordinate over a network, such as cloud computing, web services, and peer-to-peer systems.
  - Service-oriented software engineering: the application of software engineering principles and methods to software systems that are designed and implemented as a collection of reusable and interoperable services, such as service-oriented architecture (SOA) and microservices.
  - Agile software engineering: the application of software engineering principles and methods that emphasize flexibility, adaptability, collaboration, and customer feedback, such as agile methodologies (e.g., Scrum, XP, Kanban) and practices (e.g., user stories, test-driven development, continuous integration).

- Software engineering can also be influenced by various factors, such as:

  - Software engineering paradigms: the models and frameworks that guide the software engineering process, such as waterfall, spiral, incremental, iterative, and prototyping.
  - Software engineering models: the representations and abstractions that describe the software system and its development, such as data models, process models, object models, and state models.
  - Software engineering methods: the techniques and tools that support the software engineering activities, such as analysis methods, design methods, testing methods, and documentation methods.
  - Software engineering standards: the rules and conventions that define the quality and consistency of the software engineering process and products, such as ISO/IEC 12207, IEEE 830, and CMMI.
  - Software engineering challenges: the problems and difficulties that software engineers face in developing software systems, such as complexity, uncertainty, change, and risk.
