According to the search results, the objectives of software testing are:

- To evaluate the work products such as requirements, design, user stories, and code 
- To verify the fulfillment of all specified requirements 
- To validate if the test object is complete and works as per the expectation of the users and the stakeholders 
- To build confidence in the quality level of the test object 
- To improve software quality by finding and fixing defects

The diagram shows the following steps:

- The work products such as requirements, design, user stories, and code are evaluated by verification techniques such as reviews, inspections, and static analysis .
- The requirements are used to create test cases and test data that cover the specified functionality and quality attributes .
- The test object, which is the software product or application under test, is validated by executing the test cases and test data using various testing techniques such as black-box, white-box, functional, performance, etc .
- The test results, which are the outcomes of the validation process, are compared with the expected results to identify defects .
- The defects, which are the deviations from the requirements or expectations, are reported and fixed by the developers .

The main objective of software testing is to ensure that the test object meets the requirements and expectations of the users and the stakeholders, and to improve its quality by finding and fixing defects .
