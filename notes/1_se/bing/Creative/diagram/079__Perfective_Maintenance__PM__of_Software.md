Perfective Maintenance (PM) of Software is the process of modifying software or applications to implement new or changed user requirements which concern functional enhancements. It is one of the four types of software maintenance, along with corrective, adaptive, and preventive maintenance. Perfective maintenance focuses on the evolution of requirements and features that exist in the system. It includes new features and new user requirements for refining the software and improving its reliability and performance.
