## Unit 5 - Software Maintenance and Software Project Management

Software maintenance and software project management are two related but distinct disciplines that aim to ensure the quality and functionality of software products throughout their life cycle. Software maintenance involves the activities of modifying, correcting, enhancing, and adapting software after its initial delivery to meet changing requirements, fix defects, improve performance, or comply with standards. Software project management involves the planning, organizing, monitoring, and controlling of software development projects, from inception to completion, within the constraints of time, budget, scope, and quality.

The following diagram illustrates the basic architecture of a software maintenance and software project management process using ASCII art:

```
+------------------+    +------------------+    +------------------+
|                  |    |                  |    |                  |

|                  |    |                  |    |  Process         |
+------------------+    +------------------+    +------------------+
|                  |    |                  |    |                  |
|  - Requirements  |    |  - Corrective    |    |  - Initiation    |
|  - Design        |    |  - Adaptive      |    |  - Planning      |
|  - Implementation|    |  - Perfective    |    |  - Execution     |
|  - Testing       |    |  - Preventive    |    |  - Monitoring    |
|  - Deployment    |    |                  |    |  - Closing       |
|                  |    |                  |    |                  |
+------------------+    +------------------+    +------------------+
|                  |    |                  |    |                  |
|  +------------+  |    |  +------------+  |    |  +------------+  |

|  |            |  |    |  |            |  |    |  |            |  |
|  +------------+  |    |  +------------+  |    |  +------------+  |
|                  |    |                  |    |                  |
+------------------+    +------------------+    +------------------+
```

The software development process is responsible for creating the software product according to the specified requirements and design. The software maintenance process is responsible for modifying the software product after its delivery to keep it operational and up to date. The software project management process is responsible for overseeing the software development and maintenance processes, ensuring that they meet the project objectives and deliver the expected value to the stakeholders.
