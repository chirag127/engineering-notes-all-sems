Evolutionary development models in SDLC are a combination of iterative and incremental models that deliver the system in small and frequent releases. Each release is developed through a mini waterfall model, and the system evolves with user feedback and changing requirements. There are different types of evolutionary models, such as prototyping, spiral, and agile models. The following diagram illustrates the basic structure of an evolutionary model in SDLC:

```
+----------------+     +----------------+     +----------------+
|                |     |                |     |                |
|  Requirements  |     |  Requirements  |     |  Requirements  |
|                |     |                |     |                |
+-------+--------+     +-------+--------+     +-------+--------+
        |                      |                      |
        v                      v                      v
+-------+--------+     +-------+--------+     +-------+--------+
|                |     |                |     |                |
|     Design     |     |     Design     |     |     Design     |
|                |     |                |     |                |
+-------+--------+     +-------+--------+     +-------+--------+
        |                      |                      |
        v                      v                      v
+-------+--------+     +-------+--------+     +-------+--------+
|                |     |                |     |                |
| Implementation |     | Implementation |     | Implementation |
|                |     |                |     |                |
+-------+--------+     +-------+--------+     +-------+--------+
        |                      |                      |
        v                      v                      v
+-------+--------+     +-------+--------+     +-------+--------+
|                |     |                |     |                |
|     Testing    |     |     Testing    |     |     Testing    |
|                |     |                |     |                |
+-------+--------+     +-------+--------+     +-------+--------+
        |                      |                      |
        v                      v                      v
+-------+--------+     +-------+--------+     +-------+--------+
|                |     |                |     |                |
|    Delivery    |     |    Delivery    |     |    Delivery    |
|                |     |                |     |                |
+-------+--------+     +-------+--------+     +-------+--------+
        |                      |                      |
        +---------------------->                      |
        |                      |                      |
        +--------------------------------------------->

```

Each box represents a phase of the waterfall model, and each arrow represents the transition from one phase to another. The horizontal arrows indicate the feedback loops that allow the system to evolve with user input and changing requirements. The vertical arrows indicate the delivery of a release to the customer. The first release is usually a prototype or a minimum viable product, and the subsequent releases add more features and functionalities to the system. The final release is the complete and refined system that meets the customer's expectations and needs.
