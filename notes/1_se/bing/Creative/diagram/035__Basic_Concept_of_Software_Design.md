The basic concept of software design is the process of envisioning and defining software solutions to one or more sets of problems, using a set of primitive components and subject to constraints. One of the main components of software design is the software requirements analysis (SRA), which lists the specifications used in software engineering. Software design may involve user experience design, low-level component and algorithm design, and high-level architecture design. Software design is both a process and a model, and it involves various concepts and principles, such as abstraction, modularity, coupling, cohesion, etc.
