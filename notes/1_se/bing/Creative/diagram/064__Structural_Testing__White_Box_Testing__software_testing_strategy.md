Structural testing, also known as white box testing, is a software testing strategy that verifies the internal structure, design, and implementation of an application. It requires the tester to have knowledge of the source code and use programming skills to design test cases. The tester chooses inputs to exercise paths through the code and determine the expected outputs. The goal of structural testing is to achieve complete code coverage and find hidden errors, security holes, and broken paths in the code.
