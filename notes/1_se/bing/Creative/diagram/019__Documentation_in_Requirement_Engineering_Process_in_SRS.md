Documentation in Requirement Engineering Process in SRS is the activity of creating a document that describes the software requirements specification (SRS) of a software system. The SRS document is a formal agreement between the development team and the customer that defines what the software will do and how it will perform. The SRS document also serves as a parent document for other software engineering documents, such as design specifications, test plans, and user manuals.
