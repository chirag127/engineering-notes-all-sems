## Unit 4 - Software Testing

- Software testing is the process of verifying and validating that a software product meets the requirements and expectations of the stakeholders.
- Software testing can be performed at different levels of abstraction, such as unit testing, integration testing, system testing, and acceptance testing.
- Software testing can also be classified into different types, such as functional testing, non-functional testing, structural testing, and behavioral testing.
- Software testing can be conducted in different modes, such as manual testing, automated testing, or hybrid testing.
- Software testing can follow different approaches, such as black-box testing, white-box testing, or gray-box testing.
- Software testing can be guided by different strategies, such as test-driven development, behavior-driven development, or model-based testing.
- Software testing can be supported by different techniques, such as equivalence partitioning, boundary value analysis, decision table testing, state transition testing, or pairwise testing.
- Software testing can be evaluated by different criteria, such as test coverage, test effectiveness, test efficiency, or test quality.
- Software testing can be improved by different methods, such as test design, test execution, test analysis, test reporting, or test management.
