## Unit 5 - Software Maintenance and Software Project Management

- Software maintenance is the process of modifying a software product after delivery to correct faults, to improve performance or other attributes, or to adapt to changing environments.  
- Software maintenance is important because it consumes a large part of the overall lifecycle costs and also the inability to change software quickly and reliably means that business opportunities are lost.  
- Software maintenance is a broad activity that includes four types:  
  - Corrective software maintenance: fixing errors or bugs that affect the functionality of the software.
  - Preventive software maintenance: detecting and correcting latent faults that may cause future problems or reduce the maintainability of the software.
  - Perfective software maintenance: enhancing the capabilities, performance, or usability of the software according to the user's needs or feedback.
  - Adaptive software maintenance: modifying the software to cope with changes in the environment, such as hardware, operating system, or standards.
- Software maintenance requires proper planning, management, and control to ensure the quality and reliability of the software. Some of the key issues and challenges in software maintenance are:  
  - Aligning with customer priorities and expectations
  - Estimating the cost and effort of maintenance activities
  - Staffing and assigning responsibilities to maintenance teams
  - Understanding the structure and behavior of the software
  - Analyzing the impact of changes on the software and its dependencies
  - Testing and verifying the changes and their effects
  - Measuring and improving the maintainability of the software
  - Documenting and communicating the changes and their rationale
- Software project management is the process of planning, organizing, leading, and controlling the software development and maintenance activities to achieve the project objectives within the given constraints of scope, time, cost, and quality.  
- Software project management involves the following phases:  
  - Initiation: defining the project scope, objectives, deliverables, stakeholders, and feasibility.
  - Planning: developing the project plan, schedule, budget, resources, risks, quality, and communication strategies.
  - Execution: implementing the project plan, performing the software development and maintenance tasks, monitoring and controlling the project progress, and reporting the project status and issues.
  - Closure: delivering the final software product, evaluating the project performance, documenting the project outcomes and lessons learned, and releasing the project resources.
- Software project management requires the application of various tools, techniques, and methodologies to ensure the successful completion of the project. Some of the common tools and techniques are:  
  - Work breakdown structure (WBS): a hierarchical decomposition of the project scope into manageable tasks and deliverables.
  - Gantt chart: a graphical representation of the project schedule, showing the start and end dates, durations, dependencies, and milestones of the project tasks.
  - Critical path method (CPM): a technique for identifying the longest sequence of dependent tasks that determines the minimum project duration and the project slack.
  - Earned value management (EVM): a technique for measuring the project performance, comparing the actual work done and the actual cost incurred with the planned work and the planned cost.
  - Agile methodology: a flexible and iterative approach to software development and maintenance, emphasizing customer collaboration, adaptive planning, frequent delivery, and continuous improvement.
