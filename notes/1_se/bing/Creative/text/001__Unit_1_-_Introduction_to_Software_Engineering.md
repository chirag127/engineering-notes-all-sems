## Unit 1 - Introduction to Software Engineering

- Software engineering is the application of engineering principles and practices to the development, maintenance, and evolution of software systems.
- Software engineering aims to produce software that meets the needs and expectations of the stakeholders, such as customers, users, developers, and managers, within the constraints of budget, schedule, and quality.
- Software engineering involves various activities, such as:
  - Requirements engineering: eliciting, analyzing, specifying, and validating the software requirements.
  - Design: creating a high-level and low-level structure of the software system, such as its architecture, components, interfaces, and data structures.
  - Implementation: writing, testing, and debugging the source code of the software system, using programming languages, tools, and frameworks.
  - Verification and validation: checking and ensuring that the software system meets the requirements and specifications, and conforms to the expected behavior and quality standards, using techniques such as testing, inspection, review, and analysis.
  - Deployment: delivering, installing, and configuring the software system on the target platforms, such as servers, devices, or networks.
  - Maintenance: modifying, updating, and fixing the software system to cope with changing requirements, environments, or defects, using techniques such as refactoring, patching, and debugging.
  - Evolution: enhancing, adapting, and extending the software system to meet new or emerging needs, opportunities, or challenges, using techniques such as reengineering, migration, and integration.
- Software engineering also involves various processes, methods, models, standards, and best practices, such as:
  - Software development life cycle (SDLC): a framework that defines the phases, activities, tasks, deliverables, and roles involved in the software engineering process, such as waterfall, agile, iterative, or spiral models.
  - Software development methodology: a set of principles, practices, techniques, and tools that guide and support the software engineering process, such as Scrum, Kanban, XP, or RUP.
  - Software engineering ethics: a code of conduct that defines the professional and moral responsibilities and obligations of software engineers, such as honesty, integrity, competence, quality, and social impact.
  - Software engineering standards: a set of rules, guidelines, and specifications that define the quality, performance, compatibility, and interoperability of software systems, such as ISO, IEEE, or CMMI.
  - Software engineering best practices: a set of recommendations, tips, and tricks that help software engineers to improve the efficiency, effectiveness, and quality of their work, such as design patterns, code reviews, testing strategies, or documentation techniques.
