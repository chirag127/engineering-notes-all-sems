### Software Crisis

Software crisis is a term used in the early days of computing science for the difficulty of writing useful and efficient computer programs in the required time. The software crisis was due to the rapid increases in computer power and the complexity of the problems that could not be tackled. With the increase in the complexity of the software, many software problems arose because existing methods were inadequate.

Some of the causes of the software crisis were :

- Projects running over-budget
- Projects running over-time
- Software was very inefficient
- Software was of low quality
- Software often did not meet requirements
- Projects were unmanageable and code difficult to maintain
- Software was never delivered

Some of the effects of the software crisis were :

- The cost of owning and maintaining software was as expensive as developing the software
- The average software project overshoots its schedule by half
- Non-optimal resource utilization
- Difficult to alter, debug, and enhance
- The software complexity is harder to change

One possible solution to the software crisis is software engineering, which is a systematic, disciplined, and quantifiable approach to software development. Software engineering aims to improve software quality, productivity, and delivery by applying principles, methods, tools, and standards. Some of the benefits of software engineering are:

- Reduction in software over budget
- High quality of software
- Less time needed for a software project
- Experienced and skilled people working over the software project
- Software meets user requirements
