### Water Fall Model in SDLC

The Waterfall Model is a linear sequential approach to software development. It is also known as a classic life cycle model. In this model, the software development process is divided into different phases, and each phase must be completed before moving on to the next one.

Here is an ASCII diagram of the Waterfall Model:

```
+-----------+
|           |
|  Planning |
|           |
+-----+-----+
      |
      v
+-----+-----+
|           |
|  Analysis |
|           |
+-----+-----+
      |
      v
+-----+-----+
|           |
|  Design   |
|           |
+-----+-----+
      |
      v
+-----+-----+
|           |
|  Coding   |
|           |
+-----+-----+
      |
      v
+-----+-----+
|           |
|  Testing  |
|           |
+-----+-----+
      |
      v
+-----+-----+
|           |
|  Release  |
|           |
+-----+-----+
```

Each phase of the Waterfall Model is distinct and separate. The output of one phase serves as the input for the next phase. The model is called "Waterfall" because the progress flows steadily downwards, like a waterfall, through the phases of Planning, Analysis, Design, Coding, Testing, and Release.
