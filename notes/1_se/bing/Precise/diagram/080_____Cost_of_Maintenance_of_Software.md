### Cost of Maintenance of Software

Here is an ASCII diagram that shows the cost of maintenance of software:

```
+------------------------+
|                        |
|  Cost of Maintenance   |
|                        |
|  +------------------+  |
|  |                  |  |
|  |  Corrective      |  |
|  |                  |  |
|  +------------------+  |
|                        |
|  +------------------+  |
|  |                  |  |
|  |  Adaptive        |  |
|  |                  |  |
|  +------------------+  |
|                        |
|  +------------------+  |
|  |                  |  |
|  |  Perfective      |  |
|  |                  |  |
|  +------------------+  |
|                        |
|  +------------------+  |
|  |                  |  |
|  |  Preventive      |  |
|  |                  |  |
|  +------------------+  |
|                        |
+------------------------+
```

The cost of maintenance of software can be divided into four categories: Corrective, Adaptive, Perfective, and Preventive. Corrective maintenance involves fixing errors and bugs in the software. Adaptive maintenance involves making changes to the software to adapt to changes in the environment. Perfective maintenance involves improving the performance or maintainability of the software. Preventive maintenance involves taking steps to prevent future problems with the software.
