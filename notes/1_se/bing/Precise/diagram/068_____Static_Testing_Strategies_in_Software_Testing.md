### Static Testing Strategies in Software Testing

Static testing is a software testing technique where the code is not executed. Instead, the code, requirements, and design documents are reviewed to find errors. There are several strategies that can be used for static testing, including:

```
+----------------------+----------------------+----------------------+
|     Informal         |     Technical        |     Inspection       |
|      Review          |      Review          |                      |
+----------------------+----------------------+----------------------+
| - No predefined      | - Led by trained     | - Led by trained     |
|   process            |   moderator          |   moderator          |
| - Not documented     | - Defined process    | - Formal process     |
| - No formal          | - Documented         | - Documented         |
|   reporting          | - Formal reporting   | - Formal reporting   |
| - Inexpensive        | - More expensive     | - Most expensive     |
| - Less effective     | - More effective     | - Most effective     |
+----------------------+----------------------+----------------------+
```
