#### Pseudo Codes in Software Design

Pseudo code is a way to describe how a computer program or algorithm should work, using natural language instead of a specific programming language. It is often used in software design to help developers visualize the flow of a program before writing actual code. Here is an example of a pseudo code for a simple program that calculates the average of a list of numbers:

```
1. Initialize a variable called `sum` to 0
2. Initialize a variable called `count` to 0
3. For each number in the list:
    a. Add the number to the `sum`
    b. Increment the `count` by 1
4. Calculate the average by dividing the `sum` by the `count`
5. Output the average
```
