#### Function Oriented Design in Software Design

Function Oriented Design is a software design methodology that focuses on the decomposition of the system into a set of interacting functions. The main idea behind this approach is to identify the major functions that the system must perform and design the software structure around these functions.

Here is an ASCII diagram that illustrates the basic concept of Function Oriented Design:

```
+----------------+
|  System        |
|                |
|  +----------+  |
|  | Function |  |
|  |    1     |  |
|  +----------+  |
|                |
|  +----------+  |
|  | Function |  |
|  |    2     |  |
|  +----------+  |
|                |
|  +----------+  |
|  | Function |  |
|  |    3     |  |
|  +----------+  |
|                |
+----------------+
```

In this diagram, the system is represented as a box that contains several smaller boxes, each representing a function. The functions interact with each other to perform the overall task of the system. The design process involves identifying the functions, determining their interactions, and organizing them in a logical and efficient manner.
