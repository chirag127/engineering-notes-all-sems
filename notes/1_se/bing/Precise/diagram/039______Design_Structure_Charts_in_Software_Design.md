#### Design Structure Charts in Software Design

Design Structure Charts (DSCs) are a graphical representation of the design of a software system. They show the hierarchical structure of the system, the modules and their relationships, and the flow of data and control between them.

Here is an example of a Design Structure Chart:

```
+----------------+
|     System     |
+----------------+
       |
       |
+----------------+
|   Subsystem 1  |
+----------------+
       |
       |
+----------------+
|   Module 1.1   |
+----------------+
       |
       |
+----------------+
|   Module 1.2   |
+----------------+
       |
       |
+----------------+
|   Module 1.3   |
+----------------+
```

In this example, the system is composed of one subsystem, which is further divided into three modules. The arrows show the flow of data and control between the different levels of the hierarchy.
