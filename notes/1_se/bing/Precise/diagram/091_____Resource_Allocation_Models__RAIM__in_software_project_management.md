### Resource Allocation Models (RAIM) in software project management

Resource Allocation Models (RAIM) are used in software project management to allocate resources to tasks in a project. Here is an ASCII diagram that represents a simple RAIM:

```
+-----------------+     +-----------------+
| Task 1          |     | Task 2          |
|                 |     |                 |
| +-------------+ |     | +-------------+ |
| | Resource A  | |     | | Resource B  | |
| +-------------+ |     | +-------------+ |
|                 |     |                 |
| +-------------+ |     | +-------------+ |
| | Resource B  | |     | | Resource C  | |
| +-------------+ |     | +-------------+ |
|                 |     |                 |
+-----------------+     +-----------------+
```
