#### Object Oriented Design in Software Design

Here is an ASCII diagram that represents the basic principles of Object Oriented Design in Software Design:

```
+----------------+
|   Class Name   |
+----------------+
| - attribute1   |
| - attribute2   |
| + method1()    |
| + method2()    |
+----------------+
```

In Object Oriented Design, a class represents an object or a concept in the software. The class has attributes (represented by the `-` symbol) that describe the characteristics of the object. The class also has methods (represented by the `+` symbol) that define the behavior of the object.

The diagram above shows a simple class with two attributes and two methods. The class name is at the top of the diagram, and the attributes and methods are listed below it.
