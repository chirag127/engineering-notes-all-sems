#### Various Size Oriented Measures in Software Design
Size-oriented measures are used to estimate the size of a software product. These measures are based on the assumption that the size of a software product is related to its functionality, complexity, and the effort required to develop it. Some of the commonly used size-oriented measures are:

1. **Lines of Code (LOC)**: This measure counts the number of lines of code in a software product. It is a simple and widely used measure, but it has some limitations. For example, it does not take into account the complexity of the code or the programming language used.

2. **Function Points (FP)**: This measure estimates the size of a software product based on its functionality. It takes into account the number of inputs, outputs, user interactions, and other factors that contribute to the functionality of the software. Function points are more complex to calculate than lines of code, but they provide a more accurate estimate of the size of a software product.

3. **Object Points (OP)**: This measure is similar to function points, but it is used for object-oriented software products. It takes into account the number of classes, methods, and attributes in the software product.

4. **Feature Points (FeP)**: This measure is similar to function points, but it is used for software products that have a large number of features. It takes into account the number of features in the software product and the complexity of each feature.

These measures can be used to estimate the size of a software product, which can then be used to estimate the effort required to develop the software, the cost of the software, and other important factors. However, it is important to note that these measures are not perfect and should be used in conjunction with other measures to get a more accurate estimate of the size of a software product.

Mnemonics: **LOC, FP, OP, FeP** are the various size-oriented measures in software design. Remember **LOC** for **Lines of Code**, **FP** for **Function Points**, **OP** for **Object Points**, and **FeP** for **Feature Points**. These measures can be used to estimate the size of a software product.
