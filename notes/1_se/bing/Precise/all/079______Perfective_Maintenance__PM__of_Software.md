#### Perfective Maintenance (PM) of Software

Perfective Maintenance (PM) of software is the process of improving the software after it has been delivered to the user. It involves making changes to the software to improve its functionality, efficiency, and maintainability. Some of the key points to remember about Perfective Maintenance (PM) of software are:

1. Perfective Maintenance is carried out to improve the software's performance, maintainability, and functionality.
2. It is an ongoing process that is carried out throughout the software's lifecycle.
3. Perfective Maintenance can involve making changes to the software's code, design, and documentation.
4. It can also involve adding new features or capabilities to the software.
5. Perfective Maintenance is important because it helps to keep the software up-to-date and relevant to the user's needs.
6. It can also help to reduce the cost of maintaining the software over time.

A mnemonic to remember the key aspects of Perfective Maintenance is **P**erformance, **M**aintainability, **F**unctionality, **O**ngoing, **C**hanges, **N**ew features, **U**p-to-date, **R**educe cost. **PMF OCNUR**.
