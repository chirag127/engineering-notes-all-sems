#### Code Inspection (Code Inspection) Static testing strategy

Code Inspection is a type of static testing strategy that involves a systematic examination of the source code of a program. It is a manual process that is carried out by a team of trained individuals, usually consisting of the author of the code, a moderator, and one or more reviewers.

The main objective of code inspection is to identify and correct defects in the code before it is released for testing. This can help to reduce the cost and time required for testing and can improve the overall quality of the software.

Here are some key points to remember about Code Inspection:

1. Code Inspection is a manual process that is carried out by a team of trained individuals.
2. The main objective of code inspection is to identify and correct defects in the code before it is released for testing.
3. Code Inspection can help to reduce the cost and time required for testing and can improve the overall quality of the software.
4. During a code inspection, the team will review the code line by line to identify any potential issues or defects.
5. The team will also check the code for compliance with coding standards and best practices.
6. Any issues or defects that are identified during the code inspection will be documented and reported to the author of the code for correction.
7. Code Inspection is a collaborative process that involves the author of the code, a moderator, and one or more reviewers.

A mnemonic to remember the key points of Code Inspection is **MOTRCCD**:

- **M**anual process
- **O**bjective is to identify and correct defects
- **T**eam of trained individuals
- **R**educe cost and time for testing
- **C**heck for compliance with coding standards
- **C**ollaborative process
- **D**ocument and report issues

In conclusion, Code Inspection is an important static testing strategy that can help to improve the quality of software by identifying and correcting defects in the code before it is released for testing. It is a collaborative process that involves a team of trained individuals working together to review the code and ensure that it meets the required standards. By using Code Inspection, software development teams can save time and money, and deliver higher quality software to their customers.
