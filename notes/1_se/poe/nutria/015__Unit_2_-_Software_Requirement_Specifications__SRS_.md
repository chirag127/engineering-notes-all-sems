
## Unit 2 - Software Requirement Specifications (SRS)

1. Software Requirement Specifications (SRS) is a document that describes the functional and non-functional requirements of a software system.

2. It is used to define the scope of a software project, including the objectives, functions, and features of the software.

3. It is important to have a clear and detailed SRS, as it provides a reference for the development team and stakeholders.

4. An SRS should include a description of the user interface, the data structures, and the algorithms used in the software.

5. It should also include a description of the system's performance, reliability, and security requirements.

6. The SRS should also include a description of the system's functional requirements, such as the input, output, and processing functions.

7. Finally, the SRS should include a description of the system's non-functional requirements, such as usability, scalability, and maintainability.
