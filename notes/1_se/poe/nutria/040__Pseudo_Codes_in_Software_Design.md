

#### Pseudo Codes in Software Design

1. Pseudo codes are a type of informal high-level description of a computer program or algorithm. 
2. Pseudo codes are used to represent the flow of a program in a concise and structured way.
3. Pseudo codes are written in plain English, making them easy to understand and follow.
4. Pseudo codes are written with the intention of being converted into a programming language.
5. Pseudo codes are written in a way that is easy to understand and follow, even if the reader is not familiar with the programming language.
6. Pseudo codes are written in a way that makes it easy to debug and modify the program.
7. Pseudo codes can also be used to document existing programs, making it easier for others to understand the program's logic.
8. Pseudo codes are often used in software design to describe the logic of a program before any code is written.
9. Pseudo codes are also used to describe algorithms, making them easier to understand and implement.
