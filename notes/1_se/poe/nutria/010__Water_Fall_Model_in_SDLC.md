
### Water Fall Model in SDLC

The Waterfall Model is an iterative software development process that follows a sequential design process. It is one of the most commonly used software development life cycle (SDLC) models.

1. Requirements Gathering and Analysis: The first step in the Waterfall Model is to define and analyze the requirements of the project. This includes gathering customer requirements and designing a system to meet those requirements.

2. System Design: System design involves creating a detailed design of the system based on the customer requirements. It includes deciding on the architecture of the system, the components that will be used, and the interfaces between the components.

3. Implementation: The implementation phase is where the actual coding of the system takes place. This includes writing the code and debugging it to make sure it works properly.

4. Testing: Testing is an important part of the Waterfall Model. It involves testing the system to make sure it meets the customer requirements and is free from bugs and errors.

5. Maintenance: The last step in the Waterfall Model is maintenance. This involves fixing any bugs or errors that are discovered during the testing phase, as well as making any necessary changes to the system to keep it up to date.
