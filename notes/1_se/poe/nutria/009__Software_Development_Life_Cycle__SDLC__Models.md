
### Software Development Life Cycle (SDLC) Models

1. Waterfall Model: The Waterfall Model is a sequential software development process, where progress flows in one direction through the phases of Requirements, Design, Implementation, Verification, and Maintenance.

2. Iterative and Incremental Model: This model is a combination of the waterfall model and iterative model. It combines the features of both the models and is used when the requirements of the software are not clear and it is expected to change frequently.

3. Spiral Model: The Spiral Model is an iterative software development process model that combines elements of both design and prototyping-in-stages, in an effort to combine advantages of top-down and bottom-up concepts.

4. V-Model: The V-Model is an extension of the waterfall model and is based on the association of a testing phase for each corresponding development stage.

5. Agile Model: The Agile Model is a process for developing software that is based on iterative and incremental development, where requirements and solutions evolve through collaboration between self-organizing, cross-functional teams.
