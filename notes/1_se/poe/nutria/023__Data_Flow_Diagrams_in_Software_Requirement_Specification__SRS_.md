
### Data Flow Diagrams in Software Requirement Specification (SRS)

- Data Flow Diagrams (DFDs) are used in Software Requirement Specification (SRS) to visualize the flow of data through a system.
- DFDs are composed of four basic components: processes, data stores, data flows, and entities.
- Processes represent the actions that are taken on data as it moves through the system.
- Data stores represent the locations where data is stored or held.
- Data flows represent the movement of data between processes and data stores.
- Entities represent the external sources and destinations of data.
- DFDs can be used to identify potential problems in the system, such as data loss or data duplication.
- DFDs can also be used to identify potential areas for improvement, such as reducing the number of steps required to complete a process.
