
### Prototype Model in SDLC

* The Prototype Model is an iterative software development process used in the software engineering life cycle.
* It is used to validate the requirements of a system before the design process begins.
* The Prototype Model consists of multiple iterations, each of which involves creating a prototype and testing it.
* The prototype is a working version of the system, but is not intended to be released to the public.
* The goal of the Prototype Model is to quickly identify and fix any issues with the design before the system is released.
* In the Prototype Model, the development team works on the system in short bursts, with each iteration producing a working prototype.
* After each iteration, the prototype is tested and any bugs or issues are identified and fixed.
* This process continues until the system meets all the requirements and is ready for release.
