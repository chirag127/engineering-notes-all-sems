## Unit 3 - Software Design

1. Software Architecture
- The structural design of a software system. It describes the components/modules of a system and the relationships between them.
- Includes high-level components and ways they interact.
- The architecture of a system determines its key properties like scalability, performance, modifiability, etc.

2. Design Patterns
- Commonly occurring solutions to software design problems.
- Eg: Singleton pattern, Factory pattern, Strategy pattern, etc.
- Allow reusing architectural knowledge and providing standard terminology/best practices.
- Help make software more flexible, reusable and maintainable.

3. Object-Oriented Design
- centers around objects, data encapsulation and methods.
- Objects are instantiated from classes, have data (attributes) and behavior (methods).
- Important concepts: inheritance, polymorphism, abstraction, coupling, cohesion, etc.
- Benefits: modularity, reusability, maintainability. Used in languages like Java, C++, Python, etc.

4. Functional Programming
- Treats computation as evaluation of mathematical functions and avoids changing-state and mutable data.
- Emphasizes functions, recursion, immutability, referential transparency.
- Benefits: concurrency, parallelism, testability, etc.
- Languages: Lisp, Haskell, Scala, Erlang, etc.
