### Iterative Enhancement Models in SDLC

1. Incremental Model: In incremental model, modules of a system are developed in increments. Each increment builds on the previous increment. The increments are delivered in multiple releases. This model reduces risk and allows user to take advantage of the project earlier.
2. Spiral Model: The spiral model focuses on risks involved in a project. Each phase starts with a risk analysis activity. Based on risks, alternative solutions and plans are identified. Every phase involves designing, building and testing increments of software.
3. Evolutionary Prototyping Model: It refers to creating prototypes in a cyclic manner. Initial prototype with some core features is created and shown to user. Further prototypes are evolved based on user feedback. This process continues till the user is satisfied with the product.
4. Agile Model: Agile methods break the product into small incremental builds. These builds are provided in iterations. Each iteration involves requirements analysis, design, coding, and testing. The customer can evaluate each build and provide feedback. Agile methods promote teamwork, accountability, and adaptability to changes.
