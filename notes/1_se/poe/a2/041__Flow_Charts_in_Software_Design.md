#### Flow Charts in Software Design

1. Flow charts are diagrams that show the flow of data or process steps in a software system. They use standardized symbols to represent steps/processes and flow direction.
2. Flow charts are a way to visually represent algorithms or process flows. They help break down complex processes into simple steps and are useful for both programmers and non-technical stakeholders to understand the overall flow.
3. The basic flow chart symbols are:
- Oval shape: Start/End
- Rectangle: Process
- Diamond: Decision
- Arrow: Flow direction
4. Flow charts can be used to outline:
- High-level system logic
- Process/workflow steps
- Pseudo code for programming logic
5. Advantages of using flow charts:
- Easy to understand
- Help identify issues/bottlenecks
- Useful documentation for system/process
- Platform independent way to represent logic
6. Limitations of flow charts:
- Can get complex for large processes
- Difficult to maintain as systems scale
- Logic can be difficult to follow for complex decisions/processes
