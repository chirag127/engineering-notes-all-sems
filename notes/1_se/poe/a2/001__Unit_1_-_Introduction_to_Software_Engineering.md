## Unit 1 - Introduction to Software Engineering

1. Software Engineering: Software Engineering is the systematic application of engineering approaches to the development of software. It involves a series of steps including analyzing problems, designing systems, and testing and maintaining software.

2. Software Development Lifecycle: The software development lifecycle (SDLC) is a structured process for developing software. The major stages of SDLC are:

- Requirements Analysis: Defining the requirements of the software to be developed.
- Design: Developing a design that satisfies the requirements.
- Implementation: Implementing the design in a programming language.
- Testing: Testing the software to identify and fix bugs.
- Deployment: Deploying the software for user use.
- Maintenance: Maintaining and updating the software as required.

3. Programming Paradigms: Programming paradigms are styles of building the structure and elements of computer programs. The major paradigms are:

- Imperative: Focus on steps to solve a problem. Examples: C, C++, Java.
- Object-oriented: Focus on objects and their interactions. Examples: Java, C++, Python.
- Functional: Avoid changing state and mutable data. Examples: Lisp, Haskell, Clojure.
- Logic: Focus on logic and proof. Examples: Prolog.

4. Software Development Methods: Software development methods provide frameworks for systematic development of software. Some popular methods are:

- Waterfall model: Sequential development of software through requirements, design, implementation, testing, and deployment phases.
- Agile methodology: Iterative development with customer collaboration. Includes methods like Scrum and Extreme Programming.
- Rapid application development: Quick development of software through prototyping and iterative refinement.
