### Waterfall Model in SDLC

1. Requirement Analysis: The first phase of SDLC is Requirement Analysis. In this phase, the requirements of the system to be developed are documented. The requirements are gathered from the user and documented in a SRS (Software Requirement Specification) document.

2. Design: The SRS document is analyzed to prepare the design of the system. The design phase transforms the user requirements into technical specifications for the system. The DRS (Design Requirement Specification) document is prepared which serves as input for the next phase.

3. Implementation: The modules are developed as per the design specifications in the implementation phase. Programming language and software tools are used to implement the system.

4. Testing: In this phase, the system is tested against the requirements to identify defects and bugs. This phase ensures that the developed system meets the user's requirements.

5. Deployment: Once the testing is done, the system is deployed in the user environment. The user starts using the system and gives feedback.

6. Maintenance: The system is maintained and updated to fix the issues, add new features, and enhance the system as per the user feedback.
