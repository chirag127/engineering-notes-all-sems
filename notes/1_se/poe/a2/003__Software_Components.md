### Software Components

1. Application software - Computer programs designed to help users perform specific tasks. Examples include word processors, spreadsheets, database management systems, etc.
2. System software - Software that interacts with computer hardware to perform basic tasks. Examples include operating systems, device drivers, firmware, etc.
3. Programming languages - Languages used to write instructions for computers to execute. Examples include Java, Python, C++, etc.
4. APIs - Interfaces that allow applications to interact with each other and access features or data. APIs use a computing language/protocol to facilitate the interaction.
5. Libraries - Collections of pre-written code that can be reused by programmers. They help reduce time required to develop applications and also ensure standardized, optimized methods are used.
6. Software frameworks - Structural support for writing programs. They include reusable code libraries, a defined programming paradigm, and a call interface. Examples include .NET Framework, Ruby on Rails, etc.
7. Software tools - Programs that aid in the software development process. Examples include compilers, debuggers, profilers, IDEs, version control systems, etc.
