#### Various Size Oriented Measures in Software Design

Here are some important points to understand the concept of size-oriented measures in software design:

1. Size-oriented measures are used to estimate the size of a software project, which is essential for determining the cost, timeline, and resources required for the project.

2. One of the most commonly used size-oriented measures is Lines of Code (LOC), which refers to the number of lines of code in the software program.

3. Another size-oriented measure is Function Points (FP), which is calculated based on the number of inputs, outputs, inquiries, files, and external interfaces in the software.

4. Object Points (OP) is another size-oriented measure that is used to estimate the size of object-oriented software projects. It considers the number of objects, methods, and attributes in the software.

5. Size-oriented measures are important because they provide a quantitative basis for estimating the effort required to develop and maintain software projects.

6. Size-oriented measures can also be used to track the progress of a software project and identify potential problems or issues that may arise during the development process.

7. However, it's important to note that size-oriented measures should not be used as the sole basis for estimating software project effort. Other factors, such as complexity, skill level of the development team, and project requirements, must also be taken into account.

8. There are many tools and techniques available for measuring software size, such as automated code analysis tools and manual code reviews. It's important to choose the right tool or technique for the specific project and development environment.

9. In conclusion, size-oriented measures are an important aspect of software design that can help estimate the size and effort required for a project. By using these measures, development teams can better plan and manage software projects, leading to more successful outcomes.
