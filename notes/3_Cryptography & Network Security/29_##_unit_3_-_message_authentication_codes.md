## Unit 3 - Message Authentication Codes
Message Authentication Codes (MACs) are cryptographic primitives used to ensure the authenticity of data. They are created by combining a secret key with the data to be authenticated, and produce a fixed-length output (the MAC). The recipient of the data can then use the same key and the data to recreate the MAC and compare it to the one received, verifying that the data has not been tampered with. MACs are commonly used in network protocols and file formats to ensure the integrity of data transmitted over untrusted networks. They are a key component of confidentiality and data integrity in many security systems.
