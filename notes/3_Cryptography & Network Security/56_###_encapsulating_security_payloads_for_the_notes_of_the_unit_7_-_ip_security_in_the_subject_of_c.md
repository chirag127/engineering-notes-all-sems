### Encapsulating security payloads for the notes of the Unit 7 - IP Security in the subject of Cryptography & Network Security
Encapsulating Security Payloads (ESP) is a protocol used to provide confidentiality, data origin authentication, and integrity protection to IP packets. It operates at the Network Layer of the OSI Model and is a component of IPsec, a suite of protocols for secure IP communication. ESP can be used in either transport or tunnel mode, depending on the desired level of security. In transport mode, ESP provides security for individual IP packets, while in tunnel mode, it provides security for the entire IP packet. ESP uses cryptographic algorithms such as AES and SHA-256 to encrypt and authenticate data. ESP also includes a sequence number to prevent replay attacks and ensure the integrity of the data. Overall, ESP is an important component of IPsec and helps to secure IP communications on the Internet.
