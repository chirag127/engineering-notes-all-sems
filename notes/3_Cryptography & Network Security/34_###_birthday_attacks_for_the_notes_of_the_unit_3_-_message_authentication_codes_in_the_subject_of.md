### birthday attacks for the notes of the Unit 3 - Message Authentication Codes in the subject of Cryptography & Network Security
A birthday attack is a type of attack that exploits the mathematical "birthday paradox" to find a collision in a hash function, which is used to produce a message authentication code (MAC). In cryptography, a hash function is used to produce a fixed-length output (the MAC) from an input of arbitrary length (the message). The goal of a birthday attack is to find two different messages that produce the same MAC, which would allow an attacker to forge a message. The attack is called a "birthday attack" because it is based on the paradox that two people in a room with just 23 other people have a better than even chance of having the same birthday. Similarly, in cryptography, finding two messages with the same MAC is considered a collision, and the birthday attack is used to find such a collision.
