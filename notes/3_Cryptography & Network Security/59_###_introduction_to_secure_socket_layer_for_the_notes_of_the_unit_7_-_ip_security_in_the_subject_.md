### Introduction to Secure Socket Layer for the notes of the Unit 7 - IP Security in the subject of Cryptography & Network Security
SSL (Secure Socket Layer) is a protocol for establishing secure links between networked computers. It was replaced by TLS (Transport Layer Security) in 1999. SSL uses public-key cryptography to encrypt data and verify the identity of the server. SSL provides confidentiality, integrity and authentication for communication over the internet. It is widely used in e-commerce, banking and other sensitive transactions. To use SSL, a website must have an SSL certificate from a trusted certificate authority (CA). The certificate contains the public key of the website, and the browser uses it to encrypt data sent to the server. SSL operates at the transport layer, between the application layer and the network layer. It is important for users to verify that a website is using SSL by checking for the padlock icon in the browser and verifying the certificate.
