### steganography for the notes of the Unit 1 - Introduction to security attacks, services and mechanism in the subject of Cryptography & Network Security
Steganography is the practice of concealing a secret message within another message or image. The goal is to hide the existence of the secret message from an unauthorized recipient. Examples include hiding a message within an image file or audio file. Steganography differs from cryptography, which is the practice of encrypting a message to prevent unauthorized access. Both techniques can be used together for added security.
