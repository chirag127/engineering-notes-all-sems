

### Inheritance in Core Java

Inheritance is one of the primary concepts in object-oriented programming (OOP). It allows one class to inherit the properties and methods of another class. This concept allows developers to create a hierarchy of classes, which can be used to model real-world objects and their relationships.

Inheritance is a powerful tool for code reuse, as it allows developers to create a base class from which other classes can inherit. This allows developers to create classes that are specialized versions of a base class.

Mnemonic for Inheritance: 

* **I** - Inheritance
* **N** - New
* **H** - Hierarchy
* **E** - Extend
* **R** - Reuse
* **I** - Interface
* **T** - Type
* **A** - Abstract
* **N** - Non-static
* **C** - Class

Advantages of Inheritance: 

* Code Reusability: Inheritance allows developers to reuse existing code, reducing the amount of code that needs to be written. 
* Increased Efficiency: By reusing existing code, developers can focus on writing code for the specific task at hand, making development more efficient. 
* Improved Maintainability: By using inheritance, developers can reduce the amount of code that needs to be maintained, as the same code can be used across multiple classes.

Disadvantages of Inheritance: 

* Increased Complexity: Inheritance can increase the complexity of the codebase, as it can lead to dependencies between classes. 
* Increased Coupling: Inheritance can lead to increased coupling between classes, as changes to a base class can have unintended consequences in derived classes. 
* Overuse: Inheritance is a powerful tool, but it should not be overused, as it can lead to an overly complex codebase.

Examples of Inheritance: 

* A `Car` class can be used as the base class for other classes, such as `SUV`, `Truck`, `Sedan`, etc. 
* A `Animal` class can be used as the base class for other classes, such as `Dog`, `Cat`, `Horse`, etc. 
* A `Shape` class can be used as the base class for other classes, such as `Circle`, `Triangle`, `Square`, etc.

Applications of Inheritance:

* GUI toolkits: Inheritance can be used to create custom widgets that are derived from existing widgets. 
* Database systems: Inheritance can be used to create custom data types that are derived from existing data types. 
* Object-oriented programming: Inheritance is one of the core concepts of object-oriented programming, and it can be used to create complex hierarchies of classes.
