
### Connecting to Internet

1. Connecting to the internet involves establishing a connection between a device and the internet. This connection can be wired, wireless, or both.
2. Wired connections are typically made using an Ethernet cable, while wireless connections can be made using Wi-Fi, Bluetooth, infrared, or cellular technologies.
3. To connect to the internet, the device needs to be configured with the appropriate settings. This includes the IP address, subnet mask, default gateway, and DNS server.
4. The IP address is a unique identifier assigned to the device, while the subnet mask is used to determine which portion of the IP address is the network address and which is the host address.
5. The default gateway is the IP address of the router, which is used to route traffic to the internet.
6. The DNS server is used to resolve domain names to IP addresses, allowing users to access websites by typing in the domain name instead of the IP address.
7. Once the device is configured with the appropriate settings, it can connect to the internet.
8. Once connected, the device can access the internet and use the various services it provides, such as web browsing, email, file sharing, and streaming services.
9. Mnemonic: PING (IP address, Subnet Mask, Default Gateway, DNS Server)
