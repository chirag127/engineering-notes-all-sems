

#### Introduction to Java

* Java is a popular, object-oriented programming language developed by Sun Microsystems in 1995. 
* It is a general-purpose language used to create a wide variety of applications, including web applications, mobile apps, and desktop applications.
* Java is a strongly typed language, meaning that all variables must be declared with a specific type before they can be used.
* Java is platform-independent, meaning that the same code can be used on multiple operating systems. 
* Java is an interpreted language, meaning that the code is compiled at runtime instead of at compile-time.
* Java is a secure language, meaning that it is designed to prevent malicious code from running on a system.
* Java is a multi-threaded language, meaning that multiple tasks can be run simultaneously.
* Java is an object-oriented language, meaning that code is organized around objects and their interactions.

Mnemonics and Learning Tricks:

* JAVA: Just A Vague Acronym 
* WORA: Write Once, Run Anywhere 
* PIE: Platform Independent and Extensible
