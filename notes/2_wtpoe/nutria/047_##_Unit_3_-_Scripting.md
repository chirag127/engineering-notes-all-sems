
## Unit 3 - Scripting

Scripting is a type of programming that involves writing scripts or code to automate tasks. It is an efficient way to automate repetitive tasks and can be used to create powerful and complex applications. Scripting languages are generally easier to learn than traditional programming languages, making them ideal for beginners.

### Mnemonics and Learning Tricks

Scripting can be made easier to learn with mnemonics and learning tricks. Some examples include:

- **S**tructure your code logically to make it easier to read and debug.
- **C**reate functions to separate different tasks.
- **R**emember to check your code for errors.
- **I**dentify and use the appropriate data types for your variables.
- **P**lan ahead to avoid repeating code.
- **T**est your code regularly to make sure it works as expected.

### Advantages

- Scripting languages are generally easier to learn than traditional programming languages.
- Scripts can be quickly modified to adapt to changing requirements.
- Scripts can automate repetitive tasks, making them more efficient.
- Scripts can be used to create powerful and complex applications.

### Disadvantages

- Scripts can be difficult to debug and maintain.
- Scripts can be vulnerable to security vulnerabilities if not properly written.
- Scripts can be difficult to optimize for performance.
- Scripts can be difficult to port to other platforms.
