
#### AWT Controls

* AWT stands for Abstract Window Toolkit. It is a set of classes provided by Java for creating graphical user interfaces (GUIs).
* AWT controls are components of a GUI that allow user interaction. Examples of AWT controls include buttons, checkboxes, labels, text fields, and scrollbars.
* AWT controls are platform dependent, meaning the same code may produce different results on different platforms.
* AWT controls are lightweight components, meaning they are rendered by the operating system rather than the Java Virtual Machine (JVM).
* AWT controls are created using the `java.awt` package.
* To create an AWT control, you must first create a `Frame` object. This is the window in which your AWT control will be displayed.
* Then, you must create the AWT control itself. This is done by instantiating a class from the `java.awt` package.
* Once the AWT control is created, it can be added to the `Frame` object using the `add()` method.
* AWT controls can be customized using the `setSize()`, `setBackground()`, and `setFont()` methods.
* AWT controls can also be given event handlers, which are methods that are called when a certain event occurs.
* Mnemonics are shortcuts that can be used to quickly access AWT controls. For example, the shortcut `Ctrl+S` can be used to save a file.
