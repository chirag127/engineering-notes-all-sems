

#### Java Applet in Core Java

* Java applets are small programs written in the Java programming language and designed to be embedded in HTML web pages.
* Java applets are usually used for interactive activities such as games, calculators, or other types of programs that require user input.
* Java applets are downloaded from a web server and run in a sandbox, an isolated environment, on the client computer.
* The Java sandbox restricts the applet from accessing the local file system, network, or other resources on the client computer.
* Java applets can also be run in a browser window, where they can access the browser's objects such as the document object model (DOM) and JavaScript objects.
* The advantages of using applets include their ability to run on any platform, their small size, and the fact that they are compiled and run in a secure environment.
* The disadvantages of using applets include their slow startup time and the fact that they require a Java-enabled browser.
* Mnemonics and learning tricks for Java Applet include:
  * **A**pplet - small program written in Java
  * **P**latform - runs on any platform
  * **P**erformance - slow startup time
  * **L**imitations - requires a Java-enabled browser
  * **E**nvironment - runs in a sandbox
  * **T**ools - accesses browser's objects such as DOM and JavaScript objects
