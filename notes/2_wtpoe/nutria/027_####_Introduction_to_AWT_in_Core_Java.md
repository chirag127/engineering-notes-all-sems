
#### Introduction to AWT in Core Java

- AWT stands for _Abstract Window Toolkit_ and it is a library of Java classes used to create graphical user interfaces (GUIs) and add rich graphics functionality to Java applications.
- AWT components are platform-independent, meaning they will look and behave the same across different platforms.
- AWT components are event-driven, meaning that they respond to user input such as mouse clicks or keyboard presses.
- AWT components are lightweight, meaning they are less resource-intensive than heavyweight components such as Swing components.
- AWT components are divided into two main categories: containers and components. Containers are components that can contain other components, such as a window or a panel. Components are the actual graphical elements, such as buttons, labels, and text fields.
- AWT components are created using the `java.awt` package and can be used to create a wide variety of graphical user interfaces.
- Common AWT components include buttons, labels, text fields, check boxes, radio buttons, menus, and scroll bars.
- Common AWT containers include frames, dialogs, and panels.
- AWT also provides a set of layout managers that can be used to arrange components within a container.
- AWT also provides a set of utility classes for drawing shapes, manipulating images, and printing documents.
- Mnemonic: AWT stands for _Abstract Window Toolkit_ and is used to create graphical user interfaces in Java.
