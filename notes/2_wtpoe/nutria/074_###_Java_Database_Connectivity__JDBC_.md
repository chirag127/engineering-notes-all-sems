
### Java Database Connectivity (JDBC)

JDBC is a Java API that enables Java programs to access a database. It provides a set of classes and interfaces that allow a Java program to connect to a database, send queries and receive results. JDBC also provides a set of classes and interfaces to create SQL statements, execute them and process the results.

**Mnemonics and Learning Tricks**

JDBC stands for Java Database Connectivity. 

**Advantages**

- JDBC is platform independent, meaning it can be used to access databases from any platform, including Windows, Mac OS, and Linux.
- JDBC is secure and reliable, as it provides authentication and encryption.
- JDBC is easy to use and understand.
- JDBC is extensible, meaning that it can be extended to support additional database systems.

**Disadvantages**

- JDBC is slower than native database access technologies, such as ODBC.
- JDBC is not as robust as native database access technologies, as it does not provide full access to all database features.
- JDBC is not as flexible as native database access technologies, as it requires the use of Java.

**Examples**

JDBC is used to access databases such as Oracle, MySQL, PostgreSQL, and Microsoft SQL Server. It is also used to access NoSQL databases such as MongoDB and Cassandra.

**Applications**

JDBC is used in a variety of applications, including web applications, desktop applications, and mobile applications. It is also used in embedded systems, such as those used in automobiles.
