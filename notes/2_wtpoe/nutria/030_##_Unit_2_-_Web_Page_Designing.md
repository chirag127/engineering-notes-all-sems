
## Unit 2 - Web Page Designing

1. Web page designing involves creating a web page that contains various elements such as text, images, videos, and other multimedia. 
2. It is important to have a clear understanding of the purpose of the web page and the target audience before starting the design process.
3. The web page should be designed with a focus on usability and accessibility, so that it is easy to use and navigate.
4. The design of the web page should be aesthetically pleasing and consistent with the overall look and feel of the website.
5. The web page should be optimized for search engine optimization (SEO) to ensure that it is easily found by potential visitors.
6. A good web page design should also be responsive, meaning that it should adjust its layout and content depending on the device it is viewed on.
7. Web page design involves the use of HTML, CSS, and JavaScript to create the structure and styling of the web page.
8. Good web page design also includes the use of web fonts, colors, and graphics to create an attractive and effective design.
9. Mnemonics and learning tricks for web page designing include remembering the structure of HTML tags, understanding the basics of CSS, and learning the basics of JavaScript.
10. Good web page design also requires an understanding of web accessibility, usability, and SEO principles.
