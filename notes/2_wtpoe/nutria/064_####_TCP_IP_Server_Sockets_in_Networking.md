
#### TCP/IP Server Sockets in Networking

* TCP/IP (Transmission Control Protocol/Internet Protocol) is the language computers use to communicate on the internet.
* TCP/IP server sockets are used to create a network connection between two computers.
* Server sockets are created on the server side and they listen for client requests.
* When a client request is received, the server socket will establish a connection with the client and transmit data.
* The server socket will keep the connection open until the client disconnects or the server socket is closed.
* The server socket will then go back to listening for client requests.
* Advantages of using TCP/IP server sockets include:
  * They are reliable and secure.
  * They are easy to use and maintain.
  * They are platform independent.
  * They are widely used and supported.
* Disadvantages of using TCP/IP server sockets include:
  * They are not as fast as other network protocols.
  * They are not as efficient as other network protocols.
  * They are more complex to configure.
  * They require more resources than other network protocols.
* Examples of applications that use TCP/IP server sockets include:
  * Web servers
  * File transfer applications
  * Email servers
  * Chat applications
  * Remote access applications
  * Gaming servers

* Mnemonics and learning tricks for TCP/IP server sockets include:
  * Think of TCP/IP as “transporting connections and packets in a protocol”.
  * Remember that server sockets are the “listeners” of the network.
  * Visualize the connection process as a “handshake” between the server and the client.
  * Think of the connection as a “tube” that carries data between the two computers.
