

# Functions in JavaScript

Functions in JavaScript are an important part of the language. They allow you to create reusable code that can be used in multiple places. Functions are also used to create objects and classes, as well as for event handling and other complex tasks.

## What is a Function?

A function is a block of code that is executed when it is called. It can take parameters as input and return a value or nothing. Functions can also be defined inside other functions, creating a nested structure.

## Anatomy of a Function

A function is made up of three parts:

1. A name: This is how you refer to the function when you want to call it.
2. Parameters: These are the values that you pass into the function when you call it.
3. The body: This is the code that is executed when the function is called.

## Defining a Function

To define a function, you use the `function` keyword followed by the function name, parameters (if any), and the body of the function.

```javascript
function myFunction(param1, param2) {
  // code to be executed
}
```

## Calling a Function

Once you have defined a function, you can call it by using its name followed by parentheses containing any parameters that the function requires.

```javascript
myFunction(param1, param2);
```
