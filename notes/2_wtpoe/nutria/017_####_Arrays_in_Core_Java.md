

#### Arrays in Core Java

- Arrays are a type of data structure used to store a collection of elements of the same type. 
- They are typically used to store a sequence of elements, such as numbers or characters. 
- Arrays in Core Java are objects that can be used to store multiple values of the same type. 
- Arrays are declared with a specified size and type. 
- The elements of an array are indexed from 0 to the size minus one. 
- Arrays can be single-dimensional, multi-dimensional, or jagged. 
- Arrays can be used to store lists of objects, such as strings, integers, or other data types. 
- Arrays can also be used to store objects of the same type.
- Arrays can be initialized with a set of values when they are declared. 
- Values can also be added to an array after it has been declared. 
- Arrays can be looped through using a for loop. 
- Arrays can be sorted using the Arrays.sort() method.
- Arrays can be searched using the binarySearch() method.

  - A - Array
  - R - Represent
  - R - Row
  - A - And
  - Y - Column
  - S - Store
  - I - Indexed
  - N - Number
