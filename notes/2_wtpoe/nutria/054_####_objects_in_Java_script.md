
# Objects in JavaScript

Objects in JavaScript are collections of key-value pairs and provide a structured way to store and manipulate data. Objects can contain primitive data types, such as numbers and strings, as well as other objects.

Objects are created using the keyword `new` and a constructor function. The constructor function defines the properties and methods of the object.

## Creating Objects

Creating an object in JavaScript is as simple as writing `var myObject = new Object();`. This creates an empty object with no properties or methods. Properties can be added to the object by using dot notation or bracket notation.

## Accessing Object Properties

Object properties can be accessed using dot notation or bracket notation. Dot notation is used when the property name is known, while bracket notation is used when the property name is unknown or contains special characters.

## Modifying Object Properties

Object properties can be modified by assigning a new value to the property. This can be done using dot notation or bracket notation.

## Deleting Object Properties

Object properties can be deleted using the `delete` keyword.

## Methods

Objects can contain methods, which are functions that can be invoked using dot notation. Methods can be used to manipulate the object's data or perform other operations.

## Constructors

Constructors are special functions that are used to create objects. They are used to set the initial values of the object's properties and methods.

## Mnemonics

Objects in JavaScript can be remembered easily using the acronym "POMM":

* **P**roperties
* **O**bjects
* **M**odifying
* **M**ethods
