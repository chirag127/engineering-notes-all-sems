

#### Manipulating in JDBC

- JDBC (Java Database Connectivity) is a Java-based data access technology that enables Java applications to access and manipulate data in a relational database. 
- JDBC provides a set of classes and interfaces that enable a Java application to connect to a database, send queries and update statements, and process the results.
- JDBC also provides a set of classes and interfaces that allow a Java application to interact with a database in a more object-oriented way, allowing the application to manipulate data in a database as if it were a collection of Java objects.
- JDBC supports two types of data manipulation: **Statement** and **PreparedStatement**. 
- **Statement** objects are used to execute SQL queries and updates, while **PreparedStatement** objects are used to execute pre-compiled SQL statements.
- JDBC also provides a set of classes and interfaces for transaction management, allowing a Java application to control when transactions are committed or rolled back.
- JDBC also provides a set of classes and interfaces for error handling, allowing a Java application to detect and handle errors that occur when accessing and manipulating data in a database.
- Mnemonics and learning tricks for manipulating in JDBC include:
  - **S**QL: Used to execute SQL queries and updates
  - **P**reparedStatement: Used to execute pre-compiled SQL statements
  - **T**ransaction: Used to control when transactions are committed or rolled back
  - **E**rror: Used to detect and handle errors that occur when accessing and manipulating data in a database.
