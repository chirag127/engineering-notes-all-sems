
## Unit 5 - Servlets

Servlets are Java programs that run on a web server and provide a way to extend the server's functionality. They are the backbone of many web applications and can be used to process requests and generate dynamic content.

#### What are the Advantages of Using Servlets?
- Servlets are platform-independent, as they are written in Java.
- Servlets are fast, as they are compiled to native machine code and can be cached in memory.
- Servlets are secure, as they are subject to the Java Security Manager.
- Servlets are extensible, as they can be extended to provide additional functionality.

#### What are the Disadvantages of Using Servlets?
- Servlets require a Java-enabled web server to run.
- Servlets require more memory and CPU than static HTML pages.
- Servlets require more development time than static HTML pages.

#### What is the Basic Structure of a Servlet?
A servlet has a basic structure that consists of a class definition, initialization parameters, and a service method. The class definition is used to define the servlet's name, the initialization parameters are used to configure the servlet, and the service method is used to process requests and generate responses.

#### What is the Life Cycle of a Servlet?
The life cycle of a servlet consists of four phases: initialization, service, destruction, and garbage collection. The initialization phase is used to initialize the servlet, the service phase is used to process requests and generate responses, the destruction phase is used to clean up resources, and the garbage collection phase is used to reclaim unused memory.
