
#### Internet Addressing in Networking

* Internet addressing is the process of assigning a unique address to each device connected to a network. This address is used to identify the device and allow communication between it and other devices on the network. 
* Internet Protocol (IP) addresses are the most commonly used type of address in networking. They are typically composed of four numbers separated by periods, and they can be either static (unchanging) or dynamic (changing).
* Subnetting is a technique used to divide a single IP address into multiple smaller addresses. This is done to allow for more efficient use of the address space and to improve network performance.
* Network Address Translation (NAT) is another technique used to address devices on a network. NAT allows multiple devices to share a single IP address, which can be used to conserve address space and improve security.
* Domain Name System (DNS) is a system used to map domain names to IP addresses. This allows users to access websites and other services using a human-readable name instead of a numerical IP address.
* Mnemonics for Internet Addressing:
    * **IP**: **I**dentify **P**eople
    * **Subnetting**: **S**ubnet **T**ranslation
    * **NAT**: **N**etwork **A**ddress **T**ranslation
    * **DNS**: **D**omain **N**ame **S**ystem
