

#### I/O in Core Java

* I/O stands for Input/Output and is a core concept in Java. It is used to read and write data from external sources, such as files, databases, and other applications. 
* Java provides a comprehensive set of I/O classes and packages that can be used to read and write data from external sources.
* Java I/O is divided into two categories: stream-based I/O and object-based I/O. Stream-based I/O is used to read and write bytes of data, while object-based I/O is used to read and write objects. 
* Stream-based I/O includes classes such as InputStream and OutputStream, which are used to read and write data from a stream. Object-based I/O includes classes such as ObjectInputStream and ObjectOutputStream, which are used to read and write objects. 
* Java also provides classes for working with files, such as FileInputStream and FileOutputStream. These classes provide methods for reading and writing data from and to files. 
* In addition to stream-based and object-based I/O, Java also provides classes for working with databases, such as JDBC and Hibernate. These classes provide methods for reading and writing data from and to databases.
* Mnemonics and learning tricks for I/O in Core Java include: 
    * **I**nput/**O**utput 
    * **S**tream-based **I**/**O** 
    * **O**bject-based **I**/**O** 
    * **F**ile **I**/**O** 
    * **J**DBC and **H**ibernate
