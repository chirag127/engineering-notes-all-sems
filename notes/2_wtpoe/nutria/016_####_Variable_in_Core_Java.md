

### Variable in Core Java

Variable in Core Java is a term used to refer to a named memory location that stores a value that can be changed during the execution of a program. Variables are used to store information such as numbers, strings, and objects. Variables are declared with a type, which determines the size and layout of the variable's memory and the range of values that can be stored within that memory.

#### Mnemonics and Learning Tricks

A helpful mnemonic to remember the different types of variables in Core Java is "SCOOB":

* **S**tatic variables
* **C**lass variables
* **O**bject variables
* **O**bject reference variables
* **B**oolean variables

It is also useful to remember that static and class variables are declared with the keyword "static" and object variables are declared without the keyword.

#### Advantages and Disadvantages

Variables in Core Java provide several advantages over other programming languages. They are easy to use, efficient and can store a variety of data types. However, they do have some disadvantages. For example, they can be difficult to debug and can lead to unexpected errors if not used correctly.

#### Examples

A simple example of a variable in Core Java is a counter variable. This type of variable stores an integer value that is incremented or decremented each time a certain action is performed. For example, the following code creates a counter variable named "num" and increments it each time the loop is executed:

```
int num = 0;

while (num < 10) {
    num++;
}
```

Another example is a string variable, which stores a sequence of characters. The following code creates a string variable named "name" and assigns it the value "John":

```
String name = "John";
```
