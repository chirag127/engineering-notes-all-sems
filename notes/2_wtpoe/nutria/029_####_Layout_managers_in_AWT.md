

#### Layout managers in AWT

* Layout managers are used to arrange components in a container in a particular manner.
* AWT (Abstract Windowing Toolkit) provides four layout managers:
  * FlowLayout
  * BorderLayout
  * GridLayout
  * CardLayout

##### FlowLayout

* FlowLayout is the simplest layout manager class.
* It organizes components in a line, one after the other, like a flow.
* It is the default layout manager for a panel.
* It is represented by `java.awt.FlowLayout` class.
* The following Mnemonic can be used to remember the FlowLayout: *F*or *L*ayout, *F*low *L*ayout.

##### BorderLayout

* BorderLayout divides the container into five regions: North, South, East, West, and Center.
* It is represented by `java.awt.BorderLayout` class.
* The following Mnemonic can be used to remember the BorderLayout: *B*order *L*ayout *E*xplained *E*asily.

##### GridLayout

* GridLayout arranges the components in a rectangular grid.
* It is represented by `java.awt.GridLayout` class.
* The following Mnemonic can be used to remember the GridLayout: *G*rid *L*ayout *E*xplained *E*asily.

##### CardLayout

* CardLayout treats each component in the container as a card.
* It is represented by `java.awt.CardLayout` class.
* The following Mnemonic can be used to remember the CardLayout: *C*ard *L*ayout *E*xplained *E*asily.
