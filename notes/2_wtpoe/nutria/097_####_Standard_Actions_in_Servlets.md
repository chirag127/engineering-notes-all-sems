

### Standard Actions in Servlets

- A servlet is a Java class that is used to extend the capabilities of a server. 
- Standard actions are methods that are used to respond to requests from a client. 
- The most commonly used standard actions are:
    - doGet() - used to process requests from a client using the HTTP GET method.
    - doPost() - used to process requests from a client using the HTTP POST method.
    - doPut() - used to process requests from a client using the HTTP PUT method.
    - doDelete() - used to process requests from a client using the HTTP DELETE method.
- These methods are called when a client sends a request to the servlet. 
- The methods can then process the request and send a response back to the client. 
- The response can be in the form of HTML, XML or JSON. 
- Standard actions are used to create dynamic web applications. 
- They are also used to create RESTful web services. 
- Mnemonics for Standard Actions in Servlets:
    - GET - "Get the data"
    - POST - "Post the data"
    - PUT - "Put the data"
    - DELETE - "Delete the data"
- Advantages: 
    - Standard actions allow for the creation of dynamic web applications. 
    - They are easy to use and understand. 
    - They are also used to create RESTful web services. 
- Disadvantages:
    - Standard actions can be difficult to debug. 
    - They can also be slow to process requests.
- Examples: 
    - A servlet can be used to create a web page that displays the current weather. 
    - It can also be used to create a web page that allows a user to search for a product.
