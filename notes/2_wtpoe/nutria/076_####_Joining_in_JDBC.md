

### Joining in JDBC

- Joining is an important concept in JDBC, which allows users to combine data from multiple tables into a single result set. 
- It is used to query data from multiple tables and can be used to join tables based on a common field between them. 
- Joins are classified into four types: inner join, left join, right join, and full join. 
- Inner join is the most commonly used join and is used to return only the rows that match the join condition. 
- Left join returns all the rows from the left table, along with the matching rows from the right table. 
- Right join is the opposite of left join and returns all the rows from the right table, along with the matching rows from the left table. 
- Full join returns all the rows from both the left and right tables, regardless of whether the join condition is met or not.
- Mnemonics:
  - INNER JOIN: "I Only Need Matching Entries"
  - LEFT JOIN: "Left Entries Only"
  - RIGHT JOIN: "Right Entries Only"
  - FULL JOIN: "Fetch All Entries"
