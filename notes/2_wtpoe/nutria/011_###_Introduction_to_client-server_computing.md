
### Introduction to Client-Server Computing

* Client-server computing is a model of computing in which the client computer requests services from a server computer. 
* The server is responsible for providing the requested services, such as data storage, file sharing, web page hosting, etc. 
* The client computer typically has less processing power and storage capacity than the server computer.
* The client-server model is used in a wide variety of applications, ranging from web hosting to online banking and gaming. 
* The client-server model can be used to create distributed computing systems, which allow multiple computers to work together to provide a service. 
* The client-server model is also used in peer-to-peer networks, where multiple computers can act as both clients and servers.
* One of the advantages of the client-server model is that it allows for scalability, as additional clients can be added to the system without having to modify the server.
* Another advantage of the client-server model is that it allows for better security, as the server can be configured to only allow certain types of requests from clients.
* Finally, the client-server model allows for better resource management, as the server can be configured to allocate resources to clients based on their needs.

Mnemonic: CSC - Client-Server Computing
