
### Protocols Governing Web

* HTTP (Hypertext Transfer Protocol) is the protocol used to exchange information between web browsers and web servers. It is the foundation of data communication for the World Wide Web. It is a stateless protocol, which means that it does not keep track of the client's requests and the server's responses. 

* HTTPS (Hypertext Transfer Protocol Secure) is an extension of HTTP that provides secure communication over the internet. It is used to secure the transmission of sensitive data, such as credit card numbers and passwords. It uses Transport Layer Security (TLS) or Secure Sockets Layer (SSL) to encrypt data before it is transmitted. 

* FTP (File Transfer Protocol) is a protocol used to transfer files between computers over the internet. It is a client-server protocol, which means that the client initiates the connection and the server responds to the requests. It is often used to download files from a server to a client machine. 

* SMTP (Simple Mail Transfer Protocol) is a protocol used for sending and receiving emails. It is a client-server protocol, which means that the client initiates the connection and the server responds to the requests. It is used to transfer emails between mail servers and is the foundation of email communication. 

* DNS (Domain Name System) is a protocol used to translate human-readable domain names into machine-readable IP addresses. It is a distributed database system that is used to store information about domain names and their associated IP addresses. It is used to route traffic on the internet. 

* SSL (Secure Sockets Layer) is a protocol used to secure communications between two computers. It is used to encrypt data before it is transmitted over the internet. It is used to secure web communications, such as web browsing and online banking. 

* DHCP (Dynamic Host Configuration Protocol) is a protocol used to assign IP addresses to computers on a network. It is used to configure the network settings of computers on a network automatically. It is used to assign IP addresses to devices on a network without the need for manual configuration.
