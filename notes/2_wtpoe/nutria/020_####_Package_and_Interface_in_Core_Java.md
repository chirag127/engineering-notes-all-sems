

#### Package and Interface in Core Java

* Packages in Java are used to group related classes and interfaces. They provide access protection and namespace management.
* An interface in Java is a collection of abstract methods, which are defined in a class and implemented by the class that extends it. Interfaces are used to achieve abstraction and multiple inheritance in Java.
* Mnemonics for Packages: **P**ackages **A**re **C**ollections **K**eeping **A**ll **G**ood **E**lements
* Mnemonics for Interfaces: **I**nterfaces **N**eed **T**o **E**xtend **F**unctionality **A**nd **C**omplete **E**xpectations

* Advantages of Packages:
    * They provide access control and namespace management. 
    * They help to organize and structure the code.
    * They also enable developers to re-use code.

* Advantages of Interfaces:
    * They provide a way to achieve abstraction.
    * They facilitate multiple inheritance.
    * They can be used to define methods that one or more classes can implement.

* Examples of Packages:
    * java.lang: Contains the classes and interfaces that are essential to the Java language.
    * java.io: Contains classes for input and output operations.
    * java.util: Contains utility classes, such as date, time and collections.

* Examples of Interfaces:
    * Runnable: Defines the run() method, which is used to execute a thread.
    * Comparable: Defines the compareTo() method, which is used to compare two objects.
    * Cloneable: Defines the clone() method, which is used to create a copy of an object.
