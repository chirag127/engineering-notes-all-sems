
#### String handling in Core Java

* Strings are a sequence of characters, represented by the `String` class in Java.
* Strings are immutable, meaning that once they are created, they cannot be changed.
* Strings can be concatenated with the `+` operator.
* Strings can be compared with the `equals()` method.
* Strings can be searched for characters and substrings with the `indexOf()` method.
* Strings can be converted to lowercase or uppercase with the `toLowerCase()` and `toUpperCase()` methods.
* Strings can be split into substrings with the `split()` method.
* Strings can be trimmed of whitespace with the `trim()` method.
* Strings can be checked for emptiness with the `isEmpty()` method.
* Strings can be checked for a certain length with the `length()` method.

A helpful mnemonic for remembering the methods of the `String` class is "CATS":

* **C**oncatenate
* **A**lter case
* **T**rim
* **S**plit
