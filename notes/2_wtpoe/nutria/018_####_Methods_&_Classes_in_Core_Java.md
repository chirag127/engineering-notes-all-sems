
#### Methods & Classes in Core Java

* **Methods** are the fundamental building blocks of Java programs. They are used to perform operations on data and to control the flow of a program. Each method has its own signature, which includes its name, parameters, and return type. 

* **Classes** are the basic building blocks of object-oriented programming. A class is a template that defines the properties and behaviors of an object. It contains fields (variables) and methods (functions) that are used to manipulate the fields.

* **Objects** are instances of classes. They are created by calling the constructor of a class. Objects can be used to access and manipulate the fields and methods of the class.

* **Constructors** are special methods that are used to create objects. They have the same name as the class and no return type.

* **Inheritance** is a way of creating a new class from an existing one. The new class (the subclass) inherits the fields and methods of the existing class (the superclass).

* **Interfaces** are collections of related methods that can be implemented by multiple classes. They are used to define a common set of behaviors for a group of classes.

* **Abstract Classes** are classes that cannot be instantiated. They are used to define a common set of behaviors for a group of classes.

* **Enumerations** are classes that contain a fixed set of constant values. They are used to define a set of related values.

* **Exceptions** are special objects that are used to indicate an error has occurred. They are used to handle errors and provide information about them.
