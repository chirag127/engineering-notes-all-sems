
## Unit 1 - Introduction to Web Technology

- Web technology is a broad term that covers the various tools and processes used to create and maintain websites and web applications. 
- It includes everything from HTML and CSS to JavaScript, AJAX, and web servers. 
- Web technology is used to create dynamic, interactive web pages that can be accessed by anyone with an internet connection. 
- HTML is the foundation of web technology, providing the basic structure and layout of a web page. 
- CSS is used to control the look and feel of a web page, allowing for customization and styling. 
- JavaScript is a scripting language used to add interactivity and dynamic content to web pages. 
- AJAX is a technology used to make web pages more responsive and interactive by allowing data to be sent and received without refreshing the page. 
- Web servers are used to host web pages and web applications, allowing them to be accessed by anyone with an internet connection.
- Mnemonics: HTML (Hypertext Markup Language), CSS (Cascading Style Sheets), JS (JavaScript), AJAX (Asynchronous JavaScript and XML) 
- Learning Trick: Remember HTML and CSS as the "bones" of a web page, while JavaScript and AJAX are the "muscles" that provide interactivity and dynamic content.
