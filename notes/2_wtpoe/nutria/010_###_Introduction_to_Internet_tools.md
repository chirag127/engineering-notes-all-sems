
### Introduction to Internet Tools

- **Internet Protocols** are the set of rules and standards that govern how data is transmitted over the internet. The most commonly used protocols are TCP/IP, HTTP, FTP, and SMTP.
- **IP Addresses** are numerical identifiers assigned to each device connected to a network. They are used to route data to the correct device.
- **Domain Names** are human-readable names assigned to websites. They are translated into IP addresses by the Domain Name System (DNS).
- **Web Browsers** are software programs used to access and view web pages. Popular browsers include Google Chrome, Mozilla Firefox, and Microsoft Edge.
- **Search Engines** are websites that index webpages and provide search results. Popular search engines include Google, Bing, and Yahoo.
- **Hypertext Markup Language (HTML)** is a coding language used to create webpages. HTML documents are composed of tags and attributes that define the structure and content of a webpage.
- **Cascading Style Sheets (CSS)** is a coding language used to define the layout and design of a webpage. CSS documents are composed of rules that define the look and feel of a webpage.
- **JavaScript** is a coding language used to add interactivity to webpages. JavaScript code is embedded in webpages and executed by the browser.
- **Mnemonics** are memory aids that can help you remember facts and concepts. For example, the acronym "HTTP" stands for "HyperText Transfer Protocol", and the acronym "FTP" stands for "File Transfer Protocol".
