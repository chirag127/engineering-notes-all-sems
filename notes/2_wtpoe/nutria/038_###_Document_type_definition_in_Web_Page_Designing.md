
### Document type definition in Web Page Designing

* Document Type Definition (DTD) is a markup language used to define the structure and elements of an XML document.
* It is the foundation for validating the structure of an XML document.
* DTDs are written in a special syntax and are used to define the legal building blocks of an XML document, including elements, attributes, and entities.
* DTDs can be used to validate the syntax of an XML document, ensuring that the document is well-formed and contains valid elements.
* DTDs can also be used to define the data types of elements and attributes, such as strings, numbers, dates, and more.
* DTDs can also be used to define relationships between elements, such as parent-child relationships and sibling relationships.
* DTDs are written in a special syntax, which is similar to HTML and XML.
* DTDs are used to define the structure of an XML document and the rules that must be followed in order to create a valid document.
* A good mnemonic for remembering DTDs is: "Define The Document".
