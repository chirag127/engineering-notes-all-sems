

### Data Type in Core Java

Data types are an important part of any programming language, and Core Java is no exception. The following is an overview of the data types available in Core Java:

1. Primitive Data Types: These are the basic data types that are built into the language and are not objects. They include boolean, byte, char, short, int, long, float, and double.

2. Reference Data Types: These are objects that are stored in the heap, and are accessed by a reference. They include classes, interfaces, arrays, and enumerations.

3. Wrapper Classes: These are classes that wrap primitive data types and provide additional functionality. They include Boolean, Byte, Character, Short, Integer, Long, Float, and Double.

Mnemonics and Learning Tricks:

1. BITS: Boolean, Integer, Short, and Byte are all primitive data types in Core Java.

2. FLOAT: Float and Double are both primitive data types in Core Java.

3. PEAR: Primitives, Enums, Arrays, and References are all data types in Core Java.

4. WRAP: Wrapper classes are used to wrap primitive data types.
