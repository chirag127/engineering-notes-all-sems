
### Types of Beans in Enterprise Java Bean

There are four types of beans in Enterprise Java Bean (EJB):

1. **Session Beans**: Session beans are used to represent the business logic of an application and are used to manage the interactions between the client and the application. They are also used to manage the application state and can be used to store data in a database.

2. **Entity Beans**: Entity beans are used to represent the data of an application. They can be used to store data in a database and can be used to interact with the client.

3. **Message-Driven Beans**: Message-driven beans are used to process messages sent to an application. They are used to process messages asynchronously and can be used to process messages from different clients.

4. **Singleton Beans**: Singleton beans are used to represent a single instance of an application. They are used to maintain the state of an application and can be used to coordinate the activities of multiple clients.

To remember the types of beans in EJB, one can use the mnemonic **SEMS**, which stands for **Session**, **Entity**, **Message-Driven**, and **Singleton**.
