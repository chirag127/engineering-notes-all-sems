
### Forms in Web Page Designing

Forms are an essential part of web page design. They allow users to interact with the page, providing a way for them to submit data and receive feedback. Forms are used for a variety of tasks, such as collecting user information, submitting orders, and providing feedback. 

Forms are composed of several different elements, including text fields, checkboxes, radio buttons, and drop-down menus. Each element is used to collect different types of data from the user. 

#### Text Fields

Text fields are used to collect short pieces of text from the user. They are typically used to collect names, email addresses, and other short pieces of information. 

#### Checkboxes

Checkboxes are used to collect boolean values from the user. They are typically used to allow the user to select multiple options from a list. 

#### Radio Buttons

Radio buttons are used to collect a single value from the user. They are typically used to allow the user to select a single option from a list. 

#### Drop-down Menus

Drop-down menus are used to collect a single value from the user. They are typically used to allow the user to select a single option from a list of many options.
