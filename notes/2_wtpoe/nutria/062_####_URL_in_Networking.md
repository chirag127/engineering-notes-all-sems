

#### URL in Networking

* URL stands for Uniform Resource Locator and it is used to locate a particular resource on the Internet. 
* It is a string of characters that identifies a specific resource on the World Wide Web (WWW). 
* A URL is composed of several parts, including a protocol, domain name, path, and query string. 
* The protocol specifies the type of resource being requested (e.g., HTTP, FTP, etc.). 
* The domain name is the name of the server hosting the resource. 
* The path is the location of the resource on the server. 
* The query string is used to pass additional information to the server. 
* URLs are used to access webpages, download files, and access other resources on the web. 
* URLs are case-sensitive and must be entered correctly in order for the resource to be accessed. 
* Mnemonic: URL = Uniform Resource Locator
