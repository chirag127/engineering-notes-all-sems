
## Unit 4 - Enterprise Java Bean

1. Enterprise Java Beans (EJBs) are server-side components that are used to create distributed applications in Java. 
2. They are written in the Java programming language and are deployed to an application server. 
3. EJBs are used to encapsulate business logic and provide a secure, transactional environment for distributed applications. 
4. There are three types of EJBs: Session Beans, Entity Beans, and Message-Driven Beans. 
5. Session Beans are used to provide a service to a client. They are used for business logic and can be either stateful or stateless. 
6. Entity Beans are used to represent persistent data in a database. They are used to store and retrieve data from a database. 
7. Message-Driven Beans are used to process asynchronous messages from a message queue. 
8. EJBs provide a secure, transactional environment for distributed applications. They are used to encapsulate business logic and provide a secure, transactional environment for distributed applications. 
9. EJBs can be deployed to any Java EE compliant application server. 
10. EJBs provide a secure, transactional environment for distributed applications, and are used to encapsulate business logic.
