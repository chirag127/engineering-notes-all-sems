## Unit 1 - Introduction to Web Technology

Web technology refers to the tools, techniques, and protocols used to create and maintain web applications and websites. This unit provides an overview of the fundamentals of web technology, including the history of the web, the architecture of web applications, and the various technologies used to create web content.

### History of the Web

1. In 1989, Tim Berners-Lee invented the World Wide Web while working at CERN.
2. The first web page was published in 1991.
3. The first web browser, called WorldWideWeb, was developed in 1990.
4. The first widely used web browser, Mosaic, was released in 1993.

### Architecture of Web Applications

1. The client-server architecture is the most common architecture used in web applications.
2. The client is typically a web browser that sends requests to a server.
3. The server processes the request and sends back a response to the client.
4. The most common protocol used in web applications is HTTP.

### Technologies Used in Web Development

1. HTML: Hypertext Markup Language is used to create the structure and content of web pages.
2. CSS: Cascading Style Sheets is used to style and format web pages.
3. JavaScript: A programming language used to create interactive web pages and web applications.
4. Server-side scripting languages: Such as PHP, Python, and Ruby are used to create dynamic web pages and web applications.
5. Databases: Such as MySQL, PostgreSQL, and Oracle are used to store and manage data in web applications.

### Mnemonics and Learning Tricks

1. To remember the order of HTML tags, use the mnemonic "My Very Educated Mother Just Served Us Nachos" (MVE MJ SUN).
2. To remember the order of CSS properties, use the mnemonic "Margaret Enjoys Eating Delicious Chocolate Syrup" (MEEDCS).

In conclusion, this unit provides a foundational understanding of web technology, including the history of the web, the architecture of web applications, and the technologies used to create web content. Understanding these fundamentals is essential for anyone interested in pursuing a career in web development.
