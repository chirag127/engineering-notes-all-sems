#### Java Applet in Core Java

Java Applets are small applications that can be executed on a web browser. They are written in Java programming language and are typically used to provide interactive features to web pages. Java Applets are a powerful tool for creating dynamic and interactive web pages.

##### Features of Java Applet

Some of the key features of Java Applets are:

- Applets are platform independent.
- Applets can be executed on any platform that supports a web browser with a Java Virtual Machine (JVM).
- Applets can be embedded in HTML pages.
- Applets can be used to create dynamic and interactive web pages.
- Applets are written in Java programming language.

##### Advantages of Java Applet

Some of the advantages of Java Applet are:

- Applets are platform independent.
- Applets can be executed on any platform that supports a web browser with a JVM.
- Applets can be embedded in HTML pages.
- Applets can be used to create dynamic and interactive web pages.
- Applets are written in Java programming language which is a widely used programming language.

##### Disadvantages of Java Applet

Some of the disadvantages of Java Applet are:

- Applets require a JVM to be installed on the client machine.
- Applets may take longer to load compared to other web technologies.
- Applets have limited access to the client machine.

##### Mnemonics and Learning Tricks

- E: Applets can be embedded in HTML pages.

##### Examples of Java Applet

Here is an example of a simple Java Applet that displays a message on a web page:

```java
import java.applet.*;
import java.awt.*;

public class HelloWorld extends Applet {
   public void paint(Graphics g) {
      g.drawString("Hello World!", 20, 20);
   }
}
```
