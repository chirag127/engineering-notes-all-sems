#### Methods & Classes in Core Java

In Java, a method is a collection of statements that perform a specific task. A class, on the other hand, is a blueprint for creating objects. Java has a rich set of methods and classes that are essential for developing robust applications. In this section, we will discuss some of the commonly used methods and classes in Core Java.

##### Methods

1. Main Method - The main method is the entry point of any Java program. It is a special method that is executed when the program is started. The main method has the following signature:

```
public static void main(String[] args) {
    // code goes here
}
```

2. toString Method - The toString method is used to convert an object to a string representation. It is defined in the Object class and can be overridden in any class. The toString method has the following signature:

```
public String toString() {
    // code goes here
}
```

3. equals Method - The equals method is used to compare two objects for equality. It is also defined in the Object class and can be overridden in any class. The equals method has the following signature:

```
public boolean equals(Object obj) {
    // code goes here
}
```

4. hashCode Method - The hashCode method is used to get a hash code value for an object. It is also defined in the Object class and can be overridden in any class. The hashCode method has the following signature:

```
public int hashCode() {
    // code goes here
}
```

##### Classes

1. String Class - The String class is used to represent a sequence of characters. It is one of the most commonly used classes in Java. The String class has many useful methods such as length, substring, and indexOf.

2. Math Class - The Math class provides a set of mathematical functions such as sin, cos, and tan. These functions are useful for performing complex calculations in Java programs.

3. ArrayList Class - The ArrayList class is used to create dynamic arrays in Java. It is a part of the Java Collection Framework and provides many useful methods such as add, remove, and size.

4. Scanner Class - The Scanner class is used to read input from the user in Java programs. It provides many useful methods such as nextInt, nextDouble, and nextLine.
