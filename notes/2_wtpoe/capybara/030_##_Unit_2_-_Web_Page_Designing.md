## Unit 2 - Web Page Designing

Web page designing is an essential skill in today's world, where the internet plays a significant role. This unit covers the fundamental concepts and skills required to design a web page. The following are the key topics covered in this unit:

1. HTML: HTML stands for Hypertext Markup Language. It is used to create the structure and content of a web page. HTML is a markup language that uses tags to define elements on a web page. Some of the essential tags used in HTML are <html>, <head>, <title>, <body>, <h1> to <h6>, <p>, <img>, <a>, etc. 

2. CSS: CSS stands for Cascading Style Sheets. It is used to style and layout a web page. CSS separates the presentation of a web page from its content. Some of the important concepts in CSS are selectors, properties, and values. CSS can be used to set the font size, color, background color, layout, and many other aspects of a web page.

3. Responsive Web Design: Responsive web design is an approach to designing a web page that makes it look good and work well on all devices, including desktops, laptops, tablets, and smartphones. The key to responsive web design is to use flexible layouts, images, and media queries. 

4. Accessibility: Accessibility is an essential aspect of web page design. It means making a web page usable for people with disabilities. Some of the important considerations in accessibility are using proper HTML markup, providing alternative text for images, using proper color contrast, providing captions for videos, and making the web page keyboard accessible.

5. Website Layout: Website layout refers to the arrangement of elements on a web page. A good website layout should be easy to navigate, visually pleasing, and functional. Some of the important considerations in website layout are using a grid system, using whitespace effectively, and placing important elements above the fold.

6. Mnemonics and Learning Tricks: Some of the learning tricks that can be helpful for web page designing are:

- Remembering the HTML tags by their function, for example, <h1> stands for heading 1, <p> stands for paragraph, and <img> stands for image.
- Using CSS frameworks like Bootstrap, which provide pre-designed templates and styles.
- Using online resources like W3Schools, which provide tutorials, examples, and references for HTML, CSS, and other web technologies.

In conclusion, web page designing is an essential skill for anyone interested in creating and maintaining a website. This unit covers the fundamental concepts and skills required for web page designing, including HTML, CSS, responsive web design, accessibility, website layout, and learning tricks.
