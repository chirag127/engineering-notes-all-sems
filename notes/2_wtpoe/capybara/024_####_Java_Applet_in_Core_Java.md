#### Java Applet in Core Java

Java Applet is a program that runs inside a web browser. It is a small application written in Java programming language. In Core Java, Java Applets are used to create dynamic and interactive web pages.

Here are some important points to keep in mind while learning about Java Applets in Core Java:

1. A Java Applet is a subclass of the java.applet.Applet class.

2. Java Applets are used to create dynamic and interactive web pages.

3. Java Applets are run in a web browser and can be used to create animations, games, and other interactive content.

4. Java Applets are platform-independent, which means that they can be run on any operating system that has a web browser.

5. Java Applets are loaded and run on the client-side, which means that they can take advantage of the client's hardware resources.

6. Java Applets are executed within a secure sandbox environment, which means that they cannot access the client's file system or other resources without the user's permission.

7. Java Applets are designed to be lightweight and fast, which makes them ideal for creating small, interactive programs that can be delivered over the internet.

8. Java Applets can communicate with other Applets running in the same web page or with Applets running on other web pages.

9. Java Applets can be embedded in HTML pages using the <applet> tag.

10. Java Applets can be developed using various Integrated Development Environments (IDEs) such as Eclipse, NetBeans, and IntelliJ IDEA.
