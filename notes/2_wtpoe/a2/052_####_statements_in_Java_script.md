#### If-Else Statement
- Used for conditional execution of code.
- Syntax: if (condition) {code to execute if true} else {code to execute if false}
- Mnemonic: If the condition is true, the code inside the if block will run, else the code in the else block will run.
- Example: if (age > 18) {console.log("Eligible to vote");} else {console.log("Not eligible to vote");}

#### Switch Statement
- Used for multiple conditional execution of code.
- Syntax: switch (expression) {case x: code; break; case y: code; break; default: code;}
- Mnemonic: The switch expression is evaluated and compared to the cases. If there is a match, that case's code is executed. The break stops further case evaluation. Default code runs if no case matches.
- Example: switch (color) {case 'red': console.log('Color is red'); break; case 'blue': console.log('Color is blue'); break; default: console.log('Color is neither red nor blue');}
