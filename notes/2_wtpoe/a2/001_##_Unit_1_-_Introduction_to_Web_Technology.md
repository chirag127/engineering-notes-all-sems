## Unit 1 - Introduction to Web Technology

### Types of Websites

- Static Websites: Consists of static HTML pages with content that does not change frequently. Information is same for all users. Examples: Personal websites, business brochure sites.
- Dynamic Websites: Content changes frequently and is customized for users. Uses server-side languages like PHP, Ruby, Python etc. Examples: E-commerce sites, social networking sites, blogs.

### Components of Websites

- HTML: Used to create web pages and structure content
- CSS: Used to style the web pages and design the look and feel
- JavaScript: Used to add interactivity and dynamic functionality to web pages
- Server-side Languages: Used to generate dynamic website content
- Databases: Used to store data and retrieve information for dynamic websites

### How Internet Works

- Understanding of client-server model and HTTP protocol
- Client (browser) sends HTTP request to server, server sends HTTP response
- URLs, domain names, IP addresses, hosting, and deployment

**Advantages of Websites:**

- Ease of access to information
- Connect people across the globe
- E-commerce and business opportunities
- Learning and education
