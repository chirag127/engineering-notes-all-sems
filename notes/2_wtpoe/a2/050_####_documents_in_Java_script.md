#### Documents in JavaScript

JavaScript supports the following types of documents:

- HTML Documents: JavaScript is embedded into HTML pages and interacts with the HTML elements and content. Some key points to remember:

HTML is used to structure the web page and display data.
JavaScript is used to add dynamic functionality and interactivity to web pages.
JavaScript code is embedded within HTML pages.

Mnemonics: HTM LOVES JS (HTML Loves JavaScript)

- XML Documents: JavaScript can also access and manipulate XML documents. Some key points to remember:

XML is used to store and transport data.
JavaScript can be used to modify XML data, extract information, validate XML, etc.
JavaScript code is embedded within XML documents or can access XML documents separately using the XMLHttpRequest object.

- JSON Documents: JavaScript Object Notation or JSON is a lightweight data interchange format based on a subset of the JavaScript language syntax. Some key points to remember:

JSON is useful for transmitting data in web applications.
JavaScript can easily convert JSON data to JavaScript objects and vice-versa using the built-in JSON methods.
JSON data can be parsed from files or HTTP responses.

Advantages:

Lightweight and readable
Language independent
Supports arrays and objects
Used for AJAX applications

Examples and Applications:

Converting JS object to/from JSON
Parsing JSON data
Sending/receiving JSON data using AJAX
Storing user preferences using local storage in JSON format
etc.
