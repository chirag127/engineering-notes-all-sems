### Protocols Governing Web

The World Wide Web works on the basis of certain standard protocols that ensure interoperability between web servers and web browsers. The major protocols governing the web are:

1. Hypertext Transfer Protocol (HTTP): HTTP is the underlying protocol of the World Wide Web. It defines how messages should be formatted and transmitted, and what actions web servers and browsers should take in response to various commands. For example, when you enter a URL into your browser, an HTTP command is sent to the web server directing it to fetch and transmit the requested webpage.

2. Hypertext Markup Language (HTML): HTML is the main markup language for creating web pages and web applications. It uses a series of elements consisting of tags enclosed in angle brackets to define the structure of a web page semantically. For example, the <html>, <head>, and <body> tags are used to define the overall structure of a page, while tags like <h1> and <p> are used to add headings and paragraphs.

3. Cascading Style Sheets (CSS): CSS is used to style the appearance of web pages written in HTML and XHTML. It separates the presentation of web pages from its content, enabling web pages to be presented in different styles. Using CSS, you can define styles for a wide range of elements including fonts, colors, layout, and animations.

4. Uniform Resource Locators (URLs): URLs are addresses that locate resources on the web. They contain the protocol (such as HTTP) followed by the domain name or IP address and optionally the path to a specific resource. For example, in the URL `https://en.wikipedia.org/wiki/Main_Page`, `https://en.wikipedia.org` is the domain name and `/wiki/Main_Page` is the path to the resource. URLs are fundamental to the functioning of the web and are used to link web pages and access resources.
