### Core Java

- Java is a class-based, object-oriented programming language that is designed to be platform independent.
- Following are some key points to learn Core Java:

**Object Oriented Programming**
- Everything in Java is an Object.
- Object has state(fields/attributes) and behavior(methods).
- Encapsulation - hiding the implementation details.
- Inheritance - acquiring the properties of the parent class.
- Polymorphism - one interface, multiple implementations.

**Exception Handling**
- Try and Catch blocks to handle checked exceptions.
- Finally block will always execute.
- Throw and Throws keywords.
- Checked vs Unchecked exceptions.

**Multithreading**
- Extending Thread class or Implementing Runnable interface.
- Starting a thread - start() method.
- Synchronization - to avoid race conditions.
- Deadlock - two threads waiting on each other indefinitely.

**Collections Framework**
- List - ArrayList, LinkedList, Vector.
- Set - HashSet, TreeSet.
- Map - HashMap, TreeMap, LinkedHashMap.
- Iterator and ListIterator interfaces to iterate.

**Serialization and Deserialization**
- Converting object into byte stream and byte stream into object respectively.
- Externalization is more flexible and requires explicit control.
- transient and static variables are not serialized.

**Annotations**
- Provide metadata to the code.
- Predefined and custom annotations.
- Used for code inspection and various other purposes.

**Generics**
- Provides type-checking at compile time and allows code to be reused.
- Upper and lower bounds to restrict the type.
- Wildcard character `?` to represent an unknown type.
