### Images in Web Page Designing

Images play an important role in web page designing and making the web page attractive and informative. Some key points about images in web page designing are:

1. Choose appropriate image format: Choose the image format wisely based on the image content and web page requirements. The most common formats are JPEG, PNG and GIF. JPEG is ideal for photographs, PNG is ideal for logos and text and GIF is ideal for images with solid colors like logos.

2. Optimize image size: The image size should be optimized so that the web page loads fast. Large size images can slow down the web page loading. Resize and compress the images to reduce the size. Do not compromise on the image quality while reducing the size.

3. Add alt text: Alt text provides alternative text description for images which is helpful for readers using screen readers. It is a good practice to add alt text to all images that convey some information or serve a purpose.

4. Maintain aspect ratio: Do not distort the aspect ratio of images. Maintain the ratio while resizing images so that the images do not look stretched or squished. This is applicable to both enlarging and reducing image size.

5. Align images properly: Align the images properly with respect to the text and other elements on the web page. Use appropriate HTML tags like `<img>` `align` attribute or CSS `float` and `display` properties to align images.

Mnemonics:

- For image format: Just Pick Correct Format (JPEG, PNG, GIF)
- For image size: Resize But Not Quality Compromise
- For alt text: Alt Text For Screen Readers
- For aspect ratio: Maintain Ratio, Avoid Distortion
- For image alignment: Align With HTML Or CSS
