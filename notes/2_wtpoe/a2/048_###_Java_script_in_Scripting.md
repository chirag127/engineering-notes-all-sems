### Java script in Scripting

JavaScript is a lightweight, interpreted programming or scripting language that is typically embedded into web pages. This allows web pages to be interactive and more dynamic.

Some key points about JavaScript in scripting:

- JavaScript is case-sensitive. Variables, function names, etc. differentiate between lowercase and uppercase letters.
- JavaScript comments are written with // for single-line comments or /* */ for multi-line comments.
- JavaScript variables do not need declarations. A variable can be created simply by assigning a value to it using var, let or const.
- JavaScript has dynamic typing. You do not need to specify data types for variables, functions, etc.
- JavaScript supports functions, objects, arrays, strings, numbers, booleans, nulls, etc.
- JavaScript can perform actions on web pages like opening new browser windows, redirecting to other pages, validating web forms, detecting web browsers, etc.
- Some useful mnemonics/learning tricks:
    - "Variables live in houses" - var lives in the global scope
    - "Let's get local" - let has block scope
    - "Const stays constant" - const has block scope and cannot be reassigned
- Examples:
    - Alert box: alert("Hello world!");
    - Prompt for input: prompt("Enter your name: ");
    - Redirect to Google: window.location = "https://google.com";
- Advantages: Easy to learn, lightweight, interactive web pages
- Disadvantages: Can be misused, code can be hard to debug
- Applications: Front-end web development, client-side scripting, game development, etc.
