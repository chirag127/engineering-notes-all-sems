### History of Internet

The internet has a long and rich history of growth and evolution. Here are the key milestones in the history of the internet:

- **1969**: The US government funds the first experimental packet switching network called ARPANET. It connected UCLA, SRI International, UCSB, and the University of Utah.
- **1971**: The email is invented. The first email is sent by Ray Tomlinson.
- **1973**: The TCP/IP communications protocols are created to allow multiple different networks to connect and form an "internet."
- **1979**: USENET is created, allowing users to exchange messages in newsgroups.
- **1983**: TCP/IP is adopted as the standard protocol for ARPANET. This marked the start of the modern Internet.
- **1989**: Tim Berners-Lee invents the World Wide Web while at CERN. He creates the first web browser computer program.
- **1990**: The first web browser for Microsoft Windows is released, giving the general public access to the World Wide Web.
- **1991**: The World Wide Web goes public, and the first web pages are created and hosted. The global Internet is formed.
- **1993**: The Mosaic web browser is introduced, making the Internet more visually engaging and easier to use.
- **1994**: The network backbone is upgraded to T3 (45 Mbps) lines to handle increased traffic. The first online shopping mall opens.
- **1995**: The network is upgraded again to OC3 (155 Mbps) lines. Amazon and eBay are founded. The Java programming language is released, enabling web pages to include interactive content.
- **1998**: Google is founded, and PayPal is established.
- **1999**: Napster peer-to-peer file sharing service is launched, challenging existing music distribution models.
- **2001**: The bubble of the dot-com boom bursts. Wikipedia is launched.
- **2003**: The MySpace social networking site is launched.
- **2004**: The Mozilla Firefox browser is released, providing competition to Internet Explorer. Facebook is founded.
- **2005**: YouTube is founded, paving the way for online video sharing.
- **2007**: Apple launches the iPhone, which popularizes the mobile app economy.
- **2010**: Over 2 billion people use the Internet. Tablets are introduced, and mobile broadband allows widespread smartphone use.
- **2016**: Over 3.7 billion people use the Internet. The Internet of Things, artificial intelligence, and virtual/augmented reality start to emerge.
