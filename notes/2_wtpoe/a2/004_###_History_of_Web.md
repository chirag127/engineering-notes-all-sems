### History of Web

The World Wide Web has a rich history going back to the late 1960s and early 1970s. Here are the major milestones in the web's development:

- In 1968, Douglas Engelbart demonstrated the oNLine System (NLS), an early hypertext system with graphics and on-screen editing.
- In 1989, Tim Berners-Lee invented the World Wide Web while at CERN. He wrote the first web browser computer program in 1990 while employed at CERN.
- In 1993, Marc Andreessen and Eric Bina introduced Mosaic, the first web browser to gain widespread popularity. It ran on Unix and Windows and had an easy-to-use interface. This led to an explosion in web use.
- In 1994, SSL (Secure Sockets Layer) was released, making it safe to transmit credit card numbers and other sensitive data on the web.
- In 1995, JavaScript was created by Brendan Eich, allowing web pages to become interactive. The PHP server-side scripting language was also released this year.
- In 1998, the schema for XML (Extensible Markup Language) was published. XML allowed users to create customized markup languages to suit their needs.
- In the early 2000s, technologies like Flash, AJAX, and CSS2 allowed web pages to include multimedia content and more interactivity. Web services were also introduced, allowing systems to communicate with each other.
- In the late 2000s and 2010s, HTML5, CSS3, and JavaScript frameworks made slick web interfaces possible. Mobile adoption of the web increased rapidly, and social networking sites like Facebook and Twitter became immensely popular.
