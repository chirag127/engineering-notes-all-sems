#### Variable in Core Java

A variable is a container which holds the value that can change. In Core Java, there are mainly 3 types of variables:

1. Local Variable: Declared inside a method, constructor or block. Visible only within that method, constructor or block.
    - Mnemonic: Think of local variable as variable with localized scope i.e. limited to a local context.
2. Instance Variable: Declared inside a class outside any method, constructor or block. Each instance (object) of the class has its own copy of the instance variable.
    - Mnemonic: Think of instance variable as variable that is instantiated whenever an instance or object of the class is created.
3. Static Variable: Also declared inside a class outside any method, constructor or block. But there is only one copy of a static variable shared by all instances (objects) of the class.
    - Mnemonic: Think of static variable as variable that is tied to the class itself rather than any instance or object of the class.

Some important points to remember:

- Variable name should be descriptive and not too long. Follow camelCase naming convention.
- Variable must be declared before use.
- Variable must be initialized before use.
- Variable type depends on the type of data it holds like int, char, float, double, boolean, etc.
- Final variables cannot be reassigned a value.
- Constant variables are usually declared as final and hold names in uppercase.
