## Unit 2 - Web Page Designing

1. HTML Basics
- HTML stands for Hypertext Markup Language
- It is the main web markup language to structure web pages
- HTML uses tags like <html>, <head>, <title>, <body>, <h1>, <p>, etc. to structure the web page
- HTML tags are enclosed within angle brackets < >
- HTML documents have a .html extension
- Example: <html> <head> <title>Page Title</title> </head> <body> <h1>My First Heading</h1> <p>My first paragraph of text</p> </body> </html>

2. HTML Version History
- HTML started as a simple document markup language by Tim Berners-Lee in 1980s
- HTML has gone through several versions from HTML 1.0 to the latest HTML 5
- Each version was improved to add more features and capabilities to HTML
- HTML 5 is the latest version with major improvements like video, audio, canvas, semantic elements, etc.
- Older browsers may not support latest HTML 5 features, so fallbacks may be required

3. HTML Semantic Elements
- HTML 5 introduced semantic elements like <header>, <footer>, <article>, <section>, etc.
- Semantic elements clearly define its purpose to both the browser and the developer
- Examples:
    - <header> for introductory content or set of navigation links
    - <footer> for footer content like copyright information
    - <article> for blog posts or forum comments
    - <section> for thematic groups of content
- Using semantic elements leads to more accessible and readable code
