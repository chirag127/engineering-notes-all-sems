#### Data type in Core Java

Data types in Java define the type of values that can be stored in variables. They determine the size and type of values that can be stored.

The main data types in Java are:

- **Primitive data types:** byte, short, int, long, float, double, boolean, char
- **Non-primitive data types:** String, Arrays, Classes, Interfaces, etc.

**Mnemonics to remember primitive data types:**

- _**B**yte_ is for _**B**ytes_ (8-bit)
- _**S**hort_ is for _**S**mall_ (16-bit)
- _**I**nt_ is for _**I**nteger_ (32-bit)
- _**L**ong_ is for _**L**arger_ (64-bit)
- _**F**loat_ has _**F**ew_ decimal points (32-bit)
- _**D**ouble_ has _**D**ecimal_ points (64-bit)
- _**B**ool_ has _**B**inary_ values (true/false)
- _**C**har_ represents a single _**C**haracter_

**Advantages of primitive data types:**

- They are faster and efficient as they are directly stored in the memory.
- They use less memory as they have fixed sizes.

**Disadvantages of primitive data types:**

- The size of the primitive data types is fixed. We cannot increase or decrease their size.
- We cannot perform many operations on primitive data types. To utilize methods, we need to convert them to non-primitive data types like String or Classes.

**Examples of primitive data types:**

- int num = 5; // Integer
- double decimal = 5.6; // Double
- char letter = 'A'; // Character
- boolean status = true; // Boolean

**Applications of primitive data types:**

- Storing numeric values in variables and calculations
- Storing single characters
- Storing true/false values for conditional logic
- And many more based on the requirement
