#### Objects in JavaScript

JavaScript is an object-oriented programming language. Everything in JavaScript is an object, with its properties and methods.

**Some important objects in JavaScript are:**

1. **Global object**: The global object refers to an object that is globally available in the browser environment. It allows you to access the browser's JavaScript environment and has methods and properties to interact with the browser. Some examples are `window`, `document`, `navigator`, etc.

**Mnemonic:** Global objects are like global variables but more powerful. They allow you to access the browser and its features.

2. **Math object**: The Math object allows you to perform mathematical tasks. Some examples are:

- `Math.random()` - generates a random number
- `Math.round()` - rounds a number
- `Math.ceil()` - rounds a number up to the nearest integer
- `Math.floor()` - rounds a number down to the nearest integer

**Mnemonic:** The Math object is your math helper. Whenever you need to do math, call upon the Math object.

3. **Date object**: The Date object allows you to work with dates and times. You can use it to get the current date and time, convert date formats, add and subtract different time intervals, etc. Some examples are:

- `new Date()` - returns the current date and time
- `getFullYear()` - returns the year
- `getMonth()` - returns the month
- `getDate()` - returns the day
- `getHours()`, `getMinutes()`, `getSeconds()` - returns the time

**Learning trick:** Remember that the Date object helps you _date_ and _time_ travel! You can get any information you need about a specific date or time or modify it.
