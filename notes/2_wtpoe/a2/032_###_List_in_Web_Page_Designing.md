### List in Web Page Designing

Lists are one of the basic formatting options available in web page designing to present a series of items in an organized manner. The lists can be ordered or unordered and help to enhance the readability of the content.

**Unordered Lists**: Unordered lists are lists marked with bullet points. They do not have any specific order and are created using `<ul>` tag. Each list item starts with `<li>` tag. For example:

<ul>
<li>Item 1</li>
<li>Item 2</li>
<li>Item 3</li>
</ul>

**Ordered Lists**: Ordered lists are lists marked with numbers or letters and are used to present items in a specific order. They are created using `<ol>` tag. Each list item starts with `<li>` tag. For example:

<ol>
<li>Step 1</li>
<li>Step 2</li>
<li>Step 3</li>
</ol>

**Nesting Lists**: Lists can be nested to create sublist under a main list item. This is done by adding another `<ul>` or `<ol>` inside a `<li>` tag. For example:

<ul>
<li>Fruits
<ul>
<li>Apples</li>
<li>Oranges</li>
<li>Bananas</li>
</ul>
</li>
<li>Vegetables
<ul>
<li>Tomatoes</li>
<li>Cabbage</li>
<li>Potatoes</li>
</ul>
</li>
</ul>
