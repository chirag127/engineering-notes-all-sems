## Unit 3 - Scripting

Scripting is a way to automate tasks through programming or script languages. Some key points about scripting:

- Scripts are sequences of commands that are interpreted and executed by a scripting engine or interpreter.
- Scripting languages are easier to learn and faster to code in compared to traditional programming languages. Some popular scripting languages are Python, JavaScript, PHP, Ruby, etc.
- Scripts are used to automate repetitive tasks, perform system administration tasks, and to glue together separate software components.
- Some common uses of scripting are:
    - Automating software builds and deployment.
    - Web development using languages like PHP, ASP, JSP, etc.
    - Automating tasks on operating systems like creating users, updating systems, etc. using shell scripts.
    - Adding functionality to applications through plugins and extensions.
- Advantages of scripting:
    - Quick and easy to code.
    - Increased productivity due to task automation.
    - Flexibility and rapid prototyping.
- Disadvantages of scripting:
    - May be less efficient than compiled languages.
    - Scripts are prone to errors and bugs.
    - Security issues if inputs are not properly sanitized.

Some mnemonics and learning tricks for scripting:

- Think of scripting as a sequence of commands (like a recipe) to automate repetitive tasks.
- Practice writing small scripts to perform common tasks like generating reports, data processing, etc. This helps in learning the basics.
- Start with an easy to learn scripting language like Python or JavaScript which have simple and readable syntax.
- Work through some project-based scripting tutorials and code samples to apply your learning.
- Keep a reference of common functions and libraries in the scripting language you are learning. This helps in efficient coding.
