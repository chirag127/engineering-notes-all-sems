#### Internet Addressing in Networking

- IP addresses: IP addresses are 32-bit numeric addresses written as four numbers separated by periods. Each device connected to the Internet is assigned a unique IP address. The IP address has two parts: network ID and host ID. The network ID identifies the network on which the device resides and the host ID identifies the specific device on that network.

- Classful IP addressing: In classful IP addressing, IP addresses are classified into five classes: A, B, C, D, and E. Classes A, B, and C are used for host addressing. Class D addresses are used for multicast applications. Class E addresses are experimental. The class of an IP address determines the structure and usage of the address.

- Classless Inter-Domain Routing (CIDR): CIDR is a method for allocating and specifying the Internet addresses. It replaces the older system of classful network design. CIDR notation is a compact way of representing an IP address and its associated routing prefix. The CIDR notation is the IP address followed by a slash and the number of significant bits in the subnet mask. For example, 192.168.2.0/24 represents the IP address 192.168.2.0 and its associated routing prefix 255.255.255.0.

- Subnetting: Subnetting is a technique used to divide a network into two or more smaller networks. It allows an organization to create multiple logical networks that exist within a single Class A, B, or C network. Subnetting allows optimal utilization of the available addresses and provides a way to control broadcast traffic. The subnet mask is used to determine the subnet and host portions of the IP address.

- Mnemonics:
-- Class A addresses: 1.0.*.*
-- Class B addresses: 130-191.*.*
-- Class C addresses: 192-223.*.*
