#### Methods & Classes in Core Java

- **Class:** A class is a blueprint that defines the structure and behavior of a type of object. Classes are fundamental components of object-oriented programming in Java.
- **Method:** A method is a block of code which only runs when it is called. Methods are used to perform certain actions, and they are also known as functions.

**Mnemonics:**
- Class: Think of a class as a category. For e.g. Dog is a class.
- Method: Think of a method as an action. For e.g. bark() is a method of the Dog class.

**Learning Tricks:**
- To memorize classes: Think of noun examples, e.g. Dog, Cat, Student. A class is like a generic type.
- To memorize methods: Think of verb examples, e.g. run(), jump(), eat(). A method is like an action.

**Advantages of Methods:**
- Avoid repetition of code.
- Increased organization and readability.
- Information hiding - hide the complexity of the code.
- Increased flexibility - methods can be reused.

**Disadvantages of Methods:**
- Extra processing time required to call and return from methods.
- Potential of making the program harder to debug due to abstraction.

**Examples of Methods:**
- `public void sayHello()`: Prints "Hello"
- `public int addNumbers(int a, int b)`: Returns sum of two numbers
- `public double calculateArea(double radius)`: Calculates and returns the area of a circle

**Applications of Methods:**
- Reusability - calling methods multiple times.
- Abstraction - hiding complex logic.
- Organizing code into logical blocks.
- Increasing the readability of code.
