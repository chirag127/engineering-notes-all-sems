#### String handling in Core Java

- Strings are immutable in Java which means once created they cannot be modified. Any operation on a String results in a new String.
- Strings can be created using double quotes "Hello" or using the new keyword new String("Hello").
- The length of a String can be found using the length() method.
- Strings can be concatenated using the + operator. For e.g. "Hello" + "World" results in "HelloWorld".
- Strings can be compared using the equals() method or the == operator. The == operator checks if two strings refer to the same object while the equals() method checks if two strings have the same content.
- The compareTo() method can be used to compare the alphabetical order of two strings. It returns a negative, zero or positive number depending on whether the first string is lesser than, equal to or greater than the second string respectively.
- The equalsIgnoreCase() method can be used to compare two strings ignoring the case.
- The startsWith() and endsWith() methods can be used to check if a string starts or ends with another string respectively.
- The contains() method can be used to check if a string contains another substring.
- The indexOf() and lastIndexOf() methods can be used to find the index of a substring in a string.
- The substring() method can be used to extract a substring from a string.
- The toUpperCase() and toLowerCase() methods can be used to convert a string to uppercase and lowercase respectively.
- The trim() method can be used to remove leading and trailing whitespaces from a string.
- Strings can be split using the split() method which splits a string based on a delimiter.
- Strings can be formatted using the format() method or the Apache Common Lang library.
