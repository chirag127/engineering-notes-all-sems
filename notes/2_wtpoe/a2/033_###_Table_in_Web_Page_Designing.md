### Table in Web Page Designing

- A table is a structured way of organizing data into rows and columns. Tables are commonly used in web pages to display data and information in an easy to read format.
- To create a table in HTML, use the <table> tag. The <table> tag encloses the entire table. Each row in the table is defined with the <tr> tag, and each column is defined with the <td> tag.
- For example:
<table>
  <tr>
    <td>Row 1, Column 1</td>
    <td>Row 1, Column 2</td>
  </tr>
  <tr>
    <td>Row 2, Column 1</td>
    <td>Row 2, Column 2</td>
  </tr>
</table>

- This will create a 2x2 table with 2 rows and 2 columns. You can add as many rows and columns as you need for your data.
- Some key attributes for the <table> tag are:

- border - specifies the width of the border around the table
- cellpadding - specifies the space between the cell content and its border
- cellspacing - specifies the space between cells
- width - specifies the width of the table

- You can also use CSS styling to customize the table further - change border styles, add background colors, rotate text, etc.
- Tables should be used for tabular data - things that logically belong in rows and columns like sports scores, product information, etc. Do not use tables for layout as there are better options available like CSS flexbox and CSS grid.
- Overall, tables allow you to present data in an organized way, but should be used appropriately and not for purposes other than displaying tabular data.
