#### I/O in Core Java

I/O in Core Java refers to the Input/Output operations that a Java program performs to communicate with the outside world. Some key points about I/O in Core Java are:

- Java provides extensive I/O support libraries to perform various types of I/O operations like reading and writing data from/to sources like files, databases, network, console, etc.
- The `java.io` package contains the primary I/O streams and readers/writers to perform I/O in Java.
- Some commonly used I/O streams are:
    - `FileInputStream` and `FileOutputStream` - To read and write binary data to/from files.
    - `BufferedInputStream` and `BufferedOutputStream` - To read and write binary data to/from files in a buffered manner for better performance.
    - `DataInputStream` and `DataOutputStream` - To read and write primitive data types to/from a source.
    - `PrintStream` - To print formatted data to a text-based output stream.
    - `Scanner` - To parse primitive types and strings using regular expressions.
- Character streams like `Reader` and `Writer` and their subclasses are used to read and write character data and strings.
- `Console` class can be used to read input and write output directly to the system console.
- Some mnemonics to remember are:
    - Use streams to read/write raw bytes.
    - Use readers/writers to read/write characters and strings.
    - Buffered streams improve read/write performance.
    - Choose streams/readers/writers based on the data source and data type.
- Examples, advantages, disadvantages, and applications of I/O streams can be discussed in detail with code snippets for better understanding.
