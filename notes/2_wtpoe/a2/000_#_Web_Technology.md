# Web Technology

## HTML

- HyperText Markup Language
- Used to structure and provide content for web pages
- Elements are denoted by tags like <html>, <head>, <title>, <body>, <h1>, <p>, etc.
- Attributes provide additional information about elements like id, class, style, etc.
- Version history: HTML, HTML 2, HTML 3.2, HTML 4, XHTML, HTML5
- Mnemonics: Every Good Boy Does Fine (for remembering order of notes on scale)

Advantages:

- Platform independent
- Easy to learn
- Multimedia support

Disadvantages:

- Static web pages
- Presentation is limited
- Security issues

Applications: Websites, web apps

## CSS

- Cascading Style Sheets
- Used to style web pages and specify how elements should be displayed
- Values of different CSS properties can be modified to change appearance of elements
- Consists of selectors and declarations block
- Different ways to include CSS: internal, external, inline
- Version history: CSS1, CSS2, CSS2.1, CSS3
- Mnemonics: (Can't Remember What CSS Stands For)
