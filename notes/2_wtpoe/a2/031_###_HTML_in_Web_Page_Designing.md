### HTML in Web Page Designing

HTML stands for Hypertext Markup Language. It is the main markup language used to create web pages. Some key points to learn about HTML for web page designing are:

1. HTML uses tags like <html>, <head>, <title>, <body>, <h1>, <p>, etc. to structure the web page and add content.
2. HTML tags are enclosed within angle brackets <>. Some tags come in pairs with opening and closing tags like <p>Paragraph</p>. Some tags are standalone like <br> for line break.
3. The <html> tag indicates the start and end of the HTML document. The <head> tag contains metadata about the page. The <title> tag specifies the title of the web page. The <body> tag contains the visible page content.
4. Headings are defined using <h1> to <h6> tags. <h1> is the highest heading level and <h6> is the lowest. They are useful for section headings.
5. Paragraphs are defined using <p> tags. Line breaks can be added using <br> tag.
6. HTML supports formatting text using tags like <b> for bold, <i> for italics, <u> for underline, etc.
7. HTML supports adding images using <img> tag and specifying the image source using src attribute.
8. HTML supports creating links to other pages using <a> anchor tag and specifying the link in href attribute.
9. HTML supports creating lists (ordered, unordered, definition) using <ol>, <ul> and <dl> tags respectively along with <li> list item tag.
10. HTML supports adding tables using <table>, <tr>, <th> and <td> tags.
11. HTML supports adding forms using <form> tag and form elements like <input>, <textarea>, <select>, <option>, etc. to take user input.
