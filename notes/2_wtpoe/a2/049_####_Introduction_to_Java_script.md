#### Introduction to JavaScript

JavaScript is a lightweight, interpreted programming or scripting language that is typically embedded into web pages. This means JavaScript code is executed by a browser instead of a central processor.

Some key points about JavaScript:

- It is case sensitive. Variable names, function names, etc. must be spelled correctly with proper capitalization.
- It is a prototype-based language. Object properties and methods can be shared via a prototype object.
- It is an event-driven language. JavaScript can react to events such as page loads, button clicks, form entry, etc. and execute code in response.
- It can act on and update HTML elements and styles. JavaScript can dynamically update web pages without requiring a refresh.
- It can validate form data. JavaScript is often used to check form input for proper data types, length, format, etc. and alert the user to any issues before submission.
- It is asynchronous. JavaScript often handles tasks in a non-blocking, asynchronous manner. This allows a web page to be responsive and functional while other processes complete.

Some useful mnemonics and tricks to learn JavaScript:

- "Semicolon"; - Remember to use semicolons to terminate statements and separate statements/expressions. Lack of semicolons is a common syntax error.
- "Brackets" [] - Square brackets are used to access array elements and with some built-in methods. Curly brackets {} are used for blocks of code and in JSON.
- "Equals equals" == - Use triple equals === for strict equality checking to check both value and type. Double equals == performs type coercion which can lead to issues.
- "Global scope" - Variables, functions, and objects defined in the global scope can be accessed from anywhere. Use variables declared with let or const to limit scope to block levels.
- "Hoisting" - Variable and function declarations are "hoisted" to the top of their scope, meaning they can be used before they are declared. However, variable assignments are not hoisted.
