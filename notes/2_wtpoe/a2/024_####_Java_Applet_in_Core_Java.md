#### Java Applet in Core Java

- Java applets are small Java programs that are embedded inside web pages and run inside a Java-enabled browser. They are designed to provide interactive features to web applications that cannot be provided by HTML alone.
- Some key points about Java applets:

1. Java applets are executed on the client side by the web browser.
2. Java applets are compiled into bytecodes before being sent to the browser. The browser's Java Virtual Machine executes the bytecodes and displays the output.
3. Java applets have limited access to resources for security reasons. They cannot access local files on the client machine or network resources other than the web page that launched them.
4. Java applets must be signed with a certificate to access privileged resources. Self-signed certificates can be used for testing but to deploy applets on public web pages, a certificate from a recognized certificate authority is required.
5. Java applets can include graphical user interfaces with buttons, text fields, etc. and can respond to user events. They can also include multimedia components.

Some tips to learn Java applets:

- Understand the client-server model and how applets fit into it. Applets are executed on the client side.
- Get familiar with the structure of a web page containing an applet - the <applet> and </applet> tags, attributes like code, width, height, etc.
- Learn how to create a basic GUI applet with components like buttons and text fields and how to handle events. Understanding Java AWT and Swing is necessary for this.
- Learn how to digitally sign applets and the importance of code signing.
- Understand the security limitations imposed on applets and why they exist.
- Look at examples of practical, real-world Java applets to understand their potential uses.
