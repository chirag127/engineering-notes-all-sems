#### Arrays in Core Java

- An array is a data structure in Java that contains a fixed number of elements of a single type.
- The elements in an array are accessed via indices. The index of the first element is 0, the second element is 1, and so on.
- To declare an array, specify the type of elements and square brackets [ ] after the type. For example, int[] ages; declares an array of integers.
- To instantiate an array, specify the size within the brackets. For example, ages = new int[10]; creates an array of 10 ints.
- The array size cannot be increased or decreased once instantiated. A new array of a different size needs to be created.
- Arrays can be single-dimensional, multidimensional or ragged. Single-dimensional arrays are the most common. Multidimensional arrays are arrays of arrays. Ragged arrays have inner arrays of different sizes.
- Some key benefits of arrays are:
    - Fixed size - provides efficiency of access. The index of an element can be calculated easily.
    - Ordered - elements are accessed based on their position in the array.
    - Fast access - accessing elements is fast since the index can be calculated quickly and elements are stored in contiguous memory locations.
- Some drawbacks of arrays are:
    - Fixed size - size cannot be increased or decreased easily. A new array needs to be created if a different size is required.
    - Inefficient indexing - if elements are not used in sequence based on their indices, retrieving elements becomes inefficient.
    - Excess space - if array is not full, the remaining space is wasted.
- Arrays can be used to store and access ordered data such as names, numbers, etc. Some examples are: storing scores of students in a class, storing product information in an ecommerce application, etc.
