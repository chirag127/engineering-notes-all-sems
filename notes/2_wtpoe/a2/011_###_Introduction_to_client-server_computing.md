### Introduction to client-server computing

In client-server computing, the workload is distributed between two computers (or processes):

- **Server**: The server handles data storage and provides services or resources to client computers. It waits for requests from clients and responds to them.
- **Client**: The client computer accesses the services and resources provided by the server. It contacts the server and requests the data or services it needs.

The key advantages of the client-server model are:

- **Centralized data**: Data is stored centrally on the server, making it easier to maintain and secure.
- **Specialized servers**: Servers can be optimized for providing services efficiently.
- **Thin clients**: Client computers can be simpler, as they don't need to store all the data and software required.

Some potential disadvantages are:

- **Reliance on network**: The network is critical for the client-server model to function. If the network is down, clients cannot access server resources.
- **Bottlenecks**: The server can become a bottleneck if it receives too many requests simultaneously. Extra servers or load balancing may be required for high loads.

A simple example of client-server computing is email:

- **Email server**: Handles storage of user emails and routing of messages.
- **Email client** (e.g. Gmail web app or Outlook): Contacts the email server and requests messages for a user. Sends new messages to the server to be routed.

More complex applications include database servers, file servers, and web servers powering websites. Client-server computing is a key distributed computing architectural model, enabling resources and data to be centralized while scaling to many users.
