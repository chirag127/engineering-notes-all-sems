#### AWT controls

The Abstract Window Toolkit (AWT) contains a set of controls/widgets which can be reused to create GUI applications:

- **Label**: displays text/image on the screen. No user input. Examples: headings, captions, images.
- **Button**: performs an action on click. Examples: Submit, Reset, Ok, Cancel buttons.
- **TextField**: accepts single-line text input from the user. Example: search field.
- **TextArea**: accepts multi-line text input from the user. Example: comment box.
- **Checkbox**: displays a checkbox which can be checked/unchecked. Example: Agree to terms checkbox.
- **List**: displays a list of items from which the user can select one. Example: list of options.
- **Choice**: similar to List but displayed as a pop-up menu.
- **Scrollbars**: used to scroll through data/menu options that don't fit on the screen. Horizontal/Vertical scrollbars.
- **Canvas**: a custom component to draw shapes/graphs.
- **Frame**: a top-level window to contain other AWT components.

**Mnemonics:**

- Label: L
- Button: B
- Textfield: T
- Textarea: A
- Checkbox: C
- List: Li
- Choice: Ch
- Scrollbars: Sc
- Canvas: Ca
- Frame: F

**Advantages:** Simple to use, portable across platforms.
**Disadvantages:** Limited UI capabilities compared to Swing.
**Applications:** Basic GUI apps like calculators, text editors.
