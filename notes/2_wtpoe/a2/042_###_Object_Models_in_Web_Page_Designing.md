### Object Models in Web Page Designing

The following are the key object models used in web page designing:

1. **Document Object Model (DOM):**
- It is a programming interface for HTML and XML documents.
- It represents the page so that programs can change the document structure, style, and content.
- The DOM is structured as nodes in a tree, with each node representing a part of the document (element, text, comment, etc.).
- **Mnemonics:** DOM is like a family tree of the web page where each HTML element is a family member.
- **Advantages:** It allows programs to easily access and update the content, structure, and styles of a web document. This enables user interactions, animations, and more.

2. **Cascading Style Sheets Object Model (CSSOM):**
- It is a set of APIs that let you programmatically read and change a web page's styles as defined by CSS.
- It converts the CSS stylesheets into objects that can be manipulated by JavaScript.
- The model consists of a hierarchy of StyleSheet objects which contain Rule objects which in turn contain Declaration objects.
- **Mnemonics:** Think of CSSOM like a wardrobe for the web page which lets you style the elements (family members from the DOM tree) by changing their dresses (CSS styles).

3. **Browser Object Model:**
- It allows JavaScript to access and control the browser and its components.
- It exposes APIs to work with tabs, windows, history, bookmarks, etc.
- For example, the `window` object represents an open window in the browser and has properties and methods to work with the current window.
- The object models together enable dynamic and interactive web pages.
