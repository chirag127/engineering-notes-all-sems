### Heuristics for the notes of the Unit 2 - Problem Solving Methods in the subject of Artificial Intelligence
Heuristics are problem-solving strategies that use shortcuts and educated guesses to find solutions. They are used in Artificial Intelligence to help solve problems that are too complex to solve using traditional algorithms. 

1. Means-Ends Analysis: This heuristic involves breaking down the problem into smaller sub-problems and finding ways to reduce the difference between the current state and the goal state. 

2. Hill Climbing: This heuristic involves searching for the best solution by making small, incremental changes to the current solution and evaluating the results. 

3. Simulated Annealing: This heuristic involves searching for the best solution by randomly changing the current solution and accepting the change if it improves the solution, or rejecting it if it makes the solution worse. 

4. Constraint Satisfaction: This heuristic involves finding a solution that satisfies a set of constraints or conditions. 

5. Local Search: This heuristic involves searching for the best solution by making small, incremental changes to the current solution and evaluating the results. 

6. Genetic Algorithms: This heuristic involves using techniques inspired by natural selection and genetics to find solutions. 

7. Beam Search: This heuristic involves searching for the best solution by keeping a limited number of solutions and choosing the best one at each step. 

8. A* Search: This heuristic involves searching for the best solution by using a combination of the cost of reaching the goal and the estimated cost of reaching the goal from the current state.
