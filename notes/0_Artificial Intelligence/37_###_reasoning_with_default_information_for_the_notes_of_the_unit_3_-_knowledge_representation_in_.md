### Reasoning with Default Information for the notes of the Unit 3 - Knowledge Representation in the subject of Artificial Intelligence
Reasoning with Default Information refers to the process of making inferences based on incomplete or uncertain information. In Artificial Intelligence, it is a method of knowledge representation that allows a system to make assumptions or draw conclusions based on what it already knows. 

This method involves using default rules or assumptions, which are assumed to be true unless proven otherwise. For example, if a system knows that all birds can fly, it can conclude that a sparrow is capable of flying without having to explicitly state this fact. 

In AI, reasoning with default information is often used in expert systems, where the system must make decisions based on limited information. It is also used in natural language processing, where the system must interpret text based on context and background knowledge. 

Overall, reasoning with default information is a useful tool for AI systems to make inferences and decisions in situations where information is incomplete or uncertain.
