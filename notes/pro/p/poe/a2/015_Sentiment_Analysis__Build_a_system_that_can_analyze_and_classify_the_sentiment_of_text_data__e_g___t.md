# Sentiment Analysis

Sentiment analysis is the process of identifying and categorizing opinions expressed in a piece of text, especially in order to determine whether the writer's attitude towards a particular topic, product, etc. is positive, negative, or neutral.

## How to build a sentiment analysis system?

1. Gather data - Collect data such as tweets, reviews, comments, etc. which needs to be analyzed. The more quality data you have, the better the sentiment analysis system can be trained.
2. Preprocess data - Clean the data by removing stop words, punctuation, special characters, etc. Stemming and lemmatization can also be done to normalize the words.
3. Feature extraction - Extract features from the data that can be used to train the machine learning model. Some common features used are bag-of-words, TF-IDF, etc.
4. Train machine learning model - Train a machine learning model such as Naive Bayes, Logistic Regression or Neural Networks on the extracted features to classify the sentiment into positive, negative or neutral.
5. Evaluate model - Evaluate the performance of the trained model using metrics such as accuracy, precision, recall, F1-score, etc. Tune the model hyperparameters to improve the performance.
6. Make predictions - Use the trained model to make predictions on new input data and classify the sentiment.

Technologies commonly used for sentiment analysis are Python, NLP, TensorFlow, Keras and NLTK.
