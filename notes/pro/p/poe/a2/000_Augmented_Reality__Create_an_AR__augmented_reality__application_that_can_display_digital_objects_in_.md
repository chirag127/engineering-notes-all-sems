# Augmented Reality

## Create an AR (augmented reality) application

1.  Display digital objects in the real world - AR applications can display 3D digital objects in the real world via the device camera. The digital objects are overlayed on the real world and appear to co-exist in the same space as the user.
2.  Interact with digital objects - Users can interact with the digital objects via touch, gestures, voice, etc. The objects can react to the interactions and the real world. For example, a digital button can open a digital door on a real wall.
3.  Technologies
    1.  Unity - A popular game engine used to develop AR experiences. It provides AR SDKs to work with ARKit, ARCore, and Vuforia.
    2.  ARKit - Apple's AR development framework for iOS devices. It uses the device camera and motion sensors to detect the real world and overlay AR experiences.
    3.  ARCore - Google's AR development framework for Android devices. Like ARKit, it uses the device sensors to enable AR.
    4.  Vuforia - A platform for developing AR experiences. It uses image recognition and machine learning to detect and track images, objects, and scenes to overlay digital objects.
    5.  C# - A programming language used to develop apps with Unity.
