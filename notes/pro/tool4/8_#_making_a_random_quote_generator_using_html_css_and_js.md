# making A Random Quote Generator using html css and js

Sure, I'd be happy to help you with creating a Random Quote Generator using HTML, CSS and JavaScript. 

Here's a step-by-step guide:

1. Create an HTML file and add the basic structure of a webpage, including the head and body.

2. In the head of the HTML file, link the CSS and JavaScript files. You can either link to external files or embed the CSS and JavaScript code within the HTML file.

3. In the body of the HTML file, create a container element to hold the quote, such as a div with an id of "quote-container".

4. Within the quote container, create a paragraph element to display the quote, and a button element to trigger the quote generation.

5. In the CSS file, style the quote container and the quote text. You can use CSS to set the font, color, and size of the text, as well as the background color and padding of the container.

6. In the JavaScript file, create an array of quotes, each consisting of a quote string and an author string.

7. Write a function to generate a random number, and use that number to select a random quote from the array.

8. Write a function to update the quote text and author in the HTML file, using the textContent property of the paragraph element and the innerHTML property of the author element.

9. Attach an event listener to the button element, so that when the button is clicked, the quote generation function is called and the quote is updated.

10. Finally, test the Random Quote Generator in your browser to make sure it's working as expected.

And that's it! With these steps, you should have a basic Random Quote Generator up and running. You can further customize it by adding additional styles, animations, or functionality as desired.
