### Characteristic of Temporal data for the notes of the Unit 5 - Real Time Operating Systems and Databases in the subject of Real Time System
Temporal data has the following characteristics:
1. Timestamp: Each record has a timestamp that indicates when it was created or updated.
2. Time-based relationships: Temporal data often has relationships with other records based on time, such as "happened before" or "happened during".
3. Time-varying: Temporal data changes over time, and the changes are stored in the database.
4. Historical data: Temporal data often has a history of changes, allowing for analysis of trends over time.
5. Time-sensitive queries: Temporal data often requires time-sensitive queries, such as finding the latest value for a given record.
