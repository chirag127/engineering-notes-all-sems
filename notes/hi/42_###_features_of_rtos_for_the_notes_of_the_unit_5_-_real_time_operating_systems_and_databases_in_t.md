### Features of RTOS for the notes of the Unit 5 - Real Time Operating Systems and Databases in the subject of Real Time System
-Preemptive Scheduling: RTOS schedules tasks based on priority, ensuring that high priority tasks are executed before low priority ones.
-Interrupt Management: RTOS handles hardware interrupts and software interrupts, allowing for efficient processing of real-time events.
-Memory Management: RTOS manages memory allocation, preventing fragmentation and ensuring efficient use of memory resources.
-Synchronization: RTOS provides mechanisms for synchronizing tasks, such as semaphores and mutexes, to ensure that tasks can communicate and coordinate with each other.
-Real-time Performance: RTOS provides predictable and consistent response times, making it suitable for real-time applications with strict timing requirements.
-Fault Tolerance: RTOS provides mechanisms for detecting and recovering from errors, ensuring that the system continues to operate even in the event of a failure.
