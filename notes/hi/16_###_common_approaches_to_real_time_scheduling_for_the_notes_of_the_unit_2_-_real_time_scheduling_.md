### Common Approaches to Real Time Scheduling for the notes of the Unit 2 - Real Time Scheduling in the subject of Real Time System
Real Time Scheduling Approaches:
1. Rate Monotonic Scheduling (RMS): assigns priority based on periodic task period, with shorter period having higher priority.
2. Earliest Deadline First (EDF): assigns priority based on task's closest deadline.
3. Least Laxity First (LLF): assigns priority based on difference between deadline and remaining execution time.
4. Hybrid Scheduling: combines elements of multiple approaches for improved performance.
5. Priority Inheritance Protocol (PIP): adjusts task priority dynamically to prevent priority inversion.
6. Deadline Monotonic Scheduling (DMS): assigns priority based on task's relative deadline.
7. Global Earliest Deadline First (G-EDF): schedules tasks on multiple processors based on EDF.
