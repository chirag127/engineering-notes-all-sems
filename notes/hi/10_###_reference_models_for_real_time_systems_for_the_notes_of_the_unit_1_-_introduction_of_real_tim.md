### Reference Models for Real Time Systems for the notes of the Unit 1 - Introduction of Real Time System in the subject of Real Time System
Reference Models for Real Time Systems:

1. Real-Time Operating System (RTOS) Model: A set of software components that provide basic services to real-time applications.

2. Real-Time Executive Model: A high-level, abstract representation of a real-time system. It defines the basic structure and behavior of the system.

3. Real-Time Communication Model: A model that defines the communication mechanisms between real-time processes, tasks, and other system components.

4. Real-Time Scheduling Model: A model that defines the scheduling of real-time tasks, processes, and other system components.

5. Real-Time Resource Management Model: A model that defines the allocation and management of system resources, such as memory and processing power, for real-time applications.

6. Real-Time Performance Model: A model that defines the performance characteristics of a real-time system, including response time, throughput, and reliability.
