### Definition for the notes of the Unit 1 - Introduction of Real Time System in the subject of Real Time System
Unit 1 - Introduction to Real Time Systems:

1. Definition: A real-time system is a computer system that processes and responds to input data within a specific time constraint.

2. Characteristics:
- Predictable and bounded response times
- Consistent performance under varying workloads
- Ability to handle multiple tasks simultaneously
- Responsiveness to external events

3. Applications:
- Defense systems (e.g. missile guidance)
- Medical systems (e.g. patient monitoring)
- Industrial control systems (e.g. process control)
- Transportation systems (e.g. air traffic control)

4. Challenges:
- Managing complexity and variability of real-world inputs
- Ensuring reliability and safety in mission-critical applications
- Balancing performance and resource utilization

5. Key concepts:
- Hard real-time systems
- Soft real-time systems
- Real-time scheduling algorithms
- Real-time communication protocols
- Real-time databases.
