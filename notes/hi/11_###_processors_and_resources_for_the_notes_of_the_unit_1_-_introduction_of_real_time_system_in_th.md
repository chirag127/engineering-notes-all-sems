### Processors and Resources for the notes of the Unit 1 - Introduction of Real Time System in the subject of Real Time System
Processors:
1. Central Processing Unit (CPU) - performs arithmetic and logical operations.
2. Microcontroller - small, integrated CPU for embedded systems.
3. Digital Signal Processor (DSP) - specialized for processing signals.

Resources:
1. Memory - stores programs and data.
2. Input/Output Devices - allow communication with the system.
3. Timers - measure time intervals.
4. Interrupts - allow the processor to respond to events.
