### Soft Real Time Systems for the notes of the Unit 1 - Introduction of Real Time System in the subject of Real Time System
Soft real-time systems are systems where deadlines are important, but missing a deadline is not catastrophic. These systems typically have less stringent requirements for response time compared to hard real-time systems. Examples of soft real-time systems include multimedia applications, scientific simulations, and control systems. 

In a soft real-time system, the system's response time is not guaranteed, but the system should still respond within a reasonable amount of time. The system's performance is usually measured in terms of the average response time or the maximum response time. 

Soft real-time systems are often designed using a priority-based scheduling algorithm, where tasks with higher priority are given more processing time compared to tasks with lower priority. This ensures that important tasks are completed in a timely manner, while less important tasks may take longer to complete. 

In conclusion, soft real-time systems are systems where deadlines are important but missing a deadline is not catastrophic. These systems are typically used in applications where response time is important but not critical, and are designed using priority-based scheduling algorithms.
