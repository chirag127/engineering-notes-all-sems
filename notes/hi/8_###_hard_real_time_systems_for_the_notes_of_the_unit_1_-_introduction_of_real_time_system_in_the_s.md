### Hard Real Time Systems for the notes of the Unit 1 - Introduction of Real Time System in the subject of Real Time System
Hard Real-Time Systems:

- Have strict deadlines for tasks, missing a deadline can have severe consequences.
- Examples: Aerospace, Military, Medical equipment.
- Tasks must be completed within a guaranteed time frame.
- System design must consider worst-case scenarios.
- Preemptive scheduling algorithms used to ensure deadlines met.
- Typically use specialized hardware and low-level programming languages.
