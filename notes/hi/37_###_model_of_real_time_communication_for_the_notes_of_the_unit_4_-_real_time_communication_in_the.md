### Model of Real Time Communication for the notes of the Unit 4 - Real Time Communication in the subject of Real Time System
Model of Real Time Communication:

1. Client-Server Model: A client sends a request to a server and the server returns a response.

2. Peer-to-Peer Model: Two or more devices communicate directly with each other without a central server.

3. Publish-Subscribe Model: A sender publishes messages to a topic and subscribers receive messages that match their interests.

4. Request-Reply Model: A request is sent to a recipient who returns a reply.

5. Push-Pull Model: A sender pushes information to a recipient who pulls the information when needed.

6. Event-Driven Model: An event triggers a response from the system.

7. Store-and-Forward Model: A sender stores a message and the recipient retrieves it later.
