### Effect of Resource Contention and Resource Access Control (RAC) for the notes of the Unit 3 - Resources Sharing in the subject of Real Time System
Resource Contention:
- Occurs when multiple processes attempt to access the same resource simultaneously
- Can lead to delays and decreased performance in real-time systems

Resource Access Control (RAC):
- A mechanism to regulate access to shared resources
- Helps prevent resource contention and ensures predictable resource utilization
- Can include priority-based scheduling, lock-based synchronization, and reservation-based allocation

Effects of RAC on real-time systems:
- Improved resource utilization and reduced delays
- Better predictability and reliability in resource allocation
- Enhanced system performance and stability 
- Increased system efficiency and responsiveness 
- Better support for real-time constraints and deadlines.
