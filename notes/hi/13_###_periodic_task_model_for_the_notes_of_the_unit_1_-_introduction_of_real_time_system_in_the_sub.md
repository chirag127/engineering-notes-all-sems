### Periodic Task Model for the notes of the Unit 1 - Introduction of Real Time System in the subject of Real Time System
The Periodic Task Model is a scheduling algorithm used in real-time systems. It schedules tasks that have a fixed period of execution time and a fixed deadline. The tasks are executed periodically, with the same period and deadline for each execution. The period defines the duration between two consecutive executions of a task and the deadline defines the maximum acceptable delay for task completion. The scheduling algorithm ensures that all tasks meet their deadlines, by assigning priority to tasks based on their period and deadline. The Periodic Task Model is suitable for real-time systems that have tasks with predictable execution time and deadlines, such as control systems, multimedia systems, and embedded systems.
