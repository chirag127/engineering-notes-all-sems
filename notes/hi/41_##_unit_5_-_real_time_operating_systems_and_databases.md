## Unit 5 - Real Time Operating Systems and Databases
Unit 5 covers the concepts of Real-Time Operating Systems (RTOS) and Databases. 

RTOS:
- A type of operating system that guarantees a predictable response time to events in real-time systems. 
- Designed to handle time-critical applications such as industrial control systems, medical equipment, and military systems. 
- Features include: preemption, prioritization, and scheduling algorithms.

Databases:
- A collection of data stored and organized in a specific manner, allowing for efficient retrieval and manipulation of the data. 
- Types of databases include: Relational, NoSQL, and Graph databases. 
- Key concepts in databases include: tables, fields, records, and SQL (Structured Query Language).
