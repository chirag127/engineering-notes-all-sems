
## Unit - 2 - Project Life Cycle and Effort Estimation for the notes of the course Software Project Management

1. **Project Life Cycle:** A project life cycle is the sequence of phases that a project passes through from its initiation to its closure. It typically consists of the following phases: initiation, planning, execution, monitoring and controlling, and closure. 

2. **Effort Estimation:** Effort estimation is the process of predicting the amount of effort required to complete a project. It is an important part of project management, as it helps to determine the resources, timeline, and cost of the project. Effort estimation can be done using various techniques such as expert judgment, analogy, and parametric estimation. 

3. **Mnemonics and Learning Tricks:** Mnemonics are memory aids that can help to remember complex concepts. They can be used to remember the steps in a project life cycle or the components of effort estimation. For example, the acronym PEPEC (Planning, Execution, Monitoring, Evaluation, and Closure) can be used to remember the steps in a project life cycle. Similarly, the acronym COCOMO (COnstruction COst MOdeling) can be used to remember the components of effort estimation. 

4. **Advantages of Project Life Cycle:** The main advantage of using a project life cycle is that it provides a structured approach to project management. It helps to ensure that all the necessary steps are taken and that the project is completed on time and within budget. Additionally, it helps to identify potential problems and risks early in the project and address them before they become serious issues. 

5. **Disadvantages of Project Life Cycle:** One of the main disadvantages of using a project life cycle is that it can be time-consuming and expensive. Additionally, it can be difficult to accurately estimate the effort required for each phase of the project, which can lead to delays and cost overruns. Finally, it can be difficult to keep track of the progress of the project, as the project may be divided into multiple phases.
