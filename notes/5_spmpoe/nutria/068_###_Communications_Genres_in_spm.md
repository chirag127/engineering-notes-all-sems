
### Communications Genres in SPM

* Point-to-Point (P2P): This is the simplest form of communication between two devices or two users. It involves a direct connection between the two parties, with no intermediary or middleman involved. P2P communication is typically used for file sharing, messaging, and other applications that require a direct connection. 

* Broadcast: In this type of communication, a single message is sent to multiple recipients at the same time. This is typically used for radio and television broadcasting, as well as for sending out notifications in an organization.

* Multicast: This is similar to broadcast, but it involves a single message being sent to a select group of recipients. It is used in applications such as online meetings, video conferencing, and streaming media.

* Mesh Network: A mesh network is a type of network where each node is connected to at least two other nodes. This type of communication is used for applications such as sensor networks, where each node is responsible for relaying messages to other nodes.

* Client-Server: This is the most common type of communication used in networks. In this type of communication, there is a central server that handles requests from clients. The server then sends the requested data back to the clients. This type of communication is used for applications such as web browsing, email, and file sharing.

* Store-and-Forward: This type of communication involves messages being sent to a central server, which then stores the message until it can be sent to the intended recipient. This type of communication is used for applications such as email and instant messaging. 

* Peer-to-Peer (P2P): This is similar to the P2P type of communication described above, but it involves multiple nodes working together to share data. This type of communication is used for applications such as file sharing and streaming media.
