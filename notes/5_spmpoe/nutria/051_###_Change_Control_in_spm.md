
### Change Control in SPM

- Change control is a process used in software project management (SPM) to ensure that changes to the project are documented and approved before implementation.
- It is important to have a change control process in place so that changes made to the project are tracked, approved and implemented in an organized manner.
- Change control is a key part of the software development life cycle (SDLC).
- The purpose of change control is to ensure that changes are properly evaluated and implemented in a controlled manner.
- Change control includes the following steps:
    1. Identify the change.
    2. Analyze the change.
    3. Approve the change.
    4. Implement the change.
    5. Monitor the change.
- Change control helps to reduce risks associated with changes to the project by ensuring that changes are properly evaluated and implemented.
- Change control also helps to ensure that the project remains on track and on budget.
- Mnemonics and learning tricks for Change Control in SPM include:
    - C.C.A.I.M. (Identify, Analyze, Approve, Implement, Monitor).
    - “I AIM to Change” (Identify, Analyze, Implement, Monitor to Change).
- Change control is a critical component of software project management and should be taken seriously.
