
### Effort and Cost Estimation Techniques in spm

- Effort and cost estimation techniques in software project management (SPM) are used to estimate the amount of time, effort and resources required to complete a software project. 
- These techniques help to identify potential risks and plan for contingencies, as well as provide a basis for project control and budgeting.
- The most commonly used effort and cost estimation techniques are:
    - **Function Point Analysis (FPA)**: FPA is a technique used to measure the size of a software system in terms of the number of functions it performs. It is used to estimate the effort and cost of a project by taking into account the number of functions and their complexity.
    - **COCOMO (Constructive Cost Model)**: COCOMO is a model used to estimate the cost and effort of software projects based on the size of the project and the type of development environment. 
    - **Delphi Method**: The Delphi method is a technique used to estimate the effort and cost of a project by asking experts to provide their estimates and then combining the results.
    - **Parametric Estimation**: Parametric estimation is a technique used to estimate the effort and cost of a project by using historical data from similar projects.
    - **Analogous Estimation**: Analogous estimation is a technique used to estimate the effort and cost of a project by comparing it to similar projects.
    - **Bottom-up Estimation**: Bottom-up estimation is a technique used to estimate the effort and cost of a project by breaking it down into smaller components and estimating the effort and cost of each component.
- Each technique has its own advantages and disadvantages, and should be chosen based on the specific requirements of the project.
- Additionally, Mnemonics and learning tricks can be used to help remember and understand the different effort and cost estimation techniques. For example, the acronym “FPA COCOMO DELPHI” can be used to remember the five techniques discussed above.
