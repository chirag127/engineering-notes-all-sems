
### Creation of Critical Paths in SPM

1. Critical Path is the sequence of activities in a project that determine the minimum duration of the project.
2. It is important to identify the critical path in order to ensure that the project is completed on time.
3. In SPM, critical paths are created using the following steps:
    1. Identify all the activities in the project.
    2. Estimate the duration of each activity.
    3. Identify the dependencies between the activities.
    4. Calculate the earliest start and finish dates for each activity.
    5. Calculate the latest start and finish dates for each activity.
    6. Identify the critical path by comparing the earliest and latest start and finish dates of each activity.
4. The critical path is the longest path from the start to the finish of the project.
5. The critical path should be monitored closely to ensure that the project is completed on time.
6. Mnemonics and learning tricks can be used to remember the steps in creating a critical path. For example, the acronym EELC (Estimate, Establish Links, Calculate Earliest, Calculate Latest) can be used to remember the steps.
