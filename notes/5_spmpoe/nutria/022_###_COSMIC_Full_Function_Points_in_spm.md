
### COSMIC Full Function Points in spm

- COSMIC Full Function Points (FFP) is a software sizing method created by the French company COSMIC (COmputer Software Measurement International Consortium).
- It is a way to measure the functional size of a software system, based on the functions it provides and the data it processes. 
- It is used to estimate the size of a software system, and is often used in software cost estimation.
- The FFP method uses a set of standard counting rules to calculate the size of a software system. 
- The rules are based on the number of functions, the number of data elements, and the complexity of the functions and data elements. 
- The size of the system is expressed in terms of Function Points (FPs), which are a measure of the amount of functionality provided by the system.
- Function Points are calculated by assigning a weight to each of the functions and data elements in the system. 
- The weight is based on the complexity of the function or data element. 
- The total number of Function Points is then calculated by summing the weights of all the functions and data elements in the system. 
- The Function Points can then be used to estimate the size of the system, and to estimate the cost of developing and maintaining the system.

- Advantages of using COSMIC FFP include:
  - It is a relatively simple and straightforward method for measuring the functional size of a software system.
  - It is a well-established and widely-used method for software sizing.
  - It provides a consistent and objective measure of the size of a software system.
- Disadvantages of using COSMIC FFP include:
