## Cost Schedules in spm

A cost schedule is a table that shows the costs incurred and earned at different stages of a project. It is an important tool used in spm to monitor the financial progress of a project and take corrective actions if required.

Some key points about cost schedules in spm:

1. Cost schedules are prepared during project planning and updated regularly as the project progresses. They show planned and actual costs at different stages of the project.
2. Costs are categorized into direct costs and indirect costs. Direct costs are those that can be directly attributed to the project like raw materials and labor. Indirect costs are overhead costs like rent and administration expenses.
3. The total budget for the project is allocated to different cost categories and time periods in the cost schedule. This helps in monitoring if the costs are within budget and taking action if there are variances.
4. Earned value analysis uses the cost schedules to check if the project is on track by comparing the earned value (EV) to the planned value (PV) and actual costs (AC). The key metrics of schedule variance (SV), cost variance (CV) and cost performance index (CPI) are calculated from the cost schedule.
5. Additional columns for forecasted costs and a cumulative cost total are useful to predict the final cost of the project and check for major deviations from the budget.

Some mnemonics to remember:

- PV: Planned Value, what you planned to spend by now
- EV: Earned Value, what you actually spent according to the plan
- AC: Actual Cost, what you actually spent

SV = EV - PV; CV = EV - AC; CPI = EV/AC

Cost schedules provide a simple way to track project costs and take corrective actions to control costs. They are a key input for earned value analysis to monitor project performance.
