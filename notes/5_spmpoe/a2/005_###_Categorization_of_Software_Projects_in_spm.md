### Categorization of Software Projects in spm

The following are the major categories of software projects:

1. System Software: System software includes the operating system which runs on the computer and enables applications software to function. Examples are Windows, Linux, etc. It also includes software deployed to manage and monitor the computer system and network such as antivirus software, software firewalls, etc.
2. Application Software: Application software are programs designed to perform specific tasks for users. Examples are word processors, spreadsheets, database management systems, multimedia software, etc.
3. Custom Software: Custom software is designed and developed to meet the specific needs of an organization or user. It is tailored to the requirements of the organization or user. Examples are enterprise resource planning systems, customer relationship management systems, etc. developed for a specific organization.
4. Open-source Software: Open-source software has source code that is freely available for anyone to use, modify and share. The source code is open to public. Examples are Mozilla Firefox, Google Chrome, Linux operating system, etc.
5. Proprietary Software: Proprietary software has restricted access to source code. It is copyrighted and distributed under a license. The user can only use the software and not modify the source code. Examples are Microsoft Windows, Adobe Photoshop, etc.
