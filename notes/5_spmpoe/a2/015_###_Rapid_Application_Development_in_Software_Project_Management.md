### Rapid Application Development in Software Project Management

Rapid Application Development (RAD) is an iterative software development process aimed at reducing development time. It emphasizes on developing prototypes and obtaining user feedback early in the development cycle. Some key characteristics of RAD are:

- Focus on reusability: By using previously developed prototypes and software components, development time can be reduced.
- Use of prototypes: Early development of prototypes to get user feedback and requirements. Prototypes are iteratively refined to get the final product.
- Parallel development: Team is divided into smaller groups that work in parallel, this reduces overall development time.
- Emphasis on user involvement: Constant user feedback is taken throughout the development cycle.
- Use of CASE tools: Use of Computer Aided Software Engineering (CASE) tools and code generators to speed up the process.

Advantages:
- Reduced development time and costs.
- User involvement leads to development of more desirable product.
- Parallel development reduces time.

Disadvantages:
- Requires highly skilled developers and designers.
- Risk of not meeting deadlines if user feedback is delayed.
- Inflexible if requirements change.
- May lead to less robust software if time is strictly constrained.

Some mnemonics to remember characteristics:
PRUFCC: Prototypes, Reuse, User involvement, Fast, Cheap, Parallelism

Applications: Developing small or medium sized systems with tight timelines, internal tools development, website development, etc.
