### Earned Value Analysis in spm

Earned Value Analysis (EVA) is a project management technique that measures the performance of a project against planned progress. It integrates scope, cost, and schedule measures to help assess project performance and forecast future project outcomes.

Key points to learn:

1. Planned Value (PV): The authorized budget assigned to the work to be accomplished for a schedule activity or work breakdown structure component.
2. Earned Value (EV): The measurable physical progress plus the approved budget for that work. It is the budgeted cost of work performed during a given period.
3. Actual Cost (AC): The realized cost incurred for the work performed on an activity during a given period.

Formulas to remember:

- Cost Variance (CV) = Earned Value (EV) - Actual Cost (AC)
- Schedule Variance (SV) = Earned Value (EV) - Planned Value (PV)
- Cost Performance Index (CPI) = Earned Value (EV) / Actual Cost (AC)
- Schedule Performance Index (SPI) = Earned Value (EV) / Planned Value (PV)

Advantages:

- Integrates scope, cost and schedule measures to give a comprehensive view of project health.
- Forecasts project outcomes and variances.
- Identifies potential issues early to take corrective actions.

Disadvantages:

- Requires extensive planning to establish the baselines.
- Can be difficult to implement due to variances in work and cost estimation.
- Does not indicate the root causes of variances which need to be further analyzed.
