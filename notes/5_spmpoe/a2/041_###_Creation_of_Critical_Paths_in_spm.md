### Creation of Critical Paths in spm

The following steps are involved in creating critical paths in spm:

1. Identify all activities - List down all the activities involved in the project. These activities are represented by nodes in the network diagram.
2. Determine dependencies - Determine the dependencies between the activities. Identify which activities must be completed before the next activity can start. These dependencies are represented by arrows in the network diagram.
3. Draw the network diagram - Draw the network diagram with activities as nodes and dependencies as arrows. The network diagram gives a visual representation of the project schedule.
4. Identify critical path - The critical path is the longest path through the network diagram. It determines the minimum project completion time. To identify the critical path:
    - Find all paths from start to finish
    - Determine the duration of each path
    - The path with the longest duration is the critical path

**Mnemonic:** "DEPIC" - Dependencies, Enter, Paths, Identify, Critical

**Advantage:** Identification of critical path helps in scheduling the project efficiently by focusing resources on critical activities.
**Disadvantage:** Small delays in critical activities can lead to delays in the overall project. Proper risk mitigation strategies need to be in place to avoid delays in critical path.
