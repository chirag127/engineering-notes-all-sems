## Activities in spm

The following are the main activities performed in simple programmable machine (spm):

1. Fetch: The instruction is fetched from the memory address specified by the program counter. The program counter is then incremented to point to the next instruction.
2. Decode: The fetched instruction is decoded to identify the operation to be performed and the operands required.
3. Read operands: The operands are read from the registers or memory as specified in the instruction.
4. Execute: The operation specified in the instruction is executed on the operands. This may involve arithmetic/logical operations or data transfer to/from memory/registers.
5. Write result: The result is written to the destination as specified in the instruction. This may be a register or a memory location.

**Mnemonics to remember the activities:**

Please Do Read and Execute (P-Fetch, D-Decode, R-Read operands, E-Execute, W-Write result)

**Advantages:** Simple to implement, Fast
**Disadvantages:** Less powerful, Limited set of instructions
**Applications:** Used in old processors, Microcontrollers, etc.
