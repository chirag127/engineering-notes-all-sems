### Activities in Software Project Management

The core activities involved in Software Project Management are:

1.  Planning: This is the first and foremost activity where the project manager identifies the scope, tasks, schedules, resources, and budgets required for the project. Some learning tricks to remember the key planning activities are:
    -   WBS: Work Breakdown Structure - breaking down the project into smaller manageable tasks
    -  GANTT: Gantt Chart - visual representation of the project schedule
    -  PERT: Program Evaluation and Review Technique - analyzing and estimating project timelines
    -  CPM: Critical Path Method - identifying critical and non-critical tasks
2.  Estimation: This involves estimating the effort and cost required for each task identified in the Planning process. Some estimation techniques are:
    -  Expert Judgement: Relying on experts' experience to provide estimates
    -  Analogous Estimation: Basing estimates on historical data from similar projects
    -  Parametric Modelling: Using mathematical models to calculate estimates based on project parameters
3.  Design: The design of the software product is prepared and reviewed in this stage. Prototypes and Proof of Concepts are developed.
4.  Development: The actual development of the software product is done in this stage. Programming, testing, and integration of modules are completed.
5.  Testing: Thorough testing of the software product is performed in this stage to identify and fix any bugs or defects. Different testing levels like Unit, Integration, System, and Acceptance Testing are carried out.
6.  Deployment: The final software product is deployed and made available for actual use by the end-users.
7.  Monitoring and Control: The project manager closely monitors the progress, budget, resources, quality, and risks throughout the project lifecycle and takes corrective actions whenever required to ensure the project delivers as per plans.

The above points cover the key activities in Software Project Management. Diagrams, examples, and more details can be included for each activity if required. The activities are carried out systematically and iteratively as per the chosen project management methodology like Agile, Waterfall, etc. to successfully deliver the software project.
