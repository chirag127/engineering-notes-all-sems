### Network Planning Models in spm

The following are the major network planning models used in spm:

1. Tree topology:
- Hierarchical model with a root node at the top and additional levels of nodes branching out
- Data flows in only one direction from root to leaves
- Easy to understand and implement but not robust as a single point of failure at root nodes affects the whole network
- Mnemonic: Think of a tree with roots, branches, and leaves to remember the hierarchical structure and uni-directional data flow

2. Ring topology:
- Nodes are connected in a closed loop, forming a ring
- Data travels in only one direction around the ring
- robust as there is no single point of failure but adding or removing nodes disrupts the network temporarily
- Mnemonic: Think of a ring to remember the circular connection between nodes and uni-directional data flow

3. Star topology:
- All nodes connect to a central switch
- Data flows from nodes to the central switch
- Easy to set up and maintain but the central switch is a single point of failure
- Mnemonic: Think of a star shape with all points connecting to the center to remember all nodes connecting to a central switch
