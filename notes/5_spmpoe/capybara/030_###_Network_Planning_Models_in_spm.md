### Network Planning Models in SPM

Network planning models are an essential part of Project Management. They help in creating a roadmap for the project by identifying the tasks, dependencies, and timelines. In this section, we will discuss the different network planning models used in SPM.

#### 1. Critical Path Method (CPM)

The Critical Path Method is one of the most popular network planning models used in SPM. It helps in identifying the critical path, which is the longest path of dependent activities that determines the overall project duration. CPM is useful in identifying the tasks that have no slack time, and any delay in these tasks will delay the entire project.

#### 2. Program Evaluation and Review Technique (PERT)

PERT is a probabilistic network planning model used in SPM. It considers the uncertainty and risk associated with project activities and provides a range of possible project completion times. PERT uses three time estimates for each activity: optimistic, pessimistic, and most likely. Based on these estimates, the expected duration and variance of each activity are calculated.

#### 3. Graphical Evaluation and Review Technique (GERT)

GERT is a network planning model that allows loops and conditional branches in the project network. It is useful when the project has complex relationships and dependencies between activities. GERT is an extension of PERT and CPM and is used to model the decision-making process in the project.

#### 4. Monte Carlo Simulation

Monte Carlo Simulation is a statistical technique used in network planning models to identify project risks and uncertainties. It is a computer-based simulation that uses random variables to generate different scenarios of project completion times. Monte Carlo Simulation helps in identifying the probability of project completion within a given time frame.

#### 5. Precedence Diagramming Method (PDM)

PDM is a network planning model used in SPM that uses boxes to represent activities and arrows to represent dependencies. It is a simplified version of CPM and is useful when the project has few dependencies or when the dependencies are easy to understand. PDM is easy to read and understand, making it a popular choice for small projects.

Mnemonics and Learning Tricks:

The network planning models can be remembered using the following mnemonic: CP-GEM. It stands for Critical Path, Program Evaluation, and Review Technique, Graphical Evaluation and Review Technique, Monte Carlo Simulation, and Precedence Diagramming Method.
