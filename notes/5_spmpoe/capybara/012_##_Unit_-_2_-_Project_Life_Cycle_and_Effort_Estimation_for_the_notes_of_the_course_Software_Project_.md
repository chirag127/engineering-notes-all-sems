## Unit - 2 - Project Life Cycle and Effort Estimation for the notes of the course Software Project Management

Project Life Cycle refers to the series of phases that a project goes through from the beginning to the end. Each phase has its own set of deliverables, objectives, and outcomes. The project life cycle is divided into five phases:

1. **Initiation Phase:** This phase is the starting point of the project. In this phase, the project is identified and defined. The main objective of this phase is to determine the feasibility of the project and to define its goals and objectives.

2. **Planning Phase:** In this phase, the project is planned in detail. The project manager creates a project plan, which outlines the scope, schedule, cost, quality, and resources required for the project. The project plan is used as a guide throughout the project.

3. **Execution Phase:** This phase is where the actual work of the project takes place. The project manager assigns tasks to team members, monitors progress, and makes necessary adjustments to the project plan.

4. **Monitoring and Control Phase:** In this phase, the project manager monitors the project's progress, identifies and resolves issues, and controls changes to the project plan.

5. **Closure Phase:** This is the final phase of the project life cycle. In this phase, the project manager ensures that all project deliverables have been completed, conducts a final review of the project, and closes the project.

Effort estimation is the process of predicting the amount of effort required to complete a project. It is an important part of project management because it helps to determine the project's schedule, budget, and resource requirements. There are several methods of effort estimation, including:

1. **Expert Judgment:** This method involves consulting with experts who have experience in similar projects to estimate the effort required for the project.

2. **Analogous Estimation:** This method involves using data from similar projects to estimate the effort required for the current project.

3. **Parametric Estimation:** This method involves using statistical data to estimate the effort required for the project based on the size and complexity of the project.

4. **Three-Point Estimation:** This method involves using three estimates to calculate the average effort required for the project. The three estimates are the best-case scenario, worst-case scenario, and most likely scenario.

Mnemonics and learning tricks:

1. Remember the five phases of the project life cycle using the acronym IPEMC - Initiation, Planning, Execution, Monitoring and Control, and Closure.
2. Use the mnemonic "EAP" to remember the four parameters that need to be estimated during effort estimation - Effort, Availability, Productivity, and Performance.
3. To remember the three-point estimation method, use the mnemonic "BWM" - Best-case scenario, Worst-case scenario, and Most likely scenario.

In conclusion, understanding the project life cycle and effort estimation methods is crucial for successful project management. By using these methods, project managers can ensure that projects are completed on time, within budget, and to the satisfaction of stakeholders.
