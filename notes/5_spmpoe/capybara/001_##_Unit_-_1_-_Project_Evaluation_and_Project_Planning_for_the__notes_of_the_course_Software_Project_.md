## Unit - 1 - Project Evaluation and Project Planning for the notes of the course Software Project Management

Project evaluation and project planning are crucial steps in software project management. They help in determining the feasibility of a project, estimating the resources required, and defining the project scope. In this unit, we will discuss the following topics related to project evaluation and project planning:

### Project Evaluation

1. **Feasibility Study:** It is the first step in project evaluation. A feasibility study helps in determining whether the project is worth investing in or not. It involves analyzing the technical, economic, legal, and operational aspects of the project.

2. **Market Analysis:** Market analysis is the process of identifying the potential customers and competitors of the project. It helps in determining the demand for the product or service being developed and the market size.

3. **Technical Analysis:** Technical analysis involves evaluating the technical aspects of the project such as the software requirements, hardware requirements, and the technical expertise required to complete the project.

4. **Financial Analysis:** Financial analysis helps in determining the financial feasibility of the project. It involves estimating the cost of the project, the revenue projections, and the return on investment.

### Project Planning

1. **Project Scope:** Project scope defines the boundaries of the project. It involves defining the project objectives, deliverables, and the timeline for completion.

2. **Resource Planning:** Resource planning involves estimating the resources required for the project such as personnel, equipment, and materials. It helps in determining the budget for the project.

3. **Risk Management:** Risk management is the process of identifying, assessing, and mitigating the risks associated with the project. It involves developing a risk management plan and monitoring the risks throughout the project lifecycle.

4. **Project Scheduling:** Project scheduling involves creating a detailed timeline for the project. It helps in identifying the critical path, defining the milestones, and tracking the progress of the project.

Mnemonics and Learning Tricks:

1. For remembering the steps involved in project evaluation, use the acronym FTMF, which stands for Feasibility Study, Technical Analysis, Market Analysis, and Financial Analysis.

2. To remember the steps involved in project planning, use the acronym SRSP, which stands for Scope, Resource Planning, Scheduling, and Risk Management.

Remembering these acronyms can be helpful in recalling the steps involved in project evaluation and project planning. However, it is important to note that understanding the concepts and their interrelationships is crucial for effective project management.
